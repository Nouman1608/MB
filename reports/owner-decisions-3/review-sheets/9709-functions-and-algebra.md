## Questions

**1.** The function f is defined by f(x) = x² − 6x + 11 for x ∈ ℝ.

**(a)** Express f(x) in the form (x − a)² + b, where a and b are constants. **[2]**

**(b)** State the range of f. **[1]**

**2.** Find the set of values of k for which the equation 2x² + kx + 8 = 0 has no real roots. **[3]**

**3.** Solve the inequality 2x² − 5x − 12 > 0. **[3]**

**4.** Solve the simultaneous equations 2x + y = 7 and x² + y² = 10. **[5]**

**5.** Solve the equation x⁴ − 13x² + 36 = 0. **[4]**

**6.** The functions f and g are defined by f(x) = 3x − 2 and g(x) = x² + 1, for x ∈ ℝ.

**(a)** Find fg(x) and gf(x), giving each in its simplest form. **[2]**

**(b)** Solve the equation fg(x) = gf(x), giving your answers correct to 3 significant figures. **[4]**

**7.** The function f is defined by f(x) = x² − 4x + 1 for x ≥ 2.

**(a)** Express f(x) in the form (x − a)² + b and hence state the range of f. **[2]**

**(b)** Find an expression for f⁻¹(x). **[3]**

**(c)** State the domain of f⁻¹. **[1]**

**8.** The function g is defined by g(x) = (2x + 3)/(x − 1) for x ∈ ℝ, x ≠ 1.

**(a)** Find an expression for g⁻¹(x). **[3]**

**(b)** State the domain of g⁻¹. **[1]**

**(c)** State the range of g. **[1]**

**9.** The curve y = f(x) has a minimum point at B(4, −1). State the coordinates of the minimum point on each of the following curves.

**(a)** y = f(x) + 3 **[1]**

**(b)** y = f(x − 1) **[1]**

**(c)** y = 2f(x) **[1]**

**(d)** y = f(2x) **[1]**

**(e)** Describe fully the single transformation that maps the curve y = f(x) on to the curve y = f(2x). **[2]**

**10.** The equation x² + kx + (k + 3) = 0 has a repeated root, where k is a constant.

**(a)** Find the two possible values of k. **[4]**

**(b)** Find the repeated root for each value of k. **[2]**

## Mark scheme and full working

Marking key: **M** = method mark, **A** = accuracy mark (depends on the preceding M mark unless stated), **B** = independent mark. "ft" = follow through: a later mark can still be awarded for correct use of an earlier wrong value. Unsupported answers from a calculator score no marks except where a question says otherwise. These conventions are to be confirmed by the teacher.

**1.**

**(a)** x² − 6x + 11 = (x − 3)² − 9 + 11 [B1 for a = 3]; so f(x) = **(x − 3)² + 2** [B1 for b = 2].

**(b)** (x − 3)² ≥ 0 for all real x, so the minimum value of f is 2 and the range is **f(x) ≥ 2** [1].

**2.** Discriminant: k² − 4 × 2 × 8 = k² − 64 [M1]; no real roots means the discriminant is negative: k² − 64 < 0 [M1]; **−8 < k < 8** [A1]. (Accept |k| < 8; not "k < 8" alone.)

**3.** 2x² − 5x − 12 = (2x + 3)(x − 4) [M1]; critical values x = −1.5 and x = 4 [A1]; the curve is a positive U-shape, so it is above the x-axis outside the roots: **x < −1.5 or x > 4** [A1]. (Accept x < −3/2.)

**4.** From the first equation y = 7 − 2x [M1]; substituting: x² + (7 − 2x)² = 10, so 5x² − 28x + 39 = 0 [A1]; solving: (5x − 13)(x − 3) = 0 [M1] (or the quadratic formula: discriminant 784 − 780 = 4); x = 3 or x = 2.6 [A1]; the solutions are **x = 3, y = 1** and **x = 2.6, y = 1.8** [A1].

**5.** Let u = x²: u² − 13u + 36 = 0 [M1]; (u − 4)(u − 9) = 0, so u = 4 or u = 9 [A1]; x² = 4 or x² = 9 [M1]; **x = ±2 or x = ±3** [A1]. (Accept the four values listed; −2, 2, −3, 3.)

**6.**

**(a)** fg(x) = 3(x² + 1) − 2 = **3x² + 1** [B1]; gf(x) = (3x − 2)² + 1 = **9x² − 12x + 5** [B1].

**(b)** Set 3x² + 1 = 9x² − 12x + 5 [M1]; 6x² − 12x + 4 = 0, which simplifies to 3x² − 6x + 2 = 0 [A1]; formula: x = (6 ± √12) ÷ 6 [M1]; **x = 1.58** or **x = 0.423** [A1] (exact: x = 1 ± √3/3). Both values are needed for the A mark.

**7.**

**(a)** f(x) = x² − 4x + 1 = (x − 2)² − 3 [B1]; for x ≥ 2 the smallest value is f(2) = −3 and f increases, so the range is **f(x) ≥ −3** [B1].

**(b)** y = (x − 2)² − 3, so y + 3 = (x − 2)² [M1]; x − 2 = √(y + 3), taking the positive root because x ≥ 2 [B1]; **f⁻¹(x) = 2 + √(x + 3)** [A1].

**(c)** The domain of f⁻¹ is the range of f: **x ≥ −3** [1] (ft from (a)).

**8.**

**(a)** Let y = (2x + 3)/(x − 1); then y(x − 1) = 2x + 3 [M1]; yx − y = 2x + 3, so x(y − 2) = y + 3 [M1]; x = (y + 3)/(y − 2), so **g⁻¹(x) = (x + 3)/(x − 2)** [A1].

**(b)** **x ∈ ℝ, x ≠ 2** [1].

**(c)** The range of g is the domain of g⁻¹: **g(x) ≠ 2** (all real values except 2) [1]. Check: g(x) = 2 + 5/(x − 1), which is never 2.

**9.**

**(a)** Translation up by 3: **(4, 2)** [1].

**(b)** Translation 1 to the right: **(5, −1)** [1].

**(c)** Stretch in the y-direction by factor 2: **(4, −2)** [1].

**(d)** Stretch in the x-direction by factor ½: **(2, −1)** [1].

**(e)** A **stretch** [B1] parallel to the x-axis (the y-axis is invariant) with **scale factor ½** [B1]. (Both parts are needed: "stretch" alone scores one mark; accept "stretch in the x-direction, scale factor 0.5".)

**10.**

**(a)** Repeated root means discriminant = 0: k² − 4(k + 3) = 0 [M1 A1]; k² − 4k − 12 = 0 [M1]; (k − 6)(k + 2) = 0, so **k = 6 or k = −2** [A1].

**(b)** For k = 6: x² + 6x + 9 = (x + 3)² = 0, so **x = −3** [B1]; for k = −2: x² − 2x + 1 = (x − 1)² = 0, so **x = 1** [B1].

## Where marks are usually lost (student-facing note on the page)

- Writing the completed square with the wrong sign for a, or forgetting to subtract a² from the constant (question 1, question 7).
- Solving a quadratic inequality as if it were an equation and giving "−1.5 < x < 4" instead of the two outer regions (question 3).
- Finding x but not y in simultaneous equations, so that the pairs of values are never matched (question 4).
- Stopping at u = 4 and u = 9 in a "quadratic in x²" and forgetting the negative square roots (question 5).
- Reversing the order of composition: fg means "do g first, then f" (question 6).
- Taking the wrong sign of the square root when finding an inverse, instead of using the domain of f to decide (question 7(b)).
- Mixing up the effect on the x-coordinate: f(x − 1) moves the graph right and f(2x) halves the x-values (question 9).
