## S3.3 detail

- Inventory: 21,665 resource pages in the repo; 6,643 (31%) contain figures; 54,579 figure uses; 19,669 distinct images, all on `img.marlbridge.com` (a different host from the pages). Per page: median 7, p95 15, max 25 (Google allows 1,000 per sitemap URL entry). Page types with figures: revision-notes 3,323, lessons/other 3,151, study guides 165, practice 4. Not every one is necessarily in the sitemap (S2's resources group decides).
- Google guidance: image sitemaps are optional; Googlebot discovers `<img src>` in rendered HTML, and these are plain `<img>` in `<figure>` with alt and figcaption. Google dropped `image:caption`, `image:title`, `image:geo_location` and `image:license` in 2022, leaving only `image:loc`, so a sitemap adds no descriptive signal. It helps mainly for images found only via JS. Cross-host `image:loc` (CDN host) is accepted, but the image host should be verified in Search Console. `img.marlbridge.com` is crawlable: its robots.txt contains only comments, images return 200 with `immutable` caching and `cf-cache-status: HIT`.
- Cost: `namespaces.image` is false in `astro.config.mjs` (S2's file); about 54.6k `<image:image>` entries would bloat the resources child sitemaps and require more splitting (50,000 URL / 50 MB per file).
- Verdict: not worthwhile now. Revisit only if Search Console shows images indexing poorly (Performance, search type Image).
