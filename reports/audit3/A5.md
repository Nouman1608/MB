contents anywhere in the repo, and the bucket cannot be listed from here (no credentials, by instruction; the public host
`papers.marlbridge.com` is refused by the proxy, and the README records that its custom domain was not yet connected).

**What was built.** A per-course section on the course page, `CoursePastPapers.astro`, fed by the existing
`courseLibrary(c)` and `courseListing(course)`: heading "Past papers", one line naming the board, the document count and
the year range, the newest two years by series (for example "June 2024": "Paper 4, variant 2: Question paper (PDF),
Mark scheme (PDF)"; "Whole series: Examiner report (PDF)"), each link with the library's full accessible name, and a link
to the full listing. The existing hero link and "About this course" row (D-463) are unchanged. A course with no manifest
entry gets no section, no heading and no link: the "107 of 166 courses have none" situation stays honest until files exist.

**Manifest format (no change; documented in docs/past-papers/README.md).** One JSON file per course,
`src/data/past-papers/courses/<board>-<qualification>-<subject>-<code>.json`:

```json
{
  "board": "cambridge",            // course slugs as in /boards/<board>/<qualification>/<subject>/
  "qualification": "igcse",
  "subject": "chemistry",
  "syllabusCode": "0620",          // one of the course's codes on the site
  "componentWord": "Paper",        // optional: Paper (default) | Unit | Component
  "rightsNote": "...",             // optional: else PAST_PAPER_RIGHTS_NOTES[board] (required, >= 20 chars)
  "files": [
    { "year": 2024, "session": "june", "paper": "4", "variant": "2", "type": "question-paper",
      "file": "https://papers.marlbridge.com/cambridge/0620/2024-june/0620-2024-june-p4-v2-qp.pdf" },
    { "year": 2024, "session": "june", "type": "examiner-report",
      "file": "https://papers.marlbridge.com/cambridge/0620/2024-june/0620-2024-june-er.pdf" }
  ]
}
```

- `session`: `january | march | june | october | november | specimen`, limited per board by `BOARD_SESSIONS`
  (Cambridge: march, june, november, specimen; IB: none, rejected by design).
- `type`: `question-paper | insert | mark-scheme | examiner-report | grade-thresholds`; `paper` is required for the first
  three, optional for the last two (a whole-series document). `variant` optional, as a string.
- `file`: `https://` on `img.marlbridge.com` or `papers.marlbridge.com`, or `/papers/...` under `public/`. Letters, digits,
  `.`, `_`, `-`, `/` only; Cambridge `_ci_` files rejected; no duplicates.
- Recommended object keys in the bucket: `<board>/<code>/<year>-<session>/<code>-<year>-<session>-p<paper>[-v<variant>]-<qp|ms|in|er|gt>.pdf`.
  If the owner can export a bucket listing in that key layout (for example `npx wrangler r2 object list` output, run by
  the owner), each key maps to one `files` line mechanically; a converter can be written once a listing exists.
