### 11. IB MYP and IB DP groups in "Find study resources" (homepage)

**Cause.** The homepage block is `FreeRevisionTools.astro` (A1), but the grouping is in the shared
`src/components/tools/CourseFinder.astro` (used by the homepage in `compact` mode and by `/resources/` in `full` mode).
That file is not in any agent's ownership list, so per the brief I did not edit it.

- In compact mode no qualification heading is rendered (`{full && <H2 data-q-heading ...>}`), and the board heading is
  skipped for the IB (`{b.bs !== 'ib' && (<BoardH>{`${b.b} ${q.q}`}</BoardH>)}`), because "International Baccalaureate IB
  Middle Years Programme" would repeat itself. So the IB MYP and IB DP groups are the only groups with no heading at all,
  and in the HTML they run on straight after the "Pearson Edexcel GCSE" list.
- Live before (homepage, raw HTML, whitespace collapsed):
  `<h4 class="m-0 mb-2 mb-label text-teal-700">Pearson Edexcel GCSE</h4> <ul ...> ... Business ... 1BS0 · 167 resources ... </ul> </div> </section><section data-q-block="ib-myp" aria-label="IB Middle Years Programme" class> <div data-b-block="ib" class="mt-5 scroll-mt-24 first:mt-0"> <ul ...> ... Design (MYP) ...`
  and `data-q-block="ib-dp" aria-label="IB Diploma Programme" class> <div data-b-block="ib" ...> <ul` (no heading).

**Fix (ready to apply, `git apply reports/audit3/A1-coursefinder.patch`, checked with `git apply --check`).** The tree's
board groups get a `heading` field from one rule, `groupHeading(bs, b, q) = bs === 'ib' ? q : `${b} ${q}``, which is the
same rule `courseLabel()` already uses for the course links. The template renders `{b.heading}` for every group, and only
leaves it out in full mode when it would repeat the qualification heading directly above it (IB on `/resources/`, as today).
No heading text is hard-coded.

- After (compact/homepage): `<h4 class="m-0 mb-2 mb-label text-teal-700">IB Middle Years Programme</h4>` before the MYP list,
  `<h4 ...>IB Diploma Programme</h4>` before the DP list. Other groups unchanged ("Pearson Edexcel GCSE", "College Board AP®").
- After (full//resources/): unchanged (IB groups sit under their own H2 "IB Middle Years Programme" / "IB Diploma Programme").
- Not rendered here (no build allowed); the reviewer's build will show it.
