## I361 - Five OxfordAQA data-layer records declare specification versions older than their own resources and the live documents, through a retired path [Inconsistency, Low]

- **Files:** `igcse-oxfordaqa-english-language-paper-1`
- **Where:** src/data/academic/syllabus-topics.ts records for 9270, 9275, 9675, 9230 and 9635, with the legacy oaqaresources sourceUrl lines for those and for 9630 and 9685; src/pages/command-words/index.astro line 95
- **Locate by:** `title: "OxfordAQA International GCSE English Language: Literary Non-fiction and Composition (9270)"`

**What is wrong.** The records declare 9270 Version 4.2, 9275 Version 4.2, 9675 Version 4.1, 9230 Version 3.3 and 9635 Version 2.4, each with a sourceUrl on the retired oaqaresources path, five of them over http. The resources for the same codes declare 9270 5.1, 9275 5.1, 9675 5.3, 9230 4.3 and 9635 3.2, and the specifications linked from OxfordAQA's own qualification pages are exactly those versions. So the data layer disagrees with the corpus it describes. The 9630 record has no version and a legacy path; the linked document is Version 4.4, matching its resources. The 9625 record carries the legacy path only in a notes string. 9685 is not settled. The record says Version 2.2 and the resources say 3.1. OxfordAQA's psychology page currently links a document marked Version 2.2 and "for teaching from September 2016", while the 2022 copy the resources link is Version 3.1, "for teaching from September 2018". The board's own page appears to link the older document, so which is current needs the board. The command-words page also links an oaqaresources path; whether it still resolves was not checked. Revised documents also exist for 9275 (Version 1.0) and 9675 (Version 5.6), and 9725 (Version 1.0); these are successors, not errors in these records.

**Fix.** Declare 5.1, 5.1, 5.3, 4.3 and 3.2 in the five records and link the live copies, as D-238 did for 9201, 9202 and 9620; relink 9630; leave 9685 until the current version is confirmed.

**Evidence.** Specifications linked from OxfordAQA qualification pages for 9230 (v4.3), 9270 (v5.1), 9275 (v5.1; revised v1.0), 9625 (v3.1), 9630 (v4.4), 9635 (v3.2), 9675 (v5.3; revised v5.6), 9685 (v2.2; 2022 copy v3.1), 9725 (v1.0); Cambridge O Level First Language Urdu 3247 syllabuses 721463 (2027, v1) and 664479 (2025-2026). - https://www.cambridgeinternational.org/Images/721463-2027-syllabus.pdf
