# Part 1 — Auditor correction: E491 is downgraded

## E491 — DOWNGRADED from Confirmed error to Inconsistency

The finding's premise was that a command word absent from the board's table is a word the
board does not use. That does not hold. **Cambridge IGCSE Business Studies 0450, Version 2,
section 4, page 26**, and **Cambridge O Level Business Studies 7115, Version 2 (December
2025), page 26** both read, verbatim and identically:

> Command words and their meanings help candidates know what is expected from them in the
> exams. The table below **includes** command words used in the assessment for this
> syllabus. The use of the command word will relate to the subject context.

Both tables list the same eight words: Calculate, Consider, Define, Explain, Identify,
Justify, Outline, State. "Includes" does not close the list — and the 0450 specification's
own subject content then uses **"Recommend and justify"** as an instruction in **thirteen**
content bullets, for example at 2.2.3:

> • Recommend and justify an appropriate leadership style in given circumstances

So `Recommend` is demonstrably board-used in 0450 and 7115, not merely in 9609. The same
applies to `Give`, `List` and `Classify`, the last of which appears in 7115's own content
at 1.2.2.

This is the second time this audit has treated a non-exhaustive command-word table as a
closed list, after the I221 retraction of 12 September. **Standing correction to method:
before any finding asserts that a command word is off-list, quote the table's own preamble
and check the specification's subject content for the word.**

**What survives of E491** is a house-consistency point, not a board-compliance one: a
resource family should use one vocabulary, and the practice papers and their revision-notes
siblings did not. That part was fixed on the eight named files.

**What does not survive** is the instruction to sweep for "off-list" words, and the
rationale recorded in D-188 that rests on it. No further action is required on `Recommend`,
`Suggest`, `Give`, `List` or `Classify` anywhere.

> ***Ratio decidendi*** is the **legal reason for the decision** — this alone is binding on

**`aqa-a-level-psychology-approaches-practice`, question 6(b)** — stem `[6]`, scheme

# Part 3 — New defects

## E664 — Two of four Section A items are set on the wrong half of the source set [Confirmed error, High]

- **File:** `igcse-world-history-international-relations-practice`
- **Locate by:** `Sources A, B and C below are the pre-released three`

**What is wrong.** The file declares Sources A, B and C pre-released and D and E unseen. It
then sets question 1 on Source A and question 3 on Source C — both pre-released. The
specification, §4.4.1, says of both items, verbatim:

> Question 1 tests AO3 and is worth 4 marks. **It is based on an unseen source.**

and for the 8-mark item, that it too is based on an unseen source. The specimen paper's own
allocation confirms the split must run the other way: 01.2 pairs Source A with Source B, and
the 6-mark item requires one unseen source and one pre-released one.

This was introduced by the same rebuild that correctly added the pre-release mechanism for
E556, so the mechanism is now stated accurately and then applied backwards.

**Fix.** Declare B, D and E pre-released and A and C unseen, which satisfies every item
simultaneously, or re-point questions 1 and 3 at D and E.

## E665 — The 8-mark item's mark scheme has three levels where the board's has four [Confirmed error, Medium]

- **File:** `igcse-world-history-international-relations-practice`
- **Locate by:** `Level 1 (1–3):* content only, described generally`

The practice scheme runs Level 1 (1–3), Level 2 (4–5), Level 3 (6–8). The official specimen
mark scheme, items 1.3 and 2.3, uses four levels at 1–2, 3–4, 5–6, 7–8. Every other tariff
in the file matches the board's level boundaries exactly, so this is the single outlier.

**Fix.** Rebuild the 8-mark scheme to four levels on the board's boundaries.

## E666 — The 6-mark item demands provenance the board does not assess there [Confirmed error, Medium]

- **File:** `igcse-world-history-international-relations-practice`
- **Locate by:** `the difference explained using **content and provenance**`

Specification §4.4.1 for the 6-mark item requires students to explain a difference "using
the content of each and their own knowledge". Specimen mark scheme 1.2, Level 3, rewards "a
developed comparison of the sources based on content and relevant knowledge". Provenance
appears nowhere in that item; the practice scheme's top level requires it.

Two smaller mismatches in the same file. Question 3's stem is "**How useful is** Source C…"
where the board's command is "**Why is** Source C useful to a historian studying…" — the
board's phrasing excludes limitations, and "how useful" invites them, which is why the
file's own "Where marks are usually lost" section then has to warn against what its own
stem invites. And question 3's rubric says "content **and/or** provenance" where both the
specification and the specimen require content, provenance and contextual knowledge
together.

**Fix.** Remove provenance from the 6-mark top level; reword question 3's stem to the
board's; change "and/or" to "and".

## E668 — A worked example sets an essay on an option assessed entirely by sources [Confirmed error, Medium]
