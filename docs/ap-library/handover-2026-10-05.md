# Handover: advanced-course (AP) library (updated 5 October 2026, 22:15 PKT)

This note replaces the Phase 1 handover. History: D-389 (Phase 1), D-390 (live), D-391 (programme page), D-392 (Phase 2), D-393 (Phase 3), D-394 (exam-skills guides and facts check).

## Where the library stands

**Live and complete for the 2026-27 frameworks (May 2027 exams).** All 11 courses (Chemistry, Biology, Calculus AB, Calculus BC, Statistics, Physics 1, Physics 2, Physics C: Mechanics, Physics C: E&M, Microeconomics, Macroeconomics) cover every topic in their Course and Exam Descriptions. `npm run report:ap-library` lists 637 of 637 framework topics as drafted.

| Resource type | What it is | Count |
|---|---|---|
| Study guide, revision notes, practice questions, topic checklist | One set per topic (Calculus Units 1-8 written once in `calculus-ab/` as `ab-and-bc` and listed on both Calculus hubs; BC-only topics in `calculus-bc/`) | 556 of each |
| Unit diagnostic | One question per topic, "if you missed this" links, no predicted scores | 72 |
| Mixed unit review | Questions that combine topics, worked solutions, suggested Marlbridge rubrics | 72 |
| Exam-skills guide | Course-wide: (1) task verbs and free-response technique; (2) a course-specific skill (chemistry: explanations, calculations and representations; biology: experimental design and data; calculus: notation and justification; statistics: communicating conclusions; physics: representations, derivations and experimental design; economics: graphs and cause-and-effect explanations) | 20 |

These counts are for internal use only. Site copy never states a resource count.

**Status fields.** Every resource has `editorialStatus: drafted` and carries `checkedBy: marlbridge-academic-team` / `checkedDate: 2026-10-05`. This credit line means the page was independently checked against the 2026-27 framework by a second writer (D-388/D-390 meaning). It does not mean a teacher reviewed it. No page names a reviewer.

**How every page was made.** One writer and one independent verifier per job. Every number was recomputed twice in Python, and a 12-word overlap check ran against the Course and Exam Description. Verifiers replaced anything too close to released exam questions, CED sample questions, textbook problems or the library's own pages. The briefs are in `/home/claude/ap/` (session workspace): `BRIEF_AP.md`, `BRIEF_UNIT.md`, `BRIEF_SKILLS.md` and the matching `VERIFY_*.md`.

**Facts.** Writers checked real-world facts online where they could. The facts they kept without a check are in `facts-pending-online-check-2026-10-05.md` (Phase 2) and `facts-phase3-2026-10-05.md` (Phase 3). Six independent checkers then re-checked all of them online: 287 confirmed, none wrong, and 8 standard statements whose sources could not be reached (`facts-online-check-results-2026-10-05.md`).

## How the pieces fit

- **Content.** `src/content/ap-resources/<course>/*.md`, with the schema in `src/content.config.ts` (`apResources`).
- **Frameworks and sources.** `src/data/ap/frameworks.ts` and `src/data/ap/sources.ts`. These are the only places for exam-format facts.
- **Pages.** `src/pages/advanced-course-resources/`:
  - The course hub lists unit diagnostics and reviews under their unit, and the exam-skills guides in their own "Exam skills" section.
  - Resource pages show "Whole course" scope for exam-skills guides.
- **Exam-skills guides.** They use the course's first unit number (1; Physics 2: 9; Physics C: E&M: 8) as a marker and have empty `topics`.
- **Validator.** `scripts/validate-ap-library.mjs` runs inside `npm run build`. It checks structure, ids, links, review honesty, the credit line and minimum substance by type.
- **Schema limits enforced by the build.** Title at most 110 characters; description 70-220 characters.
- **Audit traps seen so far.** Run `npm run audit:all` after content changes. These have tripped it before:
  - An SVG path command like `Q20,230` reads as an audit ID, so write `Q 20,230`.
  - A labelled symbol like `U12` also reads as an audit ID; write `U₁₂`.
  - A list line starting `- [X]` renders as a checkbox.
  - Two pages with identical descriptions fail the audit.
