## 4. Real bugs found and fixed this session

Three genuine, previously-undiscovered bugs surfaced by actually running the gate (rather than assuming it would pass) were root-caused and fixed with minimal, targeted edits:

1. **`scripts/validate-assessments.mjs`** — falsely rejected the OCR A Level Business H436 future-syllabus transition record because `syllabuses.ts` only records one "current" code (H431) per board+qualification+subject. Fixed to also accept a match via the assessment record's `relatedCode` field. Commit `840c0d6`.

2. **`scripts/audit-content-integrity.mjs`** — a hardcoded forward-slash substring filter against raw filesystem paths never matched on Windows (which uses backslash via `path.join()`), silently making the entire audit a no-op (`hubPagesChecked` always 0, vacuous pass). Fixed to filter on the pre-existing URL-path normalizer instead. Now correctly checks 160 hub pages. Commit `56735be`.

3. **`scripts/test-negative-validation-suite.mjs`** — the shared `withMutation()` test helper read files without normalizing line endings, so literal multi-line search-and-replace patterns silently failed to match on a Windows checkout with `core.autocrlf=true` (CRLF line endings), throwing an uncaught error that crashed the whole suite. Fixed to normalize to LF before mutation and re-apply CRLF on write-back only if the file originally had it. Commit `587ddd6`.

Also committed: 53 missing legacy-slug redirects for resource pages that already existed on disk but had never been added to `public/_redirects` (commit `f4b7302`), and a line-ending normalization of `public/llms.txt` (commit `3647074`).
