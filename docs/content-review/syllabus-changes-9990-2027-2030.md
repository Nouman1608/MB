## 2027: equivalent, no page needs to change

Subject content (3.1 AS Level, 3.2 A Level with the four specialist options) and the details of the assessment (Papers 1 to 4: durations, marks, sections, weightings, command words, planning studies) are the same in meaning. The 2027 syllabus says there are "no significant changes which affect teaching" (pp. 3, 61).

The only additions are a general note in the section 3 introduction that ICD-11 terms are used (alternative terms accepted), which repeats the note already at the start of Specialist Option 1, plus wording and layout changes.

Result: the taxonomy now has a 2027 record that reuses the 2024-2026 topics and slugs. The resources filed under "2024-2026" stay valid for 2027.

## 2028-2030: topics and assessment unchanged, wording changed

Cambridge describes "very minor changes ... to improve clarity" (p. 61). Core studies, option and sub-topic numbers and Papers 1 to 4 are unchanged. Changes a resource would have to follow (page numbers are of the 2028-2030 PDF unless stated):
