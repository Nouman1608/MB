# A-level topic gaps sprint (D-399, 6 October 2026)

## What was done

Every topic that had no page in six weak specifications now has a study guide, revision notes and a practice set.
That is 110 topics and 330 new pages.

|---|---|---|
| AQA A-level Chemistry (7405) | 31 | Version 1.2, July 2026 |
| AQA A-level Mathematics (7357) | 18 | Version 1.3, 31 January 2018 |

| Cambridge O Level Biology (5090) | 16 | 2026-2028 syllabus |

After the sprint, `npm run coverage:academic-v2` reports zero topics without resources for all six.

**How each topic was made.**
- One writer wrote the three pages, and an independent verifier then checked them.
- Every number was recomputed in Python twice: the writers' scripts are in `/home/claude/gaps/checks/` and the verifiers' in `/home/claude/gaps/verify/` (session workspace).
- Every learning outcome in the official text was mapped to where it is taught.
- Practice questions are original.

## Facts check

Eight checkers searched online for the real-world facts on these pages that the official texts don't state. Results with sources are in `facts-check/`.
- **Corrected:**
  - COUNT counts numeric cells, not rows (7357).
  - A g value of 9.7 was given for a real place; it is now 9.78 (7357).
  - IAS 7 interest and dividends choice: now says "currently", with a note on IFRS 18 from 2027 (7127).
  - Pivot tables may refresh automatically in newer versions (9626).
- **Softened:**
  - IPv6 "ran out" became "were running out".
  - Perrin's year was removed.
  - "Only the liver" became "the liver".
  - "All ethanol evaporates" became "most".
  - Visking tubing: sucrose passes "more slowly".
