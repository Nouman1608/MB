## Key terms

| Term | Meaning | Example |
|---|---|---|
| Ordinality | The position of a number in an ordered list | 0.399 comes before 0.4 |
| Ascending | Smallest first | 3/8, 0.399, 0.4, 41% |
| Descending | Largest first | 41%, 0.4, 0.399, 3/8 |
| Integer | A whole number, positive, negative or zero | −3, 0, 12 |
| Common denominator | A shared denominator for comparing fractions | 24 for 2/3, 5/8, 7/12 |
| Cross-multiplying | Comparing a/b and c/d by a × d and b × c | 4/9 vs 5/11: 44 < 45 |
| Inequality symbol | A sign showing which value is larger | 3/7 < 0.43 |

## Method summary

```
1. Convert every value to one form (usually decimals).
2. Write every decimal to the same number of places (4 is safe).
3. Place negatives first; among negatives, the larger size is smaller.
4. Compare digit by digit from the left.
5. Write the final list in the ORIGINAL forms.
```

## Quick comparisons

| Shortcut | Example |
|---|---|
| Same numerator: larger denominator is smaller | 5/9 < 5/8 |
| Same denominator: larger numerator is larger | 7/12 < 11/12 |
| Benchmark 1/2: numerator less than half the denominator means below 1/2 | 4/9 < 1/2 < 5/9 |
| Cross-multiply | 4/9 vs 5/11: 4 × 11 = 44, 9 × 5 = 45, so 4/9 < 5/11 |
| Benchmark 1: improper fractions and percentages over 100% are above 1 | 5/4 > 1 > 99% |

## Negatives

```
−0.6 < −0.52 < −0.5 < −0.45
the value furthest from 0 is the smallest
```

Order the sizes, then reverse.

## Between two values

- Convert both to a common denominator; if there is no gap, double the denominator.
- Or convert to decimals and choose a value in between: between 2/5 and 1/2 lie 0.45, 9/20 and 47%.

## Symbols and words

| Symbol | Words |
|---|---|
| < | less than, under, below |
| > | more than, over, above, exceeds |
| ≤ | at most, no more than, maximum, up to and including |
| ≥ | at least, no fewer than, minimum |
| = | equal to |
| ≠ | not equal to |

The open side faces the larger value. ≤ and ≥ include the end value; < and > do not.

## Worked reminder

Order 0.72, 3/4, 72.5% and 18/25, largest first.

```
3/4   = 0.7500
72.5% = 0.7250
0.72  = 0.7200
18/25 = 72/100 = 0.7200
largest first: 3/4, 72.5%, then 0.72 and 18/25 (equal)
```

When two values are equal, say so, or write them with = between them in the list: 3/4, 72.5%, 0.72 = 18/25.

## Closest to a target

Subtract to find each distance from the target, ignore the sign, then pick the smallest distance. For values near 1/2, use 0.5 as the target: 0.505 is closer than 0.47, because 0.005 < 0.03.

## Exam traps

- **Longer decimal assumed larger:** 0.399 < 0.4.
- **Larger denominator assumed larger:** 5/9 < 5/8.
- **Negatives ordered by size:** −3/5 is smaller than −1/2.
- **Converted forms left in the answer** instead of the original forms.
- **Too few decimal places** to separate close values such as 5/8, 0.628 and 0.63.
- **2/3 treated as 0.67:** they are not equal; 2/3 < 0.67.
- **Wrong direction** in the answer: read "smallest first" or "largest first" twice.
- **≤ and < confused** when listing integers: −3 < n excludes −3.

## Quick self-test

1. Write 0.4, 3/8, 41% and 0.399 in order, smallest first.
2. Which is larger, 4/9 or 5/11? Show how you decide.
3. Write −1/2, −0.45, −3/5 and −52% in order, smallest first.
4. Write 1 1/3, 130%, 1.34 and 5/4 in order, smallest first.
5. Insert <, > or = : 0.7 ... 7/10
6. Insert <, > or = : 3/7 ... 0.43
7. Insert <, > or = : 0.33 ... 1/3
8. Write down a fraction between 2/5 and 1/2.
9. A lift carries at most 12 people. Write this with n for the number of people and an inequality symbol.
10. List the integers n such that −3 < n ≤ 2.
11. Which is larger: 0.666... (0.6 recurring) or 0.67?
12. Use a common denominator to write 2/3, 5/8 and 7/12 in order, smallest first.

### Answers

1. 0.375, 0.399, 0.400, 0.410: **3/8, 0.399, 0.4, 41%**.
2. 4 × 11 = 44 and 9 × 5 = 45, so **5/11** is larger.
3. −0.6, −0.52, −0.5, −0.45: **−3/5, −52%, −1/2, −0.45**.
4. 1.25, 1.30, 1.333..., 1.34: **5/4, 130%, 1 1/3, 1.34**.
5. **=**
6. 3/7 = 0.4285..., so **<**
7. 1/3 = 0.333..., so **<**
8. For example **9/20** (= 0.45).
9. **n ≤ 12**.
10. **−2, −1, 0, 1, 2**.
11. **0.67**.
12. 16/24, 15/24, 14/24, so **7/12, 5/8, 2/3**.
