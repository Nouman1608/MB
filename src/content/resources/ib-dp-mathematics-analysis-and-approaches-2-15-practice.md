This set covers **section 2.15 (AHL only)** of IB DP Mathematics: Analysis and Approaches, first assessment 2021: solving g(x) ≥ f(x) graphically and analytically. Questions are calculator-free unless marked "(calculator allowed)". Revise the method first in the [inequalities study guide](/resources/ib-dp-mathematics-analysis-and-approaches-2-15/) and the [inequalities revision notes](/resources/ib-dp-mathematics-analysis-and-approaches-2-15-revision-notes/).

## Section A

**1.** Solve (x + 1)(x − 2)(x − 5) ≥ 0. **[2]**

**2.** Solve x³ < 16x. **[3]**

**3.** Solve (x − 3)²(x + 2) ≤ 0. **[3]**

**4.** Solve 7x − x³ − 6 ≥ 0. **[4]**

**5.** Solve (2x − 1)/(x + 3) ≥ 1. **[4]**

**6.** For two functions, g(x) − f(x) = (x + 2)(x − 1)(x − 3). Write down the solution of g(x) < f(x). **[2]**

## Section B

**7.** Let p(x) = x³ − 4x² + x + 6.

**(a)** Show that (x + 1) is a factor of p(x). **[1]**
**(b)** Factorise p(x) fully. **[2]**
**(c)** Hence solve x³ + x + 6 ≥ 4x². **[2]**
**(d)** Solve p(x) > 6, giving your answer in exact form. **[4]**

**8.** Solve x³ + 2x² ≥ 4x + 8. **[5]**

**9.** Find the set of values of k for which x² − kx + k + 3 > 0 for all real x. **[4]**

**10.** (calculator allowed) Solve 2 sin x ≥ x² − 1, where x is in radians. **[4]**

**11.** (calculator allowed) Solve ln x ≤ x − 2. **[4]**

**12.** An open box is made from a rectangular sheet of card 10 cm by 8 cm by cutting a square of side x cm from each corner and folding up the sides.

**(a)** Show that the volume of the box is V = 4x³ − 36x² + 80x. **[2]**
**(b)** Write down the possible values of x. **[1]**
**(c)** Without using a calculator, find the values of x for which the volume is at least 48 cm³. **[5]**

## Answers

**1.** Signs −, +, −, + across −1, 2, 5 [1]: −1 ≤ x ≤ 2 or x ≥ 5 [1]

**2.** x³ − 16x < 0, so x(x − 4)(x + 4) < 0 [1]. Signs −, +, −, + across −4, 0, 4 [1]: x < −4 or 0 < x < 4 [1]
*Examiner insight:* Dividing by x gives x² < 16, that is −4 < x < 4, which is wrong for −4 < x ≤ 0 and misses x < −4.

**3.** (x − 3)² ≥ 0, so the sign is that of (x + 2), with zero at x = 3 [1]. x ≤ −2 [1] or x = 3 [1]

**4.** Multiply by −1 and reverse: x³ − 7x + 6 ≤ 0 [1]. x = 1 is a root, so x³ − 7x + 6 = (x − 1)(x − 2)(x + 3) [1]. Signs −, +, −, + across −3, 1, 2 [1]: x ≤ −3 or 1 ≤ x ≤ 2 [1]

**5.** (2x − 1)/(x + 3) − 1 ≥ 0 [1], so (x − 4)/(x + 3) ≥ 0 [1]. Critical values −3 and 4; signs +, −, + [1]: x < −3 or x ≥ 4 [1]
*Examiner insight:* Multiplying both sides by (x + 3) gives x ≥ 4 only, losing x < −3 where x + 3 is negative.

**6.** g − f < 0: signs −, +, −, + across −2, 1, 3 [1], so x < −2 or 1 < x < 3 [1]

**7. (a)** p(−1) = −1 − 4 − 1 + 6 = 0, so (x + 1) is a factor [1]
**(b)** p(x) = (x + 1)(x² − 5x + 6) [1] = (x + 1)(x − 2)(x − 3) [1]
**(c)** The inequality is p(x) ≥ 0 [1]: −1 ≤ x ≤ 2 or x ≥ 3 [1]
**(d)** x³ − 4x² + x > 0, so x(x² − 4x + 1) > 0 [1]. Roots 0 and 2 ± √3 [1]. Signs −, +, −, + across 0, 2 − √3, 2 + √3 [1]: 0 < x < 2 − √3 or x > 2 + √3 [1]

**8.** x³ + 2x² − 4x − 8 ≥ 0 [1]. x²(x + 2) − 4(x + 2) = (x + 2)(x² − 4) [1] = (x + 2)²(x − 2) [1]. The squared factor does not change sign, so the expression is ≥ 0 for x ≥ 2 [1], and also at x = −2 [1]
Final answer: x ≥ 2 or x = −2.

**9.** Discriminant must be negative: k² − 4(k + 3) < 0 [1], so k² − 4k − 12 < 0 [1]. (k − 6)(k + 2) < 0 [1], giving −2 < k < 6 [1]

**10.** Intersections of y = 2 sin x and y = x² − 1 at x = −0.423 [1] and x = 1.73 [1] (3 s.f.). At x = 0, 0 ≥ −1, so 2 sin x is above between them [1]: −0.423 ≤ x ≤ 1.73 [1]
*Examiner insight:* There are no other intersections: for |x| > √3 the parabola exceeds 2, the largest value of 2 sin x.

**11.** Domain x > 0 [1]. Intersections at x = 0.159 [1] and x = 3.15 [1]. ln x lies below the line outside these values: 0 < x ≤ 0.159 or x ≥ 3.15 [1]
*Examiner insight:* "x ≤ 0.159" alone includes negative values, where ln x is undefined.

**12. (a)** Length 10 − 2x, width 8 − 2x, height x [1]. V = x(10 − 2x)(8 − 2x) = x(80 − 36x + 4x²) = 4x³ − 36x² + 80x [1]
**(b)** 0 < x < 4 [1]
**(c)** 4x³ − 36x² + 80x − 48 ≥ 0, so x³ − 9x² + 20x − 12 ≥ 0 [1]. x = 1 is a root [1], so the cubic is (x − 1)(x − 2)(x − 6) [1]. Signs −, +, −, + across 1, 2, 6 gives 1 ≤ x ≤ 2 or x ≥ 6 [1]. With 0 < x < 4: 1 ≤ x ≤ 2 [1]

## Where marks are usually lost

- Dividing by x or multiplying by a denominator of unknown sign.
- Ignoring a double root, or forgetting its isolated solution.
- Forgetting to reverse the inequality after multiplying by −1.
- Giving only the boundary values from a GDC, with no interval.
- Ignoring the domain of a logarithm or the context of a model.
