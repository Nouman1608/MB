Condensed notes for subtopic **1.5 Ordering** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027. The [Ordering study guide](/resources/cambridge-o-level-mathematics-4024-ordering/) explains each method with worked examples; the [Ordering practice questions](/resources/cambridge-o-level-mathematics-4024-ordering-practice/) give exam-style questions with mark schemes.

## Syllabus outcome

Order quantities by magnitude and demonstrate familiarity with the symbols =, ≠, >, <, ⩾ and ⩽.

## Key terms

| Term | Meaning |
|---|---|
| Magnitude | size of a quantity |
| Ascending | smallest first |
| Descending | largest first |
| Inequality | statement using >, <, ⩾ or ⩽ |
| Strict inequality | uses > or <; the end value is not included |
| Boundary value | the number at the end of the range |

## Symbols

| Symbol | Meaning | Includes end value? |
|---|---|---|
| = | equal to | yes |
| ≠ | not equal to | not applicable |
| > | greater than | no |
| < | less than | no |
| ⩾ | greater than or equal to | yes |
| ⩽ | less than or equal to | yes |

Words to symbols:

| Words | Symbol |
|---|---|
| at least | ⩾ |
| at most, no more than | ⩽ |
| more than, exceeds | > |
| fewer than, below | < |
| between 3 and 8 (not including) | 3 < x < 8 |
| from 3 to 8 inclusive | 3 ⩽ x ⩽ 8 |

## Methods

| Type | Method |
|---|---|
| Integers | use a number line; more negative means smaller |
| Decimals | line up the places, add zeros, compare from the left |
| Fractions | common denominator, or divide to get decimals |
| Mixed forms | convert everything to decimals |
| Powers and roots | evaluate or bracket between perfect squares or cubes |
| Standard form | compare the powers of 10 first, then the front numbers |
| Prices | find the cost per unit |

## Worked examples

### Negative numbers

```
-11 < -8 < -4 < 0 < 7
```

The smallest is the negative number furthest from zero. The gap from -11 to 7 is 18.

### Decimals

```
0.45, 0.405, 0.5     →   0.450, 0.405, 0.500
ascending:  0.405, 0.45, 0.5
```

### Fractions

```
4/7 = 48/84   and   7/12 = 49/84
so 4/7 < 7/12
```

### Mixed forms

```
3/5, 0.58, 61%, 5/9   →   0.6, 0.58, 0.61, 0.5556
ascending:  5/9, 0.58, 3/5, 61%
```

### Powers

```
2^-3 = 0.125,  1/9 = 0.111...,  11% = 0.11,  0.1
descending:  2^-3, 1/9, 11%, 0.1
```

### Roots without a calculator

```
5.4^2 = 29.16 < 30      so  √30 > 5.4
5.4^3 = 157.464 > 150   so  ∛150 < 5.4
ascending:  ∛150, 5.4, √30
```

## Fractions with the same top or bottom

| Situation | Rule | Example |
|---|---|---|
| Same denominator | bigger numerator is bigger | 5/9 > 4/9 |
| Same numerator | smaller denominator is bigger | 3/5 > 3/8 |
| Different both | cross-multiply or use decimals | 4/7 < 7/12 |

Cross-multiplying: compare 4 × 12 = 48 with 7 × 7 = 49; the larger product sits on the side of the larger fraction.

## Listing integers in a range

| Inequality | Integers |
|---|---|
| -3 < x ⩽ 2 | -2, -1, 0, 1, 2 |
| 4 ⩽ x < 9 | 4, 5, 6, 7, 8 |
| -2 ⩽ x ⩽ 2 | -2, -1, 0, 1, 2 |
| 0 < x < 5 | 1, 2, 3, 4 |

On a number line, a filled circle means the end is included. An open circle means it is not.

|---|---|
| 0.75 and 3/4 | = |
| 2/3 and 0.67 | ≠ |

| 50% and 1/2 | = |

## Value for money

Compare the cost per item (price ÷ quantity) or the quantity per unit of money. Always use the same unit for all the offers.

## Ordering in context

| Task | Working | Result |
|---|---|---|
| Order 17/20, 80%, 0.84, 4/5 | 0.85, 0.8, 0.84, 0.8 | 80% = 4/5 < 0.84 < 17/20 |
| Largest of 5/7, 8/11, 13/18 | 0.714, 0.727, 0.722 | 8/11 |
| Smallest of 0.3, 1/4, 28% | 0.3, 0.25, 0.28 | 1/4 |
| Order -0.4, -1/3, -0.35 | -0.4, -0.333, -0.35 | -0.4 < -0.35 < -1/3 |

Two quantities that are equal share a position in the list. Write them next to each other and use = between them.

## Common phrases in questions

| Phrase | What to do |
|---|---|
| Write in order of size | check the direction; if none is stated, smallest first is standard |
| Write down the largest | pick one value and check the others against it |
| Put the correct sign between | use <, > or = |
| List the integers | check each end against the inequality sign |
| Which is better value | compare the cost per unit |

## Exam traps

- A negative number with a bigger digit is smaller: -7 < -2.
- Check whether the answer is ascending or descending.
- A strict inequality leaves out the end value.
- Longer decimals are not automatically larger.
- Convert to a common form and show it.
- 0.666... is not equal to 0.67.
- In compound inequalities such as -3 < x ⩽ 2, check each end separately.
- Give the final order in the form used in the question when asked to "write the numbers".

## Self-test

1. Put the correct symbol, < or >, between -6 and -2.
2. Write in order, smallest first: 0.3, 1/4, 28%, 0.29.
3. Which is greater, 5/6 or 7/9?
4. List the integers x where -1 ⩽ x < 4.
5. Write an inequality for "y is greater than 2 and at most 10".
6. Put in order, largest first: 3.2 × 10⁻², 4.1 × 10⁻³, 2.9 × 10⁻².
7. Is 0.3̇ equal to 0.33?
8. Which is cheaper per litre: 4 litres for $7.20 or 6 litres for $10.50?

**Answers**

1. **-6 < -2**.
2. 1/4 = 0.25 and 28% = 0.28, so **1/4, 28%, 0.29, 0.3**.
3. 5/6 = 15/18 and 7/9 = 14/18, so **5/6**.
4. **-1, 0, 1, 2, 3**.
5. **2 < y ⩽ 10**.
6. **3.2 × 10⁻², 2.9 × 10⁻², 4.1 × 10⁻³**: the power -2 is larger than -3, and 3.2 is larger than 2.9.
7. **No**: 0.3̇ = 0.333..., which is greater than 0.33.
8. 7.20 ÷ 4 = $1.80 and 10.50 ÷ 6 = $1.75, so the **6-litre** pack is cheaper.
