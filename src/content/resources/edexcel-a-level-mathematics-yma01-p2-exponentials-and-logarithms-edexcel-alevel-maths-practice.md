These questions cover section 5 of Unit P2 (YMA01, Issue 3): the graph of y = aˣ, the laws of logarithms and the solution of aˣ = b. Revise first with the [P2 exponentials and logarithms study guide](/resources/edexcel-a-level-mathematics-yma01-p2-exponentials-and-logarithms-edexcel-alevel-maths/) and the [P2 exponentials and logarithms revision notes](/resources/edexcel-a-level-mathematics-yma01-p2-exponentials-and-logarithms-edexcel-alevel-maths-revision-notes/). ## Section A

**1.** Without a calculator, find the value of log₂ 8 + log₂(1/4). **[2]**

**2.** Without a calculator, show that ½ log₃ 81 + log₃ 6 − log₃ 2 = 3. **[3]**

**3.** Solve 7²ˣ⁻¹ = 40, giving your answer to 3 significant figures. **[3]**

**4.** The curve with equation y = k aˣ, where k and a are positive constants, passes through the points (1, 6) and (3, 54). Find k and a. **[3]**

## Section B

**5.** Solve log₂(x + 6) − log₂(x − 1) = 3. **[4]**

**6.** Solve log₄(x + 2) + log₄(x − 4) = 2, explaining why any other root of your working must be rejected. **[5]**

**7.** **(a)** Show that the solution of 2³ˣ = 5ˣ⁻¹ can be written as x = −log 5 ÷ log 1.6. **[3]**

**(b)** Hence find x to 3 significant figures. **[1]**

**8.** Solve 7²ˣ − 8(7ˣ) + 15 = 0, giving your answers to 3 significant figures. **[5]**

**9.** Solve 3²ˣ⁺¹ − 10(3ˣ) + 3 = 0. **[5]**

**10.** The number of bacteria in a culture t hours after observation begins is modelled by N = 500 × 1.2ᵗ.

**(a)** State the number of bacteria when observation begins. **[1]**

**(b)** Find the number of complete hours after which the model first predicts more than 10 000 bacteria. **[3]**

**11.** Solve the simultaneous equations

log₃ x + log₃ y = 4

log₃ x − 2 log₃ y = 1

where x > 0 and y > 0. **[6]**

**12.** The sum of the first n terms of a geometric series is Sₙ = 4(1 − 0.75ⁿ). Find the smallest value of n for which Sₙ > 3.96. **[4]**

## Answers

**1.** log₂ 8 = 3 and log₂(1/4) = −2 [1], so the value is **1** [1].

**2.** ½ log₃ 81 = log₃ 81^½ = log₃ 9 [1]. log₃ 9 + log₃ 6 − log₃ 2 = log₃(9 × 6 ÷ 2) = log₃ 27 [1] = 3, since 3³ = 27 [1].

**3.** (2x − 1) log 7 = log 40 [1], so 2x − 1 = log 40 ÷ log 7 = 1.8957... [1], and x = 2.8957... ÷ 2 = **1.45** [1].

**4.** ka = 6 and ka³ = 54 [1]. Dividing: a² = 9, so a = 3 (a > 0) [1], and k = 6 ÷ 3 = **2** [1]. So **k = 2, a = 3**.

**5.** log₂((x + 6)/(x − 1)) = 3 [1], so (x + 6)/(x − 1) = 2³ = 8 [1]. x + 6 = 8x − 8 [1], so 7x = 14 and **x = 2** [1]. (Check: x + 6 = 8 and x − 1 = 1 are both positive.)

**6.** log₄((x + 2)(x − 4)) = 2 [1], so (x + 2)(x − 4) = 4² = 16 [1]. x² − 2x − 8 = 16, so x² − 2x − 24 = 0 and (x − 6)(x + 4) = 0 [1]. x = 6 or x = −4 [1]. When x = −4, x − 4 = −8 and log₄(−8) is undefined, so x = −4 is rejected and **x = 6** [1].

**7. (a)** Taking logs: 3x log 2 = (x − 1) log 5 [1]. 3x log 2 − x log 5 = −log 5, so x(log 8 − log 5) = −log 5 [1]. log 8 − log 5 = log 1.6, so x = −log 5 ÷ log 1.6 [1].

**(b)** **x = −3.42** [1].

Total: 4

**8.** Let y = 7ˣ: y² − 8y + 15 = 0 [1], so (y − 3)(y − 5) = 0 and y = 3 or y = 5 [1]. 7ˣ = 3 gives x = log 3 ÷ log 7 [1] = **0.565** [1]; 7ˣ = 5 gives x = log 5 ÷ log 7 = **0.827** [1].

**9.** 3²ˣ⁺¹ = 3 × (3ˣ)², so with y = 3ˣ: 3y² − 10y + 3 = 0 [1] [1] (one mark for the rewrite, one for the quadratic). (3y − 1)(y − 3) = 0 [1], so y = ⅓ or y = 3 [1]. 3ˣ = ⅓ gives **x = −1**; 3ˣ = 3 gives **x = 1** [1].

**10. (a)** When t = 0, N = 500 × 1 = **500** [1].

**(b)** 500 × 1.2ᵗ > 10 000, so 1.2ᵗ > 20 [1]. t > log 20 ÷ log 1.2 = 16.43 [1]. So the model first predicts more than 10 000 after **17 hours** [1]. (Check: N ≈ 9244 at t = 16 and N ≈ 11 093 at t = 17.)

Total: 4

**11.** The first equation gives log₃(xy) = 4, so xy = 81 [1] [1]. The second gives log₃(x/y²) = 1 [1], so x = 3y² [1]. Substituting: 3y³ = 81, so y³ = 27 and **y = 3** [1]. Then **x = 27** [1]. (Check: log₃ 27 + log₃ 3 = 3 + 1 = 4 and log₃ 27 − 2 log₃ 3 = 3 − 2 = 1.)

**12.** 4(1 − 0.75ⁿ) > 3.96, so 1 − 0.75ⁿ > 0.99 and 0.75ⁿ < 0.01 [1]. n log 0.75 < log 0.01; log 0.75 < 0, so the inequality reverses: n > log 0.01 ÷ log 0.75 [1] = 16.008 [1]. The smallest value is **n = 17** [1]. (0.75¹⁶ ≈ 0.01002 is just too large, and 0.75¹⁷ ≈ 0.0075.)

## Where marks are usually lost

- Writing log₂ 8 + log₂(1/4) as log₂(8¼), or confusing log₂(1/4) with ¼.
- In Questions 5 and 6, solving the quadratic or linear equation without first combining the logarithms correctly.
- Keeping a root that makes the argument of a logarithm negative, as with x = −4 in Question 6.
- Treating 3²ˣ⁺¹ as 3(3ˣ) + 1 or as (3ˣ)² + 1 in Question 9.
- Forgetting to reverse the inequality when dividing by log 0.75 in Question 12, which gives n < 16.008 and no sensible answer.
- Rounding 16.008 to 16 in Question 12: the value of n must be a whole number above the boundary.
