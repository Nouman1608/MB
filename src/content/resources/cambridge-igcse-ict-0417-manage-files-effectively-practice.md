## Answers

**1.** C: .txt. **[1]**

**2.** Bringing data from a file of a different type into the application currently being used (1). **[1]**

**3.** Any two: uses up to 256 colours (1); lossless compression (1); supports simple animation (1); supports transparency (1). **[2]**

**4.** Any one: .accdb (1); .odb (1); .sdb (1). **[1]**

**5.** Any two: use the file manager's search box with the part of the name (1); open the application's recent files list (1); sort the folder by name so similar names are together (1). **[2]**

**6.** HTML view shows the markup behind the page, so the examiner can check the tags and attributes used (1). **[1]**

**7. (a)** Any three: a top-level folder for the practice (1); subfolders by type of file, such as Patients, Appointments, Staff and Finance (1); further subfolders within these, for example by year inside Finance (1); files inside named descriptively (1).

**(b)** Any two: files can be found more quickly because staff know where each type is kept (1); related files are kept together, so they can be backed up or moved together (1); less chance of saving over or deleting the wrong file (1). **[5]**

**8. (a)** Any two: plain text (1); one record per line (1); fields separated by commas (1); can be opened by most spreadsheet and database software (1).

**(b)** Any two: that the first row has been used as field names (1); that each field has the correct data type, such as date or number (1); that all 150 records have been imported (1); that no data has been split into the wrong fields (1). **[4]**

**9. (a)** .rtf (1), because it keeps basic formatting and can be opened and edited in most word processors (1).

**(b)** .pdf (1), because it keeps the exact layout, fonts and images on any device and cannot easily be changed by accident (1).

**(c)** .txt (1), because it holds only the characters with no formatting (1). **[6]**

**10. (a)** .jpg (1), because its lossy compression gives a small file while keeping millions of colours, so the page loads quickly (1).

**(b)** .png (1), because it supports transparency and lossless compression keeps the logo's edges sharp (1). Accept .gif with the transparency reason. **[4]**

**11.** Saving keeps the spreadsheet in the application's own format, with formulas, formatting, charts and all worksheets (1). Exporting as .csv writes a separate copy in a generic format (1) that keeps only the data values from one sheet, so formulas and formatting are lost (1). **[3]**

**12.** Any four: the recipient may use different software or a different operating system, so a generic format such as .pdf or .rtf can still be opened (1); data can be moved between different applications, for example .csv from a spreadsheet to a database (1); files remain readable in the future even if the original software is no longer available (1); web formats such as .htm, .css, .jpg and .png can be displayed in any browser (1); .txt can be opened by almost any program (1). Maximum 4. **[4]**

## Frequently asked questions

**Is .rtf an application format or a generic format?**
The 0417 syllabus lists it in both groups. It is saved by word processors, and it can be opened by most of them, which is why it is useful for moving formatted text.

**Will renaming report.docx to report.pdf convert it?**
No. Changing the extension by hand does not change the data inside. Use Save as or Export to create a real PDF.
