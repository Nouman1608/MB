## Section A: short answers

**1.** Which of these is skipped during a slide show but remains in the presentation file?

A: a deleted slide

B: a hidden slide

C: a slide with presenter notes

D: a slide with a transition **[1]**

**2.** State what is meant by a *call out box*. **[1]**

**3.** Name **two** types of moving image or media that the syllabus says can be inserted on a slide. **[2]**

**4.** A presentation has 14 slides. A new slide is inserted after slide 5. State the new number of the slide that was slide 9. **[1]**

**5.** State **one** purpose of adding alternative text to an image. **[1]**

**6.** State the difference between a transition and an animation. **[2]**

## Section B: structured questions

**7.** A presentation for a garden centre has nine slides. Carry out these instructions in order and answer the questions.

- Insert a new slide after slide 2.
- Move the slide that is now slide 8 so that it becomes slide 3.
- Delete slide 10.

**(a)** State how many slides there are at the end.

**(b)** State the original number of the slide that was deleted.

**(c)** Explain why the order in which the instructions are carried out matters. **[4]**

**8.** Slide 1 of a club's presentation is a menu with the text *Events*, *Membership* and *Contact*.

**(a)** Describe how to make the text *Events* go to the slide titled *Events* when clicked.

**(b)** Describe how to make the text *Contact* open a new email to the club's address.

**(c)** Each content slide needs a button that returns to the menu. Describe how to add it. **[6]**

**9.** A student adds a hyperlink from an image to a price list spreadsheet. On another computer, clicking the image gives an error.

**(a)** Suggest **one** reason why the link no longer works.

**(b)** Describe how the student could prevent this problem. **[2]**

**10.** A slide shows a photograph of a bicycle. The teacher wants the brakes, the gears and the saddle labelled.

**(a)** Name a suitable object to label each part, and describe how it should be placed.

**(b)** Write suitable alternative text for the photograph.

**(c)** Explain why the photograph should be resized with its aspect ratio locked. **[5]**

**11.** A student applies a different transition to each of 12 slides and makes every bullet point enter with a different animation.

**(a)** Describe how to make the transitions consistent.

**(b)** Describe what consistent animation effects would mean in this presentation.

**(c)** Explain why consistency is important for the audience. **[5]**

**12.** A teacher uses the same presentation with two classes. Class A should see an extension slide; Class B should not. She also wants reminders of what to say that only she can see.

**(a)** State and explain what she should do with the extension slide for Class B.

**(b)** State where she should put her reminders and explain why. **[4]**

**13.** A slide contains a chart of monthly visitor numbers for one museum. Describe **three** edits that would improve the chart for the audience. **[3]**

## Answers

**1.** B: a hidden slide. **[1]**

**2.** A shape with a pointer or tail used to label or point to part of a slide (1). **[1]**

**3.** Any two, 1 mark each: video clips (1); animated images (1); audio clips (sound) (1). **[2]**

**4.** Slide 10 (1). **[1]**

**5.** Any one: screen-reader software can read the description to users who cannot see the image (1); it describes the image if it cannot be displayed (1). **[1]**

**6.** A transition is the effect when moving from one slide to the next (1); an animation is an effect applied to an object, such as text or an image, within a slide (1). **[2]**

**7. (a)** 9 slides (1).

**(b)** Original slide 9 (1). Working: after the insert there are 10 slides and original slides 3 to 9 become slides 4 to 10. Slide 8 is now original slide 7; moving it to position 3 shifts slides 3 to 7 down one place, so the order is original 1, 2, 7, new, 3, 4, 5, 6, 8, 9. Slide 10 is original slide 9, which is deleted.

**(c)** Each insert, move or delete changes the numbers of other slides (1), so carrying out the steps in a different order would change which slide each number refers to (1). **[4]**

**8. (a)** Select the text *Events* (1) and insert a hyperlink to a place in this document, choosing the slide titled *Events* (1).

**(b)** Select the text *Contact* (1) and insert a hyperlink to an email address, entering the club's address (1).

**(c)** Insert an action button (for example Home or a blank button) on each content slide, or on the master/layout so it appears on all of them (1), and change its action settings to hyperlink to the menu slide, slide 1 (1). **[6]**

**9. (a)** Any one: the spreadsheet is stored in a different folder or drive that the other computer does not have (1); the spreadsheet was not copied with the presentation (1); the file was renamed or moved (1).

**(b)** Save the spreadsheet in the same folder as the presentation before creating the link, and copy the whole folder (1). **[2]**

**10. (a)** Call out boxes (1), with each pointer or tail pointing at the correct part of the bicycle and not covering other parts (1).

**(b)** A description of the content, for example "Photograph of a bicycle showing the brakes, gears and saddle" (1).

**(c)** So the photograph keeps its proportions (1) and is not stretched or squashed, which would distort the bicycle (1). **[5]**

**11. (a)** Select all slides and apply one transition, with the same speed or duration, to every slide (for example using apply to all) (1).

**(b)** The same animation effect for all bullet points on every slide (1), entering in the same way and order, for example one at a time on click (1).

**(c)** Many different effects distract the audience from the content (1) and make the presentation look unprofessional or unplanned (1). **[5]**

**12. (a)** Hide the slide (1); it is skipped in the slide show for Class B but stays in the file to show Class A (1).

**(b)** In the presenter notes for each slide (1), because they are not shown on the audience's screen during the show but can be seen or printed by the presenter (1). **[4]**

**13.** Any three, 1 mark each: add a chart title (1); add axis titles, for example *Month* and *Number of visitors* (1); remove the legend because there is only one series (1); use a suitable chart type such as a column or line chart (1); make labels large enough to read on screen (1). **[3]**

## Frequently asked questions

**Is an action button the same as a hyperlink?**
An action button is a shape with action settings, which work like a hyperlink. The difference is that the button is a ready-made shape, whereas a hyperlink can be attached to any text or object.

**Do I need to know which menu to use?**
No. Menus differ between packages. Describe what you do, for example "select the text and insert a hyperlink to the slide titled Events".
