These notes condense section 6 of Unit P2 (Pearson Edexcel International Advanced Level Mathematics, YMA01, Issue 3): "knowledge and use of tan θ = sin θ/cos θ and sin²θ + cos²θ = 1" and the "solution of simple trigonometric equations in a given interval". For full worked examples, use the [P2 trigonometry study guide](/resources/edexcel-a-level-mathematics-yma01-p2-trigonometry-edexcel-alevel-maths/), then try the [P2 trigonometry practice questions](/resources/edexcel-a-level-mathematics-yma01-p2-trigonometry-edexcel-alevel-maths-practice/).

## Identities to know by heart

- sin²θ + cos²θ ≡ 1, so sin²θ ≡ 1 − cos²θ and cos²θ ≡ 1 − sin²θ
- tan θ ≡ sin θ/cos θ (cos θ ≠ 0)

Neither is printed in the formulae booklet for this unit.

## Signs by quadrant (degrees)

| Quadrant | Angle range | Positive ratios |
|---|---|---|
| First | 0° to 90° | sin, cos, tan |
| Second | 90° to 180° | sin only |
| Third | 180° to 270° | tan only |
| Fourth | 270° to 360° | cos only |

## Second solutions from the principal value α

| Equation | Solutions in 0° to 360° | Solutions in 0 to 2π | Period |
|---|---|---|---|
| sin x = k | α, 180° − α | α, π − α | 360° or 2π |
| cos x = k | α, 360° − α | α, 2π − α | 360° or 2π |
| tan x = k | α, α + 180° | α, α + π | 180° or π |

If α is negative (from sin⁻¹ or tan⁻¹ of a negative number), add the period to bring it into range before using the table.

## Exact values to recall

| θ | 30° (π/6) | 45° (π/4) | 60° (π/3) |
|---|---|---|---|
| sin θ | ½ | √2/2 | √3/2 |
| cos θ | √3/2 | √2/2 | ½ |
| tan θ | √3/3 | 1 | √3 |

## Which method?

| Equation contains | Do this |
|---|---|
| sin x and cos x, no squares, e.g. a sin x = b cos x | Divide by cos x to get tan x = b/a |
| sin x and cos²x | Replace cos²x by 1 − sin²x: quadratic in sin x |
| cos x and sin²x | Replace sin²x by 1 − cos²x: quadratic in cos x |
| tan x and sin x, cos x | Replace tan x by sin x/cos x and multiply through by cos x |
| a ratio squared = k | Take ± square roots; solve both |
| a common factor, e.g. sin x cos x = ½ sin x | Factorise; do not divide by sin x |
| f(2x), f(x + 30°) | Adjust the interval first |

## Interval adjustment examples

- 0° ≤ x < 360°: 0° ≤ 3x < 1080° (three full turns: expect up to six solutions for sin or cos)
- 0 ≤ x < 2π: π/4 ≤ x + π/4 < 9π/4
- −180° < x < 180°: −360° < 2x < 360°

## Key terms

| Term | Meaning |
|---|---|
| Identity (≡) | True for every value of the variable for which both sides are defined |
| Equation | True only for particular values, which you solve for |
| Principal value | The value given by sin⁻¹, cos⁻¹ or tan⁻¹ on a calculator |
| Period | The interval after which the graph repeats: 360° for sin and cos, 180° for tan |
| Compound angle | An angle such as x + 30° or x − π/4 |
| Multiple angle | An angle such as 2x or 3x |
| Radian | Angle measure with π radians = 180° |

## Exam traps

- Calculator in the wrong mode for the interval given.
- Forgetting the ± when square-rooting sin²x = ¼ or tan²x = 3.
- Not extending the interval for 2x or 3x, then dividing back.
- Dividing by sin x or cos x and losing the solutions where it is zero.
- Keeping sin x = 1.5 or cos x = −2: no solution.
- Answers outside the interval, especially after subtracting a compound-angle shift.
- Rounding the principal value before adding 180°.
- Giving decimals when "exact" or "in terms of π" is asked.

## Self-test

**1.** cos θ = −0.6 and 90° < θ < 180°. Find sin θ and tan θ.

**2.** Simplify (1 − cos²x)/sin x.

**3.** Simplify sin x/tan x.

**4.** Solve cos x = −½ for 0° ≤ x < 360°.

**5.** Solve tan x = 1 for 0 ≤ x < 2π.

**6.** If −180° < x < 180°, what interval does 2x lie in?

**7.** Solve sin(x + 20°) = 1 for 0° ≤ x < 360°.

**8.** Solve 2 sin²x = 1 for 0° ≤ x < 360°.

**9.** How many solutions does sin x = 0.4 have for 0° ≤ x < 720°?

**10.** Write 3 sin²x + 2 cos x in terms of cos x only.

**11.** Why does sin x = 2 have no solutions?

**12.** Solve cos 2x = 0 for 0 ≤ x < π.

### Answers

**1.** sin²θ = 1 − 0.36 = 0.64 and sine is positive in the second quadrant, so sin θ = 0.8; tan θ = 0.8 ÷ (−0.6) = −4/3.

**2.** sin²x/sin x = sin x.

**3.** sin x ÷ (sin x/cos x) = cos x.

**4.** x = 120°, 240°.

**5.** x = π/4, 5π/4.

**6.** −360° < 2x < 360°.

**7.** x + 20° = 90°, so x = 70° (the next value, 450°, gives x = 430°, outside the interval).

**8.** sin x = ±√2/2, so x = 45°, 135°, 225°, 315°.

**9.** Four: two in each 360° turn.

**10.** 3(1 − cos²x) + 2 cos x = 3 + 2 cos x − 3 cos²x.

**11.** −1 ≤ sin x ≤ 1 for every x.

**12.** 0 ≤ 2x < 2π: 2x = π/2, 3π/2, so x = π/4, 3π/4.
