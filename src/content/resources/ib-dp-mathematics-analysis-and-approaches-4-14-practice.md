## Section A

**1.** The discrete random variable X has this distribution.

| x | −1 | 0 | 2 | 5 |
|---|---|---|---|---|
| P(X = x) | 0.2 | 0.3 | 0.4 | 0.1 |

**(a)** Find E(X). **[2]**

**(b)** Find Var(X). **[3]**

**2.** E(X) = 5 and Var(X) = 4.

**(a)** Find E(3X + 2). **[1]**

**(b)** Find Var(3X + 2). **[1]**

**(c)** Find the standard deviation of 2 − X/2. **[2]**

**3.** A continuous random variable X has pdf f(x) = k/x² for 1 ≤ x ≤ 4, and f(x) = 0 otherwise.

**(a)** Show that k = 4/3. **[2]**

**(b)** Write down the mode of X. **[1]**

**(c)** Find the median of X. **[3]**

**(d)** Find E(X), giving your answer in the form a ln 2. **[2]**

**4.** A continuous random variable X has pdf f(x) = kx³ for 0 ≤ x ≤ 2, and f(x) = 0 otherwise.

**(a)** Find k. **[2]**

**(b)** Find E(X). **[2]**

**(c)** Find Var(X). **[3]**

**(d)** Find the exact value of the median. **[2]**

**5.** A discrete random variable X takes the value 1 with probability p and the value 0 with
probability 1 − p. Show that Var(X) = p(1 − p). **[3]**

## Section B

**6.** A continuous random variable X has pdf

f(x) = kx for 0 ≤ x < 2, f(x) = k(4 − x) for 2 ≤ x ≤ 4, and f(x) = 0 otherwise.

**(a)** Find k. **[2]**

**(b)** Write down the mode, and explain why the median and the mean are also 2. **[2]**

**(c)** Find Var(X). **[4]**

**(d)** Find P(1 < X < 3). **[2]**

**7.** A spinner gives a score X with this distribution.

| x | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| P(X = x) | 0.4 | a | 0.2 | 0.1 |

**(a)** Find a. **[1]**

**(b)** Find E(X) and Var(X). **[4]**

**(c)** A player wins Y = 2X − 3 tokens. Find E(Y) and the standard deviation of Y. **[3]**

**8.** A continuous random variable X has pdf f(x) = k sin x for 0 ≤ x ≤ π, and f(x) = 0 otherwise.

**(a)** Find k. **[2]**

**(b)** Write down the mode and the median of X. **[2]**

**(c)** Use technology to find Var(X). **[3]**

**(d)** Find P(X < π/4). **[2]**

**9.** The time, X minutes, for a courier to make a delivery has mean 28 and variance 36. The cost of a
delivery, in dollars, is C = 0.5X + 4.

**(a)** Find E(C). **[1]**

**(b)** Find the standard deviation of C. **[2]**

**10.** A continuous random variable X has pdf f(x) = ax + b for 0 ≤ x ≤ 2, and f(x) = 0 otherwise.
E(X) = 7/6.

**(a)** Show that 2a + 2b = 1. **[2]**

**(b)** Find a and b. **[4]**

**(c)** Find Var(X). **[3]**

**(d)** Find the median of X. **[3]**

**11.** A discrete random variable X takes the values 0, 1 and 2 with probabilities p, q and 0.3
respectively. E(X) = 1.

**(a)** Find p and q. **[3]**

**(b)** Find Var(X). **[2]**

## Answers

**1. (a)** E(X) = −0.2 + 0 + 0.8 + 0.5 [1] = 1.1 [1]

**(b)** E(X²) = 0.2 + 0 + 1.6 + 2.5 = 4.3 [1]; Var(X) = 4.3 − 1.1² [1] = 4.3 − 1.21 = 3.09 [1].
**[5]**

**2. (a)** 3(5) + 2 = 17 [1]

**(b)** 3² × 4 = 36 [1]

**(c)** Var = (1/2)² × 4 = 1 [1], so the standard deviation is 1 [1]. **[4]**

**3. (a)** ∫₁⁴ k/x² dx = k[−1/x]₁⁴ = k(−1/4 + 1) = 3k/4 [1]. 3k/4 = 1, so k = 4/3 [1].

**(b)** f is decreasing on [1, 4], so the mode is 1 [1].

**(c)** ∫₁ᵐ (4/3)x⁻² dx = (4/3)(1 − 1/m) [1] = 1/2 [1], so 1 − 1/m = 3/8 and m = 8/5 [1].

**(d)** E(X) = ∫₁⁴ (4/3)(1/x) dx = (4/3) ln 4 [1] = (8/3) ln 2 [1]. **[8]**

**4. (a)** k∫₀² x³ dx = 4k = 1 [1], so k = 1/4 [1].

**(b)** E(X) = ∫₀² x⁴/4 dx [1] = 32/20 = 8/5 [1].

**(c)** E(X²) = ∫₀² x⁵/4 dx = 64/24 = 8/3 [1]; Var(X) = 8/3 − (8/5)² [1] = 8/3 − 64/25 = 8/75 [1].

**(d)** m⁴/16 = 1/2 [1], so m⁴ = 8 and m = 8^(1/4) = 2^(3/4) [1]. **[9]**

**5.** E(X) = 0(1 − p) + 1(p) = p [1]. E(X²) = 0²(1 − p) + 1²(p) = p [1].
Var(X) = p − p² = p(1 − p) [1]. **[3]**

**6. (a)** ∫₀² kx dx + ∫₂⁴ k(4 − x) dx = 2k + 2k = 4k [1] = 1, so k = 1/4 [1].

**(b)** Mode = 2, the peak of f [1]. The graph of f is symmetric about x = 2, so the median and mean
also equal 2 [1].

**(c)** E(X²) = ∫₀² x³/4 dx + ∫₂⁴ x²(4 − x)/4 dx [1] = 1 + 11/3 = 14/3 [2];
Var(X) = 14/3 − 2² = 2/3 [1].

**(d)** P(X < 1) = ∫₀¹ x/4 dx = 1/8 [1]; by symmetry P(X > 3) = 1/8, so P(1 < X < 3) = 1 − 1/4 = 3/4
[1]. **[10]**

**7. (a)** 0.4 + a + 0.2 + 0.1 = 1, so a = 0.3 [1].

**(b)** E(X) = 0.4 + 0.6 + 0.6 + 0.4 = 2 [1]. E(X²) = 0.4 + 1.2 + 1.8 + 1.6 = 5 [1].
Var(X) = 5 − 2² [1] = 1 [1].

**(c)** E(Y) = 2(2) − 3 = 1 [1]. Var(Y) = 2² × 1 = 4 [1], so the standard deviation of Y is 2 [1].
**[8]**

**8. (a)** k∫₀^π sin x dx = k[−cos x]₀^π = 2k [1] = 1, so k = 1/2 [1].

**(b)** f is symmetric about x = π/2 with its maximum there, so mode = π/2 [1] and median = π/2 [1].

**(c)** E(X) = π/2 by symmetry [1]. E(X²) = ∫₀^π (1/2)x² sin x dx = 2.9348… (GDC) [1].
Var(X) = 2.9348… − (π/2)² = 0.467 (3 s.f.) [1].

**(d)** ∫₀^(π/4) (1/2) sin x dx = (1/2)(1 − cos(π/4)) [1] = (1/2)(1 − √2/2) ≈ 0.146 [1]. **[9]**

**9. (a)** E(C) = 0.5(28) + 4 = 18 dollars [1].

**(b)** Var(C) = 0.5² × 36 = 9 [1], so the standard deviation is 3 dollars [1]. **[3]**

**10. (a)** ∫₀² (ax + b) dx = [ax²/2 + bx]₀² [1] = 2a + 2b = 1 [1].

**(b)** E(X) = ∫₀² (ax² + bx) dx = 8a/3 + 2b = 7/6 [1]. From (a), b = 1/2 − a [1], so
8a/3 + 1 − 2a = 7/6 [1], giving 2a/3 = 1/6, a = 1/4 and b = 1/4 [1].

**(c)** E(X²) = ∫₀² (x³ + x²)/4 dx = (4 + 8/3)/4 = 5/3 [1]; Var(X) = 5/3 − (7/6)² [1] = 60/36 − 49/36 =
11/36 [1].

**(d)** ∫₀ᵐ (x + 1)/4 dx = (m²/2 + m)/4 = 1/2 [1], so m² + 2m − 4 = 0 [1] and m = −1 + √5 ≈ 1.24,
rejecting the negative root [1]. **[12]**

**11. (a)** E(X) = q + 0.6 = 1, so q = 0.4 [1]. p + 0.4 + 0.3 = 1 [1], so p = 0.3 [1].

**(b)** E(X²) = 0.4 + 4(0.3) = 1.6 [1]; Var(X) = 1.6 − 1 = 0.6 [1]. **[5]**

## How this set builds

Questions 1, 2, 5, 7, 9 and 11 work on discrete variance and linear transformations. Questions 3, 4
and 10 cover the full set of pdf skills by hand: finding constants, mode, median, mean and variance.
Questions 6 and 8 add a piecewise pdf and a trigonometric pdf, where symmetry gives the mean and
median without integration, and technology handles the harder integral.
