These questions cover section 3.8.1 of the AQA AS and A-level Biology specification (7401/7402), for first teaching 2015: *Alteration of the sequence of bases in DNA can alter the structure of proteins* (A-level only). All data are invented. Revise first with the [study guide on base sequence and protein structure](/resources/aqa-a-level-biology-7402-alteration-of-the-base-sequence-can-alter-protein-structure-aqa-alevel-biology/) and the [revision notes on base sequence and protein structure](/resources/aqa-a-level-biology-7402-alteration-of-the-base-sequence-can-alter-protein-structure-aqa-alevel-biology-revision-notes/).

## Section A: Short-answer questions

**1.** Which **one** of the following mutations is least likely to change the amino acid sequence of a polypeptide? **[1]**

A: Deletion of one base near the start of the gene

B: Substitution of the third base of a triplet

C: Addition of two bases in the middle of the gene

D: Duplication of a single base

**2.** Which **one** of the following deletions of adjacent bases from the coding region of a gene would **not** cause a frame shift? **[1]**

A: 1 base

B: 2 bases

C: 4 bases

D: 6 bases

**3.** Define the term *mutagenic agent* and give **one** example. **[2]**

**4.** Explain why a mistake made during DNA replication can become a permanent mutation in the cells that descend from that cell. **[2]**

**5.** Explain why the degenerate nature of the genetic code means that some substitution mutations have no effect on the encoded polypeptide. **[2]**

**6.** The mRNA codon UCA codes for serine. The table shows the codons that result from each possible single-base substitution in UCA.

| Position changed | New codons and what they code for |
|---|---|
| First base | ACA Thr; CCA Pro; GCA Ala |
| Second base | UAA stop; UUA Leu; UGA stop |
| Third base | UCU Ser; UCC Ser; UCG Ser |

**(a)** What fraction of the possible substitutions are silent? **[1]**

**(b)** What fraction would produce a shortened polypeptide? **[1]**

**(c)** Use the table to explain why substitutions of the third base of a codon are less likely to change a polypeptide than substitutions of the first or second base. **[1]**

## Section B: Structured questions

**7.** The template strand of the start of a short gene is shown, read in triplets from left to right.

TAC TTT GGC ACC CTA GAT ATC

Codons supplied: AUG Met; AAA Lys; CCG Pro; CCA Pro; UGG Trp; UGA stop; GAU Asp; CUA Leu; UAG stop; CGU Arg; GGG Gly; AUC Ile; UAU Tyr.

**(a)** Write the mRNA sequence transcribed from this template strand. **[1]**

**(b)** Give the amino acid sequence it codes for. **[1]**

**(c)** For each mutation in the template strand, give the new amino acid sequence and name the type of mutation.

(i) The third base of the third triplet changes from C to T. **[2]**

(ii) The third base of the fourth triplet changes from C to T. **[2]**

(iii) The first base of the third triplet (G) is lost. **[2]**

**8.** Two mutant forms of an enzyme were studied. Each differs from the normal enzyme by one amino acid. The activity of each was measured under the same conditions.

| Enzyme | Position of changed amino acid | Activity (% of normal) |
|---|---|---|
| Normal | none | 100 |
| Mutant X | In the active site | 0 |
| Mutant Y | On the surface, far from the active site | 96 |

**(a)** Explain why mutant X has no activity. **[3]**

**(b)** Suggest why mutant Y still has almost normal activity. **[2]**

**9.** Bacterial cultures were exposed to ultraviolet light for different times. Mutant colonies were then counted.

| Exposure time (s) | Mutant colonies per million surviving cells |
|---|---|
| 0 | 2 |
| 10 | 9 |
| 20 | 21 |
| 30 | 38 |

**(a)** Calculate the percentage increase in mutant colonies between 0 s and 30 s. **[2]**

**(b)** Explain why mutant colonies were found even with no ultraviolet exposure. **[1]**

**(c)** A student concludes that ultraviolet light caused a mutation in one particular gene. Evaluate this conclusion. **[2]**

**10.** One gene has a single-base addition, and another gene of the same length has the addition of three adjacent bases between two triplets. Compare the likely effects of these two mutations on the polypeptides produced. **[3]**

**11.** A mutation changes the stop codon at the end of a gene from UAG to CAG, which codes for glutamine. Explain how this mutation could affect the protein produced. **[3]**

**12.** A single base substitution occurs in the gene for an enzyme.

**(a)** Explain how this substitution could cause loss of enzyme activity. **[4]**

**(b)** Give **two** reasons why a base substitution in this gene might have no effect on enzyme activity. **[2]**

## Answers

**1.** B [1]. **[1]**

**2.** D: six bases is a multiple of three, so the frame is kept [1]. **[1]**

**3.** A factor that increases the rate of gene mutation [1]; one example: ionising radiation (such as X-rays), ultraviolet light, or a named mutagenic chemical such as some in tobacco smoke [1]. **[2]**

*Examiner insight:* "causes mutations" is weaker than "increases the rate of mutation", which is the specification's wording.

**4.** When the DNA with the error is next replicated, the changed base acts as a template, so both new molecules carry the changed sequence [1]; the changed DNA is passed to daughter cells at every later division [1]. **[2]**

**5.** Most amino acids are coded for by more than one triplet [1], so a substitution can produce a new triplet that still codes for the same amino acid, leaving the primary structure unchanged [1]. **[2]**

**6. (a)** 3/9 = 1/3 [1].

**(b)** 2/9, the two substitutions that give stop codons [1].

**(c)** All three third-base changes still code for serine, whereas every first-base and second-base change gives a different amino acid or a stop codon [1]. **[3]**

*Examiner insight:* in part (c), quote the table. "The third base matters less" with no evidence would not gain the mark.

**7. (a)** AUG AAA CCG UGG GAU CUA UAG [1].

**(b)** Met-Lys-Pro-Trp-Asp-Leu, then stop [1].

**(c)(i)** Template GGC becomes GGT, so the mRNA codon CCG becomes CCA, which still codes for Pro; the sequence is unchanged: Met-Lys-Pro-Trp-Asp-Leu [1]. Substitution, silent because the code is degenerate [1].

**(c)(ii)** Template ACC becomes ACT, so the codon UGG becomes UGA, a stop codon; the polypeptide is Met-Lys-Pro only [1]. Substitution, producing a premature stop codon [1].

**(c)(iii)** The mRNA becomes AUG AAA CGU GGG AUC UAU AG, giving Met-Lys-Arg-Gly-Ile-Tyr [1]. Deletion, causing a frame shift so every amino acid after Lys changes [1]. **[8]**

*Examiner insight:* converting the template strand to mRNA first is the step most often missed. Write the new mRNA on the page so the method can be credited.

**8. (a)** The changed amino acid has a different R group, so different bonds (hydrogen, ionic or disulfide) form in the active site [1]; the active site changes shape [1], so it is no longer complementary to the substrate and no enzyme-substrate complexes form [1].

**(b)** The change is far from the active site, so the active site keeps its shape [1]; the new R group may have similar properties to the old one, so the tertiary structure is hardly changed [1]. **[5]**

**9. (a)** (38 − 2) ÷ 2 × 100 [1] = 1800% [1].

**(b)** Mutations occur spontaneously, for example as errors in DNA replication [1].

**(c)** The data show that the number of mutant colonies rose with exposure time, so UV light increased the mutation rate [1]; but the data do not show which genes were changed, and mutagens raise the rate of mutation in general rather than targeting one gene, so the conclusion is not supported [1]. **[5]**

*Examiner insight:* "evaluate" needs a judgement. Say what the data support, what they do not, and conclude.

**10.** The single-base addition causes a frame shift, so every triplet after it changes [1] and many amino acids differ, often with a premature stop codon [1]. The three-base addition keeps the frame, so only one extra amino acid is added (or two triplets are altered if it falls inside a triplet) and the rest of the sequence is unchanged, so the effect is usually much smaller [1]. **[3]**

**11.** Translation no longer stops at the normal place [1]; extra amino acids are added until another stop codon in the same frame is reached [1]; the longer polypeptide may fold into a different tertiary structure and lose its function [1]. **[3]**

**12. (a)** The mRNA codon changes, so a different amino acid is inserted and the primary structure changes [1]. The new R group forms different hydrogen bonds, ionic bonds or disulfide bridges [1]. The tertiary structure, and so the shape of the active site, changes [1]. The substrate is no longer complementary, so fewer or no enzyme-substrate complexes form [1].

**(b)** Any two, one mark each: the new triplet codes for the same amino acid because the code is degenerate [1]; the substitution is in an intron or other non-coding DNA [1]. (Also accept: the new amino acid is away from the active site and has similar properties, so the tertiary structure is not changed.) **[6]**

*Examiner insight:* part (a) is a chain: each link (amino acid, R group bonds, tertiary structure, active site) is a separate marking point, so do not skip one.

## Where marks are usually lost

- Using the template strand in an mRNA codon table without converting it.
- Calling a substitution a frame shift.
- Writing "the protein is denatured" for a mutation. The protein is made with a different shape; nothing has been denatured.
- Missing out the bonds between R groups when linking amino acid change to tertiary structure.
- Giving percentage changes divided by the new value instead of the original value.
