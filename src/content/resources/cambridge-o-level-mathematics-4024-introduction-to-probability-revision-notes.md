These notes summarise section 8.1, Introduction to probability, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. Full explanations are in the [introduction to probability study guide](/resources/cambridge-o-level-mathematics-4024-introduction-to-probability/), and exam-style questions are in the [introduction to probability practice questions](/resources/cambridge-o-level-mathematics-4024-introduction-to-probability-practice/).

## What is examined

- The probability scale from 0 to 1.
- Notation: P(A) is the probability of A, and P(A′) is the probability of not A.
- Calculating the probability of a single event. Give answers as a fraction, decimal or percentage.
- Using information from tables, graphs and Venn diagrams.
- The probability of an event not happening is 1 minus the probability that it happens.

## Key terms

| Term | Meaning |
|---|---|
| Event | an outcome or set of outcomes of interest |
| Outcome | one possible result |
| Equally likely | each outcome has the same chance |
| Random | chosen so that every outcome is equally likely |
| Complement | the event "not A", written A′ |
| Certain | probability 1 |
| Impossible | probability 0 |
| Venn diagram | a diagram of overlapping sets |

## The scale

```
0 ---- 1/4 ---- 1/2 ---- 3/4 ---- 1
impossible   unlikely   even chance   likely   certain
```

A probability is never less than 0 or more than 1. Fractions, decimals and percentages are all allowed: 3/8 = 0.375 = 37.5%.

## The two key formulas

```
P(event) = number of favourable outcomes / total number of equally likely outcomes
P(A′) = 1 − P(A)
```

For a complete list of outcomes, the probabilities add up to 1.

## Method box: a single event

1. List or count all the possible outcomes. This is the denominator.
2. Count the outcomes that match the event. This is the numerator.
3. Write the fraction and simplify.
4. Convert to a decimal or a percentage if asked.
5. Check that the answer is between 0 and 1.

## Standard sets

| Situation | Total outcomes | Useful facts |
|---|---|---|
| Fair dice | 6 | primes 2, 3, 5; even 2, 4, 6; multiples of 3: 3, 6 |
| Coin | 2 | heads or tails |
| Pack of cards | 52 | 4 suits of 13; 26 red, 26 black; 12 picture cards; 4 aces |
| Numbers 1 to 20 | 20 | primes: 2, 3, 5, 7, 11, 13, 17, 19; squares 1, 4, 9, 16 |
| Letters of a word | number of letters | count repeated letters separately |

## Tables, charts and Venn diagrams

| Source | How to get the denominator |
|---|---|
| Frequency table | add all the frequencies |
| Two-way table | use the grand total |
| Pie chart | 360° |
| Bar chart | add the heights of the bars |
| Venn diagram | add every region, including outside the circles |

### Venn diagram checks

```
only A = n(A) − n(both)
only B = n(B) − n(both)
neither = total − (only A + both + only B)
```

In notation: P(A ∩ B) means both, and P(A ∪ B) means A or B or both.

## Worked patterns

```
Dice: P(prime) = 3/6 = 1/2;  P(more than 6) = 0;  P(less than 7) = 1
Bag 5 red, 3 blue, 2 green:  P(not blue) = 7/10
P(B) = 0.8  →  P(B′) = 0.2
P(rain) = 3x, P(no rain) = x + 0.2:  4x + 0.2 = 1,  x = 0.2,  P(rain) = 0.6
Venn (30 students, F 18, T 12, both 5):  P(F or T) = 25/30 = 5/6
```

## Describing probabilities in words

| Probability | Word |
|---|---|
| 0 | impossible |
| between 0 and 1/2 | unlikely |
| 1/2 | even chance |
| between 1/2 and 1 | likely |
| 1 | certain |

Examples: a fair coin landing heads is an even chance, rolling a 7 on a standard dice is impossible, and rolling a number below 7 is certain.

## Layout for full marks

1. Write the probability as a fraction first: P(red) = 5/10.
2. Simplify the fraction if you can.
3. Only then convert it to a decimal or a percentage.
4. Do not write a ratio or "5 out of 10" as the final answer unless asked.

## Must-know distinctions

| Idea | Be clear that |
|---|---|
| Probability vs frequency | probability is a fraction of the total |
| Event vs complement | together they make 1 |
| Prime numbers | 1 is not prime |
| And vs or | and = overlap, or = either or both |
| Fraction vs ratio | write probability as a fraction, not 3 : 7 |

## Exam traps

- Using the wrong total.
- Counting 1 as a prime.
- Probabilities greater than 1.
- Forgetting repeated letters in a word.
- Using only one circle's total in a Venn diagram.
- Not simplifying fractions.

## Command words you will meet

| Command word | What to do |
|---|---|
| Calculate | work out the probability, showing the fraction |
| Write down | give the probability without working |
| Show that | give structured evidence to a stated probability |
| Explain | give reasons in words |
| Work out | calculate with or without a calculator |

## Self-test

1. A fair dice is rolled. Find P(a number greater than 2).
2. A bag has 3 red and 5 blue marbles. Find P(not red).
3. P(A) = 0.35. Find P(A′).
4. Write 7/20 as a decimal and as a percentage.
5. A card is chosen from a pack of 52. Find P(a club).
6. A letter is chosen from the word PROBABILITY. Find P(B).
7. P(snow) = 2x and P(no snow) = 3x + 0.1. Find x.
8. Of 25 pupils, 14 have a pet dog (D), 9 have a cat (C), and 4 have both. Find P(neither).
9. A number from 1 to 30 is chosen. Find P(a multiple of 5).
10. A bag has x green counters and 9 yellow counters. P(green) = 2/5. Find x.

### Answers

1. Numbers 3, 4, 5, 6: **4/6 = 2/3**.
2. 5/8.
3. 1 − 0.35 = **0.65**.
4. **0.35** and **35%**.
5. 13/52 = **1/4**.
6. PROBABILITY has 11 letters, with B twice: **2/11**.
7. 2x + 3x + 0.1 = 1, so 5x = 0.9 and **x = 0.18**.
8. Dog only 10, cat only 5, both 4, so neither = 25 − 19 = 6: **6/25**.
9. 5, 10, 15, 20, 25, 30: 6/30 = **1/5**.
10. x/(x + 9) = 2/5, so 5x = 2x + 18 and **x = 6**.
