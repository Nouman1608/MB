## Answers

**1.** Software that performs tasks for the end user [1].

**2.** Software that manages the computer system's resources and acts as a platform for running application software [1].

**3.** **(a)** Application [1]. **(b)** System [1]. **(c)** System (utility) [1]. **(d)** Application [1].

**4.** Any suitable utility with its purpose, such as anti-virus, which finds and removes malware [1 for the name, 1 for
the purpose]. Other acceptable examples: backup (copies files), disk defragmenter, file compression, encryption,
firewall.

**5.** It manages the hardware, such as the processor, memory and devices [1]; it shares the resources between the
programs that are running, so that they do not interfere with each other [1]; it provides a platform so that
application programs can run without having to control the hardware themselves [1].

**6.** **(a)** The OS decides which program the processor works on and for how long [1]; it switches between programs
quickly, so that several programs appear to run at the same time [1].
**(b)** The OS allocates RAM to each program when it starts [1]; it keeps the programs' memory separate and frees the
memory when the program closes [1].
**(c)** Any two from: it uses user accounts and passwords to identify users [1]; it sets access rights to control which
files each user can read or change [1]; it stops one program from interfering with another [1] (maximum 2).

**7.** The OS contains (or loads) a device driver for the printer [1]; the word processor sends the print request to the
OS, rather than to the printer directly [1]; the driver translates the request into instructions that the printer
understands [1].

**8.** The OS manages the processor, sharing its time between the programs [1]; it switches between them very quickly
[1], so that each program gets a turn and they appear to run together (multitasking) [1].

**9.** **(a)** Disk defragmenter (defragmentation utility) [1].
**(b)** It rearranges the pieces of each file so that they are stored next to each other [1], so the drive can read a
file with less movement, and access is quicker [1].

**10.** System software manages the computer's resources, but a photo editor is used by the user to edit photographs
[1]; the size of a program does not decide its class. It is application software because it performs an end-user
task [1].

**11.**

| Program | Class |
|---|---|
| A web browser | Application |
| A backup utility | System |
| A device driver | System |
| A presentation program | Application |
| A firewall | System |

All five correct [3]; four correct [2]; two or three correct [1].

**12.** User accounts and passwords: only people with a valid account and password can log in [1 for the method, 1 for the
explanation]. Access rights: the OS controls who can read, change or delete each file [1 for the method, 1 for the
explanation]. Accept other valid methods, such as keeping programs' memory separate.

**13.** A backup utility [1]; it copies the files to another location [1]; so that the files can be restored if the
originals are lost, damaged or deleted [1].

**14.** A file compression program does a maintenance (housekeeping) task on the files and storage [1]; it does not carry out
a task that the end user wants as their main work, and so it is system software (a utility) [1].

## Where marks are usually lost

- Naming an OS function without saying what the OS does.
- Calling a browser or a game system software.
- Describing the OS as hardware.
- Confusing processor management with memory management.
- Giving brand names instead of types of software.
