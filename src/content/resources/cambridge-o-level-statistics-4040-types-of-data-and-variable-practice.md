These questions cover section 1.5 of the Cambridge O Level Statistics (4040) syllabus for examination in 2025, 2026 and 2027: "Types of data and variable", including the terms qualitative, quantitative, discrete and continuous. Revise first with the [types of data study guide](/resources/cambridge-o-level-statistics-4040-types-of-data-and-variable/) or the [types of data revision notes](/resources/cambridge-o-level-statistics-4040-types-of-data-and-variable-revision-notes/).

## Section A: short questions

**1.** State whether each variable is qualitative, quantitative discrete or quantitative continuous.

**(a)** The number of eggs in a nest. **[1]**

**(b)** The colour of a car. **[1]**

**(c)** The volume of water in a bottle. **[1]**

**(d)** The number of minutes late of a train, measured with a stopwatch. **[1]**

**2.** A football team's players wear numbers from 1 to 23. A pupil works out the mean shirt number. Explain why this is not useful. **[2]**

**3.** Explain why shoe size is discrete although it can take the value 6½. **[1]**

**4.** The length of a leaf is recorded as 8.7 cm, to the nearest millimetre. Write down the least and greatest possible values of its true length. **[2]**

**5.** A doctor records patients' ages in completed years.

**(a)** A patient is recorded as 42. Write an inequality for the patient's true age, a years. **[1]**

**(b)** Write down the class boundaries of the age class 40–49. **[1]**

**6.** Which one of these is continuous data? Give a reason.

A: Number of pages in a book

B: Time taken to read a book

C: Language a book is written in

**[2]**

**7.** A pupil says: "Discrete data are always whole numbers." Give a counter-example and explain. **[2]**

## Section B: longer questions

**8.** A gardening club records the following for each of its 40 members: (i) the type of garden (flat, terrace or allotment), (ii) the number of fruit trees, (iii) the area of the garden in square metres, (iv) the membership number, (v) the mass of tomatoes harvested last year.

**(a)** Classify each variable. **[5]**

**(b)** Suggest a suitable diagram for variable (i) and for variable (v), giving a reason for each. **[2]**

**9.** The times taken by 50 runners to complete a race were recorded to the nearest second, in classes 600–659, 660–719, 720–779 and 780–839 seconds.

**(a)** Explain why time is a continuous variable even though the recorded values are whole numbers. **[1]**

**(b)** State the class boundaries and the width of the class 660–719. **[2]**

**(c)** Give one reason why a histogram is more suitable than a bar chart with gaps for these data. **[1]**

**10.** The masses of 30 parcels are recorded to the nearest 0.1 kg and grouped as 0.5–0.9, 1.0–1.4, 1.5–1.9 and 2.0–2.4 kg.

**(a)** Find the class boundaries of the class 1.5–1.9 kg. **[1]**

**(b)** Find the width and the midpoint of that class. **[2]**

**(c)** A parcel has a true mass of 1.96 kg. Which class is it recorded in? Explain. **[1]**

**11.** For each variable, state the type and suggest which average (mean, median or mode) is suitable, with a reason.

**(a)** Make of mobile phone owned. **[2]**

**(b)** Number of mobile phones in a household. **[2]**

**12.** A survey asks shoppers to rate a shop's service as 1 (poor), 2 (fair), 3 (good), 4 (very good) or 5 (excellent).

**(a)** Explain why these data could be described as qualitative. **[1]**

**(b)** The manager quotes a mean rating of 3.6. Give one criticism of using the mean here. **[1]**

**(c)** Suggest a more suitable summary of the ratings. **[1]**

## Answers

**1. (a)** Quantitative discrete [1]. **[1]**

**(b)** Qualitative [1]. **[1]**

**(c)** Quantitative continuous [1]. **[1]**

**(d)** Quantitative continuous: it is a measured time [1]. **[1]**

**2.** Shirt numbers are labels, so the data are qualitative [1]; arithmetic on them has no meaning, so the mean does not describe the players in any way [1]. **[2]**

**3.** Only certain separate values are possible, such as 6, 6½ and 7; there are no sizes in between [1]. **[1]**

**4.** Least 8.65 cm [1]; greatest 8.75 cm (strictly, just below 8.75) [1]. **[2]**
*Examiner insight:* For a value to the nearest millimetre, add and subtract half a millimetre, 0.05 cm.

**5. (a)** 42 ≤ a < 43 [1]. **[1]**

**(b)** 40 and 50 [1]. **[1]**
*Examiner insight:* Completed years round down, so the boundaries are not 39.5 and 49.5.

**6.** B [1]. Time is measured and can take any value in a range [1]. **[2]**

**7.** Shoe sizes such as 4½, or marks awarded in halves [1]; these are discrete because only separate values are possible, even though some are not whole numbers [1]. **[2]**

**8. (a)** (i) Qualitative [1]. (ii) Quantitative discrete [1]. (iii) Quantitative continuous [1]. (iv) Qualitative, since the number is a label [1]. (v) Quantitative continuous [1]. **[5]**

**(b)** (i) A pie chart or a bar chart with gaps, because the data are categories [1]. (v) A histogram (or cumulative frequency polygon) with grouped classes, because mass is continuous [1]. **[2]**

**9. (a)** Time is measured and can take any value; it is only rounded to whole seconds when recorded [1]. **[1]**

**(b)** Boundaries 659.5 and 719.5 seconds [1]; width 719.5 − 659.5 = 60 seconds [1]. **[2]**

**(c)** The data are continuous, so the bars should touch with no gaps, matching the boundaries [1]. **[1]**

**10. (a)** 1.45 kg and 1.95 kg [1]. **[1]**

**(b)** Width 1.95 − 1.45 = 0.5 kg [1]; midpoint (1.45 + 1.95) ÷ 2 = 1.7 kg [1]. **[2]**

**(c)** 1.96 kg rounds to 2.0 kg to the nearest 0.1 kg, so it is recorded in the class 2.0–2.4 kg [1]. **[1]**

**11. (a)** Qualitative [1]; the mode, since categories cannot be ordered or averaged numerically [1]. **[2]**

**(b)** Quantitative discrete [1]; the mean (or median), since the values are counts that can be added; the mode is also acceptable with a reason such as giving the most common household [1]. **[2]**

**12. (a)** The numbers are labels for ordered categories (poor to excellent) rather than measured amounts [1]. **[1]**

**(b)** The gaps between categories may not be equal, so a mean of 3.6 has no clear meaning [1]. **[1]**

**(c)** The mode or median rating, or the percentage of shoppers giving each rating [1]. **[1]**

## Where marks are usually lost

- Writing "quantitative" without "discrete" or "continuous".
- Treating number labels as quantitative.
- Calling a measured variable discrete because the values recorded are whole numbers.
- Using ± 0.5 for ages in completed years.
- Choosing a diagram without linking it to the data type.

## Frequently asked questions

**Does every classification question need a reason?**
Only when the question asks for one, but a short reason (counted, measured, a label) protects the mark when a variable is borderline.

**How are rounding questions marked?**
Each limit is usually a separate mark, so write both the least and greatest values with units.
