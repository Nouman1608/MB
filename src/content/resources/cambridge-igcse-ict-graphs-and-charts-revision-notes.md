Topic 16 of Cambridge IGCSE ICT 0417 is about producing graphs and charts from data: selecting contiguous, non-contiguous or specified data ranges, choosing a suitable chart type, adding every label the task asks for, adding a second data series or second axis, formatting numbers and axis scales, and enhancing appearance, for example by extracting a pie sector. It is assessed practically, mainly with spreadsheets in Paper 3, and charts are placed into documents in Paper 2.

## How do you select data for a chart?

| Type | Meaning | How |
|---|---|---|
| Contiguous | Cells next to each other in one block | Drag across the block |
| Non-contiguous | Cells in separate blocks, for example column A and column D | Select the first range, hold Ctrl (or Cmd) and select the second |
| Specified range | Exactly the rows/columns the task names | Select only those cells, including the labels if needed, but not totals unless asked |

Include the **category labels** (for example the month names) with the data so they appear on the axis or legend.

## Which chart type should you choose?

| Chart | Best for | Example |
|---|---|---|
| Bar / column chart | Comparing separate categories | Sales of each product |
| Line graph | Showing change or a trend over time (continuous data) | Temperature each hour |
| Pie chart | Showing parts of one whole, as proportions | Share of votes for each candidate |
| Comparative (multi-series) bar or line | Comparing two or more sets of data across the same categories | This year's and last year's sales by month |

A pie chart only works with **one** data series.

## Chart labels

| Label | What it shows |
|---|---|
| Chart title | What the whole chart is about |
| Legend | Key to which colour or pattern represents which series or sector |
| Sector labels | Name of each slice of a pie chart |
| Sector values / percentages | Value or percentage of each slice |
| Category axis title | Title of the x-axis (for example "Month") |
| Value axis title | Title of the y-axis (for example "Sales ($)") |
| Category axis labels | Names along the category axis (Jan, Feb, ...) |
| Value axis labels | Numbers along the value axis |
| Data value labels | Value shown on or above each bar or point |

A chart with **one** series usually does not need a legend; remove it if the task asks. Spell titles exactly as given.

## Second data series and second axis

- **Add a second data series** to compare, for example *Income* and *Costs* on the same chart.
- **Add a second (secondary) value axis** when the two series have very different scales or units — for example rainfall in mm on the left axis and temperature in °C on the right axis. Each axis needs its own title. Combining a column chart and a line on the secondary axis makes the two series easy to tell apart.

## Number formats and axis scale

- Format axis or data labels to a **specified number of decimal places** (for example 1 dp) and with **currency symbols** (for example $ or €) as the task states.
- Set the axis **minimum** and **maximum** values and the **increment** (major unit). Example: minimum 0, maximum 500, increment 50 gives marks 0, 50, 100 ... 500.

## Enhancing a chart

- **Extract (explode) a pie sector**: drag one slice outward to highlight it, for example the largest share.
- **Change the colour scheme or fill patterns** — patterns help when the chart will be printed in black and white.

## Worked example: following a chart instruction

*Data: months in A2:A13, rainfall in C2:C13, average temperature in E2:E13.*

Instruction: "Create a chart showing rainfall as columns and temperature as a line on a secondary axis. Title: *Rainfall and Temperature 2025*. Label both value axes. Set the rainfall axis from 0 to 300 in steps of 50."

Steps: select A1:A13, then Ctrl-select C1:C13 and E1:E13 (non-contiguous) → insert a combination chart → set temperature series as a line on the secondary axis → add the chart title exactly → add value axis titles *Rainfall (mm)* and *Temperature (°C)* and a category axis title *Month* → format the primary axis: min 0, max 300, major unit 50 → check the legend identifies both series.

## Common mistakes and exam traps

- Including a **total** row or column in the selected data, which distorts the chart.
- Choosing a pie chart for data that is not parts of a whole, or for more than one series.
- Leaving out a required label, or mis-typing the title.
- Using a legend when only one series is shown and the task says to remove it.
- Not changing the axis to the minimum, maximum and increment stated.
- Forgetting that a secondary axis needs its own title.

## Frequently asked questions

**What is non-contiguous data in a chart?**
It is data in ranges that are not next to each other, such as a column of names and a column of totals with other columns between them. Select the first range, then hold Ctrl and select the others.

**When should you add a secondary axis?**
When two data series have very different values or units, so one would look flat on the same scale. The second series is plotted against its own axis on the right.

**What chart should I use to show a trend over time?**
A line graph, because it shows how values change from one point in time to the next.

**How do you highlight one slice of a pie chart?**
Extract (explode) the sector by pulling it out from the rest of the pie, and add a data label if needed.
