This set covers **section 2.16 (AHL only)** of IB DP Mathematics: Analysis and Approaches, first assessment 2021. Questions 1–5 all use the same function, f(x) = x² − 6x + 5 = (x − 1)(x − 5), whose graph has vertex (3, −4). Questions are calculator-free unless marked "(calculator allowed)". The methods are in the [modulus and related graphs study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-16/) and the [modulus and related graphs revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-16-revision-notes/).

## Section A

**1.** For f(x) = x² − 6x + 5:

**(a)** Write down the coordinates of the local maximum point of y = \|f(x)\|. **[1]**
**(b)** Solve \|f(x)\| = 4, giving exact answers. **[3]**

**2.** For f(x) = x² − 6x + 5, consider y = f(\|x\|).

**(a)** Write down the x-intercepts. **[2]**
**(b)** Write down the coordinates of the minimum points. **[1]**
**(c)** Write down the y-intercept. **[1]**

**3.** For f(x) = x² − 6x + 5, consider y = 1/f(x).

**(a)** Write down the equations of all the asymptotes. **[3]**
**(b)** Write down the coordinates of the local maximum point. **[1]**
**(c)** Write down the y-intercept. **[1]**

**4.** For f(x) = x² − 6x + 5, consider y = f(2x − 1).

**(a)** Write down the image of the vertex (3, −4). **[1]**
**(b)** Find the x-intercepts. **[2]**

**5.** For f(x) = x² − 6x + 5, consider y = [f(x)]².

**(a)** Write down the coordinates of the local maximum point. **[1]**
**(b)** Write down the points where the graph meets the x-axis, and describe its behaviour there. **[1]**
**(c)** Write down the y-intercept. **[1]**

**6.** Solve \|2x − 7\| = x − 2. **[3]**

## Section B

**7.** Solve \|x² − 2x\| = x. **[4]**

**8.**

**(a)** Solve \|x + 2\| = \|3x − 4\|. **[3]**
**(b)** Hence solve \|x + 2\| > \|3x − 4\|. **[2]**

**9.** Solve \|x² − 8\| ≤ 1, giving exact answers. **[4]**

**10.** Solve \|2x − 1\| < x + 4. **[5]**

**11.** Let g(x) = 1/(x² − 4).

**(a)** Write down the equations of the asymptotes of the graph of g. **[2]**
**(b)** Write down the coordinates of the local maximum point of the graph of g. **[1]**
**(c)** Solve g(x) = 1/5. **[2]**
**(d)** Write down the coordinates of the local minimum point of y = \|g(x)\|. **[1]**

**12.** (calculator allowed)

**(a)** Solve \|eˣ − 3\| = 2 − x. **[4]**
**(b)** Hence solve \|eˣ − 3\| < 2 − x. **[3]**

## Answers

**1. (a)** (3, 4) [1]
**(b)** f(x) = 4: x² − 6x + 1 = 0, so x = 3 ± 2√2 [1]. f(x) = −4: (x − 3)² = 0, so x = 3 [1]. Solutions 3 − 2√2, 3 and 3 + 2√2 [1]
*Examiner insight:* y = 4 is exactly the height of the reflected vertex, so the line touches the graph at x = 3 and that solution is easy to miss.

**2. (a)** x = −5, −1, 1, 5: ±1 [1] and ±5 [1]
**(b)** (−3, −4) and (3, −4) [1]
**(c)** (0, 5) [1]

**3. (a)** x = 1 [1]; x = 5 [1]; y = 0 [1]
**(b)** (3, −1/4) [1]
**(c)** (0, 1/5) [1]

**4. (a)** (p, q) → ((p + 1)/2, q), so (2, −4) [1]
**(b)** Zeros 1 and 5 map to (1 + 1)/2 = 1 and (5 + 1)/2 = 3 [1], giving (1, 0) and (3, 0) [1]
*Examiner insight:* Check: f(2x − 1) = (2x − 2)(2x − 6) = 4(x − 1)(x − 3).

**5. (a)** (3, 16) [1]
**(b)** (1, 0) and (5, 0), where the graph touches the axis (minimum points) [1]
**(c)** (0, 25) [1]

**6.** 2x − 7 = x − 2 gives x = 5 [1]. 2x − 7 = −(x − 2) gives x = 3 [1]. Both give x − 2 ≥ 0, so x = 3 or x = 5 [1]

**7.** x² − 2x = x gives x(x − 3) = 0, so x = 0 or 3 [1]. x² − 2x = −x gives x(x − 1) = 0, so x = 0 or 1 [1]. All satisfy x ≥ 0 [1]. Solutions x = 0, 1, 3 [1]

**8. (a)** x + 2 = 3x − 4 gives x = 3 [1]. x + 2 = −(3x − 4) gives x = 1/2 [1]. So x = 1/2 or x = 3 [1]
**(b)** Test x = 1: 3 > 1, true [1]. So 1/2 < x < 3 [1]

**9.** −1 ≤ x² − 8 ≤ 1 [1], so 7 ≤ x² ≤ 9 [1]. Hence −3 ≤ x ≤ −√7 [1] or √7 ≤ x ≤ 3 [1]

**10.** 2x − 1 = x + 4 gives x = 5 [1], valid since x + 4 = 9 ≥ 0 [1]. −(2x − 1) = x + 4 gives x = −1 [1], valid since x + 4 = 3 ≥ 0 [1]. The V-graph lies below the line between the two points: −1 < x < 5 [1]

**11. (a)** x = −2 and x = 2 [1]; y = 0 [1]
**(b)** x² − 4 has a minimum (0, −4), so g has a local maximum (0, −1/4) [1]
**(c)** x² − 4 = 5 [1], so x = ±3 [1]
**(d)** (0, 1/4) [1]

**12. (a)** Case eˣ − 3 = 2 − x: eˣ + x = 5, so x = 1.31 (3 s.f.) [1]. Case eˣ − 3 = x − 2: eˣ = x + 1, so x = 0 [1]. Check 2 − x ≥ 0: 2 − 1.31 > 0 and 2 − 0 > 0, both valid [1]. Solutions x = 0 and x = 1.31 [1]
**(b)** For x < ln 3, the inequality is 3 − eˣ < 2 − x, that is eˣ > x + 1, which is true for every x except x = 0, where the graphs touch [1]. For x ≥ ln 3, the inequality is eˣ + x < 5, so x < 1.31 [1]. Solution x < 1.31, x ≠ 0 [1]
*Examiner insight:* At x = 0 the line y = 2 − x is tangent to y = \|eˣ − 3\|, so the solution set has a single point removed rather than splitting into separate intervals. Zooming in on the GDC graph shows this.

## Where marks are usually lost

- Reflecting in the wrong axis for \|f(x)\| or f(\|x\|).
- Moving zeros under f(2x − 1) by halving and then adding 1, instead of adding 1 and then halving.
- Missing the tangent solution in question 1(b) or question 12.
- Not checking that the right-hand side is non-negative in a modulus equation.
- Reversing the region in a modulus inequality; always test one value.
