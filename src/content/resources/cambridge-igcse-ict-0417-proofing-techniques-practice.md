## Section A: short answers

**1.** State what is meant by *verification*. **[1]**

**2.** A price of 47.25 on an invoice is typed as 42.75. Name this type of data entry error. **[1]**

**3.** State what is meant by a *widow* in a document. **[1]**

**4.** Which **one** of the following describes double data entry?

A: The computer checks that the data is within a set range.

B: A person reads the data back to the customer.

C: The data is entered twice and the computer compares the two entries.

D: The data is checked against a list of allowed values.

**[1]**

**5.** Give **two** errors, other than spelling, that a person should look for when visually verifying typed data against a paper form. **[2]**

**6.** Give **one** advantage and **one** disadvantage of visual checking compared with double data entry. **[2]**

## Section B: structured questions

**7.** A clerk types these details from a handwritten form. Compare the two versions and identify the **four** errors, naming the type of each.

| Field | Form | Typed |
|---|---|---|
| Surname | McAllister | Mcallister |
| Membership number | 30651 | 30561 |
| Town | Port Glasgow | Port Glasow |
| Postcode | PA14 5XY | PA14 5XY, with two spaces in the middle |

**[4]**

**8.** A hospital enters patient blood test results into its system.

**(a)** Describe how double data entry would be carried out. **[2]**

**(b)** Explain why the hospital might choose double data entry rather than visual checking. **[2]**

**(c)** Give **one** error that double data entry would not detect. **[1]**

**9.** A student prints a four-page newsletter in two columns and finds these problems:

- the last line of an article appears alone at the top of the second column;
- a bulleted list starts at the bottom of column 1 and continues in column 2;
- page 4 is completely empty.

For each problem, describe how the student should correct it. **[3]**

**10.** A presentation has 12 slides. Slide 7 contains a table that continues onto slide 8, and slide 12 is empty.

Explain why each of these should be corrected before the presentation is shown. **[2]**

**11.** A school enters exam marks out of 80. A range check of 0 to 80 is used and the data is also verified.

**(a)** A mark of 85 is typed. State which method would detect this and why. **[2]**

**(b)** For another student, a mark of 63 is typed as 36. State which method would detect this and why. **[2]**

**12.** Explain why a system should use both validation and verification. Use examples in your answer. **[4]**

**13.** A report has been edited by three people. Describe **three** proofreading checks, other than spelling and grammar, that should be made before it is printed. **[3]**

## Answers

**1.** Checking that data has been copied accurately from the source (document) into the computer. **[1]**

**2.** Transposed numbers (credit transposition). **[1]**

**3.** The last line of a paragraph left alone at the top of a new page or column. **[1]**

**4.** C: The data is entered twice and the computer compares the two entries. **[1]**

**5.** Any two: transposed numbers (1); inconsistent character spacing (1); inconsistent case (1); missing or extra data (1). **[2]**

**6.** Advantage, any one: quicker or cheaper, because data is entered only once (1). Disadvantage, any one: the checker may miss errors, for example through tiredness, whereas the computer compares every character in double entry (1). **[2]**

**7.** 1 mark each, error with its type:
- Surname: *Mcallister*, inconsistent case (capital A missing) (1).
- Membership number: 30561, transposed numbers (6 and 5 swapped) (1).
- Town: *Glasow*, incorrect spelling (1).
- Postcode: two spaces, inconsistent character spacing (1). **[4]**

**8. (a)** The results are entered twice, usually by two different people (1); the computer compares the two versions and flags any differences, which are checked against the original results and corrected (1). **[2]**

**(b)** The data is important because errors could affect a patient's treatment (1); the computer compares every character, so it is less likely than a tired person to miss an error such as two swapped digits (1). **[2]**

**(c)** Any one: the same error made in both entries (1); an error that was already on the source document (1). **[1]**

**9.** 1 mark each:
- Widow: turn on widow/orphan control or keep the paragraph's lines together, rather than adding blank lines (1).
- Split list: insert a column break before the list (or keep the list paragraphs together) so the whole list is in one column (1).
- Blank page: show formatting marks and delete the extra empty paragraphs or stray page break that create page 4 (1). **[3]**

**10.** A table split across slides is hard for the audience to read and compare, because the header row and some data are not visible together (1); an empty final slide looks unfinished or unprofessional and leaves the audience with nothing to view (1). **[2]**

**11. (a)** Validation, the range check (1), because 85 is outside the allowed range of 0 to 80 and is rejected (1). **[2]**

**(b)** Verification (visual checking or double data entry) (1), because 36 is inside the range so passes validation, but it does not match the mark on the source (1). **[2]**

**12.** Up to 4 marks:
- Validation checks that data is reasonable and obeys rules (1), for example a range check rejects a month of 14 (1).
- Verification checks that data matches the source (1), for example finding 2063 typed as 2036, which validation would accept because it is a reasonable value (1).
- Each method misses errors the other catches, so using both reduces errors the most (1). **[4]**

**13.** Any three, 1 mark each: line spacing is consistent throughout (1); styles are applied consistently to headings and body text (1); there are no blank pages (1); there are no widows or orphans (1); tables and lists are not split across pages or columns (1); character spacing and case are consistent (1). **[3]**

## Frequently asked questions

**Is proofreading the same as verification?**
They overlap. Verification is checking data entry against a source. Proofreading checks a whole document, including its layout, styles and blank pages, as well as its text.

**Do I need to know other verification methods?**
The 15.2 notes and guidance name visual checking and double data entry. Learn those two first and be ready to compare them.
