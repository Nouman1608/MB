These questions cover subtopic **2.13 Functions** in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. The subtopic is **Extended only** (E2.13), so every question is Extended content for Paper 2 or Paper 4. None of them needs a calculator.

For worked examples, read the [functions study guide](/resources/igcse-mathematics-0580-functions/); for a one-page summary, use the [functions revision notes](/resources/cambridge-igcse-mathematics-0580-functions-cambridge-igcse-maths-revision-notes/).

## Questions

### Section A: short questions

**1.** f(x) = 7 − 2x. Find f(−4). **[1]**

**2.** g(x) = x² − 3x. Find g(−2). **[1]**

**3.** f(x) = 3x + 4. Solve f(x) = −11. **[2]**

**4.** f(x) = (x + 6)/2. Find f⁻¹(x). **[2]**

**5.** f(x) = 2x + 1 and g(x) = x².

**(a)** Find fg(3). **[1]**

**(b)** Find gf(3). **[1]**

**6.** f(x) = x² + 1 has domain {−2, 0, 3}. Write down the range. **[2]**

### Section B: structured questions

**7.** f(x) = 5x − 2 and g(x) = (x + 3)/2.

**(a)** Find gf(x), giving your answer in its simplest form. **[2]**

**(b)** Find f⁻¹(x). **[2]**

**(c)** Solve f(x) = g(x). **[3]**

**8.** f(x) = x² + 4.

**(a)** The domain of f is all real numbers. State the range. **[1]**

**(b)** The domain is changed to 0 ≤ x ≤ 3. State the range. **[2]**

**(c)** Explain why f(x) = 2 has no solution. **[1]**

**9.** f(x) = 3/(x − 2), x ≠ 2.

**(a)** Explain why x = 2 is excluded from the domain. **[1]**

**(b)** Find f⁻¹(x). **[3]**

**(c)** Find f⁻¹(6). **[1]**

**10.** f(x) = 2x − 3 and g(x) = x² + 1.

**(a)** Find gf(x), giving your answer in the form ax² + bx + c. **[2]**

**(b)** Solve gf(x) = 26. **[3]**

**11.** f(x) = 4/(x + 1), x ≠ −1, and g(x) = 2x − 1.

**(a)** Find fg(x), giving your answer as a fraction in its simplest form. **[2]**

**(b)** Find gf(x), giving your answer as a single fraction. **[3]**

**12.** f(x) = x³ − 5.

**(a)** Find f⁻¹(x). **[2]**

**(b)** Find f⁻¹(3). **[1]**

**13.** f(x) = 3x + k, where k is a constant. Given that ff(2) = 30, find k. **[3]**

## Answers

**1.** 7 − 2(−4) = 7 + 8 = **15** [1].

**2.** (−2)² − 3(−2) = 4 + 6 = **10** [1].

**3.** 3x + 4 = −11 [1], 3x = −15, **x = −5** [1].

**4.** y = (x + 6)/2, so 2y = x + 6 and x = 2y − 6 [1]. **f⁻¹(x) = 2x − 6** [1].

**5. (a)** g(3) = 9, f(9) = **19** [1].

**(b)** f(3) = 7, g(7) = **49** [1].
*Examiner insight:* fg(3) and gf(3) are different. The function next to the 3 is applied first.

**6.** f(−2) = 5, f(0) = 1, f(3) = 10 [1]. Range **{1, 5, 10}** [1].

**7. (a)** g(5x − 2) = (5x − 2 + 3)/2 [1] = **(5x + 1)/2** [1].

**(b)** y = 5x − 2, x = (y + 2)/5 [1]. **f⁻¹(x) = (x + 2)/5** [1].

**(c)** 5x − 2 = (x + 3)/2 [1]. 10x − 4 = x + 3, so 9x = 7 [1]. **x = 7/9** [1].
*Examiner insight:* f(x) = g(x) is an ordinary equation, not a composite. Set the two expressions equal and solve; do not substitute one into the other.

**8. (a)** **f(x) ≥ 4** [1].

**(b)** f(0) = 4 and f(3) = 13 [1]. **4 ≤ f(x) ≤ 13** [1].

**(c)** x² ≥ 0, so x² + 4 is never less than 4, and 2 is not in the range [1].

**9. (a)** At x = 2 the denominator is 0, and division by zero is undefined [1].

**(b)** y = 3/(x − 2), so x − 2 = 3/y [1], x = 3/y + 2 [1]. **f⁻¹(x) = 3/x + 2** (or (2x + 3)/x) [1].

**(c)** 3/6 + 2 = **2.5** [1] (check: f(2.5) = 3/0.5 = 6).

**10. (a)** gf(x) = (2x − 3)² + 1 [1] = **4x² − 12x + 10** [1].

**(b)** 4x² − 12x + 10 = 26, so x² − 3x − 4 = 0 [1]. (x − 4)(x + 1) = 0 [1]. **x = 4 or x = −1** [1].
*Examiner insight:* dividing 4x² − 12x − 16 = 0 by 4 before factorising keeps the numbers small; check one answer: f(4) = 5 and g(5) = 26.

**11. (a)** f(2x − 1) = 4/((2x − 1) + 1) = 4/(2x) [1] = **2/x** [1].

**(b)** gf(x) = 2 × 4/(x + 1) − 1 [1] = (8 − (x + 1))/(x + 1) [1] = **(7 − x)/(x + 1)** [1].
*Examiner insight:* in (a), 4/(2x) is correct but not in its simplest form; the second mark needs the cancelling to 2/x.

**12. (a)** y = x³ − 5, x³ = y + 5 [1]. **f⁻¹(x) = ∛(x + 5)** [1].

**(b)** ∛8 = **2** [1].

**13.** ff(x) = 3(3x + k) + k = 9x + 4k [1]. ff(2) = 18 + 4k = 30 [1]. **k = 3** [1].

## Where marks are usually lost

- Applying the functions in a composite in the wrong order.
- Missing brackets, such as writing 2x − 3² + 1 for (2x − 3)² + 1.
- Writing f⁻¹(x) as 1/f(x).
- Giving a range in terms of x, or as x-values.
- Leaving a composite fraction unsimplified when the simplest form is asked for.
