## Section A: short answers

**1.** State the name of the hardware component that allows a computer to connect to a network. **[1]**

**2.** Name the type of software that combines separately compiled parts of a program into a single program that can be run. **[1]**

**3.** Identify which **two** of the following are system software.

A: graphics editing software

B: device driver

C: computer aided design software

D: utility software

**[2]**

**4.** State **two** functions of a motherboard. **[2]**

**5.** A student says: "An applet and an app are the same thing." Explain why the student is not correct. **[2]**

**6.** Give **two** characteristics of digital data. **[2]**

## Section B: structured questions

**7.** A games designer builds a new computer for video editing and gaming.

**(a)** Describe the purpose of the graphics card in this computer. **[2]**

**(b)** The designer adds a sound card. Describe **two** conversions the sound card carries out. **[2]**

**(c)** Explain why the designer installs a device driver when connecting a new graphics tablet. **[2]**

**8.** A school science department uses a computer connected to a temperature sensor.

**(a)** In one experiment the computer records the temperature of a liquid every ten seconds for an hour. Identify the type of applications software used. **[1]**

**(b)** In another, the computer switches a heater on whenever the temperature falls below a set value. Identify the type of applications software used and explain how it differs from your answer to part (a). **[3]**

**9.** A programmer writes a program in a high-level language.

**(a)** Describe the role of a compiler. **[2]**

**(b)** Explain why the programmer also uses a linker. **[2]**

**10.** An office worker's computer is running slowly. A technician suggests running three utilities: a virus scanner, a disk defragmenter and a backup program.

Describe the purpose of each utility. **[3]**

**11.** A computer system for a recording studio captures a live drum performance and plays it back through speakers after editing.

**(a)** Explain why the sound from the microphone must be converted before it can be edited. **[2]**

**(b)** Explain why the edited data must be converted again before it is played. **[2]**

**(c)** Name the device that carries out the conversion in part (a). **[1]**

**12.** Describe the differences between applications software and system software. Give **one** example of each. **[4]**

## Answers

**1.** Network Interface Card (NIC). **[1]**

**2.** Linker. **[1]**

**3.** B: device driver (1); D: utility software (1). **[2]**

**4.** Any two: holds the CPU and memory (1); provides slots for expansion cards such as a graphics card (1); provides the connections that allow all components to communicate (1). **[2]**

**5.** An app is a complete program for a particular task, usually on a mobile device (1); an applet is a small program that performs one task and runs inside another program, such as a web browser (1). **[2]**

**6.** Any two: discrete values rather than continuous (1); stored as binary, 0s and 1s (1); can be processed directly by a computer (1). **[2]**

**7. (a)** It processes the image data (1) and sends the signal to the monitor that produces the picture, taking graphics work away from the CPU (1). **[2]**

**(b)** Converts digital sound data to analogue for speakers or headphones (1); converts analogue input from a microphone to digital data (1). **[2]**

**(c)** The driver tells the operating system how to communicate with the tablet (1); without it the tablet would not work correctly, or at all (1). **[2]**

**8. (a)** Measurement software (credit data logging). **[1]**

**(b)** Control software (1). It uses the sensor readings to decide when to switch the heater on (1), whereas measurement software only records the readings for later analysis and does not operate an output device (1). **[3]**

**9. (a)** Translates the whole high-level program into machine code (1) before it is run, producing an executable file (1). **[2]**

**(b)** The program may be made of separately compiled sections or use library routines (1); the linker joins these into a single program that can be run (1). **[2]**

**10.** Virus scanner: checks files for viruses and removes or quarantines them (1). Defragmenter: rearranges the parts of files on a hard disk so they are stored together and can be read faster (1). Backup program: makes a copy of files so that they can be restored if the originals are lost or damaged (1). **[3]**

**11. (a)** The microphone produces an analogue signal that varies continuously (1); the computer can only process digital data, so it must be converted to digital (1). **[2]**

**(b)** The data is stored as digital (1), but speakers need an analogue signal to produce sound, so it is converted from digital to analogue (1). **[2]**

**(c)** Analogue-to-digital converter (ADC), or the sound card. **[1]**

**12.** Applications software provides the services the user needs to solve a task (1), whereas system software provides the services the computer needs to operate (1). One example of applications software, such as word processing, spreadsheet, database management system, audio editing or video editing (1). One example of system software, such as an operating system, compiler, linker, device driver or utility (1). **[4]**

## Frequently asked questions

**Is an operating system applications software?**
No. The 0417 syllabus lists operating systems under system software, together with compilers, linkers, device drivers and utilities.

**Do I need to know how a compiler works step by step?**
No. You need to describe what it does: translate a whole high-level program into machine code before it is run.
