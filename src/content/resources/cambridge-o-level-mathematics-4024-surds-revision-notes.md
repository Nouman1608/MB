Condensed notes for subtopic **1.18 Surds** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027. The [Surds study guide](/resources/cambridge-o-level-mathematics-4024-surds/) explains each method with worked examples; the [Surds practice questions](/resources/cambridge-o-level-mathematics-4024-surds-practice/) give exam-style questions with mark schemes.

## Syllabus outcomes

1. Understand and use surds, including simplifying expressions.
2. Rationalise the denominator.

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Surd | irrational root of a rational number | √5 |
| Like surds | same number under the root | 3√2 and 7√2 |
| Simplified surd | no square factor under the root | 6√2 |
| Conjugate | same terms, opposite sign between | 2 + √5 and 2 - √5 |
| Rationalise | remove the surd from the denominator | 6/√3 = 2√3 |

## Rules

| Rule | Example |
|---|---|
| √a × √b = √(ab) | √6 × √10 = √60 = 2√15 |
| √a ÷ √b = √(a/b) | √50 ÷ √2 = √25 = 5 |
| √a × √a = a | √7 × √7 = 7 |
| (k√a)² = k²a | (3√2)² = 18 |
| √(a + b) ≠ √a + √b | √(9 + 16) = 5, not 7 |
| (a + √b)(a - √b) = a² - b | (5 + √2)(5 - √2) = 23 |

## Adding and subtracting

Simplify each surd, then combine like surds.

| Expression | Working | Result |
|---|---|---|
| √45 + √20 | 3√5 + 2√5 | 5√5 |
| √75 + √12 - √27 | 5√3 + 2√3 - 3√3 | 4√3 |
| √18 + √50 - √8 | 3√2 + 5√2 - 2√2 | 6√2 |
| 3√2 + 2√5 | unlike | cannot combine |
| 5√7 - 2√7 | like | 3√7 |

## Expanding

| Expression | Result |
|---|---|
| (2 + √5)² | 9 + 4√5 |
| (3 + √2)(1 + √2) | 5 + 4√2 |
| (√3 + 2)(√3 - 2) | -1 |
| (2√3 - 1)² | 13 - 4√3 |
| (5 + √2)(5 - √2) | 23 |

The brackets must be expanded fully: first × both terms, second × both terms.

## Rationalising

| Type | Method | Example |
|---|---|---|
| a/√b | multiply top and bottom by √b | 6/√3 = 2√3 |
| a/(k√b) | multiply by √b | 5/(2√5) = √5/2 |
| a/(c + √b) | multiply by c - √b | 3/(2 + √5) = 3√5 - 6 |
| a/(c - √b) | multiply by c + √b | 4/(3 - √5) = 3 + √5 |
| a/(√b - √d) | multiply by √b + √d | 1/(√7 - √3) = (√7 + √3)/4 |

Denominator after conjugate: c² - b (or b - d) is a whole number.

Check with a calculator when allowed: 3/(2 + √5) = 0.708 and 3√5 - 6 = 0.708.

## Rational or irrational?

| Expression | Value | Type |
|---|---|---|
| √2 × √8 | √16 = 4 | rational |
| √3 × √5 | √15 | irrational |
| (1 + √2)(1 - √2) | 1 - 2 = -1 | rational |
| 3 + √5 | cannot be simplified | irrational |
| √(9/4) | 3/2 | rational |
| √(5/9) | √5/3 | irrational |
| 2 × √7 | 2√7 | irrational |

A rational number plus or times an irrational number (other than 0) is irrational. Two irrational numbers can combine to give a rational one, as √2 × √8 shows.

## Surds under a fraction

Split the root over the top and bottom, then simplify each.

| Expression | Working | Result |
|---|---|---|
| √(9/4) | 3/2 | 3/2 |
| √(5/9) | √5/3 | √5/3 |
| √(8/18) | √8 ÷ √18 = 2√2 ÷ 3√2 | 2/3 |
| 1/√2 | multiply top and bottom by √2 | √2/2 |
| √2 ÷ √8 | √(2/8) = √(1/4) | 1/2 |

## A full worked example

Express (√5 + 1)/(√5 - 1) in the form a + b√5.

```
multiply top and bottom by (√5 + 1):
numerator:   (√5 + 1)^2 = 5 + 2√5 + 1 = 6 + 2√5
denominator: 5 - 1 = 4
result: (6 + 2√5)/4 = (3 + √5)/2 = 3/2 + (1/2)√5
```

Steps to remember: conjugate, expand top, expand bottom, then simplify the fraction by cancelling common factors.

## Exam traps

- √(a + b) is not √a + √b.
- Unlike surds do not combine.
- Square a bracket with three terms: (2 + √5)² = 4 + 4√5 + 5.
- Multiply the top and the bottom when rationalising.
- Use the conjugate for a bracket denominator.
- Simplify fully: 2√18 becomes 6√2.
- Watch the sign when the denominator is -1.
- Keep the answer exact unless a decimal is asked for.
