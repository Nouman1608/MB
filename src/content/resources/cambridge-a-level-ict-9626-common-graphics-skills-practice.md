These questions cover **section 19.1 Common graphics skills** of the Cambridge International AS & A Level Information Technology 9626 syllabus for examination in 2025, 2026 and 2027 (version 4). This is **A Level only** content. The syllabus tests the practical skills in Paper 4 (Advanced Practical) and bases Paper 3 (Advanced Theory) on sections 12 to 21, where calculators are not allowed. These written questions can be answered on paper; practise the tools in your own graphics software too.

## Questions

**1.** A poster is built in a graphics program using separate layers for the background, a logo, a photograph and the title text.

**(a)** Explain **two** benefits of using separate layers. **[2]**
**(b)** The logo accidentally hides part of the title. State how the layers can be changed so that the title is visible. **[1]**
**(c)** The designer wants to make the photograph partly see-through so that the background shows through it. State the setting that is changed. **[1]**
**(d)** State why the designer should keep a layered copy of the file after flattening it for export. **[1]**

**2.** State the transform tool that would be used for each of the following.

**(a)** Making the image a mirror image of itself. **[1]**
**(b)** Turning a shape around a point by 30 degrees. **[1]**
**(c)** Slanting a rectangle to make a parallelogram. **[1]**
**(d)** Making a flat picture look as if it is sloping away into the distance. **[1]**

**3.** A designer is making a ring-shaped logo from two circles, and wants to arrange six icons in a neat row.

**(a)** Describe how the ring can be made using a grouping or merging tool. **[2]**
**(b)** Explain the difference between grouping objects and combining (joining) them. **[2]**
**(c)** Describe how the six icons can be given equal spaces between them and a common top edge. **[2]**

**4.** Describe the purpose of each of the following layout tools.

**(a)** guidelines **[1]**
**(b)** snapping **[1]**

**5.** A colour in RGB is described by three values from 0 to 255.

**(a)** State the number of colours that can be made with 8 bits for each of the red, green and blue values. **[1]**
**(b)** State how RGB creates colour, and name a device that uses it. **[2]**
**(c)** State how CMYK creates colour, and explain why the K is included. **[3]**
**(d)** Describe what a colour management system does. **[1]**

**6.** A photograph is 800 pixels wide and 600 pixels high. Each pixel uses 24 bits.

**(a)** Calculate the uncompressed size of the image in bytes. **[3]**
**(b)** The image is changed to use 8 bits per pixel. Calculate the new size in bytes. **[2]**
**(c)** The photograph is to be printed as a 4-inch by 3-inch picture at 300 pixels per inch. State the width and height in pixels that the image needs, and explain why the 800 by 600 pixel image would not be suitable. **[3]**

**7.** The graphic designer must choose a file format for each of the following. Name a suitable format and justify your choice.

**(a)** A photograph for a web page. **[2]**
**(b)** A company logo that must be enlarged to the size of a billboard without losing quality. **[2]**
**(c)** A simple icon with a transparent background and sharp edges. **[2]**

**8.** State **two** disadvantages of using a very high resolution for an image that is only to be shown on a web page. **[2]**

## Answers

**1. (a)** Any two: each element can be edited, moved or deleted without affecting the others [1]; elements can be shown, hidden or reordered to try different designs [1]; locked layers prevent accidents; opacity can be set for each layer. [1] **[2]**
**(b)** Change the order of the layers so that the title layer is above the logo layer (or move the logo). [1] **[1]**
**(c)** The opacity (transparency) of the photograph layer. [1] **[1]**
**(d)** Flattening removes the layers, so the layered file is needed to edit individual elements later. [1] **[1]**

**2. (a)** Reflect (flip). [1]
**(b)** Rotate. [1]
**(c)** Skew (or shear). [1]
**(d)** Perspective. [1] **[4]**

**3. (a)** Draw a large circle and a smaller circle in the centre [1]; select both and use subtract so the small circle is cut out of the large one. [1] **[2]**
**(b)** Grouping keeps the objects separate, so they move and resize together and can be ungrouped [1]; combining or joining makes them a single new object, with one outline, which cannot be separated back into the original shapes in the same way. [1] **[2]**
**(c)** Select the icons and use the distribute tool (horizontally) to make the gaps equal [1]; use the align top tool to line up their top edges. [1] **[2]**

**4. (a)** Lines dragged from the rulers to mark positions (such as margins or the centre) that objects can be lined up with. [1] **[1]**
**(b)** It makes objects jump to the grid, guides or other objects, so that placement is exact. [1] **[1]**

**5. (a)** 256 × 256 × 256 = 16,777,216. [1] **[1]**
**(b)** It is additive: red, green and blue light are combined (full values of all three make white) [1]; used by screens such as a monitor, television or phone (also cameras and scanners). [1] **[2]**
**(c)** It is subtractive: cyan, magenta and yellow inks absorb (subtract) colours from the white light reflected by paper [1]. The K stands for key, black [1]. Black is included because mixing the three inks gives a muddy dark colour, and black ink gives true black and saves coloured ink. [1] **[3]**
**(d)** It uses colour profiles to convert colours between devices so that they look consistent on screens and in print. [1] **[1]**

**6. (a)** Pixels = 800 × 600 = 480,000 [1]. Bits = 480,000 × 24 = 11,520,000 [1]. Bytes = 11,520,000 ÷ 8 = 1,440,000. [1] **[3]**
**(b)** 480,000 × 8 = 3,840,000 bits [1]; ÷ 8 = 480,000 bytes. [1] **[2]**
**(c)** Width 4 × 300 = 1,200 pixels and height 3 × 300 = 900 pixels. [1] The 800 by 600 image has 800 ÷ 4 = 200 pixels per inch (and 600 ÷ 3 = 200) [1], which is below 300, so the print would look soft or blocky. [1] **[3]**
*Examiner insight:* Show the multiplication of pixels first, then bits to bytes by dividing by 8. Quoting only the final number risks losing method marks.

**7. (a)** JPG [1]; lossy compression gives a small file that downloads quickly, and the loss of detail is hard to see in a photograph. [1] **[2]**
**(b)** SVG (a vector format) [1]; vector graphics are made of shapes defined by mathematics, so they can be scaled to any size without losing quality. [1] **[2]**
**(c)** PNG (or SVG, or GIF) [1]; PNG supports transparency and keeps sharp edges because its compression is lossless. [1] **[2]**

**8.** Any two: the file is much larger, so the page is slow to load [1]; it uses more storage and bandwidth [1]; the screen cannot show the extra detail, so there is no visible benefit [1]; the program is slower to edit it. **[2]**

## Where marks are usually lost

- Calling RGB subtractive or CMYK additive.
- Giving the file size in bits when bytes are asked for, or forgetting to divide by 8.
- Flattening layers without keeping a layered copy.
- Choosing JPG for a logo or an image that needs transparency.
- Saying "high resolution is always better" without mentioning file size.
- Mixing up align (put on a line) with distribute (equal gaps).

## Frequently asked questions

**How do I calculate the file size of an uncompressed image?**
Multiply the width in pixels by the height in pixels to get the number of pixels, multiply by the bits per pixel, then divide by 8 to get bytes.

**Which file formats must I know?**
SVG, BMP, JPG/JPEG, PNG, GIF, TIF and PDF, including whether each is a bitmap or vector format and where it is suitable.
