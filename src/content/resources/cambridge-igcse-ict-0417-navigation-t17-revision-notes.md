These notes cover the **navigation** row of Topic 17 in Cambridge IGCSE ICT 0417: "add and delete bookmarks/hyperlinks". The [navigation study guide](/resources/cambridge-igcse-ict-0417-navigation-t17/) explains every step with a worked set of instructions, and the [navigation practice questions](/resources/cambridge-igcse-ict-0417-navigation-t17-practice/) let you test yourself.

## Syllabus coverage

| Syllabus statement | Notes and guidance |
|---|---|
| Navigation | Add and delete bookmarks/hyperlinks |

## Key terms

| Term | Meaning |
|---|---|
| Bookmark | A named location (a point or selected text) in a document |
| Hyperlink | Text or an object that takes the reader to a target when clicked |
| Display text | The text the reader sees and clicks |
| Target | Where the link goes: a bookmark, web page, file or email address |
| ScreenTip | Short text shown when the pointer rests on a link |
| mailto: | The start of a link target that opens a new email to an address |
| Remove hyperlink | Takes the link away but keeps the text |
| Broken link | A link whose target no longer exists |

## Bookmarks: recall

- Select the text or click the point, then insert a bookmark and type the name.
- Name exactly as instructed. In Microsoft Word: start with a letter; letters, numbers and underscores only; **no spaces**.
- Valid: *Top*, *Fees*, *Part_3*. Invalid: *Part 3*, *3rd_part*.
- Bookmarks do not print. Turn on bookmark display to check their position.
- Delete from the bookmark list; the text stays.

## Hyperlinks: recall

- Select **only** the specified words, then insert a hyperlink.
- Choose the target type:
  - place in this document (bookmark or heading);
  - web page (full address);
  - existing file;
  - email address (stored as *mailto:* plus the address).
- Add a ScreenTip if asked.
- Test every link (often Ctrl+click while editing).
- Edit a link to change its target or display text.

## Deleting: what happens to the text?

| Action | Text afterwards | Link afterwards |
|---|---|---|
| Remove hyperlink | Still there, plain | Gone |
| Delete the linked text | Gone | Gone |
| Delete a bookmark | Still there | Any link to it is broken |
| Delete bookmarked text | Gone | Bookmark gone; links to it broken |

## Purpose of navigation features

- Jump to a section of a long electronic document without scrolling.
- Contents lists and "back to top" links speed up moving around.
- Cross-references take the reader straight to related content.
- Links connect the document to web pages, other files and contact email addresses.
- They work only on screen: a printed document needs page numbers instead.

## Evidence in the practical

- The printed page shows only underlined text, not where it goes.
- Take a screenshot of the hyperlink dialogue showing the target, if evidence is asked for.
- Display bookmarks before taking a screenshot of their position.

## Worked example: checking three links

A student's document has three links. Each is tested with Ctrl+click and the hyperlink dialogue is opened.

| Display text | Target found | Correct? | Fix |
|---|---|---|---|
| *Opening hours* | Bookmark *Hours* at the heading *Opening hours* | Yes | None |
| *Visit our website* | Bookmark *Top* | No: should be a web page | Edit the link and enter the web address |
| *Write to us* | Web page with the email address typed in | No: should be an email target | Edit the link, choose email address, enter the address |

Two of the three links display correctly on the page but go to the wrong kind of target. Only testing and opening the dialogue shows this, which is why checking is part of the skill.

## Exam traps

- A **space** in a bookmark name.
- Bookmark on the wrong text, or at a point just before or after the heading.
- Linking the whole line instead of the exact words.
- "Remove the hyperlink" means **keep the text**.
- Deleting a bookmark without fixing the links that pointed to it.
- Forgetting the target type: an email link must go to an email address, not a web page.
- Not testing.

## Self-test

1. Define a bookmark.
2. Give two valid bookmark names and one invalid name with the reason.
3. Name the four types of hyperlink target.
4. What is the display text of a hyperlink?
5. What does a *mailto:* link do when clicked?
6. How is a hyperlink removed without deleting the text?
7. What happens to a hyperlink if its target bookmark is deleted?
8. Why does a printed document not benefit from hyperlinks?
9. What is a ScreenTip?
10. Give one purpose of a "back to top" link.
11. How would you prove in your evidence where a hyperlink goes?
12. A task says: "Make the word *Map* a hyperlink to the file named in the paper." Which target type is used?

### Answers

1. A named location in a document, marking a point or selected text, that can be jumped to or linked to.
2. Valid, for example *Top* and *Results_2*; invalid, for example *Results 2* because it contains a space (or *2Results* because it starts with a digit, in Word).
3. A place in this document (bookmark or heading), a web page, an existing file and an email address.
4. The text the reader sees and clicks on.
5. It opens a new email message addressed to the given email address.
6. Right-click it and choose remove hyperlink.
7. It is broken: it no longer goes to the correct place.
8. A printed page cannot be clicked, so the links do nothing.
9. Short text that appears when the pointer rests on a hyperlink.
10. To let the reader return to the start of the document quickly, without scrolling.
11. Take a screenshot of the hyperlink dialogue showing the target.
12. Existing file.
