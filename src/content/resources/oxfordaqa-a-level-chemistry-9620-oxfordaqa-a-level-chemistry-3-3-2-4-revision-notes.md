## The subtopic in four lines

1. Methane + chlorine in UV light → chloromethane + hydrogen chloride.
2. Mechanism: **free-radical substitution**.
3. Steps: **initiation** (radicals made), **propagation** (radical in, radical out), **termination** (radicals combine).
4. Dots for radicals; no curly arrows; one balanced equation per step.

## Key terms

| Term | Meaning to learn |
|---|---|
| Radical | Species with an unpaired electron |
| Homolytic fission | Bond breaking with one electron going to each atom |
| Substitution | Replacement of one atom or group by another |
| Initiation | Step that forms radicals from a molecule (needs UV) |
| Propagation | Step that uses one radical and produces another |
| Termination | Step in which two radicals combine and the chain stops |
| Chain reaction | Propagation steps regenerate the radical, so the cycle repeats |
| Further substitution | Replacement of more H atoms to give CH₂Cl₂, CHCl₃, CCl₄ |

## The mechanism to learn

```
Initiation      Cl₂ → 2Cl•                         (UV light)
Propagation     CH₄ + Cl• → •CH₃ + HCl
                •CH₃ + Cl₂ → CH₃Cl + Cl•
Termination     Cl• + Cl• → Cl₂
                •CH₃ + Cl• → CH₃Cl
                •CH₃ + •CH₃ → C₂H₆
```

| Step | Radicals left | Radicals right |
|---|---|---|
| Initiation | 0 | 2 |
| Propagation | 1 | 1 |
| Termination | 2 | 0 |

**Why Cl–Cl breaks:** it is weaker (about 243 kJ mol⁻¹) than C–H (about 413 kJ mol⁻¹), and UV light provides enough energy for homolytic fission.

## Further substitution

Each extra chlorine needs the same pair of propagation steps: Cl• removes an H atom as HCl, leaving a chlorinated methyl radical, which then takes a Cl atom from Cl₂ and regenerates Cl•. Example for trichloromethane:

```
CH₂Cl₂ + Cl• → •CHCl₂ + HCl
•CHCl₂ + Cl₂ → CHCl₃ + Cl•
```

| Overall | Equation |
|---|---|
| To CH₃Cl | CH₄ + Cl₂ → CH₃Cl + HCl |
| To CH₂Cl₂ | CH₄ + 2Cl₂ → CH₂Cl₂ + 2HCl |
| To CHCl₃ | CH₄ + 3Cl₂ → CHCl₃ + 3HCl |
| To CCl₄ | CH₄ + 4Cl₂ → CCl₄ + 4HCl |

**Control:** excess CH₄ → mainly CH₃Cl. Excess Cl₂ → mainly CCl₄. Separate the mixture by fractional distillation (different boiling points).

**Two-carbon products** (ethane, chloroethane) come only from termination between carbon radicals, which is evidence for the mechanism.

## Numbers and calculations to recall

| Quantity | Value or method |
|---|---|
| Cl–Cl bond enthalpy | about 243 kJ mol⁻¹ (weaker, breaks in UV) |
| Mean C–H bond enthalpy | about 413 kJ mol⁻¹ |
| Atom economy for CH₃Cl | 50.5 ÷ (16.0 + 71.0) × 100 = 58.0 % |
| Atom economy for CCl₄ | 154.0 ÷ (16.0 + 284.0) × 100 = 51.3 % |
| Percentage yield | actual mass ÷ theoretical mass × 100 |

Boiling points rise from CH₃Cl (about −24 °C) to CCl₄ (about 77 °C): more electrons, stronger van der Waals forces, so the mixture can be fractionally distilled.

## Spotting a faulty step

- An ion such as Cl⁻ in any step: the fission shown is heterolytic, which is wrong for this mechanism.
- H• anywhere: wrong; hydrogen leaves as HCl.
- Two radicals in and one out: not a valid step of either kind.
- A step whose atoms do not balance: rewrite it before deciding its type.

## Exam traps

- UV light is the condition, not a catalyst; it is needed for initiation.
- First propagation step makes **HCl**, never H•.
- •CH₃ has the dot on carbon.
- No curly arrows in radical steps.
- Termination: two radicals in, none out. Propagation: one in, one out.
- Product is a mixture unless methane is in excess.
- Homolytic fission gives radicals, not ions.
- Atom economy for CH₃Cl is low (58.0 %) because HCl forms too.

## Self-test

Answer without looking, then check below.

1. Name the mechanism of the reaction of methane with chlorine.
2. State the condition needed.
3. Write the initiation step.
4. Write the two propagation steps for forming chloromethane.
5. Write the termination step that forms ethane.
6. Why does the Cl–Cl bond break rather than a C–H bond?
7. What does "homolytic" mean?
8. Write the two propagation steps that form tetrachloromethane from trichloromethane.
9. How can a high proportion of chloromethane be obtained?
10. Explain why a trace of chloroethane is found in the product.
11. Write the overall equation for the formation of dichloromethane from methane.
12. Calculate the maximum mass of trichloromethane (Mr 119.5) from 3.20 g of methane.

### Answers

1. Free-radical substitution.
2. Ultraviolet light.
3. Cl₂ → 2Cl•.
4. CH₄ + Cl• → •CH₃ + HCl; •CH₃ + Cl₂ → CH₃Cl + Cl•.
5. 2•CH₃ → C₂H₆.
6. Cl–Cl is the weaker bond, so UV light supplies enough energy to break it.
7. The shared pair splits, one electron going to each atom.
8. CHCl₃ + Cl• → •CCl₃ + HCl; •CCl₃ + Cl₂ → CCl₄ + Cl•.
9. Use excess methane.
10. A •CH₃ radical and a •CH₂Cl radical combine in a termination step.
11. CH₄ + 2Cl₂ → CH₂Cl₂ + 2HCl.
12. n(CH₄) = 3.20 ÷ 16.0 = 0.200 mol; mass = 0.200 × 119.5 = 23.9 g.
