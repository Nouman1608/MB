This guide covers subtopic **1.18 Surds** in Topic 1 Number of the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. It is **Extended only**: the Core syllabus lists C1.18 as "Extended content only". The Extended statements (E1.18) are:

1. **Understand and use surds, including simplifying expressions.** The syllabus examples are √20 = 2√5 and √200 − √32 = 6√2.
2. **Rationalise the denominator.** The syllabus examples are 10/√5 = 2√5 and 1/(−1 + √3) = (1 + √3)/2.

Surd questions expect exact answers, so a decimal from a calculator does not score, even on Paper 4. The [exponential growth, decay and surds guide](/resources/igcse-mathematics-0580-exponential-growth-decay-and-surds/) introduces the rules. This page builds fluency with longer expressions: choosing the largest square factor, collecting several surds, expanding squares of brackets, comparing sizes without a calculator, and rationalising two-term denominators with surds on top as well. Afterwards, use the [surds revision notes](/resources/cambridge-igcse-mathematics-0580-surds-cambridge-igcse-maths-revision-notes/) and the [surds practice questions](/resources/cambridge-igcse-mathematics-0580-surds-cambridge-igcse-maths-practice/).

## The rules you use

For positive numbers a and b:

```
√a × √b = √(ab)          √a ÷ √b = √(a/b)          √a × √a = a
```

There is **no** rule for adding: √a + √b is not √(a + b). For example, √9 + √16 = 3 + 4 = 7, but √25 = 5.

A surd is in its **simplest form** when the number under the root has no square factor other than 1. Learn the squares to 15² = 225; they are the factors you look for.

## Simplifying (1.18.1)

Find the **largest** square factor, split the root, and take the square root of that factor.

### Worked example 1

Simplify (a) √75, (b) √288.

```
(a) 75 = 25 × 3        √75 = √25 × √3 = 5√3

(b) 288 = 144 × 2      √288 = 12√2
```

If you use a smaller square factor first, such as 288 = 4 × 72 to get 2√72, you are not finished: 2√72 = 2 × 6√2 = 12√2. Using the largest square factor saves steps.

### Worked example 2: collecting surds

Simplify (a) √200 − √32 (the syllabus example), (b) 3√12 + √27 − √48.

```
(a) √200 = 10√2       √32 = 4√2
    10√2 - 4√2 = 6√2

(b) 3√12 = 3 × 2√3 = 6√3     √27 = 3√3     √48 = 4√3
    6√3 + 3√3 - 4√3 = 5√3
```

Surds collect like algebra terms: 6√3 + 3√3 is like 6x + 3x. You can only collect them once they have the **same number under the root**.

## Multiplying and expanding

Multiply the whole numbers together and the surds together. Then simplify.

### Worked example 3

Expand and simplify (a) (3 − √2)(5 + 2√2), (b) (√7 + √3)², (c) (2√5)³.

```
(a) 3 × 5 = 15        3 × 2√2 = 6√2
    -√2 × 5 = -5√2    -√2 × 2√2 = -2 × 2 = -4
    15 + 6√2 - 5√2 - 4 = 11 + √2

(b) (√7 + √3)(√7 + √3) = 7 + √21 + √21 + 3 = 10 + 2√21

(c) (2√5)^3 = 2^3 × (√5)^3 = 8 × 5√5 = 40√5
```

In (b), the square of a bracket has a middle term: (√7 + √3)² is not 7 + 3. In (c), (√5)³ = √5 × √5 × √5 = 5√5.

## Comparing sizes without a calculator

To compare surds, write each one as a single root, or square both.

### Worked example 4

Which is larger, 3√5 or 2√11?

```
(3√5)^2 = 9 × 5 = 45
(2√11)^2 = 4 × 11 = 44
45 > 44, so 3√5 is larger.
```

Squaring keeps the order because both numbers are positive.

## Exact answers in other topics

Surds give exact answers in Pythagoras' theorem, trigonometry and mensuration. The question signals this with "give your answer in surd form", "exact" or "in the form a + b√c".

### Worked example 5

(a) A right-angled triangle has shorter sides √6 cm and √10 cm. Find the hypotenuse.
(b) A rectangle measures (3 + √2) cm by (3 − √2) cm. Find its area and perimeter.

```
(a) h^2 = (√6)^2 + (√10)^2 = 6 + 10 = 16, so h = 4 cm

(b) Area = (3 + √2)(3 - √2) = 9 - 3√2 + 3√2 - 2 = 7 cm^2
    Perimeter = 2(3 + √2) + 2(3 - √2) = 6 + 2√2 + 6 - 2√2 = 12 cm
```

Brackets of the form (a + √b)(a − √b) always give a whole number, a² − b. This fact is the key to rationalising.

## Rationalising the denominator (1.18.2)

Rationalising means rewriting a fraction so that there is no surd in the denominator. Multiply the top and bottom by the same thing, so that the value does not change.

| Denominator | Multiply top and bottom by | Because |
|---|---|---|
| √b or k√b | √b | √b × √b = b |
| a + √b | a − √b | (a + √b)(a − √b) = a² − b |
| a − √b | a + √b | (a − √b)(a + √b) = a² − b |

### Worked example 6: one-term denominators

Rationalise (a) 10/√5 (the syllabus example), (b) 9/(2√3).

```
(a) 10/√5 × √5/√5 = 10√5/5 = 2√5

(b) 9/(2√3) × √3/√3 = 9√3/(2 × 3) = 9√3/6 = 3√3/2
```

Always simplify after rationalising. In (b), 9 and 6 share a factor of 3.

### Worked example 7: two-term denominators

Rationalise (a) 1/(−1 + √3) (the syllabus example), (b) 6/(3 − √3), (c) (2 + √5)/(√5 − 1).

```
(a) Multiply by (1 + √3)/(1 + √3)
    denominator: (-1 + √3)(1 + √3) = -1 - √3 + √3 + 3 = 2
    answer: (1 + √3)/2

(b) Multiply by (3 + √3)/(3 + √3)
    denominator: 9 - 3 = 6
    6(3 + √3)/6 = 3 + √3

(c) Multiply by (√5 + 1)/(√5 + 1)
    numerator: (2 + √5)(√5 + 1) = 2√5 + 2 + 5 + √5 = 7 + 3√5
    denominator: 5 - 1 = 4
    answer: (7 + 3√5)/4
```

In (a), −1 + √3 is the same as √3 − 1, so multiply by √3 + 1. When the numerator also contains a surd, as in (c), expand it fully before you simplify.

## Common mistakes

- Adding under the root: √9 + √16 ≠ √25.
- Not using the largest square factor, so the answer is not fully simplified.
- Collecting unlike surds, such as 2√3 + 4√2 = 6√5.
- Missing the middle term when squaring a bracket.
- Writing √5 × √5 = 25 instead of 5.
- Multiplying only the denominator when rationalising, which changes the value.
- Forgetting to simplify a rationalised answer, such as leaving 9√3/6.
- Using a calculator decimal on a question that asks for an exact answer.

## Exam technique for the command words

- **Simplify**: the answer must be in simplest surd form, with no square factor under the root and like surds collected.
- **Show that** an expression equals a given surd: show every step, including each separate simplification, because the answer is printed.
- **Write in the form** a + b√c: state the values of a, b and c if asked, and check that c has no square factor.
- **Rationalise the denominator**: the final answer must have a whole-number denominator, and be simplified.
