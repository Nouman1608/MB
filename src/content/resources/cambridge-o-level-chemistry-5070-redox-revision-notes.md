Condensed recall for subtopic 6.4 of Cambridge O Level Chemistry 5070. For full explanations and three worked examples, use the [redox study guide](/resources/cambridge-o-level-chemistry-5070-redox/); to practise, try the [redox practice questions](/resources/cambridge-o-level-chemistry-5070-redox-practice/).

## Definitions

- **Redox:** simultaneous reduction and oxidation.
- **Oxidation:** gain of oxygen; loss of electrons; increase in oxidation number.
- **Reduction:** loss of oxygen; gain of electrons; decrease in oxidation number.
- **Oxidising agent:** a substance that oxidises another substance and is itself reduced.
- **Reducing agent:** a substance that reduces another substance and is itself oxidised.

Memory aid: **OIL RIG**, Oxidation Is Loss, Reduction Is Gain (of electrons).

## Key terms

| Term | Meaning |
|---|---|
| Oxidation number | Number showing how oxidised or reduced an element is in a substance |
| Roman numeral | Shows the oxidation number of the element it follows, e.g. iron(III) = +3 |
| Spectator ion | Ion present but unchanged in a reaction |
| Ionic equation | Equation showing only the particles that change |
| Half-equation | Equation showing electrons lost (oxidation) or gained (reduction) by one species |
| Displacement | A more reactive element replaces a less reactive one from its compound; always redox |

## Oxidation number rules

1. Uncombined element = 0.
2. Monatomic ion = its charge.
3. Sum in a compound = 0.
4. Sum in an ion = charge on the ion.

Usual values: O = −2, H = +1, Group I = +1, Group II = +2, halide ions = −1.

## Roman numerals in names

- The numeral is the oxidation number of the element just before it: iron(II) sulfate = FeSO₄; iron(III) sulfate = Fe₂(SO₄)₃.
- Use it to write formulae: copper(I) oxide has Cu at +1, so two Cu balance one O: Cu₂O.
- In an anion, the numeral belongs to the central element: manganate(VII) means Mn is +7.

## Quick reference values

| Species | Oxidation number |
|---|---|
| Fe in FeCl₂ / FeCl₃ | +2 / +3 |
| Cu in Cu₂O / CuO | +1 / +2 |
| S in H₂S / SO₂ / SO₃ / SO₄²⁻ | −2 / +4 / +6 / +6 |
| N in NH₃ / NO₂ / NO₃⁻ | −3 / +4 / +5 |
| Mn in MnO₂ / MnO₄⁻ | +4 / +7 |
| C in CO / CO₂ | +2 / +4 |
| Cl in Cl₂ / Cl⁻ | 0 / −1 |

## Method: is it redox?

1. Assign oxidation numbers to every element on both sides.
2. If any element's number changes, it is redox; if none change, it is not.
3. Increase = oxidised; decrease = reduced.
4. The reactant containing the element **reduced** is the **oxidising agent**; the reactant containing the element **oxidised** is the **reducing agent**.

Not redox: neutralisation, precipitation, thermal decomposition of carbonates.

## Splitting an ionic equation into half-equations

Take Mg + 2H⁺ → Mg²⁺ + H₂ (magnesium with an acid).

1. Pick out each species that changes: Mg becomes Mg²⁺; H⁺ becomes H₂.
2. Balance atoms in each half: Mg → Mg²⁺; 2H⁺ → H₂.
3. Add electrons to balance charge: Mg → Mg²⁺ + 2e⁻ (oxidation); 2H⁺ + 2e⁻ → H₂ (reduction).
4. Check the electrons lost equal the electrons gained (2 each here).

So magnesium is the reducing agent and hydrogen ions are the oxidising agent: the reaction of a metal with an acid is redox, even though neutralisation is not.

## Spotting redox quickly

- Any reaction in which an **element becomes a compound**, or a compound becomes an element, is redox: combustion, displacement, metal + acid, electrolysis, extraction of metals.
- Reactions in which ions simply swap partners (precipitation) or H⁺ combines with OH⁻ (neutralisation) are not redox.

## Colour tests

| Reagent | Acts as | Colour change | Shows the added substance is |
|---|---|---|---|
| Acidified aqueous potassium manganate(VII) | Oxidising agent | Purple → colourless | A reducing agent |
| Aqueous potassium iodide | Reducing agent | Colourless → yellow-brown (iodine forms) | An oxidising agent |

Examples: SO₂ and Fe²⁺ decolourise manganate(VII); Cl₂ and H₂O₂ turn iodide brown.

## Exam traps

- An oxidising agent is **reduced**, not oxidised.
- Divide by the number of atoms: in Fe₂O₃, each Fe is +3.
- Ions are not zero: Br⁻ is −1, Fe²⁺ is +2.
- Name the agent as a substance ("chlorine"), not as a process.
- Do not call neutralisation redox: no oxidation numbers change.
- The two colour tests go in opposite directions: manganate(VII) loses colour; iodide gains colour.
- Spectator ions (like K⁺ in KBr) do not change oxidation number.
- In potassium manganate(VII), the numeral refers to manganese, not potassium.

## Self-test

1. Define reduction in terms of electrons.
2. Define an oxidising agent.
3. State the oxidation number of oxygen in O₂ and in MgO.
4. Deduce the oxidation number of S in SO₃.
5. Deduce the oxidation number of Cr in Cr₂O₇²⁻.
6. Write the formula of copper(I) oxide.
7. In Mg + Cu²⁺ → Mg²⁺ + Cu, which species is oxidised?
8. In question 7, name the oxidising agent.
9. Is AgNO₃ + NaCl → AgCl + NaNO₃ a redox reaction? Explain.
10. What colour change is seen when sulfur dioxide is bubbled into acidified potassium manganate(VII)?
11. A solution turns aqueous potassium iodide yellow-brown. What does this show?
12. In 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻, state the change in oxidation number of iron and of chlorine.

**Answers**

1. Gain of electrons.
2. A substance that oxidises another substance and is itself reduced.
3. 0 in O₂; −2 in MgO.
4. S + 3(−2) = 0, so +6.
5. 2Cr + 7(−2) = −2, so 2Cr = +12 and Cr = +6.
6. Cu₂O.
7. Magnesium (Mg), which loses electrons.
8. Cu²⁺ ions (copper(II) ions).
9. No: all oxidation numbers stay the same (Ag +1, N +5, O −2, Na +1, Cl −1).
10. Purple to colourless.
11. The solution contains an oxidising agent, which oxidises iodide ions to iodine.
12. Iron +2 → +3 (oxidised); chlorine 0 → −1 (reduced).
