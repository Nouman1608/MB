These questions cover **section 5.17 of IB DP Mathematics: Analysis and Approaches: areas enclosed by a curve and the y-axis, and volumes of revolution about the x-axis or y-axis**. It is AHL content, for HL students. Every rotation is through 2π. Questions are labelled "(calculator-free)" or "(calculator allowed)".

Learn the methods first in the [section 5.17 study guide](/resources/ib-dp-mathematics-analysis-and-approaches-5-17/) and the [section 5.17 revision notes](/resources/ib-dp-mathematics-analysis-and-approaches-5-17-revision-notes/).

## Section A

**1.** (calculator-free) Find the area of the region enclosed by the curve x = y³, the y-axis and the line y = 2. **[2]**

**2.** (calculator-free) The region R is enclosed by y = ln(x + 1), the y-axis and the line y = ln 3. Find the exact area of R. **[4]**

**3.** (calculator-free) The region under y = 2x + 1, for 0 ≤ x ≤ 1, is rotated about the x-axis. Find the exact volume. **[3]**

**4.** (calculator-free) The region under y = e^(−x), for 0 ≤ x ≤ 1, is rotated about the x-axis. Find the exact volume. **[3]**

**5.** (calculator-free) The region under y = cos x, for 0 ≤ x ≤ π/2, is rotated about the x-axis. Show that the volume is π²/4. **[4]**

**6.** (calculator-free) The region enclosed by y = 1/x (x > 0), the y-axis and the lines y = 1 and y = 4 is rotated about the y-axis. Find the volume. **[4]**

## Section B

**7.** (calculator-free) The region enclosed by y = x³ (x ≥ 0), the y-axis and the line y = 8 is rotated about the y-axis. Find the exact volume. **[4]**

**8.** (calculator-free) The region enclosed between y = √x and y = x is rotated about the x-axis.

**(a)** Find the x-coordinates of the points where the curves meet. **[1]**
**(b)** Find the volume of the solid formed. **[4]**

**9.** (calculator-free) The region enclosed between y = x² and y = 2x, for x ≥ 0, is rotated about the y-axis.

**(a)** Express each curve in the form x = g(y), and state which is further from the y-axis for 0 < y < 4. **[2]**
**(b)** Find the volume of the solid formed. **[4]**

**10.** (calculator-free) The upper half of the ellipse x²/9 + y²/4 = 1 is rotated about the x-axis to form an ellipsoid. Find its volume. **[5]**

**11.** (calculator allowed) Let f(x) = x e^(−x), for 0 ≤ x ≤ 2.

**(a)** Find the area of the region enclosed by the graph of f, the x-axis and the line x = 2. **[2]**
**(b)** The region is rotated about the x-axis. Find the volume of the solid formed. **[3]**

**12.** (calculator-free) The region under y = √(ln x), for 1 ≤ x ≤ e, is rotated about the x-axis. Use integration by parts to find the volume. **[5]**

**13.** (calculator-free) The region under y = 1/x, for 1 ≤ x ≤ k, is rotated about the x-axis. The volume is 3π/4. Find k. **[4]**

## Answers

**1.** ∫₀² y³ dy [1] = **4** [1] **[2]**

**2.** x = e^y − 1 [1]; area = ∫₀^(ln 3) (e^y − 1) dy [1] = [e^y − y]₀^(ln 3) = (3 − ln 3) − 1 [1] = **2 − ln 3** [1] **[4]**
*Examiner insight:* The limits are y-values, 0 and ln 3; using the x-values 0 and 2 with dy is the error to avoid.

**3.** V = π ∫₀¹ (2x + 1)² dx [1] = π[(2x + 1)³/6]₀¹ [1] = π(27 − 1)/6 = **13π/3** [1] **[3]**

**4.** V = π ∫₀¹ e^(−2x) dx [1] = π[−(1/2)e^(−2x)]₀¹ [1] = **(π/2)(1 − e⁻²)** [1] **[3]**

**5.** V = π ∫₀^(π/2) cos²x dx [1]; cos²x = (1 + cos 2x)/2 [1]; π[x/2 + (sin 2x)/4]₀^(π/2) [1] = π(π/4) = π²/4 [1] **[4]**

**6.** x = 1/y, so x² = y⁻² [1]; V = π ∫₁⁴ y⁻² dy [1] = π[−y⁻¹]₁⁴ [1] = π(1 − 1/4) = **3π/4** [1] **[4]**

**7.** x = y^(1/3), so x² = y^(2/3) [1]; V = π ∫₀⁸ y^(2/3) dy [1] = π[(3/5)y^(5/3)]₀⁸ [1] = (3/5)(32)π = **96π/5** [1] **[4]**

**8. (a)** √x = x gives **x = 0 and x = 1** [1]
**(b)** On (0, 1), √x > x, so √x is the outer radius [1]; V = π ∫₀¹ ((√x)² − x²) dx = π ∫₀¹ (x − x²) dx [1] [1] = π(1/2 − 1/3) = **π/6** [1] **[5]**

**9. (a)** x = √y and x = y/2 [1]; for 0 < y < 4, √y > y/2, so x = √y is further from the axis [1]
**(b)** V = π ∫₀⁴ (y − y²/4) dy [1] [1] = π[y²/2 − y³/12]₀⁴ [1] = π(8 − 16/3) = **8π/3** [1] **[6]**

**10.** y² = 4(1 − x²/9) [1]; limits x = −3 to 3 [1]; V = π ∫₋₃³ 4(1 − x²/9) dx [1] = 4π[x − x³/27]₋₃³ [1] = 4π(2 − (−2)) = **16π** [1] **[5]**
*Examiner insight:* Check with the general result (4/3)πab², here (4/3)π(3)(2²) = 16π.

**11. (a)** ∫₀² x e^(−x) dx [1] = **0.594** (0.59399…) [1]
**(b)** V = π ∫₀² x² e^(−2x) dx [1] [1] = **0.598** (0.59839…) [1] **[5]**

**12.** V = π ∫₁^e ln x dx [1]; parts with u = ln x, dv/dx = 1: [x ln x]₁^e − ∫₁^e 1 dx [1] [1]; = (e − 0) − (e − 1) [1]; **V = π** [1] **[5]**

**13.** V = π ∫₁ᵏ x⁻² dx [1] = π[−x⁻¹]₁ᵏ = π(1 − 1/k) [1]; π(1 − 1/k) = 3π/4 [1]; **k = 4** [1] **[4]**
