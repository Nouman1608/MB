This set covers **section 2.13 (AHL only)** of IB DP Mathematics: Analysis and Approaches, first assessment 2021: rational functions of the form (ax + b)/(cx² + dx + e) and (ax² + bx + c)/(dx + e). All questions are calculator-free. The methods are explained in the [rational functions study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-13/) and summarised in the [rational functions revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-13-revision-notes/).

## Section A

**1.** Let f(x) = (x − 5)/(x² − 3x − 10).

**(a)** Simplify f(x). **[1]**
**(b)** Write down the equations of the asymptotes of the graph of f. **[2]**
**(c)** Write down the coordinates of the point missing from the graph. **[1]**

**2.** Let g(x) = (2x + 1)/(x² − 9).

**(a)** Write down the equations of the vertical asymptotes. **[1]**
**(b)** Write down the equation of the horizontal asymptote. **[1]**
**(c)** Find the coordinates of the axis intercepts. **[2]**

**3.** Let h(x) = (x − 4)/(x² + 2x + 2).

**(a)** Show that the graph of h has no vertical asymptote. **[2]**
**(b)** Write down the equation of the horizontal asymptote and the point where the graph crosses it. **[2]**

**4.** Let f(x) = (x² + 4x − 1)/(x + 2), x ≠ −2.

**(a)** Write f(x) in the form x + p + q/(x + 2). **[2]**
**(b)** Write down the equations of the asymptotes. **[2]**

**5.** Find the equation of the oblique asymptote of y = (3x² − x)/(x − 1). **[3]**

**6.** The graph of y = (ax² + bx − 3)/(2x + 1) has oblique asymptote y = x − 2. Find a and b. **[3]**

## Section B

**7.** Let f(x) = (x − 1)/(x² − 4x + 4).

**(a)** Write down the equations of the asymptotes. **[2]**
**(b)** Find the coordinates of the axis intercepts. **[2]**
**(c)** Determine the sign of f(x) for x < 1, 1 < x < 2 and x > 2, and hence describe the graph near x = 2. **[3]**
**(d)** The graph has exactly one turning point, at its y-intercept. Write down the range of f. **[2]**

**8.** Let f(x) = (x + 1)/(x² + 3).

**(a)** Explain why the graph of f has no vertical asymptote. **[1]**
**(b)** By writing y = f(x) as a quadratic equation in x, show that y must satisfy 12y² − 4y − 1 ≤ 0. **[4]**
**(c)** Hence find the range of f. **[2]**
**(d)** Find the coordinates of the maximum point. **[2]**

**9.** Let f(x) = (x² − 2x + 4)/(x − 2), x ≠ 2.

**(a)** Show that f(x) = x + 4/(x − 2). **[2]**
**(b)** Write down the equations of the asymptotes. **[2]**
**(c)** Show that the graph does not meet the x-axis. **[2]**
**(d)** Find the range of f. **[4]**

**10.** The function f(x) = (x + p)/(x² + qx + r) has vertical asymptotes x = −1 and x = 4, and its graph passes through (2, −1).

**(a)** Find q and r. **[2]**
**(b)** Find p. **[2]**
**(c)** Find the coordinates of the axis intercepts. **[2]**

**11.** Let f(x) = (x² + 9)/x, x ≠ 0.

**(a)** Write down the equations of the asymptotes. **[2]**
**(b)** Show that the range of f is y ≤ −6 or y ≥ 6. **[3]**
**(c)** Find the coordinates of the local minimum point. **[2]**

**12.** Let f(x) = 2x/(x² − x − 2).

**(a)** Write down the equations of all the asymptotes. **[2]**
**(b)** Determine the sign of f(x) in each of the intervals x < −1, −1 < x < 0, 0 < x < 2 and x > 2. **[3]**
**(c)** Describe the behaviour of the graph as x approaches −1 from the left and from the right. **[2]**

## Answers

**1. (a)** x² − 3x − 10 = (x − 5)(x + 2), so f(x) = 1/(x + 2), x ≠ 5 [1]
**(b)** x = −2 [1]; y = 0 [1]
**(c)** (5, 1/7) [1]
*Examiner insight:* x = 5 is not an asymptote, because the factor cancels.

**2. (a)** x = −3 and x = 3 [1]
**(b)** y = 0 [1]
**(c)** (−1/2, 0) [1]; (0, −1/9) [1]

**3. (a)** Δ = 2² − 4(1)(2) = −4 [1] < 0, so the denominator is never zero [1]
**(b)** y = 0 [1]; it crosses at (4, 0) [1]

**4. (a)** x² + 4x − 1 = (x + 2)² − 5 [1], so f(x) = x + 2 − 5/(x + 2) [1]
**(b)** x = −2 [1]; y = x + 2 [1]

**5.** 3x² − x = (x − 1)(3x + 2) + 2 [2], so y = 3x + 2 [1]

**6.** (2x + 1)(x − 2) = 2x² − 3x − 2 [1], so the numerator is 2x² − 3x − 2 + R [1], giving a = 2 and b = −3 [1]
*Examiner insight:* The constant term then fixes R = −1, but R does not affect the asymptote.

**7. (a)** x = 2 [1]; y = 0 [1]
**(b)** (1, 0) [1]; (0, −1/4) [1]
**(c)** (x − 2)² > 0, so the sign is that of x − 1: negative for x < 1, positive for 1 < x < 2 and x > 2 [2]. So y → +∞ on both sides of x = 2 [1]
**(d)** f(x) ≥ −1/4 [2]
*Examiner insight:* The minimum (0, −1/4) is the lowest point because f → 0 from below as x → −∞ and f > 0 for x > 1.

**8. (a)** x² + 3 > 0 for all x, so the denominator is never zero [1]
**(b)** y(x² + 3) = x + 1 [1], so yx² − x + (3y − 1) = 0 [1]. Real x requires Δ = 1 − 4y(3y − 1) ≥ 0 [1], so 1 − 12y² + 4y ≥ 0, that is 12y² − 4y − 1 ≤ 0 [1]
**(c)** (6y + 1)(2y − 1) ≤ 0 [1], so −1/6 ≤ y ≤ 1/2 [1]
**(d)** When Δ = 0, x = 1/(2y) = 1 [1], so the maximum is (1, 1/2) [1]

**9. (a)** x(x − 2) = x² − 2x [1], so x² − 2x + 4 = x(x − 2) + 4 and f(x) = x + 4/(x − 2) [1]
**(b)** x = 2 [1]; y = x [1]
**(c)** x² − 2x + 4 = 0 has Δ = 4 − 16 = −12 [1] < 0, so there are no x-intercepts [1]
**(d)** y(x − 2) = x² − 2x + 4 gives x² − (2 + y)x + (4 + 2y) = 0 [1]. Δ = (2 + y)² − 4(4 + 2y) = y² − 4y − 12 [1]. Need (y − 6)(y + 2) ≥ 0 [1], so y ≤ −2 or y ≥ 6 [1]
*Examiner insight:* A range such as −2 ≤ y ≤ 6 reverses the answer. The two branches leave a gap between the local maximum and the local minimum.

**10. (a)** Denominator (x + 1)(x − 4) = x² − 3x − 4 [1], so q = −3 and r = −4 [1]
**(b)** f(2) = (2 + p)/(4 − 6 − 4) = −1 [1], so 2 + p = 6 and p = 4 [1]
**(c)** (−4, 0) [1]; (0, 4/(−4)) = (0, −1) [1]

**11. (a)** x = 0 [1]; f(x) = x + 9/x, so y = x [1]
**(b)** yx = x² + 9, so x² − yx + 9 = 0 [1]. Δ = y² − 36 ≥ 0 [1], so y ≤ −6 or y ≥ 6 [1]
**(c)** At y = 6 the repeated root is x = y/2 = 3 [1], so the local minimum is (3, 6) [1]

**12. (a)** x = −1 and x = 2 [1]; y = 0 [1]
**(b)** x < −1: negative; −1 < x < 0: positive [1]; 0 < x < 2: negative [1]; x > 2: positive [1]
**(c)** From the left, f(x) → −∞ [1]; from the right, f(x) → +∞ [1]

## Where marks are usually lost

- Treating a cancelled factor as a vertical asymptote.
- Missing the oblique asymptote, or writing y = 0 for a quadratic-over-linear function.
- Reversing the inequality when solving Δ ≥ 0 for the range.
- Giving intercepts as single numbers instead of coordinates.
- Sign tables that ignore a squared factor, which never changes sign.
