These notes condense **4.2.2.2 State symbols** of the AQA GCSE Chemistry (8462) specification (for teaching from
September 2016, version 1.2). It is Paper 1 content for both tiers, with no Higher-only statements and no
required practical. For full explanations, see the
[state symbols study guide](/resources/aqa-gcse-chemistry-8462-state-symbols/); then practise with the
[state symbols practice questions](/resources/aqa-gcse-chemistry-8462-state-symbols-practice/).

## Core facts

- The three states of matter are shown as **(s)**, **(l)** and **(g)**.
- **(aq)** is used for **aqueous solutions**: substances dissolved in water.
- The symbol is written in brackets straight after the formula.
- You must be able to **include state symbols** in the equations for the reactions in the specification.
- State symbols **do not affect balancing**. Balance first, add symbols last.

## The four symbols

| Symbol | Meaning | Examples |
|---|---|---|
| (s) | solid | Mg(s), CaCO₃(s), Cu(s), a precipitate |
| (l) | liquid | H₂O(l), Br₂(l), molten NaCl(l) |
| (g) | gas | H₂(g), O₂(g), CO₂(g), Cl₂(g) |
| (aq) | dissolved in water | HCl(aq), NaOH(aq), CuSO₄(aq) |

## Choosing the symbol

| Clue in the question | Symbol |
|---|---|
| "ribbon", "powder", "lumps", "crystals", "precipitate", "excess solid" | (s) |
| "pure water", "liquid", "molten" | (l) |
| "bubbles", "gas given off", "burns in air", "steam" | (g) |
| "dilute acid", "solution", "aqueous", "alkali" | (aq) |

## Reference set of equations

| Reaction | Equation with state symbols |
|---|---|
| Metal and acid | Mg(s) + 2HCl(aq) → MgCl₂(aq) + H₂(g) |
| Zinc and sulfuric acid | Zn(s) + H₂SO₄(aq) → ZnSO₄(aq) + H₂(g) |
| Carbonate and acid | CaCO₃(s) + 2HCl(aq) → CaCl₂(aq) + H₂O(l) + CO₂(g) |
| Metal oxide and acid | CuO(s) + H₂SO₄(aq) → CuSO₄(aq) + H₂O(l) |
| Neutralisation | NaOH(aq) + HCl(aq) → NaCl(aq) + H₂O(l) |
| Group 1 metal and water | 2Na(s) + 2H₂O(l) → 2NaOH(aq) + H₂(g) |
| Metal and oxygen | 2Mg(s) + O₂(g) → 2MgO(s) |
| Precipitation | Pb(NO₃)₂(aq) + 2KI(aq) → PbI₂(s) + 2KNO₃(aq) |
| Electrolysis of molten salt | 2NaCl(l) → 2Na(l) + Cl₂(g) |

## Using symbols to read an equation

- A **(g)** product can escape from an open container, so the mass of solid left may fall. Thermal decomposition
  of a carbonate is an example: CaCO₃(s) → CaO(s) + CO₂(g).
- A **(s)** product formed from two solutions is a precipitate. It can be separated by filtering.
- An **(aq)** product is dissolved. To obtain the solid salt you must remove some of the water, for example by
  evaporating, then crystallising.
- A **(l)** product that is water formed in the reaction is not a solution.

## More worked equations

| Description | With state symbols |
|---|---|
| Iron nail in copper(II) sulfate solution | Fe(s) + CuSO₄(aq) → FeSO₄(aq) + Cu(s) |
| Copper(II) oxide heated with carbon | 2CuO(s) + C(s) → 2Cu(s) + CO₂(g) |
| Sulfuric acid and sodium hydroxide solutions | H₂SO₄(aq) + 2NaOH(aq) → Na₂SO₄(aq) + 2H₂O(l) |
| Haber process | N₂(g) + 3H₂(g) ⇌ 2NH₃(g) |
| Melting and boiling of water | H₂O(s) → H₂O(l) → H₂O(g) |

A change of state keeps the same formula. It is a physical change, not a chemical reaction.

## Key terms

| Term | Meaning |
|---|---|
| Aqueous | Dissolved in water |
| Solute | The substance that dissolves |
| Solvent | The liquid it dissolves in, here water |
| Precipitate | An insoluble solid formed in a solution |
| Molten | A solid that has melted to a liquid |

## Pure water versus a solution

- **Water by itself is H₂O(l).** It is a liquid, not a solution.
- **Steam is H₂O(g).**
- **(aq) always means something is dissolved in water.** The water is the solvent, not the solute.

## Step-by-step method for adding symbols

1. Check that the equation is already balanced. Do not change it.
2. Read the description for the state of each reactant.
3. Decide each product: gas that bubbles off (g), solid that settles out (s), salt that remains in solution
   (aq), water formed in the reaction (l).
4. Write the symbol straight after each formula, after the balancing number.
5. Count the formulae and the symbols to check none is missing.

## Exam traps

- **H₂O(aq).** Pure water is (l).
- **(aq) used for any liquid.** Molten compounds and liquid elements are (l).
- **Symbol placed before the formula.** Write H₂(g), not (g)H₂.
- **Missing symbols.** If the question asks for state symbols, every substance needs one.
- **Dissolved product marked (s).** A salt that stays in solution is (aq).
- **Changing the balancing numbers** to fit the symbols. They are independent.

## Quick self-test

1. What does (aq) stand for?
2. Which state symbol is used for steam?
3. Give the state symbol for pure water.
4. Give the state symbol for a precipitate.
5. Add state symbols to: 2Mg + O₂ → 2MgO (magnesium ribbon burning in oxygen).
6. Add state symbols to: Zn + H₂SO₄ → ZnSO₄ + H₂ (zinc granules added to dilute sulfuric acid, bubbles seen).
7. Add state symbols to: NaOH + HCl → NaCl + H₂O (both reactants are solutions, and the product is a solution).
8. Why is molten sodium chloride written NaCl(l) and not NaCl(aq)?
9. Do state symbols change the balancing numbers in an equation?
10. In 2Na(s) + 2H₂O(l) → 2NaOH(aq) + H₂(g), why is the sodium hydroxide (aq)?
11. Add state symbols to: CaCO₃ → CaO + CO₂ (calcium carbonate lumps heated strongly).
12. How does the symbol (g) on a product explain why a solid can lose mass during a reaction?

### Answers

1. Aqueous: dissolved in water.
2. (g).
3. (l).
4. (s).
5. 2Mg(s) + O₂(g) → 2MgO(s).
6. Zn(s) + H₂SO₄(aq) → ZnSO₄(aq) + H₂(g).
7. NaOH(aq) + HCl(aq) → NaCl(aq) + H₂O(l).
8. Molten means melted without water. It is a liquid, not a solution in water.
9. No. State symbols are added after balancing and do not change the numbers of atoms.
10. It dissolves in the water that is left, so it is a solution.
11. CaCO₃(s) → CaO(s) + CO₂(g).
12. The gas can escape into the air, so its mass is no longer counted with the solid left behind.
