This guide covers section 2.1, Use of symbols, in topic 2 (Equations, formulae and identities) of the Pearson Edexcel International GCSE Mathematics A (4MA1) specification, Issue 2. It is the language the rest of the algebra in the course is written in: what a letter stands for, why algebra obeys the same rules as arithmetic, and how powers are written and combined.

## What the specification says

| Statement | Students should be taught to | Tier |
|---|---|---|
| Foundation 2.1 A | understand that symbols may be used to represent numbers in equations or variables in expressions and formulae | Both |
| Foundation 2.1 B | understand that algebraic expressions follow the generalised rules of arithmetic | Both |
| Foundation 2.1 C | use index notation for positive and negative integer powers (including zero) | Both |
| Foundation 2.1 D | use index laws in simple cases | Both |
| Higher 2.1 A | use index notation involving fractional, negative and zero powers | Higher only |

The Higher Tier assumes all the Foundation content, so Higher students need every row. Fractional powers are the only Higher-only part.

## Letters as numbers: unknowns and variables

A letter always stands for a number, but in two different ways.

- In an **equation** such as 3x + 4 = 19, the letter is an **unknown**: there is one value (here x = 5) that makes the statement true.
- In a **formula** such as P = 4s, or an **expression** such as 2n + 1, the letters are **variables**: they can take many values, and the formula or expression tells you how the quantities are linked.

Two more words complete the vocabulary:

| Word | Has an equals sign? | Example | What you can do with it |
|---|---|---|---|
| Expression | No | 5a − 2b | Simplify it, or evaluate it for given values |
| Equation | Yes | 5a − 2 = 13 | Solve it |
| Formula | Yes, linking quantities | A = lw | Substitute into it, or rearrange it |
| Identity | Yes, true for every value | 2(x + 3) = 2x + 6 | Use it to rewrite an expression |

An identity is sometimes written with the symbol ≡. Exam questions often ask you to say which of these words describes a given line, so learn the table.

## Algebra follows the rules of arithmetic

Statement 2.1 B says algebraic expressions follow the "generalised rules of arithmetic". Every rule you use with numbers still holds when the numbers are replaced by letters.

```
Order does not matter for + and ×:    a + b = b + a        ab = ba
It does matter for − and ÷:           a − b ≠ b − a        a ÷ b ≠ b ÷ a
Brackets multiply out:                a(b + c) = ab + ac
Order of operations still applies:    2x² means 2 × x², not (2x)²
```

Notation follows from these rules: 3 × a is written 3a, a × a is a², and a ÷ b is usually written as the fraction a/b.

**Worked example 1.** Find the value of each expression when x = −3.

```
(a) 2x²   = 2 × (−3)²  = 2 × 9  = 18
(b) (2x)² = (−6)²      = 36
(c) −x²   = −(9)       = −9
(d) (−x)² = (3)²       = 9
```

The order of operations decides each answer. In (a) only x is squared; in (b) the bracket is worked out first; in (c) the square is applied before the minus sign.

## Index notation (both tiers)

A power, or index, counts repeated multiplication: a × a × a = a³. Do not confuse it with a coefficient: 3a means a + a + a, while a³ means a × a × a.

The specification includes zero and negative integer powers. Both follow from continuing a pattern of division:

```
2³ = 8,  2² = 4,  2¹ = 2,  2⁰ = 1,  2⁻¹ = 1/2,  2⁻² = 1/4
```

Each step down divides by 2, so:

- a⁰ = 1 for any non-zero a
- a⁻ⁿ = 1/aⁿ, the reciprocal of aⁿ

So 5⁻² = 1/25 (not −25), 10⁻³ = 0.001, and (2/3)⁻¹ = 3/2.

## Index laws in simple cases (both tiers)

```
xᵐ × xⁿ = xᵐ⁺ⁿ        add the powers
xᵐ ÷ xⁿ = xᵐ⁻ⁿ        subtract the powers
(xᵐ)ⁿ  = xᵐⁿ         multiply the powers
```

The laws only combine powers of the **same base**. Numbers in front (coefficients) are multiplied or divided as ordinary numbers.

**Worked example 2.** Simplify (a) 4a³ × 3a⁻⁵ (b) 20y⁴ ÷ 5y⁻² (c) (3x²)³ (d) 6p⁵q² ÷ 2p⁵q.

```
(a) 4 × 3 = 12;   a³ × a⁻⁵ = a⁻²              12a⁻²  (or 12/a²)
(b) 20 ÷ 5 = 4;   y⁴ ÷ y⁻² = y⁴⁻⁽⁻²⁾ = y⁶      4y⁶
(c) 3³ = 27;      (x²)³ = x⁶                  27x⁶
(d) 6 ÷ 2 = 3;    p⁵ ÷ p⁵ = p⁰ = 1;  q² ÷ q = q    3q
```

In (c), the power outside the bracket applies to the 3 as well as to x². In (d), p⁰ = 1, so p disappears from the answer.

**Worked example 3 (finding a missing power).** Find n when 7ⁿ × 7³ = 7¹⁰.

Add the powers: n + 3 = 10, so **n = 4**. The same idea works for division: if 5⁸ ÷ 5ⁿ = 5², then 8 − n = 2, so n = 6.

## Fractional powers (Higher tier only)

A fractional power is a root:

```
a^(1/n) = the nth root of a          e.g. 1000^(1/3) = 10
a^(m/n) = (nth root of a)^m          e.g. 16^(3/4) = 2³ = 8
```

Take the root first: the numbers stay small. A negative sign in the power still means "reciprocal".

**Worked example 4 (Higher).** Work out (a) 64^(−2/3) (b) (25/4)^(−1/2) (c) 0.01^(3/2).

```
(a) cube root of 64 = 4;  4² = 16;  reciprocal → 1/16
(b) reciprocal first: (4/25)^(1/2) = 2/5
(c) square root of 0.01 = 0.1;  0.1³ = 0.001
```

**Worked example 5 (Higher, unknown power).** Find x when (a) 8ˣ = 1/4 (b) 27ˣ = 9.

Write both sides as powers of the same base.

```
(a) 8 = 2³ and 1/4 = 2⁻²,  so 2^(3x) = 2⁻²,  3x = −2,  x = −2/3
(b) 27 = 3³ and 9 = 3²,    so 3^(3x) = 3²,   3x = 2,   x = 2/3
```

**Worked example 6 (Higher, algebra).** Write √x / x² as a single power of x.

√x = x^(1/2), so √x ÷ x² = x^(1/2 − 2) = **x^(−3/2)**.

## Common mistakes

- Multiplying the powers when multiplying terms: x³ × x⁴ = x⁷, not x¹².
- Applying an index law to different bases: 2³ × 3² cannot be written as a single power.
- Adding powers in a sum: x³ + x² cannot be simplified.
- Forgetting the coefficient inside a bracket: (3x²)³ = 27x⁶, not 3x⁶.
- Writing 2⁰ = 0 or 5⁻² = −25.
- Treating −x² as (−x)² when substituting a negative number.
- For fractional powers, working out the power before the root, which makes numbers huge and error-prone.

## Exam technique

- **"Simplify"**: give a single term where possible. A negative power such as 12a⁻² is acceptable unless the question asks for positive powers.
- **"Write down the value of"**: one mark, no working expected; the answer is usually an exact fraction or integer.
- **"Find the value of n"**: write the equation in the powers (n + 3 = 10) so a method mark is visible.
- **"Work out" with fractional powers** on a calculator paper: you may check with the calculator, but give the exact answer (1/16, not 0.0625, if the question asks for a fraction).
- When substituting a negative number, write it in brackets on your first line of working.
