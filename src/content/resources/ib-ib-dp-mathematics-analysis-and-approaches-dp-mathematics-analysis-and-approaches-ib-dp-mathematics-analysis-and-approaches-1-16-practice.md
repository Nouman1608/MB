This practice set covers section 1.16 of IB Diploma Programme Mathematics: Analysis and Approaches: systems of up to three linear equations in three unknowns, with a unique solution, infinitely many solutions or no solution. Every question is HL only. Questions are labelled "(calculator-free)" or "(calculator allowed)" to match HL Paper 1 and Papers 2 and 3. Give calculator answers exactly or to 3 significant figures.

Learn the methods first in the [1.16 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-16/) and the [1.16 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-16-revision-notes/).

## Section A

**1.** (calculator-free) Solve the simultaneous equations 4x + 3y = 5 and 6x − 5y = 17. **[3]**

**2.** (calculator allowed) Use technology to solve
2x + 3y − z = 1,
x − y + 4z = 7,
3x + y + 2z = 4.5. **[2]**

**3.** (calculator-free) Explain why the system
x + y + z = 2,
2x + 2y + 2z = 5,
x − y + z = 0
has no solution. **[2]**

**4.** (calculator-free) Consider the system
x − y + 2z = 1,
2x + y + z = 5,
4x − y + 5z = 7.

**(a)** Show that x = 2 − λ, y = 1 + λ, z = λ satisfies all three equations for every real λ. **[3]**
**(b)** Find the solution for which x = y. **[2]**

**5.** (calculator-free) After row operations, a system becomes
x + 2y − z = 4,
y + 3z = 7,
(k − 1)z = k + 1.

**(a)** State the values of k for which the system has a unique solution. **[1]**
**(b)** Show that there is no value of k for which the system has infinitely many solutions. **[2]**
**(c)** Solve the system when k = 3. **[2]**

**6.** (calculator-free) The curve y = ax² + bx + c passes through the points (1, 2), (−1, 6) and (2, 3). Find a, b and c. **[4]**

## Section B

**7.** (calculator-free) Solve
x + 2y + 4z = 1,
3x + y − 2z = 6,
2x − 3y + 6z = 15. **[5]**

**8.** (calculator-free) Consider the system
x + y − z = 2,
2x + 3y + z = 9,
3x + 5y + 3z = 16.

**(a)** Show that the system has infinitely many solutions. **[3]**
**(b)** Find the general solution. **[3]**
**(c)** Find the solution for which x + y + z = 4. **[2]**

**9.** (calculator-free) Consider the system
x + 2y + z = 1,
2x + 5y + 3z = 4,
x + 3y + az = b,
where a, b ∈ ℝ.

**(a)** Find the value of a for which the system does not have a unique solution. **[3]**
**(b)** For this value of a, find the value of b for which the system has infinitely many solutions. **[1]**
**(c)** For these values of a and b, find the general solution. **[3]**
**(d)** Solve the system when a = 4 and b = 7. **[2]**

**10.** (calculator allowed) In this invented context, a café records three orders. Two coffees, one tea and three muffins cost $16.00. One coffee, two teas and one muffin cost $10.30. Three coffees and two muffins cost $13.90. Let c, t and m be the prices in dollars of a coffee, a tea and a muffin.

**(a)** Write down a system of three equations in c, t and m. **[2]**
**(b)** Use technology to find c, t and m. **[2]**
**(c)** Find the cost of four coffees and three teas. **[1]**

**11.** (calculator-free) Consider the system
x + 2y − z = 0,
2x + y + z = 0,
x − y + kz = 0.

**(a)** Explain why the system is consistent for every value of k. **[1]**
**(b)** Find the value of k for which the system has infinitely many solutions. **[3]**
**(c)** For this value of k, find the general solution. **[2]**

**12.** (calculator-free) A system of three linear equations in x, y and z has the two solutions (1, 2, 3) and (3, 1, 4).

**(a)** By considering a general equation px + qy + rz = d satisfied by both points, show that (1 + 2t, 2 − t, 3 + t) is a solution of the system for every real t. **[3]**
**(b)** State the number of solutions of the system. **[1]**

## Answers

**1.** Multiply the first by 5 and the second by 3: 20x + 15y = 25 and 18x − 15y = 51 [1]. Add: 38x = 76, so **x = 2** [1]. Then 8 + 3y = 5, so **y = −1** [1]
*Examiner insight:* Check in the second equation: 12 + 5 = 17.

**2.** System entered in a GDC solver [1]: **x = −0.393, y = 1.32, z = 2.18** (exactly −11/28, 37/28, 61/28) [1]
*Examiner insight:* Writing the system you entered protects the method mark if a value is mistyped.

**3.** The left-hand side of the second equation is twice that of the first, so it should equal 2 × 2 = 4 [1]. It equals 5; (2) − 2(1) gives 0 = 1, a contradiction, so the system is inconsistent and has no solution [1]

**4. (a)** First: (2 − λ) − (1 + λ) + 2λ = 1 [1]. Second: 2(2 − λ) + (1 + λ) + λ = 5 [1]. Third: 4(2 − λ) − (1 + λ) + 5λ = 7 [1]
**(b)** 2 − λ = 1 + λ gives λ = 1/2 [1], so **x = 3/2, y = 3/2, z = 1/2** [1]

**5. (a)** **k ≠ 1** [1]
**(b)** Infinitely many solutions needs k − 1 = 0 and k + 1 = 0 [1]. k = 1 gives 0 = 2, so there is no solution; no single k satisfies both conditions [1]
**(c)** 2z = 4, so z = 2; y = 7 − 6 = 1 [1]; x = 4 − 2 + 2 = 4: **(4, 1, 2)** [1]

**6.** a + b + c = 2, a − b + c = 6, 4a + 2b + c = 3 [1]. Subtracting the first two: 2b = −4, so **b = −2** [1]. Then a + c = 4 and 4a + c = 7, so 3a = 3 [1], giving **a = 1, c = 3** [1]
*Examiner insight:* Check with (2, 3): 4 − 4 + 3 = 3.

**7.** (2) − 3(1): −5y − 14z = 3 [1]. (3) − 2(1): −7y − 2z = 13 [1]. Seven times the first minus five times the second: −98z + 10z = 21 − 65, so −88z = −44 [1] and **z = 1/2** [1]. Then −5y − 7 = 3 gives **y = −2**, and x − 4 + 2 = 1 gives **x = 3** [1]

**8. (a)** (2) − 2(1): y + 3z = 5 [1]. (3) − 3(1): 2y + 6z = 10 [1]. The second is twice the first, so eliminating y gives 0 = 0: consistent with infinitely many solutions [1]
**(b)** Let z = λ, λ ∈ ℝ [1]. y = 5 − 3λ [1]; x = 2 − y + z = **−3 + 4λ**, so the general solution is x = −3 + 4λ, y = 5 − 3λ, z = λ [1]
**(c)** (−3 + 4λ) + (5 − 3λ) + λ = 2 + 2λ = 4 [1], so λ = 1 and the solution is **(1, 2, 1)** [1]
*Examiner insight:* A general solution with no stated parameter, or with numbers only, earns no marks in (b).

**9. (a)** (2) − 2(1): y + z = 2 [1]. (3) − (1): y + (a − 1)z = b − 1. Subtracting: (a − 2)z = b − 3 [1]. No unique solution when **a = 2** [1]
**(b)** Infinitely many solutions when b − 3 = 0, so **b = 3** [1]
**(c)** Let z = λ [1]. y = 2 − λ [1]; x = 1 − 2(2 − λ) − λ = −3 + λ, so the general solution is **x = −3 + λ, y = 2 − λ, z = λ, λ ∈ ℝ** [1]
**(d)** 2z = 4, so z = 2 and y = 0 [1]; x = 1 − 0 − 2 = −1: **(−1, 0, 2)** [1]

**10. (a)** 2c + t + 3m = 16.00 and c + 2t + m = 10.30 [1]; 3c + 2m = 13.90 [1]
**(b)** Using a GDC solver [1]: **c = 2.90, t = 2.40, m = 2.60** [1]
**(c)** 4(2.90) + 3(2.40) = **$18.80** [1]
*Examiner insight:* Missing the zero coefficient of t in the third equation is the commonest entry error.

**11. (a)** x = y = z = 0 satisfies all three equations, so at least one solution exists [1]
**(b)** (2) − 2(1): −3y + 3z = 0, so y = z [1]. (3) − (1): −3y + (k + 1)z = 0, and with y = z this gives (k − 2)z = 0 [1]. Infinitely many solutions when **k = 2** [1]
**(c)** Let z = λ; then y = λ [1] and x = −2y + z = −λ: **x = −λ, y = λ, z = λ, λ ∈ ℝ** [1]

**12. (a)** p + 2q + 3r = d and 3p + q + 4r = d, so subtracting gives 2p − q + r = 0 [1]. Then p(1 + 2t) + q(2 − t) + r(3 + t) = (p + 2q + 3r) + t(2p − q + r) [1] = d + 0 = d, for every t, so the point lies on every equation of the system [1]
**(b)** **Infinitely many** solutions [1]

## Where marks are usually lost

- Sign slips on the right-hand side during row operations, as in question 7.
- Calling 0 = 0 inconsistent; it signals infinitely many solutions.
- General solutions with no parameter or no "λ ∈ ℝ".
- Dividing by a − 2 or k − 1 before treating that value separately.
- Leaving out a zero coefficient when entering a system into a GDC.
