## Section A

**1.** State what is meant by a biometric measure and give two examples used on mobile devices. **[3]**

**2.** State what the letters CAPTCHA stand for, or describe the purpose of a CAPTCHA test in your own words. **[1]**

**3.** State two rules that a website might set to make users' passwords stronger. **[2]**

**4.** State what an automatic software update does. **[1]**

## Section B

**5.** A phone uses fingerprint recognition.

**(a)** Describe how the phone uses the fingerprint to decide whether to unlock. **[2]**

**(b)** Give two advantages of fingerprint recognition compared with a four digit PIN. **[2]**

**(c)** Give two disadvantages of fingerprint recognition. **[2]**

**6.** A website lets people create accounts. Hundreds of fake accounts have been created in one hour by a program.

**(a)** Name a measure that the website could add to stop this. **[1]**

**(b)** Explain how the measure works. **[2]**

**(c)** Give one disadvantage of the measure for genuine users. **[1]**

**7.** A bank's login page is being attacked by a program that tries thousands of passwords in a short time. Describe
two measures that would help to prevent this. **[4]**

**8.** A user forgets their password to an online shop. The shop sends an email to the address that the user registered.

**(a)** Describe what the email contains. **[1]**

**(b)** Explain how this process helps to make sure that the person resetting the password is the genuine user. **[2]**

**(c)** Explain how this process could still be used by an attacker. **[2]**

**9.** An operating system has a weakness that attackers are using to install malware. The maker has released an update
that fixes it.

**(a)** Explain why it is better for the update to be installed automatically. **[2]**

**(b)** Give one disadvantage of automatic updates. **[1]**

**10.** A student says that a strong password is enough to keep an account secure. Explain why additional measures
could still be needed. **[3]**

**11.** A school wants to protect the accounts of its staff. Evaluate two measures from the list of biometrics, password
systems and email confirmation. **[6]**

**12.** Complete the table by naming the measure that best prevents each threat.

| Threat | Measure |
|---|---|
| A thief steals a locked phone | |
| A bot posts thousands of spam comments | |
| A known weakness in a web browser | |
| A fake account registered with someone else's email address | |

**[4]**

## Answers

**1.** A biometric measure identifies a person by a physical (or behavioural) characteristic that is unique to them [1];
examples: fingerprint, face (facial recognition), iris, voice [1 each, up to 2].

**2.** CAPTCHA stands for Completely Automated Public Turing test to tell Computers and Humans Apart, or: a test that
is easy for a person but difficult for a program, used to distinguish humans from bots [1].

**3.** Any two from: a minimum length [1]; a mixture of upper and lower case letters, numbers and symbols [1]; no
common words or personal information [1]; locking the account after several wrong attempts [1].

**4.** It downloads and installs patches and new versions without the user having to do anything [1].

**5.** **(a)** The phone scans the user's finger [1] and compares it with the stored fingerprint data; it unlocks only if
they match [1].
**(b)** Any two from: nothing to remember [1]; quick and convenient [1]; hard to share or guess, unlike a PIN that can
be watched [1].
**(c)** Any two from: the sensor may reject a genuine user, for example with wet fingers [1]; it may be copied or fooled
in rare cases [1]; a fingerprint cannot be changed if the data is stolen [1]; there are privacy concerns [1]; the
sensor adds to the cost [1].

**6.** **(a)** CAPTCHA [1]. **(b)** The website shows a test that is easy for a person but hard for a program, such as
reading distorted text or choosing pictures [1]; the account is created only if the test is passed, so the program is
unable to create accounts [1]. **(c)** It can be annoying or slow, or difficult for people with poor eyesight [1].

**7.** Any two measures, each with a description: limit the number of login attempts, so that the account is locked
after a few wrong tries [1 for the measure, 1 for the explanation that the program cannot try thousands of passwords];
use a CAPTCHA on the login page, so that a program cannot submit the form [1, 1]; require strong passwords, so that
guessing is much harder [1, 1].

**8.** **(a)** A link (or code) that lets the user create a new password [1].
**(b)** The email is sent only to the registered address [1]; only a person who has access to that mailbox can use the
link, so a stranger cannot reset the password [1].
**(c)** If the attacker has already taken over the user's email account [1], they can use the link to reset the
password on the shop account [1].

**9.** **(a)** The update fixes the weakness that the attackers are using [1]; with automatic updates the fix is applied
quickly without the user having to remember, so the time during which the device is open to attack is shorter [1].
**(b)** For example: it uses bandwidth or storage; it may restart the device at an inconvenient time; an update may
occasionally cause a new fault [1].

**10.** The password may be obtained by phishing or by watching the user type [1]; it may be guessed or reused from another
account that has been breached [1]; other measures, such as email confirmation or biometrics, add a second check, and
software updates close vulnerabilities that a password cannot protect against [1].

**11.** Up to 3 marks for each measure: a description of how it works [1], an advantage [1] and a disadvantage [1].
Biometrics: a fingerprint or face scan is compared with stored data; quick and nothing to remember; may reject a genuine
user and cannot be changed if stolen. Password systems: a secret password that must meet rules for strength; cheap and
familiar; can be forgotten, reused or phished. Email confirmation: a link or code is sent to the registered address;
cheap and confirms the user has access to that mailbox; relies on the security of the email account and may be delayed
(any two measures, with a valid description, advantage and disadvantage each, for 6 marks).

**12.**

| Threat | Measure |
|---|---|
| A thief steals a locked phone | Biometrics (or a password) |
| A bot posts thousands of spam comments | CAPTCHA |
| A known weakness in a web browser | Automatic software updates |
| A fake account registered with someone else's email address | Email confirmation |

One mark for each correct row [4].

---

## Where marks are usually lost

- Naming a measure without saying how it works.
- Saying that CAPTCHA identifies a user rather than telling humans from programs.
- Giving only advantages in an evaluation question such as Question 11.
- Writing that biometrics cannot be wrong or cannot be changed.
- Forgetting that email confirmation depends on the security of the email account.
