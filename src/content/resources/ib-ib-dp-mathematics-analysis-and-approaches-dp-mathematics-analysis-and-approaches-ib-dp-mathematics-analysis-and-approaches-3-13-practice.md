These questions cover syllabus section 3.13 of IB DP Mathematics: Analysis and Approaches (first assessment 2021), which is HL only: the scalar product, the angle between two vectors, and perpendicular and parallel vectors. Questions are labelled "(calculator-free)" or "(calculator allowed)"; give calculator answers to 3 significant figures. Vectors are written in rows. The methods are in the [3.13 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-13/) and the [3.13 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-13-revision-notes/).

## Section A

**1.** (calculator-free)

**(a)** Find (2, −3, 1) · (4, 1, −5). **[1]**

**(b)** State what your answer shows about the two vectors. **[1]**

**2.** (calculator-free) Find the values of k for which (k, 3, −2) is perpendicular to (k, −1, 1). **[3]**

**3.** (calculator allowed) Find the angle between (1, −2, 2) and (4, 0, −3), in degrees. **[3]**

**4.** (calculator-free) Vectors a and b satisfy |a| = 2, |b| = 5, and the angle between them is 2π/3.

**(a)** Find a · b. **[2]**

**(b)** Find |a + b|. **[2]**

**5.** (calculator-free) Show that (a + b) · (a − b) = |a|² − |b|² for any vectors a and b. **[2]**

**6.** (calculator-free) Let v = (3, 6, −9) and w = (−1, −2, 3). Verify that |v · w| = |v||w|, and state what this shows. **[2]**

## Section B

**7.** (calculator allowed) The points P(2, 1, 0), Q(4, 3, 1) and R(1, 5, 2) form a triangle.

**(a)** Find QP and QR. **[2]**

**(b)** Find angle PQR. **[3]**

**(c)** Find the area of triangle PQR. **[2]**

**8.** (calculator-free) Let a = (1, 2, −1), b = (2, −1, 1) and c = (λ, 1, μ). Find λ and μ given that c is perpendicular to both a and b. **[4]**

**9.** (calculator-free) OABC is a rhombus, with OA = a and OC = c, so that |a| = |c|. Prove that the diagonals OB and AC are perpendicular. **[4]**

**10.** (calculator-free) Find the angles between v = (1, 1, √2) and each of the x-, y- and z-axes. **[3]**

**11.** (calculator-free) A(1, 2, 3), B(3, 2, 1) and C(t, 0, 2). Given that angle ABC is a right angle, find t. **[3]**

**12.** (calculator-free) Vectors u and v satisfy |u| = 3, |v| = 2 and |u + v| = √7.

**(a)** Find u · v. **[2]**

**(b)** Find the angle between u and v. **[2]**

## Answers

**1. (a)** 8 − 3 − 5 = **0** [1]

**(b)** The vectors are **perpendicular** [1]

**2.** k² − 3 − 2 = 0 [1], so k² = 5 [1] and **k = ±√5** [1]

**3.** Scalar product 4 + 0 − 6 = −2 [1]; magnitudes 3 and 5, so cos θ = −2/15 [1]; **θ = 97.7°** [1]

*Examiner insight:* The negative scalar product means the angle must be obtuse; 82.3° is the result of dropping the minus sign.

**4. (a)** a · b = 2 × 5 × cos(2π/3) [1] = **−5** [1]

**(b)** |a + b|² = 4 + 2(−5) + 25 = 19 [1], so **|a + b| = √19** [1]

**5.** (a + b) · (a − b) = a · a − a · b + b · a − b · b [1]. Since a · b = b · a, the middle terms cancel, leaving **|a|² − |b|²** [1]

**6.** v · w = −3 − 12 − 27 = −42, so |v · w| = 42 [1]. |v| = √126 = 3√14 and |w| = √14, so |v||w| = 42. The vectors are **parallel** (angle π, since v · w < 0) [1]

**7. (a)** **QP = (−2, −2, −1)** [1] and **QR = (−3, 2, 1)** [1]

**(b)** QP · QR = 6 − 4 − 1 = 1 [1]. |QP| = 3 and |QR| = √14 [1]. cos PQR = 1/(3√14), so **PQR = 84.9°** [1]

**(c)** Area = ½ × 3 × √14 × sin 84.89° [1] = **5.59** square units [1]

*Examiner insight:* Keep the unrounded angle in the calculator for (c). The exact area is 5√5/2, which the vector product in section 3.16 gives directly.

**8.** c · a = λ + 2 − μ = 0 [1] and c · b = 2λ − 1 + μ = 0 [1]. Adding: 3λ + 1 = 0, so **λ = −1/3** [1], and **μ = λ + 2 = 5/3** [1]

**9.** OB = a + c [1] and AC = c − a [1]. OB · AC = (a + c) · (c − a) = c · c − a · a = |c|² − |a|² [1]. Since |a| = |c|, OB · AC = 0, so the (non-zero) diagonals are **perpendicular** [1]

**10.** |v| = √(1 + 1 + 2) = 2 [1]. With the x-axis: cos θ = 1/2, so **60°**; with the y-axis: **60°** [1]; with the z-axis: cos θ = √2/2, so **45°** [1]

**11.** BA = (−2, 0, 2) and BC = (t − 3, −2, 1) [1]. BA · BC = −2(t − 3) + 0 + 2 = 0 [1], so **t = 4** [1]

*Examiner insight:* The right angle is at B, so both vectors must start at B. Using AB and AC tests the angle at A instead.

**12. (a)** |u + v|² = |u|² + 2u · v + |v|², so 7 = 9 + 2u · v + 4 [1], giving **u · v = −3** [1]

**(b)** cos θ = −3/(3 × 2) = −1/2 [1], so **θ = 2π/3** [1]

## Where marks are usually lost

- Giving a vector as the value of a scalar product.
- Forming the angle at a vertex with one vector pointing in and one pointing out.
- Leaving out the 2a · b term when expanding |a + b|².
- Ignoring the sign of the scalar product, so an obtuse angle is reported as acute.
- In proofs, not stating that the vectors are non-zero, or not naming the property used.
