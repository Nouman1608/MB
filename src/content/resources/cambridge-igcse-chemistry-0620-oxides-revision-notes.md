Condensed notes for subtopic **7.2 Oxides**, Cambridge IGCSE Chemistry 0620, 2026–2028. Items marked *(Extended)* are Supplement content. For the full explanation and a worked classification example, see the [oxides study guide](/resources/cambridge-igcse-chemistry-0620-oxides/); for exam-style questions, try the [oxides practice questions](/resources/cambridge-igcse-chemistry-0620-oxides-practice/).

## Key terms

| Term | Meaning |
|---|---|
| Oxide | A compound of an element with oxygen only |
| Acidic oxide | Oxide (usually of a non-metal) that reacts with bases/alkalis to form a salt and water |
| Basic oxide | Oxide of a metal that reacts with acids to form a salt and water |
| Amphoteric oxide *(Extended)* | Oxide that reacts with acids **and** with bases to produce a salt and water |
| Alkali | A soluble base; some basic oxides dissolve to form alkalis |

## The classification

| Type | Element | Named examples (syllabus) | Reacts with |
|---|---|---|---|
| Acidic | Non-metal | SO₂, CO₂ | Bases / alkalis |
| Basic | Metal | CuO, CaO | Acids |
| Amphoteric *(Extended)* | Metal (exceptions) | Al₂O₃, ZnO | Acids **and** bases |

Rule of thumb: **non-metal → acidic; metal → basic**. Across a period, oxides change from basic to acidic as the elements change from metal to non-metal.

## Quick classifier

| Oxide | Element type | Classification |
|---|---|---|
| Na₂O, K₂O | Metal (Group I) | Basic (dissolves to form an alkali) |
| MgO, CaO | Metal (Group II) | Basic |
| CuO | Metal (transition) | Basic (insoluble) |
| ZnO, Al₂O₃ | Metal | Amphoteric *(Extended)* |
| CO₂, SO₂, SO₃ | Non-metal | Acidic |
| NO₂ | Non-metal | Acidic (contributes to acid rain) |

Balancing tip: each oxide ion (O²⁻) takes **two** H⁺ ions to make **one** H₂O. Al₂O₃ has three oxide ions, so it needs 6HCl and makes 3H₂O.

## Key equations

**Acidic oxides + alkali → salt + water**

```
CO2 + 2NaOH → Na2CO3 + H2O
SO2 + 2NaOH → Na2SO3 + H2O
CO2 + Ca(OH)2 → CaCO3 + H2O       (limewater turns milky)
```

**Acidic oxides + water → acidic solution**

```
CO2 + H2O ⇌ H2CO3
SO2 + H2O → H2SO3                  (acid rain)
```

**Basic oxides + acid → salt + water**

```
CuO + H2SO4 → CuSO4 + H2O         (black solid → blue solution)
CaO + 2HCl → CaCl2 + H2O
MgO + 2HNO3 → Mg(NO3)2 + H2O
```

**Soluble basic oxides + water → alkali**

```
CaO + H2O → Ca(OH)2
Na2O + H2O → 2NaOH
```

**Basic oxide + acidic oxide → salt** (flue gas desulfurisation)

```
CaO + SO2 → CaSO3
```

**Amphoteric oxides** *(Extended)*

```
ZnO + 2HCl → ZnCl2 + H2O
ZnO + 2NaOH → Na2ZnO2 + H2O              (sodium zincate)
Al2O3 + 6HCl → 2AlCl3 + 3H2O
Al2O3 + 2NaOH → 2NaAlO2 + H2O            (sodium aluminate)
```

## Testing an unknown oxide

| With dilute acid | With aqueous NaOH | Type |
|---|---|---|
| Reacts | No reaction | Basic |
| No reaction | Reacts | Acidic |
| Reacts | Reacts | Amphoteric *(Extended)* |

If the oxide dissolves in water, universal indicator shows the result: acidic oxides give pH below 7; soluble basic oxides give pH above 7. Insoluble oxides (CuO, ZnO, Al₂O₃) must be tested by reaction instead.

## Where oxides appear elsewhere in 0620

- **Acid rain (Topic 10):** sulfur dioxide and oxides of nitrogen dissolve in rain.
- **Flue gas desulfurisation:** calcium oxide (basic) removes sulfur dioxide (acidic).
- **Limewater test (Topic 12):** carbon dioxide (acidic) reacts with calcium hydroxide.
- **Salt preparation (7.3):** an excess of insoluble basic oxide, such as CuO, is reacted with acid to make a soluble salt.
- **Periodic Table (8.1):** oxide type reflects metallic or non-metallic character across a period.

## Exam traps

- Acidic oxides react with **bases**, not acids.
- Basic oxides react with **acids**.
- Amphoteric ≠ neutral. Amphoteric means it reacts with **both**.
- Only Al₂O₃ and ZnO are named as amphoteric in this syllabus; learn them as a pair.
- CuO is a base, **not** an alkali; it is insoluble.
- Calcium hydroxide is Ca(OH)₂, not CaOH.
- Carbon dioxide gives a **weakly** acidic solution; don't describe it as strongly acidic.
- For an amphoteric oxide, the product is "salt and water" in **both** reactions.
- When explaining a classification, give the **reason**: the element is a metal or non-metal, or the oxide's observed reaction with acid or alkali.
- An insoluble oxide gives no pH reading in water, so it cannot be classified that way; test it with acid and with alkali before deciding.

## Self-test

1. Classify sulfur dioxide and calcium oxide.
2. Why is carbon dioxide an acidic oxide?
3. Write the equation for copper(II) oxide reacting with dilute hydrochloric acid.
4. State what is seen when copper(II) oxide reacts with warm dilute sulfuric acid.
5. Write the equation for sodium oxide dissolving in water.
6. Give the equation for the limewater test for carbon dioxide.
7. Why does sulfur dioxide in the air cause acid rain?
8. Which type of oxide is used to remove sulfur dioxide from waste gases? Give an example.
9. *(Extended)* Define an amphoteric oxide.
10. *(Extended)* Name the two amphoteric oxides in the syllabus.
11. *(Extended)* An oxide dissolves in both dilute nitric acid and aqueous sodium hydroxide. Classify it.
12. *(Extended)* Write the equation for zinc oxide reacting with dilute hydrochloric acid.

**Answers**

1. Sulfur dioxide: acidic; calcium oxide: basic.
2. Carbon is a non-metal, and CO₂ reacts with alkalis to form a salt and water (it dissolves in water to give a weakly acidic solution).
3. CuO + 2HCl → CuCl₂ + H₂O.
4. The black solid dissolves and a blue solution forms.
5. Na₂O + H₂O → 2NaOH.
6. CO₂ + Ca(OH)₂ → CaCO₃ + H₂O.
7. It is an acidic oxide that dissolves in rainwater to form an acidic solution.
8. A basic oxide; calcium oxide.
9. An oxide that reacts with acids and with bases to produce a salt and water.
10. Aluminium oxide (Al₂O₃) and zinc oxide (ZnO).
11. Amphoteric.
12. ZnO + 2HCl → ZnCl₂ + H₂O.
