## Section A

**1.** Determine whether each function is odd, even or neither. Justify your answers.

**(a)** f(x) = 3x⁴ − x² + 7 **[1]**
**(b)** g(x) = x⁵ sin x **[2]**
**(c)** h(x) = x² − 2x **[2]**

**2.** Show that f(x) = x² cos x + 1 is an even function. **[2]**

**3.** Show that g(x) = x\|x\| is an odd function. **[2]**

**4.**

**(a)** f is an odd function and f(3) = −5. Write down f(−3). **[1]**
**(b)** g is an even function and g(3) = −5. Write down g(−3). **[1]**
**(c)** Explain why every odd function with domain ℝ satisfies f(0) = 0. **[1]**

**5.** Let f(x) = (x − 3)² + 1, x ≥ 3. Find f⁻¹(x) and state its domain. **[4]**

**6.** Let f(x) = 4 − x.

**(a)** Show that f is self-inverse. **[2]**
**(b)** Write down the coordinates of the point where the graph of f meets the line y = x. **[1]**

## Section B

**7.** Let f(x) = x² − 6x + 5, x ≤ k.

**(a)** Write down the largest value of k for which f⁻¹ exists. **[1]**
**(b)** For this value of k, write down the range of f. **[1]**
**(c)** Find f⁻¹(x), stating its domain. **[4]**
**(d)** Find the exact coordinates of the point where the graph of y = f(x) meets the line y = x. **[3]**

**8.** Let f(x) = (3x + 2)/(4x − 3), x ≠ 3/4.

**(a)** Show that f(f(x)) = x. **[4]**
**(b)** Hence write down f⁻¹(x). **[1]**
**(c)** Write down the equations of the asymptotes of the graph of f, and explain how their point of intersection relates to the line y = x. **[3]**

**9.** Let f(x) = (kx + 5)/(2x − 3), x ≠ 3/2.

**(a)** Find the value of k for which f is self-inverse. **[2]**
**(b)** For this value of k, solve f(x) = x. **[3]**

**10.**

**(a)** Show that f(x) = sin x tan x is even. **[2]**
**(b)** Show that g(x) = sin(x + π/2) is even. **[2]**
**(c)** Show that h(x) = sin x + cos x is neither odd nor even. **[2]**

**11.** f is an odd function and g is an even function, both with domain ℝ.

**(a)** Show that the product p(x) = f(x)g(x) is odd. **[2]**
**(b)** Show that the composite q(x) = g(f(x)) is even. **[2]**
**(c)** For f(x) = 2x and g(x) = x² + 1, show that f(x) + g(x) is neither odd nor even. **[2]**

**12.** Let f(x) = √(9 − x²), 0 ≤ x ≤ 3.

**(a)** Write down the range of f. **[1]**
**(b)** Show that f is self-inverse. **[3]**
**(c)** Describe the graph of f and its symmetry. **[2]**

## Answers

**1. (a)** Only even powers and a constant, so f(−x) = f(x): even [1]
**(b)** g(−x) = (−x)⁵ sin(−x) = (−x⁵)(−sin x) [1] = x⁵ sin x = g(x), so even [1]
**(c)** h(1) = −1 and h(−1) = 3 [1]; 3 ≠ −1 and 3 ≠ 1, so neither [1]

**2.** f(−x) = (−x)² cos(−x) + 1 = x² cos x + 1 [1] = f(x), so f is even [1]

**3.** g(−x) = (−x)\|−x\| = −x\|x\| [1] = −g(x), so g is odd [1]

**4. (a)** f(−3) = −f(3) = 5 [1]
**(b)** g(−3) = g(3) = −5 [1]
**(c)** f(−0) = −f(0) gives f(0) = −f(0), so 2f(0) = 0 and f(0) = 0 [1]

**5.** y = (x − 3)² + 1, so x − 3 = √(y − 1) [1], positive root since x ≥ 3 [1]. f⁻¹(x) = 3 + √(x − 1) [1], x ≥ 1 [1]

**6. (a)** f(f(x)) = 4 − (4 − x) [1] = x [1]
**(b)** 4 − x = x gives (2, 2) [1]

**7. (a)** f(x) = (x − 3)² − 4, so k = 3 [1]
**(b)** f(x) ≥ −4 [1]
**(c)** y = (x − 3)² − 4, so (x − 3)² = y + 4 [1]. Since x ≤ 3, x − 3 = −√(y + 4) [1]. f⁻¹(x) = 3 − √(x + 4) [1], x ≥ −4 [1]
**(d)** x² − 6x + 5 = x, so x² − 7x + 5 = 0 [1]. x = (7 ± √29)/2 [1]. Only (7 − √29)/2 satisfies x ≤ 3, so the point is ((7 − √29)/2, (7 − √29)/2) [1]
*Examiner insight:* Rejecting (7 + √29)/2, which is about 6.19, needs a reason: it lies outside the restricted domain.

**8. (a)** f(f(x)) = [3(3x + 2)/(4x − 3) + 2] / [4(3x + 2)/(4x − 3) − 3] [1]. Multiply top and bottom by (4x − 3): (9x + 6 + 8x − 6)/(12x + 8 − 12x + 9) [1] = 17x/17 [1] = x [1]
**(b)** f⁻¹(x) = (3x + 2)/(4x − 3) [1]
**(c)** x = 3/4 [1] and y = 3/4 [1]. They meet at (3/4, 3/4), which lies on y = x, consistent with the graph's symmetry in y = x [1]

**9. (a)** Self-inverse form (ax + b)/(cx − a) with c = 2 and −a = −3 [1], so k = 3 [1]
**(b)** 3x + 5 = x(2x − 3) [1], so 2x² − 6x − 5 = 0 [1], giving x = (3 ± √19)/2 [1]

**10. (a)** f(−x) = sin(−x) tan(−x) = (−sin x)(−tan x) [1] = sin x tan x = f(x) [1]
**(b)** sin(x + π/2) = cos x [1], and cos(−x) = cos x, so g is even [1]
**(c)** h(π/4) = √2 and h(−π/4) = −√2/2 + √2/2 = 0 [1]. 0 ≠ √2 and 0 ≠ −√2, so neither [1]
*Examiner insight:* x = π/2 would not work in (c): h(−π/2) = −1 = −h(π/2), which agrees with the odd test at that value. Choose a value that breaks both tests.

**11. (a)** p(−x) = f(−x)g(−x) = (−f(x))(g(x)) [1] = −p(x) [1]
**(b)** q(−x) = g(f(−x)) = g(−f(x)) [1] = g(f(x)) = q(x), since g is even [1]
**(c)** s(x) = x² + 2x + 1: s(1) = 4 and s(−1) = 0 [1]; 0 ≠ 4 and 0 ≠ −4, so neither [1]

**12. (a)** 0 ≤ f(x) ≤ 3 [1]
**(b)** f(f(x)) = √(9 − (9 − x²)) [1] = √(x²) [1] = x, since x ≥ 0 [1]
**(c)** A quarter of the circle of radius 3 centred at the origin, in the first quadrant [1], symmetric in the line y = x [1]

## Where marks are usually lost

- Using a single number to "prove" a function is odd or even.
- Choosing a test value for "neither" that happens to satisfy one of the conditions.
- Taking the positive square root for an inverse when the domain is x ≤ k.
- Leaving out the domain of f⁻¹.
- Not clearing the inner fractions before simplifying f(f(x)).
- Writing √(x²) = x without noting that x ≥ 0.
