These questions cover syllabus section 3.14 of IB DP Mathematics: Analysis and Approaches (first assessment 2021), which is HL only: the vector equation of a line in two and three dimensions, the angle between two lines and simple kinematics. Questions are labelled "(calculator-free)" or "(calculator allowed)"; give calculator answers to 3 significant figures. Vectors are written in rows. The methods are in the [3.14 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-14/) and the [3.14 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-14-revision-notes/).

## Section A

**1.** (calculator-free) A line passes through (2, −1, 4) and is parallel to (3, 0, −2).

**(a)** Write down a vector equation of the line. **[2]**

**(b)** Write the line in parametric form. **[1]**

**2.** (calculator-free) A(1, 2, 3) and B(4, 0, 4).

**(a)** Find a vector equation of the line AB. **[2]**

**(b)** Write the line AB in Cartesian form. **[2]**

**3.** (calculator-free) Write the line (x + 1)/2 = (4 − y)/3 = z/5 in vector form. **[2]**

**4.** (calculator-free) Show that the point (−5, 7, −2) lies on the line r = (1, 1, 4) + λ(−2, 2, −2). **[2]**

**5.** (calculator allowed) Find the acute angle between two lines with direction vectors (1, 2, −2) and (3, 0, 4). **[3]**

**6.** (calculator-free) Write the line r = (2, −1) + λ(3, 4) in the form ax + by = c. **[2]**

## Section B

**7.** (calculator allowed) A drone moves with constant velocity. Its position after t seconds is r = (2, 1, 0) + t(3, −2, 1), with distances in metres.

**(a)** Find the speed of the drone. **[1]**

**(b)** Find its position after 4 seconds. **[1]**

**(c)** Find the time at which its height, the z-coordinate, is 6 m. **[1]**

**(d)** Find the distance it travels in the first 4 seconds. **[1]**

**8.** (calculator-free) The line L has equation r = (1, 1, 0) + λ(1, −1, 2), and P is the point (5, 1, 4). Q is a point on L.

**(a)** Write PQ in terms of λ. **[2]**

**(b)** Find the value of λ for which PQ is perpendicular to L. **[2]**

**(c)** Hence find the coordinates of the foot of the perpendicular from P to L and the shortest distance from P to L. **[2]**

**9.** (calculator allowed) *Invented data.* A ship starts at (−6, 2) and moves with constant velocity (3, 1) km h⁻¹. A port is at (6, 10).

**(a)** Find the speed of the ship. **[1]**

**(b)** Write down the position of the ship after t hours. **[1]**

**(c)** Show that the square of the distance from the ship to the port is 10t² − 88t + 208. **[2]**

**(d)** Find the time at which the ship is closest to the port and the minimum distance. **[3]**

**10.** (calculator-free) The line r = (1, 0, 2) + λ(p, 2, 1) makes an angle of 60° with a line with direction (1, 1, 0). Find the possible values of p. **[4]**

**11.** (calculator-free) The line L passes through A(2, 0, −1) and is parallel to the line joining (0, 1, 1) and (3, 2, −1).

**(a)** Find a vector equation of L. **[2]**

**(b)** Find the point where L meets the plane z = 0. **[2]**

**12.** (calculator-free) Show that r = (1, 2, 3) + λ(2, −1, 1) and r = (5, 0, 5) + μ(−4, 2, −2) represent the same line. **[3]**

## Answers

**1. (a)** **r = (2, −1, 4) + λ(3, 0, −2)**: correct point [1], correct direction [1]

**(b)** **x = 2 + 3λ, y = −1, z = 4 − 2λ** [1]

**2. (a)** Direction AB = (3, −2, 1) [1]; **r = (1, 2, 3) + λ(3, −2, 1)** [1]

**(b)** **(x − 1)/3 = (y − 2)/(−2) = (z − 3)/1** [2]

**3.** (4 − y)/3 = (y − 4)/(−3), so the point is (−1, 4, 0) and the direction is (2, −3, 5) [1]: **r = (−1, 4, 0) + λ(2, −3, 5)** [1]

*Examiner insight:* A direction with +3 in the y-component is the usual error; the sign comes from rewriting 4 − y as −(y − 4).

**4.** x: 1 − 2λ = −5 gives λ = 3 [1]. y: 1 + 6 = 7 and z: 4 − 6 = −2, both correct, so the point lies on the line [1]

**5.** |b₁ · b₂| = |3 + 0 − 8| = 5 [1]; magnitudes 3 and 5, so cos θ = 1/3 [1]; **θ = 70.5°** [1]

**6.** x = 2 + 3λ and y = −1 + 4λ, so λ = (x − 2)/3 = (y + 1)/4 [1], giving **4x − 3y = 11** [1]

**7. (a)** √(9 + 4 + 1) = **√14 = 3.74 m s⁻¹** [1]

**(b)** **(14, −7, 4)** [1]

**(c)** z = t = 6, so **t = 6 s** [1]

**(d)** 4√14 = **15.0 m** [1]

**8. (a)** Q = (1 + λ, 1 − λ, 2λ) [1], so **PQ = (λ − 4, −λ, 2λ − 4)** [1]

**(b)** (λ − 4) − (−λ) + 2(2λ − 4) = 0 [1], so 6λ − 12 = 0 and **λ = 2** [1]

**(c)** Foot **(3, −1, 4)** [1]; PQ = (−2, −2, 0), so the distance is **2√2** [1]

*Examiner insight:* Check the answer: (−2, −2, 0) · (1, −1, 2) = −2 + 2 + 0 = 0, so PQ is indeed perpendicular to L.

**9. (a)** √10 = **3.16 km h⁻¹** [1]

**(b)** **(−6 + 3t, 2 + t)** [1]

**(c)** The vector from the port to the ship is (3t − 12, t − 8) [1]. Its squared length is 9t² − 72t + 144 + t² − 16t + 64 = **10t² − 88t + 208** [1]

**(d)** The minimum of the quadratic is at t = 88/20 = **4.4 hours** [1]. Minimum squared distance 10(4.4)² − 88(4.4) + 208 = 14.4 [1], so the minimum distance is **3.79 km** [1]

*Examiner insight:* At t = 4.4 the ship is at (7.2, 6.4); the vector (1.2, −3.6) from the port is perpendicular to the velocity, since 3.6 − 3.6 = 0.

**10.** cos 60° = |p + 2|/(√(p² + 5) × √2) [1]. So 2|p + 2| = √(2(p² + 5)), and squaring, 4(p + 2)² = 2p² + 10 [1]. This gives 2p² + 16p + 6 = 0, that is p² + 8p + 3 = 0 [1], so **p = −4 ± √13** [1]

**11. (a)** Direction (3, 1, −2) [1]; **r = (2, 0, −1) + λ(3, 1, −2)** [1]

**(b)** z = −1 − 2λ = 0 gives λ = −1/2 [1]; the point is **(1/2, −1/2, 0)** [1]

**12.** (−4, 2, −2) = −2(2, −1, 1), so the directions are parallel [1]. With λ = 2 the first line gives (1 + 4, 2 − 2, 3 + 2) = (5, 0, 5), so the second line's point is on the first line [1]. Parallel lines with a common point are the same line [1]

## Where marks are usually lost

- Using a second point as the direction vector instead of the difference of the two points.
- Sign errors when reading Cartesian forms such as (4 − y)/3.
- Taking the obtuse angle between lines.
- Simplifying a velocity vector in a kinematics question, which changes the speed.
- Testing only one or two components when checking that a point lies on a line.
