## Section A: short answers

**1.** Identify the threat described in each case.

**(a)** A text message claiming to be from a parcel firm asks the user to follow a link to pay a delivery fee. **[1]**

**(b)** Someone stands behind a shopper at a cash machine and watches the PIN being entered. **[1]**

**(c)** A caller claiming to be from the bank asks for the customer's online banking password. **[1]**

## Answers

**1. (a)** Smishing [1].

**(b)** Shoulder surfing [1].

**(c)** Vishing [1]. **[3]**

**2.** To monitor traffic between a computer or network and the internet and block traffic that does not meet set rules / block unauthorised access [1]. **[1]**

**3.** Any three of: owner's name [1]; serial number [1]; expiry date [1]; owner's public key [1]; digital signature of the certificate authority [1]. Maximum 3. **[3]**

**4.** Data is scrambled into an unreadable form using an encryption key [1], so it can only be understood by someone who has the key to decrypt it [1]. **[2]**

**5.** Any two of: fingerprint [1]; face [1]; iris [1]; retina [1]; voice [1]. Maximum 2. **[2]**

**6. (a)** Pharming [1].

**(b)** In phishing the user is tricked into clicking a link in an email that leads to a fake website [1], whereas in pharming malicious code redirects the user to the fake website even when they type the correct address and do nothing wrong [1].

**(c)** Any two of: use up-to-date anti-malware software to detect pharming code [1]; check the address bar shows the correct address and https [1]; check the site has a valid digital certificate / padlock before entering details [1]. Maximum 2. **[5]**

**7.** Any three, each named and described [2 each]: a firewall [1] that blocks unauthorised traffic from the internet reaching the network [1]; strong user IDs and passwords [1], with accounts locked after several failed attempts [1]; two-factor authentication [1], so a stolen password alone does not allow access [1]; encryption of stored records [1], so stolen data cannot be read [1]; keeping software updated [1] to close known weaknesses hackers use [1]; giving staff access only to the data they need [1], limiting what a hacked account can reach [1]. Maximum 6. **[6]**

**8. (a)** A virus / malware in the downloaded file [1].

**(b)** Any three of: download only from trusted, official sources [1]; scan the file with up-to-date anti-virus software before opening it [1]; keep anti-virus software running and updated [1]; do not run executable files from unknown sources [1]; keep the operating system updated [1]. Maximum 3. **[4]**

**9. (a)** Card cloning [1].

**(b)** The skimmer reads and copies the data from the card's magnetic stripe when the card is used [1]; the criminal uses the copied data to make a duplicate card and make purchases or withdrawals [1]. **[3]**

**10.** SSL sets up an encrypted link between the customer's browser and the shop's server [1]; card and personal details are encrypted as they travel, so they cannot be read if intercepted [1]; the shop's digital certificate is checked, so the customer knows the site is genuine, shown by https and a padlock [1]. **[3]**

**11. (a)** Two-factor authentication [1].

**(b)** A criminal who has stolen the password also needs the customer's phone [1], which they are unlikely to have, so the account cannot be accessed with the password alone [1].

**(c)** Any one of: the customer cannot log in if the phone is lost, stolen or has no signal [1]; logging in takes longer [1]. Maximum 1. **[4]**

**12.** Up to 6 marks. Advantages, for example: a fingerprint cannot be forgotten, unlike a password [1]; it cannot be shared or lent to another member of staff, so access is traced to the right person [1]; it is quick, which matters in an emergency [1]; it is very hard to copy, protecting sensitive patient data [1]. Disadvantages, for example: scanners cost more than password systems [1]; recognition may fail if a finger is cut, wet or gloved, delaying access to records [1]; staff may have privacy concerns about storing biometric data [1]. Maximum 6; both advantages and disadvantages are needed for full marks. **[6]**

## Frequently asked questions

**Is a key logger hacking or card fraud?**
The syllabus lists key logging under card fraud, because it can capture card numbers as they are typed. It also captures passwords, so mention both if the question allows.

**Does a padlock mean a website is safe?**
It shows the connection is encrypted with SSL and that a certificate exists. Users should still check the address is the one they intended.
