These questions cover sub-topic 1(d) The Periodic Table of the Pearson Edexcel International GCSE Chemistry (4CH1) specification, Issue 3 (September 2024): points 1.18 to 1.24, none of which has a C reference. Revise with [the Periodic Table study guide](/resources/edexcel-igcse-chemistry-4ch1-the-periodic-table/) and the [revision notes](/resources/edexcel-igcse-chemistry-4ch1-the-periodic-table-revision-notes/).

## Section A: short questions

**1.** State the name given to a vertical column of the Periodic Table. **[1]**

**2.** Give the electronic configuration of each element.

**(a)** oxygen (atomic number 8) **[1]**
**(b)** phosphorus (atomic number 15) **[1]**
**(c)** calcium (atomic number 20) **[1]**

**3.** An atom has the configuration 2,8,7. State its group and its period. **[2]**

**4.** Element Q is in Period 3 and Group 2. Deduce the electronic configuration of Q and name Q. **[2]**

**5.** Use the Periodic Table to classify each element as a metal or a non-metal.

**(a)** lithium **[1]**
**(b)** sulfur **[1]**
**(c)** bromine **[1]**

**6.** State why helium is placed in Group 0 although its atoms have only two electrons. **[1]**

## Section B: structured questions

**7.** Nitrogen (atomic number 7) and phosphorus (atomic number 15) are in the same group.

**(a)** Give the electronic configuration of nitrogen. **[1]**
**(b)** Explain, in terms of electrons, why nitrogen and phosphorus are in the same group but different periods. **[2]**
**(c)** Explain why nitrogen and phosphorus have similar chemical properties. **[2]**

**8.** A student burns four elements, A, B, C and D, in oxygen. She shakes each oxide with water and adds universal indicator. She also tests whether each solid element conducts electricity.

| Element | Conducts when solid? | Colour of universal indicator with the oxide |
|---|---|---|
| A | Yes | Purple |
| B | No | Red |
| C | Yes | Green (oxide insoluble) |
| D | Yes | Yellow |

**(a)** Classify A and B as metals or non-metals. Give a reason for each using both results. **[2]**
**(b)** The oxide of C does not dissolve. Describe a further test on the oxide of C that would show C is a metal, and give the expected result. **[2]**
**(c)** Suggest the identity of D and explain why the conductivity test alone would have misled the student. **[2]**

**9.** The noble gases are in Group 0.

**(a)** Give the electronic configuration of argon (atomic number 18). **[1]**
**(b)** Explain why argon does not readily react. **[2]**
**(c)** Argon is used to fill light bulbs, where the hot filament would react with oxygen. Use your answer to (b) to explain this use. **[1]**
**(d)** Explain why argon exists as single atoms while chlorine exists as Cl₂ molecules. **[2]**

**10.** Argon (atomic number 18, Ar 39.9) and potassium (atomic number 19, Ar 39.1) are next to each other in the Periodic Table.

**(a)** State the order in which these two elements would be placed if the table were arranged by relative atomic mass. **[1]**
**(b)** Explain why this order would put both elements in the wrong groups, using their electronic configurations. **[3]**

**11.** Element E has atomic number 16.

**(a)** Deduce the group and period of E. **[2]**
**(b)** Predict whether the oxide of E forms an acidic or an alkaline solution in water. Explain your prediction using the position of E. **[2]**
**(c)** Oxygen is in the same group as E. Hydrogen and oxygen form H₂O. Predict the formula of the compound of hydrogen and E. **[1]**

**12.** Strontium is in Group 2 and Period 5.

**(a)** State the number of electrons in the outer shell of a strontium atom. **[1]**
**(b)** State the number of occupied shells in a strontium atom. **[1]**
**(c)** Calcium reacts with water to form calcium hydroxide and hydrogen. Predict the products when strontium reacts with water and explain your prediction. **[2]**
**(d)** Predict whether strontium oxide is a basic or an acidic oxide. Give a reason. **[1]**

## Answers

**1.** A group [1].

**2. (a)** 2,6 [1].
**(b)** 2,8,5 [1].
**(c)** 2,8,8,2 [1].
*Marking note:* 2,8,10 for calcium scores zero: the third shell holds 8 before the fourth starts for the first 20 elements.

**3.** Group 7 [1]; Period 3 [1].

**4.** 2,8,2 [1]; magnesium [1].

**5. (a)** Metal [1].
**(b)** Non-metal [1].
**(c)** Non-metal [1].

**6.** Its outer shell (the first shell) is full [1].

**7. (a)** 2,5 [1].
**(b)** Both have 5 electrons in the outer shell, so the same group [1]. Nitrogen has two occupied shells and phosphorus three, so different periods [1].
**(c)** Both have the same number of outer-shell electrons (5) [1]. Chemical reactions involve the outer-shell electrons [1].

**8. (a)** A is a metal: it conducts and its oxide gives an alkaline solution (purple, pH above 7) [1]. B is a non-metal: it does not conduct and its oxide gives an acidic solution (red, pH below 7) [1].
**(b)** Add the oxide to a dilute acid (e.g. hydrochloric acid) and warm [1]. It reacts / dissolves to form a salt and water, showing it is a basic oxide [1].
**(c)** Carbon (graphite) [1]. Graphite conducts electricity even though carbon is a non-metal, as its acidic oxide shows [1].

**9. (a)** 2,8,8 [1].
**(b)** Its outer shell is full [1]. This is a stable arrangement, so argon atoms do not lose, gain or share electrons [1].
**(c)** Argon does not react with the hot filament, so the filament is protected (it does not burn away) [1].
**(d)** Argon atoms have full outer shells, so they do not share electrons / bond with each other [1]. Chlorine atoms (2,8,7) need one more electron and share a pair of electrons to form Cl₂ molecules [1].

**10. (a)** Potassium before argon [1].
**(b)** Argon is 2,8,8: a full outer shell, so it belongs in Group 0 with the unreactive noble gases [1]. Potassium is 2,8,8,1: one outer electron, so it belongs in Group 1 with the reactive alkali metals [1]. Ordering by atomic number (18 then 19) puts each with elements of the same outer-shell structure and similar properties [1].

**11. (a)** Configuration 2,8,6 [1], so Group 6 and Period 3 [1].
**(b)** Acidic [1]. E is in Group 6, to the right of the stepped line, so it is a non-metal, and non-metal oxides are acidic [1].
**(c)** H₂E (H₂S) [1].

**12. (a)** 2 [1].
**(b)** 5 [1].
**(c)** Strontium hydroxide and hydrogen [1]. Strontium is in the same group as calcium, with the same number of outer electrons, so it reacts in a similar way [1].
**(d)** Basic: strontium is a metal (Group 2, left of the table) [1].

## Where marks are usually lost

- Giving the period as the number of outer electrons, or the group as the number of shells.
- Writing only "same group" to explain similar properties.
- Saying "8 outer electrons" for noble gases.
- Classifying D in Question 8 as a metal because it conducts.
- Forgetting that the order is by atomic number, not relative atomic mass.
