Condensed notes for subtopic **1.4 Fractions, decimals and percentages** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027. The [Fractions, decimals and percentages study guide](/resources/cambridge-o-level-mathematics-4024-fractions-decimals-and-percentages/) explains each method with worked examples; the [Fractions, decimals and percentages practice questions](/resources/cambridge-o-level-mathematics-4024-fractions-decimals-and-percentages-practice/) give exam-style questions with mark schemes.

## Syllabus outcomes

1. Use the language and notation of proper fractions, improper fractions, mixed numbers, decimals and percentages in appropriate contexts.
2. Recognise equivalence and convert between these forms.

Write fractions in simplest form. Recurring decimal notation is required, including converting between recurring decimals and fractions.

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Proper fraction | numerator less than denominator | 5/9 |
| Improper fraction | numerator at least the denominator | 11/4 |
| Mixed number | whole number plus fraction | 2 3/4 |
| Terminating decimal | decimal that stops | 0.375 |
| Recurring decimal | decimal with a repeating pattern | 0.6̇ = 0.666... |
| Percentage | number of parts per 100 | 35% = 35/100 |
| Simplest form | no common factor above 1 | 6/8 = 3/4 |

## Conversion map

| From | To | Method |
|---|---|---|
| Fraction | Decimal | numerator ÷ denominator |
| Decimal | Fraction | put over 10, 100, 1000 and simplify |
| Fraction or decimal | Percentage | multiply by 100 |
| Percentage | Decimal | divide by 100 |
| Percentage | Fraction | put over 100 and simplify |
| Improper | Mixed | divide; remainder goes over the denominator |
| Mixed | Improper | whole × denominator + numerator |

## Terminating or recurring?

Cancel the fraction to simplest form, then factorise the denominator.

| Fraction | Denominator | Result |
|---|---|---|
| 3/16 | 2⁴ | terminates (0.1875) |
| 7/20 | 2² × 5 | terminates (0.35) |
| 4/15 | 3 × 5 | recurs (0.26̇) |
| 9/24 | simplifies to 3/8, denominator 2³ | terminates (0.375) |
| 5/18 | 2 × 3² | recurs (0.27̇) |
| 2/7 | 7 | recurs (0.2̇85714̇) |

Only the prime factors 2 and 5 give a terminating decimal.

## Recurring decimal notation

| Decimal | Notation | Which digits repeat |
|---|---|---|
| 0.5555... | 0.5̇ | the 5 |
| 0.1777... | 0.17̇ | the 7 |
| 0.1232323... | 0.12̇3̇ | the 23 |
| 0.123123... | 0.1̇2̇3̇ | the 123 |
| 0.7272... | 0.7̇2̇ | the 72 |

Dots go over the first and last digits of the repeating block.

## Recurring decimal to fraction: method

1. Let x equal the decimal.
2. Multiply by a power of 10 to move the decimal point past the non-repeating part (if any).
3. Multiply by a second power of 10 to move it past one full repeating block.
4. Subtract so the repeating tails cancel.
5. Solve for x and simplify.

| Decimal | Equations | Result |
|---|---|---|
| 0.4̇ | 10x - x = 4, so 9x = 4 | 4/9 |
| 0.2̇7̇ | 100x - x = 27, so 99x = 27 | 3/11 |
| 0.35̇ | 100x - 10x = 35.55... - 3.55... = 32, so 90x = 32 | 16/45 |
| 0.16̇ | 100x - 10x = 16.66... - 1.66... = 15, so 90x = 15 | 1/6 |
| 0.1̇8̇ | 99x = 18 | 2/11 |

Shortcut check: when the repeat starts straight after the point, one repeating digit gives d/9 (so 0.4̇ = 4/9) and a two-digit block gives the block over 99 (so 0.2̇7̇ = 27/99).

## Worked example: mixed forms

Which is greater, 5/8 or 0.62?

```
5/8 = 0.625
0.625 > 0.62
```

so 5/8 is greater. Convert to the same form (here, decimals) before comparing.

## Exam traps

- A percentage needs a % sign: 0.35 is 35%, not 35.
- Cancel fully, so 12/18 becomes 2/3, not 6/9.
- A recurring decimal is not an approximation; 0.3̇ equals 1/3 exactly.
- Do not use 99 when the repeat does not start straight after the point. For 0.17̇ the multipliers are 10 and 100, giving 90x = 16.
- Show both lines x and 10x (or 100x) in recurring decimal proofs.
- 1.5% is 0.015, not 0.15.
- A mixed number is not "added" by mistake: 3 2/5 means 3 + 2/5, not 3 × 2/5.

## Self-test

1. Write 0.45 as a fraction in its simplest form.
2. Write 11/16 as a decimal.
3. Write 5/9 as a recurring decimal using dot notation.
4. Write 38/7 as a mixed number.
5. Write 2 3/8 as an improper fraction.
6. Write 175% as a decimal.
7. Does 13/40 terminate or recur? Give a reason.
8. Show that 0.6̇ = 2/3.
9. Write 0.2̇1̇ (which is 0.2121...) as a fraction.
10. Write 0.08̇ (which is 0.0888...) as a fraction.

**Answers**

1. 45/100 = **9/20**.
2. **0.6875**.
3. **0.5̇**.
4. 38 ÷ 7 = 5 remainder 3, so **5 3/7**.
5. (2 × 8 + 3)/8 = **19/8**.
6. **1.75**.
7. 40 = 2³ × 5 with no other prime factor, so it **terminates** (0.325).
8. x = 0.666..., 10x = 6.666..., so 9x = 6 and x = 6/9 = **2/3**.
9. 99x = 21, so **7/33**.
10. 100x - 10x = 8.88... - 0.88... = 8, so 90x = 8, **4/45**.
