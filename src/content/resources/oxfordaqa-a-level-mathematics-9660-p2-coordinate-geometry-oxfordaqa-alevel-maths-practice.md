These questions cover section P2.3 (Coordinate geometry in the (x, y) plane) of the OxfordAQA International AS and A-level Mathematics (9660) specification, Version 5.2: Cartesian and parametric equations of curves and conversion between the two forms. The section is in International A-level Unit P2. Read the [coordinate geometry study guide](/resources/oxfordaqa-a-level-mathematics-9660-p2-coordinate-geometry-oxfordaqa-alevel-maths/) first, or refresh the methods with the [coordinate geometry revision notes](/resources/oxfordaqa-a-level-mathematics-9660-p2-coordinate-geometry-oxfordaqa-alevel-maths-revision-notes/).

## Section A

**1.** A curve has parametric equations x = 4t, y = 2t². Find its Cartesian equation in the form y = f(x). **[2]**

**2.** A curve has parametric equations x = 3 cos θ, y = 3 sin θ + 2, for 0 ≤ θ < 2π. Find its Cartesian equation, and state the centre and radius of the circle it represents. **[3]**

**3.** A curve has parametric equations x = 2/t, y = 5t, for t ≠ 0. Find its Cartesian equation. **[2]**

**4.** Write down parametric equations for the circle (x + 1)² + (y − 4)² = 16. **[2]**

**5.** A curve has parametric equations x = eᵗ + 1, y = e²ᵗ, for all real t.

**(a)** Find its Cartesian equation. **[2]**

**(b)** State the set of values that x can take. **[1]**

## Section B

**6.** A curve C has parametric equations x = 2t − 3, y = t² + 1, for −2 ≤ t ≤ 1.

**(a)** Find a Cartesian equation for C. **[2]**

**(b)** Find the set of values of x and the set of values of y on C. **[2]**

**7.** A curve has parametric equations x = 2 sec θ, y = 3 tan θ.

**(a)** Show that 9x² − 4y² = 36. **[3]**

**(b)** Explain why the curve has no point with x = 1. **[1]**

**8.** A curve has parametric equations x = 3 cos θ, y = 1 + cos 2θ, for 0 ≤ θ ≤ π.

**(a)** Show that the Cartesian equation of the curve is y = 2x²/9. **[3]**

**(b)** State the set of values of x for the curve. **[1]**

**9.** A curve has parametric equations x = t + 2/t, y = t − 2/t, for t > 0.

**(a)** Show that x² − y² = 8. **[3]**

**(b)** Find the coordinates of the points on the curve where x = 3. **[3]**

**10.** A curve has parametric equations x = t² − 1, y = t³ − 4t.

**(a)** Find the coordinates of the points where the curve meets the coordinate axes. **[4]**

**(b)** Write down the coordinates of the point through which the curve passes twice. **[1]**

**(c)** Show that the Cartesian equation is y² = (x + 1)(x − 3)², and state the set of values of x. **[3]**

**11.** The curve x = 2t, y = t² meets the line y = x + 3 at two points. Find their coordinates. **[4]**

**12.** A curve has parametric equations x = 2t/(1 + t), y = 3/(1 + t), for t ≠ −1.

**(a)** Show that every point of the curve lies on the line 3x + 2y = 6. **[2]**

**(b)** Find the coordinates of the one point on this line that is not on the curve. **[2]**

**13.** An ellipse has parametric equations x = 5 cos θ, y = 4 sin θ, for 0 ≤ θ < 2π.

**(a)** Find a Cartesian equation for the ellipse. **[2]**

**(b)** Find the exact coordinates of the points where the ellipse meets the line y = 2. **[3]**

## Answers

**1.** t = x/4 [1], so y = 2(x/4)² = **x²/8** [1]. Total: 2

**2.** cos θ = x/3 and sin θ = (y − 2)/3 [1]. Using sin²θ + cos²θ = 1: **x² + (y − 2)² = 9** [1]. **Centre (0, 2), radius 3** [1]. Total: 3

**3.** Multiplying: xy = (2/t)(5t) [1] = 10, so **xy = 10** (or y = 10/x) [1]. Total: 2

**4.** **x = −1 + 4 cos θ** [1], **y = 4 + 4 sin θ**, for 0 ≤ θ < 2π [1]. Other correct forms, such as x = −1 + 4 sin θ, y = 4 + 4 cos θ, also earn full credit. Total: 2

**5. (a)** eᵗ = x − 1 [1], so y = (eᵗ)² = **(x − 1)²** [1].

**(b)** eᵗ > 0, so **x > 1** [1]. Total: 3

**6. (a)** t = (x + 3)/2 [1], so **y = (x + 3)²/4 + 1** [1].

**(b)** x runs from 2(−2) − 3 = −7 to 2(1) − 3 = −1, so **−7 ≤ x ≤ −1** [1]. For y: t = −2 gives 5, t = 1 gives 2, and t = 0, inside the range, gives the least value 1. So **1 ≤ y ≤ 5** [1]. Total: 4

**7. (a)** sec θ = x/2 and tan θ = y/3 [1]. Using 1 + tan²θ = sec²θ: 1 + y²/9 = x²/4 [1]. Multiply by 36: 36 + 4y² = 9x², so **9x² − 4y² = 36** [1].

**(b)** |sec θ| ≥ 1 for every θ, so |x| = 2|sec θ| ≥ 2, and x = 1 is impossible [1]. Total: 4

**8. (a)** cos θ = x/3 [1]. cos 2θ = 2cos²θ − 1, so y = 1 + 2cos²θ − 1 = 2cos²θ [1] = 2(x/3)² = **2x²/9** [1].

**(b)** For 0 ≤ θ ≤ π, cos θ runs from 1 to −1, so **−3 ≤ x ≤ 3** [1]. Total: 4

**9. (a)** x + y = 2t and x − y = 4/t [1]. Multiplying: (x + y)(x − y) = 2t × 4/t = 8 [1], so **x² − y² = 8** [1].

**(b)** t + 2/t = 3, so t² − 3t + 2 = 0 [1], giving (t − 1)(t − 2) = 0 and t = 1 or t = 2 [1]. t = 1 gives y = −1 and t = 2 gives y = 1, so the points are **(3, −1) and (3, 1)** [1]. Total: 6

**10. (a)** y = 0: t(t² − 4) = 0, so t = 0 or t = ±2 [1], giving **(−1, 0) and (3, 0)** [1].
x = 0: t² = 1, so t = ±1 [1]; t = 1 gives y = −3 and t = −1 gives y = 3, so **(0, −3) and (0, 3)** [1].

**(b)** t = 2 and t = −2 both give **(3, 0)** [1].

**(c)** y² = t²(t² − 4)² [1]. With t² = x + 1, t² − 4 = x − 3, so **y² = (x + 1)(x − 3)²** [1]. Since t² ≥ 0, **x ≥ −1** [1]. Total: 8

**11.** Substituting: t² = 2t + 3 [1], so t² − 2t − 3 = 0 and (t − 3)(t + 1) = 0 [1]. t = 3 gives **(6, 9)** [1] and t = −1 gives **(−2, 1)** [1]. Total: 4

**12. (a)** 3x + 2y = 6t/(1 + t) + 6/(1 + t) [1] = 6(t + 1)/(1 + t) = 6 [1].

**(b)** y = 3/(1 + t) is never 0 [1], so the point of the line with y = 0, which is **(2, 0)**, is not on the curve [1]. Total: 4

**13. (a)** cos θ = x/5 and sin θ = y/4 [1], so **x²/25 + y²/16 = 1** [1].

**(b)** 4 sin θ = 2, so sin θ = 1/2 and θ = π/6 or 5π/6 [1]. Then x = 5 cos(π/6) = 5√3/2 and x = 5 cos(5π/6) = −5√3/2 [1]. The points are **(5√3/2, 2) and (−5√3/2, 2)** [1]. Total: 5

## Where marks are usually lost

- Stating a Cartesian equation with no restriction when the parameter limits x or y.
- Missing the turning value t = 0 when finding the range of y in a question like Question 6.
- Using the wrong trigonometric identity, or the right one with the wrong sign.
- Finding the parameter values but not converting them to coordinates.
- Giving only one of two points when the equation in t has two roots.
- Leaving a "show that" answer without its final line matching the given result.
