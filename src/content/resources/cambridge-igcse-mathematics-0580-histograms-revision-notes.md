These notes condense section **E9.7 Histograms** from Topic 9 Statistics of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. The syllabus lists C9.7 as "Extended content only", so this page is for **Extended** candidates (Papers 2 and 4). You must "Draw and interpret histograms" and "Calculate with frequency density". The notes say the vertical axis is labelled "Frequency density", and define frequency density = frequency ÷ class width.

The full teaching, with worked examples, is in the [histograms study guide](/resources/cambridge-igcse-mathematics-0580-histograms/). For marked questions, use the [histograms practice questions](/resources/cambridge-igcse-mathematics-0580-histograms-practice/).

## Key terms

| Term | Meaning |
|---|---|
| Histogram | Touching bars for grouped continuous data; bar area represents frequency |
| Class width | Upper boundary − lower boundary |
| Frequency density | Frequency ÷ class width: the height of a bar |
| Unequal class widths | Classes of different sizes, such as 0–10 and 10–30 |
| Modal class | The class with the highest frequency density (tallest bar) |

## The two formulae

```
frequency density = frequency ÷ class width      (to DRAW a bar)
frequency         = frequency density × class width   (to READ a bar)
```

So **area of bar = frequency**. When all classes are the same width, the histogram has the same shape as a frequency bar chart; with unequal widths only frequency density gives a fair picture.

## Drawing: checklist

```
1. Add columns: class width, frequency density.
2. Horizontal axis: continuous, even scale; classes at their true positions.
3. Vertical axis: labelled "Frequency density", even scale from 0.
4. Each bar from lower to upper boundary, height = frequency density.
5. No gaps between bars.
6. Check: width × height of each bar = its frequency.
```

**Small reminder.**

```
Class            Frequency   Width   Frequency density
0 < x ≤ 10          12         10        1.2
10 < x ≤ 15          9          5        1.8
15 < x ≤ 30         21         15        1.4
```

The tallest bar is 10 < x ≤ 15, so that is the **modal class**, although 15 < x ≤ 30 has the highest frequency.

## Reading: checklist

- Frequency of a class = bar height × class width.
- Total frequency = total area of all the bars.
- Number in **part** of a class = density × width of that part (assume values are spread evenly). It is an estimate.

**Small reminder.** A bar for 20 < x ≤ 40 has frequency density 2. The estimated number between 25 and 30 is 2 × 5 = **10**.

## When the vertical axis has no numbers

```
1. Use the class whose frequency you know: density = frequency ÷ width.
2. Compare with its bar height to find what 1 unit of height means.
3. Convert every other bar: height → density → × width → frequency.
```

Or use area: (area of known bar) ÷ (its frequency) = area per item.

**Small reminder.** Class width 5, frequency 20, bar 8 cm tall: density 4, so 1 cm = 0.5. A bar of width 10 and height 3 cm has density 1.5 and frequency **15**.

## Exam traps

- Plotting frequency on the vertical axis when the widths are unequal.
- Wrong class width: 15 < x ≤ 30 is 15 wide, not 14 or 30.
- Gaps between bars, or bars that do not start and end at the class boundaries.
- Vertical axis left unlabelled, or labelled "Frequency".
- Modal class chosen by highest frequency instead of tallest bar.
- Reading bar height as frequency.
- In "part of a class" questions, using a fraction of the frequency density instead of the area of the part.
- Fractional frequencies (such as 13.5 people): a sign you have misread a width or a height.

## Quick self-test

1. A class 20 < x ≤ 35 has frequency 45. Find the frequency density.
2. A bar has frequency density 0.8 and class width 25. Find the frequency.
3. What does the area of a histogram bar represent?
4. What must the vertical axis of a histogram be labelled?
5. Why do the bars of a histogram touch?
6. Why use frequency density instead of frequency when class widths are unequal?
7. Find the class width of 2.5 < h ≤ 4.
8. A histogram has three bars: density 2 for width 10, density 4 for width 5, and density 1 for width 20. Find the total frequency.
9. In the "small reminder" table above, which class is modal? Why is it not 15 < x ≤ 30?
10. A bar for 40 < t ≤ 60 has density 1.5. Estimate the number of values between 40 and 45.
11. A known bar of width 10 and frequency 30 is 6 cm tall. Another bar is 20 wide and 2 cm tall. Find its frequency.
12. All the classes of a histogram have width 5. How does the histogram compare with a bar chart of the frequencies?

### Answers

1. Width 15: 45 ÷ 15 = **3**.
2. 0.8 × 25 = **20**.
3. The **frequency** of that class.
4. **Frequency density.**
5. The data are **continuous**, so the classes meet with no gaps.
6. A wider class collects more values just because it is wide; density shows **how crowded** each class is.
7. **1.5.**
8. 20 + 20 + 20 = **60**.
9. **10 < x ≤ 15** (density 1.8, the tallest bar); 15 < x ≤ 30 has more values but is spread over a wider class.
10. 1.5 × 5 = **7.5**, so about 7 or 8 values (an estimate).
11. Density = 30 ÷ 10 = 3 for 6 cm, so 1 cm = 0.5; 2 cm = 1; 1 × 20 = **20**.
12. **Same shape**: every height is the frequency divided by 5.
