## Answers

**1. (a)** **2nd quadrant** **[1]**

**(b)** **4th quadrant** **[1]**

**(c)** **on the y-axis** (below the origin) **[1]**

**(d)** **3rd quadrant** **[1]** **[4]**

*Examiner insight:* A point with x = 0 or y = 0 is on an axis and is not in any quadrant.

**2. (a)** **D(-2, -3)** **[1]**

**(b)** width 4 - (-2) = 6 and height 1 - (-3) = 4 **[1]**; area = **24** square units **[1]** **[3]**

**3.** From B to C is 2 right and 3 up **[1]**; D = (1 + 2, 2 + 3) = **(3, 5)** **[1]** **[2]**

**4. (a)** **(3, 2)** **[1]**

**(b)** **(-3, -2)** **[1]** **[2]**

**5. (a)** **y = 4** **[1]**

**(b)** 5 - (-3) = **8** units **[1]** **[2]**

*Examiner insight:* The y-values are equal, so the line is horizontal. Subtracting a negative gives an addition.

**6.** **(-2, 3)** **[1]**

**7. (a)** **(6, 0)** **[1]**

**(b)** base 6, height 8 **[1]**; area = 1/2 × 6 × 8 = **24** square units **[1]** **[3]**

**8. (a)** AC = 4 - (-2) = **6** **[1]**; BD = 3 - (-3) = **6** **[1]**

**(b)** area = 1/2 × 6 × 6 = **18** square units **[1]** **[3]**

**9.** On the y-axis x = 0, so 2a - 6 = 0 **[1]**; **a = 3** **[1]**; y = 3 + 1 = 4, so the point is **(0, 4)** **[1]** **[3]**

**10.** 2 - 3 = -1 **[1]**; 5 - 4 = 1; the new point is **(-1, 1)** **[1]** **[2]**

**11.** The side length is 5 **[1]**; **C(5, 5)** and **D(0, 5)** **[1]** **[2]**

**12. (a)** **isosceles** **[1]**; R is on the y-axis above the midpoint of PQ, so RP = RQ **[1]**

**(b)** area = 1/2 × 8 × 6 = **24** square units **[1]** **[3]**

**13.** On the y-axis x = 0, so **k = 0** **[1]**; the y-coordinate is 2(0) - 1 = **-1** **[1]** **[2]**

**14.** y values: **-5, -3, -1, 1, 3, 5** **[2]** (one mark if one value is wrong); points (-2, -5), (-1, -3), (0, -1), (1, 1), (2, 3), (3, 5) **[1]** **[3]**

## Where marks are usually lost

- Swapping x and y in Questions 1 and 4.
- Placing (0, -5) in a quadrant in Question 1(c).
- Computing 5 - 3 = 2 instead of 5 - (-3) = 8 in Question 5.
- Reflecting in the wrong axis in Question 4.
- Forgetting that the diagonals of the kite lie along the axes and finding lengths by guesswork in Question 8.
- Setting y = 0 rather than x = 0 in Questions 9 and 13.

## Frequently asked questions

**How do I remember which number comes first?**
The x-coordinate comes first because you move along (across) before you move up or down. Think "along the corridor, up the stairs".

**What is the difference between the x-axis and the line x = 0?**
The x-axis is the line y = 0, the horizontal axis. The line x = 0 is the y-axis, the vertical axis.
