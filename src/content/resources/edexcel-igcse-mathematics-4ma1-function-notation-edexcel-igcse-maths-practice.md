## Section A

**1.** **(Higher tier only)** f(x) = 5x + 2.

**(a)** Find f(−3). **[1]**

**(b)** Solve f(x) = 27. **[2]**

**2.** **(Higher tier only)** g : x ↦ x² − 4x. Find g(−2). **[1]**

**3.** **(Higher tier only)** h(x) = 7/(2x − 6). State the value of x that must be excluded from the domain of h, and give a reason. **[1]**

**4.** **(Higher tier only)** f(x) = √(x + 9).

**(a)** State which values of x must be excluded from the domain of f. **[1]**

**(b)** State the range of f. **[1]**

**5.** **(Higher tier only)** f(x) = 2x − 1 and g(x) = x² + 3.

**(a)** Find fg(2). **[2]**

**(b)** Find gf(2). **[1]**

**6.** **(Higher tier only)** f(x) = (x − 4)/5. Find f⁻¹(x). **[2]**

## Section B

**7.** **(Higher tier only)** f(x) = 3x + 1 and g(x) = x².

**(a)** Find fg(x). **[1]**

**(b)** Find gf(x), giving your answer in expanded form. **[2]**

**(c)** Solve fg(x) = gf(x). **[3]**

**8.** **(Higher tier only)** f(x) = 6/(x − 2), x ≠ 2.

**(a)** Find f⁻¹(x). **[3]**

**(b)** State the value of x that must be excluded from the domain of f⁻¹. **[1]**

**9.** **(Higher tier only)** f(x) = 1 − 4x.

**(a)** Find ff(x) in its simplest form. **[2]**

**(b)** Solve ff(x) = 13. **[1]**

**10.** **(Higher tier only)** f(x) = x² + 6x + 10.

**(a)** Write f(x) in the form (x + p)² + q. **[2]**

**(b)** Hence state the range of f. **[1]**

**11.** **(Higher tier only)** g(x) = (x + 4)/(2x − 3), x ≠ 1.5. Find g⁻¹(x). **[4]**

**12.** **(Higher tier only)**

**(a)** f(x) = kx − 5, where k is a constant, and f⁻¹(7) = 4. Find k. **[2]**

**(b)** h(x) = x³. Find h⁻¹(−8). **[1]**

**13.** **(Higher tier only)** Explain why the rule "x maps to ±√x", for x > 0, does not define a function. **[1]**

## Answers

**1. (a)** 5(−3) + 2 = **−13** [1].

**(b)** 5x + 2 = 27 [1]; 5x = 25, **x = 5** [1].

**2.** (−2)² − 4(−2) = 4 + 8 = **12** [1].

**3.** **x = 3**, because 2(3) − 6 = 0 and division by zero is undefined [1].

**4. (a)** **x < −9**, because x + 9 would be negative and a negative number has no real square root [1].

**(b)** **f(x) ≥ 0** [1].

**5. (a)** g(2) = 7 [1]; f(7) = **13** [1].

**(b)** f(2) = 3, g(3) = **12** [1].

**6.** y = (x − 4)/5, so 5y = x − 4 and x = 5y + 4 [1]; **f⁻¹(x) = 5x + 4** [1].

**7. (a)** **fg(x) = 3x² + 1** [1].

**(b)** gf(x) = (3x + 1)² [1] = **9x² + 6x + 1** [1].

**(c)** 3x² + 1 = 9x² + 6x + 1 [1]; 0 = 6x² + 6x = 6x(x + 1) [1]; **x = 0 or x = −1** [1].

**8. (a)** y = 6/(x − 2), so y(x − 2) = 6 [1]; x − 2 = 6/y, x = 6/y + 2 [1]; **f⁻¹(x) = 6/x + 2** (or (2x + 6)/x) [1].

**(b)** **x = 0** [1].

**9. (a)** ff(x) = 1 − 4(1 − 4x) [1] = **16x − 3** [1].

**(b)** 16x − 3 = 13, so 16x = 16 and **x = 1** [1].

**10. (a)** (x + 3)² − 9 + 10 [1] = **(x + 3)² + 1** [1].

**(b)** (x + 3)² ≥ 0, so **f(x) ≥ 1** [1].

**11.** y(2x − 3) = x + 4 [1]; 2xy − 3y = x + 4, so 2xy − x = 3y + 4 [1]; x(2y − 1) = 3y + 4 [1]; **g⁻¹(x) = (3x + 4)/(2x − 1)** [1].

**12. (a)** f⁻¹(7) = 4 means f(4) = 7, so 4k − 5 = 7 [1]; **k = 3** [1].

**(b)** (−2)³ = −8, so **h⁻¹(−8) = −2** [1].

**13.** Each input (for example 9) would have two outputs (3 and −3), but a function gives exactly one output for each input [1].

## Where marks are usually lost

- Question 1(b): giving f(27) = 137 instead of solving for the input.
- Question 2: writing (−2)² as −4, or −4 × (−2) as −8, giving 4 or −4.
- Question 4(b): writing the range as x ≥ 0 or x ≥ −9. The range describes outputs, f(x).
- Question 5: working fg(2) as g(f(2)) = 12. In fg, g is applied first.
- Question 7(a): writing (3x + 1)² for fg(x), which is gf(x).
- Question 7(c): dividing both sides by x and losing the solution x = 0. Factorise instead.
- Question 8(a): stopping at x = 6/y + 2 without swapping the letters.
- Question 11: collecting terms but not factorising out x, so the answer still contains x on both sides.
- Question 12(a): finding the inverse function first. It works, but f(4) = 7 is quicker.

## Checking inverses

Every inverse on this page can be checked with one number. For question 6, f(9) = 1 and f⁻¹(1) = 5 + 4 = 9. For question 8, f(5) = 6/3 = 2 and f⁻¹(2) = 3 + 2 = 5. For question 11, g(2) = 6/1 = 6 and g⁻¹(6) = 22/11 = 2. If the number does not come back to where it started, re-check the rearrangement, especially the signs when the x terms were collected.
