These notes condense subtopic **1.18 Surds** of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. It is **Extended only**. The two statements are: understand and use surds, including simplifying expressions; and rationalise the denominator. Worked examples are in the [surds study guide](/resources/cambridge-igcse-mathematics-0580-surds-cambridge-igcse-maths/), and exam-style questions are in the [surds practice questions](/resources/cambridge-igcse-mathematics-0580-surds-cambridge-igcse-maths-practice/).

## Key terms

| Term | Meaning |
|---|---|
| Surd | A root that cannot be written as a whole number or fraction, such as √2 or √15 |
| Simplest form | No square factor (other than 1) left under the root |
| Like surds | Surds with the same number under the root, such as 3√5 and 7√5 |
| Exact answer | An answer left in surd form, not as a rounded decimal |
| Rationalise | Remove the surd from the denominator of a fraction |
| Conjugate | The same two terms with the sign between them changed: a + √b and a − √b |

## Rules

```
√a × √b = √(ab)        √a ÷ √b = √(a/b)        √a × √a = a
k√a × m√b = km√(ab)    (√a)^3 = a√a
√a + √b  is NOT  √(a + b)
```

## Simplifying: largest square factor

| Surd | Largest square factor | Simplest form |
|---|---|---|
| √98 | 49 | 7√2 |
| √180 | 36 | 6√5 |
| √128 | 64 | 8√2 |
| √20 | 4 | 2√5 (syllabus example) |

Squares to know: 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196, 225.

## Collecting

1. Simplify each surd.
2. Collect like surds as you would collect like terms.
3. Unlike surds stay separate: 2√3 + 4√2 cannot be simplified.

Syllabus example: √200 − √32 = 10√2 − 4√2 = **6√2**.

## Expanding

| Expression | Result |
|---|---|
| (a + √b)(a − √b) | a² − b (no surd) |
| (a + √b)² | a² + 2a√b + b |
| (√a + √b)² | a + b + 2√(ab) |
| (p + q√c)(r + s√c) | expand all four terms; q√c × s√c = qsc |

## Comparing sizes

Square both (or write each as a single root) and compare: 4√3 = √48 and 3√5 = √45, so 4√3 is larger.

## Rationalising

| Denominator | Multiply top and bottom by |
|---|---|
| √b | √b |
| k√b | √b (then simplify) |
| a + √b | a − √b |
| a − √b | a + √b |
| √a + √b | √a − √b |

Syllabus examples:

```
10/√5 = 10√5/5 = 2√5
1/(-1 + √3) = (1 + √3)/((-1 + √3)(1 + √3)) = (1 + √3)/2
```

After rationalising: expand the numerator if it has two terms, then cancel any common factor with the denominator.

## Worked reminders

**Expanding with surds in both brackets.** (2√3 − 1)(√3 + 4):

```
2√3 × √3 = 2 × 3 = 6        2√3 × 4 = 8√3
-1 × √3 = -√3               -1 × 4 = -4
6 + 8√3 - √3 - 4 = 2 + 7√3
```

**A negative denominator after rationalising.** (3 + √2)/(1 − √2):

```
multiply top and bottom by (1 + √2)
numerator:   (3 + √2)(1 + √2) = 3 + 3√2 + √2 + 2 = 5 + 4√2
denominator: 1 - 2 = -1
answer:      -(5 + 4√2) = -5 - 4√2
```

**A surd on top and bottom.** (√5 + 1)/(√5 − 1):

```
multiply top and bottom by (√5 + 1)
numerator:   (√5 + 1)^2 = 5 + 2√5 + 1 = 6 + 2√5
denominator: 5 - 1 = 4
answer:      (6 + 2√5)/4 = (3 + √5)/2
```

## Final checks on any surd answer

- Is the number under each root free of square factors?
- Have all like surds been collected?
- Is the denominator a whole number (if you were asked to rationalise)?
- Does every term in the numerator share a factor with the denominator? If so, cancel it.
- Is the answer in the exact form the question asks for, such as a + b√c?

## Exam traps

- √a + √b written as √(a + b).
- √72 written as 2√18 (not simplest form; it is 6√2).
- Unlike surds collected: 3√2 + √3 = 4√5.
- (2 + √3)² written as 4 + 3 = 7, missing 4√3.
- √5 × √5 written as 25.
- Only the denominator multiplied when rationalising.
- An answer such as 9√3/6 left unsimplified.
- A decimal given when an exact answer was required.

## Self-test

1. Simplify √98.
2. Simplify √180.
3. Simplify √50 + √8.
4. Simplify √63 − √28.
5. Simplify √6 × √15.
6. Expand and simplify (4 + √3)(4 − √3).
7. Expand and simplify (1 + √5)².
8. Simplify 2√3 × 5√3.
9. Rationalise the denominator of 12/√6.
10. Rationalise the denominator of 5/(2√10).
11. Rationalise the denominator of 4/(√7 + √3).
12. Which is larger, 4√3 or 3√5? Show how you know.

### Answers

1. 49 × 2: **7√2**
2. 36 × 5: **6√5**
3. 5√2 + 2√2 = **7√2**
4. 3√7 − 2√7 = **√7**
5. √90 = √(9 × 10) = **3√10**
6. 16 − 3 = **13**
7. 1 + 2√5 + 5 = **6 + 2√5**
8. 10 × 3 = **30**
9. 12√6/6 = **2√6**
10. 5√10/(2 × 10) = 5√10/20 = **√10/4**
11. 4(√7 − √3)/(7 − 3) = 4(√7 − √3)/4 = **√7 − √3**
12. (4√3)² = 48 and (3√5)² = 45, so **4√3** is larger
