These notes condense section 3.1.3, The periodic table, of the OxfordAQA International GCSE Chemistry (9202) specification, Version 6.2. For full explanations and worked examples, use the [periodic table study guide](/resources/oxfordaqa-igcse-chemistry-9202-the-periodic-table/); then try the [periodic table practice questions](/resources/oxfordaqa-igcse-chemistry-9202-the-periodic-table-practice/).

## Statements a to c in one line each

- **a** Arranged by atomic (proton) number; groups are columns of similar elements; "periodic" because similar properties recur at regular intervals; based on Mendeleev's work.
- **b** Same group → same number of outer electrons → similar chemical properties; grouping by properties allowed undiscovered elements to be predicted.
- **c** Group 0 noble gases are unreactive: stable electron arrangements; 8 outer electrons, helium 2.

## Layout

| Feature | Meaning |
|---|---|
| Order | increasing atomic number |
| Group (column) | same number of outer electrons; similar chemical properties |
| Period (row) | same number of occupied shells |
| Group number (1–7) | number of outer electrons |
| Group 0 | full, stable outer shell |

## Reading position from structure

```
outer electrons      → group number (1–7), or Group 0 if the shell is full
number of shells     → period number
sum of the digits    → atomic number → element
```

| Structure | Group | Period | Element |
|---|---|---|---|
| 2,1 | 1 | 2 | lithium |
| 2,8,2 | 2 | 3 | magnesium |
| 2,5 | 5 | 2 | nitrogen |
| 2,8,6 | 6 | 3 | sulfur |
| 2,8,8 | 0 | 3 | argon |
| 2,8,8,2 | 2 | 4 | calcium |

## Mendeleev in five points

1. Published his table in 1869, before protons, neutrons and electrons were known.
2. Arranged elements mainly by atomic mass **but** put elements with similar properties in the same group.
3. Swapped pairs where mass order did not fit properties, such as tellurium and iodine.
4. Left **gaps** for undiscovered elements.
5. **Predicted** their properties; later discoveries (such as gallium and germanium) matched.

Modern explanation: ordering by atomic number places tellurium (52) before iodine (53) even though tellurium's Ar is higher.

## Noble gases

| Element | Structure | Outer electrons |
|---|---|---|
| He | 2 | 2 |
| Ne | 2,8 | 8 |
| Ar | 2,8,8 | 8 |

- Unreactive: stable arrangement, no tendency to gain, lose or share electrons.
- Unknown in 1869; fitted in later as a whole new group.
- Other elements react in ways that give them the same stable arrangement as a noble gas.

## Worked recall: explaining similar properties

*Why do magnesium and calcium react in similar ways?*

```
Mg 2,8,2     Ca 2,8,8,2
both have 2 outer electrons → same group (Group 2)
reactions involve outer electrons → similar chemical properties
```

*Why is neon unreactive?* Neon is 2,8: eight outer electrons, a stable arrangement, so it does not gain, lose or share electrons.

## Periodic patterns at a glance

| Atomic number | Element | Outer electrons | Group |
|---|---|---|---|
| 3 | Li | 1 | 1 |
| 10 | Ne | 8 | 0 |
| 11 | Na | 1 | 1 |
| 18 | Ar | 8 | 0 |
| 19 | K | 1 | 1 |

The number of outer electrons rises along each period and then repeats: this repetition is why the table is "periodic".

## Key terms

| Term | Meaning |
|---|---|
| Atomic number | number of protons; the basis of the modern table's order |
| Group | vertical column of elements with similar properties |
| Period | horizontal row of elements |
| Outer electrons | electrons in the highest occupied energy level |
| Noble gases | unreactive Group 0 elements with stable electron arrangements |
| Periodic | repeating at regular intervals |
| Prediction | Mendeleev's description of the properties of undiscovered elements |

## Exam traps

- The modern table is ordered by **atomic number**, not atomic mass.
- Same **group** = same outer electrons; same **period** = same number of shells.
- Helium has **two** outer electrons, yet it is in Group 0.
- Mendeleev did **not** know about electrons or protons.
- Say "predicted properties" as well as "left gaps".
- "Similar properties" means similar **chemical** properties.
- Group 0 is not "Group 8" in this specification.

## Self-test

1. In what order are elements placed in the modern periodic table?
2. Why is the table called "periodic"?
3. Why do elements in the same group have similar chemical properties?
4. An element has structure 2,8,5. Give its group and period.
5. Which element is in Group 2, Period 2?
6. Give two ways in which Mendeleev's table differed from a simple list in order of atomic mass.
7. Why did Mendeleev leave gaps?
8. What evidence convinced chemists that Mendeleev's table was useful?
9. Why are noble gases unreactive?
10. How many outer electrons does helium have?
11. Explain how ordering by atomic number solves the problem of tellurium and iodine.
12. Why were the noble gases missing from Mendeleev's original table?

## Answers

1. Increasing atomic (proton) number.
2. Elements with similar properties occur at regular intervals.
3. They have the same number of electrons in their outer energy level.
4. Group 5, Period 3 (phosphorus).
5. Beryllium (2,2).
6. He grouped elements by similar properties, swapping some pairs out of mass order; he left gaps for undiscovered elements.
7. To keep elements with similar properties in the same group, leaving spaces for elements not yet discovered.
8. Elements discovered later had properties that matched his predictions.
9. Their atoms have stable arrangements of electrons (a full outer shell), so they do not easily gain, lose or share electrons.
10. Two.
11. Tellurium has atomic number 52 and iodine 53, so tellurium comes first, which matches their properties even though tellurium has the higher Ar.
12. They had not yet been discovered.
