These questions cover content statement **B11** of AQA A-level Mathematics (7357), Section B: Algebra and functions: "Use of functions in modelling, including consideration of limitations and refinements of the models." Every context and figure is invented. Give answers with units, and tie every limitation to the context. Revise from the [B11 study guide](/resources/aqa-a-level-mathematics-7357-b11-functions-in-modelling-aqa-alevel-maths/) and the [B11 revision notes](/resources/aqa-a-level-mathematics-7357-b11-functions-in-modelling-aqa-alevel-maths-revision-notes/).

## Section A

**1.** Distinguish between interpolation and extrapolation when using a model. **[2]**

**2.** A quantity y takes the values 4, 10, 20, 34 when t = 0, 1, 2, 3.

**(a)** Show that a quadratic model is suitable. **[1]**

**(b)** Find the model in the form y = a + bt + ct². **[3]**

**3.** A taxi fare £F for a journey of d km is modelled by F = a + bd. A 3 km journey costs £8.10 and a 10 km journey costs £18.60.

**(a)** Find a and b. **[3]**

**(b)** Interpret a and b in context. **[2]**

**4.** A model predicts a value of 18.4 when the observed value is 20. Find the percentage error. **[2]**

**5.** The number of people N in a queue t minutes after a ticket office opens is modelled by N = 40 − 3t. State, with reasons, the values of t for which the model can be used. **[2]**

**6.** The value £V of a car t years after purchase is modelled by V = 20 000 − 2500t. Give one limitation of the model and suggest a refinement. **[2]**

## Section B

**7.** A drone flies at a constant height along a straight line that passes directly over a sensor. Its horizontal distance d metres from the sensor t seconds after it is first tracked is modelled by d = |300 − 12t|, for 0 ≤ t ≤ 50.

**(a)** Find the time at which the drone is directly above the sensor. **[1]**

**(b)** Find the times at which d = 60. **[2]**

**(c)** State the speed of the drone. **[1]**

**(d)** The sensor detects the drone when d ≤ 90. Find how long the drone is detected for. **[2]**

**(e)** Give one limitation of the model. **[1]**

**8.** The average cost £C per delegate for a training day with n delegates is modelled by C = a + b/n. With 25 delegates the average cost is £68; with 100 it is £38.

**(a)** Find a and b. **[3]**

**(b)** Interpret a and b in context. **[2]**

**(c)** The venue holds at most 150 delegates. Find the lowest possible average cost, to the nearest penny. **[1]**

**(d)** Explain why the model cannot be used when n = 0. **[1]**

**9.** The data below are collected.

| x | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| y | 10 | 13 | 18 | 25 | 34 |

Model A is y = 10 + 6x. Model B is y = 10 + 2x + x².

**(a)** Find the largest error of Model A over the data, and give it as a percentage of the observed value. **[2]**

**(b)** Show that Model B fits every data point. **[2]**

**(c)** Use both models to predict y when x = 10, and comment on the reliability of these predictions. **[3]**

**10.** The depth h cm of water in a tank t minutes after a drain is opened is modelled by h = 0.05(t − 40)², for 0 ≤ t ≤ 40.

**(a)** State the depth when the drain is opened. **[1]**

**(b)** Find the time at which the depth is 20 cm. **[2]**

**(c)** Explain why the model must not be used for t > 40. **[1]**

**(d)** Suggest how the model could be extended for t > 40. **[1]**

**11.** A phone plan's monthly cost £C for m minutes of calls is modelled by C = 12 for 0 ≤ m ≤ 300, and C = 12 + 0.05(m − 300) for m > 300.

**(a)** Find the cost for 420 minutes. **[1]**

**(b)** Find the number of minutes that costs £20. **[2]**

**(c)** Show that the two rules give the same cost at m = 300. **[1]**

**(d)** A customer claims that "the more you call, the cheaper each minute becomes". Test this claim using m = 300 and m = 600. **[2]**

**12.** A shop models the weekly sales S of a new game in week w after its release by S = 600/w, for w ≥ 1.

**(a)** Find the predicted sales in week 4. **[1]**

**(b)** Find the total predicted sales for weeks 1 to 4. **[2]**

**(c)** State two limitations of the model. **[2]**

**(d)** Suggest one refinement. **[1]**

## Answers

**1.** Interpolation is predicting for an input inside the range of the data used to build the model [1]; extrapolation is predicting outside that range, where the pattern may not continue, so it is less reliable [1].

**2. (a)** First differences 6, 10, 14; second differences 4 and 4 are constant, so a quadratic fits [1].

**(b)** t = 0 gives a = 4 [1]. The second difference is 2c = 4, so c = 2 [1]. t = 1: 4 + b + 2 = 10, so b = 4: **y = 4 + 4t + 2t²** [1].

*Examiner insight:* test the model on the last point: 4 + 12 + 18 = 34. A check like this catches an arithmetic slip before it spoils later parts.

**3. (a)** a + 3b = 8.10 and a + 10b = 18.60 [1]. Subtracting: 7b = 10.50, so **b = 1.5** [1] and **a = 3.60** [1].

**(b)** a: a fixed charge of £3.60 for any journey [1]. b: £1.50 for each kilometre travelled [1].

**4.** Error = 20 − 18.4 = 1.6 [1]; 1.6/20 × 100 = **8%** [1].

**5.** N must not be negative: 40 − 3t ≥ 0 gives t ≤ 13⅓, so the model is for 0 ≤ t ≤ 13⅓ minutes [1]. N must be a whole number, so outputs should be rounded, and the model assumes people leave at a steady rate with nobody joining [1].

**6.** Limitation: the value falls by the same £2,500 every year and becomes negative after 8 years, which cannot happen [1]. Refinement: use a model whose value falls by a smaller amount each year and never goes below zero, or set V to a minimum (scrap) value after a stated time [1].

**7. (a)** 300 − 12t = 0, so **t = 25 s** [1].

**(b)** 300 − 12t = 60 or 300 − 12t = −60 [1], so **t = 20 s or t = 30 s** [1].

**(c)** **12 m/s** (the size of the gradient) [1].

**(d)** |300 − 12t| ≤ 90 gives 210 ≤ 12t ≤ 390, so 17.5 ≤ t ≤ 32.5 [1]. Detected for **15 seconds** [1].

**(e)** For example: the drone is assumed to fly at constant speed in an exactly straight line; wind or a change of speed would alter the times [1].

**8. (a)** a + b/25 = 68 and a + b/100 = 38 [1]. Subtracting: b(1/25 − 1/100) = 30, so b × 3/100 = 30 and **b = 1000** [1]. Then a = 68 − 40 = **28** [1].

**(b)** Total cost = nC = 28n + 1000 [1]: £28 per delegate (for example, food and materials) and a fixed £1,000 (for example, room hire) [1].

**(c)** n = 150: C = 28 + 1000/150 = **£34.67** [1].

**(d)** 1000/n is undefined at n = 0; with no delegates there is no average cost per delegate [1].

**9. (a)** Model A gives 10, 16, 22, 28, 34; the errors are 0, −3, −4, −3, 0, so the largest is 4 at x = 2 [1]. As a percentage: 4/18 × 100 = **22.2%** [1].

**(b)** x = 1: 10 + 2 + 1 = 13; x = 2: 10 + 4 + 4 = 18 [1]. x = 3: 10 + 6 + 9 = 25; x = 4: 10 + 8 + 16 = 34; and x = 0 gives 10. All five match [1].

**(c)** Model A: 10 + 60 = **70**. Model B: 10 + 20 + 100 = **130** [1]. B fits the data much better [1], but x = 10 is well outside the data range, so both are extrapolations; the large difference between them shows how uncertain the prediction is [1].

*Examiner insight:* a comparison earns more when it says both which model fits better and why neither prediction can be fully trusted.

**10. (a)** h = 0.05 × 1600 = **80 cm** [1].

**(b)** (t − 40)² = 400 [1]. t − 40 = −20, taking the negative root because t ≤ 40, so **t = 20 minutes** [1].

**(c)** For t > 40 the formula increases again, predicting that the tank refills while the drain is open [1].

**(d)** Set h = 0 for t > 40, since the tank stays empty [1].

**11. (a)** 12 + 0.05 × 120 = **£18** [1].

**(b)** 12 + 0.05(m − 300) = 20, so 0.05(m − 300) = 8 [1] and **m = 460** [1].

**(c)** At m = 300 the second rule gives 12 + 0 = 12, the same as the first [1].

**(d)** m = 300: 12/300 = £0.04 per minute. m = 600: C = 12 + 15 = £27, and 27/600 = £0.045 per minute [1]. The cost per minute is higher at 600 minutes, so the claim is false beyond 300 minutes [1].

**12. (a)** 600/4 = **150** [1].

**(b)** 600 + 300 + 200 + 150 [1] = **1250** [1].

**(c)** Any two, tied to the context: sales are assumed to be highest in week 1 and fall every week, but a sale, review or holiday could raise them [1]; the model never reaches zero, and it can give non-integer sales, such as 600/7 = 85.7 [1].

**(d)** For example: add a term for a later boost such as a holiday period, or fit the constant using more weeks of real sales data [1].

## Where marks are usually lost

- Answers with no units or no sentence in context.
- Limitations stated in general terms, with no link to the situation.
- Refinements that do not say what to change.
- Using the wrong root when solving inside a restricted domain.
- Ignoring the domain when a model gives negative or impossible values.
- Comparing models on fit alone, without commenting on extrapolation.
