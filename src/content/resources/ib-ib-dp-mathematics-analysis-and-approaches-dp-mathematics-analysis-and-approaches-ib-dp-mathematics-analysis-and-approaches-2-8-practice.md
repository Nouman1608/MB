This practice set covers section 2.8 of IB Diploma Programme Mathematics: Analysis and Approaches: the reciprocal function and rational functions of the form (ax + b)/(cx + d). It is for SL and HL. Questions are calculator-free unless labelled, matching Paper 1. For sketch questions the answers list the features a full-mark sketch must show.

## Section A

**1.** Let f(x) = 1/x, x ≠ 0.

**(a)** Write down the equations of the asymptotes of the graph of f. **[2]**
**(b)** Show that f is self-inverse. **[1]**

**2.** Let f(x) = (x + 4)/(x − 3), x ≠ 3.

**(a)** Write down the equations of the asymptotes. **[2]**
**(b)** Find the coordinates of the intercepts with the axes. **[2]**

**3.** Write down the domain and range of g(x) = (5x − 1)/(2x − 4). **[2]**

**4.** The graph of f(x) = (ax + 3)/(x + d) has asymptotes x = −2 and y = 4. Write down the values of a and d. **[2]**

**5.** Find the coordinates of the points where y = 8/x meets y = 2x. **[3]**

**6.** **(a)** Show that (2x + 7)/(x + 3) = 2 + 1/(x + 3). **[2]**
**(b)** Hence describe the transformation that maps y = 1/x onto y = (2x + 7)/(x + 3). **[2]**

## Section B

**7.** Let f(x) = (4x + 2)/(x − 1), x ≠ 1.

**(a)** Write down the equations of the asymptotes. **[2]**
**(b)** Find the intercepts with the axes. **[2]**
**(c)** Sketch the graph of f. **[2]**
**(d)** Find f⁻¹(x) and write down the equations of the asymptotes of its graph. **[3]**

**8.** (calculator allowed) In an invented model, the time in minutes to fill a 240-litre tank at a constant rate of r litres per minute is T(r) = 240/r, for r > 0.

**(a)** Find T(30). **[1]**
**(b)** Find the rate needed to fill the tank in 6 minutes. **[1]**
**(c)** Interpret the two asymptotes of the graph of T in this context. **[2]**
**(d)** Explain why only the branch r > 0 is used. **[1]**
**(e)** The model becomes T(r) = 240/r + 5 when a setting-up time is included. Interpret the new horizontal asymptote. **[1]**

**9.** Let f(x) = 6/(x + 1), x ≠ −1, and g(x) = x + 2.

**(a)** Write down the equations of the asymptotes of the graph of f. **[2]**
**(b)** Find the coordinates of the points where the graphs of f and g meet. **[4]**

**10.** A graph has equation y = (ax + b)/(x + d), asymptotes x = −3 and y = 2, and passes through (0, 1).

**(a)** Find a, b and d. **[4]**
**(b)** Find the x-intercept of the graph. **[1]**

**11.** Let f(x) = (3x + 5)/(x − 3), x ≠ 3.

**(a)** Show that f is its own inverse. **[3]**
**(b)** State what this implies about the graph of f. **[1]**
**(c)** Find the exact x-coordinates of the points where the graph of f meets the line y = x. **[2]**

**12.** Let g(x) = 3/(x − 2) − 1, x ≠ 2.

**(a)** Write down the equations of the asymptotes of the graph of g. **[2]**
**(b)** Find the intercepts with the axes. **[2]**
**(c)** Write g(x) as a single fraction in the form (ax + b)/(cx + d). **[1]**

## Answers

**1. (a)** **x = 0** [1] and **y = 0** [1]
**(b)** f(f(x)) = 1/(1/x) = x, so f⁻¹ = f [1]

**2. (a)** **x = 3** [1]; **y = 1** [1]
**(b)** **(0, −4/3)** [1]; **(−4, 0)** [1]

**3.** Domain **x ≠ 2** [1]; range **y ≠ 5/2** [1]

**4.** **a = 4** [1]; **d = 2** [1]

**5.** 8/x = 2x gives x² = 4 [1], so x = ±2 [1]: **(2, 4) and (−2, −4)** [1]

**6. (a)** 2 + 1/(x + 3) = (2(x + 3) + 1)/(x + 3) [1] = (2x + 7)/(x + 3) [1]
**(b)** Translation **3 units left** [1] and **2 units up** [1]

**7. (a)** **x = 1** [1]; **y = 4** [1]
**(b)** **(0, −2)** [1]; **(−1/2, 0)** [1]
**(c)** Dashed, labelled asymptotes with the intercepts marked [1]; branches in the bottom-left and top-right regions, approaching both asymptotes [1]
**(d)** y(x − 1) = 4x + 2 gives x(y − 4) = y + 2 [1], so **f⁻¹(x) = (x + 2)/(x − 4)** [1]; asymptotes **x = 4 and y = 1** [1]

**8. (a)** **8 minutes** [1]
**(b)** 240/r = 6 gives **r = 40 litres per minute** [1]
**(c)** r = 0: as the rate approaches 0, the filling time grows without limit [1]. T = 0: faster rates give shorter times, but the time never reaches 0 [1]
**(d)** Rates and times must be positive [1]
**(e)** T = 5: however fast the water flows, the job takes at least 5 minutes [1]

**9. (a)** **x = −1** [1]; **y = 0** [1]
**(b)** 6/(x + 1) = x + 2, so 6 = (x + 1)(x + 2) [1]; x² + 3x − 4 = 0 [1]; (x + 4)(x − 1) = 0 [1]; points **(1, 3) and (−4, −2)** [1]

**10. (a)** **d = 3** [1]; **a = 2** [1]; f(0) = b/3 = 1 [1], so **b = 3** [1]
**(b)** 2x + 3 = 0 gives **(−3/2, 0)** [1]

**11. (a)** y(x − 3) = 3x + 5 [1]; x(y − 3) = 3y + 5 [1]; x = (3y + 5)/(y − 3), so f⁻¹(x) = (3x + 5)/(x − 3) = f(x) [1]
**(b)** The graph is symmetric about the line y = x [1]
**(c)** (3x + 5)/(x − 3) = x gives x² − 6x − 5 = 0 [1], so **x = 3 ± √14** [1]

**12. (a)** **x = 2** [1]; **y = −1** [1]
**(b)** g(0) = −3/2 − 1 = −5/2, so **(0, −5/2)** [1]; 3/(x − 2) = 1 gives **(5, 0)** [1]
**(c)** (3 − (x − 2))/(x − 2) = **(5 − x)/(x − 2)** [1]

## Where marks are usually lost

- Horizontal asymptote taken as b/d or a instead of a/c.
- Asymptotes written as numbers, or drawn solid and unlabelled.
- Branches drawn in the wrong pair of regions.
- Forgetting that the asymptotes of an inverse are swapped.
- Missing the meaning of an asymptote in a context question.
