## Key terms

| Term | Meaning |
|---|---|
| Nucleotide | Monomer of a nucleic acid: phosphate + pentose + nitrogenous base |
| Pentose | Five-carbon sugar: deoxyribose in DNA, ribose in RNA |
| Sugar–phosphate backbone | Chain of alternating sugars and phosphates joined by covalent bonds |
| Condensation | Reaction joining two molecules with release of water |
| Complementary base pairing | A with T (or U in RNA), C with G, by hydrogen bonds |
| Antiparallel | The two DNA strands run in opposite directions |
| Double helix | Two DNA strands wound around each other |
| Purine (HL) | Double-ring base: adenine, guanine |
| Pyrimidine (HL) | Single-ring base: cytosine, thymine, uracil |
| Nucleosome (HL) | DNA wound around a core of eight histone proteins |
| Directionality (HL) | Each strand has a 5′ end and a 3′ end |

## A1.2.1 to A1.2.5: building blocks

- DNA is the genetic material of all living organisms; some viruses use RNA, but viruses are not living.
- Nucleotide: base on carbon 1′, phosphate on carbon 5′, –OH on carbon 3′ links to the next phosphate.
- Diagram shapes: circle (phosphate), pentagon (sugar), rectangle (base).
- Condensation links phosphate to the 3′ carbon of the previous sugar, releasing water.
- Backbone is all covalent, so the base sequence is stable.
- The base sequence is the code; only the bases vary.
- RNA: a polymer made by condensation of nucleotides, usually single-stranded.

**Counting rule.** A strand of n nucleotides has n − 1 sugar–phosphate links and released n − 1 water molecules when it formed.

## A1.2.6 and A1.2.7: DNA compared with RNA

| | DNA | RNA |
|---|---|---|
| Strands | Two, antiparallel, double helix | One |
| Sugar | Deoxyribose | Ribose |
| Bases | A, T, C, G | A, U, C, G |
| Strands held by | Hydrogen bonds between bases | (single strand) |

## A1.2.8: why pairing matters

- **Replication**: each strand is a template; only the complementary nucleotide fits.
- **Transcription**: mRNA copies the template strand's sequence (U opposite A).
- **Translation**: tRNA anticodons pair with mRNA codons.
- Hydrogen bonds are weak, so strands separate and re-form; the covalent backbone stays intact.

## Base composition sums

For **double-stranded DNA**: A = T, G = C, and A + T + G + C = 100%.

**Worked reminder.** G = 18%. Then C = 18%, A + T = 64%, A = T = 32%.

If A ≠ T or G ≠ C, the nucleic acid is single-stranded. If U is present and T is absent, it is RNA.

## A1.2.9 and A1.2.10: information and ancestry

- n bases give 4ⁿ possible sequences: 4³ = 64 codons, 4⁸ = 65 536.
- Sequences can be any length and any order: capacity is effectively limitless.
- The genetic code is shared by almost all life: evidence for universal common ancestry.

## A1.2.11 to A1.2.13 (HL only)

- **5′ end**: free phosphate; **3′ end**: free –OH.
- Nucleotides are added to the 3′ end, so synthesis runs 5′ → 3′.
- Strands are antiparallel: the 5′ end of one lies opposite the 3′ end of the other.
- Every pair is purine + pyrimidine, so the helix has a constant width.
- Nucleosome: eight histones in the core; another histone on linker DNA; positive histones attract negative phosphates.

## A1.2.14 and A1.2.15 (HL only): the evidence

| Evidence | What was done or found | Conclusion and limit |
|---|---|---|
| Hershey–Chase | ³⁵S labelled phage protein, ³²P labelled phage DNA; blender, then centrifuge | ³²P entered bacteria, ³⁵S stayed outside: supports DNA as genetic material; not every count was clean |
| Chargaff | A ≈ T, G ≈ C across species; (A + T) ÷ (G + C) varies by species | Falsified the tetranucleotide hypothesis; observations alone cannot prove a universal rule |

**Why those isotopes?** Sulfur is in protein but not DNA; phosphorus is in DNA but not protein. Each label marks only one molecule.

## Exam traps

- Bases placed in the backbone.
- Strands said to be joined covalently.
- Thymine or deoxyribose placed in RNA.
- A = T applied to RNA.
- Forgetting to write a complementary strand in the 5′ → 3′ direction.
- "Chargaff proved base pairing": his data were consistent with it and falsified a rival idea.

## Quick self-test

1. Name the three parts of a nucleotide.
2. To which carbon of the pentose is the base attached?
3. What type of reaction joins nucleotides, and what is released?
4. Give two structural differences between DNA and RNA other than the number of strands.
5. Why can DNA strands separate easily but keep their base sequence?
6. A double-stranded DNA sample has 35% thymine. Give the percentage of guanine.
7. A sample contains 27% A, 19% U, 30% G and 24% C. What kind of nucleic acid is it?
8. How many sequences are possible for a stretch of 5 bases?
9. Why is the universal genetic code evidence for common ancestry?
10. (HL) Why do all base pairs have the same width?
11. (HL) Why did Hershey and Chase use ³⁵S and ³²P?
12. (HL) Which hypothesis did Chargaff's data falsify?

### Answers

1. Phosphate, pentose sugar, nitrogenous base.
2. Carbon 1′.
3. Condensation; water.
4. Deoxyribose in DNA but ribose in RNA; thymine in DNA but uracil in RNA.
5. Hydrogen bonds between bases are weak; the backbone is held by strong covalent bonds.
6. A = 35%, so A + T = 70%, G + C = 30%, G = **15%**.
7. Single-stranded RNA (uracil present; A ≠ U, G ≠ C).
8. 4⁵ = **1024**.
9. The same codons code for the same amino acids in almost all organisms, which is best explained by inheritance from one ancestor.
10. Each pair is one double-ring purine with one single-ring pyrimidine.
11. Sulfur occurs only in the protein and phosphorus only in the DNA, so each label tracked one molecule.
12. The tetranucleotide hypothesis.
