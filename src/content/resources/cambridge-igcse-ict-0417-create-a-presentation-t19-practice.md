## Section A: short answers

**1.** When a text file is imported into presentation software, what does a line with no indentation become?

A: a bullet point

B: a slide title

C: presenter notes

D: a footer **[1]**

**2.** State the character used at the start of a line in a .txt file to make it a bullet point. **[1]**

**3.** Give **two** reasons for creating a presentation from an existing text file rather than typing the content. **[2]**

**4.** A text file contains six lines with no tab, ten lines with one tab and four lines with two tabs. State how many slides are created. **[1]**

**5.** In a rich text file, state how the software decides which lines become slide titles. **[1]**

**6.** State what is meant by *demoting* a line in a presentation outline. **[1]**

## Section B: structured questions

**7.** A file called *museum.txt* contains:

```
Welcome to the Museum
[tab]Open daily from 10:00
Galleries
[tab]Ancient World
[tab][tab]Pottery and coins
[tab]Modern Art
Visitor Information
[tab]Café on the ground floor
```

**(a)** State the number of slides created when the file is imported.

**(b)** State the title of the second slide.

**(c)** Describe how *Pottery and coins* will appear on its slide. **[4]**

**8.** Ravi starts a new blank presentation and inserts slides from an outline file that has four top-level lines. His presentation now has five slides.

**(a)** Explain why there are five slides.

**(b)** Describe how he should correct this.

**(c)** A later task says "Insert an image on slide 3". Explain why not correcting the problem could lose marks. **[5]**

**9.** After importing a file, a student sees that the line *Booking essential* has become the title of a new slide, but it should be a bullet on the slide before it.

**(a)** Suggest the most likely cause in the original .txt file.

**(b)** Describe how to correct the slide in the presentation software. **[3]**

**10.** A presentation is created from a rich text file. The imported text appears in a different font and colour from the one the task later sets on the master slide.

**(a)** Explain why this happens.

**(b)** Describe what the student should do so that the master slide formatting is applied to every slide. **[3]**

**11.** Write the content of a .txt file, using "[tab]" for each tab, that would create these two slides:

- Slide 1: title *Healthy Lunches*, with bullets *Fruit every day* and *Water not fizzy drinks*.
- Slide 2: title *Menu Ideas*, with the bullet *Wraps*, and under it the sub-bullet *Chicken and salad*. **[4]**

**12.** A teacher has written lesson notes in a word processor and asks a technician to make a slide presentation from them.

Describe the steps the technician should take to create the presentation from the notes and check that it is correct. **[6]**

## Answers

**1.** B: a slide title. **[1]**

**2.** The tab character (1). **[1]**

**3.** Any two, 1 mark each: it is faster because the text does not need to be retyped (1); it is more accurate because no new typing errors are introduced (1); the structure of titles and bullets is kept (1); the content can be written by one person and the presentation designed by another (1). **[2]**

**4.** Six (1). **[1]**

**5.** From the heading styles or outline levels: lines in the top heading style (for example Heading 1) become titles (1). **[1]**

**6.** Moving the line down one level in the hierarchy, for example from a bullet to a sub-bullet (1). **[1]**

**7. (a)** Three slides (1).

**(b)** *Galleries* (1).

**(c)** As a second-level bullet (1), indented under the bullet *Ancient World* on the *Galleries* slide (1). **[4]**

**8. (a)** A new blank presentation already contains one empty title slide (1); the four imported slides were added after it, giving five (1).

**(b)** Select the empty first slide and delete it (1).

**(c)** With the blank slide still present, every imported slide is numbered one higher than intended (1), so the image would be placed on the wrong slide, which was meant to be slide 2 (1). **[5]**

**9. (a)** The line had no tab at the start, or was indented with spaces instead of a tab (1).

**(b)** Select the line (1) and demote it one level, for example using the Tab key or the demote command, so it becomes a bullet on the previous slide (1). **[3]**

**10. (a)** The rich text file carried its own font and colour formatting into the slides (1), and this local formatting overrides the master slide (1).

**(b)** Reset the slides (select all slides and use the reset command) so that they take their formatting from the master slide (1). **[3]**

**11.**
```
Healthy Lunches
[tab]Fruit every day
[tab]Water not fizzy drinks
Menu Ideas
[tab]Wraps
[tab][tab]Chicken and salad
```
1 mark each: both titles with no tab (1); the two bullets on slide 1 with one tab each (1); *Wraps* with one tab under *Menu Ideas* (1); *Chicken and salad* with two tabs (1). **[4]**

**12.** Any six, 1 mark each:
- Check or apply heading styles in the notes so titles are Heading 1 and points are Heading 2 (or save as a text file with tabs for levels) (1).
- Open the file as an outline, or insert slides from the outline into a new presentation (1).
- Delete any empty first slide left from the new presentation (1).
- Check there is one slide for each top-level heading (1).
- Check each title is in the title placeholder (1).
- Check bullets are under the correct titles at the correct levels; promote or demote any that are wrong (1).
- Remove empty slides or empty bullet lines (1).
- Check the text matches the notes exactly (1).
- Reset slides so they follow the master slide (1).
- Save the presentation in the presentation software's format with a suitable name (1). **[6]**

## Frequently asked questions

**Does it matter whether the file is .txt or .rtf?**
Both can be used. In a .txt file levels come from tabs; in a .rtf file they usually come from heading styles, and formatting may be carried across, so reset the slides afterwards.

**Should I correct mistakes I notice in the supplied text?**
Only if the task tells you to. The text on the slides is expected to match the file supplied.
