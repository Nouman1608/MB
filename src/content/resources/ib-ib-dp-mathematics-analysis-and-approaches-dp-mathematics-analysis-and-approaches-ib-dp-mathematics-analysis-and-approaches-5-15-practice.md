These questions cover **section 5.15 of IB DP Mathematics: Analysis and Approaches: derivatives and indefinite integrals of further functions, composites with a linear function, and partial fractions**. It is AHL content, for HL students. All questions are calculator-free.

Learn the methods first in the [section 5.15 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-5-15/) and the [section 5.15 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-5-15-revision-notes/).

## Section A

**1.** Differentiate y = sec 4x. **[2]**

**2.** Differentiate y = arctan(√x), for x > 0, simplifying your answer. **[3]**

**3.** Differentiate y = 5^(3x). **[2]**

**4.** Differentiate y = x² log₃ x, for x > 0. **[3]**

**5.** Find ∫ cosec²(3x) dx. **[2]**

**6.** Find ∫ 1/(25 + x²) dx. **[2]**

## Section B

**7.** **(a)** By writing cos y = x, show that d/dx(arccos x) = −1/√(1 − x²), for 0 < y < π. **[3]**
**(b)** Find ∫ 3/√(16 − x²) dx, for |x| < 4. **[2]**

**8.** **(a)** Express (2x + 7)/(x² + 5x + 6) in partial fractions. **[3]**
**(b)** Hence find ∫ (2x + 7)/(x² + 5x + 6) dx. **[2]**
**(c)** Show that ∫₀¹ (2x + 7)/(x² + 5x + 6) dx = ln(81/32). **[3]**

**9.** **(a)** By completing the square, find ∫ 1/(x² − 6x + 13) dx. **[4]**
**(b)** Hence find the exact value of ∫₃⁵ 1/(x² − 6x + 13) dx. **[2]**

**10.** A curve y = f(x) has gradient f′(x) = 3ˣ and passes through the point (0, 2/ln 3). Find f(x). **[4]**

**11.** **(a)** Use an identity to find ∫ cot²x dx. **[3]**
**(b)** Hence find the exact value of ∫ from π/4 to π/2 of cot²x dx. **[3]**

**12.** Let y = x arctan x.

**(a)** Find dy/dx. **[2]**
**(b)** Show that d²y/dx² = 2/(1 + x²)². **[3]**

**13.** Find the exact value of ∫₀^√3 1/(3 + x²) dx. **[3]**

**14.** **(a)** Differentiate y = arcsin(3x). **[2]**
**(b)** Hence find ∫ 1/√(1 − 9x²) dx, for |x| < 1/3. **[2]**

**15.** **(a)** Express 6/(x² − 9) in partial fractions. **[3]**
**(b)** Hence find ∫ 6/(x² − 9) dx, for x > 3. **[2]**
**(c)** Explain why the method of part (a) cannot be used for ∫ 6/(x² + 9) dx, and find that integral. **[3]**

## Answers

**1.** Chain rule: sec 4x tan 4x × 4 [1]; **dy/dx = 4 sec 4x tan 4x** [1] **[2]**

**2.** 1/(1 + (√x)²) [1] × 1/(2√x) [1]; **dy/dx = 1/(2√x(1 + x))** [1] **[3]**

**3.** 5^(3x) ln 5 × 3 [1]; **dy/dx = 3 ln 5 · 5^(3x)** [1] **[2]**

**4.** Product rule: 2x log₃ x + x² × 1/(x ln 3) [1] [1]; **dy/dx = 2x log₃ x + x/ln 3** [1] **[3]**

**5.** ∫ cosec²x dx = −cot x [1]; **−(1/3) cot 3x + C** [1] **[2]**

**6.** a = 5 [1]; **(1/5) arctan(x/5) + C** [1] **[2]**

**7. (a)** −sin y dy/dx = 1 [1]; sin y = √(1 − cos²y) = √(1 − x²), positive for 0 < y < π [1]; dy/dx = −1/√(1 − x²) [1]
**(b)** **3 arcsin(x/4) + C** [1] [1] (−3 arccos(x/4) + C is equivalent) **[5]**

**8. (a)** (2x + 7)/((x + 2)(x + 3)) = A/(x + 2) + B/(x + 3) [1]; x = −2: A = 3 [1]; x = −3: B = −1 [1]
**(b)** **3 ln|x + 2| − ln|x + 3| + C** [1] [1]
**(c)** [3 ln(x + 2) − ln(x + 3)]₀¹ = (3 ln 3 − ln 4) − (3 ln 2 − ln 3) [1] = 4 ln 3 − 5 ln 2 [1] = ln(81/32) [1] **[8]**

**9. (a)** x² − 6x + 13 = (x − 3)² + 4 [1]; form 1/(u² + 2²) with u = x − 3 [1]; **(1/2) arctan((x − 3)/2) + C** [1] [1]
**(b)** (1/2)[arctan 1 − arctan 0] [1] = **π/8** [1] **[6]**

**10.** f(x) = 3ˣ/ln 3 + C [1] [1]; f(0) = 1/ln 3 + C = 2/ln 3, so C = 1/ln 3 [1]; **f(x) = (3ˣ + 1)/ln 3** [1] **[4]**

**11. (a)** cot²x = cosec²x − 1 [1]; ∫ (cosec²x − 1) dx [1] = **−cot x − x + C** [1]
**(b)** [−cot x − x] from π/4 to π/2 = (0 − π/2) − (−1 − π/4) [1] [1] = **1 − π/4** [1] **[6]**

**12. (a)** Product rule: **dy/dx = arctan x + x/(1 + x²)** [1] [1]
**(b)** d/dx arctan x = 1/(1 + x²) [1]; quotient rule: d/dx[x/(1 + x²)] = (1 + x² − 2x²)/(1 + x²)² = (1 − x²)/(1 + x²)² [1]; sum = (1 + x² + 1 − x²)/(1 + x²)² = 2/(1 + x²)² [1] **[5]**

**13.** a = √3: anti-derivative (1/√3) arctan(x/√3) [1]; (1/√3)(arctan 1 − arctan 0) [1] = **π/(4√3)** (= √3π/12) [1] **[3]**

**14. (a)** Chain rule: 1/√(1 − (3x)²) × 3 [1]; **dy/dx = 3/√(1 − 9x²)** [1]
**(b)** The integrand is (1/3) of the derivative in (a) [1]; **(1/3) arcsin(3x) + C** [1] **[4]**

**15. (a)** x² − 9 = (x − 3)(x + 3) [1]; 6/((x − 3)(x + 3)) = A/(x − 3) + B/(x + 3): A = 6/6 = 1 [1], B = 6/(−6) = −1 [1]
**(b)** **ln(x − 3) − ln(x + 3) + C** = ln((x − 3)/(x + 3)) + C [1] [1]
**(c)** x² + 9 has no real roots, so it does not factorise into real linear factors [1]; it is the arctan form with a = 3 [1]: **2 arctan(x/3) + C** [1] **[8]**
*Examiner insight:* The two integrands differ only by a sign in the denominator, yet one gives logarithms and the other an inverse tangent; checking the discriminant first decides the method.

## How this set builds

Questions 1 to 6 practise each new derivative and integral once. Questions 7 and 12 ask you to derive or combine results rather than quote them. Questions 8, 9 and 15 are the rational-integrand decision in action: factorise and use partial fractions, or complete the square and use arctan. Questions 10, 11 and 13 add boundary conditions, identities and exact definite values.
