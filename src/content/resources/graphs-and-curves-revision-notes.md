## Recognising the shape from the equation

| Equation | Shape | Key features |
|---|---|---|
| y = mx + c | Straight line | Gradient m, y-intercept c |
| y = ax² + bx + c | **Parabola** | a > 0 opens up (∪), a < 0 opens down (∩) |
| y = ax³ + … | **Cubic** | a > 0 rises left-to-right; up to 2 turning points |
| y = k/x | **Hyperbola** | Two branches; asymptotes at both axes |
| y = aˣ | **Exponential** | Rapid growth; passes through (0, 1); never reaches zero |

Identifying the shape before plotting means one bad point cannot mislead you.

## Plotting from a table

1. Substitute each x into the equation carefully — **negative values squared are positive**: (−3)² = 9, not −9.
2. Plot every point accurately.
3. Join with a **smooth curve**, not straight segments.
4. Extend to the edges of the given range.

## Solving equations graphically

The **solutions of f(x) = 0** are where the curve crosses the **x-axis**.

To solve `f(x) = g(x)`, draw both graphs and read the **x-coordinates of the intersections**.

To solve `x² − 3x = 2` from a drawn graph of `y = x² − 3x`: draw the line **y = 2** and read where they meet.

## Key features to identify

- **Roots / x-intercepts** — where y = 0.
- **y-intercept** — set x = 0.
- **Turning point** — maximum or minimum; for a quadratic it lies on the line of symmetry at `x = −b/2a`, or read it from completed square form.
- **Line of symmetry** — vertical line through the turning point.
- **Asymptotes** — lines the curve approaches but never touches (reciprocal and exponential graphs).

## Gradient of a curve

Draw a **tangent** at the point, then find the gradient of the tangent using a large triangle. This gives the instantaneous rate of change at that point.

## Exam traps

- Squaring negatives: (−4)² = +16.
- Joining points with straight lines instead of a smooth curve.
- Forgetting that y = k/x never crosses either axis.
- An exponential graph approaches but never reaches the x-axis.
- Reading solutions from the wrong axis — roots are **x**-values.
- Using a tiny triangle for a tangent gradient.

## Self-test

1. What shape is y = −2x² + 3?
2. Where does y = 3ˣ cross the y-axis?
3. How do you find the solutions of x² − 4 = 0 from a graph?
4. Why does y = 6/x have no value at x = 0?
5. How do you find the gradient of a curve at a point?

**Answers:** 1. A parabola opening downwards (∩), since a is negative. 2. At (0, 1) — any non-zero number to the power 0 equals 1. 3. Read the x-coordinates where the curve y = x² − 4 crosses the x-axis (at x = −2 and x = 2). 4. Division by zero is undefined; the y-axis is an asymptote the curve approaches but never meets. 5. Draw a tangent to the curve at that point and calculate the gradient of the tangent using a large triangle.
