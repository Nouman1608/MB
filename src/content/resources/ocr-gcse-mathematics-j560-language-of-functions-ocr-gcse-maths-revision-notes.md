These notes condense section 6.05, Language of functions, of OCR GCSE (9-1) Mathematics J560, Version 2.1 (August 2026). Inputs and outputs are for **both tiers**; inverse and composite functions are **Higher tier only**. The specification states that knowledge of function notation will not be required, so functions appear as machines, in words, or as equations in x and y. Full explanations are in the [language of functions study guide](/resources/ocr-gcse-mathematics-j560-language-of-functions-ocr-gcse-maths/); test yourself with the [language of functions practice questions](/resources/ocr-gcse-mathematics-j560-language-of-functions-ocr-gcse-maths-practice/). The wider topic is in the [inequalities and functions revision notes](/resources/ocr-gcse-mathematics-inequalities-and-the-language-of-functions-revision-notes/).

## Coverage at a glance

| Content | Tier |
|---|---|
| Simple expressions as functions with inputs and outputs | Both tiers |
| The reverse process as the inverse function | Higher tier only |
| Two functions in succession as a composite function | Higher tier only |

## Key terms

| Term | Meaning |
|---|---|
| Function | A rule giving exactly one output for each input |
| Input | The value fed in, usually x |
| Output | The value produced, usually y |
| Function machine | A diagram of boxes showing the operations in order |
| Inverse function | The function that reverses the process, taking each output back to its input |
| Composite function | Two functions applied one after the other, the output of the first becoming the input of the second |
| Self-inverse | A function that is its own inverse, such as y = 10 − x |

## Expression to machine

The order of operations decides the order of boxes: brackets, powers, × and ÷, + and −.

| Expression | Machine | Output for input 4 |
|---|---|---|
| y = 5x + 2 | ×5, +2 | 22 |
| y = 5(x + 2) | +2, ×5 | 30 |
| y = x²/8 | square, ÷8 | 2 |
| y = (x − 1)² + 3 | −1, square, +3 | 12 |
| y = 20 − 3x | ×3, subtract from 20 | 8 |

## Machine to expression

Apply each box to the whole of what you have so far, adding brackets as needed.

```
input x → +6 → ÷2 → −1
x + 6  →  (x + 6)/2  →  y = (x + 6)/2 − 1
```

Simplified: y = x/2 + 2. Check with input 4: (4 + 6)/2 − 1 = 4, and 4/2 + 2 = 4.

## Input from an output

Form an equation and solve. For y = 5(x + 2) with output 45: 5(x + 2) = 45, x + 2 = 9, x = 7.

## Inverse functions (Higher tier only)

```
Method 1: reverse the machine
  1. Undo each box (+ ↔ −, × ↔ ÷, square ↔ square root).
  2. Put the boxes in the OPPOSITE order.
  3. "Subtract from k" is undone by "subtract from k".

Method 2: swap and rearrange
  1. Replace y with x and x with y.
  2. Make y the subject.

Always check: input a number, then put the output into the inverse.
```

| Function | Inverse |
|---|---|
| y = x + 7 | y = x − 7 |
| y = 6x | y = x/6 |
| y = 2x − 9 | y = (x + 9)/2 |
| y = (x + 4)/3 | y = 3x − 4 |
| y = 15 − x | y = 15 − x (self-inverse) |
| y = 8/x | y = 8/x (self-inverse) |
| y = x³ + 1 | y = ∛(x − 1) |

A function where two inputs share an output, such as y = x², cannot be fully reversed unless the inputs are restricted (for example to positive numbers).

## Composite functions (Higher tier only)

```
"A then B": put the WHOLE expression for A wherever x appears in B.
Order matters: "A then B" is usually different from "B then A".
Inverse of "A then B" = undo B first, then undo A.
```

Reminder: A is y = x − 2 and B is y = x².

- A then B: y = (x − 2)². Input 5 gives 9.
- B then A: y = x² − 2. Input 5 gives 23.

Reminder: the inverse of "×4 then +1" is "−1 then ÷4", giving y = (x − 1)/4.

## Exam traps

- Reading boxes left to right from the expression instead of using the order of operations.
- Dropping brackets: (x + 6)/2 is not x + 6/2.
- Undoing the boxes but keeping the original order.
- Undoing "subtract from 20" with "+20".
- Composites in the wrong order: check which function the question says comes first.
- Squaring only part of an expression in a composite: (x − 2)² ≠ x² − 4.
- Forgetting the final check of an inverse with a number.
- Using notation the question has not used. OCR J560 does not require function notation, so answer in the form the question uses (usually y = ...).

## Quick self-test

1. Draw the machine for y = 4(x − 3).
2. Find the output of y = 4(x − 3) for input 10.
3. A machine adds 5 and then multiplies by 3. Write y in terms of x.
4. For y = 2x² − 1, find the output when the input is −3.
5. For y = 7x − 2, find the input that gives an output of 40.
6. Complete: for y = x² + 4, the inputs 3 and ___ give the same output.
7. (Higher tier only) Find the inverse of y = 3x + 8.
8. (Higher tier only) Find the inverse of y = (x − 5)/2.
9. (Higher tier only) Find the inverse of y = 9 − 2x.
10. (Higher tier only) A is y = x + 1 and B is y = 3x. Find "A then B" and "B then A".
11. (Higher tier only) Using question 10, find the output of "B then A" for input 4.
12. (Higher tier only) Find the inverse of "A then B" from question 10.

### Answers

1. x → −3 → ×4 → y
2. 4 × 7 = 28
3. y = 3(x + 5)
4. 2 × 9 − 1 = 17
5. 7x − 2 = 40, so 7x = 42 and x = 6
6. −3
7. y = (x − 8)/3
8. y = 2x + 5
9. Swap: x = 9 − 2y, so y = (9 − x)/2
10. A then B: y = 3(x + 1); B then A: y = 3x + 1
11. 3 × 4 + 1 = 13
12. Undo ×3 then undo +1: y = x/3 − 1
