These notes condense **syllabus section 1.12** of IB DP Mathematics: Analysis and Approaches (first assessment 2021): i with i² = −1, Cartesian form, real and imaginary parts, conjugate, modulus, argument and the complex plane. It is **HL only**. For explanations and worked examples, use the [section 1.12 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-12/).

## Condensed recall

**The number i.** i² = −1, so √(−k) = i√k for k > 0. Powers cycle with period 4: i, −1, −i, 1. For iⁿ, use the remainder when n is divided by 4.

**Cartesian form.** z = a + bi with a, b ∈ ℝ.

| Quantity | For z = a + bi | For z = −6 + 8i |
|---|---|---|
| Re z | a | −6 |
| Im z | b (real) | 8 |
| z* | a − bi | −6 − 8i |
| \|z\| | √(a² + b²) | 10 |
| arg z | angle from positive real axis | π − arctan(4/3) ≈ 2.21 |

**Arithmetic**

- (a + bi) ± (c + di) = (a ± c) + (b ± d)i
- (a + bi)(c + di) = (ac − bd) + (ad + bc)i
- (a + bi)/(c + di): multiply top and bottom by c − di; the denominator becomes c² + d².
- 1/i = −i, since i × (−i) = −i² = 1.

**Conjugate facts**

- z + z* = 2 Re z; z − z* = 2i Im z
- zz* = |z|²
- (z ± w)* = z* ± w*; (zw)* = z*w*; (z/w)* = z*/w*
- z = z* if and only if z is real

**Equal complex numbers.** a + bi = c + di ⇔ a = c and b = d. One complex equation gives two real equations.

**Equations involving z and z*.** Substitute z = a + bi, expand, collect real and imaginary parts, solve the simultaneous equations.

**Quadratics with real coefficients.** If the discriminant is negative, the roots are p ± qi, a conjugate pair: z = (−b ± i√(4ac − b²))/(2a).

**Complex plane (Argand diagram)**

- z = a + bi is the point (a, b).
- z*: reflection in the real axis. −z: rotation by π about the origin.
- z + w: parallelogram (vector) addition.
- |z − w|: distance between the points z and w.

**Argument by quadrant.** Sketch, find the reference angle α with tan α = |b|/|a|, then:

- first quadrant: α; second: π − α; third: −(π − α); fourth: −α (for −π < θ ≤ π).
- On the axes: positive real 0, positive imaginary π/2, negative real π, negative imaginary −π/2.

## Key terms

| Term | Meaning |
|---|---|
| Imaginary unit, i | The number with i² = −1 |
| Complex number | A number a + bi with a, b real |
| Real part, Re z | a in a + bi |
| Imaginary part, Im z | b in a + bi (a real number) |
| Purely imaginary | A complex number with real part 0, such as 5i |
| Conjugate, z* | a − bi |
| Modulus, \|z\| | √(a² + b²), the distance from the origin |
| Argument, arg z | The angle from the positive real axis to z |
| Complex plane, Argand diagram | The plane with a real and an imaginary axis |

## Exam traps

- **Im z includes i.** Im(5 − 2i) = −2, not −2i.
- **Calculator argument.** arctan(b/a) gives the wrong quadrant whenever a < 0.
- **Conjugate of the wrong number.** When dividing, multiply by the conjugate of the denominator.
- **Sign in iz*.** i(a − bi) = b + ai, not −b + ai.
- **√(−a)√(−b).** √(−4) × √(−9) = 2i × 3i = −6, not √36 = 6.
- **Unstated range for arg.** If a question uses 0 ≤ θ < 2π, give 4π/3, not −2π/3.
- **Modulus is never negative.** |−3 − 4i| = 5.

## Self-test

1. Simplify i³⁸.
2. Find (3 − 2i)(4 + i).
3. Write (1 + 3i)/(1 − i) in the form a + bi.
4. Write down Re z, Im z and z* for z = −2 + 7i.
5. Find |z| for z = 5 − 12i.
6. Find arg z, exactly, for z = −√3 + i.
7. Solve z² + 4z + 13 = 0.
8. Find real x and y with x + 2y + (x − y)i = 7 + i.
9. Solve 3z + z* = 8 − 4i.
10. Show that zz* is real for any complex number z.
11. Find the distance between 1 + 5i and 4 + i on the complex plane.
12. Describe the position of z* relative to z on an Argand diagram.

**Answers**

1. 38 = 4 × 9 + 2, so i³⁸ = i² = −1.
2. 12 + 3i − 8i − 2i² = 14 − 5i.
3. (1 + 3i)(1 + i)/2 = (1 + 4i − 3)/2 = −1 + 2i.
4. Re z = −2, Im z = 7, z* = −2 − 7i.
5. √(25 + 144) = 13.
6. Second quadrant, reference angle π/6, so arg z = 5π/6.
7. z = (−4 ± √(16 − 52))/2 = (−4 ± 6i)/2 = −2 ± 3i.
8. x + 2y = 7 and x − y = 1, so y = 2 and x = 3.
9. With z = a + bi: 4a + 2bi = 8 − 4i, so a = 2, b = −2, z = 2 − 2i.
10. (a + bi)(a − bi) = a² − b²i² = a² + b², which is real.
11. |(4 + i) − (1 + 5i)| = |3 − 4i| = 5.
12. It is the reflection of z in the real axis.
