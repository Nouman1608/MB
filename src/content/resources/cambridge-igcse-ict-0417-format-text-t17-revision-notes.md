These notes cover the **format text** skill in Topic 17 of Cambridge IGCSE ICT 0417. The [format text study guide](/resources/cambridge-igcse-ict-0417-format-text-t17/) explains every setting with worked examples; the [format text practice questions](/resources/cambridge-igcse-ict-0417-format-text-t17-practice/) test them.

## Syllabus coverage

| Syllabus statement | Notes and guidance |
|---|---|
| Format text | Set line spacing including single, 1.5 times, double, multiple, spacing before and after paragraphs |
| | Set tabulation including left, right, centred and decimal tabs, indented paragraphs and hanging paragraphs |
| | Text enhancement including bold, underline, italic, superscript and subscript, changes in case |
| | Create or edit lists including bulleted, numbered |

## Key terms

| Term | Meaning |
|---|---|
| Line spacing | Distance between lines within a paragraph |
| Paragraph spacing | Gap before or after a paragraph, set in points |
| Tab stop | A ruler position where text lines up when Tab is pressed |
| Decimal tab | Lines numbers up on their decimal points |
| Indent | Distance a paragraph edge is moved in from the margin |
| Hanging paragraph | First line at the margin, later lines indented |
| Superscript | Small characters raised above the line, such as the 2 in m² |
| Subscript | Small characters lowered below the line, such as the 2 in H₂O |
| Sentence case | Only the first letter of the sentence is a capital |

## Line and paragraph spacing

- Single, 1.5 lines, double, or multiple (type a value such as 1.15 or 3).
- Spacing **before** and **after** paragraphs is measured in **points**.
- Apply to whole paragraphs, ideally by editing the body style.
- Never use empty paragraphs (pressing Enter) for space: they are not exact and move when text changes.

## The four tabs

| Tab | Text aligns | Use |
|---|---|---|
| Left | from the stop rightwards | Lists of names or items |
| Right | ending at the stop | Text against the right margin, page numbers |
| Centred | around the stop | Short column headings |
| Decimal | on the decimal point | Prices, measurements |

- Set exact positions in the tabs dialogue, for example "decimal tab at 13 cm".
- One Tab press per stop; no spaces.
- Tab stops carry on to the next line when you press Enter.
- To remove a tab stop, drag it off the ruler or clear it in the dialogue.

## Indents

- **Left** and **right** indents move the whole paragraph in from a margin.
- **First-line** indent moves only line 1 in.
- **Hanging** indent: line 1 at the margin, other lines in; used for references, glossaries and numbered points.
- Set on the ruler or, for exact values, in the paragraph dialogue.

## Enhancement and case

- Bold, italic, underline for emphasis; underline sparingly on screen.
- Superscript: m², cm³, 2⁸, 1st, footnote numbers.
- Subscript: H₂O, CO₂.
- Select **only** the characters to raise or lower.
- Case options: UPPERCASE, lowercase, Sentence case, Capitalise Each Word, tOGGLE cASE.
- Use the change case tool, not retyping.

## Lists

- Bullets: no set order. Numbers: steps or ranking.
- Number styles: 1, 2, 3; a, b, c; i, ii, iii.
- Change bullet symbol; switch between bullets and numbers.
- Restart numbering for a new list, or continue from the previous one.
- Increase indent to make a sub-item.
- Never type numbers by hand.

## Instruction to setting

| Instruction | Setting to use |
|---|---|
| "Leave a gap of 6 pt below each paragraph" | Spacing after: 6 pt |
| "Use double spacing for the draft" | Line spacing: double |
| "Line up the costs" | Decimal tab at the stated position |
| "Indent the quotation 2 cm from both margins" | Left indent 2 cm and right indent 2 cm |
| "Format the references with a hanging indent" | Special indent: hanging, at the stated value |
| "Display the title in capitals" | Change case: UPPERCASE |
| "Make the steps a numbered list" | Numbering, in the style asked for |

Check each one in the paragraph or font dialogue, where exact values are shown, rather than judging by eye.

## Exam traps

- Confusing **line spacing** (within a paragraph) with **spacing after** (between paragraphs).
- Using a **right** tab for prices with different numbers of decimal places: use a **decimal** tab.
- Building a hanging indent from Enter and Tab on each line.
- Making the whole "m2" superscript instead of just the 2.
- **Capitalise each word** is not the same as **sentence case**.
- Leaving the numbering continuing from an earlier list when the task wants a new list starting at 1.

## Self-test

1. What does "multiple" line spacing let you set?
2. In which unit is spacing before and after a paragraph usually set?
3. Why should Enter not be used to create space between paragraphs?
4. Which tab would line up 3.5, 12.25 and 150.0 correctly?
5. Which tab would you use to put page numbers against the right margin of a contents list?
6. What is a hanging paragraph? Give one use.
7. Write CO2 with correct formatting and name the enhancement used.
8. Give the result of applying sentence case to "THE ANNUAL SPORTS DAY".
9. Give the result of capitalise each word on "the annual sports day".
10. A numbered list starts at 4 instead of 1. What setting should be changed?
11. How is a sub-item created in a numbered list?
12. Why is the change case tool better than retyping?

### Answers

1. Any line spacing value, such as 1.15 or 3 times single.
2. Points (pt).
3. The gap is not an exact size, and the empty paragraphs move or appear at the top of pages when text changes.
4. A decimal tab.
5. A right tab.
6. The first line starts at the margin and the following lines are indented; used for reference lists, glossaries or numbered points.
7. CO₂, with the 2 in subscript.
8. The annual sports day.
9. The Annual Sports Day.
10. Restart numbering (set the value to start at 1).
11. Increase the indent of the item (demote it to the next level).
12. It is quicker and cannot introduce typing errors.
