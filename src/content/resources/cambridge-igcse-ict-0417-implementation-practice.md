## Section A: short answers

**1.** Name the method of implementation in which the old system is stopped and the new system is started on the same day. **[1]**

**2.** Give **two** advantages of phased implementation. **[2]**

**3.** State **one** reason why parallel running is the most expensive method. **[1]**

**4.** Identify the method of implementation described in each case.

**(a)** A bank introduces its new system in its Northern region branches only, then the rest of the country. **[1]**

**(b)** A council introduces the new council-tax module first, then the parking-permits module, then the housing module. **[1]**

**5.** Give **two** reasons why direct changeover is risky. **[2]**

## Section B: structured questions

**6.** Hilltop Veterinary Group has 18 surgeries. It is installing a new appointments and records system.

**(a)** Describe how pilot running would be carried out at Hilltop. **[2]**

**(b)** Give **two** advantages of pilot running for Hilltop. **[2]**

**(c)** Give **one** disadvantage of pilot running for Hilltop. **[1]**

**7.** Brookside Credit Union is replacing the system that records members' savings and loans.

**(a)** Explain why parallel running would be suitable for Brookside. **[3]**

**(b)** Describe **two** problems Brookside's staff might face during parallel running. **[2]**

**8.** Explain the difference between pilot running and phased implementation. **[2]**

**9.** A one-person dog-walking business is moving its bookings from a paper diary to a smartphone app. Explain why direct changeover is a suitable method. **[3]**

**10.** Marlowe Manufacturing's new system has separate modules for stock control, production planning and payroll. Explain why phased implementation might suit this system. **[3]**

**11.** Compare direct changeover and parallel running for a hospital's new patient records system. **[6]**

**12.** A school is replacing its electronic register and report system just before the summer holiday. Discuss which implementation method would be most suitable. **[4]**

## Answers

**1.** Direct changeover [1]. **[1]**

**2.** Any two of: if one part fails only that part is affected [1]; problems are easy to trace to the part just introduced [1]; staff can learn the system one part at a time [1]; each part is checked before the next is added [1]. Maximum 2. **[2]**

**3.** Any one of: all work is done twice, in both systems [1]; extra staff time or overtime is needed [1]. Maximum 1. **[1]**

**4. (a)** Pilot running [1].

**(b)** Phased implementation [1]. **[2]**

**5.** Any two of: if the new system fails there is no old system to fall back on [1]; data could be lost [1]; work could stop completely [1]; all staff must be trained before the changeover, which may not be achieved [1]. Maximum 2. **[2]**

**6. (a)** The whole new system is introduced in one surgery first while the other 17 keep the old system [1]; once it works well there it is introduced in the remaining surgeries [1].

**(b)** Any two of: if the system fails, only one surgery's appointments and records are affected [1]; faults can be fixed before the other surgeries change over [1]; staff at the pilot surgery can help train staff at other surgeries [1]; cheaper than running two systems at every surgery [1]. Maximum 2.

**(c)** Any one of: the other surgeries wait longer for the benefits [1]; the pilot surgery may not be typical, so some problems appear later [1]; if the pilot fails that surgery's records may be affected [1]. Maximum 1. **[5]**

**7. (a)** Members' savings and loans are financial records, so errors or lost data would be very serious [1]; with parallel running the old system is still running if the new one fails [1]; results from both systems can be compared, so errors in the new system are found before it is relied on [1].

**(b)** Any two of: every transaction must be entered twice, doubling the workload [1]; staff may make errors because they are tired or rushed [1]; overtime or extra temporary staff may be needed, increasing costs [1]; staff may be confused by using two systems at once [1]. Maximum 2. **[5]**

**8.** Pilot running introduces the whole new system at one site or department first [1], whereas phased implementation introduces one part of the system at a time across the whole organisation [1]. **[2]**

**9.** There is only one person and one location, so pilot or phased methods are not possible in a meaningful way [1]; direct changeover is the quickest and cheapest, which suits a very small business [1]; the risk is low because if the app fails the owner can return to the paper diary or contact customers directly [1]. **[3]**

**10.** The system is already divided into clear modules, so each can be introduced separately [1]; for example stock control can be introduced and checked before production planning [1]; if one module fails, the others are unaffected, and staff learn one module at a time [1]. **[3]**

**11.** Up to 6 marks for points about both methods, for example:
- With direct changeover the new system is used at once, so benefits are immediate [1].
- Direct changeover is cheaper because records are entered only once [1].
- With direct changeover there is no fall-back, so if the new system fails patient records may be unavailable or lost [1].
- With parallel running the old system is still available if the new one fails [1].
- Parallel running allows outputs to be compared so errors are found before patients are affected [1].
- Parallel running is expensive and doubles the work of busy staff [1].
- Conclusion: parallel running is more suitable, because patient safety outweighs the extra cost [1].
Maximum 6; points about both methods are needed for full marks. **[6]**

**12.** Up to 4 marks, for example: during the holiday there are no pupils, so registers are not being taken [1]; this makes direct changeover more acceptable, because a failure would not affect daily registers and could be fixed before term [1]; parallel running would be less useful because there is little live data during the holiday to enter into both systems [1]; a reasoned conclusion, such as direct changeover in the holiday, with testing before the new term [1]. Credit any other method if it is justified with reference to the timing and the school. **[4]**

## Frequently asked questions

**Can two methods be combined?**
Yes. A common combination is pilot running with parallel running at the pilot site. If you combine methods, justify each part.

**How many methods should I discuss in a "discuss" question?**
Enough to reach a justified conclusion: usually the method you recommend and at least one alternative you reject, with reasons.
