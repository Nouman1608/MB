These notes condense subtopic **E7.4 Vector geometry** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027). It is **Extended only**; C7.4 reads "Extended content only". For full explanations and worked examples, read the [vector geometry study guide](/resources/cambridge-igcse-mathematics-0580-vector-geometry/); for exam-style questions, use the [vector geometry practice questions](/resources/cambridge-igcse-mathematics-0580-vector-geometry-practice/).

## What the syllabus says

1. Represent vectors by directed line segments.
2. Use position vectors.
3. Use the sum and difference of two or more vectors to express given vectors in terms of two coplanar vectors.
4. Use vectors to reason and to solve geometric problems, for example: show that vectors are parallel, show that 3 points are collinear, and solve vector problems involving ratio and similarity.

## Key terms

| Term | Meaning |
|---|---|
| Directed line segment | A line segment with a direction, such as AB with an arrow |
| Position vector | The vector from the origin O to a point: OA = **a** |
| Coplanar vectors | Vectors in the same plane; in 0580, two base vectors such as **a** and **b** |
| Parallel | One vector is a scalar multiple of the other |
| Collinear | Lying on one straight line |
| Similar triangles | Same shape; corresponding sides in the same ratio |

## Core rules

```
AB = b − a                      (end − start, using position vectors)
BA = −AB = a − b
AB + BC = AC                    (follow the route)
P on AB, AP : PB = m : n   →    AP = (m/(m+n)) AB
                                OP = a + (m/(m+n))(b − a)
Midpoint of AB             →    ½(a + b)
```

**Ratio fractions to remember**

| AP : PB | AP as a fraction of AB |
|---|---|
| 1 : 1 | ½ |
| 1 : 2 | ⅓ |
| 2 : 1 | ⅔ |
| 1 : 3 | ¼ |
| 2 : 3 | ⅖ |
| 3 : 2 | ⅗ |

## Proof templates

**Parallel**

```
Find both vectors in terms of a and b, simplified.
Show PQ = k × RS.
"PQ is a multiple of RS, so PQ is parallel to RS (and k times as long)."
```

**Collinear**

```
Find PQ and PR (they share P).
Show PR = k × PQ.
"PQ and PR are parallel and share the point P, so P, Q and R are collinear."
Ratio: if PR = k PQ, then PQ : QR = 1 : (k − 1).
```

**Unknown scalar**

```
k a + 6b parallel to a + 2b  →  ratio of coefficients equal
6 ÷ 2 = 3, so k = 3 × 1 = 3
```

**Similarity**

```
If CD = k AB and the triangles share a vertex, the triangles are similar.
Length scale factor k, area scale factor k².
```

## Shapes to recognise

| Shape | Vector facts |
|---|---|
| Parallelogram OABC | OA = CB, OC = AB; OB = **a** + **c**; AC = **c** − **a** |
| Trapezium | one pair of sides with one vector a multiple of the other |
| Regular hexagon with centre O | opposite sides equal and parallel; OC = **b** − **a** when OA = **a**, OB = **b** |

## Worked reminder

OA = **a**, OB = **b**, P on OA with OP : PA = 3 : 1, Q on OB with OQ : QB = 3 : 1.

```
OP = ¾a,  OQ = ¾b
PQ = ¾b − ¾a = ¾(b − a) = ¾ AB
PQ is parallel to AB; triangles OPQ and OAB are similar,
length ratio 3 : 4, area ratio 9 : 16.
```

## Exam traps

- Writing AB = **a** − **b**.
- Converting AP : PB = 2 : 3 to ⅔ instead of ⅖.
- Leaving AM or AB in an answer that must be "in terms of **a** and **b**".
- Saying "collinear" without naming the shared point.
- Not stating the scalar multiple in a parallel proof.
- Using the length scale factor for an area.

## Self-test

1. OA = **a**, OB = **b**. Write AB in terms of **a** and **b**.
2. M is the midpoint of AB. Write OM in terms of **a** and **b**.
3. P lies on AB with AP : PB = 1 : 4. Write AP in terms of **a** and **b**.
4. Is 4**a** − 2**b** parallel to **b** − 2**a**? Explain.
5. OABC is a parallelogram with OA = **a** and OC = **c**. Write AC.
6. A, B and C have position vectors (0, 1), (2, 4) and (6, 10). Are they collinear?
7. PQ = 2**a** + **b** and PR = 6**a** + 3**b**. What can you conclude?
8. For question 7, find PQ : QR.
9. k**a** − 4**b** is parallel to 3**a** + 2**b**. Find k.
10. CD = 5AB and the triangles OAB and OCD share the vertex O. Find the ratio of their areas.
11. OA = **a**, OB = **b**, P on AB with AP : PB = 3 : 1. Find OP.
12. OABC is a trapezium with CB = 3OA. If OA = **a** and OC = **c**, find AB.

### Answers

1. **b − a**
2. **½a + ½b**
3. **⅕(b − a)**
4. **Yes**: 4**a** − 2**b** = −2(**b** − 2**a**)
5. **c − a**
6. AB = (2, 3), AC = (6, 9) = 3AB, shared point A: **yes, collinear**
7. PR = 3PQ and they share P: **P, Q and R are collinear**
8. QR = PR − PQ = 2PQ, so **PQ : QR = 1 : 2**
9. Multiplier −2 from the **b** terms, so **k = −6**
10. Lengths 5 : 1, so areas **25 : 1** (OCD : OAB)
11. **a** + ¾(**b** − **a**) = **¼a + ¾b**
12. AB = −**a** + **c** + 3**a** = **2a + c**
