These notes condense **3.3.11.2 Base properties** of amines from the OxfordAQA International AS and A-level Chemistry (9620) specification, Version 5.3. It is International A2 content, examined in Unit 4 and able to reappear in Unit 5. For explanations and worked examples read the [amine base properties study guide](/resources/oxfordaqa-a-level-chemistry-9620-oxfordaqa-a-level-chemistry-3-3-11-2/); then try the [amine base properties practice questions](/resources/oxfordaqa-a-level-chemistry-9620-oxfordaqa-a-level-chemistry-3-3-11-2-practice/).

## The subtopic in four lines

1. Amines accept protons with the lone pair on nitrogen, so they are bases.
2. In water only a small proportion are protonated, so they are weak bases.
3. Base strength: primary aliphatic amine > ammonia > primary aromatic amine.
4. The order depends on how available the nitrogen lone pair is.

## Key terms

| Term | Meaning to learn |
|---|---|
| Brønsted–Lowry base | Proton (H⁺) acceptor |
| Lone pair | Pair of non-bonding electrons on N used to bond to H⁺ |
| Weak base | Only partly protonated (ionised) in water |
| Ammonium ion (substituted) | RNH₃⁺, formed when an amine accepts H⁺ |
| Positive inductive effect | Electron release by an alkyl group towards an atom it is bonded to |
| Delocalisation | Spreading of electrons over several atoms; here the N lone pair into the benzene ring |
| Primary aliphatic amine | R–NH₂ with N on a chain or non-aromatic ring carbon |
| Primary aromatic amine | Ar–NH₂ with N on a benzene ring carbon |

## Equations to know

- In water: RNH₂ + H₂O ⇌ RNH₃⁺ + OH⁻ (equilibrium well to the left).
- With HCl: RNH₂ + HCl → RNH₃⁺Cl⁻.
- With H₂SO₄: 2RNH₂ + H₂SO₄ → (RNH₃⁺)₂SO₄²⁻.
- Freeing the amine: RNH₃⁺ + OH⁻ → RNH₂ + H₂O.

## Naming salts

| Amine | Salt with HCl |
|---|---|
| CH₃NH₂ methylamine | CH₃NH₃⁺Cl⁻ methylammonium chloride |
| CH₃CH₂CH₂NH₂ propylamine | CH₃CH₂CH₂NH₃⁺Cl⁻ propylammonium chloride |
| C₆H₅NH₂ phenylamine | C₆H₅NH₃⁺Cl⁻ phenylammonium chloride |

## The base strength explanation

| Step | Aliphatic amine | Ammonia | Aromatic amine |
|---|---|---|---|
| Group on N | Alkyl | H only | Benzene ring |
| Effect | Electron release (positive inductive effect) | None | Lone pair overlaps with ring's delocalised p electrons |
| Electron density on N | Increased | Reference | Decreased |
| Lone pair availability | More available | Reference | Less available |
| Result | Stronger base than NH₃ | Middle | Weaker base than NH₃ |

Five-mark recipe:

1. Basis: lone pair on N accepts H⁺; more available = stronger base.
2. Aliphatic: alkyl group releases electrons towards N.
3. So lone pair more available than in NH₃.
4. Aromatic: lone pair delocalised into the benzene ring.
5. So lone pair less available than in NH₃.

## Aliphatic or aromatic? Check the N

| Compound | N bonded to | Type | Stronger or weaker than NH₃ |
|---|---|---|---|
| C₆H₅NH₂ | ring carbon | aromatic | weaker |
| C₆H₅CH₂NH₂ | CH₂ | aliphatic | stronger |
| C₆H₅CH₂CH₂NH₂ | CH₂ | aliphatic | stronger |
| C₆H₁₁NH₂ | non-aromatic ring carbon | aliphatic | stronger |
| CH₃C₆H₄NH₂ (N on ring) | ring carbon | aromatic | weaker |

## Amines with acids in practice

- An amine that is barely soluble in water, such as phenylamine, dissolves in dilute HCl because it forms an ionic salt.
- Adding excess NaOH to the salt solution releases the amine again, which separates out.
- This acid–alkali sequence separates a basic amine from neutral organic impurities.
- The final step of the Sn/HCl reduction of a nitro compound uses the same idea.
- An amine also reacts with a weak acid such as ethanoic acid, giving a salt such as propylammonium ethanoate, CH₃CH₂CH₂NH₃⁺ CH₃COO⁻.

## Titration facts

- Amine : HCl = 1 : 1 for one –NH₂ group; amine : H₂SO₄ = 2 : 1.
- Mr from titration: mass ÷ moles of HCl used.
- Weak base with strong acid: equivalence point below pH 7, so use methyl orange.

## Exam traps

- "Amines are strong bases because they react completely with acids": wrong; weak refers to water.
- No mention of the lone pair: an answer about "electron density" alone loses marks.
- "Phenylamine is weak because the ring is large": wrong reason.
- Ammonia placed weakest: it lies between aliphatic and aromatic amines.
- Benzylamine called aromatic: N is not on the ring.
- RNH₄⁺ written for the ion: it is RNH₃⁺.
- Using 1 : 1 with sulfuric acid in a titration.

## Self-test

Answer without looking, then check below.

1. What feature of an amine molecule allows it to act as a base?
2. Write an equation for ethylamine reacting with water.
3. Explain the term weak base for ethylamine.
4. Name the salt formed from propylamine and hydrochloric acid.
5. Write an equation for that salt reacting with sodium hydroxide.
6. Put phenylamine, ammonia and methylamine in order, strongest base first.
7. Why is methylamine a stronger base than ammonia?
8. Why is phenylamine a weaker base than ammonia?
9. Is C₆H₅CH₂NH₂ stronger or weaker than ammonia? Why?
10. How many moles of butylamine react with 0.0150 mol of H₂SO₄?
11. 0.365 g of an amine reacts with 50.0 cm³ of 0.100 mol dm⁻³ HCl. What is its Mr?
12. Which indicator suits a titration of an amine with hydrochloric acid?

### Answers

1. The lone pair of electrons on the nitrogen atom.
2. CH₃CH₂NH₂ + H₂O ⇌ CH₃CH₂NH₃⁺ + OH⁻.
3. Only a small proportion of ethylamine molecules accept a proton from water; the equilibrium lies to the left.
4. Propylammonium chloride, CH₃CH₂CH₂NH₃⁺Cl⁻.
5. CH₃CH₂CH₂NH₃⁺Cl⁻ + NaOH → CH₃CH₂CH₂NH₂ + NaCl + H₂O.
6. Methylamine > ammonia > phenylamine.
7. The methyl group releases electron density towards N, making the lone pair more available.
8. The lone pair on N is partly delocalised into the benzene ring, so it is less available.
9. Stronger: N is bonded to a CH₂ group, not the ring, so the lone pair is not delocalised and the alkyl group releases electrons.
10. 0.0300 mol.
11. n = 0.00500 mol, so Mr = 0.365 ÷ 0.00500 = 73.0.
12. Methyl orange.
