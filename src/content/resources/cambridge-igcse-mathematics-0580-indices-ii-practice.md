These questions cover subtopic **2.4 Indices II** in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. Questions without a label use content common to Core (C2.4) and Extended (E2.4): positive, zero and negative indices. Questions marked **(Extended)** use fractional indices, which are E2.4 only. All questions can be done without a calculator, as they might be on Paper 1 or Paper 2.

For explanations, read the [Indices II study guide](/resources/cambridge-igcse-mathematics-0580-indices-ii/); for a condensed summary, use the [Indices II revision notes](/resources/cambridge-igcse-mathematics-0580-indices-ii-revision-notes/).

## Questions

### Section A: short questions

**1.** Simplify

**(a)** p⁶ × p⁻² **[1]**

**(b)** (2y³)⁵ **[2]**

**2.** Simplify 21m⁴n ÷ 7m⁻¹n³. **[2]**

**3.** Work out the value of 4⁰ − 4⁻¹. **[1]**

**4.** Find the value of n in each case.

**(a)** y³ × yⁿ = y⁻⁴ **[1]**

**(b)** (y⁻²)ⁿ = y⁸ **[1]**

**5.** Solve

**(a)** 5ˣ = 625 **[1]**

**(b)** 2ˣ⁻³ = 1/4 **[2]**

**6.** (Extended) Work out 16^(−3/4). **[2]**

**7.** (Extended) Simplify (27x⁹)^(1/3). **[2]**

### Section B: structured questions

**8.** Simplify (3a²b)³ × 2a⁻⁴b². **[3]**

**9.**

**(a)** Simplify 6x⁵y⁻² / (9x²y⁻⁵). **[2]**

**(b)** Simplify (4x⁻²)⁻². **[2]**

**10.** Solve

**(a)** 3²ˣ⁺¹ = 243 **[2]**

**(b)** 10ˣ × 10² = 0.1 **[2]**

**11.** (Extended) Solve

**(a)** 8ˣ = 32 **[2]**

**(b)** 4ˣ⁺¹ = 8ˣ⁻¹ **[3]**

**12.** (Extended)

**(a)** Write (x² + √x)/x as the sum of two powers of x. **[2]**

**(b)** Write 3/(2x²) in the form axⁿ. **[1]**

**(c)** Expand and simplify (x^(1/2) − 2)(x^(1/2) + 3). **[2]**

**13.**

**(a)** (Extended) Solve x^(3/4) = 27. **[2]**

**(b)** p and q are integers with 2ᵖ × 4^q = 32 and p − q = 2. Find p and q. **[4]**

**14.** (Extended) Write these four numbers in order of size, starting with the smallest. Show how you worked out the value of each.

2⁻²     4^(1/2)     8⁰     16^(−1/4) **[3]**

## Answers

**1. (a)** 6 + (−2) = 4: **p⁴** [1].

**(b)** 2⁵ = 32 [1] and (y³)⁵ = y¹⁵ [1]: **32y¹⁵**.
*Examiner insight:* (2y³)⁵ = 2y¹⁵ is a very common error; the 2 is inside the bracket and is raised to the power 5 too.

**2.** 21 ÷ 7 = 3 and 4 − (−1) = 5, giving 3m⁵ [1]; 1 − 3 = −2, giving n⁻² [1]. Answer **3m⁵n⁻²** or **3m⁵/n²**.

**3.** 1 − 1/4 = **3/4** [1].

**4. (a)** 3 + n = −4, so **n = −7** [1].

**(b)** −2n = 8, so **n = −4** [1].

**5. (a)** 625 = 5⁴, so **x = 4** [1].

**(b)** 1/4 = 2⁻² [1]. x − 3 = −2, so **x = 1** [1].

**6.** 16^(3/4) = (⁴√16)³ = 2³ = 8 [1]. Negative index: **1/8** [1].
*Examiner insight:* a negative fractional index has three jobs: root (denominator 4), power (numerator 3) and reciprocal (the minus sign). Doing them in that order keeps the numbers small.

**7.** 27^(1/3) = 3 [1] and (x⁹)^(1/3) = x³ [1]: **3x³**.

**8.** (3a²b)³ = 27a⁶b³ [1]. 27 × 2 = 54 [1]. a⁶⁻⁴ = a² and b³⁺² = b⁵: **54a²b⁵** [1].

**9. (a)** 6/9 = 2/3 [1]; x⁵⁻² = x³ and y⁻²⁻⁽⁻⁵⁾ = y³: **2x³y³/3** [1].

**(b)** 4⁻² = 1/16 [1] and (x⁻²)⁻² = x⁴: **x⁴/16** [1].
*Examiner insight:* in (b) the outer −2 applies to the 4 as well. Answers of 4x⁴ or −8x⁴ show the coefficient was not raised to the power.

**10. (a)** 243 = 3⁵ [1]. 2x + 1 = 5, so **x = 2** [1].
*Examiner insight:* 3⁵ = 243 must be known for the non-calculator paper; listing 3, 9, 27, 81, 243 is acceptable working.

**(b)** 10ˣ⁺² = 10⁻¹ [1]. x + 2 = −1, so **x = −3** [1].

**11. (a)** 2³ˣ = 2⁵ [1]. 3x = 5, so **x = 5/3** [1].

**(b)** 4 = 2² and 8 = 2³, so 2^(2x+2) = 2^(3x−3) [1]. 2x + 2 = 3x − 3 [1], so **x = 5** [1].
*Examiner insight:* (2²)ˣ⁺¹ is 2^(2x+2), not 2^(2x+1). The whole bracket x + 1 is multiplied by 2. Check: 4⁶ = 4096 and 8⁴ = 4096.

**12. (a)** x²/x = x [1] and x^(1/2)/x = x^(−1/2) [1]: **x + x^(−1/2)**.

**(b)** **(3/2)x⁻²** or 1.5x⁻² [1].

**(c)** x + 3x^(1/2) − 2x^(1/2) − 6 [1] = **x + x^(1/2) − 6** [1].

**13. (a)** x = 27^(4/3) [1] = (∛27)⁴ = 3⁴ = **81** [1].

**(b)** 4^q = 2^(2q), so 2^(p + 2q) = 2⁵ [1], giving p + 2q = 5 [1]. Subtracting p − q = 2 gives 3q = 3 [1]. **q = 1, p = 3** [1].
*Examiner insight:* this is an index equation and a pair of simultaneous equations in one; the first mark is for writing every term as a power of 2.

**14.** Values: 2⁻² = 1/4, 4^(1/2) = 2, 8⁰ = 1, 16^(−1/4) = 1/2 [1] for any three correct, [1] for all four. Order: **2⁻², 16^(−1/4), 8⁰, 4^(1/2)** [1].
*Examiner insight:* write the values as fractions or decimals before ordering. The order of the indices alone (−2, −1/4, 0, 1/2) happens to agree here only by chance; with different bases it would not.

## Where marks are usually lost

- Not raising the coefficient inside a bracket to the power.
- Adding indices for a power of a power, as in (y⁻²)ⁿ.
- Equating indices before both sides use the same base.
- Multiplying only the first term of an index such as x + 1 by the outer power.
- Taking the power before the root with fractional indices, which makes the numbers too large to handle without a calculator.
