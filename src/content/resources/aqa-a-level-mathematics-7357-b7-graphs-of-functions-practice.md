These questions cover content statement **B7** of AQA A-level Mathematics (7357), Section B: Algebra and functions: sketching polynomials, the modulus of a linear function, y = a/x and y = a/x² with their asymptotes; interpreting algebraic solutions graphically; using intersections to solve equations; and proportional relationships. Where a sketch is asked for, describe it in words in your answer if you are not drawing: shape, intercepts and asymptotes. Revise from the [B7 study guide](/resources/aqa-a-level-mathematics-7357-b7-graphs-of-functions/) and the [B7 revision notes](/resources/aqa-a-level-mathematics-7357-b7-graphs-of-functions-revision-notes/).

## Section A

**1.** Sketch y = (x − 1)(x + 2)², stating the coordinates of the points where the curve meets the axes. **[3]**

**2.** A cubic curve touches the x-axis at (−3, 0), crosses it at (2, 0) and meets the y-axis at (0, −9). Find its equation in the form y = a(x − p)²(x − q). **[3]**

**3.** For the graph of y = |3x − 6|, state the coordinates of the vertex, the y-intercept and the gradients of the two arms. **[2]**

**4.** Solve |x + 4| = |3x|. **[3]**

**5.** Describe the graph of y = −3/x², stating its asymptotes and where its branches lie. **[2]**

**6.** y is inversely proportional to x, and y = 2.4 when x = 15.

**(a)** Find y when x = 4. **[2]**

**(b)** Describe the graph of y against 1/x. **[1]**

## Section B

**7.**

**(a)** Solve |x − 2| = 2x + 5. **[3]**

**(b)** Explain why squaring both sides of this equation produces an extra value, and identify that value. **[2]**

**8.** The line y = 2x − 1 and the curve y = k/x are drawn on the same axes, where k is a constant.

**(a)** Show that the x-coordinates of any intersection points satisfy 2x² − x − k = 0. **[1]**

**(b)** Find the value of k for which the line is a tangent to the curve, and the coordinates of the point of contact. **[3]**

**(c)** Find the set of values of k for which the line meets the curve at two points. **[2]**

**9.**

**(a)** By rearranging x³ − 2x² − 1 = 0 into the form x − 2 = 1/x² and considering the graphs of y = x − 2 and y = 1/x², explain why the equation has exactly one real root. **[3]**

**(b)** Show that this root lies between 2 and 3. **[2]**

**10.** The curve y = 4/x² and the line y = 3 − x are drawn on the same axes.

**(a)** Show that the x-coordinates of the intersection points satisfy x³ − 3x² + 4 = 0. **[2]**

**(b)** Given that x = −1 is a root, factorise x³ − 3x² + 4 fully. **[2]**

**(c)** Hence describe how the curve and the line meet, giving coordinates. **[2]**

**11.** In an invented experiment, the time T seconds for a swing is recorded for different rope lengths L metres.

| L | 0.25 | 1 | 2.25 | 4 |
|---|---|---|---|---|
| T | 1 | 2 | 3 | 4 |

**(a)** Show that T is proportional to √L and find the constant of proportion. **[2]**

**(b)** State what should be plotted to give a straight line through the origin. **[1]**

**(c)** Find L when T = 5. **[1]**

**12.**

**(a)** On the same axes, sketch y = |x − 2| and y = 3/x, showing intercepts and asymptotes. **[3]**

**(b)** Hence find the number of real solutions of x|x − 2| = 3, and find each solution exactly. **[3]**

## Answers

**1.** Roots: crosses at (1, 0), touches at (−2, 0) because of the squared factor [1]. y-intercept: (−1)(4) = −4, so (0, −4) [1]. Positive x³ term: the curve rises from bottom left, touches the axis at x = −2, dips through (0, −4), crosses at x = 1 and rises to top right [1].

**2.** y = a(x + 3)²(x − 2) [1]. At (0, −9): −9 = a(9)(−2) = −18a, so a = 1/2 [1]. **y = ½(x + 3)²(x − 2)** [1].

*Examiner insight:* the y-intercept is the cheapest point for finding a. Assuming a = 1 gives a curve through (0, −18), which does not match.

**3.** Vertex **(2, 0)**, y-intercept **(0, 6)** [1]. Gradients **3** (right arm) and **−3** (left arm) [1].

**4.** Both sides are non-negative, so square: (x + 4)² = 9x² [1]. 8x² − 8x − 16 = 0, so x² − x − 2 = 0 [1]. **x = 2 or x = −1**; check: 6 = 6 and 3 = 3 [1].

**5.** Asymptotes **x = 0 and y = 0** [1]. Both branches lie **below the x-axis**, symmetric in the y-axis, and the curve has no intercepts [1].

**6. (a)** y = k/x, so k = 2.4 × 15 = 36 [1]. When x = 4, **y = 9** [1].

**(b)** A straight line **through the origin** with gradient 36 [1].

**7. (a)** Right arm (x ≥ 2): x − 2 = 2x + 5 gives x = −7, which is not ≥ 2, so it is rejected [1][1]. Left arm (x < 2): 2 − x = 2x + 5 gives **x = −1**; check: |−3| = 3 and 2(−1) + 5 = 3 [1].

**(b)** Squaring gives (x − 2)² = (2x + 5)², whose roots are x = −1 and **x = −7** [1]. At x = −7 the right side 2x + 5 = −9 is negative, but a modulus cannot equal a negative number, so −7 is not a solution [1].

*Examiner insight:* squaring is only safe when both sides are known to be non-negative. When one side is an ordinary expression, use the arms or check every root.

**8. (a)** k/x = 2x − 1, and multiplying by x (x ≠ 0) gives k = 2x² − x, so 2x² − x − k = 0 [1].

**(b)** Tangent: discriminant = 0, so 1 + 8k = 0 [1] and **k = −1/8** [1]. Then 2x² − x + 1/8 = 0 has the repeated root x = 1/4, and y = 2(1/4) − 1 = −1/2, so the contact point is **(1/4, −1/2)** [1].

**(c)** Two points: 1 + 8k > 0, so k > −1/8 [1]. If k = 0 the curve is y = 0 (x ≠ 0), which meets the line once, so **k > −1/8, k ≠ 0** [1].

**9. (a)** x = 0 is not a root, so dividing by x² is valid: x − 2 − 1/x² = 0, giving x − 2 = 1/x² [1]. y = 1/x² is always positive, so the graphs can meet only where x − 2 > 0, that is x > 2 [1]. For x > 2 the line is increasing and the curve is decreasing, so they meet exactly once; hence exactly one real root [1].

**(b)** f(x) = x³ − 2x² − 1: f(2) = −1 and f(3) = 8 [1]. There is a change of sign and f is continuous, so the root lies between 2 and 3 [1].

**10. (a)** 4/x² = 3 − x, so 4 = 3x² − x³ [1], giving x³ − 3x² + 4 = 0 [1].

**(b)** Dividing by (x + 1) gives x² − 4x + 4 [1], so the cubic is **(x + 1)(x − 2)²** [1].

**(c)** The graphs cross at **(−1, 4)** [1]. x = 2 is a repeated root, so the line **touches** the curve at **(2, 1)**: it is a tangent there [1].

*Examiner insight:* "Hence" signals that the repeated factor is the point. Listing x = −1 and x = 2 without saying the line touches at x = 2 misses the interpretation mark.

**11. (a)** T/√L = 1/0.5, 2/1, 3/1.5, 4/2, all equal to 2 [1]. So T ∝ √L with **T = 2√L** [1].

**(b)** Plot **T against √L** [1].

**(c)** √L = 5/2, so **L = 6.25 m** [1].

**12. (a)** y = |x − 2|: a V with vertex (2, 0) and y-intercept (0, 2) [1]. y = 3/x: branches in the first and third quadrants [1], with asymptotes x = 0 and y = 0 labelled [1].

**(b)** x ≠ 0, so the equation is |x − 2| = 3/x. For x < 0 the right side is negative, so there are no solutions [1]. For 0 < x < 2: 2 − x = 3/x gives x² − 2x + 3 = 0, whose discriminant is 4 − 12 < 0, so no solutions [1]. For x ≥ 2: x − 2 = 3/x gives x² − 2x − 3 = 0, so x = 3 (x = −1 is rejected). **One solution: x = 3** [1].

*Examiner insight:* the sketch shows one crossing, on the right arm, but the marks need the algebra for each region. The discriminant explains why the left arm and the hyperbola miss.

## Where marks are usually lost

- Drawing a crossing where a squared factor means the curve should touch.
- Assuming a leading coefficient of 1 when building an equation from a sketch.
- Squaring an equation with a modulus on one side only and keeping a false root.
- Not excluding x = 0 in a hyperbola question.
- Counting a repeated root as two intersection points.
- Describing a proportional graph without "through the origin".
