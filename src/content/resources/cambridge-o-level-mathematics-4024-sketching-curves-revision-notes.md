These notes summarise section 2.11, Sketching curves, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. For explanations and fully worked sketches, see the [sketching curves study guide](/resources/cambridge-o-level-mathematics-4024-sketching-curves/). ## The five types at a glance

| Type | Form | Shape facts | Features to label |
|---|---|---|---|
| Linear | ax + by = c | straight line | both intercepts |
| Quadratic | y = ax² + bx + c | U if a > 0, ∩ if a < 0 | turning point, line of symmetry, roots, y-intercept |
| Cubic | y = ax³ + b | like y = x³, no turning points | y-intercept (0, b), root |
| Cubic | y = ax³ + bx² + cx | through the origin; low-left to high-right if a > 0 | roots, turning points in the right intervals |
| Reciprocal | y = a/x + b | two separate branches | asymptotes x = 0 and y = b, root |
| Exponential | y = arˣ + b | growth if r > 1, decay if 0 < r < 1 (a > 0) | y-intercept (0, a + b), asymptote y = b |

## Key terms

| Term | Meaning |
|---|---|
| Root | where the graph meets the x-axis |
| Turning point | a maximum or minimum point where the curve changes direction |
| Line of symmetry | for a quadratic, the vertical line through the turning point |
| Vertical asymptote | a vertical line the curve approaches but never meets (x = 0 for a/x + b) |
| Horizontal asymptote | a horizontal line the curve approaches (y = b for a/x + b and arˣ + b) |
| Completed-square form | y = a(x + p)² + q, turning point (−p, q) |

## Completing the square for the turning point

1. If a ≠ 1, take a out of the x² and x terms only.
2. Halve the coefficient of x inside the bracket: x² + 2kx = (x + k)² − k².
3. Multiply back by a and collect the constants.
4. Read the turning point: y = a(x + p)² + q has turning point (−p, q). It is a minimum if a > 0 and a maximum if a < 0.

Examples:

- y = x² − 10x + 21 = (x − 5)² − 4, minimum **(5, −4)**, line of symmetry x = 5, roots 3 and 7.
- y = −x² + 6x − 5 = −(x − 3)² + 4, maximum **(3, 4)**, roots 1 and 5, y-intercept −5.

Roots of a quadratic are always symmetrical about the line of symmetry: 3 and 7 are each 2 away from 5.

## Cubic facts

- y = ax³ + bx² + cx: factorise as x(ax² + bx + c); the roots are 0 and the roots of the bracket.
- y = −x³ + 9x = −x(x − 3)(x + 3): roots −3, 0, 3; a < 0, so high on the left and low on the right.
- y = −2x³ + 16: y-intercept 16; root where x³ = 8, so x = 2; no turning points.

## Reciprocal facts

- y = a/x + b: asymptotes x = 0 and y = b.
- Root: solve a/x = −b, so x = −a/b.
- y = −4/x + 1: asymptotes x = 0 and y = 1, root x = 4, branches top left and bottom right because a < 0.

## Exponential facts

- y = arˣ + b passes through (0, a + b) and approaches y = b.
- y = 2ˣ − 8: y-intercept −7, root at 2ˣ = 8, so x = 3, asymptote y = −8.
- If a > 0, the curve always stays above y = b; it never touches it.

## Interpreting a sketch

- Number of solutions of f(x) = k: count how often the line y = k meets the sketch.
- Range of a quadratic: y ≥ q for a minimum at (−p, q); y ≤ q for a maximum.
- A horizontal line at the asymptote level meets a reciprocal or exponential graph **zero** times.

## Exam traps

- Sign error reading the turning point: (x − 5)² gives x = 5, (x + 2)² gives x = −2.
- Completing the square without taking out a when a ≠ 1.
- Curves that touch, cross or bend away from an asymptote.
- A cubic with negative a drawn the wrong way round.
- Forgetting that ax³ + bx² + cx always passes through the origin.
- Unlabelled intercepts, so the sketch cannot be checked.

## Self-test

1. Find the intercepts of 5x + 2y = 20.
2. Write x² − 10x + 21 in the form (x + p)² + q and state the turning point.
3. Write y = 3x² − 12x + 7 in completed-square form and give the turning point.
4. Is the turning point of y = −(x − 3)² + 4 a maximum or a minimum? Give the range of y.
5. Find the roots of y = x³ − 2x² − 8x.
6. Describe the shape of y = −x³ + 9x at the far left and far right.
7. State the asymptotes of y = 5/x + 3.
8. Find the root of y = −4/x + 1.
9. State the y-intercept and asymptote of y = 4(3)ˣ − 1.
10. Explain why y = 2(0.5)ˣ + 3 has no roots.
11. For y = 6/x − 2, how many solutions does 6/x − 2 = k have when k = −2?
12. The point (1, 10) lies on a quadratic with line of symmetry x = 4. Write down another point on the curve.

### Answers

1. x = 0 gives y = 10; y = 0 gives x = 4. **(0, 10) and (4, 0)**.
2. **(x − 5)² − 4**, turning point **(5, −4)**.
3. 3(x² − 4x) + 7 = 3[(x − 2)² − 4] + 7 = **3(x − 2)² − 5**, minimum **(2, −5)**.
4. **Maximum**, so **y ≤ 4**.
5. x(x² − 2x − 8) = x(x − 4)(x + 2), so **x = −2, 0, 4**.
6. a = −1 < 0: **high on the far left, low on the far right**.
7. **x = 0 and y = 3**.
8. −4/x + 1 = 0, so 4/x = 1, **x = 4**.
9. y-intercept 4 − 1 = **3**; asymptote **y = −1**.
10. 2(0.5)ˣ is always positive, so **y is always greater than 3** and never 0.
11. **None**: y = −2 is the horizontal asymptote.
12. (1, 10) is 3 left of x = 4, so **(7, 10)** is on the curve.
