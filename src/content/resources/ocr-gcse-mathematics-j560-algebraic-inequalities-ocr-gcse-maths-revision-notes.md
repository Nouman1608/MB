## Key terms

| Term | Meaning |
|---|---|
| Strict inequality | Uses < or >; the boundary value is not included |
| Inclusive inequality | Uses ≤ or ≥; the boundary value is included |
| Solution set | All the values that make the inequality true |
| Integer solutions | The whole numbers in the solution set |
| Critical values | The values where the two sides are equal; for a quadratic, its roots |
| Set notation | {x \| condition}, read "the set of x such that ..." |
| Union ∪ | Joins two separate pieces of a solution set |
| Region | The part of a graph where every point satisfies the inequalities |

## Number lines

```
x > 2     open circle at 2, arrow right
x ≤ −1    filled circle at −1, arrow left
−2 < x ≤ 4   open circle at −2, filled circle at 4, line between
```

Open circle: not included (< or >). Filled circle: included (≤ or ≥).

## Linear inequalities: method

```
1. Expand brackets; clear fractions by multiplying by a positive number.
2. Collect x terms on one side (choose the side that keeps x positive).
3. Collect numbers on the other side.
4. Divide by the coefficient of x.
   Dividing or multiplying by a NEGATIVE reverses the sign.
5. Double inequality: do each step to all three parts.
```

| Operation on both sides | Sign direction |
|---|---|
| Add or subtract any number | Unchanged |
| Multiply or divide by a positive number | Unchanged |
| Multiply or divide by a negative number | Reversed |
| Swap the two sides over | Reversed (x < 4 is the same as 4 > x) |

Reminder: 4 − 3x ≥ 19 gives −3x ≥ 15, so x ≤ −5.

Reminder: (x + 5)/3 < 2 gives x + 5 < 6, so x < 1.

Reminder: −4 < 2x + 2 ≤ 8 gives −6 < 2x ≤ 6, so −3 < x ≤ 3. Integers: −2, −1, 0, 1, 2, 3.

## Quadratic inequalities (Higher tier only)

```
1. Rearrange to  (quadratic) > 0,  < 0,  ≥ 0  or  ≤ 0.
2. Factorise to find the critical values.
3. Sketch the U-shaped curve through the roots.
4. "> 0" or "≥ 0": the parts ABOVE the axis, outside the roots (two pieces).
   "< 0" or "≤ 0": the part BELOW the axis, between the roots (one piece).
```

| Inequality | Solution | Set notation |
|---|---|---|
| (x − 2)(x − 6) < 0 | 2 < x < 6 | {x \| 2 < x < 6} |
| (x − 2)(x − 6) ≥ 0 | x ≤ 2 or x ≥ 6 | {x \| x ≤ 2} ∪ {x \| x ≥ 6} |
| x² > 16 | x < −4 or x > 4 | {x \| x < −4} ∪ {x \| x > 4} |
| x² ≤ 25 | −5 ≤ x ≤ 5 | {x \| −5 ≤ x ≤ 5} |

If the x² coefficient is negative, multiply the whole inequality by −1 first and reverse the sign, so the curve is U-shaped.

## Regions (Higher tier only)

```
1. Draw each boundary as a line (change the symbol to =).
2. ≤ or ≥: solid line.  < or >: dashed line.
3. Test a point not on the line, e.g. (0, 0).
4. Shade or label as the question instructs.
```

- y > 2x − 1: dashed line; (0, 0) gives 0 > −1, true, so the side containing the origin.
- x + 2y ≥ 6: solid line through (6, 0) and (0, 3); (0, 0) gives 0 ≥ 6, false, so the other side.
- Integer points on a dashed boundary are not in the region.

## Exam traps

- Reversing the sign after subtracting (wrong) or forgetting it after dividing by a negative (wrong).
- In a fraction, multiplying only part of the other side.
- Answers given as x = 3 instead of x ≥ 3.
- End points of integer lists: −3 < x includes −2, not −3.
- x² > 9 written as x > ±3 or x > 3 only.
- Two pieces written as −3 > x > 3, which no number satisfies.
- Wrong circles on a number line, or every boundary line drawn solid.
- Set notation with no braces or no "such that" bar.

## Quick self-test

1. Write "n is at least 12" as an inequality.
2. Solve 5x + 3 > 28.
3. Solve 4 − 3x ≥ 19.
4. Solve 3(2x − 1) ≤ 4x + 9.
5. Solve (x + 5)/3 < 2.
6. Solve −4 < 2x + 2 ≤ 8 and list the integer solutions.
7. Describe the number line for x < −2.
8. (Higher tier only) Solve x² − 7x + 10 < 0.
9. (Higher tier only) Solve x² ≥ 16, giving the answer in set notation.
10. (Higher tier only) List the integers that satisfy x² + x − 12 < 0.
11. (Higher tier only) Should the line for y < 3x + 2 be solid or dashed? Is (0, 0) in the region?
12. (Higher tier only) Is the point (2, 2) in the region x + 2y ≥ 6?

### Answers

1. n ≥ 12
2. 5x > 25, so x > 5
3. −3x ≥ 15, so x ≤ −5
4. 6x − 3 ≤ 4x + 9, 2x ≤ 12, so x ≤ 6
5. x + 5 < 6, so x < 1
6. −3 < x ≤ 3; integers −2, −1, 0, 1, 2, 3
7. Open circle at −2, arrow pointing left
8. (x − 2)(x − 5) < 0, so 2 < x < 5
9. {x | x ≤ −4} ∪ {x | x ≥ 4}
10. (x + 4)(x − 3) < 0 gives −4 < x < 3; integers −3, −2, −1, 0, 1, 2
11. Dashed; 0 < 2 is true, so yes, (0, 0) is in the region
12. 2 + 4 = 6 and 6 ≥ 6 is true, so yes (it lies on the solid boundary)
