File management in Cambridge IGCSE ICT 0417 (Topic 11) means locating, opening, saving and exporting files in a planned folder structure with sensible names, choosing the right file format, and compressing files with .zip or .rar when they are too large to store or send. It is tested in Paper 1 (characteristics of file formats) and underpins every task in the practical Papers 2 and 3.

## 11.1 How should files be organised and named?

- Use a **hierarchical folder structure**: a top folder for a project with subfolders such as *Images*, *Documents* and *Data*.
- Use **meaningful file names** so a file can be found without opening it, for example `Sales_Report_March.docx` rather than `Document1.docx`.
- In the practical exams use **exactly** the name, folder and format the task gives you.
- Save regularly; use **Save As** to create a new version or a different format without overwriting the original.

### What must you be able to save or print?

The syllabus lists: a document, screenshots, database reports, data tables, graphs/charts, a web page in **browser view** and a web page in **HTML view** (the source code).

## Application formats and generic formats

| Application package formats (syllabus list) | Generic formats (syllabus list) |
|---|---|
| .docx, .doc, .xlsx, .xls, .sdb, .sdc, .accdb, .odb, .rtf, .pptx, .ppt | .csv, .txt, .rtf, .pdf, .css, .htm, .jpg, .png |

An **application format** is the native format of one software package and keeps all its features (formulas, styles, slide transitions). A **generic format** can be opened by many different programs on different platforms.

### Why are generic file formats needed?

- The person receiving the file may not have the same software or version.
- Data can be moved between different applications (for example, a .csv export from a spreadsheet imported into a database).
- Files can be opened on different operating systems and devices.

## Characteristics of the syllabus file formats

| Format | Full name | Characteristics and uses |
|---|---|---|
| .css | Cascading Style Sheet | Text file holding styles for web pages; attached to .htm pages |
| .csv | Comma Separated Values | Plain text table; fields separated by commas, one record per line; used to move data between spreadsheets and databases; no formatting or formulas |
| .gif | Graphics Interchange Format | Image format limited to 256 colours; supports simple animation and transparency; small files for logos and icons |
| .htm | HyperText Markup | Web page file written in HTML; opened by a web browser |
| .jpg | Joint Photographic Experts Group | Compressed image format for photographs; small file size, some quality lost |
| .pdf | Portable Document Format | Keeps the exact layout and fonts; opens on most devices; difficult to edit, so good for final documents |
| .png | Portable Network Graphics | Compressed image with no loss of quality; supports transparency; good for graphics and screenshots |
| .rtf | Rich Text Format | Text with basic formatting (fonts, bold, italic); opened by most word processors |
| .txt | Text | Plain text only; no formatting; very small; opened by any text editor |
| .zip | Zip archive | Compressed file that can hold one or more files and folders |
| .rar | Roshal Archive | Compressed archive similar to zip; needs suitable software to create |

## 11.2 Why reduce file sizes, and how?

**Need to reduce file size:**

- Saves storage space on a device, server or cloud account.
- Files upload, download and transfer faster.
- Email systems often limit attachment size.
- Uses less bandwidth when transmitting.

**Method**: compress the file or files into a **.zip** or **.rar** archive. Several files can be grouped into one archive, which is easier to send. The receiver extracts (unzips) the archive to use the files.

## Worked example: choosing a format

*A teacher has a class list in a spreadsheet. She needs to send it to the school office, which uses a different database program, and to parents as a document that must not change.*

- To the office: export as **.csv**, because it is a generic format that the database can import, keeping the fields and records.
- To parents: save as **.pdf**, because the layout is fixed and it can be opened on almost any device without the original software.
- Several class lists at once: put them in a **.zip** file to reduce the size and send one attachment.

## Common mistakes and exam traps

- Saving with the wrong name, wrong case or in the wrong folder in Papers 2 and 3 — follow the instruction exactly.
- Saying .csv keeps formulas or formatting. It stores only the values, separated by commas.
- Confusing .htm (the web page) with .css (the stylesheet).
- Calling .rtf a generic format that keeps everything. It keeps basic text formatting only.
- Writing "makes the file smaller" as the *need* for compression. Say why that matters: faster transmission, attachment limits, less storage.

## Frequently asked questions

**What is a generic file format?**
A generic file format is one that can be opened by many different applications, not just the software that created it. Examples in the 0417 syllabus are .csv, .txt, .rtf, .pdf, .css, .htm, .jpg and .png.

**What is the difference between .jpg and .png?**
Both are compressed image formats. JPG loses some quality to make photographs small, while PNG keeps full quality and supports transparency, so it suits graphics and screenshots.

**Why compress files before emailing them?**
Many email systems limit attachment size, and smaller files upload and download faster. A .zip or .rar archive can also combine several files into one attachment.

**What is the difference between browser view and HTML view of a web page?**
Browser view shows the page as a visitor sees it. HTML view shows the source code of the page.

## Self-test

1. Give two reasons for using a hierarchical folder structure.
2. State the file format used to move data from a spreadsheet to a database.
3. Give one characteristic of .gif.
4. Name two compressed archive formats in the syllabus.

*Answers: 1 files easier to find, related files kept together, less risk of overwriting; 2 .csv; 3 256 colours / supports animation / transparency / small files; 4 .zip and .rar; 5 the layout stays the same on any device and the employer does not need the original software.*
