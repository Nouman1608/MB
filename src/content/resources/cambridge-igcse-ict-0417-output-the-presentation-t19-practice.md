## Section A: short answers

**1.** Which printout shows one slide per page with the speaker's notes underneath?

A: handouts

B: full page slides

C: presenter notes

D: outline **[1]**

**2.** State **two** features of a looped on-screen carousel. **[2]**

**3.** A presentation has 20 slides. Calculate the number of pages needed to print handouts with 6 slides per page. **[1]**

**4.** State **one** reason why a speaker would print presenter notes. **[1]**

**5.** Give **one** advantage and **one** disadvantage of printing handouts with 9 slides per page rather than 3. **[2]**

**6.** State what happens to a hidden slide when a carousel runs. **[1]**

## Section B: structured questions

**7.** A cinema wants a presentation showing upcoming films on a screen in its foyer. It will run all day without staff.

**(a)** State the most suitable display method.

**(b)** Describe **three** settings needed so that the presentation runs as required.

**(c)** Explain why the presentation should not include a sound clip on every slide. **[5]**

**8.** A carousel has 16 slides, of which 4 are hidden. Each visible slide is shown for 15 seconds.

**(a)** Calculate the time taken for one complete loop. Give your answer in minutes and seconds.

**(b)** Calculate how many complete loops run in one hour.

**(c)** The manager wants one loop to last exactly 2 minutes with the same slides visible. Calculate the time each slide should be shown. **[4]**

**9.** A teacher uses the cinema-style carousel settings in a lesson. The slides keep changing while she is still explaining them.

**(a)** Explain why this happens.

**(b)** Describe how she should set up the show for her lesson.

**(c)** Give **two** advantages of a presenter-controlled show for a lesson. **[5]**

**10.** A speaker is giving a talk with a 13-slide presentation. She wants a printout to use while speaking, and the 30 people in the audience each need a copy of the slides with space to write notes.

**(a)** State the printout the speaker should use and describe what it contains.

**(b)** State a suitable printout for the audience and justify your choice.

**(c)** Calculate the number of pages printed for one audience member using 3 slides per page. **[5]**

**11.** A task says: "Print the presentation as handouts with 4 slides per page. Your name must appear in the header of each page." A student puts her name in the footer of the master slide.

Explain why this does not meet the instruction and describe what she should do. **[3]**

**12.** Compare full page slides and handouts as printed outputs. **[4]**

**13.** A museum exhibition uses the same presentation in two ways: as a carousel between guided tours and as a presenter-controlled show during each tour.

Describe how the settings must be changed when a guide starts a tour, and explain why. **[3]**

## Answers

**1.** C: presenter notes. **[1]**

**2.** Any two, 1 mark each: slides advance automatically (1); uses slide timings (1); restarts from the first slide after the last, looping continuously (1); needs no presenter (1); runs until Esc is pressed (1). **[2]**

**3.** 20 ÷ 6 = 3.33, rounded up to 4 pages (1). **[1]**

**4.** Any one: to remind them what to say for each slide (1); to see each slide with its notes while speaking (1). **[1]**

**5.** Advantage: fewer pages, saving paper or cost (1). Disadvantage: each slide is smaller and harder to read, or there is no space for notes (1). **[2]**

**6.** It is skipped; it is not shown (1). **[1]**

**7. (a)** A looped on-screen carousel (1).

**(b)** 1 mark each, any three: set a timing on every slide so it advances automatically (1); set the show to loop continuously until Esc, or use kiosk mode (1); set the show to use timings, not manual advance (1); apply consistent transitions so the change between slides is smooth (1).

**(c)** The sound would repeat all day in a public area, annoying staff and customers (1). **[5]**

**8. (a)** Visible slides: 16 − 4 = 12; 12 × 15 = 180 seconds = 3 minutes 0 seconds (1).

**(b)** 3600 ÷ 180 = 20 loops (1).

**(c)** 2 minutes = 120 seconds (1); 120 ÷ 12 = 10 seconds per slide (1). **[4]**

**9. (a)** The slides have timings and the show is set to use them, so they advance automatically after a set time (1).

**(b)** Set the show to be presented by a speaker with manual advance (1), so the timings are not used (1).

**(c)** Any two, 1 mark each: she controls the pace (1); she can pause for questions (1); she can go back or jump to a slide using links or buttons (1); she can use presenter view to see her notes (1). **[5]**

**10. (a)** Presenter notes (notes pages) (1), showing each slide, one per page, with her notes underneath (1).

**(b)** Handouts with 3 slides per page (1), because this layout normally includes lines beside each slide for the audience to write notes (1).

**(c)** 13 ÷ 3 = 4.33, rounded up to 5 pages (1). **[5]**

**11.** The master slide footer appears on the slides, not in the header of the handout pages (1). The instruction asks for the name in the header of each printed page (1). She should add her name in the header settings for notes and handouts and then print handouts with 4 slides per page (1). **[3]**

**12.** 1 mark each, up to 4:
- Full page slides print one slide per page; handouts print several slides per page (1).
- Full page slides are larger and easier to read; handout slides are smaller (1).
- Handouts use fewer pages and less paper (1).
- Full page slides suit checking detail or display; handouts suit giving the audience a copy to take away (1).
- Some handout layouts include space for audience notes; full page slides do not (1). **[4]**

**13.** Change the show from looped with timings to presenter controlled with manual advance (1). Explanation: during a tour the guide needs to set the pace and talk about each slide for as long as needed (1); if the timings stayed on, slides would change while the guide was speaking (1). **[3]**

## Frequently asked questions

**Are "presenter notes" and "notes pages" the same thing?**
Yes, for printing. The syllabus calls the printout presenter notes; many packages call the same layout notes pages.

**Do I need to know exact menu names, such as kiosk mode?**
No. Describe the settings: timings on each slide, looping until Esc and using timings for a carousel; manual advance for a presenter-controlled show.
