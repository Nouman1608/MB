These questions cover **3.1.4.3 Applications of Hess's law** of the OxfordAQA International AS and A-level Chemistry (9620) specification, Version 5.3. It is International AS content, examined in Unit 1. Section A has short recall and application questions; Section B has longer, structured questions. All enthalpy values are in kJ mol⁻¹ and are supplied for these questions. If a point is unfamiliar, read the [Hess's law study guide](/resources/oxfordaqa-a-level-chemistry-9620-oxfordaqa-a-level-chemistry-3-1-4-3/) or the [Hess's law revision notes](/resources/oxfordaqa-a-level-chemistry-9620-oxfordaqa-a-level-chemistry-3-1-4-3-revision-notes/) first.

## Questions

### Section A

**1.** State Hess's law. **[2]**

**2.** Calculate ΔH for Fe₂O₃(s) + 3CO(g) → 2Fe(s) + 3CO₂(g). ΔfH: Fe₂O₃(s) −824, CO(g) −111, CO₂(g) −394. **[3]**

**3.** Explain why no enthalpy of formation value for Fe(s) is needed in question 2. **[1]**

**4.** For N₂(g) + 3H₂(g) → 2NH₃(g), ΔH = −92. State ΔH for NH₃(g) → ½N₂(g) + 1½H₂(g). **[1]**

**5.** Calculate the standard enthalpy of formation of propane, C₃H₈(g). ΔcH: C(s) −394, H₂(g) −286, C₃H₈(g) −2220. **[2]**

**6.** Explain why the enthalpy of formation of propane cannot be measured directly. **[1]**

### Section B

**7.** In the manufacture of nitric acid, ammonia is oxidised: 4NH₃(g) + 5O₂(g) → 4NO(g) + 6H₂O(g). ΔfH: NH₃(g) −46, NO(g) +90, H₂O(g) −242.

**(a)** Draw a labelled Hess cycle for this reaction using enthalpies of formation. **[2]**

**(b)** Calculate ΔH for the reaction. **[3]**

**(c)** State why no value is given for O₂(g). **[1]**

**8.** Butane and methylpropane are isomers, C₄H₁₀. ΔcH: butane −2877, methylpropane −2869.

**(a)** Calculate ΔH for butane → methylpropane. **[2]**

**(b)** Explain why the two combustion values can be used in one cycle. **[1]**

**(c)** State which isomer has the lower enthalpy. **[1]**

**9.** Use these equations to calculate ΔH for 2NO₂(g) → N₂O₄(g). Show your working.

```
N₂(g) + 2O₂(g) → 2NO₂(g)        ΔH = +66
N₂(g) + 2O₂(g) → N₂O₄(g)        ΔH = +9
```

**[3]**

**10.** The enthalpy change for MgCO₃(s) → MgO(s) + CO₂(g) is found by reacting each solid separately with excess hydrochloric acid:

```
ΔH₁: MgCO₃(s) + 2HCl(aq) → MgCl₂(aq) + CO₂(g) + H₂O(l)     ΔH₁ = −46
ΔH₂: MgO(s) + 2HCl(aq) → MgCl₂(aq) + H₂O(l)                ΔH₂ = −146
```

**(a)** Draw a Hess cycle linking the decomposition to the two reactions with acid. **[2]**

**(b)** Calculate ΔH for the decomposition. **[2]**

**(c)** Suggest why the decomposition enthalpy is not measured directly. **[1]**

**11.** Glucose, C₆H₁₂O₆(s), has ΔcH = −2803. ΔcH: C(s) −394, H₂(g) −286.

**(a)** Write the equation for the standard enthalpy of formation of glucose. **[1]**

**(b)** Calculate the standard enthalpy of formation of glucose. **[3]**

**12.** Hydrogen is made by reacting methane with steam: CH₄(g) + H₂O(g) → CO(g) + 3H₂(g). ΔfH: CH₄(g) −75, H₂O(g) −242, CO(g) −111.

**(a)** Calculate ΔH for this reaction. **[2]**

**(b)** State whether the reaction is exothermic or endothermic. **[1]**

**(c)** Explain how the answer to (a) would change if the value for H₂O(l), −286, were used by mistake. **[1]**

## Answers

### Section A

**1.** The enthalpy change for a reaction is independent of the route taken [1]; provided the initial and final conditions are the same [1] **[2]**

**2.** ΔH = ΣΔfH(products) − ΣΔfH(reactants) [1]; = 3(−394) − [−824 + 3(−111)] = −1182 − (−1157) [1]; = **−25 kJ mol⁻¹** [1] **[3]**

**3.** Iron is an element in its standard state, so its ΔfH is zero [1] **[1]**

**4.** **+46 kJ mol⁻¹** (reverse sign, then halve) [1] **[1]**

**5.** ΔfH = [3(−394) + 4(−286)] − (−2220) = −2326 + 2220 [1]; = **−106 kJ mol⁻¹** [1] **[2]**

*Examiner insight:* With combustion data the order is reactants minus products; reversing it gives +106.

**6.** Carbon and hydrogen do not react directly to form propane (any other products would form, or no reaction) [1] **[1]**

### Section B

**7. (a)** Reaction across the top; elements (N₂, H₂, O₂) at the bottom [1]; arrows upwards from the elements to reactants and to products, labelled 4 × ΔfH(NH₃) and 4 × ΔfH(NO) + 6 × ΔfH(H₂O) [1]

**(b)** ΣΔfH(products) = 4(+90) + 6(−242) = −1092 [1]; ΣΔfH(reactants) = 4(−46) = −184 [1]; ΔH = −1092 − (−184) = **−908 kJ mol⁻¹** [1]

**(c)** O₂ is an element in its standard state, so ΔfH = 0 [1] **[6]**

**8. (a)** ΔH = ΔcH(butane) − ΔcH(methylpropane) [1]; = −2877 − (−2869) = **−8 kJ mol⁻¹** [1]

**(b)** Both isomers burn to give the same products, 4CO₂ + 5H₂O, so the two combustion routes meet at the same point [1]

**(c)** Methylpropane [1] **[4]**

**9.** Reverse the first equation: 2NO₂(g) → N₂(g) + 2O₂(g), ΔH = −66 [1]; add the second equation, so N₂ and 2O₂ cancel [1]; ΔH = −66 + 9 = **−57 kJ mol⁻¹** [1] **[3]**

**10. (a)** MgCO₃ → MgO + CO₂ across the top; MgCl₂(aq) + H₂O(l) + CO₂(g) at the bottom [1]; arrows from MgCO₃ down labelled ΔH₁ and from MgO + CO₂ down labelled ΔH₂ [1]

**(b)** ΔH = ΔH₁ − ΔH₂ [1]; = −46 − (−146) = **+100 kJ mol⁻¹** [1]

**(c)** It needs strong heating, so the heat taken in cannot be measured easily with a calorimeter (or the reaction is slow and may be incomplete) [1] **[5]**

**11. (a)** 6C(s) + 6H₂(g) + 3O₂(g) → C₆H₁₂O₆(s) [1]

**(b)** ΔfH = [6ΔcH(C) + 6ΔcH(H₂)] − ΔcH(glucose) [1]; = [6(−394) + 6(−286)] − (−2803) = −4080 + 2803 [1]; = **−1277 kJ mol⁻¹** [1] **[4]**

*Examiner insight:* The O₂ in the formation equation is not burned and has no combustion value; only C, H₂ and glucose appear in the calculation.

**12. (a)** ΔH = −111 − [−75 + (−242)] [1]; = −111 + 317 = **+206 kJ mol⁻¹** [1]

**(b)** Endothermic [1]

**(c)** The reactant total would be 44 more negative, so ΔH would be 44 kJ mol⁻¹ larger (+250 kJ mol⁻¹), which is wrong because the steam is a gas [1] **[4]**

## Where marks are usually lost

- Using "products minus reactants" with combustion data.
- Forgetting balancing numbers.
- Giving elements a non-zero ΔfH.
- Reversing an equation without changing the sign.
- Unlabelled cycle arrows, or arrows pointing the wrong way.
