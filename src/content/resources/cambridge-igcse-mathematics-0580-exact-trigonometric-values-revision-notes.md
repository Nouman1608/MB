These notes condense subtopic **E6.3 Exact trigonometric values** from Topic 6 Trigonometry of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. It is **Extended only** (the Core syllabus lists C6.3 as "Extended content only") and is mostly tested on the non-calculator Paper 2. For worked examples, read the [exact trigonometric values study guide](/resources/cambridge-igcse-mathematics-0580-exact-trigonometric-values/); to practise, use the [exact trigonometric values practice questions](/resources/cambridge-igcse-mathematics-0580-exact-trigonometric-values-practice/).

## The statement

Know the exact values of sin x and cos x for x = 0°, 30°, 45°, 60° and 90°, and of tan x for x = 0°, 30°, 45° and 60°.

## The table

| x | 0° | 30° | 45° | 60° | 90° |
|---|---|---|---|---|---|
| sin x | 0 | 1/2 | √2/2 | √3/2 | 1 |
| cos x | 1 | √3/2 | √2/2 | 1/2 | 0 |
| tan x | 0 | √3/3 | 1 | √3 | not required |

**Recall patterns**

```
sin from 0° to 90°:  √0/2, √1/2, √2/2, √3/2, √4/2
cos: the same list in reverse
tan: 0, √3/3, 1, √3   (each is opposite ÷ adjacent in the triangles below)
```

## The two triangles

```
45° triangle      sides 1, 1, √2         angles 45°, 45°, 90°
half-equilateral  sides 1, √3, 2         1 opposite 30°, √3 opposite 60°, 2 = hypotenuse
```

Scale them: a 45° triangle with short sides 7 has hypotenuse 7√2; a 30°–60°–90° triangle with hypotenuse 10 has sides 5 and 5√3.

## Key terms

| Term | Meaning |
|---|---|
| Exact value | A value written with integers, fractions and surds, never a rounded decimal |
| Surd | An irrational root such as √2 or √3 |
| Rationalise the denominator | Multiply top and bottom by the surd so no root is left on the bottom: 1/√3 = √3/3 |
| Equivalent forms | 1/√2 = √2/2 and 1/√3 = √3/3 |
| Acute angle | Between 0° and 90°; exact-value equations here use this range |

## Recognising decimals

On a calculator paper, these decimals signal a special angle.

| Decimal | Exact form | Angle |
|---|---|---|
| 0.5 | 1/2 | sin 30°, cos 60° |
| 0.7071… | √2/2 | sin 45°, cos 45° |
| 0.8660… | √3/2 | sin 60°, cos 30° |
| 0.5773… | √3/3 | tan 30° |
| 1.7320… | √3 | tan 60° |

## Surd rules used most

```
√3 × √3 = 3          √2 × √2 = 2
a ÷ (b/c) = a × c/b
k/√n = k√n / n       e.g. 12/√2 = 6√2,  9/√3 = 3√3
unlike surds do not combine:  4 + 4√3 stays as it is
```

**Worked reminder.** Exact value of 6 cos 30° − 2 tan 60°:

```
6 × √3/2 − 2 × √3 = 3√3 − 2√3 = √3
```

## Equations with exact values

| Equation (0° ≤ x ≤ 90°) | Rearranged | x |
|---|---|---|
| 2 sin x = 1 | sin x = 1/2 | 30° |
| √2 cos x = 1 | cos x = √2/2 | 45° |
| tan x − √3 = 0 | tan x = √3 | 60° |
| 2 cos x = 0 | cos x = 0 | 90° |

## Two triangles sharing a side

Paper 2 often joins a 45° triangle and a 30°–60°–90° triangle along a common height. Find the shared side first, then scale each special triangle.

**Worked reminder.** A perpendicular from A meets BC at D, with AD = 4 cm, angle B = 45° and angle C = 60°.

```
triangle ABD (45°):  BD = 4,  AB = 4√2
triangle ACD (60° at C): AD is opposite 60°, so DC = 4/√3 = 4√3/3
BC = 4 + 4√3/3
```

The side opposite 60° is the **√3** side of the 1 : √3 : 2 triangle, so the side opposite 30° (here DC) is AD ÷ √3.

## Exam traps

- Swapping √2/2 and √3/2.
- Writing the √3 side opposite the 30° angle; the shortest side is opposite the smallest angle.
- Assuming sin 2x = 2 sin x: sin 60° is not 2 × sin 30°.
- sin² 45° means (sin 45°)² = 1/2, not sin(45²).
- Adding unlike surds, such as 3 + 3√3 = 6√3.
- Leaving a surd in the denominator when "simplest form" is asked.
- Replacing an exact answer with a rounded decimal.
- Giving a value for tan 90°.

## Self-test

1. Find the exact value of sin 30° + cos 60°.
2. Find the exact value of tan 45° − sin 90°.
3. Find the exact value of cos 30° × tan 30°.
4. Find the exact value of sin² 60° + cos² 60°.
5. Find the exact value of 2 sin 45° cos 45°.
6. Find the exact value of tan 60° ÷ tan 30°.
7. A right-angled triangle has hypotenuse 14 cm and an angle of 30°. Find the exact lengths of the other two sides.
8. A 45° right-angled triangle has two sides of 5 cm. Find the exact hypotenuse.
9. The side adjacent to a 30° angle in a right-angled triangle is 4√3 cm. Find the opposite side and the hypotenuse.
10. Solve sin x = 1/2 for 0° ≤ x ≤ 90°.
11. Solve √3 tan x = 3 for 0° ≤ x ≤ 90°.
12. Solve cos x = 0 for 0° ≤ x ≤ 90°.

### Answers

1. 1/2 + 1/2 = **1**
2. 1 − 1 = **0**
3. √3/2 × 1/√3 = **1/2**
4. 3/4 + 1/4 = **1**
5. 2 × √2/2 × √2/2 = 2 × 2/4 = **1**
6. √3 ÷ (1/√3) = **3**
7. **7 cm** (opposite 30°) and **7√3 cm**
8. **5√2 cm**
9. Opposite = 4√3 × √3/3 = **4 cm**; hypotenuse = **8 cm**
10. **x = 30°**
11. tan x = 3/√3 = √3, so **x = 60°**
12. **x = 90°**
