## Section A: short answers

**1.** State what a person receives when they buy a copy of a word-processing program. **[1]**

**2.** Which **one** of these is a method used to prevent software copyright being broken?

A: firewall

B: dongle

C: spam filter

D: biometric scanner **[1]**

**3.** Give **two** reasons why software is easier to pirate than a printed book. **[2]**

**4.** Name the type of licence a college would buy so that a program can be installed on every computer on its campus. **[1]**

**5.** Give **two** examples of actions that break the copyright of a computer game. **[2]**

**6.** State **one** limitation of using a hologram on software packaging to prevent piracy. **[1]**

## Section B: structured questions

**7.** A small accountancy firm has eight computers. The manager buys one copy of a tax program with a single-user licence and asks a member of staff to install it on all eight computers.

**(a)** Explain why this breaks copyright. **[2]**

**(b)** Describe how online activation would prevent the program being used on the other computers. **[3]**

**(c)** Suggest what the firm should have bought instead. **[1]**

**8.** A games company is worried about illegal copies of its new game being sold online.

**(a)** Describe **two** effects that the illegal copies could have on the company. **[2]**

**(b)** Describe **two** risks to a customer who buys one of the illegal copies. **[2]**

**9.** A design company protects its software with a dongle.

**(a)** Describe how a dongle prevents the software being used illegally. **[2]**

**(b)** Give **one** disadvantage of a dongle for a legitimate user. **[1]**

**10.** Explain why copyright legislation is needed for computer software. **[4]**

**11.** A student says: "I bought this program, so I can put it on my friend's laptop as well." Explain whether the student is correct, referring to the principles of software copyright. **[3]**

**12.** A software producer currently relies only on a licence agreement that users accept during installation. Evaluate **three** other methods the producer could add to prevent its copyright being broken. **[6]**

## Answers

**1.** A licence to use the program (not ownership of the program or its copyright). **[1]**

**2.** B: dongle. **[1]**

**3.** Any two: a copy costs almost nothing to make (1); each digital copy is identical to the original (1); copies can be distributed quickly over the internet (1). **[2]**

**4.** A site licence. **[1]**

**5.** Any two: giving a copy to a friend (1); selling copies (1); downloading the game from an unauthorised site (1); installing it on more devices than the licence allows (1); modifying the game's code without permission (1); using a crack to bypass activation (1). **[2]**

**6.** It helps buyers recognise genuine packaging but does not stop the program being copied digitally or downloaded (1). **[1]**

**7. (a)** A single-user licence permits use on only one computer (1); the other seven installations are unlicensed copies, which is software piracy (1).

**(b)** The product key is sent to the producer's server when the program is first installed (1). The server links the key to that computer (1). When the same key is entered on another computer, the server recognises it has already been activated and refuses to activate the program, so it will not run (1).

**(c)** A multi-user licence for eight computers, or a site licence (1). **[6]**

**8. (a)** Any two: loss of income from sales (1); less money to develop updates or new games (1); possible job losses (1); damage to reputation if illegal copies contain malware or bugs (1).

**(b)** Any two: the copy may contain malware such as a virus or spyware (1); no updates, patches or technical support (1); the customer may be fined or prosecuted (1); the copy may stop working if the producer detects it (1). **[4]**

**9. (a)** The dongle is a small hardware device that must be plugged into the computer (1); the software checks for the dongle and will only run while it is present, so a copy installed elsewhere will not run (1).

**(b)** Any one: if the dongle is lost or damaged the software cannot be used (1); it occupies a port (1); the software can only be used on one computer at a time (1). **[3]**

**10.** Software takes a great deal of time and money to develop (1). It can be copied quickly and cheaply, and each copy is identical to the original (1). Copyright law makes copying without permission illegal, so the producer earns income from each licence (1). It also allows the producer to take legal action against people who copy the software (1). Credit also: protects income needed to fund future development or updates (1). Maximum 4. **[4]**

**11.** The student is not correct (1). Buying software buys a licence to use it, while the copyright stays with the producer (1). Unless the licence allows more than one device, installing it on the friend's laptop is an unauthorised copy and is software piracy (1). **[3]**

**12.** Up to 6 marks for three methods, each described (1) and evaluated (1):
- Product key: a unique code must be entered before the program will install or run (1); but keys can be shared or produced by key generators (1).
- Online activation: the key is checked by the producer's server and linked to one device (1); this stops one key being used on many computers, but needs an internet connection (1).
- Dongle: the program runs only when the hardware device is plugged in (1); very hard to copy, but it can be lost and adds cost (1).
- Encryption: the program code only runs with the correct decryption key (1); difficult to defeat but adds cost and complexity (1).
- Subscription account: the software only works while the user is signed in to a paid account (1); regular checks make piracy hard, but legitimate users need internet access (1).

Credit a concluding judgement that combining methods is more effective than any one alone. **[6]**

## Frequently asked questions

**Do I need to name a copyright law?**
No. The 0417 syllabus asks why copyright legislation is needed and what it means for software, not for the names of particular laws.

**Is a firewall a copyright protection method?**
No. A firewall protects a computer or network from unauthorised access. Copyright protection methods are things such as product keys, activation, dongles and licence agreements.
