## Index notation for repeated products

The index counts how many times the base appears as a factor.

```
5 × 5 × 5 × 7 × 7 = 5³ × 7²
10 × 10 × 10 × 10 × 10 × 10 = 10⁶ = 1 000 000
```

Different bases stay separate. 5³ × 7² cannot be combined into one power.

## Recognising powers

One number can be several different powers. Spotting this is the key to most index questions.

| Number | As powers |
|---|---|
| 16 | 2⁴, 4² |
| 64 | 2⁶, 4³, 8² |
| 81 | 3⁴, 9² |
| 125 | 5³ |
| 243 | 3⁵ |
| 625 | 5⁴, 25² |
| 1 000 | 10³ |

## Roots: exact values and two answers

A square root of n is a number that squares to n. Every positive number has two square roots, one positive and one negative: both 7² and (−7)² equal 49. The symbol √49 means the positive root only, 7. If x² = 49, then x = 7 or x = −7, written x = ±7.

A cube root has only one real value, and it keeps the sign: ∛(−27) = −3, because (−3)³ = −27.

**Roots of fractions and decimals** ("calculate with roots").

```
√(9/16) = √9/√16 = 3/4
√0.49   = 0.7          (0.7² = 0.49)
∛0.008  = 0.2          (0.2³ = 0.008)
√144 + ∛(−64) = 12 + (−4) = 8
```

Count decimal places to check: squaring a number with one decimal place gives two, so √0.49 must have one decimal place.

## Negative and zero indices

A negative index means "one over" the positive power; the zero index gives 1.

```
4⁻²     = 1/4² = 1/16
10⁻³    = 1/1 000 = 0.001
(1/5)⁻² = 5² = 25
7⁰      = 1
2⁻¹ + 4⁻¹ = 1/2 + 1/4 = 3/4
```

For a fraction raised to a negative power, flip the fraction and make the index positive. A negative index never makes the value negative: 4⁻² is a small positive number.

## The laws of indices with numbers

```
3⁴ × 3⁵   = 3⁹              add the indices
5⁷ ÷ 5⁹   = 5⁻² = 1/25      subtract the indices
(7²)³     = 7⁶              multiply the indices
(2³)⁻²    = 2⁻⁶ = 1/64
```

The laws need the **same base**. When the bases differ, try to rewrite them as powers of one base.

**Worked example 1.** Write 8² × 4³ as a power of 2, and work out 9⁴ ÷ 27.

```
8² × 4³ = (2³)² × (2²)³ = 2⁶ × 2⁶ = 2¹²

9⁴ ÷ 27 = (3²)⁴ ÷ 3³ = 3⁸ ÷ 3³ = 3⁵ = 243
```

**Worked example 2.** Find the value of x in each equation.

```
2ˣ = 8⁴           8⁴ = (2³)⁴ = 2¹²,  so x = 12
3ˣ⁺¹ = 81         81 = 3⁴, so x + 1 = 4 and x = 3
5ˣ = 1/125        1/125 = 5⁻³, so x = −3
```

Once both sides are written with the same base, the indices must be equal.

## Fractional indices (Higher tier only)

The denominator of a fractional index is a root; the numerator is a power.

```
a^(1/n) = ⁿ√a
a^(m/n) = (ⁿ√a)ᵐ
```

**Worked example 3 (Higher tier only).** Evaluate 81^(3/4), 4^(5/2), (16/81)^(−1/4) and 1 000^(−2/3).

```
81^(3/4)       = (⁴√81)³ = 3³ = 27
4^(5/2)        = (√4)⁵ = 2⁵ = 32
(16/81)^(−1/4) = (81/16)^(1/4) = 3/2
1 000^(−2/3)   = 1/(∛1 000)² = 1/10² = 1/100
```

Take the root first: it keeps the numbers small. The specification's example, 16^(−3/4) = 1/(16^(1/4))³ = 1/2³ = 1/8, follows the same pattern.

**Combinations of powers and roots (Higher tier only).** √8 = (2³)^(1/2) = 2^(3/2), and 1/∛4 = (2²)^(−1/3) = 2^(−2/3). Writing a root as a fractional power lets you use the laws of indices on it: 2^(3/2) × 2^(1/2) = 2² = 4, which is √8 × √2 = √16.

## Estimating powers and roots (Higher tier only)

Find the perfect powers either side, then judge which is closer.

**Worked example 4 (Higher tier only).**

```
√51 to the nearest whole number:
  7² = 49, 8² = 64; 51 is much closer to 49, so √51 ≈ 7

∛130:  5³ = 125 and 6³ = 216, so ∛130 ≈ 5

2.9⁴:  close to 3⁴ = 81, and a little less

√(98.7 × 0.51):  ≈ √(100 × 0.5) = √50 ≈ 7
```

For a nearest-whole-number answer that is close to halfway, test the midpoint: 7.5² = 56.25, and 51 < 56.25, so √51 is below 7.5 and rounds to 7.

## Common mistakes

- Reading 2⁴ as 2 × 4 = 8.
- Giving only +7 when x² = 49 asks for all values of x.
- Writing 4⁻² as −16 or −8.
- Adding indices when the bases differ, as in 2³ × 3² = 6⁵.
- Multiplying indices for a product instead of adding them: 3⁴ × 3⁵ is 3⁹, not 3²⁰.
- (Higher tier only) Applying the power before the root in a fractional index, which creates huge numbers.
- (Higher tier only) Treating a^(1/2) as a/2.

## Exam technique

- **"Write as a single power"** or **"in index form"**: the answer is one base with one index, such as 2¹².
- **"Find the value"** or **"Evaluate"**: give an ordinary number, such as 1/64.
- **"Find x"**: show both sides rewritten with the same base before equating the indices.
- **Non-calculator papers**: learn the powers table above; it turns most questions into recognition.
