This practice set covers section 2.3 of IB Diploma Programme Mathematics: Analysis and Approaches: sketching graphs from information or a context, transferring graphs from a GDC to paper, and graphing sums and differences of functions. It is for SL and HL. Questions are labelled "(calculator-free)" or "(calculator allowed)". For sketch questions the answers list the features a full-mark sketch must show, one mark per feature. Give GDC answers to 3 significant figures.

Learn the methods first in the [2.3 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-3/) and the [2.3 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-3-revision-notes/).

## Section A

**1.** (calculator-free) Sketch the graph of y = (x + 1)(x − 3), labelling the axis intercepts and the vertex. **[3]**

**2.** (calculator allowed) Sketch the graph of y = x³ − 3x² for −1 ≤ x ≤ 4, labelling the end points and the turning points with their coordinates. **[4]**

**3.** (calculator-free) A cup of coffee at 85 °C is left to cool in a room at 20 °C. Sketch a graph of its temperature T °C against time t minutes. **[3]**

**4.** (calculator allowed) Let f(x) = x²e^(−x) for 0 ≤ x ≤ 5. Find the coordinates of the maximum point and of both end points of the graph. **[3]**

**5.** (calculator allowed) Use technology to sketch y = x + 1/x for −4 ≤ x ≤ 4, x ≠ 0, labelling the turning points and the vertical asymptote. **[3]**

**6.** (calculator-free) A function has domain −2 ≤ x < 3. State how each end of its graph should be shown. **[2]**

## Section B

**7.** (calculator allowed) Let h(x) = 2ˣ − x² for −2 ≤ x ≤ 5.

**(a)** Find the zeros of h. **[3]**
**(b)** Find the coordinates of the local maximum and local minimum points of h. **[2]**
**(c)** Hence solve 2ˣ > x² for −2 ≤ x ≤ 5. **[2]**

**8.** (calculator-free) A function f has domain −2 ≤ x ≤ 5. Also f(−2) = 3, f(5) = 2, the zeros of f are x = 1 and x = 4, and the only turning point is a minimum at (2.5, −2).

**(a)** Sketch the graph of y = f(x). **[4]**
**(b)** Write down the range of f. **[1]**
**(c)** Find the number of solutions of f(x) = 2.5, giving a reason. **[2]**

**9.** (calculator allowed) In this invented model, the concentration of a medicine in the blood t hours after a dose is C(t) = 20te^(−0.4t) mg per litre, for 0 ≤ t ≤ 12.

**(a)** Find the maximum concentration and the time at which it occurs. **[2]**
**(b)** Find C(12). **[1]**
**(c)** Sketch the graph of C. **[3]**
**(d)** Find the length of time for which C(t) > 10. **[3]**

**10.** (calculator allowed) Let f(x) = ln x + x/2 − 2 for 0 < x ≤ 6.

**(a)** Write down the equation of the vertical asymptote of the graph. **[1]**
**(b)** Find the zero of f. **[1]**
**(c)** Find f(6). **[1]**
**(d)** Sketch the graph of f. **[3]**

**11.** (calculator-free) Let f(x) = 4 − x² and g(x) = 2x, and let h(x) = f(x) + g(x).

**(a)** Write h(x) in the form a(x − p)² + q. **[2]**
**(b)** The graph of f meets the positive x-axis at x = 2. Find h(2) and explain why it equals g(2). **[2]**
**(c)** Find the exact zeros of h and write down its y-intercept. **[2]**

**12.** (calculator allowed) In an invented comparison, account A holds 500 + 40t dollars and account B holds 300(1.1)ᵗ dollars after t years. Let D(t) = 300(1.1)ᵗ − (500 + 40t), 0 ≤ t ≤ 15.

**(a)** Find D(0) and interpret its sign. **[2]**
**(b)** Use technology to find the value of t for which D(t) = 0. **[2]**
**(c)** State which account holds more money at t = 15, and by how much. **[2]**

## Answers

**1.** Upward parabola [1]; intercepts (−1, 0), (3, 0) and (0, −3) labelled [1]; vertex (1, −4) labelled [1]

**2.** End points (−1, −4) and (4, 16) with closed dots [1]; local maximum (0, 0) [1]; local minimum (2, −4) [1]; correct cubic shape between them, rising, falling, then rising [1]

**3.** Starts at (0, 85) with nothing for t < 0 [1]; decreasing with the gradient becoming less steep [1]; horizontal asymptote T = 20 shown dashed, with the curve staying above it [1]
*Examiner insight:* A straight line reaching the t-axis earns only the first mark: it implies a constant cooling rate and a temperature of 0 °C.

**4.** Maximum **(2, 0.541)** [1]; end points **(0, 0)** [1] and **(5, 0.168)** [1]

**5.** Two branches with asymptote x = 0 dashed and labelled [1]; local minimum (1, 2) [1]; local maximum (−1, −2) [1]

**6.** **Closed dot at x = −2** because −2 is included [1]; **open dot at x = 3** because 3 is excluded [1]

**7. (a)** **x = −0.767** [1], **x = 2** [1], **x = 4** [1]
**(b)** Maximum **(0.485, 1.16)** [1]; minimum **(3.21, −1.05)** [1]
**(c)** h(x) > 0 where 2ˣ > x² [1]: **−0.767 < x < 2 or 4 < x ≤ 5** [1]

**8. (a)** Closed end points (−2, 3) and (5, 2) [1]; zeros at 1 and 4 [1]; minimum (2.5, −2) labelled [1]; one smooth fall then one smooth rise, with no other turning points [1]
**(b)** **−2 ≤ f(x) ≤ 3** [1]
**(c)** On −2 ≤ x ≤ 2.5, f falls from 3 to −2, passing 2.5 once; on 2.5 ≤ x ≤ 5 it only rises to 2 [1]. So there is **one solution** [1]

**9. (a)** Maximum at **t = 2.5 hours** [1]; **C = 18.4 mg per litre** [1]
**(b)** **C(12) = 1.98** mg per litre [1]
**(c)** Starts at (0, 0) [1]; single maximum at (2.5, 18.4) [1]; decreasing to the closed end point (12, 1.98) and staying above the axis [1]
**(d)** C(t) = 10 at t = 0.648 [1] and t = 6.36 [1]; time = 6.36 − 0.648 = **5.71 hours** [1]

**10. (a)** **x = 0** [1]
**(b)** **x = 2.32** [1]
**(c)** ln 6 + 1 = **2.79** [1]
**(d)** Curve rising from near the dashed asymptote x = 0 [1]; crossing the x-axis at 2.32 [1]; ending with a closed dot at (6, 2.79) [1]

**11. (a)** h(x) = 4 + 2x − x² = −(x² − 2x) + 4 [1] = **−(x − 1)² + 5** [1]
**(b)** h(2) = f(2) + g(2) = 0 + 4 = **4** [1]; it equals g(2) because f(2) = 0, so only g contributes to the sum there [1]
**(c)** (x − 1)² = 5, so **x = 1 ± √5** [1]; y-intercept **(0, 4)** [1]
*Examiner insight:* In (b) the point of the question is that the sum equals g wherever f is zero; the graph of h does not pass through (2, 0) itself.

**12. (a)** D(0) = 300 − 500 = **−200** [1]; negative, so account A starts with $200 more [1]
**(b)** Graphing D and finding its zero [1]: **t = 12.7 years** [1]
**(c)** D(15) = 153 > 0 [1], so **account B** holds about **$153 more** [1]

## Where marks are usually lost

- Sketches with the right shape but no labelled coordinates.
- End points shown with the wrong type of dot, or curves extended past the domain.
- Asymptotes not dashed or not named.
- Context graphs with an impossible feature, as in question 3.
- Intersection values read as y-coordinates when the question asks for x.
