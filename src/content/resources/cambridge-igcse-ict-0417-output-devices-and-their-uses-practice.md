## Section B: structured questions

**7.** A dental surgery wants to produce crowns that fit each patient exactly.

**(a)** Name the output device the surgery could use. **[1]**

**(b)** Describe how this device produces the crown. **[2]**

**(c)** Give **two** advantages of this method for the surgery. **[2]**

**8.** A school is choosing a printer for its reprographics room, which prints about 10,000 worksheets a week.

**(a)** Recommend a type of printer. **[1]**

**(b)** Justify your recommendation by comparing it with an inkjet printer. **[3]**

**(c)** Give **one** health and safety precaution for the room where this printer is used. **[1]**

**9.** A town planning office needs printouts of maps that are 1 metre wide.

**(a)** Name the most suitable output device. **[1]**

**(b)** Give **two** reasons for your choice. **[2]**

**10.** A car dashboard uses a touch screen to display navigation and music options.

**(a)** Explain why the touch screen is an output device in this system. **[1]**

**(b)** Give **two** advantages of a touch screen for the dashboard. **[2]**

**11.** A visually impaired student uses software that reads web pages aloud.

**(a)** Name the output device needed. **[1]**

**(b)** Describe how the computer's data is turned into sound. **[2]**

**(c)** Give **one** problem with this output in a school library. **[1]**

**12.** An automatic greenhouse uses a temperature sensor, a microprocessor and a motor to open and close a window.

**(a)** State whether the motor is an input or an output device, and why. **[2]**

**(b)** Describe how the system keeps the greenhouse below 28 °C. **[3]**

**13.** Compare a laser printer and a dot matrix printer for a warehouse that prints delivery notes in three copies. **[4]**

## Answers

**1.** Laser printer. **[1]**

**2.** 3D printer. **[1]**

**3.** B: actuator. **[1]**

**4.** Any two: presentations in classrooms or meetings (1); showing films to an audience or home cinema (1); training sessions (1); advertising displays (1). **[2]**

**5.** Any two: impact printer (1); pins in the print head strike an inked ribbon (1); characters made from dots (1); can print on multi-part or continuous paper (1); noisy (1). **[2]**

**6.** Any two: ink cartridges expensive, so high cost per page (1); slow for large volumes (1); ink can smudge before it dries (1); nozzles can block if unused (1). **[2]**

**7. (a)** 3D printer. **[1]**

**(b)** A digital design of the crown is created, for example from a scan of the patient's tooth using CAD software (1); the printer builds the crown layer by layer from a suitable material (1). **[2]**

**(c)** Any two: each crown can be customised to fit one patient (1); made quickly on site, so patients wait less (1); no mould is needed (1); the design can be changed and reprinted if it does not fit (1). **[2]**

**8. (a)** Laser printer. **[1]**

**(b)** Any three: a laser printer is much faster than an inkjet, so 10,000 sheets can be printed in a reasonable time (1); its cost per page is lower, whereas inkjet cartridges run out quickly and are expensive (1); toner cartridges print many more pages than ink cartridges, so they are changed less often (1); toner does not smudge, whereas inkjet ink can smudge while wet (1). **[3]**

**(c)** Keep the room well ventilated, because laser printers can give off ozone and toner particles (1). **[1]**

**9. (a)** Plotter. **[1]**

**(b)** Any two: can print on very large sheets or rolls (1); produces very precise, accurate lines needed for maps (1); can print on different materials (1). **[2]**

**10. (a)** It displays the navigation map and music options to the driver (1). **[1]**

**(b)** Any two: the screen shows only the buttons needed for the current task, so there are fewer controls (1); no separate display and buttons are needed, saving space (1); maps and menus can be updated with software (1). **[2]**

**11. (a)** Speaker (credit headphones). **[1]**

**(b)** The text is converted into digital sound data by the software (1); this is converted to an analogue signal by a digital-to-analogue converter or sound card and played through the speaker (1). **[2]**

**(c)** The sound would disturb other students (credit: others can hear what the student is reading) (1). **[1]**

**12. (a)** Output device (1), because it receives a signal from the microprocessor and produces movement (1). **[2]**

**(b)** The temperature sensor sends readings to the microprocessor continuously (1); the microprocessor compares each reading with 28 °C (1); if the temperature is above 28 °C it sends a signal to the motor to open the window, and when it falls below, the motor closes the window (1). **[3]**

**13.** Any four, covering both printers: a dot matrix printer is an impact printer, so it can print all three copies of a multi-part delivery note at once (1), whereas a laser printer would have to print three separate pages (1); a dot matrix printer is more tolerant of dust in a warehouse (1); a laser printer is faster and gives higher-quality output (1); a dot matrix printer is noisy, which matters less in a warehouse (1); a laser printer costs more to buy (1). **[4]**

## Frequently asked questions

**Is a touch screen counted as an input or an output device?**
Both. Section 2.1 treats it as input and section 2.3 as output. Answer according to what the question asks it to do.

**Do I need to know how an OLED screen works in detail?**
No. Know that each pixel produces its own light, so OLED screens can be very thin and flexible, while LCD screens need a backlight.
