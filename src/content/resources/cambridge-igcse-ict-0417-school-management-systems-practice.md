## Section A: short answers

**1.** Which **one** of the following registration methods cannot be lent to another learner? **[1]**

A: Magnetic stripe card

B: RFID tag

C: Fingerprint scan

D: Smart card

**2.** State what CAL stands for. **[1]**

**3.** Give **two** items of data stored with each attendance entry. **[2]**

**4.** State **one** reason why staff are given different access levels to the school management system. **[1]**

**5.** Give **two** ways a school can use a learner's recorded test marks. **[2]**

## Section B: structured questions

**6.** Hillside School is replacing paper registers with a fingerprint system at the main entrance.

**(a)** Describe how the system records that a learner has arrived. **[3]**

**(b)** Give **two** disadvantages of the fingerprint system. **[2]**

**7.** A school still uses OMR register sheets that teachers complete each morning.

**(a)** Describe how the attendance data reaches the computer. **[2]**

**(b)** Explain **one** problem with this method compared with an electronic register. **[2]**

**8.** The school management system sends a text message to parents when their child is absent.

**(a)** Describe how the system decides that a learner is absent. **[2]**

**(b)** Explain **one** benefit of the text message to the school. **[2]**

**9.** A teacher enters end-of-term test marks into the school management system.

**(a)** Describe **two** ways the system helps the teacher write reports. **[2]**

**(b)** Explain **one** risk of storing learners' marks and personal details in the system. **[2]**

**10.** A school buys maths software that sets questions and marks the answers.

**(a)** Explain **two** advantages of the software for learners. **[4]**

**(b)** Describe how the software helps the teacher monitor progress. **[2]**

## Section C: extended questions

**11.** Discuss the advantages and disadvantages of using RFID tags rather than an electronic register taken by the teacher for recording attendance. **[6]**

**12.** "Computer aided learning means schools will need fewer teachers." Evaluate this statement. **[6]**

---

## Answers

**1.** **C** [1]. A fingerprint belongs to the learner, while cards and tags can be handed to someone else. **[1]**

**2.** Computer aided learning [1]. **[1]**

**3.** Learner ID [1]; date and time of arrival [1] (also credit: present, absent or late status). **[2]**

**4.** To protect learners' personal data, so staff see only the information they need for their role [1]. **[1]**

**5.** Calculate averages and grades [1]; compare results with targets to identify learners who need support [1] (also credit: produce reports for parents; find topics to reteach). **[2]**

**6. (a)** The learner places a finger on the scanner, which captures the fingerprint [1]; the system compares it with the fingerprints stored in the database to identify the learner [1]; it stores the learner's ID with the date and time of arrival as an attendance record [1].

**(b)** The scanners and software are expensive to buy and install [1]; parents may object because biometric data is sensitive personal data [1] (also credit: scans fail if a finger is cut or dirty; queues can form at the entrance). **[5]**

**7. (a)** The completed sheets are collected and fed into an OMR reader [1], which detects the position of the shaded marks and transfers the attendance data to the database [1].

**(b)** The data is not available until the sheets have been collected and scanned [1], so the office cannot tell immediately who is absent, which delays contacting parents and makes the emergency list out of date [1]. **[4]**

**8. (a)** The system checks whether an attendance record exists for the learner for that day [1]; if there is no record by the preset time, the learner is marked absent [1].

**(b)** Parents are informed on the same day without staff phoning each family [1], so unexplained absence or truancy is found quickly and staff time is saved [1]. **[4]**

**9. (a)** It calculates totals, averages and grades automatically [1]; it shows each learner's marks against targets, so the teacher can comment on progress [1] (also credit: report templates fill in data automatically).

**(b)** If the system is hacked or a password is shared, personal data could be seen by unauthorised people [1], breaching learners' privacy and the school's legal duty to protect personal data [1]. **[4]**

**10. (a)** Learners get instant feedback on each answer [1], so they can correct mistakes straight away instead of waiting for marking [1]. Learners can work at their own pace and repeat questions [1], so slower learners are not left behind and faster learners can move on [1].

**(b)** Scores are saved to each learner's record automatically [1], so the teacher can see who is struggling with which topics without marking every answer [1]. **[6]**

**11.** Advantages of RFID: registration is very fast as learners pass the reader, so no lesson time is used [1]; every entry is time-stamped automatically, so lateness is recorded accurately [1]; tags can show which building a learner is in during an emergency [1]. Disadvantages: tags can be lent to a friend, so a learner can be recorded as present when absent [1]; tags are lost or forgotten and must be replaced [1]; the readers are expensive to install, whereas an electronic register needs only the teacher's computer [1]. **[6]**

**12.** For: CAL can deliver lessons and mark tests automatically, saving teachers' time [1]; learners can study at home without a teacher present [1]. Against: software cannot answer unexpected questions or explain an idea in a different way [1]; teachers are still needed to plan learning, motivate learners and manage behaviour [1]; some learners need personal support that software cannot provide [1]. Judgement: the statement is mostly wrong; CAL changes how teachers spend their time but supports rather than replaces them [1]. **[6]**

## Where marks are usually lost

- Writing "the card is scanned" without saying what is stored.
- Saying biometric systems have no disadvantages.
- Describing CAL vaguely as "using computers"; say what the software does.
- Forgetting to mention data protection when asked about risks.
