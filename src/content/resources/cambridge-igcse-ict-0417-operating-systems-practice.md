## Section A: short answers

**1.** Name the type of interface in which the user selects icons using a pointing device. **[1]**

**2.** State what is meant by the *syntax* of a command in a command line interface. **[1]**

**3.** Which interface type would normally use the least memory?

A: graphical user interface

B: dialogue-based interface

C: command line interface

D: gesture-based interface

**[1]**

**4.** Give **two** items of hardware that a dialogue-based interface needs. **[2]**

**5.** Give **two** examples of gestures used on a tablet and the action each one carries out. **[2]**

**6.** State **two** characteristics of a graphical user interface. **[2]**

## Section B: structured questions

**7.** A new member of staff in an office has never used a computer before.

**(a)** Recommend the most suitable type of interface for this person. **[1]**

**(b)** Justify your recommendation. **[2]**

**(c)** Give **one** disadvantage of this interface type. **[1]**

**8.** A smart speaker in a kitchen responds to spoken questions.

**(a)** Describe how the user interacts with the speaker. **[2]**

**(b)** The speaker sometimes fails to respond correctly when the extractor fan is running. Explain why. **[2]**

**(c)** Give **one** privacy concern about this type of interface in a shared home. **[1]**

**9.** A museum installs a large interactive display. Visitors control it by waving their hands in front of a camera, without touching the screen.

**(a)** Give **two** advantages of this interface for the museum. **[2]**

**(b)** Describe **two** problems that could occur. **[2]**

**10.** A system administrator must rename 300 files in a folder so that each name begins with the year.

Explain why a command line interface might be more efficient than a graphical user interface for this task. **[3]**

**11.** Describe **three** differences between a command line interface and a gesture-based interface. **[3]**

**12.** A car manufacturer is choosing between a touch screen GUI and a dialogue-based interface for controlling the satellite navigation and phone while driving.

Discuss the advantages and disadvantages of each, and recommend one. **[6]**

## Answers

**1.** Graphical user interface (GUI). **[1]**

**2.** The exact rules for how a command must be typed, including spelling, order and punctuation. **[1]**

**3.** C: command line interface. **[1]**

**4.** Microphone (1); speaker (1). **[2]**

**5.** Any two, each with its action: swipe to scroll or move to the next page or picture (1); pinch to zoom in or out (1); tap to select or open (1); drag to move an item (1). **[2]**

**6.** Any two: uses icons, windows and menus (1); items selected with a pointer or by touch (1); options visible on screen so commands need not be remembered (1); several programs open in separate windows (1). **[2]**

**7. (a)** Graphical user interface. **[1]**

**(b)** Any two: options are shown as icons and menus, so no commands need to be learned (1); icons are intuitive and represent their function (1); fewer errors than typing commands (1); the same layout is used in many programs, so skills transfer (1). **[2]**

**(c)** Any one: uses more memory or processing power (1); gives less direct control than a CLI (1). **[1]**

**8. (a)** The user speaks a question or command to the speaker (1); speech recognition identifies the words and the speaker replies in speech or carries out the action (1). **[2]**

**(b)** The fan creates background noise (1), which mixes with the user's voice so the words are not recognised correctly (1). **[2]**

**(c)** Any one: other people in the room can hear the request and the answer (1); the device is listening for commands and may record conversations (1). **[1]**

**9. (a)** Any two: visitors do not touch the screen, which is more hygienic (1); no mouse or keyboard to break or be stolen (1); natural movements are easy to learn, so no instructions are needed (1); suitable for visitors of all ages (1). **[2]**

**(b)** Any two: a visitor's accidental movement or a passer-by may be recognised as a command (1); only a limited set of gestures is recognised, so visitors may not know which to use (1); poor lighting can stop movements being detected (1); holding an arm up becomes tiring (1). **[2]**

**10.** A single typed command can be applied to all 300 files at once (1), whereas in a GUI each file would have to be selected and renamed separately, or through many menu steps (1). The administrator is experienced and knows the commands, so typing is faster for them (1). **[3]**

**11.** Any three, each a contrast: a CLI uses typed commands whereas a gesture interface uses hand or body movements (1); a CLI needs a keyboard whereas a gesture interface uses a touch screen or a camera and sensors (1); a CLI is hard to learn whereas gestures are natural and quick to learn (1); a CLI uses little memory and processing power whereas gesture recognition needs more (1); a CLI gives more control over the system whereas a gesture interface offers a limited set of actions (1). **[3]**

**12.** Touch screen GUI, advantages, up to 2: options are visible on the screen (1); map can be zoomed and selected accurately (1); works in a noisy car (1). Disadvantages, up to 2: the driver must look away from the road and take a hand off the wheel (1); small icons are hard to select while the car is moving (1). Dialogue-based, advantages, up to 2: hands stay on the wheel and eyes on the road, so it is safer (1); no need to read the screen (1). Disadvantages, up to 2: road noise, passengers or music can stop commands being recognised (1); the driver must know which commands work (1). Recommendation with reason, for example dialogue-based because safety while driving matters most (1). **[6]** Award a maximum of 6 marks from these points; answers that cover only one interface are limited to 3 marks.

## Frequently asked questions

**Is a touch screen a GUI or a gesture-based interface?**
It can be described as both. Tapping icons is GUI interaction; swiping and pinching are gestures. In your answer, describe what the user actually does in the scenario.

**Do I need to know the names of real operating systems?**
No. No marks are awarded for brand names, so describe the interface type instead.
