These questions cover content statement **B8** of AQA A-level Mathematics (7357), Section B: Algebra and functions: "Understand and use composite functions; inverse functions and their graphs." gf(x) means g(f(x)). Revise from the [B8 study guide](/resources/aqa-a-level-mathematics-7357-b8-composite-and-inverse-functions-aqa-alevel-maths/) and the [B8 revision notes](/resources/aqa-a-level-mathematics-7357-b8-composite-and-inverse-functions-aqa-alevel-maths-revision-notes/).

## Section A

**1.** f(x) = x² + 1 and g(x) = 2x − 3, for all real x.

**(a)** Find fg(x) in expanded form. **[2]**

**(b)** Solve fg(x) = 10. **[2]**

**2.** f(x) = 1/(x − 2), x ≠ 2. Find ff(x) in simplest form, and state the two values of x excluded from the domain of ff. **[4]**

**3.** f(x) = 4x − 1. Find the function g such that fg(x) = 8x² + 3. **[2]**

**4.** f(x) = 2x + 3. Find the function h such that hf(x) = 4x² + 12x + 5. **[3]**

**5.** f(x) = (3x − 1)/(x + 2), x ≠ −2. Find f⁻¹(x) and state the domain of f⁻¹. **[3]**

**6.** f(x) = x − 4 for all real x, and g(x) = √x for x ≥ 0. Find (gf)⁻¹(x) and state its domain. **[3]**

## Section B

**7.** f(x) = (4x + 1)/(2x − 4), x ≠ 2.

**(a)** Show that f is self-inverse. **[3]**

**(b)** Hence write down the value of ff(7). **[1]**

**(c)** State the equations of the asymptotes of y = f(x), and explain how they are consistent with part (a). **[2]**

**8.** f(x) = x² + 4x + 7, for x ≥ k.

**(a)** Write f(x) in the form (x + a)² + b. **[1]**

**(b)** State the smallest value of k for which f has an inverse. **[1]**

**(c)** Taking this value of k, find f⁻¹(x) and state its domain. **[3]**

**(d)** Show that the graphs of y = f(x) and y = f⁻¹(x) do not meet. **[2]**

**9.** f(x) = 3 − 2x for all real x, and g(x) = 1/x for x ≠ 0.

**(a)** Find gf(x) and state the value of x that must be excluded. **[2]**

**(b)** Solve gf(x) = f(x). **[3]**

**(c)** Find (gf)⁻¹(x). **[2]**

**10.** The point (4, 11) lies on y = f(x), where f(x) = ax − 1 and a is a constant.

**(a)** Write down the coordinates of a point on y = f⁻¹(x). **[1]**

**(b)** Find a and f⁻¹(x). **[3]**

**(c)** Find the coordinates of the point where y = f(x) and y = f⁻¹(x) meet. **[2]**

**11.** f(x) = x² and g(x) = x − 3, for all real x.

**(a)** Explain why f has no inverse. **[1]**

**(b)** State the range of fg and the range of gf. **[2]**

**(c)** Solve fg(x) = gf(x). **[2]**

**12.** f(x) = 5 − x², for x ≤ 0.

**(a)** State the range of f. **[1]**

**(b)** Find f⁻¹(x), and state its domain and range. **[4]**

**(c)** Find the exact x-coordinate of the point where y = f(x) meets y = f⁻¹(x). **[2]**

## Answers

**1. (a)** fg(x) = (2x − 3)² + 1 [1] = **4x² − 12x + 10** [1]

**(b)** 4x² − 12x = 0, so 4x(x − 3) = 0 [1]. **x = 0 or x = 3** [1]

**2.** ff(x) = 1/(1/(x − 2) − 2) [1] = (x − 2)/(1 − 2(x − 2)) = **(x − 2)/(5 − 2x)** [1]. x = 2 is excluded because f(2) is undefined [1]. x = 5/2 is excluded because f(5/2) = 2, which f cannot accept [1].

*Examiner insight:* the simplified formula shows only x = 5/2 as a problem. The value x = 2 must come from the first step of the composite.

**3.** f(g(x)) = 4g(x) − 1 = 8x² + 3 [1], so **g(x) = 2x² + 1** [1]

**4.** (2x + 3)² = 4x² + 12x + 9 [1], so 4x² + 12x + 5 = (2x + 3)² − 4 [1]. Therefore **h(x) = x² − 4** [1]

*Examiner insight:* the substitution u = 2x + 3, x = (u − 3)/2 also works. Either way, check by finding h(2x + 3).

**5.** y(x + 2) = 3x − 1, so x(y − 3) = −1 − 2y [1]. **f⁻¹(x) = (2x + 1)/(3 − x)** [1], with domain **x ≠ 3** [1]

**6.** gf(x) = √(x − 4), for x ≥ 4, with range gf(x) ≥ 0 [1]. y = √(x − 4) gives x = y² + 4 [1], so **(gf)⁻¹(x) = x² + 4, x ≥ 0** [1]

*Examiner insight:* without the domain x ≥ 0, x² + 4 is many-one and is not the inverse. The domain is the range of gf.

**7. (a)** y(2x − 4) = 4x + 1, so 2xy − 4y = 4x + 1 [1]. x(2y − 4) = 4y + 1, so x = (4y + 1)/(2y − 4) [1]. Hence f⁻¹(x) = (4x + 1)/(2x − 4) = f(x), so f is self-inverse [1]

**(b)** ff(x) = x, so **ff(7) = 7** [1]

**(c)** Asymptotes **x = 2 and y = 2** [1]. Reflection in y = x turns x = 2 into y = 2 and y = 2 into x = 2, so the pair is unchanged, as a self-inverse graph requires [1]

**8. (a)** **(x + 2)² + 3** [1]

**(b)** The turning point is at x = −2, so **k = −2** [1]

**(c)** y = (x + 2)² + 3 gives x + 2 = √(y − 3), taking the positive root because x ≥ −2 [1]. **f⁻¹(x) = √(x − 3) − 2** [1], with domain **x ≥ 3** (the range of f) [1]

**(d)** f is increasing for x ≥ −2, so any meeting point lies on y = x: x² + 4x + 7 = x gives x² + 3x + 7 = 0 [1]. The discriminant is 9 − 28 = −19 < 0, so there are no real solutions and the graphs do not meet [1]

**9. (a)** gf(x) = **1/(3 − 2x)** [1], with **x ≠ 3/2** excluded [1]

**(b)** 1/(3 − 2x) = 3 − 2x, so (3 − 2x)² = 1 [1]. 3 − 2x = 1 or 3 − 2x = −1 [1], so **x = 1 or x = 2** [1]

**(c)** y = 1/(3 − 2x) gives 3 − 2x = 1/y and x = (3y − 1)/(2y) [1]. **(gf)⁻¹(x) = (3x − 1)/(2x)**, x ≠ 0 [1]

*Examiner insight:* checking with f⁻¹(g⁻¹(x)) is quick: g⁻¹(x) = 1/x and f⁻¹(x) = (3 − x)/2, so f⁻¹(1/x) = (3 − 1/x)/2, the same function.

**10. (a)** **(11, 4)** [1]

**(b)** 11 = 4a − 1, so **a = 3** [1]. y = 3x − 1 gives x = (y + 1)/3 [1], so **f⁻¹(x) = (x + 1)/3** [1]

**(c)** f is increasing, so the graphs meet on y = x: 3x − 1 = x, giving x = 1/2 [1]. The point is **(1/2, 1/2)** [1]

**11. (a)** f is many-one: for example f(2) = f(−2) = 4, so it has no inverse [1]

**(b)** fg(x) = (x − 3)², with range **fg(x) ≥ 0** [1]. gf(x) = x² − 3, with range **gf(x) ≥ −3** [1]

**(c)** x² − 6x + 9 = x² − 3 [1], so 6x = 12 and **x = 2** [1]

**12. (a)** f(0) = 5 is the largest value, so the range is **f(x) ≤ 5** [1]

**(b)** y = 5 − x² gives x² = 5 − y [1]. Since x ≤ 0, take the negative root: x = −√(5 − y) [1]. **f⁻¹(x) = −√(5 − x)**, with domain **x ≤ 5** [1] and range **f⁻¹(x) ≤ 0** [1]

**(c)** f is increasing on x ≤ 0, so solve 5 − x² = x: x² + x − 5 = 0 and x = (−1 ± √21)/2 [1]. Only the value with x ≤ 0 is valid: **x = (−1 − √21)/2** [1]

*Examiner insight:* the negative square root in (b) is the key mark. A positive root would give outputs that are not in the domain of f.

## Where marks are usually lost

- Applying g before f in gf.
- Finding the domain of ff from the simplified formula only.
- Writing the inverse with both signs of a root, or with the wrong sign.
- Leaving out the domain of an inverse, especially when it makes a many-one formula one-one.
- Keeping a root of f(x) = x that lies outside the domain of f.
- Writing "f has no inverse" without an example of two inputs with the same output.
