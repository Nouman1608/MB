These questions cover section 3 of Unit P3 (YMA01, Issue 3): the functions eˣ and ln x, the equations e^(ax + b) = p and ln(ax + b) = q, and logarithmic graphs. Revise first with the [P3 exponentials and logarithms study guide](/resources/edexcel-a-level-mathematics-yma01-p3-exponentials-and-logarithms-edexcel-alevel-maths/) and the [P3 exponentials and logarithms revision notes](/resources/edexcel-a-level-mathematics-yma01-p3-exponentials-and-logarithms-edexcel-alevel-maths-revision-notes/). Contexts and data are invented.

## Section A

**1.** Solve e^(3x − 1) = 20, giving the exact answer and the answer to 3 significant figures. **[3]**

**2.** Solve ln(2x − 1) = 3, giving the exact answer and the answer to 3 significant figures. **[3]**

**3.** Write 3 ln 2 + ln 5 − ln 4 as a single logarithm in its simplest form. **[2]**

## Section B

**4.** Solve 2 ln x = ln(3x + 10). **[4]**

**5.** f(x) = 4 − 3e^(−2x), x ∈ ℝ.

**(a)** State the coordinates of the point where the curve y = f(x) meets the y-axis, and the equation of its asymptote. **[2]**

**(b)** Find the exact x-coordinate of the point where the curve meets the x-axis. **[2]**

**(c)** State the range of f. **[1]**

**6.** Solve 3e^(2x) − 10eˣ + 3 = 0, giving your answers in terms of natural logarithms. **[5]**

**7.** Solve 2eˣ + 3e^(−x) = 7, giving your answers in exact form. **[5]**

**8.** f(x) = 3 + ln(2x − 1), x > ½.

**(a)** Find an expression for f⁻¹(x). **[3]**

**(b)** State the domain of f⁻¹. **[1]**

**(c)** Solve f(x) = 5, giving your answer exactly. **[2]**

**9.** Two variables are believed to satisfy y = axⁿ, where a and n are constants.

**(a)** Show that this relationship gives a straight line when lg y is plotted against lg x. **[2]**

**(b)** The line of best fit passes through (0.3, 0.86) and (1.1, 2.06). Find n, and a to 3 significant figures. **[4]**

**10.** The number of plants N in a garden t months after planting is modelled by N = kbᵗ. A graph of ln N against t is a straight line through (0, 1.8) and (5, 3.3).

**(a)** Find k and b to 3 significant figures. **[4]**

**(b)** Interpret the value of k in this context. **[1]**

**(c)** Use the model to predict N when t = 10. **[2]**

**11.** The concentration of a drug in a patient's blood, C mg per litre, t hours after an injection is modelled by C = 12e^(−0.2t).

**(a)** State the initial concentration. **[1]**

**(b)** Find the time taken for the concentration to fall to 3 mg per litre, giving your answer exactly and to 3 significant figures. **[3]**

**(c)** State what happens to C in the long term. **[1]**

**12.** Solve ln(x + 1) − ln x = 1, giving your answer in terms of e. **[3]**

## Answers

**1.** 3x − 1 = ln 20 [1], so x = (1 + ln 20)/3 [1] = **1.33** [1].

**2.** 2x − 1 = e³ [1], so x = (e³ + 1)/2 [1] = **10.5** [1].

**3.** 3 ln 2 = ln 8, so the expression is ln(8 × 5 ÷ 4) [1] = **ln 10** [1].

**4.** ln x² = ln(3x + 10), so x² = 3x + 10 [1]. x² − 3x − 10 = 0, so (x − 5)(x + 2) = 0 [1]. x = 5 or x = −2 [1]. ln x is undefined at x = −2, so **x = 5** [1].

**5. (a)** (0, 4 − 3) = **(0, 1)** [1]; asymptote **y = 4** [1].

**(b)** 4 − 3e^(−2x) = 0, so e^(−2x) = 4/3 [1], and x = −½ ln(4/3), or **x = ½ ln(3/4)** [1].

**(c)** **f(x) < 4** [1].

Total: 5

**6.** Let u = eˣ: 3u² − 10u + 3 = 0 [1]. (3u − 1)(u − 3) = 0 [1], so u = ⅓ or u = 3 [1]. eˣ = 3 gives **x = ln 3** [1]; eˣ = ⅓ gives **x = ln(⅓) = −ln 3** [1].

**7.** Multiply by eˣ: 2e^(2x) + 3 = 7eˣ [1], so 2e^(2x) − 7eˣ + 3 = 0 [1]. (2eˣ − 1)(eˣ − 3) = 0 [1]. eˣ = ½ gives **x = ln ½ = −ln 2** [1]; eˣ = 3 gives **x = ln 3** [1].

**8. (a)** y = 3 + ln(2x − 1), so ln(2x − 1) = y − 3 [1] and 2x − 1 = e^(y − 3) [1]. **f⁻¹(x) = (e^(x − 3) + 1)/2** [1].

**(b)** The range of f is all real numbers, so the domain of f⁻¹ is **x ∈ ℝ** [1].

**(c)** ln(2x − 1) = 2, so 2x − 1 = e² [1] and **x = (e² + 1)/2** [1].

Total: 6

**9. (a)** lg y = lg(axⁿ) = lg a + n lg x [1]. This has the form Y = nX + c with Y = lg y, X = lg x, gradient n and intercept lg a, so it is a straight line [1].

**(b)** n = (2.06 − 0.86)/(1.1 − 0.3) = 1.2/0.8 [1] = **1.5** [1]. 0.86 = lg a + 1.5 × 0.3, so lg a = 0.41 [1] and **a = 10^0.41 = 2.57** [1].

Total: 6

**10. (a)** ln N = ln k + t ln b. Intercept: ln k = 1.8, so **k = e^1.8 = 6.05** [1] [1]. Gradient: ln b = (3.3 − 1.8)/5 = 0.3 [1], so **b = e^0.3 = 1.35** [1].

**(b)** k is the number of plants at the time of planting (t = 0), about 6 [1].

**(c)** ln N = 1.8 + 0.3 × 10 = 4.8 [1], so N = e^4.8 ≈ **122** plants [1].

Total: 7

**11. (a)** **12 mg per litre** [1].

**(b)** 12e^(−0.2t) = 3, so e^(−0.2t) = ¼ [1]. −0.2t = ln ¼ = −ln 4 [1], so **t = 5 ln 4 = 6.93 hours** [1].

**(c)** C tends to 0: the drug is eventually cleared from the blood [1].

Total: 5

**12.** ln((x + 1)/x) = 1 [1], so (x + 1)/x = e [1]. x + 1 = ex, so x(e − 1) = 1 and **x = 1/(e − 1)** [1].

## Where marks are usually lost

- In Question 4, writing 2 ln x as ln 2x, or keeping x = −2.
- In Question 5, giving the asymptote as y = 0 because the basic curve y = eˣ has that asymptote.
- In Questions 6 and 7, solving for u and stopping, or losing the solution x = −ln 3 by thinking a negative x is impossible: only u = eˣ must be positive.
- In Question 9(b), using 10 to undo a natural logarithm or e to undo lg.
- In Question 10, confusing which constant comes from the gradient and which from the intercept.
