## What the specification asks

| Ref | Statement |
|---|---|
| 2.04a | Ordinality: order integers, fractions, decimals and percentages (the specification's example list is 4/5, 3/4, 0.72, −0.9) |
| 2.04b | Symbols: use <, >, ≤, ≥, = and ≠ |

Ordering is a skill of choosing a common form. Any one of decimals, percentages or a common denominator will work; the best choice depends on the numbers.

## Choosing a method

| Situation | Fastest method |
|---|---|
| Mixed forms (fractions, decimals, percentages) | Convert all to decimals with the same number of places |
| Two fractions only | Cross-multiply: a/b < c/d when a × d < b × c (positive denominators) |
| Fractions with the same numerator | The larger denominator gives the smaller fraction: 5/9 < 5/8 |
| Fractions close to a benchmark | Compare each with 1/2 or 1 |
| Many fractions with friendly denominators | Common denominator |

**Worked example 1 (the specification's list).** Order 4/5, 3/4, 0.72 and −0.9, smallest first.

```
4/5 = 0.80    3/4 = 0.75    0.72    −0.9 = −0.90
negative first: −0.9
then 0.72 < 0.75 < 0.80
order: −0.9, 0.72, 3/4, 4/5
```

Write the final answer in the **original** forms, not the converted decimals.

## Close values: go to enough decimal places

When values agree to two decimal places, keep going.

**Worked example 2.** Order 5/8, 7/11, 0.63 and 62.8%, largest first.

```
5/8   = 0.6250
7/11  = 0.6363...
0.63  = 0.6300
62.8% = 0.6280
largest first: 7/11 (0.6363), 0.63, 62.8%, 5/8
```

Three of these round to 0.63 at two decimal places, so two places would not separate them. Pad every value to four places before comparing digit by digit.

**Worked example 3 (recurring decimals).** Order 0.6, 2/3, 0.67 and 0.666, smallest first.

```
0.6   = 0.6000
2/3   = 0.6666...
0.666 = 0.6660
0.67  = 0.6700
order: 0.6, 0.666, 2/3, 0.67
```

2/3 is larger than 0.666 because its 6s continue for ever, but smaller than 0.67.

## Cross-multiplying two fractions

**Worked example 4.** Which is larger, 5/7 or 7/10? By how much?

```
5 × 10 = 50 and 7 × 7 = 49
50 > 49, so 5/7 > 7/10
difference: 50/70 − 49/70 = 1/70
```

The cross products are the numerators over the common denominator 70, which is why the test works.

## Negatives: the order flips

For negative numbers, the one further from zero is smaller.

**Worked example 5.** Order −3/4, −0.7, −2/3 and −68%, smallest first.

```
−3/4 = −0.75     −0.7 = −0.70     −2/3 = −0.6666...     −68% = −0.68
furthest from zero is smallest:
−0.75 < −0.70 < −0.68 < −0.6666...
order: −3/4, −0.7, −68%, −2/3
```

A useful check: the sizes in order are 0.75, 0.70, 0.68, 0.667, largest first, which is the reverse of the order for the positive versions.

## Values above 1

Mixed numbers, improper fractions and percentages above 100% are ordered the same way.

```
7/4 = 1.75    1.8    165% = 1.65    1 5/8 = 1.625
smallest first: 1 5/8, 165%, 7/4, 1.8
```

## Finding a value between two others

**Worked example 6.** Write down a fraction between 3/5 and 2/3.

```
3/5 = 18/30 and 2/3 = 20/30
19/30 lies between them   (19/30 = 0.6333...)
```

Over the lowest common denominator, 9/15 and 10/15, there is no gap, so the denominator was doubled to 30. Doubling again to 60 gives 36/60 and 40/60, with room for 37/60, 38/60 and 39/60. A decimal works too: 0.65 or 63% lie between 0.6 and 2/3.

## Distance from a target value

Some questions ask which value is closest to a given number. Find each difference from the target, ignoring the sign, and compare those.

**Worked example 9.** Which of 0.47, 6/11, 53% and 0.505 is closest to 1/2?

```
target 1/2 = 0.5
0.47:  0.5 − 0.47  = 0.03
6/11 = 0.5454...:  0.5454... − 0.5 = 0.0454...
53% = 0.53:  0.53 − 0.5 = 0.03
0.505: 0.505 − 0.5 = 0.005
closest: 0.505
```

Notice that 0.47 and 53% are the same distance from 1/2, one below and one above. Ordering the four values first (0.47, 0.505, 53%, 6/11) and then marking 0.5 among them on a number line gives the same answer visually.

## Inequality symbols in words and context

| Symbol | Read as | Context words |
|---|---|---|
| < | is less than | "under", "below", "fewer than" |
| > | is greater than | "over", "more than", "exceeds" |
| ≤ | is less than or equal to | "at most", "no more than", "maximum" |
| ≥ | is greater than or equal to | "at least", "no fewer than", "minimum" |
| = | is equal to | — |
| ≠ | is not equal to | — |

**Worked example 7.** Insert the correct symbol, then use one in context.

```
0.3 ... 1/3          0.3 < 0.333..., so 0.3 < 1/3
0.125 ... 1/8        both 0.125, so 0.125 = 1/8
2/3 ... 0.67         2/3 ≠ 0.67 (and 2/3 < 0.67)
"A ride needs riders at least 1.2 m tall":  height ≥ 1.2 m
```

The symbol always opens towards the larger value.

**Worked example 8 (comparing results).** Four students' test scores are 17/20, 42/50, 83% and 0.84 of the marks. Who did best?

```
17/20 = 85%    42/50 = 84%    83%    0.84 = 84%
best: 17/20 (85%); 42/50 and 0.84 are equal (84%)
```

## Common mistakes

- Comparing decimals by length: 0.63 is larger than 0.628, even though it has fewer digits.
- Thinking a larger denominator means a larger fraction.
- Ordering negatives as if they were positive.
- Leaving the answer in converted decimals instead of the original forms.
- Rounding 2/3 to 0.67 and then calling it equal to 0.67.
- Reversing "at least" and "at most".

## Exam technique

- **"Write in order"**: show the converted values, then give the list in the original forms, and say "smallest first" or "largest first" as the question asks.
- **"Show that"** one value is larger: give both values in the same form to enough decimal places, then state the conclusion with a symbol.
- **Non-calculator papers**: use short division or a common denominator for awkward fractions such as 7/11.
