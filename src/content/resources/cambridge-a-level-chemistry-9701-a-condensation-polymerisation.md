This guide covers subtopic **35.1, Condensation polymerisation**, from Topic 35, Polymerisation, of
Cambridge International AS & A Level Chemistry 9701, 2025–2027 series. It is A Level content. The
broader [Condensation Polymerisation and Polymer Degradability study guide](/resources/a-condensation-polymerisation-and-polymer-degradability/)
introduces the idea with PET; this page works through each of the five monomer combinations the
syllabus names, gives a reliable method for drawing repeat units, and shows how to read a polymer
chain backwards.

## What the syllabus asks for

Subtopic 35.1 has four learning outcomes:

1. describe the formation of polyesters: "the reaction between a diol and a dicarboxylic acid or
   dioyl chloride" and "the reaction of a hydroxycarboxylic acid"
2. describe the formation of polyamides: "the reaction between a diamine and a dicarboxylic acid or
   dioyl chloride", "the reaction of an aminocarboxylic acid" and "the reaction between amino acids"
3. deduce the repeat unit of a condensation polymer obtained from a given monomer or pair of monomers
4. identify the monomer(s) present in a given section of a condensation polymer molecule

## The rule behind every condensation polymer

Each new link forms between two functional groups and releases a small molecule. To make a chain
rather than a single molecule, **every monomer needs two reactive groups**, one at each end.

| Groups that react | Link formed | Small molecule lost |
|---|---|---|
| –OH + –COOH | ester, –COO– | H₂O |
| –OH + –COCl | ester, –COO– | HCl |
| –NH₂ + –COOH | amide, –CONH– | H₂O |
| –NH₂ + –COCl | amide, –CONH– | HCl |

Dioyl chlorides react faster and at lower temperatures than dicarboxylic acids, for the same reason
acyl chlorides react faster than carboxylic acids.

## Polyesters

**(a) Diol + dicarboxylic acid.** Ethane-1,2-diol and benzene-1,4-dicarboxylic acid give PET:

    n HOCH₂CH₂OH + n HOOCC₆H₄COOH → –[OCH₂CH₂OOCC₆H₄CO]ₙ– + 2n H₂O

**(a) Diol + dioyl chloride.** The same polymer forms from benzene-1,4-dioyl chloride, ClOCC₆H₄COCl,
but HCl is lost instead of water:

    n HOCH₂CH₂OH + n ClOCC₆H₄COCl → –[OCH₂CH₂OOCC₆H₄CO]ₙ– + 2n HCl

**(b) A hydroxycarboxylic acid.** One molecule carries both groups, so it polymerises with itself.
2-hydroxypropanoic acid (lactic acid), CH₃CH(OH)COOH, gives poly(lactic acid):

    n HOCH(CH₃)COOH → –[OCH(CH₃)CO]ₙ– + n H₂O

## Polyamides

**(a) Diamine + dicarboxylic acid or dioyl chloride.** Hexane-1,6-diamine and hexanedioic acid (or
hexanedioyl chloride) give nylon-6,6:

    n H₂N(CH₂)₆NH₂ + n HOOC(CH₂)₄COOH → –[NH(CH₂)₆NHCO(CH₂)₄CO]ₙ– + 2n H₂O

**(b) An aminocarboxylic acid.** 6-aminohexanoic acid, H₂N(CH₂)₅COOH, gives a single-monomer
polyamide:

    n H₂N(CH₂)₅COOH → –[NH(CH₂)₅CO]ₙ– + n H₂O

**(c) Amino acids.** Each amino acid has –NH₂ and –COOH, so they join through peptide (amide) bonds
to give a polypeptide. With glycine and alanine, a section might be
–NHCH₂CO–NHCH(CH₃)CO–NHCH₂CO–. Proteins are polyamides of this kind.

**A note on the small-molecule count.** Strictly, n molecules of a diol and n of a diacid form 2n − 1
links, so 2n − 1 molecules of water. For a long chain the difference from 2n is negligible, and either
form is usually accepted; follow the convention your question uses.

## Method: drawing a repeat unit from monomers

1. Draw each monomer with its reactive groups at the ends.
2. Remove the atoms that leave: –OH from each –COOH (or –Cl from each –COCl), and –H from each –OH
   or –NH₂ that reacts.
3. Join the pieces with the new link, ester or amide.
4. Draw **open bonds** at both ends, through the brackets, and add **n**.
5. Check: a two-monomer repeat unit contains **one** of each monomer residue and **two** links' worth
   of atoms (one link inside, one shared at the ends).

For a single monomer (hydroxy- or aminocarboxylic acid), the repeat unit is one monomer residue.

## Method: finding monomers from a polymer section

1. Locate every **–COO–** or **–CONH–** link in the backbone.
2. Break each link at the C–O or C–N single bond.
3. Add –OH back to every C=O end (or –Cl, if the question asks for a dioyl chloride), and –H back to
   every O or N end.
4. **Direction test:** if all the links face the same way (–CO–O–, –CO–O–, …), there is one
   monomer type. If they alternate (–CO–O– then –O–CO–), there are two.

## Worked example 1: repeat unit from a diol and a dioyl chloride

**Question.** Propane-1,3-diol, HO(CH₂)₃OH, reacts with butanedioyl chloride, ClOC(CH₂)₂COCl. Draw the
repeat unit and name the small molecule lost.

**Answer.** Remove H from each –OH of the diol and Cl from each –COCl, then join through ester
links:

    –[O(CH₂)₃OOC(CH₂)₂CO]–

The small molecule is **HCl**. *Examiner's note:* a common error is to keep an –OH or –Cl at the end
of the repeat unit. Both ends must be open bonds.

## Worked example 2: monomers from a polymer section, and counting repeat units

**Question.** A polymer section is –NH(CH₂)₄NHCOC₆H₄CONH(CH₂)₄NHCOC₆H₄CO–.
(a) Identify the monomers. (b) A sample has Mᵣ = 27 400. Calculate the approximate number of repeat
units. (Aᵣ: H = 1.0, C = 12.0, N = 14.0, O = 16.0)

**Answer.**

(a) The amide links alternate in direction, so there are two monomers. Breaking the C–N bonds and
adding H to N and OH to C=O gives **butane-1,4-diamine, H₂N(CH₂)₄NH₂**, and
**benzene-1,4-dicarboxylic acid, HOOCC₆H₄COOH** (or its dioyl chloride).

(b) Repeat unit –NH(CH₂)₄NHCOC₆H₄CO– is C₁₂H₁₄N₂O₂.
Mᵣ = 12(12.0) + 14(1.0) + 2(14.0) + 2(16.0) = 218.0.
Number of repeat units = 27 400 / 218.0 = 125.7, so about **126**.

**Formula check.** The repeat unit's formula equals the two monomers' formulae added together, minus
two of the small molecule. Here C₄H₁₂N₂ + C₈H₆O₄ − 2H₂O = C₁₂H₁₄N₂O₂, which confirms the structure.

## Worked example 3: single-monomer and polypeptide sections

**Question.** Identify the monomer(s) in each section.
(i) –OCH(CH₃)CO–OCH(CH₃)CO–OCH(CH₃)CO–
(ii) –NHCH₂CO–NHCH(CH₃)CO–NHCH(CH₂OH)CO–

**Answer.**

(i) Every ester link faces the same way and every unit between links is identical, so there is one
monomer: **2-hydroxypropanoic acid, CH₃CH(OH)COOH**.

(ii) Every amide link faces the same way, but the units differ in their side chains, so this is a
polypeptide made from three different amino acids: **glycine, alanine and serine**. The links all
facing one way tells you each monomer carried both an –NH₂ and a –COOH; the different side chains
tell you how many different amino acids there were.

## Common mistakes

- Using a monomer with only **one** functional group; it caps the chain instead of extending it.
- Losing H₂O when a **dioyl chloride** is used; the by-product is HCl.
- Leaving end groups (–OH, –H, –Cl) on a repeat unit.
- Including **two** of one monomer in a two-monomer repeat unit.
- Breaking a polymer at the C=O bond instead of the C–O or C–N single bond.
- Treating peptide bonds as different from amide bonds; they are the same link.

## Exam technique for the command words

- **Describe** the formation: name both monomers, the link formed and the small molecule lost; an
  equation with n is often expected.
- **Deduce** a repeat unit: draw it with open bonds and brackets, with every atom shown in the link.
- **Identify** monomers: give full structural formulae, including both functional groups.
- **Calculate** the number of repeat units: Mᵣ of polymer ÷ Mᵣ of repeat unit, rounded sensibly.
