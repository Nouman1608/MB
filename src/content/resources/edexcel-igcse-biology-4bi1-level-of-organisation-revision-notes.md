Condensed notes for sub-topic 2(a) **Level of organisation**, point **2.1**, of Pearson Edexcel International GCSE Biology (4BI1), Issue 3: "describe the levels of organisation in organisms: organelles, cells, tissues, organs and systems". Examinable on Papers 1 and 2.

## The ladder

**organelle → cell → tissue → organ → system → organism**

| Level | One-line definition | Test question |
|---|---|---|
| Organelle | Structure inside a cell with a particular function | Is it inside a cell? |
| Cell | Basic structural and functional unit of life | Is it one cell? |
| Tissue | Group of similar cells working together for a function | Is it many cells of one type? |
| Organ | Several different tissues working together for a function | Can you name two or more tissues in it? |
| System | Group of organs working together for a function | Is it a set of organs? |

## Ladders for named organs

**Heart (circulatory system)**

- Organelle: mitochondria in cardiac muscle cells (energy for contraction)
- Cell: cardiac muscle cell
- Tissue: cardiac muscle; connective tissue in the valves; blood
- Organ: heart
- System: circulatory system (heart, arteries, veins, capillaries, blood)

**Lungs (gas exchange or breathing system)**

- Organelle: nucleus of an alveolar cell
- Cell: thin, flattened cell of the alveolus wall
- Tissue: epithelium of the alveoli; smooth muscle in the bronchioles; blood in the capillaries
- Organ: lung
- System: breathing system (trachea, bronchi, bronchioles, lungs, with the diaphragm and intercostal muscles)

**Root (plant)**

- Organelle: mitochondria in root hair cells (energy for active transport of mineral ions)
- Cell: root hair cell
- Tissue: root epidermis; xylem; phloem
- Organ: root
- System: root system

**Leaf (plant)**

- Organelle: chloroplast
- Cell: palisade mesophyll cell or guard cell
- Tissue: epidermis; palisade mesophyll; spongy mesophyll; xylem; phloem
- Organ: leaf
- System: shoot system (leaves and stem)

## Why the levels exist

- Large organisms have most cells far from the surface, so one cell cannot do every job.
- Cells **specialise**: their structure suits one function.
- Similar specialised cells form **tissues**; tissues combine into **organs**; organs combine into **systems**.
- Each system carries out a life process: digestion, transport, gas exchange, excretion, co-ordination, reproduction.
- Single-celled organisms stop at the cell level: one cell carries out all life processes.

## Key terms

| Term | Meaning |
|---|---|
| Organelle | A structure within a cell with a specific function |
| Cell | The smallest unit that can carry out the processes of life |
| Tissue | Similar cells working together to perform a function |
| Organ | Different tissues working together to perform a function |
| System | Organs working together to perform a function |
| Specialised cell | A cell whose structure is adapted to one function |
| Multicellular | Made of many cells |
| Unicellular | Made of one cell |

## Method in steps: "describe the levels of organisation in X"

1. Name the system X belongs to.
2. Name one organ in that system.
3. Name two tissues in that organ.
4. Name one cell type in one of those tissues.
5. Name one organelle in that cell and its job.
6. Write them in order, smallest first, with the level name beside each.

## Exam traps

- "A tissue is a group of cells": missing **similar**, so it also describes an organ.
- "An organ is made of cells": should be "made of different tissues".
- Blood is a **tissue**, not an organ and not "just a liquid".
- Xylem and phloem are **tissues**; the stem, root and leaf are the organs.
- Skin is an **organ**, not a tissue: it contains several tissues.
- A guard cell is a **cell**; a stoma is a pore between two guard cells, not an organelle.
- Asked for a sequence "from the smallest", start with the organelle, not the cell.

## Self-test

**1.** Define a tissue.
**2.** Define an organ.
**3.** Name the level of a mitochondrion.
**4.** Name the level of blood, with a reason.
**5.** Is the stomach a tissue or an organ? Give a reason.
**6.** Name two tissues found in a leaf.
**7.** Put in order, smallest first: lung, alveolar epithelium, nucleus, breathing system, alveolar cell.
**8.** Name the level of a root hair cell.
**9.** Which system do the kidneys belong to?
**10.** Why does a single-celled organism have no tissues?
**11.** Name an organ in the nervous system.
**12.** Give the level above the organ in a plant, with an example.

### Answers

**1.** A group of similar cells working together to carry out a particular function.
**2.** A structure made of several different tissues working together to carry out a particular function.
**3.** Organelle.
**4.** Tissue: it is made of similar cells (red and white blood cells, platelets) in plasma, working together to transport substances and fight infection.
**5.** Organ: it contains different tissues, such as muscle, glandular tissue and epithelium.
**6.** Any two: epidermis, palisade mesophyll, spongy mesophyll, xylem, phloem.
**7.** Nucleus → alveolar cell → alveolar epithelium → lung → breathing system.
**8.** Cell.
**9.** The urinary system, which carries out excretion.
**10.** It is only one cell, so there are no groups of similar cells.
**11.** Brain or spinal cord.
**12.** System: for example the shoot system (leaves and stem) or the root system.
