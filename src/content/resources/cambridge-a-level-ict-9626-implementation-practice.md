These questions cover **section 16.5 Implementation** of the Cambridge International AS & A Level Information Technology 9626 syllabus for examination in 2025, 2026 and 2027 (version 4). This is **A Level only** content examined in Paper 3 (Advanced Theory), where calculators are not allowed. All questions can be answered on paper.

Revise first with the [study guide](/resources/cambridge-a-level-ict-9626-implementation/) and [revision notes](/resources/cambridge-a-level-ict-9626-implementation-revision-notes/). The [Cambridge A Level IT hub](/boards/cambridge/a-level/ict/) lists every topic.

## Questions

**1.** State the **four** methods of implementing a new system. **[4]**

**2.** Describe what is meant by direct changeover. **[2]**

**3.** A city library service has 12 branches. It is replacing its book-lending system with a new one.

**(a)** Describe how pilot implementation would be carried out for this library service. **[3]**
**(b)** Give **two** advantages of pilot implementation for this library service. **[2]**
**(c)** Give **one** disadvantage of pilot implementation for this library service. **[1]**

**4.** A manufacturer is replacing the system that calculates the wages of 800 factory workers.

**(a)** Explain why parallel running is a suitable method. **[2]**
**(b)** Describe how parallel running would be carried out. **[2]**
**(c)** Give **two** disadvantages of parallel running for the manufacturer. **[2]**

**5.** A college is introducing a new system with four separate modules: admissions, timetabling, attendance and reports. It will introduce one module at a time, completing each before starting the next. Each module takes 3 weeks to introduce and settle in.

**(a)** Name the method of implementation. **[1]**
**(b)** Calculate the time needed to introduce all four modules. **[1]**
**(c)** Explain why the college might prefer this method to direct changeover. **[2]**
**(d)** Give **one** disadvantage of this method. **[1]**

**6.** Explain the difference between phased implementation and pilot implementation. **[2]**

**7.** A small florist has one shop and three staff. Its old stock spreadsheet has been losing data. A new stock-control package has been bought and tested. Staff can be trained in an afternoon.

**(a)** Recommend an implementation method for the florist. **[1]**
**(b)** Justify your recommendation. **[3]**

**8.** A hospital is replacing its patient records system. Records are used on every ward, every hour of the day.

Evaluate the suitability of direct changeover and parallel running for the hospital, and recommend a method. **[6]**

## Answers

**1.** Parallel running [1]; direct changeover [1]; phased implementation [1]; pilot implementation. [1] **[4]**

**2.** The old system is stopped on a set date [1] and the new system starts to be used straight away, with no period in which both run. [1] **[2]**

**3. (a)** The whole new system is installed in one branch only [1], and used there for a trial period with real borrowers and staff [1]. If it works well, faults are fixed and it is installed in the other 11 branches (perhaps in groups). [1] **[3]**
**(b)** Any two, one mark each: any fault affects only one branch, not all 12; staff in the pilot branch can help train staff in the others; the system is tested in real conditions with real data; lessons from the pilot can be used to improve the system before roll-out. **[2]**
**(c)** Any one: it takes a long time to reach all 12 branches; the library service has two different systems running at once; the pilot branch's staff may be under pressure if problems occur. [1] **[1]**
*Examiner insight:* An advantage must be applied to this scenario: "fewer branches affected" scores, but "it is safe" alone does not.

**4. (a)** Wages are critical, because errors in pay would affect 800 workers [1]; parallel running keeps the old system as a fallback and lets the two sets of results be compared before the old system is switched off. [1] **[2]**
**(b)** The same timesheet data is entered into both the old and the new wages systems for one or more pay runs [1], and the wages produced by both are compared, with any differences investigated; the old system is switched off once the results agree. [1] **[2]**
**(c)** Any two: work is done twice, which takes more staff time and costs more; staff workload doubles, so errors may increase; it may need extra computers or capacity; it takes longer than direct changeover. [1 each] **[2]**

**5. (a)** Phased implementation. [1] **[1]**
**(b)** 4 × 3 = 12 weeks. [1] **[1]**
**(c)** If one module fails, only that part is affected and the rest of the old system still works, so the risk is lower [1]; staff can learn one module at a time. [1] **[2]**
**(d)** Any one: it takes longer to complete; the old and new systems must work together during the changeover. [1] **[1]**

**6.** Phased introduces one part (module) of the system at a time, across the whole organisation [1]; pilot introduces the whole system, but in one place (such as one branch) first. [1] **[2]**
*Examiner insight:* Put both halves in the answer. "Phased is in stages" alone does not distinguish it.

**7. (a)** Direct changeover. [1] **[1]**
**(b)** Any three, one mark each: there is only one shop and so no other site for a pilot [1]; the package has been tested [1]; the old system is already unreliable, so there is little worth keeping as a fallback [1]; the data volume is small and staff can be trained quickly, so disruption is low [1]; parallel running would be costly for three staff for little benefit [1]. **[3]**

**8.** Direct changeover (up to 2 marks): quick, cheap, no double entry [1]; but very high risk, because if the new system fails on any ward there is no fallback and patient care could be harmed. [1]
Parallel running (up to 3 marks): the old records remain available and can be compared with the new [1]; safest for critical records [1]; but nurses and clerks must enter data twice, which is slow and may lead to mistakes in a busy hospital, and it costs more. [1]
Conclusion (1 mark): a justified recommendation, for example parallel running, or pilot on one ward followed by roll-out, because patient safety matters more than cost. [1]
Maximum 6. **[6]**
*Examiner insight:* A recommendation without a reason related to the hospital will not be credited.

## Where marks are usually lost

- Writing "one department at a time" for phased implementation.
- Giving advantages that do not refer to the scenario.
- Saying direct changeover is "fast" and ignoring the absence of a fallback.
- Not saying that both systems are run, and compared, in parallel running.
- Leaving out a conclusion in an "evaluate" question.

## Frequently asked questions

**How should I choose an implementation method in an exam answer?**
Name a method, explain how it would work in the scenario, give an advantage or disadvantage for that scenario and, if the command word asks you to justify or evaluate, finish with a conclusion.

**Is parallel running always the best method?**
No. It is the safest but the most costly, so it suits critical systems where errors would be serious.
