Section 1.3 of Cambridge IGCSE ICT 0417 asks for the characteristics of four types of operating system interface (command line, graphical, dialogue-based and gesture-based), the differences between them, and the advantages and disadvantages of each type.

Condensed for revision. For the full explanations and model answers, use the [operating systems study guide](/resources/cambridge-igcse-ict-0417-operating-systems/), then try the [operating systems practice questions](/resources/cambridge-igcse-ict-0417-operating-systems-practice/).

## Each interface in three lines

**Command Line Interface (CLI)**

- Typed commands at a prompt, exact syntax, text only.
- For: full control, low memory use, fast for experts, one command can act on many files.
- Against: commands must be learned, typing errors, not suitable for beginners.

**Graphical User Interface (GUI)**

- Windows, icons, menus and a pointer (WIMP), or touch.
- For: easy to learn, intuitive, no commands to remember, several windows open.
- Against: more memory, processing power and storage; slower for experts; less direct control.

**Dialogue-based interface**

- Spoken commands; speech recognition; the computer may answer in speech.
- For: hands-free and eyes-free, helps users with some disabilities, no typing.
- Against: background noise, accents and unclear speech cause errors; limited commands; not private.

**Gesture-based interface**

- Hand or body movements detected by a touch screen or a camera and sensors.
- For: natural and quick to learn, no extra input device, contact-free options are hygienic.
- Against: accidental gestures, limited range of gestures, tiring, affected by lighting.

## Comparison table

| | CLI | GUI | Dialogue | Gesture |
|---|---|---|---|---|
| Input | Typing | Pointing and clicking | Speech | Movement |
| Learning | Hard | Easy | Fairly easy | Easy |
| Resources needed | Low | High | High | High |
| Control | Most | Less | Limited commands | Limited gestures |
| Typical user | Technician | Most users | Driver, user with a disability | Phone or tablet user, gamer |

## Matching interface to scenario

| Scenario | Best fit | Key reason |
|---|---|---|
| Configuring a network server | CLI | Direct control; commands applied to many items |
| Office worker writing reports | GUI | Easy to learn; several windows open |
| Driver changing music or calling | Dialogue | Hands stay on the wheel |
| User who cannot use their hands | Dialogue | Speech replaces typing and pointing |
| Surgeon viewing scans | Gesture (camera) or dialogue | No touching, so no contamination |
| Young child using a tablet | Gesture (touch) | Natural movements, no reading needed |

## One task, four interfaces

Opening a document called *report*:

- **CLI**: type the command and the file name exactly, then press Enter.
- **GUI**: double-click the file's icon in a folder window.
- **Dialogue**: say "open report" and wait for the computer to confirm.
- **Gesture**: tap the file's icon on a touch screen.

## Key terms

| Term | Meaning |
|---|---|
| Interface | The way a user communicates with a computer |
| Syntax | The exact rules for how a command must be typed |
| Prompt | Symbol or text showing that the CLI is ready for a command |
| WIMP | Windows, icons, menus, pointer: the traditional GUI |
| Icon | A small picture representing a program, file or action |
| Speech recognition | Software that identifies spoken words |
| Gesture | A movement, such as a swipe or pinch, linked to an action |

## Exam traps

- A CLI still has a display; it shows text instead of graphics.
- "Dialogue-based" means spoken interaction, not typing into a chat box.
- Do not give "easy to use" and "user friendly" as two separate advantages.
- A GUI's disadvantage is more memory and processing power, not simply "slow".
- In a recommend question, one interface must be named before the justification.
- Justify using the scenario: "hands-free, so the driver keeps both hands on the wheel".

## Self-test

1. State what is meant by a command line interface.
2. Give **two** advantages of a CLI.
3. What does WIMP stand for?
4. Give **one** disadvantage of a GUI compared with a CLI.
5. Describe how a user gives instructions in a dialogue-based interface.
6. Give **two** reasons a dialogue-based interface might not recognise a command.
7. Name **two** ways a gesture-based interface can detect movements.
8. Give **one** disadvantage of a gesture-based interface.
9. Which interface uses the least memory and processing power?
10. Recommend an interface for a chef following a recipe while cooking, and give a reason.
11. Why is a GUI easier for a beginner than a CLI?
12. Give **one** advantage of a camera-based gesture interface over a touch screen.

## Self-test answers

1. An interface where the user types commands at a prompt, using exact syntax, with mainly text on screen.
2. Any two: more control; low memory and processing use; fast for experts; one command can act on many files; commands can be saved and repeated.
3. Windows, icons, menus, pointer.
4. It uses more memory and processing power, or is slower for experienced users, or gives less direct control.
5. They speak commands, which speech recognition software identifies; the computer may reply in speech.
6. Any two: background noise; an accent or unclear speech; the command is not one it recognises; illness affecting the voice.
7. A touch screen; a camera with sensors.
8. Any one: accidental movements are recognised; limited gestures; tiring; affected by lighting.
9. The CLI.
10. Dialogue-based, because the chef's hands may be busy or dirty and can stay on the task.
11. Options are shown as icons and menus that can be recognised, so no commands need to be remembered.
12. No physical contact is needed, which is more hygienic; or gestures can be made from a distance.
