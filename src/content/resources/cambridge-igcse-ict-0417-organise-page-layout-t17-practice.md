**1.** State the difference between portrait and landscape orientation. **[1]**

**2.** Which **one** of the following makes the text after it start at the top of the next column?

A: page break

B: column break

C: continuous section break

D: next page section break

**[1]**

**4.** Give **two** layout settings that can be different in different sections of the same document. **[2]**

## Section B: structured questions

**7.** A school newsletter is set up on A4 portrait paper with left and right margins of 2 cm. The articles are in three equal columns with 1 cm spacing between columns.

**(a)** Calculate the width of the text area. **[1]**

**(b)** Calculate the width of each column. Show your working. **[2]**

**(c)** The newsletter title must span the full width of the page above the three columns. Describe how this is done. **[2]**

**8.** A six-page report is in portrait orientation. Page 4 contains a wide table and must be in landscape orientation; all other pages stay portrait.

Describe how the student should set this up. **[3]**

**9.** A student deletes a section break near the end of a document. The text on the pages before it suddenly appears in two columns.

**(a)** Explain why this has happened. **[2]**

**(b)** State how the student should correct it. **[1]**

**10.** A leaflet has a text width of 17 cm and two unequal columns with 1 cm spacing. The left column is 5.5 cm wide.

**(a)** Calculate the width of the right column. **[1]**

**(b)** Explain why the widths should be typed into the column settings rather than set by dragging the ruler. **[1]**

**11.** A student moves a heading to the top of the next page by pressing Enter until it gets there.

Explain **two** problems this causes and state the better method. **[3]**

**12.** A leaflet is printed on A5 paper in landscape orientation, with left and right margins of 1.5 cm and two equal columns with 0.7 cm spacing.

Calculate the width of each column. Show your working. **[2]**

**13.** A task says: "Set the margins to 2.5 cm." A student's software is measuring in inches, and the student types 2.5.

Explain the effect on the document. **[2]**

## Answers

**1.** Portrait pages are taller than they are wide; landscape pages are wider than they are tall. **[1]**

**2.** B: column break. **[1]**

**3.** 21.0 - 2 - 2 = 17.0 cm. **[1]**

**4.** Any two: orientation (1); margins (1); number of columns (1); column width or spacing (1); headers and footers (1); page numbering (1); page size (1). **[2]**

**5.** Letter paper is a different size from A4 (21.59 × 27.94 cm against 21.0 × 29.7 cm) (1), so the text area, line endings and page breaks will not match the expected A4 layout, and the document may print with wrong margins or be scaled (1). **[2]**

**6.** Show formatting marks (¶), so that the break appears as a labelled dotted line that can be selected. **[1]**

**7. (a)** 21.0 - 2 - 2 = 17.0 cm. **[1]**

**(b)** Two gaps of 1 cm = 2 cm (1); (17.0 - 2) ÷ 3 = 5.0 cm per column (1). **[2]**

**(c)** Insert a continuous section break after the title (1); set the section containing the articles to three columns, leaving the title's section as one column (1). **[2]**

**8.** Insert a next page section break before the table (at the start of page 4) (1); insert another next page section break after the table (1); set only the section containing page 4 to landscape, leaving the other sections portrait (1). **[3]**

**9. (a)** The section break held the layout settings of the section before it (1); deleting it merged the two sections, so the earlier text took on the two-column layout of the section after the break (1). **[2]**

**(b)** Undo the deletion (or reinsert a section break and set the earlier section back to one column). **[1]**

**10. (a)** 17 - 5.5 - 1 = 10.5 cm. **[1]**

**(b)** Typing the values sets the exact measurements required, whereas dragging the ruler gives only approximate widths. **[1]**

**11.** Any two problems, 1 mark each: if text above is added or deleted, the heading moves away from the top of the page (1); the extra blank lines can create an unwanted blank page or blank space (1); it is slow and hard to keep consistent (1). Better method: insert a page break before the heading (1). **[3]**

**12.** A5 landscape width is 21.0 cm, so text width = 21.0 - 1.5 - 1.5 = 18.0 cm (1); one gap: (18.0 - 0.7) ÷ 2 = 17.3 ÷ 2 = 8.65 cm per column (1). **[2]**

**13.** The margins would be 2.5 inches, which is 2.5 × 2.54 = 6.35 cm, instead of 2.5 cm (1); the text area would be much narrower, so the text would run onto more pages and the layout would not match the instruction (1). **[2]**

## Frequently asked questions

**Do I need to remember paper sizes?**
Knowing that A4 is 21.0 cm by 29.7 cm lets you calculate text and column widths, and makes it easy to spot when the paper size is wrong.

**Why do column widths sometimes change by themselves?**
If the widths and spacing you enter do not add up to the text width, the software adjusts a value to make them fit. Check every value after you set them.
