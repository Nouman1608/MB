This practice set covers section 2.5 of IB Diploma Programme Mathematics: Analysis and Approaches: composite functions, the identity function and inverse functions. It is for SL and HL. Questions are calculator-free unless labelled, matching Paper 1; give exact answers.

## Section A

**1.** Let f(x) = 3x − 4 and g(x) = x² + 1.

**(a)** Find (f ∘ g)(2). **[1]**
**(b)** Find and simplify (g ∘ f)(x). **[2]**

**2.** Let f(x) = (x + 5)/2. Find f⁻¹(x). **[2]**

**3.** Let f(x) = 4 − 3x.

**(a)** Find f⁻¹(x). **[2]**
**(b)** Verify that (f ∘ f⁻¹)(x) = x. **[1]**

**4.** Let f(x) = x + 2. Given that (f ∘ g)(x) = 3x² − 1, find g(x). **[2]**

**5.** Write h(x) = √(5x + 1) in the form (f ∘ g)(x), stating f(x) and g(x). **[2]**

**6.** Let f(x) = 2x − 3. Solve f(x) = f⁻¹(x). **[3]**

## Section B

**7.** Let f(x) = 1/(x − 2), x ≠ 2, and g(x) = x² + 2, x ∈ ℝ.

**(a)** Find and simplify (f ∘ g)(x). **[2]**
**(b)** State the domain of f ∘ g. **[1]**
**(c)** Find (g ∘ f)(x). **[2]**
**(d)** Write down the range of g ∘ f. **[1]**

**8.** Let f(x) = (2x − 1)/(x + 3), x ≠ −3.

**(a)** Find f⁻¹(x). **[4]**
**(b)** State the domain of f⁻¹. **[1]**
**(c)** Hence write down the range of f. **[1]**

**9.** Let f(x) = x² + 4x + 7, x ≥ −2.

**(a)** Write f(x) in the form (x + p)² + q. **[2]**
**(b)** Write down the range of f. **[1]**
**(c)** Find f⁻¹(x), stating its domain. **[3]**
**(d)** Find f⁻¹(12). **[1]**

**10.** Let f(x) = 2x + 1 and g(x) = x² − 3.

**(a)** Find (f ∘ g)(x). **[1]**
**(b)** Find (g ∘ f)(x). **[2]**
**(c)** Show that there is no real x for which (f ∘ g)(x) = (g ∘ f)(x). **[3]**

**11.** (calculator allowed) In an invented model, a currency service converts d dollars into euros using E(d) = 0.92d − 2, and converts e euros into yen using Y(e) = 160e.

**(a)** Find (Y ∘ E)(d) and explain what it represents. **[2]**
**(b)** Find (Y ∘ E)(500). **[1]**
**(c)** Find (Y ∘ E)⁻¹(x). **[2]**
**(d)** Find the number of dollars needed to receive 50 000 yen. **[1]**

**12.** Let f(x) = −x³, x ∈ ℝ.

**(a)** Find f⁻¹(x). **[2]**
**(b)** Solve f(x) = f⁻¹(x). **[3]**
**(c)** Explain why not all the solutions in (b) lie on the line y = x. **[1]**

## Answers

**1. (a)** g(2) = 5, so (f ∘ g)(2) = 15 − 4 = **11** [1]
**(b)** (3x − 4)² + 1 [1] = **9x² − 24x + 17** [1]

**2.** y = (x + 5)/2 gives x = 2y − 5 [1], so **f⁻¹(x) = 2x − 5** [1]

**3. (a)** y = 4 − 3x gives 3x = 4 − y [1], so **f⁻¹(x) = (4 − x)/3** [1]
**(b)** f((4 − x)/3) = 4 − (4 − x) = x [1]

**4.** g(x) + 2 = 3x² − 1 [1], so **g(x) = 3x² − 3** [1]

**5.** **g(x) = 5x + 1** [1] and **f(x) = √x** [1]

**6.** f⁻¹(x) = (x + 3)/2 [1]. 2x − 3 = (x + 3)/2 gives 4x − 6 = x + 3 [1], so **x = 3** [1]
*Examiner insight:* Because f is increasing, solving 2x − 3 = x gives the same answer more quickly; either method earns full marks.

**7. (a)** 1/((x² + 2) − 2) [1] = **1/x²** [1]
**(b)** **x ≠ 0** [1]
**(c)** (1/(x − 2))² + 2 [1] = **1/(x − 2)² + 2**, x ≠ 2 [1]
**(d)** 1/(x − 2)² takes every positive value, so the range is **(g ∘ f)(x) > 2** [1]

**8. (a)** y(x + 3) = 2x − 1 [1]; xy − 2x = −1 − 3y [1]; x(y − 2) = −(3y + 1), so x = (3y + 1)/(2 − y) [1]; **f⁻¹(x) = (3x + 1)/(2 − x)** [1]
**(b)** **x ≠ 2** [1]
**(c)** The range of f is the domain of f⁻¹: **f(x) ≠ 2** [1]

**9. (a)** (x + 2)² − 4 + 7 [1] = **(x + 2)² + 3** [1]
**(b)** **f(x) ≥ 3** [1]
**(c)** y = (x + 2)² + 3 gives x + 2 = √(y − 3), positive root since x ≥ −2 [1]; **f⁻¹(x) = −2 + √(x − 3)** [1], domain **x ≥ 3** [1]
**(d)** −2 + √9 = **1** [1]

**10. (a)** 2(x² − 3) + 1 = **2x² − 5** [1]
**(b)** (2x + 1)² − 3 [1] = **4x² + 4x − 2** [1]
**(c)** 2x² − 5 = 4x² + 4x − 2 gives 2x² + 4x + 3 = 0 [1]. Discriminant 16 − 24 = −8 [1] < 0, so there are no real solutions [1]

**11. (a)** 160(0.92d − 2) = **147.2d − 320** [1]; it converts d dollars directly into yen [1]
**(b)** 147.2(500) − 320 = **73 280 yen** [1]
**(c)** y = 147.2x − 320 gives x = (y + 320)/147.2 [1], so **(Y ∘ E)⁻¹(x) = (x + 320)/147.2** [1]
**(d)** (50 000 + 320)/147.2 = **$341.85** [1]

**12. (a)** y = −x³ gives x³ = −y and x = −∛y [1], so **f⁻¹(x) = −∛x** [1]
**(b)** −x³ = −∛x, so x³ = ∛x and x⁹ = x [1]; x(x⁸ − 1) = 0 [1], giving **x = −1, 0, 1** [1]
**(c)** f is decreasing, so its graph and its inverse can meet off y = x: at x = 1, f(1) = f⁻¹(1) = −1 ≠ 1 [1]

## Where marks are usually lost

- Composites worked in the wrong order.
- The domain of a composite read from the simplified formula, as in question 7.
- Rational inverses with the x terms not collected first, as in question 8.
- ± left in an inverse on a restricted domain.
- Solving f(x) = x for a decreasing function and missing solutions, as in question 12.
