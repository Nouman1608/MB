Document production in Cambridge IGCSE ICT 0417 (Topic 17) is the word-processing skill set assessed in Paper 2: organising page layout (size, orientation, margins, columns and breaks), formatting text (line spacing, tabs, indents, enhancements, lists), finding and replacing text, and adding bookmarks and hyperlinks. You must also know the purpose of page, section and column breaks and of gutter margins.

## Organise page layout

| Setting | Options / notes |
|---|---|
| Page size | For example A4 or letter, as instructed |
| Orientation | Portrait (tall) or landscape (wide) |
| Margins | Top, bottom, left, right, set to the exact measurement |
| Columns | Number of columns, column width, spacing between columns |
| Breaks | Page break, section break, column break — set and remove |

## What is the purpose of page, section and column breaks?

| Break | Purpose |
|---|---|
| Page break | Starts the following text on a new page, for example to begin a new chapter or keep a table together |
| Section break | Divides the document into sections that can have different layouts — for example one column for the title, then two columns for the body, or a landscape page among portrait ones; different headers and footers per section |
| Column break | Forces the following text to the top of the next column, for example to balance columns or start a new article |

## Format text

### Line spacing

Single, 1.5 lines, double, or multiple (for example 1.15). **Paragraph spacing** before and after is set in points and is separate from line spacing.

### Tabs and indents

| Tab | Text aligns ... | Use |
|---|---|---|
| Left | starting at the tab stop | Lists of names |
| Right | ending at the tab stop | Page numbers in a contents list |
| Centred | centred on the tab stop | Centred headings in columns |
| Decimal | on the decimal point | Prices and money values |

- **Indented paragraph**: the whole paragraph is moved in from the margin.
- **Hanging paragraph** (hanging indent): the first line starts at the margin and the following lines are indented — used for numbered references and glossaries.

### Text enhancement and case

Bold, underline, italic, **superscript** (raised text, for example m²) and **subscript** (lowered text, for example H₂O). Changes in case: UPPER CASE, lower case, Sentence case, Title Case.

### Lists

Bulleted lists for items in no particular order; numbered lists for steps or ranked items. Change bullet type or numbering style when instructed.

## Find and replace

- **Match case**: only finds text with the same capitals (replacing *ICT* will not change *ict*).
- **Whole words only**: only finds the complete word (replacing *cat* will not change *category*).
- Use **Replace All** only when you are sure every occurrence should change; check the count reported.

## Navigation: bookmarks and hyperlinks

- A **bookmark** marks a location in a document by name.
- A **hyperlink** can jump to a bookmark in the same document, another file, a web page or an email address.
- You must be able to **add and delete** both.

## What is a gutter margin for?

A **gutter margin** is extra margin space added to the inside edge of pages (left side, or top) for **binding**, so text is not hidden in the binding when the document is printed and bound or stapled. Mirrored margins with a gutter are used when pages are printed on both sides.

## Worked example: setting up a newsletter

*Instruction: A4 portrait, margins 2 cm all round, 1.5 cm gutter. Title in a single column, the rest in two columns 1 cm apart. Prices aligned with a decimal tab at 12 cm.*

Steps: set page size A4 and portrait → margins 2 cm, gutter 1.5 cm → type the title → insert a **continuous section break** after it → format the new section as two columns with 1 cm spacing → select the price lines → set a decimal tab at 12 cm.

## Common mistakes and exam traps

- Using a page break when a section break is needed to change the number of columns.
- Pressing Enter or Space repeatedly to move text instead of using breaks, tabs or alignment.
- Using a left tab for money values instead of a decimal tab.
- Forgetting "match case" or "whole words" in find and replace, so the wrong text is changed.
- Confusing line spacing with spacing before/after paragraphs.
- Setting a gutter on the wrong side, or forgetting it is for binding.

## Frequently asked questions

**What is the difference between a page break and a section break?**
A page break simply starts a new page. A section break starts a new section, which can have its own columns, orientation, margins and headers and footers.

**What is a decimal tab used for?**
A decimal tab lines up numbers by their decimal point, so prices such as 4.50 and 125.99 line up neatly in a column.

**Why would you set a gutter margin?**
To leave extra space on the inside edge of each page for binding, so no text is lost when the document is bound.

**What does "match case" do in find and replace?**
It only finds text whose capital and lower-case letters match exactly what you typed.

## Self-test

1. Name the break used to change from one column to two columns on the same page.
2. Which tab would you use to line up the page numbers on the right of a contents page?
3. Give one example each of superscript and subscript.
4. Describe a hanging paragraph.
5. State the purpose of a gutter margin.

*Answers: 1 (continuous) section break; 2 right tab; 3 superscript: m² or 1st, subscript: H₂O or CO₂; 4 first line at the margin, following lines indented; 5 extra space on the inside edge for binding.*
