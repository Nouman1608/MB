This guide covers subtopic **1.18 Surds** in Topic 1, Number, of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027 series. A surd is a root that cannot be written as an exact fraction, such as √2 or √7. Working with surds keeps answers exact instead of rounding them. The [Number revision notes](/resources/o-level-mathematics-number-revision-notes/) give a brief summary. This page covers simplifying, adding, multiplying, expanding and rationalising, with every step shown.

Companion pages: the [Surds revision notes](/resources/cambridge-o-level-mathematics-4024-surds-revision-notes/) and the [Surds practice questions](/resources/cambridge-o-level-mathematics-4024-surds-practice/).

## What the syllabus asks

The syllabus asks you to:

1. understand and use surds, including simplifying expressions
2. rationalise the denominator.

The notes give examples of simplifying a single root and combining several roots into one multiple of a surd, and of rationalising a fraction with a single surd as the denominator and one with a bracket such as a number plus a surd. You need to do this by hand, because surds are mainly examined on the non-calculator paper.

## What is a surd?

A **surd** is an irrational root of a rational number. √2, √3, √5, √7 and ∛4 are surds. Roots that come out exactly, such as √16 = 4 and √(9/25) = 3/5, are not surds because they are rational.

Surds have infinitely many decimal places that never repeat, so the exact value is best written with the root sign. The calculator shows only an approximation: √2 = 1.41421356...

## Two rules

For positive numbers a and b:

```
√(a x b) = √a x √b
√(a ÷ b) = √a ÷ √b
```

These are the only rules for multiplying and dividing roots. There is **no** rule for addition: √(a + b) is not √a + √b. For example, √(9 + 16) = √25 = 5, but √9 + √16 = 3 + 4 = 7.

Another fact is √a × √a = a. Squaring a root cancels it.

```
√5 x √5 = 5
(3√2)^2 = 9 x 2 = 18
```

## Simplifying a surd

To simplify √n, look for the **largest square number** that divides n. Write n as that square times another factor. Take the square root of the square.

**Worked example.** Simplify √72.

```
72 = 36 x 2
√72 = √36 x √2 = 6√2
```

**Worked example.** Simplify √45.

```
45 = 9 x 5
√45 = 3√5
```

**Worked example.** Simplify √48.

```
48 = 16 x 3
√48 = 4√3
```

If you do not spot the largest square at once, you can take out smaller squares in stages. For √72, 72 = 4 × 18 gives 2√18, and 18 = 9 × 2 gives 2 × 3√2 = 6√2. The result is the same, but going in one step is faster.

A surd is **fully simplified** when the number under the root has no square factor except 1. So 6√2 is simplified, but 2√18 is not.

## Adding and subtracting surds

You can only add or subtract **like surds**, which have the same number under the root. Simplify every surd first, as unlike surds may turn out to be like surds. Then treat √ as if it were a letter and collect like terms.

**Worked example.** Simplify √45 + √20.

```
√45 = 3√5
√20 = 2√5
3√5 + 2√5 = 5√5
```

**Worked example.** Simplify √75 + √12 - √27.

```
√75 = 5√3,   √12 = 2√3,   √27 = 3√3
5√3 + 2√3 - 3√3 = 4√3
```

**Worked example.** Simplify 3√2 + 2√5.

```
These are unlike surds, so the expression cannot be simplified further.
```

## Multiplying surds

Multiply the numbers outside the roots, and multiply the numbers inside the roots. Then simplify.

```
(3√2) x (4√5) = 12√10
√6 x √10 = √60 = √(4 x 15) = 2√15
```

To square a bracket containing surds, remember that (a + b)² has a middle term.

## Expanding brackets with surds

Expand as in algebra, with every term in the first bracket multiplied by every term in the second.

**Worked example.** Expand and simplify (2 + √5)².

```
(2 + √5)(2 + √5) = 4 + 2√5 + 2√5 + 5
                 = 9 + 4√5
```

**Worked example.** Expand and simplify (3 + √2)(1 + √2).

```
3 + 3√2 + √2 + 2 = 5 + 4√2
```

**Worked example.** Expand (√3 + 2)(√3 - 2).

```
3 - 2√3 + 2√3 - 4 = -1
```

This last example is a **difference of two squares**: (a + b)(a - b) = a² - b². With surds, it removes the root. For example, (5 + √2)(5 - √2) = 25 - 2 = 23. The pair a + √b and a - √b are called **conjugates**.

## Rationalising the denominator

A fraction with a surd in the denominator is usually rewritten so that the denominator is a whole number. This is called **rationalising**.

### A single surd in the denominator

Multiply the top and bottom by the surd.

```
6/√3 = (6 x √3)/(√3 x √3) = 6√3/3 = 2√3
5/(2√5) = (5 x √5)/(2√5 x √5) = 5√5/10 = √5/2
```

You multiply by the surd only (not by 2√5), to keep the working simple.

### A bracket with a surd in the denominator

For a denominator like a + √b, multiply top and bottom by the conjugate a - √b. The product (a + √b)(a - √b) = a² - b is rational.

**Worked example.** Rationalise 3/(2 + √5).

```
multiply top and bottom by (2 - √5):
3(2 - √5) / ((2 + √5)(2 - √5))
= (6 - 3√5) / (4 - 5)
= (6 - 3√5) / (-1)
= 3√5 - 6
```

Check numerically: 3 ÷ (2 + 2.236) = 0.708, and 3 × 2.236 - 6 = 0.708. ✓

**Worked example.** Rationalise 4/(3 - √5).

```
multiply by (3 + √5):
4(3 + √5) / (9 - 5) = 4(3 + √5)/4 = 3 + √5
```

**Worked example.** Rationalise 1/(√7 - √3).

```
multiply by (√7 + √3):
(√7 + √3) / (7 - 3) = (√7 + √3)/4
```

**Worked example.** Show that (2 + √3)/(2 - √3) = 7 + 4√3.

```
multiply top and bottom by (2 + √3):
(2 + √3)^2 / (4 - 3) = (4 + 4√3 + 3)/1 = 7 + 4√3
```

## Surds in geometry

Exact lengths and areas often involve surds.

**Worked example.** A rectangle has sides √12 cm and √27 cm. Find its area and perimeter in exact form.

```
√12 = 2√3,   √27 = 3√3
area = √12 x √27 = √324 = 18 cm^2
perimeter = 2(2√3 + 3√3) = 10√3 cm
```

**Worked example.** A right-angled isosceles triangle has two sides of length 4 cm. Find the hypotenuse.

```
h^2 = 4^2 + 4^2 = 32
h = √32 = √(16 x 2) = 4√2 cm
```

## Exam technique

- Look for a square factor first: 4, 9, 16, 25, 36, 49. If the question says "simplify", the answer must have no square factors under the root.
- When the answer must be "in the form a + b√c", expand fully and collect rational terms together and surd terms together.
- To rationalise, multiply top and bottom by the same thing. Show the new denominator being worked out.
- Do not use a calculator decimal when an exact answer is asked for.
- Check with a decimal approximation on a scrap calculation if the paper allows.

## Common mistakes

- Writing √(a + b) = √a + √b.
- Adding unlike surds, such as 3√2 + 2√5 = 5√7.
- Forgetting the middle terms when squaring a bracket: (2 + √5)² is not 4 + 5.
- Multiplying the top but not the bottom when rationalising.
- Using the same sign instead of the conjugate: (2 + √5)(2 + √5) is not rational.
- Leaving a surd partly simplified, such as 2√18.
- Mishandling the minus sign when the denominator becomes -1.

## Where this leads

Surds appear in Pythagoras' theorem, trigonometry with exact values, the quadratic formula and coordinate geometry for lengths of line segments. The skills of expanding and simplifying also support the algebraic manipulation topic.
