This guide covers subtopic **1.7 Indices I** in Topic 1, Number, of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027 series. Indices I deals with numerical powers: you evaluate and simplify expressions in which the base is a number. The [Number revision notes](/resources/o-level-mathematics-number-revision-notes/) give a brief summary, and the [Indices II study guide](/resources/cambridge-o-level-mathematics-4024-indices-ii/) extends the same rules to algebra and to equations. This page builds the numerical skills that Indices II relies on.

Companion pages: the [Indices I revision notes](/resources/cambridge-o-level-mathematics-4024-indices-i-revision-notes/) and the [Indices I practice questions](/resources/cambridge-o-level-mathematics-4024-indices-i-practice/).

## What the syllabus asks

The syllabus lists two outcomes:

1. Understand and use indices that are positive, zero, negative and fractional. Examples include that a power of one half is a square root (6 to the power 1/2 is √6) and that a power of one quarter is a fourth root. You may also be asked to find the value of a number with a negative index, such as 7⁻², or with a fractional index.
2. Understand and use the rules of indices. Examples are finding 2⁻³ × 2⁴, (2³)² and 2³ ÷ 2⁴.

Both papers can include these questions. On Paper 1 you must do them without a calculator, so you need the roots and powers of small numbers at your fingertips: squares to 15², cubes to 10³ and the powers of 2, 3 and 5.

## Positive indices

The index (power) tells you how many times to use the base as a factor.

```
2^5 = 2 x 2 x 2 x 2 x 2 = 32
5^3 = 125
10^4 = 10 000
```

## The rules of indices

For any non-zero base a and any indices m and n:

```
a^m x a^n = a^(m + n)       (same base, multiply: add the indices)
a^m ÷ a^n = a^(m - n)       (same base, divide: subtract the indices)
(a^m)^n   = a^(m x n)       (power of a power: multiply the indices)
```

These rules only work when the bases are the same. Expressions such as 2³ × 3² cannot be combined by adding indices.

**Worked example.** Work out 2⁻³ × 2⁴.

```
2^-3 x 2^4 = 2^(-3 + 4) = 2^1 = 2
```

**Worked example.** Work out (2³)².

```
(2^3)^2 = 2^(3 x 2) = 2^6 = 64
```

**Worked example.** Work out 2³ ÷ 2⁴.

```
2^3 ÷ 2^4 = 2^(3 - 4) = 2^-1 = 1/2
```

## The zero index

Any non-zero number to the power 0 equals 1.

```
5^0 = 1,   (-7)^0 = 1,   (3/4)^0 = 1
```

The reason: 5³ ÷ 5³ = 1, and the division rule gives 5^(3 - 3) = 5⁰. So 5⁰ = 1. The base zero is excluded because 0⁰ is not defined.

Watch the difference between 3 × 5⁰ = 3 × 1 = 3 and (3 × 5)⁰ = 15⁰ = 1.

## Negative indices

A negative index means "the reciprocal of the positive power".

```
a^-n = 1 / a^n
7^-2 = 1/49
4^-2 = 1/16
10^-3 = 1/1000 = 0.001
```

A negative index does **not** make the value negative. It makes the number small (when the base is greater than 1).

For a fraction, turn the fraction upside down and make the index positive.

```
(2/3)^-2 = (3/2)^2 = 9/4
(1/5)^-3 = 5^3 = 125
```

**Worked example.** Work out 2⁻³ + 2⁰ + 2³.

```
2^-3 = 1/8,   2^0 = 1,   2^3 = 8
1/8 + 1 + 8 = 9 1/8
```

## Fractional indices

A fractional index combines a root and a power. The **denominator** is the root and the **numerator** is the power.

```
a^(1/2) = √a          a^(1/3) = ∛a          a^(1/4) = fourth root of a
a^(m/n) = (n-th root of a)^m
```

The reason: a^(1/2) × a^(1/2) = a^1 = a, so a^(1/2) is the number which multiplied by itself gives a, which is the square root.

```
81^(1/2) = 9
16^(1/4) = 2
8^(2/3)  = (∛8)^2 = 2^2 = 4
```

Take the **root first**, then the power. That keeps the numbers small. For 8^(2/3), working out 8² = 64 and then the cube root is harder than the cube root of 8 followed by squaring.

### Negative fractional indices

Combine the two ideas: reciprocal, root, then power.

**Worked example.** Find the value of 27^(-2/3).

```
negative index: reciprocal   1 / 27^(2/3)
denominator 3:  cube root    ∛27 = 3
numerator 2:    square it    3^2 = 9
27^(-2/3) = 1/9
```

**Worked example.** Find the value of (1/4)^(-3/2).

```
negative index: turn over    4^(3/2)
denominator 2:  √4 = 2
numerator 3:    2^3 = 8
```

**Worked example.** Find the value of 125^(-1/3).

```
1 / ∛125 = 1/5
```

## Combining the rules

Many questions use several rules in one expression. Write every number as a power of one base, apply the rules to the indices, and then evaluate.

**Worked example.** Work out 3⁵ × 3⁻² ÷ 3⁴.

```
3^(5 + (-2) - 4) = 3^(-1) = 1/3
```

**Worked example.** Work out (2⁻³ × 16) ÷ 4.

```
16 = 2^4,   4 = 2^2
2^(-3 + 4 - 2) = 2^-1 = 1/2
```

**Worked example.** Work out 16^(3/4) - 9^(-1/2).

```
16^(3/4) = (fourth root of 16)^3 = 2^3 = 8
9^(-1/2) = 1 / √9 = 1/3
8 - 1/3 = 7 2/3
```

**Worked example.** Show that 25^(-1/2) × 10² = 20.

```
25^(-1/2) = 1/√25 = 1/5
10^2 = 100
1/5 x 100 = 20
```

## Why the rules work

Each rule comes from counting factors. For 2⁴ × 2⁵ you have four 2s and then five more, nine 2s in all, so the product is 2⁹. In 2⁶ ÷ 2² you cancel two of the six factors and have four left, giving 2⁴. In (2³)² you have two groups of three 2s, which is six 2s, giving 2⁶. Once you trust these three counting rules, the zero, negative and fractional indices follow by asking what index would keep the rules working.

- Zero: 5² ÷ 5² must be 5⁰, and it is also 25 ÷ 25 = 1.
- Negative: 5² ÷ 5⁴ must be 5⁻², and it is also 25 ÷ 625 = 1/25.
- Fractional: 9^(1/2) × 9^(1/2) must be 9¹ = 9, so 9^(1/2) is 3.

## Finding an unknown index

Sometimes the index is the unknown. Write both sides as powers of the same base, then equate the indices. Logarithms are not needed.

**Worked example.** Find n if 2ⁿ = 1/32.

```
1/32 = 1/2^5 = 2^-5
so n = -5
```

**Worked example.** Find n if 4ⁿ = 8.

```
4 = 2^2, so 4^n = 2^(2n)
8 = 2^3
2n = 3, so n = 3/2
```

**Worked example.** Find n if 9ⁿ = 27.

```
9 = 3^2 and 27 = 3^3
3^(2n) = 3^3, so 2n = 3 and n = 3/2
```

**Worked example.** Write 0.04 as a power of 5.

```
0.04 = 4/100 = 1/25 = 5^-2
```

Choose the smallest base that both numbers share: 2 for 4, 8, 16 and 32; 3 for 9, 27 and 81; 5 for 25 and 125.

## More values to check yourself

```
(1/8)^(-2/3) = 8^(2/3) = 4
49^(-1/2) x 7^2 = 1/7 x 49 = 7
(2^-2)^-3 = 2^6 = 64
1000^(2/3) = (∛1000)^2 = 10^2 = 100
81^(-1/2) = 1/9
(27/8)^(-1/3) = (8/27)^(1/3) = 2/3
```

## Powers of ten and the link to decimals

Powers of 10 give place value: 10³ = 1000, 10² = 100, 10¹ = 10, 10⁰ = 1, 10⁻¹ = 0.1, 10⁻² = 0.01, 10⁻³ = 0.001. Negative indices on 10 give decimals with that many places. This idea is used in the next subtopic on standard form.

## Using a calculator (Paper 2)

Use the power key and enter fractional indices in brackets, such as 12^(3/2). Without the brackets, the calculator reads 12^3 ÷ 2.

```
12^(3/2) = 41.569...  = 41.6 (3 significant figures)
```

For an exact answer, do the work by hand first. For example, 9^(3/2) = (√9)³ = 27 exactly.

## Exam technique

- Show the root and the power as separate steps. A correct answer with no working can score fully, but one slip in a mental calculation scores nothing.
- Make the bases the same before applying the rules. Write 16 as 2⁴ or 8 as 2³.
- Decide the form of your answer: a fraction such as 1/9 is usually better than 0.1111...
- Check negative index answers: the result of a positive base to any power is positive.

## Common mistakes

- Treating a negative index as a negative number: 2⁻³ is 1/8, not -8.
- Multiplying the base by the index: 2³ is 8, not 6.
- Adding indices when the bases differ: 2³ × 3² is not 6⁵.
- Writing 5⁰ = 0 or 5⁰ = 5. It is 1.
- Using the power before the root and making the arithmetic harder.
- Forgetting to flip the fraction in (2/3)⁻².
- Subtracting indices in the wrong order in a division.

## Where this leads

The same rules apply in algebra, in standard form (powers of 10) and in compound interest and exponential growth. The next stage, [Indices II](/resources/cambridge-o-level-mathematics-4024-indices-ii/), uses these rules with letters and in equations.
