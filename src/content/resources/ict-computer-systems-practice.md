## Section A

**1.** Name the four main components of the CPU or of a computer system and state the role of each. **[4]**

**2.** Distinguish between an input device, an output device and a storage device, giving an example of each. **[3]**

## Section B

**3.** Explain the difference between primary and secondary storage, and explain why a computer needs both. **[5]**

**4.** A business is choosing between magnetic, optical and solid state storage for backing up 5 TB of data weekly.

**(a)** Recommend a medium and justify it with **two** reasons. **[4]**
**(b)** Explain why backups should also be stored off-site. **[2]**

**5.** Explain **four** threats to data security and describe **one** measure to counter each. **[12]**

**6.** Explain the difference between a wired and a wireless network, giving one advantage of each, and explain the role of a router. **[6]**

## Answers

**1.** The **control unit** — fetches, decodes and coordinates the execution of instructions [1]. The **arithmetic logic unit** — performs calculations and logical comparisons [1]. **Registers/cache** — very fast temporary storage for data being worked on immediately [1]. **Main memory (RAM)** — holds the programs and data currently in use [1]. (Also accept: input, process, storage, output as the four components of a system.)

**2. Input** — sends data into the system, e.g. a keyboard or scanner [1]. **Output** — presents processed data to the user, e.g. a monitor or printer [1]. **Storage** — retains data for later use, e.g. a hard disk [1].

**3. Primary storage** is **directly accessible by the processor** and holds what is in use now; it is **fast but small and mostly volatile** [1] [1]. **Secondary storage** is **not directly accessible by the CPU** and holds programs and files permanently; it is **much larger and non-volatile but far slower** [1] [1]. Both are needed because RAM is **too small and too expensive to hold everything and loses its contents when the power goes off**, while secondary storage is far too slow for the processor to work from directly [1].

**4. (a)** **Magnetic hard disks or tape** [1]. They offer the **lowest cost per terabyte**, which matters at 5 TB per week [1]; **capacity is ample and write speeds are adequate for an overnight backup**, and tape in particular has a long archival life [1]; optical discs would require an impractical number of discs and SSDs would be far more expensive per terabyte [1].
**(b)** If the backup is stored in the same building, a **fire, flood or theft would destroy the original data and the backup together** [1], so an off-site or cloud copy is essential for recovery from a site-wide disaster [1].

**5.** Any four, 3 marks each: **Malware (viruses, ransomware)** — programs that damage data or hold it to ransom [1] [1]; countered by **anti-malware software kept up to date, and regular offline backups** so encrypted data can be restored [1].
**Phishing** — fraudulent emails or sites that trick users into revealing credentials [1] [1]; countered by **staff training to recognise suspicious messages and by two-factor authentication**, so a stolen password alone is insufficient [1].
**Hacking / unauthorised access** — an outsider gains entry to the network [1] [1]; countered by a **firewall, strong password policy and access rights limiting each user to what they need** [1].
**Data interception** — data read while being transmitted [1] [1]; countered by **encryption**, so intercepted data is unreadable without the key [1].
**Accidental loss or hardware failure** [1] [1]; countered by a **regular, tested backup routine and RAID redundancy** [1].
**Insider misuse** [1] [1]; countered by **access levels, audit logs and physical security** [1].

**6.** A **wired network** connects devices by cable; a **wireless network** connects them by radio [1]. Wired advantage: **faster, more reliable and more secure**, since the signal cannot be intercepted from outside the building [1]. Wireless advantage: **devices can move freely and no cabling is needed**, so it is cheaper to install and more flexible [1].
A **router** connects the local network to another network, usually the internet [1]; it **examines the destination address of each data packet and forwards it along the best route** [1], and typically also provides the firewall, DHCP addressing and wireless access point functions [1].

## Where marks are usually lost

- Saying RAM is a type of secondary storage.
- Recommending a storage medium without justifying it against the stated requirement.
- Naming a security threat without a matching countermeasure.
- Confusing a router with a switch.
