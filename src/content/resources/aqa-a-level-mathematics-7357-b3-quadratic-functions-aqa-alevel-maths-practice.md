## Section A

**1.** Write x² − 10x + 31 in the form (x − p)² + q. Hence state the coordinates of the turning point of y = x² − 10x + 31 and the equation of its line of symmetry. **[3]**

**2.** Write 5 + 12x − 3x² in the form a − b(x − c)², where a, b and c are constants. Hence state the maximum value of 5 + 12x − 3x² and the value of x at which it occurs. **[4]**

**3.** The equation kx² + 4x + (k − 3) = 0, where k ≠ 0, has a repeated root. Find the possible values of k. **[4]**

**4.** For the curve y = −x² + 2x + 3, find the coordinates of the points where it meets the axes and of its turning point, and describe the shape of the graph. **[4]**

**5.** Solve 2x⁴ − 7x² − 4 = 0. **[3]**

**6.** Solve (x + 2)² − 5(x + 2) − 14 = 0. **[2]**

## Section B

**7.** f(x) = 2x² + 8x + c, where c is a constant.

**(a)** Write f(x) in the form a(x + p)² + q, where q is in terms of c. **[2]**

**(b)** The minimum value of f(x) is 3. Find c. **[1]**

**(c)** Find the set of values of c for which f(x) = 0 has two distinct real roots. **[2]**

**8.** Prove that the equation x² + (k + 1)x + k − 2 = 0 has two distinct real roots for every real value of k. **[4]**

**9.** Solve 4ˣ − 6 × 2ˣ + 8 = 0. **[4]**

**10.** In an invented model, the height h metres of a ball t seconds after it is thrown is h = 1.5 + 14t − 5t².

**(a)** Write h in the form A − B(t − C)². **[3]**

**(b)** State the maximum height and the time at which it occurs. **[1]**

**(c)** Find the time at which the ball reaches the ground, giving your answer to 3 significant figures. **[3]**

**11.** A parabola has its turning point at (3, −8) and passes through (5, 0).

**(a)** Find its equation in the form y = ax² + bx + c. **[3]**

**(b)** Write down the other point where it crosses the x-axis. **[1]**

**12.** The equation (p − 1)x² + 4x + (p + 2) = 0, where p ≠ 1, has no real roots. Find the set of possible values of p. **[5]**

## Answers

**1.** (x − 5)² − 25 + 31 [1] = (x − 5)² + 6, so p = 5 and q = 6 [1]. Turning point **(5, 6)**; line of symmetry **x = 5** [1].

**2.** −3(x² − 4x) + 5 [1] = −3[(x − 2)² − 4] + 5 [1] = 17 − 3(x − 2)², so **a = 17, b = 3, c = 2** [1]. Maximum value **17** when **x = 2** [1].

*Examiner insight:* the −3 multiplies the −4 inside the square bracket, giving +12. Losing that sign is the most common error with a negative leading coefficient.

**3.** Discriminant = 4² − 4k(k − 3) [1]. A repeated root needs this to equal 0 [1]: 16 − 4k² + 12k = 0, so k² − 3k − 4 = 0 [1]. (k − 4)(k + 1) = 0, so **k = 4 or k = −1** [1].

*Examiner insight:* check each value. k = 4 gives (2x + 1)² = 0 and k = −1 gives −(x − 2)² = 0, both repeated roots. The condition k ≠ 0 matters because k = 0 would make the equation linear.

**4.** y = 0: −(x² − 2x − 3) = −(x − 3)(x + 1) = 0, so **(−1, 0) and (3, 0)** [1]. x = 0 gives **(0, 3)** [1]. y = −(x − 1)² + 4, so the turning point is **(1, 4)**, a maximum [1]. The graph is an n-shaped parabola (negative x² coefficient), symmetric about x = 1 [1].

**5.** Let u = x²: 2u² − 7u − 4 = 0, so (2u + 1)(u − 4) = 0 [1]. u = 4 or u = −1/2 [1]. x² = −1/2 has no real solutions, so **x = 2 or x = −2** [1].

*Examiner insight:* the final mark needs the rejection of u = −1/2 with a reason, as well as both signs from x² = 4.

**6.** Let u = x + 2: u² − 5u − 14 = 0, so (u − 7)(u + 2) = 0 and u = 7 or −2 [1]. **x = 5 or x = −4** [1].

**7. (a)** 2(x² + 4x) + c = 2[(x + 2)² − 4] + c [1] = **2(x + 2)² + c − 8** [1].

**(b)** Minimum value is c − 8 = 3, so **c = 11** [1].

**(c)** Two distinct real roots need the minimum value below zero (or 64 − 8c > 0) [1]: c − 8 < 0, so **c < 8** [1].

*Examiner insight:* (c) links the completed square to the discriminant. An upward parabola with its vertex below the x-axis must cross it twice, and both routes give c < 8.

**8.** Discriminant = (k + 1)² − 4(1)(k − 2) [1] = k² + 2k + 1 − 4k + 8 = k² − 2k + 9 [1]. Completing the square: k² − 2k + 9 = (k − 1)² + 8 [1]. (k − 1)² ≥ 0, so the discriminant is at least 8 and is always positive; hence there are two distinct real roots for every real k [1].

*Examiner insight:* a proof needs the general argument, not a check of a few values of k. The concluding sentence is a marking point in its own right.

**9.** 4ˣ = (2ˣ)², so with u = 2ˣ [1] the equation is u² − 6u + 8 = 0 [1]. (u − 2)(u − 4) = 0, so u = 2 or u = 4, both positive [1]. 2ˣ = 2 gives **x = 1**; 2ˣ = 4 gives **x = 2** [1].

**10. (a)** h = −5(t² − 2.8t) + 1.5 [1] = −5[(t − 1.4)² − 1.96] + 1.5 [1] = **11.3 − 5(t − 1.4)²** [1].

**(b)** Maximum height **11.3 m** at **t = 1.4 s** [1].

**(c)** 0 = 11.3 − 5(t − 1.4)², so (t − 1.4)² = 2.26 [1]. t = 1.4 ± √2.26 [1]. The negative value (about −0.103) is before the throw, so **t = 2.90 s** (3 s.f.) [1].

*Examiner insight:* keep √2.26 unrounded until the end. In context, always say why a root is rejected.

**11. (a)** y = a(x − 3)² − 8 [1]. Using (5, 0): 0 = 4a − 8, so a = 2 [1]. y = 2(x − 3)² − 8 = **2x² − 12x + 10** [1].

**(b)** The curve is symmetric about x = 3, and (5, 0) is 2 units to the right, so the other crossing is **(1, 0)** [1].

**12.** No real roots: 4² − 4(p − 1)(p + 2) < 0 [1]. 16 − 4(p² + p − 2) < 0, so 24 − 4p − 4p² < 0 [1], which gives p² + p − 6 > 0 [1]. (p + 3)(p − 2) > 0 has critical values −3 and 2 [1]. So **p < −3 or p > 2** [1], which excludes p = 1 as required.

*Examiner insight:* dividing by −4 reverses the inequality. A sketch of y = p² + p − 6 shows the "outside the roots" region.

## Where marks are usually lost

- Not multiplying the constant inside the bracket by the leading coefficient when completing the square.
- Giving the turning point with the wrong sign: (x − 5)² + 6 has its vertex at (5, 6), not (−5, 6).
- Using > 0 when a question asks for equal roots, or = 0 when it asks for no real roots.
- Forgetting the ± when solving x² = 4 after a substitution.
- Keeping a negative value of x² or of 2ˣ.
- Rounding before the last step in a modelling question.
- Reversing an inequality incorrectly after dividing by a negative number.
