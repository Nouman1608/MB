This practice set covers section 2.10 of IB Diploma Programme Mathematics: Analysis and Approaches: solving equations analytically and graphically, with technology where no analytic method exists, including real-life models. It is for SL and HL. Questions are labelled "(calculator-free)" or "(calculator allowed)"; give exact answers where no calculator is allowed and 3 significant figures otherwise.

Learn the methods first in the [2.10 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-10/) and the [2.10 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-10-revision-notes/).

## Section A

**1.** (calculator-free) Solve e^(2x) − 7eˣ + 12 = 0. **[3]**

**2.** (calculator-free) Solve 2^(x + 1) = 40, giving your answer in terms of natural logarithms. **[2]**

**3.** (calculator-free) Solve log₃(x + 4) + log₃(x − 4) = 2. **[3]**

**4.** (calculator-free) Solve √(2x + 3) = x. **[3]**

**5.** (calculator allowed) Solve x³ + x − 5 = 0. **[2]**

**6.** (calculator allowed) Consider the equation 2ˣ = 3 − x.

**(a)** Explain why the equation has exactly one solution. **[1]**
**(b)** Find the solution and verify it exactly. **[1]**

## Section B

**7.** (calculator-free) Solve 4ˣ − 6 × 2ˣ + 8 = 0. **[4]**

**8.** (calculator allowed) Consider the equation e^(−x) = x² − 2.

**(a)** Explain why the equation cannot be solved analytically by the methods of this course. **[1]**
**(b)** Use technology to find all the solutions. **[2]**
**(c)** Use a graph to explain why there is no solution with x < 0. **[1]**

**9.** (calculator allowed) In an invented model, the temperature of a drink t minutes after it is poured is T = 25 + 60e^(−0.08t) °C.

**(a)** Find the temperature after 10 minutes. **[1]**
**(b)** Find, algebraically, the time at which the temperature is 50 °C. **[3]**
**(c)** A second drink has temperature 95 − 4t °C at time t. Find the time at which the two drinks have the same temperature. **[2]**

**10.** (calculator-free) Solve 3ˣ = 2^(x + 2), giving your answer in the form ln a / ln b where a and b are rational. **[4]**

**11.** (calculator-free)

**(a)** Solve ln(x + 1) − ln x = ln 3. **[3]**
**(b)** Solve 2 ln x = ln(5x − 6). **[3]**

**12.** (calculator allowed) In an invented comparison, account A holds 2000(1.035)ᵗ dollars and account B holds 2500 + 50t dollars after t years.

**(a)** Find, algebraically, the time at which account A reaches $3000. **[2]**
**(b)** Use technology to find the time at which the two accounts hold equal amounts. **[2]**

## Answers

**1.** u = eˣ: u² − 7u + 12 = 0 [1], so u = 3 or u = 4 [1]: **x = ln 3 or x = ln 4** [1]

**2.** 2^(x + 1) = 40 gives 2ˣ = 20 [1], so **x = ln 20 / ln 2** [1]

**3.** log₃((x + 4)(x − 4)) = 2, so x² − 16 = 9 [1]; x = ±5 [1]; x = −5 makes log₃(x − 4) undefined, so **x = 5** [1]

**4.** 2x + 3 = x², so x² − 2x − 3 = 0 and x = 3 or x = −1 [1]. Check: √9 = 3 ✓ [1]; √1 = 1 ≠ −1 ✗. So **x = 3** [1]
*Examiner insight:* Without a written check of x = −1, the final mark is lost even if the answer x = 3 is correct.

**5.** **x = 1.52** [2]

**6. (a)** 2ˣ is increasing and 3 − x is decreasing, so their graphs cross at most once, and they do cross [1]
**(b)** **x = 1**: 2¹ = 2 and 3 − 1 = 2 [1]

**7.** u = 2ˣ, so 4ˣ = u² [1]; u² − 6u + 8 = 0 gives (u − 2)(u − 4) = 0 [1]; 2ˣ = 2 gives **x = 1** [1]; 2ˣ = 4 gives **x = 2** [1]

**8. (a)** It mixes an exponential with a polynomial, so no rearrangement isolates x [1]
**(b)** Graph both sides [1]: the only solution is **x = 1.49** [1]
**(c)** The graph of y = e^(−x) − x² + 2 stays above the x-axis for all x < 0 (its value is 3 at x = 0 and the exponential term outgrows x² as x → −∞), so the graphs do not meet there [1]

**9. (a)** 25 + 60e^(−0.8) = **52.0 °C** [1]
**(b)** 60e^(−0.08t) = 25 [1]; e^(−0.08t) = 25/60, so −0.08t = ln(5/12) [1]; t = 12.5 ln(12/5) = **10.9 minutes** [1]
**(c)** Graph both models [1]: **t = 11.5 minutes** [1]

**10.** x ln 3 = (x + 2) ln 2 [1]; x ln 3 − x ln 2 = 2 ln 2 [1]; x(ln 3 − ln 2) = ln 4 [1]; **x = ln 4 / ln(3/2)** (≈ 3.42) [1]

**11. (a)** ln((x + 1)/x) = ln 3 [1]; (x + 1)/x = 3 [1]; **x = 1/2**, which makes both logarithms defined [1]
**(b)** ln x² = ln(5x − 6), so x² − 5x + 6 = 0 [1]; x = 2 or x = 3 [1]; both give x > 0 and 5x − 6 > 0, so **both are valid** [1]

**12. (a)** 1.035ᵗ = 1.5 [1], so t = ln 1.5 / ln 1.035 = **11.8 years** [1]
**(b)** Intersection of the two graphs [1]: **t = 13.4 years** [1]

## Where marks are usually lost

- False roots kept in log and square-root equations, as in questions 3 and 4.
- Rejected roots with no reason given.
- Decimals on calculator-free questions where a logarithmic form is required.
- A GDC answer with no indication of the equation graphed.
- Answers outside a model's domain not checked.
