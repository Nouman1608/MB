Condensed notes for syllabus section 6.3, Artificial intelligence: the meaning of AI, its three characteristics, and the two systems the syllabus limits you to, expert systems and machine learning.

## Four facts to start with

1. **AI** is a branch of computer science dealing with the simulation of intelligent behaviours by computers.
2. AI is described by data and rules, the ability to reason, and (it can include) the ability to learn and adapt.
3. An **expert system** has a knowledge base, a rule base, an inference engine and an interface.
4. **Machine learning** is when a program automatically adapts its own processes and/or data.

## Key terms

| Term | Definition |
|---|---|
| Artificial intelligence | Branch of computer science dealing with the simulation of intelligent behaviours by computers |
| Expert system | Program that uses an expert's knowledge and rules to give advice or decisions |
| Knowledge base | Database of facts about the subject |
| Rule base | Set of rules (IF ... THEN) used to reach conclusions |
| Inference engine | Part that reasons by applying the rules to the facts and the user's answers |
| Interface | Part the user uses to enter answers and see results |
| Machine learning | Program automatically adapts its own processes and/or data |
| Reasoning | Using data and rules to reach a conclusion |

## Three characteristics of AI

| Characteristic | Note |
|---|---|
| Collection of data and the rules for using it | Always present |
| Ability to reason | Always present |
| Ability to learn and adapt | Can be included; not every system has it |

## Expert system parts

| Part | Remember it as |
|---|---|
| Knowledge base | The facts |
| Rule base | The IF ... THEN rules |
| Inference engine | The reasoner that applies the rules |
| Interface | The screen for questions and answers |

Flow: user answers (interface) then inference engine searches knowledge base and applies rule base, then conclusion shown (interface).

## Machine learning in four steps

1. Give the program lots of data.
2. It finds patterns.
3. It checks its results and adjusts its processes or data.
4. It makes better decisions over time.

## Expert system versus machine learning

| | Expert system | Machine learning |
|---|---|---|
| Rules from | Human experts | The data |
| Changes by itself? | No | Yes |
| Example | Fault finder | Spam filter |

## Worked example: applying rules

Rules: (1) IF engine does not turn over AND lights are dim THEN battery is flat. (2) IF engine does not turn over AND lights are bright THEN starter motor is faulty. The user enters: engine does not turn over, lights are bright. The inference engine tests rule 1: lights are not dim, so it fails. Rule 2 matches. Conclusion: starter motor is faulty, shown through the interface.

## Where AI appears in everyday life

| Use | Characteristic shown |
|---|---|
| Voice assistant | Data and rules; reasoning to find an answer |
| Shopping recommendations | Learning from the user's choices |
| Medical diagnosis helper | Rules from experts; reasoning |
| Chess or video game opponent | Reasoning; may learn from play |

## Concerns about AI

- Jobs may be replaced.
- Decisions can be wrong or unfair if the data is poor.
- Personal data is collected and must be protected.
- Users may trust a system that is wrong.

## Describing operation: the sentence pattern

For an expert system: "The user answers questions through the **interface**. The **inference engine** searches the **knowledge base** and applies the **rule base** to the answers. The conclusion is displayed through the interface." For machine learning: "The program is given data, finds patterns, checks its results and adapts its own processes or data, so decisions improve."

## Exam traps

- **AI = human thinking.** It simulates intelligent behaviour.
- **Knowledge base and rule base swapped.** Facts versus rules.
- **Interface forgotten.**
- **All AI learns.** Not necessarily.
- **Machine learning = following orders.** It adapts itself.
- **Inference engine only "stores".** It reasons.

## Self-test

1. Define artificial intelligence.
2. State the three main characteristics of AI.
3. Name the four components of an expert system.
4. What is stored in the knowledge base?
5. What is the job of the inference engine?
6. What form do the rules in a rule base often take?
7. What is machine learning?
8. Give one example of machine learning.
9. Give one advantage of an expert system.
10. Give one limitation of an expert system.

**Answers**

1. A branch of computer science dealing with the simulation of intelligent behaviours by computers.
2. Collection of data and the rules for using it; the ability to reason; it can include the ability to learn and adapt.
3. Knowledge base, rule base, inference engine, interface.
4. Facts and knowledge about the subject, collected from experts.
5. To reason: it searches the knowledge base and applies the rules to reach a conclusion.
6. IF ... THEN statements.
7. When a program automatically adapts its own processes and/or data.
8. Any one: spam filter, speech recognition, a game program that improves by playing.
9. Any one: available at any time, consistent, holds more knowledge than one person, non-experts can use it.
10. Any one: only as good as its knowledge and rules, cannot use common sense, expensive to build, needs updating.
