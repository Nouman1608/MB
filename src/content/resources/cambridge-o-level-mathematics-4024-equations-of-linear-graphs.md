This guide covers subtopic **3.5 Equations of linear graphs** in Topic 3, Coordinate geometry, of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027 series. The syllabus asks you to interpret and obtain the equation of a straight-line graph. The [Coordinate geometry revision notes](/resources/o-level-mathematics-coordinate-geometry-revision-notes/) summarise the whole topic. This page shows how to read the gradient and intercept from an equation, how to write an equation from a graph, from a gradient and a point, or from two points, and how to move between the different forms.

Companion pages: the [Equations of linear graphs revision notes](/resources/cambridge-o-level-mathematics-4024-equations-of-linear-graphs-revision-notes/) and the [Equations of linear graphs practice questions](/resources/cambridge-o-level-mathematics-4024-equations-of-linear-graphs-practice/).

## What the syllabus asks

The syllabus asks you to interpret and obtain the equation of a straight-line graph. Questions may:

- use and request lines in different forms: ax + by = c, y = mx + c and x = k
- involve finding the equation when the graph is given
- ask for the gradient or y-intercept of a graph from an equation.

It also states that candidates are expected to give equations of a line in a **fully simplified form**. This means no unnecessary brackets, fractions cleared where sensible, and common factors cancelled.

## The equation y = mx + c

Any straight line that is not vertical can be written as

```
y = mx + c
```

- **m** is the gradient (how much y changes for each 1 unit increase in x).
- **c** is the y-intercept (the value of y when x = 0, so the line crosses the y-axis at (0, c)).

For y = 5 - 2x, written as y = -2x + 5, the gradient is -2 and the y-intercept is 5.

For a line through the origin, c = 0 and the equation is y = mx. For a horizontal line, m = 0 and the equation is y = c. A vertical line cannot be written as y = mx + c, because its gradient is undefined. Its equation is x = k.

## Special lines

| Line | Equation | Gradient |
|---|---|---|
| horizontal through (0, 5) | y = 5 | 0 |
| vertical through (-3, 0) | x = -3 | undefined |
| x-axis | y = 0 | 0 |
| y-axis | x = 0 | undefined |
| through the origin with gradient 2 | y = 2x | 2 |

## Reading the gradient and y-intercept from an equation

If the equation is already y = mx + c, read off m and c. If it is in another form, rearrange to make y the subject.

**Worked example.** Find the gradient and y-intercept of the line 3x - 4y = 24.

```
3x - 4y = 24
-4y = -3x + 24
y = (3/4)x - 6
gradient = 3/4,  y-intercept = -6
```

**Worked example.** Find the gradient and y-intercept of 4x + 5y = 20.

```
5y = -4x + 20
y = -(4/5)x + 4
gradient = -4/5,  y-intercept = 4
```

When you divide by a negative number or a number that goes into every term, divide every term. The most frequent mistake is to divide only the first term.

**Worked example.** Write 2y = 6x - 4 in the form y = mx + c.

```
y = 3x - 2
```

## Finding the equation from a graph

1. Read the y-intercept c from where the line crosses the y-axis.
2. Find the gradient m using two clear points on the line.
3. Write y = mx + c.

**Worked example.** A line crosses the y-axis at (0, 3) and passes through (2, 7). Find its equation.

```
c = 3
gradient = (7 - 3) ÷ (2 - 0) = 4 ÷ 2 = 2
equation: y = 2x + 3
```

Check by substituting the second point: 2(2) + 3 = 7. ✓

If the line does not cross at a clear grid point on the y-axis, use two points to find m, then substitute one point to find c.

## Finding the equation from a gradient and a point

Substitute the gradient m and the coordinates of the point into y = mx + c, and solve for c.

**Worked example.** Find the equation of the line with gradient -3 that passes through (2, -1).

```
y = -3x + c
-1 = -3(2) + c
-1 = -6 + c
c = 5
equation: y = -3x + 5
```

There is another route that uses the point directly: y - y₁ = m(x - x₁). Here that gives y - (-1) = -3(x - 2), so y + 1 = -3x + 6 and y = -3x + 5. Both methods give the same answer. Use the one that you find easier to remember.

## Finding the equation from two points

First find the gradient, then substitute one point to find c.

**Worked example.** Find the equation of the line through (-1, 5) and (3, -3).

```
gradient = (-3 - 5) ÷ (3 - (-1)) = -8 ÷ 4 = -2
y = -2x + c
use (-1, 5):  5 = -2(-1) + c = 2 + c,  so c = 3
equation: y = -2x + 3
```

Check with the other point: -2(3) + 3 = -3. ✓

**Worked example.** Find the equation of the line through (0, -2) and (4, 6), and where it crosses the x-axis.

```
gradient = (6 - (-2)) ÷ (4 - 0) = 8 ÷ 4 = 2
the y-intercept is -2 (the point (0, -2))
equation: y = 2x - 2
x-axis crossing: y = 0 gives 2x = 2, x = 1, so the point is (1, 0)
```

## Different forms of the same line

The line y = (3/2)x - 3 can be written without fractions. Multiply every term by 2:

```
2y = 3x - 6
3x - 2y = 6
```

This is the form ax + by = c, with integer coefficients. The syllabus lets questions ask for the equation in either form, so be ready to convert.

To go the other way, from ax + by = c to y = mx + c, isolate y as shown above. Take care with the signs.

| Form | Example | When it is useful |
|---|---|---|
| y = mx + c | y = 2x + 3 | reading gradient and intercept |
| ax + by = c | 3x - 2y = 6 | integer coefficients; finding intercepts |
| x = k | x = -2 | vertical lines |
| y = k | y = 5 | horizontal lines |

## Checking a point on a line

Substitute the coordinates into the equation. For 3x - 2y = 6, the point (4, 3) gives 12 - 6 = 6, so it is on the line. The point (6, -3) gives 18 + 6 = 24, so it is not.

## Intercepts from an equation

For y = -2x + 3:

```
x = 0:  y = 3        crosses the y-axis at (0, 3)
y = 0:  0 = -2x + 3, x = 1.5     crosses the x-axis at (1.5, 0)
```

## Equations from real situations

Some problems give a linear relationship in words. The gradient is the rate of change and the y-intercept is the starting value (a fixed charge).

**Worked example.** A taxi charges a fixed $3 plus $2.50 for each kilometre. Write the cost C dollars in terms of the distance d km, and find the cost of an 8 km journey.

```
C = 2.5d + 3
gradient 2.5 means $2.50 per km;  intercept 3 is the fixed charge
d = 8:  C = 2.5 x 8 + 3 = $23
```

## Relationships with other lines

Lines with the same gradient are parallel. Lines whose gradients multiply to give -1 are perpendicular. These ideas are developed in the next two subtopics, including a [perpendicular lines study guide](/resources/cambridge-o-level-mathematics-4024-perpendicular-lines/).

## Exam technique

- Write y = mx + c first, then find m and c in separate steps.
- Check your equation with a second point from the line.
- Give the final equation in the form requested. If no form is asked for, y = mx + c is fine, with fractions in simplest form.
- Put the equation of a horizontal or vertical line in the form y = k or x = k.
- Do not use a bare number as an equation: "y = 2x + 3", not "2x + 3".

## Common mistakes

- Swapping m and c.
- Giving the gradient of 3x - 4y = 24 as 3 or -4 instead of 3/4.
- Dividing only the first term by a coefficient when rearranging.
- Forgetting the sign when dividing by a negative number.
- Using the wrong change order in the gradient.
- Writing a vertical line as y = a number.
- Leaving a fraction unsimplified or an equation not fully simplified.

## Where this leads

Equations of lines lead to parallel and perpendicular lines and the perpendicular bisector. They also give the foundation for simultaneous equations solved by graphs, and for linear programming style inequalities on a grid.
