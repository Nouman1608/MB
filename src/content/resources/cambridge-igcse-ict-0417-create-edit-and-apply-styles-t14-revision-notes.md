These notes condense the "Create, edit and apply styles" skill in Topic 14 of Cambridge IGCSE ICT 0417. For full explanations and a worked style specification, read the [styles study guide](/resources/cambridge-igcse-ict-0417-create-edit-and-apply-styles-t14/), then try the [styles practice questions](/resources/cambridge-igcse-ict-0417-create-edit-and-apply-styles-t14-practice/).

## The four actions

- **Create**: new named style with its settings.
- **Modify**: change the style's settings; all text with that style follows.
- **Update**: copy the formatting of selected text into the style; all text with that style follows.
- **Apply**: give text the style.

**Modify vs update:** modify goes style to text; update goes text to style. Updating from a faulty example spreads the fault.

**Consistency:** one set of instructions formats every paragraph with that style, so they cannot differ.

## Font

| Setting | Key facts |
|---|---|
| Face | The named typeface, such as Arial or Times New Roman |
| Type: serif | Small strokes at letter ends; Times New Roman, Georgia; long printed text |
| Type: sans-serif | No strokes; Arial, Calibri, Verdana; headings, screens, young readers |
| Point size | 72 pt = 1 inch; body usually 10 to 12 pt |
| Colour | Use the exact colour named, the same in every style that asks for it |

## Alignment and enhancement

| Alignment | Edges |
|---|---|
| Left | Straight left, ragged right |
| Right | Straight right, ragged left |
| Centre | Each line centred between margins |
| Fully justified | Both edges straight; word spaces stretched |

**Enhancements:** bold, underline, italic (can combine).

## Spacing

| Setting | Controls | Unit |
|---|---|---|
| Spacing before | Gap above a paragraph | Points |
| Spacing after | Gap below a paragraph | Points |
| Line spacing | Gap between lines within a paragraph | Single, 1.5, double, or exact points |

Use spacing settings, not extra Enter presses: exact, consistent and part of the style.

## Bullets

| Setting | Meaning |
|---|---|
| Shape | The bullet symbol: dot, square, arrow, tick |
| Alignment | Position of the bullet from the margin |
| Line spacing | Spacing between the lines of list items |
| Indent | Where the item text starts; a hanging indent lines wrapped lines up with the text |

## Quick example

*Spec:* "*Notes-List*: round bullets at 0.5 cm, text indented at 1.25 cm, 1.15 line spacing, 4 pt after."

- Shape: round dot. Alignment: 0.5 cm from the margin.
- Indent: text and wrapped lines start at 1.25 cm (hanging indent).
- Line spacing 1.15 inside each item; 4 pt gap after each item.

## Specification checklist

Name, face or type, size, colour, alignment, enhancement, spacing before, spacing after, line spacing, bullet shape, bullet alignment, text indent. Tick each off.

## Key terms

| Term | Meaning |
|---|---|
| Style | A named, saved set of formatting applied in one step |
| Modify a style | Change a style's settings directly |
| Update a style | Make a style match the formatting of selected text |
| Serif | Font type with small strokes at the ends of letters |
| Sans-serif | Font type without those strokes |
| Point | Unit of font size and spacing; 72 points = 1 inch |
| Fully justified | Text aligned to both margins |
| Hanging indent | First line starts further left than the following lines |

## Exam traps

- Style names must match the instruction **exactly**.
- "A serif font" allows any serif face, but keep it **the same** throughout.
- Line spacing is **within** a paragraph; paragraph spacing is **between** paragraphs.
- Do not press Enter twice to make space.
- Updating a style from text with an unwanted setting spreads the error.
- Hand formatting on top of a style does **not** change when the style is modified.
- Bullet **alignment** and text **indent** are separate settings.

## Self-test

1. List the four actions on styles named in the syllabus.
2. State the difference between modifying and updating a style.
3. How does a style ensure consistency?
4. Give one example each of a serif and a sans-serif font face.
5. Why is a sans-serif font often chosen for on-screen headings?
6. How many points make one inch?
7. Describe fully justified text.
8. Name the three text enhancements in the syllabus.
9. What is the difference between spacing after and line spacing?
10. Why is spacing after better than pressing Enter for a gap?
11. Name the four bullet settings in the syllabus.
12. A list's second lines start under the bullet. Which setting needs changing?

## Self-test answers

1. Create, modify, update, apply.
2. Modifying changes the style's settings directly; updating copies the formatting of selected text into the style.
3. Every paragraph with the style takes its formatting from one set of instructions, so they all match.
4. Serif: Times New Roman or Georgia. Sans-serif: Arial, Calibri or Verdana.
5. Plain letter shapes are clear on screen and at a distance.
6. 72.
7. Text aligned to both the left and right margins, with word spacing stretched.
8. Bold, underline, italic.
9. Spacing after is the gap below a paragraph; line spacing is the gap between lines inside it.
10. It is exact, consistent and part of the style, so it changes everywhere if the style is modified.
11. Shape, alignment, line spacing, indent.
12. The indent (set a hanging indent so wrapped lines align with the text).
