This guide covers subtopic **1.5 Ordering** in Topic 1, Number, of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027 series. Ordering means arranging numbers or quantities by size and describing the comparison with the right symbol. The [Number revision notes](/resources/o-level-mathematics-number-revision-notes/) give a brief summary of the topic. This page shows how to compare numbers written in different forms, how to read and write inequality statements, and how to avoid the usual slips with negative numbers.

Companion pages: the [Ordering revision notes](/resources/cambridge-o-level-mathematics-4024-ordering-revision-notes/) and the [Ordering practice questions](/resources/cambridge-o-level-mathematics-4024-ordering-practice/).

## What the syllabus asks

The syllabus asks you to **order quantities by magnitude** and to show that you are familiar with the symbols =, ≠, >, <, ⩾ and ⩽. The word magnitude means size. Ordering questions often mix forms (fractions, decimals, percentages), include negative numbers, or use powers and roots. The skill also underpins later work on inequalities and bounds.

## The symbols

| Symbol | Meaning | Example |
|---|---|---|
| = | is equal to | 0.5 = 1/2 |
| ≠ | is not equal to | 0.67 ≠ 2/3 |
| > | is greater than | 8 > 3 |
| < | is less than | -5 < -2 |
| ⩾ | is greater than or equal to | x ⩾ 4 |
| ⩽ | is less than or equal to | x ⩽ 9 |

The open end of the symbol points at the larger quantity, and the point faces the smaller one. A statement can be read from either end: 3 < 8 and 8 > 3 say the same thing.

The symbols ⩾ and ⩽ include the boundary value. If x ⩾ 4, then x can equal 4. If x > 4, it cannot.

## Ordering whole numbers and integers

Positive numbers get bigger as they move to the right on a number line. Negative numbers get **smaller** as they get further from zero.

```
-9 < -4 < -1 < 0 < 3 < 8
```

The negative number with the larger digit is the smaller number: -9 is less than -4. A useful picture is temperature or a lift below ground level. The number -9 °C is colder than -4 °C.

**Worked example.** Put these temperatures in order, coldest first: -4 °C, 7 °C, -11 °C, 0 °C, -8 °C.

```
-11, -8, -4, 0, 7
```

The difference between the hottest and the coldest is 7 - (-11) = 18 °C. Subtracting a negative gives an addition.

## Ordering decimals

Compare digits from the left, one place at a time. Add zeros if that helps you line up the places.

```
0.45  and  0.405  and  0.5
write with 3 decimal places:  0.450,  0.405,  0.500
ascending:  0.405 < 0.45 < 0.5
```

A longer decimal is not necessarily bigger. The number 0.5 is greater than 0.405 even though 0.405 has more digits.

For negative decimals, the comparison reverses: -0.03 is greater than -0.3, because -0.03 is closer to zero.

## Ordering fractions

There are two reliable methods.

**Method 1: common denominator.** Write each fraction with the same denominator, then compare numerators.

**Worked example.** Which is larger, 4/7 or 7/12?

```
common denominator: 7 x 12 = 84
4/7  = 48/84
7/12 = 49/84
49 > 48, so 7/12 is larger
```

**Method 2: convert to decimals.** Divide the numerator by the denominator. This is quick on Paper 2 and also works well if the fractions have denominators such as 2, 4, 5, 8 or 10.

```
4/7  = 0.5714...
7/12 = 0.5833...
```

When fractions share a numerator, the one with the smaller denominator is larger. For example, 3/5 > 3/8, because fifths are bigger than eighths.

## Mixed forms: fractions, decimals and percentages

Convert everything to one form. Decimals are usually the easiest choice.

**Worked example.** Write 3/5, 0.58, 61% and 5/9 in order of size, smallest first.

```
3/5 = 0.6
0.58
61% = 0.61
5/9 = 0.5555...

smallest first:  5/9,  0.58,  3/5,  61%
```

Notice that 5/9 comes first because 0.5555... is less than 0.58. Check by comparing the first two decimal places before the third.

## Ordering negative fractions and decimals

**Worked example.** Write -3, 0.5, -1.2, -1/2 and 2/5 in order, smallest first.

```
decimals:  -3,  0.5,  -1.2,  -0.5,  0.4
smallest first:  -3,  -1.2,  -1/2,  2/5,  0.5
```

Start by separating negatives from positives. Every negative number is less than every positive number. Then order the negatives by distance from zero (furthest first), and the positives by size.

## Ordering powers and roots

Calculate or estimate each value in a common form.

**Worked example.** Put 2⁻³, 0.1, 1/9 and 11% in order, largest first.

```
2^-3 = 1/8 = 0.125
0.1
1/9  = 0.1111...
11%  = 0.11

largest first:  2^-3,  1/9,  11%,  0.1
```

**Worked example.** Write √30, 5.4 and ∛150 in order of size, smallest first.

```
5.4^2 = 29.16, which is less than 30, so √30 > 5.4
5.4^3 = 157.464, which is more than 150, so ∛150 < 5.4

smallest first:  ∛150,  5.4,  √30
```

Squaring or cubing the decimal and comparing with the number under the root avoids having to find the root itself, which is helpful on Paper 1. A calculator confirms this: ∛150 = 5.313 and √30 = 5.477.

## Ordering numbers in standard form

Compare the powers of 10 first. A larger power means a larger number, as long as each value is in standard form. If the powers are equal, compare the numbers in front.

```
6.1 x 10^4,  9.8 x 10^3,  5.9 x 10^4
power 4:  6.1 and 5.9      power 3:  9.8
ascending:  9.8 x 10^3 < 5.9 x 10^4 < 6.1 x 10^4
```

## Writing and reading inequalities

An inequality describes a range of values. To list the integers that satisfy it, check each end carefully.

**Worked example.** List the integers x such that -3 < x ⩽ 2.

```
-3 < x excludes -3
x ⩽ 2 includes 2
x = -2, -1, 0, 1, 2
```

**Worked example.** Write an inequality for "n is at least 5 but less than 12".

```
"at least 5" means 5 or more:   n ⩾ 5
"less than 12":                 n < 12
combined:                       5 ⩽ n < 12
```

Useful phrases: "at least" means ⩾; "at most" means ⩽; "more than" means >; "fewer than" means <; "no more than" means ⩽; "exceeds" means >.

### Number line pictures

On a number line, a **filled circle** shows that the end value is included (⩽ or ⩾). An **open circle** shows that it is not (< or >). A line between the circles shows all the values in between. This notation returns in the work on inequalities in algebra.

## Equal or not equal?

Sometimes you need to decide between = and ≠. Convert both sides to the same form and check.

```
0.75 = 3/4            equal
2/3 ≠ 0.67            0.666... is not the same as 0.67
0.7 recurring ≠ 7/10  0.777... is not 0.7
```

Rounded decimals are approximations, so they are not equal to the exact fractions they come from.

## Comparing quantities in context

Ordering is a key step when judging value for money. To compare prices, find the cost of one item or one unit.

**Worked example.** Which is the best buy: 3 pens for $4.80, 5 pens for $7.75 or 2 pens for $3.30?

```
4.80 ÷ 3 = $1.60
7.75 ÷ 5 = $1.55
3.30 ÷ 2 = $1.65
```

The 5-pen pack, at $1.55 each, is the cheapest per pen.

## Exam technique

- Convert to one form before comparing, and write the converted values down so that a marker can follow the work.
- Always check the direction asked for: "smallest first" (ascending) or "largest first" (descending).
- Give the final list in the original forms of the numbers, unless the question asks otherwise. For example, write 3/5 rather than 0.6.
- In "list the integers" questions, check each end value against the inequality sign.

## Common mistakes

- Putting -2 before -7 because 2 is less than 7. The value -7 is smaller.
- Thinking 0.45 is smaller than 0.405 because it has fewer digits.
- Ordering fractions by their denominators alone.
- Including an end value that a strict inequality excludes.
- Giving the order largest first when the question asks for smallest first.
- Treating a rounded decimal as equal to a recurring one.

## Where this leads

Ordering leads straight into algebraic inequalities, limits of accuracy, estimation and the interpretation of statistical data. The same comparison skills are used for the median, which needs data in order, and for judging which of several offers is the best value.
