These notes condense subtopic **1.7 Indices I** of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. Core (C1.7) covers positive, zero and negative integer indices and the rules of indices; Extended (E1.7) adds **fractional** indices, marked **Extended only** below. Everything here uses numbers; algebraic indices are Indices II. For full worked examples, use the [Indices I study guide](/resources/cambridge-igcse-mathematics-0580-indices-i/); to test yourself, use the [Indices I practice questions](/resources/cambridge-igcse-mathematics-0580-indices-i-practice/).

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Base | The number being multiplied | 6 in 6³ |
| Index (power, exponent) | How many times the base is a factor | 3 in 6³ |
| Zero index | Gives 1 for any non-zero base | 9⁰ = 1 |
| Negative index | Reciprocal of the positive power | 9⁻¹ = 1/9 |
| Fractional index (Extended) | Root, then power | 9^(1/2) = 3 |
| Reciprocal | 1 ÷ the number | reciprocal of 4/7 is 7/4 |

## The rules

```
aᵐ × aⁿ  = aᵐ⁺ⁿ          multiply  -> ADD indices
aᵐ ÷ aⁿ  = aᵐ⁻ⁿ          divide    -> SUBTRACT indices
(aᵐ)ⁿ    = aᵐⁿ           power of a power -> MULTIPLY indices
a⁰       = 1             (a ≠ 0)
a⁻ⁿ      = 1/aⁿ
(a/b)⁻ⁿ  = (b/a)ⁿ
a^(1/n)  = ⁿ√a           Extended only
a^(m/n)  = (ⁿ√a)ᵐ        Extended only
```

The first three rules need the **same base**.

| Power | Value | Power | Value |
|---|---|---|---|
| 2⁻¹ | 1/2 | 10⁻¹ | 0.1 |
| 2⁻² | 1/4 | 10⁻² | 0.01 |
| 2⁻³ | 1/8 | 10⁻³ | 0.001 |
| 3⁻² | 1/9 | 5⁻² | 1/25 |
| 4⁻¹ | 1/4 | (1/2)⁻³ | 8 |
| 2¹⁰ | 1024 | 3⁵ | 243 |

## Method in steps

**Simplify a product or quotient of powers**

```
1. Check every term has the same base (rewrite 4, 8, 9, 27... if needed).
2. Write the index arithmetic on its own line.
3. Evaluate the final single power.

4³ × 2⁻⁵ = (2²)³ × 2⁻⁵ = 2⁶ × 2⁻⁵ = 2¹ = 2
```

**Evaluate a negative power of a fraction**

```
(3/4)⁻² -> flip -> (4/3)² = 16/9 = 1 7/9
```

**Evaluate a fractional index (Extended only)**

```
1. Negative?  Remember "one over" for the end.
2. Denominator = root.  Numerator = power.
3. Root first, then power.

125^(−2/3): ∛125 = 5, 5² = 25, one over -> 1/25
(16/81)^(3/4): fourth root -> 2/3, cube -> 8/27
0.01^(1/2) = √0.01 = 0.1
```

## Must-know distinctions

| Looks similar | Actually |
|---|---|
| 3⁻² and −3² | 1/9 and −9 |
| (−3)² and −3² | 9 and −9 |
| 2³ × 2⁴ and (2³)⁴ | 2⁷ and 2¹² |
| 2³ + 2⁴ and 2⁷ | 24 and 128: no rule for adding |
| 16^(1/2) and 16 ÷ 2 | 4 and 8 |
| 8^(2/3) and 8²/3 | 4 and 64/3 |

## Exam traps

- A negative index gives a reciprocal, not a negative value.
- Anything (non-zero) to the power 0 is 1, not 0.
- Different bases do not combine by adding indices: 2³ × 3² = 8 × 9 = 72, not 6⁵.
- Subtracting a negative index: 3² ÷ 3⁻⁴ = 3⁶.
- On a calculator, bracket fractional indices: 64^(2/3).
- (Extended) Turn decimal indices into fractions: 0.5 = 1/2, 0.25 = 1/4, 1.5 = 3/2.

## Quick self-test

1. Find the value of 6⁰.
2. Find the value of 4⁻².
3. Find the value of (2/3)⁻¹.
4. Find the value of 10⁻⁴ as a decimal.
5. Find the value of 3⁴ × 3⁻⁶.
6. Find the value of 5⁷ ÷ 5⁹.
7. Find the value of (2⁻¹)⁻³.
8. Write 8 × 2⁻⁵ as a single power of 2.
9. Write 27 ÷ 9³ as a single power of 3.
10. (Extended) Find the value of 64^(1/3).
11. (Extended) Find the value of 9^(−3/2).
12. (Extended) Find the value of (8/125)^(2/3).

### Answers

1. 1
2. 1/16
3. 3/2 = 1½
4. 0.0001
5. 3⁻² = 1/9
6. 5⁻² = 1/25
7. 2³ = 8
8. 2³ × 2⁻⁵ = 2⁻²
9. 3³ ÷ 3⁶ = 3⁻³
10. 4
11. √9 = 3, 3³ = 27, one over: 1/27
12. ∛(8/125) = 2/5, squared: 4/25

## Where marks are usually lost

- Turning a negative index into a negative number.
- Adding indices for numbers with different bases.
- Index sign errors when dividing by a negative power.
- (Extended) Applying the power before the root, then being unable to finish without a calculator.

## Worked reminders

```
Core:  7⁻¹ × 7³ ÷ 7⁰ = 7^(−1 + 3 − 0) = 7² = 49
Core:  (10²)⁻² = 10⁻⁴ = 0.0001
Core:  25 × 5⁻⁴ = 5² × 5⁻⁴ = 5⁻² = 1/25
Core:  2⁻¹ + 2⁻² = 1/2 + 1/4 = 3/4        (no index rule for +)
Ext:   4^(1/2) × 27^(1/3) = 2 × 3 = 6
Ext:   (0.25)^(−1/2) = (1/4)^(−1/2) = 4^(1/2) = 2
```

The fourth line is a reminder that addition is done by evaluating each power, not by combining indices.

## Frequently asked questions

**Is 2⁻³ negative?**
No. 2⁻³ = 1/2³ = 1/8, which is positive. A negative index makes a reciprocal.

**Do I need to know fractional indices for Core?**
No. Fractional indices are in the Extended statement E1.7 only.
