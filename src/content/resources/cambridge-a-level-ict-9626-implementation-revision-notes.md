These notes condense **section 16.5 Implementation** of the Cambridge International AS & A Level Information Technology 9626 syllabus for examination in 2025, 2026 and 2027 (version 4). It is **A Level only** content, examined in Paper 3 (Advanced Theory).

Test yourself with the [practice questions](/resources/cambridge-a-level-ict-9626-implementation-practice/). The [Cambridge A Level IT hub](/boards/cambridge/a-level/ict/) has every topic and the [free diagnostics](/diagnostics/) show where to start.

## What implementation involves

- Install hardware and software.
- Transfer (convert) data from the old system.
- Train users.
- Choose a changeover method: a trade-off between **risk, cost, time and disruption**.

## The four methods

| Method | What happens |
|---|---|
| **Parallel running** | Old and new systems both run with real data for a time; results compared; old system then switched off |
| **Direct changeover** | Old system stops on a set date; new system starts straight away |
| **Phased implementation** | New system introduced one part (module) at a time |
| **Pilot implementation** | Whole new system introduced in one location or department first, then rolled out |

## Advantages and disadvantages

| Method | Advantages | Disadvantages |
|---|---|---|
| **Parallel** | Lowest risk; old system as fallback; results can be compared; time to learn | Expensive and slow; work done twice; extra staff load; needs capacity for both |
| **Direct** | Cheapest and quickest; no double work; everyone changes together | Highest risk; no fallback; faults affect everyone; no time to learn |
| **Phased** | Failure limited to one part; learn one part at a time; fix before next phase | Slow overall; old and new must work together; system must be divisible |
| **Pilot** | Faults limited to one site; pilot users help train others; real conditions | Slow to reach all sites; pilot staff under pressure; two systems in use; needs several sites |

## When is each suitable?

| Situation | Best method | Reason |
|---|---|---|
| Payroll or banking, where errors are serious | Parallel | Fallback and comparison |
| Old system failing, or a weekend closure possible, low risk | Direct | Quick and cheap |
| System has separate modules (enrolment, fees, results) | Phased | Reduces risk gradually |
| Chain of similar branches or schools | Pilot | Trial in one site first |

## Phased vs pilot (do not confuse)

- **Phased:** *part* of the system, everywhere.
- **Pilot:** *all* of the system, in one place.

## Worked example

A hospital has 5 wards and a new patient records system with 3 modules: admissions, medication, discharge.

- **Phased:** one module at a time across all wards. If each module takes 4 weeks to settle before the next starts, full changeover takes 3 x 4 = 12 weeks.
- **Pilot:** the whole system on one ward for 6 weeks, then the other 4 wards. A good choice because the wards are similar and a mistake on medication is serious, so errors should be limited to one ward.
- **Parallel:** records kept in both systems for a period. Safest, but nurses enter data twice on busy wards.
- **Direct:** hardest to justify here, because a failure would affect every ward.

## How to answer

1. Name the method.
2. Say how it would be carried out in *this* situation.
3. Give a point for this situation: an advantage or a disadvantage.
4. If asked to justify or evaluate, finish with a conclusion.

## Must-know distinctions

- **Parallel** (both run, comparing) vs **direct** (one switch, no overlap).
- **Phased** (parts) vs **pilot** (place).
- **Risk** (what if it fails) vs **cost** (staff and equipment) vs **time**.
- **Fallback** exists in parallel (old system); it does not in direct.

## Quick self-test

1. Which method has no fallback?
2. Which method involves doing all the work twice?
3. A shop chain installs a new till system in one shop first. Which method?
4. A system has 4 modules. Each is introduced in turn over 2-week periods, with the old system handling the rest. How long does the changeover take?
5. Give one disadvantage of phased implementation.
6. Which method is the most suitable for a system that calculates tax for a government department, and why?
7. Give one advantage of pilot implementation.
8. What is data transfer (file conversion) in implementation?
9. Why is training needed whichever method is used?
10. Which method is quickest and cheapest?

### Answers

1. Direct changeover.
2. Parallel running.
3. Pilot implementation.
4. 4 x 2 = 8 weeks (phased implementation).
5. Any one: it takes longer to finish; the old and new systems must work together; the system must be divisible into parts.
6. Parallel running: errors in tax calculation would be serious, and the old system can be used to check the results and as a fallback.
7. Any one: faults only affect one site; the pilot users can help train others; the system is tested in real conditions.
8. Moving the data from the old system into the format and storage of the new one, checking that none is lost or changed.
9. Users must be able to use the new system and know what to do when something goes wrong, whatever the method.
10. Direct changeover.

## Where marks are usually lost

- Describing phased as "one department at a time" (that is pilot).
- Listing advantages and disadvantages without referring to the scenario.
- Saying direct changeover is "good because it is cheap" with no mention of the risk.
- Saying parallel running is "slow" but not saying why (double work).
- Choosing pilot for a business with one site.
- No conclusion in a "justify" or "evaluate" question.

## Frequently asked questions

**Which implementation method is best?**
None is best in every case. Parallel running is safest but costly, direct changeover is cheapest but riskiest, phased suits systems in separate modules and pilot suits organisations with many similar sites.

**What is the difference between phased and pilot implementation?**
Phased introduces one part of the system at a time. Pilot introduces the whole system in one place first.
