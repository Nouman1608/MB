This guide covers subtopic **1.9 Estimation** in Topic 1, Number, of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027 series. Estimation includes rounding numbers, making quick approximate calculations to check an answer, and choosing a sensible level of accuracy for a real situation. The [Number revision notes](/resources/o-level-mathematics-number-revision-notes/) give a brief summary. This page covers each skill with worked examples and explains the common traps.

Companion pages: the [Estimation revision notes](/resources/cambridge-o-level-mathematics-4024-estimation-revision-notes/) and the [Estimation practice questions](/resources/cambridge-o-level-mathematics-4024-estimation-practice/).

## What the syllabus asks

The syllabus lists three outcomes:

1. Round values to a specified degree of accuracy, including decimal places and significant figures.
2. Make estimates for calculations involving numbers, quantities and measurements.
3. Round answers to a reasonable degree of accuracy in the context of a given problem.

Estimation is useful on both papers. On Paper 1 it is a method of calculation, since you cannot use a calculator. On Paper 2 it is a way of checking that your calculator answer is sensible. The assessment details also say that, unless a question states otherwise, non-exact answers on the calculator paper are given to 3 significant figures, and to 1 decimal place for angles in degrees.

## Rounding to the nearest ten, hundred or thousand

Find the digit in the place you are rounding to. Look at the digit immediately to its right. If that digit is 5 or more, round up. If it is 4 or less, round down. Replace the digits after the rounding place with zeros.

```
47 650 to the nearest thousand:
the thousands digit is 7; the next digit is 6, so round up
= 48 000

8 249 to the nearest hundred:
the hundreds digit is 2; the next digit is 4, so round down
= 8 200

365 to the nearest 10:
the tens digit is 6; the next digit is 5, so round up
= 370
```

## Decimal places

The number of decimal places counts digits after the decimal point. To round to a given number of decimal places, look at the next digit to the right.

```
6.0495 to 2 d.p.:   third decimal digit is 9, so round up the second: 6.05
3.14159 to 3 d.p.:  fourth digit is 5, so round up: 3.142
0.04567 to 3 d.p.:  fourth digit is 6, so round up: 0.046
```

Keep trailing zeros when they show the accuracy: 4.30 to 2 d.p. is not the same statement as 4.3 to 1 d.p.

## Significant figures

Significant figures (s.f.) count from the **first non-zero digit**. Zeros between non-zero digits count. Zeros at the start do not. Zeros at the end of a whole number may be only placeholders.

```
30 970 to 3 s.f.:
first significant digit 3; then 0, 9 → 3 s.f. are 3, 0, 9; next digit is 7, so round up
= 31 000    (the zeros keep the place value)

0.004052 to 2 s.f.:
leading zeros do not count; digits 4 and 0; next digit is 5, so round up
= 0.0041

7 349 to 2 s.f. = 7 300
7 349 to 1 s.f. = 7 000
```

Always use zeros to keep the size of a whole number. For example, 30 970 to 3 s.f. is 31 000, not 31.

## Estimating the value of a calculation

To estimate, round each number to **1 significant figure**, then do an easy calculation. Show the rounded values.

**Worked example.** Estimate the value of (58.7 × 3.12) ÷ 0.205.

```
58.7 → 60,   3.12 → 3,   0.205 → 0.2

estimate = (60 x 3) ÷ 0.2
         = 180 ÷ 0.2
         = 900
```

The exact value is 893.4, so the estimate is close.

**Worked example.** Estimate the value of √82.5 ÷ 0.48.

```
For a square root, choose the nearest square number: 82.5 → 81, so √81 = 9
0.48 → 0.5
estimate = 9 ÷ 0.5 = 18
```

A rule for the exam: estimates are usually done with 1 s.f., but when a root is involved, round to a perfect square or cube so that the root is exact.

**Worked example.** Estimate (19.6 × 0.51) ÷ 4.1.

```
19.6 → 20,   0.51 → 0.5,   4.1 → 4
20 x 0.5 = 10;   10 ÷ 4 = 2.5
```

The exact value is 2.438..., which confirms the estimate is sensible.

### Over or under?

Rounding a number up in a product makes the estimate larger, while rounding a number in the denominator up makes it smaller. You can sometimes say whether an estimate is above or below the exact answer.

**Worked example.** Estimate 4.3² + 2.7² using 1 s.f. and say whether the estimate is bigger or smaller than the exact value.

```
4.3 → 4,  2.7 → 3
4^2 + 3^2 = 16 + 9 = 25
exact = 18.49 + 7.29 = 25.78
```

The estimate is smaller than the exact value. The first term was reduced a lot by rounding down, and the second was increased by a smaller amount.

## Using estimates to check an answer

An estimate quickly shows whether an answer is in the right range.

**Worked example.** A student writes 38.2 × 49.7 = 18 985.4. Use an estimate to show that this is wrong.

```
38.2 → 40,  49.7 → 50
40 x 50 = 2000
```

The answer should be about 2000, so 18 985.4 is far too big. The correct value is 1898.54. The student has placed the decimal point wrongly.

## Sensible accuracy in context

Many real-life answers need to be rounded **sensibly**, which sometimes means rounding up or down regardless of the usual rules.

- **Money**: round to the nearest cent (2 decimal places), e.g. $237.50 ÷ 7 = $33.92857... = $33.93.
- **Things you cannot split**: if you need 4.73 buses, you need 5 buses. Round **up**, because 4 buses are not enough.
- **Things you cannot exceed**: if each bag holds 5 kg and you have 23 kg, you can fill 4 bags fully. Round **down**.
- **Measurements**: give answers to a similar accuracy as the data in the question. If lengths are given to 1 decimal place, an answer to 8 decimal places is not sensible.

**Worked example.** There are 213 students going on a trip. Each coach holds 45 students. How many coaches are needed?

```
213 ÷ 45 = 4.733...
4 coaches hold 180, which is not enough
answer: 5 coaches
```

## Rounding in a multi-step problem

Do not round values in the middle of a calculation. Keep full calculator values (or store them in the memory) and round only the final answer. If the problem has several parts, use the unrounded value from the earlier part in the later parts.

**Worked example (Paper 2).** Work out 58.7 × 3.12 ÷ 0.205 and give the answer correct to 3 significant figures.

```
calculator: 893.385...
answer: 893 (3 s.f.)
```

A common check is to compare with the estimate (900). They agree to the first digit.

## Rounding and standard form

Large numbers can be rounded and written in standard form: 7 805 621 000 to 2 s.f. is 7.8 × 10⁹. Small numbers work the same way: 0.00389462 to 3 s.f. is 0.00389 or 3.89 × 10⁻³. Decimal places can be misleading for small numbers, since 0.00389462 to 2 d.p. is 0.00, which loses all the information.

## Exam technique

- When asked for an estimate, always show the rounded numbers (usually to 1 s.f.). The method mark depends on them.
- Do not write down only the exact answer if the question says "estimate".
- Check the question to see whether it wants decimal places or significant figures.
- If you are told "to the nearest whole number", give an integer.
- For Paper 2 answers, give 3 s.f. unless told otherwise.

## Common mistakes

- Rounding 0.205 to 0.3 instead of 0.2, by looking at the wrong digit.
- Counting leading zeros as significant figures.
- Writing 31 instead of 31 000 when rounding 30 970 to 3 s.f.
- Rounding in the middle of a calculation, then rounding again at the end.
- Rounding down 4.73 buses to 4.
- Estimating by rounding the answer rather than the numbers.
- Forgetting that a root needs a nearby square number to make the estimate easy.

## Where this leads

Estimation prepares you for limits of accuracy, where rounded values produce upper and lower bounds, and for checking answers in every other topic, such as area, volume, speed and percentages.
