These notes condense **section 15.2 Project management software** (Topic 15 Project management) of the Cambridge International AS & A Level Information Technology 9626 syllabus for 2025, 2026 and 2027. A Level content, examined in Paper 3 Advanced Theory. Full explanations and worked examples are in the [project management software study guide](/resources/cambridge-a-level-ict-9626-project-management-software/); test yourself with the [project management software practice questions](/resources/cambridge-a-level-ict-9626-project-management-software-practice/).

## The three strands

1. **Types**: desktop, web-based, mobile; personal, single-user, collaborative.
2. **Uses**: planning, scheduling tasks, allocating resources, costings, communication, collaborative working and decisions.
3. **Advantages and disadvantages** of the types, and of using the software.

## Types: recall

| Type | Description | Advantage | Disadvantage |
|---|---|---|---|
| Desktop | Installed on a computer | Works offline; fast; full features | Install and update on each machine; sharing creates versions |
| Web-based | Runs in a browser; data on provider's servers | Any device; automatic updates; live sharing | Needs internet; subscription; data held by a third party |
| Mobile | App on phone or tablet | Update anywhere; alerts; camera | Small screen; fewer features; lost-device risk |
| Personal | One person's own tasks | Simple and cheap | No teams, dependencies or costs |
| Single-user | Full package for one manager | Advanced charts and budgets | Others cannot work on the plan at once |
| Collaborative | Many users on one plan | Shared, up-to-date; better communication | Cost per user; training; needs internet |

**Two ways to classify:** where it runs (desktop, web-based, mobile) and who uses it (personal, single-user, collaborative). A product can be in both groups, such as a web-based collaborative tool.

## Uses: recall

| Use | What the software does |
|---|---|
| Planning | Work breakdown structure, milestones, templates, store documents |
| Scheduling | Durations and dependencies give a Gantt chart and critical path; recalculates when tasks slip |
| Resource allocation | Assigns people and equipment; shows workloads; warns of over-allocation |
| Costings | Cost per resource; totals; planned against actual cost; forecasts |
| Communication | Messages, comments, notifications, shared calendars, status reports |
| Collaboration and decisions | Shared documents, task updates, recorded decisions, up-to-date reports |

## Advantages and disadvantages of using the software

| Advantages | Disadvantages |
|---|---|
| Saves time on calculations and updating | Cost of licences and training |
| All information in one place | Time to set up and enter data |
| Early warning of delays, clashes and overspending | Plan is only as good as the data |
| Automatic charts and reports | Staff may not use it properly |
| Supports teams in several places | Complex packages are hard to learn |
| Templates reuse earlier projects | Over-reliance instead of judgement |
| Audit trail of decisions | Security risk when stored online |

## Quick examples

**Rescheduling.** Task A (4 days) is followed by B (6 days) and C (5 days) in parallel, then D (3 days). Longest path A, B, D = 4 + 6 + 3 = **13 days**. If A takes 7 days, it becomes 7 + 6 + 3 = **16 days**.

**Over-allocation.** A person has 40 hours available and is given tasks of 20, 18 and 12 hours. Total = 50 hours. Utilisation = 50 ÷ 40 = **125%**.

**Subscription.** 12 users at £6 each per month: 12 × 6 = £72 a month; × 12 = **£864** a year.

## Choosing software

| Situation | Choice |
|---|---|
| Student planning revision | Personal |
| One consultant, detailed plans, no internet at client's site | Single-user desktop |
| Team in three countries | Collaborative web-based |
| Site manager walking round a building site | Mobile |
| Company concerned about keeping data on its own servers | Desktop, or a self-hosted collaborative system |

## How the software links to other topics

- **Gantt charts**, **PERT** and **critical path** (section 15.3) are drawn and calculated by the software.
- **Cloud computing** (section 14.4) explains the benefits and risks of web-based tools.
- **Network security** (section 14.9) applies to project data stored online.
- **Project stages** (section 15.1): the software supports planning, monitoring and reporting.

## Exam traps

- Saying the software "does the project for you".
- Mixing the two ways of classifying types.
- Vague advantages ("saves time") with no feature or reason.
- Ignoring the need for an internet connection for web-based and collaborative tools.
- Giving only advantages, or only disadvantages.
- Not linking the choice of software to the scenario.

## Self-test

1. Name three types of project management software based on where they run.
2. What is collaborative project management software?
3. Give one advantage of desktop software.
4. Give one disadvantage of mobile software.
5. How does the software support scheduling?
6. What is meant by over-allocation of resources?
7. How can the software help with costings?
8. Give two ways in which it supports communication.
9. Give two disadvantages of using project management software.
10. Which type suits a team across several countries?
11. Why should a manager not rely on the software alone?
12. A tool costs £5 per user per month for 20 users. What is the cost for a year?

### Answers

1. Desktop, web-based, mobile.
2. Software that lets many users work on the same project at the same time, updating tasks and sharing files.
3. Any one: works without the internet; fast; full features.
4. Any one: small screen; fewer features; risk if the device is lost.
5. Durations and dependencies produce a schedule and a Gantt chart, and dates are recalculated when a task changes.
6. A resource is given more work than the time it has available.
7. It adds up the costs of resources and tasks and compares planned with actual cost.
8. Any two: messaging, comments, notifications, shared calendars, status reports.
9. Any two: cost; training; time to set up; staff may resist; inaccurate data gives false results.
10. Collaborative web-based software.
11. The plan depends on the data entered and on decisions that need human judgement.
12. 20 × 5 = £100 a month; 100 × 12 = £1,200 a year.
