## Section A

**1.** Solve x⁴ − 13x² + 36 = 0. **[3]**

**2.** Solve 3x² + 4x − 2 = 0, giving your answers in the form (a ± √b)/c. **[3]**

**3.** Find the discriminant of 2x² − 5x + 4 and hence state the number of real roots of 2x² − 5x + 4 = 0. **[2]**

**4.** Solve x² − 2x − 15 > 0. **[3]**

**5.** Find the value of k for which x² + 6x + k = 0 has two equal roots. **[2]**

**6.** Solve x² − 4x − 1 = 0 by completing the square. **[2]**

## Section B

**7.** **(a)** Solve 3x² ≤ 5x + 2. **[3]**
**(b)** Hence write down the integers that satisfy the inequality. **[1]**

**8.** Consider kx² + (k + 3)x + 1 = 0, where k ≠ 0.

**(a)** Show that the discriminant is k² + 2k + 9. **[2]**
**(b)** Hence show that the equation has two distinct real roots for every non-zero k. **[2]**
**(c)** Describe what happens when k = 0. **[1]**

**9.** The line y = 2x + c and the curve y = x² − 4x + 7 are given.

**(a)** Find the value of c for which the line is a tangent to the curve. **[3]**
**(b)** Find the coordinates of the point of contact for this value of c. **[2]**
**(c)** Write down the values of c for which the line meets the curve at two points. **[1]**

**10.** Consider (m − 2)x² + 2mx + (m + 4) = 0.

**(a)** Show that the discriminant is 8(4 − m). **[2]**
**(b)** Find the values of m for which the equation has two distinct real roots. **[2]**
**(c)** Solve the equation when m = 2. **[1]**

**11.** Find the values of a for which ax² + 6x + a < 0 for all real x. **[4]**

**12.** In an invented design brief, a rectangular courtyard has length 4 m more than its width, w m.

**(a)** The area must be at least 60 m². Show that w² + 4w − 60 ≥ 0 and hence find the possible values of w. **[3]**
**(b)** The perimeter must be at most 44 m. Find the set of possible widths that satisfy both conditions. **[2]**

## Answers

**1.** Let u = x²: u² − 13u + 36 = 0 [1], so (u − 4)(u − 9) = 0 [1], giving **x = ±2, ±3** [1]

**2.** x = (−4 ± √(16 + 24))/6 [1] = (−4 ± 2√10)/6 [1] = **(−2 ± √10)/3** [1]

**3.** Δ = 25 − 32 = −7 [1] < 0, so there are **no real roots** [1]

**4.** (x − 5)(x + 3) > 0 [1]; critical values −3 and 5 [1]; **x < −3 or x > 5** [1]
*Examiner insight:* "−3 > x > 5" or "x < −3 and x > 5" describes no numbers and loses the final mark.

**5.** 36 − 4k = 0 [1], so **k = 9** [1]

**6.** (x − 2)² − 5 = 0 [1], so **x = 2 ± √5** [1]

**7. (a)** 3x² − 5x − 2 ≤ 0, so (3x + 1)(x − 2) ≤ 0 [1]; critical values −1/3 and 2 [1]; **−1/3 ≤ x ≤ 2** [1]
**(b)** **0, 1, 2** [1]

**8. (a)** Δ = (k + 3)² − 4(k)(1) [1] = k² + 6k + 9 − 4k = k² + 2k + 9 [1]
**(b)** k² + 2k + 9 = (k + 1)² + 8 [1]; (k + 1)² ≥ 0, so Δ ≥ 8 > 0 and there are always two distinct real roots [1]
**(c)** The equation becomes 3x + 1 = 0, which is linear with one root, x = −1/3 [1]

**9. (a)** x² − 4x + 7 = 2x + c, so x² − 6x + (7 − c) = 0 [1]. Δ = 36 − 4(7 − c) = 8 + 4c [1]; tangent when Δ = 0, so **c = −2** [1]
**(b)** x² − 6x + 9 = 0 gives x = 3 [1]; y = 2(3) − 2 = 4, so **(3, 4)** [1]
**(c)** **c > −2** [1]

**10. (a)** Δ = (2m)² − 4(m − 2)(m + 4) [1] = 4m² − 4(m² + 2m − 8) = 32 − 8m = 8(4 − m) [1]
**(b)** 8(4 − m) > 0 gives m < 4 [1]; the equation must be quadratic, so **m < 4 and m ≠ 2** [1]
**(c)** 4x + 6 = 0, so **x = −3/2** [1]

**11.** The parabola must open downwards: a < 0 [1]. It must not meet the axis: 36 − 4a² < 0 [1], so a² > 9, giving a < −3 or a > 3 [1]. Combined: **a < −3** [1]

**12. (a)** w(w + 4) ≥ 60 gives w² + 4w − 60 ≥ 0 [1]; (w + 10)(w − 6) ≥ 0 [1]; since w > 0, **w ≥ 6** [1]
**(b)** 2(w + w + 4) ≤ 44 gives w ≤ 10 [1]; so **6 ≤ w ≤ 10** [1]

## Where marks are usually lost

- "and" instead of "or" for two separate regions, as in question 4.
- Selecting the wrong region of a quadratic inequality.
- Leaving out a ≠ 0 or m ≠ 2 when the coefficient of x² contains a parameter.
- Using Δ < 0 alone in an "always negative" question, as in question 11.
- Keeping negative widths or lengths in a context.
