These notes cover the **pagination** statement in Topic 17 of Cambridge IGCSE ICT 0417: "the purpose of setting page, section and column breaks". The [pagination study guide](/resources/cambridge-igcse-ict-0417-pagination-t17/) explains each purpose in depth with a planned report; the [pagination practice questions](/resources/cambridge-igcse-ict-0417-pagination-t17-practice/) test it.

## Key terms

| Term | Meaning |
|---|---|
| Pagination | Dividing a document into pages |
| Automatic (soft) page break | Placed by the software when a page is full; moves as text changes |
| Manual (hard) page break | Inserted by the user; following text always starts a new page |
| Section | Part of a document with its own page settings |
| Next page section break | New section starting on a new page |
| Continuous section break | New section starting on the same page |
| Odd or even page section break | New section starting on the next odd- or even-numbered page |
| Column break | Following text starts at the top of the next column |

## Purpose of a page break

- Start a chapter, title page, contents or appendix on a new page.
- Move a heading that would be stranded at the bottom of a page.
- Keep a table, chart or image whole on one page.
- Keep the structure fixed when text is edited.
- Make printed output predictable.

## Purpose of a section break

Allows **page settings** to change part-way through a document:

- orientation (a landscape page in a portrait report);
- margins and paper size;
- number of columns;
- headers and footers (a different header for each chapter);
- page numbering (none on the cover, i, ii, iii for the contents, restart at 1).

| Need | Break |
|---|---|
| New layout on a new page | Next page |
| New layout on the same page | Continuous |
| Chapters starting on right-hand pages | Odd page |
| Start on the next even-numbered page | Even page |

## Purpose of a column break

- Start an article or heading at the top of a column.
- Keep a short item (list, contact box) together in one column.
- Control how columns are balanced.
- A continuous section break at the end of the last column can balance the columns.

## Decision rule

1. Only a new page needed, same settings? **Page break.**
2. A page setting changes (orientation, columns, margins, headers, numbering)? **Section break**, next page or continuous.
3. Move text to the next column? **Column break.**

## Why breaks, not blank lines

- Blank lines move when text above them changes.
- They may create blank pages or gaps at the top of pages.
- They cannot change orientation, columns or numbering.

## Worked example: matching breaks to needs

| Situation | Break | Reason |
|---|---|---|
| A newsletter's second article must start at the top of column 2 | Column break | Moves the article to the next column |
| A booklet's title page must have no page number | Next page section break after it | Numbering can be set differently in each section |
| Every chapter of a report must begin on a fresh page | Page break | Only the page changes |
| The last page has three columns but the rest has two | Section break before it | Column count changes |

## Exam traps

- "A section break starts a new page": only the **next page** type does, and that is not its purpose. Its purpose is to let **settings change**.
- A column break does not **create** columns.
- Explaining a break without referring to the **scenario** in the question.
- Forgetting **headers, footers and numbering** as reasons for section breaks.
- Suggesting blank lines or repeated Enter presses as a method.

## Self-test

1. Define pagination.
2. What is an automatic page break?
3. Give two purposes of a manual page break.
4. What does a section break allow that a page break does not?
5. Name the four kinds of section break.
6. A report needs page numbering to start at 1 on page 3. What break is needed and where?
7. When would a continuous section break be used?
8. Give two purposes of a column break.
9. Why might chapters of a printed book use odd page section breaks?
10. Why should a page break be used before a table rather than pressing Enter?
11. A heading is the last line on a page. Give one way to correct this.
12. A newsletter's last page has a full first column and an almost empty second column. How can the columns be balanced?

### Answers

1. Dividing a document into pages.
2. A break placed by the software when a page is full; it moves when text changes.
3. Any two: start a chapter or part on a new page; keep a table or chart whole; move a stranded heading to the next page; keep the structure fixed when editing.
4. It allows page settings such as orientation, margins, columns, headers and footers and page numbering to change part-way through a document.
5. Next page, continuous, odd page and even page.
6. A next page section break at the end of page 2, then restart numbering at 1 in the new section.
7. When the layout changes on the same page, for example a title in one column above text in two columns.
8. Any two: start an article at the top of a column; keep an item together; control the balance of columns.
9. So that each chapter starts on a right-hand page.
10. The break stays in place if text above is edited; blank lines move, so the table could split or a gap could appear.
11. Insert a page break before the heading (or set the heading to keep with the next paragraph).
12. Insert a continuous section break at the end of the text in the last column.
