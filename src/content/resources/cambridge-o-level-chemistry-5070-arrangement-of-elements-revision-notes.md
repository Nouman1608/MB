Condensed recall for Cambridge O Level Chemistry 5070 subtopic **8.1 Arrangement of elements**. For full explanations and worked examples, use the [Arrangement of elements study guide](/resources/cambridge-o-level-chemistry-5070-arrangement-of-elements/).

## The six outcomes in one line each

- Elements are arranged in **periods** (rows) and **groups** (columns) in order of **increasing proton number**.
- Across a period, character changes from **metallic** (left) to **non-metallic** (right).
- **Group number** fixes the **ion charge**: I → 1+, II → 2+, III → 3+, V → 3−, VI → 2−, VII → 1−.
- Same group = **same number of outer-shell electrons** = similar chemical properties.
- Position predicts properties: group gives the type of chemistry, period plus the across-period trend gives how metallic it is.
- Given data about a group, state the **direction** of the trend and predict the next value consistently.

## Key terms

| Term | Meaning |
|---|---|
| Proton number (atomic number) | Number of protons in the nucleus; the ordering basis of the table |
| Period | A horizontal row; period number = number of occupied electron shells |
| Group | A vertical column; for Groups I–VII, group number = number of outer-shell electrons |
| Electronic configuration | Arrangement of electrons in shells, written e.g. 2,8,5 |
| Metallic character | Tendency to lose electrons and form positive ions; conducts, forms basic oxides |
| Non-metallic character | Tendency to gain or share electrons; forms negative ions or covalent bonds, acidic oxides |
| Noble gas configuration | A full outer shell; the configuration atoms reach when they form ions |
| Trend | A steady change in a property down a group or across a period |

## Position ↔ configuration

| Configuration | Shells | Outer electrons | Period | Group | Element |
|---|---|---|---|---|---|
| 2,1 | 2 | 1 | 2 | I | Lithium |
| 2,6 | 2 | 6 | 2 | VI | Oxygen |
| 2,8,3 | 3 | 3 | 3 | III | Aluminium |
| 2,8,7 | 3 | 7 | 3 | VII | Chlorine |
| 2,8,8,1 | 4 | 1 | 4 | I | Potassium |
| 2,8,8,2 | 4 | 2 | 4 | II | Calcium |

Proton number = total electrons in the neutral atom, so the configuration also gives the proton number (2 + 8 + 8 + 2 = 20 for calcium).

## Period 3 at a glance

```
Na    Mg    Al  |  Si    P     S     Cl    Ar
metals          |  non-metals            noble gas
basic oxides  amphoteric  acidic oxides  no oxide
form + ions               form − ions (P, S, Cl)
```

Aluminium oxide is the amphoteric one; silicon is a non-metal with a giant covalent structure.

## Formulae from group numbers

Write each ion charge from its group, then balance the charges to zero.

| Groups combining | Charges | Formula type | Example |
|---|---|---|---|
| I + VII | 1+, 1− | AB | NaCl, KBr |
| II + VII | 2+, 1− | AB₂ | MgCl₂, CaBr₂ |
| I + VI | 1+, 2− | A₂B | Na₂O, K₂S |
| II + VI | 2+, 2− | AB | MgO, CaS |
| III + VII | 3+, 1− | AB₃ | AlCl₃ |
| III + VI | 3+, 2− | A₂B₃ | Al₂O₃ |

This works for unfamiliar elements in the same groups: barium (Group II) and iodine (Group VII) give BaI₂.

## Handling "given information" questions

1. Read the first and last values to find the direction (increases or decreases down the group).
2. Check the middle values follow it; note any irregularity rather than ignoring it.
3. State the trend in words.
4. Predict a value or behaviour for the missing element that continues the direction. A range ("above 184 °C") is safer than a calculated value from irregular data.
5. If asked to explain, link to the number of shells or the outer electrons.

## Exam traps

- "In order of relative atomic mass" loses the mark; argon (relative atomic mass 40) comes before potassium (relative atomic mass 39) because of proton number.
- Same group means same number of **outer** electrons, not the same total number of electrons or shells.
- Group IV and Group VIII elements do not form simple ions at this level.
- Hydrogen is not an alkali metal, even when drawn above Group I.
- Transition elements do not follow the group-number ion rule; they have variable oxidation numbers.
- "Similar" chemical properties is not "identical": the differences are the trends.
- When predicting, name a reference element in the same group and say it is in the same group.
- Helium is in Group VIII with only two outer electrons; its shell is still full.

## Self-test

1. State the basis on which elements are ordered in the Periodic Table.
2. An atom has the configuration 2,8,6. Give its period, group and name.
3. State the charge on an ion formed by an element in Group VI.
4. Explain why sodium and potassium have similar chemical properties.
5. Describe how metallic character changes across Period 3.
6. Write the formula of the compound formed between calcium and fluorine.
7. Explain why argon is placed before potassium although its relative atomic mass is higher.
8. Element Q is in Group I, Period 6. Predict whether its oxide is acidic or basic and give the formula of its chloride.
9. Which Period 3 element forms an amphoteric oxide?
10. An element forms a 3− ion. State its group and the number of electrons in its outer shell before reacting.
11. Name the element in Period 4 with two outer electrons.
12. Data show the melting points of four elements in a group fall steadily down the group. Predict the melting point of the next element relative to the last one given.

**Answers:** 1. Increasing proton (atomic) number. 2. Period 3, Group VI, sulfur. 3. 2−. 4. Both have one electron in the outer shell, and the outer electrons take part in reactions, so they react in the same way. 5. Changes from metals (Na, Mg, Al) on the left to non-metals (Si, P, S, Cl) on the right, ending with the noble gas argon. 6. CaF₂. 7. Elements are ordered by proton number; argon has 18 protons and potassium 19, so argon comes first whatever the masses. 8. Basic, because Group I elements are metals; formula QCl. 9. Aluminium. 10. Group V; five outer electrons. 11. Calcium. 12. Lower than the last value given, because the trend is a decrease down the group.
