Section 13.1 of Cambridge IGCSE ICT 0417 is the foundation of every practical task. You must be able to "enter and modify text and numbers with total accuracy", "use editing techniques to manipulate text and numbers including highlight, delete, move, cut, copy, paste, drag and drop", "place objects into the document from a variety of sources including text, image, screenshot, shapes, table, graph or chart, spreadsheet extract, database extract", and "wrap text around a table, chart or image including above, below, square and tight". The syllabus adds that in this section "document" means any of the applications in the practical sections, so these skills apply in word processing, presentations, spreadsheets, databases and web authoring alike.

The [Layout study guide](/resources/cambridge-igcse-ict-layout-study-guide/) covers page setup and paragraph formatting. This guide concentrates on accuracy, editing techniques, placing objects and wrapping. For quick recall use the [create or edit a document revision notes](/resources/cambridge-igcse-ict-0417-create-or-edit-a-document-revision-notes/), and test yourself with the [create or edit a document practice questions](/resources/cambridge-igcse-ict-0417-create-or-edit-a-document-practice/).

## Entering text and numbers with total accuracy

"Total accuracy" means the entered data matches the source exactly. A single error in a name, a figure or a web address can lose the mark for the whole item, and an error in a number entered into a spreadsheet or database can make every result based on it wrong.

### What counts as an error

- **Spelling**, including proper nouns such as names of people and places.
- **Case**: "Marlbridge" is not the same as "marlbridge".
- **Transposition**: two characters swapped, such as 1 584 typed as 1 548.
- **Missing or extra characters**, including punctuation and spaces.
- **Wrong symbols**: a hyphen where a dash was asked for, or a letter O in place of a zero.
- **Omitted words or lines** when copying from a source.

### How to check

1. Compare your text with the source **line by line**, not by reading for sense, because the brain fills in what it expects.
2. Turn on **show formatting marks** to see double spaces, extra paragraph marks and tab characters.
3. Check **numbers digit by digit**, and check that totals still add up where they should.
4. Remember that a **spell check cannot find** a correctly spelled wrong word ("form" for "from") or a mistyped number.

## Editing techniques

### Highlight (select)

Most editing starts by selecting the text or object. Useful methods include double-clicking to select a word, triple-clicking (or clicking in the left margin) to select a paragraph, holding Shift with the arrow keys to extend a selection precisely, and Select All to select the whole document. In a spreadsheet, select a cell or a range by dragging or by clicking the first cell and Shift-clicking the last.

### Delete

**Delete** removes the selected text or the character to the right of the cursor; **Backspace** removes the character to the left. When deleting a paragraph, check that you have not left an extra blank line or a double space behind.

### Cut, copy and paste

| Action | What happens | Original stays? |
|---|---|---|
| Cut | Selection removed and placed on the clipboard | No |
| Copy | Selection placed on the clipboard | Yes |
| Paste | Clipboard contents inserted at the cursor | Clipboard keeps its contents, so it can be pasted again |

**Move** is cut followed by paste: the text appears in the new place and disappears from the old one. **Copy and paste** duplicates text, for example when the same heading must appear twice.

When pasting from another application, the software usually offers paste options: keep the source formatting, match the formatting of the destination, or paste as plain text only. If the task says the pasted text must match the rest of the document, choose the option that matches the destination formatting or pastes text only.

### Drag and drop

**Drag and drop** moves a selection by dragging it to a new position with the mouse; holding a modifier key (often Ctrl) while dropping copies it instead. It is quick for short distances on the same screen, such as swapping two words. For long distances, such as moving a paragraph several pages, cut and paste is more reliable.

## Placing objects from a variety of sources

| Object | Typical source | Points to check |
|---|---|---|
| Text | A .txt or .rtf file, or another document | Imported text matches the document's styles; no extra blank lines |
| Image | An image file | Position, size and aspect ratio as instructed |
| Screenshot | A capture of the screen or of one window | Cropped so the required detail is readable |
| Shapes | The software's drawing tools | Size, line and fill as specified; grouped if made of several parts |
| Table | Created in the document or copied from elsewhere | Number of rows and columns; fits within the margins |
| Graph or chart | Created in a spreadsheet and copied in | Titles and labels readable; correct data shown |
| Spreadsheet extract | Selected cells from a spreadsheet | Only the required rows and columns; numbers formatted as in the source |
| Database extract | Records or a report from a database query | Only the required fields and records, in the required order |

An extract is **part** of a larger file, so select only what the task asks for. Copying a whole worksheet when the task asks for three columns would add unwanted data and lose marks.

## Wrapping text around a table, chart or image

Text wrapping controls how body text flows around an object. The syllabus names four arrangements:

| Wrapping | Effect | Typical use |
|---|---|---|
| Above | Text stops above the object; nothing beside it | Part of top and bottom wrapping: the object sits on its own line |
| Below | Text continues below the object | Used with "above" so the object has text above and below only |
| Square | Text flows around a rectangular box enclosing the object | A chart or table beside a paragraph in a report |
| Tight | Text follows the outline of the object itself | An irregularly shaped image, such as a logo with a transparent background |

Square and tight look the same for a rectangular photograph, because its outline already is a rectangle. The difference shows with irregular shapes.

## Worked example: an editing task

*Source text to be entered:* "The museum opened in 1987 and receives 42 650 visitors each year."

*A student types:* "The musuem opened in 1978 and recieves 42 650 visitors each year"

*Errors found by line-by-line checking:*

1. "musuem": transposed letters (spell check would find this).
2. "1978": transposed digits (spell check would **not** find this).
3. "recieves": misspelling.
4. Missing full stop at the end.

*Next instruction:* "Move the second paragraph so that it becomes the last paragraph, and copy the heading to the top of page 2."

- Select the whole second paragraph, including its paragraph mark, **cut** it, place the cursor at the start of an empty line after the last paragraph and **paste**.
- Select the heading, **copy**, move to the top of page 2 and **paste**. The heading now appears in both places.
- Check that no blank lines or double spaces remain where the paragraph was removed.

## Common mistakes

- Relying on spell check to find errors in names and numbers.
- Copying instead of cutting when the task says move, leaving the text in two places.
- Pasting with source formatting, so the pasted text has a different font from the rest of the document.
- Placing a whole spreadsheet when an extract was asked for.
- Leaving an object in line with text when square or tight wrapping was requested.
- Confusing tight wrapping with square wrapping on an irregular image.

## Exam technique

In the practical papers, tick off each instruction once it is complete and then proofread the whole document against the source. In theory questions, **describe** an editing technique by giving its steps in order ("select the text, cut it, place the cursor, paste"). When asked to **explain** a choice, such as tight wrapping, link it to the object in the scenario: "tight, because the logo is circular and the text can follow its edge".

## Check your understanding

1. Why might a spell check miss an error in a typed date? *It does not check that numbers match the source.*
2. What is the difference between cut and copy? *Cut removes the original; copy leaves it in place.*
3. Name four kinds of object that can be placed into a document. *Image, screenshot, chart, spreadsheet extract (also text, shapes, table, database extract).*
4. When does tight wrapping differ from square wrapping? *When the object has an irregular outline.*
