## Questions

### Section A: short questions

**1.** Which statement describes the genetic code as degenerate?

A: The same triplets code for the same amino acids in all organisms.

B: Each base is part of only one triplet.

C: Most amino acids are coded for by more than one triplet.

D: Each triplet codes for more than one amino acid. **[1]**

**2.** Name the enzyme that joins RNA nucleotides during transcription. **[1]**

**3.** A pre-mRNA molecule has 2,400 nucleotides. The introns total 780 nucleotides. Calculate the number of amino acids in the polypeptide it codes for, if the last codon is a stop codon. **[3]**

### Section B: longer questions

**4.** The template strand of part of a gene has the base sequence TAC CTT TTT GAC AAC ATC.

**(a)** Write the sequence of the mRNA transcribed from this template. **[2]**

**(b)** Use the codon table to give the sequence of amino acids in the polypeptide. **[2]**

**(c)** State the sequence of bases in the anticodon of the tRNA molecule that carries the third amino acid. **[1]**

**5.** A mutation changed the third triplet of the template strand in question 4 from TTT to TTC.

**(a)** Use the codon table to explain why the polypeptide is not changed. **[2]**

**(b)** A different mutation deleted the fourth base of the template strand (the first C of the second triplet). Give the new mRNA sequence read in triplets and the first five amino acids of the new polypeptide, and explain why this mutation has a greater effect than the one in part (a). **[4]**

**6.** In a different gene, a mutation changed the second codon of the mRNA from GAA to GUA. Explain how this might reduce the activity of an enzyme coded for by the gene. **[4]**

**7.** Describe the roles of ribosomes, tRNA and ATP in translation. **[5]**

**8.** Compare transcription in a prokaryotic cell with transcription in a eukaryotic cell. **[3]**

**9.** A polypeptide of 250 amino acids is made by translation.

**(a)** Calculate the minimum number of nucleotides in the coding region of the mRNA, including the stop codon. **[2]**

**(b)** State the number of peptide bonds in the polypeptide. **[1]**

**10.** Explain what is meant by protein folding, and describe the role of chaperones. **[3]**

## Answers

**1.** **C** [1]. **[1]**
*Examiner insight:* Option A is universal, B is non-overlapping. Learn all three properties as a set.

**2.** RNA polymerase [1]. **[1]**

**3.** mRNA length = 2,400 - 780 = 1,620 nucleotides [1]. Codons = 1,620 / 3 = 540 [1]. One is the stop codon, so 539 amino acids [1]. **[3]**

**4. (a)** Each base pairs with its complement, with uracil in place of thymine (A pairs with U) [1]. mRNA: AUG GAA AAA CUG UUG UAG [1]. **[2]**

**(b)** Methionine - glutamic acid - lysine - leucine - leucine, then stop [2; 1 for four correct]. **[2]**

**(c)** The third codon is AAA, so the anticodon is UUU [1]. **[1]**
*Examiner insight:* The third amino acid is lysine, and the anticodon is complementary to the codon. Be careful not to write the DNA triplet instead.

**5. (a)** The template change makes the third codon AAG instead of AAA [1]. Both AAA and AAG code for lysine because the genetic code is degenerate, so the polypeptide is the same [1]. **[2]**

**(b)** New mRNA: AUG AAA AAC UGU UGU AG [1]. First five amino acids: methionine, lysine, asparagine, cysteine, cysteine [1]. The deletion shifts the reading frame, because the code is read in non-overlapping triplets, so every codon after the deletion changes [1]. In (a) only one base changed and the amino acid stayed the same, but here most or all later amino acids are different [1]. **[4]**

**6.** The amino acid changes from glutamic acid to valine [1]. The R-groups differ, so the hydrogen bonds, ionic bonds or disulfide bridges that fold the polypeptide may change [1]. The tertiary structure, and therefore the shape of the active site, changes [1]. The substrate no longer fits well, so fewer enzyme-substrate complexes form and the activity falls [1]. **[4]**

**7.** The ribosome binds to the mRNA and holds the mRNA and tRNA in place [1]. A tRNA molecule brings a specific amino acid, and its anticodon pairs with the complementary codon on the mRNA [1]. The ribosome catalyses the formation of a peptide bond between adjacent amino acids [1] and moves along the mRNA by one codon at a time [1]. ATP provides the energy to attach amino acids to tRNA and to form peptide bonds [1]. **[5]**

**8.** In both, RNA polymerase joins RNA nucleotides using the template strand [1]. In prokaryotes, transcription results directly in mRNA [1]. In eukaryotes, transcription produces pre-mRNA, which is spliced to remove introns to give mRNA [1]. **[3]**

**9. (a)** 250 x 3 = 750 nucleotides for the amino acids [1], plus 3 for the stop codon = 753 [1]. **[2]**

**(b)** 249 [1]. **[1]**

**10.** Protein folding is the process by which a polypeptide folds into its characteristic three-dimensional structure [1], which is determined by the amino acid sequence [1]. Chaperones are specialised proteins that assist the folding of other proteins [1]. **[3]**

## Where marks are usually lost

- Writing the mRNA by copying the template, not by finding its complement.
- Putting thymine in an mRNA sequence.
- Confusing the codon with the anticodon.
- Counting the stop codon as an amino acid.
- Explaining the effect of a mutation without saying how the change reaches the protein's shape.
