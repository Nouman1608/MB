These notes summarise section 6.4, Pythagoras' theorem and trigonometry in 3D, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. Full explanations are in the [Pythagoras' theorem and trigonometry in 3D study guide](/resources/cambridge-o-level-mathematics-4024-pythagoras-theorem-and-trigonometry/), and exam-style questions are in the [Pythagoras' theorem and trigonometry in 3D practice questions](/resources/cambridge-o-level-mathematics-4024-pythagoras-theorem-and-trigonometry-practice/).

## What is examined

Calculations and problems in three dimensions using Pythagoras' theorem and trigonometry, including the angle between a line and a plane.

## Key terms

| Term | Meaning |
|---|---|
| Space diagonal | a diagonal joining opposite corners of a solid |
| Projection | the shadow of a line on a plane, with perpendiculars dropped to the plane |
| Angle between a line and a plane | the angle between the line and its projection |
| Apex | the top point of a pyramid or cone |
| Sloping edge | an edge from the apex to a base corner |
| Slant height | the height of a sloping face, from the base edge to the apex |
| Vertical height | the perpendicular height from the apex to the base |
| Plane | a flat surface |

## Formulas to use

```
cuboid l × w × h:   base diagonal = √(l² + w²)
                    space diagonal = √(l² + w² + h²)
pyramid (apex above the centre):
    sloping edge² = height² + (half base diagonal)²
    slant height² = height² + (half base side)²
cone:  slant² = radius² + height²
angles: sin, cos, tan in the right-angled triangle chosen
```

## Method box: any 3D problem

1. Draw the solid and mark the line or angle.
2. Find a right-angled triangle that includes it.
3. Redraw the triangle flat, with its right angle and known lengths.
4. If a side is missing, find it from another right-angled triangle, often in the base.
5. Use Pythagoras or trigonometry. Keep full accuracy.
6. Answer lengths to 3 significant figures and angles to 1 decimal place.

## Method box: the angle between a line and a plane

1. Pick a point on the line that is above or away from the plane.
2. Drop a perpendicular to the plane. Find its foot.
3. Join the foot to the point where the line meets the plane. This is the projection.
4. The required angle is between the line and its projection, in a right-angled triangle.

## Typical results

| Solid and data | Result |
|---|---|
| cuboid 8 × 6 × 5 | base diagonal 10, space diagonal 11.2, angle with base 26.6° |
| cuboid 12 × 5 × 4 | space diagonal 13.6, angle with base 17.1° |
| square pyramid base 10, height 12 | edge 13.9, edge angle 59.5°, face angle 67.4° |
| rectangular pyramid 8 × 6, height 12 | edge 13, angle with base 67.4° |
| cone slant 13, radius 5 | height 12, base angle 67.4° |
| cube side 6 | space diagonal 10.4, angle with base 35.3° |

## Which angle is which?

| Angle | Triangle used |
|---|---|
| sloping edge and base | height, half base diagonal, edge |
| sloping face and base | height, half base side, slant height |
| space diagonal and base | height, base diagonal, space diagonal |
| space diagonal and a vertical face | the perpendicular, the diagonal across that face, the space diagonal |

## Elevation in 3D

1. Find the horizontal distance from the observation point to the foot of the vertical object, using the ground plane.
2. Use tan of the angle of elevation with the vertical height and that horizontal distance.

Example: tower 30 m high, observer 40 m west of the base: elevation 36.9°. Another observer 50 m south of the base: elevation 31.0°. Distance between the observers: 64.0 m.

## Must-know distinctions

| Idea | Be clear that |
|---|---|
| Slant height vs sloping edge | slant height is on a face; the edge is on the corner |
| Half base side vs half base diagonal | the face angle uses the side; the edge angle uses the diagonal |
| Line and plane | use the projection |
| Vertical height | at 90° to the base |

## Exam traps

- Drawing a triangle with no right angle.
- Using the base side instead of half the base diagonal.
- Reading lengths from the sketch.
- Rounding early.
- Using the wrong plane for an angle.
- Forgetting that the apex is above the centre.

## Self-test

1. A cuboid is 3 cm by 4 cm by 12 cm. Find its space diagonal.
2. A cuboid has a base 6 cm by 8 cm and height 5 cm. Find the angle between the space diagonal and the base.
3. A square-based pyramid has base side 6 cm and vertical height 4 cm. Find the sloping edge to 3 significant figures.
4. Find the angle between a sloping edge and the base in question 3.
5. A rectangular-based pyramid has base 8 cm by 6 cm and height 12 cm. Find the sloping edge.
6. A cone has slant height 10 cm and radius 6 cm. Find its height and the angle between the slant side and the base.
7. A cylinder has radius 4 cm and height 6 cm. Find the longest straight line inside it.
8. A room is 6 m by 8 m by 5 m. Find the distance from a floor corner to the opposite ceiling corner.
9. A square pyramid has base side 10 cm and height 12 cm. Find the angle between a face and the base.
10. A cube has side 4 cm. Find the angle between a space diagonal and the base.

### Answers

1. √(9 + 16 + 144) = **13 cm**.
2. Base diagonal 10, tan θ = 5/10, so **26.6°**.
3. Half the base diagonal = 3√2 = 4.243, edge² = 16 + 18 = 34, so **5.83 cm**.
4. tan θ = 4/4.243, so **43.3°**.
5. Half the diagonal = 5, edge² = 144 + 25 = 169, so **13 cm**.
6. Height = 8 cm; cos θ = 6/10, so **53.1°**.
7. √(8² + 6²) = **10 cm**.
8. √(36 + 64 + 25) = √125 = **11.2 m**.
9. tan φ = 12/5, so **67.4°**.
10. The base diagonal is 4√2 = 5.657, so tan θ = 4/5.657 and θ = **35.3°**.
