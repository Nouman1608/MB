These questions cover subtopic **2.7 Sequences** in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. Questions without a label use content common to Core (C2.7) and Extended (E2.7): continuing sequences, term-to-term rules, and nth terms of linear, simple quadratic and simple cubic sequences. Questions marked **(Extended)** use general quadratic and cubic sequences, exponential sequences, combinations and subscript notation. None of them needs a calculator.

For worked examples, read the [sequences study guide](/resources/cambridge-igcse-mathematics-0580-sequences-cambridge-igcse-maths/); for a summary, use the [sequences revision notes](/resources/cambridge-igcse-mathematics-0580-sequences-cambridge-igcse-maths-revision-notes/).

## Questions

### Section A: short questions

**1.** Write down the next two terms of 1, 4, 10, 19, 31, …. **[2]**

**2.** The sequence 2, 6, 18, 54, … continues.

**(a)** Write down the term-to-term rule. **[1]**

**(b)** Write down the next term. **[1]**

**3.** Find the nth term of 8, 13, 18, 23, …. **[2]**

**4.** Find the nth term of 15, 11, 7, 3, …. **[2]**

**5.** Find the nth term of 4, 7, 12, 19, 28, …. **[2]**

**6.** Find the nth term of 0, 7, 26, 63, …. **[2]**

### Section B: structured questions

**7.** A sequence of tile patterns uses 5 tiles in Pattern 1, 8 tiles in Pattern 2 and 11 tiles in Pattern 3. The number of tiles goes up by the same amount each time.

**(a)** Find an expression for the number of tiles in Pattern n. **[2]**

**(b)** Which pattern uses 62 tiles? **[1]**

**(c)** Explain why no pattern uses exactly 100 tiles. **[2]**

**8.** Sequence A is 3, 5, 7, 9, … and sequence B is 4, 9, 16, 25, ….

**(a)** Find the nth term of sequence A. **[1]**

**(b)** Find the nth term of sequence B. **[1]**

**(c)** Show that the nth term of B minus the nth term of A is always n². **[2]**

**9.** (Extended)

**(a)** Find the nth term of 3, 10, 21, 36, 55, …. **[3]**

**(b)** Find the 20th term. **[1]**

**10.** (Extended) Find the nth term of the cubic sequence 2, 15, 44, 95, 174, …. **[4]**

**11.** (Extended)

**(a)** Find the nth term of 2, 8, 32, 128, …. **[2]**

**(b)** Find the nth term of 160, 80, 40, 20, …. **[2]**

**(c)** Which is the first term of the sequence in part (b) that is less than 1? Give its position and value. **[2]**

**12.** (Extended) By comparing it with the sequence 2ⁿ, find the nth term of 4, 7, 12, 21, 38, …. **[3]**

**13.** (Extended) Two sequences have nth terms Pₙ = n² + 4n and Qₙ = 6n + 15. Find the value of n for which Pₙ = Qₙ. **[3]**

## Answers

**1.** Differences 3, 6, 9, 12 go up by 3, so the next differences are 15 and 18 [1]. **46, 64** [1].

**2. (a)** **Multiply by 3** [1].

**(b)** **162** [1].

**3.** Difference 5, so 5n [1]; zero term 3: **5n + 3** [1].

**4.** Difference −4, so −4n [1]; zero term 19: **19 − 4n** [1].

**5.** Compare with 1, 4, 9, 16, 25: each term is 3 more [1]. **n² + 3** [1].

**6.** Compare with 1, 8, 27, 64: each term is 1 less [1]. **n³ − 1** [1].

**7. (a)** Difference 3, zero term 2 [1]: **3n + 2** [1].

**(b)** 3n + 2 = 62, 3n = 60: **Pattern 20** [1].

**(c)** 3n + 2 = 100 gives 3n = 98 [1], so n = 32.66…, which is not a whole number, so no pattern has 100 tiles [1].
*Examiner insight:* "because it is not in the sequence" restates the question. The mark needs the calculation and the comment that n is not an integer.

**8. (a)** **2n + 1** [1].

**(b)** **(n + 1)²** [1].

**(c)** (n + 1)² − (2n + 1) = n² + 2n + 1 − 2n − 1 [1] = **n²** [1].

**9. (a)** Differences 7, 11, 15, 19; second difference 4, so 2n² [1]. Terms minus 2n²: 1, 2, 3, 4, 5 [1]. **2n² + n** [1].

**(b)** 2(400) + 20 = **820** [1].

**10.** Third difference 6 (first differences 13, 29, 51, 79; second 16, 22, 28), so n³ [1]. Terms minus n³: 1, 7, 17, 31, 49 [1]. This has second difference 4, so 2n²; remainder −1 each time [1]. **n³ + 2n² − 1** [1].
*Examiner insight:* check with n = 2: 8 + 8 − 1 = 15. A slip in one difference spreads through every later step, so check each row of differences before using it.

**11. (a)** Ratio 4, first term 2 [1]: **2 × 4ⁿ⁻¹** [1] (also written 2²ⁿ⁻¹).

**(b)** Ratio ½, first term 160 [1]: **160 × (½)ⁿ⁻¹** [1].

**(c)** Terms: 160, 80, 40, 20, 10, 5, 2.5, 1.25, 0.625 [1]. The **9th term, 0.625** [1].

**12.** 2ⁿ: 2, 4, 8, 16, 32. Terms minus 2ⁿ: 2, 3, 4, 5, 6 [1], which is n + 1 [1]. **2ⁿ + n + 1** [1].

**13.** n² + 4n = 6n + 15, so n² − 2n − 15 = 0 [1]. (n − 5)(n + 3) = 0 [1]. n is a position, so **n = 5** [1] (check: P₅ = 45 = Q₅).

## Where marks are usually lost

- Using the first term rather than the zero term for the constant in a linear nth term.
- Writing +4n for a decreasing sequence.
- Taking the n² coefficient as the second difference instead of half of it.
- Stopping at second differences for a cubic.
- Writing (½)ⁿ instead of (½)ⁿ⁻¹, so that every term is half the size it should be.
- Keeping a negative or fractional value of n as a position.
