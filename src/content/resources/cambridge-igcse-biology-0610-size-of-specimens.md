## The formula and its three forms

**magnification = image size ÷ actual size**

- **Image size** is how big the specimen appears in the drawing, photograph or micrograph. You usually measure it with a ruler, in millimetres.
- **Actual size** is how big the specimen really is.
- **Magnification** is how many times bigger the image is than the real thing. It has **no units**, and is written with a multiplication sign, such as **×400**.

Rearranged:

| To find | Use |
|---|---|
| Magnification | image size ÷ actual size |
| Actual size | image size ÷ magnification |
| Image size | magnification × actual size |

A memory aid: in the triangle **I** on top, **A** and **M** underneath. Cover the one you want; what is left tells you whether to multiply or divide.

**The one rule that matters most:** image size and actual size must be in the **same unit** before you divide.

## Measuring an image

1. Choose the measurement the question asks for: length, width or diameter. Measure along the line shown if there is one.
2. Use a ruler marked in millimetres. Line up 0 with one edge, not the end of the ruler.
3. Read to the nearest millimetre and **write the measurement down** in your working. Examiners usually allow a small tolerance, but only if they can see your value.
4. Measure the **image**, never the real specimen, for "image size".

## Core worked examples

### Worked example 1: finding magnification

A drawing of a pollen grain is 24 mm across. The actual pollen grain is 0.04 mm across.

```
magnification = image size ÷ actual size
              = 24 ÷ 0.04
              = 600
```

**Answer: ×600.** Write it with the × sign and no units.

### Worked example 2: finding actual size

A drawing of an insect is 72 mm long. The drawing is labelled ×4.

```
actual size = image size ÷ magnification
            = 72 ÷ 4
            = 18 mm
```

**Answer: 18 mm.** The real insect is smaller than the drawing, as it should be for a magnified image. Check that your answer makes sense this way round.

### Worked example 3: finding image size

A cell is 0.02 mm wide. A photograph shows it at ×1500.

```
image size = magnification × actual size
           = 1500 × 0.02
           = 30 mm
```

**Answer: 30 mm.**

### Worked example 4: using a scale bar

A micrograph has a scale bar labelled 0.5 mm. The bar measures 20 mm on the page. A cell in the same image measures 36 mm.

```
magnification = image of scale bar ÷ actual length of scale bar
              = 20 ÷ 0.5 = ×40
actual size of cell = 36 ÷ 40 = 0.9 mm
```

**Answer: 0.9 mm.** A scale bar is a known actual size drawn at the image's magnification, so it lets you find the magnification first.

### Worked example 5: measuring several cells

Five cells lie end to end across 30 mm of a photograph taken at ×200.

```
actual length of five cells = 30 ÷ 200 = 0.15 mm
actual length of one cell   = 0.15 ÷ 5 = 0.03 mm
```

Measuring across several cells and dividing gives a more accurate average than measuring one small cell.

## 2.2.3 Converting mm and μm -- Extended only

Cells are tiny, so their sizes are often given in **micrometres** (μm).

**1 mm = 1000 μm**

| Conversion | Do this | Example |
|---|---|---|
| mm → μm | Multiply by 1000 | 0.075 mm × 1000 = **75 μm** |
| μm → mm | Divide by 1000 | 2500 μm ÷ 1000 = **2.5 mm** |

A check: the number in micrometres is always **bigger** than the same length in millimetres, because micrometres are smaller units.

### Worked example 6: magnification with mixed units

A photograph shows a cell 40 mm wide. The actual cell is 8 μm wide. Calculate the magnification.

```
convert image size to μm: 40 mm × 1000 = 40 000 μm
magnification = 40 000 ÷ 8 = 5000
```

**Answer: ×5000.** Without converting, 40 ÷ 8 gives ×5, which is a thousand times too small.

### Worked example 7: actual size in micrometres

A drawing of a cell is 60 mm long at ×1200. Give the actual length in μm.

```
actual size = 60 ÷ 1200 = 0.05 mm
0.05 mm × 1000 = 50 μm
```

**Answer: 50 μm.**

## Common errors

- Dividing actual size by image size, which gives a number less than 1 for a magnified image.
- Giving magnification units, such as "×600 mm".
- Forgetting the × sign.
- Mixing units: dividing an image in mm by an actual size in μm.
- (Extended) Multiplying when you should divide in a conversion. Check that the μm value is the larger number.
- Measuring the wrong dimension, or measuring from the end of the ruler instead of from 0.
- Rounding too early. Keep the full value until the final answer.

## Exam technique for Cambridge command words

- **State the formula:** write it in words, exactly: magnification = image size ÷ actual size.
- **Calculate:** write the formula, substitute values with units, then give the answer with the correct unit (or × for magnification). Working earns method marks even if the final number slips.
- **Measure:** give your measurement in mm before using it.
- **Show your working:** always, especially for conversions.

## Frequently asked questions

**Does magnification have units?** No. It is a ratio, written with a × sign, such as ×250.

**How many micrometres are in a millimetre?** 1000.

**Is converting units Core or Extended?** Converting between mm and μm is Extended only; Core calculations use millimetres throughout.
