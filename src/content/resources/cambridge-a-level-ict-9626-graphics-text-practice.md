This is **A Level only** content. The syllabus tests the practical skills in Paper 4 (Advanced Practical) and bases Paper 3 (Advanced Theory) on sections 12 to 21, where calculators are not allowed. ## Questions

**1.** Explain the difference between each pair of terms.

**(a)** kerning and letter spacing **[2]**
**(b)** font size and line spacing **[2]**

**2.** A designer is creating a poster for a school science fair and a logo for a law firm.

**(a)** Recommend a type of font face for each, and give a reason for each recommendation. **[4]**
**(b)** Give **two** guidelines for choosing fonts that apply to both designs. **[2]**

**3.** A paragraph is set in 12-point text with a line spacing of 1.5 times the font size.

**(a)** Calculate the distance from one baseline to the next, in points. **[1]**
**(b)** Calculate the height of a block of 8 lines, in points and in inches. There are 72 points in one inch. **[3]**
**(c)** State the effect of reducing the line spacing to 1.0 times the font size. **[1]**

**4.** A 12-letter word in a logo is spaced out. The designer adds 3 points of letter spacing between every pair of letters.

**(a)** State how many gaps there are between the letters. **[1]**
**(b)** Calculate the extra width, in points. **[1]**
**(c)** In the same logo, the letters "AV" look too far apart. State the adjustment to make and explain why it is different from changing the letter spacing. **[2]**

**5.** A badge for a swimming club is a circle. The club name must curve around the top of the circle, and "Est. 1998" must curve around the bottom and read the right way up.

**(a)** Describe how the club name can be made to follow the circle. **[3]**
**(b)** Give **one** problem that may need to be corrected after the text is attached. **[1]**
**(c)** The designer wants only the text to show, not the circle. State what should be done to the circle. **[1]**

**6.** A comic strip uses speech bubbles. The speech for a character is placed in a bubble shape.

**(a)** Describe what is meant by setting text in a shape. **[2]**
**(b)** The text is too long for the bubble and part of it disappears. Give **two** ways to put this right. **[2]**

**7.** The designer finishes the club logo and converts the text to curves.

**(a)** Describe what happens to the letters when text is converted to curves. **[2]**
**(b)** Give **two** advantages of converting the text in a logo to curves. **[2]**
**(c)** Give **one** disadvantage and state what the designer should do before converting to reduce the risk. **[2]**

**8.** Evaluate the use of a decorative script font for the whole text of a hospital information leaflet. **[4]**

## Answers

**1. (a)** Kerning adjusts the space between one specific pair of letters [1]; letter spacing changes the space between all the letters in a selected block by the same amount. [1] **[2]**
**(b)** Font size is the height of the characters (in points) [1]; line spacing is the vertical distance from one line of text to the next (baseline to baseline). [1] **[2]**

**2. (a)** Science fair poster: sans-serif (or a clear display font for the title) [1], because it is clean and easy to read from a distance. [1] Law firm logo: serif [1], because it looks traditional, formal and trustworthy. (Accept another suitable choice with a reason.) [1] **[4]**
**(b)** Any two: use few fonts, usually no more than two; make sure the text is legible at the viewing distance; match the style to the audience and message; use enough contrast with the background. [1 each] **[2]**

**3. (a)** 12 × 1.5 = 18 points. [1] **[1]**
**(b)** 8 × 18 [1] = 144 points [1]; 144 ÷ 72 = 2 inches. [1] **[3]**
**(c)** The lines would be closer together (12 points apart), so the text would be more crowded. [1] **[1]**

**4. (a)** 11 gaps. [1] **[1]**
**(b)** 11 × 3 = 33 points. [1] **[1]**
**(c)** Apply kerning to the pair A and V, to reduce the gap between them [1]; letter spacing changes all the letters equally, so it cannot correct a single awkward pair. [1] **[2]**
*Examiner insight:* A word of n letters has n − 1 gaps. Using 12 gaps is the usual slip.

**5. (a)** Draw a circle (or use the badge's circle) as the path [1]; select the club name and use the fit-text-to-path tool to attach it to the circle [1]; move the text along the path (or offset it) so it is centred at the top. [1] **[3]**
**(b)** Any one: letters crowd or spread unevenly at the curve, so the spacing or size must be adjusted; the text may be on the wrong side of the path, upside down or inside the circle and need flipping. [1] **[1]**
**(c)** Remove the outline (set the circle's stroke and fill to none). [1] **[1]**

**6. (a)** The text is placed inside a shape, which acts as a frame [1], and the text wraps to follow the shape's boundary. [1] **[2]**
**(b)** Any two: make the bubble larger; reduce the font size; shorten the text; reduce line spacing or padding. [1 each] **[2]**

**7. (a)** Each letter is turned from a font character into a vector shape made of nodes and paths [1], so it can be edited with the node tools but is no longer text. [1] **[2]**
**(b)** Any two: the logo looks the same on any computer even if the font is not installed; the letters can be reshaped or combined with other shapes; effects can be applied to each letter. [1 each] **[2]**
**(c)** The text can no longer be edited as text, so spelling or wording mistakes cannot be fixed by retyping [1]. Before converting, the designer should proofread the text carefully and save a copy with the live text. [1] **[2]**

**8.** A script font is hard to read in long passages [1], and the patients include people who are ill, older or have poor eyesight, so legibility is important [1]. It could look friendly, but a hospital leaflet needs clarity more than decoration [1]. A clear sans-serif or serif font would be better for the body, and a script could be used for a short heading at most. [1] **[4]**
*Examiner insight:* "Evaluate" needs a judgement based on the leaflet's purpose and readers, not a general statement about fonts.

## Where marks are usually lost

- Mixing up kerning and letter spacing.
- Counting n gaps instead of n − 1 between n letters.
- Forgetting to convert points to inches (divide by 72).
- Recommending a font without a reason.
- Saying that text on a path can no longer be edited.
- Not mentioning the loss of text editing when converting to curves.

## Frequently asked questions

**How many points are in an inch?**
There are 72 points in one inch, so 36-point text is about half an inch tall.

**Is text on a path still editable?**
Yes. It remains live text attached to the path, so it can be edited, and it follows the path if the path is changed.
