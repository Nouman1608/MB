These questions cover **section 5.8 of IB DP Mathematics: Analysis and Approaches: local maximum and minimum points, optimisation and points of inflexion**. It is SL content, so the set suits SL and HL students. Questions are labelled "(calculator-free)" or "(calculator allowed)". Give answers exactly or to 3 significant figures. Figures in context questions are invented for practice.

Learn the methods first in the [section 5.8 study guide](/resources/ib-dp-mathematics-analysis-and-approaches-5-8/) and the [section 5.8 revision notes](/resources/ib-dp-mathematics-analysis-and-approaches-5-8-revision-notes/).

## Section A

**1.** (calculator-free) Let f(x) = x³ − 6x² − 15x + 4. Find the coordinates of the stationary points of f and determine their nature. **[5]**

**2.** (calculator-free) Let y = x e^(−x/2).

**(a)** Find the x-coordinate of the stationary point. **[3]**
**(b)** Show that this point is a maximum. **[2]**

**3.** (calculator-free) A function f has derivative f′(x) = x(x − 2)². Determine the nature of each stationary point of f, giving reasons. **[4]**

**4.** (calculator-free) Show that the curve y = x⁴ + 4x³ has a stationary point of inflexion at the origin. **[4]**

**5.** (calculator-free) Let f(x) = x³ + 3x² − 9x + 2. Find the equation of the tangent to the graph of f at its point of inflexion. **[5]**

## Section B

**6.** (calculator-free) A closed box has a rectangular base measuring x cm by 2x cm and a height of h cm. Its volume is 72 cm³.

**(a)** Show that the surface area S cm² is given by S = 4x² + 216/x. **[3]**
**(b)** Find the value of x that minimises S, and justify that it is a minimum. **[4]**
**(c)** Find the minimum surface area. **[1]**

**7.** (calculator allowed) A small company models its weekly profit, P thousand dollars, when it makes x hundred items by P(x) = 40x e^(−0.05x), for 0 ≤ x ≤ 80.

**(a)** Find P′(x). **[2]**
**(b)** Find the number of items that maximises the profit, and the maximum profit. **[3]**
**(c)** Given that P″(x) = 0.1(x − 40)e^(−0.05x), state the interval on which the graph of P is concave-down. **[1]**

**8.** (calculator-free) The point P(x, x²) lies on the curve y = x², and A is the point (0, 2).

**(a)** Show that AP² = x⁴ − 3x² + 4. **[2]**
**(b)** Find the minimum distance AP. **[4]**

**9.** (calculator-free) Let f(x) = x³ + ax² + bx, where a, b ∈ ℝ. The graph of f has a stationary point at (1, −5).

**(a)** Find the values of a and b. **[4]**
**(b)** Find the coordinates of the other stationary point and determine its nature. **[3]**
**(c)** Find the coordinates of the point of inflexion. **[2]**

**10.** (calculator-free) Let f(x) = 2 sin x + cos 2x, for 0 ≤ x ≤ 2π.

**(a)** Show that f′(x) = 2 cos x (1 − 2 sin x). **[2]**
**(b)** Find the x-coordinates of the four stationary points. **[3]**
**(c)** Find the greatest and least values of f on the interval. **[3]**

**11.** (calculator-free) A cylinder of radius r cm and height h cm fits exactly inside a sphere of radius 6 cm, so that r² + (h/2)² = 36.

**(a)** Show that the volume of the cylinder is V = π(36h − h³/4). **[2]**
**(b)** Find the exact value of h that maximises V, and justify that it is a maximum. **[4]**
**(c)** Find the maximum volume in the form kπ√3. **[2]**

**12.** (calculator-free) Let f(x) = (x² − 3)eˣ.

**(a)** Show that f′(x) = (x + 3)(x − 1)eˣ. **[2]**
**(b)** Find the exact coordinates of the stationary points and determine their nature. **[5]**
**(c)** Given that f″(x) = (x² + 4x − 1)eˣ, find the exact x-coordinates of the points of inflexion. **[2]**

## Answers

**1.** f′(x) = 3x² − 12x − 15 = 3(x − 5)(x + 1) [1]; x = −1 or x = 5 [1]; (−1, 12) and (5, −96) [1]; f″(x) = 6x − 12: f″(−1) = −18 < 0, so **(−1, 12) is a maximum** [1]; f″(5) = 18 > 0, so **(5, −96) is a minimum** [1] **[5]**

**2. (a)** Product rule: dy/dx = e^(−x/2) − (x/2)e^(−x/2) [1] = (1 − x/2)e^(−x/2) [1]; e^(−x/2) ≠ 0, so **x = 2** [1]
**(b)** d²y/dx² = (x/4 − 1)e^(−x/2) [1]; at x = 2 this is −(1/2)e^(−1) < 0, so a maximum [1] **[5]**
*Examiner insight:* A sign-change argument is also accepted in (b): dy/dx > 0 for x < 2 and dy/dx < 0 for x > 2.

**3.** Stationary points at x = 0 and x = 2 [1]. At x = 0, f′ changes from negative to positive, so **a local minimum** [1]. At x = 2, (x − 2)² ≥ 0 and x > 0 on both sides, so f′ is positive on both sides [1]: **a stationary point of inflexion** [1] **[4]**
*Examiner insight:* f″(2) = 0 here, so the second derivative test cannot classify x = 2; the sign-change reasoning is required.

**4.** dy/dx = 4x³ + 12x² = 4x²(x + 3), which is 0 at x = 0, so the origin is a stationary point [1]. d²y/dx² = 12x² + 24x = 12x(x + 2) [1]. At x = 0, d²y/dx² = 0; for small negative x, 12x(x + 2) < 0, and for small positive x it is > 0 [1]. The concavity changes at a point with zero gradient, so it is a stationary point of inflexion [1] **[4]**

**5.** f′(x) = 3x² + 6x − 9, f″(x) = 6x + 6 [1]; f″ = 0 at x = −1 and changes sign [1]; f(−1) = −1 + 3 + 9 + 2 = 13 [1]; gradient f′(−1) = 3 − 6 − 9 = −12 [1]; tangent y − 13 = −12(x + 1), so **y = −12x + 1** [1] **[5]**

**6. (a)** 2x²h = 72, so h = 36/x² [1]; S = 2(2x²) + 2(xh) + 2(2xh) = 4x² + 6xh [1] = 4x² + 6x(36/x²) = 4x² + 216/x [1]
**(b)** dS/dx = 8x − 216/x² [1] = 0, so x³ = 27, **x = 3** [1]; d²S/dx² = 8 + 432/x³ [1] = 24 > 0 at x = 3, so a minimum [1]
**(c)** S = 36 + 72 = **108 cm²** [1] **[8]**

**7. (a)** P′(x) = 40e^(−0.05x) − 2x e^(−0.05x) [1] = (40 − 2x)e^(−0.05x) [1]
**(b)** P′(x) = 0 when x = 20 [1], so **2000 items** [1]; P(20) = 800e^(−1) = **294 thousand dollars** (294.30…) [1]
**(c)** **0 ≤ x < 40** [1] **[6]**
*Examiner insight:* In (b), x = 20 means 20 hundred items; leaving the answer as "20" ignores the units given in the stem.

**8. (a)** AP² = (x − 0)² + (x² − 2)² [1] = x² + x⁴ − 4x² + 4 = x⁴ − 3x² + 4 [1]
**(b)** d(AP²)/dx = 4x³ − 6x = 2x(2x² − 3) [1]; x = 0 or x² = 3/2 [1]; at x² = 3/2, AP² = 9/4 − 9/2 + 4 = 7/4, which is less than the value 4 at x = 0, so it is the minimum [1]; **AP = √7/2** (≈ 1.32) [1] **[6]**

**9. (a)** f′(1) = 3 + 2a + b = 0 [1]; f(1) = 1 + a + b = −5 [1]; subtracting the second equation from the first gives 2 + a = 5, so **a = 3** [1]; then b = −6 − a, so **b = −9** [1]
**(b)** f′(x) = 3x² + 6x − 9 = 3(x + 3)(x − 1), so x = −3 [1]; f(−3) = −27 + 27 + 27 = 27, giving **(−3, 27)** [1]; f″(−3) = 6(−3) + 6 = −12 < 0, so a **maximum** [1]
**(c)** f″(x) = 6x + 6 = 0 at x = −1 [1]; f(−1) = −1 + 3 + 9 = 11, so **(−1, 11)** [1] **[9]**

**10. (a)** f′(x) = 2 cos x − 2 sin 2x [1] = 2 cos x − 4 sin x cos x = 2 cos x (1 − 2 sin x) [1]
**(b)** cos x = 0: x = π/2, 3π/2 [1]; sin x = 1/2: x = π/6, 5π/6 [1]; all four stated [1]
**(c)** f(π/6) = f(5π/6) = 1 + 1/2 = 3/2; f(π/2) = 1; f(3π/2) = −2 − 1 = −3; f(0) = f(2π) = 1 [1]; **greatest value 3/2** [1]; **least value −3** [1] **[8]**
*Examiner insight:* Checking the end points is part of the method in (c), even though here they do not give the extreme values.

**11. (a)** r² = 36 − h²/4 [1]; V = πr²h = π(36 − h²/4)h = π(36h − h³/4) [1]
**(b)** dV/dh = π(36 − 3h²/4) [1] = 0, so h² = 48 [1], **h = 4√3** (h > 0) [1]; d²V/dh² = −(3π/2)h < 0 for h > 0, so a maximum [1]
**(c)** r² = 36 − 12 = 24 [1]; V = π × 24 × 4√3 = **96π√3 cm³** (≈ 522 cm³) [1] **[8]**

**12. (a)** f′(x) = 2x eˣ + (x² − 3)eˣ [1] = (x² + 2x − 3)eˣ = (x + 3)(x − 1)eˣ [1]
**(b)** x = −3 or x = 1, since eˣ ≠ 0 [1]; points **(−3, 6e⁻³)** and **(1, −2e)** [1]; f″(−3) = (9 − 12 − 1)e⁻³ = −4e⁻³ < 0, so a **maximum** [1]; f″(1) = (1 + 4 − 1)e = 4e > 0, so a **minimum** [1]; both coordinates exact [1]
**(c)** x² + 4x − 1 = 0 [1]; **x = −2 ± √5** [1] **[9]**
