## Section A

**1.** Define the term hardware. **[1]**

**2.** Define the term software. **[2]**

**3.** State whether each item is hardware or software. **[4]**

**(a)** a graphics card
**(b)** a web browser
**(c)** an operating system
**(d)** main memory (RAM)

## Section B

**4.** A photograph is stored in a file on a solid-state drive. Explain why the photograph file is not software, and identify which part of the system is hardware. **[3]**

**5.** Explain why a computer with a processor, memory and storage, but with no software installed, cannot be used to write an essay. **[3]**

**6.** Explain why the same laptop can be used as a word processor at one moment and as a music player the next. **[3]**

**7.** A program has 2,500 machine code instructions. Each instruction occupies 4 bytes.

**(a)** Calculate the number of bytes needed to store the program. **[1]**
**(b)** Give your answer in KiB (1 KiB = 1,024 bytes), to 2 decimal places. **[1]**
**(c)** State which part of this scenario is hardware and which is software. **[2]**

**8.** A school plans four changes to its computers. State whether each is a hardware change or a software change, and give a reason. **[4]**

**(a)** Fitting 8 GiB more RAM.
**(b)** Installing a new version of the word processor.
**(c)** Replacing the keyboards.
**(d)** Removing an unused game.

**9.** A student says: "Software is anything stored on a computer." Evaluate this statement with reference to a document file and a spreadsheet application. **[4]**

**10.** Describe, in order, the hardware and software involved when a user clicks Save in a drawing program. Include at least **two** items of each. **[4]**

**11.** A washing machine contains a small controller. A program stored in a memory chip in the controller runs whenever the machine is switched on.

**(a)** State what the memory chip is and what the program is, using the terms hardware and software. **[2]**
**(b)** Name the term for software stored in a chip in a hardware device. **[1]**
**(c)** Explain why a laptop is more flexible than the controller. **[2]**

**12.** A user wants a computer to open several programs at once without slowing down, and to be able to use a new printer.

**(a)** Suggest a hardware change that would help with the first need. **[1]**
**(b)** Suggest a software change that is needed for the second need, and explain why. **[2]**

## Answers

**1.** The **electronic components** of a computer system [1]. **[1]**

**2.** The **sequences of instructions** [1] that are **executed using the hardware** [1]. **[2]**

**3. (a)** Hardware [1] **(b)** Software [1] **(c)** Software [1] **(d)** Hardware [1] **[4]**

**4.** A photograph file is **data** [1], not a sequence of instructions to be executed [1]; the solid-state drive that stores it is the hardware (an electronic component) [1]. **[3]**

**5.** The hardware has **no instructions to execute** [1], so the processor has nothing to do [1]; a word processor or operating system (software) is needed to accept typing, store the text and display it [1]. **[3]**

**6.** The hardware stays the same [1] but different software (instructions) is executed [1], so the processor does a different job each time; software controls what the hardware does [1]. **[3]**

**7. (a)** 2,500 × 4 = **10,000 bytes** [1]. **[1]**
**(b)** 10,000 ÷ 1,024 = **9.77 KiB** (to 2 d.p.) [1]. **[1]**
**(c)** The storage device, memory and processor are hardware [1]; the 2,500 instructions (the program) are software [1]. **[2]**

**8. (a)** Hardware, because RAM is a physical electronic component [1]. 
**(b)** Software, because it replaces the program's instructions [1].
**(c)** Hardware, because a keyboard is a physical input device [1].
**(d)** Software, because the game is a program, a sequence of instructions [1].
**[4]**

**9.** The statement is **incorrect** [1]. A document file is stored on the computer but is **data**, not instructions [1]. A spreadsheet application is software because it is a **sequence of instructions executed by the hardware** [1]. Software is defined by being instructions, not by being stored, because data is also stored [1]. **[4]**

**10.** Any sensible chain with at least two items of each [4: two hardware items [1]; two software items [1]; correct order [1]; clear link between them [1]]. Example: the mouse (hardware) clicks Save; the drawing program (software) is being executed by the processor (hardware); the operating system (software) asks the file system to write the file; the solid-state drive (hardware) stores the data. **[4]**

**11. (a)** The memory chip is **hardware** [1]; the program is **software** (a sequence of instructions) [1]. **[2]**
**(b)** **Firmware** [1]. **[1]**
**(c)** The laptop can run **many different programs**, installed or changed by the user [1], whereas the controller runs one fixed program for a single task [1]. **[2]**

**12. (a)** Fit more RAM [1]. **[1]**
**(b)** Install the printer's **driver** [1], because the operating system needs software that knows how to control that particular device [1]. **[2]**

## Frequently asked questions

**Is firmware hardware or software?**
Firmware is software, because it is a sequence of instructions, but it is stored in a chip that is part of a hardware device.

**Is a USB drive hardware or software?**
The drive is hardware. The programs and files it contains are software and data respectively.
