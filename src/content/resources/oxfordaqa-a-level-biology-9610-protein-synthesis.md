This guide goes deeper on one section of the OxfordAQA International AS and A-level Biology (9610) specification, Version 5.1: **3.1.8 Protein synthesis**, in Unit 1, The diversity of living organisms. Unit 1 is part of the International AS and counts towards the full International A-level.

Protein synthesis turns the base sequence of a gene into the amino acid sequence of a polypeptide, which then folds into a working protein. The section is easiest to master as a pipeline: code, transcription, (splicing), translation, folding. Test yourself afterwards with the [protein synthesis practice questions](/resources/oxfordaqa-a-level-biology-9610-protein-synthesis-practice/).

| Section | Content |

You must be able to relate base sequences of nucleic acids to the amino acid sequence of a polypeptide when given suitable information about the genetic code. You are not required to recall specific codons and the amino acids they code for in written papers, so a codon table will be provided whenever you need one.

## The genetic code

The code is carried by **base triplets** in DNA. Each triplet codes for a specific amino acid. The corresponding three bases on mRNA are a **codon**. Because there are four bases, there are 4 x 4 x 4 = 64 possible triplets, which is more than enough for twenty amino acids. Some triplets signal where to start or stop.

Three properties of the code are named in the specification:

- **Universal.** The same triplets code for the same amino acids in almost all organisms, which is why genes can function when moved between species.
- **Non-overlapping.** Each base is part of only one triplet, so the sequence is read in groups of three in order.
- **Degenerate.** Most amino acids are coded for by more than one triplet. This means that some changes in the base sequence do not change the amino acid sequence.

## Transcription

**Transcription** is the production of mRNA from DNA.

1. The enzyme **RNA polymerase** attaches to the DNA at the start of the gene.
2. The DNA double helix unwinds and hydrogen bonds between the strands break locally. One strand, the **template strand**, is copied.
3. Free RNA nucleotides pair with the exposed bases on the template by complementary base pairing (the RNA nucleotide with uracil pairs with adenine on DNA).
4. RNA polymerase joins the RNA nucleotides together, forming a strand of mRNA.
5. At the end of the gene the mRNA is released and the DNA re-forms the double helix.

The mRNA has the same base sequence as the other (non-template) DNA strand, except that uracil replaces thymine.

### Prokaryotes and eukaryotes

- In **prokaryotes**, transcription results directly in the production of mRNA from DNA. Genes have no introns.
- In **eukaryotes**, transcription results in **pre-mRNA**, which contains copies of both exons and introns. Pre-mRNA is then **spliced**: the introns are removed and the exons joined to form **mRNA**. The mRNA leaves the nucleus through a nuclear pore and goes to a ribosome.

**Worked example 1: transcription and splicing.** A pre-mRNA molecule has 3,000 nucleotides. The introns total 1,140 nucleotides.

1. mRNA length = 3,000 - 1,140 = 1,860 nucleotides.
2. Number of codons = 1,860 / 3 = 620.
3. If the last codon is a stop codon, the polypeptide has 620 - 1 = **619 amino acids**.

## Translation

**Translation** is the production of a polypeptide from the sequence of codons on mRNA. It takes place at a **ribosome**.

1. A ribosome binds to the mRNA at a start codon.
2. Each **tRNA** molecule carries a specific amino acid. The amino acid is attached to the tRNA using energy from **ATP**.
3. A tRNA whose **anticodon** is complementary to the first codon pairs with it by hydrogen bonds. A second tRNA pairs with the next codon, so two amino acids are held side by side.
4. A peptide bond forms between the amino acids by condensation. The first tRNA leaves, to be re-used.
5. The ribosome moves along the mRNA one codon at a time, and the chain lengthens.
6. At a stop codon no tRNA binds and the polypeptide is released.

The roles to be able to state exactly:

| Component | Role |
|---|---|
| mRNA | Carries the code from DNA to the ribosome |
| Ribosome | Holds the mRNA and tRNA in position and catalyses peptide bond formation |
| tRNA | Brings a specific amino acid and pairs with a codon through its anticodon |
| ATP | Provides the energy to attach amino acids to tRNA and to form peptide bonds |

Many ribosomes can translate one mRNA at the same time, so many copies of the polypeptide are made quickly.

### Worked example 2: from DNA to polypeptide

Use this mini codon table, which a question would supply: AUG = Met (start), GAA = Glu, UUU = Phe, GGC = Gly, UGG = Trp, UAA = stop.

**Question:** The template strand of a gene reads TAC CTT AAA CCG ACC ATT. Give the mRNA and the polypeptide.

1. Complementary mRNA bases: T pairs with A, A with U, C with G, G with C.
2. TAC gives AUG; CTT gives GAA; AAA gives UUU; CCG gives GGC; ACC gives UGG; ATT gives UAA.
3. mRNA: **AUG GAA UUU GGC UGG UAA**.
4. Polypeptide: **Met-Glu-Phe-Gly-Trp**, and then stop.
5. The anticodons of the tRNA molecules would be UAC, CUU, AAA, CCG and ACC, the same sequence as the DNA template with U in place of T.

### Worked example 3: effects of changes

Use the same gene. The mRNA is AUG GAA UUU GGC UGG UAA.

- **Substitution in codon 2 (GAA to GUA).** Glu becomes Val. One amino acid differs, which could alter the tertiary structure and function.
- **Substitution in the third base of codon 4 (GGC to GGU).** Gly is still Gly because the code is degenerate. This is a silent change.
- **Substitution that creates a stop codon (UGG to UAG).** The polypeptide stops early with only four amino acids: Met-Glu-Phe-Gly.
- **Deletion of one base from codon 2.** The reading frame shifts, because the code is non-overlapping and read in threes. All later codons change, giving AUG AAU UUG GCU GGU AA, which codes for Met-Asn-Leu-Ala-Gly (with Asn = AAU, Leu = UUG, Ala = GCU and Gly = GGU). Frame shifts normally have greater effects than substitutions.

## Protein folding

**Protein folding** is the process by which a polypeptide folds into its characteristic three-dimensional structure.

- The folding is determined by the **amino acid sequence** (the primary structure). The R-groups form hydrogen bonds, ionic bonds and disulfide bridges, which hold the shape.
- **Chaperones** are specialised proteins that assist the folding of other proteins, for example by preventing the polypeptide from forming incorrect bonds while folding.

If a protein does not fold correctly, it cannot function. The link back to a gene mutation is direct: a changed base can change an amino acid, which can change the folding and the active site of an enzyme.

## Common mistakes

- Using thymine in mRNA, or uracil in DNA.
- Writing the mRNA by copying the template strand, instead of finding its complement.
- Confusing codon (on mRNA) with anticodon (on tRNA).
- Saying that tRNA "translates" or "reads" DNA. It pairs with mRNA.
- Writing that transcription happens at the ribosome. It happens in the nucleus in eukaryotes.
- Saying introns are "removed from DNA". They are removed from pre-mRNA.
- Forgetting that the stop codon does not code for an amino acid when counting.
- Saying "degenerate" means that the code is faulty.

## Exam technique

- **Work in order.** Write the mRNA first, then split it into triplets, then read the amino acids from the table.
- **Use the table you are given**, and state the amino acid names in the order they are read.
- **Give two parts to a consequence answer.** For a mutation, state the change to the base, the codon and the amino acid, and then the effect on the protein.
- **Name the enzyme.** RNA polymerase for transcription; there is no enzyme named for translation, but ribosomes catalyse peptide bonds.

## Frequently asked questions

**Do I need to learn the codon table?**
No. The specification states that you will not be required to recall specific codons and their amino acids in written papers. Practise using a table.

**What is the difference between a gene and a polypeptide?**
A gene is a length of DNA. A polypeptide is the chain of amino acids that the gene codes for. A protein may contain one or more polypeptides.
