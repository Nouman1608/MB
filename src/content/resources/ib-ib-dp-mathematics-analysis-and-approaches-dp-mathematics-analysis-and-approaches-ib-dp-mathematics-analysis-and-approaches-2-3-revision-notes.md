These notes condense section 2.3 of the IB *Mathematics: analysis and approaches guide* (first assessment 2021): creating a sketch from given information or a context, transferring a graph from a screen to paper, and using technology to graph functions and their sums and differences. It is common to SL and HL. Full explanations and worked examples are in the [2.3 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-3/); exam-style questions are in the [2.3 practice set](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-3-practice/).

## Core recall

- **Draw:** accurate, to scale, plotted points joined smoothly; ruler for straight lines.
- **Sketch:** correct general shape and position, relevant features labelled.
- Both need labelled axes and labelled key features.
- On a restricted domain: closed dot = end included; open dot = end excluded.
- Asymptotes: dashed lines labelled with their equations.
- Graph of f + g: add the heights at each x.
- Zeros of f − g = x-coordinates of the intersections of y = f(x) and y = g(x).
- Sign of f − g shows which graph is higher.

## Key terms

| Term | Meaning |
|---|---|
| Sketch | Shape and relevant features, not to scale |
| Draw | Accurate graph to scale |
| Viewing window | The x and y ranges shown on a GDC screen |
| End point | Point where a graph on a restricted domain stops |
| Asymptote | A line the curve approaches ever more closely |
| Turning point | Local maximum or minimum, where the graph changes direction |
| Sum of functions | (f + g)(x) = f(x) + g(x) |
| Difference of functions | (f − g)(x) = f(x) − g(x) |

## Sketch checklist

Before you leave a graph, tick off in your head:

- axes named;
- x- and y-intercepts;
- maxima and minima with coordinates;
- asymptotes dashed and labelled;
- end points with the right type of dot;
- shape correct between the labelled points (no extra bends);
- graph inside the stated domain only.

## From a context to a graph

| Situation | Shape feature |
|---|---|
| Quantity cannot be negative | Graph stays on or above the horizontal axis |
| Time starts at 0 | Nothing to the left of the vertical axis |
| Change slows down | Curve flattens |
| Approaches a fixed level | Horizontal asymptote at that level |
| Constant rate | Straight line |
| Rises then falls | One maximum |

**Quick example.** A car's value falls by the same percentage each year: start at the purchase price, decrease, flatten, never reach 0, so draw a horizontal asymptote on the t-axis.

## GDC to paper

1. Choose or record the window.
2. Find the key points on the GDC: intercepts, turning points, end values.
3. Mark them on your axes at the right scale.
4. Join them with the shape on the screen.
5. Check the ends: do not let the curve finish at the edge of the window if the domain is wider, or continue if the domain stops.

**Quick example.** For y = x²e^(−x), 0 ≤ x ≤ 5: start (0, 0), maximum (2, 0.541), end (5, 0.168). The curve never returns to the axis inside the domain.

## Sums and differences

- (f + g)(x) at a point: add the two heights. For f(x) = x and g(x) = 1/x, the sum at x = 1 is 2.
- f(x) = g(x) ⇔ (f − g)(x) = 0: find intersections by graphing one difference.
- (f − g)(x) > 0 means f is above g at that x.

## Exam traps

- Missing labels: shape alone rarely earns full marks.
- Solid or unlabelled asymptotes.
- Wrong dot type at end points.
- Sketch continued past the domain, or cut short at the window edge.
- Context graph with an impossible feature (negative time, temperature below the surroundings).
- Zeros of f − g given as y-values.

## Self-test

1. What is the difference between "draw" and "sketch"?
2. A domain is −3 < x ≤ 2. Describe the dots at each end.
3. How should an asymptote be shown?
4. f(x) = x² and g(x) = 3. Find (f + g)(2) and (f − g)(2).
5. The zeros of f − g are x = −1 and x = 4. What do they tell you?
6. (f − g)(x) < 0 for 0 < x < 3. Which graph is higher there?
7. A ball is thrown up and falls to the ground. What shape is its height–time graph?
8. Water drains from a tank at a constant rate. What shape is its volume–time graph?
9. A quantity approaches 50 but never reaches it. What line should appear on the sketch?
10. Why should you write down the viewing window you used?
11. y = x²e^(−x) for 0 ≤ x ≤ 5. Does the graph meet the x-axis anywhere except the origin?
12. A sketch must show f(x) = (x − 2)(x + 1). Which three points should be labelled?

### Answers

1. Draw: accurate and to scale; sketch: correct shape and labelled features, not to scale.
2. Open dot at x = −3, closed dot at x = 2.
3. As a dashed line labelled with its equation.
4. (f + g)(2) = 7; (f − g)(2) = 1.
5. y = f(x) and y = g(x) intersect where x = −1 and x = 4.
6. y = g(x).
7. A curve with a single maximum (a parabola for a simple model), ending at height 0.
8. A straight line with negative gradient, ending at volume 0.
9. A dashed horizontal asymptote at the level 50.
10. It explains the scale and extent of your sketch, and shows the domain you considered.
11. No: x² > 0 and e^(−x) > 0 for 0 < x ≤ 5, so y > 0.
12. (2, 0), (−1, 0) and (0, −2).
