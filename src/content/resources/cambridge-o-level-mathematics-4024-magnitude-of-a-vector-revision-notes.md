These notes summarise section 7.3, Magnitude of a vector, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. Full explanations are in the [magnitude of a vector study guide](/resources/cambridge-o-level-mathematics-4024-magnitude-of-a-vector/), and exam-style questions are in the [magnitude of a vector practice questions](/resources/cambridge-o-level-mathematics-4024-magnitude-of-a-vector-practice/). Column vectors are typed as (x, y), with x on top.

## The one formula

```
|(x, y)| = √(x² + y²)
```

- |**a**| means the magnitude (length) of **a**; |AB| means the length of AB.
- It comes from Pythagoras: the vector is the hypotenuse of a triangle with sides |x| and |y|.
- A magnitude is never negative. Signs of components do not matter after squaring.

## Key terms

| Term | Meaning |
|---|---|
| Magnitude | the length of a vector |
| Modulus signs | the vertical lines in |a| |
| Exact form | a surd answer such as 2√5, not a decimal |
| Surd simplification | √(k²m) = k√m, for example √20 = 2√5 |
| Pythagorean triple | whole numbers with x² + y² = z², such as 5, 12, 13 |
| Scalar multiple rule | |ka| = |k| × |a| |

## Quick values to recognise

| Vector | Magnitude |
|---|---|
| (3, 4), (−3, 4), (4, −3) | 5 |
| (6, −8), (−8, 6) | 10 |
| (5, 12) | 13 |
| (8, 15) | 17 |
| (−9, 12) | 15 |
| (1, 1) | √2 ≈ 1.41 |
| (2, −6) | √40 = 2√10 ≈ 6.32 |

## Method boxes

**Magnitude from two points**

1. AB = B − A, component by component.
2. |AB| = √(x² + y²).

Example: A(2, −3), B(−4, 5) gives AB = (−6, 8) and |AB| = 10.

**Magnitude of a combination**

1. Work out the combined vector first.
2. Then apply the formula.

Example: a = (2, 3), b = (4, −1). a + b = (6, 2), so |a + b| = √40 ≈ 6.32. Compare |a| + |b| = √13 + √17 ≈ 7.73: not the same.

**Unknown component**

1. Write x² + y² = (magnitude)².
2. Solve; expect two answers (±) unless told otherwise.

Examples:

- |(p, 24)| = 25: p² + 576 = 625, p² = 49, p = ±7.
- |(2m, m)| = 10: 4m² + m² = 100, m² = 20, m = ±2√5.

**Equal magnitudes**

1. Square both magnitudes, so the roots disappear.
2. Set the squares equal and solve.

Example: |(3, k)| = |(−1, 5)| gives 9 + k² = 26, so k² = 17 and k = ±√17.

## Simplifying surd magnitudes

Look for the largest square factor under the root.

| Magnitude | Square factor | Simplified |
|---|---|---|
| √20 | 4 | 2√5 |
| √45 | 9 | 3√5 |
| √72 | 36 | 6√2 |
| √200 | 100 | 10√2 |
| √250 | 25 | 5√10 |

A simplified surd is still exact. Only change to a decimal when the question asks for one or does not ask for an exact answer, and then give 3 significant figures.

## Must-know distinctions

| Idea | Do | Do not |
|---|---|---|
| Squaring components | x² + y² | (x + y)² |
| Negative components | (−5)² = 25 | −5² = −25 on a calculator |
| Combined vectors | combine, then find the length | add the separate lengths |
| Scalar multiples | \|ka\| = \|k\| × \|a\| | let the length go negative |
| Unknown component | give both ± values | drop the negative root |
| Comparing lengths | compare x² + y² directly | round each root first |

## Comparing without square roots

To decide which of two vectors is longer, compare x² + y². For (7, −7) and (−9, 4): 49 + 49 = 98 and 81 + 16 = 97, so (7, −7) is very slightly longer. Rounding each root to 1 significant figure would make them look equal.

## Exam traps

- Writing (x + y)² instead of x² + y².
- Typing −8² into a calculator and getting −64.
- Stopping at x² + y² and forgetting the root.
- Assuming |a + b| = |a| + |b|.
- Giving one value of an unknown when two are possible.
- Leaving √20 unsimplified when an exact simplified answer is asked for.
- Rounding before the last step in a longer problem.
- Thinking equal magnitudes mean equal vectors: (7, 1) and (5, 5) both have length √50.

## Self-test

1. Find |(−9, 12)|.
2. Find |(2, −6)| exactly and to 3 significant figures.
3. A is (2, −3) and B is (−4, 5). Find |AB|.
4. c = (1, 2). Find |c| and |4c| in exact form.
5. |(p, 24)| = 25. Find the possible values of p.
6. |(2m, m)| = 10. Find m in exact form.
7. a = (2, 3) and b = (4, −1). Find |a + b| to 3 significant figures.
8. Using question 7, is |a + b| equal to |a| + |b|? Show why.
9. Show that (7, 1) and (5, 5) have the same magnitude. Are they equal vectors?
10. d = (5, −12). Find |−2d|.
11. Find |(10, 24)|.
12. The magnitude of (k, k) is 6√2. Find the positive value of k.

### Answers

1. √(81 + 144) = √225 = **15**.
2. √(4 + 36) = √40 = **2√10 ≈ 6.32**.
3. AB = (−6, 8), so |AB| = **10**.
4. |c| = **√5**; |4c| = **4√5**.
5. p² = 625 − 576 = 49, so **p = 7 or −7**.
6. 5m² = 100, m² = 20, **m = ±2√5**.
7. a + b = (6, 2), |a + b| = √40 ≈ **6.32**.
8. **No**: |a| + |b| = √13 + √17 ≈ 7.73, which is greater than 6.32.
9. 7² + 1² = 50 and 5² + 5² = 50, so both are **√50**. They are **not equal**, because their components differ, so their directions differ.
10. |d| = 13, so |−2d| = 2 × 13 = **26**.
11. √(100 + 576) = √676 = **26**.
12. 2k² = 72, k² = 36, **k = 6**.
