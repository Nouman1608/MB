These notes summarise section 9.1, Classifying statistical data, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. The syllabus wording is "classify and tabulate statistical data", with tally tables and two-way tables as examples. For worked explanations, read the [classifying statistical data study guide](/resources/cambridge-o-level-mathematics-4024-classifying-statistical-data/); for exam-style work, use the [classifying statistical data practice questions](/resources/cambridge-o-level-mathematics-4024-classifying-statistical-data-practice/).

## Key terms

| Term | Meaning |
|---|---|
| Raw data | data as collected, before it is organised |
| Categorical data | labels or words, such as colour or country |
| Numerical data | numbers that are counted or measured |
| Discrete data | counted; only separate values, such as 0, 1, 2 or shoe sizes |
| Continuous data | measured; any value in a range, such as time or length |
| Tally | strokes in groups of five, the fifth across the other four |
| Frequency | how many times a value or class occurs |
| Class | a group of values in a grouped table |
| Class boundary | the value where one continuous class ends and the next begins |
| Two-way table | a table classifying items by two features, with row and column totals |

## Classification test

- **Counted** → discrete. **Measured** → continuous. **Words or labels** → categorical.
- Shoe size: discrete (half sizes exist but nothing between them).
- Age, time, mass, height, temperature: continuous.
- Number of people, cars, goals: discrete.
- Money: usually treated as discrete (steps of one cent).
- Shirt numbers, phone numbers, postcodes: categorical, as the numbers are labels.

## Rules for classes

- Continuous: write classes with inequalities, such as 20 ≤ m < 30, 30 ≤ m < 40.
- Each value must fit **exactly one** class: no gaps, no overlaps.
- A value on a boundary, such as m = 30, goes in the class that includes it (30 ≤ m < 40).
- Discrete: classes such as 0–9, 10–19 are fine, because nothing lies between 9 and 10.
- Use sensible, usually equal, widths and enough classes to show a pattern.
- Grouping hides exact values, so later calculations from the table are estimates.

## Method: tally to frequency

1. Draw the table with a value or class column, a tally column and a frequency column.
2. Work through the raw data once, in order, ticking off each value.
3. Count each tally into a frequency.
4. Add the frequencies and compare with the number of items.

## Method: completing a two-way table

1. Copy every given number into its cell, including totals.
2. Find any row or column with one gap; fill it by subtraction.
3. Repeat until the table is full.
4. Check every row and column adds up, and that the row totals and column totals both reach the grand total.

### Example

80 people in a café: 45 are adults. 30 drink coffee, 20 of them adults. 15 drink neither, 6 of them adults. 16 children drink tea.

| | Coffee | Tea | Neither | Total |
|---|---|---|---|---|
| Adults | 20 | 19 | 6 | 45 |
| Children | 10 | 16 | 9 | 35 |
| Total | 30 | 35 | 15 | 80 |

Order used: children total 80 − 45 = 35; children coffee 30 − 20 = 10; children neither 15 − 6 = 9; adults tea 45 − 20 − 6 = 19; tea total 19 + 16 = 35.

## Fractions from a two-way table

| Question wording | Which total |
|---|---|
| "What fraction of the adults drink tea?" | adults total: 19/45 |
| "What fraction of the tea drinkers are adults?" | tea total: 19/35 |
| "What fraction of all the people are adults who drink tea?" | grand total: 19/80 |

Read the words after "of the" to find the total you divide by.

## Grouping examples

| Data | Good classes | Why |
|---|---|---|
| Marks out of 50 (discrete) | 0–9, 10–19, 20–29, 30–39, 40–50 | whole numbers only, so no gaps |
| Times in seconds (continuous) | 0 ≤ t < 10, 10 ≤ t < 20, ... | every possible time has one class |
| Heights in cm (continuous) | 150 ≤ h < 155, 155 ≤ h < 160, ... | narrow classes keep the detail |

Too few classes hide the pattern; too many leave most classes nearly empty. A grouped table must still show the total number of items.

## Exam traps

- Calling age discrete because it is given in whole years.
- Classes such as 10–20, 20–30 for continuous data.
- A boundary value placed in the lower class.
- Not checking the frequency total.
- Using the wrong total for a fraction from a two-way table.
- Forgetting to fill the total cells, which are part of "complete the table".

## Self-test

1. Classify: (a) the number of pages in a book, (b) the time to read it, (c) its genre.
2. Is shoe size discrete or continuous? Explain.
3. Why is a player's shirt number categorical?
4. Which class does m = 40 belong to: 30 ≤ m < 40 or 40 ≤ m < 50?
5. What is wrong with the classes 0–10, 10–20, 20–30 for lengths in centimetres?
6. A tally shows IIII IIII III. What is the frequency?
7. A frequency table has frequencies 7, 12, 9 and x for 40 items. Find x.
8. In the café table above, how many children drink coffee?
9. What fraction of the tea drinkers are children?
10. What percentage of all the people drink neither?
11. Why can you not find the exact number of journeys over 22 minutes from the class 20 ≤ t < 25?
12. In a two-way table, the boys' row reads 14, x, 9 with total 35. Find x.

### Answers

1. (a) **discrete**, (b) **continuous**, (c) **categorical**.
2. **Discrete**: only certain sizes (such as 6, 6½, 7) exist, with nothing between them.
3. The number is a **label**; arithmetic on it has no meaning.
4. **40 ≤ m < 50**.
5. They **overlap** at 10 and 20, so those values have two possible classes.
6. **13**.
7. x = 40 − 28 = **12**.
8. **10**.
9. **16/35**.
10. 15/80 = **18.75%**.
11. Grouping hides the **exact values** within the class.
12. x = 35 − 14 − 9 = **12**.
