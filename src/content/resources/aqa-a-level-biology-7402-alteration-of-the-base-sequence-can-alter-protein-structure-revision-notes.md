These notes condense section 3.8.1 of the AQA AS and A-level Biology specification (7401/7402), for first teaching 2015: *Alteration of the sequence of bases in DNA can alter the structure of proteins* (A-level only). For full explanations and longer worked examples, use the [study guide on base sequence and protein structure](/resources/aqa-a-level-biology-7402-alteration-of-the-base-sequence-can-alter-protein-structure/). Then try the [practice questions on base sequence and protein structure](/resources/aqa-a-level-biology-7402-alteration-of-the-base-sequence-can-alter-protein-structure-practice/).

## The section in six lines

1. Gene mutations might arise during DNA replication.
2. Six types: addition, deletion, substitution, inversion, duplication, translocation of bases.
3. They occur spontaneously; mutagenic agents increase the mutation rate.
4. They can give a different amino acid sequence in the encoded polypeptide.
5. A change to one triplet may not change the amino acid: the code is degenerate.
6. Some mutations change every triplet downstream: a frame shift.

## Key terms

| Term | Meaning to learn |
|---|---|
| Gene mutation | A change in the base sequence of DNA |
| Triplet | Three bases in DNA coding for one amino acid; read non-overlapping |
| Degenerate code | Most amino acids have more than one triplet |
| Frame shift | Every triplet after the mutation changes, because bases added or lost are not a multiple of three |
| Mutagenic agent | Something that increases the rate of mutation, such as ionising radiation, UV light or certain chemicals |
| Spontaneous mutation | A mutation from errors in normal processes such as replication, with no outside agent |
| Template strand | The DNA strand that RNA polymerase reads; mRNA is complementary to it |
| Coding strand | The other DNA strand; same sequence as mRNA, with T for U |
| Primary structure | The sequence of amino acids in a polypeptide |
| Tertiary structure | The 3D folding held by hydrogen bonds, ionic bonds and disulfide bridges |

## The six types at a glance

| Type | Bases in the gene | Frame shift? |
|---|---|---|
| Substitution | Same number | No: one triplet changes |
| Addition | More | Yes, unless a multiple of three is added |
| Deletion | Fewer | Yes, unless a multiple of three is lost |
| Duplication | More | Yes, unless the repeat is a multiple of three |
| Inversion | Same number | No, but triplets in the reversed section can change |
| Translocation | Fewer at one site, more at the other | Possible at either site |

## How mutations arise

- During replication, a wrong base can be paired and joined into the new strand, or a base can be missed or added.
- The next round of replication copies the error into both new molecules, so it becomes permanent.
- Ionising radiation can break DNA strands.
- UV light and some chemicals alter bases so they pair wrongly.
- Mutagens raise the overall rate; they do not choose a gene.

## Five outcomes of a change to one triplet

Worked reminder. mRNA: AUG UCA GGA UAC CAG AUU UAA gives Met-Ser-Gly-Tyr-Gln-Ile, then stop. Codons supplied: UAU Tyr; CAC His; UAA stop; GAU Asp; ACC Thr; AGA Arg; UUU Phe.

| Change | Result | Outcome |
|---|---|---|
| UAC to UAU | Tyr to Tyr | Silent: degenerate code |
| UAC to CAC | Tyr to His | One amino acid different |
| UAC to UAA | Tyr to stop | Polypeptide only Met-Ser-Gly |
| Delete first G of GGA | AUG UCA GAU ACC AGA UUU AA | Met-Ser-Asp-Thr-Arg-Phe: frame shift, original stop lost |
| Add three bases between codons | One extra codon | One extra amino acid; frame kept |

## The chain to write

Base sequence changes → mRNA codon changes → different amino acid (or stop) → primary structure changes → different R group forms different hydrogen bonds, ionic bonds or disulfide bridges → tertiary structure changes → active site (or binding site) changes shape → substrate no longer complementary → fewer or no enzyme-substrate complexes.

Use every arrow in a long answer. Each link is usually a marking point.

## Why some mutations have little or no effect

- Degenerate code: the new triplet codes for the same amino acid. Third-base changes are most often silent.
- The mutation is in an intron, which is removed by splicing before translation.
- The new amino acid has an R group with similar properties, so the same bonds form.
- The change is away from the active site or binding site and does not alter folding there.
- An addition or deletion of three bases adds or removes one amino acid without a frame shift.

## Why some mutations have a large effect

- Frame shift near the start of a gene: almost every amino acid changes.
- A new stop codon early in the sequence: a short, non-functional polypeptide.
- Loss of a stop codon: extra amino acids are added.
- A change to cysteine: a disulfide bridge may be lost or gained.
- A change from a charged to a hydrophobic R group, or the reverse: ionic bonds and folding change.

## Reading questions: three checks

1. Is the strand given template, coding or mRNA? Convert to mRNA first.
2. How many bases are added or lost? Divide by three to decide on a frame shift.
3. Which triplet number is affected? Count from the start codon, three bases at a time.

## Exam traps

- Calling a substitution a frame shift.
- Saying "the mutation changes the protein" with no reference to amino acids or bonds.
- Writing that the active site is "destroyed". Say it changes shape so the substrate is no longer complementary.
- Using the template strand directly in an mRNA codon table.
- Saying mutagens "cause mutations in genes for cancer". They increase the rate of mutation generally.
- Forgetting that a mutation in a non-coding region may have no effect on the polypeptide.
- Assuming a deletion of three bases always removes one whole codon. If the three bases span two codons, two codons change into one new one, but the frame is still kept.

## Quick self-test

1. Name the six types of gene mutation in the specification.
2. When in the cell cycle might a gene mutation arise?
3. What does a mutagenic agent do?
4. Define a frame shift.
5. Why might a substitution not change the polypeptide?
6. A template strand reads TAC GGA. Give the mRNA.
7. Which mutation type keeps the number of bases the same but reverses a section?
8. Why is a frame shift near the start of a gene usually more harmful than one near the end?
9. A substitution changes a codon for cysteine to a codon for serine. Suggest why the protein may stop working.
10. Give two reasons why a mutation in DNA might not change the polypeptide at all.
11. How many bases must be deleted to remove one amino acid without a frame shift?
12. A mutation changes UAA to UAC. State the effect on the polypeptide.

### Answers

1. Addition, deletion, substitution, inversion, duplication, translocation.
2. During DNA replication (in interphase).
3. Increases the rate of mutation.
4. A mutation that changes every base triplet downstream of it, because the number of bases added or lost is not a multiple of three.
5. The code is degenerate, so the new triplet may code for the same amino acid.
6. AUG CCU.
7. Inversion.
8. More of the triplets lie downstream, so more amino acids change.
9. Serine cannot form a disulfide bridge, so a bridge holding the tertiary structure may be lost and the protein may fold differently.
10. Any two from: degenerate code; mutation in an intron; mutation in other non-coding DNA.
11. Three (or a multiple of three).
12. The stop codon is lost, so translation continues and the polypeptide is longer.

## Frequently asked questions

**What is the difference between the coding strand and the template strand?**
RNA polymerase reads the template strand, so mRNA is complementary to it. The coding strand has the same sequence as the mRNA, with T in place of U.
