This guide covers the correction of errors, outcomes 1.2.5 to 1.2.9 of Topic 2: Control Procedures in Unit 1 (The Accounting System and Costing) of the Pearson Edexcel International Advanced Subsidiary/Advanced Level in Accounting (YAC11), Specification Issue 2, September 2018. It is International AS content. Amounts are in dollars and the businesses are invented.

Use it with the [correction of errors revision notes](/resources/edexcel-a-level-accounting-yac11-correction-of-errors-revision-notes/) and the [correction of errors practice questions](/resources/edexcel-a-level-accounting-yac11-correction-of-errors-practice/). The trial balance itself is in the [trial balance guide](/resources/edexcel-a-level-accounting-yac11-trial-balance/), and building a control account from scratch is in the [control accounts guide](/resources/a-level-edexcel-accounting-control-accounts-and-correction-of-errors/).

## What the specification asks for

| Outcome | Wording |
|---|---|
| 1.2.5 | The errors that do and do not affect the balancing of the trial balance |
| 1.2.6 | Journal entries to correct errors |
| 1.2.7 | The suspense account |
| 1.2.8 | Statements of revised profit |
| 1.2.9 | Correction of errors in control accounts |

In exam questions these five outcomes usually arrive together: one list of errors, then journals, a suspense account and a revised profit figure. Treat them as one process.

## One test for 1.2.5

Ask a single question of every error: **were equal amounts posted to the debit side and the credit side?**

- **Yes**, even if to the wrong accounts or for the wrong (but equal) amount: the trial balance still agrees. No suspense entry.
- **No**: the totals differ, and the correction must pass through the suspense account.

This test handles cases that do not fit a named type. A cheque from a customer debited to bank **and** debited to the customer's account puts 1,200 more on the debit side than the credit side for a 600 cheque, so it affects the balancing even though both "sides" were posted.

## Writing correcting journals (1.2.6)

Lay out what happened before you write the journal. The correction is what turns the first line into the second.

| | Debit | Credit |
|---|---|---|
| What was done | Bank 600, Trade receivables 600 | — |
| What should have been done | Bank 600 | Trade receivables 600 |
| Correction | Suspense 1,200 | Trade receivables 1,200 |

The bank entry was right, so it is not touched. The receivables account needs 1,200 on the credit side: 600 to cancel the wrong debit and 600 for the missing credit. The imbalance is made up from suspense.

Each journal has the date, the account debited, the account credited, the amounts and a **narrative** saying what is being corrected. Never alter or erase the original entry.

## Worked example 1: journals, suspense and revised profit

Morven Electrical keeps receivables and payables control accounts in its general ledger. Its trial balance at 31 March 2026 did not agree: debits exceeded credits by 1,060, which was entered in a suspense account. Profit for the year was first calculated as 38,420. These errors were then found:

1. The sales day book for March was overcast by 1,000.
2. Rent of 1,450 was correctly credited to bank but debited to rent as 1,540.
3. Discount received of 230 was credited to discount received but not debited to the trade payables control account.
4. Shop fittings costing 2,800, paid by bank transfer, were debited to purchases.
5. A cheque for 600 from a customer was debited in the bank account and also debited in the trade receivables control account.

**Journal**

| | Account | Dr | Cr |
|---|---|---:|---:|
| 1 | Revenue | 1,000 | |
| | Trade receivables control | | 1,000 |
| | *Correction of overcast sales day book* | | |
| 2 | Suspense | 90 | |
| | Rent | | 90 |
| | *Rent of 1,450 debited as 1,540* | | |
| 3 | Trade payables control | 230 | |
| | Suspense | | 230 |
| | *Debit entry for discount received omitted* | | |
| 4 | Shop fittings | 2,800 | |
| | Purchases | | 2,800 |
| | *Capital expenditure debited to purchases* | | |
| 5 | Suspense | 1,200 | |
| | Trade receivables control | | 1,200 |
| | *Cheque received debited instead of credited* | | |

Error 1 needs no suspense entry: the day book total was posted to both the control account (debit) and revenue (credit), so both were overstated equally. Error 4 is an error of principle and also balances.

**Suspense account**

| Dr | $ | Cr | $ |
|---|---:|---|---:|
| Rent | 90 | Difference per trial balance | 1,060 |
| Trade receivables control | 1,200 | Trade payables control | 230 |
| | **1,290** | | **1,290** |

The opening entry is a **credit** because the credit column was short. The account closes with no balance, which confirms the three suspense errors explain the whole difference: 90 + 1,200 − 230 = 1,060.

**Statement of revised profit for the year ended 31 March 2026**

| | Increase | Decrease | $ |
|---|---:|---:|---:|
| Profit for the year as first calculated | | | 38,420 |
| 1 Revenue overstated | | 1,000 | |
| 2 Rent overstated | 90 | | |
| 4 Purchases overstated | 2,800 | | |
| | **2,890** | **1,000** | **+1,890** |
| **Revised profit for the year** | | | **40,310** |

Errors 3 and 5 change only statement of financial position accounts, so they do not affect profit. Gross profit rises by 2,800 − 1,000 = 1,800, because revenue and purchases are trading items; the rent correction affects profit for the year only. If the question gave a depreciation rate, the shop fittings would also need a depreciation charge, which would reduce the revised profit; without one, make no adjustment.

## Worked example 2: correcting a control account and the list (1.2.9)

Kestrel Hardware's trade receivables control account shows 18,640, but its list of customer balances totals 18,250. Errors found:

- (i) A customer's credit balance of 75 was included in the list as a debit balance.
- (ii) The sales returns day book was undercast by 200.
- (iii) An irrecoverable debt of 340 was written off in the customer's account but not recorded in the general ledger.
- (iv) A credit sale invoice of 520 was omitted from the sales day book.

First decide where each error sits. The individual customer accounts are posted from each document; the control account and the general ledger accounts are posted from day book totals.

| Error | Control account | List of balances | Profit |
|---|---|---|---|
| (i) | Not affected | −150 (remove the debit 75 and treat it as a credit 75) | None |
| (ii) | −200 | Not affected | −200 (sales returns understated) |
| (iii) | −340 | Not affected (already written off) | −340 (expense missing) |
| (iv) | +520 | +520 | +520 (revenue missing) |

**Corrected trade receivables control account**

| Dr | $ | Cr | $ |
|---|---:|---|---:|
| Balance per books | 18,640 | Sales returns | 200 |
| Revenue | 520 | Irrecoverable debts | 340 |
| | | Balance c/d | 18,620 |
| | **19,160** | | **19,160** |

**Corrected list:** 18,250 − 150 + 520 = **18,620**, which now agrees.

None of these errors needs suspense. In (ii) the undercast total was posted to both the sales returns account and the control account, so both were wrong by the same amount; in (iii) and (iv) neither side of the general ledger entry was made. An error of the kind in Worked example 1, such as a discount posted to the control account as a different amount from the discount account, would involve suspense.

## Common mistakes

- Opening suspense on the long side of the trial balance instead of the short side.
- Sending an error of principle or a day book casting error through suspense.
- Correcting a double debit with the original amount instead of twice it.
- Adjusting the list of balances for an error that sits only in the control account, or the reverse.
- Changing profit for a correction between two statement of financial position accounts, such as receivables and bank.
- Writing journals with no narratives when the question asks for them.

## Exam technique for the command words

- **Identify** (whether an error affects the balancing): a verdict for each error is enough, but checking it with the equal-amounts test avoids guessing.
- **Prepare** (journal entries, a suspense account, a statement of revised profit): use the standard format, with narratives for journals and a closing total that shows suspense clears.
- **Calculate** (revised profit): show the starting figure and each adjustment with its direction.
- **Explain** (why an error did not affect the trial balance): state that equal debits and credits were posted and link this to the specific error.
