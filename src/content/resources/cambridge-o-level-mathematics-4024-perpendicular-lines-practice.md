These questions cover section 3.7, Perpendicular lines, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. The method is explained in the [perpendicular lines study guide](/resources/cambridge-o-level-mathematics-4024-perpendicular-lines/), and the [coordinate geometry revision notes](/resources/o-level-mathematics-coordinate-geometry-revision-notes/) summarise it. Show your working.

## Section A

**1.** Write down the gradient of a line perpendicular to y = 5x + 2. **[1]**

**2.** Find the gradient of a line perpendicular to 4x + 3y = 6. **[2]**

**3.** Find the equation of the line perpendicular to y = −2/3 x + 1 that passes through (0, 4). **[2]**

**4.** Find the equation of the line perpendicular to y = 4x − 1 that passes through (8, 5). **[3]**

**5.** Show that the lines y = 2x + 3 and x + 2y = 8 are perpendicular. **[2]**

**6.** Find the equation of the line perpendicular to 3x − 5y = 10 that passes through (6, −2). Give your answer in the form ax + by = c, where a, b and c are integers. **[3]**

## Section B

**7.** A is the point (−3, 2) and B is the point (5, 6).

**(a)** Find the midpoint of AB.

**(b)** Find the gradient of AB.

**(c)** Find the equation of the perpendicular bisector of AB. **[5]**

**8.** P is (−1, 0), Q is (3, 2) and R is (1, 6).

**(a)** Show that angle PQR is a right angle.

**(b)** Find the area of triangle PQR. Give your answer in square units. **[5]**

**9.** The line 3x + ky = 7 is perpendicular to the line y = 2x − 5. Find the value of k. **[3]**

**10.** The line l has equation y = 2x + 1.

**(a)** Find the equation of the line through (7, 0) that is perpendicular to l.

**(b)** Find the coordinates of the point where the two lines meet.

**(c)** Hence find the shortest distance from (7, 0) to l, giving your answer to 3 significant figures. **[6]**

**11.** Write down the equation of the line through (2, −1) that is perpendicular to the line x = 5. **[2]**

**12.** A is (2, 1), B is (6, 3) and C is (k, 7). The line AB is perpendicular to BC. Find the value of k. **[3]**

## Answers

**1.** The gradient is **−1/5** [1].

**2.** 3y = −4x + 6, so y = −4/3 x + 2 and the gradient is −4/3 [1]. The perpendicular gradient is **3/4** [1].

**3.** The given gradient is −2/3, so the perpendicular gradient is 3/2 [1]. The point (0, 4) is on the y-axis, so c = 4 and **y = 3/2 x + 4** [1].

**4.** The perpendicular gradient is −1/4 [1]. 5 = −1/4(8) + c, so 5 = −2 + c [1]. c = 7, so **y = −1/4 x + 7** [1].

**5.** The first gradient is 2 [1]. x + 2y = 8 gives y = −1/2 x + 4, with gradient −1/2. The product 2 × (−1/2) = −1, so the lines are perpendicular [1].

**6.** 5y = 3x − 10, so the gradient is 3/5 [1]. The perpendicular gradient is −5/3, so y + 2 = −5/3(x − 6) [1]. Then 3y + 6 = −5x + 30, giving **5x + 3y = 24** [1].

*Examiner insight:* Check with the point: 5(6) + 3(−2) = 24.

**7. (a)** Midpoint = ((−3 + 5)/2, (2 + 6)/2) = **(1, 4)** [1].

**(b)** Gradient = (6 − 2)/(5 − (−3)) = 4/8 = **1/2** [1].

**(c)** The perpendicular gradient is −2 [1]. y − 4 = −2(x − 1) [1], so **y = −2x + 6** [1].

**8. (a)** Gradient of PQ = (2 − 0)/(3 + 1) = 1/2 [1]. Gradient of QR = (6 − 2)/(1 − 3) = −2 [1]. The product is −1, so angle PQR = 90° [1].

**(b)** PQ = √(16 + 4) = √20 and QR = √(4 + 16) = √20 [1]. Area = 1/2 × √20 × √20 = 1/2 × 20 = **10** square units [1].

**9.** 3x + ky = 7 gives y = −3/k x + 7/k, so its gradient is −3/k [1]. The perpendicular gradient to 2 is −1/2, so −3/k = −1/2 [1]. **k = 6** [1].

**10. (a)** The perpendicular gradient is −1/2, so y = −1/2(x − 7) = −x/2 + 7/2 [1][1].

**(b)** 2x + 1 = −x/2 + 7/2 [1], so 5x/2 = 5/2, x = 1 and y = 3, giving **(1, 3)** [1].

**(c)** Distance from (7, 0) to (1, 3) = √(36 + 9) = √45 [1] = **6.71** [1].

**11.** The line x = 5 is vertical [1], so the perpendicular line is horizontal: **y = −1** [1].

**12.** The gradient of AB = (3 − 1)/(6 − 2) = 1/2, so BC needs gradient −2 [1]. The gradient of BC = (7 − 3)/(k − 6) = 4/(k − 6) [1]. 4/(k − 6) = −2, so k − 6 = −2 and **k = 4** [1].

## Where marks are usually lost

- Turning the gradient upside down but not changing the sign.
- Using the gradient of the segment as the gradient of the perpendicular bisector.
- Using an end point rather than the midpoint for the bisector.
- Mistaking the gradient of an equation such as 4x + 3y = 6 for 4 or 4/3.
- Forgetting that a vertical line x = a is perpendicular to a horizontal line.
