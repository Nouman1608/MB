## Section A

**1.** Name the type of malware that locks a user's files until a payment is made. **[1]**

**2.** State what is meant by hacking. **[1]**

**3.** State what is meant by a brute-force attack. **[1]**

**4.** Name **two** methods of authentication. **[2]**

**5.** State the purpose of a firewall. **[1]**

**6.** Name the security protocol that encrypts data sent between a web browser and a web server. **[1]**

**7.** State what is meant by social engineering. **[1]**

## Section B

**8.** Describe the difference between a virus and a worm. **[2]**

**9.** Describe what is meant by spyware and state its aim. **[2]**

**10.** An online shop's website is slowed down and then stops responding because it receives a very large number of requests from thousands of infected computers at the same time.

**(a)** Name this type of attack. **[1]**

**(b)** Explain the aim of the attacker. **[2]**

**(c)** Suggest **one** solution the shop could use to reduce the effect of the attack, and explain how it helps. **[2]**

**11.** A user types the correct web address of her bank into her browser, but a fake website that looks identical to the bank's site is displayed.

**(a)** Name this threat. **[1]**

**(b)** Describe how this threat works. **[2]**

**(c)** State **one** way to help avoid being a victim of this threat. **[1]**

**12.** An employee receives an email with the subject "URGENT: your account will be closed". It asks him to click a link to confirm his password. The email contains several spelling mistakes.

**(a)** Name the threat. **[1]**

**(b)** Explain **two** things the employee should check before clicking the link. **[4]**

**13.** A company stores customer records on a network. Explain how access levels help to keep the records safe. **[3]**

**14.** A website allows users to log in using a username, a password and a code that is sent to the user's mobile phone.

**(a)** Name this type of authentication. **[1]**

**(b)** Explain why it is more secure than using only a username and password. **[2]**

**15.** A hospital uses a fingerprint scanner to let staff enter the records room.

**(a)** Name the type of authentication. **[1]**

**(b)** Give **one** advantage and **one** disadvantage of this type of authentication. **[2]**

**16.** A student uses public Wi-Fi in a café to log in to an online shop. Explain the threat to the student's data and how SSL helps. **[4]**

**17.** Explain why a user should turn on automatic software updates to help protect a computer from malware. **[3]**

## Answers

**1.** Ransomware [1].

**2.** Gaining unauthorised access to a computer system [1].

**3.** Using software to try a very large number of possible passwords or keys until the correct one is found [1].

**4.** Any two: username and password; biometrics; two-step verification [1 each].

**5.** To examine the traffic going into and out of a network and block anything that does not meet the rules [1].

**6.** SSL (secure socket layer) [1].

**7.** Manipulating people so that they give away information or carry out an action that helps the attacker [1].

**8.** A virus attaches itself to a file or program and spreads when the infected file is run or shared [1], whereas a worm spreads by itself across a network without needing a host file or action from the user [1].

**9.** Software that secretly records what the user does, for example the keys pressed [1]. Its aim is to collect private information such as passwords or card details and send it to the attacker [1].

**10. (a)** Distributed denial of service (DDoS) attack [1].
**(b)** The attacker wants to make the website unavailable to genuine customers [1], for example to cause the shop to lose sales or to demand money to stop the attack [1].
**(c)** A firewall [1], which can examine the incoming traffic and block requests that come from suspicious sources [1]. Or a proxy server [1], which can filter the traffic before it reaches the web server [1].

**11. (a)** Pharming [1].
**(b)** Malicious code on the user's computer (or a changed DNS record) redirects the browser to a fake website, even though the correct address was typed [1]. The fake site looks real so that the user enters her login or payment details, which are captured [1].
**(c)** Any one: use anti-malware software; keep software updated; check the URL and the padlock before entering details [1].

**12. (a)** Phishing [1].
**(b)** Any two checks, each with a reason: the spelling and tone of the message [1], because mistakes or an urgent, threatening tone suggest the email is not genuine [1]; the URL attached to the link [1], because a fake link will go to a web address that does not match the real company's [1]; whether the sender's address matches the company [1], because a fake sender will use a different domain [1]. Maximum 4.

**13.** Different users are given different levels of access to the data, for example read only, edit or full control [1]. Staff can only see or change the records they need for their job [1], so there is less risk of accidental changes, of data being copied or deleted by insiders, or of a hacker using a low-level account to reach everything [1].

**14. (a)** Two-step verification [1].
**(b)** A person who steals the password would also need the code sent to the user's phone [1], so the password alone is not enough to gain access [1].

**15. (a)** Biometrics [1].
**(b)** Advantage (one): hard to copy or guess; the person cannot forget or lose it; it cannot be shared easily. Disadvantage (one): needs special hardware; may fail to recognise a staff member (for example a cut or dirty finger); cannot be changed if copied. [1 for an advantage, 1 for a disadvantage]

**16.** On public Wi-Fi, the data sent to the shop could be intercepted by someone else on the network [1], who could read the login details or card numbers [1]. SSL encrypts the data between the browser and the shop's server [1], so any data that is intercepted is meaningless to the interceptor [1].

**17.** Software updates include security patches that close weaknesses in the software [1]. Malware often uses known weaknesses to get into a computer [1]. If updates are installed automatically, the weaknesses are fixed soon after the patch is released without relying on the user to remember [1].

## Where marks are usually lost

- Question 1: writing "virus". Ransomware demands payment.
- Question 8: saying a worm is "worse". Describe how each one spreads.
- Question 10 (c): naming anti-virus software, which does not filter traffic.
- Question 11: writing "phishing" for a threat that redirects automatically.
- Question 12 (b): naming a check without saying why it helps.
- Question 13: saying that access levels "stop hackers" without saying what each level allows.
- Question 15 (b): saying biometrics "cannot be hacked". Choose a clear, specific advantage and disadvantage.
- Question 16: saying SSL "stops interception". It makes intercepted data meaningless.

## Checking a threat answer

Underline the words in the scenario that show how the attack arrived (an email, a redirect, a flood of requests, a file). The method of arrival usually identifies the threat.
