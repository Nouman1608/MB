## Section B: structured questions

**7.** A café menu lists items and prices like this:

| Item | Price |
|---|---|
| Soup | 4.5 |
| Sandwich | 6.25 |
| Fruit platter | 12.75 |

**(a)** Name the most appropriate type of tab stop for the prices and explain why. **[2]**

**(b)** A student lines up the prices by pressing the space bar. Explain why this is a poor method. **[2]**

**8.** A report must have body text with 1.5 line spacing and 12 pt spacing after each paragraph.

**(a)** Explain the difference between these two settings. **[2]**

**(b)** The student presses Enter twice at the end of each paragraph to create the space. Give **two** reasons why this is not acceptable. **[2]**

**9.** A science worksheet contains the text: "The volume of the tank is 2 m3 and it holds water, H2O."

Describe how each of the two numbers should be formatted. **[2]**

**10.** A student has a heading typed as "health and safety in the workshop".

**(a)** Give the heading after applying capitalise each word. **[1]**

**(b)** Give the heading after applying sentence case. **[1]**

**(c)** Explain why the student should use the change case tool rather than retyping the heading. **[1]**

**11.** A reference list must use a hanging indent of 1.25 cm.

Describe how the student should set this and explain why it suits a reference list. **[3]**

**12.** A numbered list of instructions has seven items. The teacher asks for a new item to be added between items 3 and 4, and for the list to use lower-case letters instead of numbers.

**(a)** Explain why the numbering should be automatic rather than typed. **[2]**

**(b)** State what the label of the new item will be after both changes. **[1]**

**13.** A contents page lists chapter titles on the left and page numbers at the right margin. Describe how tab stops should be used to set this out. **[2]**

## Answers

**1.** 1.5 lines (1); double (1). **[2]**

**2.** B: the 2 in H2O. **[1]**

**3.** Right tab. **[1]**

**4.** OPENING TIMES. **[1]**

**5.** The first line of the paragraph starts at the left margin (1) and all following lines are indented further in (1). **[2]**

**6.** When the order of the items matters, for example steps to follow, or when items are ranked. **[1]**

**7. (a)** Decimal tab (1); the prices have different numbers of digits and decimal places, and a decimal tab lines them up on the decimal point so units, tens and decimals are in columns (1). **[2]**

**(b)** Spaces have different widths in proportional fonts, so the prices will not line up exactly (1); if a price or item changes length, the spaces must all be adjusted by hand (1). **[2]**

**8. (a)** Line spacing (1.5) is the distance between the lines within each paragraph (1); spacing after (12 pt) is the gap below each paragraph, separating it from the next (1). **[2]**

**(b)** Any two: the gap is not 12 pt, because an empty line takes its height from the font and line spacing (1); empty paragraphs can end up at the top of a page when text moves (1); the spacing may become inconsistent if some paragraphs have two empty lines and some one (1); it does not meet the instruction to use paragraph spacing (1). **[2]**

**9.** The 3 in m3 should be superscript, giving m³ (1); the 2 in H2O should be subscript, giving H₂O (1). **[2]**

**10. (a)** Health And Safety In The Workshop. **[1]**

**(b)** Health and safety in the workshop. **[1]**

**(c)** It is quicker and avoids introducing spelling errors by retyping. **[1]**

**11.** Select the reference list (1) and, in the paragraph settings, choose a hanging indent with a value of 1.25 cm (or drag the hanging indent marker on the ruler) (1). It suits a reference list because the first line of each entry stands out at the margin, so each reference is easy to find (1). **[3]**

**12. (a)** Automatic numbering updates the numbers of later items when an item is inserted (1), whereas typed numbers would all need retyping from item 4 onwards, which is slow and error-prone (1). **[2]**

**(b)** d **[1]**

**13.** Use a left tab (or the margin) for the chapter titles (1) and a right tab at the right margin so that the page numbers line up at their right-hand edge (1). **[2]**

## Frequently asked questions

**Is 1.5 line spacing the same as 150 per cent?**
Yes, 1.5 lines means one and a half times single spacing. Choose the 1.5 lines option, or multiple with a value of 1.5.

**Does the syllabus include leader dots on tab stops?**
The format text guidance names left, right, centred and decimal tabs, indented paragraphs and hanging paragraphs. Make sure you can use these four tab types first.
