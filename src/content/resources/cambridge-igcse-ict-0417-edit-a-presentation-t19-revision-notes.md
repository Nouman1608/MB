These notes condense the "Edit a presentation" content row of Cambridge IGCSE ICT 0417 Topic 19. The full explanation, with a worked example of slide numbers changing during edits, is in the [Edit a presentation study guide](/resources/cambridge-igcse-ict-0417-edit-a-presentation-t19/). Test yourself with the [Edit a presentation practice questions](/resources/cambridge-igcse-ict-0417-edit-a-presentation-t19-practice/), and see the [Presentations revision notes](/resources/cambridge-igcse-ict-presentations-revision-notes/) for the whole topic.

## Syllabus checklist

- Apply slide layout; insert a new slide; move or delete a slide.
- Insert and edit objects: text (headings, subheadings, bulleted lists), images (still images, video clips, animated images), charts, tables, audio clips, symbols, lines, arrows, call out boxes, shapes.
- Add presenter notes.
- Insert and edit a hyperlink from text or an object to a slide in the presentation, an external file or an email address.
- Insert an action button and modify its settings to go to a specified slide or file.
- Add alternative text or a screentip to an object.
- Apply consistent transitions and consistent animation effects.
- Hide slides.

## Key terms

| Term | Meaning |
|---|---|
| Slide layout | The arrangement of placeholders on a slide |
| Placeholder | A reserved box for a title, text, image, chart or table |
| Animated image | An image file (often GIF) containing frames that play as movement |
| Call out box | A shape with a pointer used to label part of a slide |
| Presenter notes | Notes for the speaker attached to a slide, not shown to the audience on screen |
| Hyperlink | Text or an object that, when clicked, goes to another slide, a file or an email address |
| Action button | A ready-made button shape whose settings decide what happens when clicked |
| Alternative text | A description of an object for screen readers and for when it cannot be displayed |
| Screentip | Text shown when the pointer hovers over a hyperlink or object |
| Transition | The effect when one slide changes to the next |
| Animation | An effect on an object within a slide, such as text entering |
| Hidden slide | A slide kept in the file but skipped in the slide show |

## Slide operations: what changes

| Action | Slide count | Numbering |
|---|---|---|
| Insert after slide *n* | +1 | Slides after *n* go up by 1 |
| Delete slide *n* | −1 | Slides after *n* go down by 1 |
| Move slide | Same | Slides between old and new position shift by 1 |
| Hide slide | Same | Unchanged; slide skipped only in the show |

Insert puts the new slide **after the selected slide**. Work through numbered instructions in order and confirm slides by **title**.

## Objects: quick rules

- Text goes in **placeholders**, so master formatting applies.
- Images: **lock aspect ratio**; crop, don't squash.
- Charts: suitable type, **chart title**, **axis titles**, legend only for more than one series.
- Tables: header row; consistent alignment in each column.
- Audio and video: set start (on click or automatically) if instructed.
- Symbols: insert from the symbol set (©, °, €), not look-alike characters.
- Lines, arrows, call outs: set colour and thickness; point arrows and call-out tails at the right feature.
- Shapes: use alignment and distribution tools to line them up.

## Hyperlinks vs action buttons

| | Hyperlink | Action button |
|---|---|---|
| Attached to | Selected text or any object | A built-in button shape |
| Destinations | Slide in this presentation, external file, email address | Specified slide or file (also next, previous, first, last slide) |
| Common trap | File link breaks if the file is moved out of the folder | Left on the default "next slide" setting |

Link to a slide by choosing its **title** from the list. Test every link in slide show view.

## Alternative text vs screentip

| | Alternative text | Screentip |
|---|---|---|
| Who it helps | Users of screen readers; anyone if the object fails to display | Any user pointing at a link or object |
| When seen or heard | Read aloud or shown in place of the object | When the pointer hovers |
| Good example | "Bar chart of visitor numbers rising each month" | "Opens the price list" |

## Consistency rules

- **One transition** for every slide (same effect and speed). Use "apply to all", then check.
- **Same animation** for similar objects on every slide, in the order given, with the start option given (on click or after previous).
- Reason: varied effects distract the audience and look unplanned.

## Exam traps

- Deleting when the instruction says **hide**.
- Hyperlinking to a slide by number, then moving slides so the link goes to the wrong one (link by title).
- Action button left on its default action.
- Presenter notes typed into the slide instead of the notes pane.
- Alternative text that is just the file name.
- A chart pasted with no title or axis titles.
- One slide with a different transition after "apply to all".

## Self-test

1. Where is a new slide placed when it is inserted?
2. A presentation has 10 slides. Slide 4 is deleted. What number is the slide that was slide 7?
3. Give **three** destinations of a hyperlink named in the syllabus.
4. What must usually be changed after inserting an action button?
5. State the difference between alternative text and a screentip.
6. Why should transitions be consistent?
7. A hidden slide is in a 12-slide presentation. How many slides are shown in the slide show?
8. Name **two** types of image the syllabus lists, other than a still image.
9. What are presenter notes for, and can the audience see them on screen?
10. Give **two** features a chart on a slide should have.
11. Why should a hyperlink to an external file use a file in the same folder as the presentation?
12. What is a call out box used for?

### Answers

1. Immediately after the slide that is selected.
2. Slide 6.
3. A slide in the presentation, an external file, an email address.
4. Its action settings, so it goes to the specified slide or file instead of the default.
5. Alternative text describes the object for screen readers or when it cannot be displayed; a screentip appears when the pointer hovers over the link or object.
6. So the effects do not distract the audience and the presentation looks professional and planned.
7. 11.
8. Video clips and animated images.
9. To remind the speaker what to say; no, they are not shown on the audience's screen.
10. Any two: a title; axis titles; a suitable chart type; a legend if there is more than one series.
11. So the link still works when the folder of files is moved to another computer.
12. To label or point to a particular part of a slide, image or chart.
