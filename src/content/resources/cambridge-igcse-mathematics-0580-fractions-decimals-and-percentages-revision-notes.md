These notes condense subtopic **1.4 Fractions, decimals and percentages** of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. Everything is for both tiers except the recurring decimal sections, which are **Extended only** (E1.4); Core candidates are not expected to use recurring decimal notation. For explanations and worked examples, use the [fractions, decimals and percentages study guide](/resources/cambridge-igcse-mathematics-0580-fractions-decimals-and-percentages/); then try the [practice questions](/resources/cambridge-igcse-mathematics-0580-fractions-decimals-and-percentages-practice/).

## Equivalences worth knowing by heart

| Fraction | Decimal | Percentage |
|---|---|---|
| 1/2 | 0.5 | 50% |
| 1/4, 3/4 | 0.25, 0.75 | 25%, 75% |
| 1/5 | 0.2 | 20% |
| 1/8, 3/8 | 0.125, 0.375 | 12.5%, 37.5% |
| 1/10 | 0.1 | 10% |
| 1/20 | 0.05 | 5% |
| 1/25 | 0.04 | 4% |
| 1/50 | 0.02 | 2% |
| 1/100 | 0.01 | 1% |
| 1/3, 2/3 | 0.333…, 0.666… | 33⅓%, 66⅔% |

Build others from these: 7/8 = 7 × 0.125 = 0.875; 3/20 = 3 × 0.05 = 0.15.

## Key terms

| Term | Meaning |
|---|---|
| Proper fraction | Numerator less than denominator |
| Improper fraction | Numerator greater than or equal to denominator |
| Mixed number | Whole number plus a proper fraction |
| Simplest form | No common factor other than 1 in numerator and denominator |
| Equivalent | Same value, different form |
| Terminating decimal | Stops after a finite number of digits |
| Recurring decimal | A digit or block of digits repeats for ever (Extended notation) |

## Conversion steps

```
Fraction -> decimal:     divide top by bottom
                         (or make the bottom 10, 100, 1000)
Decimal  -> fraction:    put over 10 / 100 / 1000 by the last digit's place,
                         then simplify
Decimal  -> percentage:  × 100
Percentage -> decimal:   ÷ 100
Percentage -> fraction:  put over 100, then simplify
Mixed -> improper:       whole × denominator + numerator, over denominator
Improper -> mixed:       divide; remainder over denominator
```

## Small reminders

```
0.08     = 8/100   = 2/25     = 8%
1.6      = 16/10   = 8/5      = 1 3/5  = 160%
0.25%    = 0.0025  = 1/400
4 2/9    = 38/9
53/8     = 6 5/8   = 6.625
```

## Which form should the answer be in?

| The question says | Give |
|---|---|
| "as a fraction in its simplest form" | A fully cancelled fraction; an improper fraction or a mixed number are both fractions |
| "as a mixed number" | Whole number and proper fraction, e.g. 2 3/8 |
| "as a decimal" | The exact decimal if it terminates; otherwise round as instructed |
| "as a percentage" | A number followed by %, e.g. 62.5% |
| "Which is larger?" | Convert every value to the same form, then state the answer in the original form |

**Comparing in context.** Shop A sells 3/5 of its stock, shop B sells 58% of the same amount. 3/5 = 60%, so shop A sold more. Write the converted values down: the comparison mark depends on them.

## Terminating or not?

Simplify the fraction first. If the denominator's only prime factors are 2 and 5, the decimal terminates.

| Fraction | Denominator | Terminates? |
|---|---|---|
| 9/16 | 2⁴ | yes: 0.5625 |
| 7/20 | 2² × 5 | yes: 0.35 |
| 4/15 | 3 × 5 | no |
| 21/35 | simplifies to 3/5 | yes: 0.6 |

**Core:** a decimal that does not stop is written to the accuracy asked, for example 4/15 = 0.267 (3 d.p.).

## Recurring decimals (Extended only)

**Reading the dots**

| Written | Means |
|---|---|
| 0.7̇ | 0.777… |
| 0.27̇ | 0.2777… |
| 0.2̇7̇ | 0.272727… |
| 0.2̇07̇ | 0.207207… |

**Converting to a fraction**

```
1. x = the decimal.
2. Multiply by 10, 100, 1000... to make TWO numbers with the same recurring tail.
3. Subtract to remove the tail.
4. Divide and simplify.

0.2̇7̇:  x = 0.2727...   100x = 27.2727...   99x = 27   x = 27/99 = 3/11
0.27̇:   10x = 2.777...  100x = 27.777...    90x = 25   x = 25/90 = 5/18
```

Shortcut check: a one-digit block over 9, a two-digit block over 99, a three-digit block over 999 (only when the repeat starts straight after the point).

## Exam traps

- Simplify fully: 18/24 → 3/4, not 9/12.
- Place value: 0.07 = 7/100, not 7/10.
- Percentages can exceed 100% (1.6 = 160%) and be less than 1% (0.004 = 0.4%).
- A mixed number's whole part is multiplied by the denominator, not added to the numerator.
- Round correctly, do not truncate: 2/3 = 0.67 (2 d.p.), not 0.66.
- (Extended) A dot on one digit is not the same as dots on a block: 0.27̇ ≠ 0.2̇7̇.
- (Extended) In "show that", a calculator division is not a proof.

## Quick self-test

1. Write 45/75 in its simplest form.
2. Write 0.65 as a fraction in its simplest form.
3. Write 3/40 as a decimal.
4. Write 2.4 as a percentage.
5. Write 0.3% as a decimal.
6. Write 5 3/8 as an improper fraction.
7. Write 29/4 as a mixed number and as a decimal.
8. Will 11/24 give a terminating decimal? Explain.
9. Write 5/6 as a decimal correct to 3 decimal places.
10. (Extended) Write 0.6̇ as a fraction in its simplest form.
11. (Extended) Write 0.1̇5̇ as a fraction in its simplest form.
12. (Extended) Write 0.83̇ as a fraction in its simplest form.

### Answers

1. HCF 15: 3/5
2. 65/100 = 13/20
3. 0.075
4. 240%
5. 0.003
6. 43/8
7. 7 1/4 = 7.25
8. No: 24 = 2³ × 3, and the factor 3 means it recurs.
9. 0.833
10. x = 0.666…, 10x = 6.666…, 9x = 6, x = 2/3
11. x = 0.1515…, 100x = 15.1515…, so 99x = 15 and x = 15/99 = 5/33
12. 10x = 8.333…, 100x = 83.333…, 90x = 75, x = 75/90 = 5/6

## Where marks are usually lost

- Not simplifying, or simplifying only part of the way.
- Place-value slips between tenths, hundredths and thousandths.
- Treating 135% as 0.135 or 0.4% as 0.04.
- (Extended) Mismatched tails when subtracting, leaving a decimal in the equation.
