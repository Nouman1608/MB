This set covers **syllabus section 1.7** of IB DP Mathematics: Analysis and Approaches (first assessment 2021): rational exponents, the laws of logarithms, change of base and solving exponential equations. It is common content for SL and HL. Questions are labelled "(calculator-free)" for Paper 1 style or "(calculator allowed)" for Paper 2 style. Give answers exactly or to 3 significant figures unless told otherwise.

Study the methods first in the [section 1.7 study guide](/resources/ib-dp-mathematics-analysis-and-approaches-1-7/) and the [section 1.7 revision notes](/resources/ib-dp-mathematics-analysis-and-approaches-1-7-revision-notes/).

## Section A

**1.** (calculator-free) Evaluate:

**(a)** 64^(2/3) **[1]**
**(b)** (1/32)^(−2/5) **[2]**

**2.** (calculator-free) Write each expression in the form axⁿ.

**(a)** 6/√x **[1]**
**(b)** x²∛x **[1]**
**(c)** (2√x)³ **[1]**

**3.** (calculator-free) Write as a single logarithm, simplifying where possible.

**(a)** log 8 + log 5 − log 4, and hence evaluate it. **[2]**
**(b)** 3 ln x − (1/2) ln y + ln 2 **[2]**

**4.** (calculator-free) Given that ln a = 2 and ln b = 5, find the exact value of:

**(a)** ln(a²b) **[1]**
**(b)** ln(√a/b³) **[2]**
**(c)** log_a b **[1]**

**5.** (calculator-free) Find the exact value of log₂₅ 125. **[2]**

**6.** (calculator allowed) Solve 7^x = 40. **[2]**

## Section B

**7.** (calculator-free) Solve 8^(x + 1) = 4^(2x − 1). **[3]**

**8.** (calculator-free) Solve log₂ x + log₂(x − 2) = 3. **[4]**

**9.** (calculator-free)

**(a)** Show that log₉ y = (1/2) log₃ y for y > 0. **[2]**
**(b)** Hence solve log₃(x + 2) = log₉(5x + 16). **[4]**

**10.** (calculator allowed) Solve 4^x = 3^(x + 2). Give your answer in the form x = ln p/ln q, where p, q ∈ ℚ, and to 3 significant figures. **[4]**

**11.** (calculator-free) Solve e^(2x) − 2e^x − 15 = 0, giving your answer exactly. **[4]**

**12.** The number of users N of an app t months after launch is modelled by N = 400 × 2^(t/3).

**(a)** (calculator-free) Find N when t = 9. **[1]**
**(b)** (calculator allowed) Find the number of whole months after launch at which N first exceeds 20 000. **[3]**
**(c)** (calculator-free) Show that the model can be written as N = 400e^(kt), where k = (ln 2)/3. **[2]**

**13.** (calculator-free)

**(a)** Simplify (x^(3/2) + x^(1/2))/x^(1/2), for x > 0. **[2]**
**(b)** Solve 2^x + 2^(x + 2) = 40. **[3]**

## Answers

**1. (a)** (∛64)² = 4² = **16** [1]
**(b)** (1/32)^(−2/5) = 32^(2/5) [1] = (⁵√32)² = 2² = **4** [1]

**2. (a)** **6x^(−1/2)** [1]
**(b)** x² × x^(1/3) = **x^(7/3)** [1]
**(c)** 2³ × (x^(1/2))³ = **8x^(3/2)** [1]

**3. (a)** log(8 × 5/4) = log 10 [1] = **1** [1]
**(b)** ln x³ − ln y^(1/2) + ln 2 [1] = **ln(2x³/√y)** [1]

**4. (a)** 2 ln a + ln b = 4 + 5 = **9** [1]
**(b)** (1/2) ln a − 3 ln b [1] = 1 − 15 = **−14** [1]
**(c)** ln b/ln a = **5/2** [1]

**5.** log₅ 125/log₅ 25 [1] = **3/2** [1]
*Examiner insight:* Base 5 works because 25 and 125 are both powers of 5. Writing log 125/log 25 is also correct, but then you must still show it equals 3/2 without a calculator.

**6.** x = ln 40/ln 7 [1] = **1.90** (3 s.f.) [1]

**7.** 2^(3x + 3) = 2^(4x − 2) [1]. 3x + 3 = 4x − 2 [1], so **x = 5** [1]

**8.** log₂[x(x − 2)] = 3 [1], so x² − 2x = 8 [1]. (x − 4)(x + 2) = 0, so x = 4 or x = −2 [1]. x = −2 makes log₂ x undefined, so **x = 4** only [1]
*Examiner insight:* The final mark is for rejecting x = −2 with a reason. Stating "x = 4" with no comment on −2 loses it.

**9. (a)** By change of base, log₉ y = log₃ y/log₃ 9 [1] = log₃ y/2 = (1/2) log₃ y [1]
**(b)** log₉(5x + 16) = (1/2) log₃(5x + 16), so 2 log₃(x + 2) = log₃(5x + 16), giving log₃(x + 2)² = log₃(5x + 16) [1]. (x + 2)² = 5x + 16 [1], so x² − x − 12 = 0 and (x − 4)(x + 3) = 0 [1]. x = −3 gives log₃(−1), which is undefined, so **x = 4** [1]
*Examiner insight:* Check x = 4: log₃ 6 and log₉ 36 = (1/2) log₃ 36 = log₃ 6. They agree.

**10.** x ln 4 = (x + 2) ln 3 [1]. x ln 4 − x ln 3 = 2 ln 3 [1], so x = 2 ln 3/(ln 4 − ln 3) = **ln 9/ln(4/3)** [1] = **7.64** (3 s.f.) [1]

**11.** Let u = e^x: u² − 2u − 15 = 0 [1], so (u − 5)(u + 3) = 0 [1]. e^x = −3 is impossible because e^x > 0 [1]. e^x = 5, so **x = ln 5** [1]

**12. (a)** 400 × 2³ = **3200** [1]
**(b)** 2^(t/3) > 50 [1], so t/3 > log₂ 50 = ln 50/ln 2, giving t > 16.93… [1]. N first exceeds 20 000 after **17 months** [1]
**(c)** 2 = e^(ln 2), so 2^(t/3) = (e^(ln 2))^(t/3) [1] = e^((ln 2/3)t). So N = 400e^(kt) with k = (ln 2)/3 [1]

**13. (a)** x^(3/2)/x^(1/2) + x^(1/2)/x^(1/2) [1] = **x + 1** [1]
**(b)** 2^(x + 2) = 4 × 2^x, so 2^x(1 + 4) = 40 [1]. 2^x = 8 [1], so **x = 3** [1]
*Examiner insight:* Taking logs of a sum is not allowed. Factorise the common power 2^x first.

## Where marks are usually lost

- Rejected roots of log equations left in, or rejected with no reason.
- (ln x)² treated as 2 ln x, or log(x + y) split into two logs.
- Exact answers given as decimals when "exact" or "in the form ln p/ln q" is asked.
- In (b)-type context questions, the inequality solved but the answer not rounded up to the next whole month.
- Combining logs with coefficients still in front: 3 ln x + ln 2 is ln(2x³), not ln(6x).
