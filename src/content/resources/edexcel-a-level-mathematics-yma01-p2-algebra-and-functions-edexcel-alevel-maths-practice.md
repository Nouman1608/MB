## Section A

**1.** Find the remainder when x³ + 4x² − 3x + 5 is divided by (x − 2). **[2]**

**2.** Find the remainder when 6x³ − x² + 2x − 4 is divided by (3x − 1). **[2]**

**3.** Use algebraic long division to divide x³ + 2x² − 5x − 9 by (x + 3), stating the quotient and the remainder. **[3]**

**4.** The remainder when x³ + kx − 8 is divided by (x − 3) is equal to the remainder when it is divided by (x + 1).

**(a)** Find the value of the constant k. **[3]**

**(b)** Find this remainder. **[1]**

## Section B

**5.** f(x) = 2x³ − 7x² + 9.

**(a)** Use the factor theorem to show that (2x − 3) is a factor of f(x). **[2]**

**(b)** Factorise f(x) fully. **[3]**

**6.** f(x) = x³ − 3x² − 10x + 24.

**(a)** Show that f(2) = 0. **[1]**

**(b)** Factorise f(x) fully. **[3]**

**(c)** Hence solve f(x) = 0. **[1]**

**7.** g(x) = x³ − 3x + 2.

**(a)** Show that (x − 1) is a factor of g(x). **[1]**

**(b)** Factorise g(x) fully. **[2]**

**(c)** Describe how the graph of y = g(x) meets the x-axis at x = 1, giving a reason. **[1]**

**8.** f(x) = 3x³ + kx² − 4x + 4, where k is a constant. Given that (x + 2) is a factor of f(x):

**(a)** find the value of k **[2]**

**(b)** show that the equation f(x) = 0 has exactly one real root. **[3]**

**9.** f(x) = x³ + ax² + bx − 12, where a and b are constants. (x − 3) is a factor of f(x), and when f(x) is divided by (x + 1) the remainder is −4.

**(a)** Find the values of a and b. **[4]**

**(b)** Factorise f(x) fully. **[2]**

**10.** Express 4x³ − 8x² + 3x + 5 in the form (2x − 1)(Ax² + Bx + C) + R, where A, B, C and R are constants to be found. **[4]**

**11.** f(x) = 6x³ + 7x² − x − 2. Factorise f(x) fully and hence solve f(x) = 0. **[4]**

## Answers

**1.** By the remainder theorem the remainder is f(2) [1] = 8 + 16 − 6 + 5 = **23** [1].

**2.** The remainder is f(⅓) [1] = 6/27 − 1/9 + 2/3 − 4 = 2/9 − 1/9 + 6/9 − 36/9 = **−29/9** [1].

**3.** Dividing the leading terms in turn gives x², then −x, then −2:

x³ + 2x² − (x³ + 3x²) = −x², bringing down −5x gives −x² − 5x [1]

−x² − 5x − (−x² − 3x) = −2x, bringing down −9 gives −2x − 9; −2x − 9 − (−2x − 6) = −3 [1]

Quotient **x² − x − 2**, remainder **−3** [1]. (Check: f(−3) = −27 + 18 + 15 − 9 = −3.)

**4. (a)** f(3) = 27 + 3k − 8 = 19 + 3k and f(−1) = −1 − k − 8 = −9 − k [1]. Setting them equal: 19 + 3k = −9 − k [1], so 4k = −28 and **k = −7** [1].

**(b)** Remainder = 19 + 3(−7) = **−2** [1].

Total: 4

**5. (a)** f(3/2) = 2(27/8) − 7(9/4) + 9 = 27/4 − 63/4 + 36/4 [1] = 0, so (2x − 3) is a factor [1].

**(b)** f(x) = (2x − 3)(x² − 2x − 3) [1] [1] (one mark for the leading and constant terms of the quotient, one for the full quotient) = **(2x − 3)(x − 3)(x + 1)** [1].

Total: 5

**6. (a)** f(2) = 8 − 12 − 20 + 24 = 0 [1].

**(b)** (x − 2) is a factor [1]; f(x) = (x − 2)(x² − x − 12) [1] = **(x − 2)(x − 4)(x + 3)** [1].

**(c)** **x = 2, x = 4, x = −3** [1].

Total: 5

**7. (a)** g(1) = 1 − 3 + 2 = 0, so (x − 1) is a factor [1].

**(b)** g(x) = (x − 1)(x² + x − 2) [1] = **(x − 1)²(x + 2)** [1].

**(c)** (x − 1) is a repeated factor, so the curve touches the x-axis at x = 1 without crossing it [1].

Total: 4

**8. (a)** f(−2) = −24 + 4k + 8 + 4 = 0 [1], so 4k = 12 and **k = 3** [1].

**(b)** f(x) = (x + 2)(3x² − 3x + 2) [1]. For the quadratic factor, b² − 4ac = 9 − 24 = −15 [1]. This is negative, so 3x² − 3x + 2 = 0 has no real roots, and the only real root of f(x) = 0 is x = −2 [1].

Total: 5

**9. (a)** f(3) = 0: 27 + 9a + 3b − 12 = 0, so 3a + b = −5 [1].

f(−1) = −4: −1 + a − b − 12 = −4, so a − b = 9 [1].

Adding: 4a = 4, so **a = 1** [1]; then **b = −8** [1].

**(b)** f(x) = x³ + x² − 8x − 12 = (x − 3)(x² + 4x + 4) [1] = **(x − 3)(x + 2)²** [1].

Total: 6

**10.** By the remainder theorem, R = f(½) = 4/8 − 8/4 + 3/2 + 5 = **5** [1].

Comparing x³ terms: 2A = 4, so **A = 2** [1].

Comparing x² terms: 2B − A = −8, so 2B = −6 and **B = −3** [1].

Comparing constants: −C + R = 5, so **C = 0** [1]. (Check the x terms: 2C − B = 0 + 3 = 3, as required.)

So 4x³ − 8x² + 3x + 5 ≡ (2x − 1)(2x² − 3x) + 5.

**11.** f(−1) = −6 + 7 + 1 − 2 = 0, so (x + 1) is a factor [1]. f(x) = (x + 1)(6x² + x − 2) [1] = (x + 1)(3x + 2)(2x − 1) [1]. So f(x) = 0 when **x = −1, x = −⅔ or x = ½** [1].

## Where marks are usually lost

- Substituting x = 1/3 for the factor (3x + 1) or x = 3 for (x + 3): solve "divisor = 0" first.
- In Question 3, subtracting only the leading term instead of the whole line, which corrupts every later step.
- Stopping at (x − 2)(x² − x − 12) when the question says "factorise fully".
- In Question 8(b), stating "no real roots" for the quadratic without quoting the discriminant.
- In Question 10, forgetting that the x³ coefficient of (2x − 1)(Ax² + Bx + C) is 2A, not A.
