These notes condense subtopic **2.4 Indices II** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027). Core (C2.4) covers positive, zero and negative indices; Extended (E2.4) adds fractional indices. Lines marked *(Extended)* are E2.4 only. Logarithms are not required at either tier. For explanations and worked examples, read the [Indices II study guide](/resources/cambridge-igcse-mathematics-0580-indices-ii-cambridge-igcse-maths/); for marked exam-style questions, use the [Indices II practice questions](/resources/cambridge-igcse-mathematics-0580-indices-ii-cambridge-igcse-maths-practice/).

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Base | The number or letter being raised to a power | in 5x³, the base of the power is x |
| Index (power, exponent) | How many factors of the base | x³ = x × x × x |
| Coefficient | The number multiplying the power | in 5x³ it is 5 |
| Zero index | Any non-zero base to the power 0 is 1 | a⁰ = 1, so 7a⁰ = 7 |
| Negative index | One over the positive power | x⁻³ = 1/x³ |
| Fractional index *(Extended)* | Denominator = root, numerator = power | x^(2/3) = (∛x)² |
| Index equation | An equation with the unknown in the power | 2ˣ = 32 |

## Condensed recall

### The rules

| Rule | Use | Example |
|---|---|---|
| xᵐ × xⁿ = xᵐ⁺ⁿ | multiplying | 3a⁴ × 2a⁻¹ = 6a³ |
| xᵐ ÷ xⁿ = xᵐ⁻ⁿ | dividing | 18a⁶ ÷ 6a⁻² = 3a⁸ |
| (xᵐ)ⁿ = xᵐⁿ | power of a power | (x⁻²)³ = x⁻⁶ |
| (kx)ⁿ = kⁿxⁿ | bracket with a coefficient | (3x⁴)³ = 27x¹² |
| x⁰ = 1 | zero index | (4y)⁰ = 1 |
| x⁻ⁿ = 1/xⁿ | negative index | 2x⁻¹ = 2/x |
| x^(1/n) = ⁿ√x *(Extended)* | unit fraction | 81^(1/4) = 3 |
| x^(m/n) = (ⁿ√x)ᵐ *(Extended)* | general fraction | 32^(3/5) = 2³ = 8 |

### Missing index

Turn the rule into an equation in the unknown power.

```
x^7 ÷ x^n = x^10   ->   7 - n = 10   ->   n = -3
```

### Index equations

```
1. Write both sides as powers of the SAME base.
2. Use (a^m)^n = a^(mn) to tidy each side into a single power.
3. Equate the indices and solve.
4. Check by substituting.
```

| Number | As a power |
|---|---|
| 1/32 | 2⁻⁵ |
| 0.001 | 10⁻³ |
| 243 | 3⁵ |
| 1 | any base to the power 0 |
| √5 *(Extended)* | 5^(1/2) |
| 1/3 *(Extended, as a power of 9)* | 9^(−1/2) |

### Writing terms as axⁿ *(Extended)*

| Expression | axⁿ form |
|---|---|
| 4/x³ | 4x⁻³ |
| 1/(5x²) | (1/5)x⁻² |
| 2√x | 2x^(1/2) |
| 6/(x√x) | 6x^(−3/2) |

### Unknown in the base *(Extended)*

Raise both sides to the reciprocal power: x^(3/2) = 27 gives x = 27^(2/3) = 9. For an even power such as x⁻² = 1/16, there are two answers, x = 4 or x = −4.

### Two worked recalls

**Simplify** (2x³y⁻¹)² × 3xy⁴.

```
(2x^3 y^-1)^2 = 4x^6 y^-2
4 × 3 = 12;  x: 6 + 1 = 7;  y: -2 + 4 = 2
Answer: 12x^7 y^2
```

**Solve** *(Extended)* 27ˣ = 9ˣ⁺¹.

```
27 = 3^3 and 9 = 3^2
3^(3x) = 3^(2x+2)
3x = 2x + 2  ->  x = 2
Check: 27^2 = 729 and 9^3 = 729
```

## Exam traps

- **Adding instead of multiplying** for a power of a power: (x³)⁴ = x¹², not x⁷.
- **Forgetting the coefficient** inside a bracket: (2x⁵)³ = 8x¹⁵.
- **Zero index on the wrong part:** 5x⁰ = 5, but (5x)⁰ = 1.
- **Negative index read as negative number:** 3⁻² = 1/9, not −9 and not −6.
- **x means x¹** in a missing-index question.
- **Different letters never combine:** a³ × b² stays as a³b²; only powers of the same base add.
- **Adding powers is not a rule:** x³ + x² cannot be simplified to x⁵; the index laws apply to multiplication and division only.
- **Mismatched bases:** in 25ˣ = 5ˣ⁺³, rewrite 25ˣ as 5²ˣ before equating; 2x = x + 3 gives x = 3.
- **Fraction order** *(Extended)*: 125^(2/3) is cube root first (5), then square (25). Root first keeps numbers small on the non-calculator paper.
- **Negative fractional index** *(Extended)*: 125^(−2/3) = 1/25. Deal with the minus sign last, as "one over".

## Self-test

1. Simplify (3x⁴)³.
2. Simplify 18a⁶ ÷ 6a⁻².
3. Simplify 4x⁻³y² × 5x⁵y⁻⁶, giving your answer with positive indices.
4. Work out 7⁰ + 2⁻³.
5. Find n when x⁷ ÷ xⁿ = x¹⁰.
6. Solve 2ˣ = 1/32.
7. Solve 3²ˣ⁻¹ = 27.
8. *(Extended)* Work out 125^(−2/3).
9. *(Extended)* Simplify (16x⁸)^(3/4).
10. *(Extended)* Write 6/(x√x) in the form axⁿ.
11. *(Extended)* Solve 9ˣ = 1/3.
12. *(Extended)* Solve 25ˣ = 5ˣ⁺³.

### Answers

1. 3³ = 27 and (x⁴)³ = x¹²: **27x¹²**.
2. 18 ÷ 6 = 3; 6 − (−2) = 8: **3a⁸**.
3. 20x²y⁻⁴ = **20x²/y⁴**.
4. 1 + 1/8 = **9/8** (or 1.125).
5. 7 − n = 10, **n = −3**.
6. 1/32 = 2⁻⁵, so **x = −5**.
7. 27 = 3³, so 2x − 1 = 3 and **x = 2**.
8. ∛125 = 5, 5² = 25, so **1/25**.
9. 16^(3/4) = 2³ = 8 and (x⁸)^(3/4) = x⁶: **8x⁶**.
10. x√x = x^(3/2), so **6x^(−3/2)**.
11. 9 = 3² and 1/3 = 3⁻¹: 3²ˣ = 3⁻¹, so 2x = −1 and **x = −1/2**.
12. 5²ˣ = 5ˣ⁺³, so 2x = x + 3 and **x = 3**.
