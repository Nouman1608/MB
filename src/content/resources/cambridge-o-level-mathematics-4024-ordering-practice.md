## Section A

**1.** Copy each statement and put <, > or = in the gap.

**(a)** -7 ... -3 **[1]**

**(b)** 0.45 ... 4/9 **[1]**

**(c)** 3/8 ... 0.375 **[1]**

**2.** Write these in order of size, smallest first.

3/5 0.58 61% 5/9 **[3]**

**3.** Write these in order of size, smallest first.

-3 0.5 -1.2 -1/2 2/5 **[2]**

**4.** Which is larger, 4/7 or 7/12? Show how you decide. **[2]**

**5.** List all the integers x such that -3 < x ⩽ 2. **[2]**

**6.** Write an inequality for each statement.

**(a)** n is at least 5 but less than 12. **[1]**

**(b)** y is greater than -4 and at most 6. **[1]**

## Section B

**7.** Write these in order of size, largest first.

2⁻³ 0.1 1/9 11% **[3]**

**8.** Without using a calculator, show that ∛150 < 5.4 < √30. **[3]**

**9.** Write these in order of size, smallest first.

6.1 × 10⁴ 9.8 × 10³ 5.9 × 10⁴ **[2]**

**10.** Copy each statement and write = or ≠ in the gap.

**(a)** 0.7̇ ... 7/10 **[1]**

**(b)** 2/3 ... 0.67 **[1]**

**11.** Five cities recorded these temperatures in °C: -4, 7, -11, 0, -8.

**(a)** Write the temperatures in order, coldest first. **[1]**

**(b)** Find the difference between the highest and the lowest temperature. **[2]**

**12.** The inequality x ⩾ -1 and x < 3 describes a range of values.

**(a)** Write the two statements as one inequality. **[1]**

**(b)** List the integer values of x. **[1]**

**(c)** Describe how the ends would be shown on a number line. **[2]**

**13.** *Calculator.* Three shops sell pens. Shop A: 3 pens for $4.80. Shop B: 5 pens for $7.75. Shop C: 2 pens for $3.30. Which shop gives the lowest price per pen? Show your working. **[3]**

**14.** n is a positive integer and 7.2 < √n < 7.8. Find the smallest and the largest possible values of n. **[3]**

## Answers

**1. (a)** **-7 < -3** **[1]**

**(b)** 4/9 = 0.444..., so **0.45 > 4/9** **[1]**

**(c)** 3/8 = 0.375, so **3/8 = 0.375** **[1]** **[3]**

**2.** 3/5 = 0.6, 61% = 0.61, 5/9 = 0.555... **[1]**; order of the decimals 0.555..., 0.58, 0.6, 0.61 **[1]**; **5/9, 0.58, 3/5, 61%** **[1]** **[3]**

*Examiner insight:* Convert to decimals first and write them down. Giving the final list in the original forms is the safest way to answer.

**3.** Order of values -3, -1.2, -0.5, 0.4, 0.5 **[1]**; **-3, -1.2, -1/2, 2/5, 0.5** **[1]** **[2]**

**4.** 4/7 = 48/84 and 7/12 = 49/84 **[1]**; so **7/12** is larger **[1]** **[2]**

**5.** **-2, -1, 0, 1, 2** **[2]** (one mark if one value is missing or extra, for example -3 included)

**6. (a)** **5 ⩽ n < 12** **[1]**

**(b)** **-4 < y ⩽ 6** **[1]** **[2]**

**7.** 2⁻³ = 0.125, 1/9 = 0.111..., 11% = 0.11 **[1]**; order of the decimals 0.125, 0.111..., 0.11, 0.1 **[1]**; **2⁻³, 1/9, 11%, 0.1** **[1]** **[3]**

**8.** 5.4² = 29.16, which is less than 30, so √30 > 5.4 **[1]**; 5.4³ = 157.464, which is more than 150, so ∛150 < 5.4 **[1]**; therefore ∛150 < 5.4 < √30 **[1]** **[3]**

*Examiner insight:* "Show that" needs the working lines. A calculator value alone is not enough on a no-calculator question.

**9.** Powers of 10: 9.8 × 10³ is the smallest **[1]**; **9.8 × 10³, 5.9 × 10⁴, 6.1 × 10⁴** **[1]** **[2]**

**10. (a)** 0.777... is not 0.7, so **≠** **[1]**

**(b)** 0.666... is not 0.67, so **≠** **[1]**

**(c)** **=** **[1]** **[3]**

**11. (a)** **-11, -8, -4, 0, 7** **[1]**

**(b)** 7 - (-11) **[1]** = **18 °C** **[1]** **[3]**

**12. (a)** **-1 ⩽ x < 3** **[1]**

**(b)** **-1, 0, 1, 2** **[1]**

**(c)** A filled circle at -1 because -1 is included **[1]**; an open circle at 3 because 3 is not included **[1]** **[4]**

**13.** A: 4.80 ÷ 3 = $1.60 **[1]**; B: 7.75 ÷ 5 = $1.55 and C: 3.30 ÷ 2 = $1.65 **[1]**; **Shop B** is cheapest **[1]** **[3]**

**14.** Square all three parts: 51.84 < n < 60.84 **[1]**; the smallest integer is **52** **[1]**; the largest is **60** **[1]** **[3]**

*Check:* √52 = 7.21 and √60 = 7.75, but √61 = 7.81, which is too big.

## Where marks are usually lost

- Writing -3 < -7 in Question 1(a) because 3 is less than 7.
- Comparing 0.45 with 4/9 by the number of digits.
- Giving the order largest first in Question 2.
- Including -3 in the list in Question 5.
- Using ⩽ when the question says "less than" in Question 6.
- Saying 0.7̇ = 7/10 in Question 10.
- Not squaring both ends of the inequality in Question 14.

## Frequently asked questions

**How do I remember which way the symbols point?**
The wide, open end faces the larger quantity. So in 3 < 8, the point is next to the 3, the smaller number.

**Is 5 ⩽ 5 a true statement?**
Yes. The symbol ⩽ means less than or equal to, and 5 is equal to 5.
