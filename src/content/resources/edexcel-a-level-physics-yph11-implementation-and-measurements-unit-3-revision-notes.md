Condensed notes for section **3.4 Implementation and measurements**, Unit 3: Practical Skills in Physics I, Pearson Edexcel IAL Physics (YPH11), Issue 3. Full teaching and a worked critique are in the [Unit 3 implementation and measurements study guide](/resources/edexcel-a-level-physics-yph11-implementation-and-measurements-unit-3/); questions are in the [Unit 3 implementation and measurements practice questions](/resources/edexcel-a-level-physics-yph11-implementation-and-measurements-unit-3-practice/).

## What the question gives you

Details of an experiment carried out by an **inexperienced student**, sometimes with results. You judge it on five points and suggest improvements. You do not plan it from scratch (that is 3.3) and you do not do the full analysis (that is 3.5).

## The five-point check

| Check | Good practice | Typical comment that scores |
|---|---|---|
| Number of readings | At least 6 values of the independent variable; 3 repeats where scatter is likely | "Only four values, so the shape of the graph cannot be confirmed; take at least six" |
| Range | As wide as the apparatus and safety allow | "Loads only from 1 N to 3 N; extend to 8 N, staying below the limit of proportionality" |
| Significant figures | Readings to the instrument's resolution, consistent in each column | "Lengths given as 0.5 m and 0.55 m; a metre rule reads to 1 mm, so 0.500 m and 0.550 m" |
| Inconsistent reading | Identified with a calculation, then checked or repeated | "At 4.0 N the ratio is 15 mm/N against 12 mm/N for the rest; repeat this reading" |
| Improvement | Named apparatus or change, plus the error it reduces | "Use a set square to check the rule is vertical, reducing error in reading the extension" |

## Spotting the inconsistent reading

1. Find the pattern the theory or most points suggest (constant ratio, constant difference, straight line).
2. Calculate the ratio or difference for every row.
3. Name the row that breaks the pattern and how far it is off (as a value or a percentage).
4. Suggest a cause: misread scale, digits swapped, timer started late, wrong range on a meter, a variable that changed.
5. Say what to do: check the calculation, repeat the reading; exclude it only with a reason.

**Mini example.** Spring loads 1, 2, 3, 4, 5 N; extensions 15, 30, 45, 66, 75 mm. Ratio: 15, 15, 15, 16.5, 15 mm/N. At 4 N the expected extension is 60 mm; 66 mm is 6 mm (10%) high. Repeat it.

## Significant figures rules

- Raw readings: to the instrument's resolution, so a constant number of decimal places in each column.
- Metre rule in metres: three decimal places (0.375 m). In millimetres: whole numbers (375 mm).
- Micrometer: always two decimal places in mm (0.50 mm, not 0.5 mm).
- Vernier calipers: one decimal place in mm (16.0 mm).
- Calculated values: same number of significant figures as the least precise data, usually 3; a mix of 3 and 4 is accepted when values cross a power of ten.
- Hand timing recorded to 0.01 s claims more precision than reaction time allows: say so.

## Reading a micrometer

Reading = sleeve millimetres + 0.5 mm (if the half-mark shows) + thimble divisions × 0.01 mm − zero error.

| Sleeve | Half-mark visible? | Thimble | Zero error | Reading |
|---|---|---|---|---|
| 2 mm | No | 18 | 0.00 mm | 2.18 mm |
| 2 mm | Yes | 18 | 0.00 mm | 2.68 mm |
| 0 mm | Yes | 36 | +0.02 mm | 0.86 − 0.02 = 0.84 mm |
| 5 mm | No | 07 | −0.01 mm | 5.07 + 0.01 = 5.08 mm |

A negative zero error is **added** back: the instrument reads too low.

## Improvements bank

| If the method shows... | Suggest... | Because... |
|---|---|---|
| Rule held by hand beside a spring | Clamp the rule; set square to check vertical | Rule stays vertical and still |
| Reading a pointer against a scale | Eye level, or mirror behind the scale | Removes parallax |
| One diameter reading with a ruler | Micrometer, readings at several points and orientations | Smaller resolution; checks uniformity |
| Hand timing of a short interval | Light gates and timer, or time over a longer distance | Reaction time becomes negligible |
| Timing starts as the ball enters the liquid | Start timing lower down | Ball reaches terminal velocity first |
| Current left on during readings | Switch off between readings | Avoids heating changing resistance |
| Readings only while increasing a variable | Also take readings while decreasing | Reveals hysteresis or lag |
| Single readings | Repeat three times and average | Reduces effect of random error |

## Key terms

| Term | Meaning |
|---|---|
| Inexperienced student | The person whose method or data you are checking |
| Anomalous reading | A result that does not fit the pattern of the others |
| Resolution | The smallest interval an instrument can show |
| Parallax error | A reading error from viewing a scale at an angle |
| Fiducial marker | A fixed reference point used to start and stop timing |
| Hysteresis | Different readings when a variable is increased and then decreased |
| Limit of proportionality | Point beyond which extension is no longer proportional to load |
| Terminal velocity | Constant speed when the forces on a falling object balance |

## Exam traps

- Saying "more readings" without a number or reason.
- Saying "anomalous" without a calculation.
- Recommending that an anomaly simply be ignored.
- Writing improvements that are not apparatus or method changes ("be more accurate").
- Forgetting the half-millimetre mark on a micrometer sleeve.
- Subtracting a negative zero error instead of adding it.

## Self-test

**1.** What is the minimum sensible number of values of the independent variable for a graph?
**2.** A student records lengths as 0.2 m, 0.25 m, 0.3 m with a metre rule. Correct them.
**3.** Sleeve 4 mm, half-mark visible, thimble 22. What is the reading?
**4.** Using Question 3, the zero error is −0.03 mm. What is the corrected reading?
**5.** Loads 2, 4, 6, 8 N give extensions 10, 20, 34, 40 mm. Which reading is inconsistent?
**6.** Using Question 5, by how much is it off?
**7.** Why should the upper timing mark be well below the surface in a falling-ball experiment?
**8.** Give an improvement for a spring extension measured with a hand-held ruler.
**9.** Why is a time of 0.85 s measured by hand a poor reading?
**10.** A student loads a wire up to 3 N only; it breaks at about 40 N. Comment on the range.
**11.** What should a student do with an inconsistent reading before excluding it?
**12.** Why do Vernier readings have one decimal place in mm?

### Answers

**1.** Six.
**2.** 0.200 m, 0.250 m, 0.300 m.
**3.** 4 + 0.5 + 0.22 = 4.72 mm.
**4.** 4.72 + 0.03 = 4.75 mm.
**5.** 34 mm at 6 N (5 mm/N elsewhere, 5.7 mm/N here).
**6.** Expected 30 mm, so 4 mm (about 13%) too high.
**7.** So the ball has reached terminal velocity before timing starts.
**8.** Clamp the rule and use a set square to check it is vertical; add a pointer and read at eye level.
**9.** Reaction time of about 0.1–0.2 s is a large fraction of 0.85 s; use light gates or a longer interval.
**10.** The range is far too small to show the behaviour; extend it towards, but safely below, the breaking load.
**11.** Recheck it and repeat the measurement.
**12.** Vernier calipers resolve 0.1 mm.
