These questions cover sub-topic 1.2, Concept and uses of classification systems, of the Cambridge IGCSE Biology 0610 syllabus for examination in 2026, 2027 and 2028. Outcomes 1 to 4 are Core. Questions on outcomes 5 to 7 (evolutionary relationships and DNA) are labelled **(Extended)**, and a Core candidate can skip them. Organisms labelled with letters and all DNA data are invented.

## Questions

### Section A: short questions

**1.** Which is the correct way to print the binomial name of the leopard? **[1]**

A: Panthera Pardus

B: panthera pardus

C: *Panthera pardus*

D: *Pardus panthera*

**2.** State what organisms placed in the same group have in common. **[1]**

**3.** Fish of type P and type Q are bred together. Their offspring are healthy but cannot reproduce. State whether P and Q are the same species, and explain your answer. **[2]**

**4.** The English oak is *Quercus robur* and the northern red oak is *Quercus rubra*.

**(a)** Name the genus of these trees. **[1]**

**(b)** State what sharing a genus suggests about the two trees. **[1]**

**5.** State how many pairs of statements are needed in a dichotomous key that identifies nine organisms. **[1]**

### Section B: structured questions

**6.** Use the key to identify leaves A to D.

```
1  Leaf divided into separate leaflets .......... go to 2
   Leaf in one piece ............................ go to 3
2  Leaflets arranged in pairs along a stalk ..... Rowan
   Leaflets all spreading from one point ........ Horse chestnut
3  Leaf edge smooth ............................. Laurel
   Leaf edge toothed ............................ Beech
```

- Leaf A is in one piece with a toothed edge.
- Leaf B has five leaflets all spreading from the top of the stalk.
- Leaf C is in one piece with a smooth edge.
- Leaf D has leaflets in pairs along a stalk.

**7.** The table describes four animals.

| Animal | Legs | Wings | Shell |
|---|---|---|---|
| Snail | 0 | no | yes |
| Slug | 0 | no | no |
| Beetle | 6 | yes | no |
| Spider | 8 | no | no |

Construct a dichotomous key to identify the four animals. **[4]**

**8.** A student writes the human binomial name as "homo Sapiens". Identify **two** errors and write the name correctly by hand. **[3]**

**9.** *(Extended)* Explain why classification systems aim to reflect evolutionary relationships rather than appearance alone. Use an example in your answer. **[3]**

**10.** *(Extended)* Scientists compared a 50-base section of the same gene in four species. The table shows the number of bases that differ from species J.

| Comparison | Bases that differ |
|---|---|
| J and K | 4 |
| J and L | 12 |
| J and M | 21 |

**(a)** Calculate the percentage of bases that are identical in J and L. **[2]**

**(b)** State which species is most closely related to J, and explain your answer. **[2]**

**(c)** Suggest why DNA evidence can be more reliable than visible features for classification. **[1]**

**11.** *(Extended)* Explain why two species that share a recent common ancestor have similar DNA base sequences. **[3]**

**12.** A student writes this first step in a key for garden animals:

```
1  Has a shell ........ go to 2
   Is slimy ........... go to 3
```

Explain why this step is poorly written, and rewrite it. **[3]**

## Answers

**1.** **C** [1]. The genus has a capital letter, the species is lower case, and the name is in italics with the genus first. **[1]**

**2.** They share features [1]. **[1]**

**3.** They are **not** the same species [1], because their offspring are infertile, and a species is a group that can produce **fertile** offspring [1]. **[2]**

**4. (a)** *Quercus* [1].

**(b)** They are closely related [1]. **[2]**

**5.** Eight (n − 1) [1]. **[1]**

**6.** A: beech [1]. B: horse chestnut [1]. C: laurel [1]. D: rowan [1]. **[4]**

*Examiner insight:* Start at step 1 for every leaf and note the route, for example B: 1 → 2 → horse chestnut. Jumping in part-way through a key is the usual cause of wrong answers.

**7.** One mark for each correct pair of contrasting statements based on a visible feature, up to three [1] [1] [1], and one mark for a key in which each animal ends at its own name [1]. For example:

```
1  Has legs ................ go to 2
   Has no legs ............. go to 3
2  Has 6 legs .............. beetle
   Has 8 legs .............. spider
3  Has a shell ............. snail
   Has no shell ............ slug
```

Other correct keys, for example starting with "has wings / has no wings", earn the same marks. **[4]**

**8.** The genus should start with a capital letter: "Homo" [1]. The species should be lower case: "sapiens" [1]. Correct handwritten form: Homo sapiens, underlined [1]. **[3]**

**9.** Organisms in a group should share a common ancestor [1]. Organisms can look similar because they live in similar ways rather than because they are closely related [1]; for example, dolphins and sharks both have fins and streamlined bodies, but dolphins are mammals and are more closely related to other mammals than to sharks [1]. **[3]**

**10. (a)** (50 − 12) ÷ 50 × 100 [1] = **76%** [1].

**(b)** K [1], because its base sequence differs from J's at the fewest positions, so it has the most similar sequence and the most recent common ancestor with J [1].

**(c)** Visible features can be similar in unrelated organisms, whereas DNA differences build up over time after groups separate [1]. **[5]**

**11.** When a species splits into two, both start with the same base sequence inherited from the common ancestor [1]. Changes to DNA then build up separately in each group over time [1]. If the split was recent, there has been less time for changes, so the sequences are still very similar [1]. **[3]**

**12.** The two statements describe **different** features (shell and sliminess), so they are not opposites [1]; an animal could be both, or neither, and could not be placed [1]. Rewrite, for example: "1 Has a shell ... go to 2 / Has no shell ... go to 3" [1]. **[3]**

## Where marks are usually lost

- Writing a species definition without "fertile offspring".
- Capitalising the species word or forgetting to underline a handwritten name.
- Keys with steps that are not opposites, or that use opinions such as "large".
- (Extended) Saying species have "the same DNA", or that one species evolved from the other.
- (Extended) Forgetting to subtract the differences before working out the percentage identical.

## Frequently asked questions

**Can a key have more than one correct answer?**
Yes. Any key that uses paired, contrasting, visible features and leads each organism to its own name is accepted.

**Do Core candidates need DNA comparisons?**
No. Outcomes 1.2.5 to 1.2.7 are Supplement content, so they are for Extended candidates only.
