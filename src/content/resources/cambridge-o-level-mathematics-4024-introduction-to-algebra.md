This guide covers subtopic **2.1 Introduction to algebra** in Topic 2, Algebra and graphs, of Cambridge O Level Mathematics (Syllabus D) 4024, 2025–2027 series. The broader [Algebraic Manipulation study guide](/resources/algebraic-manipulation/) introduces 2.1 in a few lines before moving on. This page gives the subtopic its own full treatment, because careless substitution, especially with negative numbers, costs marks in every later topic.

Companion pages: the [introduction to algebra revision notes](/resources/cambridge-o-level-mathematics-4024-introduction-to-algebra-revision-notes/) and the [introduction to algebra practice questions](/resources/cambridge-o-level-mathematics-4024-introduction-to-algebra-practice/).

## What the syllabus asks

The 4024 syllabus lists two learning outcomes for 2.1:

1. Know that letters can be used to represent generalised numbers.
2. Substitute numbers into expressions and formulas.

4024 has two papers, Paper 1 (non-calculator) and Paper 2 (calculator), and every candidate sits both. Substitution appears on both, so you need to be fluent with and without a calculator.

## The vocabulary of algebra

Using the right word helps you read questions correctly.

| Word | Meaning | Example |
|---|---|---|
| Term | A single number, letter or product of them | 5, x, 3ab, −4y² |
| Coefficient | The number multiplying the letters in a term | 3 in 3ab; −4 in −4y² |
| Expression | Terms combined by + or −, with no equals sign | 3x − 2y + 7 |
| Equation | Two expressions that are equal for particular values | 3x − 2 = 10 |
| Formula | A rule connecting quantities, usually with a subject | A = πr² |

An expression can be **simplified** or **evaluated**; an equation is **solved**; a formula has values **substituted** into it.

## Algebraic notation

Algebra drops some symbols, so read each term carefully.

```
3n      means 3 × n
ab      means a × b
n²      means n × n           (not 2 × n)
2n²     means 2 × n × n       (only n is squared)
(2n)²   means 2n × 2n = 4n²
a/b     means a ÷ b
−x²     means −(x × x)        (the square is done first)
```

The difference between 2n² and (2n)² is a frequent source of lost marks. Indices are applied before multiplication, so in 2n² only the n is squared.

## Letters as generalised numbers

A letter can stand for **any** number, not just one unknown value. This lets you write a statement that is true for every case at once.

| In words | Algebra (n is any integer) |
|---|---|
| Three consecutive integers | n, n + 1, n + 2 |
| An even number | 2n |
| An odd number | 2n + 1 (or 2n − 1) |
| Two consecutive odd numbers | 2n + 1, 2n + 3 |
| A multiple of 7 | 7n |
| A number one less than a multiple of 4 | 4n − 1 |

**Worked example.** Show that the sum of any three consecutive integers is a multiple of 3.

```
n + (n + 1) + (n + 2)
= 3n + 3
= 3(n + 1)
```

Because 3(n + 1) is 3 multiplied by an integer, the sum is always a multiple of 3. Checking examples such as 4 + 5 + 6 = 15 does not prove the statement, because it only shows one case. The generalised number does the proof.

**Worked example.** A cinema ticket costs a dollars for an adult and c dollars for a child. Write an expression for the cost, in dollars, of tickets for 2 adults and 3 children.

```
2a + 3c
```

Here the letters stand for prices that are not given. If later told a = 9 and c = 6, the expression gives 2(9) + 3(6) = 18 + 18 = 36 dollars.

## Substitution: method

To substitute, replace each letter with its value **in brackets**, then follow the order of operations: brackets, indices, division and multiplication, addition and subtraction.

Writing the brackets is the single best habit for avoiding sign errors.

**Worked example.** Given a = −3, b = 4 and c = ½, find the value of each expression.

```
(i)   a²          = (−3)²          = 9
(ii)  −a²         = −(−3)²         = −9
(iii) 2a²         = 2 × (−3)²      = 2 × 9 = 18
(iv)  (2a)²       = (2 × −3)²      = (−6)² = 36
(v)   a³          = (−3)³          = −27
(vi)  b − a       = 4 − (−3)       = 7
(vii) 3a − 2b     = 3(−3) − 2(4)   = −9 − 8 = −17
(viii) ab ÷ c     = (−3)(4) ÷ ½    = −12 × 2 = −24
(ix)  (a + b)/c   = (−3 + 4) ÷ ½   = 1 × 2 = 2
```

Points to notice:

- (i) and (ii) differ: in −a² the square is done first, then the negative is applied.
- Squaring a negative gives a positive; cubing a negative gives a negative.
- Dividing by ½ is the same as multiplying by 2.
- In (ix) the fraction line acts as a bracket: the whole of a + b is divided by c.

## Substituting into formulas

A formula connects real quantities, so the answer often has units and may need rounding. On Paper 2, give non-exact answers to 3 significant figures unless the question asks for something else; this is the 4024 convention.

**Worked example (Paper 1 style).** The formula s = ut + ½at² gives the distance s metres moved by an object. Find s when u = 3, a = −2 and t = 5.

```
s = (3)(5) + ½(−2)(5)²
  = 15 + ½(−2)(25)
  = 15 − 25
  = −10
```

The negative answer is meaningful: the object ends up 10 metres behind its starting point. Do not drop the sign.

**Worked example (Paper 1 style).** The formula F = 9C/5 + 32 converts a temperature in degrees Celsius to degrees Fahrenheit. Find F when C = −40.

```
F = 9(−40)/5 + 32
  = −360/5 + 32
  = −72 + 32
  = −40
```

**Worked example (Paper 2 style).** The time T seconds for a pendulum of length l metres to swing is T = 2π√(l/g). Find T when l = 0.8 and g = 9.8.

```
T = 2π√(0.8 ÷ 9.8)
  = 2π√0.081632...
  = 1.7951...
  = 1.80 (3 significant figures)
```

Keep the full calculator value until the end and round only once. Rounding √0.0816 to 0.29 part-way through gives 1.82, which is wrong to 3 significant figures. Note too that 1.80 keeps its final zero, because it is the third significant figure.

**Worked example.** The area of a trapezium is A = ½(a + b)h. Find A when a = 3.6, b = 5.2 and h = 2.5.

```
A = ½(3.6 + 5.2)(2.5)
  = ½(8.8)(2.5)
  = 4.4 × 2.5
  = 11
```

This one is exact, so no rounding is needed.

## Exam technique

The 4024 command words that appear most with this subtopic are:

- **Work out** or **Find**: show the substitution line, then the value. A correct substitution line can earn a method mark even if the arithmetic slips.
- **Show that**: provide structured evidence that leads to the given result. With a generalised number, this means algebra for every case, not a list of examples.
- **Write down**: an answer without significant working, such as an expression for an even number.

When a substituted answer looks strange, such as a negative length, check the signs before moving on. Where the context allows a negative value, as with displacement or temperature, keep it.

## Common mistakes

- Treating 2n² as (2n)².
- Writing −3² = 9. The square applies to 3 only, so −3² = −9, while (−3)² = 9.
- Subtracting a negative incorrectly: 4 − (−3) is 7, not 1.
- Substituting without brackets, so that a = −3 in 3a becomes "3 − 3".
- Rounding part-way through a Paper 2 calculation.
- Using a numerical example as if it proved a general statement.
- Forgetting that the fraction line groups the whole numerator, as in (a + b)/c.
