These notes condense subtopic **E6.4 Trigonometric functions** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027). It is **Extended only** (C6.4 reads "Extended content only"), so it appears on Papers 2 and 4. For full explanations and worked examples, read the [trigonometric functions study guide](/resources/cambridge-igcse-mathematics-0580-trigonometric-functions/); for exam-style questions, use the [trigonometric functions practice questions](/resources/cambridge-igcse-mathematics-0580-trigonometric-functions-practice/).

## The syllabus in two lines

- **E6.4.1** Recognise, sketch and interpret y = sin x, y = cos x and y = tan x for 0° ⩽ x ⩽ 360°.
- **E6.4.2** Solve equations involving sin x, cos x or tan x for 0° ⩽ x ⩽ 360°, such as sin x = √3/2 and 2 cos x + 1 = 0.

## Key terms

| Term | Meaning |
|---|---|
| Period | The horizontal distance after which a graph repeats: 360° for sin and cos, 180° for tan |
| Asymptote | A line the graph approaches but never meets; for tan x, x = 90° and x = 270° |
| Turning point | A maximum or minimum on the sin or cos wave |
| Related acute angle (α) | The angle between 0° and 90° with the same ratio value, ignoring the sign |
| Principal value | The single angle the inverse key gives; it may be negative or the wrong one |
| Range of solutions | The interval in the question, such as 0° ⩽ x ⩽ 360°; answers outside it are rejected |

## Graph facts to recall

```
y = sin x : (0°, 0)  max (90°, 1)   (180°, 0)  min (270°, −1)  (360°, 0)
y = cos x : max (0°, 1)  (90°, 0)  min (180°, −1)  (270°, 0)  max (360°, 1)
y = tan x : (0°, 0)  asymptote x = 90°  (180°, 0)  asymptote x = 270°  (360°, 0)
            tan 45° = 1, tan 135° = −1, tan 225° = 1, tan 315° = −1
```

Recognising a curve: through (0°, 1) means cos; through (0°, 0) and between −1 and 1 means sin; vertical asymptotes mean tan.

## Signs in each quarter

| Quarter | 0° to 90° | 90° to 180° | 180° to 270° | 270° to 360° |
|---|---|---|---|---|
| sin x | + | + | − | − |
| cos x | + | − | − | + |
| tan x | + | − | + | − |
| Angle in terms of α | α | 180° − α | 180° + α | 360° − α |

Also: cos x = sin(90° − x), so cos 70° = sin 20°.

## Equation method in five steps

```
1. Rearrange: get sin x, cos x or tan x on its own.
2. Check: sin or cos outside −1 to 1 → no solutions.
3. Find α from the value without its sign.
4. Place answers in the quarters with the right sign (usually two).
5. Reject answers outside the range; round to 1 d.p. at the very end.
```

**Number of solutions in 0° ⩽ x ⩽ 360°**

| Equation | Solutions |
|---|---|
| sin x = k or cos x = k, with −1 < k < 1, k ≠ 0 | 2 |
| sin x = 0 or tan x = 0 | 3 (0°, 180°, 360°) |
| cos x = 0 | 2 (90°, 270°) |
| sin x = 1 or sin x = −1 or cos x = −1 | 1 |
| cos x = 1 | 2 (0°, 360°) |
| tan x = k, k ≠ 0 | 2 (180° apart) |
| sin x or cos x = k with k > 1 or k < −1 | 0 |

## Two short reminders

**Non-calculator.** 2 sin x + √3 = 0 → sin x = −√3/2 → α = 60° → sin negative in the last two quarters → x = 240° or 300°.

**Calculator.** 8 cos x − 3 = 2 cos x + 2 → 6 cos x = 5 → cos x = 0.8333… → α = 33.557…° → x = 33.6° or 326.4°.

## Exam traps

- Answering only the inverse-key value. Most equations need two answers.
- Using 180° − α for a cosine equation. For cos, the partner of α is 360° − α.
- Writing a negative angle from the calculator as a final answer.
- Dividing only part of an expression when isolating the ratio.
- Joining the branches of tan x across an asymptote in a sketch, or drawing pointed turning points on sin and cos.
- Forgetting 0° and 360° when both ends of the range are included.
- Missing a condition such as "sin x is negative", which removes one of the answers.

## Self-test

1. Write down the coordinates of the minimum point of y = cos x for 0° ⩽ x ⩽ 360°.
2. Write down the equations of the asymptotes of y = tan x for 0° ⩽ x ⩽ 360°.
3. A curve passes through (0°, 0) and (90°, 1). Which of the three graphs is it?
4. Solve cos x = √3/2 for 0° ⩽ x ⩽ 360°.
5. Solve tan x = −1 for 0° ⩽ x ⩽ 360°.
6. Solve 2 sin x = −√2 for 0° ⩽ x ⩽ 360°.
7. (calculator) Solve 4 sin x = 3 for 0° ⩽ x ⩽ 360°.
8. (calculator) Solve 5 cos x + 2 = 0 for 0° ⩽ x ⩽ 360°.
9. Given cos 40° = 0.766 (3 d.p.), find x between 0° and 360° with cos x = −0.766.
10. How many solutions does sin x = −1 have for 0° ⩽ x ⩽ 360°?
11. Solve tan x = 0 for 0° ⩽ x ⩽ 360°.
12. Explain why 3 cos x + 4 = 0 has no solutions.

### Answers

1. **(180°, −1)**
2. **x = 90° and x = 270°**
3. **y = sin x** (tan x also passes through the origin, but tan 90° is undefined)
4. α = 30°, cos positive in the first and last quarters: **x = 30° or 330°**
5. α = 45°, tan negative in the second and fourth quarters: **x = 135° or 315°**
6. sin x = −√2/2, α = 45°: **x = 225° or 315°**
7. sin x = 0.75, α = 48.590…°: **x = 48.6° or 131.4°**
8. cos x = −0.4, α = 66.421…°: **x = 113.6° or 246.4°**
9. cos negative in the middle quarters: **x = 140° or 220°**
10. **One** (x = 270°)
11. **x = 0°, 180° or 360°**
12. cos x = −4/3, which is less than −1, and cos x always lies between −1 and 1.
