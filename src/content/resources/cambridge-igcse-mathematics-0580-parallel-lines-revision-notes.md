These notes condense subtopic **3.6 Parallel lines** from Topic 3 of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. The statement is the same for both tiers: "Find the gradient and equation of a straight line parallel to a given line." Items that need a line in the form ax + by = c, or a gradient calculated from coordinates, use Extended skills and are marked *(Extended)*. For worked examples, read the [parallel lines study guide](/resources/cambridge-igcse-mathematics-0580-parallel-lines/); for exam-style questions, use the [parallel lines practice questions](/resources/cambridge-igcse-mathematics-0580-parallel-lines-practice/).

## The rule

```
Parallel lines  <->  equal gradients
Same gradient AND same intercept  ->  the same line
```

## Key terms

| Term | Meaning |
|---|---|
| Parallel | Always the same distance apart; never meet |
| Gradient, m | Steepness; equal for parallel lines |
| y-intercept, c | Where the line crosses the y-axis; differs for different parallel lines |
| Parallel to the x-axis | Horizontal: y = k |
| Parallel to the y-axis | Vertical: x = k |
| Trapezium | Quadrilateral with exactly one pair of parallel sides |
| Parallelogram | Quadrilateral with two pairs of parallel sides |

## Method: equation of a parallel line

```
1. m = gradient of the given line (rearrange if needed)
2. y = mx + c with the SAME m
3. Substitute the given point -> solve for the NEW c
4. Write y = mx + c; check the point fits
```

**Reminder examples**

```
Parallel to y = 4x - 1 through (0, 7):    y = 4x + 7
Parallel to y = -3x + 2 through (2, 1):   1 = -6 + c, c = 7   ->  y = -3x + 7
Parallel to y = 0.5x through (-4, 3):     3 = -2 + c, c = 5   ->  y = 0.5x + 5
```

## Lines parallel to the axes

| Through the point | Parallel to the x-axis | Parallel to the y-axis |
|---|---|---|
| (3, –2) | y = –2 | x = 3 |
| (–5, 6) | y = 6 | x = –5 |
| (0, 0) | y = 0 (the x-axis) | x = 0 (the y-axis) |

## *(Extended)* Given line in the form ax + by = c

Keep a and b; change only the constant.

```
Parallel to 3x - y = 4 through (1, 5):
3x - y = d,   3(1) - 5 = d = -2   ->   3x - y = -2   (i.e. y = 3x + 2)

Parallel to x + 2y = 8 through (4, -1):
x + 2y = d,   4 + 2(-1) = d = 2   ->   x + 2y = 2
```

Gradient check: x + 2y = 8 gives y = –½x + 4, so the gradient is –½ for both lines.

## Spotting parallel lines

Rearrange each to y = mx + c and compare m.

```
y = 2x + 7        m = 2
2y = 4x - 3       y = 2x - 1.5,   m = 2    parallel to the first
y = 7 - 2x        m = -2                   not parallel
4x - 2y = 1       y = 2x - 0.5,   m = 2    parallel to the first
```

## Unknowns and shapes

- y = (2k + 1)x – 3 parallel to y = 7x + 1: 2k + 1 = 7, so **k = 3**.
- Trapezium or parallelogram from coordinates: compare gradients of opposite sides. One equal pair means a trapezium; two equal pairs means a parallelogram.

## Exam traps

- Copying the original intercept into the new equation.
- Using –1/m (the perpendicular rule) by mistake.
- Reading the gradient of ax + by = c as a.
- Treating y = 3x + 1 and y = 1 + 3x as two parallel lines.
- Writing x = k for a line parallel to the x-axis.
- Leaving the answer as values of m and c instead of an equation.

## Self-test

1. Write down the gradient of any line parallel to y = –6x + 1.
2. Find the equation of the line parallel to y = 2x – 5 through (0, 3).
3. Find the equation of the line parallel to y = 3x + 4 through (2, 1).
4. Find the equation of the line parallel to y = –x + 9 through (–3, 5).
5. Write down the equation of the line parallel to the x-axis through (4, –7).
6. Write down the equation of the line parallel to the y-axis through (4, –7).
7. Are y = 5x + 2 and y = 2 + 5x parallel? Explain.
8. y = (k + 2)x – 1 is parallel to y = 6x + 3. Find k.
9. *(Extended)* Find the gradient of any line parallel to 4x + 5y = 20.
10. *(Extended)* Find the equation of the line parallel to 4x + 5y = 20 through (5, 2), in the form ax + by = c.
11. *(Extended)* Which two of these lines are parallel: A y = 3x – 1, B 6x – 2y = 5, C 3y = x + 2?
12. *(Extended)* P(0, 0), Q(6, 2), R(7, 5), S(1, 3). Is PQRS a parallelogram?

### Answers

1. **–6**
2. **y = 2x + 3**
3. 1 = 6 + c, c = –5: **y = 3x – 5**
4. 5 = 3 + c, c = 2: **y = –x + 2**
5. **y = –7**
6. **x = 4**
7. **No**: same gradient and same intercept, so they are the **same line**
8. k + 2 = 6: **k = 4**
9. y = –0.8x + 4: **–4/5**
10. 4(5) + 5(2) = 30: **4x + 5y = 30**
11. B is y = 3x – 2.5, gradient 3: **A and B** (C has gradient 1/3)
12. PQ and SR both have gradient 1/3; QR and PS both have gradient 3: **yes**
