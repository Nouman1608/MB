These notes condense section 1.5 of the Cambridge O Level Statistics (4040) syllabus for examination in 2025, 2026 and 2027: "Types of data and variable", including the terms qualitative, quantitative, discrete and continuous. Full explanations and worked examples are in the [types of data study guide](/resources/cambridge-o-level-statistics-4040-types-of-data-and-variable/), and the [types of data practice questions](/resources/cambridge-o-level-statistics-4040-types-of-data-and-variable-practice/) give exam-style drill. The rest of topic 1 is summarised in the [data collection revision notes](/resources/o-level-statistics-data-collection-revision-notes/).

## Key terms

| Term | Meaning | Examples |
|---|---|---|
| Variable | A feature that can change from one member of the population to another | Height, colour, score |
| Qualitative | Non-numerical categories or descriptions | Blood group, nationality, shirt number |
| Quantitative | Numerical amounts that can be meaningfully averaged | Mass, number of pets |
| Discrete | Quantitative data that can take only separate values | Number of goals, shoe size |
| Continuous | Quantitative data that can take any value in a range | Time, length, temperature |

## Decision chart in words

1. Is the value a number with a size, so that adding or averaging makes sense?
   - No: **qualitative**. Stop.
   - Yes: **quantitative**. Go to step 2.
2. Is the value **counted**, or are only certain separate values possible?
   - Yes: **discrete**.
   - No, it is **measured** and any value in a range is possible: **continuous**.

## Why the type matters

| Type | Tables | Diagrams | Averages that make sense |
|---|---|---|---|
| Qualitative | Category frequency table; two-way table | Pie chart, bar chart with gaps, pictogram | Mode |
| Discrete | Ungrouped frequency table; grouped table for large ranges | Bar chart or vertical line graph with gaps | Mean, median, mode |
| Continuous | Grouped table with boundaries that leave no gaps | Histogram, frequency polygon, cumulative frequency curve or polygon | Mean, median, modal class |

## Recorded values of continuous data

A continuous value is always rounded when recorded, so it represents an interval.

- To the nearest whole unit: recorded value ± 0.5.
- To the nearest 0.1: ± 0.05. To the nearest 0.01: ± 0.005.
- To the nearest 10: ± 5.

**Worked reminder.** A length recorded as 6.3 cm to the nearest mm lies in 6.25 ≤ l < 6.35. The class 6.0–6.4 cm has boundaries 5.95 and 6.45, and width 0.5 cm.

**Age in completed years.** Rounding is down, not to the nearest. Age 17 means 17 ≤ age < 18. The class 10–14 years has boundaries 10 and 15, width 5, and midpoint 12.5.

## Borderline cases

- **Shoe size**: discrete, because only halves and whole sizes exist.
- **Money**: changes in the smallest unit of currency, so discrete in principle; treated as continuous when values are large and grouped.
- **Marks on a test**: discrete (whole or half marks).
- **Rating on a scale of 1 to 5**: ordered categories; state how you treat it.
- **Number labels** (bus route, house number, phone number): qualitative.

## Exam traps

- "Discrete means whole numbers" is wrong; discrete means separate values, which can include halves.
- A variable is continuous even if the recorded values are whole numbers: time in whole minutes is still continuous.
- "Quantitative" alone is incomplete when the question offers discrete and continuous as well; give both words.
- A numerical code is not quantitative; use the "does the mean make sense?" test.
- Gaps between bars belong to qualitative and discrete data; a histogram (no gaps) is for continuous data.
- Do not use ± 0.5 for ages in completed years.
- When asked to "give a reason", say counted or measured, not just "because it is a number".

## Quick self-test

1. Classify "number of rooms in a house".
2. Classify "favourite colour".
3. Classify "time to boil a kettle".
4. Is a bus route number quantitative? Give a reason.
5. Why is shoe size discrete even though it can be 7½?
6. A mass is recorded as 58 kg to the nearest kilogram. Write the interval in which the true mass lies.
7. A time is recorded as 4.27 s to the nearest 0.01 s. Write the interval.
8. Give the class boundaries of the age class 30–39 years, ages in completed years.
9. Give the class boundaries of the length class 30–39 cm, lengths to the nearest cm.
10. Which average is the only suitable one for qualitative data with no order?
11. Name a suitable diagram for the heights of 80 plants, and say why.
12. A pupil writes "journey time in minutes is discrete because I recorded whole minutes". Correct the pupil.

### Answers

1. Quantitative, discrete (counted).
2. Qualitative.
3. Quantitative, continuous (measured).
4. No. It is a label, so it is qualitative; route 20 is not twice route 10.
5. Only certain separate sizes exist, such as 7, 7½ and 8; a size between them is not possible.
6. 57.5 ≤ m < 58.5 kg.
7. 4.265 ≤ t < 4.275 s.
8. 30 and 40 years.
9. 29.5 and 39.5 cm.
10. The mode.
11. A histogram (or cumulative frequency polygon), because height is continuous, so bars must touch with no gaps.
12. Time is measured and can take any value, so it is continuous; the values were only rounded to whole minutes when recorded.

## Frequently asked questions

**What is the quickest way to tell discrete from continuous?**
Ask whether the value was counted or measured. Counted values are discrete; measured values are continuous.

**Is a percentage discrete or continuous?**
It depends on what it comes from. A percentage worked out from a measurement, such as the percentage of fat in a food, is continuous. A percentage of a fixed number of items counted, such as 7 out of 20 questions, can take only certain values.
