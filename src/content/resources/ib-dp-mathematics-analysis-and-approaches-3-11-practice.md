These questions cover syllabus section 3.11 of IB DP Mathematics: Analysis and Approaches (first assessment 2021), which is HL only: relationships between trigonometric functions and the symmetry properties of their graphs. Questions are labelled "(calculator-free)" or "(calculator allowed)". The methods are in the [3.11 study guide](/resources/ib-dp-mathematics-analysis-and-approaches-3-11/) and the [3.11 revision notes](/resources/ib-dp-mathematics-analysis-and-approaches-3-11-revision-notes/).

## Section A

**1.** (calculator-free) Write each expression in terms of a single trigonometric function of θ.

**(a)** sin(π + θ) **[1]**

**(b)** cos(π/2 + θ) **[1]**

**(c)** tan(2π − θ) **[1]**

**2.** (calculator-free) Given that cos α = 0.6 and α is acute, write down the value of:

**(a)** cos(π − α) **[1]**

**(b)** cos(π + α) **[1]**

**(c)** sin(π/2 − α) **[1]**

**(d)** cos(−α) **[1]**

**3.** (calculator-free) Simplify sin(π − x) + sin(π + x). **[2]**

**4.** (calculator-free) Write down the equations of the lines of symmetry of the graph of y = cos x for 0 ≤ x ≤ 2π. **[2]**

**5.** (calculator allowed) The equation sin x = 0.35 has the solution x = 0.358 (3 s.f.) in 0 ≤ x ≤ π/2. Find the other solutions in −2π ≤ x ≤ 2π. **[3]**

**6.** (calculator-free) Use compound angle identities to show that tan(π/2 − θ) = cot θ. **[2]**

## Section B

**7.** (calculator allowed) Let f(x) = sin x + cos x.

**(a)** Show that f(π/2 − x) = f(x). **[2]**

**(b)** Hence write down the equation of a line of symmetry of the graph of f. **[1]**

**(c)** Given that f(0.2) = 1.18 (3 s.f.), write down another value of x in 0 ≤ x ≤ π/2 for which f(x) = 1.18. **[1]**

**8.** (calculator-free) Let θ be acute with tan θ = 2. Find the exact value of:

**(a)** tan(π + θ) **[1]**

**(b)** tan(π/2 − θ) **[1]**

**(c)** sin(π − θ) **[2]**

**(d)** cos(3π/2 − θ) **[2]**

**9.** (calculator-free)

**(a)** Use a compound angle identity to show that cos(x + π/2) = −sin x. **[2]**

**(b)** Hence describe a single transformation that maps the graph of y = cos x onto the graph of y = −sin x. **[1]**

**(c)** Using a result about sin(π − x), describe a reflection that maps the graph of y = sin x onto itself. **[2]**

**10.** (calculator-free) Simplify sin(π − x) cos(−x) / (cos(π + x) sin(π/2 + x)), where it is defined. **[3]**

**11.** (calculator-free)

**(a)** Show that g(x) = x sin x is an even function. **[2]**

**(b)** Show that h(x) = x² tan x is an odd function. **[2]**

**12.** (calculator-free) Solve sin(π − x) = cos(π + x) for 0 ≤ x ≤ 2π. **[4]**

## Answers

**1. (a)** **−sin θ** [1]

**(b)** **−sin θ** [1]

**(c)** **−tan θ** [1]

**2. (a)** **−0.6** [1]

**(b)** **−0.6** [1]

**(c)** **0.6** [1]

**(d)** **0.6** [1]

*Examiner insight:* (c) uses the swap: sin(π/2 − α) = cos α, not sin α = 0.8.

**3.** sin(π − x) = sin x and sin(π + x) = −sin x [1], so the sum is **0** [1]

**4.** **x = π** [1], and **x = 0** and **x = 2π** [1]

*Examiner insight:* x = π is the obvious answer; x = 0 and x = 2π also count, because the graph of y = cos x is symmetric about every line x = kπ.

**5.** π − 0.3576 = **2.78** [1]; 0.3576 − 2π = **−5.93** [1]; 2.784 − 2π = **−3.50** [1]

**6.** sin(π/2 − θ) = cos θ and cos(π/2 − θ) = sin θ [1], so tan(π/2 − θ) = cos θ/sin θ = **cot θ** [1]

**7. (a)** f(π/2 − x) = sin(π/2 − x) + cos(π/2 − x) [1] = cos x + sin x = f(x) [1]

**(b)** **x = π/4** [1]

**(c)** π/2 − 0.2 = **1.37** [1]

*Examiner insight:* x and π/2 − x are reflections of each other in x = π/4, which is why (b) follows from (a) with no further working.

**8. (a)** tan has period π: **2** [1]

**(b)** cot θ = **1/2** [1]

**(c)** sin(π − θ) = sin θ [1]; with tan θ = 2 and θ acute, the triangle has hypotenuse √5, so sin θ = **2√5/5** [1]

**(d)** cos(3π/2 − θ) = cos(3π/2) cos θ + sin(3π/2) sin θ = −sin θ [1] = **−2√5/5** [1]

**9. (a)** cos(x + π/2) = cos x cos(π/2) − sin x sin(π/2) [1] = 0 − sin x = **−sin x** [1]

**(b)** **Translation π/2 to the left** [1]

**(c)** sin(π − x) = sin x, so points x and π − x have the same height [1]; the graph is mapped onto itself by **reflection in the line x = π/2** [1]

**10.** Numerator: sin x cos x [1]. Denominator: (−cos x)(cos x) = −cos²x [1]. Expression = sin x cos x/(−cos²x) = **−tan x** [1]

**11. (a)** g(−x) = (−x) sin(−x) = (−x)(−sin x) [1] = x sin x = g(x), so g is even [1]

**(b)** h(−x) = (−x)² tan(−x) = x²(−tan x) [1] = −h(x), so h is odd [1]

**12.** sin(π − x) = sin x [1] and cos(π + x) = −cos x [1]. If cos x = 0 then sin x = ±1 ≠ 0, so divide: tan x = −1 [1]. **x = 3π/4, 7π/4** [1]

*Examiner insight:* Both solutions are needed for the final mark; tan repeats every π, so 3π/4 + π = 7π/4 is in the interval.

## Where marks are usually lost

- Confusing π − θ with π + θ, as tested in questions 1 and 3.
- Forgetting that π/2 ± θ swaps sin and cos.
- Using the quadrant of θ rather than of the new angle to fix the sign.
- Giving a sketch instead of an identity-based argument when asked to show a result.
- Stopping after the partner solution instead of adding or subtracting periods.
