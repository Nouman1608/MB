## Answers

**1.** (A) *بناتی ہیں* [1]: *ہر صبح* signals a habit; *امی* takes the respect plural.

**2.** (A) *چلی گئی* [1]: *پچھلی رات* is past, and *بجلی* is feminine.

**3.** (B) *دی* [1]: with *نے*, the verb agrees with the direct object *گھڑی* (feminine singular);
*بہن کو* is the indirect object and does not control agreement.

**4.** (A) *سے* [1]: comparison.

**5.** (C) *کچھ* [1]: *کچھ دیر* means "some time"; *کوئی* and *کسی* need a countable noun.

**6.** (A) *سے* [1]: *کسی چیز سے ڈر لگنا*.

**7.** (B) *آسانی* [1]: the gap needs a noun between *بڑی* and *سے*; (D) would repeat *سے*.

**8.** (C) *لڑکوں* [1]: before *نے* the noun takes the oblique plural.

**9.** One mark each [10]:

| Gap | Answer | Rule |
|---|---|---|
| (a) | B لگتا | habitual present; *میلہ* is masculine singular |
| (b) | B نے | transitive verb *بنایا* in the past needs *نے* |
| (c) | A سے | comparison with *زیادہ* |
| (d) | A کا | *رش* is masculine: *کا رش* |
| (e) | C گئیں | respect plural for *پرنسپل صاحبہ*, feminine |
| (f) | A اعتماد | a noun is needed in *بڑے ... سے* |
| (g) | A انوکھا | agrees with masculine *خیال* |
| (h) | A کامیاب | *سب سے* + plain adjective; C doubles the superlative |
| (i) | B بجائیں | with *نے*, agrees with feminine plural *تالیاں* |
| (j) | A حصہ | collocation *حصہ لینا*; *شرکت* goes with *کرنا* |

**10.** Two points [2]: the verb follows *نے*, so it must agree with the object, not the subject [1];
the object *تالیاں* is feminine plural, so the form is *بجائیں*, while *بجایا* is masculine singular
[1].

**11.** One mark each [3]: (a) conjugation of verbs / subject-verb agreement (habitual present agreeing
with *میلہ*); (f) parts of speech (a noun needed, not an adjective); (j) vocabulary appropriate to the
context (the collocation *حصہ لینا*).

**12.** (a) *جائیں گی* [1]: the subject *سب لڑکیاں* is feminine plural, so the future ending is
*ـیں گی*. (b) *انتظار* [1]: the collocation is *کسی کا انتظار کرنا*; *امید* goes with *رکھنا* or
*کرنا* with *کی* and *سے* (*کسی سے امید رکھنا*), so it does not fit *ان کا ... کیا*.

## Where marks are usually lost

- **Question 3**: agreeing with *بہن* instead of the direct object *گھڑی*.
- **Gap (e)**: choosing singular *گئی*, forgetting the respect plural.
- **Gap (h)**: choosing *کامیاب ترین* because it "sounds more advanced".
- **Gap (j)**: choosing *شرکت* because the meaning is right, without checking the verb that follows.
