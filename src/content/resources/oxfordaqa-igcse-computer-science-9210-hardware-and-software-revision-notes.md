Condensed notes for section **3.4.1 Hardware and software** of OxfordAQA International GCSE Computer Science
(9210). Explanations and worked examples are in the [Hardware and software study
guide](/resources/oxfordaqa-igcse-computer-science-9210-hardware-and-software/).

## What the specification asks

- **Define** the terms **hardware** and **software**.
- Understand the **relationship** between them.

## Definitions

| Term | Definition |
|---|---|
| Hardware | The physical components of a computer system, which you can touch |
| Software | The programs (sets of instructions) that tell the hardware what to do |

Software is not physical. It is stored as binary data and run by the processor.

## Examples

| Hardware | Software |
|---|---|
| CPU, motherboard | Operating system |
| RAM, ROM | Word processor |
| Hard disk drive, solid state drive | Web browser |
| Keyboard, mouse, microphone, scanner | Games |
| Monitor, speaker, printer | Utility programs such as anti-virus |
| Network card, cables | The program in an embedded device, such as a washing machine |

## Quick test

- Could you drop it on your foot? Yes means hardware.
- Is it a list of instructions? Yes means software.
- A **disc** is hardware; the **game** stored on it is software.
- A **file** is data held on hardware. It is not hardware.

## The relationship

1. **Hardware needs software.** The processor needs a program to tell it which instructions to carry out. Without
   software, the hardware is not useful.
2. **Software needs hardware.** A program must be stored (storage, memory), executed (processor) and its results shown
   (output devices).
3. **Software is stored on hardware and run by hardware.** Secondary storage holds the program; it is copied to RAM; the
   processor fetches and executes the instructions.
4. **One machine, many jobs.** The same hardware can do different tasks by running different software.
5. **Hardware limits software.** A program may need a minimum amount of memory, storage or processor speed.

Sentence to use: "Hardware is the physical parts and software is the instructions that tell it what to do. Software
cannot run without hardware, and hardware cannot do anything useful without software."

## Summary table

| | Hardware | Software |
|---|---|---|
| Physical? | Yes | No |
| Example | Processor | Operating system |
| Role | Runs the instructions, stores and moves data, inputs and outputs | Gives the instructions |
| Without the other | Does nothing useful | Cannot run |

## Worked examples

**Classify: solid state drive, spreadsheet, speaker, operating system.** Hardware: solid state drive, speaker.
Software: spreadsheet, operating system.

**Explain why a new program runs slowly on an old computer.** The program needs more processing power or memory than the
hardware has, so the processor takes longer to execute the instructions. The software has changed but the hardware has
not.

**Explain why a computer with no operating system cannot be used.** The hardware is working, but there are no instructions
to manage the processor, memory and devices, so it cannot start up or run other programs.

**Explain why two identical laptops can behave differently.** The hardware is the same, but they have different software
installed, so they carry out different instructions.

## Exam traps

- **"Hardware is the parts of the computer."** Add that they are physical.
- **"Software is the programs."** Add that they are instructions that tell the hardware what to do.
- **Files called hardware.** A file is data, stored on hardware.
- **Operating system called hardware** or **memory card called software.**
- **One-way relationship.** Explain both directions.
- **"Inside is hardware, outside is software."** The case, the screen and the keyboard are hardware.
- **Vague words.** Use "components", "instructions" and "programs".
- **Software damaged by being dropped.** Only hardware can be physically damaged.

## Key terms

| Term | Meaning |
|---|---|
| Component | A physical part of a computer system |
| Program | A set of instructions that a computer can follow |
| Instruction | A single step that the processor can carry out |
| Operating system | Software that manages the computer's resources |
| Input device | Hardware that sends data into a computer |
| Output device | Hardware that presents data from a computer |

## Self-test

1. Define hardware.
2. Define software.
3. State whether a keyboard is hardware or software.
4. State whether a web browser is hardware or software.
5. State whether an operating system is hardware or software.
6. Explain why software cannot run without hardware.
7. Explain why hardware needs software.
8. A game is stored on a DVD. State which is hardware and which is software.
9. State what is meant by saying that the same computer can do different jobs.
10. A phone is dropped and the screen cracks. State whether this is a hardware or a software fault.

**Answers:**
1. The physical components of a computer system.
2. The programs (sets of instructions) that tell the hardware what to do.
3. Hardware.
4. Software.
5. Software.
6. The processor must execute the instructions, and memory or storage must hold them, so the program needs hardware.
7. Without software the processor has no instructions to carry out, so it cannot do anything useful.
8. The DVD is hardware; the game is software.
9. Different software can be installed and run on the same hardware, so one computer can do many tasks.
10. A hardware fault.
