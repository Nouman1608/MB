These notes condense section 13.2 of Cambridge IGCSE ICT 0417, "Tables": working with tables within documents. For explanations and a full worked table task, read the [tables study guide](/resources/cambridge-igcse-ict-0417-tables/), then try the [tables practice questions](/resources/cambridge-igcse-ict-0417-tables-practice/).

## Syllabus coverage

| Syllabus wording | What to be able to do |
|---|---|
| Create a table with a specified number of rows and columns | Insert the exact size; count heading and title rows |
| Place text or objects in a table | Type, paste or insert images into cells |
| Edit a table and its contents | Insert and delete rows and columns; merge cells |
| Format a table | Horizontal and vertical cell alignment; show or hide gridlines; wrap text in a cell; shade cells; adjust row height and column width |

## Creating and filling

- **Rows** go across; **columns** go down.
- Count: data rows + heading row (+ title row if inside the table).
- Use **insert table** with exact numbers, not drawing.
- **Tab** moves to the next cell; Tab in the last cell adds a row.
- Resize images to fit cells, keeping the aspect ratio.

## Editing

| Task | Correct command | Common error |
|---|---|---|
| Add a row | Insert row above or below | Typing below the table, which starts a new paragraph |
| Add a column | Insert column left or right | Table pushed past the right margin |
| Remove a row | Delete rows | Pressing Delete, which only clears contents |
| Remove a column | Delete columns | Clearing text only |
| Title across the top | Merge the cells in that row | Merging cells in other rows too |

## Cell alignment

**Horizontal:** left, right, centre, fully justified.

**Vertical:** top, middle, bottom.

| Content | Usual alignment |
|---|---|
| Text such as names | Left |
| Numbers and prices | Right |
| Headings | Centre (and middle vertically if asked) |
| Long text in a wide cell | Fully justified |

Vertical alignment is only visible when the row is taller than its contents.

## Other formatting

| Setting | What it does | Why use it |
|---|---|---|
| Show gridlines | Lines around every cell are visible (borders applied) | Data tables easy to read across and down |
| Hide gridlines | No lines visible | Tables used only to line up forms or lists |
| Wrap text in a cell | Long text continues on new lines inside the cell | Keeps columns narrow, shows all text |
| Shading | Background colour in cells | Highlights the heading row or alternate rows |
| Row height | Exact or at-least height | Room for wrapped text or images |
| Column width | Exact width in cm | Fit data; fill the text width |

## Width calculation

Remaining width = text width - fixed columns; divide by the number of equal columns.

*Example:* text width 16 cm, first column 4 cm, three equal columns: (16 - 4) / 3 = 4 cm each.

## Instruction checklist

Before saving a table task, check each of these against the instruction:

- number of rows and columns, including heading and title rows;
- merged cells exactly as named;
- horizontal **and** vertical alignment of headings and data;
- gridlines shown or hidden as asked;
- wrapping, shading colour, row heights and column widths;
- the whole table within the page margins.

## Key terms

| Term | Meaning |
|---|---|
| Cell | The box where a row and a column meet |
| Merge cells | Join adjacent cells into one |
| Gridlines | The lines separating the cells of a table |
| Cell alignment | Position of content within a cell, horizontally and vertically |
| Fully justified | Text spread so both edges are straight |
| Shading | A coloured background applied to cells |
| Wrap text | Long text continues on further lines within the same cell |

## Exam traps

- Read whether the instruction gives **columns or rows first**.
- Include the **heading row** in the row count.
- **Delete key** clears contents; **delete rows** removes the row.
- "Centre horizontally **and** vertically" needs **two** settings.
- Show gridlines means **all** cell lines, not only the outer border.
- Use **exact** measurements when given; do not drag.
- Merging the wrong cells loses the structure and the data cells.
- Light shading keeps text **readable**.

## Self-test

1. A table needs 15 data rows and a heading row. How many rows should be inserted?
2. Which way do columns run?
3. What happens when Tab is pressed in the last cell of a table?
4. How do you add two rows at once?
5. What is the difference between pressing Delete and using delete rows?
6. Why are cells merged in the first row of a table?
7. List the four horizontal cell alignments named in the syllabus.
8. List the three vertical cell alignments.
9. Why are prices usually right-aligned?
10. When would gridlines be hidden?
11. What does wrapping text in a cell do to the row?
12. A 15 cm wide table has one 5 cm column and two equal columns. How wide is each equal column?

## Self-test answers

1. 16.
2. Down the table (vertically).
3. A new row is added.
4. Select two rows, then insert rows above or below.
5. Delete clears the cell contents; delete rows removes the rows themselves.
6. To make a title span the full width of the table.
7. Left, right, centre, fully justified.
8. Top, middle, bottom.
9. So the digits line up by place value and can be compared.
10. When the table is used only to arrange content, such as a form or list, and no lines are wanted.
11. It becomes taller so the extra lines of text fit.
12. (15 - 5) / 2 = 5 cm each.
