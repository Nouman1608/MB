**Syllabus:** Cambridge International AS & A Level Chemistry 9701, 2025–2027, **A Level** subtopic
35.2: "predict the type of polymerisation reaction for a given monomer or pair of monomers" and
"deduce the type of polymerisation reaction which produces a given section of a polymer molecule".

## Addition or condensation: the comparison

| Feature | Addition | Condensation |
|---|---|---|
| What the monomer needs | C=C (not in a benzene ring) | two reactive groups that can form ester or amide links |
| By-product | none | H₂O or HCl at each link |
| Backbone | all carbon | contains –COO– or –CONH– |
| Repeat unit formula vs monomer | identical | monomers − small molecules |
| Examples | poly(ethene), poly(chloroethene), poly(propene) | PET, nylon-6,6, poly(lactic acid), polypeptides |

## From monomers: ask three questions in order

1. **C=C outside a ring?** → **addition**. Other groups become side groups.
2. **No C=C, but two linkable groups per molecule?** → **condensation**.
   - –OH + –COOH (or –COCl) → polyester
   - –NH₂ + –COOH (or –COCl) → polyamide
   - Both groups on one molecule → single-monomer condensation polymer
3. **Neither?** → **no polymer** (or only a small molecule such as a single ester or diester).

## From a polymer section: read the backbone

- Backbone **only C atoms** → **addition**. Monomer: two-carbon unit with C=C restored.
- Backbone with **O or N** in ester or amide links → **condensation**. Monomers: break at C–O / C–N,
  add back H and OH.
- **Side groups** (–COOCH₃, –CONH₂, –COOH, –OH, –C₆H₅, –Cl, –CN) do not change the type.

## Quick classification table

| Monomer(s) | Type | Polymer section or repeat unit |
|---|---|---|
| CH₂=CH₂ | addition | –CH₂CH₂– |
| CH₂=CHCl | addition | –CH₂CHCl– |
| CH₂=CHC₆H₅ | addition | –CH₂CH(C₆H₅)– |
| CH₂=CHCOOH | addition | –CH₂CH(COOH)– |
| CH₂=C(CH₃)COOCH₃ | addition | –CH₂C(CH₃)(COOCH₃)– |
| HOCH₂CH₂OH + HOOCC₆H₄COOH | condensation | –OCH₂CH₂OOCC₆H₄CO– |
| H₂N(CH₂)₆NH₂ + ClOC(CH₂)₄COCl | condensation | –NH(CH₂)₆NHCO(CH₂)₄CO– |
| H₂NCH(CH₃)COOH | condensation | –NHCH(CH₃)CO– |
| CH₃CH₂OH + CH₃COOH | none | single ester only |

## Formula evidence

- Addition: repeat unit formula **=** monomer formula (nothing lost). Empirical formula of polymer =
  empirical formula of monomer.
- Condensation, one monomer: repeat unit = monomer − H₂O.
- Condensation, two monomers: repeat unit = monomer A + monomer B − 2H₂O (or − 2HCl).

## When the pair of monomers is two alkenes

- Two different alkenes can join by **addition** into one chain, giving an addition **copolymer**.
- The test is the same: both have C=C, no small molecule is lost, and the backbone is all carbon.
- Example: ethene with chloroethene gives a chain containing both –CH₂CH₂– and –CH₂CHCl– units.

## Equations: what each type looks like

    n CH₂=CHCl → –[CH₂CHCl]ₙ–                                   (addition: no by-product)
    n HOCH₂COOH → –[OCH₂CO]ₙ– + n H₂O                           (condensation: one monomer)
    n H₂N(CH₂)₆NH₂ + n HOOC(CH₂)₄COOH → –[NH(CH₂)₆NHCO(CH₂)₄CO]ₙ– + 2n H₂O

If you find yourself writing a by-product for an alkene, or no by-product for a condensation, go
back and recheck the type.

## Key terms

| Term | Meaning |
|---|---|
| addition polymerisation | monomers with C=C join with no loss of atoms |
| condensation polymerisation | monomers join with loss of a small molecule at each link |
| monomer | small molecule that joins repeatedly to form a polymer |
| repeat unit | section of the chain that repeats |
| backbone | main chain of atoms running through the polymer |
| side group | atom or group attached to the backbone but not part of it |
| copolymer | polymer made from two different monomers |

## Exam traps

- A C=C **always** points to addition, even if –COOH, –OH or –CONH₂ is also present.
- A **benzene ring** does not undergo addition polymerisation.
- **Side-chain esters** do not make a polymer a polyester.
- **One** reactive group per molecule means no chain.
- Two diols, or two diacids, cannot link to each other.
- Addition polymers have **no by-product**; never add "+ H₂O" to an addition equation.
- When asked to "deduce the type", state the evidence from the backbone, not just the answer.
- A repeat unit of an addition polymer has **two** backbone carbons from each monomer; drawing
  three or four backbone carbons for one alkene monomer is a common slip.

## Self-test

1. Predict the type of polymerisation for CH₂=CHCH₃.
2. Predict the type for HOCH₂CH₂COOH.
3. Why does CH₂=CHCOOCH₃ not form a polyester?
4. Can hexane-1,6-diamine alone form a polymer? Explain.
5. Deduce the type of polymer in –CH₂CCl₂CH₂CCl₂–.
6. Deduce the type of polymer in –NH(CH₂)₂NHCO(CH₂)₂CO–.
7. Give the monomer of –CH₂CH(CN)–.
8. Why does benzene-1,4-dicarboxylic acid with ethane-1,2-diol give a condensation polymer, not an
   addition polymer?
9. A repeat unit has formula C₂H₃Cl and so does its monomer. Which type of polymerisation?
10. Methanol is mixed with propanedioic acid, HOOCCH₂COOH. Does a polymer form?
11. Predict the type for H₂NC₆H₄COOH.
12. Give the evidence that –CH₂C(CH₃)(COOCH₃)– comes from addition polymerisation.

**Answers:**

1. Addition (C=C).
2. Condensation (–OH and –COOH in one molecule).
3. The C=C undergoes addition; the ester group is a side group and does not form links.
4. No: both groups are –NH₂, which cannot react with each other to form amide links.
5. Addition: the backbone contains only carbon (monomer CH₂=CCl₂).
6. Condensation: amide links in the backbone (polyamide).
7. Propenenitrile, CH₂=CHCN.
8. The ring has delocalised π electrons, not an isolated C=C; the –COOH groups react with –OH groups.
9. Addition: the formulae are identical, so nothing was lost.
10. No: methanol has only one –OH, so the chain cannot grow (a diester can form).
11. Condensation (polyamide from –NH₂ and –COOH on one molecule).
12. The backbone is all carbon; the ester is a side group; the repeat unit formula equals the
    monomer formula, C₅H₈O₂.
