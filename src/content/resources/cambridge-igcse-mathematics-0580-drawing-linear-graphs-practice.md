These questions cover subtopic 3.2 Drawing linear graphs of the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. Questions marked **(Extended)** use equations in forms other than y = mx + c, which only the Extended tier is given; all others suit both tiers. Each question is labelled (non-calculator) or (calculator). Use graph paper where a question asks you to draw; readings from your own graph are accepted within a small tolerance.

**13.** (non-calculator) The lines x = –2, y = 1 and y = x + 5 are drawn on one grid. They enclose a triangle.

**(a)** Find the coordinates of the three vertices of the triangle. **[3]**

**(b)** Find the area of the triangle. **[1]**

## Answers

**1.** x = –2: y = 3(–2) – 2 = **–8**; x = 0: y = **–2** [1]; x = 2: y = 3(2) – 2 = **4** [1]

**2. (a)** **y = 7** [1]

**(b)** **x = –2** [1]

*Examiner insight:* the horizontal line keeps the y-coordinate fixed, so its equation uses y. Writing x = 7 describes a vertical line.

**3. (a)** x = –4: **6**; x = 0: **4** [1]; x = 2: **3**; x = 6: **1** [1]

**(b)** y falls by 1 for every 2 added to x, so y = 0 when x = 8: **(8, 0)** [1]

**4.** The step from x = 1 to x = 2 is –4, but every other step is –3, so **–5 is wrong** [1]; y = –3(2) + 2 = **–4** [1]

*Examiner insight:* recalculating only the value that breaks the pattern is quicker than redoing the whole table.

**5.** x-values that are multiples of 5, including –5 and 10 [1]; **(–5, –4), (0, –1) and (10, 5)** [1]

**6.** x = –3: 3y = 12, **y = 4**; x = 0: **y = 2** [1]; x = 3: **y = 0**; x = 6: 3y = –6, **y = –2** [1]

**7.** 5 = 9 – 2k, so **k = 2** [1]; m = 9 – 2(–3) = 9 + 6 = **15** [1]

*Examiner insight:* 9 – 2(–3) is 15, not 3. Brackets round the negative value stop the sign slip.

**8. (a)** **–5, –2, –0.5, 2.5, 4** in order for x = –2, 0, 1, 3, 4: any three correct [1]; all five correct [1]

**(b)** All seven points plotted accurately [1]; one ruled straight line from x = –2 to x = 4 [1]

**(c)** **x = 1.3** (accept 1.2 to 1.4) [1]

*Examiner insight:* the exact value is 4/3, but a reading from the graph is all that is asked for. A line that stops at x = 3 loses the second mark in (b).

**9. (a)** y = 2x – 1: (–1, –3), (0, –1), (2, 3), (4, 7) [1]; y = –x + 5: (–1, 6), (0, 5), (2, 3), (4, 1) [1]

**(b)** Both lines ruled across –1 ≤ x ≤ 4 [1]

**(c)** **(2, 3)** [1]

**(d)** **y = 3** [1]

*Examiner insight:* the shared point (2, 3) appears in both tables, which confirms the crossing point before the lines are drawn.

**10. (a)** y = –4(–3) + 3 = 12 + 3 = **15** [1]

**(b)** –4x + 3 = 12 [1]; –4x = 9, so **x = –2.25** [1]

**(c)** –4x + 3 = 0 gives x = 0.75: **(0.75, 0)** [1]

**(d)** –4x + 3 = –6 gives –4x = –9, so **x = 2.25** [1]

*Examiner insight:* a y-value beyond the printed axis is not always a mistake. Check it, then draw the line only within the grid.

**11. (a)** –3y = 12 – 4x, so **y = (4x – 12)/3** (or y = (4/3)x – 4) [1]

**(b)** x = –3: **y = –8**; x = 0: **y = –4** [1]; x = 3: **y = 0**; x = 6: **y = 4** [1]

**(c)** 4(4.5) – 3(2) = 18 – 6 = 12, so the point lies on the line [1]

**12. (a)** **(–1, 11), (0, 7), (3, –5)** or any three correct points including both ends [1]

**(b)** **(–1, 2), (0, 1), (3, –2)** or any three correct points including both ends [1]

**(c)** **(2, –1)** [1]

**(d)** 7 – 4(2) = –1 and 2 + (–1) = 1, so (2, –1) is on both lines [1]

*Examiner insight:* the crossing is not at an x-value in either table, so an accurate drawing or a check in both equations is essential.

**13. (a)** x = –2 and y = 1 meet at **(–2, 1)** [1]; x = –2 and y = x + 5 meet at **(–2, 3)** [1]; y = 1 and y = x + 5 meet where x + 5 = 1, at **(–4, 1)** [1]

**(b)** Base from (–4, 1) to (–2, 1) is 2, height from (–2, 1) to (–2, 3) is 2; area = ½ × 2 × 2 = **2 square units** [1]

## Where marks are usually lost

- Drawing y = k as a vertical line.
- Stopping a line short of the given range.
- Sign errors when substituting negative x-values.
- Leaving gaps in a printed table.
- (Extended) Dividing only some terms when rearranging ax + by = c.
- Reading a crossing point without checking it in both equations.
