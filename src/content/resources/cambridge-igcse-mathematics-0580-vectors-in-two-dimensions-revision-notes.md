These notes condense subtopic **E7.2 Vectors in two dimensions** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027). It is **Extended only**; C7.2 reads "Extended content only". For full explanations and worked examples, read the [vectors in two dimensions study guide](/resources/cambridge-igcse-mathematics-0580-vectors-in-two-dimensions/); for exam-style questions, use the [vectors in two dimensions practice questions](/resources/cambridge-igcse-mathematics-0580-vectors-in-two-dimensions-practice/).

## What the syllabus says

- **E7.2.1** Describe a translation using a vector represented by a column vector (x, y), by AB (with an arrow) or by **a**.
- **E7.2.2** Add and subtract vectors.
- **E7.2.3** Multiply a vector by a scalar.

Vectors are printed as AB with an arrow or as bold **a**. When writing by hand, underline the letter.

## Key terms

| Term | Meaning |
|---|---|
| Vector | A quantity with size and direction, such as a translation |
| Scalar | An ordinary number with size only |
| Column vector (x, y) | x across (right +), y up (+) |
| Equal vectors | Same size and same direction, wherever they are drawn |
| Negative vector −**a** | Same size as **a**, opposite direction |
| Resultant | The single vector equal to two or more vectors in sequence |
| Zero vector | (0, 0): no overall movement |
| Parallel vectors | One is a scalar multiple of the other |

## Rules in one block

```
Vector A → B           = (x_B − x_A, y_B − y_A)       end − start
BA                     = −AB
(a, b) + (c, d)        = (a + c, b + d)
(a, b) − (c, d)        = (a − c, b − d)
k(a, b)                = (ka, kb)
AB + BC                = AC                            nose to tail
a − b                  = a + (−b)
b − a                  = −(a − b)
```

**Picture of a − b:** draw **a** and **b** from the same point; **a** − **b** goes from the tip of **b** to the tip of **a**.

## Scalar multiples

| k | Effect on **a** |
|---|---|
| k > 1 | same direction, longer |
| 0 < k < 1 | same direction, shorter |
| k = −1 | same length, reversed |
| k < 0 | reversed, scaled by the size of k |

Parallel test: (x₁, y₁) is parallel to (x₂, y₂) when x₁ ÷ x₂ = y₁ ÷ y₂ (the same multiplier for both entries).

## Vector equations

One vector equation gives two equations: **top = top** and **bottom = bottom**.

```
(x, −1) − 3(2, y) = (4, 8)
top:     x − 6 = 4      →  x = 10
bottom:  −1 − 3y = 8    →  y = −3
```

When the unknowns are multipliers, as in m**a** + n**b** = **c**, the two equations are simultaneous; solve them together and substitute back to check.

## Two worked reminders

**Combining.** **a** = (−1, 4), **b** = (3, −2). Find 2**a** − 3**b**.

```
2a = (−2, 8)      3b = (9, −6)
2a − 3b = (−2 − 9, 8 − (−6)) = (−11, 14)
```

Write each scaled vector on its own line first; the subtraction of −6 is where most slips happen.

**Journey.** A drone flies (4, 1), then (−2, 3), then (5, −6). The resultant is (4 − 2 + 5, 1 + 3 − 6) = (7, −2). The vector straight back to the start is (−7, 2). Adding the stages in a different order gives the same resultant.

## Translations

- The vector of a translation is the same for every point of the shape: pick any vertex and its image.
- The translation that undoes the vector (x, y) is (−x, −y).
- Two translations in turn are the same as one translation by their sum.
- Example: a triangle with a vertex at (2, −3) is mapped to a triangle with that vertex at (−1, 4). The translation is (−1 − 2, 4 − (−3)) = (−3, 7), and the reverse translation is (3, −7).

## Exam traps

- Start minus end, giving the reverse vector.
- Scaling only the top entry.
- Sign slips such as 2 − (−8) written as −6.
- Drawing a fraction line inside a column vector.
- Writing **a** − **b** when the route needs **b** − **a**.
- Answering "describe fully" with only a vector and no word "translation".

## Self-test

1. Find the vector from A(1, 6) to B(−3, 2).
2. Write down BA for the points in question 1.
3. **p** = (2, −5) and **q** = (−1, 3). Find **p** + **q**.
4. Using **p** and **q** from question 3, find **p** − **q**.
5. Find 4**q** − **p**.
6. Find −½(6, −8).
7. Is (−6, 15) parallel to (2, −5)? Give a reason.
8. A translation (−2, 7) is followed by a translation (5, −3). Find the single translation.
9. Find x and y if (x, 2) + (3, y) = (−1, −4).
10. Find k if (k, −12) is parallel to (2, 3).
11. Point (4, −1) is translated by (−6, 2). Find its image.
12. In parallelogram ABCD, AB = **u** (with an arrow). Write down DC and CD.

### Answers

1. (−3 − 1, 2 − 6) = **(−4, −4)**
2. **(4, 4)**
3. **(1, −2)**
4. (2 + 1, −5 − 3) = **(3, −8)**
5. (−4, 12) − (2, −5) = **(−6, 17)**
6. **(−3, 4)**
7. **Yes**: (−6, 15) = −3 × (2, −5)
8. **(3, 4)**
9. x + 3 = −1 so **x = −4**; 2 + y = −4 so **y = −6**
10. Multiplier from the bottom: −12 ÷ 3 = −4, so **k = −8**
11. **(−2, 1)**
12. DC = **u**; CD = **−u**
