This guide teaches subtopic **1.4 Fractions, decimals and percentages** from the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. Both tiers must use the language and notation of proper fractions, improper fractions, mixed numbers, decimals and percentages, recognise equivalence and convert between the forms, and write fractions in their simplest form. The tiers differ on **recurring decimals**: Core candidates (C1.4) are not expected to use recurring decimal notation or to convert recurring decimals; Extended candidates (E1.4) must do both. Those sections are marked **Extended only**.

Use it with the [fractions, decimals and percentages revision notes](/resources/cambridge-igcse-mathematics-0580-fractions-decimals-and-percentages-cambridge-igcse-maths-revision-notes/) and [practice questions](/resources/cambridge-igcse-mathematics-0580-fractions-decimals-and-percentages-cambridge-igcse-maths-practice/). ## The language

| Word | Meaning | Example |
|---|---|---|
| Numerator | Top of a fraction | 3 in 3/8 |
| Denominator | Bottom of a fraction: how many equal parts the whole is split into | 8 in 3/8 |
| Proper fraction | Numerator smaller than denominator | 5/9 |
| Improper fraction | Numerator equal to or larger than denominator | 11/4 |
| Mixed number | A whole number and a proper fraction | 2¾ |
| Decimal | A number written with place value after the decimal point | 0.375 |
| Percentage | A number of hundredths | 37.5% = 37.5/100 |
| Equivalent | Different forms of the same value | 3/8 = 0.375 = 37.5% |
| Simplest form | Numerator and denominator have no common factor except 1 | 84/126 = 2/3 |

**Simplest form in one step.** Divide numerator and denominator by their HCF. For 84/126 the HCF is 42, so 84/126 = 2/3. Dividing in several smaller steps (by 2, then 3, then 7) is fine, but check that nothing more cancels at the end.

## Converting between the forms

```
             ÷ denominator                × 100
  FRACTION  --------------->  DECIMAL  ----------->  PERCENTAGE
            <---------------           <-----------
          write over 10, 100,             ÷ 100
          1000 and simplify
```

**Fraction to decimal.** Divide the numerator by the denominator, or make the denominator a power of 10.

```
7/40:  7/40 = 175/1000 = 0.175            (× 25 top and bottom)
3/8:   3 ÷ 8 = 0.375                      (short division)
```

**Decimal to fraction.** Write the decimal over the place value of its last digit, then simplify.

```
0.36  = 36/100  = 9/25
0.045 = 45/1000 = 9/200
2.15  = 215/100 = 43/20 = 2 3/20
```

**Percentages.** A percentage is a fraction with denominator 100.

```
135%  = 135/100 = 27/20 = 1.35 = 1 7/20
0.5%  = 0.5/100 = 5/1000 = 1/200 = 0.005
3/16  = 0.1875 = 18.75%
```

Percentages above 100% are greater than one whole; percentages below 1% are less than one hundredth. Both appear in questions because they test whether you understand the conversion rather than a memorised pattern.

**Mixed numbers and improper fractions.**

```
3 5/7  = (3 × 7 + 5)/7 = 26/7
47/6   = 7 remainder 5 = 7 5/6
```

## Which fractions give terminating decimals?

A fraction in its simplest form gives a **terminating** decimal only when its denominator has no prime factors other than 2 and 5. So 7/40 (40 = 2³ × 5) terminates, but 5/12 (12 = 2² × 3) does not. Knowing this tells you before dividing whether to expect an answer that stops.

**Core: what to do with a decimal that does not stop.** Core candidates are not expected to use recurring notation. Write enough digits to show the value, or round to the accuracy asked: 5/12 = 0.4166…, which is 0.417 to 3 decimal places, or 41.7% to 3 significant figures.

## Worked example 1 (Core and Extended): comparing results

Amira scored 17/20 in a test and 42/50 in a second test. Write each score as a percentage and state which was better.

```
17/20 = 85/100 = 85%
42/50 = 84/100 = 84%
The first test was better.
```

Changing to a common form, here percentages, is the standard method whenever fractions with different denominators are compared.

## Recurring decimals (Extended only)

**Notation.** A dot above a digit shows that it repeats; dots above the first and last digits of a block show that the whole block repeats.

```
0.4̇     = 0.444 444...
0.58̇    = 0.588 888...       (only the 8 repeats)
0.1̇8̇    = 0.181 818...       (the block 18 repeats)
0.04̇5̇   = 0.045 454 5...     (the block 45 repeats, after the 0)
```

**Fraction to recurring decimal.** Divide; the digits repeat as soon as a remainder repeats.

```
5/11:  5 ÷ 11 = 0.454 545... = 0.4̇5̇
7/12:  7 ÷ 12 = 0.583 333... = 0.583̇
```

**Recurring decimal to fraction.** Let x equal the decimal. Multiply by powers of 10 to get two numbers with the **same** recurring tail, and subtract.

## Worked example 2 (Extended only)

Write 0.58̇ as a fraction in its simplest form.

```
x     = 0.588 88...
10x   = 5.888 88...
100x  = 58.888 88...
100x − 10x = 58.888... − 5.888...
90x = 53
x = 53/90
```

Here 10x and 100x share the tail .888…, so subtracting removes it. Using x and 10x would leave 9x = 5.3, which still works (x = 5.3/9 = 53/90) but leaves a decimal to clear.

## Worked example 3 (Extended only)

Write 0.04̇5̇ as a fraction in its simplest form.

```
x       = 0.045 454 5...
10x     = 0.454 545...
1000x   = 45.454 545...
1000x − 10x = 45
990x = 45
x = 45/990 = 1/22
```

The recurring block has two digits, so the two multipliers differ by a factor of 100 (10 and 1000). Check with a calculator on Paper 4: 1 ÷ 22 = 0.045 454 5…

**Show that questions.** If asked to *show that* 0.1̇8̇ = 2/11, the working must be algebraic, not a calculator division:

```
x = 0.181 818...      100x = 18.181 818...
99x = 18              x = 18/99 = 2/11
```

## Common errors

- Leaving an answer as 36/100 when "simplest form" is asked for.
- Writing 0.045 as 45/100 (wrong place value) or 135% as 0.135.
- Converting a mixed number by multiplying only the whole number: 3 5/7 is 26/7, not 21/7 + 5.
- Rounding 5/12 to 0.41 instead of 0.42 (2 d.p.), by truncating rather than rounding.
- (Extended) Putting a dot over the 5 as well as the 8 in 0.58̇, which changes the value to 0.585 858…
- (Extended) Subtracting two expressions whose recurring tails do not match.

## Exam technique

- **Write as a fraction in its simplest form**: show the unsimplified fraction, then the cancelled one.
- **Write as a decimal / percentage**: give the exact value when it terminates; otherwise round as instructed.
- **Show that** (Extended recurring decimals): set up x, two multiples with the same tail, the subtraction and the simplification. An answer that only quotes the fraction gains nothing.
- **Which is larger**: convert everything to one form, and say which form you used.

## Frequently asked questions

**Do Core candidates need to convert recurring decimals?**
No. The 0580 Core notes say Core candidates are not expected to use recurring decimal notation or to convert a recurring decimal to a fraction and vice versa. Extended candidates must.

**Is 1.35 or 1 7/20 the better answer for 135% as a number?**
Both are correct; give the form the question asks for. If it says "as a fraction", 27/20 or 1 7/20 are both fractions in their simplest form.
