## Section A

**1.** Which statement correctly describes homeostasis?

A: the removal of waste products from the body

B: the maintenance of a constant internal environment

C: the response of an organism to a stimulus

D: the transfer of energy between organisms

**[1]**

**2.** In a negative feedback system, what happens when a condition rises above the set point?

A: a response that increases it further

B: a response that reverses the change

C: no response

D: a response that stops the receptors

**[1]**

**3.** State what is meant by the internal environment of a mammal. **[1]**

**4.** Give **two** examples of conditions that are kept constant by homeostasis. **[2]**

**5.** State what is meant by a set point. **[1]**

## Section B

**6.** Core body temperature in a healthy person is kept at about 37 degrees Celsius.

**(a)** Explain why it is important that body temperature does not change very much. **[2]**

**(b)** Describe how negative feedback brings the temperature back to normal after it has risen. **[4]**

**(c)** State what happens to the response once the temperature has returned to the set point. **[1]**

**7.** A heater in a room is controlled by a thermostat set at 20 degrees Celsius.

**(a)** State what happens to the heater when the room temperature falls below 20 degrees Celsius. **[1]**

**(b)** Explain why this is an example of negative feedback. **[2]**

**(c)** State one way in which control of body temperature is more complex than the control of a room by a thermostat. **[1]**

**8.** The graph data show the blood glucose concentration of a healthy person at different times. A meal was eaten at 0 minutes.

| Time (minutes) | Blood glucose concentration (mg per 100 cm3) |
|---|---|
| -30 | 88 |
| 0 | 90 |
| 30 | 126 |
| 60 | 117 |
| 120 | 99 |
| 180 | 90 |

**(a)** State the time at which the concentration was highest. **[1]**

**(b)** Calculate the percentage increase in concentration between 0 and 30 minutes. **[2]**

**(c)** Explain how the data show that negative feedback is operating. **[3]**

**(d)** Suggest what the data would look like if the feedback had failed. **[1]**

**9.** The diagram shows a feedback loop with these boxes: set point, receptor, control centre, effector and response. Explain the role of each box in a negative feedback loop. **[5]**

**10.** A student says that homeostasis keeps the body at exactly the same temperature at all times. Comment on this statement. **[2]**

**11.** Explain why mammals can stay active on cold days but reptiles often become sluggish. **[2]**

## Answers

**1.** B [1]. **[1]**

**2.** B [1]. **[1]**

**3.** The blood and the tissue fluid that surrounds the cells [1]. **[1]**

**4.** Any two of: body temperature; blood glucose concentration; water content of the blood; carbon dioxide concentration [1 each]. **[2]**

**5.** The normal level (target value) of a condition [1]. **[1]**

**6.**

**(a)** Enzymes work best at an optimum temperature [1], so a large change would slow the reactions or denature the enzymes [1].

**(b)** Temperature receptors detect the rise [1]. The brain (control centre) compares it with the set point and sends signals [1]. Effectors, such as sweat glands, respond to cool the body [1]. The temperature falls back to the set point [1].

**(c)** The response reduces or stops [1]. **[7]**

**7.**

**(a)** The heater switches on [1].

**(b)** A fall in temperature causes a response (heating) that reverses the change [1], and the heater switches off when the set temperature is reached [1].

**(c)** Any sensible answer, for example: the body uses living receptors, nerves, hormones and several effectors, not a single switch [1]. **[4]**

**8.**

**(a)** 30 minutes [1].

**(b)** (126 - 90) divided by 90 x 100 [1] = 40 per cent [1].

**(c)** After the rise caused by the meal, the concentration falls back [1] to about the original level (90) by 180 minutes [1], so a response must be reversing the change [1].

**(d)** The concentration would keep rising or stay high and not return to the set point [1]. **[7]**

**9.** The set point is the normal value that the system aims for [1]. The receptor detects a change from the set point [1]. The control centre compares and sends instructions [1]. The effector carries out the action [1]. The response reverses the change and returns the condition to the set point [1]. **[5]**

**10.** The statement is not correct [1]. The temperature varies slightly around the set point, and homeostasis keeps it within narrow limits [1]. **[2]**

**11.** Mammals keep a constant body temperature by homeostasis [1], so their enzymes work well in a wide range of outside temperatures, but a reptile's temperature follows the surroundings and falls on cold days [1]. **[2]**

## Where marks are usually lost

- Describing the response without saying that it reverses the change.
- Leaving out the receptor or the effector.
- Forgetting that the response stops when the set point is reached.
- Defining homeostasis as "keeping things the same" without "internal environment".
- Using the final value in place of the starting value for a percentage change.
