These questions cover subtopic E6.4, Trigonometric functions, in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. The subtopic is Extended only, so every question suits Paper 2 or Paper 4 candidates. Each question is labelled (non-calculator) or (calculator). Unless a question says otherwise, every range is 0° ⩽ x ⩽ 360° and non-exact angles are given to 1 decimal place. Learn the methods first with the [trigonometric functions study guide](/resources/cambridge-igcse-mathematics-0580-trigonometric-functions/) and the [trigonometric functions revision notes](/resources/cambridge-igcse-mathematics-0580-trigonometric-functions-revision-notes/).

## Questions

### Section A: short questions

**1.** (non-calculator) The graph of y = tan x is drawn for 0° ⩽ x ⩽ 360°.

**(a)** Write down the equations of its two asymptotes. **[1]**

**(b)** Write down the x-coordinates of the points where it crosses the x-axis. **[1]**

**2.** (non-calculator) Solve sin x = 1/2. **[2]**

**3.** (non-calculator) Solve √2 cos x + 1 = 0. **[3]**

**4.** (calculator) Solve 7 sin x = −3. **[3]**

**5.** (non-calculator) You are given that tan 70° = 2.747 (to 4 significant figures). Find two values of x for which tan x = −2.747. **[2]**

**6.** (non-calculator) Write down the number of solutions of each equation.

**(a)** cos x = −0.3 **[1]**

**(b)** sin x = 1.5 **[1]**

**(c)** tan x = 4 **[1]**

### Section B: longer questions

**7.** (calculator) The graph of y = sin x is drawn for 0° ⩽ x ⩽ 360°.

**(a)** The line y = k meets the graph at exactly one point. Write down the two possible values of k. **[2]**

**(b)** The line y = 0.8 meets the graph at A and B. The x-coordinate of A is 53.1°, correct to 1 decimal place. Find the x-coordinate of B. **[1]**

**(c)** Solve sin x = −0.8. **[2]**

**8.** (calculator)

**(a)** Solve 3 tan x + 4 = 2 − tan x. **[3]**

**(b)** Solve 5 cos x − 1 = 2 cos x + 1. **[3]**

**9.** (non-calculator) The curve y = tan x and the line y = √3 meet at the points P and Q. Find the coordinates of P and Q. **[3]**

**10.** (non-calculator)

**(a)** Find the value of x for which cos x = 1/2 and sin x is negative. **[2]**

**(b)** Find the value of x for which sin x = −√3/2 and tan x is positive. **[2]**

**11.** (calculator)

**(a)** Solve 2 sin x + 3 = 3.9. **[3]**

**(b)** Explain why the equation 2 sin x + 3 = 0 has no solutions. **[1]**

**12.** (non-calculator) A student solves tan x = −√3 and writes "x = −60° or x = 120°".

**(a)** Explain what is wrong with the student's answer. **[1]**

**(b)** Write down the correct solutions. **[2]**

**13.** (calculator) Solve (4 − 3 cos x) ÷ 2 = 3.5. **[3]**

## Answers

**1. (a)** **x = 90° and x = 270°** [1]

**(b)** **0°, 180° and 360°** [1]

*Examiner insight:* all three crossings count, because the range includes both 0° and 360°.

**2.** α = 30°, since sin 30° = 1/2 [1]; sin is positive in the first two quarters, so **x = 30° or 150°** [1]

**3.** cos x = −1/√2 [1]; α = 45° [1]; cos is negative in the middle two quarters, so **x = 135° or 225°** [1]

*Examiner insight:* −1/√2 and −√2/2 are the same value. Recognising it as the cos 45° value, with a minus sign, is the key step.

**4.** sin x = −3/7 [1]; α = sin⁻¹(3/7) = 25.376…° [1]; sin is negative in the last two quarters: 180° + 25.376…° and 360° − 25.376…°, so **x = 205.4° or 334.6°** [1]

*Examiner insight:* the calculator gives −25.4°, which is outside the range. Using α avoids having to adjust a negative angle.

**5.** tan is negative in the second and fourth quarters with α = 70° [1]: **x = 110° or 290°** [1]

**6. (a)** **2** [1]

**(b)** **0**, because sin x is never greater than 1 [1]

**(c)** **2** [1]

**7. (a)** The line touches the wave only at its maximum or minimum, so **k = 1** [1] or **k = −1** [1]

**(b)** By symmetry about x = 90°, B is at 180° − 53.1° = **126.9°** [1]

**(c)** α = 53.1° from part (b) [1]; sin is negative in the last two quarters: **x = 233.1° or 306.9°** [1]

*Examiner insight:* the given value of 53.1° is rounded, but 180° + 53.130…° = 233.130…° still rounds to 233.1°, so either value works here. In general, use the unrounded calculator value.

**8. (a)** 4 tan x = −2, so tan x = −0.5 [1]; α = tan⁻¹(0.5) = 26.565…° [1]; **x = 153.4° or 333.4°** [1]

**(b)** 3 cos x = 2, so cos x = 2/3 [1]; α = cos⁻¹(2/3) = 48.189…° [1]; **x = 48.2° or 311.8°** [1]

*Examiner insight:* in (a) collect the tan x terms on one side before dividing. Treating tan x like an ordinary unknown is the whole method.

**9.** tan x = √3 gives α = 60° [1]; tan is positive in the first and third quarters, so x = 60° or 240° [1]; **P(60°, √3)** and **Q(240°, √3)** [1]

**10. (a)** cos x = 1/2 gives x = 60° or 300° [1]; sin x is negative only from 180° to 360°, so **x = 300°** [1]

**(b)** sin x = −√3/2 gives x = 240° or 300° [1]; tan x is positive from 180° to 270°, so **x = 240°** [1]

*Examiner insight:* list both solutions of the first equation, then test each one against the condition. Writing only the final answer risks losing the method mark.

**11. (a)** 2 sin x = 0.9, so sin x = 0.45 [1]; α = sin⁻¹(0.45) = 26.743…° [1]; **x = 26.7° or 153.3°** [1]

**(b)** It gives sin x = −1.5, which is less than −1, and sin x always lies between −1 and 1 [1]

**12. (a)** −60° is outside the range 0° ⩽ x ⩽ 360° (and the second solution in the range is missing) [1]

**(b)** α = 60°, tan is negative in the second and fourth quarters [1]: **x = 120° or 300°** [1]

*Examiner insight:* the two solutions of a tan equation are always 180° apart; 120° + 180° = 300° is a quick check.

**13.** 4 − 3 cos x = 7, so −3 cos x = 3 and cos x = −1 [1]; cos x = −1 at the minimum of the cos wave only [1]; **x = 180°** [1]

*Examiner insight:* cos x = −1 has one solution, not two. A sketch of the wave shows the horizontal line y = −1 touching the curve at its lowest point.

## Where marks are usually lost

- Stopping after one solution when the range holds two.
- Giving the calculator's negative angle as an answer.
- Using the sine partner 180° − α in a cosine equation.
- Dividing only some terms when rearranging.
- Rounding α before adding or subtracting it.
- Missing the endpoints 0° and 360° in equations with a value of 0.
