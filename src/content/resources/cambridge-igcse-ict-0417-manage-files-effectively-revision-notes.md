## Core skills in brief

- **Locate**: follow the path (drive, then folders, then file), use search, use recent files, sort the folder.
- **Open** loads a file in its own application. **Import** brings data of a different type into the current application.
- **Plan** the hierarchy first: broad categories at the top, narrower ones below, so files are found in a few clicks.
- **Name** files descriptively, and in exams copy the given name exactly, including capitals.
- **Save** keeps the native format; **export** or **Save as** another type writes a copy in a different format.

## Application formats by software type

| Software | Formats |
|---|---|
| Word processing | .docx, .doc, .rtf |
| Spreadsheet | .xlsx, .xls, .sdc |
| Database | .accdb, .odb, .sdb |
| Presentation | .pptx, .ppt |

.doc, .xls and .ppt are older formats kept for compatibility with older software.

## What is lost on export

| Export to | Kept | Lost |
|---|---|---|
| .csv | Data values in rows and columns | Formulas, formatting, charts, extra sheets |
| .txt | Characters only | All formatting, images, tables |
| .rtf | Text and basic formatting | Some complex layout features |
| .pdf | Exact layout and appearance | Easy editing |

## Evidence outputs

- **Screenshot**: captures the screen to show settings, formulas or structure; crop so it is readable.
- **Browser view**: the web page as a visitor sees it.
- **HTML view**: the markup behind the page.
- **Database report**: formatted output of a query. **Data table**: records in rows, fields in columns.
- Always check print preview for cut-off content and orientation.

## The eleven named formats

| Format | Two facts to write |
|---|---|
| css | Style rules for web pages; plain text |
| csv | Values separated by commas; moves data between spreadsheets and databases |
| gif | Up to 256 colours, lossless; animation and transparency |
| htm | Web page markup; displayed by a browser |
| jpg | Lossy; millions of colours; photos |
| pdf | Fixed layout on any device; hard to edit |
| png | Lossless; transparency; logos and screenshots |
| rtf | Text with basic formatting; opens in most word processors |
| txt | Plain text; no formatting |
| zip | Compressed archive of one or more files |
| rar | Compressed archive; usually needs separate software to create |

## Key terms

| Term | Meaning |
|---|---|
| Path | The route of drives and folders leading to a file |
| Hierarchical structure | Folders arranged as a tree of folders and subfolders |
| Native format | An application's own file format |
| Import | Bring data of a different file type into the current application |
| Export | Save a copy in a different format for use elsewhere |
| Generic file format | A format that many applications can open, not tied to one company's software |
| HTML view | The code view of a web page |

## Exam traps

- Renaming the extension does **not** convert a file.
- .rtf is in **both** the application and the generic lists.
- jpg is **lossy**; gif and png are **lossless**.
- A .csv keeps values, not **formulas**.
- When a task asks for both web page views, print **both**.
- Copy instructed file names **exactly**; a missing capital can cost the mark.

## Self-test

1. Give two ways of locating a file whose name you have forgotten.
2. State the difference between opening and importing a file.
3. Why should a folder structure be planned before saving files?
4. Name the generic format used to move a table of data from a spreadsheet into a database.
5. A spreadsheet with formulas is exported as .csv. What happens to the formulas?
6. Give two application formats for presentation software.
7. Which image format supports simple animation?
8. Why is a pdf suitable for a finished manual sent to customers?
9. State what HTML view of a web page shows.
10. Give one difference between .rtf and .txt.
11. Give three reasons why generic file formats are needed.
12. Name two formats that store compressed archives.

## Self-test answers

1. Any two: use the search box (by part of the name, type or date); open the recent files list; sort the folder by date modified.
2. Opening loads a file in the application that created it; importing brings data of a different type into the current application.
3. So that files are saved in logical places from the start and can be found quickly.
4. .csv.
5. They are lost; only the calculated values are saved.
6. .pptx and .ppt.
7. gif.
8. It keeps the exact layout on any device and is not easily edited.
9. The markup (code) that produces the page.
10. .rtf keeps basic formatting such as fonts and bold; .txt keeps no formatting.
11. Recipient may use different software; data can be moved between applications; files stay readable in future; web formats work in any browser.
12. zip and rar.
