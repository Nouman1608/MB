These notes condense subtopic **2.1 Introduction to algebra** of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. Core and Extended candidates learn the same two statements: know that letters can be used to represent generalised numbers, and substitute numbers into expressions and formulas. Worked examples are in the [introduction to algebra study guide](/resources/cambridge-igcse-mathematics-0580-introduction-to-algebra-cambridge-igcse-maths/), and exam-style questions are in the [introduction to algebra practice questions](/resources/cambridge-igcse-mathematics-0580-introduction-to-algebra-cambridge-igcse-maths-practice/).

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Variable | A letter standing for a number that can change | t |
| Term | A number, a letter, or numbers and letters multiplied | −4xy |
| Coefficient | The number multiplying the letters in a term | −4 in −4xy |
| Expression | Terms with + or − and no equals sign | 3a + 2b − 5 |
| Equation | A statement that two expressions are equal for certain values | 3a + 2 = 11 |
| Formula | A rule connecting variables, with a subject | P = 2l + 2w |
| Subject | The single variable on the left of a formula | P |
| Substitute | Replace letters with given numbers | a = 3 in 3a + 2 gives 11 |

## Conventions

```
3 × x     = 3x            a × b     = ab
x × x     = x^2           2 × x × x = 2x^2   (not (2x)^2 = 4x^2)
a ÷ b     = a/b           1 × x     = x
```

## Words into algebra

| Words | Expression |
|---|---|
| 7 more than y | y + 7 |
| 7 less than y | y − 7 |
| y less than 7 | 7 − y |
| twice n, minus 3 | 2n − 3 |
| the product of a and b, divided by 4 | ab/4 |
| the square of the sum of p and q | (p + q)² |
| the sum of the squares of p and q | p² + q² |

**Method for word problems:** give each unknown a letter, write every other quantity in terms of it, then combine. Example: a book costs b dollars and a pen costs 3 dollars less; 2 books and 5 pens cost 2b + 5(b − 3) = **7b − 15** dollars.

## Generalised numbers

If n is any integer:

| Description | Expression |
|---|---|
| consecutive integers | n, n + 1, n + 2 |
| the integer before n | n − 1 |
| any even number | 2n |
| any odd number | 2n + 1 or 2n − 1 |
| consecutive even numbers | 2n, 2n + 2 |
| any multiple of 5 | 5n |

To explain that an expression is always even, write it as 2 × (a whole number): 4n + 2 = 2(2n + 1).

## Substitution

1. Write the expression with each letter replaced by its value **in brackets**.
2. Powers first, then × and ÷, then + and −.
3. Keep full values; round only at the end.

**Sign facts**

```
(-2)^2 = 4         -2^2 = -4          (-2)^3 = -8
a - (-b) = a + b    (-) × (-) = (+)    (-) × (+) = (-)
```

**Worked reminder.** x = −2 and y = 5.

```
4x^2      = 4 × (-2)^2 = 4 × 4 = 16
(4x)^2    = (-8)^2 = 64
xy - y    = (-2)(5) - 5 = -15
(y - x)^2 = (5 - (-2))^2 = 7^2 = 49
x^3 + 2y  = -8 + 10 = 2
```

## Exam traps

- 2x with x = 5 written as 25: 2x means 2 × 5 = 10.
- −x² with x = −3 given as 9; it is −9 (only x is squared, then the sign applies).
- 3a² treated as (3a)².
- "y less than 7" written as y − 7.
- "Write a formula" answered with an expression (no subject and no equals sign).
- Square root taken of each term separately: √(u² + 2as) is not u + √(2as).
- Rounding part-way through a substitution on the calculator paper.

## Self-test

1. Write an expression for 7 more than y.
2. Write an expression for the product of a and b, divided by 4.
3. A book costs b dollars. A pen costs 3 dollars less than a book. Write an expression for the cost of 2 books and 5 pens.
4. n is an integer. Write an expression for the integer just before n.
5. n is an integer. Explain why 4n + 2 is always even.
6. x = −2. Find the value of 4x².
7. x = −2. Find the value of (4x)².
8. x = −2 and y = 5. Find the value of xy − y.
9. x = −2 and y = 5. Find the value of (y − x)².
10. x = −2 and y = 5. Find the value of x³ + 2y.
11. A = ½(a + b)h. Find A when a = 7, b = 12 and h = 5.6.
12. F = 1.8C + 32. Find F when C = 25.

### Answers

1. **y + 7**
2. **ab/4**
3. 2b + 5(b − 3) = **7b − 15**
4. **n − 1**
5. 4n + 2 = **2(2n + 1)**, which is 2 times a whole number, so it is even
6. 4 × 4 = **16**
7. (−8)² = **64**
8. −10 − 5 = **−15**
9. 7² = **49**
10. −8 + 10 = **2**
11. ½ × 19 × 5.6 = **53.2**
12. 45 + 32 = **77**
