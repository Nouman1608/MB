## Section A

**1.** Find ∫ (9x² − 6x + 5) dx. **[2]**

**2.** Find ∫ 10/x⁶ dx. **[2]**

**3.** Find ∫ (3x − 2)² dx. **[3]**

**4.** Find ∫ (2x⁵ − 3x)/x³ dx. **[3]**

**5.** f′(x) = 4x³ − 6x + 1 and f(−1) = 2. Find f(x). **[4]**

**6.** A curve has gradient dy/dx = 1 − 4/x² and passes through (2, 6). Find the equation of the curve.
**[4]**

**7.** ∫ f(x) dx = 2x³ − x² + C.

**(a)** Find f(x). **[1]**

**(b)** Explain why every curve y = 2x³ − x² + C has a tangent with the same gradient at x = 2, and
find that gradient. **[2]**

## Section B

**8.** An oil slick has area A m² at time t hours. It grows at a rate dA/dt = 12t − 3t² for
0 ≤ t ≤ 4, and A = 0 when t = 0.

**(a)** Find A in terms of t. **[3]**

**(b)** Find the area of the slick when t = 3. **[1]**

**(c)** Find the value of t at which the slick stops growing. **[2]**

**9.** Consider f(x) = 6/x² + x for 1 ≤ x ≤ 4.

**(a)** Explain why f(x) > 0 on this interval. **[1]**

**(b)** Write down an integral for the area enclosed by y = f(x), the x-axis, x = 1 and x = 4. **[1]**

**(c)** Use your GDC to find this area. **[1]**

**10.** Use your GDC to find the area enclosed by y = 1/(1 + x⁴), the x-axis, the y-axis and the line
x = 2. Give your answer to three significant figures. **[3]**

**11.** f′(x) = ax² + 4, f(0) = 1 and f(3) = 22. Find the value of a and hence f(x). **[4]**

**12.** A particle moves in a straight line with velocity v = 3t² − 12 m s⁻¹ at time t seconds. Its
displacement is s = 5 m when t = 1.

**(a)** Find s in terms of t. **[3]**

**(b)** Find the displacement when t = 3. **[1]**

**13.** The curves y = F(x) satisfy F′(x) = 2x − 6x⁻³.

**(a)** Find F(x) in terms of x and an arbitrary constant. **[2]**

**(b)** One of the curves passes through (1, 0). Find its equation. **[2]**

**(c)** Find the value of this F at x = −1. **[1]**

## Answers

**1.** 3x³ − 3x² + 5x + C [1 for any two correct terms, 1 for all correct with +C]. **[2]**

**2.** 10x⁻⁶ → 10x⁻⁵/(−5) [1] = −2x⁻⁵ + C = −2/x⁵ + C [1]. **[2]**

**3.** (3x − 2)² = 9x² − 12x + 4 [1]; ∫ = 3x³ − 6x² + 4x + C [2]. **[3]**

**4.** (2x⁵ − 3x)/x³ = 2x² − 3x⁻² [1]; ∫ = 2x³/3 + 3x⁻¹ + C [2]. **[3]**

**5.** f(x) = x⁴ − 3x² + x + C [2]. f(−1) = 1 − 3 − 1 + C = 2 [1], so C = 5 and
f(x) = x⁴ − 3x² + x + 5 [1]. **[4]**

**6.** y = x + 4x⁻¹ + C [2]. 6 = 2 + 2 + C [1], so C = 2 and y = x + 4/x + 2 [1]. **[4]**

**7. (a)** f(x) = 6x² − 2x [1]

**(b)** Every curve in the family has derivative 6x² − 2x, because the constant differentiates to 0
[1]. At x = 2 the gradient is 24 − 4 = 20 [1]. **[3]**

**8. (a)** A = 6t² − t³ + C [2]; A(0) = 0 gives C = 0, so A = 6t² − t³ [1].

**(b)** A(3) = 54 − 27 = 27 m² [1].

**(c)** 12t − 3t² = 3t(4 − t) = 0 [1], so t = 4 hours (t = 0 is the start) [1]. **[6]**

**9. (a)** For 1 ≤ x ≤ 4, both 6/x² and x are positive [1].

**(b)** Area = ∫₁⁴ (6/x² + x) dx [1].

**(c)** 12 [1]. **[3]**

**10.** 1/(1 + x⁴) > 0 for all x, so the area is ∫₀² 1/(1 + x⁴) dx [2] = 1.07 (3 s.f.) [1]. **[3]**

**11.** f(x) = ax³/3 + 4x + C [1]. f(0) = 1 gives C = 1 [1]. f(3) = 9a + 12 + 1 = 22 [1], so a = 1 and
f(x) = x³/3 + 4x + 1 [1]. **[4]**

**12. (a)** s = t³ − 12t + C [1]. At t = 1: 1 − 12 + C = 5 [1], so C = 16 and s = t³ − 12t + 16 [1].

**(b)** s(3) = 27 − 36 + 16 = 7 m [1]. **[4]**

**13. (a)** F(x) = x² − 6x⁻²/(−2) + C [1] = x² + 3x⁻² + C = x² + 3/x² + C [1].

**(b)** 0 = 1 + 3 + C, so C = −4 [1] and F(x) = x² + 3/x² − 4 [1].

**(c)** F(−1) = 1 + 3 − 4 = 0 [1]. **[5]**

## How this set builds

Questions 1 to 4 drill the rule on polynomials, negative powers, a square and a quotient. Questions
5, 6, 11 and 12 add boundary conditions, including two conditions for two unknowns. Questions 7 and 8
link integration to the family of curves and to rates of change. Questions 9 and 10 cover the
technology route to area, with the sign check that justifies calling a definite integral an area.

International Baccalaureate Organization, Diploma Programme, *Mathematics: analysis and approaches

(n ≠ −1); definite integrals using technology; area where f(x) > 0; boundary conditions.
