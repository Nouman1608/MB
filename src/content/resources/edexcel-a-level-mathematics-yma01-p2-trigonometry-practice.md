These questions cover section 6 of Unit P2 (YMA01, Issue 3): the identities tan θ = sin θ/cos θ and sin²θ + cos²θ = 1, and simple trigonometric equations in a given interval. Revise first with the [P2 trigonometry study guide](/resources/edexcel-a-level-mathematics-yma01-p2-trigonometry/) and the [P2 trigonometry revision notes](/resources/edexcel-a-level-mathematics-yma01-p2-trigonometry-revision-notes/). Give answers in degrees to 1 decimal place, or in radians to 3 significant figures, unless the question says otherwise.

---

## Section A

**1.** Given that cos θ = ¾ and 270° < θ < 360°, find the exact values of sin θ and tan θ. **[3]**

**2.** Solve tan x = −1.5 for 0° ≤ x < 360°. **[2]**

**3.** Solve sin x = 0.3 for 0 ≤ x < 2π, where x is in radians. **[2]**

**4.** Show that (1 − sin²x) tan x ≡ sin x cos x. **[2]**

## Section B

**5.** Solve 5 sin x = 2 cos x for −180° < x < 180°. **[3]**

**6.** Solve cos(x − 40°) = 0.6 for 0° ≤ x < 360°. **[4]**

**7.** Solve tan 2x = −√3 for 0 ≤ x < π, giving your answers as exact multiples of π. **[4]**

**8.** Solve 2 cos²x + 3 sin x = 3 for 0° ≤ x < 360°. **[6]**

**9.** **(a)** Show that the equation 2 sin x tan x = 3 can be written as 2 cos²x + 3 cos x − 2 = 0. **[3]**

**(b)** Hence solve 2 sin x tan x = 3 for 0° ≤ x < 360°. **[3]**

**10.** Solve tan²θ − 2 tan θ − 3 = 0 for 0° ≤ θ < 360°. **[5]**

**11.** Prove that (sin x + cos x)² + (sin x − cos x)² ≡ 2. **[3]**

**12.** A student solves cos 2x = 0.5 for 0° ≤ x < 360° and gives only x = 30° and x = 330°.

**(a)** Explain the student's error. **[1]**

**(b)** Find all the solutions in the interval. **[3]**

**13.** Solve sin(x + π/3) = −0.4 for 0 ≤ x < 2π, giving your answers to 3 significant figures. **[4]**

## Answers

**1.** sin²θ = 1 − 9/16 = 7/16 [1]. θ is in the fourth quadrant, where sine is negative, so **sin θ = −√7/4** [1]. tan θ = (−√7/4) ÷ (¾) = **−√7/3** [1].

**2.** Principal value tan⁻¹(−1.5) = −56.3°, so the solutions are −56.3° + 180° and −56.3° + 360° [1]: **x = 123.7°, 303.7°** [1].

**3.** Principal value 0.3047 [1]; second solution π − 0.3047. **x = 0.305, 2.84** [1].

**4.** 1 − sin²x = cos²x [1], so (1 − sin²x) tan x = cos²x × sin x/cos x = sin x cos x [1].

**5.** cos x = 0 does not satisfy the equation, so dividing by 5 cos x gives tan x = 0.4 [1]. Principal value 21.8° [1]; subtracting 180° gives the other value in the interval: **x = 21.8°, −158.2°** [1].

**6.** 0° ≤ x < 360° gives −40° ≤ x − 40° < 320° [1]. cos⁻¹ 0.6 = 53.13° [1]; the other value in range is 360° − 53.13° = 306.87° [1]. So x − 40° = 53.13° or 306.87°, giving **x = 93.1°, 346.9°** [1].

**7.** 0 ≤ 2x < 2π [1]. tan⁻¹(−√3) = −π/3; adding π gives 2π/3, and adding π again gives 5π/3 [1] [1]. So 2x = 2π/3 or 5π/3, and **x = π/3, 5π/6** [1].

**8.** 2(1 − sin²x) + 3 sin x = 3 [1], so 2 sin²x − 3 sin x + 1 = 0 [1]. (2 sin x − 1)(sin x − 1) = 0 [1], so sin x = ½ or sin x = 1 [1]. sin x = ½ gives x = 30°, 150° [1]; sin x = 1 gives x = 90° [1]. **x = 30°, 90°, 150°.**

**9. (a)** 2 sin x × sin x/cos x = 3, so 2 sin²x = 3 cos x [1]. 2(1 − cos²x) = 3 cos x [1], so 2 − 2 cos²x − 3 cos x = 0, which gives 2 cos²x + 3 cos x − 2 = 0 [1].

**(b)** (2 cos x − 1)(cos x + 2) = 0 [1]. cos x = −2 has no solutions [1]. cos x = ½ gives **x = 60°, 300°** [1].

Total: 6

**10.** (tan θ − 3)(tan θ + 1) = 0 [1]. tan θ = 3: θ = 71.6° [1], 251.6° [1]. tan θ = −1: θ = 135° [1], 315° [1].

**11.** Expanding: (sin²x + 2 sin x cos x + cos²x) + (sin²x − 2 sin x cos x + cos²x) [1] = 2 sin²x + 2 cos²x [1] = 2(sin²x + cos²x) = 2 [1].

**12. (a)** The student did not extend the interval to 0° ≤ 2x < 720°, so solutions for 2x in the second turn were missed [1].

**(b)** cos⁻¹ 0.5 = 60°, so 2x = 60°, 300°, 420°, 660° [1] [1] (one mark for 60° and 300°, one for 420° and 660°). **x = 30°, 150°, 210°, 330°** [1].

Total: 4

**13.** 0 ≤ x < 2π gives π/3 ≤ x + π/3 < 7π/3, that is 1.047 ≤ x + π/3 < 7.330 [1]. sin⁻¹(−0.4) = −0.4115, which is outside this range [1]. Sine is negative in the third and fourth quadrants: x + π/3 = π + 0.4115 = 3.5531 or x + π/3 = 2π − 0.4115 = 5.8717 [1]. Subtracting π/3 = 1.0472: **x = 2.51, 4.82** [1].

## Where marks are usually lost

- In Question 1, giving sin θ as positive because the quadrant was not checked.
- In Question 2, giving −56.3° itself, which lies outside the interval.
- In Question 6, solving cos x = 0.6 and forgetting to add 40°, or missing that 306.87° lies inside the adjusted interval.
- In Question 8, dividing through by sin x or forgetting the root sin x = 1.
- In Question 9(b), not stating that cos x = −2 is impossible.
- In Question 10, giving only the principal values 71.6° and 135°.
