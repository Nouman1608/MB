These questions cover subtopic 2.3 Algebraic fractions of Cambridge O Level Mathematics (Syllabus D) 4024, 2025–2027. All are non-calculator. Give each answer as a single fraction in its simplest form, with denominators left factorised where that is simpler.

## Section A

**1.** Write (x + 4)/5 + (2x − 3)/10 as a single fraction. **[2]**

**2.** Write (5x − 2)/6 − (x + 4)/4 as a single fraction. **[3]**

**3.** Write 7/(3x) − 1/(2x) as a single fraction. **[2]**

**4.** Simplify 9x²/8 × 4/(3x³). **[2]**

**5.** Simplify 12ab/5 ÷ 3a²/10. **[2]**

**6.** Simplify (x² − 36)/(x² − 6x). **[2]**

## Section B

**7.** Write 2/(x − 5) + 3/(x + 1) as a single fraction. **[3]**

**8.** Write x/(x + 4) − 2/(x − 1) as a single fraction. **[3]**

**9.** Simplify (x² − 7x + 10)/(x² − 25). **[3]**

**10.** Simplify (3x² + 7x + 2)/(9x² − 1). **[3]**

**11.** Simplify (10 − 5x)/(x² + x − 6). **[3]**

**12.** Write 2/(x + 3) − 12/(x² − 9) as a single fraction in its simplest form. **[4]**

**13.** Simplify (x² + 5x + 6)/(x² − 4) ÷ (x + 3)/(x − 2). **[4]**

## Answers

**1.** Common denominator 10: [2(x + 4) + (2x − 3)]/10 [1] = (2x + 8 + 2x − 3)/10 = **(4x + 5)/10** [1] **[2]**

**2.** Common denominator 12: [2(5x − 2) − 3(x + 4)]/12 [1] = (10x − 4 − 3x − 12)/12 [1] = **(7x − 16)/12** [1] **[3]**

*Examiner insight:* −3(x + 4) = −3x − 12. Writing −3x + 12 gives (7x + 8)/12.

**3.** Common denominator 6x: 14/(6x) − 3/(6x) [1] = **11/(6x)** [1] **[2]**

**4.** 36x²/(24x³) [1] = **3/(2x)** [1] **[2]**

*Examiner insight:* x² divided by x³ leaves one x in the denominator, so the answer is 3/(2x), not 3x/2.

**5.** 12ab/5 × 10/(3a²) [1] = 120ab/(15a²) = **8b/a** [1] **[2]**

*Examiner insight:* Cancel before multiplying: 12 with 3 leaves 4, 10 with 5 leaves 2, and a with a² leaves a in the denominator, so 4 × 2 × b / a = 8b/a.

**6.** (x − 6)(x + 6)/[x(x − 6)] [1] = **(x + 6)/x** [1] **[2]**

*Examiner insight:* The answer (x + 6)/x is fully simplified. The x in the numerator is a term, so it cannot cancel with the x in the denominator.

**7.** [2(x + 1) + 3(x − 5)]/[(x − 5)(x + 1)] [1] = (2x + 2 + 3x − 15)/[(x − 5)(x + 1)] [1] = **(5x − 13)/[(x − 5)(x + 1)]** [1] **[3]**

**8.** [x(x − 1) − 2(x + 4)]/[(x + 4)(x − 1)] [1] = (x² − x − 2x − 8)/[(x + 4)(x − 1)] [1] = **(x² − 3x − 8)/[(x + 4)(x − 1)]** [1] **[3]**

*Examiner insight:* x² − 3x − 8 does not factorise, so nothing cancels.

**9.** Numerator (x − 5)(x − 2) [1]; denominator (x − 5)(x + 5) [1]; = **(x − 2)/(x + 5)** [1] **[3]**

*Examiner insight:* A mark is given for each correct factorisation, so show both lines even if you spot the cancelling factor straight away.

**10.** Numerator: ac = 6, sum 7 → 6 and 1, so 3x² + 6x + x + 2 = (3x + 1)(x + 2) [1]; denominator (3x − 1)(3x + 1) [1]; = **(x + 2)/(3x − 1)** [1] **[3]**

**11.** Numerator 5(2 − x) = −5(x − 2) [1]; denominator (x + 3)(x − 2) [1]; = **−5/(x + 3)** [1] **[3]**

*Examiner insight:* Check with x = 0: the original gives 10/(−6) = −5/3, and −5/3 matches the answer. A sign error would show up as +5/3.

**12.** x² − 9 = (x − 3)(x + 3), so the common denominator is (x − 3)(x + 3) [1]. Numerator = 2(x − 3) − 12 [1] = 2x − 18 = 2(x − 9) [1]. Answer **2(x − 9)/[(x − 3)(x + 3)]** [1] **[4]**

**13.** Multiply by the reciprocal: (x² + 5x + 6)/(x² − 4) × (x − 2)/(x + 3) [1]. Factorise: (x + 2)(x + 3)/[(x − 2)(x + 2)] × (x − 2)/(x + 3) [1] [1]. Every factor cancels, leaving **1** [1] **[4]**

*Check:* with x = 0, the original is (6/−4) ÷ (3/−2) = (−3/2) ÷ (−3/2) = 1. ✓

## Where marks are usually lost

- Subtracting only the first term of the second numerator (Questions 2 and 8).
- Using (x + 3)(x² − 9) as the denominator in Question 12, which makes the working much longer.
- Missing that 2 − x = −(x − 2) in Question 11.
- Inverting the first fraction instead of the second when dividing (Question 13).
- Writing 0 instead of 1 when every factor cancels.
- Cancelling the x in (x + 6)/x to get 6 in Question 6.

## Frequently asked questions

**Should I multiply out the denominator in my final answer?**
Usually not. A factorised denominator is accepted, is simpler, and shows that nothing cancels.

**How do I check an algebraic fraction answer?**
Substitute a simple value, such as x = 0 or x = 1, into the original and your answer. They must give the same number. Avoid values that make a denominator zero.

**Do I need to state values of x that are not allowed?**
Not unless the question asks. It is still good practice to notice them, because when solving fractional equations later, a value that makes a denominator zero must be rejected.

**Which factorising forms appear most in 2.3?**
Common factors, the difference of two squares and quadratic trinomials, all from subtopic 2.2.
