These notes condense section 10.2 of Cambridge IGCSE ICT 0417, "Effective use of the internet". ## Four networks and services in one line each

- **Internet**: public, worldwide network of networks.
- **Intranet**: private network for one organisation's members; login; relevant, checked content.
- **Extranet**: part of an intranet that authorised outsiders (suppliers, customers) can log in to.
- **WWW**: the web pages and resources accessed over the internet with a browser. A service, not a network.

## Web 2.0 services compared

| | Blog | Forum | Wiki | Social networking |
|---|---|---|---|---|
| Authors | One | Many members | Many | Every user |
| Editing | Author only; readers comment | Members post and reply | Any authorised user edits any page | Own profile and posts |
| Watch out for | Opinion as fact | Unmoderated content | Errors and vandalism | Personal data and strangers |

**Moderated forum**: posts checked or removed by a moderator. **Unmoderated**: no checks.

## Functionality

- **ISP**: provides internet access; may add email, hosting, storage, filtering.
- **Web browser**: requests and displays web pages; address bar, bookmarks, history, tabs, back and forward.
- **Hyperlink**: text or image linking to another page, a place on the same page, a file or an email address.
- **URL**: the full address of a web resource.

### Parts of a URL

`https://www.example-library.ac.uk/books/search.html`

protocol `https://` · domain host `www` · domain name `example-library` · domain type `.ac` · country code `.uk` · path `/books/` · file name `search.html`

## Search engines: the four syllabus points

| Point | Strength or weakness |
|---|---|
| Speed of searching | Strength: results in a fraction of a second |
| Amount of information | Strength: vast; weakness: millions of results |
| Speed of finding relevant information | Depends on technique: keywords, quotation marks, AND, OR, NOT |
| Ease of finding reliable information | Weakness: ranking by algorithm, popularity and adverts, not accuracy |

## Evaluating information

| Criterion | Check |
|---|---|
| Up to date | Publication or last-updated date |
| Reliable | Author or organisation's expertise; agreement with trusted sources |
| Biased | Selling or persuading? Balanced? |
| Valid | References, evidence, relevance to the question |

## Protocols

| Protocol | Full name | Purpose |
|---|---|---|
| HTTP | HyperText Transfer Protocol | Transfers web pages between server and browser |
| HTTPS | HyperText Transfer Protocol secure variant | Same, with encryption; padlock shown |
| FTP | File Transfer Protocol | Transfers files between computers, such as uploading a website |
| SSL | Secure Socket Layer | Encrypted link between server and client computer |

## Risks and controls

- **Inappropriate material**: content unsuitable for the user, such as violent or adult material for children.
- **Criminal material**: content that promotes or involves illegal activity.
- **Parental control**: home filters, device settings, time limits.
- **Educational control**: school network filters, blocked sites, monitoring.
- **ISP control**: filtering at the provider, before content reaches users.
- **Debate**: protection of vulnerable users against censorship and blocking of legitimate information.

## Key terms

| Term | Meaning |
|---|---|
| Protocol | A set of rules for transferring data |
| Domain name | The registered name of the organisation in a web address |
| Moderator | A person who checks and removes posts on a forum |
| Bias | Information that presents one side or aims to persuade |
| Validity | Information that is accurate, supported by evidence and relevant |
| Filtering | Blocking access to websites or content that meet set rules |

## Exam traps

- The WWW is not the internet.
- An extranet is not public.
- A blog's readers comment; they do not edit the post.
- "HTTPS is a secure website" is too vague: it is a protocol that encrypts data in transfer.
- A .gov or .ac domain is a clue to reliability, not proof.
- Search engines rank by algorithm and adverts, so the first result is not necessarily the most reliable.
- In an evaluation, apply each criterion to the source given, then give a judgement.

## Self-test

1. State one difference between the internet and the WWW.
2. Who can access an intranet?
3. Give one feature of a wiki.
4. What is the difference between a moderated and an unmoderated forum?
5. State what an ISP provides.
6. In `https://www.citymuseum.org.za/exhibits/today.html`, identify the domain type and the path.
7. Give two features of a web browser.
8. Give one disadvantage of using a search engine to find information.
9. State the four criteria for evaluating information.
10. What is the purpose of FTP?
11. Explain how SSL protects data.
12. Give one advantage and one disadvantage of ISP control.

## Self-test answers

1. The internet is the network of networks; the WWW is the collection of pages accessed over it.
2. Members of the organisation, with a login.
3. Any authorised user can edit any page (or: quick to update; may contain errors).
4. A moderated forum has a person who checks or removes posts; an unmoderated one has no checks.
5. Access to the internet (often also email, hosting or filtering).
6. Domain type .org; path /exhibits/.
7. Any two: address bar, bookmarks, history, tabs, back and forward buttons, home page.
8. Any one: too many results; results may be unreliable or biased; ranking influenced by advertising.
9. Up to date, reliable, biased, valid.
10. Transferring files between computers, such as uploading web pages to a server.
11. It creates an encrypted link between the server and the client, so intercepted data cannot be read.
12. Advantage: protects all users, including those without home filters. Disadvantage: may block legitimate sites or be seen as censorship.
