These questions cover syllabus section 3.10 of IB DP Mathematics: Analysis and Approaches (first assessment 2021), which is HL only: the compound angle identities and the double angle identity for tan. All questions are calculator-free, so give exact answers. ## Section A

**1.** Find the exact value of sin 15°. **[2]**

**2.** **(a)** Write cos 3x cos x − sin 3x sin x as a single trigonometric function. **[1]**

**(b)** Find the exact value of sin 50° cos 20° − cos 50° sin 20°. **[2]**

**3.** Given that tan A = 2 and tan B = 3:

**(a)** find tan(A + B) **[2]**

**(b)** given also that A and B are acute, find A + B. **[1]**

**4.** Given that tan θ = −1/3, find tan 2θ. **[2]**

**5.** Show that sin(A + B) − sin(A − B) = 2 cos A sin B. **[2]**

**6.** Write cos(x − π/3) in the form p cos x + q sin x, giving the exact values of p and q. **[2]**

## Section B

**7.** Given that sin A = 4/5 with π/2 < A < π, and cos B = 24/25 with 3π/2 < B < 2π, find the exact value of:

**(a)** cos A **[1]**

**(b)** sin B **[1]**

**(c)** sin(A − B) **[2]**

**(d)** cos(A − B) **[2]**

**(e)** tan(A − B) **[1]**

**8.** Solve cos(x − π/3) = sin x for 0 ≤ x ≤ 2π. **[6]**

**9.** **(a)** Show that sin 3θ = 3 sin θ − 4sin³θ. **[4]**

**(b)** Hence solve sin 3θ = 2 sin θ for 0 ≤ θ ≤ π. **[4]**

**10.** **(a)** Show that √2 sin(x + π/4) = sin x + cos x. **[2]**

**(b)** Hence write down the greatest value of sin x + cos x and the value of x in 0 ≤ x ≤ 2π at which it occurs. **[2]**

**(c)** Hence solve sin x + cos x = 1 for 0 ≤ x ≤ 2π. **[3]**

**11.** Given that tan 2A = −24/7 and π/4 < A < π/2, find the exact value of tan A. **[4]**

**12.** Use the compound angle identities for sine and cosine to show that tan(A + B) = (tan A + tan B)/(1 − tan A tan B). **[3]**

## Answers

**1.** sin(45° − 30°) = sin 45° cos 30° − cos 45° sin 30° = (√2/2)(√3/2) − (√2/2)(1/2) [1] = **(√6 − √2)/4** [1]

**2. (a)** **cos 4x** [1]

**(b)** sin(50° − 20°) = sin 30° [1] = **1/2** [1]

**3. (a)** (2 + 3)/(1 − 6) [1] = **−1** [1]

**(b)** A and B are acute, so 0 < A + B < π, and tan(A + B) = −1 there only at **A + B = 3π/4** [1]

*Examiner insight:* The answer −π/4 is not possible for the sum of two acute angles; the reasoning about the interval is what earns the mark.

**4.** tan 2θ = 2(−1/3)/(1 − 1/9) [1] = (−2/3)/(8/9) = **−3/4** [1]

**5.** (sin A cos B + cos A sin B) − (sin A cos B − cos A sin B) [1] = **2 cos A sin B** [1]

**6.** cos x cos(π/3) + sin x sin(π/3) [1], so **p = 1/2** and **q = √3/2** [1]

**7. (a)** A is in the second quadrant: **cos A = −3/5** [1]

**(b)** B is in the fourth quadrant: **sin B = −7/25** [1]

**(c)** (4/5)(24/25) − (−3/5)(−7/25) [1] = 96/125 − 21/125 = **3/5** [1]

**(d)** (−3/5)(24/25) + (4/5)(−7/25) [1] = −72/125 − 28/125 = **−4/5** [1]

**(e)** **−3/4** [1]

*Examiner insight:* Wrong signs in (a) or (b) are followed through, but only if the working in (c) and (d) is shown.

**8.** (1/2) cos x + (√3/2) sin x = sin x [1], so (1/2) cos x = (1 − √3/2) sin x [1]. cos x = 0 would force sin x = 0, which is impossible, so divide by cos x: tan x = 1/(2 − √3) [1] = **2 + √3** after rationalising [1]. So **x = 5π/12** [1] and **x = 17π/12** [1]

*Examiner insight:* Recognising 2 + √3 as tan(5π/12) is expected on a calculator-free paper; it comes from tan(π/4 + π/6).

**9. (a)** sin 3θ = sin(2θ + θ) = sin 2θ cos θ + cos 2θ sin θ [1] = 2 sin θ cos²θ + (1 − 2sin²θ) sin θ [1] = 2 sin θ(1 − sin²θ) + sin θ − 2sin³θ [1] = **3 sin θ − 4sin³θ** [1]

**(b)** 3 sin θ − 4sin³θ = 2 sin θ gives sin θ − 4sin³θ = 0 [1], so sin θ(1 − 4sin²θ) = 0 [1]. sin θ = 0 gives **θ = 0, π** [1]; sin θ = 1/2 gives **θ = π/6, 5π/6** [1]; sin θ = −1/2 has no solution in 0 ≤ θ ≤ π.

**10. (a)** √2(sin x cos(π/4) + cos x sin(π/4)) [1] = √2(√2/2)(sin x + cos x) = **sin x + cos x** [1]

**(b)** Greatest value **√2** [1], when x + π/4 = π/2, so **x = π/4** [1]

**(c)** sin(x + π/4) = √2/2, with π/4 ≤ x + π/4 ≤ 9π/4 [1]. x + π/4 = π/4, 3π/4 or 9π/4 [1], so **x = 0, π/2, 2π** [1]

*Examiner insight:* Missing x = 2π is common; the shifted interval ends at 9π/4, which itself is a solution.

**11.** Let t = tan A: 2t/(1 − t²) = −24/7 [1], so 12t² − 7t − 12 = 0 [1]. (4t + 3)(3t − 4) = 0 gives t = 4/3 or t = −3/4 [1]. For π/4 < A < π/2, tan A > 1, so **tan A = 4/3** [1]

**12.** tan(A + B) = (sin A cos B + cos A sin B)/(cos A cos B − sin A sin B) [1]. Divide every term by cos A cos B [1]: = (sin A/cos A + sin B/cos B)/(1 − (sin A/cos A)(sin B/cos B)) = **(tan A + tan B)/(1 − tan A tan B)** [1]

## Where marks are usually lost

- Using a plus sign in cos(A + B) or a minus in cos(A − B).
- Ignoring each angle's own quadrant, as in question 7.
- Dividing by cos x without a reason, or leaving tan x = 1/(2 − √3) unsimplified.
- Failing to use the given interval to choose between roots, as in questions 3 and 11.
- Missing the endpoint solutions in question 10(c).
