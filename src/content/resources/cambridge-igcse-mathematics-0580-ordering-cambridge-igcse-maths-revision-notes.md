These notes condense subtopic **1.5 Ordering** of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027: ordering quantities by magnitude and using =, ≠, >, <, ⩾ and ⩽. Core (C1.5) and Extended (E1.5) are identical; only items using recurring decimal notation are **Extended only**. For worked examples, use the [ordering study guide](/resources/cambridge-igcse-mathematics-0580-ordering-cambridge-igcse-maths/); to test yourself, use the [ordering practice questions](/resources/cambridge-igcse-mathematics-0580-ordering-cambridge-igcse-maths-practice/).

## Symbols

| Symbol | Meaning | End value included? |
|---|---|---|
| = | equal to | — |
| ≠ | not equal to | — |
| > | greater than | no |
| < | less than | no |
| ⩾ | greater than or equal to | yes |
| ⩽ | less than or equal to | yes |

Memory aid: the symbol opens towards the larger number. A line under the symbol (⩽, ⩾) adds "or equal to".

**Listing integers.** −2 ⩽ n < 3 gives −2, −1, 0, 1, 2. Check each end separately; zero is an integer.

## Key terms

| Term | Meaning |
|---|---|
| Magnitude | Size of a quantity |
| Ascending order | Smallest first |
| Descending order | Largest first |
| Inequality | A statement using >, <, ⩾ or ⩽ |
| Place value | The value of a digit from its position (tenths, hundredths, …) |

## Method for any ordering question

```
1. Convert every value to ONE form (usually decimals) and ONE unit.
2. Write the converted values down, padded to the same number of
   decimal places.
3. Compare from the left, digit by digit.
4. Answer with the ORIGINAL values in the order asked for.
```

## Quick conversions for ordering

| Value | Decimal to compare |
|---|---|
| 3/8 | 0.375 |
| 2/3 | 0.666… |
| 5/7 | 0.714… |
| 0.4% | 0.004 |
| 115% | 1.15 |
| √10 | between 3.1 and 3.2 (3.1² = 9.61, 3.2² = 10.24) |
| 2⁻¹ | 0.5 (see [Indices I](/resources/cambridge-igcse-mathematics-0580-indices-i-cambridge-igcse-maths/)) |

## Negatives

- Further left on the number line = smaller.
- For negatives, the larger the size, the smaller the number: −3.2 < −3.02.
- Method: order the sizes as positives, then reverse.

```
−0.5, −0.45, −0.54, −½
sizes: 0.5, 0.45, 0.54, 0.5
negatives smallest first: −0.54, then −0.5 and −½ (equal), then −0.45
```

## Units

Convert to the same unit before comparing.

| Convert | Rule |
|---|---|
| km → m | × 1000 |
| m → cm | × 100 |
| kg → g | × 1000 |
| litres → ml | × 1000 |
| minutes → seconds | × 60 |
| hours → minutes | × 60 (2.3 h = 138 min, not 2 h 30 min) |

## Roots and powers without a calculator

Square (or cube) the neighbouring values to place a root:

```
Where does √30 go among 5.4, 5.5, 5.48?
5.4² = 29.16, 5.5² = 30.25, 5.48² = 30.0304
5.4 < √30 < 5.48 < 5.5
```

## Recurring decimals (Extended only)

Write out at least four decimal places: 0.2̇ = 0.2222…, 0.2̇3̇ = 0.2323…, 0.23̇ = 0.2333…. In order: 0.2̇, 0.2̇3̇, 0.23̇.

## Worked reminder: a full mixed list

Order, largest first: 0.83, 5/6, 82.5%, 0.8, 4/5

```
0.83   = 0.830
5/6    = 0.833...
82.5%  = 0.825
0.8    = 0.800
4/5    = 0.800
Largest first: 5/6, 0.83, 82.5%, then 0.8 and 4/5 (equal)
```

Two checks before writing the answer: the question says **largest** first, and the final list uses the **original** forms.

## Exam traps

- **More digits is not bigger:** 0.15 < 0.2.
- **Original form:** give the list in the forms printed in the question, not your decimals.
- **Direction:** read "smallest first", "largest first", "fastest first" (shortest time) carefully.
- **Equal values:** 2/5 and 40% are equal; place them together.
- **Time:** 1.25 hours is 1 hour 15 minutes, not 1 hour 25 minutes.
- **Squaring decimals between 0 and 1 makes them smaller:** 0.9² = 0.81 < 0.9.

## Quick self-test

1. Write the correct symbol, < or >, between −7 and −9.
2. List the integers n such that −3 < n ⩽ 2.
3. Order, smallest first: 0.09, 0.9, 0.099, 0.0999.
4. Order, smallest first: 7/20, 0.3, 33%, 1/3.
5. Order, smallest first: −2.2, −2¼, −2.02, −2.21.
6. Order, shortest first: 2.5 m, 245 cm, 2 m 6 cm, 2 040 mm.
7. Is 0.2² greater than, less than or equal to 0.2?
8. Insert = or ≠: 3/8 ... 37.5%.
9. Without a calculator, show that √20 lies between 4.4 and 4.5.
10. Which is larger: 1.4 hours or 1 hour 30 minutes?
11. Order, largest first: 2³, 3², √64, 4.
12. (Extended) Order, smallest first: 0.5̇, 0.55, 0.5̇4̇.

### Answers

1. −7 > −9
2. −2, −1, 0, 1, 2
3. 0.09, 0.099, 0.0999, 0.9
4. 0.3, 33%, 1/3, 7/20 (0.3, 0.33, 0.333…, 0.35)
5. −2¼, −2.21, −2.2, −2.02
6. In cm: 250, 245, 206, 204, so 2 040 mm, 2 m 6 cm, 245 cm, 2.5 m
7. Less than: 0.04 < 0.2
8. 3/8 = 37.5%
9. 4.4² = 19.36 < 20 and 4.5² = 20.25 > 20
10. 1.4 hours = 84 minutes < 90 minutes, so 1 hour 30 minutes is larger
11. 3² (9), then 2³ and √64 (both 8), then 4
12. 0.5̇4̇ (0.5454…), 0.55, 0.5̇ (0.5555…)

## Where marks are usually lost

- Not showing converted values, so a single slip leaves no method credit.
- Ordering negative decimals as if they were positive.
- Forgetting to convert units, or converting 1 km 85 m to 1.85 km.
- Answering in decimals when the question gave fractions and percentages.

## Frequently asked questions

**Is ⩽ the same as "at most"?**
Yes. x ⩽ 5 means x is at most 5, so 5 itself is allowed. "Fewer than 5" or "less than 5" is x < 5, which excludes 5.

**Do Core candidates need to order recurring decimals?**
No. Recurring decimal notation is Extended only in 0580. Core candidates order values such as 1/3 by writing enough decimal places, for example 0.333.
