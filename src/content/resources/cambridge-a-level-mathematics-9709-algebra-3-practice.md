These questions cover section **3.1 Algebra** of Pure Mathematics 3 (Paper 3) in the Cambridge International AS & A Level Mathematics 9709 syllabus for 2026 and 2027. A scientific calculator is allowed, but unsupported calculator answers earn no marks. Give exact answers where asked and other answers to 3 significant figures. The number in square brackets after the last part of each question is the total for the whole question.

## Questions

### Section A: short questions

**1.** Solve the equation |x + 1| = |2x − 5|. **[3]**

**2.** Solve the inequality 3x − 2 < |x + 4|. **[3]**

**3.** Find the remainder when 2x³ + x² − 5x + 4 is divided by (2x + 3). **[2]**

**4.** Expand (1 + 2x)⁻³ in ascending powers of x up to and including the term in x³, and state the set of values of x for which the expansion is valid. **[4]**

**5.** Express (3x² − 9x − 3)/((x + 1)(x − 2)²) in partial fractions. **[4]**

**6.** Find the quotient and the remainder when 2x⁴ − x³ + 3x − 1 is divided by x² + 2. **[3]**

### Section B: longer questions

**7.** The polynomial p(x) is defined by p(x) = 2x³ + ax² + bx + 6, where a and b are constants. It is given that (x − 2) is a factor of p(x) and that the remainder is −12 when p(x) is divided by (x + 1).

**(a)** Find the values of a and b.

**(b)** Hence factorise p(x) completely.

**(c)** Use the remainder theorem to find the remainder when p(x) is divided by x² − 1. **[8]**

**8.** Let f(x) = (x² + 3x + 11)/((1 + 2x)(3 + x²)).

**(a)** Express f(x) in partial fractions.

**(b)** Hence obtain the expansion of f(x) in ascending powers of x, up to and including the term in x², and state the set of values of x for which the expansion is valid. **[9]**

**9.** Let f(x) = (4x² + 9x − 4)/((2x − 1)(x + 1)).

**(a)** Express f(x) in partial fractions.

**(b)** Hence find the expansion of f(x) in ascending powers of x, up to and including the term in x², and state the set of values of x for which it is valid. **[8]**

**10.** **(a)** Sketch, on the same diagram, the graphs of y = |2x − 3| and y = |x + 1|, showing where each graph meets the axes.

**(b)** Solve the equation |2x − 3| = |x + 1|.

**(c)** Hence solve the inequality |2x − 3| < |x + 1|.

**(d)** Hence solve the equation |2√t − 3| = |√t + 1|. **[8]**

**11.** **(a)** Expand √((1 + x)/(1 − x)) in ascending powers of x, up to and including the term in x², and state the set of values of x for which the expansion is valid.

**(b)** By substituting x = 1/10 into your expansion, find an approximate value of √11, giving your answer to 4 significant figures. **[7]**

**12.** Let f(x) = (1 + 3x)/(2 − x)².

**(a)** Expand f(x) in ascending powers of x, up to and including the term in x².

**(b)** State the set of values of x for which the expansion is valid. **[5]**

## Answers

**1.** Both sides are moduli, so square: (x + 1)² = (2x − 5)² [1]. x² + 2x + 1 = 4x² − 20x + 25, so 3x² − 22x + 24 = 0 and (3x − 4)(x − 6) = 0 [1]. **x = 4/3 or x = 6** [1]

*Examiner insight:* solving only x + 1 = 2x − 5 gives x = 6 alone and loses the final mark.

**2.** Right arm: 3x − 2 = x + 4 gives x = 3, and |7| = 7, so the graphs meet there [1]. Left arm: 3x − 2 = −(x + 4) gives x = −1/2, but there 3x − 2 = −3.5, which is negative, so this is not a meeting point [1]. The line y = 3x − 2 is below the V for all x < 3: **x < 3** [1]

*Examiner insight:* squaring here gives the false boundary −1/2 and usually the wrong answer −1/2 < x < 3.

**3.** Remainder = p(−3/2) = 2(−27/8) + 9/4 + 15/2 + 4 [1] = −27/4 + 9/4 + 30/4 + 16/4 = **7** [1]

**4.** (1 + 2x)⁻³ = 1 + (−3)(2x) + [(−3)(−4)/2](2x)² + [(−3)(−4)(−5)/6](2x)³. First two terms 1 − 6x [1]. x² term 6 × 4x² = 24x² [1]. x³ term −10 × 8x³ = −80x³ [1]. So **1 − 6x + 24x² − 80x³**, valid for |2x| < 1, that is **|x| < 1/2** [1]

**5.** 3x² − 9x − 3 ≡ A(x − 2)² + B(x + 1)(x − 2) + C(x + 1) [1]. x = −1: 3 + 9 − 3 = 9A, so A = 1 [1]. x = 2: 12 − 18 − 3 = 3C, so C = −3 [1]. Compare x²: 3 = A + B, so B = 2. **1/(x + 1) + 2/(x − 2) − 3/(x − 2)²** [1]

*Examiner insight:* a form without the B/(x − 2) term cannot be made to work and scores nothing.

**6.** Write 2x⁴ − x³ + 0x² + 3x − 1. First term 2x² leaves −x³ − 4x² + 3x − 1 [1]. Next term −x leaves −4x² + 5x − 1; next term −4 leaves 5x + 7 [1]. Quotient **2x² − x − 4**, remainder **5x + 7** [1]

**7.** **(a)** p(2) = 0: 16 + 4a + 2b + 6 = 0, so 2a + b = −11 [1]. p(−1) = −12: −2 + a − b + 6 = −12, so a − b = −16 [1]. Adding: 3a = −27 [1]. **a = −9, b = 7** [1]

**(b)** p(x) = 2x³ − 9x² + 7x + 6 = (x − 2)(2x² − 5x − 3) [1] = **(x − 2)(x − 3)(2x + 1)** [1]

**(c)** p(x) ≡ (x − 1)(x + 1)q(x) + Ax + B, so p(1) = A + B = 6 and p(−1) = −A + B = −12 [1]. B = −3, A = 9: remainder **9x − 3** [1]

*Examiner insight:* in (c), the remainder after dividing by a quadratic is linear; a single constant cannot be right.

**8.** **(a)** x² + 3x + 11 ≡ A(3 + x²) + (Bx + C)(1 + 2x) [1]. x = −1/2: 39/4 = 13A/4, so A = 3 [1]. Compare x²: 1 = A + 2B, so B = −1 [1]. Compare constants: 11 = 3A + C, so C = 2. **f(x) = 3/(1 + 2x) + (2 − x)/(3 + x²)** [1]

**(b)** 3(1 + 2x)⁻¹ = 3 − 6x + 12x² [1]. (3 + x²)⁻¹ = ⅓(1 + x²/3)⁻¹ = ⅓ − x²/9 [1]. (2 − x)(⅓ − x²/9) = 2/3 − x/3 − 2x²/9 + … [1]. f(x) = **11/3 − 19x/3 + 106x²/9** [1]. Valid for **|x| < 1/2** [1]

*Examiner insight:* (3 + x²)⁻¹ needs |x| < √3, but (1 + 2x)⁻¹ needs |x| < 1/2; the narrower interval is the answer.

**9.** **(a)** The numerator and denominator are both of degree 2, so f(x) = 2 + A/(2x − 1) + B/(x + 1) [1]. 4x² + 9x − 4 ≡ 2(2x − 1)(x + 1) + A(x + 1) + B(2x − 1) [1]. x = 1/2: 3/2 = 3A/2, so A = 1 [1]. x = −1: −9 = −3B, so B = 3. **f(x) = 2 + 1/(2x − 1) + 3/(x + 1)** [1]

**(b)** 1/(2x − 1) = −(1 − 2x)⁻¹ = −1 − 2x − 4x² [1]. 3/(1 + x) = 3 − 3x + 3x² [1]. f(x) = 2 − 1 − 2x − 4x² + 3 − 3x + 3x² = **4 − 5x − x²** [1]. Valid for **|x| < 1/2** [1]

*Examiner insight:* f(0) = −4/(−1) = 4, which matches the constant term and confirms the constant 2 was included.

**10.** **(a)** V with vertex (3/2, 0) and y-intercept (0, 3) [1]. V with vertex (−1, 0) and y-intercept (0, 1), drawn crossing the first graph twice [1]

**(b)** (2x − 3)² = (x + 1)² [1], so 3x² − 14x + 8 = 0 [1]. (3x − 2)(x − 4) = 0: **x = 2/3 or x = 4** [1]

**(c)** **2/3 < x < 4** [1]

**(d)** Replace x by √t: √t = 2/3 or √t = 4 [1]. **t = 4/9 or t = 16** [1]

**11.** **(a)** (1 + x)^½ = 1 + x/2 − x²/8 [1]. (1 − x)^(−½) = 1 + x/2 + 3x²/8 [1]. Product: 1 + x/2 + x/2 + 3x²/8 + x²/4 − x²/8 [1] = **1 + x + x²/2** [1]. Valid for **|x| < 1** [1]

**(b)** With x = 1/10, √(1.1/0.9) = √(11/9) = √11/3 ≈ 1 + 0.1 + 0.005 = 1.105 [1]. √11 ≈ 3 × 1.105 = **3.315** [1]

*Examiner insight:* the substitution x = 1/10 lies inside |x| < 1, which is why the approximation is allowed; the true value is 3.3166.

**12.** **(a)** (2 − x)⁻² = ¼(1 − x/2)⁻² [1] = ¼(1 + x + 3x²/4) [1]. Multiply by (1 + 3x): ¼(1 + 4x + 15x²/4) [1] = **1/4 + x + 15x²/16** [1]

**(b)** |x/2| < 1, so **|x| < 2** [1]

## Where marks are usually lost

- Squaring a modulus inequality with an ordinary expression on one side.
- Missing the repeated-factor term B/(x − 2), or putting a constant over a quadratic factor.
- Leaving out the constant term when the numerator and denominator have equal degree.
- Not taking out 3⁻¹ or 2⁻² before expanding, or squaring only the coefficient inside the bracket.
- Giving the validity of only one part of a combined expansion.
- Treating the remainder after division by a quadratic as a constant.
