These notes condense **section 2.15 (AHL only)** of IB DP Mathematics: Analysis and Approaches, first assessment 2021: solving g(x) ≥ f(x) graphically and analytically. The full method with worked examples is in the [inequalities study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-15/); exam-style questions are in the [inequalities practice set](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-15-practice/).

## Condensed recall

**Meaning**

- g(x) ≥ f(x) where the graph of g is on or above the graph of f.
- Boundaries are the solutions of g(x) = f(x).
- Same as h(x) = g(x) − f(x) ≥ 0: where y = h(x) is on or above the x-axis.

**Scope**

- By hand: polynomial inequalities up to degree 3 (and anything that reduces to a product of simple factors).
- With technology: inequalities involving other functions, such as eˣ, ln x or sin x mixed with polynomials.

**Analytic method**

1. Rearrange to h(x) ≥ 0 (or >, ≤, <).
2. Factorise fully; for a cubic, find a root with the factor theorem first.
3. Mark zeros (and any values where h is undefined) on a number line.
4. Determine the sign in each interval.
5. Choose the intervals; include zeros for ≥ and ≤ only.

**Sign shortcuts**

- Positive leading coefficient: the sign is + for large x.
- Single roots alternate the sign; reading right to left from +.
- Cubic, positive leading coefficient, three single roots a < b < c: −, +, −, + across a, b, c.
- Even-power factor (x − r)²: no sign change at r, but h(r) = 0.
- Negative leading coefficient: multiply through by −1 and reverse the inequality first, or start from − on the right.

**Things you must never do**

- Divide by x or by a bracket whose sign you do not know.
- Multiply by a denominator that could be negative.
- Square both sides unless both sides are known to be non-negative.

**Rational expressions**

- Move everything to one side over a common denominator.
- Critical values: zeros of the numerator and of the denominator.
- Values that make the denominator zero are always excluded.

**Technology presentation**

- State the domain if a function has one (ln needs a positive argument).
- Write the equation solved, list both boundary values, then the interval.
- Exact values (such as x = −1 when ln 1 = 0) are written exactly; others to 3 significant figures.

**Writing answers**

- Separate intervals are joined by "or".
- An isolated point is written as "or x = r".
- "x ≠ r" removes a single point from an interval.

**A two-line worked reminder**

- Solve x³ + x² ≥ 6x: x(x² + x − 6) ≥ 0, so x(x + 3)(x − 2) ≥ 0.
- Signs −, +, −, + across −3, 0, 2, so −3 ≤ x ≤ 0 or x ≥ 2. Dividing by x first would lose −3 ≤ x ≤ 0 and wrongly keep x < −3.

## Key terms

| Term | Meaning |
|---|---|
| Critical value | A value of x where h(x) = 0 or h(x) is undefined |
| Sign table | A table of the sign of each factor in each interval |
| Single root | A root where the sign changes |
| Double root | A root of multiplicity 2: the sign does not change |
| Strict inequality | > or <: endpoints excluded |
| Non-strict inequality | ≥ or ≤: endpoints included (if defined) |
| Isolated solution | A single point that satisfies a non-strict inequality on its own |

## Exam traps

- x³ > 4x is not x² > 4: dividing by x loses −2 < x < 0.
- (x − 3)²(x + 1) ≤ 0 has the isolated solution x = 3 as well as x ≤ −1.
- (x − 3)²(x + 1) > 0 must exclude x = 3.
- In (x + 2)/(x − 1) ≥ 0, x = 1 is never included.
- "x < −3 and x > 2" is an empty set; use "or".
- A GDC answer with only the intersection values, and no interval, is incomplete.

## Self-test

1. Solve (x − 1)(x + 4)(x − 3) < 0.
2. Solve x³ ≥ x.
3. Solve (x + 2)²(x − 5) ≥ 0.
4. Solve (x + 2)²(x − 5) < 0.
5. Solve 9x − x³ > 0.
6. Solve x³ − 2x² ≤ 0.
7. Solve (x − 4)/(x + 1) ≤ 0.
8. Explain the error in solving x³ ≥ 9x by writing x² ≥ 9.
9. The graphs of y = g(x) and y = f(x) meet only at x = −1.2 and x = 2.7, and g is above f between them. Solve g(x) > f(x).
10. Find the values of k for which x² + kx + 4 > 0 for all x.
11. Use technology to solve eˣ ≥ 3x.
12. State the domain restriction you must apply before solving ln(3 − x) > x graphically.

### Answers

1. Signs −, +, −, + across −4, 1, 3: x < −4 or 1 < x < 3.
2. x(x − 1)(x + 1) ≥ 0: −1 ≤ x ≤ 0 or x ≥ 1.
3. x ≥ 5 or x = −2.
4. x < 5 with x ≠ −2.
5. x(x − 3)(x + 3) < 0: x < −3 or 0 < x < 3.
6. x²(x − 2) ≤ 0: x ≤ 2 (x = 0 is already included).
7. −1 < x ≤ 4.
8. Dividing by x assumes x > 0; the correct solution is −3 ≤ x ≤ 0 or x ≥ 3.
9. −1.2 < x < 2.7.
10. Discriminant k² − 16 < 0, so −4 < k < 4.
11. Boundaries at x = 0.619 and x = 1.51 (3 s.f.): x ≤ 0.619 or x ≥ 1.51.
12. 3 − x > 0, so x < 3.
