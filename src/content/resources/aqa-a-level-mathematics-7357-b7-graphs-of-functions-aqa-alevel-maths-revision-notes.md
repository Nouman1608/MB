These notes condense content statement **B7** of AQA A-level Mathematics (7357), Section B: Algebra and functions. B7 covers sketching polynomials, the modulus of a linear function, y = a/x and y = a/x² with their asymptotes, interpreting algebraic solutions graphically, using intersections to solve equations, and proportional relationships and their graphs. Full worked examples are in the [B7 graphs of functions study guide](/resources/aqa-a-level-mathematics-7357-b7-graphs-of-functions-aqa-alevel-maths/); exam-style questions are in the [B7 practice questions](/resources/aqa-a-level-mathematics-7357-b7-graphs-of-functions-aqa-alevel-maths-practice/). B7 and B8 are summarised together in the [graphs, composite and inverse functions revision notes](/resources/aqa-a-level-mathematics-graphs-of-functions-composite-functions-and-inverse-revision-notes/).

## Key terms

| Term | Meaning |
|---|---|
| Root (zero) | A value of x where y = 0; an x-intercept |
| Multiplicity | The power of a factor: (x − a)² gives a root of multiplicity 2 |
| Asymptote | A line the curve approaches ever more closely without reaching it |
| Vertical asymptote | A line x = k where y grows without limit, such as x = 0 for y = a/x |
| Horizontal asymptote | A line y = k approached as x gets very large, such as y = 0 for y = a/x |
| Modulus | |x| is the non-negative size of x |
| Direct proportion | y = kxⁿ: the graph of y against xⁿ is a line through the origin |
| Inverse proportion | y = k/xⁿ: the graph of y against 1/xⁿ is a line through the origin |

## Polynomial sketching checklist

1. Factorise fully. Each factor gives a root.
2. Odd power: crosses. Even power: touches and turns back.
3. Leading term: sign and degree fix both ends.
   - Even degree, positive: both ends up. Even, negative: both down.
   - Odd degree, positive: bottom left to top right. Odd, negative: top left to bottom right.
4. Put x = 0 for the y-intercept.
5. Test one value between roots if unsure of the sign.

**From a sketch to an equation:** write y = a × (factors with the right powers), then substitute a known point, usually the y-intercept, to find a.

*Reminder.* Touches at (3, 0), crosses at (−1, 0), passes through (0, 18), cubic: y = a(x − 3)²(x + 1), 18 = 9a, so a = 2.

## Modulus of a linear function

- y = |ax + b| is a V with vertex (−b/a, 0), arms of gradient ±a, y-intercept |b|.
- **One modulus = expression:** solve each arm separately; reject a root on the wrong arm; check in the original.
- **Modulus = modulus:** square both sides (both are non-negative), solve the quadratic, check.
- **Modulus inequality, both sides moduli:** square, then solve the quadratic inequality.

*Reminder.* |x + 1| = |x − 5| gives (x + 1)² = (x − 5)², so 12x = 24 and x = 2: the vertical line midway between the vertices.

## y = a/x and y = a/x²

| Feature | y = a/x | y = a/x² |
|---|---|---|
| Asymptotes | x = 0 and y = 0 | x = 0 and y = 0 |
| a > 0 | Quadrants 1 and 3 | Both branches above the x-axis |
| a < 0 | Quadrants 2 and 4 | Both branches below the x-axis |
| Symmetry | Rotational, order 2, about the origin | Reflection in the y-axis |
| Near x = 0 | Opposite signs on each side | Same sign on each side |

## Intersections and solutions

- The real roots of f(x) = g(x) are the x-coordinates where y = f(x) and y = g(x) meet.
- Number of distinct real roots = number of intersection points.
- A repeated root means the graphs touch (a tangent point).
- A line with a hyperbola gives a quadratic: use the discriminant, then exclude x = 0.
- To show the number of roots of a hard equation, rearrange into two sketchable curves and count crossings; give a reason for each region.

## Proportion tests from data

| Calculate | Constant? | Equation |
|---|---|---|
| y/x | Yes | y = kx |
| y/x² | Yes | y = kx² |
| xy | Yes | y = k/x |
| x²y | Yes | y = k/x² |

**Scaling rule.** If y ∝ xⁿ, multiplying x by c multiplies y by cⁿ. If y ∝ 1/xⁿ, multiplying x by c divides y by cⁿ.

## Exam traps

- A double root drawn as a crossing.
- Leading coefficient assumed to be 1 when finding an equation from a sketch.
- Asymptotes drawn but not labelled, or y = a/x² drawn below the axis for a > 0.
- Squaring when only one side is a modulus, then keeping a false root.
- A hyperbola question answered without excluding x = 0.
- Two intersections claimed when one root is repeated.
- "Line through the origin" omitted when describing a proportional graph.

## Quick self-test

1. Describe the behaviour of y = (x + 1)²(x − 4) at each root.
2. State the end behaviour of y = −2x⁴ + x.
3. A quartic touches the x-axis at x = 0 and x = 3 and passes through (1, 8). Find its equation.
4. Solve |2x − 7| = |x + 1|.
5. Solve |x| > |x − 6|.
6. State the asymptotes of y = −6/x and the quadrants it occupies.
7. How many times does y = 5/x² meet y = −x? Explain.
8. Find the values of c for which y = c/x and y = 4 − x meet at two points.
9. Solve 2/x = x − 1 and give the points of intersection.
10. y ∝ x³. x is halved. What happens to y?
11. Data: x = 1, 4, 9; y = 6, 12, 18. Find the relationship.
12. Solve x³ − 3x + 2 = 0 and say what the repeated root means for y = x³ and y = 3x − 2.

### Answers

1. Touches the axis at x = −1 (double root); crosses at x = 4.
2. Even degree, negative leading coefficient: both ends go down.
3. y = ax²(x − 3)², and 8 = a(1)(4), so a = 2: **y = 2x²(x − 3)²**.
4. (2x − 7)² = (x + 1)² gives 3x² − 30x + 48 = 0, so x² − 10x + 16 = 0: **x = 2 or x = 8**.
5. x² > (x − 6)² gives 12x > 36: **x > 3**.
6. **x = 0 and y = 0**; quadrants 2 and 4.
7. **Once.** y = 5/x² is always positive, so the meeting point needs −x > 0, x < 0; there 5/x² = −x gives x³ = −5, one solution.
8. c/x = 4 − x gives x² − 4x + c = 0; 16 − 4c > 0, so **c < 4, c ≠ 0**.
9. x² − x − 2 = 0, so x = 2 or x = −1: **(2, 1) and (−1, −2)**.
10. y is multiplied by (1/2)³, so it becomes **one-eighth** of its value.
11. y/√x = 6 each time, so **y = 6√x** (y ∝ x^(1/2)).
12. (x − 1)²(x + 2) = 0: **x = 1 (repeated) or x = −2**. The line y = 3x − 2 is a tangent to y = x³ at (1, 1) and crosses it at (−2, −8).
