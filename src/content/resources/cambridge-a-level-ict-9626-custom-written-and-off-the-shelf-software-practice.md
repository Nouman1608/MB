These questions are for **section 2.4 Custom-written software and off-the-shelf software** (Topic 2, AS Level) of Cambridge International AS & A Level Information Technology (9626), 2025–2027. All organisations and figures are invented.

---

## Section A

**1.** Define off-the-shelf software. **[2]**

**2.** State **two** differences between proprietary software and open-source software. **[2]**

**3.** Explain why custom-written software may contain more undiscovered errors than off-the-shelf software when it is first installed. **[2]**

**4.** Give **two** uses of off-the-shelf software by individuals. **[2]**

**5.** Explain **one** reason why individuals rarely use custom-written software. **[2]**

**6.** Explain what is meant by the adaptability of software, using an example. **[2]**

## Section B

**7.** Ravelstone Clinic has 40 staff who need a patient-booking system. An off-the-shelf package costs £180 per user per year. A custom-written system would cost £45,000 to develop plus £4,500 a year for maintenance.

**(a)** Calculate the total cost of each option over five years. **[2]**

**(b)** Calculate the number of users at which the two options would cost the same over five years. **[2]**

**(c)** Explain **two** factors, other than cost, that Ravelstone should consider. **[4]**

**8.** A small charity is deciding whether to use open-source office software instead of a proprietary office suite. Discuss the advantages and disadvantages of this choice for the charity. **[6]**

**9.** Compare the level of support available for off-the-shelf software with that for custom-written software. **[4]**

**10.** Tidewell Outfitters is an online clothing retailer with an unusual process for handling returns between its three warehouses. Evaluate whether Tidewell should commission custom-written software to manage returns. **[6]**

**11.** A software house builds custom-written control software for a factory using open-source components. Explain **two** benefits of using open-source components. **[4]**

**12.** A student wants software to edit videos for a school project and has no budget. Recommend a type of software, referring to both off-the-shelf or custom-written, and proprietary or open-source. Justify your recommendation. **[4]**

---

## Answers

**1.** Ready-made software developed for a general market [1] that is sold or licensed to many users, rather than written for one client [1]. **[2]**

**2.** Any two from: proprietary source code is kept secret, open-source code is published [1]; proprietary licences forbid modification, open-source licences allow it [1]; proprietary usually needs a paid licence, open-source is often free; proprietary has professional support, open-source often relies on a community. **[2]**

**3.** Custom software has been tested only by the developer and the client [1], whereas off-the-shelf software has been used by many people who have reported bugs that were then fixed [1]. **[2]**

**4.** Any two from: word processing [1]; photo editing [1]; games; web browsing; anti-virus protection; managing personal finances. **[2]**

**5.** The individual would have to pay the whole development cost alone [1], which is far more than the price of a ready-made package that does most of what they need [1]. **[2]**

**6.** How easily software can be changed or extended to fit a user's needs [1]; for example, custom software for a warehouse can have a new screen added when the warehouse adds a delivery service [1]. **[2]**

**7. (a)** Off-the-shelf: 40 × 180 × 5 = **£36,000** [1]. Custom: 45,000 + 5 × 4,500 = **£67,500** [1].

**(b)** Off-the-shelf cost per user over five years = 180 × 5 = £900 [1]; 67,500 ÷ 900 = **75 users** [1].

**(c)** Adaptability [1]: if the clinic's booking rules are unusual, a package may not fit and staff would need workarounds, while custom software could match them [1]. Time [1]: the package is available immediately, whereas custom software may take months, delaying the benefits [1]. Also accept testing or support, explained. **[8]**

**8.** Advantages: usually free, so the charity saves licence fees for every computer [1]; it can be installed on as many computers as needed [1]; volunteers can use it at home without buying a licence [1]. Disadvantages: support may rely on community forums rather than a helpline [1]; some file formats may not display exactly as in the proprietary suite when sharing with other organisations [1]; staff may need time to learn a different interface [1]. **[6]**

**9.** Off-the-shelf software has large user communities, forums, help pages and training courses [1], and many staff already know it [1], whereas custom-written support comes only from the developer, but is tailored to the client's system [1]; custom support may end if the developer stops trading [1]. **[4]**

**10.** For custom: the returns process is unusual, so a package is unlikely to fit [1]; software built around it could save staff time across three warehouses [1] and can be changed as the business changes [1]. Against: development is expensive and takes months [1], and the software is tested only by the developer and Tidewell, so errors may appear when it goes live [1]. Conclusion: custom software is justified if no package can handle the returns process, because the process runs every day and affects customers directly [1]. **[6]**

**11.** The components are free to use, so development costs less [1] and the factory pays less for the custom system [1]. The source code is available, so the developer can modify the components to fit the factory's machines exactly [1], and many developers have already tested and inspected the code [1]. **[4]**

**12.** Off-the-shelf, because video editing is a common task and the student needs software straight away [1], and custom software would cost far more than any budget [1]. Open-source, because it is usually free of charge [1] and has enough features for a school project, with online tutorials for support [1]. **[4]**

## Where marks are usually lost

- Calculating custom cost without the yearly maintenance.
- Giving one-sided answers when asked to compare or discuss.
- Writing "open-source means free" without mentioning source code.
- Ignoring the scenario: an answer about "a company" when the question names a clinic or a charity.
- Recommending without justifying.
