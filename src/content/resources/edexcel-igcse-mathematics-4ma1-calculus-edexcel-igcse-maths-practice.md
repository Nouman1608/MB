## Section A

**1.** **(Higher tier only)** y = 6x⁴ − 3x² + 8. Find dy/dx. **[2]**

**2.** **(Higher tier only)** y = 5x − 7 + 2/x. Find dy/dx. **[2]**

**3.** **(Higher tier only)** y = (2x − 1)(x + 4). Find dy/dx. **[2]**

**4.** **(Higher tier only)** Find the gradient of the curve y = x² − 6x + 1 at the point (5, −4). **[2]**

**5.** **(Higher tier only)** y = (x⁴ + 3x²)/x². Find dy/dx. **[2]**

**6.** **(Higher tier only)** State what dy/dx = 0 tells you about the graph of y at that point. **[1]**

## Section B

**7.** **(Higher tier only)** A curve has equation y = x³ − 12x + 4.

**(a)** Find the coordinates of the two turning points. **[4]**

**(b)** State which turning point is the maximum. Give a reason. **[1]**

**8.** **(Higher tier only)** Find the coordinates of the point on the curve y = 2x² − 8x + 3 where the gradient is 4. **[3]**

**9.** **(Higher tier only)** Find the equation of the tangent to the curve y = x² + 3x − 2 at the point where x = 1. **[4]**

**10.** **(Higher tier only)** A particle moves along a straight line. Its displacement, s metres, from a fixed point O after t seconds is s = t³ − 6t² + 9t.

**(a)** Find an expression for the velocity v. **[1]**

**(b)** Find the two times when the particle is at rest. **[2]**

**(c)** Find the acceleration when t = 4. **[2]**

**(d)** Find the displacement from O when the particle is first at rest. **[1]**

**11.** **(Higher tier only)** y = x + 9/x, for x > 0.

**(a)** Find the coordinates of the turning point. **[3]**

**(b)** Explain, using the shape of the graph, whether it is a maximum or a minimum. **[1]**

**12.** **(Higher tier only)** A gardener has 80 m of fencing. She makes a rectangular enclosure against a straight wall, using the fencing for the other three sides. The two sides at right angles to the wall are each x m long.

**(a)** Show that the area, A m², is A = 80x − 2x². **[2]**

**(b)** Find the maximum area. **[3]**

**13.** **(Higher tier only)** The volume, V cm³, of water in a container t seconds after a tap is opened is V = 3t² + 20t. Find the rate at which the volume is increasing when t = 4. **[2]**

## Answers

**1.** **24x³ − 6x** (1 mark for each correct term; the 8 differentiates to 0) [2].

**2.** 2/x = 2x⁻¹ [1]; **dy/dx = 5 − 2/x²** (or 5 − 2x⁻²) [1].

**3.** y = 2x² + 7x − 4 [1]; **dy/dx = 4x + 7** [1].

**4.** dy/dx = 2x − 6 [1]; at x = 5, the gradient is **4** [1].

**5.** y = x² + 3 [1]; **dy/dx = 2x** [1].

**6.** The gradient is zero, so the point is a **stationary point** (the tangent is horizontal) [1].

**7. (a)** dy/dx = 3x² − 12 [1]; 3x² − 12 = 0 gives x = 2 or x = −2 [1]; x = 2: y = 8 − 24 + 4 = −12; x = −2: y = −8 + 24 + 4 = 20 [1]; **(2, −12) and (−2, 20)** [1].

**(b)** **(−2, 20)**: the curve is a cubic with a positive x³ coefficient, so the left-hand turning point is the maximum [1].

**8.** dy/dx = 4x − 8 [1]; 4x − 8 = 4 gives x = 3 [1]; y = 18 − 24 + 3 = −3, so **(3, −3)** [1].

**9.** At x = 1, y = 1 + 3 − 2 = 2 [1]; dy/dx = 2x + 3 [1], which is 5 at x = 1 [1]; 2 = 5(1) + c gives c = −3, so **y = 5x − 3** [1].

**10. (a)** **v = 3t² − 12t + 9** [1].

**(b)** 3(t² − 4t + 3) = 3(t − 1)(t − 3) = 0 [1]; **t = 1 and t = 3** [1].

**(c)** a = dv/dt = 6t − 12 [1]; at t = 4, **a = 12 m/s²** [1].

**(d)** s = 1 − 6 + 9 = **4 m** [1].

**11. (a)** y = x + 9x⁻¹, so dy/dx = 1 − 9x⁻² = 1 − 9/x² [1]; 1 − 9/x² = 0 gives x² = 9, and x > 0 so x = 3 [1]; y = 3 + 3 = 6: **(3, 6)** [1].

**(b)** For x > 0 the value of y is very large when x is close to 0 and also when x is large, so the curve comes down and goes back up: (3, 6) is a **minimum** [1].

**12. (a)** The side parallel to the wall is 80 − 2x [1]; A = x(80 − 2x) = 80x − 2x² [1].

**(b)** dA/dx = 80 − 4x [1]; 80 − 4x = 0 gives x = 20 [1]; A = 1600 − 800 = **800 m²**, a maximum because A is a negative quadratic in x [1].

**13.** dV/dt = 6t + 20 [1]; at t = 4, **44 cm³ per second** [1].

## Where marks are usually lost

- Question 1: differentiating the constant 8 to 8, or 6x⁴ to 6x³.
- Question 2: differentiating 2/x as 2 or as −2/x. Rewrite as 2x⁻¹ first.
- Question 3: multiplying the derivatives of the brackets, 2 × 1 = 2, instead of expanding first.
- Question 5: differentiating the numerator and the denominator separately.
- Question 7(a): finding only x = 2 from 3x² = 12; the negative root is also a turning point.
- Question 9: using the gradient function 2x + 3 as the gradient, giving a "tangent" that is not a straight line.
- Question 10(b): setting s = 0 instead of v = 0 for "at rest".
- Question 10(c): substituting t = 4 into v instead of a.
- Question 11(a): differentiating 9/x as 9 or −9/x.
- Question 12(a): using 80 − x for the side along the wall, which counts only one of the two x sides.
- Question 12(b): giving x = 20 as the answer when the question asks for the area.

## Checking with the graph

A quick check for question 7: a cubic with a positive x³ coefficient goes up, then down, then up, and (−2, 20) is higher than (2, −12), as a maximum on the left should be. For question 12, try a value either side of x = 20: x = 19 gives A = 798 and x = 21 gives A = 798, both smaller than 800.
