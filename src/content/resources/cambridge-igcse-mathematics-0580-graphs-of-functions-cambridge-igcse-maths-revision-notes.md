These notes condense subtopic **2.10 Graphs of functions** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027): constructing tables of values, drawing and interpreting graphs, and solving equations graphically. Core (C2.10) uses ax + b, ±x² + ax + b and a/x with integer a and b. Lines marked *(Extended)* are E2.10 only: sums of up to three terms axⁿ (n = −2, −1, −½, 0, ½, 1, 2, 3), abˣ + c, and exponential growth and decay. For worked examples, read the [graphs of functions study guide](/resources/cambridge-igcse-mathematics-0580-graphs-of-functions-cambridge-igcse-maths/); for marked questions, use the [graphs of functions practice questions](/resources/cambridge-igcse-mathematics-0580-graphs-of-functions-cambridge-igcse-maths-practice/).

## Key terms

| Term | Meaning |
|---|---|
| Table of values | Chosen x-values with their calculated y-values, ready to plot |
| Root | A solution of f(x) = 0; where the graph crosses the x-axis |
| Intersection | A point where two graphs meet; its x-coordinate solves f(x) = g(x) |
| Line of symmetry | For a quadratic, the vertical line halfway between the roots |
| Asymptote | A line a curve approaches but never meets |
| Growth / decay *(Extended)* | Repeated multiplication by a factor greater than 1 / between 0 and 1 |

## Shapes to recognise

| Function | Graph |
|---|---|
| y = ax + b | straight line, gradient a, y-intercept b |
| y = x² + ax + b | U-shaped parabola |
| y = −x² + ax + b | n-shaped parabola |
| y = a/x, a > 0 | two branches, in the 1st and 3rd quadrants |
| y = a/x, a < 0 | two branches, in the 2nd and 4th quadrants |
| y = ax³ + … *(Extended)* | S-shaped; a > 0 rises left to right, a < 0 falls |
| y = a/x² *(Extended)* | two branches, both on the same side of the x-axis (above if a > 0) |
| y = a√x *(Extended)* | starts at the origin, defined for x ≥ 0, rising ever more slowly if a > 0 |
| y = abˣ *(Extended)* | passes through (0, a); grows if b > 1 |

## Condensed recall

### Building a table

```
1. One row per term; brackets around negative x-values.
2. Square or cube before applying the sign in front: -(-3)^2 = -9.
3. Add the rows for y.
4. Check: quadratics are symmetrical; values should change smoothly.
```

Exclude x = 0 for any term with a negative power of x (a/x, a/x²).

### Drawing

- Small crosses, plotted exactly.
- One smooth curve through every point; no ruled segments, no flat bottoms.
- Reciprocal branches never cross x = 0.

### Graphical solutions

| You want to solve | Draw | Read |
|---|---|---|
| f(x) = 0 | nothing extra (y = 0 is the x-axis) | where the curve crosses the x-axis |
| f(x) = k | horizontal line y = k | x-coordinates of crossings |
| another equation | rearrange to f(x) = (linear expression), draw y = that line | x-coordinates of crossings |

Line check: (the curve's expression) − (the line's expression) must equal your equation's left side.

Example: graph of y = x² − 3x is drawn; to solve x² − 5x + 2 = 0, add 2x − 2 to both sides to give x² − 3x = 2x − 2. Draw **y = 2x − 2**.

### Number of solutions

The number of crossing points is the number of real solutions in the drawn range. A sign change in a table shows that a root lies between those two x-values.

### Exponential models *(Extended)*

```
y = a × b^x:   value at x = 0 is a
b > 1 growth;  0 < b < 1 decay
percentage change per step = (b - 1) × 100%
y = a × b^x + c:  value at x = 0 is a + c, asymptote y = c
```

## Exam traps

- **−x² with negative x.** For y = −x² + 5 at x = −3: −9 + 5 = −4, not 14.
- **Graph readings outside tolerance** come from careless scale reading; check what one small square represents.
- **Wrong line.** For x² − 3x = 4 the line is y = 4 (horizontal), not y = 4x.
- **y instead of x.** "Solve" asks for x-values.
- **A missing solution.** Check both sides of a turning point and both branches of a reciprocal graph for crossings.
- **Joining reciprocal branches** across the asymptote.
- **Including x = 0** in a table for a/x or a/x² *(Extended)*.
- **Percentage from the multiplier** *(Extended)*: 0.85 is a 15% decrease, not 85%.

## Self-test

1. Find y when x = −1 for y = x² − 4x + 1.
2. Find y when x = −3 for y = −x² + 5.
3. For y = 12/x, find y when x = −4, and explain why there is no value at x = 0.
4. The graph of y = x² − 3x is drawn. Which line would you draw to solve x² − 3x = 4? Give the solutions.
5. The graph of y = x² − 3x is drawn. Which line would you draw to solve x² − 5x + 2 = 0?
6. Where does y = x² + x − 2 cross the x-axis?
7. *(Extended)* Find y when x = −1 for y = x³ − 2x².
8. *(Extended)* Find y when x = 0.5 for y = 2/x².
9. *(Extended)* Find y when x = −1 for y = 3 × 2ˣ.
10. *(Extended)* The graph of y = x³ − 4x is drawn. Which line would you draw to solve x³ − 6x + 1 = 0?
11. *(Extended)* The value of a car is modelled by V = 5000 × 0.85ᵗ. Is this growth or decay, and by what percentage each year?
12. *(Extended)* For y = x³ − 2x − 2, y = −3 at x = 1 and y = 2 at x = 2. What does this tell you?

### Answers

1. 1 + 4 + 1 = **6**.
2. −9 + 5 = **−4**.
3. 12/(−4) = **−3**; 12 ÷ 0 is **undefined**, so there is no point at x = 0 (the y-axis is an asymptote).
4. **y = 4**; x² − 3x − 4 = 0 gives **x = −1 and x = 4**.
5. **y = 2x − 2**.
6. (x + 2)(x − 1) = 0: **(−2, 0) and (1, 0)**.
7. −1 − 2 = **−3**.
8. 2 ÷ 0.25 = **8**.
9. 3 × 0.5 = **1.5**.
10. x³ − 4x = 2x − 1, so **y = 2x − 1**.
11. **Decay**, because 0.85 < 1; **15% per year**.
12. y changes sign, so **a root of x³ − 2x − 2 = 0 lies between x = 1 and x = 2**.
