## Section A

**1.** Find the x-coordinates of the stationary points of the curve y = 2x³ − 3x² − 12x + 4. **[3]**

**2.** f(x) = x² − 8x + 3. Find the set of values of x for which f is increasing. **[2]**

**3.** Show that f(x) = 5 − 2x − x³ is a decreasing function. **[2]**

**4.** The curve y = x³ + ax, where a is a constant, has a stationary point where x = 2. Find the value of a. **[2]**

## Section B

**5.** Find the coordinates of the stationary point of the curve y = x² + 16/x, x ≠ 0, and determine its nature. **[5]**

**6.** The curve C has equation y = x³ − 3x² − 9x + 5.

**(a)** Find the coordinates of the stationary points of C and determine their nature. **[6]**

**(b)** State the set of values of x for which y decreases as x increases. **[1]**

**7.** The curve C has equation y = 3x⁴ − 8x³ + 2.

**(a)** Find the coordinates of the two stationary points of C. **[4]**

**(b)** Determine the nature of each stationary point, showing your reasoning. **[3]**

**8.** Find the coordinates of the stationary point of y = x^(3/2) − 6x + 5, x > 0, and show that it is a minimum. **[5]**

**9.** A gardener has 60 m of fencing to make a rectangular enclosure against a long straight wall. The wall forms one side, and the fencing forms the other three sides. The two sides perpendicular to the wall each have length x m.

**(a)** Show that the area enclosed is A = 60x − 2x² square metres. **[2]**

**(b)** Find the maximum possible area, justifying that it is a maximum. **[4]**

**10.** An open box is made from a square sheet of card of side 24 cm by cutting a square of side x cm from each corner and folding up the sides.

**(a)** Show that the volume of the box is V = 4x³ − 96x² + 576x cubic centimetres. **[2]**

**(b)** Find the value of x that gives the maximum volume, find this maximum volume, and justify that it is a maximum. **[5]**

**11.** A closed cylinder has radius r cm, height h cm and volume 128π cm³.

**(a)** Show that the total surface area is A = 2πr² + 256π/r. **[2]**

**(b)** Find the value of r for which A is a minimum, and the minimum value of A as a multiple of π, justifying that it is a minimum. **[5]**

**12.** f(x) = x³ + kx² + 3x, where k is a constant. The curve y = f(x) has a stationary point where x = 1.

**(a)** Find the value of k. **[2]**

**(b)** Show that f is an increasing function, and explain what this tells you about the stationary point at x = 1. **[3]**

## Answers

**1.** dy/dx = 6x² − 6x − 12 [1]. Setting dy/dx = 0: 6(x² − x − 2) = 6(x − 2)(x + 1) = 0 [1], so **x = 2 or x = −1** [1].

**2.** f′(x) = 2x − 8 [1]. f′(x) > 0 when **x > 4** [1].

**3.** f′(x) = −2 − 3x² [1]. Since 3x² ≥ 0, f′(x) ≤ −2 < 0 for all x, so f is decreasing [1].

**4.** dy/dx = 3x² + a [1]. At x = 2: 12 + a = 0, so **a = −12** [1].

**5.** y = x² + 16x⁻¹, so dy/dx = 2x − 16x⁻² [1]. Setting this to zero: 2x³ = 16, so x³ = 8 [1] and x = 2 [1]. y = 4 + 8 = 12, so the point is **(2, 12)** [1]. d²y/dx² = 2 + 32x⁻³ = 2 + 4 = 6 > 0, so it is a **minimum** [1].

**6. (a)** dy/dx = 3x² − 6x − 9 [1] = 3(x − 3)(x + 1) = 0, so x = 3 or x = −1 [1]. y(−1) = −1 − 3 + 9 + 5 = 10 and y(3) = 27 − 27 − 27 + 5 = −22 [1]. d²y/dx² = 6x − 6 [1]. At x = −1, d²y/dx² = −12 < 0, so **(−1, 10) is a maximum** [1]. At x = 3, d²y/dx² = 12 > 0, so **(3, −22) is a minimum** [1].

**(b)** **−1 < x < 3** [1].

Total: 7

**7. (a)** dy/dx = 12x³ − 24x² [1] = 12x²(x − 2) = 0, so x = 0 or x = 2 [1]. y(0) = 2 and y(2) = 48 − 64 + 2 = −14 [1]. The points are **(0, 2) and (2, −14)** [1].

**(b)** d²y/dx² = 36x² − 48x. At x = 2 it is 144 − 96 = 48 > 0, so **(2, −14) is a minimum** [1]. At x = 0 it is 0, so test the gradient either side: at x = −0.1, dy/dx = 12(0.01)(−2.1) < 0, and at x = 0.1, dy/dx = 12(0.01)(−1.9) < 0 [1]. The gradient does not change sign, so **(0, 2) is a stationary point of inflection**, neither a maximum nor a minimum [1].

Total: 7

**8.** dy/dx = (3/2)x^½ − 6 [1]. Setting this to zero: x^½ = 4 [1], so x = 16 [1]. y = 16^(3/2) − 96 + 5 = 64 − 96 + 5 = −27, giving **(16, −27)** [1]. d²y/dx² = (3/4)x^(−½) = 3/16 > 0, so it is a minimum [1].

**9. (a)** The side parallel to the wall has length 60 − 2x [1], so A = x(60 − 2x) = 60x − 2x² [1].

**(b)** dA/dx = 60 − 4x = 0 gives x = 15 [1]. A = 60(15) − 2(225) = 900 − 450 = **450 m²** [1] [1]. d²A/dx² = −4 < 0, so this is a maximum [1].

Total: 6

**10. (a)** The base is a square of side 24 − 2x and the height is x [1], so V = x(24 − 2x)² = x(576 − 96x + 4x²) = 4x³ − 96x² + 576x [1].

**(b)** dV/dx = 12x² − 192x + 576 [1] = 12(x − 4)(x − 12) = 0, so x = 4 or x = 12 [1]. x = 12 gives a base of side 0 (no box), so **x = 4** [1]. V = 4 × (24 − 8)² = 4 × 256 = **1024 cm³** [1]. d²V/dx² = 24x − 192 = −96 < 0 at x = 4, so this is a maximum [1].

Total: 7

**11. (a)** πr²h = 128π gives h = 128/r² [1]. A = 2πr² + 2πrh = 2πr² + 2πr × 128/r² = 2πr² + 256π/r [1].

**(b)** dA/dr = 4πr − 256πr⁻² [1]. Setting this to zero: 4πr³ = 256π, so r³ = 64 and **r = 4** [1]. A = 2π(16) + 256π/4 = 32π + 64π = **96π cm²** [1] [1]. d²A/dr² = 4π + 512πr⁻³ = 4π + 8π = 12π > 0, so this is a minimum [1].

Total: 7

**12. (a)** f′(x) = 3x² + 2kx + 3 [1]. f′(1) = 6 + 2k = 0, so **k = −3** [1].

**(b)** f′(x) = 3x² − 6x + 3 = 3(x − 1)² [1]. Since (x − 1)² ≥ 0, f′(x) ≥ 0 for all x, and f′(x) = 0 only at x = 1, so f is increasing [1]. The gradient is positive on both sides of x = 1, so the stationary point is neither a maximum nor a minimum: it is a stationary point of inflection [1].

Total: 5

## Where marks are usually lost

- In Question 5, differentiating 16/x as 16 instead of −16x⁻².
- In Questions 6 and 7, finding the x-values and then substituting into dy/dx instead of y.
- In Question 7(b), stating "point of inflection" because d²y/dx² = 0, without checking the gradient either side.
- In Questions 9 to 11, finding the x or r value and not going on to the maximum area, maximum volume or minimum surface area that was asked for.
- In Question 10(b), not explaining why x = 12 is rejected.
