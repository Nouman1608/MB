## Questions

**1.** State two differences between a bitmap image and a vector graphic. **[2]**

**2.** Explain the difference between grouping two shapes and using the add (union) tool on them. **[2]**

**3.** A travel company's poster appears on its website and is also printed for shop windows.

**(a)** Describe how the RGB colour system produces colour. **[2]**
**(b)** Explain why the printed version should be prepared using CMYK. **[2]**
**(c)** State the purpose of a colour management system (CMS). **[1]**

**4.** An uncompressed image is 2000 × 1500 pixels with 24-bit colour. Take 1 MB = 1,000,000 bytes.

**(a)** Calculate the file size in MB. Show your working. **[2]**
**(b)** The colour depth is reduced to 8 bits. State the number of colours available. **[1]**
**(c)** State the new file size. **[1]**
**(d)** Give one drawback of this reduction for a photograph of a sunset. **[1]**

**5.** A photograph is 2400 × 1800 pixels.

**(a)** Calculate its print size at 300 ppi. **[1]**
**(b)** It is printed at 16 × 12 inches instead. Calculate the effective resolution and describe the likely effect. **[3]**
**(c)** State the pixel dimensions needed to print it at 16 × 12 inches at 300 ppi. **[1]**

**6.** Identify the most suitable file format for each use, giving a reason:
- a company logo with a transparent background, shown at many sizes on a website
- a holiday photograph emailed to friends
- a short looping animated button with a few flat colours
- a fixed-layout flyer sent to a commercial printer
**[4]**

**7.**

**(a)** Describe the difference between a cusp node and a symmetrical node. **[2]**
**(b)** Explain why nodes are deleted from a path drawn with the freehand tool. **[2]**

**8.** A photograph shows a yellow kite against a cloudy sky. The kite is to be placed on a new background.

**(a)** Explain the difference between the magic wand tool and the colour select tool. **[2]**
**(b)** Explain why a mask should be used to hide the old sky rather than erasing it. **[2]**

**9.**

**(a)** Write the row of pixels `RRRRRRGGGBBBBBBBBBRR` using run-length encoding. **[1]**
**(b)** Explain why run-length encoding would not reduce the size of the row `RGRGRGRG`. **[2]**
**(c)** Describe the effects of heavy lossy compression on an image of a price list containing small text. **[3]**

**10.** A bakery owner has a hand-drawn logo, scanned as a bitmap. Evaluate converting it into an editable vector shape using a trace bitmap tool. **[6]**

**11.** A cycling club needs a circular badge logo with its name curved round the edge. The logo will be used on the club website and on large printed banners. Describe how graphics software would be used to create the logo and prepare it for both uses. **[10]**

## Answers

**1.** A bitmap stores a grid of pixels, each with a colour; a vector stores shapes as paths of nodes and curves [1]. A bitmap pixelates when enlarged; a vector stays sharp at any size [1]. **[2]**
*Examiner insight:* Each mark needs both sides of the comparison; "vectors are better quality" with no reason earns nothing.

**2.** Grouping keeps the shapes as separate objects that move and transform together, and they can be ungrouped [1]. Add merges the overlapping shapes into one single outline, so the original separate shapes no longer exist [1]. **[2]**
*Examiner insight:* "Explain the difference" needs a statement about each tool; describing only one caps the answer at one mark.

**3. (a)** Red, green and blue light are mixed at different intensities [1]. It is additive: full intensity of all three gives white and none gives black [1].
**(b)** Printers use cyan, magenta, yellow and black inks, a subtractive system [1]. Some RGB colours cannot be printed, so preparing in CMYK shows how colours will actually look on paper [1].
**(c)** To convert colours between devices using their profiles, so the poster looks consistent on screen and in print [1]. **[5]**
*Examiner insight:* In (b) a reason linked to printing ink is needed; "CMYK is for print" alone restates the question.

**4. (a)** 2000 × 1500 × 24 = 72,000,000 bits; ÷ 8 = 9,000,000 bytes [1] = **9 MB** [1].
**(b)** 2⁸ = **256** colours [1].
**(c)** **3 MB** [1].
**(d)** The smooth sky gradient shows visible bands of colour because there are too few shades [1]. **[5]**
*Examiner insight:* Show the ÷ 8 step; a correct method with a slip in the final figure can still earn the method mark.

**5. (a)** 2400 ÷ 300 = 8, 1800 ÷ 300 = 6, so **8 × 6 inches** [1].
**(b)** 2400 ÷ 16 = 150 [1], so **150 ppi** [1]. The print looks soft or blocky because each pixel covers a larger area [1].
**(c)** **4800 × 3600 pixels** [1]. **[5]**
*Examiner insight:* Give units (inches, ppi, pixels); a bare number may not be credited.

**6.**
- Logo: **SVG** (or PNG), because it scales without losing quality and supports transparency [1].
- Holiday photograph: **JPEG**, because lossy compression gives a small file with millions of colours [1].
- Animated button: **GIF**, because it can hold a simple animation and a few flat colours fit within 256 colours [1].
- Flyer: **PDF**, because it keeps the layout, fonts and vector content for print [1]. **[4]**
*Examiner insight:* A format with no reason, or a generic reason ("good quality"), usually earns nothing.

**7. (a)** A cusp node's handles move independently, making a sharp corner [1]. A symmetrical node's handles stay in line and equal in length, so the curve bends equally on each side [1].
**(b)** Freehand drawing creates many nodes, giving a wobbly line [1]. Deleting unneeded nodes simplifies the path, giving a smoother curve, easier editing and a smaller file [1]. **[4]**
*Examiner insight:* Describe handle behaviour, not just the result; "one is pointy" is too vague.

**8. (a)** The magic wand selects neighbouring pixels of a similar colour to the one clicked [1]. Colour select selects all pixels of that colour anywhere in the image, joined or not [1].
**(b)** A mask hides pixels without deleting them [1], so the edge of the kite can be corrected later if too much or too little was hidden [1]. **[4]**
*Examiner insight:* The second mark in (b) needs the consequence: the edit can be undone or refined.

**9. (a)** **6R 3G 9B 2R** [1].
**(b)** There are no runs of repeated colour [1], so each pixel needs a count as well as a colour, making the encoded row longer, not shorter [1].
**(c)** Detail is permanently removed [1]. Blocky patches and fuzzy halos appear round the edges of letters [1], so small text becomes blurred and may be hard to read [1]. **[6]**
*Examiner insight:* In (c) link the artefacts to the content given; a general definition of lossy compression earns at most one mark.

**10.**
- The vector logo scales to any size, from a label to a shop sign, without pixelating [1].
- Shapes and colours can be edited separately, for example recolouring for a seasonal version [1].
- A simple logo traces to a small file [1].
- Fine details, such as pencil texture or soft shading, may be lost or simplified [1].
- The trace may contain many unnecessary nodes and need time-consuming clean-up [1].
- Conclusion: worthwhile here, because a logo with clear lines traces well and must be used at many sizes, provided the result is checked and cleaned [1]. **[6]**
*Examiner insight:* "Evaluate" needs both sides and a justified conclusion; one-sided answers cannot reach full marks.

**11.**
- Set up a square page and use rulers, guidelines and snapping to place items accurately [1].
- Draw the badge with the ellipse tool, holding the proportions so it is a circle [1].
- Create the inner design from shapes, using add, subtract or intersect to build single outlines [1].
- Align all items to the centre of the page and group them so they move together [1].
- Use text on a path so the club name follows the circle; choose a clear font face and size, and adjust kerning and letter spacing so the letters sit evenly [1].
- Use the colour picker to apply the club's exact colours as solid or gradient fills [1].
- Convert the text to curves in the final copy, so the printer does not need the font; keep an editable master [1].
- Keep the logo as a vector so it stays sharp when enlarged to banner size [1].
- For the website, export as SVG (or PNG with transparency) in RGB [1].
- For banners, export as PDF with CMYK colours, checked through colour management, so print colours match the screen design [1]. **[10]**
*Examiner insight:* Marks come from named tools linked to purpose; a general description ("make it look professional") with no tools earns little.

## Where marks are usually lost

- Calling CMYK additive or recommending RGB output for a printer.
- Missing the ÷ 8 step or giving 2 × bits instead of 2 to the power of bits.
- Giving resolution answers without units.
- Choosing JPEG for a logo needing transparency, or GIF for a full-colour photograph.
- Explaining only one side of a "difference" question.
- One-sided "evaluate" answers with no conclusion.
- Forgetting that text converted to curves can no longer be edited as text.
