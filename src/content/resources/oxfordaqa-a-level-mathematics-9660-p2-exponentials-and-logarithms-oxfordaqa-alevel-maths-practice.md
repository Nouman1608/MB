These questions cover section P2.5 (Exponentials and logarithms) of the OxfordAQA International AS and A-level Mathematics (9660) specification, Version 5.2, in International A-level Unit P2. Give non-exact answers to 3 significant figures. Read the [exponentials and logarithms study guide](/resources/oxfordaqa-a-level-mathematics-9660-p2-exponentials-and-logarithms-oxfordaqa-alevel-maths/) first, or refresh the methods with the [exponentials and logarithms revision notes](/resources/oxfordaqa-a-level-mathematics-9660-p2-exponentials-and-logarithms-oxfordaqa-alevel-maths-revision-notes/).

## Section A

**1.** Solve 5e²ˣ = 40, giving your answer in the form a ln 2. **[2]**

**2.** Solve ln(4x − 1) = 2, giving your answer in exact form. **[2]**

**3.** For the curve y = eˣ − 4, state the equation of the asymptote and the exact coordinates of the points where the curve meets the axes. **[3]**

**4.** For the curve y = ln(x − 3), state the domain, the equation of the asymptote and the coordinates of the x-intercept. **[3]**

**5.** Write 5 × 2ᵗ in the form 5eᵏᵗ, giving k to 3 significant figures. **[1]**

## Section B

**6.** Solve e²ˣ − 4eˣ − 12 = 0, explaining why one solution of the related quadratic is rejected. **[4]**

**7.** Solve 2eˣ + 3e⁻ˣ = 7, giving your answers in exact form. **[4]**

**8.** Solve ln(x + 3) + ln(x − 1) = ln 12. **[4]**

**9.** The function f is defined by f(x) = 3 + e⁻²ˣ for all real x.

**(a)** State the range of f. **[1]**

**(b)** Find f⁻¹(x). **[3]**

**(c)** State the domain of f⁻¹. **[1]**

**10.** The mass, m grams, of a radioactive substance after t days is modelled by m = 80e⁻ᵏᵗ. After 6 days the mass is 60 grams.

**(a)** Find the value of k. **[3]**

**(b)** Find the half-life of the substance. **[2]**

**(c)** Find the time taken for the mass to fall to 10 grams. **[2]**

**11.** The number of birds, N, on an island t years after observations began is modelled by N = Aeᵏᵗ. When t = 3, N = 1200, and when t = 8, N = 2000.

**(a)** Find the values of k and A. **[4]**

**(b)** Use the model to predict the number of birds when t = 20. **[1]**

**(c)** Give one reason why this prediction may be unreliable. **[2]**

**12.** A metal block is placed in a room. Its temperature, θ °C, t minutes later is modelled by θ = 18 + 62e⁻ᵏᵗ. After 5 minutes its temperature is 49 °C.

**(a)** Show that k = 0.139 to 3 significant figures. **[3]**

**(b)** Find the time at which the temperature of the block reaches 25 °C. **[2]**

**(c)** State the temperature the model predicts for the block in the long term. **[1]**

**13.** An investment has value V = 2000 × (1.05)ᵗ after t years.

**(a)** Write V in the form 2000eᵏᵗ, giving k to 4 significant figures. **[2]**

**(b)** Find the time at which V first reaches 5000. **[2]**

**(c)** A second investment has value W = 2000e^(0.05t). Explain which investment grows faster. **[1]**

## Answers

**1.** e²ˣ = 8 [1], so 2x = ln 8 = 3 ln 2 and **x = (3/2) ln 2** (≈ 1.04) [1]. Total: 2

**2.** 4x − 1 = e² [1], so **x = (e² + 1)/4** (≈ 2.10) [1]. Total: 2

**3.** **Asymptote y = −4** [1]. x = 0 gives **(0, −3)** [1]. y = 0 gives eˣ = 4, so **(ln 4, 0)** [1]. Total: 3

**4.** **Domain x > 3** [1]. **Asymptote x = 3** [1]. ln(x − 3) = 0 when x − 3 = 1, giving **(4, 0)** [1]. Total: 3

**5.** 2ᵗ = e^(t ln 2), so **k = ln 2 ≈ 0.693** [1]. Total: 1

**6.** Let u = eˣ: u² − 4u − 12 = 0 [1], so (u − 6)(u + 2) = 0 [1]. u = −2 is rejected because eˣ > 0 for all x [1]. So eˣ = 6 and **x = ln 6** [1]. Total: 4

**7.** Multiply by eˣ: 2e²ˣ + 3 = 7eˣ, so 2e²ˣ − 7eˣ + 3 = 0 [1]. Then (2eˣ − 1)(eˣ − 3) = 0 [1], so eˣ = 1/2 or eˣ = 3 [1]. **x = −ln 2 or x = ln 3** [1]. Total: 4

**8.** ln[(x + 3)(x − 1)] = ln 12 [1], so x² + 2x − 3 = 12 and x² + 2x − 15 = 0 [1]. (x + 5)(x − 3) = 0 [1]. x = −5 is rejected because ln(x − 1) would be undefined, so **x = 3** [1]. Total: 4

**9. (a)** e⁻²ˣ > 0, so **f(x) > 3** [1].

**(b)** y = 3 + e⁻²ˣ, so e⁻²ˣ = y − 3 [1]. Then −2x = ln(y − 3) [1], giving **f⁻¹(x) = −½ ln(x − 3)** [1].

**(c)** The domain of f⁻¹ is the range of f: **x > 3** [1]. Total: 5

**10. (a)** 60 = 80e⁻⁶ᵏ [1], so e⁻⁶ᵏ = 3/4 and 6k = ln(4/3) [1]. **k = 0.0479** (3 s.f.) [1].

**(b)** e⁻ᵏᵗ = 1/2, so t = (ln 2)/k [1] = **14.5 days** [1].

**(c)** 80e⁻ᵏᵗ = 10, so e⁻ᵏᵗ = 1/8 and t = (ln 8)/k [1] = **43.4 days** [1]. Total: 7

**11. (a)** 1200 = Ae³ᵏ and 2000 = Ae⁸ᵏ [1]. Dividing: e⁵ᵏ = 5/3 [1], so **k = (1/5) ln(5/3) = 0.102** (3 s.f.) [1]. A = 1200e⁻³ᵏ = **883** (3 s.f.) [1].

**(b)** N = 883e^(20k) ≈ **6820 birds** (3 s.f., using unrounded A and k) [1].

**(c)** Any reasoned point: the model grows without limit [1], but the island has limited food and space, so growth is likely to slow; or the prediction extrapolates far beyond the data from t = 3 to t = 8 [1]. Total: 7

**12. (a)** 49 = 18 + 62e⁻⁵ᵏ, so 62e⁻⁵ᵏ = 31 [1]. e⁻⁵ᵏ = 1/2, so 5k = ln 2 [1] and k = (ln 2)/5 = 0.13862… = **0.139** (3 s.f.) [1].

**(b)** 62e⁻ᵏᵗ = 7, so t = ln(62/7)/k [1] = **15.7 minutes** [1].

**(c)** As t → ∞, e⁻ᵏᵗ → 0, so θ → **18 °C**, the room temperature [1]. Total: 6

**13. (a)** 1.05ᵗ = e^(t ln 1.05) [1], so **k = ln 1.05 = 0.04879** (4 s.f.) [1].

**(b)** 1.05ᵗ = 2.5, so t = ln 2.5/ln 1.05 [1] = 18.8; V first reaches 5000 after **18.8 years** [1].

**(c)** W grows faster, because e^0.05 ≈ 1.0513 > 1.05, so W is multiplied by more each year (equivalently, 0.05 > 0.04879) [1]. Total: 5

## Where marks are usually lost

- Leaving a negative value of eˣ in the final answer, or rejecting it without a reason.
- Splitting ln[(x + 3)(x − 1)] wrongly, or forgetting to check roots in the original logarithms.
- Writing the inverse but not its domain, or giving the domain of f instead of its range.
- Rounding k to 2 or 3 figures and then using the rounded value, so later answers drift.
- Giving a generic comment on a model instead of one tied to the context.
- Forgetting the long-term value 18 when solving 18 + 62e⁻ᵏᵗ = 25.
