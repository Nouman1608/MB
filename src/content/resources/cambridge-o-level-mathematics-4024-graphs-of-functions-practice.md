These questions cover section 2.10, Graphs of functions, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. Where a question would normally ask you to draw a graph, it gives you the information you would read from it, so every part can be answered on paper. Read the [graphs of functions study guide](/resources/cambridge-o-level-mathematics-4024-graphs-of-functions/) for the methods and keep the [graphs of functions revision notes](/resources/cambridge-o-level-mathematics-4024-graphs-of-functions-revision-notes/) to hand. ## Section A

**1.** Complete the table of values for y = x³ − 4x + 2.

| x | −2 | −1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|
| y | 2 | | 2 | | 2 | |

**[3]**

**2.** For y = 6/x², find y when x = 0.5 and when x = 3, giving the second answer to 2 decimal places. **[2]**

**3.** The graph of y = x² + 2/x has been drawn. Find the equation of the straight line that should be drawn to solve x³ − 4x + 2 = 0. **[2]**

**4.** The graph of y = 2ˣ has been drawn for 0 ≤ x ≤ 3. Find the equation of the line needed to solve 2ˣ + x = 5, and explain why the equation has exactly one solution in this range. **[3]**

**5.** For y = 5 × 2ˣ + 3, find

**(a)** the y-intercept,

**(b)** the equation of the horizontal asymptote,

**(c)** the value of y when x = 3. **[3]**

**6.** A tangent to a curve passes through (−1, 7) and (3, −5). Find the gradient of the curve at the point where the tangent touches it. **[2]**

## Section B

**7.** The function y = x² − 4/x is defined for x > 0.

**(a)** Complete the table, giving values to 2 decimal places where needed.

| x | 0.5 | 1 | 1.5 | 2 | 3 | 4 |
|---|---|---|---|---|---|---|
| y | −7.75 | | | 2 | | 15 |

**(b)** Use the table to state between which two tabulated x-values the curve crosses the x-axis.

**(c)** Show that the x-coordinate where the curve meets the line y = 1 is a solution of x³ − x − 4 = 0. **[7]**

**8.** A population of bacteria is modelled by N = 50 × 2ᵗ, where t is the time in hours.

**(a)** Find N when t = 0, 3 and 5.

**(b)** A graph of N against t is drawn. Reading across from N = 1000 meets the curve at t ≈ 4.3. Explain what this value means.

**(c)** A tangent to the curve at t = 3 passes through (2, 123) and (4, 677). Estimate the rate at which the population is growing when t = 3, including units. **[6]**

**9.** The value of a car is modelled by V = 15 000 × 0.85ᵗ dollars, where t is its age in years. All figures are invented.

**(a)** Find the value after 3 years, to the nearest dollar.

**(b)** State the percentage by which the value falls each year.

**(c)** From the graph, the value falls to 7500 dollars at t ≈ 4.3. What does this say about the time taken for the value to halve?

**(d)** Explain why, according to the model, the value never reaches zero. **[6]**

**10.** The table gives some values of y = x³ − 3x.

| x | −2 | −1 | 0 | 1 | 2 |
|---|---|---|---|---|---|
| y | −2 | 2 | 0 | −2 | 2 |

**(a)** The line y = x is drawn on the same grid. Show that the x-coordinates of the intersections satisfy x³ − 4x = 0, and solve this equation.

**(b)** Find the line to draw to solve x³ − 3x − 1 = 0.

**(c)** Using the table, state how many solutions x³ − 3x − 1 = 0 has for −2 ≤ x ≤ 2, giving a reason. **[7]**

**11.** The function y = 4√x − x is graphed for 0 ≤ x ≤ 16.

**(a)** Complete the table.

| x | 0 | 1 | 4 | 9 | 16 |
|---|---|---|---|---|---|
| y | | | | | |

**(b)** State the greatest value of y in the table and the value of x at which it occurs.

**(c)** The line y = 2 meets the curve at x ≈ 0.3 and x ≈ 11.7. Write down the equation these values solve. **[5]**

**12.** The curve y = x² − 2x − 3 is drawn. Amir wants the gradient at x = 3. He joins the points (1, −4) and (3, 0) on the curve and gets 2.

**(a)** Explain why his method is wrong.

**(b)** A correctly drawn tangent at (3, 0) passes through (5, 8). Find the gradient of the curve at x = 3. **[3]**

## Answers

**1.** x = −1: −1 + 4 + 2 = **5** [1]. x = 1: 1 − 4 + 2 = **−1** [1]. x = 3: 27 − 12 + 2 = **17** [1].

*Examiner insight:* The given values (2 at x = −2, 0 and 2) let you test your calculator method before you fill the gaps.

**2.** x = 0.5: 6 ÷ 0.25 = **24** [1]. x = 3: 6 ÷ 9 = **0.67** [1].

*Examiner insight:* Dividing by a small number such as 0.25 makes y large; this is why the curve rises steeply near the y-axis.

**3.** Divide by x: x² − 4 + 2/x = 0 [1], so x² + 2/x = 4 and the line is **y = 4** [1].

*Examiner insight:* Dividing by x is only valid because x = 0 is not a solution; the curve itself is not defined there.

**4.** 2ˣ = 5 − x, so draw **y = 5 − x** [1]. The curve y = 2ˣ increases throughout [1] and the line decreases, so they can cross at most once; at x = 0 the curve is below the line (1 < 5) and at x = 3 it is above (8 > 2), so they cross exactly once [1]. (The solution is x ≈ 1.7.)

*Examiner insight:* An explanation needs a reason for "at least one" and a reason for "no more than one".

**5. (a)** 5 × 1 + 3 = **8** [1].

**(b)** **y = 3** [1].

**(c)** 5 × 8 + 3 = **43** [1].

*Examiner insight:* For abˣ + c the y-intercept is a + c, not a.

**6.** (−5 − 7) ÷ (3 − (−1)) [1] = −12 ÷ 4 = **−3** [1].

*Examiner insight:* Keep the order of subtraction the same on top and bottom.

**7. (a)** x = 1: 1 − 4 = **−3** [1]. x = 1.5: 2.25 − 2.667 = **−0.42** [1]. x = 3: 9 − 1.333 = **7.67** [1].

**(b)** y changes from negative to positive between **x = 1.5 and x = 2** [1].

**(c)** At the intersection x² − 4/x = 1 [1]. Multiply by x: x³ − 4 = x [1], so x³ − x − 4 = 0 [1]. (The solution is x ≈ 1.8.)

*Examiner insight:* A "show that" answer must end with the exact equation in the question, with each step visible.

**8. (a)** 50, 400 and 1600 [2] (one mark for any two correct).

**(b)** The population reaches 1000 bacteria after about **4.3 hours** [1].

**(c)** Gradient = (677 − 123) ÷ (4 − 2) [1] = 554 ÷ 2 = 277 [1], so about **277 bacteria per hour** [1].

*Examiner insight:* The units of a gradient are "y-units per x-unit". Leaving them out loses the interpretation.

**9. (a)** 15 000 × 0.85³ = 15 000 × 0.614125 [1] = **9212 dollars** [1].

**(b)** 1 − 0.85 = 0.15, so **15%** [1].

**(c)** 7500 is half of 15 000, so the value **halves in about 4.3 years** [1].

**(d)** 0.85ᵗ is always positive [1], so V is 15 000 times a positive number and is never zero; the curve approaches the t-axis without reaching it [1].

*Examiner insight:* The multiplier is 0.85, so the fall is 15%. Writing 85% is a common slip.

**10. (a)** x³ − 3x = x [1], so x³ − 4x = 0. Factorise: x(x² − 4) = 0, x(x − 2)(x + 2) = 0 [1], so **x = −2, 0, 2** [1].

**(b)** x³ − 3x = 1, so draw **y = 1** [1].

**(c)** **Three** solutions [1]. From the table, y goes from −2 up to 2 (between x = −2 and −1), down to −2 (between −1 and 1) and up to 2 again (between 1 and 2) [1]; each of these sections passes through y = 1 once [1].

*Examiner insight:* The values at x = −1 and x = 1 are the high and low points of the table, and comparing them with 1 tells you how many crossings there are.

**11. (a)** 0, 3, 4, 3, 0 [2] (one mark for three or four correct).

**(b)** Greatest value **y = 4 at x = 4** [1].

**(c)** **4√x − x = 2** [2] (or an equivalent form such as 4√x − x − 2 = 0).

*Examiner insight:* The greatest value is at x = 4, not halfway between the roots at 0 and 16, so this curve is not symmetrical like a parabola. Read values from the curve, not by assumption.

**12. (a)** He has found the gradient of a chord between two points on the curve [1], not the gradient at x = 3, which needs the tangent at that point [1].

**(b)** (8 − 0) ÷ (5 − 3) = **4** [1].

*Examiner insight:* The chord gradient (2) and the tangent gradient (4) differ because the curve is getting steeper between x = 1 and x = 3.

## Where marks are usually lost

- Arithmetic slips with negative x, especially cubes of negative numbers.
- Rearranging an equation so that neither side matches the curve on the grid.
- Reading only one intersection when there are two or three.
- Using two points on the curve, not on the tangent, for a gradient.
- Giving a gradient in context without units or without saying what a negative sign means.
- Treating the y-intercept of abˣ + c as a rather than a + c.
