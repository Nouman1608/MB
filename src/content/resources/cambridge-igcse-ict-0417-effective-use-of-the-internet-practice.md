## Section B: structured questions

**7.** Look at this web address: `https://www.harbourcollege.ac.za/courses/ict.htm`

**(a)** Identify the protocol, the domain type and the file name. **[3]**

**(b)** Explain what the protocol shows about data sent to this website. **[2]**

**8.** A car manufacturer uses an intranet. It wants its parts suppliers to be able to see its stock levels.

**(a)** Describe **two** differences between an intranet and the internet. **[2]**

**(b)** Name the type of network the suppliers would use and describe how their access would be limited. **[2]**

**9.** A student uses a search engine to research volcanoes for a geography project.

**(a)** Describe **two** advantages of using a search engine for this research. **[2]**

**(b)** Explain why it may not be easy for the student to find reliable information. **[2]**

**10.** The student finds two web pages about the same volcano.

Page X is a travel company's page, last updated six years ago, advertising tours to the volcano.

Page Y is a university geology department's page, updated last month, with references to scientific papers.

Evaluate which page is more suitable for the project. Refer to the four criteria for evaluating information. **[4]**

**11.** A primary school wants to stop pupils seeing inappropriate material on the internet.

**(a)** Describe how educational control could be used. **[2]**

**(b)** Describe **one** other level of control that could protect the pupils when they are at home. **[2]**

**(c)** Give **one** disadvantage of strict filtering for the school. **[1]**

**12.** A class is deciding whether to use a wiki or social networking to share revision notes. Compare the features of a wiki and social networking for this purpose. **[4]**

## Answers

**1.** A set of rules for transferring data between devices (1). **[1]**

**2.** B: FTP. **[1]**

**3.** Any two: written by one author or a small team (1); entries shown in reverse date order (1); readers can add comments but cannot edit the posts (1); usually expresses the author's opinions (1). **[2]**

**4.** Text or an image that, when selected, takes the user to another web page, another part of the same page, a file or an email address (1). **[1]**

**5.** Any two: bookmarks or favourites (1); history (1); back button (1). **[2]**

**6.** In a moderated forum a moderator checks or removes posts, whereas in an unmoderated forum posts are not checked (1). **[1]**

**7. (a)** Protocol: https (1); domain type: .ac (1); file name: ict.htm (1).

**(b)** HTTPS is the secure variant of HTTP (1); data sent between the browser and the server is encrypted using an SSL link, so it cannot be read if intercepted (1). **[5]**

**8. (a)** Any two: the internet is public whereas an intranet is private to the organisation (1); an intranet needs a login to access (1); intranet content is relevant to the organisation and checked, whereas internet content is unregulated (1); an intranet is usually protected by a firewall (1).

**(b)** An extranet (1). Each supplier is given a user ID and password and can only see the areas, such as stock levels, they are authorised to view (1). **[4]**

**9. (a)** Any two: results are returned very quickly (1); a vast amount of information is available (1); good keywords or operators bring relevant pages quickly (1); information may be more up to date than in books (1); it includes images and video (1).

**(b)** Anyone can publish on the internet, so pages may be inaccurate, biased or out of date (1); results are ranked by the search engine's algorithm, popularity or advertising rather than accuracy, so the student must check each source (1). **[4]**

**10.** Page Y is more suitable. Any four: Page Y is more up to date, updated last month compared with six years ago (1); Page Y is more reliable because a university geology department has expertise (1); Page X is likely to be biased because the company wants to sell tours (1); Page Y is more valid because its claims are supported by references (1); the student should still check Page Y against another source (1). Maximum 4. **[4]**

**11. (a)** The school uses filtering software on its network to block websites with inappropriate content (1), and may monitor pupils' internet use or block searches containing certain words (1).

**(b)** Parental control (1): parents use filtering software or device settings to block unsuitable sites and set time limits (1). Or: ISP control (1): the provider filters content before it reaches the home connection (1).

**(c)** Any one: useful sites for research may be blocked (1); pupils do not learn to judge content for themselves (1). **[5]**

**12.** Any four, with at least one point about each:
- On a wiki, any authorised class member can edit and improve the same notes (1), so notes can be corrected and updated by everyone (1).
- On a wiki, mistakes or vandalism may appear until someone corrects them (1).
- On social networking, each user posts on their own profile and others can only comment or share (1), so the notes are spread across many posts and harder to organise (1).
- Social networking may expose personal data or allow contact from people outside the class (1).

**[4]**

## Frequently asked questions

**Do I need to learn the full names of the protocols?**
Yes. The syllabus gives HyperText Transfer Protocol, its secure variant HTTPS, File Transfer Protocol and Secure Socket Layer by name.

**Is a .gov site always reliable?**
Not automatically. The domain type is a useful clue, but you should still check the date, the author and whether other reliable sources agree.
