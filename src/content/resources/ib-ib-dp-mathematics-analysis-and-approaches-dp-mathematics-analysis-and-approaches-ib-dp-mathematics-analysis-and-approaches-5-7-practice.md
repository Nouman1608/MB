Questions are labelled "(calculator-free)" for Paper 1 style or "(calculator allowed)" for Paper 2 style. Give answers exactly or to 3 significant figures.

## Section A

**1.** (calculator-free) Let f(x) = 2x⁴ − 5x³ + x − 7. Find f″(x). **[2]**

**2.** (calculator-free) Let y = e^(3x) + sin 2x. Find d²y/dx². **[2]**

**3.** (calculator-free) Let f(x) = x³ − 3x² − 24x + 5. Find the set of values of x for which the graph of f is concave-up. **[3]**

**4.** (calculator-free) A function f has derivative f′(x) = x² − 4.

**(a)** Write down f″(x). **[1]**
**(b)** Find the interval on which the graph of f is concave-down. **[1]**
**(c)** Explain why f has a local maximum at x = −2. **[2]**

**5.** (calculator-free) Let y = x ln x, for x > 0. Show that d²y/dx² > 0 for all x > 0. **[3]**

**6.** (calculator-free) On an interval, a function satisfies f′(x) > 0 and f″(x) < 0. Describe the behaviour of the graph of f on that interval. **[2]**

## Section B

**7.** (calculator-free) Let f(x) = x e^(2x).

**(a)** Show that f′(x) = (1 + 2x)e^(2x). **[2]**
**(b)** Find f″(x), giving your answer in factorised form. **[2]**
**(c)** Find the interval on which the graph of f is concave-down. **[1]**
**(d)** Find the exact coordinates of the point where the concavity of f changes. **[2]**

**8.** (calculator-free) A function f is defined for −3 ≤ x ≤ 5. The graph of its derivative, y = f′(x), has these features:

- f′(x) = 0 at x = −2 and at x = 4 only;
- f′(x) < 0 for −3 ≤ x < −2 and for 4 < x ≤ 5, and f′(x) > 0 for −2 < x < 4;
- the graph of f′ is increasing for −3 < x < 1 and decreasing for 1 < x < 5, with a local maximum at x = 1.

**(a)** Find the x-coordinate of the local minimum point of f, and justify your answer. **[2]**
**(b)** Find the x-coordinate of the local maximum point of f, and justify your answer. **[2]**
**(c)** Write down the interval on which the graph of f is concave-up. **[2]**
**(d)** State the x-coordinate where the concavity of f changes, and give a reason. **[2]**

**9.** (calculator-free) Water is pumped into a tank and later drained. The depth of water, h cm, after t minutes is modelled by h(t) = 8 + 6t² − t³, for 0 ≤ t ≤ 5.

**(a)** Find h′(t) and h″(t). **[2]**
**(b)** Find the time at which the depth is increasing fastest, and the rate of increase at that time. **[3]**
**(c)** Describe how the depth is changing for 2 < t < 4, referring to h′ and h″. **[2]**

**10.** (calculator-free) Let f(x) = ln(x² + 4).

**(a)** Show that f″(x) = (8 − 2x²)/(x² + 4)². **[4]**
**(b)** Hence find the interval on which the graph of f is concave-up. **[2]**

**11.** (calculator allowed) Let f(x) = e^(0.5x) − 2x², for −2 ≤ x ≤ 8.

**(a)** Find f″(x). **[2]**
**(b)** Solve f″(x) = 0. **[2]**
**(c)** Write down the interval on which the graph of f is concave-down. **[1]**

**12.** (calculator-free) Let f(x) = x³ + px² + qx, where p, q ∈ ℝ. The concavity of the graph of f changes at the point (1, 4).

**(a)** Find the value of p. **[2]**
**(b)** Find the value of q. **[2]**
**(c)** Show that f is increasing for all values of x. **[2]**

## Answers

**1.** f′(x) = 8x³ − 15x² + 1 [1]; **f″(x) = 24x² − 30x** [1] **[2]**

**2.** dy/dx = 3e^(3x) + 2 cos 2x [1]; **d²y/dx² = 9e^(3x) − 4 sin 2x** [1] **[2]**
*Examiner insight:* The chain rule acts twice on each term, so the factors are 3 × 3 and 2 × 2; a common slip is 9e^(3x) + 4 sin 2x, with the wrong sign from differentiating cos.

**3.** f′(x) = 3x² − 6x − 24 [1]; f″(x) = 6x − 6 [1]; concave-up when 6x − 6 > 0, so **x > 1** [1] **[3]**

**4. (a)** **f″(x) = 2x** [1]
**(b)** **x < 0** [1]
**(c)** f′(−2) = 4 − 4 = 0, so x = −2 is a stationary point [1]; f″(−2) = −4 < 0 (or f′ changes from positive to negative at x = −2), so it is a local maximum [1] **[4]**

**5.** Product rule: dy/dx = 1 × ln x + x × (1/x) [1] = ln x + 1 [1]; d²y/dx² = 1/x, which is positive because x > 0 [1] **[3]**

**6.** f is increasing [1]; its gradient is decreasing, so it is increasing at a decreasing rate / concave-down [1] **[2]**

**7. (a)** Product rule: f′(x) = e^(2x) + x × 2e^(2x) [1] = (1 + 2x)e^(2x) [1]
**(b)** f″(x) = 2e^(2x) + (1 + 2x) × 2e^(2x) [1] = **4(x + 1)e^(2x)** [1]
**(c)** e^(2x) > 0, so f″(x) < 0 when x + 1 < 0: **x < −1** [1]
**(d)** f″ changes sign at x = −1 [1]; f(−1) = −e^(−2), so **(−1, −e⁻²)** [1] **[7]**
*Examiner insight:* In (c), stating that e^(2x) is always positive is the reasoning; without it the sign test is incomplete.

**8. (a)** **x = −2** [1]; f′ changes from negative to positive there [1]
**(b)** **x = 4** [1]; f′ changes from positive to negative there [1]
**(c)** f′ is increasing [1], so f is concave-up for **−3 < x < 1** [1]
**(d)** **x = 1** [1]; f′ has a local maximum there, so f″ changes sign from positive to negative [1] **[8]**
*Examiner insight:* Answering (a) with x = 1 (the maximum of the f′ graph) is the classic error: it confuses the shape of f′ with the shape of f.

**9. (a)** **h′(t) = 12t − 3t²** [1]; **h″(t) = 12 − 6t** [1]
**(b)** h″(t) = 0 when t = 2 [1]; h″ changes from positive to negative, so h′ is a maximum at **t = 2 minutes** [1]; h′(2) = 24 − 12 = **12 cm per minute** [1]
**(c)** h′(t) = 3t(4 − t) > 0, so the depth is increasing [1]; h″(t) < 0, so it is increasing at a decreasing rate [1] **[7]**
*Examiner insight:* "Increasing fastest" means h′ is maximised, so solve h″ = 0; solving h′ = 0 finds when the depth stops rising (t = 4), which answers a different question.

**10. (a)** f′(x) = 2x/(x² + 4) [1]; quotient rule: f″(x) = [2(x² + 4) − 2x × 2x]/(x² + 4)² [1] = (2x² + 8 − 4x²)/(x² + 4)² [1] = (8 − 2x²)/(x² + 4)² [1]
**(b)** Denominator positive, so concave-up when 8 − 2x² > 0 [1]: **−2 < x < 2** [1] **[6]**

**11. (a)** f′(x) = 0.5e^(0.5x) − 4x [1]; **f″(x) = 0.25e^(0.5x) − 4** [1]
**(b)** e^(0.5x) = 16 [1]; x = 2 ln 16 = **5.55** (5.5451…) [1]
**(c)** **−2 ≤ x < 5.55** [1] **[5]**

**12. (a)** f″(x) = 6x + 2p [1]; f″(1) = 0 gives 6 + 2p = 0, so **p = −3** [1]
**(b)** f(1) = 1 − 3 + q = 4 [1], so **q = 6** [1]
**(c)** f′(x) = 3x² − 6x + 6 = 3[(x − 1)² + 1] [1]; this is at least 3 for all x, so f′(x) > 0 and f is increasing everywhere [1] **[6]**
*Examiner insight:* An alternative for (c) is the discriminant of 3x² − 6x + 6: 36 − 72 < 0 with a positive leading coefficient, so f′ is always positive.
