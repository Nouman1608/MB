## Section B: structured questions

**7.** A student creates a timetable table with 6 columns and 8 rows. The first column holds lesson times and the first row holds the days.

**(a)** The school adds a Saturday club. Describe how to add a column for Saturday at the right-hand end. **[2]**

**(b)** The last row is no longer needed. The student selects it and presses the Delete key. Explain why this does not complete the task, and state what should be done. **[2]**

**(c)** A lunch break runs across every day. Describe how to show "Lunch" once across all the day columns in one row. **[2]**

**8.** A price list table has the columns *Item*, *Size* and *Price*.

**(a)** State the most suitable horizontal alignment for each column, and give a reason for the Price column. **[3]**

**(b)** The heading row has been made 1.5 cm tall. Describe how to place the headings exactly in the centre of their cells. **[2]**

**9.** A page has a text width of 17 cm. A table must fill this width. Column 1 is 5 cm and column 2 is 3.5 cm. Columns 3 and 4 must be equal.

**(a)** Calculate the width of columns 3 and 4. Show your working. **[2]**

**(b)** Explain why the widths should be entered in the table properties rather than set by dragging. **[1]**

**10.** A form to collect contact details is laid out using a table with two columns: labels on the left and spaces to write on the right.

**(a)** Explain why the designer might hide the gridlines. **[1]**

**(b)** The designer later decides lines are needed under each answer space. Explain the difference between this and showing all gridlines. **[2]**

**11.** In a table of book reviews, the review column is narrow and long reviews run past the edge of the cell.

**(a)** Name the formatting that would keep the column narrow but show all the text. **[1]**

**(b)** Describe the effect this has on the rows. **[1]**

**(c)** Explain why vertical alignment of the other cells in these rows now matters. **[2]**

**12.** Describe, in order, the steps needed to carry out this instruction: "Create a table with 3 columns and 5 rows. Place a logo image in the top left cell. Merge the other two cells in the first row and enter the company name. Show all gridlines." **[4]**

## Answers

**1.** The box where a row and a column meet, which holds one item of content (1). **[1]**

**2.** B: middle. **[1]**

**3.** 11 rows (9 + 1 + 1) (1). **[1]**

**4.** Text too long for the column width continues on new lines inside the same cell, making the row taller (1). **[1]**

**5.** Any two: separates the headings from the data (1); makes the headings stand out so the table is easier to read (1); can match a house style colour scheme (1). **[2]**

**6.** Any two: insert rows (1); insert columns (1); delete rows (1); delete columns (1); merge cells (1). **[2]**

**7. (a)** Select the last column (1) and insert a column to the right, then type *Saturday* in the first row (1).

**(b)** The Delete key only clears the contents of the cells, so the empty row remains (1). The student should use the delete rows command (1).

**(c)** Select the cells in the lunch row under all the day columns (1) and merge them into one cell, then type *Lunch* (1). **[6]**

**8. (a)** Item: left (1); Size: centre or left (1); Price: right, so that the digits line up by place value and prices can be compared (1).

**(b)** Select the heading cells (1) and set horizontal alignment to centre and vertical alignment to middle (1). **[5]**

**9. (a)** 17 - 5 - 3.5 = 8.5 cm remaining (1); 8.5 / 2 = 4.25 cm for each of columns 3 and 4 (1).

**(b)** Entering values gives the exact widths specified; dragging is imprecise, so the table may not fill the width exactly (1). **[3]**

**10. (a)** The table is only used to line up the labels and spaces, and lines around every cell would make the form look cluttered (1).

**(b)** Lines under each answer space are borders applied to selected cell edges only (1), whereas showing all gridlines puts a line around every cell, including the labels (1). **[3]**

**11. (a)** Wrap text within the cell (1).

**(b)** The rows become taller so that every line of the review fits (1).

**(c)** The other cells in those rows are now taller than their contents (1), so their vertical alignment (top, middle or bottom) decides where the text sits, and it should be set consistently (1). **[4]**

**12.** Insert a table with 3 columns and 5 rows (1); insert the logo into the top left cell and resize it to fit, keeping the aspect ratio (1); select the second and third cells of the first row, merge them and type the company name (1); apply borders to all cells so all gridlines show (1). **[4]**

## Frequently asked questions

**Are gridlines the same as borders?**
Showing gridlines means making the lines between all cells visible. In a word processor this is usually done by applying borders to every cell. Some software also shows faint on-screen guides that do not print.

**Does vertical alignment matter in a normal table?**
Only when a row is taller than its contents, for example after the row height is increased or another cell in the row wraps onto several lines.
