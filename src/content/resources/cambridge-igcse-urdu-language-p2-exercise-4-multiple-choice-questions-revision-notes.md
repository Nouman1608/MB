## The exercise in one box

```
Paper 2, Exercise 4 – Multiple-choice questions     8 marks
Hear       a discussion between two speakers
Answer     multiple-choice comprehension questions, in Urdu
Assesses   L1, L2, L3 and L4: the only exercise testing all four
Heard      twice, with pauses to read and answer
```

The syllabus does not fix the number of questions or options.

## Question types by objective

- **L1 detail:** کب؟ کہاں؟ کتنے؟ One stated fact.
- **L2 opinion or objection:** ... کی کیا رائے ہے؟ / ... کو کس بات پر اعتراض ہے؟
- **L3 connection:** دونوں کس بات پر متفق ہوتے ہیں؟ / آخر میں کیا طے پاتا ہے؟
- **L4 implied:** "..." سے کیا مراد ہے؟ / ... کیسا محسوس کرتا ہے؟ / گفتگو کا مقصد کیا ہے؟

## Key terms

| Urdu | English |
|---|---|
| گفتگو | discussion, conversation |
| تجویز | suggestion |
| اعتراض | objection |
| متفق ہونا | to agree |
| طے پانا | to be decided |
| مقصد | purpose |
| مطلب / مراد | meaning |

## Turn-openers

- **Agree:** بالکل ٹھیک، میں آپ سے متفق ہوں، چلو یہی ٹھیک ہے
- **Partly agree:** یہ خیال برا نہیں، مگر ... / آپ کی بات اپنی جگہ درست ہے، لیکن ...
- **Disagree:** میں ایسا نہیں سمجھتا، یہ ضروری تو نہیں
- **Hesitate:** ہمم ...، پتا نہیں ...
- **Surprise / admiration / annoyance:** ارے! واقعی؟ / واہ! بہت خوب / اُف!

## Feeling words in options

| Urdu | English |
|---|---|
| پُرجوش | excited |
| مایوس | disappointed |
| پریشان | worried |
| حیران | surprised |
| متاثر | impressed |
| مطمئن | satisfied |
| ناراض | annoyed |

The feeling is often **shown, not named**: an exclamation, a complaint, a change of tone.

## The four wrong-option types

1. **Right words, wrong speaker.**
2. **Suggested, then rejected** (wrong if the question asks what was decided).
3. **True, but not the answer to this question.**
4. **Reported view** that the other speaker corrects (سنا ہے ... / لوگ کہتے ہیں ...).

If you can say why each other option is wrong, your choice is safe.

## Mini-example

> **علی:** چلو، اس اتوار کو چڑیا گھر چلتے ہیں۔\
> **ثنا:** یہ خیال برا نہیں، مگر اتوار کو وہاں بہت رش ہوتا ہے۔ ہفتے کو چلیں؟

Question: ثنا کو علی کی تجویز پر کیا اعتراض ہے? The answer is the crowd on Sunday (اتوار کو رش), not the
zoo itself: her turn-opener accepts the idea and the reservation follows مگر.

## The routine

1. **Pause:** read the stems; underline names and question words; write both initials.
2. **First hearing:** provisional choices; note who suggests, objects, agrees, changes mind.
3. **Second hearing:** confirm; listen to replies after suggestions and to the final lines.
4. **After:** one answer per question; change only with clear evidence.

## Exam traps

- Assigning a view to the wrong speaker.
- Choosing an idea that was dropped later.
- Taking "یہ خیال برا نہیں، مگر" as agreement.
- Missing a feeling shown only through tone.
- Changing a sound answer on the second hearing.

## Self-test

1. Which listening objectives does Exercise 4 assess?
2. A speaker replies "آپ کی بات اپنی جگہ درست ہے، لیکن ...". What is coming?
3. What is a "suggested, then rejected" distractor, and when is it wrong?
4. How might a speaker show they are impressed without saying متاثر?
5. Why write both speakers' initials before the recording starts?
6. When should you change an answer on the second hearing?

**Answers:** 1. All four, L1 to L4. 2. A reservation or disagreement: the speaker accepts the point only
partly. 3. An idea that is raised in the discussion and later dropped; it is wrong when the question asks
what was decided or agreed. 4. With an exclamation such as واہ! or بہت خوب, or a remark such as "تم نے تو
سب سوچ رکھا ہے!". 5. So you can note who suggests, objects and agrees, which prevents the most common error
of assigning a view to the wrong speaker. 6. Only when you clearly hear evidence that contradicts your
first choice, not because of a half-remembered word.
