This guide covers subtopic **6.4 Redox** in Topic 6, Chemical reactions, of Cambridge IGCSE Chemistry 0620, 2026–2028 series. The [redox reactions study guide](/resources/redox-reactions/) introduces the three definitions with the hydrogen–copper(II) oxide and zinc–copper(II) sulfate examples. This page practises the skills the syllabus actually tests: assigning oxidation numbers systematically, deciding whether a reaction is redox at all, naming the oxidising and reducing agents, and reading the two colour tests. Follow up with the [redox revision notes](/resources/cambridge-igcse-chemistry-0620-redox-revision-notes/) and the [redox practice questions](/resources/cambridge-igcse-chemistry-0620-redox-practice/).

## What the syllabus asks for

**Core** (all candidates):

- Use a Roman numeral to indicate the oxidation number of an element in a compound.
- Define redox reactions as involving simultaneous oxidation and reduction.
- Define oxidation as gain of oxygen and reduction as loss of oxygen.
- Identify redox reactions as reactions involving gain and loss of oxygen, and identify the oxidation and reduction.

**Supplement** (Extended candidates only):

- Define oxidation as loss of electrons and an increase in oxidation number; reduction as gain of electrons and a decrease in oxidation number.
- Identify redox reactions by gain and loss of electrons, and by changes in oxidation number using four rules.
- Identify redox reactions by the colour changes with acidified aqueous potassium manganate(VII) or aqueous potassium iodide.
- Define and identify oxidising agents and reducing agents.

## Roman numerals in names (Core)

The Roman numeral after a metal's name is its oxidation number in that compound. It tells you the charge on the metal ion, so you can build the formula.

| Name | Metal ion | Formula |
|---|---|---|
| Iron(II) chloride | Fe²⁺ | FeCl₂ |
| Iron(III) chloride | Fe³⁺ | FeCl₃ |
| Iron(III) oxide | Fe³⁺ | Fe₂O₃ |
| Copper(I) oxide | Cu⁺ | Cu₂O |
| Copper(II) oxide | Cu²⁺ | CuO |

Working backwards also works: in Fe₂O₃, three oxide ions carry 6− in total, so two iron ions carry 6+, which means each is Fe³⁺, hence *iron(III)* oxide. Numerals are needed where an element can have more than one oxidation number; they are used in names such as potassium manganate(VII) and vanadium(V) oxide too.

## Oxygen transfer (Core)

Look for the substance that gains oxygen (oxidised) and the one that loses it (reduced).

```
Fe2O3 + 3CO → 2Fe + 3CO2
```

Iron(III) oxide loses oxygen: **reduced** to iron. Carbon monoxide gains oxygen: **oxidised** to carbon dioxide.

```
Fe2O3 + 2Al → Al2O3 + 2Fe
```

Aluminium gains oxygen (oxidised); iron(III) oxide loses oxygen (reduced). Both processes happen together in each reaction; that is what "simultaneous" means in the definition.

Burning is also oxidation: in 2Mg + O₂ → 2MgO, magnesium gains oxygen. Here the oxygen molecule is the substance reduced, which the oxygen definition cannot show. That gap is why the Extended definitions exist.

## Electron transfer (Supplement)

**Oxidation is loss** of electrons; **reduction is gain** of electrons. Split an ionic reaction into the two changes:

```
Mg(s) + Cu2+(aq) → Mg2+(aq) + Cu(s)

Mg → Mg2+ + 2e-        (electrons lost: oxidation)
Cu2+ + 2e- → Cu        (electrons gained: reduction)
```

The number of electrons lost must equal the number gained. In 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻, each Fe²⁺ loses one electron (two in total), and the chlorine molecule gains two electrons to form two chloride ions.

## Oxidation numbers (Supplement)

The four rules in the syllabus:

1. An uncombined element has oxidation number **0** (Mg, O₂, Cl₂).
2. A monatomic ion has an oxidation number equal to its **charge** (Na⁺ = +1, O²⁻ = −2).
3. Oxidation numbers in a **compound** add up to **0**.
4. Oxidation numbers in an **ion** add up to the **charge** on the ion.

In practice you also use the usual values in compounds: oxygen −2, hydrogen +1, Group I +1, Group II +2.

### Worked examples

**Sulfur in the sulfate ion, SO₄²⁻.** S + 4(−2) = −2, so S = **+6**.

**Nitrogen in the ammonium ion, NH₄⁺.** N + 4(+1) = +1, so N = **−3**.

**Sulfur in SO₂ and SO₃.** S + 2(−2) = 0, so S = +4; S + 3(−2) = 0, so S = +6. In the Contact process step 2SO₂ + O₂ → 2SO₃, sulfur rises from +4 to +6 (oxidised) and oxygen falls from 0 to −2 (reduced).

### Is it redox?

Assign oxidation numbers to every element on both sides. If any element's number changes, it is redox.

| Reaction | Changes? | Redox? |
|---|---|---|
| CaCO₃ → CaO + CO₂ | Ca +2, C +4, O −2 throughout | No |
| NaOH + HCl → NaCl + H₂O | No element changes | No |
| Ag⁺ + Cl⁻ → AgCl | Ag +1, Cl −1 throughout | No |
| Cl₂ + 2KBr → 2KCl + Br₂ | Cl 0 → −1; Br −1 → 0 | Yes |

Neutralisation, precipitation and thermal decomposition of carbonates are not redox; displacement reactions of metals and of halogens are.

## Oxidising and reducing agents (Supplement)

- An **oxidising agent** oxidises another substance and is **itself reduced**.
- A **reducing agent** reduces another substance and is **itself oxidised**.

A reliable method: first decide what is oxidised and what is reduced, then swap the labels. The substance that is reduced is the oxidising agent.

**Worked example.** 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻

- Fe: +2 → +3, increase: Fe²⁺ is oxidised, so Fe²⁺ is the **reducing agent**.
- Cl: 0 → −1, decrease: Cl₂ is reduced, so Cl₂ is the **oxidising agent**.

In Fe₂O₃ + 3CO → 2Fe + 3CO₂, carbon monoxide is the reducing agent and iron(III) oxide is the oxidising agent.

## The two colour tests (Supplement)

| Reagent | Its role | Colour change when redox occurs | It shows the other substance is... |
|---|---|---|---|
| Acidified aqueous potassium manganate(VII) | Oxidising agent (is reduced) | Purple → colourless | A reducing agent |
| Aqueous potassium iodide | Reducing agent (is oxidised to iodine) | Colourless → brown (yellow-brown) | An oxidising agent |

Examples: adding aqueous iron(II) sulfate to acidified potassium manganate(VII) decolourises the purple solution, because Fe²⁺ is a reducing agent. Bubbling chlorine into aqueous potassium iodide turns the solution brown, because chlorine oxidises iodide ions to iodine.

Match the reagent to what you want to detect: manganate(VII) **detects reducing agents**; iodide **detects oxidising agents**.

## Common mistakes

- **Treating "oxidising agent" as "the thing oxidised".** It is the opposite: the oxidising agent is reduced.
- **Describing manganate(VII) as turning "clear".** Clear means transparent; the colour change is purple to **colourless**.
- **Forgetting the sign** in an oxidation number. Write +6, not 6.
- **Adding the subscript wrongly.** In Fe₂O₃ the three oxygens total −6, and that −6 is shared between two iron atoms.
- **Calling every reaction involving ions redox.** Check for a change in oxidation number first.
- **Mixing up which way electrons move.** OIL RIG: oxidation is loss, reduction is gain.

## Exam technique for the command words

- **Define**: give the precise wording. For Extended, the oxidising agent definition has two parts (oxidises another substance; is itself reduced). One part alone earns one mark at most.
- **Identify**: name the species, using the formula exactly as it appears (Fe²⁺, not "iron").
- **Explain why a reaction is redox**: name what is oxidised and what is reduced, and give the evidence (oxygen gained, electrons lost, or oxidation number change with values).
- **Deduce** an oxidation number: show the sum so a slip can still earn method credit.
