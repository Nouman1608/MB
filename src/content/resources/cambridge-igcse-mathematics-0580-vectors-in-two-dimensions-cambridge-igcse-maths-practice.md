These questions cover subtopic E7.2, Vectors in two dimensions, in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. The subtopic is Extended only, and every question here can be done without a calculator. Column vectors are written (x, y), with x the top entry. Learn the methods first with the [vectors in two dimensions study guide](/resources/cambridge-igcse-mathematics-0580-vectors-in-two-dimensions-cambridge-igcse-maths/) and the [vectors in two dimensions revision notes](/resources/cambridge-igcse-mathematics-0580-vectors-in-two-dimensions-cambridge-igcse-maths-revision-notes/).

## Questions

### Section A: short questions

**1.** A translation maps C(4, −1) onto D(−2, 3).

**(a)** Write the vector CD as a column vector. **[1]**

**(b)** Write down the vector DC. **[1]**

**2.** **u** = (5, −2) and **v** = (−3, 4).

**(a)** Find **u** + **v**. **[1]**

**(b)** Find **u** − **v**. **[1]**

**3.** **w** = (−6, 9).

**(a)** Find ⅔**w**. **[1]**

**(b)** Find −3**w**. **[1]**

**4.** Which of these vectors are parallel to (2, −3)? Give a reason for each one you choose.

(4, −6)     (−2, 3)     (6, 9)     (−10, 15)     **[2]**

**5.** The point (−3, 5) is translated by (4, −7) and the image is then translated by (−2, 2).

**(a)** Find the coordinates of the first image. **[1]**

**(b)** Write down the single column vector that maps (−3, 5) directly onto the final image. **[1]**

**6.** PQRS is a parallelogram with vertices in that order. PQ = **a** and QR = **b** (as vectors). Write down, in terms of **a** and **b**,

**(a)** SR, **[1]**

**(b)** SP. **[1]**

### Section B: longer questions

**7.** **p** = (4, 1), **q** = (−2, 3) and **r** = (0, −5). Find

**(a)** 2**p** + **q**, **[2]**

**(b)** **p** − 3**q**, **[2]**

**(c)** ½(**p** + **r**). **[2]**

**8. (a)** Find x and y if (x, 3) − 2(4, y) = (−1, 13). **[3]**

**(b)** Find the numbers m and n such that m(1, 2) + n(3, −1) = (7, 0). **[3]**

**9. (a)** The vector (k, −6) is parallel to (−4, 3). Find k. **[2]**

**(b)** The vector (2, t) is parallel to (−4, 3). Find t. **[2]**

**10.** A hiker walks along the vector **a** = (2, 5), then along **b** = (4, −1), then along a third vector **c**. Distances are in kilometres. She finishes 1 km due east of her starting point. Find **c**. **[3]**

**11.** A shape is translated by a vector **t** and its image is then translated by (3, −4). The overall effect is a translation by (−1, 2).

**(a)** Find **t**. **[2]**

**(b)** Write down the translation that returns the final image to the original shape. **[1]**

**12.** **a** = (3, −1) and **b** = (1, 2). Find the vector **c** such that 2**c** + **a** = 3**b**. **[3]**

## Answers

**1. (a)** (−2 − 4, 3 − (−1)) = **(−6, 4)** [1]

**(b)** **(6, −4)** [1]

**2. (a)** **(2, 2)** [1]

**(b)** (5 − (−3), −2 − 4) = **(8, −6)** [1]

**3. (a)** **(−4, 6)** [1]

**(b)** **(18, −27)** [1]

**4.** **(4, −6) = 2(2, −3)** and **(−2, 3) = −1(2, −3)** [1]; **(−10, 15) = −5(2, −3)**, while (6, 9) is not parallel because 6 ÷ 2 = 3 but 9 ÷ (−3) = −3 [1]

*Examiner insight:* a negative multiplier still means parallel; the vector simply points the opposite way.

**5. (a)** **(1, −2)** [1]

**(b)** (4, −7) + (−2, 2) = **(2, −5)** [1]

**6. (a)** SR is equal to PQ, so SR = **a** [1]

**(b)** SP is opposite in direction to QR, so SP = **−b** [1]

**7. (a)** 2**p** = (8, 2) [1]; 2**p** + **q** = **(6, 5)** [1]

**(b)** 3**q** = (−6, 9) [1]; **p** − 3**q** = (4 + 6, 1 − 9) = **(10, −8)** [1]

**(c)** **p** + **r** = (4, −4) [1]; ½(**p** + **r**) = **(2, −2)** [1]

**8. (a)** top: x − 8 = −1, so **x = 7** [1]; bottom: 3 − 2y = 13 [1], so **y = −5** [1]

**(b)** m + 3n = 7 and 2m − n = 0 [1]; n = 2m, so 7m = 7 [1]; **m = 1, n = 2** [1]

*Examiner insight:* check (b) by substituting: (1, 2) + (6, −2) = (7, 0). A check like this catches sign errors before they cost the final mark.

**9. (a)** Multiplier from the bottom entries: −6 ÷ 3 = −2 [1]; k = −2 × (−4) = **8** [1]

**(b)** Multiplier from the top entries: 2 ÷ (−4) = −½ [1]; t = −½ × 3 = **−1.5** [1]

**10.** **a** + **b** = (6, 4) [1]; **a** + **b** + **c** = (1, 0) [1]; **c** = (1 − 6, 0 − 4) = **(−5, −4)** [1]

*Examiner insight:* "1 km due east" is the vector (1, 0). Many answers use (0, 1), which is due north.

**11. (a)** **t** + (3, −4) = (−1, 2) [1]; **t** = **(−4, 6)** [1]

**(b)** **(1, −2)** [1]

**12.** 3**b** = (3, 6) [1]; 2**c** = 3**b** − **a** = (0, 7) [1]; **c** = **(0, 3.5)** [1]

## Where marks are usually lost

- Calculating start minus end.
- Multiplying only one entry by a scalar.
- Sign errors when subtracting negative entries.
- Mixing up east (1, 0) and north (0, 1).
- Solving only one of the two equations from a vector equation.
