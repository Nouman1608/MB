"Edit a presentation" is the longest content row in Topic 19 of the Cambridge IGCSE ICT 0417 syllabus. Its guidance lists: apply slide layout; insert a new slide; move or delete a slide; insert and edit objects (text, images, video clips, animated images, charts, tables, audio clips, symbols, lines, arrows, callout boxes and shapes); add presenter notes; insert and edit hyperlinks to a slide, an external file or an email address; insert action buttons; add alternative text or a screentip; apply consistent transitions and animations; and hide slides. This guide takes the list in groups, shows how each is done and checked, and works through a sequence of edits where slide numbers change as you go.

The [Presentations study guide](/resources/cambridge-igcse-ict-presentations-study-guide/) gives an overview of editing. Consolidate this page with the [Edit a presentation revision notes](/resources/cambridge-igcse-ict-0417-edit-a-presentation-t19-revision-notes/) and the [Edit a presentation practice questions](/resources/cambridge-igcse-ict-0417-edit-a-presentation-t19-practice/).

## Slides: layout, insert, move, delete

**Apply slide layout.** A layout is an arrangement of placeholders. Applying a different layout to an existing slide rearranges its content into the new placeholders: changing "title and content" to "two content" adds a second content box beside the first, ready for an image or chart. Choose the layout that fits the content instead of drawing loose text boxes, because placeholders keep the master's formatting.

**Insert a new slide.** A new slide is added **after the slide currently selected**, using the layout you choose. If an instruction says "insert a new slide after slide 4", select slide 4 first.

**Move a slide.** Drag it in the slide thumbnails or in slide sorter view, or cut and paste it. Moving changes the number of every slide between the old and new positions.

**Delete a slide.** Select it and delete. If the task says *hide*, do not delete: a hidden slide stays in the file.

## Objects on a slide

| Object | Points to get right |
|---|---|
| Text: headings, subheadings, bulleted lists | Type into the title and content placeholders so the master formatting applies; use bullet levels for sub-points |
| Still images | Keep the aspect ratio locked; crop rather than squash; place without covering text |
| Video clips | Inserted from a file; set how they start (on click or automatically) if the task says |
| Animated images | Usually an animated GIF file; inserted like a still image, and the movement plays in the slide show |
| Charts | Enter or paste the data, choose a chart type that fits, add a chart title, axis titles and a legend only if there is more than one series |
| Tables | Set the number of rows and columns; use a header row; keep text the same size and alignment in each column |
| Audio clips (sound) | Inserted from a file; set whether it plays on click or automatically; an icon appears on the slide |
| Symbols | Inserted from the symbol character set, for example ©, °, € or ✓, not typed as look-alike letters |
| Lines and arrows | Drawn with the shape tools; set colour, thickness and arrowhead style; an arrow points from cause to effect |
| Call out boxes | A shape with a pointer, used to label part of an image or chart; point the tail at the feature |
| Shapes | Rectangles, circles and so on; set fill and outline; use alignment tools to line several shapes up |

"Edit" an object means change its size, position, formatting or content after inserting it. For example, edit a chart by changing its data or adding a missing axis title; edit a table by inserting a row or merging header cells.

## Presenter notes

Presenter notes are typed into the notes pane below each slide. They remind the speaker what to say and can be printed as notes pages, but they are not shown to the audience during a presenter-controlled show. Type them exactly as the task gives them, on the slide named.

## Hyperlinks and action buttons

A **hyperlink** can be attached to selected **text** or to an **object** such as an image or shape. The syllabus names three destinations:

- **a slide within the presentation**, for example a link on a menu slide to slide 5;
- **an external file**, such as a document or spreadsheet; keep the file in the same folder so the link still works when the folder is moved;
- **an email address**, which opens a new message addressed to it, sometimes with a subject line set.

To **edit** a hyperlink, select the linked text or object and change its destination or display text. When the destination is a slide, choose the slide by its title, not by guessing a number, because numbers change when slides move.

An **action button** is a ready-made shape (such as Home, Back, Next or a blank button) whose action settings choose what happens on a mouse click. The default for many buttons is "next slide" or "previous slide", so you often need to **modify the settings** to go to a specified slide, such as the menu, or to open a specified file.

## Alternative text and screentips

**Alternative text** is a description attached to an image or other object. Screen-reader software reads it aloud for users who cannot see the slide, and it describes the object if it cannot be displayed. A **screentip** is text that appears when the pointer hovers over a hyperlink or object, for example "Opens the booking form". Write both to describe the content or purpose, not just the file name: "Map of the park entrances" rather than "image2.png".

## Transitions and animations, applied consistently

A **transition** controls the change from one slide to the next; an **animation** controls how an object on a slide enters, moves or leaves. The syllabus stresses **consistent** use:

- Apply the **same transition**, with the same speed or duration, to every slide, normally with an "apply to all" command, then check no slide was left with a different one.
- Apply the **same animation effect** to similar objects. If bullets on slide 2 fly in from the left one at a time, bullets on other slides should do the same.
- Check the **order** of animations on each slide matches the order the task gives, and whether each starts on click or after the previous one.

Consistency keeps the audience's attention on the content and makes the presentation look planned.

## Hiding slides

A hidden slide stays in the file, keeps its place and is still visible in normal and slide sorter views (usually marked with a crossed-out number), but it is **skipped in the slide show**. Hide a slide that is needed for some audiences but not others, such as an answers slide for a lesson.

## Worked example: edits that change slide numbers

*The presentation and brief are invented.* A presentation has eight slides. The task gives these instructions in order:

1. Insert a new slide after slide 3 with the title *Our Team*.
2. Delete the slide titled *Old Prices*, which was slide 6 at the start.
3. Move slide 2 so that it becomes the last slide.
4. On slide 1, link the text *Contact us* to the email address given.
5. Hide the slide titled *Staff Only*.

Working:

- After step 1 there are 9 slides. *Our Team* is slide 4, and the original slides 4 to 8 become slides 5 to 9. *Old Prices* is now slide **7**, not 6.
- After step 2 there are 8 slides again; the original slides 7 and 8 are back to being slides 7 and 8.
- After step 3, slide 2 moves to position 8 and every slide from 3 to 8 moves up one place. *Our Team* is now slide 3.
- Step 4 adds an email hyperlink to selected text on slide 1; test it in the slide show.
- Step 5: hiding keeps the slide count at 8, but the show displays only 7 slides.

The lesson: when instructions refer to slides by number, work in the order given and use titles to confirm you have the right slide after each insert, delete or move.

## Common mistakes

- Inserting a slide after the wrong slide because a different one was selected.
- Deleting a slide that should only have been hidden.
- An action button left on its default "next slide" setting.
- A hyperlink to a file in a different folder, which breaks when the work is moved.
- Alternative text that only repeats the file name.
- "Apply to all" used for the transition, then a different transition added to one slide later.
- A chart with no title or axis titles, or a legend for a single series.

## Exam technique

Practical instructions use *apply*, *insert*, *move*, *delete*, *add*, *link* and *hide*. Each is usually checked separately, so run the slide show at the end and click every hyperlink and action button. In theory questions, *describe* a feature by saying what it does, and *explain* by adding why: "The slide is hidden so that it is skipped during the show but remains in the file for a later audience."
