These notes condense subtopic **2.11 Sketching curves** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027): recognise, sketch and interpret graphs. Core (C2.11) covers linear and quadratic graphs, with symmetry and roots; turning points are not required at Core. Lines marked *(Extended)* are E2.11 only: cubic, reciprocal and exponential graphs, turning points, asymptotes, and turning points of quadratics by completing the square. For worked examples, read the [sketching curves study guide](/resources/cambridge-igcse-mathematics-0580-sketching-curves/); for marked questions, use the [sketching curves practice questions](/resources/cambridge-igcse-mathematics-0580-sketching-curves-practice/).

## Key terms

| Term | Meaning |
|---|---|
| Sketch | A freehand graph showing the correct shape and labelled key features, not to scale |
| Root | Where the curve meets the x-axis (y = 0) |
| y-intercept | Where the curve meets the y-axis (x = 0) |
| Line of symmetry | For a quadratic, the vertical line through the turning point, halfway between the roots |
| Turning point *(Extended)* | A maximum or minimum point, where the curve changes direction |
| Asymptote *(Extended)* | A line the curve approaches but never reaches; drawn dashed |
| Repeated root *(Extended)* | A squared factor, where the curve touches the x-axis and turns |

## Feature table for every family

| Family | Form | Shape | Features to label |
|---|---|---|---|
| Linear | ax + by = c | straight line | both intercepts |
| Quadratic | y = ax² + bx + c | U if a > 0; n if a < 0 | roots, y-intercept (0, c), line of symmetry; *(Extended)* turning point |
| Cubic *(Extended)* | y = ax³ + b | S-shape, one root; rising if a > 0, falling if a < 0 | (0, b), root |
| Cubic *(Extended)* | y = ax³ + bx² + cx | through the origin; up to three roots | all roots, including (0, 0) |
| Reciprocal *(Extended)* | y = a/x + b | two branches | asymptotes x = 0 and y = b; root if any |
| Exponential *(Extended)* | y = arˣ + b | one smooth curve | (0, a + b), asymptote y = b, root if any |

## Condensed recall

### Quadratics

```
Roots:      factorise and set each bracket to 0
Symmetry:   x = (root1 + root2) / 2
Turning point (Extended):  a(x + p)^2 + q  ->  (-p, q)
            a > 0 minimum; a < 0 maximum
No roots:   a > 0 and q > 0 (curve entirely above the x-axis),
            or a < 0 and q < 0 (entirely below)
```

Examples: x² + 8x + 10 = (x + 4)² − 6, minimum (−4, −6). −x² + 6x − 2 = −(x − 3)² + 7, maximum (3, 7).

### Cubics *(Extended)*

- Positive leading coefficient: bottom left to top right. Negative: top left to bottom right.
- Factorise fully; single factors are crossings, a squared factor is a touch.
- y = 2x³ − 16 has y-intercept (0, −16) and root 2x³ = 16, x = 2.

### Reciprocals *(Extended)*

- a > 0: branches top right and bottom left of the asymptote crossing (0, b).
- a < 0: top left and bottom right.
- Root from a/x + b = 0; no y-intercept.

### Exponentials *(Extended)*

- r > 1: increasing; 0 < r < 1: decreasing (for a > 0).
- y-intercept a + b; asymptote y = b.
- If a > 0 and b ≥ 0 the curve never meets the x-axis.

## Recognising a graph quickly

Ask one question at a time:

1. Straight or curved?
2. Does it pass through the origin? (no constant term)
3. Is there an asymptote? (x in a denominator, or x as a power)
4. What is the sign of the highest power?
5. Where does it cross the y-axis?

## Exam traps

- **Turning point sign.** (x + 4)² − 6 has its minimum at x = −4, not 4.
- **n-shape forgotten.** A negative x² coefficient turns the whole parabola upside down.
- **Roots of −x² + … quadratics.** Take out −1 first: 8 − 2x − x² = −(x + 4)(x − 2).
- **Touch versus cross.** x(x + 2)² touches the x-axis at −2 and crosses at 0.
- **Curves through asymptotes.** Reciprocal and exponential curves must never cross their asymptotes.
- **Joined reciprocal branches.** Two separate pieces.
- **Missing labels.** An unlabelled sketch with the right shape scores little.
- **Lopsided parabolas.** Even where turning points are not required (Core), the curve must be symmetrical about its line of symmetry, with the lowest or highest point on that line.

## Self-test

1. Find the intercepts of 2x + 5y = 10.
2. For y = x² − 6x + 5, find the roots, the y-intercept and the line of symmetry.
3. For y = 8 − 2x − x², find the roots, y-intercept, shape and line of symmetry.
4. Describe the shape of y = 3 − x² and give its y-intercept.
5. *(Extended)* Find the turning point of y = x² + 8x + 10 and state its type.
6. *(Extended)* Find the turning point of y = −x² + 6x − 2 and state its type.
7. *(Extended)* Find where y = 2x³ − 16 crosses each axis.
8. *(Extended)* Find the roots of y = x³ + x² − 6x.
9. *(Extended)* Describe how y = x³ + 4x² + 4x meets the x-axis.
10. *(Extended)* Give the asymptotes and root of y = 5/x − 3.
11. *(Extended)* Give the y-intercept and asymptote of y = 3 × 2ˣ + 1. Does it have a root?
12. *(Extended)* In which quadrants are the branches of y = −2/x?

### Answers

1. **(5, 0) and (0, 2)**.
2. (x − 1)(x − 5): roots **x = 1, 5**; y-intercept **(0, 5)**; symmetry **x = 3**.
3. −(x + 4)(x − 2): roots **x = −4, 2**; y-intercept **(0, 8)**; **n-shape**; symmetry **x = −1**.
4. **n-shape** (negative x²), symmetrical about the y-axis, y-intercept **(0, 3)**.
5. (x + 4)² − 6: **minimum (−4, −6)**.
6. −(x − 3)² + 7: **maximum (3, 7)**.
7. **(0, −16)** and **(2, 0)**.
8. x(x + 3)(x − 2): **x = −3, 0, 2**.
9. x(x + 2)²: **touches at (−2, 0)**, **crosses at (0, 0)**.
10. Asymptotes **x = 0, y = −3**; root 5/x = 3, **x = 5/3**.
11. y-intercept **(0, 4)**; asymptote **y = 1**; **no root**, as the curve stays above y = 1.
12. **Second and fourth** (top left and bottom right).
