**Syllabus:** Cambridge International AS & A Level Chemistry 9701, 2025–2027, **A Level** subtopic
35.1: polyesters, polyamides, deducing repeat units, and identifying "the monomer(s) present in a
given section of a condensation polymer molecule".

## The core idea

- Monomers with **two reactive groups** join, and a **small molecule** (H₂O or HCl) is lost at every
  link.
- Ester link **–COO–**: polyester. Amide link **–CONH–**: polyamide.
- Acid groups (–COOH) lose **H₂O**; acyl chloride groups (–COCl) lose **HCl**.

## The five syllabus monomer combinations

| Type | Monomers | Example | Repeat unit | Lost |
|---|---|---|---|---|
| polyester (a) | diol + dicarboxylic acid | HOCH₂CH₂OH + HOOCC₆H₄COOH | –OCH₂CH₂OOCC₆H₄CO– | H₂O |
| polyester (a) | diol + dioyl chloride | HOCH₂CH₂OH + ClOCC₆H₄COCl | –OCH₂CH₂OOCC₆H₄CO– | HCl |
| polyester (b) | hydroxycarboxylic acid | CH₃CH(OH)COOH | –OCH(CH₃)CO– | H₂O |
| polyamide (a) | diamine + dicarboxylic acid / dioyl chloride | H₂N(CH₂)₆NH₂ + HOOC(CH₂)₄COOH | –NH(CH₂)₆NHCO(CH₂)₄CO– | H₂O / HCl |
| polyamide (b) | aminocarboxylic acid | H₂N(CH₂)₅COOH | –NH(CH₂)₅CO– | H₂O |
| polyamide (c) | amino acids | H₂NCH(R)COOH | –NHCH(R)CO– | H₂O |

## Drawing a repeat unit: five checks

1. Take –OH off each –COOH (or –Cl off each –COCl).
2. Take –H off each –OH or –NH₂.
3. Join with the ester or amide link.
4. Leave **open bonds** at both ends; add brackets and **n**.
5. Two-monomer polymer: **one** residue of each monomer per repeat unit.

**Formula check:** repeat unit = monomer A + monomer B − 2 × (small molecule).

## Monomers from a chain: four steps

1. Find each –COO– or –CONH– link.
2. Break the **C–O** or **C–N** single bond (not C=O).
3. Add –OH to each C=O end; add –H to each O or N end.
4. **Links all facing one way** → one monomer type (or amino acids). **Links alternating** → two
   monomers.

## Useful repeat-unit masses (Aᵣ: H = 1.0, C = 12.0, N = 14.0, O = 16.0)

| Polymer | Repeat unit formula | Mᵣ of repeat unit |
|---|---|---|
| PET | C₁₀H₈O₄ | 192.0 |
| poly(lactic acid) | C₃H₄O₂ | 72.0 |
| nylon-6,6 | C₁₂H₂₂N₂O₂ | 226.0 |
| polyamide from 6-aminohexanoic acid | C₆H₁₁NO | 113.0 |

**Number of repeat units = Mᵣ(polymer) ÷ Mᵣ(repeat unit).**

## Small-molecule count

- n diol + n diacid → (2n − 1) H₂O strictly; often written as **2n H₂O** for a long chain.
- n hydroxy- or aminocarboxylic acid → (n − 1) H₂O strictly; often written **n H₂O**.

## Writing the full equation with n

Example: hexane-1,6-diamine with hexanedioyl chloride.

    n H₂N(CH₂)₆NH₂ + n ClOC(CH₂)₄COCl → –[NH(CH₂)₆NHCO(CH₂)₄CO]ₙ– + 2n HCl

Checklist for the equation:

- the same **n** in front of each monomer and as the subscript on the brackets;
- the small molecule multiplied by **2n** for a two-monomer polymer, or **n** for a single monomer;
- the correct small molecule for the functional group used (HCl here, because a dioyl chloride
  reacts).

## Same chemistry as the small molecules

The links in condensation polymers are the same functional groups met earlier, so their reactions
carry over:

- an **ester link** forms like an ester from an alcohol and an acyl chloride (33.2), or from an
  alcohol and a carboxylic acid (AS 18.2);
- an **amide link** forms like an amide from an amine and an acyl chloride (34.3);
- a **peptide link** is an amide link between amino acids (34.4).

This is why the reactions that break these links in small molecules, acid and alkaline hydrolysis,
also break down polyesters and polyamides (35.3).

## Key terms

| Term | Meaning |
|---|---|
| condensation polymerisation | joining of monomers with loss of a small molecule at each link |
| repeat unit | smallest section of a polymer that repeats to build the chain |
| polyester | condensation polymer with ester (–COO–) links |
| polyamide | condensation polymer with amide (–CONH–) links |
| dioyl chloride | molecule with two –COCl groups |
| diol / diamine | molecule with two –OH / two –NH₂ groups |
| hydroxycarboxylic acid | one molecule with –OH and –COOH |
| aminocarboxylic acid | one molecule with –NH₂ and –COOH |
| polypeptide | polyamide made from amino acids |

## Exam traps

- Dioyl chloride → **HCl**, not water.
- Repeat units have **no end groups**: no –OH, –H or –Cl hanging off the ends.
- Two-monomer polyesters and polyamides: **one** of each monomer in the repeat unit, not two.
- Break at **C–O / C–N**, never at C=O.
- A single monomer must have **both** groups (–OH and –COOH, or –NH₂ and –COOH).
- A monomer with only one reactive group stops chain growth.

## Self-test

1. What small molecule is lost when a diamine reacts with a dioyl chloride?
2. Draw the repeat unit from butane-1,4-diol and hexanedioic acid.
3. Draw the repeat unit of the polymer from 4-hydroxybutanoic acid, HO(CH₂)₃COOH.
4. Draw the repeat unit of the polyamide from hexane-1,6-diamine and decanedioyl chloride,
   ClOC(CH₂)₈COCl.
5. Identify the monomers in –OCH₂CH₂OOC(CH₂)₂CO–OCH₂CH₂OOC(CH₂)₂CO–.
6. Identify the monomer in –NH(CH₂)₃CO–NH(CH₂)₃CO–.
7. How can you tell from a section whether a polyester came from one or two monomers?
8. A sample of nylon-6,6 has Mᵣ = 33 900. Estimate the number of repeat units.
9. Why can ethanol not be used to make a polyester?
10. Give the type of link in a polypeptide.
11. Write the formula check for the repeat unit of PET.
12. Name the polymer type formed from an aminocarboxylic acid.

**Answers:**

1. HCl.
2. –O(CH₂)₄OOC(CH₂)₄CO–.
3. –O(CH₂)₃CO–.
4. –NH(CH₂)₆NHCO(CH₂)₈CO–.
5. Ethane-1,2-diol, HOCH₂CH₂OH, and butanedioic acid, HOOC(CH₂)₂COOH.
6. 4-aminobutanoic acid, H₂N(CH₂)₃COOH.
7. Links all facing the same way → one monomer; links alternating in direction → two monomers.
8. 33 900 / 226.0 = 150.
9. It has only one –OH group, so it would cap a chain rather than extend it.
10. Amide (peptide) link, –CONH–.
11. C₂H₆O₂ + C₈H₆O₄ − 2H₂O = C₁₀H₈O₄.
12. A polyamide.
