These questions cover subtopic **2.10 Graphs of functions** in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. Questions without a label use Core content (C2.10): linear, quadratic and a/x graphs. Questions marked **(Extended)** use E2.10 content: sums of powers of x, abˣ + c, and exponential growth and decay. Where a question says a graph "is drawn", draw it yourself on graph paper to check your answers; graph readings are accepted within a small tolerance.

For worked examples, read the [graphs of functions study guide](/resources/cambridge-igcse-mathematics-0580-graphs-of-functions/); for a summary, use the [graphs of functions revision notes](/resources/cambridge-igcse-mathematics-0580-graphs-of-functions-revision-notes/).

## Questions

### Section A: short questions

**1.** Complete the table for y = x² − 2x − 3. **[2]**

```
x   -2   -1    0    1    2    3    4
y    5   ..   -3   ..   ..    0   ..
```

**2.** Find the value of y = −x² + 4 when x = −3. **[1]**

**3.** Complete the table for y = 4/x. **[2]**

```
x   -4   -2   -0.5   0.5    2    4
y   ..   ..    ..     8    ..   ..
```

**4.** The graph of y = x² − 2x − 3 is drawn for −2 ≤ x ≤ 4.

**(a)** Write down the roots of x² − 2x − 3 = 0. **[1]**

**(b)** Write down the equation of the line of symmetry of the graph. **[1]**

**5.** (calculator) Using the graph of y = x² − 2x − 3, write down the equation of the line you would draw to solve x² − 2x − 3 = 2, and give the solutions correct to 1 decimal place. **[3]**

**6.** (Extended) Complete the table for y = x³ − 3x² + 2. **[2]**

```
x   -1    0    1    2    3
y   ..    2   ..   ..    2
```

### Section B: structured questions

**7.** The graphs of y = 4/x and y = 5 − x are drawn on the same grid.

**(a)** Show that the x-coordinates of the points where they meet satisfy x² − 5x + 4 = 0. **[2]**

**(b)** Find the coordinates of the two points where the graphs meet. **[2]**

**8.** (calculator) The graph of y = x² − 2x − 3 is drawn for −2 ≤ x ≤ 4.

**(a)** Find the equation of the straight line you would draw on the grid to solve x² − 3x − 1 = 0. **[2]**

**(b)** Give the solutions of x² − 3x − 1 = 0 correct to 1 decimal place. **[2]**

**9.** (Extended) The graph of y = x³ − 3x² + 2 is drawn for −1 ≤ x ≤ 3, using your table from Question 6.

**(a)** Use the table to explain how many solutions x³ − 3x² + 2 = 0 has in this range, and write down the one that is a whole number. **[2]**

**(b)** Estimate the other solutions correct to 1 decimal place. **[2]**

**(c)** Find the equation of the line you would draw to solve x³ − 3x² − x + 3 = 0. **[2]**

**10.** (Extended) The table is for y = x/2 + 2/x, x > 0.

```
x    0.5    1    2    3     4
y    4.25   ..   ..   2.17  ..
```

**(a)** Complete the table. **[2]**

**(b)** Use the graph to write down the least value of y for x > 0. **[1]**

**(c)** Explain why x/2 + 2/x = 1.5 has no solution for x > 0. **[1]**

**11.** (Extended, calculator) The table is for y = 2ˣ − 3.

```
x   -2     -1    0    1    2    3
y   ..    -2.5   ..   -1   ..   5
```

**(a)** Complete the table. **[2]**

**(b)** Write down the equation of the horizontal asymptote of the graph. **[1]**

**(c)** Use the graph to estimate the root of 2ˣ − 3 = 0, correct to 1 decimal place. **[1]**

**12.** (Extended, calculator) A hot drink cools. Its temperature above room temperature, T °C, after t minutes is modelled by T = 70 × 0.9ᵗ.

**(a)** Write down the value of T when t = 0. **[1]**

**(b)** By what percentage does T decrease each minute? **[1]**

**(c)** Find T when t = 5, 10 and 20, correct to 1 decimal place. **[2]**

**(d)** The graph of T against t is drawn. Use it to estimate the time when T = 35. **[1]**

## Answers

**1.** x = −1: 1 + 2 − 3 = 0; x = 1: 1 − 2 − 3 = −4 [1]. x = 2: 4 − 4 − 3 = −3; x = 4: 16 − 8 − 3 = 5 [1]. Row: **5, 0, −3, −4, −3, 0, 5**.

**2.** −(−3)² + 4 = −9 + 4 = **−5** [1].

**3.** **−1, −2, −8** for the negative x-values [1]; **2, 1** for x = 2 and 4 [1].

**4. (a)** **x = −1 and x = 3** [1].

**(b)** **x = 1** [1].

**5.** Line **y = 2** [1]. x² − 2x − 5 = 0 has solutions 1 ± √6, so **x ≈ −1.4** [1] and **x ≈ 3.4** [1].

**6.** x = −1: −1 − 3 + 2 = **−2** [1]; x = 1: **0**, x = 2: 8 − 12 + 2 = **−2** [1].

**7. (a)** 4/x = 5 − x [1]. Multiply by x: 4 = 5x − x², so x² − 5x + 4 = 0 [1].

**(b)** (x − 1)(x − 4) = 0, so x = 1 or 4 [1]. Points **(1, 4) and (4, 1)** [1].

**8. (a)** x² − 3x − 1 = 0 becomes x² − 2x − 3 = x − 2 (add x − 2 to both sides) [1]. Line **y = x − 2** [1].

**(b)** **x ≈ −0.3** [1] and **x ≈ 3.3** [1] (exact values (3 ± √13)/2).
*Examiner insight:* check the line by subtraction: (x² − 2x − 3) − (x − 2) = x² − 3x − 1. If this does not give the equation in the question, the line is wrong.

**9. (a)** y changes sign between x = −1 and 0, is 0 at x = 1, and changes sign between x = 2 and 3, so there are **three** solutions [1]. The whole-number solution is **x = 1** [1].

**(b)** **x ≈ −0.7** [1] and **x ≈ 2.7** [1] (exact values 1 ± √3).

**(c)** x³ − 3x² − x + 3 = 0 becomes x³ − 3x² + 2 = x − 1 [1]. Line **y = x − 1** [1].

**10. (a)** x = 1: 0.5 + 2 = **2.5**; x = 2: 1 + 1 = **2** [1]. x = 4: 2 + 0.5 = **2.5** [1].

**(b)** **y = 2** (at x = 2) [1].

**(c)** The line y = 1.5 lies below the lowest point of the curve (y = 2), so it never meets the curve [1].

**11. (a)** x = −2: 0.25 − 3 = **−2.75** [1]; x = 0: **−2** and x = 2: **1** [1].

**(b)** **y = −3** [1].

**(c)** **x ≈ 1.6** [1] (accurate value 1.58…).
*Examiner insight:* the curve approaches y = −3 on the left but never reaches it; a graph that crosses or touches the asymptote loses the shape mark.

**12. (a)** **70 °C** [1].

**(b)** Multiplier 0.9, so **10%** [1].

**(c)** **41.3, 24.4 and 8.5** [1] for two correct, [1] for all three.

**(d)** **t ≈ 6.6 minutes** [1] (accept 6.4 to 6.8).

## Where marks are usually lost

- Working out −(−3)² as +9.
- Plotting a correct table with straight ruled segments.
- Drawing a horizontal line through the wrong value, or a line not rearranged from the given equation.
- Missing one of three solutions of a cubic.
- Treating 0.9 as a 90% decrease.
