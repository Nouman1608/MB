## The exercise in one table

| Feature | Exercise 5 |
|---|---|
| Marks | 8 |
| Length | approximately 120 words |
| Form | short functional prose, such as an email |
| Stimulus | short prompts and/or pictures |
| Specified | purpose, format and audience |
| Objectives | W1, W2, W3, W4, W5 |
| Suggested time | about 15 minutes |

The syllabus does not publish a split of the 8 marks. This site's practice convention is up to 4 for
task and communication and up to 4 for language.

## P-F-A before you write

- **Purpose:** دعوت، شکریہ، معذرت، معلومات، مشورہ، شکایت
- **Format:** ای میل، خط، پیغام → greeting, opening line, closing line, sign-off
- **Audience:** friend or family → **تم**; teacher, principal, manager → **آپ**

Then tick off each prompt as you plan it.

## تم and آپ: the verb forms

| Verb | تم | آپ |
|---|---|---|
| ہونا | تم کیسے ہو؟ | آپ کیسے ہیں؟ |
| آنا (request) | ضرور آنا / آؤ | تشریف لائیے / آئیے گا |
| بتانا | مجھے بتاؤ | مجھے بتائیے |
| کرنا | یہ کام کرو | یہ کام کیجیے |
| possessive | تمہارا، تمہاری | آپ کا، آپ کی |

**Never mix them** in one piece.

## Openings and closings

| | Informal | Formal |
|---|---|---|
| Salutation | پیارے سلمان، / پیاری ثنا، | محترم پرنسپل صاحب، / محترمہ… |
| First line | امید ہے تم خیریت سے ہو گے / ہو گی۔ | امید ہے آپ خیریت سے ہوں گے۔ |
| Reason for writing | یہ بتانے کے لیے لکھ رہا/رہی ہوں کہ… | میں یہ ای میل… کے سلسلے میں لکھ رہا/رہی ہوں۔ |
| Closing line | جلدی جواب دینا۔ اپنا خیال رکھنا۔ | آپ کے جواب کا منتظر رہوں گا / منتظر رہوں گی۔ |
| Sign-off | تمہارا دوست، / تمہاری سہیلی، | والسلام، / آپ کا شاگرد، / آپ کی شاگردہ، |

## Phrases by purpose

| Purpose | Informal (تم) | Formal (آپ) |
|---|---|---|
| Invite | کیا تم… آ سکتے ہو؟ ضرور آنا! | میں آپ کو… کی دعوت دینا چاہتا/چاہتی ہوں۔ |
| Thank | تمہارا بہت شکریہ کہ تم نے… | میں آپ کا تہِ دل سے شکر گزار ہوں کہ آپ نے… |
| Apologise | معاف کرنا، میں… نہیں کر سکا/سکی۔ | میں معذرت خواہ ہوں کہ… |
| Advise | میرے خیال میں تمہیں… چاہیے۔ | میرا مشورہ ہے کہ آپ… |
| Complain | — | مجھے افسوس کے ساتھ کہنا پڑ رہا ہے کہ… / میری گزارش ہے کہ… |
| Inform | تمہیں یہ بتانا تھا کہ… | آپ کو مطلع کرنا چاہتا/چاہتی ہوں کہ… |

## Picture prompts

If the stimulus includes pictures, each picture usually stands for one piece of content (a place, an
activity, a problem). Name what the picture shows, then develop it like a written prompt: what it is,
a detail, and how you felt about it. Ignoring a picture is the same as missing a prompt.

## The 120-word plan

```
Opening            10-15 words
Prompt 1           ~30 words: statement + detail + feeling
Prompt 2           ~30 words
Prompt 3           ~30 words
Closing + sign-off 10-15 words
```

## Language to show range

- **Tenses:** past (گئے تھے), present (ملتے ہیں), future (ہو گی), conditional (اگر… تو…).
- **Connectives:** کیونکہ، اس لیے، لیکن، اس کے علاوہ، جب… تو…
- **Feelings:** مجھے بہت خوشی ہوئی، مجھے افسوس ہے کہ…، مجھے یقین ہے کہ…

## Accuracy checks

| Error | Correct |
|---|---|
| میں نے ایک نیا کتاب خریدا۔ | میں نے ایک نئی کتاب خریدی۔ |
| ہم نے پارک گئے۔ | ہم پارک گئے۔ (جانا is intransitive: no نے) |
| آپ کل ضرور آؤ۔ | آپ کل ضرور آئیے گا۔ |
| girl writing: میں لکھ رہا ہوں | میں لکھ رہی ہوں |

## Traps

- a prompt missed
- register drift between تم and آپ
- no greeting or sign-off
- prompts listed, not developed
- far beyond 120 words
- copying prompt wording

## Self-test

1. How many marks is Exercise 5 worth, and how long should the answer be?
2. What three things does the question specify?
3. Write the آپ form of "مجھے بتاؤ".
4. Why is "ہم نے بازار گئے" wrong?
5. Give an informal closing line and a formal one.
6. What does a well-developed prompt contain?
7. The task says: "اپنے استاد کو ای میل لکھیے اور بتائیے کہ آپ کل اسکول کیوں نہیں آ سکیں گے". Name the
   purpose, format, audience and register.

**Answers:** 1. 8 marks; approximately 120 words. 2. Purpose, format and audience. 3. مجھے بتائیے۔
4. جانا is intransitive, so it does not take نے: "ہم بازار گئے". 5. Informal, for example جلدی جواب
دینا; formal, for example آپ کے جواب کا منتظر رہوں گا (or منتظر رہوں گی). 6. A statement, a detail or
reason, and a feeling or comment. 7. Purpose: to inform and apologise (explain an absence); format: an
email; audience: a teacher; register: formal, so آپ throughout, with a closing such as آپ کا شاگرد or
آپ کی شاگردہ.
