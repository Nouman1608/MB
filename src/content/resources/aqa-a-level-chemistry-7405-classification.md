This guide teaches section **3.2.1.1 Classification** of the AQA AS and A-level Chemistry specification (7404/7405), for teaching from September 2015. It is AS content, examined on Paper 1 at AS and A-level, and A-level Paper 3 can test it. The [Periodicity study guide](/resources/aqa-a-level-chemistry-periodicity/) covers the whole of 3.2.1. This page goes deeper on one idea: how an element's position in the Periodic Table, fixed by its proton number, tells you its block, and how to move in both directions between position, block and electron configuration. Recall is in the [Classification revision notes](/resources/aqa-a-level-chemistry-7405-classification-revision-notes/), and questions are in the [Classification practice questions](/resources/aqa-a-level-chemistry-7405-classification-practice/). You will need the electron configuration rules from [Electron configuration](/resources/aqa-a-level-chemistry-7405-electron-configuration/).

## What the specification asks

| Content | What you must be able to do |
|---|---|
| An element is classified as s, p, d or f block | Name the block of any element |
| according to its position in the Periodic Table | Use the position of an element to decide the block |
| which is determined by its proton number | Explain why the order of the table follows proton number |

The wording is short, but it connects to several other ideas: the sub-levels filled in order, the groups and periods, and the properties that repeat across a period.

## How the Periodic Table is organised

The elements are arranged in order of **increasing proton number** (atomic number), which is the number of protons in the nucleus. Each element has one more proton than the one before it. In an atom, the number of electrons equals the number of protons, so the electron configuration also builds up one electron at a time.

- A **period** is a horizontal row. Elements in the same period have their outer electrons in the same main energy level (shell).
- A **group** is a vertical column. Elements in the same group have the same number of outer-shell electrons and similar chemical properties.
- A **block** is a region of the table whose elements are filling the same type of sub-level.

The table is not arranged by relative atomic mass. A few pairs of elements (for example argon and potassium) would swap places if it were. Proton number gives the right order, and it explains why properties repeat.

## The four blocks

The block is defined by the sub-level that holds the **highest-energy electron**, that is, the last electron added when you build up the configuration.

| Block | Position | Sub-level being filled | Groups covered |
|---|---|---|---|
| s-block | Left-hand side | s | Groups 1 and 2 (and helium's configuration, 1s²) |
| p-block | Right-hand side | p | Groups 3(13) to 0(18) |
| d-block | Middle | d | Transition elements and neighbours (Sc to Zn in period 4) |
| f-block | Bottom, below the main table | f | Lanthanoids and actinoids |

How many elements fit in each block is set by how many electrons the sub-level holds:

- s sub-level: 1 orbital, up to 2 electrons, so the s-block is 2 elements wide.
- p sub-level: 3 orbitals, up to 6 electrons, so the p-block is 6 wide.
- d sub-level: 5 orbitals, up to 10 electrons, so the d-block is 10 wide.
- f sub-level: 7 orbitals, up to 14 electrons, so the f-block is 14 wide.

## From electron configuration to block

Write the configuration, find the last sub-level to be filled, and name the block.

| Element | Z | Configuration | Last sub-level | Block |
|---|---|---|---|---|
| Sodium | 11 | 1s² 2s² 2p⁶ 3s¹ | 3s | s |
| Magnesium | 12 | 1s² 2s² 2p⁶ 3s² | 3s | s |
| Chlorine | 17 | 1s² 2s² 2p⁶ 3s² 3p⁵ | 3p | p |
| Iron | 26 | 1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁶ 4s² | 3d | d |
| Gallium | 31 | [Ar] 3d¹⁰ 4s² 4p¹ | 4p | p |
| Strontium | 38 | [Kr] 5s² | 5s | s |

Notice that iron is d-block even though its outermost shell is the 4s. The 3d sub-level fills after 4s, so the last electron goes into 3d. Gallium has a full 3d¹⁰ sub-level, but its last electron goes into 4p, so it is p-block.

### Worked example 1: identify the block of selenium

Selenium has proton number 34. Build the configuration: [Ar] 3d¹⁰ 4s² 4p⁴. The last electron enters the 4p sub-level, so selenium is a **p-block** element. It is in Group 6 (16) of period 4.

### Worked example 2: identify the block from a configuration

An element has the configuration 1s² 2s² 2p⁶ 3s² 3p⁶ 4s¹.

The last electron is in 4s, so the element is **s-block**. It has one outer electron, so it is in Group 1. With 19 electrons, it has 19 protons and is potassium.

## From position to block

You can often read the block straight from the table.

- Groups 1 and 2: s-block.
- Groups 3(13) to 0(18): p-block.
- The central block between Group 2 and Group 3 (13): d-block. In period 4 this is scandium to zinc.
- The two rows set below the table: f-block.

Group number also tells you about the outer shell. For Groups 1 and 2 the group number equals the number of outer-shell electrons. For the p-block, the number of outer-shell electrons is the group number minus 10 when the groups are numbered 13 to 18, so Group 5 (15) has five outer electrons.

### Worked example 3: from position

An element is in period 3 and Group 5 (15). It is p-block. Its configuration is 1s² 2s² 2p⁶ 3s² 3p³: the outer shell holds 5 electrons (3s² 3p³). It is phosphorus, with proton number 15.

### Worked example 4: from proton number to block, without writing the whole configuration

Which block does the element with proton number 56 belong to?

Count along the periods. Period 1 holds 2 elements, periods 2 and 3 hold 8 each, periods 4 and 5 hold 18 each, giving 2 + 8 + 8 + 18 + 18 = 54, which is xenon (a noble gas, p-block). The next two elements, 55 and 56, begin period 6 and fill the 6s sub-level. Element 56 is barium, with 6s², an **s-block** element in Group 2.

## Special cases

### Helium

Helium has the configuration 1s². By the rule "last electron enters an s sub-level" it is an s-block element. It is placed in Group 0 (18) with the noble gases because it has a full outer shell and noble gas properties, even though it is an s-block element by configuration.

### Chromium and copper

Chromium (Z = 24) and copper (Z = 29) have configurations [Ar] 3d⁵ 4s¹ and [Ar] 3d¹⁰ 4s¹, because half-filled and fully filled d sub-levels are especially stable. Both are d-block, because the 3d sub-level is the one being filled.

### Ions of d-block elements

When d-block atoms form positive ions, the 4s electrons are lost first, before the 3d electrons. Fe²⁺ is [Ar] 3d⁶, and Fe³⁺ is [Ar] 3d⁵. The block of an element refers to the atom, not to the ion.

## Why position follows proton number

The nuclear charge is the number of protons. It determines how many electrons the neutral atom has and so how the sub-levels fill. Elements in the same group have the same pattern of outer electrons, so they react similarly. As you move across a period, the nuclear charge rises by one with each step while the outer electrons stay in the same shell. This leads to the trends in atomic radius, ionisation energy and melting point covered in the [Physical properties of Period 3 elements study guide](/resources/aqa-a-level-chemistry-7405-physical-properties-of-period-3-elements/).

## Common mistakes

- Saying that the block is decided by the outer shell. It is decided by the sub-level of the highest-energy electron.
- Calling iron s-block because it has 4s² in its configuration.
- Calling gallium d-block because it has 3d¹⁰. The last electron enters 4p.
- Ordering elements by relative atomic mass instead of proton number.
- Removing 3d electrons before 4s electrons when forming ions of d-block elements. The 4s electrons are lost first.
- Forgetting that helium is s-block by configuration.
- Giving the group of an element without checking that it is s- or p-block.

## Exam technique for the command words

- **Deduce the block**: write the configuration up to the last electron, name the sub-level.
- **Explain why the elements are arranged by proton number**: refer to the number of protons, which sets the number of electrons and so the configuration and properties.
- **State the block of an element in the table**: use the position, with the group or the central region.

## Frequently asked questions

**Is hydrogen in the s-block?**
Yes. Its configuration is 1s¹. It is often placed above Group 1, though it is not an alkali metal.

**Why does the d-block begin in period 4?**
The 3d sub-level starts to fill after 4s. Before period 4 there are no d electrons in the ground state.

**What decides the number of elements in a period?**
The sub-levels available. Period 2 has 2s and 2p, which hold 8 electrons, so there are 8 elements. Period 4 has 4s, 3d and 4p, which hold 18 electrons, so there are 18 elements.
