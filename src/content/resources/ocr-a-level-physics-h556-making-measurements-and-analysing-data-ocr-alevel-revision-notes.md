Quick recall for section 2.2, Making measurements and analysing data, of the OCR Advanced GCE in Physics A specification (H556), Version 3.0 (March 2026), for first assessment in 2017: learning outcomes 2.2.1(a)-(d). For the worked examples, read the [making measurements study guide](/resources/ocr-a-level-physics-h556-making-measurements-and-analysing-data-ocr-alevel/), then test yourself with the [making measurements practice questions](/resources/ocr-a-level-physics-h556-making-measurements-and-analysing-data-ocr-alevel-practice/).

## Definitions

| Term | Meaning |
|---|---|
| Systematic error | Shifts all readings in the same direction by the same amount or proportion |
| Zero error | A systematic error: the instrument reads a non-zero value when the true value is zero |
| Random error | Unpredictable scatter of readings about the true value |
| Accuracy | Closeness of a measurement to the true value |
| Precision | Closeness of agreement between repeated measurements |
| Resolution | Smallest change an instrument can display |
| Absolute uncertainty | The ± range within which the true value is expected to lie |
| Percentage uncertainty | Absolute uncertainty ÷ value × 100 |
| Error bar | A line on a graph point showing its absolute uncertainty |
| Worst line | Steepest or shallowest straight line passing through all error bars |
| Percentage difference | \|experimental − accepted\| ÷ accepted × 100 |

## Errors at a glance

- Systematic error: averaging does **not** help; correct it, recalibrate, or change technique. Reduces **accuracy**.
- Random error: repeat and average to reduce it. Reduces **precision**.
- A systematic error on a straight-line graph gives an unexpected intercept but leaves the gradient unchanged if every reading is shifted by the same amount.
- Zero error correction: corrected reading = reading − zero reading (watch the sign).

## Finding an absolute uncertainty

| Situation | Usual estimate |
|---|---|
| Repeated readings | half the range |
| Single digital reading | the resolution (or more if the reading fluctuates) |
| Length from two ruler readings | add the uncertainty of each reading |
| Time for N oscillations | uncertainty in one period = uncertainty in total ÷ N |

Round uncertainties to one or two significant figures; match the value's decimal places to the uncertainty.

## Combining rules

| Calculation | Combine |
|---|---|
| a + b, a − b | absolute uncertainties add |
| ab, a/b | percentage uncertainties add |
| aⁿ | percentage uncertainty × \|n\| |
| √a | half the percentage uncertainty |
| 1/a | same percentage uncertainty |
| ka (k exact, such as π or 4) | same percentage uncertainty |

## Worked reminders

- Temperature rise: (78.0 ± 0.5) − (22.0 ± 0.5) = 56.0 ± 1.0 °C, which is 1.8 %.
- Sphere volume V = πd³/6 with d at 0.8 % gives V at 2.4 %.
- Wave speed v = √(T/μ) with T at 3 % and μ at 1 % gives v at ½(3 + 1) = 2 %.
- Frequency f = 1/T with T = 0.250 ± 0.005 s: 2.0 %, so f = 4.00 ± 0.08 Hz.
- Pendulum: g = 4π²l/T² has % in g = % in l + 2 × % in T.

## Graph method

1. Error bars on each point.
2. Best-fit line with balanced scatter.
3. Worst line through every error bar.
4. Gradients from large triangles.
5. Gradient uncertainty: |best − worst| (or half of steepest − shallowest; say which).
6. % uncertainty in gradient carries over to a quantity that equals the gradient or its reciprocal.

## Comparing with an accepted value

- Find the percentage difference.
- If it is smaller than the percentage uncertainty, the result agrees with the accepted value.
- If it is larger, a systematic error is likely; name a possible cause.

## Exam traps

- "Repeat readings to remove the zero error." Repeats do not remove systematic error.
- Calling readings "precise" because they have many decimal places.
- Adding percentages for a subtraction, or absolutes for a product.
- Doubling the percentage for a square root instead of halving it.
- Worst lines that miss an error bar.
- A final answer with more significant figures than the uncertainty supports.
- Saying "human error" with no specific cause.

## Quick self-test

1. State one example of a systematic error and one of a random error.
2. A balance reads 0.4 g with nothing on it. A sample reads 25.7 g. What is the mass?
3. Readings: 2.31, 2.35, 2.29, 2.33 s. Give the mean and its absolute uncertainty.
4. Distinguish between precision and accuracy.
5. A length is 0.840 ± 0.004 m. Find the percentage uncertainty.
6. Find the percentage uncertainty in r² if r has an uncertainty of 1.5 %.
7. Find the percentage uncertainty in √x if x has an uncertainty of 6 %.
8. A distance is 12.0 ± 0.1 cm and a time 4.00 ± 0.05 s. Find the percentage uncertainty in the speed.
9. Why is the time for 10 oscillations measured rather than one?
10. Define a worst line.
11. A measured value is 2.96 × 10⁸ m s⁻¹ and the accepted value 3.00 × 10⁸ m s⁻¹. Find the percentage difference.
12. The result in Question 11 has an uncertainty of 2 %. Does it agree with the accepted value?

### Answers

1. Systematic: a zero error (or a wrongly calibrated meter). Random: reaction time when using a stopwatch (or a fluctuating reading).
2. 25.7 − 0.4 = **25.3 g**.
3. Mean = 9.28 ÷ 4 = **2.32 s**; half range = (2.35 − 2.29) ÷ 2 = **0.03 s**.
4. Precision is how closely repeated readings agree; accuracy is how close a reading is to the true value.
5. 0.004 ÷ 0.840 × 100 = **0.48 %**.
6. 2 × 1.5 = **3.0 %**.
7. ½ × 6 = **3 %**.
8. 0.83 % + 1.25 % = **2.1 %**.
9. The uncertainty in the total time is shared over 10 periods, so the percentage uncertainty in one period is ten times smaller.
10. The steepest or shallowest straight line that still passes through all the error bars.
11. 0.04 ÷ 3.00 × 100 = **1.3 %**.
12. **Yes**: the 1.3 % difference is less than the 2 % uncertainty.

## Frequently asked questions

**Does OCR A Level Physics A expect standard deviations?**
No. The specification says a rigorous statistical treatment is not expected. Half the range, resolution and the combining rules are enough.

**How do I find the uncertainty in a gradient?**
Draw a best-fit line and a worst line through all the error bars, then use the difference in their gradients. Some mark schemes halve the difference between the steepest and shallowest lines, so say which method you use.

**What is the difference between percentage uncertainty and percentage difference?**
Percentage uncertainty describes the spread of your own measurement. Percentage difference compares your result with an accepted value. Comparing the two tells you whether the result agrees.
