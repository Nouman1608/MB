These questions cover section 5, Integration, of Unit P1: Pure Mathematics 1 in Pearson Edexcel International A Level Mathematics (YMA01), Specification Issue 3: indefinite integration as the reverse of differentiation, the constant of integration, integrating powers of x (n ≠ −1), and finding y = f(x) from f′(x) and a point. No question uses definite integrals, which belong to Pure Mathematics 2.

## Section A

**1.** Find ∫(10x⁴ − 3x² + 7) dx. **[3]**

**2.** Find ∫(8/x³ + 2√x) dx, x > 0. **[3]**

**3.** Find ∫(3x − 1)(x + 2) dx. **[3]**

**4.** Find ∫(x⁴ − 3)/x² dx, x ≠ 0. **[3]**

**5.** Given that ∫f(x) dx = 3x⁴ − 2x + c, find f(x). **[2]**

## Section B

**6.** A curve has gradient function dy/dx = 4x − 6/x², x ≠ 0, and passes through the point (2, 5). Find an equation of the curve. **[4]**

**7.** Given that f′(x) = (3 + √x)², x > 0, and that f(1) = 10, find f(x). **[5]**

**8.** **(a)** Write (6x³ − √x)/(2x) in the form axᵖ + bx^q, where a, b, p and q are constants. **[2]**

**(b)** Hence find ∫(6x³ − √x)/(2x) dx. **[3]**

**9.** The function f satisfies f″(x) = 6x − 2x⁻³, x > 0. Given that f′(1) = 0 and f(1) = 4, find f(x). **[5]**

**10.** The curve C passes through the point P(4, 9) and has gradient function dy/dx = 3√x − 2, x > 0.

**(a)** Find an equation of C. **[4]**

**(b)** Find an equation of the tangent to C at P. **[2]**

**11.** The height h cm of a plant t days after measurements begin increases at a rate given by dh/dt = 0.6t^(1/2) + 0.2. When t = 0, h = 5. Find the height of the plant after 16 days. **[4]**

**12.** A student writes ∫(2x + 1)² dx = (2x + 1)³/3 + c. Explain why this is wrong, and find the correct integral. **[3]**

**13.** A family of curves has gradient function dy/dx = 3x² − 3. Find the equation of the curve in the family that passes through the origin, and the equation of the one that passes through (2, 0). **[3]**

## Answers

**1.** Two terms correct [1]; all terms correct, 2x⁵ − x³ + 7x [1]; + c [1]. **∫ = 2x⁵ − x³ + 7x + c** **[3]**

**2.** Rewrite as 8x^(−3) + 2x^(1/2) [1]. 8x^(−2)/(−2) = −4x^(−2) and 2x^(3/2)/(3/2) = (4/3)x^(3/2) [1]. **∫ = −4x^(−2) + (4/3)x^(3/2) + c** [1]. **[3]**

*Examiner insight:* With a negative power, the division gives a negative coefficient: 8 ÷ (−2) = −4.

**3.** Expand: 3x² + 5x − 2 [1]. Integrate: x³ + (5/2)x² − 2x [1], **+ c** [1]. **[3]**

**4.** Divide each term: x² − 3x^(−2) [1]. Integrate: (1/3)x³ − 3x^(−1)/(−1) [1] = **(1/3)x³ + 3x^(−1) + c** [1]. **[3]**

**5.** Integration reverses differentiation, so f(x) is the derivative of 3x⁴ − 2x + c [1]. **f(x) = 12x³ − 2** [1]. **[2]**

**6.** y = 2x² − 6x^(−1)/(−1) = 2x² + 6x^(−1) + c [2] (one mark for each integrated term). Substituting (2, 5): 5 = 8 + 3 + c [1], so c = −6 and **y = 2x² + 6/x − 6** [1]. **[4]**

**7.** Expand: (3 + √x)² = 9 + 6x^(1/2) + x [1]. Integrate: 9x + 4x^(3/2) + ½x² + c [2]. f(1) = 9 + 4 + ½ + c = 10 [1], so c = −7/2 and **f(x) = ½x² + 4x^(3/2) + 9x − 7/2** [1]. **[5]**

*Examiner insight:* The bracket must be expanded before integrating; there is no rule in P1 for integrating (3 + √x)² as it stands.

**8. (a)** 6x³/(2x) = 3x² and √x/(2x) = ½x^(−1/2) [1], so the expression is **3x² − ½x^(−1/2)** [1].

**(b)** 3x² integrates to x³ [1]; −½x^(−1/2) integrates to −½ × 2x^(1/2) = −x^(1/2) [1]; **∫ = x³ − x^(1/2) + c** [1]. **[5]**

**9.** f′(x) = 3x² + x^(−2) + c₁ [1]. f′(1) = 3 + 1 + c₁ = 0, so c₁ = −4 [1]. f(x) = x³ − x^(−1) − 4x + c₂ [1]. f(1) = 1 − 1 − 4 + c₂ = 4, so c₂ = 8 [1]. **f(x) = x³ − 1/x − 4x + 8** [1]. **[5]**

*Examiner insight:* Find c₁ before the second integration; carrying an unknown c₁ into the second step makes the algebra harder and the conditions easy to misuse.

**10. (a)** y = 3x^(3/2)/(3/2) − 2x + c = 2x^(3/2) − 2x + c [2]. At P: 9 = 2 × 8 − 8 + c [1], so c = 1 and **y = 2x^(3/2) − 2x + 1** [1].

**(b)** At x = 4, dy/dx = 3 × 2 − 2 = 4 [1]. Tangent: y − 9 = 4(x − 4), so **y = 4x − 7** [1]. **[6]**

*Examiner insight:* Part (b) needs the gradient function given in the question, not the integrated equation from part (a).

**11.** h = 0.6t^(3/2)/(3/2) + 0.2t + c = 0.4t^(3/2) + 0.2t + c [2]. t = 0, h = 5 gives c = 5 [1]. At t = 16: h = 0.4 × 64 + 3.2 + 5 = **33.8 cm** [1]. **[4]**

**12.** Differentiating (2x + 1)³/3 gives 2(2x + 1)², not (2x + 1)², so the answer is wrong; in P1 the bracket must be expanded first [1]. (2x + 1)² = 4x² + 4x + 1 [1]. **∫ = (4/3)x³ + 2x² + x + c** [1]. **[3]**

**13.** y = x³ − 3x + c [1]. Through the origin: c = 0, so **y = x³ − 3x** [1]. Through (2, 0): 8 − 6 + c = 0, so c = −2 and **y = x³ − 3x − 2** [1]. **[3]**

## Where marks are usually lost

- Leaving out + c, or including it in a part that asks for f(x) after c has been found.
- Multiplying by the new power instead of dividing by it.
- Integrating a bracket or a fraction without expanding or splitting it first.
- Substituting the given point into the gradient function instead of the integrated equation.
- Losing the sign when dividing by a negative new power.
- Using a definite integral in P1, where every integral is indefinite.

## Frequently asked questions

**How do I know when to find c?**
When the question gives a point on the curve, or a value such as f(1) = 10, use it to find c and give the particular equation. Without such information, leave + c in the answer.

**What does "hence" mean in Question 8?**
Use the form you found in part (a) to do part (b). The question is built so that the rewritten form makes the integration a single step.

**Can a P1 integration question involve a tangent?**
Yes. Questions can combine topics within P1, so finding a curve by integration can lead into differentiation work such as finding a tangent, as in Question 10.
