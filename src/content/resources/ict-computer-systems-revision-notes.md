## Hardware and software

- **Hardware** — physical components.
- **System software** — runs the machine: operating system, utilities, device drivers, compilers.
- **Application software** — does a job for the user: word processor, spreadsheet, browser, database.

The **operating system** manages memory, files, processes, input/output devices and the user interface.

## RAM vs ROM — the most examined comparison

| | RAM | ROM |
|---|---|---|
| Volatile? | **Yes** — contents lost on power off | **No** — retained |
| Read/write | Read and write | Normally read only |
| Holds | Data and programs currently in use | Boot instructions (BIOS) |
| Size | Larger | Small |

ROM holds the **instructions that start the boot process** — not the operating system itself.

## Main components

| Part | Role |
|---|---|
| CPU | Processes instructions; control unit, ALU, registers |
| Secondary storage | Permanent, non-volatile file storage |
| Input devices | Get data in |
| Output devices | Present results |

**Embedded system** — a computer built into another device for one dedicated task (washing machine, engine management), program usually in ROM.

## User interfaces

| Interface | Advantages | Disadvantages |
|---|---|---|
| Command line (CLI) | Fast for experts, low resource use, powerful | Must memorise commands, unforgiving of typos |
| Graphical (GUI) | Intuitive, no commands to learn | Uses more memory and processing power |
| Gesture / voice | Hands-free, accessible | Unreliable in noise; limited vocabulary |

## Storage compared

| Type | Examples | Pros | Cons |
|---|---|---|---|
| Magnetic | HDD, tape | High capacity, cheap per GB | Moving parts, shock-sensitive |
| Optical | CD, DVD, Blu-ray | Cheap, portable | Low capacity, scratches easily |
| Solid state | SSD, USB, memory card | Fast, silent, robust, low power | Dearer per GB, finite write cycles |

Choosing storage in an exam = match the **property** to the **scenario**, and say why.

## Exam traps

- ROM does not store the operating system.
- RAM is not permanent storage.
- Don't confuse system software with application software.
- Naming a storage type without justifying it against the scenario scores half.
- A GUI is not "better" than a CLI — it depends on the user.

## Self-test

1. State two differences between RAM and ROM.
2. What is an embedded system? Give an example.
3. Which storage suits a field-research tablet, and why?
4. Give one advantage and one disadvantage of a command line interface.
5. Classify: operating system, spreadsheet, device driver.

**Answers:** 1. RAM is volatile and read/write; ROM is non-volatile and normally read-only. 2. A computer built into another device to perform one dedicated task, e.g. a washing machine controller or car engine management system. 3. Solid state — no moving parts so it survives being carried and dropped, low power for battery life, fast access, lightweight. 4. Advantage: fast and powerful for an experienced user, low resource use. Disadvantage: commands must be memorised and typing errors are unforgiving. 5. Operating system = system software; spreadsheet = application software; device driver = system software.
