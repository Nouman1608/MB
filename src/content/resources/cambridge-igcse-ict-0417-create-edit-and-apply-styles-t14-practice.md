**7.** A student has formatted one heading by hand exactly as her teacher wants. There are 20 other headings that use the style *Section Head*.

## Answers

**1.** The distance between the lines of text within a paragraph (1). **[1]**

**2.** B: italic. **[1]**

**3.** A serif font has small strokes at the ends of the letter lines, whereas a sans-serif font has none (1). **[1]**

**4.** Any two: shape of the bullet (1); alignment of the bullet (1); line spacing (1); indent (1). **[2]**

**5.** It changes automatically to match the new settings (1). **[1]**

**6.** Any one: the space is exact and the same throughout (1); it is part of the style, so it changes everywhere when the style is modified (1); it avoids empty paragraphs that can move to the top of a page (1). **[1]**

**7. (a)** Select the example heading (1) and use the option to update the *Section Head* style to match the selection, so all headings with that style change (1).

**(b)** The italic is copied into the style (1), so all 20 headings, and any future ones using the style, also become italic (1).

**(c)** Open the *Section Head* style's settings and modify each value directly, such as font, size and colour (1). **[5]**

**8. (a)** The font is serif (Times New Roman) instead of sans-serif (1); the alignment is left instead of centre (1).

**(b)** Correcting the style changes every caption that uses it at once (1), so no caption is missed and they all match exactly, which is quicker and keeps the document consistent (1). **[4]**

**9. (a)** The indent (1).

**(b)** Set the text indent further in than the bullet position, as a hanging indent (1), so that the second and later lines of each item line up with the start of the item's text, not with the bullet (1). **[3]**

**10. (a)** Serif (1), because the serifs help guide the eye along lines in long passages of printed text (1).

**(b)** Sans-serif (1), because the plain letter shapes are clear to read from a distance and are easy for young children to recognise (1). **[4]**

**11. (a)** Spacing after (1), for example 6 pt or 12 pt (1).

**(b)** Double line spacing adds space between every line within each paragraph, not just between paragraphs (1). **[3]**

**12.** Any four: a style stores one set of formatting instructions, such as font, size, colour, alignment and spacing (1); applying the style to every paragraph of the same kind gives them identical formatting (1); no settings are chosen again by hand, so nothing is forgotten or chosen slightly differently (1); when the style is modified, every paragraph using it changes together, so the document stays consistent after edits (1); headings, body text and lists each have their own style, so each type of text looks the same wherever it appears (1). Maximum 4. **[4]**

## Frequently asked questions

**Is updating a style the same as modifying it?**
No. Modifying changes the style's own settings; updating copies the formatting of text you have selected into the style. Both then change every paragraph that uses the style.

**If a task says "a sans-serif font", which one should I use?**
Any sans-serif face meets the instruction, such as Arial or Calibri, but use the same one everywhere the instruction applies.
