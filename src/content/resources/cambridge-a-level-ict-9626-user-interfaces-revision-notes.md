These notes condense **section 2.5 User interfaces** (Topic 2 Hardware and software) of the Cambridge International AS & A Level Information Technology 9626 syllabus for 2025, 2026 and 2027. AS Level content, examined in Paper 1 Theory. Full explanations and worked scenarios are in the [user interfaces study guide](/resources/cambridge-a-level-ict-9626-user-interfaces/); test yourself with the [user interfaces practice questions](/resources/cambridge-a-level-ict-9626-user-interfaces-practice/).

## The four types the syllabus names

Command line interface · graphical user interface · dialogue interface · gesture-based interface.

## Key terms

| Term | Meaning |
|---|---|
| User interface | The means by which a user and a computer system communicate |
| Prompt | The symbol or text showing a CLI is ready for a command |
| Syntax | The exact form a command must take to be understood |
| Script | A file of commands run together automatically |
| WIMP | Windows, icons, menus and pointer: the features of a typical GUI |
| Speech recognition | Software that converts spoken words into text the system can act on |
| Wake word | A spoken word that tells a voice assistant to start listening |
| Touch gesture | A movement on a touch screen, such as a swipe or pinch |
| Touch-free gesture | A movement in the air detected by cameras or sensors |

## Recall by type

**Command line interface.** Typed commands at a prompt; text replies.
- Uses: server administration, remote control over networks, scripting, programming, troubleshooting.
- Advantages: fast for experts; precise control; scriptable and repeatable; very low resource use.
- Disadvantages: commands must be learned; typing errors cause failures or wrong actions; unsuitable for beginners; no visual overview.

**Graphical user interface.** Windows, icons, menus and a pointer, or touch on screen objects.
- Uses: home and office computing, phones and tablets, kiosks, most applications.
- Advantages: easy to learn; options visible; several windows at once; visual editing of images and video.
- Disadvantages: more memory, processing and screen space; slow for repetitive tasks; options hidden in menus; harder for users with impaired sight without accessibility features.

**Dialogue interface.** Spoken or typed conversation; the system asks and responds.
- Uses: in-car control, voice assistants, smart homes, automated phone services, accessibility.
- Advantages: natural; hands and eyes free; helps users with limited sight or movement.
- Disadvantages: errors with accents and background noise; limited commands; unsuitable in quiet or public places; privacy concerns.

**Gesture-based interface.** Body, hand or finger movements, on a touch screen or in the air.
- Uses: phones and tablets, motion games and virtual reality, interactive displays, car controls, sterile operating theatres.
- Advantages: intuitive; no keyboard or mouse; touch-free hygiene; engaging.
- Disadvantages: misread or accidental gestures; tiring; needs sensors, cameras and good lighting; limited range of commands.

## Choose the interface: quick matching

| Scenario feature | Best fit | Reason |
|---|---|---|
| Expert repeating a task on many machines | CLI | Scripts automate it |
| Untrained public users | GUI | Visible options, little to learn |
| Hands busy or eyes on the road | Dialogue | Hands-free and eyes-free |
| Must not touch surfaces | Gesture (touch-free) | No contact needed |
| Very limited hardware | CLI | Few resources |
| Noisy factory floor | GUI or gesture | Speech would be misheard |
| User with limited hand movement | Dialogue | No fine movement needed |

## Comparison grid

| | CLI | GUI | Dialogue | Gesture |
|---|---|---|---|---|
| Input | Typed commands | Pointer, clicks, taps | Speech or typed conversation | Body, hand or finger movement |
| Learning needed | High | Low | Low | Low to medium |
| Expert speed | Very fast | Medium | Slow for complex tasks | Medium |
| Resources | Very few | High | Speech processing | Sensors and processing |
| Weak in | Untrained users | Repetitive tasks | Noise, privacy | Poor lighting, long use |

## Building a justified answer

Name the interface → give the feature that matters → link it to the user or setting → state the benefit. For example: "A gesture interface, **because** the surgeon can scroll through scans without touching anything, **so** the sterile area is not contaminated."

## Exam traps

- Calling every touch-screen action a gesture: tapping an icon is GUI use.
- Confusing a dialogue interface with a GUI dialogue box.
- Generic points ("user-friendly") that do not separate one interface from another.
- Forgetting the environment: noise, lighting, hygiene, privacy.
- Recommending without comparing alternatives when asked to evaluate.

## Self-test

1. What does WIMP stand for?
2. Why can a CLI be faster than a GUI for an expert?
3. Give one disadvantage of a CLI for a new office worker.
4. Why does a CLI suit an old server with little memory?
5. Give two features of a well-designed GUI.
6. Give one disadvantage of a GUI compared with a CLI.
7. Give two uses of a dialogue interface.
8. Why might a dialogue interface fail in a busy café?
9. Give one example of a touch gesture and one of a touch-free gesture.
10. Why does a gesture interface suit an operating theatre?
11. Give one disadvantage of a camera-based gesture interface.
12. Which interface suits a driver who wants to change the music, and why?

### Answers

1. Windows, icons, menus, pointer.
2. Commands can be typed directly and combined in scripts, avoiding many clicks through menus.
3. Commands and their exact syntax must be learned; one typing error can cause the wrong action.
4. It uses very little memory and processing power because it shows only text.
5. Any two: consistent menus and icons, familiar symbols, visual feedback, undo, context help.
6. It needs more memory and processing power (or repetitive tasks are slower).
7. Any two: in-car control, voice assistants, smart-home control, automated phone services, accessibility.
8. Background noise causes speech-recognition errors, and speaking aloud in public is awkward.
9. Touch: swipe or pinch to zoom. Touch-free: waving a hand in front of a sensor.
10. The surgeon can control the display without touching surfaces that are not sterile.
11. Gestures can be misread or need good lighting (or arms tire).
12. A dialogue interface, because spoken commands keep the driver's hands on the wheel and eyes on the road.
