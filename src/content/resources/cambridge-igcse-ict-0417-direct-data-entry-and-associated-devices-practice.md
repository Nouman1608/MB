## Section A: short answers

**1.** Name the direct data entry method used to read car number plates at the entrance to a car park. **[1]**

**2.** State what is meant by a *transcription error*. **[1]**

**3.** Which device reads data using radio waves?

A: OMR

B: bar code reader

C: RFID reader

D: magnetic stripe reader

**[1]**

**4.** Give **two** items of data that could be stored on the magnetic stripe of a hotel key card. **[2]**

**5.** Give **two** differences between a bar code and a QR code. **[2]**

## Section B: structured questions

**6.** A supermarket uses bar code readers at its checkouts.

**(a)** Describe how the bar code reader is used to find the price of an item. **[3]**

**(b)** Explain how using bar codes helps the supermarket with stock control. **[2]**

**7.** A farmer attaches RFID tags to the ears of 400 cattle.

**(a)** Give **two** items of data the tags could identify or store. **[2]**

**(b)** Explain **two** reasons why RFID is more suitable than bar codes for the cattle. **[2]**

**8.** A survey company posts paper questionnaires to 50,000 households. Each question has answer boxes to shade in.

**(a)** Name the direct data entry method used to read the returned questionnaires. **[1]**

**(b)** Give **two** advantages of this method for the company. **[2]**

**(c)** Give **two** reasons why some questionnaires might not be read correctly. **[2]**

**9.** A customer pays for a meal using chip and PIN.

**(a)** Describe the steps the customer follows. **[3]**

**(b)** Give **one** way the customer's PIN could be discovered by a criminal. **[1]**

**10.** A restaurant puts a QR code on each table so that customers can view the menu on their phones.

**(a)** Give **two** benefits of this for the restaurant. **[2]**

**(b)** Explain **one** security risk for customers. **[2]**

**11.** A law firm has 30 years of printed case documents. It wants to store them as searchable, editable files.

**(a)** Name the hardware and the software the firm needs. **[2]**

**(b)** Explain why the files must be checked after conversion. **[2]**

**12.** A library is replacing magnetic stripe membership cards and bar-coded books with RFID.

Discuss the advantages and disadvantages of this change for the library. **[6]**

## Answers

**1.** Optical Character Recognition (OCR), often called automatic number plate recognition. **[1]**

**2.** A mistake made when data is copied or typed in by hand, such as a wrong digit. **[1]**

**3.** C: RFID reader. **[1]**

**4.** Any two: room number (1); check-out or expiry date and time (1); guest or booking reference (1). **[2]**

**5.** Any two: a bar code is made of lines whereas a QR code is a two-dimensional pattern of squares (1); a QR code holds much more data than a bar code (1); a QR code can be read from any angle (1); a QR code can still be read if partly damaged (1); QR codes can be read by most phone cameras (1). **[2]**

**6. (a)** The cashier moves the item past the reader so that the bar code faces it (1); the reader detects the pattern of lines and converts it into the product number (1); the number is used to look up the item's record in the database, which gives the price and description (1). **[3]**

**(b)** Each sale is recorded automatically, so the stock level in the database is reduced by one (1); when the stock falls to a set level, more can be reordered automatically or a warning produced (1). **[2]**

**7. (a)** Any two: a unique animal identification number (1); date of birth (1); owner or farm (1); breed (1); vaccination or medical records (1). **[2]**

**(b)** Any two: RFID needs no line of sight, so tags can be read without holding a scanner against a moving animal (1); several animals can be read at once as they pass through a gate (1); tags are hard-wearing, whereas a bar code label could be covered in mud or damaged (1); data on some tags can be updated (1). **[2]**

**8. (a)** Optical Mark Recognition (OMR). **[1]**

**(b)** Any two: very fast for a large number of forms (1); accurate, with no typing errors (1); fewer staff needed to process results (1); results can be analysed automatically (1). **[2]**

**(c)** Any two: marks made with the wrong type of pen or too faintly (1); marks outside the boxes (1); more than one box shaded for a question (1); forms folded, torn or dirty (1). **[2]**

**9. (a)** The customer inserts the card into the reader (1); the chip is read and the customer checks the amount (1); the customer types their PIN on the keypad, which is checked against the card before the payment is accepted (1). **[3]**

**(b)** Any one: someone watching as the PIN is typed (shoulder surfing) (1); a hidden camera recording the keypad (1). **[1]**

**10. (a)** Any two: menus can be updated without reprinting (1); saves printing costs (1); fewer menus to clean between customers (1); can link to online ordering, reducing staff time (1). **[2]**

**(b)** A criminal could stick a fake QR code over the real one (1), which takes customers to a harmful website that may steal their details or install malware (1). **[2]**

**11. (a)** Hardware: a scanner (1). Software: Optical Character Recognition (OCR) software (1). **[2]**

**(b)** OCR may misrecognise characters (1) because of faded or damaged originals, unusual fonts or handwritten notes, so errors would be stored in legal documents (1). **[2]**

**12.** Advantages, up to 4: several books can be read at once, so borrowing is faster (1); no line of sight needed, so books need not be opened to find a code (1); self-service borrowing and returns are easier, freeing staff (1); RFID gates at the exit can detect books not borrowed, reducing theft (1); tags are harder-wearing than magnetic stripes or bar code labels (1); stock-taking is faster because shelves can be scanned quickly (1). Disadvantages, up to 4: tags and readers cost more than bar codes and stripes (1); every book must be tagged, which takes staff time (1); tags may be read by unauthorised readers, raising privacy concerns (1); members need new cards (1); metal shelving can interfere with signals (1). **[6]** Award a maximum of 6 marks from these points; one-sided answers are limited to 4 marks.

## Frequently asked questions

**Is OCR an input device?**
OCR is software that works with a scanner or camera. In the 0417 list it is named as "Optical Character Recognition/Reader", so you can refer to the system as an OCR reader.

**Do contactless cards count as RFID?**
Yes, in this subtopic contactless payment is a use of RFID technology, which is why the card only needs to be held near the reader.
