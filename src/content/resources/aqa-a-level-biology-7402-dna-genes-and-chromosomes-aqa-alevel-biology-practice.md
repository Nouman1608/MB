Teaching is in the [DNA, genes and chromosomes study guide](/resources/aqa-a-level-biology-7402-dna-genes-and-chromosomes-aqa-alevel-biology/) and the [DNA, genes and chromosomes revision notes](/resources/aqa-a-level-biology-7402-dna-genes-and-chromosomes-aqa-alevel-biology-revision-notes/).

## Section A: short questions

**1.** **(a)** Name the proteins associated with DNA in the nucleus of a eukaryotic cell. **[1]**

**(b)** Define the term *locus*. **[1]**

**2.** Give two similarities between the DNA in a mitochondrion and the DNA in a prokaryotic cell. **[2]**

**3.** A student wrote: "Every gene codes for a protein." Explain why this statement is not correct. **[2]**

**4.** Calculate the minimum number of DNA bases in a coding sequence for a polypeptide of 312 amino acids, including one stop triplet. **[1]**

**5.** There are four different bases in DNA and 20 different amino acids in proteins. Explain why each amino acid must be coded for by at least three bases. **[2]**

**6.** On the coding strand of DNA, the triplets GGA, GGC, GGG and GGT all code for the amino acid glycine.

**(a)** Name the property of the genetic code that these data illustrate. **[1]**

**(b)** A mutation changes a GGA triplet in a gene to GGC. Explain the effect on the polypeptide. **[2]**

## Section B: longer questions

**7.** A section of DNA 15 bases long codes for part of a polypeptide.

**(a)** How many amino acids would this section code for if the code were non-overlapping, and how many if it were overlapping, with a new triplet starting at every base? **[2]**

**(b)** In an experiment, changing the eighth base of a sequence like this changed only one amino acid in the polypeptide. Explain what this suggests about the genetic code. **[2]**

**8.** A eukaryotic gene is 2,400 bases long. It contains three introns of 410, 520 and 648 bases.

**(a)** Calculate the number of bases in the exons. **[1]**

**(b)** Calculate the percentage of the gene made up of exons. Give your answer to 3 significant figures. **[1]**

**(c)** Assume that all exon bases code for amino acids except for one stop triplet. Calculate the number of amino acids in the polypeptide. **[2]**

**9.** The human gene for the hormone insulin can be inserted into bacteria, which then make human insulin with the same amino acid sequence. Explain which property of the genetic code makes this possible. **[2]**

**10.** Two organisms were studied. In organism P, about 88% of the DNA codes for polypeptides. In organism Q, less than 5% does.

**(a)** Suggest which organism is a eukaryote. **[1]**

**(b)** Explain your answer, using your knowledge of eukaryotic DNA. **[2]**

**11.** Explain why DNA in the nucleus of a eukaryotic cell is associated with histones. **[2]**

**12.** Describe the ways in which the nuclear DNA of a eukaryote contains base sequences that do not code for polypeptides. **[4]**

## Answers

**1. (a)** Histones [1]. **[1]**

**(b)** The fixed position that a gene occupies on a particular DNA molecule [1]. **[1]**

**2.** Any two [1 each]: both short; both circular; both not associated with proteins (histones). **[2]**

**3.** Some genes code for a functional RNA [1], such as ribosomal RNA or transfer RNA, which is not translated into a polypeptide [1]. Accept: genes code for polypeptides, and a protein may contain more than one polypeptide. **[2]**

**4.** 312 × 3 + 3 = **939 bases** [1]. **[1]**

**5.** A code of two bases gives only 4² = 16 combinations, too few for 20 amino acids [1]; three bases give 4³ = 64 combinations, which is enough [1]. **[2]**

**6. (a)** Degenerate [1]. **[1]**

**(b)** GGC also codes for glycine, so the same amino acid is coded for [1]; the primary structure of the polypeptide is unchanged [1]. **[2]**

**7. (a)** Non-overlapping: 15 ÷ 3 = **5 amino acids** [1]. Overlapping: 15 − 2 = **13 amino acids** [1]. **[2]**

**(b)** In an overlapping code, one base would be part of three triplets, so changing it would change up to three amino acids [1]. Only one changed, so each base is part of only one triplet: the code is non-overlapping [1]. **[2]**

*Examiner insight:* State what would happen under the alternative model, then compare with the result.

**8. (a)** Introns = 410 + 520 + 648 = 1,578 bases; exons = 2,400 − 1,578 = **822 bases** [1]. **[1]**

**(b)** 822 ÷ 2,400 × 100 = **34.3%** [1]. **[1]**

**(c)** Coding bases = 822 − 3 = 819 [1]; 819 ÷ 3 = **273 amino acids** [1]. **[2]**

**9.** The genetic code is universal [1]: each triplet codes for the same amino acid in bacteria as in humans, so the gene is translated into the same amino acid sequence [1]. **[2]**

**10. (a)** Organism Q [1]. **[1]**

**(b)** Eukaryotic nuclear DNA contains non-coding multiple repeats between genes [1] and introns within genes [1], so only a small proportion codes for polypeptides. **[2]**

**11.** Nuclear DNA molecules are very long [1], and winding them around histones (and coiling further) packs them into the small nucleus [1]. **[2]**

**12.** There are non-coding multiple repeats of base sequences [1] between genes [1]. Within genes, only exons code for amino acid sequences [1]; exons are separated by non-coding introns [1]. Accept: some genes code for functional RNA rather than polypeptides. **[4]**

## Where marks are usually lost

- Writing "a gene codes for a protein" without mentioning polypeptides or functional RNA.
- Leaving histones out of the definition of a chromosome.
- Mixing up degenerate and non-overlapping.
- Forgetting the stop triplet in base counts, or dividing by three before subtracting it.
- Saying introns are found in prokaryotic genes.
