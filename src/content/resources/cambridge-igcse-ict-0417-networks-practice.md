**1.** Name the hardware that must be fitted to a computer before it can connect to any network. **[1]**

**2.** Which device joins two network segments so that they act as one network?

A: bridge

B: hub

C: NIC

D: wireless access point

## Section B: structured questions

**6.** A family's home network has a router, two laptops, a smart TV and three phones.

**(a)** Explain why the router needs to store the addresses of the devices on the network. **[2]**

**(b)** Describe how the router routes a data packet sent from a laptop to a website. **[3]**

**7.** A small office replaces its hub with a switch.

**(a)** Explain how a switch handles data differently from a hub. **[2]**

**(b)** Give **two** benefits of the change for the office. **[2]**

**8.** A student buys wireless headphones for her phone.

**(a)** Name the wireless technology most likely to be used. **[1]**

**(b)** Describe the steps needed to connect the headphones for the first time. **[3]**

**(c)** Explain why wi-fi would be used, instead, to connect the phone to the internet at home. **[2]**

**9.** A design company stores all its project files in cloud storage.

**(a)** Describe how cloud storage lets three designers work on the same file. **[2]**

**(b)** Give **two** advantages of cloud storage compared with storing the files on each designer's own computer. **[2]**

**(c)** Describe **two** issues the company should consider. **[2]**

**10.** A car manufacturer gives its parts suppliers access to its stock levels, but not to staff records.

**(a)** Name the type of network environment used. **[1]**

**(b)** Describe how access to the stock levels would be controlled. **[2]**

**11.** A school has a cabled network in each of its two buildings on one site, wireless access in the library, and a link to the local education office in another town.

Identify which part of this network is a LAN, which is a WLAN and which is a WAN, and give **one** reason for each. **[6]**

**12.** Discuss the advantages and disadvantages of using cloud storage rather than an external portable hard drive to back up a small business's files. **[6]**

## Answers

**1.** Network Interface Card (NIC). **[1]**

**2.** A: bridge. **[1]**

**3.** A small unit of data, sent across a network, that carries the address of its destination. **[1]**

**4.** Any two: both are wireless (1); both use radio waves (1); both need the devices to be within range (1); both can be secured with passwords, pairing or encryption (1); both remove the need for cables (1). **[2]**

**5.** Any two: sharing timetables and homework (1); internal news and notices for staff and students (1); storing school policies and forms (1); access to learning resources only for school members (1). **[2]**

**6. (a)** Data arriving from the internet must be delivered to the correct device (1); the stored addresses let the router send each packet to the laptop, TV or phone that requested it (1). **[2]**

**(b)** The data is split into packets, each carrying the destination address (1); the router reads the destination address of each packet and forwards it towards the internet along the best available route (1); the packets may take different routes and are put back in order at the destination (1). **[3]**

**7. (a)** A hub sends incoming data to every connected device (1), whereas a switch learns which device is connected to each port and sends data only to the intended device (1). **[2]**

**(b)** Any two: less unnecessary traffic, so the network is faster (1); data is not sent to devices that should not receive it, improving security (1); fewer data collisions (1). **[2]**

**8. (a)** Bluetooth. **[1]**

**(b)** Turn on Bluetooth on the phone and switch the headphones to pairing or discoverable mode (1); select the headphones from the list of devices found on the phone (1); confirm the pairing, entering a code if asked, so the devices connect automatically in future (1). **[3]**

**(c)** Wi-fi has a longer range and a faster data rate than Bluetooth (1), and it connects the phone to the home network and, through the router, to the internet (1). **[2]**

**9. (a)** The file is stored once on the provider's servers (1); each designer is given permission or a link, and opens and edits the same file over the internet, with changes saved for all (1). **[2]**

**(b)** Any two: files can be accessed from any device with internet access, for example at clients' offices (1); everyone works on the latest version (1); the provider handles backups, so files survive if a computer fails (1); no need to buy extra storage hardware (1). **[2]**

**(c)** Any two: no internet means no access to the files (1); security depends on the provider, and the files could be hacked (1); subscription costs continue (1); large files are slow to upload or download (1); data may be stored in another country with different laws (1). **[2]**

**10. (a)** Extranet. **[1]**

**(b)** Each supplier is given a username and password (1), and their account is only allowed to see the stock-level pages, not other parts of the intranet such as staff records (1). **[2]**

**11.** LAN: the cabled network in each building (1), because devices are connected by cables within one site (1). WLAN: the wireless access in the library (1), because devices connect through wireless access points, without cables (1). WAN: the link to the education office (1), because it connects networks over a large geographical area, in another town (1). **[6]**

**12.** Cloud storage, advantages, up to 4: files are stored off-site, so they survive a fire, flood or theft at the business (1); the provider maintains and backs up the servers (1); files can be restored from anywhere with internet access (1); backups can happen automatically (1); no hardware to buy, lose or damage (1). Cloud storage, disadvantages, up to 4: no internet access means files cannot be backed up or restored (1); ongoing subscription cost (1); security of the data depends on the provider (1); uploading large amounts of data can be slow (1); portable drive is a one-off cost and is under the business's own control (1). **[6]** Award a maximum of 6 marks from these points; one-sided answers are limited to 4 marks.

## Frequently asked questions

**What is the difference between a bridge and a router?**
A bridge joins two segments of the same network so they act as one. A router joins different networks, such as a home LAN and the internet, and uses addresses to route data packets between them.

**Can I describe the internet as a WAN?**
Yes. The internet is the largest example of a wide area network, connecting networks all over the world.
