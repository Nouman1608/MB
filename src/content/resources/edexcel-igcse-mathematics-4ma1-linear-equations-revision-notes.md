Quick-recall notes for section 2.4, Linear equations, in Pearson Edexcel International GCSE Mathematics A (4MA1). Both statements (2.4 A solving, 2.4 B setting up from data) are Foundation Tier content that the Higher Tier also covers, so these notes apply to both tiers; Higher papers tend to use more fractions. For explanations and worked examples, read the [linear equations study guide](/resources/edexcel-igcse-mathematics-4ma1-linear-equations/); for exam-style questions, use the [linear equations practice questions](/resources/edexcel-igcse-mathematics-4ma1-linear-equations-practice/).

## The five-step method

```
1  Clear fractions     × every term by the LCM of the denominators
2  Expand brackets     watch a minus in front
3  Collect             unknowns on one side, numbers on the other
4  Divide              by the coefficient of the unknown
5  Check               substitute into the ORIGINAL equation
```

## Key terms

| Term | Meaning |
|---|---|
| Linear equation | An equation in which the unknown has power 1 only |
| Solution (root) | The value of the unknown that makes the equation true |
| Coefficient | The number multiplying the unknown, e.g. −3 in 7 − 3x |
| Fractional coefficient | A coefficient that is a fraction, e.g. x/4 has coefficient 1/4 |
| LCM | Lowest common multiple of the denominators, used to clear fractions |
| Inverse operation | The operation that undoes another (+ and −, × and ÷) |
| Form an equation | Write an equation from information in words or a diagram |

## Patterns to recognise

| Type | Example | Key step | Answer |
|---|---|---|---|
| Brackets | 3(2x − 1) − 2(x + 4) = 9 | −2 × 4 = −8 | x = 5 |
| Both sides | 7 − 3x = 2x + 22 | add 3x | x = −3 |
| Fractional coefficients | x/4 + x/6 = 5 | × 12 | x = 12 |
| Fraction minus fraction | (3x − 1)/5 − (x + 2)/2 = 1 | × 10, bracket each numerator | x = 22 |
| Three fractions | (x − 4)/3 + (2x + 1)/4 = 7/6 | × 12, including 7/6 → 14 | x = 2.7 |
| Unknown in denominator | 12/(2x − 1) = 4/(x + 2) | cross-multiply | x = −7 |

## Signs after clearing fractions

```
−(x + 2)/2  × 10   →   −5(x + 2)   →   −5x − 10
−(x − 3)/4  × 12   →   −3(x − 3)   →   −3x + 9
```

The fraction line is a bracket. Write the bracket in before you expand.

## Forming equations from data

1. "Let ... be x", with units.
2. Write every other quantity in terms of x.
3. Use the fact given: total, perimeter, angle sum, "the same as", "twice as many".
4. Solve.
5. Answer the actual question in context.

| Fact in words | Equation pattern |
|---|---|
| Angles of a triangle | sum = 180 |
| Angles of a quadrilateral | sum = 360 |
| Angles on a straight line | sum = 180 |
| Perimeter of a rectangle | 2(l + w) = P |
| "Three consecutive integers add to S" | n + (n + 1) + (n + 2) = S |
| "A gives B £k and then they are equal" | A − k = B + k |
| "In t years' time" | add t to every age |

## Exam traps

- **Partial multiplication.** Every term is multiplied, including whole numbers and the right-hand side.
- **Dividing upside down.** 4x = 20 gives 5; 20x = 4 gives 1/5.
- **Negative answers.** −15 = 5x gives x = −3; negative answers are normal.
- **Answer the question.** If you are asked for the angles, x = 50 alone is incomplete.
- **Ages.** "In 12 years" adds 12 to both people's ages, not just one.
- **No working.** An unsupported answer cannot gain method marks if it is wrong.
- **Equations that are not linear.** If x² appears and does not cancel, use quadratic methods instead.

## Checking

Substitute into the original equation, not into a later line, because a later line may already contain the error. For a word problem, also check the answer against the story (for example, that lengths are positive).

## Equations with decimals

Decimals can be cleared like fractions: multiply every term by 10 or 100.

```
0.4x + 1.3 = 0.9x − 2.2      × 10
4x + 13 = 9x − 22
35 = 5x,  x = 7
```

Alternatively, collect the terms directly on a calculator paper; the answer is the same. Do not round a decimal coefficient before solving.

## Self-test

1. Solve 4(x + 2) − 3(x − 1) = 15.
2. Solve 9 − 4x = x + 29.
3. Solve x/3 + x/5 = 16.
4. Solve (2x + 1)/3 − (x − 2)/4 = 2.
5. Solve (x + 1)/2 + (x − 3)/5 = 3/10.
6. Solve 6/(x + 4) = 2/(x − 2).
7. Solve 5 − 2(3 − x) = 11.
8. A triangle has angles (x + 15)°, 2x° and (3x − 15)°. Find x and the largest angle.
9. A square has sides of (2x − 3) cm and a perimeter of 44 cm. Find x.
10. Ella has £18 more than Sam. Together they have £94. How much does Sam have?
11. Three consecutive integers add to 141. Find them.
12. Solve 0.3x − 1.6 = 0.1x + 0.8.

### Answers

1. 4x + 8 − 3x + 3 = 15, so **x = 4**.
2. −20 = 5x, so **x = −4**.
3. × 15: 5x + 3x = 240, so **x = 30**.
4. × 12: 4(2x + 1) − 3(x − 2) = 24, so 5x + 10 = 24 and **x = 2.8**.
5. × 10: 5(x + 1) + 2(x − 3) = 3, so 7x − 1 = 3 and **x = 4/7**.
6. 6(x − 2) = 2(x + 4), so 4x = 20 and **x = 5**.
7. 5 − 6 + 2x = 11, so 2x = 12 and **x = 6**.
8. 6x = 180, so **x = 30**; the angles are 45°, 60° and 75°, so the largest is **75°**.
9. 4(2x − 3) = 44, so 8x = 56 and **x = 7**.
10. s + (s + 18) = 94, so 2s = 76 and Sam has **£38**.
11. 3n + 3 = 141, so n = 46: **46, 47, 48**.
12. × 10: 3x − 16 = x + 8, so 2x = 24 and **x = 12**.
