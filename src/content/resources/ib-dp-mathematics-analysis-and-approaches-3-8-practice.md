These questions cover syllabus section 3.8 of IB DP Mathematics: Analysis and Approaches (first assessment 2021): solving trigonometric equations in a finite interval, graphically and analytically, including quadratics in sin x, cos x or tan x. They are SL and HL. Questions are labelled "(calculator-free)" or "(calculator allowed)". Give exact answers where the question is calculator-free, and otherwise 3 significant figures. The methods are in the [3.8 study guide](/resources/ib-dp-mathematics-analysis-and-approaches-3-8/) and the [3.8 revision notes](/resources/ib-dp-mathematics-analysis-and-approaches-3-8-revision-notes/).

## Section A

**1.** (calculator-free) Solve 2 cos x + 1 = 0 for 0 ≤ x ≤ 2π. **[3]**

**2.** (calculator-free) Solve tan 3x = −1 for 0 ≤ x ≤ π/2. **[3]**

**3.** (calculator-free) Solve 4sin²x = 3 for 0 ≤ x ≤ π. **[3]**

**4.** (calculator-free) Solve cos(x + π/4) = √3/2 for 0 ≤ x ≤ 2π. **[4]**

**5.** (calculator allowed) Solve 3 sin x = 1 for 0° ≤ x ≤ 360°. **[3]**

**6.** (calculator-free) Find the number of solutions of sin 2x = 0.9 for 0 ≤ x ≤ 3π. Justify your answer. **[2]**

## Section B

**7.** (calculator allowed) Solve 2 sin 2x = 3 sin x for 0 ≤ x ≤ 2π. **[6]**

**8.** (calculator allowed)

**(a)** Show that the equation 6cos²x + sin x − 5 = 0 can be written as 6sin²x − sin x − 1 = 0. **[2]**

**(b)** Hence solve 6cos²x + sin x − 5 = 0 for 0 ≤ x ≤ 2π. **[5]**

**9.** (calculator-free) Solve √3 sin x + cos x = 0 for 0 ≤ x ≤ 2π. **[4]**

**10.** (calculator allowed)

**(a)** Solve 3 sin x = x − 1 for −π ≤ x ≤ π. **[3]**

**(b)** Hence solve 3 sin x > x − 1 for −π ≤ x ≤ π. **[2]**

**11.** (calculator-free) *Invented data.* The depth of water, h metres, in a channel t hours after midnight is modelled by h(t) = 12 + 5 sin(πt/6), for 0 ≤ t ≤ 24. Find all the times at which the depth is 14.5 m. **[4]**

**12.** (calculator-free) Solve cos 2x = cos x for 0 ≤ x ≤ 2π. **[5]**

## Answers

**1.** cos x = −1/2 [1]; **x = 2π/3** [1] and **x = 4π/3** [1]

**2.** 0 ≤ 3x ≤ 3π/2 [1]. tan 3x = −1 gives 3x = 3π/4 (7π/4 is outside) [1], so **x = π/4** [1]

*Examiner insight:* Listing 3x = 7π/4 and then x = 7π/12 is a common slip; 7π/12 > π/2, so it is outside the interval.

**3.** sin x = ±√3/2 [1]. On 0 ≤ x ≤ π, sin x ≥ 0, so sin x = −√3/2 has no solutions [1]. **x = π/3, 2π/3** [1]

**4.** π/4 ≤ x + π/4 ≤ 9π/4 [1]. cos u = √3/2 gives u = 11π/6 or 13π/6 in this interval (π/6 is too small) [1]. x = 11π/6 − π/4 = **19π/12** [1] and x = 13π/6 − π/4 = **23π/12** [1]

*Examiner insight:* The solution u = π/6 gives a negative x, which is why the shifted interval must be written down first.

**5.** sin x = 1/3 [1], so x = **19.5°** [1] or 180° − 19.47° = **161°** [1]

**6.** 0 ≤ 2x ≤ 6π, which is three complete cycles of sine [1]. Since 0 < 0.9 < 1, each cycle gives two solutions, so there are **6 solutions** [1]

**7.** 4 sin x cos x = 3 sin x [1], so sin x(4 cos x − 3) = 0 [1]. sin x = 0 gives **x = 0, π, 2π** [1]. cos x = 3/4 [1] gives **x = 0.723** [1] and **x = 2π − 0.723 = 5.56** [1]

*Examiner insight:* Dividing both sides by sin x loses three of the five solutions, and with them three marks.

**8. (a)** cos²x = 1 − sin²x, so 6(1 − sin²x) + sin x − 5 = 0 [1], giving −6sin²x + sin x + 1 = 0, that is **6sin²x − sin x − 1 = 0** [1]

**(b)** (2 sin x − 1)(3 sin x + 1) = 0 [1]. sin x = 1/2 gives **x = π/6, 5π/6** [1]. sin x = −1/3 [1] gives x = π + 0.3398 = **3.48** [1] and x = 2π − 0.3398 = **5.94** [1]

*Examiner insight:* The calculator gives −0.340 for sin x = −1/3, which is outside the interval; the two solutions come from π − (−0.340) and 2π + (−0.340).

**9.** If cos x = 0 then sin x = ±1 and the left side is ±√3 ≠ 0, so dividing by cos x is safe [1]. tan x = −1/√3 = −√3/3 [1]. tan is negative in the second and fourth quadrants: **x = 5π/6** [1] and **x = 11π/6** [1]

**10. (a)** Graph y = 3 sin x and y = x − 1 for −π ≤ x ≤ π [1]. Intersections at **x = −1.87, −0.538** [1] and **2.58** [1]

**(b)** From the graphs, 3 sin x is above x − 1 to the left of the first root and between the second and third roots: **−π ≤ x < −1.87** [1] or **−0.538 < x < 2.58** [1]

*Examiner insight:* Check (b) with one value: at x = 0, 3 sin 0 = 0 > −1, so the middle interval is correct.

**11.** 12 + 5 sin(πt/6) = 14.5 gives sin(πt/6) = 1/2 [1]. 0 ≤ πt/6 ≤ 4π [1]. πt/6 = π/6, 5π/6, 13π/6, 17π/6 [1], so **t = 1, 5, 13, 17**: 01:00, 05:00, 13:00 and 17:00 [1]

**12.** 2cos²x − 1 = cos x [1], so 2cos²x − cos x − 1 = 0 and (2 cos x + 1)(cos x − 1) = 0 [1]. cos x = 1 gives **x = 0, 2π** [1]. cos x = −1/2 gives **x = 2π/3** [1] and **x = 4π/3** [1]

*Examiner insight:* The endpoint solutions x = 0 and x = 2π both count because the interval includes its endpoints.

## Where marks are usually lost

- Not rewriting the interval for 3x or x + π/4 before listing solutions.
- Dividing by sin x or cos x without checking it cannot be zero.
- Keeping only the calculator's value and forgetting the partner solution.
- Leaving out endpoint solutions, such as x = 0 and x = 2π.
- Missing a solution from the second factor of a quadratic.
- For inequalities, giving the intersections without the intervals between them.
