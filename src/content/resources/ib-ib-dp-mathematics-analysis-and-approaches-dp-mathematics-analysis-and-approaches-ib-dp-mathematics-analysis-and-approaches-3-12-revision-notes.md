These notes condense syllabus section 3.12 of IB DP Mathematics: Analysis and Approaches (first assessment 2021), which is HL only (AHL): the concept of a vector, position and displacement vectors, base vectors and components, the algebraic and geometric operations, and proofs of geometrical properties using vectors. The full explanations are in the [3.12 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-12/); test yourself afterwards with the [3.12 practice questions](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-12-practice/). Vectors are written in rows here; write them as columns in the exam.

## Core facts

| Idea | Result |
|---|---|
| Base vectors | i = (1, 0, 0), j = (0, 1, 0), k = (0, 0, 1) |
| Components | v₁i + v₂j + v₃k = (v₁, v₂, v₃) |
| Position vector of A | OA = a, with the coordinates of A as components |
| Displacement | AB = b − a (end minus start) |
| Distance AB | \|b − a\| |
| Magnitude | \|v\| = √(v₁² + v₂² + v₃²) |
| Unit vector | v/\|v\| |
| Vector of length L along v | (L/\|v\|) v |
| Parallel | w = kv for some scalar k ≠ 0 |
| Collinear A, B, C | AB parallel to BC (or AC) and a common point |
| Midpoint of AB | (a + b)/2 |
| Point P with AP : PB = m : n | p = a + (m/(m + n))(b − a) |

## Key terms

| Term | Meaning |
|---|---|
| Vector | A quantity with magnitude and direction |
| Scalar | A quantity with magnitude only |
| Directed line segment | An arrow representing a vector; equal arrows (same length and direction) are the same vector |
| Zero vector 0 | The vector with all components 0 |
| Negative vector −v | Same magnitude as v, opposite direction |
| Unit vector | A vector of magnitude 1 |
| Collinear | Lying on one straight line |

## Geometric rules

- **Triangle law:** AB + BC = AC. Chains of vectors "join up": AB + BC + CD = AD.
- **Parallelogram law:** a + b is the diagonal of the parallelogram with sides a and b from one point; a − b is the other diagonal (from the end of b to the end of a).
- **Going backwards:** BA = −AB.
- **Scalar multiples:** 2v is twice as long as v in the same direction; −½v is half as long in the opposite direction.

## Methods

**Find a fourth vertex of a parallelogram ABCD**

1. Use AD = BC (sides in order).
2. d = a + c − b.
3. Check AB = DC.

**Show three points are collinear**

1. Find two displacement vectors sharing a point, such as AB and BC.
2. Show one is a scalar multiple of the other.
3. State that they share B, so A, B and C are collinear.

**Solve for an unknown in a magnitude**

1. Square: |v|² = v₁² + v₂² + v₃².
2. Solve the resulting equation (often a quadratic, so expect two answers).

**Vector proof**

1. Define base vectors (a, b, …) and draw a diagram.
2. Express each required vector in terms of them.
3. Show a scalar multiple, equal vectors or equal position vectors.
4. Conclude in words.

## Worked reminders

- 2(1, −3, 4) − (5, 0, −2) = (−3, −6, 10).
- |(6, −2, 3)| = √49 = 7, so the unit vector is (6/7, −2/7, 3/7).
- (−4, 6, −10) = −2(2, −3, 5), so the two vectors are parallel and point in opposite directions.
- A(3, 1, −2), B(5, −3, 2): midpoint (4, −1, 0); |AB| = √(4 + 16 + 16) = 6.
- In triangle OAB with OA = a and OB = b, if M is the midpoint of AB then OM = a + ½(b − a) = ½(a + b).
- 5j − k = (0, 5, −1).

## Exam traps

- **Order in displacement.** AB = b − a, not a − b.
- **Collinear needs a point.** Parallel vectors alone only give parallel lines.
- **Magnitudes don't add.** |a + b| ≤ |a| + |b|, with equality only for the same direction.
- **Missing components.** 2i − 3k has a zero j-component.
- **Unit vector check.** Its magnitude must be exactly 1.
- **Two answers.** Equations like |v| = 3 with an unknown component usually give two values.
- **Vertex order.** In parallelogram PQRS, PQ = SR, not PQ = RS.

## Self-test

1. Write 3i − j + 2k in component form.
2. Given a = (2, 0, −1) and b = (1, 3, 4), find 3a − b.
3. A(1, 4, −2), B(3, 0, 2). Find AB and |AB|.
4. Find the unit vector in the direction of (0, 3, −4).
5. Find the vector of magnitude 14 in the direction of (2, 3, 6).
6. Are (3, −6, 9) and (−1, 2, −3) parallel? Explain.
7. Find k if (k, 4, 2) is parallel to (6, 12, 6).
8. Find the midpoint of A(−2, 5, 7) and B(4, −1, 3).
9. ABCD is a parallelogram with A(0, 0, 0), B(2, 1, 3) and C(5, 2, 4). Find D.
10. Find t if |(t, 1, 2)| = 3.
11. Simplify AB + BC − AC.
12. P divides AB, A(0, 3, 6), B(9, 0, 0), with AP : PB = 2 : 1. Find P.

### Answers

1. (3, −1, 2).
2. (5, −3, −7).
3. AB = (2, −4, 4); |AB| = 6.
4. (0, 3/5, −4/5).
5. |v| = 7, so 2(2, 3, 6) = (4, 6, 12).
6. Yes: (3, −6, 9) = −3(−1, 2, −3).
7. (k, 4, 2) = (1/3)(6, 12, 6), so k = 2.
8. (1, 2, 5).
9. d = a + c − b = (3, 1, 1).
10. t² + 5 = 9, so t = ±2.
11. AC − AC = 0, the zero vector.
12. p = a + (2/3)(b − a) = (6, 1, 2).
