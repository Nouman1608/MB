Condensed notes for AQA AS and A-level Biology (7401/7402) section **3.4.1 DNA, genes and chromosomes**. Explanations and worked examples on overlap and gene length are in the [DNA, genes and chromosomes study guide](/resources/aqa-a-level-biology-7402-dna-genes-and-chromosomes-aqa-alevel-biology/). Test yourself with the [DNA, genes and chromosomes practice questions](/resources/aqa-a-level-biology-7402-dna-genes-and-chromosomes-aqa-alevel-biology-practice/).

## DNA in three locations

| Feature | Prokaryotic cell | Eukaryotic nucleus | Mitochondria and chloroplasts |
|---|---|---|---|
| Length | Short | Very long | Short |
| Shape | Circular | Linear | Circular |
| Associated proteins | None | Histones | None |
| Forms chromosomes? | No (in the specification's sense) | Yes: DNA + histones | No |

**Chromosome** = one DNA molecule + its associated proteins (histones).

## Genes

- A gene is a base sequence of DNA that codes for:
  - the amino acid sequence of a polypeptide, **or**
  - a functional RNA, including ribosomal RNA and tRNAs.
- A gene occupies a fixed position, a **locus**, on a particular DNA molecule.
- Different forms of a gene at the same locus are alleles.

## The triplet code

- Three DNA bases = one triplet = one specific amino acid.
- 4 bases: 4³ = 64 triplets; 4² = 16 would be too few for 20 amino acids.
- Some triplets are stop signals.

| Property | Definition | Consequence |
|---|---|---|
| Universal | Same triplet → same amino acid in all organisms | Genes can be expressed in other species |
| Non-overlapping | Each base belongs to one triplet only | One base change affects at most one amino acid |
| Degenerate | Most amino acids have more than one triplet | A base change may not alter the amino acid |

## Non-coding DNA in eukaryotes

- Much nuclear DNA does not code for polypeptides.
- **Non-coding multiple repeats** between genes: short sequences repeated many times.
- **Exons**: base sequences within a gene that code for amino acid sequences.
- **Introns**: non-coding sequences within a gene, separating exons.
- Prokaryotic genes have no introns.

## Useful counts

| Question | Method |
|---|---|
| Minimum bases to code for *n* amino acids | 3*n* (add 3 for a stop triplet if asked) |
| Amino acids from *b* coding bases (no stop) | *b* ÷ 3 |
| Amino acids from *b* bases if code overlapped | *b* − 2 |
| Intron length | Gene length − exon length |
| Percentage coding | Exon bases ÷ total bases × 100 |

## Key terms

| Term | Definition |
|---|---|
| Histone | Protein around which eukaryotic nuclear DNA is wound |
| Chromosome | A DNA molecule and its associated proteins |
| Gene | Base sequence of DNA coding for a polypeptide's amino acid sequence or a functional RNA |
| Locus | Fixed position of a gene on a particular DNA molecule |
| Triplet | Sequence of three DNA bases coding for one amino acid |
| Universal | Same triplets code for the same amino acids in all organisms |
| Non-overlapping | Each base is read in only one triplet |
| Degenerate | More than one triplet codes for most amino acids |
| Exon | Coding sequence within a gene |
| Intron | Non-coding sequence within a gene |

## Exam traps

- "A gene codes for a protein" is incomplete: polypeptide **or** functional RNA.
- "Chromosome = DNA" misses the proteins.
- Prokaryotic DNA is not in a nucleus and is not linear.
- Organelle DNA resembles prokaryotic DNA: short, circular, no protein.
- Degenerate ≠ non-overlapping; learn both definitions and both consequences.
- Triplets are on DNA; codons are on mRNA (3.4.2).
- Introns remain in DNA; they are removed from pre-mRNA.
- Locus is a position, not the gene itself.

## Answer frames that score

- **Compare DNA:** "Prokaryotic DNA is short and circular, whereas eukaryotic nuclear DNA is very long and linear; prokaryotic DNA is not associated with proteins, whereas nuclear DNA is wound around histones."
- **Explain degeneracy:** "More than one triplet codes for the amino acid, so the new triplet may code for the same amino acid and the primary structure is unchanged."
- **Explain why a gene is longer than 3 × amino acids:** "It contains introns and a stop triplet, which do not code for amino acids."

## Linking forward

## Quick self-test

1. Give three ways eukaryotic nuclear DNA differs from prokaryotic DNA.
2. Define a chromosome.
3. Give the full specification definition of a gene.
4. Name two functional RNAs.
5. What is a locus?
6. Explain why a two-base code could not work.
7. Define degenerate, as applied to the genetic code.
8. What is the consequence of the code being non-overlapping?
9. A gene contains 1,200 bases, of which 690 are in exons. What percentage is intron?
10. What is the minimum number of DNA bases needed to code for a polypeptide of 85 amino acids, not counting stop triplets?
11. Where in the genome are non-coding multiple repeats found?
12. Name two eukaryotic organelles whose DNA is short, circular and not associated with protein.

### Answers

1. Very long (not short); linear (not circular); associated with histones (not free of proteins).
2. A DNA molecule and its associated proteins (histones).
3. A base sequence of DNA that codes for the amino acid sequence of a polypeptide or a functional RNA (including rRNA and tRNAs).
4. Ribosomal RNA and transfer RNA.
5. The fixed position of a gene on a particular DNA molecule.
6. 4² = 16 combinations, fewer than the 20 amino acids.
7. Most amino acids are coded for by more than one triplet.
8. Each base is read once, so a single base change affects only one triplet (at most one amino acid).
9. Intron bases = 510; 510 ÷ 1200 × 100 = **42.5%**.
10. 85 × 3 = **255**.
11. Between genes.
12. Mitochondria and chloroplasts.
