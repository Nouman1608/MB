This guide goes deeper into subtopic **11.1 Formulae, functional groups and terminology** of the Cambridge IGCSE Chemistry 0620 syllabus for 2026–2028. The broader [Organic Chemistry: Formulae and Naming](/resources/organic-chemistry-formulae-and-naming/) guide introduces these ideas alongside naming. ## Four kinds of formula

| Formula | What it shows | Ethanol | Tier |
|---|---|---|---|
| Molecular | the number of each type of atom | C₂H₆O | Core |
| General | a whole homologous series, using *n* | CₙH₂ₙ₊₁OH | Core |
| Structural | how the atoms are arranged, without drawing every bond | CH₃CH₂OH | Supplement |
| Displayed | every atom and every bond | see below | Core |

### Drawing a displayed formula

Four bonding rules make every displayed formula checkable:

- each **carbon** forms **4** bonds;
- each **hydrogen** forms **1** bond;
- each **oxygen** forms **2** bonds;
- a **double bond** counts as two of an atom's bonds.

```
ethanol                       ethanoic acid
    H   H                         H   O
    |   |                         |   ‖
H — C — C — O — H             H — C — C — O — H
    |   |                         |
    H   H                         H
```

In ethanoic acid, the second carbon has a double bond to one oxygen (two bonds), a single bond to the other oxygen and a single bond to the first carbon: four in total. The O–H bond must be drawn; writing "–OH" without the bond line loses the mark when a displayed formula is asked for.

**Check before moving on:** count the bonds round every carbon. If any carbon has three or five, the formula is wrong.

## General formulae, both ways round

| Series | General formula | Value of *n* | First member |
|---|---|---|---|
| Alkanes | CₙH₂ₙ₊₂ | n ≥ 1 | methane, CH₄ |
| Alkenes | CₙH₂ₙ | n ≥ 2 | ethene, C₂H₄ |
| Alcohols | CₙH₂ₙ₊₁OH | n ≥ 1 | methanol, CH₃OH |
| Carboxylic acids | CₙH₂ₙ₊₁COOH | n ≥ 0 | methanoic acid, HCOOH |

**Writing** a formula: substitute *n*. The alkane with 8 carbons is C₈H₁₈ (2 × 8 + 2 = 18).

**Interpreting** a formula: compare the numbers with each pattern.

- C₆H₁₂: hydrogens are twice the carbons, so it fits CₙH₂ₙ: an **alkene**.
- C₆H₁₄: hydrogens are 2n + 2, so an **alkane**.
- C₃H₇OH: the C₃H₇ part fits CₙH₂ₙ₊₁ and there is an –OH group, so an **alcohol**.
- C₃H₇COOH: careful. *n* = 3 counts only the carbons **outside** the –COOH group, so the molecule has **four** carbon atoms: butanoic acid.

The carboxylic acid formula is the one that catches most candidates, because the carbon in –COOH is not included in *n*.

## Functional groups and homologous series

A **functional group** is an atom or group of atoms that determines the chemical properties of a homologous series.

| Series | Functional group |
|---|---|
| Alkenes | C=C double bond |
| Alcohols | –OH |
| Carboxylic acids | –COOH |

A **homologous series** is a family of similar compounds with similar chemical properties due to the presence of the same functional group. Ethanol and propanol react in similar ways because both have –OH.

### General characteristics (Supplement)

The members of a homologous series:

1. have the **same functional group**;
2. have the **same general formula**;
3. differ from one member to the next by a **–CH₂– unit**;
4. display a **trend in physical properties**;
5. share **similar chemical properties**.

The trend in physical properties is easiest to see in boiling points. For the first four alkanes, boiling point rises as the chain gets longer: methane about −162 °C, ethane about −89 °C, propane about −42 °C and butane about −1 °C. Questions may give data like this and ask you to describe the trend or predict the next value.

Note the difference: chemical properties are **similar**, physical properties show a **trend**.

## Saturated and unsaturated

- **Saturated:** all carbon–carbon bonds are **single** bonds. Alkanes are saturated.
- **Unsaturated:** **one or more** carbon–carbon bonds are **not single**. Alkenes are unsaturated.

The definitions are about **carbon–carbon** bonds. Ethanoic acid has a C=O double bond but its only carbon–carbon bond is single, so it is not "unsaturated" in this sense. The test that tells saturated from unsaturated hydrocarbons (aqueous bromine) belongs to subtopic 11.5.

## Structural formulae and isomers (Supplement)

A **structural formula** is an **unambiguous** description of the way the atoms are arranged. CH₃CH₂OH can only be ethanol; the molecular formula C₂H₆O could also describe a different arrangement, so it is ambiguous.

**Structural isomers** are compounds with the **same molecular formula** but **different structural formulae**.

```
C4H10:  CH3CH2CH2CH3            (butane)
        CH3CH(CH3)CH3           (methylpropane)

C4H8:   CH3CH2CH=CH2            (but-1-ene)
        CH3CH=CHCH3             (but-2-ene)
```

### Worked example: isomer or the same molecule?

**Question.** A student draws CH₃CH₂CH₂CH₃ as a straight line and then draws the same four carbons in a zig-zag, with the end carbon pointing downwards. She says they are isomers. Explain whether she is right. [2]

**Answer.** She is wrong [1]. In both drawings the four carbons are joined in one continuous chain with no branch, so the atoms are connected in the same order; it is the same compound, butane, drawn differently [1].

*The test for isomers is the order in which the atoms are joined, not the shape of the drawing. A branch, a moved double bond or a moved functional group makes a new isomer; bending the chain does not.*

## Common mistakes

- **Drawing a carbon with three or five bonds.** Count every carbon.
- **Leaving out the O–H bond** in a displayed formula of an alcohol or acid.
- **Counting n as all the carbons in a carboxylic acid.** The –COOH carbon is extra.
- **Defining a homologous series by "same formula".** It is the same **general** formula and the same functional group.
- **Saying physical properties are "similar".** They show a **trend**.
- **Calling a C=O bond unsaturation.** The definitions refer to carbon–carbon bonds.
- **Counting a bent chain as an isomer.**

## Exam technique for 11.1 command words

- **Draw:** every atom, every bond, correct valencies.
- **State:** use the syllabus definitions closely: "all carbon–carbon bonds are single bonds".
- **Identify:** name the functional group or series and point to the feature that shows it.
- **Deduce:** use the general formula to get a molecular formula, or work backwards to the series.
- **Define** (Extended): structural isomers need both "same molecular formula" and "different structural formula".
