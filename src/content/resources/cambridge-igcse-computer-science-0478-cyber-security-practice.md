## Section A

**1.** Define the term **malware**. **[1]**

**2.** State the aim of a **ransomware** attack. **[1]**

**3.** State **two** features of a strong password. **[2]**

**4.** Name the cyber security solution that checks network traffic against a set of rules. **[1]**

**5.** State what is meant by two-step verification. **[2]**

**6.** Identify the malware described: "It looks like a useful program, but when it is installed it gives an attacker access to the computer." **[1]**

## Section B

**7.** Describe how a brute-force attack is carried out and state its aim. **[3]**

**8.** A password uses only the digits 0 to 9 and is 5 characters long. Calculate the number of possible passwords. Then calculate how many seconds it would take to try every one at 1,000 guesses per second. **[3]**

**9.** Explain the difference between a virus and a worm. **[2]**

**10.** Describe how a DDoS attack is carried out and state its aim. **[4]**

**11.** Explain the difference between phishing and pharming. **[4]**

**12.** A user receives an email asking them to click a link to confirm their bank details. Describe **three** checks the user could make before clicking. **[3]**

**13.** Explain how SSL helps to keep data safe when a customer pays online. **[2]**

**14.** A hospital stores patient records on a network. Explain **three** solutions it could use to keep the data safe, stating which threat each helps with. **[6]**

## Answers

**1.** Malicious software designed to cause harm to a computer or its data, or to steal information [1].

**2.** To make the victim pay a ransom to get their files unlocked or decrypted [1].

**3.** Any two from: long; a mix of upper and lower case letters; includes numbers; includes symbols; not a word or personal detail that can be guessed [1 each].

**4.** A firewall [1].

**5.** The user must prove their identity in two stages [1], such as entering a password and then a code sent to their phone [1].

**6.** A Trojan horse [1].

**7.** Software is used to try every possible combination of characters [1] until the correct password or PIN is found [1]. The aim is to gain access to the account or system [1].

**8.** Each of the 5 characters can be any of 10 digits, so the number of passwords is 10⁵ = 100,000 [1]. Time = 100,000 ÷ 1,000 [1] = 100 seconds [1].

**9.** A virus attaches itself to a file or program and spreads when a user runs or copies the infected file [1], but a worm copies itself and spreads across a network without any user action [1].

**10.** An attacker uses a large number of computers, often infected with malware [1] to send many requests to a web server at the same time [1]. The server cannot cope with the requests [1]. The aim is to make the website slow or unavailable to genuine users [1].

**11.** In phishing, the user receives a deceptive message such as an email [1] and has to click a link to reach the fake website [1]. In pharming, malicious code or altered DNS information redirects the user [1] to a fake website even though they typed the correct address, so no click on a message is needed [1].

**12.** Any three from: hover over the link to check that the real URL matches the bank's address [1]; check the spelling and grammar of the email [1]; check whether the tone is urgent or threatening [1]; check whether the sender's address is genuine [1]; check whether it uses a general greeting rather than the customer's name [1]. Maximum 3.

**13.** SSL encrypts the data sent between the customer's browser and the shop's server [1], so if the card details are intercepted they cannot be understood [1].

**14.** Any three solutions, each with a threat [2 marks each: 1 for the solution and its action, 1 for the threat]. For example: access levels [1], so that staff only see the records they need, helping to stop misuse of data or hacking [1]; a firewall [1], which blocks unwanted network traffic, helping to stop hacking and malware [1]; anti-malware software [1], which scans for and removes viruses, spyware and other malware [1]; two-step verification [1], so a stolen password alone cannot be used to log in, helping against hacking and brute-force attacks [1]; automatic software updates [1], which fix security weaknesses that hackers could exploit [1].

## Where marks are usually lost

- Question 7: giving the process without the aim, or the aim without the process.
- Question 8: leaving out the working, or adding the time for letters by mistake.
- Question 9: saying "a virus is worse than a worm". Explain how each spreads.
- Question 10: describing the attack as coming from one computer.
- Question 11: giving only the meaning of one term.
- Question 12: describing checks that do not relate to the email, such as "use anti-virus".
- Question 14: naming solutions without saying which threat they help with.

## Quick reference for checking your answers

| Item | Key point |
|---|---|
| Brute-force | Tries every combination; aim to gain access |
| Phishing | Message with link to fake site |
| Pharming | Redirects to fake site |
| Virus | Needs a host and user action |
| Worm | Spreads by itself |
| Firewall | Filters traffic against rules |
| SSL | Encrypts data between browser and server |
