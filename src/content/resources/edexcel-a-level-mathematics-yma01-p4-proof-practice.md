These questions cover section 1 of Unit P4 (YMA01, Issue 3): proof by contradiction, including the irrationality of √2, the infinity of primes and unfamiliar proofs. Revise first with the [P4 proof study guide](/resources/edexcel-a-level-mathematics-yma01-p4-proof/) and the [P4 proof revision notes](/resources/edexcel-a-level-mathematics-yma01-p4-proof-revision-notes/). You may assume that √2 is irrational where a question says so.

---

## Section A

**1.** Write down the assumption you would make to begin a proof by contradiction of each statement.

**(a)** There is no largest odd integer. **[1]**

**(b)** √5 is irrational. **[1]**

**(c)** For all real numbers x, x² − 6x + 10 > 0. **[1]**

**2.** Prove by contradiction that there is no largest even integer. **[3]**

**3.** n is an integer. Prove by contradiction that if 3n + 2 is odd, then n is odd. **[3]**

## Section B

**4.** Prove by contradiction that log₂ 5 is irrational. **[4]**

**5.** **(a)** Prove by contradiction that if a is a non-zero rational number and b is an irrational number, then ab is irrational. **[4]**

**(b)** Hence, given that √2 is irrational, show that 3√2 is irrational. **[1]**

**6.** Prove by contradiction that there are no integers a and b for which a² − 4b = 2. **[5]**

**7.** Prove by contradiction that x² + 1/x² ≥ 2 for every real number x ≠ 0. **[4]**

**8.** Prove by contradiction that no triangle has two obtuse angles. **[3]**

**9.** Suppose that p₁, p₂, ..., pₙ is a list of prime numbers, and let N = p₁p₂...pₙ + 1.

**(a)** Explain why N is not divisible by any of p₁, p₂, ..., pₙ. **[1]**

**(b)** Hence prove by contradiction that there are infinitely many prime numbers. **[5]**

**10.** Prove by contradiction that √6 is irrational. **[6]**

**11.** A student tries to use the method of the √2 proof to "prove" that √4 is irrational. She writes √4 = a/b in lowest terms, so a² = 4b², so a is even, a = 2c.

Explain why the argument cannot reach a contradiction from this point, and why this is not surprising. **[2]**

## Answers

**1. (a)** Assume there is a largest odd integer, N [1].

**(b)** Assume √5 is rational, so √5 = a/b where a and b are integers with no common factor and b ≠ 0 [1].

**(c)** Assume there is a real number x for which x² − 6x + 10 ≤ 0 [1].

Total: 3

**2.** Assume there is a largest even integer, N = 2k for some integer k [1]. Then N + 2 = 2(k + 1) is even and N + 2 > N [1]. This contradicts N being the largest even integer, so there is no largest even integer [1].

**3.** Assume 3n + 2 is odd and n is even, so n = 2k for some integer k [1]. Then 3n + 2 = 6k + 2 = 2(3k + 1), which is even [1]. This contradicts 3n + 2 being odd, so if 3n + 2 is odd then n is odd [1].

**4.** Assume log₂ 5 is rational, so log₂ 5 = p/q where p and q are integers; since 5 > 1, log₂ 5 > 0 and p and q can be taken positive [1]. Then 2^(p/q) = 5, so 2ᵖ = 5^q [1]. Since p ≥ 1, 2ᵖ is even, but 5^q is a product of odd numbers and so is odd [1]. An even number cannot equal an odd number, which is a contradiction, so log₂ 5 is irrational [1].

**5. (a)** Assume ab is rational. Write a = p/q and ab = r/s, where p, q, r, s are integers, p ≠ 0, q ≠ 0 and s ≠ 0 [1]. Then b = (r/s) ÷ (p/q) = rq/(sp) [1]. rq and sp are integers and sp ≠ 0, so b is rational [1]. This contradicts b being irrational, so ab is irrational [1].

**(b)** 3 is a non-zero rational number and √2 is irrational, so by part (a), 3√2 is irrational [1].

Total: 5

**6.** Assume there are integers a and b with a² − 4b = 2 [1]. Then a² = 4b + 2 = 2(2b + 1) is even, so a is even [1]. Write a = 2m: then 4m² = 4b + 2 [1], so 4m² − 4b = 2 and 2(m² − b) = 1 [1]. The left-hand side is even and the right-hand side is odd: a contradiction. So there are no such integers [1].

**7.** Assume there is a real x ≠ 0 with x² + 1/x² < 2 [1]. Multiplying by x², which is positive: x⁴ + 1 < 2x² [1], so x⁴ − 2x² + 1 < 0, that is (x² − 1)² < 0 [1]. A real square cannot be negative, so this is a contradiction, and x² + 1/x² ≥ 2 for all real x ≠ 0 [1].

**8.** Assume a triangle has two obtuse angles, A > 90° and B > 90° [1]. Then A + B > 180°, and since the third angle C > 0°, A + B + C > 180° [1]. This contradicts the angle sum of a triangle being 180°, so no triangle has two obtuse angles [1].

**9. (a)** p₁p₂...pₙ is a multiple of each pᵢ, so N leaves remainder 1 when divided by any pᵢ (each pᵢ ≥ 2) [1].

**(b)** Assume there are only finitely many primes, and let p₁, p₂, ..., pₙ be all of them [1]. Let N = p₁p₂...pₙ + 1 [1]. By part (a), none of p₁, ..., pₙ divides N [1]. N > 1, so N is either prime or has a prime factor, and that prime is not in the list [1]. This contradicts the list containing every prime, so there are infinitely many primes [1].

Total: 6

**10.** Assume √6 is rational: √6 = a/b where a and b are integers with no common factor and b ≠ 0 [1]. Then a² = 6b², so a² is even and therefore a is even [1]. Write a = 2c: 4c² = 6b², so 2c² = 3b² [1]. So 3b² is even, and since 3 is odd, b² is even [1], so b is even [1]. Then a and b are both even, contradicting their having no common factor, so √6 is irrational [1].

**11.** Substituting a = 2c gives 4c² = 4b², so c² = b² and b = c; nothing forces b to be even, so no common factor of a and b appears and there is no contradiction [1]. This is expected because √4 = 2 = 2/1 is rational, so a correct argument cannot prove it irrational [1].

## Where marks are usually lost

- In Question 1, writing the original statement instead of its negation, or omitting "no common factor" in part (b).
- In Questions 4 and 10, not saying why a power of 2 is even or why b² must be even.
- In Question 6, stopping at "a is even" without substituting a = 2m.
- In Question 7, multiplying an inequality by x² without noting that x² > 0.
- In Question 9(b), claiming that N itself must be prime.
