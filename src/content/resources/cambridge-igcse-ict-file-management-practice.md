These questions cover Cambridge IGCSE ICT 0417 Topic 11: managing files effectively (11.1) and reducing file sizes for storage or transmission (11.2). They test folder structures and file naming, the characteristics of the syllabus file formats, the need for generic formats and the use of .zip and .rar compression.

## Worked answers

**1.** Comma Separated Values. **[1]**

**2.** .css (Cascading Style Sheet). **[1]**

**3.** Any two: email systems often limit the size of attachments; smaller files upload and download faster; less bandwidth is used; less storage space is needed in the mailbox. **[2]**

**4.** .txt (1) and .pdf (1). **[2]**

**5. (a)** Create a main folder (for example *School*) with subfolders for each subject (1), and further subfolders inside them for topics or years, saving each file in the correct folder (1). **[2]**
**(b)** The name shows what is in the file, so she can find the right file quickly without opening several (1), and she is less likely to overwrite or delete the wrong file (1). **[2]**

**6.** One mark each, for example:
- .gif: limited to 256 colours / supports simple animation / supports transparency.
- .rtf: text with basic formatting that most word processors can open.
- .png: compressed image with no loss of quality / supports transparency.
- .txt: plain text with no formatting. **[4]**

**7. (a)** The other firm does not have the same software (1); a generic format can be opened or imported by many different applications, so the data can be used (1). **[2]**
**(b)** .csv (1): it stores the data as fields separated by commas and records on separate lines, which database software can import (1). **[2]**
**(c)** Any one: formulas (only values are kept); formatting such as fonts and colours; multiple worksheets; charts. **[1]**

**8. (a)** Put all 25 drawings into one compressed .zip (or .rar) archive (1) and attach the single, smaller archive to the email or upload it (1). **[2]**
**(b)** The download is faster / only one file to download and then extract (1). **[1]**

**9.** Up to 4 marks for points about both formats:
- .docx is an application format that can be edited easily in a word processor (1).
- .docx may look different or not open on a device without compatible software (1).
- .pdf keeps the exact layout and fonts on any device (1).
- .pdf can be opened by free readers on most devices (1).
- .pdf is hard to edit, so it suits a final version that should not be changed (1). **[4]**

**10.** Browser view: the page as a visitor sees it in the web browser (1). HTML view: the HTML source code (tags and content) of the page (1). **[2]**

**11.** Any three: the receiver may not have the same software or version as the sender (1); data can be transferred between different applications, for example a spreadsheet and a database (1); files can be opened on different operating systems and devices (1); files can still be read if the original software is no longer available (1). **[3]**

## Frequently asked questions

**Does the exam ask for full names of file formats?**
It can. Learn what each letter stands for and one characteristic and use of each format named in the syllabus.

**Is .rtf an application format or a generic format?**
The 0417 syllabus lists .rtf in both lists, because word processors save it and it can be opened by many programs.
