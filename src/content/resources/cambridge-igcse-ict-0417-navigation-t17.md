The **navigation** row of Topic 17 Document production in Cambridge IGCSE ICT 0417 is short: "add and delete bookmarks/hyperlinks". Behind those six words are several separate actions, each of which a practical task can test: creating a bookmark with a suitable name, linking text to it, linking to a web page, a file or an email address, testing the links and removing links or bookmarks without damaging the text. This guide covers each one in more detail than the [Document production study guide](/resources/cambridge-igcse-ict-document-production-study-guide/).

## Bookmarks

A **bookmark** is a named location in a document. It can mark a single point (where the cursor was) or a piece of selected text, such as a heading. Bookmarks are invisible when printed. Their purpose is to let the reader, or a hyperlink, jump straight to that place.

### Adding a bookmark

1. Select the text to be bookmarked (for example the heading *Prices*), or click at the exact point.
2. Open the bookmark option, usually on the insert menu or ribbon.
3. Type the bookmark name and choose **Add**.

### Naming bookmarks

Use the name the task gives, spelt exactly. Software has rules for names. In Microsoft Word, for example, a bookmark name must begin with a letter, can contain letters, numbers and underscores, and cannot contain spaces. So *Prices*, *Section_2* and *Top* are valid, while *2nd section* and *Price list* are not; *Price_list* would be the valid form of the second. If the software rejects a name, the most likely cause is a space or a leading digit.

### Seeing and using bookmarks

Most word processors have a setting to display bookmarks on screen (often as brackets around the bookmarked text), which is useful when checking that a bookmark is in the right place. The bookmark list can also be used to go to a bookmark directly.

## Hyperlinks

A **hyperlink** is text or an object, such as an image, that takes the reader somewhere else when it is clicked (in many word processors, Ctrl+click while editing). The text shown is the **display text**; where it goes is the **target**.

| Target | Example | Effect when clicked |
|---|---|---|
| Place in this document | The bookmark *Prices* | Jumps to that bookmark |
| Web page | A full web address | Opens the page in a browser |
| Existing file | Another document or a spreadsheet | Opens the file |
| Email address | An address beginning *mailto:* | Opens a new email to that address |

### Adding a hyperlink

1. Select exactly the text (or image) that should become the link; for example only the words *see the price list*, not the whole sentence.
2. Choose the hyperlink option.
3. Choose the target type, then the bookmark, address, file or email address.
4. If the task asks, add a **ScreenTip**, the short text that appears when the pointer rests on the link.
5. Confirm, then **test** the link.

Display text is usually shown underlined and in a different colour. If the task gives the display text, type it exactly, including capitals.

### Editing a hyperlink

Right-click the link and choose to edit it. The target can be changed (for example, from the bookmark *Prices* to *Contact*) and the display text altered without removing the link.

## Deleting bookmarks and hyperlinks

| Task | Method | What happens to the text |
|---|---|---|
| Delete a bookmark | Open the bookmark list, select the name, choose **Delete** | Text stays; only the bookmark is removed |
| Remove a hyperlink | Right-click the link, choose **Remove hyperlink** | Text stays, now as normal text |
| Delete linked text | Select the text and delete it | The text and its link are both removed |

Two points catch candidates out:

- **Removing a hyperlink is not the same as deleting the text.** If the task says "remove the hyperlink", the words should still be there afterwards, no longer underlined.
- **Deleting a bookmark breaks links to it.** A hyperlink whose target bookmark has gone no longer jumps to the right place. If you delete a bookmark, check the hyperlinks that used it and edit or remove them.

Deleting the bookmarked text itself (for example deleting a heading that carried a bookmark) usually deletes the bookmark too, with the same effect on links.

## Why navigation features are used

- In a long document, a reader can jump from a contents list or an index entry to the section without scrolling.
- "Back to top" links at the end of each section let the reader return to the start.
- Cross-references, such as "see the safety rules", can take the reader straight there.
- Links to web pages, files and email addresses connect the document to further information and to the people responsible for it.
- In an electronic document they save time; in a printed document they do nothing, so printed copies need page numbers instead.

## Worked example: a set of navigation instructions

*Task (invented):* "Create a bookmark called *Top* at the document title. Create a bookmark called *Fees* at the heading *Course fees*. On page 1, make the words *course fees* a hyperlink to the bookmark *Fees*. At the end of the document, make the text *Back to top* a hyperlink to *Top*. Make the text *Contact us* a hyperlink to the email address given. Delete the existing hyperlink on the word *timetable*, keeping the word."

1. Select the title; add a bookmark named **Top**.
2. Select the heading *Course fees*; add a bookmark named **Fees**.
3. On page 1, select only *course fees*; insert a hyperlink to a place in this document, choosing **Fees**.
4. At the end, type or select *Back to top*; insert a hyperlink to the bookmark **Top**.
5. Select *Contact us*; insert a hyperlink to the email address, which the software stores as *mailto:* followed by the address.
6. Right-click *timetable* and choose **Remove hyperlink**; the word remains as plain text.
7. Test: Ctrl+click *course fees* (it should jump to the fees heading), Ctrl+click *Back to top* (it should jump to the title) and Ctrl+click *Contact us* (it should open a new email). Display bookmarks to check both are on the right text.

If evidence is needed, take a screenshot of the hyperlink dialogue showing the target, because the printed page shows only underlined text.

## Common mistakes

- Spaces in bookmark names, so the name is rejected or changed.
- Bookmark placed on the wrong heading, or at a point a line away from it.
- Linking a whole sentence when only some words were specified.
- Deleting the word when the instruction was to remove the link.
- Deleting a bookmark and leaving links to it broken.
- Not testing links.

## Exam technique

The practical paper uses *create*, *insert*, *add* and *delete*. Follow names and display text exactly. Provide evidence the examiner can see, such as a screenshot showing the link target. In the theory paper, *describe* the purpose of a bookmark by saying what it marks and how it is used, and *explain* why hyperlinks help users of a long electronic document by saying what time or effort they save.

## Check your understanding

1. What is a bookmark? *A named location in a document that can be jumped to or linked to.*
2. Why is *Price list* not a valid Word bookmark name? *It contains a space.*
3. Name four types of hyperlink target. *A place in the document, a web page, a file and an email address.*
4. What is the difference between removing a hyperlink and deleting it? *Removing keeps the text as plain text; deleting the text removes text and link.*
5. What happens to a hyperlink when its bookmark is deleted? *It no longer goes to the correct place.*
6. Why should a link be tested? *To prove it goes to the correct target.*
