These questions cover section M1.2 of OxfordAQA International AS and A-level Mathematics (9660), version 5.2, using only Unit P1 calculus. In every question a particle moves on a straight line, t is the time in seconds, displacements are in metres from a fixed point O, and velocities are in m s⁻¹.

---

## Section A

**1.** A particle has displacement s = 2t³ − 15t² + 36t. Find expressions for its velocity and acceleration. **[2]**

**2.** For the particle in question 1, find the times at which it is instantaneously at rest. **[2]**

**3.** A particle starts from rest and has acceleration a = 12 − 4t. Find its velocity when t = 3. **[2]**

**4.** A particle has velocity v = 6√t + 2. Find its acceleration when t = 9. **[2]**

**5.** A particle has velocity v = 2(t − 4)². Explain why it never moves in the negative direction, although it is at rest when t = 4. **[2]**

## Section B

**6.** A particle has displacement s = t³ − 12t² + 45t for t ≥ 0.

**(a)** Find expressions for v and a. **[2]**

**(b)** Find the times when the particle is at rest and its displacement from O at each. **[3]**

**(c)** Find the total distance travelled in the first 6 s. **[3]**

**(d)** Find the interval of time during which the particle is moving in the negative direction and speeding up. **[2]**

**7.** A particle is at O when t = 0, moving with velocity 3 m s⁻¹. Its acceleration is a = 8 − 6t.

**(a)** Find expressions for v and s. **[3]**

**(b)** Find the greatest velocity of the particle. **[2]**

**(c)** Find the value of t, for t > 0, at which the particle is at rest, and its displacement from O at that time. **[3]**

**8.** A particle starts from O with velocity v = 6t − 2t^(3/2) for t ≥ 0.

**(a)** Find the times at which the particle is at rest. **[2]**

**(b)** Find the greatest velocity of the particle for 0 < t < 9, showing that it is a maximum. **[3]**

**(c)** Find the displacement of the particle from O when t = 9. **[2]**

**9.** For t ≥ 1, a particle moves with velocity v = 27t^(−2) − 3. It is at O when t = 1.

**(a)** Find the time at which the particle is at rest. **[2]**

**(b)** Find its acceleration at that time. **[1]**

**(c)** Find an expression for s and the particle's displacement from O when it is at rest. **[3]**

**10.** A particle starts from O with velocity v = 3t² − 10t + 8 for t ≥ 0.

**(a)** Show that the particle never returns to O. **[3]**

**(b)** Find the total distance travelled in the first 3 s, giving your answer to 3 significant figures. **[3]**

**11.** Particles P and Q both leave O at t = 0 and move along the same line in the same direction. P has velocity 3t² and Q has a constant velocity of 12 m s⁻¹.

**(a)** Find when P and Q have the same speed. **[1]**

**(b)** Find when P catches up with Q, giving your answer in exact form. **[3]**

**12.** A particle moves with velocity v = t² − 8t + 12 for 0 ≤ t ≤ 8.

**(a)** Find the intervals of time in which the particle is speeding up. **[4]**

**(b)** Find the greatest speed of the particle in this period. **[2]**

---

## Answers

**1.** v = **6t² − 30t + 36** [1]; a = **12t − 30** [1].

**2.** 6(t² − 5t + 6) = 6(t − 2)(t − 3) = 0 [1], so **t = 2 and t = 3** [1].

**3.** v = 12t − 2t² + c, and v = 0 at t = 0 gives c = 0 [1]. At t = 3, v = 36 − 18 = **18 m s⁻¹** [1].

**4.** a = dv/dt = 3t^(−1/2) [1]. At t = 9, a = 3 ÷ 3 = **1 m s⁻²** [1].

**5.** (t − 4)² ≥ 0 for every t, so v = 2(t − 4)² is never negative [1]. At t = 4 the velocity touches zero but does not change sign, so the particle stops instantaneously and continues in the positive direction [1].

**6. (a)** v = **3t² − 24t + 45** [1]; a = **6t − 24** [1].

**(b)** 3(t² − 8t + 15) = 3(t − 3)(t − 5) = 0, so **t = 3 and t = 5** [1]. s(3) = 27 − 108 + 135 = **54 m** [1]; s(5) = 125 − 300 + 225 = **50 m** [1].

**(c)** s(0) = 0 and s(6) = 216 − 432 + 270 = 54 [1]. Legs: 0 to 3 s, 54 m; 3 to 5 s, 4 m back; 5 to 6 s, 4 m forward [1]. Distance = **62 m** [1].

**(d)** v < 0 for 3 < t < 5 and a < 0 for t < 4 [1]. Both negative, so speeding up in the negative direction, for **3 < t < 4** [1].

**7. (a)** v = 8t − 3t² + c; v = 3 at t = 0, so **v = 8t − 3t² + 3** [1]. s = 4t² − t³ + 3t + k; s = 0 at t = 0, so **s = 4t² − t³ + 3t** [1] [1].

**(b)** a = 0 when t = 4/3 [1]. v = 32/3 − 16/3 + 3 = **25/3 ≈ 8.33 m s⁻¹** [1].

**(c)** 3t² − 8t − 3 = 0, so (3t + 1)(t − 3) = 0 [1] and **t = 3** (t = −1/3 rejected) [1]. s(3) = 36 − 27 + 9 = **18 m** [1].

**8. (a)** v = 2t(3 − √t) = 0 [1], so **t = 0 and t = 9** [1].

**(b)** a = 6 − 3t^(1/2) = 0 gives √t = 2, so t = 4 [1]. v = 24 − 2 × 8 = **8 m s⁻¹** [1]. da/dt = −1.5t^(−1/2) < 0 at t = 4, so this is a maximum [1].

**(c)** s = 3t² − 0.8t^(5/2), with no constant since s = 0 at t = 0 [1]. s(9) = 243 − 0.8 × 243 = **48.6 m** [1].

**9. (a)** 27t^(−2) = 3 gives t² = 9 [1], so **t = 3** [1].

**(b)** a = −54t^(−3), so at t = 3, a = −54 ÷ 27 = **−2 m s⁻²** [1].

**(c)** s = −27t^(−1) − 3t + c [1]. s = 0 at t = 1 gives c = 30, so **s = 30 − 27/t − 3t** [1]. At t = 3, s = 30 − 9 − 9 = **12 m** [1].

**10. (a)** s = t³ − 5t² + 8t, with no constant since s = 0 at t = 0 [1]. s = t(t² − 5t + 8) [1]. The quadratic has discriminant 25 − 32 = −7 < 0, so s = 0 only when t = 0, and the particle never returns to O [1].

**(b)** v = (3t − 4)(t − 2), so the particle is at rest at t = 4/3 and t = 2 [1]. s(4/3) = 112/27, s(2) = 4, s(3) = 6 [1]. Distance = 112/27 + (112/27 − 4) + (6 − 4) = 224/27 − 2 = **6.30 m** [1].

**11. (a)** 3t² = 12, so **t = 2 s** [1].

**(b)** s_P = t³ and s_Q = 12t [1]. t³ = 12t gives t(t² − 12) = 0 [1], so **t = 2√3 s** (t = 0 is the start) [1].

**12. (a)** v = (t − 2)(t − 6) and a = 2t − 8 [1]. Signs: 0 < t < 2, v > 0 and a < 0; 2 < t < 4, both negative; 4 < t < 6, v < 0 and a > 0; 6 < t ≤ 8, both positive [1]. Speeding up when the signs agree [1]: **2 < t < 4 and 6 < t ≤ 8** [1].

**(b)** Check turning point and end points: v(0) = 12, v(4) = −4, v(8) = 12 [1]. Greatest speed = **12 m s⁻¹**, at t = 0 and t = 8 [1].

## Where marks are usually lost

- Declaring a change of direction at a repeated root of v.
- Using t = 0 to fix a constant when the condition is given at t = 1.
- Integrating 27t^(−2) as +27t^(−1).
- Giving the displacement after 6 s (54 m) as the distance travelled.
- Reading negative acceleration as slowing down, without checking the sign of v.
- Ignoring end points of the interval when finding the greatest speed.
