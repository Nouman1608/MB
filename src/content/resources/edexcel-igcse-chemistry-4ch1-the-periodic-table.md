This guide teaches sub-topic 1(d) The Periodic Table from Topic 1, Principles of chemistry, of the Pearson Edexcel International GCSE Chemistry (4CH1) specification, Issue 3 (September 2024). It covers points 1.18 to 1.24. None of them carries a C reference, so all can be examined on Paper 1 and Paper 2.

The combined [atomic structure and the Periodic Table study guide](/resources/edexcel-igcse-chemistry-4ch1-atomic-structure-and-the-periodic-table/) lists the configurations of the first 20 elements. This page practises using the table as a tool: deducing configurations quickly, classifying unfamiliar elements and writing full-mark explanations. Condense it with [the Periodic Table revision notes](/resources/edexcel-igcse-chemistry-4ch1-the-periodic-table-revision-notes/) and test yourself with [the Periodic Table practice questions](/resources/edexcel-igcse-chemistry-4ch1-the-periodic-table-practice/).

## How the table is built (1.18)

Elements are placed **in order of increasing atomic number**, so each element has one more proton (and, in a neutral atom, one more electron) than the one before. A new row starts each time a new electron shell begins to fill.

- **Period**: a horizontal row. All the elements in a period have the same number of occupied electron shells.
- **Group**: a vertical column. The main group elements in one group have the same number of outer-shell electrons.

The **main groups** are Groups 1 to 7 and Group 0. The block of metals between Groups 2 and 3 is not part of the main groups, so the group-number rules below do not apply to it.

## Deducing configurations from position (1.19, 1.22)

For the first 20 elements, shells fill in the order 2, 8, 8, then the fourth shell begins.

```
number of occupied shells       = period number
electrons in the outer shell    = group number (Groups 1 to 7)
Group 0                         = full outer shell
total electrons                 = atomic number
```

**Worked example 1.** Aluminium has atomic number 13. Deduce its configuration, group and period.

```
13 electrons: first shell 2, second shell 8, remaining 13 - 2 - 8 = 3
configuration 2,8,3
three shells   -> Period 3
3 outer electrons -> Group 3
```

**Worked example 2.** Element G is in Period 2. Its atoms have four more electrons than a helium atom. Identify G.

```
helium has 2 electrons, so G has 2 + 4 = 6 electrons
configuration 2,4 -> 2 shells (Period 2), 4 outer electrons (Group 4)
atomic number 6 -> carbon
```

To describe a configuration in words, or as a shell diagram, show the nucleus with the electrons in rings: 2 on the first ring, up to 8 on the second and third. For calcium, 2,8,8,2, the fourth ring has two electrons.

## Metals and non-metals by position (1.21)

A stepped line runs from boron down to the bottom right of the table. Elements to the left of it, including the central block, are metals. Elements to its right are non-metals. Hydrogen is a non-metal.

Position works for any element, not only the first 20. For example, strontium is in Group 2, so it is a metal; selenium is in Group 6, to the right of the line, so it is a non-metal.

## Metals and non-metals from evidence (1.20)

| Evidence | Metal | Non-metal |
|---|---|---|
| Electrical conductivity of the solid element | Good conductor | Poor conductor (graphite is the exception) |
| Oxide with acid | Basic oxide: reacts with an acid to form a salt and water | No reaction (acidic oxide) |
| Oxide in water with universal indicator | Soluble metal oxides give alkaline solutions, pH above 7 | Soluble non-metal oxides give acidic solutions, pH below 7 |

A few metal oxides, such as aluminium oxide and zinc oxide, are amphoteric and also react with alkalis, so judge from the evidence the question gives.

**Worked example 3.** Classify each element.

| Element | Solid conducts? | Result with its oxide |
|---|---|---|
| R | No | Oxide is a gas; its solution in water turns universal indicator orange |
| T | Yes | Oxide does not dissolve in water but reacts with dilute nitric acid to give a salt and water |
| V | Yes | Oxide is a gas; its solution in water has pH 4 |

```
R: does not conduct + acidic oxide             -> non-metal
T: conducts + basic oxide (salt + water)       -> metal
V: conducts, but acidic oxide                  -> non-metal (carbon as graphite fits)
```

V is the trap: one piece of evidence points each way, and the oxide test decides, because graphite is a conducting non-metal.

## Why a group shares chemical properties (1.23)

Chemical reactions involve the outer-shell electrons, which atoms lose, gain or share. Elements in the same group have the **same number of outer-shell electrons**, so they react in similar ways and form compounds with similar formulae.

**Model answer.** Explain why sodium and potassium have similar chemical properties. **[2]**

> Sodium (2,8,1) and potassium (2,8,8,1) both have one electron in their outer shell [1]. Chemical reactions involve the outer-shell electrons, so both elements react in a similar way, for example both form ions with a 1+ charge [1].

"They are in the same group" restates the question and scores nothing on its own.

### Using a group to predict

Because group members behave similarly, a known reaction lets you predict another. Magnesium (Group 2) burns to form MgO, so calcium (also Group 2) is expected to form CaO. Sulfur (Group 6) forms the acidic oxide SO₂, so selenium, below it, is expected to form an acidic oxide too. Trends down a group (such as reactivity) are taught in Topic 2.

## Why the noble gases are unreactive (1.24)

**Model answer.** Explain why argon does not readily react. **[2]**

> Argon has a full outer shell of electrons (2,8,8) [1]. This is a stable arrangement, so argon atoms do not need to lose, gain or share electrons [1].

The noble gases also exist as single atoms, because their atoms do not form bonds with one another. Helium is in Group 0 with only 2 electrons, because its only shell (the first) is full. So the reason is "a full outer shell", not "eight outer electrons".

## Linking the points together

Questions often join several points in one context. For an unfamiliar main group element, work through the same checklist:

1. Position → number of shells and outer electrons → configuration (if in the first 20).
2. Position → metal or non-metal.
3. Metal → conducts, basic oxide; non-metal → poor conductor (except graphite), acidic oxide.
4. Group → similar reactions to the other members.
5. Group 0 → full outer shell → unreactive.

## Common mistakes

- Saying the table is arranged by mass or by Ar.
- Writing potassium as 2,8,9 instead of 2,8,8,1.
- Using group number to give outer electrons for a central-block metal.
- Classifying from appearance ("shiny, so metal") when conductivity and oxide data are given.
- Calling every conductor a metal: graphite conducts.
- Explaining noble gas stability with "eight outer electrons", which fails for helium.

## Exam technique

- **Deduce**: show the chain from position to shells to electrons, not just the answer.
- **Explain**: make two linked points (outer electrons + reactions involve outer electrons; full shell + stable).
- **Identify** from data: use every piece of evidence in the table and state which one decides.
- **Predict**: name the group-mate you are comparing with and the property you are carrying across.
