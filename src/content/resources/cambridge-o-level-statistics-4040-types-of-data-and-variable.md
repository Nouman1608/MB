This guide covers section 1.5 of the Cambridge O Level Statistics (4040) syllabus for examination in 2025, 2026 and 2027: "Types of data and variable", which the syllabus says includes knowledge of the terms qualitative, quantitative, discrete and continuous. Classifying a variable correctly is quick to learn, but it decides almost every later choice: which table to draw, which diagram to use, where class boundaries go and which average makes sense.

| Quantitative | Recognise data that are numerical amounts which can be meaningfully added or averaged |

| Continuous | Recognise quantitative data that can take any value in a range, usually measurements |

## Variables and data

A **variable** is a feature that changes from one member of a population to another: eye colour, number of siblings, height. The **data** are the values recorded for that variable. A question may ask you to classify the variable or the data; the answer is the same.

## Qualitative and quantitative

**Qualitative** data describe a quality or category: blood group, favourite sport, make of car, grade awarded. The values are words or labels.

**Quantitative** data are numerical measurements or counts: number of goals, mass, time taken. The values are numbers with a size, so it makes sense to add them, subtract them and find a mean.

### The number test

Some qualitative data look numerical. A shirt number, a bus route number, a house number or a telephone code is a label: shirt 10 is not "twice" shirt 5, and the mean shirt number of a team means nothing. Ask: **would the mean of these numbers tell me anything?** If not, the data are qualitative.

Qualitative categories sometimes have a natural order (small, medium, large; grade A, B, C). They are still qualitative, but the order lets you speak of the middle category.

## Discrete and continuous

Quantitative data split into two types.

**Discrete** data can take only particular, separate values, with gaps between them. Counts are always discrete: number of children, number of cars passing, number of correct answers. Discrete data are not always whole numbers: shoe sizes go up in halves (5, 5½, 6), and so do some exam marks. What matters is that the values in between are impossible.

**Continuous** data can take any value within a range. Length, mass, time, temperature and volume are continuous. Between 1.62 m and 1.63 m there are infinitely many possible heights.

### Recorded values of continuous data are rounded

You can never record a continuous value exactly; you round it to the accuracy of the instrument. So a recorded value stands for an **interval**.

| Recorded value | Accuracy | True value lies in |
|---|---|---|
| 172 cm | nearest cm | 171.5 ≤ h < 172.5 |
| 3.40 kg | nearest 0.01 kg | 3.395 ≤ m < 3.405 |
| 12.6 s | nearest 0.1 s | 12.55 ≤ t < 12.65 |
| 450 ml | nearest 10 ml | 445 ≤ v < 455 |

This is why continuous data are grouped with **class boundaries** that leave no gaps, a skill you meet again in topic 3.

### Age: continuous, but recorded in a special way

Age is continuous: time since birth. But age is normally given in **completed years**, which is rounding down, not rounding to the nearest year. Someone aged 15 may be anywhere from exactly 15 up to (but not including) 16.

| Age class (completed years) | True boundaries |
|---|---|
| 15–19 | 15 and 20 |
| 20–24 | 20 and 25 |

Compare this with heights to the nearest cm, where the class 15–19 cm would have boundaries 14.5 and 19.5. Always check how the data were rounded before writing boundaries.

### Borderline cases

| Variable | Usual classification | Reason |
|---|---|---|
| Money (prices, wages) | Discrete in principle | Goes up in the smallest coin or unit; often treated as continuous when amounts are large |
| Shoe size | Discrete | Sizes go up in halves; 5.3 is not a shoe size |
| Number of people | Discrete | Counted |
| Time taken to run 100 m | Continuous | Measured |
| Score on a 1–5 rating scale | Qualitative with order, or discrete if treated as a score | Depends on how it is used; state your reasoning |
| Temperature | Continuous | Measured |

When a question is about a borderline variable, the classification you give earns credit only with the reason.

## Worked example 1: classifying from a questionnaire

A survey of Year 11 pupils records: (i) number of brothers and sisters, (ii) method of travel to school, (iii) journey time in minutes, (iv) house number, (v) mass of school bag in kilograms, (vi) number of text messages sent yesterday.

| Variable | Type | Reason |
|---|---|---|
| (i) Siblings | Quantitative, discrete | A count: 0, 1, 2, ... |
| (ii) Travel method | Qualitative | Categories: walk, bus, car, cycle |
| (iii) Journey time | Quantitative, continuous | A measured time; any value is possible |
| (iv) House number | Qualitative | A label; its mean is meaningless |
| (v) Bag mass | Quantitative, continuous | A measurement |
| (vi) Texts sent | Quantitative, discrete | A count |

Note (iii): journey time is continuous even though the answers will be recorded in whole minutes. The rounding happens when recording; the variable itself is continuous.

## Worked example 2: from data type to method

A café owner records, for 60 customers, the drink chosen, the number of items bought and the time spent in the café to the nearest minute. Decide a suitable table and diagram for each.

- **Drink chosen** (qualitative): a frequency table of categories; a pie chart to show proportions, or a bar chart with gaps to compare counts. The mode is the only meaningful average.
- **Items bought** (discrete): an ungrouped frequency table of 1, 2, 3, ...; a bar chart or vertical line graph with gaps between values. Mean, median and mode all make sense.
- **Time spent** (continuous): a grouped frequency table with classes such as 0–9, 10–19, ... minutes, whose boundaries are 9.5, 19.5, ...; a histogram with no gaps, or a cumulative frequency polygon. The syllabus specifies cumulative frequency curves and polygons for continuous data in section 4.2.

## Worked example 3: writing a class from a recorded value

Masses of parcels are recorded to the nearest 0.1 kg. One class is written 2.0–2.4 kg. State its class boundaries and its width.

```
Lower boundary: 2.0 − 0.05 = 1.95 kg
Upper boundary: 2.4 + 0.05 = 2.45 kg
Class width: 2.45 − 1.95 = 0.5 kg
```

The width is 0.5 kg, not 0.4 kg: the gap of 0.1 kg between written classes is shared between neighbouring classes.

## Common errors

- Calling a numerical label (shirt number, room number) quantitative.
- Calling shoe size continuous because it includes halves.
- Calling journey time discrete because it was recorded in whole minutes.
- Using ±0.5 for age in completed years, giving boundaries such as 14.5 and 19.5.
- Drawing a bar chart with touching bars for qualitative data and then calling it a histogram.
- Saying "discrete means whole numbers": discrete means separate possible values.

## Exam technique

- **State the type**: give both levels for quantitative data ("quantitative and continuous"), not just one word.
- **Explain** or **give a reason**: say what the values are (counted or measured; labels or amounts).
- **Suggest a suitable diagram**: link the choice to the data type in your answer ("continuous, so a histogram with no gaps").
- Where a variable is borderline, state the classification you are using and why, then apply it consistently.

## Frequently asked questions

**Is age discrete or continuous?**
Continuous, because it is time since birth. It is usually recorded in completed years, so the age 15 covers 15 up to but not including 16.

**Can discrete data include fractions?**
Yes. Discrete data take separate values, which may include halves, as with shoe sizes. Continuous data can take any value in a range.

**Are numbers always quantitative?**
No. A number used as a label, such as a shirt number or a postcode, is qualitative because arithmetic on it has no meaning.
