## Section A

**1.** f′(x) = (x + 4)(x − 2). Find the interval on which f is decreasing. **[2]**

**2.** f(x) = x³ − 6x² + 9x + 1. Find the intervals on which f is increasing and the interval on
which it is decreasing. **[4]**

**3.** Show that f(x) = x³ + 2x − 7 is increasing for all values of x. **[2]**

**4.** f(x) = 2x + 8/x, x ≠ 0. Find the values of x for which f is decreasing. **[4]**

**5.** f(x) = x³ − kx, where k > 0. f is decreasing exactly when −1 < x < 1. Find k. **[3]**

**6.** f(x) = 3x⁴ − 4x³.

**(a)** Find f′(x) in factorised form. **[2]**

**(b)** Find the intervals on which f is increasing and decreasing, and explain what happens at
x = 0. **[3]**

## Section B

**7.** The graph of y = f′(x) crosses the x-axis at x = −1 (from below to above), at x = 2 (from above
to below) and at x = 4 (from below to above). It has a local minimum at x = 3.

**(a)** Write down the intervals on which f is increasing. **[2]**

**(b)** Write down the x-coordinates of the local maximum and local minimum points of f. **[2]**

**(c)** Write down the value of x between 2 and 4 at which f is decreasing most steeply. **[1]**

**8.** f(x) = x³ − 3kx² + 27x.

**(a)** Find the set of values of k for which f is increasing for all x. **[4]**

**(b)** For k = 3, show that f′(x) = 3(x − 3)² and describe the behaviour of f at x = 3. **[2]**

**9.** f(x) = x⁴ − 2x³ − 5x² + 7x. Use your GDC to find, to three significant figures, the intervals on
which f is decreasing. **[4]**

**10.** A company's profit, P thousand dollars, from making x hundred items is modelled by
P(x) = −x³ + 15x² + 48x for 0 ≤ x ≤ 20. (Model invented.)

**(a)** Find P′(x). **[1]**

**(b)** Find the interval of values of x in the domain for which the profit is increasing. Give the
endpoint to three significant figures. **[3]**

**(c)** Interpret your answer to (b) in context. **[1]**

**11.** f(x) = x² − 8 ln x, x > 0. Find the interval on which f is decreasing and the interval on which
it is increasing. **[4]**

**12.** f(x) = (x − 1)/(x + 2), x ≠ −2, has derivative f′(x) = 3/(x + 2)².

**(a)** Explain why f is increasing on x < −2 and on x > −2. **[1]**

**(b)** Calculate f(−3) and f(0). **[1]**

**(c)** Explain why the results of (a) and (b) do not contradict each other. **[1]**

## Answers

**1.** f′ is a positive quadratic with roots −4 and 2, so f′(x) < 0 between them [1]: −4 < x < 2 [1].
**[2]**

**2.** f′(x) = 3x² − 12x + 9 = 3(x − 1)(x − 3) [1]. Roots 1 and 3 [1]. Increasing for x < 1 and for
x > 3 [1]; decreasing for 1 < x < 3 [1]. **[4]**

**3.** f′(x) = 3x² + 2 [1]. Since x² ≥ 0, f′(x) ≥ 2 > 0 for all x, so f is increasing everywhere [1].
**[2]**

**4.** f′(x) = 2 − 8x⁻² = 2 − 8/x² [1]. f′(x) = 0 when x² = 4, x = ±2 [1]; f′ is undefined at x = 0.
f′(x) < 0 when x² < 4, x ≠ 0 [1], so f is decreasing for −2 < x < 0 and for 0 < x < 2 [1]. **[4]**

**5.** f′(x) = 3x² − k [1]. f′(x) < 0 for −√(k/3) < x < √(k/3) [1], so √(k/3) = 1 and k = 3 [1]. **[3]**

**6. (a)** f′(x) = 12x³ − 12x² [1] = 12x²(x − 1) [1]

**(b)** 12x² ≥ 0, so the sign of f′ is the sign of (x − 1) except at x = 0 [1]. Decreasing for x < 1
(stationary at x = 0); increasing for x > 1 [1]. At x = 0, f′ = 0 but does not change sign, so f has
a horizontal point of inflexion and keeps decreasing [1]. **[5]**

**7. (a)** f′ > 0 for −1 < x < 2 [1] and for x > 4 [1].

**(b)** Local maximum at x = 2 (f′ changes from + to −) [1]; local minima at x = −1 and x = 4
(f′ changes from − to +) [1].

**(c)** x = 3, where f′ has its most negative value [1]. **[5]**

**8. (a)** f′(x) = 3x² − 6kx + 27 [1]. Need discriminant ≤ 0: 36k² − 324 ≤ 0 [1], so k² ≤ 9 [1]
and −3 ≤ k ≤ 3 [1].

**(b)** f′(x) = 3x² − 18x + 27 = 3(x² − 6x + 9) = 3(x − 3)² [1]. f′(3) = 0 but f′ ≥ 0 on both sides,
so f is stationary at x = 3 and continues increasing [1]. **[6]**

**9.** f′(x) = 4x³ − 6x² − 10x + 7 [1]. GDC roots: x = −1.34, 0.577, 2.26 [1]. f′ < 0 for x < −1.34
[1] and for 0.577 < x < 2.26 [1]. **[4]**

**10. (a)** P′(x) = −3x² + 30x + 48 [1]

**(b)** P′(x) = 0 gives x² − 10x − 16 = 0, so x = 5 ± √41 [1]. In the domain, only x = 11.4 (3 s.f.)
[1]; P′(0) = 48 > 0, so P is increasing for 0 ≤ x < 11.4 [1].

**(c)** Profit rises as production increases up to about 1140 items, then falls [1]. **[5]**

**11.** f′(x) = 2x − 8/x [1] = 2(x² − 4)/x [1]. For x > 0, f′(x) = 0 only at x = 2 [1]. Decreasing for
0 < x < 2 and increasing for x > 2 [1]. **[4]**

**12. (a)** (x + 2)² > 0 for all x ≠ −2, so f′(x) > 0 on each side of x = −2 [1].

**(b)** f(−3) = (−4)/(−1) = 4 and f(0) = −1/2 [1].

**(c)** f is undefined at x = −2 (a vertical asymptote), so it is increasing on each interval
separately, not across the asymptote; −3 and 0 lie in different intervals [1]. **[3]**

## How this set builds

Questions 1 to 4 drill the four-step method on quadratic, cubic and reciprocal derivatives.
Questions 5, 6 and 8 add parameters and repeated roots, where a stationary point does not change the
direction of the graph. Question 7 reads f from the graph of f′. Questions 9 to 12 extend the method
to technology, a modelling context, a logarithm and an asymptote.
