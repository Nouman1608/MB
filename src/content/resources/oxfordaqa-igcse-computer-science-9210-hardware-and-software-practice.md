These questions cover section 3.4.1 Hardware and software of the OxfordAQA International GCSE Computer Science
(9210) specification.

---

## Section A

**1.** Define the term hardware. **[1]**

**2.** Define the term software. **[1]**

**3.** State whether each item is hardware or software.

**(a)** a printer **[1]**

**(b)** a spreadsheet program **[1]**

**(c)** a solid state drive **[1]**

**(d)** an operating system **[1]**

**4.** A student says, "A file is hardware because it is stored in the computer." Explain why the student is wrong. **[2]**

## Section B

**5.** Explain the relationship between hardware and software. **[4]**

**6.** A laptop has a working processor, memory and storage, but the operating system has been deleted.

**(a)** State why the laptop cannot be used in this state. **[2]**

**(b)** State whether the fault is in the hardware or the software, and explain how it can be repaired. **[2]**

**7.** A game is stored on a disc. State which part is hardware and which part is software, and explain how the two
are used together when the game is played. **[4]**

**8.** A school installs a new version of a word processor on its old computers. The programs now start slowly.
Explain why this happens. **[3]**

**9.** Two computers have exactly the same hardware. One is used by a graphic designer and the other is used by an
accountant. Explain how the same hardware can be used for different jobs. **[3]**

**10.** A washing machine has a controller board that runs a program stored in the machine. The program selects the
programme, controls the motor and displays the time left.

**(a)** Identify one item of hardware and one item of software in the washing machine. **[2]**

**(b)** Explain why the washing machine would not work if the program were removed. **[2]**

**11.** A phone screen is cracked and an app crashes. For each fault, state whether it is a hardware fault or a
software fault, and give a reason. **[4]**

**12.** Describe how a program that is stored on a hard disk drive is used by the hardware when the program is run.
Name three hardware components in your answer. **[4]**

**13.** A user wants to run a video editing program that needs 16 GB of memory on a computer that has 4 GB. Explain
what this shows about the relationship between hardware and software. **[3]**

**14.** A company releases an update that gives a tablet a new feature. Explain why the company did not need to change
the tablet's physical parts. **[2]**

---

## Answers

**1.** The physical components of a computer system (the parts that can be touched) [1].

**2.** The programs (sets of instructions) that tell the hardware what to do [1].

**3.** **(a)** Hardware [1]. **(b)** Software [1]. **(c)** Hardware [1]. **(d)** Software [1].

**4.** A file is data (or a program) [1]; it is stored on a hardware device, such as a drive, but a file itself is not a
physical component [1].

**5.** Hardware is the physical components of a computer system [1]; software is the programs that tell the hardware what
to do [1]; hardware needs software to give it instructions, because without a program it cannot do anything useful [1];
software needs hardware to run, because the processor has to execute the instructions and memory and storage hold
them [1].

**6.** **(a)** The operating system manages the hardware and lets the user run other programs [1]; without it, the
hardware has no instructions to work with, so the laptop cannot start up or run programs [1].
**(b)** A software fault [1]; the operating system can be reinstalled onto the storage device [1].

**7.** The disc is hardware [1]; the game is software [1]. The program is copied from the disc into memory [1], and the
processor carries out the instructions of the game, with the results shown on the screen and heard through the
speakers [1].

**8.** The new version needs more processing power or memory than the old computers have [1]; the processor is the
same, so it takes longer to execute the larger number of instructions [1]; this shows that the hardware limits how
well the software can run [1].

**9.** The hardware can run any software that is installed [1]; the designer uses graphics software and the accountant
uses spreadsheet software [1]; the processor carries out whichever instructions it is given, so different software
makes the same hardware perform different jobs [1].

**10.** **(a)** Hardware: for example the controller board, the motor or the display [1]. Software: the program stored
in the machine [1].
**(b)** The program provides the instructions that tell the machine what to do [1]; without it, the processor has no
instructions to carry out, so the hardware cannot control the motor or the display [1].

**11.** Cracked screen: hardware fault [1], because a physical component is damaged [1]. App crash: software fault [1],
because the program (instructions) has failed while the physical parts are working [1].

**12.** The program is copied from the hard disk drive (secondary storage) into the main memory, RAM [1]; the processor
(CPU) fetches each instruction from memory and executes it [1]; three components named correctly, such as hard disk
drive, RAM and CPU [1]; output is shown on a device such as the monitor [1].

**13.** The software needs a certain amount of hardware resources to run [1]; with only 4 GB, the computer does not meet
the minimum hardware requirement [1]; so the program will run slowly or not at all, which shows that hardware limits
what the software can do [1].

**14.** The update changes the software (the instructions) that the processor runs [1]; the hardware is the same and can
carry out the new instructions [1].

## Where marks are usually lost

- Writing "the parts of the computer" without saying that hardware is physical.
- Treating a file or a program as hardware because it is stored on a device.
- Describing the relationship in one direction only, as in Question 5.
- Not naming specific components in Question 12.
- Saying that a software fault can be caused by dropping a device.
