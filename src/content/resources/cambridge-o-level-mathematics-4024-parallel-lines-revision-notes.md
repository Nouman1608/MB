These notes summarise section 3.6, Parallel lines, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. Full explanations are in the [parallel lines study guide](/resources/cambridge-o-level-mathematics-4024-parallel-lines/), and exam-style questions are in the [parallel lines practice questions](/resources/cambridge-o-level-mathematics-4024-parallel-lines-practice/).

## The one idea

```
parallel lines  =  equal gradients
```

- If a line has gradient m, every parallel line has gradient m.
- Two different lines with the same gradient are parallel.
- Same gradient and same y-intercept means the same line, not two lines.

## Key terms

| Term | Meaning |
|---|---|
| Gradient | the steepness of a line, change in y divided by change in x |
| y-intercept | the value of y where the line crosses the y-axis (the c in y = mx + c) |
| Parallel | never meeting, always the same distance apart, equal gradients |
| Coincident | lying exactly on top of each other, the same line |
| Subject | the letter written alone on one side, such as y in y = mx + c |
| Standard form of a line | ax + by = c, with the letters on the left |

## Reading the gradient

| Equation given | Method | Gradient |
|---|---|---|
| y = 4x − 1 | read off the number multiplying x | 4 |
| 2y = 3x + 1 | divide every term by 2 | 3/2 |
| 3x + 2y = 7 | make y the subject | −3/2 |
| ax + by = c | rearrange, or use −a/b | −a/b |
| through two points | (y₂ − y₁)/(x₂ − x₁) | calculate |
| y = 5 | horizontal line | 0 |
| x = 2 | vertical line | undefined |

## Method box: the parallel line through a point

1. Find the gradient m of the given line. Rearrange if necessary.
2. Write y = mx + c, or y − y₁ = m(x − x₁).
3. Substitute the coordinates of the point.
4. Solve for c, or expand the brackets.
5. Write the final equation and test the point in it.

### Example

Line parallel to y = 4x − 1 through (1, −3).

```
m = 4
−3 = 4(1) + c
c = −7
y = 4x − 7
```

### Shortcut for ax + by = c

A line parallel to ax + by = c has the same left side. Only the right side changes. Substitute the point into ax + by to find the new number.

```
Parallel to 5x − 2y = 9 through (3, −1):
5(3) − 2(−1) = 17
5x − 2y = 17
```

## Special cases

- Through (a, b), parallel to the x-axis: y = b.
- Through (a, b), parallel to the y-axis: x = a.
- A line through the origin has c = 0, so y = mx.
- If the question gives the line through two points, find the gradient from the points first.

## Parallel lines in shapes

- A **parallelogram** has two pairs of parallel opposite sides. Show it by finding all four gradients and pairing opposite sides.
- A **trapezium** has exactly one pair of parallel sides. Show one pair of gradients is equal and the other pair is not.
- Missing vertex of a parallelogram ABCD: D = A + C − B.
- Three points are in a straight line if the gradient between the first two equals the gradient between the second two.

## Must-know distinctions

| Parallel | Perpendicular |
|---|---|
| gradients are equal | gradients multiply to −1 |
| same left side in ax + by = c | left side changes (a and b swap, one sign flips) |
| never meet | meet at a right angle |

## Exam traps

- Reading the gradient of 3x + 2y = 7 as 3. It is −3/2.
- Dividing only some terms by 2 in 2y = 3x + 1.
- Copying the intercept as well as the gradient.
- Writing y − 6 = m(x − 2) for the point (−2, 6). The bracket is (x + 2).
- Giving a final answer in a different form from the one asked, such as y = mx + c when integer coefficients were requested.
- Not checking: substitute the point into your answer. It takes ten seconds.

| Command word | What to do |
|---|---|

## Self-test

1. Find the gradient of a line parallel to 3x + 2y = 8.
2. Find the equation of the line parallel to y = 4x − 3 through (−1, 3).
3. Find the gradient of a line parallel to 6y = 4x + 1.
4. Find the equation of the line parallel to 6y = 4x + 1 through (3, 7).
5. The line kx − 2y = 5 is parallel to y = 3x. Find k.
6. Write down the equation of the line through (−2, 5) parallel to the y-axis.
7. Write down the equation of the line through (4, −3) parallel to the x-axis.
8. Are y = 2x + 1 and 4x − 2y = 7 parallel? Explain.
9. Find the equation of the line through (−1, −5) parallel to y = 3x + 1.
10. Find the equation of the line through (6, 2) parallel to x + 3y = 9, in the form x + 3y = c.

### Answers

1. 2y = −3x + 8, so the gradient is **−3/2**.
2. m = 4, 3 = −4 + c, c = 7, so **y = 4x + 7**.
3. y = 2/3 x + 1/6, so the gradient is **2/3**.
4. 7 = 2/3(3) + c, so c = 5 and **y = 2/3 x + 5**.
5. −2y = −kx + 5, so y = k/2 x − 5/2. k/2 = 3, so **k = 6**.
6. **x = −2**.
7. **y = −3**.
8. 4x − 2y = 7 gives y = 2x − 7/2, with gradient 2. Both gradients are 2 and the intercepts differ, so the lines are **parallel**.
9. −5 = 3(−1) + c, so c = −2 and **y = 3x − 2**.
10. 6 + 3(2) = 12, so **x + 3y = 12**.
