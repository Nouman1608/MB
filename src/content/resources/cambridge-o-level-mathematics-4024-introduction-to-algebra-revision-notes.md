Condensed notes for subtopic **2.1 Introduction to algebra** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025–2027. Full explanations and worked examples are in the [introduction to algebra study guide](/resources/cambridge-o-level-mathematics-4024-introduction-to-algebra/); exam-style questions are in the [introduction to algebra practice questions](/resources/cambridge-o-level-mathematics-4024-introduction-to-algebra-practice/).

## Syllabus outcomes

- **2.1.1** Know that letters can be used to represent generalised numbers.
- **2.1.2** Substitute numbers into expressions and formulas.

Tested on both Paper 1 (no calculator) and Paper 2 (calculator).

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Variable | A letter whose value can change | x in 3x + 1 |
| Generalised number | A letter standing for any number of a stated kind | n for any integer |
| Term | One number, letter or product of them | −5ab |
| Coefficient | Number in front of the letters | −5 in −5ab |
| Constant | A term with no letter | 7 in x² + 7 |
| Expression | Terms joined by + and −, no equals sign | 4p − q |
| Equation | Statement that two expressions are equal for certain values | 2x + 1 = 9 |
| Formula | A rule linking quantities | v = u + at |
| Subject | The letter on its own on one side of a formula | v in v = u + at |
| Substitute | Replace letters by given numbers | x = 2 in 3x → 3(2) = 6 |

## Notation to recall

```
4y      = 4 × y
xy      = x × y
y²      = y × y
3y²     = 3 × y × y
(3y)²   = 9y²
x/y     = x ÷ y
−y²     = −(y²)
```

## Generalised numbers (n an integer)

```
consecutive integers         n, n + 1, n + 2
even                         2n
odd                          2n + 1   or   2n − 1
consecutive even numbers     2n, 2n + 2
multiple of k                kn
square numbers               n²
```

**Proof pattern:** write the general form, simplify, then factor to show the property.

```
Sum of two consecutive odd numbers:
(2n + 1) + (2n + 3) = 4n + 4 = 4(n + 1)   → always a multiple of 4
```

## Substitution method

1. Write the expression again with each letter replaced by its value **in brackets**.
2. Work out powers before multiplication and division.
3. Do multiplication and division before addition and subtraction.
4. Treat a fraction line as brackets around the whole top and the whole bottom.
5. Paper 2: keep the full calculator value, round once at the end (3 significant figures unless told otherwise).

## Sign rules for substitution

```
(−) × (−) = +          (−)² = +          (−)³ = −
a − (−b) = a + b       −(−3)² = −9       ÷ ½ = × 2
```

**Example set** with p = −2, q = 5, r = −1:

```
p²              = 4
3pq             = 3(−2)(5) = −30
p − q           = −2 − 5 = −7
q² − 4pr        = 25 − 4(−2)(−1) = 25 − 8 = 17
pqr             = (−2)(5)(−1) = 10
2p³             = 2(−8) = −16
(q − p)/r       = 7 ÷ (−1) = −7
```

## Formulas worth practising

| Formula | Typical substitution |
|---|---|
| v = u + at | u = 4, a = −1.5, t = 6 → v = 4 − 9 = −5 |
| s = ut + ½at² | u = 2, a = 4, t = 3 → s = 6 + 18 = 24 |
| v² = u² + 2as | u = 12, a = −3, s = 10 → v² = 144 − 60 = 84, v = 9.17 (3 s.f.) |
| A = ½(a + b)h | a = 4, b = 10, h = 5 → A = 35 |
| V = ⅓πr²h | r = 2.5, h = 6 → V = 39.3 (3 s.f.) |

## Exam traps

- 2x² is not (2x)². Only x is squared.
- −3² = −9 but (−3)² = 9. Calculators follow the same rule, so type brackets.
- 5 − (−2) = 7. Write the brackets to see the double negative.
- In (a + b)/c, add a and b before dividing.
- Do not round part-way through a calculation.
- A list of numerical examples is not a proof; use n.
- Final answers such as 1.80 keep the zero when it is a significant figure.
- Check the context: a negative displacement or temperature is allowed; a negative length is a warning sign.

## Self-test

1. Write an expression for the product of two consecutive integers.
2. Write an expression for any odd number.
3. Find the value of 2x² when x = −4.
4. Find the value of (2x)² when x = −4.
5. Find x² − 3x + 2 when x = −4.
6. Given a = 6 and b = −2, find a − 3b.
7. Given a = 6 and b = −2, find a/b + b².
8. Find 5y² − 3y + 1 when y = −2.
9. Use v = u + at to find v when u = 20, a = −4 and t = 3.5.
10. Use K = ½mv² to find K when m = 0.4 and v = 7.5.
11. Show that the sum of an even number and the next odd number is always odd.
12. Use v² = u² + 2as to find v when u = 12, a = −3, s = 10, to 3 significant figures.

**Answers**

1. n(n + 1), which can also be written n² + n.
2. 2n + 1 (or 2n − 1), where n is an integer.
3. 2(−4)² = 2 × 16 = **32**.
4. (−8)² = **64**.
5. 16 + 12 + 2 = **30**.
6. 6 − 3(−2) = 6 + 6 = **12**.
7. 6 ÷ (−2) + (−2)² = −3 + 4 = **1**.
8. 5(4) − 3(−2) + 1 = 20 + 6 + 1 = **27**.
9. v = 20 + (−4)(3.5) = 20 − 14 = **6**.
10. K = ½(0.4)(7.5)² = 0.2 × 56.25 = **11.25**.
11. 2n + (2n + 1) = 4n + 1 = 2(2n) + 1, which is one more than an even number, so it is odd.
12. v² = 144 − 60 = 84, so v = √84 = **9.17** (3 s.f.).
