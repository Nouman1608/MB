These questions cover section **3.4 Differentiation** of Pure Mathematics 3 (Paper 3) in the Cambridge International AS & A Level Mathematics 9709 syllabus for 2026 and 2027. All angles are in radians. Give exact answers where asked. The number in square brackets after the last part of each question is the total for the whole question.

## Questions

### Section A: short questions

**1.** Differentiate with respect to x

**(a)** x³e^(−2x)

**(b)** ln(cos x). **[4]**

**2.** Find dy/dx when y = tan⁻¹(x/3), giving your answer as a single fraction. **[2]**

**3.** Find dy/dx when y = (3x − 1)/(x² + 1), simplifying the numerator. **[3]**

**4.** Find the exact gradient of the curve y = x tan⁻¹ x at the point where x = 1. **[3]**

**5.** A curve has parametric equations x = t² + 2t, y = t³ − 3t.

**(a)** Show that, for t ≠ −1, dy/dx = 3(t − 1)/2.

**(b)** Find the coordinates of the point on the curve where the gradient is zero. **[5]**

**6.** The curve x² + 3xy − y² = 3 passes through the point (1, 1). Find the gradient of the curve at this point. **[4]**

### Section B: longer questions

**7.** The curve y = e^(−x) sin x is defined for 0 ≤ x ≤ π.

**(a)** Find the exact coordinates of the stationary point.

**(b)** Determine the nature of this stationary point. **[6]**

**8.** The curve C has equation y = eˣ/(x + 2), for x > −2.

**(a)** Show that dy/dx = (x + 1)eˣ/(x + 2)².

**(b)** Find the equation of the tangent to C at the point where x = 0, and the coordinates of the point where this tangent meets the x-axis.

**(c)** Find the exact coordinates of the stationary point of C. **[7]**

**9.** A curve has parametric equations x = 3 − cos 2t, y = 2 sin t, for 0 < t < π.

**(a)** Show that dy/dx = 1/(2 sin t), for t ≠ π/2.

**(b)** Find the equation of the normal to the curve at the point where t = π/6.

**(c)** Show that the Cartesian equation of the curve can be written as x = 2 + y²/2. **[8]**

**10.** A curve has equation x² − 2xy + 3y² = 8.

**(a)** Show that dy/dx = (y − x)/(3y − x).

**(b)** Find the coordinates of the points on the curve at which the tangent is parallel to the x-axis. **[7]**

**11.** A curve has equation e^(2x) + e^y = xy + 2.

**(a)** Show that the curve passes through the origin.

**(b)** Find the equation of the normal to the curve at the origin. **[5]**

**12.** The curve C has equation y = tan⁻¹(eˣ).

**(a)** Find dy/dx.

**(b)** Show that the gradient of C is greatest when x = 0, and state this greatest gradient. **[6]**

## Answers

**1.** **(a)** Product rule: 3x²e^(−2x) + x³(−2e^(−2x)) [1] = **x²e^(−2x)(3 − 2x)** [1]

**(b)** (1/cos x) × (−sin x) [1] = **−tan x** [1]

**2.** (1/3)/(1 + x²/9) [1] = **3/(9 + x²)** [1]

**3.** dy/dx = [3(x² + 1) − (3x − 1)(2x)]/(x² + 1)² [1]. Numerator 3x² + 3 − 6x² + 2x [1]. **dy/dx = (3 + 2x − 3x²)/(x² + 1)²** [1]

*Examiner insight:* the quotient-rule structure earns the method mark even if the expansion slips, so write it in full first.

**4.** dy/dx = tan⁻¹ x + x/(1 + x²) [1]. At x = 1: tan⁻¹ 1 + 1/2 [1] = **π/4 + ½** [1]

**5.** **(a)** dx/dt = 2t + 2 and dy/dt = 3t² − 3 [1]. dy/dx = 3(t² − 1)/(2(t + 1)) [1] = 3(t − 1)(t + 1)/(2(t + 1)) = 3(t − 1)/2 [1]

**(b)** t = 1 [1], so x = 3, y = −2: **(3, −2)** [1]

**6.** 2x + 3y + 3x dy/dx − 2y dy/dx = 0: the x² and y² terms [1], the product 3xy differentiated as 3y + 3x dy/dx [1]. At (1, 1): 2 + 3 + 3 dy/dx − 2 dy/dx = 0 [1]. **dy/dx = −5** [1]

**7.** **(a)** dy/dx = −e^(−x) sin x + e^(−x) cos x [1] = e^(−x)(cos x − sin x) = 0 [1]. e^(−x) > 0, so tan x = 1 and x = π/4 [1]. **(π/4, (√2/2)e^(−π/4))** [1]

**(b)** d²y/dx² = −e^(−x)(cos x − sin x) + e^(−x)(−sin x − cos x) = −2e^(−x) cos x [1]. At x = π/4 this is negative, so the point is a **maximum** [1]

**8.** **(a)** [(x + 2)eˣ − eˣ × 1]/(x + 2)² [1] = eˣ(x + 1)/(x + 2)² [1]

**(b)** At x = 0: y = ½ and dy/dx = 1/4 [1]. Tangent **y = x/4 + ½** [1]. y = 0 gives x = −2: **(−2, 0)** [1]

**(c)** eˣ > 0, so x + 1 = 0 and x = −1 [1]. y = e^(−1)/1: **(−1, 1/e)** [1]

**9.** **(a)** dx/dt = 2 sin 2t [1] and dy/dt = 2 cos t [1]. dy/dx = 2 cos t/(4 sin t cos t) = 1/(2 sin t), cancelling cos t, which is non-zero for t ≠ π/2 [1]

**(b)** t = π/6: x = 3 − cos(π/3) = 5/2, y = 1 [1]. Tangent gradient 1/(2 × ½) = 1, so normal gradient −1 [1]. **y = 7/2 − x** [1]

**(c)** cos 2t = 1 − 2 sin²t, so x = 2 + 2 sin²t [1]. sin t = y/2, so x = 2 + 2(y²/4) = 2 + y²/2 [1]

*Examiner insight:* (c) gives a check on (a): from x = 2 + y²/2, dx/dy = y, so dy/dx = 1/y = 1/(2 sin t).

**10.** **(a)** 2x − (2y + 2x dy/dx) [1] + 6y dy/dx = 0 [1]. dy/dx(6y − 2x) = 2y − 2x [1]. dy/dx = (y − x)/(3y − x) [1]

**(b)** dy/dx = 0 when y = x [1]. Substitute: x² − 2x² + 3x² = 8, so x² = 4 [1]. **(2, 2) and (−2, −2)** [1]

*Examiner insight:* check that the denominator 3y − x is not zero at these points: it equals 4 and −4.

**11.** **(a)** At (0, 0): e⁰ + e⁰ = 2 and 0 × 0 + 2 = 2 [1]

**(b)** 2e^(2x) + eʸ dy/dx [1] = y + x dy/dx [1]. At (0, 0): 2 + dy/dx = 0, so dy/dx = −2 [1]. Normal gradient ½: **y = x/2** [1]

**12.** **(a)** eˣ/(1 + (eˣ)²) [1] = **eˣ/(1 + e^(2x))** [1]

**(b)** Let g(x) = eˣ/(1 + e^(2x)). g′(x) = [eˣ(1 + e^(2x)) − eˣ × 2e^(2x)]/(1 + e^(2x))² [1] = eˣ(1 − e^(2x))/(1 + e^(2x))² [1]. g′(x) = 0 when e^(2x) = 1, that is x = 0 [1]. g′ is positive for x < 0 and negative for x > 0, so the gradient is greatest at x = 0, where it equals **½** [1]

## Where marks are usually lost

- Squaring only the coefficient inside tan⁻¹, as in 2/(1 + 2x²).
- Losing the minus sign from e^(−2x) or cos x.
- Missing the product rule on a term like 3xy.
- Finding a relation such as y = x and not substituting it back into the curve.
- Giving the tangent gradient when the normal was asked for.
- Not justifying why a factor such as eˣ or cos t can be divided out.
