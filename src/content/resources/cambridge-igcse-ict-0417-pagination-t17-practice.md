## Section A: short answers

**1.** State the purpose of a column break. **[1]**

**2.** Which **one** of the following is needed so that a title can be in one column with the text below it in two columns, on the same page?

A: page break

B: column break

C: continuous section break

D: next page section break

**[1]**

**3.** State the difference between an automatic page break and a manual page break. **[2]**

**4.** Give **two** page settings that can be different in different sections of a document. **[2]**

**5.** Give **one** reason why a chapter in a report should start after a page break. **[1]**

## Section B: structured questions

**6.** A student pushes the heading *Conclusion* onto a new page by pressing Enter several times.

**(a)** Explain why this is not a good method. **[2]**

**(b)** State the break that should be used. **[1]**

**7.** A portrait report contains a wide table on page 6, which must be printed in landscape.

**(a)** Explain why a page break cannot be used to make only page 6 landscape. **[2]**

**(b)** Describe how breaks should be used to achieve this. **[2]**

**8.** A school newsletter is laid out in three columns. The editor wants each of three articles to begin at the top of a column.

**(a)** State the break to use and where to place it. **[2]**

**(b)** Explain why this is better than adding blank lines. **[1]**

**9.** A booklet has a cover with no page number, a contents page numbered *i*, and then chapters numbered from 1.

Explain how section breaks make this numbering possible. **[3]**

**10.** For each situation, name the most suitable break.

**(a)** A table would otherwise be split across pages 3 and 4. **[1]**

**(b)** The final page of a two-column document should return to one column. **[1]**

**(c)** Each chapter of a printed book should start on a right-hand page. **[1]**

**(d)** A contact box would otherwise be split between column 1 and column 2. **[1]**

**11.** A report has a different header for each chapter, showing that chapter's title.

Explain why section breaks are needed between the chapters. **[2]**

**12.** Explain the purpose of setting page, section and column breaks in a long document. **[6]**

## Answers

**1.** To make the text after it start at the top of the next column. **[1]**

**2.** C: continuous section break. **[1]**

**3.** An automatic page break is placed by the software when a page is full and moves when text is added or removed (1); a manual page break is inserted by the user and always starts a new page at that point (1). **[2]**

**4.** Any two: orientation (1); margins (1); paper size (1); number of columns (1); headers and footers (1); page numbering (1). **[2]**

**5.** Any one: so it begins at the top of a page and is easy to find (1); so it does not begin part-way down the page after the previous chapter (1); so the structure stays the same when earlier text is edited (1). **[1]**

**6. (a)** If text is added or removed earlier in the report, the blank lines move with it (1), so the heading may no longer be at the top of a page, or a blank page or gap may appear (1). **[2]**

**(b)** A page break (inserted before the heading). **[1]**

**7. (a)** A page break only starts a new page; it does not create a new section (1), and orientation applies to a whole section, so the whole report would change (1). **[2]**

**(b)** Insert a next page section break before the table and another after it (1); set only the section containing the table to landscape (1). **[2]**

**8. (a)** A column break (1), placed immediately before the heading of the second and the third article (1). **[2]**

**(b)** A column break stays in place when text is edited, whereas blank lines move and the articles would no longer start at the top of a column. **[1]**

**9.** A next page section break is inserted after the cover and after the contents page (1). Each section can have its own page numbering settings (1), so the cover has no number, the contents section uses roman numerals, and the chapters' section restarts numbering at 1 (1). **[3]**

**10. (a)** Page break (before the table). **[1]**

**(b)** Section break (continuous, or next page). **[1]**

**(c)** Odd page section break. **[1]**

**(d)** Column break (before the contact box). **[1]**

**11.** Headers and footers are set for a whole section (1), so each chapter must be in its own section, separated by section breaks, for its header to show a different title (1). **[2]**

**12.** Up to 6 marks, from points about all three breaks:
- Page breaks start a new part, such as a chapter or appendix, at the top of a page (1).
- They keep tables or images whole on one page and stop headings being stranded (1).
- They fix the structure so it does not move when text is edited, unlike blank lines (1).
- Section breaks allow page settings to change part-way through the document (1), such as orientation for a landscape page or the number of columns (1).
- They allow different headers, footers or page numbering in different parts (1).
- Column breaks start text, such as an article, at the top of the next column (1).
- They keep an item together in one column or help balance columns (1). **[6]**

## Frequently asked questions

**Is "keep with next" a type of break?**
No. It is a paragraph setting that stops a heading being separated from the next paragraph. It is useful alongside breaks, but the syllabus statement asks about page, section and column breaks.

**Do I need to know how the software stores section breaks?**
You need to know the purpose of each break. Knowing that deleting a section break can change the layout of the text before it is useful in practical tasks.
