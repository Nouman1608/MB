These notes condense section 9.2 of Cambridge IGCSE ICT 0417, which covers "the need for copyright legislation and the principles of copyright relating to computer software (e.g. software piracy)" and "the methods that software producers employ to prevent software copyright legislation being broken". For full explanations and worked examples, read the [copyright study guide](/resources/cambridge-igcse-ict-0417-copyright/), then try the [copyright practice questions](/resources/cambridge-igcse-ict-0417-copyright-practice/).

## Syllabus coverage

| Syllabus wording | What you must be able to do |
|---|---|
| The need for copyright legislation | Explain why software producers need legal protection |
| Principles of copyright relating to computer software | Say what users may and may not do with licensed software; define piracy |
| Methods software producers employ | Describe each anti-copying method and how it works |

## Why the law is needed: five points

1. Software is expensive and slow to develop, but **cheap and quick to copy**.
2. Each digital copy is **identical** to the original, so a pirated copy is as good as a bought one.
3. The law protects the producer's **income** from licence sales.
4. Protected income **funds new software and updates**, so innovation continues.
5. The law lets producers **take offenders to court** and claim compensation.

A sixth point, useful in longer answers: tampered pirated copies can contain malware, which damages the producer's **reputation**.

## The principles in one list

Buying software buys a **licence to use it**; copyright stays with the producer. Without permission you may not:

- copy it for others (free or paid);
- install it on more devices or for more users than licensed;
- lend or rent it;
- modify the code or reuse parts of it;
- remove copyright notices or bypass protection;
- exceed the number of simultaneous network users.

A licence may allow one back-up copy for the purchaser only.

## Licence types

| Licence | Covers |
|---|---|
| Single-user | One user or one device |
| Multi-user | A stated number of users or devices |
| Site | Every device at one location |
| Network | A set number of people using it at once |
| Subscription | Use while payments continue |

## Forms of piracy

- Giving copies to friends or family.
- One licence installed on many workplace computers.
- Downloading illegal copies from file-sharing sites.
- Selling counterfeit discs or downloads.
- Using cracks or key generators to defeat activation.

**Effects on the producer**: lost income, less money for development, job losses, reputational harm.

**Effects on the user of a pirated copy**: no updates or support, malware risk, possible fines or prosecution.

## Protection methods: what to write

| Method | One-sentence description |
|---|---|
| Licence agreement | Terms the user must accept before installation, limiting how many devices can use it |
| Product key | Unique code entered during installation; the software will not install or run without it |
| Online activation | Key checked by the producer's server and tied to a device; a used key is refused elsewhere |
| Registration | User records their details with the producer, linking the copy to a named owner |
| Dongle | Hardware device that must be plugged in for the program to run |
| Original media | The original disc must be in the drive while the program runs |
| Holograms | Hard-to-copy labels showing the packaging is genuine |
| Encryption | Program code is encrypted and needs a decryption key to run |
| DRM | Digital rights management restricts copying, sharing or playing of files |
| Subscription account | Program works only while the user is signed in to a paid account |

## Key terms

| Term | Meaning |
|---|---|
| Copyright | Legal right giving the creator control over copying and use of an original work |
| Copyright legislation | The laws that make copying without permission illegal |
| Licence | Permission to use software under stated conditions |
| Licence agreement (EULA) | The document setting out those conditions |
| Software piracy | Illegal copying, distribution or use of software |
| Counterfeit software | Illegal copies made to look like the genuine product |
| Product key | Unique code that proves a copy is licensed |
| Activation | Online check that links a key to one device |
| Dongle | Plug-in hardware key needed to run a program |

## Exam traps

- "You own the software" is wrong: you own a **licence**.
- A product key does not stop files being **copied**; it stops an unlicensed copy being **used**.
- Free sharing is still piracy: money does not have to change hands.
- Firewalls and antivirus protect **data**, not the producer's copyright.
- For **describe**, say how the method works, not just its name.
- Keep answers about **software** when the question says software; examples about photographs score nothing there.
- Holograms help buyers spot fakes; they do not prevent digital copying.

## Self-test

1. Give two reasons why software is easy to pirate.
2. State what a buyer actually receives when buying software.
3. Define *software piracy*.
4. A firm with 12 staff buys a single-user licence and installs it on all 12 computers. How many installations are unlicensed?
5. Name the type of licence that covers every computer in one school.
6. Describe how online activation prevents a key being used twice.
7. Describe how a dongle protects software.
8. Give one limitation of using holograms.
9. Give two effects of piracy on the producer.
10. Give two risks for a person using a pirated copy.
11. Why might a producer require the original disc in the drive, and why is this less used today?
12. Explain why combining several protection methods is more effective than one.

## Self-test answers

1. Copies cost almost nothing to make, and every copy is identical to the original.
2. A licence: permission to use it under stated conditions.
3. The illegal copying, distribution or use of software.
4. 11.
5. A site licence.
6. The key is sent to the producer's server and linked to the first device; when it is entered on another device the server sees it has been used and refuses activation.
7. The program checks for the dongle and will only run while it is plugged into the computer.
8. They show packaging is genuine but do not stop digital copies being made or downloaded.
9. Any two: lost income, less money for development, job losses, harm to reputation.
10. Any two: no updates or support, malware, fines or prosecution.
11. A copy of the program without the disc will not run; many computers no longer have optical drives and most software is downloaded.
12. Each method has a weakness (keys can be shared, details can be faked), so a pirate must defeat every layer, which is harder.
