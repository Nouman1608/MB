## Section A: short questions

**1.** State the type of bonding present in alkanes. **[1]**

**2.** Alkanes are described as saturated hydrocarbons.

**(a)** Explain the meaning of *saturated*. **[1]**

**(b)** Explain the meaning of *hydrocarbon*. **[1]**

**3.** Which formula represents an alkane?

A: C₄H₈

B: C₅H₁₂

C: C₆H₁₂

D: C₃H₇OH

**[1]**

**4.** Alkanes are described as generally unreactive. Name the **two** types of reaction that alkanes do undergo. **[2]**

**5.** Balance the equation for the complete combustion of pentane.

C₅H₁₂ + ...O₂ → ...CO₂ + ...H₂O **[2]**

**6.** *(Extended)* Which condition is needed for methane to react with chlorine?

A: a nickel catalyst

B: a temperature of 300 °C

C: ultraviolet light

D: an acid catalyst

**[1]**

**7.** *(Extended)* Define a *substitution reaction*. **[1]**

## Section B: structured questions

**8.** Butane, C₄H₁₀, is used as a fuel in camping stoves.

**(a)** Draw the displayed formula of butane. **[1]**

**(b)** Write a balanced symbol equation for the complete combustion of butane. **[2]**

**(c)** In a poorly ventilated tent, the stove burns butane in a limited supply of oxygen. Name the toxic gas that can form. **[1]**

**9.** A student shakes hexane with aqueous bromine in a test-tube at room temperature.

**(a)** State the colour of the mixture after shaking. **[1]**

**(b)** Explain this observation in terms of the bonding in hexane. **[1]**

**10.** *(Extended)* Ethane reacts with chlorine in ultraviolet light.

**(a)** Explain why ultraviolet light is needed. **[1]**

**(b)** Write a balanced equation for the reaction, assuming monosubstitution. **[1]**

**(c)** Draw the displayed formula of the organic product. **[1]**

**(d)** Name the inorganic product. **[1]**

**11.** *(Extended)* Propane, CH₃CH₂CH₃, reacts with chlorine in ultraviolet light to form two different monosubstituted products.

**(a)** Give the molecular formula of both products. **[1]**

**(b)** Draw the structural formulae of the two products. **[2]**

**(c)** State the term used to describe two compounds with the same molecular formula but different structural formulae. **[1]**

**12.** *(Extended)* A student writes the following equation for the reaction of methane with chlorine:

CH₄ + Cl₂ → CH₄Cl₂

**(a)** Explain why the formula of the product is impossible. **[1]**

**(b)** State the type of reaction the student's equation represents, and explain why alkanes cannot react in this way. **[2]**

**(c)** Write the correct equation. **[1]**

**13.** Methane is the main constituent of natural gas.

**(a)** Write a balanced equation for the complete combustion of methane. **[1]**

**(b)** Suggest why methane is useful as a fuel. **[1]**

## Answers

**1.** Single covalent (bonds) [1].

**2.** **(a)** All the carbon–carbon bonds are single bonds [1].

**(b)** A compound containing hydrogen and carbon only [1].

**3.** **B** [1]. C₅H₁₂ fits CₙH₂ₙ₊₂ with n = 5 (2 × 5 + 2 = 12). A and C fit CₙH₂ₙ; D is an alcohol.

**4.** Combustion [1]; substitution (with chlorine) [1].

**5.** C₅H₁₂ + **8**O₂ → **5**CO₂ + **6**H₂O. Correct CO₂ and H₂O coefficients [1]; correct O₂ coefficient [1].
*Check: oxygen on the right = (5 × 2) + 6 = 16 atoms = 8O₂.*

**6.** **C** [1]. A nickel catalyst is used to add hydrogen to alkenes; 300 °C with an acid catalyst is the condition for adding steam to ethene.

**7.** A reaction in which one atom or group of atoms is replaced by another atom or group of atoms [1].

**8.** **(a)** Four carbon atoms in an unbranched chain, joined by single bonds, with every C–H bond shown and ten hydrogen atoms in total [1]:

```
    H   H   H   H
    |   |   |   |
H — C — C — C — C — H
    |   |   |   |
    H   H   H   H
```

**(b)** 2C₄H₁₀ + 13O₂ → 8CO₂ + 10H₂O. Correct formulae [1]; correct balancing [1]. *Accept C₄H₁₀ + 6½O₂ → 4CO₂ + 5H₂O.*

**(c)** Carbon monoxide [1].

**9.** **(a)** Orange (the bromine is not decolourised) [1].

**(b)** Hexane is saturated: it has only single carbon–carbon bonds / no C=C double bond, so bromine cannot add to it [1].

**10.** **(a)** It provides the activation energy (needed to start the reaction) [1].

**(b)** C₂H₆ + Cl₂ → C₂H₅Cl + HCl [1].

**(c)** Two carbons joined by a single bond, one chlorine atom and five hydrogen atoms, all bonds shown [1]:

```
    H   H
    |   |
H — C — C — Cl
    |   |
    H   H
```

**(d)** Hydrogen chloride [1].

**11.** **(a)** C₃H₇Cl [1].

**(b)** CH₂ClCH₂CH₃ [1]; CH₃CHClCH₃ [1]. *Accept CH₃CH₂CH₂Cl for the first. Do not award two marks for CH₂ClCH₂CH₃ and CH₃CH₂CH₂Cl: these are the same molecule.*

**(c)** (Structural) isomers [1].

**12.** **(a)** The carbon atom would form six bonds; carbon forms only four [1].

**(b)** Addition [1]. Methane is saturated / has no C=C double bond, so there is no bond for chlorine to add across; a hydrogen atom must be replaced instead [1].

**(c)** CH₄ + Cl₂ → CH₃Cl + HCl [1].

**13.** **(a)** CH₄ + 2O₂ → CO₂ + 2H₂O [1].

**(b)** Its combustion is exothermic / it releases a large amount of (heat) energy when it burns [1]. *Do not credit "it burns easily" alone.*

## Where marks are usually lost

- Defining "saturated" as "containing only carbon and hydrogen" – that is the definition of a hydrocarbon.
- Giving "light" or "heat" instead of **ultraviolet light** for the chlorine reaction.
- Leaving out hydrogen chloride from substitution equations.
- Drawing the same propane product twice, written from opposite ends.
- Losing the balancing mark on even-numbered alkanes by leaving half an O₂ unexplained or by miscounting the oxygen atoms on the right.
- Missing out C–H bonds in a displayed formula.
