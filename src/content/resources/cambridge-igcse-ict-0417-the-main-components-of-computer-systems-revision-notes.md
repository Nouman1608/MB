Section 1.2 of Cambridge IGCSE ICT 0417 covers four parts of a computer system and the differences between them: the role of the CPU, the characteristics of ROM and RAM, the characteristics of input and output devices, and backing storage compared with internal memory.

Condensed for revision. For full explanations and a worked compare answer, use the [main components study guide](/resources/cambridge-igcse-ict-0417-the-main-components-of-computer-systems/), then practise with the [computer systems practice questions](/resources/ict-computer-systems-practice/).

## The system in one line

Input device → RAM → CPU processes → output device, with backing storage keeping anything that must be saved and ROM supplying the start-up instructions.

## CPU: four points that score

- Carries out (executes) the instructions of the program being run.
- Processes data: calculations, comparisons and decisions.
- Controls the flow of data between input devices, memory and output devices.
- Works on instructions and data held in RAM; programs on backing storage must be loaded into RAM first.

## ROM versus RAM

| Point of comparison | ROM | RAM |
|---|---|---|
| Volatility | Non-volatile | Volatile |
| Can contents change? | No (read only) | Yes (read and write) |
| Typical contents | Start-up (boot) instructions | Operating system, programs and data in use |
| Capacity | Small | Larger |
| Contents over time | Fixed | Change constantly |

Memory hook: **R**AM is **R**ewritable and **R**uns out when the power goes; R**O**M stays **O**n.

## Input versus output devices

| Input devices | Output devices |
|---|---|
| Send data into the computer | Present or use data that comes out of the computer |
| Capture data from a user or the environment | Give results to a user, or make something happen |
| Keyboard, mouse, microphone, scanner, sensor | Monitor, printer, speaker, projector, actuator |

A touch screen is both: input when touched, output when displaying. Say which role you mean.

## Backing storage versus internal memory

| Backing storage | Internal memory |
|---|---|
| Long-term storage of files and programs | ROM: start-up instructions; RAM: work in progress |
| Non-volatile | RAM volatile, ROM non-volatile |
| Very large capacity | Smaller capacity |
| Slower | Faster |
| Lower cost per gigabyte | Higher cost per gigabyte |
| Not directly accessed by the CPU | Directly accessed by the CPU |
| Can be internal or external and portable | Fixed inside the computer |

## Key terms

| Term | Meaning |
|---|---|
| CPU | The component that processes instructions and data to produce an output |
| Internal memory | Memory directly accessible by the CPU: RAM and ROM |
| Volatile | Data is lost when the power is removed |
| Non-volatile | Data is kept without power |
| Start-up instructions | The program in ROM that starts the computer and loads the operating system |
| Backing storage | Non-volatile storage for keeping data and programs permanently |
| Input device | Hardware used to enter data or instructions into a computer |
| Output device | Hardware used to show, print, sound or act on the results of processing |

## Exam traps

- "Memory" and "storage" are not the same word in this syllabus. RAM is memory; a hard disk is backing storage.
- Only RAM is volatile. Do not say "internal memory is volatile" in a question that includes ROM.
- The CPU does not store files.
- A difference needs both sides: "RAM is volatile **whereas** ROM is non-volatile."
- Programs run from RAM, not straight from backing storage.
- On a typical computer, ROM does not hold the operating system: it holds the start-up instructions that load the operating system from backing storage.

## Self-test

1. Describe the role of the CPU.
2. Give **two** characteristics of ROM.
3. Give **two** characteristics of RAM.
4. State **one** difference between ROM and RAM.
5. Why does a program on a hard disk have to be loaded before it can be run?
6. Give **two** examples of input devices and **two** of output devices.
7. State the difference between an input device and an output device.
8. Why can a touch screen be described as both an input and an output device?
9. Give **three** characteristics of backing storage.
10. A student loses her essay in a power cut although she had been typing for an hour. Explain why.
11. State **one** way backing storage and ROM are the same, and **one** way they differ.
12. Why does adding more RAM allow more programs to be open at once?

## Self-test answers

1. It carries out program instructions and processes data entered into the computer to produce an output, controlling the flow of data between components.
2. Any two: non-volatile; read only; holds start-up instructions; small capacity.
3. Any two: volatile; read and write; holds programs and data in use; larger capacity than ROM.
4. For example, ROM is non-volatile whereas RAM is volatile; or ROM cannot be changed whereas RAM can.
5. The CPU can only access instructions and data held in RAM, not directly on backing storage.
6. Input: keyboard, mouse, microphone, scanner, sensor. Output: monitor, printer, speaker, projector, actuator.
7. An input device sends data into the computer; an output device presents or uses data coming out of it.
8. It accepts input when touched and displays output on the same screen.
9. Any three: non-volatile; large capacity; slower than internal memory; cheaper per gigabyte; not directly accessed by the CPU; can be portable.
10. The essay was only in RAM, which is volatile, so it was lost when the power failed because it had not been saved to backing storage.
11. Same: both are non-volatile. Differ: backing storage can be written to and has a much larger capacity, whereas ROM is read only and small.
12. RAM holds the programs and data currently in use, so a larger capacity holds more of them at the same time.
