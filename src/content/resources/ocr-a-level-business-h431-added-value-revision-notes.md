## The four specification points

1. Explain what is meant by added value.
2. Explain how added value can be calculated.
3. Calculate added value.
4. Evaluate the usefulness of added value to a business and its stakeholders.

## Core recall

### Definition and formula

Added value is the difference between the selling price and the cost of bought-in inputs.

- Added value per unit = selling price − bought-in cost per unit.
- Added value as a percentage of price = added value ÷ selling price × 100.
- Total added value = added value per unit × units sold.
- Added value per employee = total added value ÷ number of employees.

Bought-in inputs are materials, components and services bought from other businesses. Wages and rent are not deducted.

### Added value is not profit

Added value pays for wages, overheads and profit:

Total added value = wages + overheads + profit (plus other costs of the business such as interest and depreciation).

A business with high added value but high wages and overheads may make little profit.

### Ways to increase added value

| Method | Example |
|---|---|
| Better quality or design | Hand-finished furniture |
| Branding | Premium price for a known name |
| Add services | Delivery, installation, guarantees |
| Do more work in-house | Make a component rather than buy it |
| Cut input costs | Negotiate with suppliers; reduce waste |
| Niche market | Customers who pay more |

### Usefulness and limits

| Useful | Limits |
|---|---|
| Shows value the business itself creates | It is not profit |
| Compares products and firms | Depends on what counts as an input |
| Points to where to add value | Price may reflect market power |
| Shows capacity to pay wages and profit | Ignores quality and satisfaction |

Stakeholders: owners (value available for profit), employees (pool for wages), suppliers (pressure on input prices), customers (pay for the added value in the price).

## Quick worked reminder

Hearth Bakery (invented): price £2.80; bought-in £0.90. Added value £1.90 (67.9%). 100,000 loaves give £190,000; with 8 employees, £23,750 each. The £190,000 is wages £110,000 + overheads £50,000 + profit £30,000.

Organic flour: bought-in £1.10; price £3.30; added value £2.20 (66.7%). At 92,000 loaves, £202,400, a rise of £12,400. At 85,000 loaves, £187,000, a fall of £3,000.

Chairs: Value Chairs £60 − £35 = £25 (41.7%). Atelier Chairs £420 − £150 = £270 (64.3%).

## Services and make-or-buy

- Services: price minus bought-in items (products, laundry). Staff time is paid out of added value, so percentages are high.
- Make or buy: making a component in-house raises added value (only the materials are bought in), but needs wages and equipment; compare the extra added value with the extra cost.
- Compare like with like: similar size, similar products, same definition of inputs.

## Key terms

| Term | Meaning |
|---|---|
| Added value | Selling price minus the cost of bought-in inputs |
| Bought-in inputs | Materials, components and services bought from other businesses |
| Value added per employee | Total added value divided by the number of employees |
| Gross profit | Revenue minus cost of sales (not the same as added value) |
| Brand | A name or reputation that allows a premium price |
| In-house production | Doing work within the business instead of buying it in |

## Evaluation prompts

- Does the higher price come from real quality, brand or service, or just from market power?
- Will customers accept the higher price, and how much would sales fall?
- Is total added value higher, not just the figure per unit?
- Do wages and overheads rise by as much, leaving profit unchanged?
- Can the added value be compared fairly with other businesses?
- Finish with a judgement using figures from the case.

## Exam traps

- Do not deduct wages or rent.
- Added value is not profit.
- Show units: per unit or in total.
- A higher percentage of price is not always better if total added value falls.
- Compare like with like.

## Self-test

1. Define added value.
2. A product sells at £25 with bought-in costs of £14. Find the added value.
3. Express the answer to question 2 as a percentage of price.
4. 6,000 units are sold at the figures in question 2. Find the total added value.
5. With 4 employees, find the added value per employee.
6. Give two ways to increase added value.
7. Give two uses of added value.
8. Why is added value not the same as profit?
9. Give one limit of added value as a measure.
10. Price £50, inputs £30, then price rises to £56 and inputs to £34. Find the new added value.
11. Why might suppliers worry about a business wishing to raise added value?
12. Why is a higher percentage of price not always better?

### Answers

1. The difference between the selling price and the cost of the bought-in inputs.
2. 25 − 14 = **£11**.
3. 11 ÷ 25 × 100 = **44%**.
4. 6,000 × 11 = **£66,000**.
5. 66,000 ÷ 4 = **£16,500**.
6. Any two: improve quality; build the brand; add services; do more in-house; cut input costs; target a niche.
7. Any two: wages; overheads; profit; interest.
8. It is calculated before wages, overheads and other costs are paid, so profit is only what is left.
9. Any one: ignores other costs; depends on definition of inputs; price may reflect market power.
10. 56 − 34 = **£22** (it was £20).
11. The business may try to cut input costs by pressing suppliers to lower their prices.
12. Total added value could fall if sales fall by more than the rise in the percentage.
