This guide covers subtopic **2.1 Introduction to algebra** in Topic 2 Algebra and graphs of the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. The Core (C2.1) and Extended (E2.1) statements are identical:

1. **Know that letters can be used to represent generalised numbers.**
2. **Substitute numbers into expressions and formulas.**

These two skills sit underneath the whole of Topic 2, and substitution appears in almost every other topic too, from mensuration formulas to the equation of a line. The [introduction to algebra and manipulation guide](/resources/igcse-mathematics-0580-introduction-to-algebra-and-manipulation/) shows the basic idea of each. This page goes further: turning words into expressions, describing any even, odd or consecutive number with a letter, the vocabulary examiners use, and substitution with negative numbers, fractions and decimals. Afterwards, use the [introduction to algebra revision notes](/resources/cambridge-igcse-mathematics-0580-introduction-to-algebra-cambridge-igcse-maths-revision-notes/) and the [introduction to algebra practice questions](/resources/cambridge-igcse-mathematics-0580-introduction-to-algebra-cambridge-igcse-maths-practice/).

## Letters as generalised numbers (2.1.1)

A letter in algebra stands for a number that can vary, or for any number of a certain kind. "Generalised" means the statement is true for every value the letter can take, not for one particular number.

### The vocabulary

| Word | Meaning | Example |
|---|---|---|
| Variable | A letter that stands for a number | x, n, t |
| Term | Numbers and letters multiplied together | 5x, −3ab, 7 |
| Coefficient | The number in front of a letter | 5 in 5x |
| Expression | Terms joined by + or −, with no equals sign | 4x − 3y + 2 |
| Equation | Two expressions that are equal for particular values | 4x − 3 = 9 |
| Formula | A rule linking two or more variables | A = lw |
| Subject | The variable on its own on one side of a formula | A in A = lw |

### Algebra conventions

- 3x means 3 × x. The number is written first, and the × sign is left out.
- ab means a × b.
- x² means x × x; 2x² means 2 × x × x, which is not the same as (2x)².
- a/b or a ÷ b is written as a fraction.
- 1x is written as x, and 0x is 0.

### Worked example 1: writing expressions from words

Write an expression for each of these.

(a) The total cost, in cents, of p pens at 45 cents each and one ruler costing r cents.
(b) Three less than twice the number n.
(c) Ali is x years old. His sister is 4 years younger than him, and his father is three times his age. Write an expression for the total of their ages.

```
(a) 45p + r

(b) twice n = 2n;  three less than that = 2n - 3

(c) Ali: x     sister: x - 4     father: 3x
    total = x + (x - 4) + 3x = 5x - 4
```

In (b), "three less than twice n" is 2n − 3, not 3 − 2n. Read "less than" as "subtract from the quantity that follows".

### Worked example 2: describing any number of a type

n stands for any whole number (integer).

(a) Write the next two consecutive integers after n.
(b) Write an expression for any even number and any odd number.
(c) Explain why 2n + 1 is always odd.

```
(a) n + 1 and n + 2

(b) Even: 2n        Odd: 2n + 1 (or 2n - 1)

(c) 2n is a multiple of 2, so it is even.
    Adding 1 to an even number always gives an odd number.
```

These expressions let you describe every case at once. For example, the sum of three consecutive integers is n + (n + 1) + (n + 2) = 3n + 3, which is 3 times (n + 1), so it is always a multiple of 3. A single numerical example, such as 4 + 5 + 6 = 15, shows only one case.

## Substituting into expressions and formulas (2.1.2)

To substitute, replace each letter with its value, in brackets, and then follow the order of operations: brackets, indices, then multiplication and division, then addition and subtraction.

Writing the value in brackets prevents the most common sign errors.

### Worked example 3: negatives and fractions (non-calculator)

a = −3, b = 4 and c = ½. Work out (a) a² − 2b, (b) 3a²b, (c) (a + b) ÷ c, (d) b − a³.

```
(a) (-3)^2 - 2(4) = 9 - 8 = 1

(b) 3 × (-3)^2 × 4 = 3 × 9 × 4 = 108

(c) (-3 + 4) ÷ (1/2) = 1 ÷ 1/2 = 2

(d) 4 - (-3)^3 = 4 - (-27) = 4 + 27 = 31
```

In (b), only a is squared: 3a²b is not (3a)²b. In (d), a negative number cubed stays negative, and subtracting a negative adds.

### Worked example 4: a formula with decimals (calculator)

The formula s = ut + ½at² gives a distance. Find s when u = 4.5, t = 3.2 and a = −1.8.

```
ut      = 4.5 × 3.2 = 14.4
½at^2   = 0.5 × (-1.8) × 3.2^2 = 0.5 × (-1.8) × 10.24 = -9.216
s       = 14.4 + (-9.216) = 5.184
```

The answer 5.184 is exact, so write all of it (or 5.18 to 3 s.f. if the question asks for that accuracy). Square t before multiplying by a; the index applies to t only.

### Worked example 5: a square root at the end (calculator)

v² = u² + 2as. Find v when u = 12, a = 3 and s = 20, given that v is positive.

```
v^2 = 12^2 + 2 × 3 × 20 = 144 + 120 = 264
v   = √264 = 16.248...  = 16.2 (3 s.f.)
```

Take the square root of the whole right-hand side, once it is a single number. √144 + √120 is not the same thing.

### Worked example 6: writing a formula, then using it

A taxi charges $3.50 plus $1.20 for each kilometre.

(a) Write a formula for the cost, C dollars, of a journey of k kilometres.
(b) Find the cost of a 14.5 km journey.
(c) A journey costs $13.10. How far was it?

```
(a) C = 3.50 + 1.20k

(b) C = 3.50 + 1.20 × 14.5 = 3.50 + 17.40 = 20.90  ->  $20.90

(c) 13.10 = 3.50 + 1.20k
    9.60 = 1.20k
    k = 8 km
```

Part (c) substitutes the known value and then solves a simple equation. A formula in a question must start with the subject and an equals sign: "3.50 + 1.20k" on its own is an expression, not a formula.

## Common mistakes

- Writing 2x as 25 when x = 5: 2x means 2 × 5 = 10.
- Squaring a negative without brackets: −3² = −9, but (−3)² = 9.
- Applying a power to the coefficient as well, so that 3a² with a = −3 becomes 81 instead of 27.
- Working left to right instead of using the order of operations.
- Writing "3 less than n" as 3 − n.
- Giving an expression when a formula was asked for, or the reverse.
- Rounding an intermediate value in a long substitution.

## Exam technique for the command words

- **Write down** an expression: one line, simplified where possible; no equals sign.
- **Write** a formula: start with the subject letter and "=".
- **Work out** or **Calculate** the value of an expression: show the substitution line with brackets round negative values, so a method mark is available.
- **Explain** why an expression is always even, odd or a multiple of a number: describe the structure (for example "2n is a multiple of 2") rather than testing one value.
