This guide covers subtopic **2.6 Inequalities** in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. Core has a single statement; Extended has four.

| Statement | Core (C2.6) | Extended (E2.6) |
|---|---|---|
| Represent and interpret inequalities, including on a number line | yes | yes |
| Construct, solve and interpret linear inequalities | no | yes, e.g. 3x < 2x + 4 and −3 ≤ 3x − 2 < 7 |
| Represent and interpret linear inequalities in two variables graphically | no | yes |
| List inequalities that define a given region | no | yes; linear programming problems are not included |

The syllabus fixes the drawing conventions, and marks depend on them:

- On a number line, **open circles** for strict inequalities (< and >) and **closed circles** for inclusive ones (≤ and ≥).
- On a graph, **broken lines** for strict inequalities and **solid lines** for inclusive ones.
- **Shade the unwanted region**, unless the question tells you otherwise.

When you have worked through the examples, use the [inequalities revision notes](/resources/cambridge-igcse-mathematics-0580-inequalities-cambridge-igcse-maths-revision-notes/) and the [inequalities practice questions](/resources/cambridge-igcse-mathematics-0580-inequalities-cambridge-igcse-maths-practice/).

## Reading and writing inequalities (Core and Extended)

| Symbol | Read as | Everyday wording |
|---|---|---|
| x < 5 | x is less than 5 | below 5, fewer than 5 |
| x ≤ 5 | x is less than or equal to 5 | at most 5, no more than 5, a maximum of 5 |
| x > 5 | x is greater than 5 | over 5, more than 5 |
| x ≥ 5 | x is greater than or equal to 5 | at least 5, no fewer than 5, a minimum of 5 |

### Worked example 1: from a number line

A number line has an open circle at −2 and a closed circle at 3, joined by a line. Write the inequality and list the integers that satisfy it.

```
   o-------------------●
  -2  -1   0   1   2   3

Open at -2: -2 is not included  ->  -2 <
Closed at 3: 3 is included      ->  ≤ 3
Inequality: -2 < x ≤ 3
Integers:   -1, 0, 1, 2, 3
```

The integer list is where many marks are lost: −2 is excluded because its circle is open, and 3 is included because its circle is closed.

### Worked example 2: from words

A lift can carry at most 8 people. Write an inequality for the number of people, n, in the lift.

```
"at most 8" means 8 is allowed:  n ≤ 8
n also counts people, so 0 ≤ n ≤ 8 with n a whole number.
```

Interpreting an inequality in context often adds a hidden condition, such as "a whole number" or "not negative".

## Solving linear inequalities (Extended)

Solve exactly as you would an equation, with one extra rule: **multiplying or dividing both sides by a negative number reverses the inequality sign.** Adding, subtracting, and multiplying or dividing by a positive number leave it unchanged.

Why the sign turns round: 2 < 5 is true, but multiplying both sides by −1 gives −2 and −5, and −2 > −5.

### Worked example 3: unknown on both sides

Solve 5x − 3 ≥ 2x + 9.

```
3x - 3 ≥ 9
3x ≥ 12
x ≥ 4
```

### Worked example 4: a negative coefficient

Solve 7 − 3x > 13.

```
Method 1:  -3x > 6
           x < -2       (divide by -3, so > becomes <)

Method 2:  7 - 13 > 3x  (add 3x to both sides, subtract 13)
           -6 > 3x
           -2 > x, which is x < -2
```

Method 2 never divides by a negative, so there is no sign to reverse. Both methods give the same answer.

### Worked example 5: a double inequality

Solve −4 ≤ 2x + 6 < 10, and list the integer values of x.

```
Subtract 6 from all three parts:  -10 ≤ 2x < 4
Divide all three parts by 2:       -5 ≤ x < 2
Integers: -5, -4, -3, -2, -1, 0, 1
```

Whatever you do, do it to all three parts. Splitting into two separate inequalities also works, but you must combine them again at the end.

### Worked example 6: fractions

Solve (x + 1)/3 ≤ (x − 2)/2.

```
Multiply both sides by 6 (positive, so no reversal):
2(x + 1) ≤ 3(x - 2)
2x + 2 ≤ 3x - 6
8 ≤ x,  that is  x ≥ 8
```

### Worked example 7: constructing and interpreting

A taxi charges a fixed $3 plus $1.50 per kilometre. Amy has $18. How far can she travel?

```
Let d be the distance in km.
3 + 1.5d ≤ 18
1.5d ≤ 15
d ≤ 10
```

Amy can travel **at most 10 km**. "Interpret" means you must give this conclusion in words.

## Inequalities in two variables (Extended)

The line y = 2x + 1 splits the grid into two half-planes. Every point on one side satisfies y > 2x + 1, and every point on the other satisfies y < 2x + 1. To show y ≥ 2x + 1:

1. Draw y = 2x + 1 as a **solid** line (because of ≥).
2. Choose a **test point** not on the line, usually (0, 0). Here 0 ≥ 2(0) + 1 is false, so (0, 0) is in the unwanted region.
3. **Shade** the side containing (0, 0), leaving the wanted region clear.

Vertical and horizontal lines need no test point: x < 4 is everything to the left of the broken line x = 4, and y ≥ −1 is everything on or above the solid line y = −1.

### Worked example 8: a region and its integer points

Region R satisfies y ≥ 2, x < 5 and y ≤ x + 1. Find the corners of R and the number of points with integer coordinates inside or on its boundary.

```
Lines: y = 2 (solid), x = 5 (broken), y = x + 1 (solid)

Corners:
y = 2 and y = x + 1  ->  (1, 2)
y = 2 and x = 5      ->  (5, 2)
x = 5 and y = x + 1  ->  (5, 6)

Integer points (x = 5 is excluded because the line is broken):
x = 1: y = 2                  1 point
x = 2: y = 2, 3               2 points
x = 3: y = 2, 3, 4            3 points
x = 4: y = 2, 3, 4, 5         4 points
Total: 10 points
```

Points on a solid boundary count; points on a broken boundary do not. That is why no point with x = 5 is listed.

## Finding the inequalities for a region (Extended)

Work the other way round:

1. Find the equation of each boundary line (use y = mx + c for sloping lines).
2. Decide the sign from the line style: solid gives ≤ or ≥, broken gives < or >.
3. Pick a point **inside** the region and substitute it to decide the direction.

### Worked example 9

A triangular region has vertices (0, −1), (0, 3) and (2, 3). The side on the y-axis is solid, the side along y = 3 is broken, and the third side is solid. Write the three inequalities that define it.

```
Side on the y-axis: x = 0, solid. The region is to the right:  x ≥ 0
Side along y = 3, broken. The region is below:                 y < 3
Third side through (0, -1) and (2, 3): gradient 4/2 = 2,
  so y = 2x - 1, solid.
  Test (0, 0), inside the triangle: 0 ≥ 2(0) - 1 is true:      y ≥ 2x - 1
```

## Common mistakes

- Using a closed circle for a strict inequality, or an open one for ≤ or ≥.
- Listing an excluded end point as an integer solution.
- Forgetting to reverse the sign after dividing by a negative.
- Giving an answer such as x = 4 instead of x ≥ 4: the solution is a set of values.
- Shading the wanted region when the convention is to shade what is not wanted.
- Using a solid line for a strict inequality.

## Exam technique

- **"Solve"**: the answer is an inequality, written with x on its own.
- **"List the integers"** or **"Write down the integer values"**: check both ends separately.
- **"Show, by shading the unwanted regions"**: label the region R if asked, and use a ruler for every boundary.
- **"Write down the inequalities that define the region"**: give one inequality per boundary line.
