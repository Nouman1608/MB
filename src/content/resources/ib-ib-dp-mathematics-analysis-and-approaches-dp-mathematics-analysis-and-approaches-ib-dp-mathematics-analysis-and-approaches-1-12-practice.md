This set covers **syllabus section 1.12** of IB DP Mathematics: Analysis and Approaches (first assessment 2021): i, Cartesian form, real and imaginary parts, conjugate, modulus, argument and the complex plane. Every question is **HL only**. Questions are labelled "(calculator-free)" for Paper 1 style or "(calculator allowed)" for Paper 2 and 3 style. Give arguments in the range −π < θ ≤ π.

Study the methods first in the [section 1.12 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-12/) and the [section 1.12 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-12-revision-notes/).

## Section A

**1.** (calculator-free)

**(a)** Simplify i¹⁵. **[1]**
**(b)** Find the value of i + i² + i³ + … + i¹⁰. **[2]**

**2.** (calculator-free) Let z = 4 − 3i and w = −1 + 2i. Find:

**(a)** 2z − w **[1]**
**(b)** zw, in the form a + bi **[2]**
**(c)** |z| **[1]**

**3.** (calculator-free) Write 5i/(2 + i) in the form a + bi. **[3]**

**4.** (calculator-free) Solve z² − 2z + 10 = 0. **[3]**

**5.** (calculator-free) Write down the exact argument of each complex number.

**(a)** −2 − 2i **[1]**
**(b)** −5i **[1]**
**(c)** −4 **[1]**

## Section B

**6.** (calculator-free) Find all pairs of real numbers x and y such that (x + 2i)(3 − yi) = 13 + i. **[5]**

**7.** (calculator-free) Solve the equation z + 2iz* = 5 + 4i. **[4]**

**8.** (calculator-free) Let z = 1 + 2i.

**(a)** Find z² in the form a + bi. **[1]**
**(b)** Find z³ in the form a + bi. **[2]**
**(c)** Hence show that z is a root of the equation z³ − z² + 3z + 5 = 0. **[2]**

**9.** (calculator-free) On an Argand diagram, the points A and B represent z₁ = 3 + i and z₂ = −1 + 4i, and O is the origin.

**(a)** Find the distance AB. **[2]**
**(b)** The point C represents z₁ + z₂. State the name of the quadrilateral OACB. **[1]**
**(c)** Find the complex number represented by the midpoint of AB. **[1]**
**(d)** Write down the complex number represented by the reflection of A in the real axis. **[1]**

**10.** (calculator-free) Let z = a + bi, where a, b ∈ ℝ. Show that (z − z*)/(2i) = Im z. **[3]**

**11.** (calculator-free) Find the complex numbers z that satisfy zz* + 2z = 15 + 4i. Give your answers in the form a + bi, with a and b exact. **[5]**

**12.** (calculator allowed) Let z = 2 − 5i.

**(a)** Find |z| and arg z. **[3]**
**(b)** Hence write down |z*| and arg z*. **[1]**

## Answers

**1. (a)** 15 = 4 × 3 + 3, so i¹⁵ = i³ = **−i** [1]
**(b)** Each block of four consecutive powers sums to 0, so the sum is i⁹ + i¹⁰ [1] = i − 1 = **−1 + i** [1]

**2. (a)** 8 − 6i + 1 − 2i = **9 − 8i** [1]
**(b)** −4 + 8i + 3i − 6i² [1] = **2 + 11i** [1]
**(c)** √(16 + 9) = **5** [1]

**3.** Multiply by (2 − i)/(2 − i) [1]: 5i(2 − i)/(4 + 1) = (10i − 5i²)/5 [1] = (5 + 10i)/5 = **1 + 2i** [1]

**4.** z = (2 ± √(4 − 40))/2 [1] = (2 ± √(−36))/2 = (2 ± 6i)/2 [1] = **1 ± 3i** [1]

**5. (a)** Third quadrant, reference angle π/4: **−3π/4** [1]
**(b)** On the negative imaginary axis: **−π/2** [1]
**(c)** On the negative real axis: **π** [1]

**6.** (x + 2i)(3 − yi) = 3x − xyi + 6i − 2yi² = (3x + 2y) + (6 − xy)i [1]. Equating parts: 3x + 2y = 13 and 6 − xy = 1, so xy = 5 [1]. Substitute y = (13 − 3x)/2: x(13 − 3x) = 10, so 3x² − 13x + 10 = 0 [1]. (3x − 10)(x − 1) = 0 [1]. **x = 1, y = 5** or **x = 10/3, y = 3/2** [1]
*Examiner insight:* Both pairs check out. A nonlinear system like this usually gives two solutions; stopping after one loses the final mark.

**7.** Let z = a + bi; then iz* = i(a − bi) = b + ai [1]. z + 2iz* = (a + 2b) + (b + 2a)i [1]. So a + 2b = 5 and 2a + b = 4 [1], giving a = 1, b = 2 and **z = 1 + 2i** [1]

**8. (a)** 1 + 4i + 4i² = **−3 + 4i** [1]
**(b)** (−3 + 4i)(1 + 2i) = −3 − 6i + 4i + 8i² [1] = **−11 − 2i** [1]
**(c)** z³ − z² + 3z + 5 = (−11 − 2i) − (−3 + 4i) + (3 + 6i) + 5 [1] = (−11 + 3 + 3 + 5) + (−2 − 4 + 6)i = 0, so z is a root [1]

**9. (a)** AB = |z₁ − z₂| = |4 − 3i| [1] = **5** [1]
**(b)** **A parallelogram** (vector addition) [1]
**(c)** (z₁ + z₂)/2 = **1 + (5/2)i** [1]
**(d)** z₁* = **3 − i** [1]

**10.** z* = a − bi, so z − z* = 2bi [1]. (z − z*)/(2i) = 2bi/(2i) [1] = b = Im z [1]

**11.** Let z = a + bi; zz* = a² + b² [1]. So (a² + b² + 2a) + 2bi = 15 + 4i [1]. Imaginary parts: 2b = 4, so b = 2 [1]. Real parts: a² + 4 + 2a = 15, so a² + 2a − 11 = 0 [1]. a = −1 ± 2√3, so **z = (−1 + 2√3) + 2i or z = (−1 − 2√3) + 2i** [1]
*Examiner insight:* zz* is real, so it contributes only to the real-part equation. Spotting that splits the problem quickly.

**12. (a)** |z| = √29 = **5.39** (3 s.f.) [1]. z is in the fourth quadrant [1], so arg z = −arctan(5/2) = **−1.19** (3 s.f.) [1]
**(b)** |z*| = **5.39** and arg z* = **1.19** [1], since z* is the reflection of z in the real axis.

## Where marks are usually lost

- Imaginary part written with an i attached.
- Arguments taken straight from a calculator's inverse tangent, in the wrong quadrant.
- Only one solution given when equating parts produces a quadratic.
- Errors in i(a − bi): the result is b + ai.
- Answers not written in the requested form a + bi.
