Section 11.1 of the Cambridge O Level Chemistry 5070 syllabus (2026–2028) sets out the language of organic chemistry. It has eight learning outcomes: structural formulae as "an unambiguous description of the way the atoms in a molecule are arranged"; drawing and interpreting displayed formulae; general formulae for alkanes, alkenes, alcohols and carboxylic acids; structural isomers; functional groups; the five characteristics of a homologous series; and the meanings of saturated and unsaturated. 5070 has no Core/Extended split, so every outcome is examined for every candidate.

The broader [Organic Chemistry: Formulae and Naming guide](/resources/organic-chemistry-formulae-and-naming/) introduces these terms alongside naming. This guide concentrates on using them precisely: converting between kinds of formula, working with general formulae in calculations, and deciding whether two drawings are isomers or the same molecule.

## Four ways to write one molecule

| Kind of formula | What it shows | Ethanol |
|---|---|---|
| Molecular | the number of each type of atom only | C₂H₆O |
| Structural | how the atoms are grouped, without drawing every bond | CH₃CH₂OH |
| Displayed | every atom and every bond | see below |
| General | the pattern for a whole homologous series | CₙH₂ₙ₊₁OH |

```
      H   H
      |   |
  H - C - C - O - H
      |   |
      H   H
```

A molecular formula can be ambiguous. C₃H₈O fits both propan-1-ol, CH₃CH₂CH₂OH, where the –OH is on an end carbon, and propan-2-ol, CH₃CH(OH)CH₃, where it is on the middle carbon. A structural formula removes that doubt, which is exactly what the syllabus means by "unambiguous".

### Reading the structural formulae named in the syllabus

The syllabus gives three examples to interpret.

- **CH₂=CH₂** (ethene): the "=" shows the carbon–carbon double bond. Each carbon also carries two hydrogens.
- **CH₃CH₂OH** (ethanol): a CH₃ group joined to a CH₂ group, which carries the –OH.
- **CH₃COOCH₃** (methyl ethanoate, an ester): read it as CH₃–C(=O)–O–CH₃. The first O is double-bonded to the carbon; the second O links that carbon to the second CH₃ group.

```
      H   O       H
      |   ‖       |
  H - C - C - O - C - H
      |           |
      H           H
```

The displayed formula above is CH₃COOCH₃. When drawing esters, the most common error is joining the two oxygens to each other. They are never bonded together; both are bonded to the same carbon.

### Rules for drawing displayed formulae

- Every carbon has **four** bonds; every hydrogen has **one**; every oxygen has **two**.
- A double bond counts as two bonds, so the carbon in C=O has only two other bonds.
- Show the O–H bond in an alcohol or acid as a line; writing "–OH" without the bond loses the mark on a displayed formula.
- Count atoms in your drawing and check against the molecular formula before moving on.

## General formulae

| Homologous series | General formula | First member | Fourth member |
|---|---|---|---|
| Alkanes | CₙH₂ₙ₊₂ | CH₄ (n = 1) | C₄H₁₀ |
| Alkenes | CₙH₂ₙ | C₂H₄ (n = 2) | C₅H₁₀ |
| Alcohols | CₙH₂ₙ₊₁OH | CH₃OH (n = 1) | C₄H₉OH |
| Carboxylic acids | CₙH₂ₙ₊₁COOH | HCOOH (n = 0) | C₃H₇COOH |

Watch the carboxylic acid formula: n counts only the carbons **outside** the –COOH group. Ethanoic acid, CH₃COOH, has two carbon atoms but n = 1. The first member, methanoic acid, has n = 0.

**Worked example 1.** An alkane has a relative molecular mass of 72. Find its molecular formula. (Ar: C = 12, H = 1)

*Answer.* For CₙH₂ₙ₊₂, Mr = 12n + (2n + 2) = 14n + 2 [1]. So 14n + 2 = 72, giving n = 5 [1]. The formula is **C₅H₁₂** [1].

**Worked example 2.** State the homologous series each compound belongs to: C₆H₁₂, C₂H₅COOH, C₇H₁₆, C₃H₇OH.

*Answer.* C₆H₁₂ fits CₙH₂ₙ, so alkene. C₂H₅COOH has –COOH, so carboxylic acid (n = 2, three carbons in total, propanoic acid). C₇H₁₆ fits CₙH₂ₙ₊₂, so alkane. C₃H₇OH has –OH and fits CₙH₂ₙ₊₁OH, so alcohol.

## Structural isomers

**Structural isomers** are compounds with the same molecular formula but different structural formulae. The syllabus names two pairs.

| Molecular formula | Isomer 1 | Isomer 2 | What differs |
|---|---|---|---|
| C₄H₁₀ | CH₃CH₂CH₂CH₃ | CH₃CH(CH₃)CH₃ | straight chain against branched chain |
| C₄H₈ | CH₃CH₂CH=CH₂ (but-1-ene) | CH₃CH=CHCH₃ (but-2-ene) | position of the double bond |

Straight chain, CH₃CH₂CH₂CH₃:

```
      H   H   H   H
      |   |   |   |
  H - C - C - C - C - H
      |   |   |   |
      H   H   H   H
```

Branched chain, CH₃CH(CH₃)CH₃:

```
          H
          |
      H - C - H
          |
      H   |   H
      |   |   |
  H - C - C - C - H
      |   |   |
      H   H   H
```

### Isomer or the same molecule?

A chain drawn with a bend is still the same chain. To test two drawings:

1. Check the molecular formulae are the same. If not, they are not isomers.
2. Find the longest continuous carbon chain in each.
3. Note where any branch, double bond or –OH sits along that chain, counting from the nearer end.

If the longest chain and the positions match, the drawings show the same molecule. CH₃CH₂CH₂CH₃ drawn in a zig-zag or an L-shape is still the straight-chain isomer, because its longest chain is still four carbons with no branch.

## Functional groups and homologous series

A **functional group** is an atom or group of atoms that determines the chemical properties of a homologous series.

| Series | Functional group |
|---|---|
| Alkenes | C=C double bond |
| Alcohols | –OH |
| Carboxylic acids | –COOH |
| Esters | –COO– |

Alkanes contain only C–C and C–H single bonds, which is why they are generally unreactive.

A **homologous series** has five characteristics, and the syllabus lists all five:

1. the same functional group
2. the same general formula
3. each member differs from the next by a –CH₂– unit
4. a trend in physical properties
5. similar chemical properties

Characteristics 1 and 5 are linked: because members share a functional group, they react in similar ways. Characteristic 4 is about **physical** properties, such as boiling point. For the first five alkanes the boiling points are approximately −162 °C, −89 °C, −42 °C, −1 °C and 36 °C. Boiling point rises as the chain gets longer, so methane to butane are gases at room temperature and pentane is a liquid.

## Saturated and unsaturated

- A **saturated** compound has molecules in which all carbon–carbon bonds are single bonds.
- An **unsaturated** compound has molecules in which one or more carbon–carbon bonds are not single bonds.

The definitions are about **carbon–carbon** bonds only. Ethanoic acid contains a C=O double bond, but all its carbon–carbon bonds are single, so it is saturated. Alkenes are unsaturated because of their C=C bond.

## Common mistakes

- Giving a molecular formula when a structural or displayed formula is asked for.
- Missing hydrogens in displayed formulae, so a carbon has three bonds.
- Drawing the ester linkage as –O–O–.
- Using n as the total number of carbons in a carboxylic acid.
- Calling two drawings of the same chain "isomers".
- Writing that members of a homologous series have the same physical properties. They show a **trend**.
- Defining "unsaturated" as "contains a double bond" without saying carbon–carbon.

## Exam technique: the command words

- **State** or **define**: give the syllabus definition exactly; for isomers, include both "same molecular formula" and "different structural formulae".
- **Draw**: show every atom and every bond for a displayed formula.
- **Deduce**: use the general formula, showing the value of n.
- **Identify**: name the functional group or series from the formula given.
