Questions marked (calculator allowed) need a calculator only for inverse trigonometric functions; do all
the others by hand. Give angles in degrees to 3 significant figures.

## Section A

**1.** Find the coordinates of the point where the line r = (1, 0, 2) + t(2, −1, 1) meets the plane
x + 3y − z = 5. **[3]**

**2.** Show that the line r = (2, 1, 1) + t(1, 1, −1) is parallel to the plane x − 2y − z = 4 but does not
lie in it. **[2]**

**3.** (calculator allowed) Find the acute angle between the planes 2x + y − 2z = 5 and 4x + 3z = 1. **[3]**

**4.** (calculator allowed) Find the angle between the line r = (0, 4, 1) + t(1, 2, 2) and the plane
2x − y + 2z = 7. **[3]**

**5.** The line r = (0, 1, 3) + t(2, k, 1) is parallel to the plane 3x − 2y + 4z = 1. Find k. **[2]**

**6.** Describe the geometrical relationship between the planes 2x − 4y + 6z = 3 and −x + 2y − 3z = 5,
giving a reason. **[2]**

## Section B

**7.** The planes Π₁ and Π₂ have equations x + 2y + z = 4 and 3x − y + 2z = 5.

**(a)** Find a vector parallel to the line of intersection of Π₁ and Π₂. **[2]**
**(b)** Find a vector equation of the line of intersection. **[3]**
**(c)** (calculator allowed) Find the acute angle between Π₁ and Π₂. **[3]**

**8.** The point P has coordinates (4, −1, 6) and the plane Π has equation 2x − y + 2z = 3.

**(a)** Write down a vector equation of the line through P perpendicular to Π. **[1]**
**(b)** Find the coordinates of the foot of the perpendicular from P to Π. **[3]**
**(c)** Find the shortest distance from P to Π. **[2]**
**(d)** Find the coordinates of the reflection of P in Π. **[2]**

**9.** The planes Π₁ and Π₂ have equations x − y + 2z = 3 and x + y − 2z = 1.

**(a)** Show that every point on the line of intersection of Π₁ and Π₂ has x-coordinate 2. **[2]**
**(b)** Find a vector equation of the line of intersection. **[3]**

**10.** Three planes have equations

x + y + z = 2
2x − y + z = 5
x + 2y − z = −3

**(a)** Without using a calculator, solve the system of equations. **[4]**
**(b)** Interpret your answer geometrically. **[1]**

**11.** Three planes have equations

x + 2y − z = 3
2x − y + z = 1
x − 3y + 2z = k

**(a)** Find the value of k for which the planes have infinitely many common points. **[3]**
**(b)** For this value of k, find a vector equation of the line common to all three planes. **[3]**
**(c)** Describe the arrangement of the planes when k takes any other value, justifying your answer. **[2]**

**12.** The plane Π has equation 2x + y − z = 6 and the line L has equation r = (1, 1, 1) + t(1, 2, k).

**(a)** Find the value of k for which L is parallel to Π. **[2]**
**(b)** For this value of k, show that L does not lie in Π. **[1]**
For the rest of this question, let k = 1.
**(c)** Find the coordinates of the point where L meets Π. **[3]**
**(d)** Find the angle between L and Π. **[2]**

**13.** The planes Π₁, Π₂ and Π₃ have equations x + y − 2z = 1, 2x + 2y − 4z = 5 and x − y + z = 0. Explain
why the three planes have no common point, and describe how they are arranged. **[3]**

## Answers

**1.** x = 1 + 2t, y = −t, z = 2 + t, so (1 + 2t) + 3(−t) − (2 + t) = 5 [1]. This gives −1 − 2t = 5, so
t = −3 [1]. The point is (−5, 3, −1) [1]. Check: −5 + 9 + 1 = 5 ✓. **[3]**

**2.** (1, 1, −1) · (1, −2, −1) = 1 − 2 + 1 = 0, so the line is parallel to the plane [1]. The point
(2, 1, 1) gives 2 − 2 − 1 = −1 ≠ 4, so the line does not lie in the plane [1]. **[2]**

**3.** n₁ · n₂ = (2)(4) + (1)(0) + (−2)(3) = 2 [1]. |n₁| = 3 and |n₂| = 5, so cos θ = 2/15 [1], giving
θ = 82.3° [1]. **[3]**

**4.** b · n = 2 − 2 + 4 = 4 and |b| = |n| = 3 [1]. sin φ = 4/9 [1], so φ = 26.4° [1]. **[3]**
*Marking note:* using cos gives 63.6°, the angle with the normal, and scores at most the first mark.

**5.** (2, k, 1) · (3, −2, 4) = 0 [1], so 6 − 2k + 4 = 0 and k = 5 [1]. **[2]**

**6.** Normals (2, −4, 6) and (−1, 2, −3) are parallel, since the first is −2 times the second [1].
Multiplying the second equation by −2 gives 2x − 4y + 6z = −10, not 3, so the planes are parallel and
distinct [1]. **[2]**

**7. (a)** (1, 2, 1) × (3, −1, 2) = ((2)(2) − (1)(−1), (1)(3) − (1)(2), (1)(−1) − (2)(3)) [1] = (5, 1, −7) [1].
**(b)** Put z = 0: x + 2y = 4 and 3x − y = 5 [1], so x = 2, y = 1 [1].
r = (2, 1, 0) + t(5, 1, −7) [1].
**(c)** n₁ · n₂ = 3 − 2 + 2 = 3 [1]; |n₁| = √6, |n₂| = √14, so cos θ = 3/√84 [1]; θ = 70.9° [1]. **[8]**

**8. (a)** r = (4, −1, 6) + t(2, −1, 2) [1].
**(b)** 2(4 + 2t) − (−1 − t) + 2(6 + 2t) = 3 [1], so 21 + 9t = 3 and t = −2 [1]. The foot is (0, 1, 2) [1].
**(c)** PF = |−2| × |(2, −1, 2)| [1] = 2 × 3 = 6 [1].
**(d)** Parameter 2 × (−2) = −4 [1] gives (4 − 8, −1 + 4, 6 − 8) = (−4, 3, −2) [1]. **[8]**

**9. (a)** Adding the equations: 2x = 4 [1], so x = 2 for any point satisfying both, which includes every
point on the line [1].
**(b)** Direction (1, −1, 2) × (1, 1, −2) = (0, 4, 2), so use (0, 2, 1) [1]. With x = 2 and z = 0: −y = 1,
so y = −1 [1]. r = (2, −1, 0) + t(0, 2, 1) [1]. **[5]**
*Marking note:* setting x = 0 gives 0 = 4 after adding, so no point; candidates who then claim the planes
do not meet lose the method marks.

**10. (a)** First + third: 2x + 3y = −1 [1]. Second + third: 3x + y = 2 [1]. From the second, y = 2 − 3x;
substituting, 2x + 6 − 9x = −1, so x = 1 [1]. Then y = −1 and z = 2 − 1 + 1 = 2 [1].
**(b)** The three planes meet at the single point (1, −1, 2) [1]. **[5]**

**11. (a)** Second − first: x − 3y + 2z = −2 [1]. This is the left side of the third equation [1], so the
system is consistent with infinitely many solutions when k = −2 [1].
**(b)** Let z = t. Then x + 2y = 3 + t and 2x − y = 1 − t, giving x = 1 − t/5 and y = 1 + 3t/5 [1].
So r = (1, 1, 0) + t(−1/5, 3/5, 1) [1], or r = (1, 1, 0) + s(−1, 3, 5) [1].
**(c)** For k ≠ −2 there is no solution [1]. No two of the normals (1, 2, −1), (2, −1, 1) and (1, −3, 2) are
parallel, so the planes form a triangular prism [1]. **[8]**

**12. (a)** (1, 2, k) · (2, 1, −1) = 0 [1], so 4 − k = 0 and k = 4 [1].
**(b)** The point (1, 1, 1): 2 + 1 − 1 = 2 ≠ 6, so L does not lie in Π [1].
**(c)** 2(1 + t) + (1 + 2t) − (1 + t) = 6 [1], so 2 + 3t = 6 and t = 4/3 [1]. The point is (7/3, 11/3, 7/3)
[1].
**(d)** b · n = 2 + 2 − 1 = 3 and |b| = |n| = √6, so sin φ = 3/6 [1] and φ = 30° [1]. **[8]**

**13.** Π₂'s equation is 2x + 2y − 4z = 5, while 2 × Π₁ gives 2x + 2y − 4z = 2, so Π₁ and Π₂ are parallel and
distinct [1]. They have no common point, so the three planes have none [1]. Π₃'s normal (1, −1, 1) is not
parallel to (1, 1, −2), so Π₃ cuts Π₁ and Π₂ in two parallel lines [1]. **[3]**

## Where marks are usually lost

- Using cos for the line-plane angle in questions 4 and 12(d).
- In question 9, choosing x = 0 to find a point and concluding there is no intersection.
- In question 11, concluding "no solution" without describing the arrangement, or calling a prism
  "parallel planes".
- Stopping at the parameter value instead of giving coordinates in questions 1, 8 and 12.
- In question 8(c), giving |t| as the distance and forgetting to multiply by |n|.
