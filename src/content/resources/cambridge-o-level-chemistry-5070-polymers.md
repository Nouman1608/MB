Section 11.8 of the Cambridge O Level Chemistry 5070 syllabus (2026–2028) is the longest in Topic 11, with twelve learning outcomes. You must be able to define polymers and monomers; identify repeat units and linkages; deduce addition polymers from alkenes "and vice versa"; deduce polyamides and polyesters from their monomers "and vice versa"; describe the differences between addition and condensation polymerisation; describe how the properties of plastics affect their disposal and the environmental challenges they cause; describe and draw nylon and PET; state that PET can be converted back into monomers; and describe proteins as natural polyamides formed from amino acids. 5070 has no Core/Extended split, so every outcome is examined for every candidate.

The broader [Polymers guide](/resources/polymers/) introduces both kinds of polymerisation with poly(ethene) and nylon. This guide concentrates on the "deduce" skills, which carry most of the marks: working from monomer to repeat unit and back again, for both addition and condensation polymers, using propene, chloroethene and the block diagrams the syllabus uses.

## Polymers and monomers

A **polymer** is a large molecule built up from many smaller molecules called **monomers**. The **repeat unit** is the smallest section of the chain that, repeated over and over, gives the whole polymer. A **linkage** is the group of atoms that joins the monomer units in a condensation polymer.

## Addition polymers

Addition polymers are made from **alkene** monomers. The C=C double bond in each monomer opens, and the monomers join into a long chain. No other product forms.

### From alkene to repeat unit

1. Draw the monomer with its C=C in the middle and its four other groups above and below.
2. Change C=C to C–C.
3. Add a bond sticking out from each carbon, through brackets, to show the chain continues.
4. Write *n* after the bracket.

Propene to poly(propene):

```
      H   CH3                H   CH3
      |   |                  |   |
  n   C = C       →      – ( C – C ) –
      |   |                  |   |
      H   H                  H   H
                                    n
```

The CH₃ group is **not** part of the main chain. It hangs off as a side group. Students often draw a three-carbon chain in the repeat unit; the main chain of an addition polymer always comes only from the two C=C carbons.

Chloroethene gives poly(chloroethene) in exactly the same way:

```
      H   Cl                 H   Cl
      |   |                  |   |
  n   C = C       →      – ( C – C ) –
      |   |                  |   |
      H   H                  H   H
                                    n
```

### From polymer back to monomer

Reverse the steps: find a two-carbon repeat unit in the main chain, remove the extension bonds and turn the C–C between those two carbons into C=C.

**Worked example 1.** Part of an addition polymer chain is –CH₂–CH(CH₃)–CH₂–CH(CH₃)–CH₂–CH(CH₃)–. Draw the repeat unit and name the monomer.

*Answer.* The pattern –CH₂–CH(CH₃)– repeats, so the repeat unit is –[CH₂–CH(CH₃)]– [1]. Making the C–C a double bond gives CH₂=CHCH₃, **propene** [1]. A three-repeat section of chain contains three monomer units: count the CH(CH₃) groups.

## Condensation polymers

Condensation polymers form when monomers with **two functional groups each** react, joining together and releasing a **small molecule** (water at this level) every time a linkage forms. The syllabus limits this to two types, each made from two different monomers. Monomers are shown as blocks, with the functional groups at each end.

### Polyamides

A **dicarboxylic acid**, HOOC–▭–COOH, reacts with a **diamine**, H₂N–▬–NH₂. The –COOH of one monomer and the –NH₂ of the next join, losing H₂O, to form an **amide linkage**:

```
      O   H
      ‖   |
  ~ – C – N – ~
```

The repeat unit contains one of each monomer: –CO–▭–CO–NH–▬–NH–

### Polyesters

A **dicarboxylic acid** reacts with a **diol**, HO–▬–OH. The –COOH and –OH join, losing H₂O, to form an **ester linkage**:

```
      O
      ‖
  ~ – C – O – ~
```

The repeat unit: –CO–▭–CO–O–▬–O–

### Working back from a condensation polymer to its monomers

**Worked example 2.** A section of polymer has the repeat unit –CO–▭–CO–O–▬–O–. Identify the type of polymer and draw the two monomers.

*Answer.* The linkage –CO–O– is an ester linkage, so this is a **polyester** [1]. Split each linkage between C=O and O. Put –OH back on each C=O end and –H back on each O end:

- monomer 1: HOOC–▭–COOH, a dicarboxylic acid [1]
- monomer 2: HO–▬–OH, a diol [1]

The same method works for a polyamide: split between C=O and N–H; put –OH on the C=O side and –H on the N side, giving a dicarboxylic acid and a diamine.

## Addition compared with condensation

| | Addition polymerisation | Condensation polymerisation |
|---|---|---|
| Monomers | alkenes, with a C=C bond | two different monomers, each with two functional groups |
| Products | the polymer only | the polymer and a small molecule (water) |
| Linkage | none: C–C chain | amide (–CONH–) or ester (–COO–) |
| Repeat unit | same atoms as the monomer | monomers minus the water lost |
| Examples | poly(ethene), poly(propene) | nylon, PET, proteins |

## Nylon, PET and proteins

- **Nylon** is a **polyamide**: dicarboxylic acid blocks joined to diamine blocks by amide linkages.
- **PET** is a **polyester**: dicarboxylic acid blocks joined to diol blocks by ester linkages. PET **can be converted back into its monomers and re-polymerised**, which allows it to be recycled into new PET. The full name of PET is not required by the syllabus.
- **Proteins** are **natural polyamides**, formed from **amino acid** monomers with the general structure H₂N–CH(R)–COOH, where R represents different side-chains. Each amino acid has an amine group at one end and a carboxylic acid group at the other, so one kind of monomer can link to the next by amide linkages:

```
–NH–CH(R)–CO–NH–CH(R')–CO–NH–CH(R'')–CO–
```

Different R groups along the chain give different proteins. The amide linkages are the same type as those in nylon.

## Plastics and the environment

Plastics are made from polymers. Many are **unreactive** and **non-biodegradable**: they are not broken down by microorganisms. These properties make plastics durable in use but create problems when they are thrown away.

| Challenge | Why it happens |
|---|---|
| Disposal in landfill sites | plastics do not decompose, so they take up space for a very long time |
| Accumulation in oceans | plastics are durable and many float, so waste builds up and harms aquatic life |
| Toxic gases from burning | burning plastics can release toxic gases, such as carbon monoxide from incomplete combustion |

## Common mistakes

- Drawing the side group of propene into the main chain.
- Leaving the C=C in an addition polymer repeat unit, or leaving out the extension bonds and *n*.
- Saying addition polymerisation produces water.
- Splitting a polyester at the wrong bond, giving monomers with three oxygen atoms at one end.
- Calling proteins polyesters. They are polyamides.
- Describing PET recycling as "melting it down"; the syllabus point is that PET is converted back into **monomers** and re-polymerised.

## Exam technique: the command words

- **Define**: polymers are large molecules built up from many smaller molecules called monomers.
- **Identify**: circle or name the linkage (amide or ester) or bracket the repeat unit.
- **Deduce**: show the change from monomer to repeat unit, or back, step by step.
- **Describe** (differences): compare monomers, products and linkages in matched pairs.
