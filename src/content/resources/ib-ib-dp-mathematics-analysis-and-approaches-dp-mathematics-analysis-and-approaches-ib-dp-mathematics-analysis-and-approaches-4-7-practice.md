This set practises syllabus section 4.7 of IB DP Mathematics: Analysis and Approaches (SL and HL):
discrete random variables, their distributions and expected value. Learn the methods first with the
[4.7 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-4-7/)
and the [4.7 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-4-7-revision-notes/).
All games and prices are invented. No technology is needed; give exact answers where possible.

## Section A

**1.** The random variable X has P(X = x) = k(5 − x) for x = 1, 2, 3, 4.

**(a)** Find k. **[2]**
**(b)** Find E(X). **[2]**

**2.** The distribution of Y is shown.

| y | 2 | 4 | 6 | 8 |
|---|---|---|---|---|
| P(Y = y) | 0.15 | 0.25 | a | 0.35 |

**(a)** Find a. **[1]**
**(b)** Find E(Y). **[2]**
**(c)** Find P(Y > 4). **[1]**

**3.** A player pays $1 to play a game and receives $k with probability 0.2; otherwise they receive nothing.
Find the value of k for which the game is fair. **[2]**

**4.** The expected number of goals a team scores in a match is 2.4. Explain why this does not contradict
the fact that a team cannot score 2.4 goals. **[1]**

## Section B

**5.** Three fair coins are tossed. X is the number of heads.

**(a)** Find the probability distribution of X. **[2]**
**(b)** Find E(X). **[1]**
**(c)** Find P(X ≥ 2). **[1]**

**6.** The distribution of X is shown, where E(X) = 2.3.

| x | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| P(X = x) | p | 0.3 | q | 0.1 |

**(a)** Find p and q. **[5]**
**(b)** Find P(X ≤ 2). **[1]**

**7.** A player pays $4 to roll a fair die. A six wins $15, a four or a five wins $3, and any other score wins
nothing.

**(a)** Construct a table showing the probability distribution of the player's gain. **[2]**
**(b)** Find the expected gain and state whether the game is fair. **[2]**
**(c)** Find the stake that would make the game fair. **[2]**

**8.** Two fair dice are rolled. D is the positive difference between the two scores (0 if they are
equal).

**(a)** Find the probability distribution of D. **[3]**
**(b)** Find E(D). **[2]**
**(c)** Find P(D ≥ 3). **[1]**

**9.** The random variable X has P(X = x) = kx² for x = 1, 2, 3.

**(a)** Find k. **[2]**
**(b)** Find E(X). **[1]**
**(c)** Find P(X = 3 | X ≥ 2). **[2]**

**10.** An insurer sells one-year phone insurance. In a year, the probability of a claim of $400 is 0.05,
the probability of a claim of $100 is 0.1, and otherwise there is no claim. At most one claim is made per
policy.

**(a)** Find the expected amount the insurer pays per policy. **[2]**
**(b)** The insurer wants an expected profit of $12 per policy. Find the premium it should charge. **[1]**

## Answers

**1. (a)** k(4 + 3 + 2 + 1) = 1 [1], so k = 0.1 [1].
**(b)** E(X) = 0.1(1 × 4 + 2 × 3 + 3 × 2 + 4 × 1) [1] = 0.1 × 20 = 2 [1]. **[4]**

**2. (a)** a = 1 − 0.75 = 0.25 [1].
**(b)** E(Y) = 2(0.15) + 4(0.25) + 6(0.25) + 8(0.35) [1] = 0.3 + 1 + 1.5 + 2.8 = 5.6 [1].
**(c)** 0.25 + 0.35 = 0.6 [1]. **[4]**

**3.** E(gain) = 0.2(k − 1) + 0.8(−1) = 0 [1], so 0.2k − 1 = 0 and k = 5 [1]. **[2]**

**4.** E(X) is the long-run mean number of goals over many matches, not the result of a single match [1].
**[1]**

**5. (a)** P(X = 0) = 1/8, P(X = 1) = 3/8, P(X = 2) = 3/8, P(X = 3) = 1/8 [2].
**(b)** (0 + 3 + 6 + 3)/8 = 1.5 [1].
**(c)** 3/8 + 1/8 = 1/2 [1]. **[4]**

**6. (a)** p + 0.3 + q + 0.1 = 1, so p + q = 0.6 [1]. p + 0.6 + 3q + 0.4 = 2.3 [1], so p + 3q = 1.3 [1].
Subtracting: 2q = 0.7, q = 0.35 [1], p = 0.25 [1].
**(b)** 0.25 + 0.3 = 0.55 [1]. **[6]**

**7. (a)** Gains: 11 with probability 1/6, −1 with probability 2/6, −4 with probability 3/6 [2].
**(b)** E(gain) = (11 − 2 − 12)/6 = −0.5 [1]. Not fair: the player loses 50 cents per game on average [1].
**(c)** Expected amount received = 15(1/6) + 3(2/6) = 21/6 [1] = $3.50, so the stake should be $3.50 [1].
**[6]**

**8. (a)** From the 36-cell grid: P(D = 0) = 6/36, P(D = 1) = 10/36, P(D = 2) = 8/36, P(D = 3) = 6/36,
P(D = 4) = 4/36, P(D = 5) = 2/36 [3] (2 marks for at least four correct values).
**(b)** E(D) = (0 + 10 + 16 + 18 + 16 + 10)/36 [1] = 70/36 = 35/18 ≈ 1.94 [1].
**(c)** (6 + 4 + 2)/36 = 1/3 [1]. **[6]**

**9. (a)** k(1 + 4 + 9) = 14k = 1 [1], so k = 1/14 [1].
**(b)** (1 + 8 + 27)/14 = 36/14 = 18/7 [1].
**(c)** P(X = 3)/P(X ≥ 2) = (9/14)/(13/14) [1] = 9/13 [1]. **[5]**

**10. (a)** 400(0.05) + 100(0.1) + 0(0.85) [1] = 20 + 10 = $30 [1].
**(b)** 30 + 12 = $42 [1]. **[3]**

## Where marks are usually lost

- Writing prizes rather than gains in question 7(a).
- Using one equation for two unknowns in question 6.
- Including P(Y = 4) in question 2(c).
- Forgetting the "no claim" outcome when checking probabilities sum to 1 in question 10.
- Dividing by 1 instead of P(X ≥ 2) in the conditional probability in question 9(c).
