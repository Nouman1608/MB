## Section B: structured questions

**6.** An online bank sends a six-digit code to a customer's phone app each time they log in, in addition to asking for their password.

**(a)** Name this type of authentication method. **[1]**

**(b)** Explain why this is more secure than using a password alone. **[2]**

**(c)** Give **one** problem the customer could have with this method. **[1]**

**7.** A company issues each employee with a smart card to enter the building.

**(a)** Give **two** advantages of smart cards over magnetic stripe cards. **[2]**

**(b)** Explain why the company asks employees to enter a PIN as well as presenting the card. **[2]**

**8.** A phone unlocks automatically when it recognises its owner's face and normal location, without the owner entering anything.

**(a)** Name the authentication approach described. **[1]**

**(b)** Give **one** advantage and **one** concern about this approach. **[2]**

**9.** A student downloads a free program and copies files from a friend's pen drive.

**(a)** Describe **two** actions the anti-malware software should carry out. **[2]**

**(b)** The software finds a suspicious file and quarantines it. Explain what this means and why it is done instead of deleting the file straight away. **[2]**

**(c)** Explain why the anti-malware software must be kept up to date. **[2]**

**10.** A charity holds a weekly meeting with volunteers in ten countries. Many volunteers only have a basic mobile phone.

**(a)** Recommend a type of electronic conference. **[1]**

**(b)** Justify your recommendation. **[2]**

**(c)** Give **one** disadvantage of this type of conference for the charity. **[1]**

**11.** A school plans to run online revision lessons in which the teacher shows slides, answers typed questions and runs short quizzes.

**(a)** Name the most suitable type of electronic conferencing. **[1]**

**(b)** List the hardware a student needs at home, and the network connection. **[3]**

**(c)** Give **two** problems the school may have with these lessons. **[2]**

**12.** A company is replacing face-to-face meetings between its offices in three countries with video-conferencing.

Discuss the advantages and disadvantages of this decision for the company. **[6]**

## Answers

**1.** Making sure data can be seen only by the people who are authorised to see it. **[1]**

**2.** Anti-spyware. **[1]**

**3.** C. **[1]**

**4.** Any two: fingerprint (1); face recognition (1); iris or retina scan (1); voice recognition (1). **[2]**

**5.** Any two: *Manchester* is a dictionary word or place name (1); *12345678* uses only numbers in an obvious sequence (1); *Ahmed2009* contains a name and probably a birth year, which others could guess (1); none of them mixes upper and lower case letters, numbers and symbols (1). **[2]**

**6. (a)** Electronic token (credit one-time passcode or two-factor authentication). **[1]**

**(b)** The code changes every time and works only once (1), so a criminal who steals or intercepts the password still cannot log in without the customer's phone (1). **[2]**

**(c)** Any one: phone lost, stolen or out of battery means no access (1); no mobile signal or internet to receive the code (1). **[1]**

**7. (a)** Any two: the chip is harder to copy than a magnetic stripe (1); the chip can store more data (1); can be contactless, so quicker to use (1); not damaged by magnetic fields (1). **[2]**

**(b)** If a card is lost or stolen (1), the finder cannot enter the building without also knowing the PIN (1). **[2]**

**8. (a)** Zero login (credit biometric if face recognition is the focus). **[1]**

**(b)** Advantage: quick and convenient, nothing to remember or type (1). Concern: the phone must continually monitor the owner's face and location, raising privacy concerns, or the owner may not realise when the device is unlocked (1). **[2]**

**9. (a)** Any two: scan the downloaded program before it is installed or run (1); scan the pen drive before files are opened (1); remove or quarantine any malware found (1); warn the student about infected files (1). **[2]**

**(b)** The file is moved to a secure area where it cannot run or spread (1); this lets the user check whether it is really malware and restore it if it is safe, instead of losing a file that may be needed (1). **[2]**

**(c)** New malware is created all the time (1); the software needs the latest information about threats to recognise and remove them (1). **[2]**

**10. (a)** Audio-conferencing. **[1]**

**(b)** Any two: volunteers only need a basic phone to join, using a phone number and PIN (1); works without a fast internet connection (1); cheap to set up and use (1). **[2]**

**(c)** Any one: no visual contact, so body language is lost (1); cannot share documents or slides (1); hard to know who is speaking with many participants (1); different time zones (1). **[1]**

**11. (a)** Web-conferencing. **[1]**

**(b)** Computer, laptop, tablet or phone (1); microphone and speakers or headset, with a webcam if video is wanted (1); a reliable internet connection, ideally fast broadband (1). **[3]**

**(c)** Any two: some students may not have suitable devices or fast internet (1); lag or dropped connections interrupt lessons (1); uninvited people could join if the meeting is not secured (1); it is harder for the teacher to check that students are paying attention (1). **[2]**

**12.** Advantages, up to 4: no travel time, so staff are more productive (1); saves travel and hotel costs (1); meetings can be arranged at short notice, for example in an emergency (1); participants can see body language and facial expressions, unlike audio-conferencing (1); less travel reduces pollution (1). Disadvantages, up to 4: time zone differences make scheduling difficult (1); equipment such as cameras and large screens has an initial cost (1); poor connections cause lag, frozen pictures or dropped calls (1); less personal than meeting face to face, so relationships may be harder to build (1); confidential meetings could be intercepted if not secured (1). **[6]** Award a maximum of 6 marks from these points; one-sided answers are limited to 4 marks.

## Frequently asked questions

**Is a one-time passcode sent by text an electronic token?**
In this section, an electronic token is software, usually on a phone, that generates or receives a one-time code. A physical token is a separate small device that generates the code.

**What hardware should I list for video-conferencing?**
Webcams or video cameras, large monitors or screens, microphones and speakers. Software and the network connection are separate points, so list them only when the question asks.
