These questions cover section **3.2 Logarithmic and exponential functions** of Pure Mathematics 3 (Paper 3) in the Cambridge International AS & A Level Mathematics 9709 syllabus for 2026 and 2027. A calculator is allowed, but show the logarithm step before any decimal. Give non-exact answers to 3 significant figures unless told otherwise. The number in square brackets after the last part of each question is the total for the whole question.

## Questions

### Section A: short questions

**1.** Solve the equation 5^(2x) = 3^(x+1), giving x correct to 3 significant figures. **[3]**

**2.** Solve the inequality 4 × 3^(2x+1) > 7, giving the critical value correct to 3 significant figures. **[3]**

**3.** It is given that ln a = p and ln b = q. Express ln(a²√b/e) in terms of p and q. **[2]**

**4.** Solve the equation ln(3x + 1) = 2 + ln x, giving x in exact form. **[3]**

**5.** Find the smallest integer n for which 0.6ⁿ < 0.05. **[3]**

**6.** Solve the equation eˣ + 6e^(−x) = 5, giving your answers in exact form. **[4]**

### Section B: longer questions

**7.** The variables x and y satisfy the equation y = kxⁿ, where k and n are constants. The graph of ln y against ln x is a straight line passing through the points (0.4, 1.9) and (2.0, −0.5).

**(a)** Show that ln y = ln k + n ln x.

**(b)** Find the values of n and k.

**(c)** Find the value of y when x = 3. **[5]**

**8.** The variables x and y are related by y = A × bˣ, where A and b are constants. When x = 2, y = 18.0, and when x = 5, y = 3.89.

**(a)** Show that the graph of ln y against x is a straight line, and state what its gradient and intercept represent.

**(b)** Find the values of A and b, each correct to 3 significant figures. **[6]**

**9.** The function f is defined by f(x) = 4 − e^(2x) for all real x.

**(a)** State the range of f.

**(b)** Sketch the graph of y = f(x), giving the exact coordinates of the points where it meets the axes and the equation of the asymptote.

**(c)** Find an expression for f⁻¹(x) and state the domain of f⁻¹. **[7]**

**10.** **(a)** Solve the equation 4ˣ − 3 × 2^(x+1) + 8 = 0.

**(b)** Hence solve the inequality 4ˣ − 3 × 2^(x+1) + 8 < 0. **[6]**

**11.** Solve the equation 2 ln(x + 3) − ln(x + 1) = 3 ln 2. **[4]**

**12.** The mass, m grams, of a radioactive substance t days after a measurement begins is modelled by m = 80e^(−0.04t).

**(a)** State the mass when the measurement begins.

**(b)** Find the time taken for the mass to fall to 20 grams.

**(c)** Show that the graph of ln m against t is a straight line, and state its gradient and the exact value of its intercept. **[6]**

## Answers

**1.** 2x ln 5 = (x + 1) ln 3 [1]. x(2 ln 5 − ln 3) = ln 3 [1]. x = ln 3/ln(25/3) = **0.518** [1]

**2.** 3^(2x+1) > 7/4, so (2x + 1) ln 3 > ln 1.75 [1]. 2x + 1 > 0.5094 [1]. **x > −0.245** [1]

*Examiner insight:* ln 3 is positive, so the sign stays the same; divide by 4 before taking logarithms to avoid a messy ln 4 term.

**3.** ln a² + ln b^½ − ln e = 2 ln a + ½ ln b − 1 [1] = **2p + ½q − 1** [1]

**4.** ln(3x + 1) − ln x = 2, so ln((3x + 1)/x) = 2 [1]. 3x + 1 = e²x [1]. x(e² − 3) = 1, so **x = 1/(e² − 3)** [1]

**5.** n ln 0.6 < ln 0.05 [1]. ln 0.6 < 0, so the sign reverses: n > ln 0.05/ln 0.6 = 5.86 [1]. **n = 6** [1]

*Examiner insight:* answering n < 5.86, or n = 5, shows the sign was not reversed.

**6.** Multiply by eˣ: e^(2x) − 5eˣ + 6 = 0 [1]. (eˣ − 2)(eˣ − 3) = 0 [1]. **x = ln 2** [1] or **x = ln 3** [1]

**7.** **(a)** ln y = ln(kxⁿ) = ln k + ln xⁿ = ln k + n ln x [1]

**(b)** Gradient n = (−0.5 − 1.9)/(2.0 − 0.4) = −2.4/1.6 = **−1.5** [1]. 1.9 = ln k − 1.5 × 0.4, so ln k = 2.5 [1]. **k = e^2.5 = 12.2** [1]

**(c)** y = 12.18 × 3^(−1.5) = **2.34** [1]

*Examiner insight:* the intercept on these axes is ln k, so giving k = 2.5 loses the final accuracy mark in (b).

**8.** **(a)** ln y = ln A + x ln b [1], which has the form Y = c + mX with Y = ln y and X = x; gradient ln b, intercept ln A [1]

**(b)** ln 18.0 = 2.8904 and ln 3.89 = 1.3584 [1]. Gradient = (1.3584 − 2.8904)/3 = −0.5107, so b = e^(−0.5107) = **0.600** [1]. ln A = 2.8904 + 2 × 0.5107 = 3.9117 [1]. **A = 50.0** [1]

*Examiner insight:* keep four or more significant figures in the logarithms; rounding ln 3.89 to 1.36 early changes A in the third figure.

**9.** **(a)** e^(2x) > 0, so **f(x) < 4** [1]

**(b)** Decreasing curve, y-intercept (0, 3) [1]. Meets the x-axis where e^(2x) = 4: **(ln 2, 0)** [1]. Asymptote **y = 4** as x → −∞, curve drawn approaching it from below [1]

**(c)** y = 4 − e^(2x) gives e^(2x) = 4 − y [1], so x = ½ ln(4 − y). **f⁻¹(x) = ½ ln(4 − x)** [1], domain **x < 4** [1]

**10.** **(a)** 4ˣ = (2ˣ)² and 2^(x+1) = 2 × 2ˣ [1]. With y = 2ˣ: y² − 6y + 8 = 0 [1]. (y − 2)(y − 4) = 0, so 2ˣ = 2 or 2ˣ = 4 [1]. **x = 1 or x = 2** [1]

**(b)** (y − 2)(y − 4) < 0 gives 2 < 2ˣ < 4 [1]. **1 < x < 2** [1]

**11.** ln((x + 3)²/(x + 1)) [1] = ln 8 [1]. (x + 3)² = 8(x + 1), so x² + 6x + 9 = 8x + 8 and x² − 2x + 1 = 0 [1]. (x − 1)² = 0: **x = 1**, and x + 3 and x + 1 are positive there, so it is valid [1]

**12.** **(a)** t = 0: **m = 80 grams** [1]

**(b)** e^(−0.04t) = 20/80 = 0.25 [1]. −0.04t = ln 0.25 [1]. **t = 34.7 days** [1]

**(c)** ln m = ln 80 − 0.04t, which is linear in t [1]. Gradient **−0.04**, intercept **ln 80** [1]

## Where marks are usually lost

- Taking logarithms without brackets, such as 2x + 1 ln 3.
- Not reversing the inequality after dividing by the logarithm of a number less than 1.
- Missing the substitution 2^(x+1) = 2 × 2ˣ in a disguised quadratic.
- Reading the intercept in linear form as k instead of ln k.
- Rounding logarithms too early in a data question.
- Forgetting that the domain of an inverse is the range of the original function.
