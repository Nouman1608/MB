This set covers **syllabus section 1.13** of IB DP Mathematics: Analysis and Approaches (first assessment 2021): polar (modulus–argument) form, Euler form, and sums, products and quotients with their geometric interpretation. Every question is **HL only**. Questions are labelled "(calculator-free)" for Paper 1 style or "(calculator allowed)" for Paper 2 and 3 style. Give arguments in the range −π < θ ≤ π unless stated.

Study the methods first in the [section 1.13 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-13/) and the [section 1.13 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-13-revision-notes/).

## Section A

**1.** (calculator-free) Write −3 + 3i in polar form and in Euler form. **[3]**

**2.** (calculator-free) Write 10 cis(−π/6) in the form a + bi. **[2]**

**3.** (calculator-free) Write −2(cos(π/7) + i sin(π/7)) in the form r cis θ, where r > 0 and −π < θ ≤ π. **[2]**

**4.** (calculator-free) Let z = 4 cis(π/3) and w = 2 cis(5π/6). Find, in the form r cis θ:

**(a)** zw **[2]**
**(b)** z/w, and write this answer also in the form a + bi **[2]**

**5.** (calculator-free) Write down |e^(iθ)| for real θ, and show that e^(iθ) × e^(−iθ) = 1. **[2]**

## Section B

**6.** (calculator-free) Let z = 1 + √3 i and w = −1 + i.

**(a)** Write z and w in polar form. **[2]**
**(b)** Hence find zw in polar form, with −π < θ ≤ π. **[2]**
**(c)** Find zw in the form a + bi. **[2]**
**(d)** Hence find the exact value of cos(11π/12). **[2]**

**7.** (calculator-free) Let z = 3 + 4i.

**(a)** Describe the geometric transformation that maps the point representing z to the point representing (1 + i)z. **[2]**
**(b)** Find (1 + i)z in the form a + bi. **[1]**
**(c)** Verify that |(1 + i)z| = √2|z|. **[1]**

**8.** (calculator-free) OABC is a square on an Argand diagram, labelled anticlockwise, where O is the origin and A represents 2 + 5i.

**(a)** Find the complex numbers represented by C and B. **[3]**
**(b)** Find the area of the square. **[1]**

**9.** (calculator-free)

**(a)** Show that sin θ + i cos θ = e^(i(π/2 − θ)). **[3]**
**(b)** Hence write (sin θ + i cos θ)e^(iθ) in Cartesian form. **[1]**

**10.** (calculator allowed) Let z₁ = 5e^(0.6i) and z₂ = 2e^(2.1i).

**(a)** Find z₁z₂ in Euler form. **[1]**
**(b)** Find z₁/z₂ in Euler form, with −π < θ ≤ π. **[1]**
**(c)** Find z₁ + z₂ in the form a + bi, and find |z₁ + z₂|. **[3]**

**11.** (calculator-free)

**(a)** Show that e^(iθ) + e^(−iθ) = 2 cos θ. **[2]**
**(b)** By squaring both sides of the result in (a), show that 4cos²θ = 2 + 2cos 2θ. **[2]**

**12.** (calculator-free) Let z = r cis θ, where r > 0.

**(a)** Show that z/z* = cis 2θ. **[3]**
**(b)** Hence find z/z* in the form a + bi when z = 1 + √3 i. **[1]**

## Answers

**1.** r = √(9 + 9) = 3√2 [1]. Second quadrant, reference angle π/4, so θ = 3π/4 [1]. **3√2 cis(3π/4) = 3√2 e^(3πi/4)** [1]

**2.** 10(√3/2) + 10(−1/2)i [1] = **5√3 − 5i** [1]

**3.** Multiplying by −1 rotates by π: 2 cis(π/7 − π) [1] = **2 cis(−6π/7)** [1]

**4. (a)** 8 cis(π/3 + 5π/6) = 8 cis(7π/6) [1] = **8 cis(−5π/6)** [1]
**(b)** 2 cis(π/3 − 5π/6) = **2 cis(−π/2)** [1] = **−2i** [1]

**5.** |e^(iθ)| = √(cos²θ + sin²θ) = **1** [1]. e^(iθ) × e^(−iθ) = e^(iθ − iθ) = e⁰ = 1 [1]

**6. (a)** z = **2 cis(π/3)** [1]; w = **√2 cis(3π/4)** [1]
**(b)** zw = 2√2 cis(π/3 + 3π/4) = 2√2 cis(13π/12) [1] = **2√2 cis(−11π/12)** [1]
**(c)** −1 + i − √3 i + √3 i² [1] = **(−1 − √3) + (1 − √3)i** [1]
**(d)** Equating real parts: 2√2 cos(−11π/12) = −1 − √3 [1], and cos(−θ) = cos θ, so **cos(11π/12) = −(1 + √3)/(2√2) = −(√6 + √2)/4** [1]

**7. (a)** 1 + i = √2 cis(π/4), so the map is an enlargement with scale factor √2 about the origin [1] and an anticlockwise rotation by π/4 about the origin [1]
**(b)** 3 + 3i + 4i + 4i² = **−1 + 7i** [1]
**(c)** |−1 + 7i| = √50 = 5√2, and √2|z| = √2 × 5 = 5√2 [1]

**8. (a)** C is A rotated by π/2 anticlockwise: C = i(2 + 5i) [1] = **−5 + 2i** [1]. B = A + C = **−3 + 7i** [1]
**(b)** Area = |A|² = 4 + 25 = **29** [1]

**9. (a)** cos(π/2 − θ) = sin θ and sin(π/2 − θ) = cos θ [1]. So e^(i(π/2 − θ)) = cos(π/2 − θ) + i sin(π/2 − θ) [1] = sin θ + i cos θ [1]
**(b)** e^(i(π/2 − θ)) × e^(iθ) = e^(iπ/2) = **i** [1]

**10. (a)** **10e^(2.7i)** [1]
**(b)** **2.5e^(−1.5i)** [1]
**(c)** z₁ = 4.127 + 2.823i and z₂ = −1.010 + 1.726i [1]. z₁ + z₂ = **3.12 + 4.55i** (3 s.f.) [1]. |z₁ + z₂| = **5.51** (3 s.f.) [1]
*Examiner insight:* A sum must be found in Cartesian form. Adding moduli (5 + 2 = 7) is a common error.

**11. (a)** e^(iθ) = cos θ + i sin θ and e^(−iθ) = cos θ − i sin θ [1]. Adding, the sine terms cancel: 2 cos θ [1]
**(b)** LHS² = e^(2iθ) + 2 + e^(−2iθ) [1] = 2 + 2 cos 2θ, using (a) with 2θ in place of θ. RHS² = 4cos²θ, so 4cos²θ = 2 + 2cos 2θ [1]

**12. (a)** z* = r cis(−θ) [1]. z/z* = (r/r) cis(θ − (−θ)) [1] = cis 2θ [1]
**(b)** arg z = π/3, so z/z* = cis(2π/3) = **−1/2 + (√3/2)i** [1]

## Where marks are usually lost

- A negative modulus left in a "polar form" answer.
- Arguments outside the stated range after adding or subtracting.
- Sums attempted in polar form.
- Only one part of a geometric transformation described (rotation without enlargement, or the reverse).
- Rotation direction confused: multiplying by i is anticlockwise.
