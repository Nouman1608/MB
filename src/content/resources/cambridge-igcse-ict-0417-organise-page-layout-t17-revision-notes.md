## Syllabus coverage

| Syllabus statement | Notes and guidance |
|---|---|
| Organise page layout | Edit page layout including page size, page orientation, page margins, number of columns, column width, spacing between columns, set and remove breaks (page, section and column breaks) |

## Key terms

| Term | Meaning |
|---|---|
| Page size | The paper size the document is set up for, such as A4 |
| Orientation | Portrait (taller than wide) or landscape (wider than tall) |
| Margin | Blank space between the paper edge and the text area |
| Text width | Page width minus the left and right margins |
| Column spacing | The gap between one column and the next |
| Section | A part of a document with its own layout settings |
| Page break | Forces the following text onto a new page |
| Column break | Forces the following text to the top of the next column |
| Continuous section break | Starts a new section without starting a new page |
| Next page section break | Starts a new section on a new page |

## Paper sizes to know

- **A4**: 21.0 × 29.7 cm (landscape: 29.7 × 21.0 cm).
- **A5**: 14.8 × 21.0 cm, half of A4.
- **A3**: 29.7 × 42.0 cm, double A4.
- **Letter**: 21.59 × 27.94 cm; a common default to change when A4 is required.

## Formulae

- Text width = page width - left margin - right margin.
- Equal column width = (text width - (columns - 1) × spacing) ÷ columns.
- Check: (columns × width) + ((columns - 1) × spacing) = text width.

### Quick examples

| Page | Margins (L, R) | Columns | Spacing | Text width | Column width |
|---|---|---|---|---|---|
| A4 portrait | 2.5, 2.5 cm | 2 | 1 cm | 16.0 cm | 7.5 cm |
| A4 portrait | 2, 2 cm | 3 | 0.5 cm | 17.0 cm | 5.33 cm |
| A4 landscape | 2.5, 2.5 cm | 3 | 1 cm | 24.7 cm | 7.57 cm |
| A5 portrait | 1.5, 1.5 cm | 2 | 0.8 cm | 11.8 cm | 5.5 cm |

## Which setting for which instruction?

- "Wide table on one page" → next page section breaks before and after; that section landscape.
- "Title across the page, text in columns" → continuous section break after the title; columns on the second section only.
- "Start this heading in the next column" → column break before the heading.
- "Start this chapter on a new page" → page break (or next page section break if the layout changes).

## Removing breaks

1. Show formatting marks (¶).
2. Find the labelled dotted line, for example "Column Break".
3. Select it and press Delete.
4. After deleting a **section** break, check the layout: the text before it may take the settings of the section after it.

## Whole document or one section?

Page size, orientation, margins and columns can each be applied to the **whole document** or to **this section** only (sometimes "this point forward", which inserts a section break for you).

- Apply to the whole document when the instruction says "the document" or "all pages".
- Apply to one section when only part changes, such as a landscape page or the columns under a title.
- After applying, scroll through every page: a setting applied to the wrong section changes pages you did not mean to touch.

## Final layout check

- Paper size and orientation match the task on every page.
- Margin values are correct in the page setup dialogue, in the right units.
- Column count, width and spacing match, and the title spans the page if required.
- No stray page or column breaks, and no blank page at the end.

## Exam traps

- Setting the margin but leaving the **paper size** wrong.
- Mixing **cm and inches** (1 inch = 2.54 cm).
- Counting as many column gaps as columns; there is always **one fewer** gap.
- Using **Enter** to push text to the next page or column instead of a break.
- Using a page break when a **section** break is needed to change orientation or columns.
- Calling column spacing the "gutter margin": the gutter margin is extra space for **binding**.

## Self-test

1. Give the width and height of A4 in landscape.
2. A4 portrait, left margin 3 cm, right margin 2 cm. What is the text width?
3. Text width 16 cm, four equal columns, 0.5 cm spacing. How wide is each column?
4. How many column gaps are there in a three-column layout?
5. Which break starts a new section on the same page?
6. A report needs page 5 alone in landscape. Which breaks are needed?
7. What should be shown on screen to find a break?
8. Why is pressing Enter many times a poor way to start a new page?
9. What can happen to the layout when a section break is deleted?
10. A task gives margins of 2.54 cm. What is this in inches?
11. Two unequal columns of 6 cm and 9 cm with 1 cm spacing fill what text width?

### Answers

1. 29.7 cm wide, 21.0 cm high.
2. 21.0 - 3 - 2 = 16.0 cm.
3. Three gaps of 0.5 cm = 1.5 cm; (16 - 1.5) ÷ 4 = 3.625 cm, about 3.63 cm.
4. Two.
5. A continuous section break.
6. Next page section breaks before and after page 5, with only that section set to landscape.
7. Formatting marks (the ¶ button).
8. The blank lines move when text above them is edited, so the new page starts in the wrong place or a blank page appears.
9. The sections merge and the text before the break can take on the layout of the section after it.
10. 1 inch.
11. 6 + 1 + 9 = 16 cm.
