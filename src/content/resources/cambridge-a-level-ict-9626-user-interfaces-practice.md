## Section A

**1.** Define the term user interface. **[2]**

**2.** Describe a command line interface. **[2]**

**3.** State **two** uses of a gesture-based interface. **[2]**

**4.** Explain why a graphical user interface needs more system resources than a command line interface. **[2]**

**5.** Distinguish between a touch gesture and a touch-free gesture, giving an example of each. **[2]**

**6.** Explain **one** privacy concern about dialogue interfaces in the home. **[2]**

## Section B

**7.** Kestrel Bay Museum is installing information kiosks for visitors.

**(a)** Identify a suitable interface for visitors and justify your choice. **[3]**

**(b)** The museum's technician must update the software on all 40 kiosks each night. Identify a suitable interface for this task and justify your choice. **[3]**

**8.** A car manufacturer plans to control its satellite navigation mainly through a dialogue interface. Discuss the advantages and disadvantages of this plan. **[6]**

**9.** Compare a command line interface with a graphical user interface for a network technician. **[4]**

**10.** Describe how a spoken dialogue interface deals with the request "Set a timer for ten minutes". **[4]**

**11.** Greyfield Supermarkets is considering replacing touch screens on its self-service tills with touch-free gesture control. Evaluate this proposal. **[6]**

**12.** A student with very limited sight needs to use a computer for coursework. Explain which type of interface would help most, and **one** limitation of it. **[4]**

**13.** Hollin Homes sells smart lighting that can be controlled by a smartphone app with a GUI and by a voice assistant. Explain **two** reasons why offering both interfaces is better than offering only one. **[4]**

---

## Answers

**1.** The means by which a user and a computer system communicate [1]: how the user gives instructions and how the system presents output [1]. **[2]**

**2.** The user types commands at a prompt using an exact syntax [1], and the system replies with text output [1]. **[2]**

**3.** Any two from: smartphones and tablets (swipe, pinch) [1]; motion-controlled games or virtual reality [1]; interactive displays; car controls; touch-free control in operating theatres. **[2]**

**4.** A GUI must draw windows, icons and images and update the screen constantly [1], which uses much more memory and processing power than displaying lines of text [1]. **[2]**

**5.** A touch gesture is made in contact with a screen, for example pinching to zoom [1]; a touch-free gesture is detected in the air by cameras or sensors, for example waving a hand to skip a track [1]. **[2]**

**6.** The device listens for a wake word, so it may record or send private conversations by mistake [1], and spoken requests may be stored by the provider, revealing personal information [1]. **[2]**

**7. (a)** A GUI on a touch screen [1], because visitors are untrained and use the kiosk briefly [1], so visible icons and menus let them find information without learning commands [1].

**(b)** A command line interface [1], because the technician can write a script that connects to each kiosk and installs the update [1], so all 40 are updated automatically overnight instead of one at a time [1]. **[6]**

**8.** Advantages: the driver keeps both hands on the wheel [1] and eyes on the road, improving safety [1]; destinations can be spoken rather than typed [1]. Disadvantages: road and passenger noise can cause recognition errors [1]; accents or unusual place names may not be understood [1]; a visual map is still needed, so dialogue cannot replace the screen entirely [1]. **[6]**

**9.** A CLI lets the technician type and script commands to configure many devices quickly [1], whereas a GUI needs many clicks for each device [1]. A CLI requires knowledge of exact syntax, and errors can have serious effects [1], whereas a GUI shows options visually, so it is easier for less familiar tasks [1]. **[4]**

**10.** The device detects the wake word and records the speech [1]. Speech-recognition software converts the sound into text [1]. The system identifies the intended action (start a timer) and the value (ten minutes) [1]. It starts the timer and confirms by replying in speech, such as "Timer set for ten minutes" [1]. **[4]**

**11.** For: customers do not touch a shared screen, improving hygiene [1]; it may feel modern and engaging [1]. Against: gestures can be misread, slowing customers and causing wrong selections [1]; customers must learn which gestures to use, which is hard for occasional or elderly shoppers [1]; cameras and sensors add cost and need suitable lighting [1]. Conclusion: not worthwhile for most stores, because speed and accuracy at the till matter more than touch-free use, unless hygiene is a particular concern [1]. **[6]**

**12.** A dialogue interface [1], because the student can give commands and dictate text by speaking, and the system can read back responses aloud, so sight is not needed [1]. Limitation: recognition errors with unclear speech or noise mean dictated coursework must be checked [1], which is hard without sight, and complex formatting is difficult by voice alone [1]. **[4]**

**13.** The voice assistant allows hands-free control, for example when carrying shopping into a dark room [1], while the GUI app works in noisy rooms or when speaking aloud would disturb others [1]. The GUI shows all lights and settings at once, which is better for setting up schedules and scenes [1], while voice is quicker for single commands such as "lights off" and helps users with limited sight [1]. **[4]**

## Where marks are usually lost

- Naming an interface without justifying it for the user or task.
- Calling every touch-screen action a gesture.
- Giving generic points ("easy to use") that do not distinguish the interfaces.
- Comparing without linking the two sides with "whereas".
- Missing the conclusion in an evaluate question.
