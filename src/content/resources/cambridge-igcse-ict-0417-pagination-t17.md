Under "know and understand" in Topic 17 Document production, Cambridge IGCSE ICT 0417 lists **pagination**: "the purpose of setting page, section and column breaks". The skill of inserting and removing breaks belongs to the page layout row (see the [organise page layout study guide](/resources/cambridge-igcse-ict-0417-organise-page-layout-t17/)). This statement asks something different: **why** you would choose each break, and what would go wrong without it. Questions on it are usually *explain* or *describe* questions, and the practical tasks reward choosing the right break for each situation. The [Document production study guide](/resources/cambridge-igcse-ict-document-production-study-guide/) gives the wider topic.

## Automatic and manual page breaks

**Pagination** is the division of a document into pages. A word processor paginates automatically: when a page is full, the text flows onto the next. This is an **automatic** (soft) page break, and it moves whenever text is added or removed above it.

A **manual** (hard) page break is one you insert. It stays where you put it, and everything after it starts on a new page, however much space is left on the current one. The purpose of setting breaks is to control where pages, sections and columns begin, rather than leaving it to wherever the text happens to run out.

## The purpose of page breaks

A page break is set so that:

- **A new part starts on a new page.** Chapters, a title page, a contents page, an appendix or a bibliography each begin at the top of a page, which makes a long document easier to find your way around.
- **A heading is not stranded.** A heading that falls on the last line of a page, with its text overleaf, can be moved down to start the next page with its content.
- **A table, chart or image stays whole.** Placing a page break before a table that would otherwise split keeps it on one page, where it can be read and compared.
- **The layout survives editing.** Unlike a stack of empty lines, a page break does not move when text above it changes, so the structure of the document is preserved.
- **Printed output is predictable**, which matters when pages will be handed out separately or inserted into a folder.

## The purpose of section breaks

A **section break** divides a document into sections, each of which can have its own page settings. Its purpose is to allow formatting that applies to pages, not to text, to change part-way through a document. Section breaks are set so that different parts can have different:

- **orientation**, such as one landscape page for a wide table in a portrait report;
- **margins** or **paper size**;
- **number of columns**, such as a title across the page above a two-column article;
- **headers and footers**, such as a chapter title in the header that changes for each chapter;
- **page numbering**, such as no number on the cover, roman numerals (i, ii, iii) for the contents, and numbering starting at 1 for the first chapter.

### Which kind of section break?

| Section break | Purpose |
|---|---|
| Next page | The new section, with its new settings, starts on a new page: a landscape page, a new chapter with its own header |
| Continuous | The new section starts on the same page: changing from one column to two under a title |
| Odd page | The new section starts on the next odd-numbered (right-hand) page: chapters of a printed book |
| Even page | The new section starts on the next even-numbered page |

A page break cannot do any of these things: it only starts a new page with the same settings. When the reason for the new page is a change of layout, a next page section break is needed.

## The purpose of column breaks

A **column break** ends the current column and moves the following text to the top of the next column. Its purposes are to:

- **start an article or heading at the top of a column**, so each item in a newsletter begins cleanly;
- **keep an item together**, for example a short list or a box of contact details that would otherwise be split between two columns;
- **control the balance of columns**, so a column does not end with a single line of a new article.

In many word processors, a continuous section break at the end of the final column also **balances** the columns, giving columns of roughly equal length on the last page, rather than one full column and one almost empty.

## Why not use blank lines?

Pressing Enter repeatedly to push text to a new page or column appears to work, but only until something changes. Add one line earlier in the document and the "new page" text starts one line down a page; delete a paragraph and it moves up into the previous page. The blank lines may also end up at the top of a page, leaving an unwanted gap, or create a blank page. Breaks remove the problem because they state the intention ("start a new page here") rather than imitate it.

## Worked example: planning breaks for a report

*Scenario (invented):* a twelve-page project report has a cover page without a page number, a contents page numbered *i*, chapters numbered from 1, each chapter starting on a new page, a wide results table in landscape, and a final page of short notes set in two columns.

| Point in the document | Break | Purpose |
|---|---|---|
| After the cover | Next page section break | Cover can have no page number while the next section is numbered |
| After the contents | Next page section break | Contents numbered in roman numerals; chapter numbering restarts at 1 |
| Between chapters | Page break | Each chapter starts on a new page; same layout, so no new section is needed |
| Before and after the results table | Next page section breaks | Only the table's section is landscape |
| Before the notes page | Next page section break | Notes section set to two columns |
| Within the notes | Column break | Starts the second group of notes at the top of column 2 |

Notice the reasoning: a plain page break is enough where only the page changes; a section break is needed wherever a page setting (numbering, orientation, columns) changes.

## Annotated model answer

*Question: A student is producing a report with a landscape page in the middle. Explain why a section break is needed. [3]*

> Orientation is a page setting that applies to a whole section, **(fact)** so without a break the whole report would become landscape. **(consequence)** A next page section break before and after the table puts it in its own section, **(method)** so that only that page is landscape and the rest stays portrait. **(purpose linked to the scenario)**

*Why it scores:* it says what the break does, why a page break would not do, and applies both to the landscape page in the question.

## Common mistakes

- Writing that a page break and a section break are the same. Only a section break allows page settings to change.
- Saying a column break "makes columns". Columns are set in the layout; a column break moves text to the next column.
- Using blank lines instead of breaks.
- Giving "to start a new page" as the purpose of a section break without saying what settings change.
- Forgetting headers, footers and page numbering as reasons for section breaks.

## Exam technique

For **describe**, say what the break does ("the following text starts at the top of the next column"). For **explain**, add why it is needed in the situation given ("so the article starts cleanly instead of beginning on the last line of column 1"). If the question gives a scenario, every point should refer to it. In practical tasks, before inserting a break, ask: is only the page changing (page break), is a page setting changing (section break), or is it a column (column break)?

## Check your understanding

1. What is the difference between an automatic and a manual page break? *An automatic break is placed by the software when a page is full and moves as text changes; a manual break is inserted by the user and stays in place.*
2. Give two purposes of a page break. *Start a chapter on a new page; keep a table from being split (also keep a heading with its text).*
3. Give three settings that a section break allows to change. *Orientation, columns and page numbering (also margins, headers and footers).*
4. When is a continuous section break used? *When the layout changes on the same page, such as from one column to two.*
5. Give one purpose of a column break. *To start an article or heading at the top of the next column.*
6. Why are blank lines not a substitute for breaks? *They move when text is edited.*
