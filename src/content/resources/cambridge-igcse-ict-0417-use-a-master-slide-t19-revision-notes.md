These notes cover the "Use a master slide" content row of Cambridge IGCSE ICT 0417 Topic 19: inserting and editing objects consistently (images, text, shapes, logos, slide headers and footers, placeholder position, automated slide numbering) and formatting master slide objects (headings, subheadings, bullets, background colour). The [Use a master slide study guide](/resources/cambridge-igcse-ict-0417-use-a-master-slide-t19/) explains each step with a worked example; the [master slide practice questions](/resources/cambridge-igcse-ict-0417-use-a-master-slide-t19-practice/) test it. For the topic as a whole, see the [Presentations revision notes](/resources/cambridge-igcse-ict-presentations-revision-notes/).

## Key terms

| Term | Meaning |
|---|---|
| Master slide | A template slide whose objects and formatting are applied to every slide based on it |
| Main master | The top-level master; changes flow to all layout masters |
| Layout master | The master for one layout (for example title slide); changes affect only slides with that layout |
| Placeholder | A reserved box for a title, body text, footer, date or slide number |
| Field | An item the software fills in automatically, such as the slide number or date |
| Background graphics | Objects on the master that sit behind slide content; a layout can hide them |
| Local formatting | Formatting applied on an individual slide, which overrides the master |
| Reset slide | Command that returns a slide's placeholders to the master's settings |
| Aspect ratio | The ratio of width to height; locking it stops an image being distorted |

## What the master controls

| Syllabus item | How it is done on the master | Check |
|---|---|---|
| Images and logos | Insert on main master, position and size exactly | Same place on every slide, including the title slide |
| Text | Text box on the master (for example organisation name) | Appears on all slides, cannot be moved in normal view |
| Shapes | Draw on master; send to back if it covers placeholders | Slide text still visible |
| Slide headers | Text box at top of master (slides often have no header placeholder) | Present on every slide |
| Slide footers | Footer placeholder, then switch on in header and footer settings | Footer text visible on slides |
| Placeholder position | Move or resize title and body placeholders on the master | All slides with that layout match |
| Automated slide numbering | Slide number field (often shown as `<#>`), switched on in settings | Each slide shows its own number |
| Headings, subheadings | Format the title (and subtitle) placeholders | Every heading matches |
| Bullets | Format each text level: character, colour, size, indent | Only the levels asked for change |
| Background colour | Set on main master | Every layout inherits it |

## Main master or layout master?

- "Every slide" → **main master** (then check each layout does not hide it).
- "Only title slides" or "only slides with the two content layout" → that **layout master**.
- Logo missing from the title slide? That layout probably **hides background graphics**.

## Why use the master? (theory answers)

- **Consistency**: every slide uses the same fonts, colours, logo and positions, giving a house style.
- **Efficiency**: a change is made once and updates every slide.
- **Fewer errors**: nothing is forgotten on one slide; objects cannot be moved by accident in normal view.
- **Automated numbering**: slide numbers stay correct when slides are added, moved or deleted.

## Calculation check: resizing a logo

With the aspect ratio locked, new height = new width × original height ÷ original width.
A 500 × 250 pixel logo set to 5 cm wide becomes 5 × 250 ÷ 500 = **2.5 cm** high.

## Exam traps

- Formatting each slide by hand: small differences appear and the consistency mark is lost.
- Typing a number on the master: every slide shows the same number.
- Footer placed on the master but not switched on in the settings, so it does not show.
- Editing a layout master when the main master was meant, so some slides are missed.
- Changing all bullet levels when the task asked for level 1 only.
- Local formatting on imported slides overriding the master: reset the slides.
- Confusing notes and handouts headers (for printouts) with slide headers.

## Self-test

1. What is a master slide?
2. State the difference between the main master and a layout master.
3. A logo placed on the main master is missing from the title slide only. Suggest why.
4. Why should an automated slide number be used instead of typed numbers?
5. A footer has been typed into the footer placeholder on the master but does not appear on any slide. What has been missed?
6. Where would you create a header that appears at the top of every slide?
7. Why should a logo be resized with the aspect ratio locked?
8. A 900 × 300 pixel logo is resized to 6 cm wide with its aspect ratio locked. Calculate its height.
9. Give **two** reasons for setting the background colour on the master rather than on each slide.
10. A task says first-level bullets must be arrows. What should you change on the master?
11. One slide still shows a different title font after the master is changed. Explain why and how to fix it.
12. Why might a shape placed on the master need to be sent to the back?

### Answers

1. A template slide that holds objects and formatting applied to every slide based on it.
2. Changes to the main master affect all layouts and slides; changes to a layout master affect only slides using that layout.
3. The title slide layout is set to hide background graphics (or the logo was placed on a different layout master).
4. It updates automatically when slides are added, moved or deleted, so numbers are always correct and need not be typed on each slide.
5. The footer has not been switched on in the header and footer settings.
6. In a text box at the top of the main master.
7. To stop it being stretched or squashed, which would distort it.
8. 6 × 300 ÷ 900 = 2 cm.
9. Any two: every slide is the same (consistency); it is done once (saves time); it can be changed in one place; no slide is missed.
10. The bullet character for level 1 of the body placeholder only.
11. That slide has local formatting that overrides the master; reset the slide so it follows the master.
12. So it does not cover the placeholders and hide the slide text.
