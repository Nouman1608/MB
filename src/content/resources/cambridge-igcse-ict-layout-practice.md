These questions cover Cambridge IGCSE ICT 0417 Topic 13: creating or editing a document (13.1), tables (13.2) and headers and footers (13.3). Layout is a practical skill used in Papers 2 and 3, so the page combines short theory questions with practical-style tasks and examiner-style checklists.

## Section A: short answers

**1.** State the purpose of a footer in a document. **[1]**

**2.** Name two automated objects that can be inserted into a header. **[2]**

**3.** State the difference between the *square* and *tight* text-wrapping options. **[2]**

**4.** Give the three vertical alignment options for a table cell. **[3]**

## Section B: structured questions

**5.** A student is writing a report in a word processor.

**(a)** Describe how she would move a paragraph from page 1 to page 3 using cut and paste. **[2]**
**(b)** Explain one advantage of drag and drop over cut and paste for moving a short phrase. **[1]**
**(c)** She inserts an extract from a spreadsheet and a chart. Give two other types of object that can be placed in a document. **[2]**

**6.** A table of exam results has 5 columns and 12 rows.

**(a)** Describe how to add a title across the full width of the table. **[2]**
**(b)** Some subject names are too long for the first column. Describe two ways of making sure they are fully visible. **[2]**
**(c)** Explain why the marks in the table should be right-aligned. **[1]**

**7.** A 30-page manual needs the text "Page 7 of 30" at the bottom of each page.

**(a)** Describe how this should be created. **[2]**
**(b)** Explain why the numbers should not be typed by hand. **[2]**

**8.** A newsletter has a chart placed in the middle of a page of text. The editor wants no text beside the chart.

**(a)** Name the text-wrapping option that should be used. **[1]**
**(b)** A table of prices also needs an extra column for "Discount" and the empty last row removed. Describe how to make these changes. **[2]**
**(c)** Explain why a designer might hide the gridlines of a table used to lay out a form. **[1]**

## Section C: practical-style tasks

Use a word processor. Take screenshots as evidence.

**9.** Create a new document. Insert a table with 3 columns and 5 rows. Enter a heading row: *Item*, *Quantity*, *Price*. Shade the heading row. Centre the heading text horizontally and vertically. Hide the gridlines for the rest of the table. **[5]**

**10.** Insert an image into a paragraph of text. Set the wrapping so the text flows closely around the image's outline. **[1]**

**11.** Add a header with your name at the left margin and the date at the right margin. Add a footer with the file name and path centred. **[4]**

## Worked answers

**1.** To show the same information (such as page numbers, file name or date) at the bottom of every page. **[1]**

**2.** Any two of: file information (file name/path), page number, total number of pages, date, time. **[2]**

**3.** Square wraps text around the rectangular boundary of the object (1); tight wraps text around the outline/shape of the object itself, closer to it (1). **[2]**

**4.** Top (1), middle (1), bottom (1). **[3]**

**5. (a)** Highlight (select) the paragraph and choose cut, which removes it to the clipboard (1); place the cursor at the correct position on page 3 and choose paste (1). **[2]**
**(b)** It is quicker for short distances, because the text is moved in one action without using the clipboard (1). **[1]**
**(c)** Any two of: text, image, screenshot, shapes, table, database extract. **[2]**

**6. (a)** Insert a new row at the top of the table (1) and merge all the cells in that row, then type the title (1). **[2]**
**(b)** Increase the column width (1); set wrap text in the cell so the name continues on a new line (1). **[2]**
**(c)** Numbers line up by their units, so they are easier to read and compare. **[1]**

**7. (a)** Insert a footer and add the automated page number field (1) and the automated total number of pages field, with the text "Page" and "of" between them (1). **[2]**
**(b)** Automated fields update automatically if pages are added or removed (1); typing by hand would take a long time and the numbers would become wrong after editing (1). **[2]**

**8. (a)** Above and below (top and bottom). **[1]**
**(b)** Select a column and insert a column to the right or left, then type the heading "Discount" (1); select the empty last row and delete the row (1). **[2]**
**(c)** The table is used only to line items up neatly, so without visible lines the form looks cleaner and less cluttered to the reader (1). **[1]**

**9.** 1 mark each:
- Table has exactly 3 columns and 5 rows.
- Headings *Item*, *Quantity*, *Price* entered with 100% accuracy.
- Heading row shaded.
- Heading text centred horizontally and vertically.
- Gridlines hidden on the other rows. **[5]**

**10.** Tight wrapping applied (text follows the image's outline). **[1]**

**11.** 1 mark each:
- Name in the header at the left margin.
- Date (preferably an automated field) at the right margin of the header.
- Automated file name and path in the footer.
- Footer item centred. **[4]**

## Frequently asked questions

**How strict is "total accuracy" in data entry?**
Very. In the practical papers text and numbers must match the source exactly, including spelling, capitals and spacing.

**Should the date in a header be typed or automated?**
If the task asks for an automated date, insert the date field; otherwise follow the instruction exactly as written.
