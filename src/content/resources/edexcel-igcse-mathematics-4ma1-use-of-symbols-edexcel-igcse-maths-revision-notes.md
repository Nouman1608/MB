Quick-recall notes for section 2.1, Use of symbols, in Pearson Edexcel International GCSE Mathematics A (4MA1). Foundation statements A to D apply to both tiers; Higher statement A (fractional powers) is Higher tier only. For explanations and worked examples, read the [use of symbols study guide](/resources/edexcel-igcse-mathematics-4ma1-use-of-symbols-edexcel-igcse-maths/); for exam-style questions, use the [use of symbols practice questions](/resources/edexcel-igcse-mathematics-4ma1-use-of-symbols-edexcel-igcse-maths-practice/).

## The four statements in one line each

- **2.1 A:** a letter stands for a number: an unknown in an equation, a variable in an expression or formula.
- **2.1 B:** algebra obeys the rules of arithmetic, including the order of operations.
- **2.1 C:** index notation for positive, zero and negative integer powers.
- **2.1 D:** the three index laws, in simple cases.
- **Higher 2.1 A:** add fractional powers to the list.

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Unknown | A letter with a particular value to be found | x in 4x − 1 = 11 |
| Variable | A letter that can take many values | r in C = 2πr |
| Term | Numbers and letters multiplied together | −7ab² |
| Coefficient | The number multiplying the letters in a term | −7 in −7ab² |
| Expression | Terms combined, with no equals sign | 3m + 2n − 5 |
| Equation | Two expressions equal for particular values | 3m + 2 = 17 |
| Formula | A rule linking quantities | v = u + at |
| Identity | True for every value of the letters | 4(a − 1) = 4a − 4 |
| Index (power) | How many times the base is multiplied by itself | the 5 in y⁵ |
| Base | The number or letter being raised to a power | y in y⁵ |
| Reciprocal | 1 divided by the number | the reciprocal of a³ is a⁻³ |

## Generalised arithmetic

```
a + b = b + a        ab = ba               (commutative)
a − b ≠ b − a        a ÷ b ≠ b ÷ a         (not commutative)
a(b + c) = ab + ac                         (distributive)
2x² = 2 × x²         (2x)² = 4x²
−x²  = −(x²)         (−x)² = x²
```

When x = −4: 2x² = 32, (2x)² = 64, −x² = −16, (−x)² = 16.

## Powers you must know

```
a⁰ = 1   (a ≠ 0)
a⁻ⁿ = 1/aⁿ
a^(1/n) = nth root of a                 Higher
a^(m/n) = (nth root of a)^m             Higher
```

| Value | Result | Value | Result |
|---|---|---|---|
| 9⁰ | 1 | 4⁻³ | 1/64 |
| 10⁻² | 0.01 | (3/5)⁻² | 25/9 |
| 81^(1/4) (Higher) | 3 | 81^(−1/4) (Higher) | 1/3 |
| 8^(2/3) (Higher) | 4 | (8/125)^(2/3) (Higher) | 4/25 |

## Index laws

```
xᵐ × xⁿ = xᵐ⁺ⁿ     xᵐ ÷ xⁿ = xᵐ⁻ⁿ     (xᵐ)ⁿ = xᵐⁿ
```

- Same base only.
- Coefficients: multiply or divide them as numbers; raise them to the outside power.
- Subtracting a negative power adds: y³ ÷ y⁻⁴ = y⁷.

## Exam traps

- **x³ × x⁴** is x⁷; the powers add, they do not multiply.
- **x³ + x⁴** cannot be simplified; the laws are for × and ÷ only.
- **(2a⁵)³** is 8a¹⁵: the 2 is cubed too.
- **5⁻²** is 1/25, a small positive number, not −25.
- **−3² on a calculator** is −9; a negative value substituted into x² must be bracketed.
- **Mixing bases:** 2⁵ × 4² can be done only after writing 4 as 2²: 2⁵ × 2⁴ = 2⁹.
- **Fractional powers (Higher):** root first, then power, then reciprocal if the power is negative.
- **Equation or identity?** If the two sides agree for every value of x, it is an identity; if only for some values, it is an equation.

## Solving for a missing power

```
3ⁿ × 3⁴ = 3¹¹          n + 4 = 11         n = 7
(5²)ⁿ = 5¹²            2n = 12            n = 6
4ˣ = 8 (Higher)        2^(2x) = 2³         x = 3/2
```

## Check an answer with a number

If you are unsure whether a simplification is right, substitute a small number such as x = 2 into both forms.

```
Claim: x³ × x⁴ = x¹²     x = 2:  8 × 16 = 128,  but 2¹² = 4096   wrong
Claim: x³ × x⁴ = x⁷      x = 2:  128 and 2⁷ = 128                 agrees
Claim: (3x)² = 3x²       x = 2:  6² = 36,  but 3 × 4 = 12         wrong
```

One agreeing value does not prove an identity, but one disagreeing value proves a claim is false. This is also a quick way to answer "Is this an identity?" questions: a single counter-example shows it is not.

## What to write down

- In a "Simplify" question, deal with the number part and the letter part separately and write both, even if you are unsure of one.
- For a missing power, write the equation in the powers (n − 3 = 6) before the answer, so the method is visible.
- For a Higher fractional power, write the root step and the reciprocal step on separate lines, so a slip in one does not hide the other.

## Self-test

1. In V = lwh, are l, w and h unknowns or variables?
2. Is 3(x − 2) = 3x − 6 an equation or an identity? Explain.
3. Find 3y² and (3y)² when y = −2.
4. Write down the value of 7⁰ and of 2⁻⁵.
5. Simplify 5m⁴ × 6m⁻⁷.
6. Simplify 18k³ ÷ 6k⁻⁵.
7. Simplify (4p³q)².
8. Find n if 2ⁿ ÷ 2³ = 2⁶.
9. Write 1/x⁴ as a power of x.
10. (Higher) Work out 125^(−2/3).
11. (Higher) Find x if 9ˣ = 27.
12. (Higher) Write x² × √x as a single power of x.

### Answers

1. **Variables**: the formula holds for many values of each.
2. An **identity**: it is true for every value of x, because expanding the left side gives the right side.
3. 3 × 4 = **12** and (−6)² = **36**.
4. **1** and **1/32**.
5. **30m⁻³** (or 30/m³).
6. **3k⁸**.
7. **16p⁶q²**.
8. n − 3 = 6, so **n = 9**.
9. **x⁻⁴**.
10. Cube root of 125 is 5; 5² = 25; reciprocal gives **1/25**.
11. 3^(2x) = 3³, so 2x = 3 and **x = 3/2**.
12. x² × x^(1/2) = **x^(5/2)**.
