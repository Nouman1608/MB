## Section A

**1.** State what is meant by a natural number, according to the AQA specification. **[1]**

**2.** State what is meant by a rational number. **[1]**

**3.** State what is meant by an irrational number. **[1]**

**4.** State the difference between a cardinal number and an ordinal number. **[2]**

**5.** State the type of number used for counting and the type used for measurement. **[2]**

**9.** Express the relationship between the sets ℕ, ℤ, ℚ and ℝ using the subset symbol ⊂, and state which numbers are in ℝ but not in ℚ. **[2]**

**10.** The set S = {'e', 'h', 'm', 'r'} is placed in alphabetical order.

**(a)** The number of goals scored in a football match. **[2]**

**(c)** The time a runner takes to complete a race, in seconds. **[2]**

**12.** The set of natural numbers is described as countably infinite, and the set of real numbers is not countable. Explain what this means. **[3]**

## Answers

**1.** A whole number from zero upwards (0, 1, 2, 3, …); zero is included [1].

**2.** A number that can be written as a fraction (ratio) of two integers [1].

**3.** A number that cannot be written as a fraction of two integers [1].

**4.** A cardinal number says how many there are (a quantity) [1]; an ordinal number says the position of an object in an ordered arrangement, such as 1st or 2nd [1].

**5.** Natural numbers for counting [1]; real numbers for measurement [1].

**6.**

| Number | ℕ | ℤ | ℚ | ℝ |
|---|---|---|---|---|
| 14 | yes | yes | yes | yes |
| −6 | no | yes | yes | yes |
| 5/8 | no | no | yes | yes |
| √36 | yes | yes | yes | yes |
| √3 | no | no | no | yes |

One mark for each row correct [5]. (√36 = 6; √3 is irrational, so it is real but not rational.)

**7. (a)** Rational, because 0.8 = 4/5 and can be written as a fraction [1].
**(b)** Rational [1], because it is a repeating decimal and can be written as a fraction (45/99 = 5/11) [1].
**(c)** Irrational [1].
**(d)** Rational [1], because every integer can be written as a fraction with denominator 1 (−7/1) [1].

**8.** √16 = 4 [1], which is a whole number and so rational (and natural) [1]; a square root is irrational only if the number is not a perfect square, for example √2 or √3 [1].

**9.** ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ [1]; the irrational numbers (such as √2 and π) are in ℝ but not in ℚ [1].

**10. (a)** 3rd (the order is e, h, m, r) [1].
**(b)** 2 [1].
**(c)** The ordinal position counts from 1 but the array index counts from 0 [1].

**11. (a)** Natural number [1], because it is a count of whole events and cannot be negative [1].
**(b)** Integer (or real) [1]; it can be negative, and an integer is enough if only whole degrees are recorded; a real number is needed if fractions of a degree matter [1].
**(c)** Real number [1], because time is a measurement on a continuous scale which can have fractional parts [1].

**12.** A set is infinite if it has no last member [1]; a countably infinite set can be matched one-for-one with the natural numbers (its members can be counted off as 1st, 2nd, 3rd and so on) [1]; the real numbers cannot be matched in this way, so they are not countable [1].

**13.** π is irrational, so its decimal expansion never ends or repeats and would need infinitely many digits [1]; only a finite approximation, to a limited number of binary digits, can be stored [1].

## Where marks are usually lost

- Treating zero as outside the natural numbers.
- Calling every square root irrational.
- Saying integers are not rational numbers.
- Confusing ordinal position with array index.
- Giving "measurement" as an integer count without thinking about precision.
