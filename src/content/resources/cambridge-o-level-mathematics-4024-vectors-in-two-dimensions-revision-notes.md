These notes condense section 7.2, Vectors in two dimensions, of the Cambridge O Level Mathematics (Syllabus D) 4024 syllabus for 2025, 2026 and 2027. Explanations and longer examples are in the [vectors in two dimensions study guide](/resources/cambridge-o-level-mathematics-4024-vectors-in-two-dimensions/); exam-style questions are in the [vectors in two dimensions practice questions](/resources/cambridge-o-level-mathematics-4024-vectors-in-two-dimensions-practice/). Column vectors are typed here as (x, y), with x on top.

## The three outcomes

1. Describe a translation by a column vector, by AB or by a single letter **a**.
2. Add and subtract vectors.
3. Multiply a vector by a scalar.

## Key terms

| Term | Meaning |
|---|---|
| Vector | a quantity with size and direction |
| Column vector (x, y) | x across (right positive), y up (positive) |
| AB | the vector from A to B |
| Equal vectors | same components, so same size and direction, anywhere on the grid |
| Negative vector −a | same size, opposite direction; both signs change |
| Scalar | an ordinary number that multiplies a vector |
| Translation | a slide of every point by the same vector |
| Triangle rule | AB + BC = AC: follow one vector, then the next from where it ends |

## Rules to remember

```
PQ = Q − P               (end minus start, component by component)
QP = −PQ
a + b = (a₁ + b₁, a₂ + b₂)
a − b = (a₁ − b₁, a₂ − b₂)
ka = (ka₁, ka₂)
```

- Handwrite single-letter vectors with an underline.
- A translation by u then by v is a translation by u + v.
- The inverse of the translation u is the translation −u.
- ka is parallel to a. If k < 0 it points the opposite way.

## Worked reminders

With p = (4, 1) and q = (−1, 3):

```
p + q = (3, 4)
p − q = (5, −2)
3p = (12, 3)     2q = (−2, 6)
3p − 2q = (14, −3)
```

**Describing a translation:** an object point (3, −2) has image (−1, 4). Image minus object gives (−4, 6), so the transformation is the **translation (−4, 6)**.

**Vector equation:** (2k, 5) − (3, m) = (7, −1) gives two equations: 2k − 3 = 7 and 5 − m = −1, so k = 5 and m = 6.

**Two unknown scalars:** ap + bq = (7, 5) gives 4a − b = 7 and a + 3b = 5. Solving simultaneously: a = 2, b = 1. Check: 2p + q = (8, 2) + (−1, 3) = (7, 5).

## Method box: vector equations

1. Simplify each side into a single column, keeping the unknowns.
2. Equate the top components; equate the bottom components.
3. Solve the one or two equations.
4. Substitute back to check.

## Method box: translation questions

1. Pick a vertex and its image.
2. Count across (right positive) and up (up positive), or subtract coordinates.
3. Check the same vector works for a second vertex.
4. Answer: "translation by the vector (x, y)" written as a column.

## Must-know distinctions

| Idea | Do | Do not |
|---|---|---|
| Vector from P to Q | Q − P | P − Q |
| Reversing a vector | change both signs | change one sign |
| Scalar multiple | multiply both components | multiply the top only |
| Subtracting | a + (−b), so 3 − (−2) = 5 | write 3 − 2 |
| Naming a translation | "translation by (x, y)" | "moved", "shifted" |
| Written answer | numbers one above the other | a coordinate pair |

## Drawing vectors on a grid

- Start the arrow at any grid point; position does not change the vector.
- For a + b, draw b from the head of a. The result runs from the tail of a to the head of b.
- For a − b, draw −b (the reverse of b) from the head of a.
- For 2a, draw two copies of a end to end; for −a, reverse the arrow.

## Exam traps

- Start minus end, which gives the reverse vector.
- Top and bottom swapped.
- −(−2) treated as −2 when subtracting.
- Scaling only the top number.
- Naming the transformation "move", "shift" or "slide" instead of translation.
- Writing a vector answer as coordinates rather than a column.
- Solving only one of the two component equations.

## Self-test

1. A is (2, 5) and B is (−3, 1). Find AB.
2. Using question 1, write down BA.
3. With p = (4, 1) and q = (−1, 3), find p + q.
4. Find 3p − 2q.
5. Find −½ × (4, −6).
6. A translation maps (3, −2) onto (−1, 4). Find its vector.
7. Write down the vector of the translation that maps (−1, 4) back onto (3, −2).
8. Find the single translation equivalent to (1, 3) followed by (5, −7).
9. Find r such that p + r = q.
10. Find k and m if (2k, 5) − (3, m) = (7, −1).
11. Is (−12, −3) a scalar multiple of p = (4, 1)? Explain.
12. Find a and b such that ap + bq = (7, 5).

### Answers

1. (−3 − 2, 1 − 5) = **(−5, −4)**.
2. **(5, 4)**.
3. **(3, 4)**.
4. (12, 3) − (−2, 6) = **(14, −3)**.
5. **(−2, 3)**.
6. **(−4, 6)**.
7. **(4, −6)**, the negative of the vector in question 6.
8. **(6, −4)**.
9. r = q − p = **(−5, 2)**.
10. 2k − 3 = 7, so **k = 5**; 5 − m = −1, so **m = 6**.
11. **Yes**: (−12, −3) = −3 × (4, 1), so it is −3p (parallel to p, opposite direction).
12. 4a − b = 7 and a + 3b = 5, so **a = 2, b = 1**.
