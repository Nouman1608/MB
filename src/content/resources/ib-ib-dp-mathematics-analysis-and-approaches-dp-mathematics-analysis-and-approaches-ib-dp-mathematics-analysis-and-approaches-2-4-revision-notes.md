These notes condense section 2.4 of the IB *Mathematics: analysis and approaches guide* (first assessment 2021): determining key features of graphs (maximum and minimum values, intercepts, symmetry, vertex, zeros or roots, and vertical and horizontal asymptotes) and finding points of intersection of two curves or lines, using technology. It is common to SL and HL. For explanations and worked examples, see the [2.4 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-4/); for exam-style questions, see the [2.4 practice set](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-4-practice/).

## Core recall

- **Zeros** of f = **roots** of f(x) = 0 = x-coordinates of the x-intercepts.
- **Maximum value** is a y-value; **maximum point** is (x, y).
- On a restricted domain, compare turning points **and** end points.
- **Vertex:** turning point of a parabola; the axis of symmetry passes through it.
- **Vertical asymptote x = a:** f(x) grows without limit as x → a; usually a zero denominator.
- **Horizontal asymptote y = b:** f(x) → b as x → ±∞.
- **Intersection of y = f(x) and y = g(x):** use the intersect tool, or the zeros of f − g.
- GDC answers to **3 significant figures** unless the value is exact.

## Key terms

| Term | Meaning |
|---|---|
| Local maximum | Higher than all nearby points |
| Global (absolute) maximum | Highest value over the whole domain |
| Zero | Input that gives output 0 |
| Root | Solution of an equation |
| Vertex | Turning point of a parabola |
| Line symmetry | Mirror symmetry in a line such as x = 3 or the y-axis |
| Rotational symmetry about the origin | Rotating by 180° about (0, 0) leaves the graph unchanged |
| Asymptote | Line approached by the curve; written as an equation |
| Point of intersection | Point that lies on both graphs |

## GDC routine

1. Enter the function(s) exactly, with brackets around numerators and denominators.
2. Choose a window that shows every feature; zoom out first, then in.
3. Use the max, min, zero and intersect tools; one point at a time.
4. Use the table of values to test asymptotes (large |x|, and x close to an excluded value).
5. Substitute any value that looks exact to confirm it.
6. Write each answer in the form asked for.

## Spotting features without a GDC

| Clue in the formula | Feature |
|---|---|
| Denominator zero at x = a (numerator not zero) | Vertical asymptote x = a |
| Numerator zero (denominator not zero) | Zero of the function |
| f(−x) = f(x) | Symmetric about the y-axis |
| f(−x) = −f(x) | Rotational symmetry about the origin |
| a(x − h)² + k | Vertex (h, k), axis x = h |
| Fraction with a bottom of higher degree than the top | Horizontal asymptote y = 0 |

**Quick example.** For f(x) = 6/(x² + 3): no vertical asymptote, horizontal asymptote y = 0, symmetric about the y-axis, maximum (0, 2), range 0 < f(x) ≤ 2.

## Number of solutions of f(x) = k

Draw the horizontal line y = k across your graph and count the crossings. Use the maximum and minimum values and the asymptotes as the boundary values of k.

**Quick example.** y = x³ − 12x has local maximum (−2, 16) and local minimum (2, −16). For x ∈ ℝ, f(x) = k has three solutions when −16 < k < 16, two when k = ±16, and one otherwise.

## Exam traps

- Value versus coordinates confused.
- End points ignored for greatest and least values on a restricted domain.
- Asymptotes written as numbers, or the GDC's joining line taken as an asymptote.
- An intersection outside the default window missed.
- Degree mode used for a trigonometric function given in radians.
- Early rounding carried into later parts.

## Self-test

1. What is the difference between a zero and a root?
2. f(x) = 2(x − 4)² + 1. Write down the vertex and the axis of symmetry.
3. Write down the vertical asymptote of y = 5/(x + 3).
4. Write down the horizontal asymptote of y = 2 + 1/x.
5. f has a local maximum (1, 4) on the domain −2 ≤ x ≤ 3, and f(3) = 9. What is the greatest value of f?
6. Find the intersection of y = x² and y = 2x + 3.
7. g(−x) = g(x) for all x. Describe the symmetry of the graph.
8. f(x) = 6/(x² + 3). State the range.
9. How do the zeros of f − g relate to the graphs of f and g?
10. The GDC gives an intersection at x = 2.9999998. What should you do?
11. y = x³ − 12x. For which k does x³ − 12x = k have exactly two solutions?
12. Explain why y = 4/(x² + 1) has no vertical asymptote.

### Answers

1. A zero belongs to a function (f(x) = 0); a root is a solution of an equation.
2. Vertex (4, 1); axis x = 4.
3. x = −3
4. y = 2
5. 9, at the end point x = 3.
6. x² − 2x − 3 = 0, so x = 3 or x = −1: (3, 9) and (−1, 1).
7. Symmetric about the y-axis.
8. 0 < f(x) ≤ 2
9. They are the x-coordinates of the points where the graphs intersect.
10. Test x = 3 by substitution; if it works, give the exact value 3.
11. k = 16 or k = −16.
12. x² + 1 ≥ 1 for all x, so the denominator is never zero.
