Condensed notes for subtopic **2.4 Indices II** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025–2027. The [Indices II study guide](/resources/cambridge-o-level-mathematics-4024-indices-ii/) explains each rule with worked examples; the [Indices II practice questions](/resources/cambridge-o-level-mathematics-4024-indices-ii-practice/) give exam-style questions with mark schemes.

## Syllabus outcomes

1. Understand and use indices: positive, zero, negative and fractional.
2. Understand and use the rules of indices.

Includes solving equations such as 32^x = 2. Logarithms are not required: match the bases instead.

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Base | The number or letter being raised to a power | 5 in 5³ |
| Index (power, exponent) | How many times the base is used as a factor | 3 in 5³ |
| Zero index | Any non-zero base to the power 0 equals 1 | 7⁰ = 1 |
| Negative index | The reciprocal of the positive power | 4^(−2) = 1/16 |
| Unit fraction index | A root | 125^(1/3) = 5 |
| Fractional index m/n | Root n, then power m | 81^(3/4) = 27 |
| Reciprocal | 1 divided by the number; a fraction turned over | reciprocal of 2/3 is 3/2 |

## The rules

```
a^m × a^n = a^(m+n)          a^m ÷ a^n = a^(m−n)        (a^m)^n = a^(mn)
a^0 = 1                      a^(−n) = 1/a^n             a^(1/n) = ⁿ√a
a^(m/n) = (ⁿ√a)^m            (ab)^n = a^n b^n           (a/b)^(−n) = (b/a)^n
```

## Evaluating: order of steps

1. Negative sign in the index → take the reciprocal.
2. Denominator of the index → take that root.
3. Numerator of the index → raise to that power.

| Expression | Working | Value |
|---|---|---|
| 125^(−2/3) | ∛125 = 5; 5² = 25; reciprocal | 1/25 |
| 81^(3/4) | ⁴√81 = 3; 3³ | 27 |
| (9/25)^(−1/2) | turn over → (25/9)^(1/2) | 5/3 |
| (1/8)^(−2/3) | turn over → 8^(2/3) = 2² | 4 |
| 10000^(−3/4) | ⁴√10000 = 10; 10³; reciprocal | 1/1000 |
| 36^(3/2) | √36 = 6; 6³ | 216 |
| 7⁰ × (1/2)^(−2) | 1 × 2² | 4 |

## Simplifying: method

Numbers with numbers, each letter with itself.

```
5x^(2/3) × 2x^(−1/6)   = 10x^(2/3 − 1/6) = 10x^(1/2)
18x^(1/4) ÷ 6x^(3/4)   = 3x^(−1/2)
(4x^(−2))^(3/2)        = 4^(3/2) x^(−3) = 8x^(−3)
(x³y^(−2))^(−2)        = x^(−6) y⁴ = y⁴/x⁶
(8x⁹)^(−1/3)           = 1/(2x³)
x^(1/2) × x^(1/3)      = x^(5/6)
```

Fraction arithmetic in indices: 2/3 − 1/6 = 4/6 − 1/6 = 1/2; 1/2 + 1/3 = 5/6.

## Solving index equations

1. Write both sides as powers of one base.
2. Use (a^m)^n = a^(mn) to simplify.
3. Set the indices equal and solve the linear equation.
4. Check by substitution.

| Equation | Common base | Index equation | Solution |
|---|---|---|---|
| 2^x = 1/32 | 2 | x = −5 | x = −5 |
| 27^x = 9^(x+2) | 3 | 3x = 2x + 4 | x = 4 |
| 4^(x+2) = 32 | 2 | 2x + 4 = 5 | x = 1/2 |
| 125^x = 25^(2x−1) | 5 | 3x = 4x − 2 | x = 2 |
| 8^(2x) = 1/4 | 2 | 6x = −2 | x = −1/3 |
| 1000^x = 1/100 | 10 | 3x = −2 | x = −2/3 |

Useful powers to know without a calculator:

| Base | Powers |
|---|---|
| 2 | 2, 4, 8, 16, 32, 64, 128, 256 |
| 3 | 3, 9, 27, 81, 243 |
| 5 | 5, 25, 125, 625 |
| 10 | 10, 100, 1000, 10000 |

Recognising 243 = 3⁵ or 256 = 2⁸ on sight saves time in Paper 1.

## Writing in the form kxⁿ

| Expression | Rewrite | k | n |
|---|---|---|---|
| 3/x² | 3x^(−2) | 3 | −2 |
| √x | x^(1/2) | 1 | 1/2 |
| 4/√x | 4x^(−1/2) | 4 | −1/2 |
| 1/(5x) | (1/5)x^(−1) | 1/5 | −1 |
| x²√x | x^(5/2) | 1 | 5/2 |
| 7∛x² | 7x^(2/3) | 7 | 2/3 |

Steps: turn roots into fractional indices, combine powers of x, and move x from the denominator by changing the sign of its index. A number in the denominator stays as a fraction.

## Unknown base

To solve x^(m/n) = c, raise both sides to the power n/m:

```
x^(3/2) = 8   →   x = 8^(2/3) = 4
x^(−1/2) = 1/3 →  x^(1/2) = 3, x = 9
```

## Exam traps

- 3^(−2) = 1/9, not −9 and not −6.
- (2x)³ = 8x³; 2x³ means only x is cubed.
- x² × x⁴ = x⁶ (add), but (x²)⁴ = x⁸ (multiply).
- x⁰ = 1, so 5x⁰ = 5.
- Subtracting a negative index: x³ ÷ x^(−2) = x⁵.
- Bases must match before indices are compared.
- Root before power keeps numbers manageable: 64^(5/6) = 2⁵ = 32.

## Self-test

1. Find the value of 49^(1/2).
2. Find the value of 8^(−1/3).
3. Find the value of 16^(3/4).
4. Find the value of (27/64)^(−2/3).
5. Simplify x^5 × x^(−7).
6. Simplify (3x⁴)².
7. Simplify 20x^(1/2) ÷ 4x^(−1/2).
8. Simplify (25x⁴)^(−1/2).
9. Solve 3^x = 81.
10. Solve 9^(x − 1) = 3^x.
11. Solve (1/8)^x = 16.
12. Solve 49^(x + 1) = 7^(4x).

**Answers**

1. **7**.
2. 1/∛8 = **1/2**.
3. (⁴√16)³ = 2³ = **8**.
4. (64/27)^(2/3) = (4/3)² = **16/9**.
5. x^(−2) = **1/x²**.
6. **9x⁸**.
7. 5x^(1/2 + 1/2) = **5x**.
8. 1/(25x⁴)^(1/2) = **1/(5x²)**.
9. 3⁴ = 81, so **x = 4**.
10. 3^(2x − 2) = 3^x, 2x − 2 = x, **x = 2**.
11. 2^(−3x) = 2⁴, −3x = 4, **x = −4/3**.
12. 7^(2x + 2) = 7^(4x), 2x + 2 = 4x, **x = 1**.
