Condensed notes for subtopic **2.2 Algebraic manipulation** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025–2027. Worked examples with full reasoning are in the [algebraic manipulation study guide](/resources/cambridge-o-level-mathematics-4024-algebraic-manipulation/); exam-style questions are in the [algebraic manipulation practice questions](/resources/cambridge-o-level-mathematics-4024-algebraic-manipulation-practice/). The earlier overview, [Algebraic Manipulation revision notes](/resources/algebraic-manipulation-revision-notes/), covers 2.1 to 2.3 together.

## Syllabus outcomes

1. Simplify by collecting like terms.
2. Expand products, including more than two brackets.
3. Factorise by extracting common factors (factorise means fully).
4. Factorise ax + bx + kay + kby, a²x² − b²y², a² + 2ab + b², ax² + bx + c, ax³ + bx² + cx.
5. Complete the square for ax² + bx + c.

## Key terms

| Term | Meaning |
|---|---|
| Like terms | Same letters to the same powers (xy and yx are like; x²y and xy² are not) |
| Simplify | Give the answer in its simplest form |
| Expand | Multiply out brackets |
| Factorise | Write as a product of factors, fully |
| Highest common factor (HCF) | Largest number and lowest powers of letters dividing every term |
| Identity | True for every value of the letter, e.g. (x + 1)² ≡ x² + 2x + 1 |
| Completed square form | a(x + p)² + q |

## Expansion patterns

```
(x + a)(x + b)   = x² + (a + b)x + ab
(px + q)(rx + s) = prx² + (ps + qr)x + qs
(a + b)²         = a² + 2ab + b²
(a − b)²         = a² − 2ab + b²
(a + b)(a − b)   = a² − b²
(x + 1)³         = x³ + 3x² + 3x + 1
```

Three brackets: multiply two, simplify, then multiply by the third.

```
(x − 3)(x + 2)(x + 1):  (x + 2)(x + 1) = x² + 3x + 2
                        (x − 3)(x² + 3x + 2) = x³ − 7x − 6
```

## Factorising decision list

1. **Common factor?** Take it out first: 12p²q + 18pq² = 6pq(2p + 3q).
2. **Two terms?** Difference of two squares: 16a² − 81b² = (4a − 9b)(4a + 9b).
3. **Three terms?** Perfect square or trinomial:
   - 25x² + 20x + 4 = (5x + 2)²
   - 3x² − 10x + 8: ac = 24, sum −10 → −6, −4 → (3x − 4)(x − 2)
4. **Four terms?** Grouping: 3xy + 12x − y − 4 = 3x(y + 4) − (y + 4) = (3x − 1)(y + 4).
5. **Check each bracket** to see if it factorises again.

Cubic form: x³ − 9x = x(x² − 9) = x(x − 3)(x + 3).

Negative leading term: 18 − 2x² = 2(9 − x²) = 2(3 − x)(3 + x).

## Completing the square

```
a = 1:    x² + bx + c = (x + b/2)² − (b/2)² + c
a ≠ 1:    ax² + bx + c = a[(x + b/2a)² − (b/2a)²] + c
```

| Expression | Completed square form |
|---|---|
| x² − 8x + 5 | (x − 4)² − 11 |
| x² + 3x + 5 | (x + 3/2)² + 11/4 |
| 2x² + 12x − 5 | 2(x + 3)² − 23 |
| 5x² + 10x − 3 | 5(x + 1)² − 8 |
| −2x² + 4x + 5 | −2(x − 1)² + 7 |

Reading the form a(x + p)² + q: if a > 0 the least value is q at x = −p; if a < 0 the greatest value is q at x = −p.

## Checking an answer

Substitute x = 1 (or another small value) into both forms. For (x − 3)(x + 2)(x + 1) at x = 1: (−2)(3)(2) = −12, and 1 − 7 − 6 = −12. ✓ A completed square form can be checked by expanding it back out.

## Exam traps

- −2(x − 4) = −2x + 8, not −2x − 8.
- (a − b)² ≠ a² − b². Write two brackets out.
- Factorise fully: 3x² − 27 → 3(x − 3)(x + 3), not 3(x² − 9).
- Grouping brackets must match exactly; take out a negative if needed.
- With a ≠ 1, multiply the subtracted square by a.
- Halving an odd b gives a fraction; keep it exact (3/2, not 1.5 rounded or 2).
- Check by expanding back or substituting x = 1.

## Self-test

1. Simplify 3xy² − 2x²y + 5y²x + x²y.
2. Expand and simplify 5(2x − 3) − 2(x − 4).
3. Expand and simplify (3x − 4)(2x + 1).
4. Expand and simplify (x + 4)(x − 1) − (x − 2)².
5. Factorise fully 15a³ − 10a².
6. Factorise ax − bx − ay + by.
7. Factorise 4x² − 28x + 49.
8. Factorise 6x² − x − 15.
9. Factorise fully 3x³ + 3x² − 36x.
10. Write x² − 6x + 1 in the form (x + p)² + q.
11. Write 2x² − 8x + 3 in the form a(x + p)² + q.
12. Expand and simplify (2a − b)² − (a + b)².

**Answers**

1. 8xy² − x²y.
2. 10x − 15 − 2x + 8 = **8x − 7**.
3. 6x² + 3x − 8x − 4 = **6x² − 5x − 4**.
4. (x² + 3x − 4) − (x² − 4x + 4) = **7x − 8**.
5. **5a²(3a − 2)**.
6. x(a − b) − y(a − b) = **(a − b)(x − y)**.
7. **(2x − 7)²**.
8. ac = −90, sum −1 → −10 and 9: 6x² − 10x + 9x − 15 = 2x(3x − 5) + 3(3x − 5) = **(2x + 3)(3x − 5)**.
9. 3x(x² + x − 12) = **3x(x + 4)(x − 3)**.
10. (x − 3)² − 9 + 1 = **(x − 3)² − 8**.
11. 2[(x − 2)² − 4] + 3 = **2(x − 2)² − 5**.
12. (4a² − 4ab + b²) − (a² + 2ab + b²) = **3a² − 6ab**.
