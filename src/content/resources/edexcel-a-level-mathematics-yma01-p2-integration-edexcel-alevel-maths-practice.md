These questions cover section 8 of Unit P2 (YMA01, Issue 3): definite integrals, areas under and between curves, and the trapezium rule. Revise first with the [P2 integration study guide](/resources/edexcel-a-level-mathematics-yma01-p2-integration-edexcel-alevel-maths/) and the [P2 integration revision notes](/resources/edexcel-a-level-mathematics-yma01-p2-integration-edexcel-alevel-maths-revision-notes/). ## Section A

**1.** Evaluate ∫₁³ (4x³ − 2x) dx. **[3]**

**2.** Evaluate ∫₁⁸ x^(1/3) dx. **[3]**

**3.** Evaluate ∫₁² (x² + 1)²/x² dx, giving your answer as a fraction. **[4]**

**4.** Given that ∫₁⁴ (ax + 3√x) dx = 29, where a is a constant, find the value of a. **[4]**

## Section B

**5.** Given that ∫₀ᵏ (3x² − 2) dx = 4, where k is a positive constant:

**(a)** show that k³ − 2k − 4 = 0 **[2]**

**(b)** show that k = 2 is the only real solution of this equation. **[3]**

**6.** Find the area of the finite region bounded by the curve y = 6x − x² − 5 and the x-axis. **[5]**

**7.** The curve C has equation y = x³ − 6x² + 8x.

**(a)** Show that C crosses the x-axis at x = 0, x = 2 and x = 4. **[2]**

**(b)** Find the value of ∫₀⁴ (x³ − 6x² + 8x) dx, and explain why it is not the total area between C and the x-axis for 0 ≤ x ≤ 4. **[2]**

**(c)** Find this total area. **[3]**

**8.** The curve y = 5 + 4x − x² and the line y = 5 − x meet at two points. Find the area of the finite region between them. **[6]**

**9.** Find the area of the finite region enclosed between the curves y = x² and y = 4x − x². **[6]**

**10.** The region R is bounded by the curve y = x², the line y = 12 − 4x and the x-axis.

**(a)** Find the coordinates of the point, with positive x-coordinate, where the curve meets the line. **[2]**

**(b)** Find the area of R. **[5]**

**11.** The table shows values of y = 2ˣ, to 4 decimal places where necessary.

| x | 0 | 0.5 | 1 | 1.5 | 2 |
|---|---|---|---|---|---|
| y | 1 | | 2 | | 4 |

**(a)** Complete the table. **[2]**

**(b)** Use the trapezium rule with all the values in the table to estimate ∫₀² 2ˣ dx, giving your answer to 3 significant figures. **[3]**

**(c)** State, with a reason, whether your estimate is an overestimate or an underestimate. **[1]**

**12.** f(x) = x + 4/x².

**(a)** Use the trapezium rule with 4 strips to estimate ∫₁³ f(x) dx. **[4]**

**(b)** Use integration to find the exact value of ∫₁³ f(x) dx. **[3]**

**(c)** Find the percentage error in your estimate from part (a). **[2]**

**(d)** State how the estimate could be made more accurate. **[1]**

## Answers

**1.** [x⁴ − x²]₁³ [1] = (81 − 9) − (1 − 1) [1] = **72** [1].

**2.** [(3/4)x^(4/3)]₁⁸ [1] = (3/4)(16) − (3/4)(1) [1] = 12 − 3/4 = **45/4** [1].

**3.** (x² + 1)²/x² = (x⁴ + 2x² + 1)/x² = x² + 2 + x⁻² [1]. Integrating: [x³/3 + 2x − x⁻¹]₁² [1] = (8/3 + 4 − ½) − (⅓ + 2 − 1) [1] = 37/6 − 4/3 = **29/6** [1].

**4.** ∫₁⁴ (ax + 3x^½) dx = [ax²/2 + 2x^(3/2)]₁⁴ [1] = (8a + 16) − (a/2 + 2) = 7.5a + 14 [1]. So 7.5a + 14 = 29 [1], giving **a = 2** [1].

**5. (a)** [x³ − 2x]₀ᵏ = k³ − 2k [1], so k³ − 2k = 4 and k³ − 2k − 4 = 0 [1].

**(b)** k = 2: 8 − 4 − 4 = 0, so (k − 2) is a factor [1]. k³ − 2k − 4 = (k − 2)(k² + 2k + 2) [1]. The quadratic has discriminant 4 − 8 = −4 < 0, so it has no real roots and k = 2 is the only real solution [1].

Total: 5

**6.** 6x − x² − 5 = 0 gives x² − 6x + 5 = 0, so x = 1 or x = 5 [1]. The curve is above the axis between them. Area = ∫₁⁵ (6x − x² − 5) dx [1] = [3x² − x³/3 − 5x]₁⁵ [1] = (75 − 125/3 − 25) − (3 − ⅓ − 5) = 25/3 − (−7/3) [1] = **32/3** [1].

**7. (a)** x³ − 6x² + 8x = x(x² − 6x + 8) [1] = x(x − 2)(x − 4), which is zero at x = 0, 2 and 4 [1].

**(b)** [x⁴/4 − 2x³ + 4x²]₀⁴ = 64 − 128 + 64 = **0** [1]. The curve is above the axis for 0 < x < 2 and below it for 2 < x < 4, so the positive and negative parts cancel [1].

**(c)** ∫₀² y dx = 4 − 16 + 16 = 4 [1]. ∫₂⁴ y dx = 0 − 4 = −4 [1]. Total area = 4 + 4 = **8** [1].

Total: 7

**8.** 5 + 4x − x² = 5 − x gives x² − 5x = 0, so x = 0 or x = 5 [1]. Between these values the curve is above the line (at x = 1: curve 8, line 4) [1]. Area = ∫₀⁵ [(5 + 4x − x²) − (5 − x)] dx = ∫₀⁵ (5x − x²) dx [1] = [5x²/2 − x³/3]₀⁵ [1] = 125/2 − 125/3 [1] = **125/6** [1].

**9.** x² = 4x − x² gives 2x² − 4x = 0, so x = 0 or x = 2 [1]. For 0 < x < 2, 4x − x² is the upper curve [1]. Area = ∫₀² (4x − x² − x²) dx = ∫₀² (4x − 2x²) dx [1] = [2x² − 2x³/3]₀² [1] = 8 − 16/3 [1] = **8/3** [1].

**10. (a)** x² = 12 − 4x, so x² + 4x − 12 = 0 and (x + 6)(x − 2) = 0 [1]. With x > 0: **(2, 4)** [1].

**(b)** The line meets the x-axis at x = 3 [1]. Under the curve from 0 to 2: ∫₀² x² dx = [x³/3]₀² = 8/3 [1] [1]. Under the line from 2 to 3: a triangle of base 1 and height 4, area 2 [1]. Area of R = 8/3 + 2 = **14/3** [1].

Total: 7

**11. (a)** 2^0.5 = **1.4142** [1]; 2^1.5 = **2.8284** [1].

**(b)** h = 0.5 [1]. Estimate = 0.25[1 + 4 + 2(1.4142 + 2 + 2.8284)] [1] = 0.25[5 + 12.4853] = **4.37** [1].

**(c)** Overestimate: the curve y = 2ˣ bends upwards, so the top of each trapezium lies above the curve [1].

Total: 6

**12. (a)** h = 0.5; f(1) = 5, f(1.5) = 3.2778, f(2) = 3, f(2.5) = 3.14, f(3) = 3.4444 [1] [1] (one mark for at least three correct values, one for all five). Estimate = 0.25[5 + 3.4444 + 2(3.2778 + 3 + 3.14)] [1] = 0.25 × 27.28 = **6.82** [1].

**(b)** ∫₁³ (x + 4x⁻²) dx = [x²/2 − 4/x]₁³ [1] = (9/2 − 4/3) − (½ − 4) [1] = 19/6 + 7/2 = **20/3** [1].

**(c)** Error = 6.82 − 6.6667 = 0.1533 [1]; percentage error = 0.1533 ÷ 6.6667 × 100 = **2.3%** [1].

**(d)** Use more strips (a smaller value of h) [1].

Total: 10

## Where marks are usually lost

- In Question 3, integrating the numerator and denominator separately instead of dividing first.
- In Question 7, reporting the integral 0 as the area.
- In Questions 8 and 9, subtracting the upper curve from the lower one, then ignoring the negative sign.
- In Question 10, integrating x² all the way from 0 to 3 instead of splitting where the boundary changes.
- In Questions 11 and 12, counting 5 ordinates as 5 strips, which gives the wrong h.
