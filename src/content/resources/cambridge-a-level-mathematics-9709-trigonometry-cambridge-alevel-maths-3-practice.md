These questions cover section **3.3 Trigonometry** of Pure Mathematics 3 (Paper 3) in the Cambridge International AS & A Level Mathematics 9709 syllabus for 2026 and 2027. Give angles in degrees to 1 decimal place and angles in radians to 3 significant figures unless a question says otherwise. The number in square brackets after the last part of each question is the total for the whole question.

Related: the [3.3 study guide](/resources/cambridge-a-level-mathematics-9709-trigonometry-cambridge-alevel-maths-3/) and the [3.3 revision notes](/resources/cambridge-a-level-mathematics-9709-trigonometry-cambridge-alevel-maths-3-revision-notes/).

## Questions

### Section A: short questions

**1.** Find the exact value of cos 105°, giving your answer in terms of surds. **[3]**

**2.** The angles A and B are acute, with sin A = 3/5 and cos B = 5/13. Without using a calculator, find the exact values of

**(a)** sin(A + B)

**(b)** tan(A − B). **[5]**

**3.** It is given that tan(x + y) = 3 and tan x = ½. Find the exact value of tan y. **[3]**

**4.** Prove the identity cosec 2θ + cot 2θ ≡ cot θ. **[3]**

**5.** Solve the equation cot θ = 2 cos θ for 0° < θ < 360°. **[4]**

**6.** Solve the equation cos 2x + 5 cos x + 3 = 0 for 0 ≤ x ≤ 2π, giving your answers in terms of π. **[4]**

**7.** Prove the identity tan(θ + 45°) − tan(45° − θ) ≡ 2 tan 2θ. **[4]**

### Section B: longer questions

**8.** **(a)** Express √3 sin θ + cos θ in the form R sin(θ + α), where R > 0 and 0° < α < 90°.

**(b)** Hence solve the equation √3 sin θ + cos θ = 1.2 for 0° < θ < 360°.

**(c)** State the greatest and least values of 4 − (√3 sin θ + cos θ)². **[7]**

**9.** **(a)** Show that the equation 3 cot²θ + 5 cosec θ + 1 = 0 can be written as 3 cosec²θ + 5 cosec θ − 2 = 0.

**(b)** Hence solve the equation 3 cot²θ + 5 cosec θ + 1 = 0 for 0° < θ < 360°. **[6]**

**10.** **(a)** By writing 3θ as 2θ + θ, prove that sin 3θ ≡ 3 sin θ − 4 sin³θ.

**(b)** Hence solve the equation sin 3θ = 2 sin θ for 0° < θ < 180°. **[7]**

**11.** **(a)** Express 7 cos θ − 24 sin θ in the form R cos(θ + α), where R > 0 and 0° < α < 90°, giving α correct to 2 decimal places.

**(b)** Hence find the least value of 30 + 7 cos θ − 24 sin θ and the smallest positive value of θ at which it occurs.

**(c)** Solve the equation 7 cos 2x − 24 sin 2x = 15 for 0° < x < 180°. **[8]**

**12.** **(a)** Show that cos 4θ ≡ 8 cos⁴θ − 8 cos²θ + 1.

**(b)** By substituting θ = π/8 into this identity, find the exact value of cos²(π/8), explaining your choice of root.

**(c)** Hence find the exact value of cos⁴(π/8). **[7]**

**13.** **(a)** Sketch the graph of y = cosec x for 0 < x < 2π, showing the asymptotes and the coordinates of the turning points.

**(b)** State the number of solutions in this interval of the equation cosec x = k when k = 0.5 and when k = 3.

**(c)** Solve the equation cosec x = 3 for 0 < x < 2π. **[7]**

## Answers

**1.** cos(60° + 45°) = cos 60° cos 45° − sin 60° sin 45° [1] = (½)(√2/2) − (√3/2)(√2/2) [1] = **(√2 − √6)/4** [1]

**2.** **(a)** cos A = 4/5 and sin B = 12/13 [1]. sin(A + B) = (3/5)(5/13) + (4/5)(12/13) [1] = **63/65** [1]

**(b)** tan A = 3/4 and tan B = 12/5, so tan(A − B) = (3/4 − 12/5)/(1 + (3/4)(12/5)) [1] = (−33/20)/(56/20) = **−33/56** [1]

*Examiner insight:* the acute angles fix the signs of cos A and sin B as positive; say so.

**3.** (½ + tan y)/(1 − ½ tan y) = 3 [1]. ½ + tan y = 3 − (3/2) tan y [1]. (5/2) tan y = 5/2, so **tan y = 1** [1]

**4.** cosec 2θ + cot 2θ = (1 + cos 2θ)/sin 2θ [1] = 2 cos²θ/(2 sin θ cos θ) [1] = cos θ/sin θ = cot θ [1]

**5.** cos θ/sin θ = 2 cos θ, so cos θ(1 − 2 sin θ) = 0 [1]. cos θ = 0: θ = 90°, 270° [1]. sin θ = ½: θ = 30°, 150° [1]. All four values, with none extra [1]

*Examiner insight:* dividing by cos θ loses 90° and 270°, which are valid because cot θ = 0 there.

**6.** 2 cos²x − 1 + 5 cos x + 3 = 0, so 2 cos²x + 5 cos x + 2 = 0 [1]. (2 cos x + 1)(cos x + 2) = 0 [1]. cos x = −2 is impossible [1]. cos x = −½: **x = 2π/3, 4π/3** [1]

**7.** With t = tan θ: tan(θ + 45°) = (t + 1)/(1 − t) [1] and tan(45° − θ) = (1 − t)/(1 + t) [1]. Difference = [(1 + t)² − (1 − t)²]/(1 − t²) = 4t/(1 − t²) [1] = 2 × 2t/(1 − t²) = 2 tan 2θ [1]

**8.** **(a)** R = √(3 + 1) = **2** [1]. R cos α = √3 and R sin α = 1, so tan α = 1/√3 and **α = 30°** [1]

**(b)** sin(θ + 30°) = 0.6 [1]. θ + 30° = 36.87° or 143.13° (390° is the upper limit for θ + 30°) [1]. **θ = 6.9° or 113.1°** [1]

**(c)** (√3 sin θ + cos θ)² = 4 sin²(θ + 30°), which lies between 0 and 4. Greatest value **4** [1], least value **0** [1]

**9.** **(a)** 3(cosec²θ − 1) + 5 cosec θ + 1 = 0 [1], so 3 cosec²θ + 5 cosec θ − 2 = 0 [1]

**(b)** (3 cosec θ − 1)(cosec θ + 2) = 0 [1]. cosec θ = 1/3 is impossible because |cosec θ| ≥ 1 [1]. cosec θ = −2, so sin θ = −½ [1]. **θ = 210° or 330°** [1]

**10.** **(a)** sin 3θ = sin 2θ cos θ + cos 2θ sin θ [1] = 2 sin θ cos²θ + (1 − 2 sin²θ) sin θ [1] = 2 sin θ(1 − sin²θ) + sin θ − 2 sin³θ [1] = 3 sin θ − 4 sin³θ [1]

**(b)** 3 sin θ − 4 sin³θ = 2 sin θ, so sin θ(1 − 4 sin²θ) = 0 [1]. sin θ = 0 has no solution in 0° < θ < 180°, and sin θ = −½ has none either [1]. sin θ = ½: **θ = 30° or 150°** [1]

**11.** **(a)** R cos α = 7, R sin α = 24: **R = 25** [1], tan α = 24/7, **α = 73.74°** [1]

**(b)** 30 + 25 cos(θ + 73.74°) is least when cos(θ + 73.74°) = −1: least value **5** [1], when θ + 73.74° = 180°, so **θ = 106.3°** [1]

**(c)** 25 cos(2x + 73.74°) = 15, so cos(2x + 73.74°) = 0.6 [1]. 2x + 73.74° lies between 73.74° and 433.74°, so 2x + 73.74° = 306.87° or 413.13° [1]. **x = 116.6°** [1] or **x = 169.7°** [1]

*Examiner insight:* 53.13° is below the shifted lower limit and must not be used; 413.13° is easy to miss.

**12.** **(a)** cos 4θ = 2 cos²2θ − 1 [1] = 2(2 cos²θ − 1)² − 1 [1] = 2(4 cos⁴θ − 4 cos²θ + 1) − 1 = 8 cos⁴θ − 8 cos²θ + 1 [1]

**(b)** cos(π/2) = 0, so with u = cos²(π/8): 8u² − 8u + 1 = 0 [1]. u = (8 ± √32)/16 = (2 ± √2)/4 [1]. cos(π/8) > cos(π/4), so cos²(π/8) > ½ and the root is **(2 + √2)/4** [1]

**(c)** cos⁴(π/8) = ((2 + √2)/4)² = (6 + 4√2)/16 = **(3 + 2√2)/8** [1]

**13.** **(a)** Two U-shaped branches: one above the axis between x = 0 and x = π, one below between x = π and x = 2π [1]. Asymptotes x = 0, x = π and x = 2π [1]. Turning points **(π/2, 1)** and **(3π/2, −1)** [1]

**(b)** k = 0.5: **no solutions** [1]. k = 3: **two solutions** [1]

**(c)** sin x = 1/3 [1]. **x = 0.340 or x = 2.80** [1]

## Where marks are usually lost

- Dividing by a trigonometric factor and losing a family of solutions.
- Not rejecting impossible values such as cos x = −2 or cosec θ = 1/3, or not saying why.
- Forgetting to shift the interval when solving R cos(2x + α) = c.
- Mixing degrees and radians.
- Proofs that work on both sides or start from the result.
- Choosing the wrong root in an exact-value question without justifying it.
