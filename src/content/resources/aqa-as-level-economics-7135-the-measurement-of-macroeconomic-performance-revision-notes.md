These notes condense **3.2.1 The measurement of macroeconomic performance** of AQA AS Economics (7135), specification version 1.3, parts 3.2.1.1 to 3.2.1.3. At AS this sub-topic stops at index numbers; uses of national income data is A-level only. The [3.2.1 study guide](/resources/aqa-as-level-economics-7135-the-measurement-of-macroeconomic-performance/) has four worked index number examples, and the [3.2.1 practice questions](/resources/aqa-as-level-economics-7135-the-measurement-of-macroeconomic-performance-practice/) test them. All figures are invented.

## Key terms

| Term | Meaning |
|---|---|
| Economic growth | An increase in real GDP over time |
| Price stability | A low and stable rate of inflation |
| Current account | Trade in goods, trade in services, primary income and secondary income |
| Real GDP | GDP adjusted for changes in the price level |
| Nominal GDP | GDP measured at current prices |
| Real GDP per capita | Real GDP divided by population |
| CPI | Consumer Prices Index; the measure used for the government's inflation target |
| RPI | Retail Prices Index; includes some housing costs, such as mortgage interest payments, that CPI excludes |
| Productivity | Output per worker or per hour worked |
| Index number | A value expressed relative to a base year value of 100 |
| Base year | The reference year of an index, set at 100 |
| Weights | Shares of spending used so that bigger items count more in an average |
| Percentage point | The absolute difference between two percentages |

## 3.2.1.1 Objectives

- Main four: economic growth, price stability, minimising unemployment, stable balance of payments on current account.
- Others: balancing the budget, a more equitable distribution of income.
- Short-run conflicts: higher AD helps growth and employment but adds to inflation and imports. Supply-side improvements can ease these conflicts in the long run.
- Priorities change over time with economic conditions and political choices.

## 3.2.1.2 Indicators to objectives

| Objective | Indicator |
|---|---|
| Growth and living standards | Real GDP, real GDP per capita, productivity |
| Price stability | CPI, RPI |
| Low unemployment | Unemployment measures |
| Balance of payments | Current account balance |

## 3.2.1.3 Index number toolkit

```
Index             = value / base value x 100
% change          = (new index - old index) / old index x 100
Rebase to year X  = old index / index in year X x 100
Real value        = nominal value / (price index / 100)
Weighted index    = sum of (weight x index) / sum of weights
Real per capita growth is roughly real growth - population growth
```

**Worked checks.**

- House price index rises from 140 to 147: (7 / 140) x 100 = 5% rise.
- Wages index 125, price index 110 (same base): real wage index = 125 / 1.10 = 113.6, so real wages are 13.6% above the base year.
- Weights 40, 35, 25 with indices 105, 110, 98: (4,200 + 3,850 + 2,450) / 100 = 105.0.
- Inflation falls from 5% to 2%: down 3 percentage points; prices still rose 2%.

**CPI and RPI features (no technical detail needed):** a basket of goods and services; spending patterns of an average family or household; weights updated as spending changes; individual households' inflation can differ.

## Reading indicator data

- **Growth rate falling but positive**: output is still rising, only more slowly. A recession needs falling real GDP.
- **Unemployment level versus rate**: if the labour force grows, the number unemployed can rise while the rate stays the same.
- **Productivity versus output**: output can rise because more people work longer hours, with no gain in output per hour.
- **Current account in money or as % of GDP**: a deficit that stays the same in money terms shrinks as a share of a growing economy.
- **Index levels versus rates**: an index of 130 says prices are 30% above the base year, not that inflation is 30% this year.

## Exam traps

- "Inflation fell, so prices fell." Wrong unless inflation is negative.
- Treating a change in index points as a percentage change when the start is not 100.
- Ignoring weights given in a table.
- Comparing nominal figures over time as if they were real.
- Using GDP when the question is about living standards per person.
- Answering "explain a conflict" with two separate descriptions and no chain between them.
- Including uses of national income data and PPP comparisons, which are not AS content.

## Self-test

1. State the four main macroeconomic objectives.
2. Explain one short-run conflict between two objectives.
3. Which indicator would you use to judge price stability?
4. An index rises from 100 to 112. What is the percentage change?
5. An index rises from 120 to 126. What is the percentage change?
6. Rebase an index value of 132 so that a year with index 110 becomes 100.
7. Nominal wages rose 6% and prices rose 4%. Roughly how much did real wages change?
8. Weights 50, 30, 20; indices 102, 110, 90. Calculate the weighted index.
9. Inflation falls from 3.5% to 2.0%. Describe the change precisely.
10. Real GDP grows 2.5% and population 0.8%. Approximately what happens to real GDP per capita?
11. Why might a pensioner's inflation rate differ from the CPI?
12. Name one objective other than the main four.

### Answers

1. Economic growth, price stability, minimising unemployment, a stable balance of payments on current account.
2. Lower interest rates raise AD, so output and employment rise, but inflationary pressure and spending on imports also rise.
3. CPI (or RPI).
4. 12%.
5. 6 / 120 = 5%.
6. 132 / 110 x 100 = 120.
7. About 2% (1.06 / 1.04 = 1.019, so 1.9%).
8. (5,100 + 3,300 + 1,800) / 100 = 102.0.
9. A fall of 1.5 percentage points; prices are still rising, but more slowly.
10. It rises by about 1.7%.
11. Their spending pattern differs from the average household's basket, for example a larger share on heating and food.
12. Balancing the budget, or a more equitable distribution of income.
