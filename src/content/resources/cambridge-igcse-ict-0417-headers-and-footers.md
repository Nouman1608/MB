Section 13.3 of Cambridge IGCSE ICT 0417 asks you to "use headers and footers appropriately within a range of software packages". The skills listed are: "create or edit headers and footers"; "align the contents of the header and footer consistently within a document including to left margin, right margin and centred within margins"; and "place text and automated objects in headers and footers including file information, page numbering, total number of pages, date, time". You must also know "the purpose of headers and footers". The [Layout study guide](/resources/cambridge-igcse-ict-layout-study-guide/) introduces headers and footers in a word processor. This guide covers their purpose in more depth, exact alignment to the margins, each automated object, and how headers and footers work in other packages.

For quick recall use the [headers and footers revision notes](/resources/cambridge-igcse-ict-0417-headers-and-footers-revision-notes/), and test yourself with the [headers and footers practice questions](/resources/cambridge-igcse-ict-0417-headers-and-footers-practice/).

## The purpose of headers and footers

A **header** is an area in the top margin and a **footer** is an area in the bottom margin. Whatever is placed in them appears in the same position on **every page** (or every page of a section) without being typed again. Their purposes include:

- **Identifying the document**: a title, company name or logo on each page shows what the document is and who produced it, even if one page is separated from the rest.
- **Navigation and order**: page numbers, especially in the form "Page 3 of 12", let readers find pages, refer to them, and put printed pages back in order. The total tells them whether any pages are missing.
- **Version control**: the file name, the date or the time show which version of a document was printed.
- **Locating the file**: the file name and path show where the electronic copy is stored.
- **Consistency and house style**: the same information in the same place on every page looks professional.
- **Keeping the body clear**: repeated details are held in the margins, leaving the main area for content.

## Creating and editing

Open the header or footer area, usually by double-clicking in the top or bottom margin or by choosing the header or footer option. Type or insert the contents, then close the header and footer view to return to the body. To edit, open the area again; a change made on one page appears on all pages in that section.

Some documents need different headers in different parts. A **different first page** option lets a title page have no header, and **section breaks** allow different headers in different sections. Check every page after editing, because a change may apply only to the current section.

## Aligning contents consistently to the margins

The syllabus names three positions: **left margin**, **right margin** and **centred within margins**.

Word processors usually provide a centre tab stop and a right tab stop in the header and footer. Pressing Tab once moves to the centre position and twice moves to the right position. These default positions are set for the page's default margins. **If the margins have been changed, the default tab stops may no longer be at the centre or right margin.** For example, if the left and right margins are increased, the default right tab may now be beyond the right margin, so the right-hand item sticks out past the body text. The fix is to move the tab stops (or use the software's alignment tabs, which are measured from the margin) so that:

- the left item starts exactly at the **left margin**;
- the centre item is **centred between the margins**, not centred on the page edge;
- the right item ends exactly at the **right margin**.

"Consistently within a document" means the alignment is the same on every page and in every section, and that header and footer items line up with each other and with the body text.

### Worked example: checking the right tab position

A page is 21 cm wide with left and right margins of 3 cm. The text width is 21 - 3 - 3 = **15 cm**. The centre tab stop should be at 15 / 2 = **7.5 cm** from the left margin, and the right tab stop at **15 cm** from the left margin. If the header still uses tab stops placed for a 16 cm text width, at 8 cm and 16 cm, the centre item will be 0.5 cm right of centre and the right item will extend 1 cm beyond the right margin. Move the tab stops to 7.5 cm and 15 cm.

## Text and automated objects

**Text** typed into a header or footer, such as a name or a title, stays the same on every page. **Automated objects** (fields) are inserted using the software's insert options and update by themselves.

| Automated object | What it shows | Updates when |
|---|---|---|
| File information: file name | The name of the file | The file is saved with a new name |
| File information: file path | The folders and drive where the file is stored, often with the name | The file is saved in a new location |
| Page number | The number of the current page | Every page shows its own number |
| Total number of pages | How many pages the document has | Pages are added or removed |
| Date | The current date | The document is opened or printed |
| Time | The current time | The document is opened or printed |

Typing "Page 1" by hand puts "Page 1" on every page. Typing today's date by hand leaves it unchanged next week. In practical tasks, the automated object is what is being tested.

"Page 3 of 12" is built from the word *Page*, a page number field, the word *of* and a total pages field.

## Headers and footers in a range of software packages

| Package | Where headers and footers are found | Notes |
|---|---|---|
| Word processor | Top and bottom margins of every page | Tab stops for left, centre and right items |
| Spreadsheet | Page setup or page layout view | Usually three sections: left, centre and right; shown on printouts, not in normal view |
| Presentation | Header and footer settings for slides | Slide number, date and footer text; can be hidden on the title slide |
| Database report | Report header and footer, page header and footer | The report header appears once at the start; the page header and footer appear on every page |

In a spreadsheet, a header or footer appears only when the sheet is printed or viewed in page layout or print preview, so always check it there.

## Common mistakes

- Typing page numbers, totals or dates by hand.
- Leaving the default tab stops after changing the margins, so the right-hand item is outside the margin.
- Centring an item on the page edge rather than between the margins.
- Placing header content in the first line of the body text, so it appears only once.
- Putting the file name in when the task asked for the file name **and path**.
- Forgetting to check the second section or the first page when different settings are used.
- Using a different font size in the header on some pages.

## Exam technique

For **state the purpose**, give one clear use, such as "to show the page number so readers can find their place". For **explain**, link the content to the reader's need: "the total number of pages is included so the reader can check that no pages are missing". In practical tasks, place each item in the exact position named, then check in print preview that each one lines up with the margins on every page.

## Check your understanding

1. Give two purposes of a footer containing "Page 4 of 9". *To show the reader's place, to put printed pages in order and to show if any are missing.*
2. Why might a right-aligned header item extend past the margin? *The default tab stop is set for a different margin width.*
3. What is the difference between the file name and the file path? *The path also shows the folders and drive where the file is stored.*
4. In a database report, which part appears on every page? *The page header and page footer.*
