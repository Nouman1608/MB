Condensed notes for section 1.3, Use of technology in accounting, Topic 1 of the Pearson Edexcel International GCSE in Accounting (4AC1), Issue 1, October 2016.

## The specification points

- **1.3 a** Explain the benefits of using technology within accounting: accounting software; spreadsheets.
- **1.3 b** Explain the issues regarding the security of data: data loss; access; confidentiality.
- **1.3 c** Explain the methods of protecting data: hardware; software.

## Accounting software

| Benefit | So... |
|---|---|
| Transaction entered once, posted everywhere | Less copying, fewer posting errors |
| Double entry completed automatically | Debits always equal credits |
| Balances updated immediately | Credit control uses current figures |
| Trial balance, aged receivables and statements on demand | Faster decisions; no waiting for month end |
| Invoices and statements printed from the records | Documents match the ledgers |
| Audit trail of user and date | Errors and fraud can be traced |
| Less paper storage; quick search | Records found in seconds |

**Limits:** cost of buying and training; wrong input still gives wrong output; errors of principle, commission, omission and original entry are not detected because the totals still agree; a system failure can stop work.

## Spreadsheets

| Benefit | So... |
|---|---|
| Formulas recalculate automatically | Totals always arithmetically correct once formulas are right |
| What-if analysis | Plans tested before decisions (price changes, cost rises) |
| Templates reused | Time saved; reports consistent each month |
| Charts from data | Trends easy to see |
| User-designed | Fits the business's own needs |

**Common formulas:** =SUM(B2:B10) totals a range; =B2/B10*100 gives a percentage; =B2*(1+B12) applies a rate held in B12.

**Limits:** no double-entry checks; a mistyped formula or a number typed over a formula gives wrong results that look correct; needs checking of key totals.

## Software versus spreadsheet

| | Accounting software | Spreadsheet |
|---|---|---|
| Best for | Recording transactions in ledgers | Analysis, budgets, schedules, what-if |
| Double-entry checks | Built in | None |
| Flexibility | Fixed layouts | Fully user-designed |
| Main risk | Wrong account chosen | Formula errors |

## Security issues

| Issue | Meaning | Typical causes | Consequence |
|---|---|---|---|
| Data loss | Records destroyed, damaged or unreadable | Drive failure, virus, power cut, fire, flood, theft, accidental deletion | Transactions must be re-entered; amounts owed unknown |
| Access | Who can open, change or delete records | Shared or weak passwords; accounts not closed when staff leave; unlocked rooms | Unauthorised changes; fraud hard to trace |
| Confidentiality | Information kept private and used only for its purpose | Hacking; emails to wrong recipients; visible screens; printouts left out | Loss of customer trust; competitors learn prices or profit |

## Protection methods

| Hardware | Protects against |
|---|---|
| Backup copies on external drives or servers, kept off the premises | Data loss |
| Uninterruptible power supply | Data loss in power cuts |
| Locked rooms and cabinets, keycards, fingerprint scanners | Access; confidentiality |
| Screens positioned away from visitors; privacy filters | Confidentiality |

| Software | Protects against |
|---|---|
| Automatic scheduled backups, including online copies | Data loss |
| Individual passwords and access levels | Access; confidentiality |
| Closing user accounts when staff leave | Access |
| Encryption of files and emails | Confidentiality |
| Antivirus and firewall programs, updated regularly | Data loss; access |
| Automatic screen locking | Confidentiality |

**Layering:** no method covers every risk; combine hardware and software.

## Key terms

| Term | Meaning |
|---|---|
| Accounting software | A program that records transactions and produces ledgers and reports |
| Spreadsheet | A grid of cells holding data and formulas that recalculate |
| What-if analysis | Changing an input to see the effect on results |
| Audit trail | A record of who entered or changed each item, and when |
| Backup | A copy of data kept to restore records if the original is lost |
| Encryption | Coding data so only authorised users can read it |
| Firewall | Software that blocks unauthorised network access |
| Access level | The set of records a user is allowed to see or change |

## Exam traps

- One-word benefits with no consequence.
- Saying software makes records "always correct".
- Saying a backup prevents unauthorised access.
- Confusing access with confidentiality.
- Classifying a password as hardware or a locked door as software.
- Giving a protection method not linked to the issue in the case.

## Self-test

**1.** Give one benefit of accounting software and its consequence.
**2.** Why can a trial balance from accounting software agree even when records are wrong?
**3.** What is meant by "what-if" analysis?
**4.** Write a formula to total cells C2 to C9.
**5.** Give one limitation of spreadsheets.
**6.** Give two causes of data loss.
**7.** What is the difference between access and confidentiality?
**8.** Name one hardware method of protecting data and the issue it addresses.
**9.** Name one software method of protecting data and the issue it addresses.
**10.** Why should backups be kept off the premises?
**11.** Why should a leaving employee's user account be closed?
**12.** What is an audit trail, and why is it useful?

### Answers

**1.** For example, balances update immediately, so credit decisions use current figures.
**2.** The program always posts equal debits and credits, so errors such as posting to the wrong type of account (error of principle) are not revealed.
**3.** Changing an input, such as a price, to see the effect on results before deciding.
**4.** =SUM(C2:C9).
**5.** No double-entry checks, so a formula error can give a wrong but neat result.
**6.** Any two: drive failure, virus, power cut, fire or flood, theft, accidental deletion.
**7.** Access is about who can open or change records; confidentiality is about keeping information private and used only for its purpose.
**8.** For example, an off-site external drive backup protects against data loss.
**9.** For example, individual passwords with access levels protect against unauthorised access.
**10.** So a fire, flood or theft at the business does not destroy the copy as well.
**11.** So the former employee cannot view or change the records.
**12.** A record of who entered or changed each item and when; it lets errors and fraud be traced.
