## Key terms

| Term | Meaning |
|---|---|
| Surd | An irrational root, such as √7 or ∛5; √25 = 5 is not a surd |
| Like surds | Multiples of the same surd, such as 4√3 and −√3, which can be collected |
| Simplest form | k√n with n having no square factor other than 1 |
| Conjugate | The same two terms with the opposite sign between them: a + √b and a − √b |
| Rationalise | Rewrite so the denominator contains no surd |
| Exact form | An answer left with surds (and fractions), not rounded |
| Rational part / surd part | In a + b√c, a is the rational part and b√c the surd part |

## Rules you must use without thinking

```
√a × √b = √(ab)           √a ÷ √b = √(a/b)
(√a)² = a                 k√n = √(k²n)
(k√n)² = k²n              (a + √b)(a − √b) = a² − b
(√a + √b)(√a − √b) = a − b
(a + √b)² = a² + 2a√b + b
```

There is no rule for √(a + b) or √a + √b.

## Method: rationalising any denominator

| Denominator | Multiply top and bottom by | New denominator |
|---|---|---|
| k√a | √a | ka |
| a + b√c | a − b√c | a² − b²c |
| √a − √b | √a + √b | a − b |
| p√a + q√b | p√a − q√b | p²a − q²b |

1. Simplify any surd first (√18 = 3√2) so the numbers stay small.
2. Write the conjugate down before multiplying.
3. Expand the numerator in full; use the difference of two squares underneath.
4. Divide **every** term by the denominator, watching for a negative one.

*Reminder.* 5/(2√3 − √2) = 5(2√3 + √2)/(12 − 2) = (2√3 + √2)/2.

## Method: solving an equation with surd coefficients

1. Collect the x terms on one side and everything else on the other.
2. Factorise out x.
3. Divide, then rationalise.
4. Check by substituting back.

*Reminder.* x√2 − 3 = x + √2 gives x(√2 − 1) = 3 + √2, so x = (3 + √2)(√2 + 1)/(2 − 1) = 5 + 4√2.

## Method: equating parts

If a + b√c = p + q√c with a, b, p, q rational and √c irrational, then a = p and b = q.

To find √(m + n√c), set it equal to x + y√c, square, and solve x² + cy² = m and 2xy = n. Choose the signs that make the result positive.

*Reminder.* (3 + √2)² = 11 + 6√2, so √(11 + 6√2) = 3 + √2.

## Comparing

Move coefficients inside: 5√2 = √50 and 4√3 = √48, so 5√2 is larger. For sums, square both (if both are positive): (√3 + √5)² = 8 + 2√15 and (√2 + √6)² = 8 + 2√12, so √3 + √5 is larger.

## Exam traps

- Collecting unlike surds: 3√2 + 2√3 stays as it is.
- (2√5)² written as 10 instead of 20.
- Dropping the middle term of (a + √b)².
- Multiplying the denominator by the conjugate but not the numerator.
- Leaving a negative denominator, or flipping the sign of only one numerator term.
- Cancelling 4 into the first term of (4 ± 2√6)/4 only.
- Rounding when the question asks for an exact value or a given surd form.
- Not stating the integers a and b when the question names them.

## Quick self-test

1. Write √300 − 2√27 in the form k√3.
2. Expand and simplify (3√2 − 1)².
3. Rationalise 6/(√5 + √2).
4. Write (1 + 2√5)/(3 − √5) in the form p + q√5.
5. Solve x√5 = 2x + 3, giving x in the form a + b√5.
6. Which is larger, 2√7 or 3√3?
7. Find integers a and b with (a + b√2)² = 19 + 6√2, where a, b > 0.
8. Solve x² − 8x + 13 = 0, giving exact answers.
9. A square has diagonal 6 cm. Find its exact side length and area.
10. Write (√3)⁵ in the form k√3.
11. Solve 3ˣ = 9√3.
12. Show that 1/(√3 − √2) − 1/(√3 + √2) = 2√2.

### Answers

1. 10√3 − 6√3 = **4√3**.
2. 18 − 6√2 + 1 = **19 − 6√2**.
3. 6(√5 − √2)/(5 − 2) = **2(√5 − √2)**, that is 2√5 − 2√2.
4. Multiply by (3 + √5): numerator 3 + √5 + 6√5 + 10 = 13 + 7√5; denominator 4. **13/4 + (7/4)√5**.
5. x(√5 − 2) = 3, so x = 3(√5 + 2)/(5 − 4) = **6 + 3√5**.
6. √28 and √27, so **2√7 is larger**.
7. a² + 2b² = 19 and ab = 3, so **a = 1, b = 3**: 1 + 18 = 19. (a = 3, b = 1 gives 11, so it fails.)
8. x = (8 ± √12)/2 = **4 ± √3**.
9. Side = 6/√2 = **3√2 cm**; area = **18 cm²**.
10. 3^(5/2) = 9√3, so **k = 9**.
11. 9√3 = 3^(5/2), so **x = 5/2**.
12. The two fractions are √3 + √2 and √3 − √2 (each denominator multiplies out to 1). Subtracting gives **2√2**.
