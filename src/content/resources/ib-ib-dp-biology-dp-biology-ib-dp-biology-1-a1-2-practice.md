## Questions

**1.** State the carbon atom of the pentose to which each of these is attached in a nucleotide.

**(a)** the nitrogenous base **[1]**

**(b)** the phosphate group of the same nucleotide **[1]**

**2.** Explain how the structure of DNA allows its two strands to separate while the base sequence of each strand is kept. **[2]**

**3.** **(a)** State the number of water molecules released when an RNA strand of 250 nucleotides is formed. **[1]**

**(b)** A linear double-stranded DNA fragment has 60 base pairs. State the number of nucleotides it contains. **[1]**

**(c)** Calculate the number of sugar–phosphate links in the fragment in (b). **[1]**

**4.** In a sample of double-stranded DNA, 21% of the bases are cytosine. Calculate the percentage of adenine, showing your working. **[2]**

**5.** The table shows the base composition of three nucleic acid samples.

| Sample | A / % | T / % | U / % | G / % | C / % |
|---|---|---|---|---|---|
| P | 26.1 | 25.9 | 0 | 24.0 | 24.0 |
| R | 31.0 | 0 | 17.2 | 28.4 | 23.4 |
| S | 18.5 | 30.2 | 0 | 22.6 | 28.7 |

Identify the type of nucleic acid in each sample and whether it is single- or double-stranded, giving reasons. **[3]**

**6.** **(a)** A DNA template strand reads 3′-TACGGATTC-5′. Write the base sequence of the mRNA transcribed from it, showing its 5′ and 3′ ends. **[2]**

**(b)** Explain the role of complementary base pairing in DNA replication. **[2]**

**7.** **(a)** Calculate the number of possible base sequences for a DNA stretch 6 bases long. **[1]**

**(b)** Explain why the information capacity of DNA is described as limitless. **[1]**

**8.** Explain how the genetic code provides evidence for universal common ancestry. **[2]**

**9.** (HL only) One strand of a DNA molecule reads 5′-ACGTTG-3′.

**(a)** State which end of this strand has a free phosphate group. **[1]**

**(b)** Write the complementary strand in the 5′ to 3′ direction. **[1]**

**(c)** Explain why DNA polymerase can only extend a new strand in one direction. **[1]**

**10.** (HL only) Suggest why a base pair between adenine and guanine would disrupt the structure of the double helix. **[2]**

**11.** (HL only) **(a)** Describe the structure of a nucleosome. **[2]**

**(b)** Suggest why histone proteins bind strongly to the DNA backbone. **[1]**

**12.** (HL only) **(a)** Hershey and Chase concluded that DNA is the genetic material of bacteriophages. Predict the results they would have obtained if protein had been the genetic material. **[2]**

**(b)** In an invented sample from one species, A = 28.9%, T = 29.3%, G = 21.0% and C = 20.8%. Explain how such data are inconsistent with the tetranucleotide hypothesis. **[2]**

## Answers

**1. (a)** Carbon 1′ [1]

**(b)** Carbon 5′ [1] **[2]**

**2.** The strands are held together by hydrogen bonds between bases, which are weak and easily broken [1]; within each strand, nucleotides are joined by strong covalent bonds in the sugar–phosphate backbone, so the sequence is not disrupted [1] **[2]**

*Examiner insight:* The answer needs both bond types and where each is; "hydrogen bonds are weak" alone explains only half the question.

**3. (a)** 249 [1]

**(b)** 120 [1]

**(c)** Each strand of 60 has 59 links, so 2 × 59 = **118** [1] **[3]**

**4.** C = G = 21%, so G + C = 42% and A + T = 58% [1]; A = 58 ÷ 2 = **29%** [1] **[2]**

**5.** P: DNA (thymine, no uracil) and double-stranded, because A ≈ T and G = C [1]. R: RNA (uracil, no thymine) and single-stranded, because A ≠ U and G ≠ C [1]. S: DNA but single-stranded, because A ≠ T and G ≠ C [1] **[3]**

*Examiner insight:* Sample S is the trap: thymine shows DNA, but unequal pairs show it is single-stranded, as in some viruses.

**6. (a)** 5′-AUGCCUAAG-3′: correct bases with U for A [1]; ends labelled correctly [1]

**(b)** Each strand acts as a template [1]; free nucleotides pair only with their complementary bases (A with T, C with G), so each new double strand has the same sequence as the original [1] **[4]**

**7. (a)** 4⁶ = **4096** [1]

**(b)** Any base can follow any other and DNA molecules can be very long, so the number of possible sequences has no practical limit [1] **[2]**

**8.** The same codons code for the same amino acids in almost all organisms [1]; the code is arbitrary, so this shared code is best explained by inheritance from a single common ancestor [1] **[2]**

**9. (a)** The 5′ end [1]

**(b)** 5′-CAACGT-3′ [1]

**(c)** New nucleotides can only be joined to the free –OH on the 3′ carbon of the growing strand, so synthesis runs 5′ to 3′ [1] **[3]**

*Examiner insight:* Writing 3′-TGCAAC-5′ is the same strand, but the question asks for 5′ to 3′; reverse the order before you write it.

**10.** Adenine and guanine are both purines with two rings [1]; the pair would be wider than a purine–pyrimidine pair, so the helix would bulge and lose its uniform diameter [1] **[2]**

**11. (a)** DNA is wound around a core of eight histone proteins [1]; a further histone binds the linker DNA between neighbouring nucleosomes [1]

**(b)** Histones are positively charged and are attracted to the negatively charged phosphate groups of the backbone [1] **[3]**

**12. (a)** Most ³⁵S (protein label) would be found in the pellet with the bacteria [1], and most ³²P (DNA label) would stay in the supernatant with the phage coats [1]

**(b)** The tetranucleotide hypothesis predicts equal amounts of all four bases, about 25% each [1]; here A and T are well above 25% and G and C below, so the bases are not in equal amounts [1] **[4]**

## Where marks are usually lost

- Placing the phosphate on carbon 3′ or the base in the backbone.
- Forgetting that a chain of n units has n − 1 links.
- Applying A = T to RNA or to single-stranded DNA.
- Writing thymine in mRNA.
- Giving a complementary strand in the 3′ to 5′ order when 5′ to 3′ is asked for.
- Describing the nucleosome without the histone core.
