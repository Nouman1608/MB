## Privacy and confidentiality

- **Privacy**: the right of people to keep their personal data to themselves and control who sees it.
- **Confidentiality**: making sure data is seen only by the people authorised to see it while it is stored or sent.
- Data sent across a network can be **intercepted**, so protect it with encryption and authentication.

## Passwords

**Avoiding interception**

- **Up-to-date anti-spyware** detects and removes spyware, such as key-logging software that records what is typed.
- **Change passwords regularly**, so an intercepted password works only for a limited time.

**Strong versus weak**

| Strong password | Weak password |
|---|---|
| Long | Short |
| Mixes upper and lower case letters, numbers and symbols | Only letters or only numbers |
| Not a dictionary word or name | A real word, a name or a pet's name |
| Not linked to the user | Includes a birthday or address |
| Different for each account | Reused on many accounts |

Example of the difference: *sunshine* is weak (a dictionary word); a long mix such as *Tr4in!Lamp_92Gx* is strong.

## Other authentication methods

| Method | How it works | Advantage | Disadvantage |
|---|---|---|---|
| Zero login | The system recognises the user automatically, for example from their device, location, face or typing pattern, with no login step | Quick; nothing to remember | Behaviour is monitored, raising privacy concerns |
| Biometrics | A unique body feature is checked: fingerprint, face, iris or retina, voice | Cannot be forgotten; hard to copy or share | Expensive equipment; injuries, lighting or illness can cause rejection; biometric data is sensitive if stolen |
| Magnetic stripe | Card is swiped; stripe holds the user's ID | Cheap and simple | Easily copied; damaged by magnets; lost cards can be misused |
| Smart card | Card with a chip, often contactless; may need a PIN | More secure than a stripe; holds more data | Can be lost or stolen |
| Physical token | A small device generates a **one-time passcode** that is entered with the user's password or PIN | Code changes each time, so an intercepted code is useless | Token can be lost; costs money to issue |
| Electronic token | An app on a phone generates or receives a one-time code | No extra device to carry | Phone lost, stolen or flat means no access |

Using two methods together (such as a password and a token) is **two-factor authentication**: an attacker would need both.

## Anti-malware software

- **Anti-malware** protects against all malicious software; **anti-virus** is the part focused on viruses.
- Checks files against known malware and watches for suspicious behaviour.
- **Removing**: the infected file is deleted or cleaned.
- **Quarantining**: the suspicious file is moved to a secure area where it cannot run, so the user can decide later whether to delete or restore it.
- Must be **kept up to date**, because new malware appears constantly.
- **Scan storage media used to transfer data**, such as pen drives, before opening files.
- **Scan downloads** and email attachments before they are opened or installed.

## Electronic conferencing

| | Video-conferencing | Audio-conferencing | Web-conferencing |
|---|---|---|---|
| What it is | Live sound and video between people in different places | Live sound only, by phone or over the internet | Meetings run through the internet, with video, audio, screen sharing, chat and whiteboards |
| Hardware | Webcams or video cameras, large monitors or screens, microphones, speakers | Telephones, or a computer with microphone and speakers or headset | Computer, tablet or phone with webcam, microphone and speakers |
| Software | Conferencing software; compression of video and sound; echo cancellation | Conference call service or VoIP software; participants given a phone number and PIN | Conferencing app or browser-based software |
| Network connection | Fast broadband connection | Telephone line or internet connection | Internet connection, ideally fast broadband |
| Uses | Business meetings, interviews, remote medical consultations | Quick team calls, conference calls with many participants | Online lessons, training, presentations, webinars, collaborative meetings |
| Advantages | See body language; no travel time or cost; meetings at short notice | Cheap; only a phone needed; easy to join | Share documents and screens; recordings; chat and polls; join from anywhere |
| Disadvantages | Time zones; lag or poor picture on slow connections; equipment cost | No visual cues; hard to know who is speaking; cannot show documents | Depends on internet speed; security of meetings; distractions at home |

## Key terms

| Term | Meaning |
|---|---|
| Authentication | Checking that a user is who they claim to be |
| Spyware | Software that secretly records a user's activity, such as key presses |
| One-time passcode | A code valid for one login only |
| Two-factor authentication | Using two different authentication methods together |
| Quarantine | Isolating a suspicious file so it cannot run |
| Webinar | A presentation or seminar delivered by web-conferencing |

## Exam traps

- A password is not stronger just because it is long: it should also mix character types and avoid real words.
- Quarantining is **not** the same as deleting.
- Anti-malware must be **up to date**; out-of-date software misses new threats.
- Audio-conferencing has **no** video and cannot share documents.
- When asked for hardware, give devices (webcam, microphone); when asked for software, give programs or features.

## Self-test

1. State the difference between privacy and confidentiality.
2. Give **two** ways of avoiding password interception named in the syllabus.
3. Give **three** features of a strong password.
4. Describe what is meant by zero login.
5. Give **one** advantage and **one** disadvantage of biometric authentication.
6. How does a physical token improve security?
7. State the difference between removing and quarantining a virus.
8. Why should a pen drive be scanned before files on it are opened?
9. Give **three** items of hardware needed for video-conferencing.
10. Give **one** disadvantage of audio-conferencing compared with video-conferencing.

## Self-test answers

1. Privacy is a person's right to control their own personal data; confidentiality is ensuring data is seen only by authorised people.
2. Use up-to-date anti-spyware; change passwords regularly.
3. Any three: long; mixes upper and lower case, numbers and symbols; not a real word or name; not linked to the user; unique to each account.
4. The user is recognised automatically, for example from their device, location, face or typing pattern, without a separate login step.
5. Advantage: cannot be forgotten, or hard to copy. Disadvantage: expensive, may reject the right user, or stolen biometric data cannot be changed.
6. It generates a one-time passcode, so a code that is intercepted cannot be used again.
7. Removing deletes or cleans the infected file; quarantining isolates it so it cannot run until the user decides what to do.
8. It may carry a virus from another computer.
9. Any three: webcam or video camera, monitor or large screen, microphone, speakers.
10. Participants cannot see each other or body language, or cannot share documents.
