This guide teaches section **3.1.6.2 Equilibrium constant Kc for homogeneous systems** of the AQA AS and A-level Chemistry specification (7404/7405), for teaching from September 2015. It is AS content, examined on Papers 1 and 2 (and Paper 3). Le Chatelier's principle predicts the direction of a shift. The equilibrium constant, Kc, lets you calculate how far a reaction goes. The skills are writing the expression, working out concentrations from moles, substituting, finding the units, and using Kc to find an unknown. The [Chemical equilibria, Le Chatelier's principle and Kc study guide](/resources/aqa-a-level-chemistry-chemical-equilibria-le-chateliers-principle-and-kc/) covers the whole topic. Recall is in the [Equilibrium constant Kc revision notes](/resources/aqa-a-level-chemistry-7405-equilibrium-constant-kc-for-homogeneous-systems-revision-notes/), and questions are in the [Equilibrium constant Kc practice questions](/resources/aqa-a-level-chemistry-7405-equilibrium-constant-kc-for-homogeneous-systems-practice/).

## What the specification asks

| Content and skills | What you must be able to do |
|---|---|
| Kc is deduced from the equation for a reversible reaction | Write the expression from a balanced equation |
| The concentration of a species X in mol dm⁻³ is represented by [X] | Use square brackets correctly |
| Kc is not affected by changes in concentration or by a catalyst | State this and explain |
| Construct an expression for Kc for a homogeneous system | Write expressions for gases or solutions |
| Calculate a value for Kc from equilibrium concentrations at constant temperature | Substitute values and give units |
| Perform calculations involving Kc | For example find an unknown concentration |
| Predict the qualitative effect of changes of temperature on the value of Kc | Link to the enthalpy change |

"Homogeneous" means that all species are in the same phase, so no solids are involved here.

## The expression

For the general reaction aA + bB ⇌ cC + dD at equilibrium:

```
Kc = [C]ᶜ [D]ᵈ ÷ ([A]ᵃ [B]ᵇ)
```

- Products are on the **top** and reactants on the **bottom**.
- Each concentration is raised to the power of its **coefficient** in the balanced equation.
- Concentrations are in **mol dm⁻³** and are those at equilibrium.

### Worked example 1: writing expressions

| Equation | Kc expression |
|---|---|
| N₂(g) + 3H₂(g) ⇌ 2NH₃(g) | [NH₃]² ÷ ([N₂][H₂]³) |
| H₂(g) + I₂(g) ⇌ 2HI(g) | [HI]² ÷ ([H₂][I₂]) |
| 2SO₂(g) + O₂(g) ⇌ 2SO₃(g) | [SO₃]² ÷ ([SO₂]²[O₂]) |
| CH₃COOH(l) + C₂H₅OH(l) ⇌ CH₃COOC₂H₅(l) + H₂O(l) | [CH₃COOC₂H₅][H₂O] ÷ ([CH₃COOH][C₂H₅OH]) |

The value of Kc depends on how the equation is written. For ½N₂ + 1½H₂ ⇌ NH₃ the constant is the square root of the one for N₂ + 3H₂ ⇌ 2NH₃, and for the reverse reaction it is the reciprocal.

## Units

Work out the units by substituting the units into the expression and cancelling.

```
N₂ + 3H₂ ⇌ 2NH₃:    (mol dm⁻³)² ÷ ((mol dm⁻³)(mol dm⁻³)³) = mol⁻² dm⁶
H₂ + I₂ ⇌ 2HI:      (mol dm⁻³)² ÷ ((mol dm⁻³)(mol dm⁻³)) = no units
2SO₂ + O₂ ⇌ 2SO₃:  (mol dm⁻³)² ÷ ((mol dm⁻³)²(mol dm⁻³)) = mol⁻¹ dm³
PCl₅ ⇌ PCl₃ + Cl₂:  (mol dm⁻³)² ÷ (mol dm⁻³) = mol dm⁻³
```

If the powers on the top and bottom are equal, Kc has no units. Always write the units, or "no units", with the answer.

## Calculating Kc

### Worked example 2: from equilibrium concentrations

At equilibrium, [H₂] = 0.20 mol dm⁻³, [I₂] = 0.20 mol dm⁻³ and [HI] = 1.60 mol dm⁻³.

```
Kc = [HI]² ÷ ([H₂][I₂]) = 1.60² ÷ (0.20 × 0.20) = 2.56 ÷ 0.040 = 64   (no units)
```

### Worked example 3: from moles in a vessel

1.00 mol of PCl₅ is placed in a 2.00 dm³ vessel and heated. At equilibrium 0.40 mol of PCl₅ remains. Calculate Kc for PCl₅ ⇌ PCl₃ + Cl₂.

```
                    PCl₅     PCl₃     Cl₂
initial / mol       1.00     0        0
change / mol       −0.60    +0.60    +0.60
equilibrium / mol   0.40     0.60     0.60
equilibrium / mol dm⁻³   0.20   0.30    0.30     (÷ 2.00 dm³)

Kc = [PCl₃][Cl₂] ÷ [PCl₅] = 0.30 × 0.30 ÷ 0.20 = 0.45 mol dm⁻³
```

The steps are: (1) amount reacted from the change in the substance whose equilibrium amount is known; (2) use the mole ratio to find the changes for the others; (3) divide by the volume to get concentrations; (4) substitute.

### Worked example 4: ammonia

1.00 mol of N₂ and 3.00 mol of H₂ are mixed in a 2.00 dm³ vessel. At equilibrium 0.40 mol of NH₃ has formed. Calculate Kc for N₂ + 3H₂ ⇌ 2NH₃.

```
                    N₂       H₂       NH₃
initial / mol       1.00     3.00     0
change / mol       −0.20    −0.60    +0.40
equilibrium / mol   0.80     2.40     0.40
equilibrium / mol dm⁻³   0.40   1.20   0.20

Kc = 0.20² ÷ (0.40 × 1.20³) = 0.040 ÷ 0.6912 = 0.0579 mol⁻² dm⁶
```

The mole ratio 1 : 3 : 2 gives the changes: 0.40 mol of NH₃ needs 0.20 mol of N₂ and 0.60 mol of H₂.

### Worked example 5: with units

At equilibrium [SO₂] = 0.040, [O₂] = 0.020 and [SO₃] = 0.060 mol dm⁻³.

```
Kc = 0.060² ÷ (0.040² × 0.020) = 0.0036 ÷ 3.2 × 10⁻⁵ = 112.5 ≈ 1.1 × 10² mol⁻¹ dm³
```

## Using Kc to find an unknown

### Worked example 6: an equilibrium concentration

For N₂O₄ ⇌ 2NO₂, Kc = 0.0060 mol dm⁻³ at 298 K. At equilibrium [N₂O₄] = 0.050 mol dm⁻³. Find [NO₂].

```
Kc = [NO₂]² ÷ [N₂O₄]     so    [NO₂]² = 0.0060 × 0.050 = 3.0 × 10⁻⁴
[NO₂] = √(3.0 × 10⁻⁴) = 0.0173 mol dm⁻³
```

### Worked example 7: an ester equilibrium

For CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O, Kc = 4.0 at the temperature used. 1.00 mol of ethanoic acid and 1.00 mol of ethanol react. Find the amount of ester at equilibrium.

Let x mol of ester form. Then 1.00 − x mol of each reactant remains. The number of moles on each side of the equation is equal, so the volume V cancels:

```
Kc = x² ÷ (1.00 − x)² = 4.0
x ÷ (1.00 − x) = 2.0   (take the square root)
x = 2.0 − 2.0x   so   3.0x = 2.0   and   x = 0.667 mol
```

At equilibrium 0.667 mol of ester (and water) is present, so two thirds of the starting materials has reacted.

## Factors that affect Kc

| Change | Effect on Kc |
|---|---|
| Concentration of a species | **None.** The position shifts to restore the same ratio, so Kc returns to the same value |
| Pressure | None |
| Catalyst | None, because it affects the forward and reverse rates equally |
| **Temperature** | **Changes Kc** |

### Temperature and Kc

- For an **exothermic** forward reaction (ΔH negative), raising the temperature **decreases** Kc. The position moves to the left, so the ratio of products to reactants falls.
- For an **endothermic** forward reaction (ΔH positive), raising the temperature **increases** Kc.

### Worked example 8: predicting the effect

The synthesis of ammonia is exothermic (ΔH = −92 kJ mol⁻¹). Predict how Kc changes when the temperature is raised from 400 K to 700 K.

The equilibrium shifts to the left, so there is less NH₃ and more N₂ and H₂ at equilibrium. The numerator decreases and the denominator increases, so Kc decreases.

### Why concentration does not change Kc

If extra N₂ is added at equilibrium, the ratio [NH₃]² ÷ ([N₂][H₂]³) falls below Kc for an instant. The system responds by forming more NH₃ until the ratio returns to the original Kc. The position has moved, but the constant has not.

## Common mistakes

- Writing the expression upside down (reactants on top).
- Missing the powers from the coefficients.
- Using moles instead of concentrations, when the vessel volume does not cancel.
- Using initial concentrations instead of equilibrium values.
- Leaving out the units, or getting the units wrong.
- Stating that Kc changes when concentrations or pressure change.
- Including solids in an expression for a heterogeneous equilibrium (not in this subtopic).
- Rounding intermediate values.

## Exam technique for the command words

- **Write an expression**: square brackets for concentrations, powers matching coefficients.
- **Calculate**: show the table, then the substitution; give units.
- **State** the effect of temperature: link the sign of ΔH to whether the position shifts and so to the change in Kc.
- **Explain** why a catalyst does not change Kc: it affects both rates equally.

## Frequently asked questions

**When can I use moles instead of concentrations?**
Only when the number of moles on both sides of the expression is equal, so the volume cancels. If in doubt, convert to concentrations.

**Does a large Kc mean a fast reaction?**
No. Kc tells you the extent of the reaction, not its rate.

**Can Kc be negative?**
No. It is a ratio of positive concentrations.
