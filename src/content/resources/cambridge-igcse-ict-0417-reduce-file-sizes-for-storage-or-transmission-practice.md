## Section A: short answers

**1.** State what is meant by a *compressed archive*. **[1]**

**2.** Which **one** of these statements about a .zip file is true?

A: It permanently removes detail from images.

B: Its contents are identical to the originals when extracted.

C: It can only hold one file.

D: It can only be opened with the software that created it. **[1]**

**3.** Give **two** reasons why a business might reduce the size of files it stores. **[2]**

**4.** Give **two** reasons why files are compressed before being sent over the internet. **[2]**

**5.** State **one** feature of .rar archives that is useful when a file is too large to send in one piece. **[1]**

**6.** State why compressing a folder of .mp4 videos produces only a small reduction in size. **[1]**

## Section B: structured questions

**7.** A sales manager has a folder of reports totalling 90 MB. Compressed as a .zip file, it is 36 MB.

**(a)** Calculate the compression ratio. **[1]**

**(b)** Calculate the percentage reduction in size. Show your working. **[2]**

**(c)** Calculate how long each version takes to send over a 12 Mbit/s connection. Show your working. **[3]**

**8.** A student must email four files totalling 26 MB to a teacher. The email system has an attachment limit of 10 MB. Compression reduces the files to 40% of their original size.

**(a)** Calculate the size of the compressed archive. **[1]**

**(b)** Explain whether the archive can be sent as one attachment. **[1]**

**(c)** Describe **two** ways the student could send the files. **[2]**

**9.** A photographer stores design projects on a USB flash drive with 2 GB of free space. Each project is 250 MB and compresses to 25% of its size.

**(a)** Calculate how many uncompressed projects fit in the free space. **[1]**

**(b)** Calculate how many compressed projects fit in the free space. Show your working. **[2]**

**(c)** Give **one** disadvantage of storing the projects compressed. **[1]**

**10.** Describe the steps a user would take to compress a folder of documents into a .zip file and check the result. **[4]**

**11.** A teacher sends students a .zip file containing worksheets. One student opens a worksheet directly from inside the archive, edits it and closes it, but cannot find the changes later. Explain what has happened and what the student should do. **[2]**

**12.** A school has a slow internet connection shared by many users. Explain why staff are asked to compress large files before uploading them to the school's cloud storage. **[4]**

## Answers

**1.** A single file that holds one or more other files in compressed form (1). **[1]**

**2.** B: its contents are identical to the originals when extracted. **[1]**

**3.** Any two: storage devices have limited capacity, so more files fit (1); less need to buy extra storage or a larger cloud plan (1); back-ups are quicker and smaller (1); old files can be archived to free space (1). **[2]**

**4.** Any two: attachment size limits may otherwise be exceeded (1); smaller files upload and download faster (1); less bandwidth or data allowance is used (1); many files can be sent as one archive (1). **[2]**

**5.** A .rar archive can be split into several parts of a chosen size (1). **[1]**

**6.** .mp4 files are already compressed, so there is little repeated data left to compress (1). **[1]**

**7. (a)** 90 / 36 = 2.5 to 1 (1).

**(b)** Saving = 90 - 36 = 54 MB (1); 54 / 90 x 100 = 60% (1).

**(c)** Original: 90 x 8 = 720 megabits; 720 / 12 = 60 seconds (1). Compressed: 36 x 8 = 288 megabits; 288 / 12 = 24 seconds (1). Correct method of converting megabytes to megabits shown (1). **[6]**

**8. (a)** 26 x 0.4 = 10.4 MB (1).

**(b)** No: 10.4 MB is larger than the 10 MB limit, so the attachment would be rejected (1).

**(c)** Any two: split the files into two archives, each under 10 MB, and send two emails (1); create a .rar archive split into parts under 10 MB (1); upload the archive to cloud storage and email a link (1); use a file transfer service (1). **[4]**

**9. (a)** 2 000 / 250 = 8 projects (1).

**(b)** Compressed size = 250 x 0.25 = 62.5 MB (1); 2 000 / 62.5 = 32 projects (1).

**(c)** Any one: each project must be extracted before it can be used, which takes time (1); if the archive file is damaged, all the files inside may be lost (1). **[4]**

**10.** Any four, in a logical order: select the folder of documents in the file manager (1); choose the compress or add-to-archive option (1); give the .zip file an appropriate name and choose where to save it (1); compare the size of the .zip file with the original folder to check it is smaller (1); open or extract the archive to check the files are all present (1). Maximum 4. **[4]**

**11.** The worksheet was opened from inside the archive as a temporary copy, so the edited version was not saved back into a normal folder (1). The student should extract the files to a folder first, then open, edit and save the worksheet from there (1). **[2]**

**12.** Any four: the connection is slow, so large files take a long time to upload (1); compressed files are smaller, so they upload faster (1); the connection is shared, so large uploads use bandwidth and slow the network for other users (1); compressing reduces the amount of data sent, leaving capacity for others (1); compressed files also take less space in the cloud storage, which may have a limit (1). Maximum 4. **[4]**

## Frequently asked questions

**Should I use 1 MB = 1 000 000 bytes or 1 048 576 bytes?**
Use whichever the question states. If it gives no convention, say which you are using; these questions use 1 000 000 bytes.

**Is a .zip file lossy?**
No. .zip and .rar are lossless: extracting the archive gives files identical to the originals.
