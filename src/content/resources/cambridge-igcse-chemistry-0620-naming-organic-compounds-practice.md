## Questions

### Section A: short questions

**1.** Which name belongs to a carboxylic acid?

A: propene

B: propanol

C: propanoic acid

D: propane **[1]**

**2.** State the type of compound present in each of the following.

**(a)** butane **[1]**

**(b)** C₃H₆ **[1]**

**(c)** methanol **[1]**

**3.** Draw the displayed formula of methane. **[1]**

**4.** Name the organic product formed when ethene reacts with hydrogen in the presence of a nickel catalyst. **[1]**

**5.** Ethanoic acid reacts with magnesium. Name the salt formed. **[1]**

**6.** *(Extended)* Name each compound.

**(a)** CH₃CH₂CH₂OH **[1]**

**(b)** CH₃CH=CHCH₃ **[1]**

**(c)** CH₃CH₂COOH **[1]**

**7.** *(Extended)* A student names CH₃CH₂CH(OH)CH₃ as "butan-3-ol". Explain the error and give the correct name. **[2]**

### Section B: structured questions

**8.** A displayed formula shows one carbon atom bonded to three hydrogen atoms and to a second carbon atom. The second carbon atom has a double bond to an oxygen atom and a single bond to an –O–H group.

**(a)** Name the compound. **[1]**

**(b)** A student says this compound is an alcohol because it contains O–H. Explain why the student is wrong. **[2]**

**(c)** Write its molecular formula in the form used in the general formula of its series. **[1]**

**9.** *(Extended)* Draw the displayed formulae of propan-1-ol and propan-2-ol, and explain why they have different names. **[4]**

**10.** *(Extended)* Esters are made from carboxylic acids and alcohols.

**(a)** Name the ester formed from ethanol and butanoic acid. **[1]**

**(b)** Name the alcohol and the carboxylic acid used to make methyl ethanoate. **[2]**

**(c)** Name the ester CH₃COOCH₂CH₂CH₃. **[2]**

**(d)** Draw the displayed formula of methyl ethanoate. **[2]**

**11.** Name the organic product of each reaction.

**(a)** ethene + steam, with an acid catalyst **[1]**

**(b)** ethene + bromine **[1]**

**(c)** fermentation of glucose **[1]**

**12.** *(Extended)* Compound X has the molecular formula C₄H₈ and is unbranched. Its double bond is between the second and third carbon atoms.

**(a)** Name compound X. **[1]**

**(b)** Write its structural formula. **[1]**

**(c)** Name the isomer of X with the double bond at the end of the chain. **[1]**

**13.** *(Extended)* A student writes the name "propyl methanoate" for the ester CH₃CH₂COOCH₃. Explain the mistake and give the correct name. **[3]**

**14.** The displayed formula of a compound shows two carbon atoms joined by a single bond. One carbon has three hydrogen atoms; the other has two hydrogen atoms and an –O–H group.

**(a)** Name the compound and state its homologous series. **[2]**

**(b)** Name the compound formed when it is oxidised. **[1]**

**(c)** Name the compound with the same number of carbon atoms that has a C=C double bond. **[1]**

## Answers

**1.** **C** [1].

**2. (a)** Alkane [1].

**(b)** Alkene [1] (fits CₙH₂ₙ).

**(c)** Alcohol [1].

**3.** One carbon with four single bonds, each to a hydrogen atom [1]:

```
    H
    |
H — C — H
    |
    H
```

**4.** Ethane [1].

**5.** Magnesium ethanoate [1].

**6. (a)** Propan-1-ol [1].

**(b)** But-2-ene [1].

**(c)** Propanoic acid [1].

**7.** The chain must be numbered from the end that gives the –OH the lowest number [1]; counting from the right, the –OH is on carbon 2, so the name is butan-2-ol [1].

**8. (a)** Ethanoic acid [1].

**(b)** The O–H is on a carbon that also has a C=O double bond [1]; together they form the –COOH group, so it is a carboxylic acid, not an alcohol [1].

**(c)** CH₃COOH [1].

**9.** Propan-1-ol displayed formula with –OH on an end carbon, all bonds shown [1]:

```
    H   H   H
    |   |   |
H — C — C — C — O — H
    |   |   |
    H   H   H
```

Propan-2-ol displayed formula with –OH on the middle carbon, all bonds shown [1]:

```
    H   H   H
    |   |   |
H — C — C — C — H
    |   |   |
    H   O   H
        |
        H
```

The –OH group is on a different carbon atom [1]; the locant number (1 or 2) shows its position in the chain [1].

**10. (a)** Ethyl butanoate [1].

**(b)** Methanol [1]; ethanoic acid [1].

**(c)** Acid part CH₃CO– has two carbons, so ethanoate; alcohol part –OCH₂CH₂CH₃ has three carbons, so propyl [1]; propyl ethanoate [1].

**(d)** Correct ester linkage with C=O and C–O–C [1]; all other bonds and hydrogens correct [1]:

```
    H   O       H
    |   ‖       |
H — C — C — O — C — H
    |           |
    H           H
```

**11. (a)** Ethanol [1].

**(b)** 1,2-dibromoethane (dibromoethane) [1].

**(c)** Ethanol [1].

**12. (a)** But-2-ene [1].

**(b)** CH₃CH=CHCH₃ [1].

**(c)** But-1-ene [1].

**13.** The student read the formula from left to right [1]. The acid part, CH₃CH₂CO–, has three carbons, so it is propanoate; the alcohol part, –OCH₃, has one carbon, so it is methyl [1]. The correct name is methyl propanoate [1].

**14. (a)** Ethanol [1]; alcohols [1].

**(b)** Ethanoic acid [1].

**(c)** Ethene [1].

## Where marks are usually lost

- Not counting the –COOH carbon in the stem of a carboxylic acid.
- Using the higher locant number, such as butan-3-ol.
- Calling ethanoic acid an alcohol because it contains O–H.
- Reading an ester formula from left to right and reversing the name.
- Missing the O–H bond or the C=O double bond in a displayed formula.
- Spelling errors such as "ethanate" or "ethanyl" that change the meaning.
