Condensed notes for syllabus section 5.3, Cyber security. For every threat, learn the process and the aim. For every solution, learn what it does and what it stops.

## Four facts to start with

1. **Cyber security threats** try to steal, damage or block access to data and systems.
2. **Malware** has six named types: virus, worm, Trojan horse, spyware, adware, ransomware.
3. **Phishing** uses a deceptive message; **pharming** redirects a correct web address to a fake site.
4. No single solution is enough, so several are used together.

## Key terms

| Term | Definition |
|---|---|
| Cyber security | Protecting computers, networks and data from threats |
| Malware | Malicious software designed to cause harm or steal data |
| Brute-force attack | Trying every possible combination until a password or PIN is found |
| Hacking | Gaining unauthorised access to a computer system or data |
| DDoS attack | Many computers send a flood of requests to make a server unavailable |
| Data interception | Capturing data as it travels over a network |
| Social engineering | Manipulating people into giving information or access |
| Firewall | Checks network traffic against rules and blocks unwanted traffic |
| Authentication | Proving who a user is |
| SSL | Security protocol that encrypts data between browser and server |
| Proxy server | Server that sits between the user and the internet and filters requests |

## Threats: process and aim

| Threat | Process | Aim |
|---|---|---|
| Brute-force | Software tries all combinations | Gain access |
| Data interception | Packets captured on a network | Read or steal data |
| DDoS | Many computers flood a server with requests | Make site unavailable |
| Hacking | Unauthorised access, such as stolen passwords | Steal, change or delete data |
| Virus | Attaches to a file; spreads when file is run | Corrupt or delete data |
| Worm | Copies itself across a network | Use bandwidth; spread |
| Trojan horse | Looks like genuine software | Open the way for harm; steal data |
| Spyware | Secretly records activity | Send personal data to attacker |
| Adware | Shows unwanted adverts | Make money; slow computer |
| Ransomware | Locks or encrypts files | Demand payment |
| Pharming | Redirects to a fake site | Collect personal data |
| Phishing | Fake message with a link | Collect personal data |
| Social engineering | Tricks a person | Get passwords, access or money |

## Solutions: what each does

| Solution | What it does |
|---|---|
| Access levels | Limit what each user can see and change |
| Anti-malware | Scans for and removes malware (anti-virus and anti-spyware) |
| Authentication | Username and password, biometrics, two-step verification |
| Automatic updates | Fix security weaknesses quickly |
| Checking spelling and tone | Spot fake messages |
| Checking the URL of a link | Spot fake websites |
| Firewall | Filters traffic in and out of a network |
| Privacy settings | Limit who sees personal data |
| Proxy server | Filters and hides user's address |
| SSL | Encrypts data between browser and server |

## Matching solutions to threats

| Threat | Best solutions |
|---|---|
| Brute-force | Strong passwords, two-step verification, limited attempts |
| Interception | SSL (encryption) |
| DDoS | Firewall, proxy server |
| Hacking | Firewall, authentication, access levels, updates |
| Malware | Anti-malware, updates |
| Phishing | Check URL, check spelling and tone |
| Pharming | Check URL, anti-malware, firewall |

## Brute-force arithmetic

- A 4-digit PIN has 10⁴ = 10,000 combinations.
- Six lowercase letters give 26⁶ = 308,915,776 combinations.
- Each extra character multiplies the number of combinations by the number of possible characters, so a longer password is much harder to find.

## Exam traps

- **Virus and worm swapped.** A worm spreads by itself.
- **Firewall removes viruses.** Anti-malware does that.
- **Phishing and pharming swapped.**
- **Aim missing.** Always state what the attacker wants.
- **SSL prevents interception.** It makes intercepted data unreadable.
- **DDoS from one computer.** It uses many computers.

## Self-test

1. What is the aim of a ransomware attack?
2. Name two types of malware that spy or display adverts.
3. How does a worm spread differently from a virus?
4. What is a brute-force attack?
5. Why is a DDoS attack called "distributed"?
6. State the difference between phishing and pharming.
7. Give three signs that a message may be a phishing attempt.
8. What does a firewall do?
9. Give two forms of authentication.
10. How does SSL help keep data safe?

**Answers**

1. To make the victim pay money to get their files back.
2. Spyware (spies) and adware (adverts).
3. A worm copies itself across a network on its own; a virus needs a host file to be run by the user.
4. Trying every possible combination until the correct password or PIN is found.
5. The requests come from many different computers.
6. Phishing uses a deceptive message and a click on a link; pharming redirects a correctly typed address to a fake site.
7. Any three: poor spelling, urgent or threatening tone, a link whose real address does not match, unexpected attachment, request for personal details.
8. Checks incoming and outgoing traffic against rules and blocks unwanted traffic.
9. Any two: username and password, biometrics, two-step verification.
10. It encrypts the data sent between the browser and the server, so intercepted data cannot be read.
