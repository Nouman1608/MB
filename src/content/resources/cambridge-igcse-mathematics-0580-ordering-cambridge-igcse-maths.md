This guide teaches subtopic **1.5 Ordering** from the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027: *order quantities by magnitude and demonstrate familiarity with the symbols =, ≠, >, <, ⩾ and ⩽*. The Core (C1.5) and Extended (E1.5) statements are identical. Ordering questions often mix forms, so this subtopic leans on [fractions, decimals and percentages](/resources/cambridge-igcse-mathematics-0580-fractions-decimals-and-percentages-cambridge-igcse-maths/) and [powers and roots](/resources/cambridge-igcse-mathematics-0580-powers-and-roots-cambridge-igcse-maths/). Only the recurring decimal example is Extended, because recurring notation belongs to E1.4.

Use it with the [ordering revision notes](/resources/cambridge-igcse-mathematics-0580-ordering-cambridge-igcse-maths-revision-notes/) and the [ordering practice questions](/resources/cambridge-igcse-mathematics-0580-ordering-cambridge-igcse-maths-practice/).

## The six symbols

| Symbol | Read as | True example | False example |
|---|---|---|---|
| = | is equal to | 0.25 = 1/4 | 0.3 = 1/3 |
| ≠ | is not equal to | 0.3 ≠ 1/3 | 2/5 ≠ 40% |
| > | is greater than | −2 > −5 | 0.5 > 0.55 |
| < | is less than | 0.09 < 0.1 | −1 < −3 |
| ⩾ | is greater than or equal to | 7 ⩾ 7 | 6 ⩾ 7 |
| ⩽ | is less than or equal to | x ⩽ 4 includes 4 | 5 ⩽ 4 |

The wide end of > and < faces the larger number. ⩾ and ⩽ include equality; > and < do not. This difference decides whether an end value is in a list: integers n with −4 < n ⩽ 1 are −3, −2, −1, 0, 1 (not −4, but 1 is included).

## Ordering integers and decimals

**Negatives.** On a number line, numbers to the left are smaller. So −8 < −3, even though 8 > 3. The further a negative number is from zero, the smaller it is.

**Decimals.** Compare place by place from the left, after lining up the decimal points. Fill gaps with zeros so every number has the same number of decimal places.

```
0.7, 0.68, 0.705, 0.07
as thousandths: 0.700, 0.680, 0.705, 0.070
smallest first: 0.07, 0.68, 0.7, 0.705
```

Comparing the number of digits instead of the place values is the classic error: 0.68 has more digits than 0.7 but is smaller.

## Ordering mixed forms

Convert everything to one form, usually decimals, and write the converted values down. Then give the final answer in the **original** forms.

**Worked example 1.** Write in order of size, smallest first: 0.62, 5/8, 61%, 0.605, 3/5

```
0.62  = 0.620
5/8   = 0.625
61%   = 0.610
0.605 = 0.605
3/5   = 0.600
Order: 3/5, 0.605, 61%, 0.62, 5/8
```

**Worked example 2 (negatives).** Write in order, smallest first: −1.5, −1⅔, −1.06, −1.6

```
−1⅔ = −1.666...
Furthest from zero is smallest: −1.666..., −1.6, −1.5, −1.06
Order: −1⅔, −1.6, −1.5, −1.06
```

For negatives, order the sizes ignoring the sign (1.06, 1.5, 1.6, 1.666…) and then reverse.

**Fractions only.** With fractions, a common denominator avoids decimals. Order 5/6, 7/9, 3/4: the LCM of 6, 9 and 4 is 36, giving 30/36, 28/36 and 27/36, so 3/4 < 7/9 < 5/6.

## Ordering quantities with units

The syllabus says "quantities", so values can carry units. Convert to one unit first.

**Worked example 3.** Order these lengths, shortest first: 1.2 km, 950 m, 125 000 cm, 1 km 85 m

```
1.2 km     = 1200 m
950 m      =  950 m
125 000 cm = 1250 m     (÷ 100)
1 km 85 m  = 1085 m
Order: 950 m, 1 km 85 m, 1.2 km, 125 000 cm
```

1 km 85 m is 1085 m, not 1850 m or 1.85 km: the 85 m must be written as 0.085 km.

## Ordering powers and roots without a calculator

Squares bracket a square root. To decide where √50 goes in a list, square the neighbouring values.

**Worked example 4 (non-calculator).** Write in order, smallest first: √50, 7.1, 2³, 50/7, 7.07

```
2³   = 8
50/7 = 7.142...         (7 × 7 = 49, remainder 1, 1/7 = 0.142...)
√50: 7.07² = 49.9849 < 50 and 7.1² = 50.41 > 50
     so 7.07 < √50 < 7.1
Order: 7.07, √50, 7.1, 50/7, 2³
```

Squaring 7.07 by hand takes a few lines, but it is the reliable way to place a root between two close decimals on Papers 1 and 2.

## True or false with the symbols

**Worked example 5.** Write the correct symbol, =, < or >, between each pair.

```
(a) 0.3 ... 1/3        0.300 < 0.333...           ->  0.3 < 1/3
(b) 2/5 ... 40%        0.4 and 0.4                ->  2/5 = 40%
(c) −2 ... −5          −2 is to the right of −5   ->  −2 > −5
(d) 0.5² ... 0.5       0.25 and 0.5               ->  0.5² < 0.5
```

Part (d) is a reminder that squaring a number between 0 and 1 makes it smaller.

## Recurring decimals (Extended only)

**Worked example 6.** Write in order, smallest first: 0.3̇4̇, 0.33, 0.34, 0.3̇

```
0.3̇4̇ = 0.343 434...
0.33  = 0.330 000...
0.34  = 0.340 000...
0.3̇   = 0.333 333...
Order: 0.33, 0.3̇, 0.34, 0.3̇4̇
```

Write at least four decimal places of each recurring decimal before comparing, so the repeating digits are visible.

## Ordering in context

**Worked example 7.** Four athletes' times for a race are 1 min 4.8 s, 64.08 s, 1.07 min and 64 3/4 s. List them from fastest to slowest.

```
1 min 4.8 s = 64.8 s
64.08 s     = 64.08 s
1.07 min    = 1.07 × 60 = 64.2 s
64 3/4 s    = 64.75 s
Fastest is the shortest time:
64.08 s, 1.07 min, 64 3/4 s, 1 min 4.8 s
```

Two traps meet here: 1.07 min is not 1 min 7 s, and "fastest first" means **smallest** time first. Read what "first" refers to before writing the order.

**Very large and very small numbers.** Values written in standard form are compared by their powers of 10 first, then by the number in front; this is taught with [standard form](/resources/cambridge-igcse-mathematics-0580-standard-form-cambridge-igcse-maths/).

## Common errors

- Treating the decimal with more digits as larger (0.68 > 0.7).
- Ordering negatives as if they were positive (−1.06 < −1.5).
- Leaving the converted decimals as the final answer instead of the original numbers.
- Reversing the order when the question says "largest first", or ignoring "smallest first".
- Mixing units: comparing 950 m with 1.2 without converting km to m.
- Including an end value with < or >, or leaving one out with ⩽ or ⩾.

## Exam technique

- **Write in order of size**: show the converted values; the answer is the original values in order.
- **Write the correct symbol**: one symbol per pair, not a word.
- **List the integers that satisfy**: check both ends against the symbol.
- **Explain** which is larger: give the converted values and a sentence, for example "5/8 = 0.625, which is greater than 0.62".

## Frequently asked questions

**Should I write the answer with < signs?**
You may, but it is not required. A list in the correct order, using the original numbers, is enough unless the question asks for symbols.

**What if two of the values are equal?**
Write them next to each other in either order, or link them with =. Showing the converted values makes it clear that you noticed they are equal.
