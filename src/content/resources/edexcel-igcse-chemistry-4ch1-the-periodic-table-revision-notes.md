These notes condense sub-topic 1(d) The Periodic Table (points 1.18 to 1.24) of the Pearson Edexcel International GCSE Chemistry (4CH1) specification, Issue 3 (September 2024). None of the points has a C reference, so everything here can appear on Paper 1 and Paper 2. For worked examples and model answers use [the Periodic Table study guide](/resources/edexcel-igcse-chemistry-4ch1-the-periodic-table/); then try [the Periodic Table practice questions](/resources/edexcel-igcse-chemistry-4ch1-the-periodic-table-practice/).

## Key terms

| Term | Meaning |
|---|---|
| Period | A horizontal row; same number of occupied electron shells |
| Group | A vertical column; main group elements have the same number of outer-shell electrons |
| Main group elements | Elements in Groups 1 to 7 and Group 0 |
| Electronic configuration | The number of electrons in each shell, innermost first, e.g. 2,8,4 |
| Outer shell | The occupied shell furthest from the nucleus |
| Basic oxide | An oxide that reacts with an acid to form a salt and water |
| Acidic oxide | An oxide that gives an acidic solution (pH below 7) if it dissolves in water |
| Noble gases | Group 0 elements; full outer shells; unreactive; single atoms |

## Arrangement (1.18)

- Order: **increasing atomic number** (not Ar). Argon (18) comes before potassium (19).
- New period = new shell starting to fill.
- Metals on the left and centre; non-metals on the right of the stepped line from boron; hydrogen is a non-metal (1.21).

## Configurations (1.19, 1.22)

Shells for the first 20 elements: 2, then 8, then 8, then the rest.

```
period   = number of shells
group    = outer electrons (Groups 1-7)
Group 0  = full outer shell
```

| Atomic number | Element | Configuration | Group | Period |
|---|---|---|---|---|
| 3 | Li | 2,1 | 1 | 2 |
| 7 | N | 2,5 | 5 | 2 |
| 12 | Mg | 2,8,2 | 2 | 3 |
| 14 | Si | 2,8,4 | 4 | 3 |
| 17 | Cl | 2,8,7 | 7 | 3 |
| 18 | Ar | 2,8,8 | 0 | 3 |
| 19 | K | 2,8,8,1 | 1 | 4 |

Fast method from atomic number: fill 2, then 8, then 8; whatever is left goes in the next shell.

## Metal or non-metal? (1.20, 1.21)

| Check | Metal | Non-metal |
|---|---|---|
| Position | Left of the stepped line (and central block) | Right of the stepped line; hydrogen |
| Solid conducts? | Yes | No (except graphite) |
| Oxide | Basic: reacts with acid → salt + water; soluble ones give pH above 7 | Acidic: soluble ones give pH below 7 |

Decide from **all** the evidence; when conductivity and oxide disagree, think graphite.

Method for the oxide test: burn the element in oxygen; shake the oxide with water and add universal indicator, or add the oxide to a dilute acid and see whether it reacts.

## Groups and noble gases (1.23, 1.24)

Answer frames:

- **Same group, similar properties:** "Both have [n] electrons in the outer shell. Reactions involve outer-shell electrons, so they react in the same way."
- **Noble gas unreactive:** "Full outer shell of electrons. Stable arrangement, so no tendency to lose, gain or share electrons."
- **Helium in Group 0:** "Its outer (first) shell is full with 2 electrons."

Prediction rule: an element behaves like the others in its group (similar reactions, similar formulae of compounds, e.g. MgO → CaO; Na₂O → K₂O).

## Unfamiliar element: the five-step check

1. Find the group and period from the position (or from the configuration).
2. If it is one of the first 20, write the configuration: shells = period, outer electrons = group.
3. Left of the stepped line → metal: conducts, basic oxide. Right → non-metal: poor conductor, acidic oxide.
4. Compare with a familiar element in the same group to predict reactions and formulae.
5. Group 0 → full outer shell → unreactive, exists as single atoms.

Reminder: selenium is in Group 6 below sulfur, so it is a non-metal with an acidic oxide, like SO₂.

## Exam traps

- "Arranged by mass" — wrong; by atomic number.
- Potassium as 2,8,9; calcium as 2,8,10.
- Using group number for elements in the central block.
- "Same group" as the whole explanation for similar properties.
- "Noble gases have 8 outer electrons" — fails for helium.
- Classifying an element as a metal because it conducts, without checking the oxide.
- Mixing up groups (columns) and periods (rows).

## Self-test

1. State the property used to order the elements in the Periodic Table.
2. What do all the elements in Period 3 have in common?
3. Give the electronic configuration of sulfur (atomic number 16).
4. An element is in Group 1 and Period 4. Give its configuration and name it.
5. An atom has configuration 2,8,3. State its group and period.
6. An element in Period 2 has 7 outer electrons. Name it.
7. Is barium, in Group 2, a metal or a non-metal? How can you tell from its position?
8. An element's oxide dissolves in water to give pH 12. Classify the element.
9. Element X conducts electricity but its oxide forms an acidic solution. Suggest what X is.
10. Explain why fluorine and chlorine have similar chemical properties.
11. Explain why neon does not form compounds.
12. Magnesium forms magnesium chloride, MgCl₂. Predict the formula of the compound formed between calcium and chlorine, and explain your prediction.

### Answers

1. Atomic number.
2. Their atoms have three occupied electron shells.
3. 2,8,6.
4. 2,8,8,1; potassium.
5. Group 3, Period 3 (aluminium).
6. Fluorine (2,7).
7. A metal: Group 2 is on the left of the stepped line.
8. A metal (basic oxide giving an alkaline solution).
9. Carbon (graphite): a non-metal that conducts.
10. Both have 7 electrons in the outer shell (2,7 and 2,8,7); reactions involve outer-shell electrons.
11. It has a full outer shell (2,8), which is stable, so it does not lose, gain or share electrons.
12. CaCl₂: calcium is in the same group as magnesium, with the same number (2) of outer electrons, so it reacts in the same way.
