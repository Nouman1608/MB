Layout in Cambridge IGCSE ICT 0417 (Topic 13) covers creating and editing a document, placing objects such as images and charts with the right text wrapping, building and formatting tables, and using headers and footers with automated fields like page numbers. The syllabus notes that "document" here means any of the applications in sections 16 to 21, so these skills are tested across the practical tasks in Papers 2 and 3.

## Syllabus coverage

| Syllabus ref | You should be able to |
|---|---|
| 13.1 Create or edit a document | Enter and modify text and numbers with total accuracy; highlight, delete, move, cut, copy, paste, drag and drop; place objects (text, image, screenshot, shapes, table, graph or chart, spreadsheet extract, database extract); wrap text around a table, chart or image (above, below, square, tight) |
| 13.2 Tables | Create a table with a set number of rows and columns; place text or objects in it; insert and delete rows and columns; merge cells; set horizontal alignment (left, right, centre, fully justified) and vertical alignment (top, middle, bottom); show or hide gridlines; wrap text in a cell; shade cells; adjust row height and column width |
| 13.3 Headers and footers | Create or edit headers and footers; align contents to the left margin, right margin or centre; place text and automated objects (file information, page number, total pages, date, time). Know the purpose of headers and footers |

## 13.1 How do you create and edit a document accurately?

- **Total accuracy** means every character, space and number matches the source; examiners check text entry letter by letter.
- **Editing techniques**: highlight (select), delete, move, cut (remove and keep on the clipboard), copy (duplicate to the clipboard), paste, drag and drop.
- **Placing objects**: insert from a file or the clipboard — text, image, screenshot, shapes, table, graph or chart, spreadsheet extract, database extract.

### Text wrapping options

| Wrap | Effect |
|---|---|
| Above and below (top and bottom) | Text stops above the object and continues below it; nothing beside it |
| Square | Text wraps around the rectangular box of the object |
| Tight | Text follows the outline of the object itself, closer to its shape |

## 13.2 How do you work with tables?

| Skill | Key points |
|---|---|
| Create | Insert a table with the exact number of rows and columns given |
| Edit | Insert or delete rows/columns where instructed; merge cells (for example to make a title row across the whole table) |
| Horizontal alignment | Left, right, centre, fully justified |
| Vertical alignment | Top, middle, bottom of the cell |
| Gridlines | Show (visible borders) or hide them as instructed |
| Wrap text in a cell | Text moves to a new line within the cell instead of widening it |
| Shading | Fill a cell or row with a colour or shade, often for a header row |
| Size | Adjust row height and column width so that all data is visible and fits the page |

## 13.3 What are headers and footers for?

**Purpose**: a header or footer appears in the top or bottom margin of **every page** (or every page of a section), so information such as page numbers, the title, the author, the file name and the date is shown consistently without being typed on each page. It helps readers navigate a document and identify printouts.

### Automated objects

| Field | Why use it |
|---|---|
| File information (file name and path) | Identifies where the document is saved |
| Page number | Updates automatically if pages are added or removed |
| Total number of pages | Lets you show "Page 3 of 10" |
| Date | Shows when the document was created or printed |
| Time | Shows when it was printed or saved |

**Alignment**: header and footer items can be placed at the left margin, centred within the margins or at the right margin. Keep the same alignment on every page. A common instruction is "page number centred in the footer, file name right-aligned in the header".

## Worked example: following a layout instruction

*Instruction: "Insert a table with 4 columns and 6 rows. Merge the cells in the top row. Centre the title in that row. Shade the top row light grey. Right-align the numbers in column 4. Hide the gridlines."*

Steps: insert a 4 × 6 table → select row 1 → merge cells → type the title → align centre → apply grey shading → select column 4 data cells → align right → remove borders/gridlines. Check: 4 columns, 6 rows (including the merged top row), shading only on row 1.

## Common mistakes and exam traps

- Typing errors in data entry — a single wrong letter or extra space can lose the accuracy mark.
- Creating the wrong number of rows or columns, or forgetting the header row when counting.
- Typing the page number by hand instead of inserting an automated field, so it does not update.
- Placing the footer item at the wrong side, or aligning it differently on different pages.
- Using square wrap when "tight" or "above and below" was asked.
- Leaving text cut off in a cell instead of wrapping it or widening the column.

## Frequently asked questions

**What is the difference between square and tight text wrapping?**
Square wrapping flows the text around the rectangular boundary of the object. Tight wrapping follows the actual outline of the object, so text sits closer to its shape.

**Why use an automated page number rather than typing it?**
An automated field updates itself when pages are added, removed or moved, so numbering stays correct. A typed number would have to be changed by hand on every page.

**What does merging cells do?**
Merging joins two or more neighbouring cells into a single cell, often to create a title across the top of a table.

**Do headers and footers apply only to word processing?**
No. In 0417 they are used in documents, database reports, presentations and spreadsheets, which is why Topic 13 applies to sections 16 to 21.

## Self-test

1. Name the four text-wrapping options listed in the syllabus.
2. Give the four horizontal alignments for a table cell.
3. State two automated objects that can be placed in a footer.
4. State one purpose of a header.
5. Distinguish between cut and copy.

*Answers: 1 above, below, square, tight; 2 left, right, centre, fully justified; 3 any two of file information, page number, total pages, date, time; 4 shows the same information, such as title or author, on every page; 5 cut removes the original and stores it on the clipboard, copy leaves the original in place.*
