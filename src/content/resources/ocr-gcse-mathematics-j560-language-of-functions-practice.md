These questions follow OCR GCSE (9-1) Mathematics J560, Version 2.1 (August 2026), section 6.05, Language of functions. Questions 1 to 6 are for both tiers. Questions 7 to 13 use content that is **Higher tier only** and are labelled. As in the specification, no function notation is used: functions are given as machines or as equations in x and y. All questions can be answered without a calculator.

Learn the methods first in the [language of functions study guide](/resources/ocr-gcse-mathematics-j560-language-of-functions/) or the [language of functions revision notes](/resources/ocr-gcse-mathematics-j560-language-of-functions-revision-notes/).

## Questions

### Section A: short questions

**1.** A function is y = 6x − 5.

**(a)** Draw a function machine for it. **[1]**

**(b)** Find the output when the input is 3. **[1]**

**2.** A machine subtracts 2, then squares, then multiplies by 3.

**(a)** Write an expression for the output y in terms of the input x. **[2]**

**(b)** Find the output when the input is −1. **[1]**

**3.** For the function y = 2(x + 7), find the input that gives an output of 30. **[2]**

**4.** A function is y = 12 − x².

**(a)** Find the outputs for the inputs 0, 1, 2 and 3. **[2]**

**(b)** Write down a different input that gives the same output as the input 3. **[1]**

**5.** Kai says that y = 5x + 1 and y = 5(x + 1) are the same function. Show that Kai is wrong. **[2]**

**6.** Machine M multiplies by 3 and then adds 4. Machine N adds 4 and then multiplies by 3. Show that, for any input, the output of N is always 8 more than the output of M. **[2]**

### Section B: structured questions

**7.** **(Higher tier only)** **(a)** Find the inverse of y = 5x − 3. **[2]**

**(b)** Check your answer by using the input 2. **[1]**

**8.** **(Higher tier only)** Find the inverse of y = (2x + 1)/3. **[3]**

**9.** **(Higher tier only)** Find the inverse of y = 7 − x/4. **[3]**

**10.** **(Higher tier only)** Function A is y = x − 4. Function B is y = x².

**(a)** Write an expression for the composite function "A then B". **[1]**

**(b)** Write an expression for the composite function "B then A". **[1]**

**(c)** Find the input for which "A then B" and "B then A" give the same output. **[3]**

**11.** **(Higher tier only)** Function A is y = 3x + 2. Function B is y = x/2 − 1.

**(a)** Show that the composite function "A then B" is y = 3x/2. **[2]**

**(b)** Find the inverse of "A then B". **[2]**

**(c)** Find the output of "B then A" when the input is 6. **[1]**

**12.** **(Higher tier only)** **(a)** Show that y = 6/x is its own inverse. **[2]**

**(b)** Is y = 6 − x its own inverse? Give a reason. **[1]**

**(c)** Use one input to show that y = x + 6 is not its own inverse. **[1]**

**13.** **(Higher tier only)** A function is y = x² + 1.

**(a)** Explain why this function has no single inverse when every number is allowed as an input. **[2]**

**(b)** The inputs are now restricted to x ≥ 0. Find the inverse. **[2]**

## Answers

**1. (a)** x → **×6** → **−5** → y [1]

**(b)** 6 × 3 − 5 = **13** [1] **[2]**

*Examiner insight:* Multiplication comes before subtraction in 6x − 5, so ×6 is the first box.

**2. (a)** (x − 2)² after the first two boxes [1]; **y = 3(x − 2)²** [1]

**(b)** (−1 − 2)² = 9, so 3 × 9 = **27** [1] **[3]**

*Examiner insight:* Writing 3x − 2² or 3(x² − 2) changes the order of the boxes. Build the expression one box at a time.

**3.** 2(x + 7) = 30, so x + 7 = 15 [1]; **x = 8** [1] **[2]**

*Examiner insight:* Undoing ×2 first and then −7 is the same as solving the equation. Check: 2 × 15 = 30.

**4. (a)** Outputs 12, 11, 8, 3: at least two correct [1]; all four correct [1]

**(b)** **x = −3** (since 12 − 9 = 3) [1] **[3]**

*Examiner insight:* Squaring gives the same result for 3 and −3. This is why some functions cannot be reversed without restricting the inputs.

**5.** For example, input 1: 5 × 1 + 1 = 6 [1]; 5(1 + 1) = 10, so the outputs differ and the functions are not the same [1] **[2]**

*Examiner insight:* One counter-example is enough to show two functions are different. Choose a simple input and show both outputs.

**6.** M gives 3x + 4 [1]; N gives 3(x + 4) = 3x + 12, and 3x + 12 − (3x + 4) = 8 [1] **[2]**

*Examiner insight:* "For any input" needs algebra, not a single number. Testing one input does not show it is always true.

**7. (a)** Reverse ×5, −3 to give +3, ÷5 [1]; **y = (x + 3)/5** [1]

**(b)** Input 2: 5 × 2 − 3 = 7, and (7 + 3)/5 = 2 [1] **[3]**

*Examiner insight:* The inverse must return the original input. If your check gives a different number, the order of the reversed boxes is usually wrong.

**8.** Swap: x = (2y + 1)/3 [1]; 3x = 2y + 1, so 2y = 3x − 1 [1]; **y = (3x − 1)/2** [1] **[3]**

*Examiner insight:* By machines: the original is ×2, +1, ÷3, so the inverse is ×3, −1, ÷2. Both methods give the same answer.

**9.** Swap: x = 7 − y/4 [1]; y/4 = 7 − x [1]; **y = 4(7 − x)**, or y = 28 − 4x [1] **[3]**

*Examiner insight:* Check with input 8: 7 − 2 = 5, and 28 − 4 × 5 = 8. A common error is y = 4(x − 7), which undoes "subtract from 7" as if it were "subtract 7".

**10. (a)** **y = (x − 4)²** [1]

**(b)** **y = x² − 4** [1]

**(c)** (x − 4)² = x² − 4 [1]; x² − 8x + 16 = x² − 4, so −8x = −20 [1]; **x = 2.5** [1] **[5]**

*Examiner insight:* Check: (2.5 − 4)² = 2.25 and 2.5² − 4 = 2.25. Expanding (x − 4)² as x² − 16 loses the middle term.

**11. (a)** (3x + 2)/2 − 1 [1]; = 3x/2 + 1 − 1 = 3x/2 [1]

**(b)** Swap: x = 3y/2, so 3y = 2x [1]; **y = 2x/3** [1]

**(c)** B gives 6/2 − 1 = 2; A gives 3 × 2 + 2 = **8** [1] **[5]**

*Examiner insight:* In part (a), substitute the whole of 3x + 2 for x in B. Dividing only the 3x by 2 is the usual slip.

**12. (a)** Swap: x = 6/y [1]; xy = 6, so y = 6/x, which is the original function [1]

**(b)** **Yes**: swapping gives x = 6 − y, so y = 6 − x again [1]

**(c)** For example, input 1 gives 7, but input 7 gives 13, not 1 [1] **[4]**

*Examiner insight:* A self-inverse function sends a to b and b back to a. A single input that fails to return is enough to disprove it.

**13. (a)** Two different inputs give the same output, for example 2 and −2 both give 5 [1]; so the reverse process would have two possible outputs for 5 and is not a function [1]

**(b)** Swap: x = y² + 1, so y² = x − 1 [1]; **y = √(x − 1)** (the positive root, since inputs were x ≥ 0) [1] **[4]**

*Examiner insight:* Restricting the inputs to x ≥ 0 removes the repeated outputs, so the reverse process is a function again.

## Where marks are usually lost

- Putting machine boxes in left-to-right order instead of the order of operations.
- Dropping brackets when writing an expression from a machine.
- Reversing the boxes without reversing their order.
- Treating "subtract from 7" as "subtract 7".
- Doing the two parts of a composite in the wrong order.
- Showing a general result with one number instead of algebra.
- Not checking an inverse with a simple input.
