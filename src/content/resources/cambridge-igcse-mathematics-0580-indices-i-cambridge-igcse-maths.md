This guide teaches subtopic **1.7 Indices I** from the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. Indices I works with **numbers**; the algebraic version is Indices II (2.4). The two tiers differ:

| Statement | Core (C1.7) | Extended (E1.7) |
|---|---|---|
| 1 Understand and use indices | positive, zero and negative integers | positive, zero, negative **and fractional** |
| 2 Understand and use the rules of indices | yes | yes |

Sections marked **Extended only** are not examined on Papers 1 and 3. Almost everything here can appear on the non-calculator papers, so the methods are written to work without one.

Use it with the [Indices I revision notes](/resources/cambridge-igcse-mathematics-0580-indices-i-cambridge-igcse-maths-revision-notes/) and the [Indices I practice questions](/resources/cambridge-igcse-mathematics-0580-indices-i-cambridge-igcse-maths-practice/). Squares, cubes and roots are covered in [powers and roots](/resources/cambridge-igcse-mathematics-0580-powers-and-roots-cambridge-igcse-maths/), and the algebraic rules in the [algebraic fractions and indices II guide](/resources/igcse-mathematics-0580-algebraic-fractions-and-indices-ii/).

## Base and index

In 5⁴, 5 is the **base** and 4 is the **index** (power or exponent). The index says how many times the base is used as a factor: 5⁴ = 5 × 5 × 5 × 5 = 625.

## Zero and negative indices

Follow a pattern of powers of 3. Each step down divides by 3.

```
3³  = 27
3²  = 9
3¹  = 3
3⁰  = 1        (3 ÷ 3)
3⁻¹ = 1/3      (1 ÷ 3)
3⁻² = 1/9      (1/3 ÷ 3)
```

So for any non-zero number a:

- **a⁰ = 1**
- **a⁻ⁿ = 1/aⁿ**: a negative index means "one over", not a negative number.

**Fractions and decimals with negative indices.** Turn the fraction upside down and make the index positive.

```
(2/5)⁻² = (5/2)² = 25/4 = 6¼
0.5⁻¹   = (1/2)⁻¹ = 2
10⁻³    = 1/1000 = 0.001
```

**Worked example 1 (Core).** Find the value of (a) 5⁻², (b) 4⁰ + 4⁻¹, (c) (1/3)⁻³.

```
(a) 1/5² = 1/25
(b) 1 + 1/4 = 1¼
(c) 3³ = 27
```

## The rules of indices

For the **same base**:

| Rule | In words | Example |
|---|---|---|
| aᵐ × aⁿ = aᵐ⁺ⁿ | multiply: add the indices | 2⁵ × 2⁻³ = 2² = 4 |
| aᵐ ÷ aⁿ = aᵐ⁻ⁿ | divide: subtract the indices | 7² ÷ 7⁵ = 7⁻³ = 1/343 |
| (aᵐ)ⁿ = aᵐⁿ | power of a power: multiply | (6⁻¹)² = 6⁻² = 1/36 |

These only combine powers of the **same** base: 2³ × 3² is 8 × 9 = 72, not 6⁵.

**Worked example 2 (Core).** Find the value of (a) 2⁵ × 2⁻⁸ ÷ 2⁻⁴, (b) (5²)⁻¹ × 5³, (c) 10⁴ ÷ 10⁶ × 10⁻¹.

```
(a) 5 + (−8) − (−4) = 1          2¹ = 2
(b) 5^(−2) × 5³ = 5^(−2 + 3) = 5¹ = 5
(c) 4 − 6 + (−1) = −3            10⁻³ = 0.001
```

Subtracting a negative index adds it: in (a), −(−4) = +4. Writing the index arithmetic on its own line makes sign slips easier to see.

## Rewriting with a common base

When the bases differ but are powers of the same number, rewrite first.

| Number | As a power of 2 | As a power of 3 | As a power of 5 |
|---|---|---|---|
| 4, 8, 16, 32 | 2², 2³, 2⁴, 2⁵ | | |
| 9, 27, 81 | | 3², 3³, 3⁴ | |
| 25, 125 | | | 5², 5³ |
| 1/8 | 2⁻³ | | |
| 1/27 | | 3⁻³ | |

**Worked example 3 (Core).** Write each as a single power of 3, then find its value where asked.

(a) 9² × 27 (b) 81 ÷ 3⁶ (find the value) (c) 1/9 as a power of 3

```
(a) (3²)² × 3³ = 3⁴ × 3³ = 3⁷
(b) 3⁴ ÷ 3⁶ = 3⁻² = 1/9
(c) 1/9 = 1/3² = 3⁻²
```

**Worked example 4 (Core): comparing values.** Write these in order of size, smallest first: 2⁻³, 3⁻², 0.2⁻², 7⁰

```
2⁻³  = 1/8 = 0.125
3⁻²  = 1/9 = 0.111...
0.2⁻² = (1/5)⁻² = 5² = 25
7⁰   = 1
Order: 3⁻², 2⁻³, 7⁰, 0.2⁻²
```

A negative index on a number between 0 and 1 gives a value greater than 1, so 0.2⁻² is the largest. Evaluating each power first is safer than comparing the indices, because the bases differ.

## Fractional indices (Extended only)

A unit-fraction index is a root:

- a^(1/2) = √a, a^(1/3) = ∛a, a^(1/n) = the nth root of a

A general fraction combines a root and a power. Take the **root first** (denominator), then the **power** (numerator), to keep the numbers small:

- a^(m/n) = (ⁿ√a)ᵐ

A negative fractional index adds "one over".

**Worked example 5 (Extended only).** Find the value of

(a) 49^(1/2) (b) 1000^(2/3) (c) 27^(−2/3) (d) (4/9)^(3/2) (e) 32^0.4

```
(a) √49 = 7
(b) ∛1000 = 10, then 10² = 100
(c) ∛27 = 3, 3² = 9, then one over: 1/9
(d) √(4/9) = 2/3, then (2/3)³ = 8/27
(e) 0.4 = 2/5: fifth root of 32 = 2, then 2² = 4
```

In (e), change the decimal index to a fraction first. In (c), the minus sign affects only "one over"; it does not make the answer negative.

**Combining the rules (Extended only).** Find 8^(1/3) × 4^(−3/2).

```
8^(1/3) = 2
4^(−3/2) = 1/(√4)³ = 1/8
2 × 1/8 = 1/4
```

Alternatively, as powers of 2: 2¹ × 2⁻³ = 2⁻² = 1/4.

## Using a calculator (Papers 3 and 4)

- Enter negative indices with the negative key, not the subtraction key, and use brackets for fractional indices: 27^(−2/3), not 27^−2/3, which a calculator may read as 27⁻² ÷ 3.
- A calculator answer to a non-calculator style question is still worth checking by the rules: 2⁻³ should be 0.125.

## Common errors

- Writing 5⁻² = −25 or −10: a negative index gives a reciprocal.
- Writing 4⁰ = 0 or 4: any non-zero number to the power 0 is 1.
- Multiplying the indices when multiplying numbers (2³ × 2⁴ = 2¹²).
- Combining different bases: 2³ × 3² ≠ 6⁵.
- (Extended) Treating 16^(1/2) as 16 ÷ 2 = 8 instead of √16 = 4.
- (Extended) Doing the power before the root on large numbers, which gives big numbers that are hard to root without a calculator.

## Exam technique

- **Find the value of**: give an exact number; a fraction such as 1/25 is exact, and 0.04 is also accepted when exact.
- **Write as a single power of 2**: the answer is 2 to some index, not a value.
- **Simplify** a numerical expression with indices: show the index arithmetic (5 − 8 + 4 = 1).
- Use a fraction rather than a rounded decimal for reciprocals such as 1/9.

## Frequently asked questions

**Is 0⁰ examined?**
No. The rule a⁰ = 1 is for non-zero a, and questions in this subtopic use non-zero bases.

**Are fractional indices needed for Core?**
No. In 0580, fractional indices appear only in the Extended statement E1.7. Core candidates use positive, zero and negative integer indices.
