These notes condense subtopic **1.3 Powers and roots** of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. Core (C1.3) and Extended (E1.3) are identical, so every line is for both tiers. For worked examples, use the [powers and roots study guide](/resources/cambridge-igcse-mathematics-0580-powers-and-roots/); to test yourself, use the [powers and roots practice questions](/resources/cambridge-igcse-mathematics-0580-powers-and-roots-practice/).

## Must recall (no calculator)

**Squares and square roots, 1 to 15**

```
1² = 1     6² = 36     11² = 121
2² = 4     7² = 49     12² = 144
3² = 9     8² = 64     13² = 169
4² = 16    9² = 81     14² = 196
5² = 25   10² = 100    15² = 225
```

**Cubes and cube roots of 1, 2, 3, 4, 5 and 10**

```
1³ = 1    2³ = 8    3³ = 27    4³ = 64    5³ = 125    10³ = 1000
```

**Useful extras (work out if needed):** 2⁴ = 16, 2⁵ = 32, 2¹⁰ = 1024, 3⁴ = 81, 6³ = 216, 10⁶ = 1 000 000.

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Square | n × n | 12² = 144 |
| Square root | Positive number whose square is given | √144 = 12 |
| Cube | n × n × n | (−2)³ = −8 |
| Cube root | Number whose cube is given | ∛(−8) = −2 |
| Power (index) | How many times the base is used as a factor | 3⁴ = 3 × 3 × 3 × 3 |
| nth root | Number whose nth power is given | fourth root of 16 = 2 |

## Rules that save marks

| Situation | Rule | Example |
|---|---|---|
| Negative squared | Positive | (−6)² = 36 |
| Negative cubed | Negative | (−6)³ = −216 |
| Square root of a negative | Not a real number | √(−9) has no value |
| Cube root of a negative | Negative | ∛(−64) = −4 |
| Decimal squared | Double the decimal places | 0.07² = 0.0049 |
| Decimal cubed | Treble the decimal places | 0.1³ = 0.001 |
| Square root of a decimal | Halve the decimal places | √0.0036 = 0.06 |
| Fraction | Apply to top and bottom | √(16/121) = 4/11 |
| Mixed number | Make improper first | (1½)² = (3/2)² = 9/4 |
| Root of a sum | Add first, then root | √(9 + 16) = √25 = 5 |
| Powers of 10 | Count zeros | 10⁴ = 10 000; √1 000 000 = 1000 |

## Worked reminders

```
(√144 + ∛8)² − 10³ = (12 + 2)² − 1000 = 196 − 1000 = −804
```

```
√(4 × 25) = √100 = 10      (a root of a product can be split: 2 × 5)
√(16 + 9) = √25 = 5        (a root of a sum cannot: not 4 + 3)
```

```
A cube has volume 0.125 m³.
125 = 5³ and 3 d.p. -> 1 d.p., so the edge is ∛0.125 = 0.5 m
```

## Estimating roots

```
Find the square (or cube) numbers either side.
√90:   81 < 90 < 100   ->  9 < √90 < 10   (nearer 9: about 9.5)
∛100:  64 < 100 < 125  ->  4 < ∛100 < 5   (nearer 5: about 4.6)
```

## Calculator keys and checks (Papers 3 and 4)

- Square: x² key. Cube: x³ key, or the power key with 3.
- Other powers: the power key (xʸ, ^ or xⁿ depending on the model).
- Square root and cube root keys; other roots with the x-th root key or by raising to 1 ÷ n (fifth root = power 0.2).
- Put a negative base in brackets: (−4)² = 16, but −4² is read as −(4²) = −16.
- Cover the **whole** expression with the root sign: √(5.2² + 3.9²), not √5.2² + 3.9².
- Estimate first: 9.8³ should be close to 1000.

## Exam traps

- 0.4² is 0.16, not 1.6 or 0.8.
- √0.4 is about 0.632, not 0.2 (0.2² = 0.04).
- √(a + b) is not √a + √b.
- "Write down" means recall: no working is expected, but there is no method mark either.
- "Write down all the figures on your calculator display" means no rounding at all.
- (−1) to an even power is 1; to an odd power is −1.

## Quick self-test

1. Write down √169.
2. Write down ∛64.
3. Work out 15² − 14².
4. Work out ∛1000 × √49.
5. Work out (−5)³.
6. Work out 0.6².
7. Work out √0.0081.
8. Work out √(1 11/25).
9. Between which two consecutive integers does √200 lie?
10. (calculator) Work out 1.05⁸, correct to 3 significant figures.
11. (calculator) Work out the fourth root of 500, correct to 3 significant figures.
12. (calculator) Work out √(12.5² − 3.5²).

2. 4

4. 10 × 7 = 70
5. −125
6. 0.36
7. 0.09

10. 1.477 455… = 1.48

12. √(156.25 − 12.25) = √144 = 12

## Where marks are usually lost

- Not knowing 13², 14² and 15² quickly on the non-calculator papers.
- Decimal place errors with squares and roots of decimals.
- Losing the negative sign on a cube or cube root.
- Rooting each term of a sum separately.
- Rounding mid-calculation, so a 3 s.f. answer is wrong in the last digit.
