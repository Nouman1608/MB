## Section A

**1.** Let f(x) = 3x² − 2x.

**(a)** Find f(−2). **[1]**
**(b)** Find and simplify f(a + 1). **[2]**

**2.** Write down the largest possible domain of each function.

**(a)** f(x) = √(2x − 6) **[1]**
**(b)** g(x) = 1/(x + 5) **[1]**
**(c)** h(x) = ln(4 − x) **[1]**

**3.** Find the range of f(x) = x² − 4 for −1 ≤ x ≤ 3. **[2]**

**4.** For each relation, state whether y is a function of x, giving a reason.

**(a)** y² = x **[1]**
**(b)** y = x³ − x **[1]**

**5.** The graph of y = f(x) passes through (−1, 6) and (2, 0). Write down:

**(a)** f⁻¹(6) **[1]**
**(b)** f⁻¹(0). **[1]**

**6.** Let f(x) = x³ + x − 3. Find f⁻¹(7). **[2]**

## Section B

**7.** Let g(x) = 4 − √(x + 1).

**(a)** Write down the largest possible domain of g. **[1]**
**(b)** Find the range of g. **[2]**
**(c)** Solve g(x) = 1. **[2]**
**(d)** Hence write down g⁻¹(1). **[1]**

**8.** A ball is thrown upwards from a cliff. Its height above the sea after t seconds is modelled by h(t) = 20 + 15t − 5t² metres, until it reaches the sea.

**(a)** Find the time at which the ball reaches the sea. **[2]**
**(b)** Write down a suitable domain for the model. **[1]**
**(c)** Find the maximum height of the ball. **[2]**
**(d)** Write down the range of h for this domain. **[1]**

**9.** Let f(x) = (x − 3)², x ∈ ℝ.

**(a)** Explain why f does not have an inverse. **[2]**
**(b)** The domain of f is restricted to x ≥ k so that the inverse exists. Write down the least value of k. **[1]**
**(c)** With this domain, state the domain and range of f⁻¹. **[2]**

**10.** A function f is increasing, has domain −2 ≤ x ≤ 4 and range 1 ≤ f(x) ≤ 9, and f(0) = 3.

**(a)** Write down the domain and range of f⁻¹. **[2]**
**(b)** Write down f⁻¹(3). **[1]**
**(c)** The graph of f passes through (−2, 1) and (4, 9). Write down two points on the graph of f⁻¹. **[2]**
**(d)** Write down the equation of the line in which the graph of f must be reflected to give the graph of f⁻¹. **[1]**

**11.** (calculator allowed) In this invented context, a printer charges C(n) = 40 + 2.5n dollars for n posters, where n ∈ ℤ and 1 ≤ n ≤ 200.

**(a)** Find C(80). **[1]**
**(b)** Explain why the domain contains only integers. **[1]**
**(c)** Write down the least and greatest values in the range of C. **[2]**
**(d)** A customer pays $315. Find the number of posters and state what this value represents in terms of C⁻¹. **[2]**

**12.** Let f(x) = x² + 6x + 5, x ≥ −3.

**(a)** By writing f(x) in the form (x + p)² + q, find the range of f. **[2]**
**(b)** Explain why f⁻¹ exists. **[1]**
**(c)** Solve f(x) = 12 for x ≥ −3. **[2]**
**(d)** Hence write down f⁻¹(12). **[1]**

## Answers

**1. (a)** 3(4) + 4 = **16** [1]
**(b)** 3(a + 1)² − 2(a + 1) = 3a² + 6a + 3 − 2a − 2 [1] = **3a² + 4a + 1** [1]

**2. (a)** 2x − 6 ≥ 0: **x ≥ 3** [1]
**(b)** **x ≠ −5** [1]
**(c)** 4 − x > 0: **x < 4** [1]

**3.** The minimum is at the vertex (0, −4), inside the domain, and the maximum is f(3) = 5 [1]. Range **−4 ≤ f(x) ≤ 5** [1]
*Examiner insight:* f(−1) = −3 is not the minimum; the end-point-only answer −3 ≤ f(x) ≤ 5 scores 0.

**4. (a)** **Not a function:** x = 4 gives y = 2 and y = −2 [1]
**(b)** **A function:** each x gives exactly one value of x³ − x [1]

**5. (a)** **−1** [1]
**(b)** **2** [1]

**6.** Solve x³ + x − 3 = 7, so x³ + x = 10 [1]. x = 2 works (8 + 2 = 10), so **f⁻¹(7) = 2** [1]

**7. (a)** **x ≥ −1** [1]
**(b)** √(x + 1) takes all values ≥ 0 [1], so **g(x) ≤ 4** [1]
**(c)** √(x + 1) = 3 [1], so x + 1 = 9 and **x = 8** [1]
**(d)** **g⁻¹(1) = 8** [1]

**8. (a)** 5t² − 15t − 20 = 0, so t² − 3t − 4 = (t − 4)(t + 1) = 0 [1]; t ≥ 0 so **t = 4 s** [1]
**(b)** **0 ≤ t ≤ 4** [1]
**(c)** h(t) = −5(t − 1.5)² + 31.25, maximum at t = 1.5 [1]; maximum height **31.25 m** [1]
**(d)** **0 ≤ h ≤ 31.25** [1]
*Examiner insight:* The range is not 20 ≤ h ≤ 31.25: the ball falls below the cliff top to the sea, so the least height is 0.

**9. (a)** f is not one-to-one [1]: for example f(1) = f(5) = 4 [1]
**(b)** **k = 3** [1]
**(c)** Domain of f⁻¹: **x ≥ 0** [1]; range of f⁻¹: **f⁻¹(x) ≥ 3** [1]

**10. (a)** Domain **1 ≤ x ≤ 9** [1]; range **−2 ≤ f⁻¹(x) ≤ 4** [1]
**(b)** **0** [1]
**(c)** **(1, −2)** [1] and **(9, 4)** [1]
**(d)** **y = x** [1]

**11. (a)** 40 + 2.5(80) = **$240** [1]
**(b)** n counts posters, so only whole numbers make sense [1]
**(c)** Least C(1) = **42.5** [1]; greatest C(200) = **540** [1]
**(d)** 40 + 2.5n = 315 gives **n = 110** [1]; this is **C⁻¹(315) = 110** [1]

**12. (a)** f(x) = (x + 3)² − 4 [1], so the range is **f(x) ≥ −4** [1]
**(b)** On x ≥ −3, f is increasing, so it is one-to-one [1]
**(c)** (x + 3)² = 16, so x + 3 = ±4 [1]; x ≥ −3 requires x + 3 = 4, so **x = 1** [1]
**(d)** **f⁻¹(12) = 1** [1]

## Where marks are usually lost

- Range read from end points, missing a turning point inside the domain, as in questions 3 and 8.
- Strict and non-strict inequalities swapped at end points.
- Keeping both roots in question 12(c) when the domain rules one out.
- Swapping only the domain, not the range, when describing f⁻¹.
- A model domain that ignores the context, such as negative times.
