These questions cover section 3.6.1 Cyber security threats of the OxfordAQA International GCSE Computer Science
(9210) specification, including social engineering and malicious code.

---

## Section A

**1.** State what is meant by cyber security. **[2]**

**2.** State what is meant by social engineering. **[1]**

**3.** Name the type of social engineering described in each situation.

**(a)** A caller pretends to be from the IT department and asks a teacher for their password. **[1]**

**(b)** A person watches a customer enter a PIN at a cash machine. **[1]**

**(c)** An email with a link to a fake bank website asks a customer to log in. **[1]**

**(d)** A user types the correct address of a website but is sent to a fake copy of the site. **[1]**

**4.** State what is meant by malware. **[1]**

## Section B

**5.** Describe the difference between a computer virus and a trojan. **[3]**

**6.** Name the type of malware described in each statement.

**(a)** It records what a user types and sends the information to an attacker. **[1]**

**(b)** It displays unwanted adverts and may track a user's browsing. **[1]**

**(c)** It looks like a useful program but contains hidden malicious code. **[1]**

**7.** A student receives an email that says, "Your account will be closed today unless you click here and enter your
details." Describe three features of the email that suggest it is phishing. **[3]**

**8.** Explain why pharming can be harder for a user to notice than phishing. **[2]**

**9.** A router in a school office is still using the password that was set by the manufacturer.

**(a)** Explain why this is a cyber security threat. **[2]**

**(b)** State two features of a strong replacement password. **[2]**

**10.** A school gives every pupil permission to edit the staff folder on the network by mistake.

**(a)** State the term used for this type of threat. **[1]**

**(b)** Explain the possible consequences. **[2]**

**(c)** Describe how the school could reduce the threat. **[2]**

**11.** A company bans staff from plugging USB memory sticks into its computers. Explain two reasons for this
decision. **[4]**

**12.** A company has not installed security updates on a server for two years. Explain why this is a threat. **[3]**

**13.** Describe how an organisation can protect its staff from social engineering. **[3]**

**14.** A bank hires a company to carry out penetration testing on its systems.

**(a)** Explain what is meant by penetration testing. **[2]**

**(b)** Describe two types of penetration test. **[4]**

**(c)** State one benefit of the bank carrying out penetration testing. **[1]**

## Answers

**1.** The processes, practices and technologies [1] designed to protect networks, computers, programs and data from
attack, damage or unauthorised access [1].

**2.** Manipulating people so that they give up confidential information [1].

**3.** **(a)** Blagging (pretexting) [1]. **(b)** Shouldering (shoulder surfing) [1]. **(c)** Phishing [1]. **(d)** Pharming
[1].

**4.** An umbrella term for hostile or intrusive software [1] (software designed to harm a system or gain unauthorised
access).

**5.** A virus attaches itself to a file or program and copies itself into other files when the infected program is run
[1]; a trojan is disguised as genuine software and is installed by the user [1]; a trojan does not copy itself, whereas
a virus does [1].

**6.** **(a)** Spyware [1]. **(b)** Adware [1]. **(c)** Trojan [1].

**7.** Any three from: it creates a sense of urgency or a threat [1]; it asks the user to click a link and enter personal
details [1]; it uses a generic greeting [1]; it may have spelling or grammar mistakes [1]; the sender's address or the
link may not match the real organisation [1].

**8.** In phishing the user must be persuaded to click a link or open an attachment, which may look suspicious [1]; in
pharming the user types the correct address and is redirected without doing anything unusual, so the fake site looks
genuine [1].

**9.** **(a)** The default password is published or well known [1], so an attacker can use it to gain access to the
router and the network [1]. **(b)** Any two from: long [1]; a mixture of upper and lower case letters, numbers and
symbols [1]; no personal information or common words [1]; not used for other accounts [1].

**10.** **(a)** Misconfigured access rights [1]. **(b)** Pupils (or an attacker using a pupil's account) could read,
change or delete confidential staff data [1]; this could cause data loss or privacy problems [1].
**(c)** Give each user only the access they need [1]; review the access rights regularly and fix any that are wrong [1].

**11.** USB memory sticks can carry malware into the network [1], bypassing the network defences and firewall [1]; staff
could copy confidential data onto a stick and take it away [1], or lose the stick and expose the data [1] (any two
reasons, with explanations, for 4 marks).

**12.** Software contains vulnerabilities, which the maker fixes with patches [1]; without the updates the known
vulnerabilities are still present [1]; attackers know about these and can use them to gain access or install malware [1].

**13.** Train staff to recognise social engineering [1]; set procedures that require identity checks before information is
given, and tell staff never to give out passwords or codes [1]; use spam filters and anti-malware, and encourage staff
to report suspicious messages [1].

**14.** **(a)** Authorised people try to gain access to the bank's systems without the normal means of access [1]; the
aim is to find weaknesses before real attackers do [1].
**(b)** Test with knowledge of the system and possibly basic credentials [1], which simulates a malicious insider
attacking from inside the system [1]; test with no knowledge of any credentials [1], which simulates an external
attack [1].
**(c)** Any one: weaknesses can be found and fixed before they are exploited; it shows how much damage an attacker could do;
it tests whether security measures work [1].

---

## Where marks are usually lost

- Calling every type of malware a virus.
- Saying a trojan copies itself.
- Mixing up phishing and pharming.
- Not explaining why default passwords are a threat, in Question 9.
- Describing penetration testing as illegal hacking rather than authorised testing.
