## Section B: structured questions

**7.** A 14-page instruction manual is printed and stapled. The footer must show "Page *n* of 14" on each page.

**(a)** Explain **two** benefits to the reader of including the total number of pages. **[2]**

**(b)** A student types "Page 1 of 14" into the footer. Describe what will appear on page 6, and explain why. **[2]**

**(c)** Describe how the footer should have been created. **[2]**

**8.** A report is on A4 paper, 21 cm wide. The left and right margins are changed from 2.5 cm to 3.5 cm. The header has the title on the left, the date in the centre and the file name on the right, using the original tab stops.

**(a)** Calculate the new text width. **[1]**

**(b)** State where the centre and right tab stops should now be, measured from the left margin. **[2]**

**(c)** Explain what is likely to be wrong with the header if the tab stops are not moved. **[2]**

**9.** A finance officer prints a spreadsheet each week. The manager wants to know which week's version each printout is.

**(a)** Name **two** automated objects that should be placed in the spreadsheet's footer, and explain why each helps. **[4]**

**(b)** The officer adds the footer but cannot see it on screen. Explain why, and state how to check it. **[2]**

**10.** A presentation has a title slide and 15 content slides. The slide number and the school name must appear on every content slide but not on the title slide. Describe how this should be set up. **[3]**

**11.** A student's report has the title typed in the first line of page 1 and copied by hand to the top of every other page. Explain **two** disadvantages of this compared with using a header. **[2]**

**12.** Explain the difference between a report header and a page header in a database report, giving an example of suitable content for each. **[4]**

## Answers

**1.** An area in the top margin whose contents appear on every page (1). **[1]**

**2.** B: file path. **[1]**

**3.** Any two: identify the document on every page (1); page numbering to help navigation and keep pages in order (1); show the version through the date, time or file name (1); show where the file is stored (1); give a consistent, professional appearance (1). **[2]**

**4.** Left margin, right margin and centred within margins (1). **[1]**

**5.** So that it updates automatically and shows the time the document was printed or opened, not a fixed time (1). **[1]**

**6.** The page header (1). **[1]**

**7. (a)** The reader can check that no pages are missing from the stapled manual (1), and can see how far through the manual they are, which helps them find their place (1).

**(b)** "Page 1 of 14" will appear on page 6 (1), because typed text in a footer is repeated unchanged on every page; it is not a field that updates (1).

**(c)** Type "Page", insert the automated page number field (1), type "of", then insert the automated total number of pages field (1). **[6]**

**8. (a)** 21 - 3.5 - 3.5 = 14 cm (1).

**(b)** Centre tab stop at 7 cm (1); right tab stop at 14 cm (1).

**(c)** The original stops were set for a 16 cm text width, at 8 cm and 16 cm (1), so the date would be 1 cm right of centre and the file name would extend 2 cm beyond the right margin (1). **[5]**

**9. (a)** Any two, each with a reason: date (1), which shows the day the sheet was printed so the week can be identified (1); time (1), which separates two printouts made on the same day (1); file name (1), which shows which saved version was printed (1); file path (1), which shows where that version is stored (1).

**(b)** Headers and footers in a spreadsheet are not shown in the normal working view (1); check them in page layout view or print preview (1). **[6]**

**10.** Open the header and footer settings for the slides (1); turn on the slide number and enter the school name as footer text (1); select the option not to show them on the title slide, and apply to all slides (1). **[3]**

**11.** Any two: it takes longer, as the title must be typed or pasted on every page (1); if pages are added or text moves, the titles end up in the middle of pages (1); a change to the title must be made on every page, so some may be missed and become inconsistent (1). **[2]**

**12.** A report header appears once, at the start of the report (1), for example the report title or the date the report was produced (1). A page header appears at the top of every page of the report (1), for example the field headings for the columns of data, so they can be read on each page (1). **[4]**

## Frequently asked questions

**Is "centred within margins" the same as centred on the page?**
Only when the left and right margins are equal. If they differ, an item centred on the page will not be centred above the body text, so align it to the centre of the space between the margins.

**Do I need to know headers and footers in software other than word processors?**
Yes. The syllabus says "within a range of software packages", so expect spreadsheets, presentations and database reports as well.
