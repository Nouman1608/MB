This guide covers subtopic **3.2 Drawing linear graphs** in Topic 3, Coordinate geometry, of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027 series. A linear equation gives a straight-line graph. The syllabus asks you to draw straight-line graphs for linear equations, including equations written in different forms. The [Coordinate geometry revision notes](/resources/o-level-mathematics-coordinate-geometry-revision-notes/) summarise the whole topic. This page teaches three reliable methods for drawing a line, and the checks that make a graph accurate.

Companion pages: the [Drawing linear graphs revision notes](/resources/cambridge-o-level-mathematics-4024-drawing-linear-graphs-revision-notes/) and the [Drawing linear graphs practice questions](/resources/cambridge-o-level-mathematics-4024-drawing-linear-graphs-practice/).

## What the syllabus asks

The syllabus asks you to draw straight-line graphs for linear equations. Its examples are equations with a negative gradient, equations written with the y-term first or last, and equations in the form ax + by = c. You may be asked to draw the line on a grid that is already scaled, or to choose the scale yourself. Graph drawing can appear on either paper.

## What makes an equation linear?

A **linear equation** in x and y has only x and y to the first power. There are no x², y², xy or 1/x terms. Examples are y = 3x - 2, y = 4 - 3x, 2x + 3y = 12 and x - 2y = 6. All of these have straight-line graphs.

Two facts follow:

- Every point on the line has coordinates that make the equation true.
- Every point that makes the equation true lies on the line.

Because a straight line is fixed by two points, you need only two points to draw it. In practice, use **three** points: the third is a check. If the three do not line up, one of them is wrong.

## Method 1: a table of values

1. Choose at least three x-values. Include negative values, zero and positive values.
2. Substitute each x-value into the equation to find y.
3. Plot the points and join them with a ruler.

**Worked example.** Draw the graph of y = 3x - 2 for x from -2 to 3.

```
x:         -2   -1    0    1    2    3
y = 3x-2:  -8   -5   -2    1    4    7
```

Working for x = -2: y = 3(-2) - 2 = -6 - 2 = -8. The points are (-2, -8), (-1, -5), (0, -2), (1, 1), (2, 4) and (3, 7). Plot them, and draw a straight line through all six, extending a little beyond the end points.

**Worked example.** Draw the graph of y = 4 - 3x for x from -1 to 4.

```
x:        -1    0    1    2    3    4
y = 4-3x:  7    4    1   -2   -5   -8
```

This line goes **down** from left to right because the coefficient of x is negative. The equation y = 4 - 3x is the same as y = -3x + 4. The order of the terms does not matter.

The values of y change by the same amount each time x goes up by 1. In the first table, y rises by 3 each time. In the second, it falls by 3. If your row of y-values does not change by a steady amount, there is an error.

## Method 2: the intercept method

This method suits equations in the form ax + by = c. Find where the line crosses each axis.

- Put x = 0 to find the y-intercept.
- Put y = 0 to find the x-intercept.

**Worked example.** Draw the graph of 2x + 3y = 12.

```
x = 0:   3y = 12,  y = 4      the point (0, 4)
y = 0:   2x = 12,  x = 6      the point (6, 0)
```

Plot (0, 4) and (6, 0) and join them. For a check, choose x = 3:

```
2(3) + 3y = 12
6 + 3y = 12
y = 2
```

The point (3, 2) should lie on the line, and it does.

**Worked example.** Draw the graph of x - 2y = 6.

```
x = 0:  -2y = 6,  y = -3     the point (0, -3)
y = 0:   x = 6               the point (6, 0)
```

This line goes up from left to right.

If the intercepts are far apart or awkward fractions, add a point in the middle as well. For instance, when 5x + 2y = 7, the y-intercept is 3.5 and the x-intercept is 1.4, which are hard to plot accurately, so use integer points such as (1, 1) and (-1, 6).

## Method 3: rearrange to y = mx + c

Rearrange the equation to make y the subject. Then m is the gradient and c is the y-intercept (see the next subtopics). Use c as the starting point and m to step to other points.

```
x - 2y = 6
-2y = -x + 6
y = x/2 - 3
```

The line crosses the y-axis at -3. For each 2 units to the right, it rises 1. From (0, -3) we reach (2, -2), (4, -1) and (6, 0).

This method needs a little thought about fractions, but it gives the gradient without a table.

## Special lines

- **Horizontal lines**, y = k. Every point has y-value k. The line y = 3 is horizontal through (0, 3).
- **Vertical lines**, x = k. Every point has x-value k. The line x = -2 is vertical through (-2, 0).
- **Lines through the origin**, y = mx. Examples are y = 2x and y = -x. The point (0, 0) always lies on the line.
- The equation **y = x** passes through (0, 0), (1, 1), (2, 2) and so on. It makes equal angles with both axes.

## Checking whether a point lies on a line

Substitute the x- and y-values into the equation. If both sides are equal, the point is on the line.

**Worked example.** Does (4, 10) lie on y = 3x - 2? Does (-1, -4)?

```
(4, 10):   3(4) - 2 = 10   ✓  on the line
(-1, -4):  3(-1) - 2 = -5  ✗  -4 is not -5, so it is not on the line
```

## Reading information from a graph

Once a line is drawn, you can read values from it.

- To find y for a given x, go up (or down) from the x-value to the line and across to the y-axis.
- To find x for a given y, go across from the y-value to the line and down to the x-axis.
- The point where a line crosses the x-axis is where y = 0.

For y = 2x + 1, when y = 7: 2x + 1 = 7 gives x = 3. A graph reading should agree with this calculation.

### Where two lines cross

The coordinates of the point where two lines cross satisfy both equations. For y = x + 1 and y = 5 - x, a graph shows them crossing at (2, 3).

```
check: 2 + 1 = 3 ✓ and 5 - 2 = 3 ✓
```

This is called solving by graphs. It gives the solution of the simultaneous equations y = x + 1 and y = 5 - x.

## Drawing accurately

- **Scale**: choose a scale that uses most of the grid, with equal steps along each axis. Label the axes x and y, and number the scale at regular intervals.
- **Points**: mark each point with a small, neat cross. Plot to within half of a small square.
- **Line**: use a sharp pencil and a ruler. Extend the line through all the points and slightly beyond, with no gaps, and label it with its equation.
- **Table**: show the working for each y-value, or at least the table of values. This earns marks even if the graph is slightly off.

A line that is drawn as a "join the dots" zigzag, or a freehand curve, loses marks. A straight line graph must be a straight line.

## Exam technique

- Start with a table of values unless the equation is in the form ax + by = c, when the intercept method is faster.
- Use at least three points, and check that they line up.
- If the question gives the x-range, use all of it.
- Read the question to see whether it wants the line drawn or just points calculated.
- When you read a value from a graph, show the construction lines.

## Common mistakes

- Substituting wrongly with negative x-values, such as -3(-1) = -3 instead of 3.
- Putting x = 0 and y = 0 values in the wrong place when using intercepts.
- Plotting (x, y) the wrong way round.
- Drawing a line through points that do not line up, instead of finding the error.
- Using only two points and not noticing a slip.
- Drawing the line only between the plotted points and not extending it.
