## Section A

**1.** Give the formula of:

**(a)** copper(I) oxide, **[1]**

**(b)** iron(II) hydroxide. **[1]**

**2.** Define *reduction* in terms of oxygen. **[1]**

**3.** In the reaction PbO + C → Pb + CO, identify the substance oxidised and the substance reduced. **[2]**

**4.** *(Extended)* Deduce the oxidation number of:

**(a)** sulfur in H₂SO₄, **[1]**

**(b)** manganese in MnO₂, **[1]**

**(c)** chlorine in Cl₂. **[1]**

**5.** *(Extended)* Which of these is **not** a redox reaction?

A: Zn + 2HCl → ZnCl₂ + H₂

B: CuCO₃ → CuO + CO₂

C: 2Na + Cl₂ → 2NaCl

D: Cl₂ + 2NaBr → 2NaCl + Br₂ **[1]**

**6.** *(Extended)* Define a *reducing agent*. **[2]**

## Section B

**7.** In a blast furnace, iron(III) oxide reacts with carbon monoxide.

Fe₂O₃ + 3CO → 2Fe + 3CO₂

**(a)** Explain, in terms of oxygen, why this is a redox reaction. **[2]**

**(b)** *(Extended)* State the change in the oxidation number of iron and of carbon. **[2]**

**(c)** *(Extended)* Identify the reducing agent. **[1]**

**8.** *(Extended)* Zinc is added to aqueous silver nitrate.

Zn(s) + 2Ag⁺(aq) → Zn²⁺(aq) + 2Ag(s)

**(a)** Write the half-equation for the change to zinc. **[1]**

**(b)** Write the half-equation for the change to silver ions. **[1]**

**(c)** Explain, in terms of electrons, which species is oxidised and which is reduced. **[2]**

**(d)** Identify the oxidising agent. **[1]**

**9.** *(Extended)* A solution of sulfur dioxide is bubbled into acidified aqueous potassium manganate(VII).

**(a)** State the colour change. **[2]**

**(b)** State what this shows about sulfur dioxide. **[1]**

**10.** *(Extended)* Bromine water is added to aqueous potassium iodide.

Br₂ + 2I⁻ → 2Br⁻ + I₂

**(a)** Describe the colour change of the potassium iodide solution. **[1]**

**(b)** Use oxidation numbers to explain why this is a redox reaction. **[3]**

**(c)** Identify the oxidising agent and the reducing agent. **[2]**

**11.** *(Extended)* Iron(II) chloride solution reacts with chlorine.

2FeCl₂ + Cl₂ → 2FeCl₃

Explain why chlorine is described as an oxidising agent in this reaction. **[2]**

**12.** *(Extended)* A student says that the reaction between aqueous sodium hydroxide and dilute nitric acid is a redox reaction because ions react. Use oxidation numbers to show that the student is wrong. **[2]**

**13.** *(Extended)* Magnesium burns in oxygen: 2Mg + O₂ → 2MgO.

**(a)** Explain, in terms of electrons, why magnesium is oxidised. **[2]**

**(b)** Identify the oxidising agent and explain your choice using oxidation numbers. **[2]**

**14.** Copper(II) oxide is heated with powdered carbon: 2CuO + C → 2Cu + CO₂.

**(a)** State what is meant by the (II) in copper(II) oxide. **[1]**

**(b)** Explain, in terms of oxygen, which substance is reduced. **[2]**

## Answers

**1. (a)** Cu₂O [1].

**(b)** Fe(OH)₂ [1].

**2.** Loss of oxygen [1].

**3.** Oxidised: carbon (C) [1]; reduced: lead(II) oxide (PbO) [1].

**4. (a)** 2(+1) + S + 4(−2) = 0, so S = +6 [1].

**(b)** Mn + 2(−2) = 0, so Mn = +4 [1].

**(c)** 0 (uncombined element) [1].

**5.** **B** [1]. Cu stays +2, C stays +4, O stays −2.

**6.** A substance that reduces another substance [1] and is itself oxidised [1].

**7. (a)** Iron(III) oxide loses oxygen, so it is reduced [1]; carbon monoxide gains oxygen, so it is oxidised; both happen at once [1].

**(b)** Iron: +3 to 0 (decrease) [1]; carbon: +2 to +4 (increase) [1].

**(c)** Carbon monoxide (CO) [1].

**8. (a)** Zn → Zn²⁺ + 2e⁻ [1].

**(b)** Ag⁺ + e⁻ → Ag (accept 2Ag⁺ + 2e⁻ → 2Ag) [1].

**(c)** Zinc loses electrons, so zinc is oxidised [1]; silver ions gain electrons, so silver ions are reduced [1].

**(d)** Silver ions (Ag⁺) [1].

**9. (a)** Purple [1] to colourless [1].

**(b)** Sulfur dioxide is a reducing agent [1].

**10. (a)** Colourless to brown [1].

**(b)** Bromine: 0 to −1, a decrease, so bromine is reduced [1]; iodine: −1 to 0, an increase, so iodide is oxidised [1]; oxidation and reduction occur together, so it is redox [1].

**(c)** Oxidising agent: bromine (Br₂) [1]; reducing agent: iodide ions (I⁻) [1].

**11.** Chlorine oxidises iron(II) to iron(III) / iron's oxidation number increases from +2 to +3 [1]; chlorine is itself reduced, from 0 to −1 [1].

**12.** In NaOH + HNO₃ → NaNO₃ + H₂O: Na stays +1, O stays −2, H stays +1, N stays +5 [1]; no oxidation number changes, so it is not redox [1].

**13. (a)** Each magnesium atom loses two electrons [1] to form a Mg²⁺ ion; loss of electrons is oxidation [1].

**(b)** Oxygen (O₂) is the oxidising agent [1]; its oxidation number decreases from 0 to −2, so it is reduced while it oxidises magnesium [1].

**14. (a)** Copper has an oxidation number of +2 / the copper ion has a 2+ charge [1].

**(b)** Copper(II) oxide is reduced [1], because it loses oxygen (to form copper) [1].

## Where marks are usually lost

- Naming the oxidised substance as the oxidising agent.
- Writing "clear" instead of "colourless" for the manganate(VII) change.
- Giving oxidation numbers without signs, or forgetting to divide by the number of atoms.
- Defining an agent with only one of its two parts.
- Writing half-equations with electrons on the wrong side: oxidation releases electrons (right side); reduction uses them (left side).
- Assuming any reaction between ions is redox without checking oxidation numbers.
