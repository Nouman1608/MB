Subtopic 23.2 of Cambridge International AS & A Level Physics 9702 (2025–2027) covers the random and spontaneous nature of radioactive decay, activity, the decay constant, half-life and the exponential decay law. These notes are condensed for recall. For full explanations and worked examples, read the [Radioactive decay study guide](/resources/cambridge-a-level-physics-9702-a-radioactive-decay/); to apply the ideas, try the [Radioactive decay practice questions](/resources/cambridge-a-level-physics-9702-a-radioactive-decay-practice/).

## Equations

```
A = λN
λ = 0.693 / t½        (0.693 = ln 2)
x = x₀ e^(−λt)        x = N, A or received count rate
ln x = ln x₀ − λt      (straight line, gradient −λ)
N = (mass / molar mass) × N_A
```

## Definitions to learn word for word

| Term | Definition |
|---|---|
| Random | Cannot predict which nucleus will decay, or when; each nucleus has a constant probability of decay per unit time |
| Spontaneous | Not affected by external factors such as temperature, pressure or chemical state |
| Activity | The number of nuclei decaying per unit time; unit becquerel (Bq) = s⁻¹ |
| Decay constant | The probability that a nucleus will decay per unit time |
| Half-life | The time taken for the number of undecayed nuclei (or the activity) to fall to half its initial value |

## Evidence for randomness

- Count over many equal time intervals with a Geiger-Müller tube and counter.
- Readings **fluctuate** unpredictably about a mean value.
- The source's activity is effectively constant during the experiment, so the fluctuations come from the decay process itself.
- This experiment shows randomness only; spontaneity needs a test of external conditions.

## Shape of the decay curve

| Feature | Detail |
|---|---|
| Start | x₀ on the vertical axis |
| Equal steps | Halves in each half-life: x₀/2, x₀/4, x₀/8 |
| Gradient | Steep at first, becoming less steep |
| End | Approaches zero, never reaches it |
| Log plot | ln x against t: straight line, gradient −λ, intercept ln x₀ |

## Units checklist

- A in Bq needs λ in s⁻¹ (convert days or hours to seconds).
- For "how long" questions only, λ can stay in h⁻¹ or day⁻¹ if t is in the same unit.
- Mass in g with molar mass in g mol⁻¹ (or both in kg).

## Quick calculations

- Number of half-lives n in time t: fraction remaining = (½)ⁿ, n = t/t½.
- After 3 half-lives: ⅛ remains (12.5 %); after 5: 1/32 (about 3 %).
- t½ = 6.0 h: λ = 0.1155 h⁻¹; activity 800 Bq → 150 Bq takes 14.5 h.
- Corrected count rate = measured − background, every time.
- 1.0 μg, molar mass 131 g mol⁻¹, t½ = 8.0 days: N = 4.60 × 10¹⁵, A = 4.6 × 10⁹ Bq.

## Key terms

| Term | Meaning |
|---|---|
| Undecayed nucleus | A nucleus of the original (parent) isotope that has not yet decayed |
| Daughter nucleus | The nucleus produced by a decay |
| Count rate | Number of decays detected per unit time; a fraction of the activity |
| Background radiation | Radiation detected with no source present, from the surroundings |
| Becquerel | One decay per second |
| Exponential decay | Decrease by the same fraction in equal time intervals |

## Exam traps

- "Half-life is half the time it takes for all the nuclei to decay": wrong; the curve never reaches zero.
- "Half-life is the time for the mass to halve": the mass hardly changes because daughter nuclei remain.
- "Decay constant is the rate of decay": it is a probability per unit time.
- Using λ in day⁻¹ with N to find A in Bq.
- Forgetting background before taking ratios or logs.
- Using log₁₀ instead of ln when solving x = x₀e^(−λt).
- Confusing random (unpredictable) with spontaneous (unaffected by conditions).
- Quoting count rate equal to activity: a detector only catches a fraction of the emissions.

## Self-test

1. Define activity and state its unit.
2. Define the decay constant.
3. Define half-life.
4. What does "spontaneous" mean for radioactive decay?
5. Describe how fluctuations in count rate show that decay is random.
6. Show that λ = 0.693/t½.
7. A source has a half-life of 2.5 min and an initial activity of 5.0 × 10⁶ Bq. Calculate its activity after 6.0 min.
8. What fraction of a sample remains undecayed after four half-lives?
9. What graph gives a straight line for radioactive decay, and what is its gradient?
10. A detector reads 85 counts per minute; background is 25 counts per minute. What is the corrected count rate?
11. A sample has an activity of 3.7 × 10⁴ Bq and a decay constant of 7.3 × 10⁻¹⁰ s⁻¹. How many undecayed nuclei does it contain?
12. Why does a sample's activity fall over time?

**Answers:** 1. The number of nuclei decaying per unit time; becquerel (Bq). 2. The probability that a nucleus decays per unit time. 3. The time taken for the number of undecayed nuclei to fall to half its initial value. 4. It is not affected by external factors such as temperature or pressure. 5. Counts recorded in equal time intervals vary unpredictably about a mean, although the activity is effectively constant. 6. At t = t½, N = N₀/2, so ½ = e^(−λt½); ln 2 = λt½; λ = 0.693/t½. 7. λ = 0.693/2.5 = 0.277 min⁻¹; A = 5.0 × 10⁶ × e^(−0.277 × 6.0) = 9.5 × 10⁵ Bq. 8. (½)⁴ = 1/16. 9. ln(activity or count rate or N) against time; gradient = −λ. 10. 60 counts per minute. 11. N = A/λ = 3.7 × 10⁴ / 7.3 × 10⁻¹⁰ = 5.1 × 10¹³. 12. The number of undecayed nuclei falls, and A = λN with λ constant.
