These notes condense section 2.2 of the IB *Mathematics: analysis and approaches guide* (first assessment 2021): the concept of a function, domain, range and graph, function notation, functions as models, and the inverse function as a reversal and as a reflection in y = x. It is common to SL and HL. For full explanations use the [2.2 study guide](/resources/ib-dp-mathematics-analysis-and-approaches-2-2/); for exam-style questions use the [2.2 practice set](/resources/ib-dp-mathematics-analysis-and-approaches-2-2-practice/).

## Core recall

- A **function** gives exactly one output for every input in its domain.
- **Vertical line test:** at most one intersection for every vertical line means y is a function of x.
- **Domain:** allowed inputs. Default = largest set of real numbers where the rule works.
- **Range:** outputs that actually occur. Find it from a sketch over the domain.
- **Inverse:** f⁻¹ undoes f. f(a) = b ⇔ f⁻¹(b) = a.
- Solving f(x) = k is the same as finding f⁻¹(k).
- f⁻¹ exists only for a **one-to-one** function (horizontal line test).
- y = f⁻¹(x) is the reflection of y = f(x) in **y = x**.
- Domain of f⁻¹ = range of f; range of f⁻¹ = domain of f.

## Key terms

| Term | Meaning |
|---|---|
| Function | A rule giving one output for each input in its domain |
| Domain | Set of inputs |
| Range | Set of outputs |
| Function notation | f(x), v(t), C(n): name of the function and its input |
| Mapping notation | f: x ↦ 3x − 1 |
| Model | A function describing a real situation, with a domain set by the context |
| One-to-one | Each output comes from exactly one input |
| Inverse function f⁻¹ | The function that reverses f |
| Interval notation | [a, b] includes ends; ]a, b[ excludes them |

## Domain checklist

| Look for | Require |
|---|---|
| Fraction | Denominator ≠ 0 |
| Square root | Inside ≥ 0 |
| Logarithm | Inside > 0 |
| Context | Physical sense: lengths > 0, counts are integers, time ≥ 0 |

**Quick examples.**
- √(10 − 2x): domain x ≤ 5.
- 4/(x² − 9): domain x ≠ ±3.
- ln(x + 1): domain x > −1.

**Range checklist**

1. Sketch over the stated domain.
2. Find turning points inside the domain.
3. Evaluate the end points of a restricted domain.
4. Note asymptotes: values approached but never reached are excluded.
5. Use ≤ when a value is reached and < when it is not.

**Quick example.** f(x) = 1 − x² on −2 ≤ x ≤ 1: f(−2) = −3, f(1) = 0, and the vertex (0, 1) lies inside the domain, so −3 ≤ f(x) ≤ 1.

## Functions as models

- The rule may allow more inputs than the situation does; the context sets the domain.
- Name the function after its input where helpful: B(t) for battery charge after t hours.
- An inverse value answers a "when" or "how many" question.

**Quick example.** A phone battery holds B(t) = 100 − 8t per cent, t hours after a full charge. The charge cannot be negative, so the domain is 0 ≤ t ≤ 12.5 and the range is 0 ≤ B ≤ 100. B⁻¹(20) = 10 is the time, in hours, at which 20% remains.

## Inverse facts without algebra

- From a point: (4, 11) on f gives (11, 4) on f⁻¹.
- From a value: f(2) = 9 gives f⁻¹(9) = 2.
- From sets: domain x ≥ 0 and range f(x) ≥ 2 for f give domain x ≥ 2 and range f⁻¹(x) ≥ 0 for f⁻¹.
- From the graph: reflect key points and asymptotes in y = x. A horizontal asymptote y = c becomes a vertical asymptote x = c.

## Exam traps

- Range taken from end points only when a turning point lies inside the domain.
- Wrong inequality direction for the domain of √(a − x).
- Using < where ≤ is correct (or the reverse) at an end point.
- f⁻¹(x) confused with 1/f(x).
- Claiming an inverse exists for a function that is not one-to-one.
- Allowing impossible values in a model, such as negative times or fractions of a person.

## Self-test

1. State the two conditions for a rule to be a function.
2. Find the domain of f(x) = √(5 − x).
3. Find the domain of g(x) = 3/(2x − 1).
4. Find the range of f(x) = x² + 3, x ∈ ℝ.
5. Find the range of f(x) = 2x − 1 for 0 ≤ x ≤ 4.
6. Does y² + x = 4 define y as a function of x? Give a reason.
7. Given f(5) = 2, write down f⁻¹(2).
8. The point (3, −1) lies on y = f(x). Write down a point on y = f⁻¹(x).
9. f has domain x ≥ 0 and range f(x) ≥ 2. State the domain and range of f⁻¹.
10. Is f(x) = x⁴, x ∈ ℝ, one-to-one? Give a reason.
11. Write 2 < x ≤ 7 in interval notation.
12. For f(x) = 4x − 3, solve f(x) = 9 and hence write down f⁻¹(9).

### Answers

1. Every input in the domain has an output, and no input has more than one output.
2. x ≤ 5
3. x ≠ 1/2
4. f(x) ≥ 3
5. −1 ≤ f(x) ≤ 7
6. No: x = 0 gives y = 2 and y = −2, two outputs for one input.
7. 5
8. (−1, 3)
9. Domain x ≥ 2; range f⁻¹(x) ≥ 0
10. No: f(−1) = f(1) = 1.
11. ]2, 7]
12. 4x − 3 = 9 gives x = 3, so f⁻¹(9) = 3.
