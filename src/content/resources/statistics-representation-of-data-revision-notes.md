## Excluded content — don't waste time on it

Drawing **pictograms** is not required. Identifying **outliers** from a box-and-whisker diagram is not
required. Cambridge deliberately scoped both out of this series — spend your time elsewhere.

## Diagram type — one-line "when to use it" lookup

| Diagram | Best for |
|---|---|
| Simple bar chart / pictogram | Quick visual comparison of categories |
| Sectional / percentage sectional bar chart, pie chart | When parts of a whole matter as much as the total |
| Comparative pie chart / multiple bar chart | Comparing two data sets side by side |
| Venn diagram | Data falling into overlapping categories |
| Box-and-whisker diagram | Summarising spread; comparing the middle 50% |
| Stem-and-leaf (incl. back-to-back) | Keeping individual data values visible |

## Two-way tables — the under-revised skill

Easy to overlook next to the visually memorable diagrams, but tested directly and independently.
A two-way table cross-tabulates **two variables at once** (e.g. travel method against gender).
Practise reading a specific row-and-column intersection, a row total, and a column total — all three
are tested separately.

## AO2 — justify, don't just name

Cambridge's AO2 (10-20% of both papers) specifically rewards **justifying the use of a specific
method** in a given situation. Practise comparing two named diagram types directly: why a
stem-and-leaf diagram preserves more detail than a grouped bar chart, but the bar chart is easier to
read at a glance for a large data set; why a pie chart shows proportion clearly but is harder than a
bar chart for comparing exact values between categories.

## Where the Topic 2/Topic 3 boundary sits

Topic 2 represents data that is still raw or lightly organised. Once data is grouped into class
intervals for a large data set, that becomes **Topic 3 (Frequency distributions)**, which introduces
histograms and frequency polygons as a separate step. Don't apply Topic 3's grouped-data techniques to
a Topic 2 question, or vice versa — this boundary is a common source of confusion.

## Worked scenario — choosing between diagrams

Suppose a class records how each of 30 students travels to school (walk, bus, car, bicycle). A simple
bar chart or pictogram shows how many students use each method at a glance. If the same data is also
broken down by gender, a sectional or multiple bar chart — or a comparative pie chart — lets a reader
see both the overall pattern and the split within it in one image. If instead the class records each
student's exact travel time in minutes, a stem-and-leaf diagram keeps every individual value visible,
which suits a small data set where no detail should be lost, while a box-and-whisker diagram becomes
more useful once you want to summarise the middle 50% of travel times and compare that spread against
another class's data. A Venn diagram would suit yet another question — for example, showing how many
students both cycle to school and also play a sport after school, where the two categories overlap
rather than being mutually exclusive. Practising this kind of "which diagram for which question"
reasoning, rather than only memorising each diagram's drawing method, is what actually earns AO2 marks.

## Where this topic sits in the wider syllabus

Both papers of 0479 are 2 hours 15 minutes, 100 marks, and equally weighted at 50% of the qualification
each, so a topic like this one — short on raw content but broad in application — can appear in either
paper, mixed alongside questions from any other topic. Topic 2's diagrams are also foundational to
almost everything that follows: frequency tables reappear when Topic 3 groups data into frequency
distributions, and the comparative skill practised here — reading and interpreting a chart, not just
drawing one — is tested throughout the whole syllabus, since any question may draw on content from any
topic.

## Exam traps

- Spending revision time drawing pictograms or identifying box-and-whisker outliers — both explicitly
  excluded.
- Treating a two-way table as a diagram-drawing skill rather than a table-reading skill.
- Naming a diagram type without being able to justify why it suits the given scenario over an
  alternative.
- Confusing Topic 2's raw-data diagrams with Topic 3's grouped-data techniques.

## Recall which sub-topic a data set belongs to

Topic 2 is deliberately about representing data that has already been collected (Topic 1) and is still
in its raw or lightly organised form. A candidate presented with a large data set that has been grouped
into class intervals should recognise this belongs to Topic 3 (Frequency distributions), which
introduces histograms and frequency polygons as a more advanced step beyond what Topic 2 requires.
Practise sorting a handful of example scenarios into "Topic 2" or "Topic 3" before the exam, since
misidentifying which stage of data handling a question is testing can lead to applying the wrong
technique entirely.

## Self-test

1. Name two diagram types explicitly excluded from this topic's requirements.
2. Which diagram type suits data with overlapping categories?
3. What does a two-way table cross-tabulate?
4. Which diagram type keeps every individual data value visible?
5. What does AO2 specifically reward on this topic?

**Answers:** 1. Pictogram drawing and box-and-whisker outlier identification. 2. Venn diagram. 3. Two
variables at once. 4. Stem-and-leaf diagram. 5. Justifying the use of a specific representation method
in a given situation.
