Topic 14 of Cambridge IGCSE ICT 0417 begins with the skill "Create, edit and apply styles". The syllabus says you should "create, modify, update and apply styles to ensure consistency of presentation", and it lists the settings a style may contain: "font including font face, type (serif, sans-serif), point size, colour"; "text alignment including left, right, centre, fully justified"; "text enhancement including bold, underline, italic"; "spacing including paragraph (before and after) and line"; and "bullets including shape, alignment, line spacing and indent". The [Styles study guide](/resources/cambridge-igcse-ict-styles-study-guide/) explains what styles are, style types and corporate house style. This guide works through the four actions the syllabus names and each listed setting in detail, so you can build a style that matches a specification exactly.

For quick recall use the [styles revision notes](/resources/cambridge-igcse-ict-0417-create-edit-and-apply-styles-t14-revision-notes/), and test yourself with the [styles practice questions](/resources/cambridge-igcse-ict-0417-create-edit-and-apply-styles-t14-practice/).

## The four actions: create, modify, update, apply

| Action | What you do | When |
|---|---|---|
| Create | Make a new named style and set its formatting | A task gives a new style name and its settings |
| Modify | Open an existing style's settings and change them | A task says to change a style, such as "change the Body style to 12 point" |
| Update | Format some text by hand, then update the style to match that text | You have formatted an example and want the style to copy it |
| Apply | Select text, or place the cursor in a paragraph, and choose the style | Every time text of that kind appears |

**Modify** and **update** both change a style, and every paragraph using it then changes too. The difference is the direction: modify changes the style first, and the text follows; update takes the formatting from the text and copies it into the style. If you update a style from a paragraph that has a stray setting, such as an accidental italic, that error spreads to every paragraph with the style, so check the example first.

Styles **ensure consistency** because every paragraph with the same style is formatted from one set of instructions. It is impossible for one heading to be 15 point and another 16 point if both use the same heading style.

## Font settings

### Font face and type

The **font face** is the named typeface, such as Arial or Times New Roman. The syllabus groups faces into two **types**:

| Type | Feature | Examples | Common use |
|---|---|---|---|
| Serif | Small strokes (serifs) at the ends of letter lines | Times New Roman, Georgia | Long printed text, such as books and reports |
| Sans-serif | No serifs; plain line ends | Arial, Calibri, Verdana | Headings, on-screen text, signs, text for young readers |

Some tasks name a face; others only give a type, such as "a serif font". In that case, any serif face is correct, but use the same face everywhere the instruction applies.

### Point size

Font size is measured in **points**; 72 points make one inch. Body text is commonly 10 to 12 point, and headings larger. Enter the exact size given; do not judge by eye.

### Colour

Set the font colour named in the task. If a specific colour is named, such as dark blue, choose that exact colour from the palette rather than a similar shade, and make sure the same shade is used in every style that asks for it.

## Text alignment

| Alignment | Effect |
|---|---|
| Left | Straight left edge, ragged right edge; easiest to read for most body text |
| Right | Straight right edge, ragged left edge; used for dates or addresses in some layouts |
| Centre | Each line centred between the margins; used for titles |
| Fully justified | Both edges straight; spaces between words are stretched, used in columns and formal documents |

## Text enhancement

**Bold**, **underline** and *italic* are the three enhancements named. They can be combined, such as bold and italic. Use them for emphasis sparingly: if a style for warnings is bold and red, the warnings stand out only because the rest of the text is not.

## Spacing

### Paragraph spacing: before and after

**Spacing before** adds space above a paragraph; **spacing after** adds space below it. Both are measured in points. For example, a heading style might have 12 pt before and 6 pt after, so the heading is closer to the text it introduces than to the text above.

Using paragraph spacing is better than pressing Enter to make blank lines, because the space is exact, is the same throughout and is part of the style, so it changes everywhere when the style is modified.

### Line spacing

**Line spacing** is the distance between lines **within** a paragraph. Common settings are single, 1.5 lines and double, or an exact value in points. Line spacing affects every line of a paragraph; paragraph spacing affects only the gap above or below the whole paragraph.

## Bullets

A bulleted list style can control four things, all named in the syllabus:

- **Shape**: the bullet symbol, such as a round dot, a square, an arrow or a tick.
- **Alignment**: where the bullet sits, measured from the margin.
- **Line spacing**: the spacing between the lines of the list items.
- **Indent**: how far the text is indented from the margin, often as a hanging indent so that the second line of an item lines up with the text and not with the bullet.

*Example specification:* "Square bullets aligned at 0 cm, text indented at 1 cm, 1.5 line spacing." The bullet sits at the margin, every line of text starts 1 cm in, and lines are 1.5 spaced.

## Worked example: building a style from a specification

*Instruction:* "Create a paragraph style called *Report-Body*: serif font, 11 point, black, fully justified, 6 pt spacing after, single line spacing. Apply it to all body text. Then modify *Report-Body* so that the line spacing is 1.5."

1. Open the new style dialog; enter the name *Report-Body* exactly, including the capital letters and hyphen.
2. Choose a serif font face, such as Times New Roman; set 11 point and black.
3. Set alignment to fully justified.
4. In paragraph settings, set spacing before 0 pt, after 6 pt, and line spacing single.
5. Save the style and apply it to every body paragraph.
6. Modify *Report-Body*: change the line spacing to 1.5. Every body paragraph updates at once.
7. Check one paragraph's settings to confirm that each value matches the instruction.

*Why it works:* because all body text uses one style, the final change takes one edit, and no paragraph is missed.

## Common mistakes

- Typing the style name differently from the instruction.
- Choosing a sans-serif font when the task says serif, or the reverse.
- Pressing Enter for space instead of setting spacing before or after.
- Confusing line spacing with paragraph spacing.
- Formatting text by hand and not applying the style, so later changes to the style do not reach it.
- Updating a style from text that contains an unwanted change.
- Setting the bullet indent but forgetting the text indent, so wrapped lines start under the bullet.

## Exam technique

In the practical papers, read the style specification as a checklist: name, font face or type, size, colour, alignment, enhancement, spacing before and after, line spacing, and any bullet settings. Tick off each one. In theory questions, **describe** a setting by saying what it changes on the page, and **explain** why styles are used by linking consistency to the scenario: "all 25 headings change together, so they stay identical".

## Check your understanding

1. What is the difference between modifying and updating a style? *Modify changes the style's settings directly; update copies the formatting of selected text into the style.*
2. Give an example of a sans-serif font. *Arial (or Calibri, Verdana).*
3. What does spacing after do? *Adds space below a paragraph.*
4. Name the four bullet settings listed in the syllabus. *Shape, alignment, line spacing and indent.*
