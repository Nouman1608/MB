Section 1.1 of Cambridge IGCSE ICT 0417 asks you to define hardware and software, name the internal components and other hardware the syllabus lists, classify software as applications or system software using the named examples, and explain the difference between analogue and digital data and why each conversion is needed.

## Two definitions to learn word for word

- **Hardware**: the physical components of a computer system.
- **Software**: programs for controlling the operation of a computer or the processing of electronic data.

## Hardware at a glance

- **CPU / processor**: executes program instructions and processes data.
- **Motherboard**: main circuit board; holds CPU and memory and connects all components.
- **RAM**: memory for programs and data in current use; read and write; volatile.
- **ROM**: holds start-up instructions; read only; non-volatile.
- **Graphics card**: processes image data and sends output to the monitor.
- **Sound card**: digital to analogue for speakers; analogue to digital from a microphone.
- **NIC**: connects the computer to a wired or wireless network.
- **Camera**: captures images as digital data.
- **Storage devices**: keep data permanently, internal or external.

## Software: which type is it?

| Applications software (solves the user's task) | System software (lets the computer operate) |
|---|---|
| Word processing | Compiler |
| Spreadsheet | Linker |
| Database management system | Device driver |
| Control and measurement software | Operating system |
| Applets and apps | Utilities |
| Video, graphics and audio editing | |
| Computer aided design (CAD) | |

### One-line jobs for the system software examples

- **Compiler**: translates a whole high-level program into machine code before it runs.
- **Linker**: joins separately compiled parts of a program into one executable program.
- **Device driver**: lets the operating system communicate with a specific hardware device.
- **Operating system**: manages hardware and software and provides the user interface.
- **Utilities**: maintenance tasks, such as anti-virus, backup, compression, formatting and defragmentation.

### Control versus measurement software

Measurement software **records** sensor readings over time for later analysis. Control software **acts** on sensor readings by switching an output device on or off. A weather station logging rainfall is measurement; a greenhouse switching on a sprinkler when the soil is dry is control.

## Analogue and digital data

| | Analogue | Digital |
|---|---|---|
| Values | Continuous; any value in a range | Discrete; set values only |
| Where found | Real world: sound, temperature, light | Inside computers, as binary |
| Processed by a computer? | Not directly | Yes |

- **Analogue to digital (ADC)**: so the computer can process data from sensors or microphones.
- **Digital to analogue (DAC)**: so the computer's output can control devices such as motors or drive speakers.

## Key terms

| Term | Meaning |
|---|---|
| Volatile | Loses its contents when power is removed (RAM) |
| Non-volatile | Keeps its contents without power (ROM, backing storage) |
| Expansion card | A circuit board added to the motherboard, such as a graphics card |
| Executable file | A program in machine code that the computer can run directly |
| Applet | A small program that performs one task inside another program |
| App | A program for a specific task, usually on a mobile device |
| ADC | Analogue-to-digital converter |
| DAC | Digital-to-analogue converter |

## Exam traps

- A device driver is **system** software, not applications software.
- A web browser or an app is applications software; the operating system it runs on is system software.
- "ROM stores the operating system" is usually wrong: it stores the start-up instructions that load it.
- Brand names score nothing: write the type of software.
- When asked for a difference, give both sides: "analogue is continuous **whereas** digital is discrete."
- A sensor produces an analogue signal; name the analogue-to-digital converter as the part that turns it into digital data.
- Hardware includes external devices: a printer or a keyboard is hardware just as much as the CPU.

## Self-test

1. Define *hardware*.
2. Name the main circuit board inside a computer.
3. State **one** characteristic of RAM and **one** characteristic of ROM.
4. Which component converts a microphone's signal so that it can be stored?
5. Give **two** examples of applications software named in the syllabus.
6. Is a linker applications or system software?
7. State what a device driver does.
8. Give **two** tasks carried out by utility software.
9. State the difference between control software and measurement software.
10. Describe **one** difference between analogue and digital data.
11. Why must a computer's output be converted before it can drive a motor?
12. A program checks a hard disk and rearranges files so they load faster. What type of software is it?

## Self-test answers

1. The physical components of a computer system.
2. The motherboard.
3. RAM: volatile, or can be written to, or holds data in current use. ROM: non-volatile, or read only, or holds start-up instructions.
4. The sound card (analogue to digital conversion).
5. Any two of: word processing, spreadsheet, database management system, control, measurement, applets and apps, video editing, graphics editing, audio editing, CAD.
6. System software.
7. It allows the operating system to communicate with, and control, a particular hardware device.
8. Any two of: virus scanning, backing up, file compression, disk formatting, defragmentation.
9. Measurement software records sensor readings for analysis; control software uses readings to operate output devices.
10. Analogue data is continuous and can take any value in a range, whereas digital data has discrete values (binary).
11. The computer produces digital data, but the motor needs an analogue signal, so a DAC converts it.
12. A utility (system software), specifically a defragmenter.
