This guide covers subtopic **2.10 Graphs of functions** in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. It is about **drawing accurate graphs** from a table of values and using them to solve equations. (Quick freehand sketches showing key features are subtopic 2.11, covered in the [sketching curves study guide](/resources/cambridge-igcse-mathematics-0580-sketching-curves-cambridge-igcse-maths/).)

| Statement | Core (C2.10) | Extended (E2.10) |
|---|---|---|
| 1 Construct tables of values; draw, recognise and interpret graphs | ax + b, ±x² + ax + b and a/x (x ≠ 0), with a and b integers | axⁿ for n = −2, −1, −½, 0, ½, 1, 2, 3, including sums of up to three such terms; and abˣ + c. Here a and c are rational and b is a positive integer |
| 2 Solve associated equations graphically, including finding and interpreting roots | yes, e.g. the intersection of a line and a curve | yes |
| 3 Draw and interpret graphs of exponential growth and decay | no | yes |

The [graphs of functions and sketching curves guide](/resources/igcse-mathematics-0580-graphs-of-functions-and-sketching-curves/) introduces the main shapes. This page concentrates on the skills that lose marks: accurate tables (especially with −x²), choosing the right line for a graphical solution, Extended curves with several terms, and reading exponential graphs. Revise with the [graphs of functions revision notes](/resources/cambridge-igcse-mathematics-0580-graphs-of-functions-cambridge-igcse-maths-revision-notes/) and practise with the [graphs of functions practice questions](/resources/cambridge-igcse-mathematics-0580-graphs-of-functions-cambridge-igcse-maths-practice/).

## Step 1: an accurate table of values

Work one term at a time and put negative x-values in brackets. On Paper 3 or 4 a calculator's table function can generate the values, but you must still copy them correctly and round as the question asks.

### Worked example 1 (Core): a negative x² term

Complete a table of values for y = −x² + 2x + 3 for −2 ≤ x ≤ 4.

```
x        -2    -1     0     1     2     3     4
-x^2     -4    -1     0    -1    -4    -9   -16
+2x      -4    -2     0     2     4     6     8
+3        3     3     3     3     3     3     3
y        -5     0     3     4     3     0    -5
```

The values are symmetrical about x = 1, which is a built-in check: a value that breaks the pattern is wrong. The most common slip is −(−2)² = +4. The square is worked out first, then the minus sign applied: −(4) = −4.

## Step 2: drawing the graph

- Plot every point with a small cross, using the scale given.
- Join quadratic, cubic, reciprocal and exponential graphs with **one smooth curve** through every point; do not use a ruler between points.
- The turning point of a quadratic may lie between plotted x-values. Round the bottom (or top) smoothly; do not draw a flat section or a point.
- A reciprocal graph has two separate branches. Never join them across x = 0.

## Step 3: solving equations graphically

The curve y = f(x) meets the line y = g(x) where f(x) = g(x). So the x-coordinates of intersection points solve the equation f(x) = g(x).

**Roots** of f(x) = 0 are where the curve crosses the x-axis (the line y = 0).

### Worked example 2 (Core): choosing the line

Using the graph of y = −x² + 2x + 3 from Worked example 1, solve (a) −x² + 2x + 3 = 0, (b) −x² + 2x + 3 = 2, (c) −x² + 3x + 1 = 0.

```
(a) Read where the curve crosses y = 0:   x = -1 and x = 3

(b) Draw y = 2 and read the crossings:    x ≈ -0.4 and x ≈ 2.4

(c) Make the left side match the curve:
    -x^2 + 3x + 1 = 0
    -x^2 + 2x + 3 = -x + 2        (subtract x, add 2 to both sides)
    Draw y = -x + 2 and read the crossings:  x ≈ -0.3 and x ≈ 3.3
```

**Check the line in (c)** by subtracting: (−x² + 2x + 3) − (−x + 2) = −x² + 3x + 1. That is the equation you were asked to solve, so the line is right.

Answers read from a graph are accepted within a tolerance, so give them to the accuracy the scale allows (often 1 decimal place). The exact answers to (b) are 1 ± √2, about −0.41 and 2.41.

### Worked example 3 (Core): a reciprocal graph and a line

The graph of y = 6/x is drawn for −6 ≤ x ≤ −1 and 1 ≤ x ≤ 6. Use it to solve 6/x = x + 1.

```
Draw y = x + 1. It meets one branch at (2, 3) and the other at (-3, -2).
Solutions: x = 2 and x = -3.
Check: 6/2 = 3 = 2 + 1;  6/(-3) = -2 = -3 + 1.
```

Multiplying out gives x² + x − 6 = 0, so the graph has solved a quadratic.

## Extended graphs: sums of powers

Extended tables combine up to three terms of the form axⁿ. Work out each term on its own row.

### Worked example 4 (Extended): a cubic with three roots

(a) Complete a table for y = x³ − 3x + 1 for −2 ≤ x ≤ 2. (b) Use the graph to estimate the roots of x³ − 3x + 1 = 0.

```
x       -2    -1     0     1     2
x^3     -8    -1     0     1     8
-3x      6     3     0    -3    -6
+1       1     1     1     1     1
y       -1     3     1    -1     3
```

The sign of y changes between x = −2 and −1, between 0 and 1, and between 1 and 2. So there are **three** roots, one in each interval. From an accurate graph they are about **x ≈ −1.9, x ≈ 0.3 and x ≈ 1.5**. Spotting sign changes in the table before you draw tells you how many roots to look for.

### Worked example 5 (Extended): a square-root term

Complete a table for y = 4√x − x for x = 0, 1, 4, 9 and describe the graph.

```
x        0     1     4     9
4√x      0     4     8    12
-x       0    -1    -4    -9
y        0     3     4     3
```

Extra points such as x = 2 (y ≈ 3.66) and x = 6 (y ≈ 3.80) show the shape: the curve rises from the origin, reaches its greatest value of 4 at x = 4, then falls slowly. The function is only defined for x ≥ 0, because √x needs x ≥ 0.

## Exponential growth and decay (Extended)

A graph of y = abˣ + c, or a growth or decay model, is drawn from a table in the usual way. Key facts to read and interpret:

- The value at x = 0 is a + c (the starting value in a model, where usually c = 0).
- If the multiplier is greater than 1, the graph shows **growth**; between 0 and 1, **decay**.
- A decay graph approaches a horizontal asymptote but never reaches it.

### Worked example 6 (Extended, calculator): reading a growth graph

A population of bacteria is modelled by N = 100 × 1.5ᵗ, where t is the time in hours.

```
t     0     1     2     3      4      5
N   100   150   225   338    506    759      (nearest whole number)
```

(a) Interpret the numbers 100 and 1.5. (b) Use the graph to estimate when the population first reaches 200.

```
(a) 100 is the population at t = 0.
    1.5 means the population is multiplied by 1.5 each hour (a 50% increase per hour).

(b) Draw across from N = 200 to the curve, then down: t ≈ 1.7 hours.
```

The doubling time read from the graph, about 1.7 hours, is the same wherever you start: from 150 at t = 1, the population reaches 300 at about t = 2.7.

### Worked example 7 (Extended): an exponential and a line

The graphs of y = 2ˣ and y = x + 3 are drawn for −3 ≤ x ≤ 3. How many solutions does 2ˣ = x + 3 have, and what are they?

```
The line meets the curve twice: x ≈ -2.9 and x ≈ 2.4.
```

No algebraic method in the syllabus solves this equation, which is exactly why the graphical method matters. Logarithms are not required.

## Common mistakes

- Squaring a negative number wrongly in the table, or applying the minus sign before squaring in −x².
- Joining points with straight segments, or joining the branches of a reciprocal graph.
- Drawing the wrong line because the equation was not rearranged to "curve = line".
- Giving the y-coordinate of an intersection when the question asks for x.
- (Extended) Including x = 0 in the table for a function with a negative power of x.
- (Extended) Rounding table values too early, so the curve is slightly off at several points.

## Exam technique

- **"Complete the table"**: check symmetry or a smooth pattern before plotting.
- **"Draw the graph"**: a smooth curve through all plotted points; a pencil line, thin and clear.
- **"Use your graph to solve"**: draw the line on the grid and leave it visible; method marks depend on it.
- **"By drawing a suitable straight line"**: write the equation of the line you draw.
- **"Estimate"**: one decimal place is usually right for a graph reading.
