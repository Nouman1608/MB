These notes condense subtopic 6.4 of Cambridge IGCSE ICT 0417, school management systems. For full explanations and a worked example of one learner's morning, read the [school management systems study guide](/resources/cambridge-igcse-ict-0417-school-management-systems/); then try the [school management systems practice questions](/resources/cambridge-igcse-ict-0417-school-management-systems-practice/).

## Syllabus coverage

| Syllabus wording | Covers |
|---|---|
| Manage learner registration and attendance | Methods of registering learners; using attendance data |
| Record learner performance including computer aided learning | Marks, reports, targets, CAL |

## Key terms

| Term | Meaning |
|---|---|
| School management system | Database software holding learner records: personal details, attendance, marks, timetables |
| Learner ID | Unique number that links all of one learner's records |
| Electronic register | Attendance taken on a computer or tablet and saved directly to the database |
| Time-stamp | The exact date and time stored with an attendance entry |
| Access levels | Permissions controlling which staff can see or change which data |
| Computer aided learning (CAL) | Using computers and software to teach and test learners |
| Parent portal | Secure website where parents view attendance, reports and messages |

## Registration methods compared

| Method | Key plus | Key minus |
|---|---|---|
| Electronic register | Data saved instantly | Uses lesson time; wrong name clicked |
| OMR sheet | Fast to scan many forms | Marks in the wrong place; sheets lost before scanning |
| Magnetic stripe or smart card | Automatic, time-stamped; can be used to pay for meals | Lost, forgotten or lent cards |
| RFID tag | Very fast, contactless; can track movement around site | Tags lent or lost; readers expensive |
| Biometric (fingerprint, face) | Cannot be lost or lent | Expensive; privacy and consent concerns; failed scans |

Remember: the main weakness of cards and tags is that **someone else can use them**; the main weakness of biometrics is **privacy**.

### What happens when a card is swiped

1. Reader captures the learner ID from the card.
2. ID and time sent to the server.
3. Database finds the learner's record and adds an attendance entry.
4. Time compared with the start time: on time or late.
5. Register updated for the tutor; no manual entry needed.

## What attendance data is used for

- Identifying late arrivals automatically by comparing the time-stamp with the start time.
- Sending text or email alerts to parents when a learner is absent.
- Producing an emergency list of who is on site.
- Spotting patterns of absence over time.
- Compiling attendance figures for school records and education authorities.

## Recording performance

- Marks entered once and linked to the learner ID.
- Averages and grades calculated automatically.
- Results compared with targets; learners falling behind highlighted.
- Reports produced for parents, often via a portal.
- Class results analysed to find topics to reteach.

**Plus points:** saves staff time; fewer calculation errors; up-to-date data for every teacher; early support. **Minus points:** training needed; input errors; security of personal data; dependence on the server and backups.

## Computer aided learning

**What it does:** delivers interactive lessons, simulations and videos; sets quizzes; marks them automatically; records the results in the learner's record.

| For | Against |
|---|---|
| Own pace, can repeat | Cost of devices and software |
| Instant feedback | Cannot answer unexpected questions like a teacher |
| Can adapt difficulty | Distraction from other content |
| Engaging multimedia | Less discussion with others |
| Usable at home | Technical faults |
| Results stored automatically | Not enough support for some learners |

CAL **supports** the teacher; it does not replace one.

## Data protection in school systems

- The system holds personal data about children, including contact and medical details.
- Strong passwords and access levels limit who can see what.
- Regular backups protect against loss.
- Data should be used only for the purposes the school has stated.

## Exam traps

- "Biometrics are 100% accurate". Scans can fail or be refused.
- Describing a card system without saying what data is stored.
- Calling any computer use in class "CAL". CAL is software that teaches and tests.
- Ignoring security when asked for disadvantages of storing learner data.
- Answering about marks when the question asks about attendance.

## Self-test

1. What links all of a learner's records in a school management system?
2. Give two items of personal data stored about a learner.
3. Give one advantage and one disadvantage of an electronic register.
4. Why might a school prefer biometric registration to swipe cards?
5. Give two disadvantages of biometric registration.
6. How does the system decide that a learner is late?
7. Describe how the system helps reduce truancy.
8. State one use of attendance data in an emergency.
9. Give two ways a school uses recorded marks.
10. What does CAL stand for?
11. Give two advantages of CAL for learners.
12. Give two reasons why CAL cannot replace teachers.

### Answers

1. A unique learner ID number.
2. Any two: name; date of birth; address; parent contact details; medical needs.
3. Advantage: data saved straight to the database. Disadvantage: takes lesson time or a wrong name may be clicked.
4. A fingerprint or face cannot be lent to a friend, lost or forgotten.
5. Any two: expensive; privacy concerns; consent needed; scans can fail.
6. It compares the time-stamp of the arrival with the preset start time.
7. It sends an automatic text or email to parents when a learner has not registered, so absence is noticed the same day.
8. Producing a list of everyone recorded as on site.
9. Any two: calculate averages; compare with targets; produce reports; find topics to reteach.
10. Computer aided learning.
11. Any two: work at own pace; instant feedback; adaptive difficulty; can use at home.
12. Any two: cannot answer unexpected questions; cannot give personal support; cannot plan learning or motivate in the way a teacher can.
