This set covers **syllabus section 1.6, simple deductive proof**, of IB DP Mathematics: Analysis and Approaches (first assessment 2021), common content for SL and HL. Every question is calculator-free, as proofs of this kind are on Paper 1 or are pure algebra on Paper 2. Lay out every "show that" and "prove" from one side to the other; never work on both sides at once.

Study the methods first in the [section 1.6 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-6/) and the [section 1.6 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-1-6-revision-notes/).

## Section A

**1.** Show that 1/4 + 1/12 = 1/3. **[1]**

**2.** For each statement, say whether the "=" could be replaced by "≡", giving a reason.

**(a)** 2(x − 5) = 2x − 10 **[1]**
**(b)** x² = 2x **[1]**
**(c)** (x + 1)² = x² + 1 **[1]**

**3.** Let n ∈ ℤ.

**(a)** Write down an expression for any odd number. **[1]**
**(b)** Write down an expression for the next odd number after it. **[1]**

**4.** Show that (2x − 1)² − (x − 2)² ≡ 3(x² − 1). **[3]**

**5.** Prove that the sum of two consecutive odd numbers is a multiple of 4. **[3]**

## Section B

**6.**

**(a)** Show that 3² + 4² + 12² = 13². **[1]**
**(b)** Prove that n² + (n + 1)² + (n(n + 1))² ≡ (n² + n + 1)². **[4]**
**(c)** Hence write 5² + 6² + 30² as the square of an integer. **[1]**

**7.** Prove that the product of any two consecutive integers is even. **[4]**

**8.**

**(a)** Show that 1/(x − 2) − 1/(x + 2) ≡ 4/(x² − 4), stating the values of x for which the identity is not defined. **[3]**
**(b)** Hence find the exact value of 1/98 − 1/102, in its simplest form. **[2]**

**9.** A student claims that n² + n + 1 is odd for every integer n, and writes: "n = 1 gives 3, n = 2 gives 7, n = 3 gives 13. These are all odd, so the statement is true."

**(a)** Explain why the student's argument is not a proof. **[1]**
**(b)** Write a correct proof of the claim. **[3]**

**10.** Prove that the difference between the squares of any two odd numbers is a multiple of 4. **[3]**

**11.**

**(a)** Show that (x + 1/x)² − (x − 1/x)² = 4 for all x ≠ 0. **[3]**
**(b)** Hence write down the value of (7.5 + 1/7.5)² − (7.5 − 1/7.5)². **[1]**

**12.**

**(a)** Expand and simplify (n + 1)³ − n³. **[2]**
**(b)** Hence prove that the difference between the cubes of two consecutive integers is always odd. **[3]**

## Answers

**1.** LHS = 3/12 + 1/12 = 4/12 = 1/3 = RHS [1]

**2. (a)** Yes: it is true for every x (expand the bracket), so it is an identity [1]
**(b)** No: it is true only for x = 0 and x = 2, so it is an equation [1]
**(c)** No: (x + 1)² = x² + 2x + 1, which equals x² + 1 only when x = 0 [1]

**3. (a)** **2n + 1** [1]
**(b)** **2n + 3** [1]

**4.** LHS = (4x² − 4x + 1) − (x² − 4x + 4) [1] = 4x² − 4x + 1 − x² + 4x − 4 [1] = 3x² − 3 = 3(x² − 1) = RHS [1]
*Examiner insight:* The middle line shows the bracket being subtracted term by term. Skipping it is where the −4 usually becomes +4.

**5.** Let the numbers be 2n + 1 and 2n + 3, n ∈ ℤ [1]. Sum = 4n + 4 = 4(n + 1) [1]. n + 1 is an integer, so the sum is a multiple of 4 [1]

**6. (a)** 9 + 16 + 144 = 169 = 13² [1]
**(b)** LHS = n² + (n² + 2n + 1) + n²(n² + 2n + 1) [1] = n⁴ + 2n³ + 3n² + 2n + 1 [1]. RHS = (n² + n + 1)² = n⁴ + n² + 1 + 2n³ + 2n² + 2n [1] = n⁴ + 2n³ + 3n² + 2n + 1. Both sides simplify to the same expression, so LHS = RHS [1]
**(c)** n = 5: n² + n + 1 = 31, so 5² + 6² + 30² = **31²** [1]
*Examiner insight:* Simplifying each side separately is valid here because both are complicated. Do not write the identity first and expand both sides together on one line.

**7.** Let the integers be n and n + 1. If n is even, n = 2m for some m ∈ ℤ [1], so n(n + 1) = 2m(2m + 1) = 2[m(2m + 1)], which is even [1]. If n is odd, n = 2m + 1 [1], so n(n + 1) = (2m + 1)(2m + 2) = 2(2m + 1)(m + 1), which is even [1]. Every integer is even or odd, so the product is always even.
*Examiner insight:* A proof by cases must cover every possibility. Here "even" and "odd" do; say so in the final sentence.

**8. (a)** LHS = ((x + 2) − (x − 2))/((x − 2)(x + 2)) [1] = 4/(x² − 4) = RHS [1]. The identity is not defined at **x = 2 and x = −2** [1]
**(b)** Put x = 100: 1/98 − 1/102 = 4/(100² − 4) [1] = 4/9996 = **1/2499** [1]

**9. (a)** Checking a few values cannot show the statement holds for every integer; an untested value could fail [1]
**(b)** n² + n + 1 = n(n + 1) + 1 [1]. n(n + 1) is a product of consecutive integers, so it is even: n(n + 1) = 2k for some k ∈ ℤ [1]. Then n² + n + 1 = 2k + 1, which is odd [1]
*Examiner insight:* Using a result proved earlier (Question 7) is allowed, provided you state it. Without it, use the two cases n even and n odd.

**10.** Let the odd numbers be 2m + 1 and 2n + 1, m, n ∈ ℤ [1]. (2m + 1)² − (2n + 1)² = 4m² + 4m + 1 − 4n² − 4n − 1 = 4m² + 4m − 4n² − 4n [1] = 4(m² + m − n² − n), and m² + m − n² − n is an integer, so the difference is a multiple of 4 [1]
*Examiner insight:* Two different letters are essential. Using 2n + 1 for both gives a difference of zero, which proves nothing.

**11. (a)** LHS = (x² + 2 + 1/x²) − (x² − 2 + 1/x²) [2] = 4 = RHS [1]
**(b)** **4** [1], by part (a) with x = 7.5.

**12. (a)** (n³ + 3n² + 3n + 1) − n³ [1] = **3n² + 3n + 1** [1]
**(b)** 3n² + 3n + 1 = 3n(n + 1) + 1 [1]. n(n + 1) is even, so n(n + 1) = 2k with k ∈ ℤ [1]. Then the difference is 6k + 1 = 2(3k) + 1, which is odd [1]

## Where marks are usually lost

- Starting a "show that" from the printed identity and transforming both sides.
- Using one letter for two independent numbers.
- Reaching 4(n + 1) and stopping without saying that n + 1 is an integer.
- Proof by cases that leaves out a case.
- Substituting numbers when the question asks for a general proof.
