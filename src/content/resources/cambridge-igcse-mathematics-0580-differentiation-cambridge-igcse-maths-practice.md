These questions cover subtopic **2.12 Differentiation** in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. The subtopic is **Extended only** (E2.12), so every question is Extended content for Paper 2 or Paper 4. None of the questions needs a calculator.

For worked examples, read the [differentiation study guide](/resources/cambridge-igcse-mathematics-0580-differentiation-cambridge-igcse-maths/); for a summary, use the [differentiation revision notes](/resources/cambridge-igcse-mathematics-0580-differentiation-cambridge-igcse-maths-revision-notes/).

## Questions

### Section A: short questions

**1.** Differentiate

**(a)** 7x⁴ **[1]**

**(b)** 5 − 3x **[1]**

**2.** y = 2x³ − x² + 6x. Find dy/dx. **[2]**

**3.** y = (x − 4)(x + 1). Find dy/dx. **[2]**

**4.** Find the gradient of the curve y = x³ − 5x at the point where x = −2. **[2]**

**5.** y = ½x⁴ − 2x. Find dy/dx. **[2]**

**6.** A tangent is drawn to a curve at a point P. The tangent passes through (1, 7) and (5, −1). Estimate the gradient of the curve at P. **[1]**

### Section B: structured questions

**7.** A curve has equation y = x² − 8x + 3.

**(a)** Find dy/dx. **[1]**

**(b)** Find the coordinates of the point on the curve where the gradient is 2. **[2]**

**(c)** Find the coordinates of the turning point of the curve. **[2]**

**8.** A curve has equation y = x³ − 6x² + 5.

**(a)** Find dy/dx. **[1]**

**(b)** Find the coordinates of the two stationary points. **[3]**

**(c)** Use the second derivative to determine the nature of each stationary point. **[2]**

**9.** A curve has equation y = 12x − x³.

**(a)** Find the coordinates of the stationary points. **[3]**

**(b)** By considering the gradient on either side, determine whether each is a maximum or a minimum. **[2]**

**10.** Find the coordinates of the two points on the curve y = x³ + 2x² where the gradient is 4. **[4]**

**11.** A farmer uses 40 m of fencing to make three sides of a rectangular pen. A wall forms the fourth side. The two sides at right angles to the wall are each x m long.

**(a)** Show that the area of the pen, A m², is given by A = 40x − 2x². **[1]**

**(b)** Use differentiation to find the value of x that gives the greatest area, and find this area. **[3]**

**(c)** Show that this value of x gives a maximum. **[1]**

**12.** The curve y = ax² + bx has a stationary point at (2, −4). Find the values of a and b. **[4]**

**13.** The gradient of the curve y = x³ − 3x at the point where x = k is 9. Find the possible values of k. **[3]**

## Answers

**1. (a)** **28x³** [1].

**(b)** **−3** [1].

**2.** 6x² − 2x [1], + 6: **6x² − 2x + 6** [1].

**3.** Expand: y = x² − 3x − 4 [1]. **dy/dx = 2x − 3** [1].
*Examiner insight:* differentiating each bracket separately and multiplying the results gives 1, which earns nothing. Expand first.

**4.** dy/dx = 3x² − 5 [1]. At x = −2: 12 − 5 = **7** [1].

**5.** ½ × 4x³ = 2x³ [1]; **2x³ − 2** [1].

**6.** (−1 − 7) ÷ (5 − 1) = **−2** [1].

**7. (a)** **2x − 8** [1].

**(b)** 2x − 8 = 2, x = 5 [1]. y = 25 − 40 + 3 = −12: **(5, −12)** [1].

**(c)** 2x − 8 = 0, x = 4 [1]. y = 16 − 32 + 3: **(4, −13)** [1].

**8. (a)** **3x² − 12x** [1].

**(b)** 3x(x − 4) = 0, so x = 0 or x = 4 [1]. **(0, 5)** [1] and **(4, −27)** [1].

**(c)** d²y/dx² = 6x − 12 [1]. At x = 0 it is −12, so **(0, 5) is a maximum**; at x = 4 it is 12, so **(4, −27) is a minimum** [1].

**9. (a)** dy/dx = 12 − 3x² = 0 [1], x² = 4, x = ±2 [1]. **(2, 16)** and **(−2, −16)** [1].

**(b)** Near x = 2: at x = 1, dy/dx = 9 (positive); at x = 3, dy/dx = −15 (negative), so **(2, 16) is a maximum** [1]. Near x = −2: at x = −3, dy/dx = −15; at x = −1, dy/dx = 9, so **(−2, −16) is a minimum** [1].
*Examiner insight:* choose test values close to each turning point and on the correct sides of it; a value beyond the other turning point can give the wrong sign.

**10.** dy/dx = 3x² + 4x [1]. 3x² + 4x = 4, so 3x² + 4x − 4 = 0 [1]. (3x − 2)(x + 2) = 0, x = 2/3 or x = −2 [1]. Points **(−2, 0)** and **(2/3, 32/27)** [1].

**11. (a)** Side parallel to the wall = 40 − 2x, so A = x(40 − 2x) = 40x − 2x² [1].

**(b)** dA/dx = 40 − 4x [1]. 40 − 4x = 0 gives **x = 10** [1]. A = 400 − 200 = **200 m²** [1].

**(c)** d²A/dx² = −4, which is negative, so it is a maximum [1].

**12.** dy/dx = 2ax + b, and at x = 2 this is 0: 4a + b = 0 [1]. The point lies on the curve: 4a + 2b = −4 [1]. Subtracting: b = −4 [1]. Then 4a = 4, so **a = 1, b = −4** [1].

**13.** dy/dx = 3x² − 3, so 3k² − 3 = 9 [1]. k² = 4 [1]. **k = 2 or k = −2** [1].

## Where marks are usually lost

- Keeping a constant term after differentiating.
- Not multiplying by the power.
- Differentiating a product of brackets without expanding.
- Using dy/dx instead of y to find the y-coordinate of a point.
- Reversing the second-derivative rule.
- Giving one value of k or x when a quadratic gives two.
