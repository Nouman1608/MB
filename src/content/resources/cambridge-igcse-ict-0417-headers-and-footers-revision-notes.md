These notes condense section 13.3 of Cambridge IGCSE ICT 0417, "Headers and footers". For explanations and a worked alignment example, read the [headers and footers study guide](/resources/cambridge-igcse-ict-0417-headers-and-footers/), then try the [headers and footers practice questions](/resources/cambridge-igcse-ict-0417-headers-and-footers-practice/).

| Syllabus wording | Revise |
|---|---|
| Use headers and footers appropriately within a range of software packages | Word processor, spreadsheet, presentation, database report |
| Create or edit headers and footers | Open, insert, close; edits apply to every page in the section |

| The purpose of headers and footers | Why they are used |

## Purpose: six reasons

1. **Identify** the document on every page (title, organisation, logo).
2. **Navigate**: page numbers help readers find and refer to pages.
3. **Order and completeness**: "Page x of y" puts printed pages in order and shows missing pages.
4. **Version control**: date, time and file name show which version was printed.
5. **Locate the file**: file name and path show where it is stored.
6. **Consistency**: repeated details in the same place, matching the house style, without retyping.

## Alignment

| Position | Where the item sits |
|---|---|
| Left margin | Starts exactly at the left margin |
| Centred within margins | Midway between the left and right margins |
| Right margin | Ends exactly at the right margin |

- Default header tab stops suit the **default** margins.
- After changing margins, **move the tab stops**: centre at half the text width, right at the full text width.
- *Example:* 21 cm page, 2.5 cm margins: text width 16 cm, so centre tab at 8 cm and right tab at 16 cm.
- Consistent = same alignment on **every page and section**.
- Check in **print preview** that header and footer items line up with the edges of the body text above and below them.

## Automated objects

| Object | Shows |
|---|---|
| File name | Name of the file |
| File path | Drive and folders, usually with the name |
| Page number | Current page |
| Total number of pages | Number of pages in the document |
| Date | Current date, updated automatically |
| Time | Current time, updated automatically |

**Typed text** stays the same on every page; **automated objects** update themselves. "Page 2 of 7" = text + page field + text + total pages field.

## Across packages

| Package | Key point |
|---|---|
| Word processor | Header and footer in the top and bottom margins; use tab stops |
| Spreadsheet | Left, centre and right sections; visible in page layout view and print preview |
| Presentation | Slide number, date and footer text; can be hidden on the title slide |
| Database report | Report header and footer appear once; page header and footer appear on every page |

## Key terms

| Term | Meaning |
|---|---|
| Header | Area in the top margin repeated on every page |
| Footer | Area in the bottom margin repeated on every page |
| Automated object (field) | Content that the software inserts and updates, such as a page number |
| File path | The location of a file: drive and folders |
| Different first page | Setting that gives the first page its own header and footer |
| Section break | Divides a document so sections can have different headers and footers |

## Exam traps

- Page numbers, totals and dates must be **automated**, not typed.
- **Centred within margins** is not the same as centred on the page edge when margins are unequal.
- Changing margins can leave the right tab **beyond** the margin.
- File **path** is more than the file **name**.
- A spreadsheet header does not show in **normal view**.
- In a database report, the **report** header appears once; the **page** header appears on every page.
- An edit to one section's header may not change other sections.

## Self-test

1. State the difference between a header and a footer.
2. Give two purposes of including the total number of pages.
3. Why is the date field better than a typed date?
4. Name the three alignment positions in the syllabus.
5. A page is 21 cm wide with margins of 2 cm each side. Where should the centre and right tab stops be?
6. What does a file path show that the file name does not?
7. How is "Page 5 of 20" built?
8. Where can you check a spreadsheet's footer?
9. Which part of a database report appears only once?
10. Give one reason to use "different first page".
11. A header has the title typed into the first line of the body. What is wrong?
12. Give two automated objects that relate to file information.

## Self-test answers

1. A header is in the top margin; a footer is in the bottom margin.
2. Readers can check no pages are missing, and printed pages can be put in order.
3. It updates automatically, so the current date is always shown.
4. Left margin, right margin, centred within margins.
5. Text width 17 cm: centre tab at 8.5 cm, right tab at 17 cm.
6. The drive and folders where the file is stored.
7. The text "Page", a page number field, the text "of" and a total number of pages field.
8. In page layout view or print preview.
9. The report header (and the report footer).
10. So that a title page has no header or footer.
11. It is part of the body, so it appears only once instead of on every page.
12. File name and file path.
