Subtopic 6.4 of Cambridge O Level Chemistry 5070 has ten learning outcomes. It begins with using "a Roman numeral to indicate the oxidation number of an element in a compound", defines redox as "simultaneous reduction and oxidation", gives three definitions each of oxidation and reduction, and ends with identifying "oxidation, oxidising agents, reduction and reducing agents in redox reactions". In between sit four rules for oxidation numbers and two colour tests.

This guide works through each definition with new examples, including a reaction that is **not** redox, so you can tell the difference. ## Roman numerals in names

Many elements, especially transition elements, can have more than one oxidation number. The Roman numeral in a name tells you which one is present.

| Name | Formula | Oxidation number of the metal |
|---|---|---|
| Iron(II) sulfate | FeSO₄ | +2 |
| Iron(III) chloride | FeCl₃ | +3 |
| Copper(I) oxide | Cu₂O | +1 |
| Copper(II) oxide | CuO | +2 |
| Manganese(IV) oxide | MnO₂ | +4 |
| Vanadium(V) oxide | V₂O₅ | +5 |
| Potassium manganate(VII) | KMnO₄ | Mn is +7 |

The numeral gives the oxidation number of the element it follows, which is not always the metal at the start of the name: in potassium manganate(VII) it belongs to manganese.

## Three ways to define oxidation and reduction

| | Oxidation | Reduction |
|---|---|---|
| Oxygen | Gain of oxygen | Loss of oxygen |
| Electrons | Loss of electrons | Gain of electrons |
| Oxidation number | Increase | Decrease |

**Redox** reactions involve **simultaneous** reduction and oxidation: if one substance is oxidised, another must be reduced in the same reaction. Use whichever definition fits the information you are given. The oxygen definition is fine for reactions involving oxides; electrons suit ionic equations and half-equations; oxidation numbers work for every case.

## The oxidation number rules

The syllabus lists four rules:

1. An element in its **uncombined** state has an oxidation number of **zero** (Fe, O₂, Cl₂ are all 0).
2. A **monatomic ion** has an oxidation number equal to its **charge** (Na⁺ is +1, Cl⁻ is −1, Fe³⁺ is +3).
3. The oxidation numbers in a **compound** add up to **zero**.
4. The oxidation numbers in an **ion** add up to the **charge on the ion**.

To use rules 3 and 4 you also need the usual values for common elements: oxygen is −2 and hydrogen is +1 in most compounds, and Group I metals are +1.

### Working out unknown oxidation numbers

| Species | Working | Answer |
|---|---|---|
| S in SO₂ | S + 2(−2) = 0 | +4 |
| S in SO₄²⁻ | S + 4(−2) = −2 | +6 |
| N in NH₄⁺ | N + 4(+1) = +1 | −3 |
| N in NO₃⁻ | N + 3(−2) = −1 | +5 |
| Mn in MnO₄⁻ | Mn + 4(−2) = −1 | +7 |
| Fe in Fe₂O₃ | 2Fe + 3(−2) = 0 | +3 |

Notice that in Fe₂O₃ you divide by two at the end: each iron is +3, not +6.

## Worked example 1: oxygen and oxidation numbers agree

In a blast furnace, iron(III) oxide is reduced by carbon monoxide:

Fe₂O₃ + 3CO → 2Fe + 3CO₂

- **Oxygen view:** Fe₂O₃ loses oxygen, so it is **reduced**; CO gains oxygen, so it is **oxidised**.
- **Oxidation numbers:** Fe goes from +3 to 0 (decrease, reduction). C goes from +2 in CO to +4 in CO₂ (increase, oxidation).
- **Agents:** carbon monoxide is the **reducing agent** (it reduces Fe₂O₃ and is itself oxidised). Iron(III) oxide is the **oxidising agent**.

## Worked example 2: no oxygen involved

Chlorine displaces bromine from aqueous potassium bromide:

Cl₂(aq) + 2KBr(aq) → 2KCl(aq) + Br₂(aq)
ionic equation: Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂

- **Electrons:** each Cl atom gains an electron to become Cl⁻ (**reduction**); each Br⁻ ion loses an electron to form Br₂ (**oxidation**).
- **Oxidation numbers:** Cl goes from 0 to −1; Br goes from −1 to 0. K stays +1 throughout: it is a spectator.
- **Agents:** chlorine is the **oxidising agent**; bromide ions (potassium bromide) are the **reducing agent**.

The oxygen definition cannot be used here, which is why the electron and oxidation-number definitions matter.

## Worked example 3: a reaction that is not redox

NaOH + HCl → NaCl + H₂O

Oxidation numbers: Na +1 → +1; O −2 → −2; H +1 → +1; Cl −1 → −1. **Nothing changes**, so this neutralisation is **not** a redox reaction. The same is true of precipitation reactions and of the thermal decomposition CaCO₃ → CaO + CO₂. Checking every element is the only reliable way to decide.

## Oxidising and reducing agents

- An **oxidising agent** oxidises another substance and is **itself reduced**.
- A **reducing agent** reduces another substance and is **itself oxidised**.

The agent is always a reactant, and it is named as the substance (for example "carbon monoxide"), not as "the carbon".

## Colour-change tests for redox

Outcome 7 names two reagents.

**Acidified aqueous potassium manganate(VII)** is an **oxidising agent**. When a **reducing agent** is added, it changes from **purple to colourless**, because the manganate(VII) ions are reduced. Sulfur dioxide and iron(II) ions both decolourise it; this is also the syllabus test for sulfur dioxide gas.

**Aqueous potassium iodide** is a **reducing agent**. When an **oxidising agent** is added, it changes from **colourless to yellow-brown**, because iodide ions are oxidised to iodine: 2I⁻ → I₂ + 2e⁻. Chlorine and hydrogen peroxide both produce this colour.

So the logic is:

- purple manganate(VII) going colourless → the added substance is a reducing agent
- colourless iodide going brown → the added substance is an oxidising agent

## Links to electrolysis

At the anode, negative ions lose electrons: oxidation. At the cathode, positive ions gain electrons: reduction. A half-equation such as Cu²⁺ + 2e⁻ → Cu shows reduction on its own; a full redox equation needs both halves.

## Common mistakes

- **Reversing the electron definitions.** Remember OIL RIG: oxidation is loss, reduction is gain.
- **Calling the oxidising agent "the substance that is oxidised".** It is reduced.
- **Forgetting to divide** when a formula contains two atoms of the element, as in Fe₂O₃ or Cu₂O.
- **Assigning zero to an ion.** Only uncombined elements are zero; Cl⁻ is −1.
- **Getting the colour tests backwards.** Manganate(VII) is purple to colourless; iodide is colourless to brown.
- **Labelling every reaction redox.** Neutralisation and precipitation are not.

## Command words

- **Define:** give the exact definition, such as "oxidation is the loss of electrons".
- **Identify:** name the substance oxidised, reduced, or acting as an agent, and give a reason if asked.
- **Deduce:** work out an oxidation number from a formula, showing the sum.
- **Explain:** link the change (oxygen, electrons or oxidation number) to the term.
