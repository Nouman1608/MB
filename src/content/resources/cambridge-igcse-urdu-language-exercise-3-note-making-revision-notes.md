## Five rules for notes

1. **Point, not topic.** "دل مضبوط ہوتا ہے", not "چہل قدمی".
2. **One point per bullet.** Split "A and B" into two bullets if both are needed.
3. **Right heading.** A correct note under the wrong heading scores nothing there.
4. **Specific.** Keep numbers, names and limits: "دس سال", not "کافی عرصہ".
5. **Keep negatives.** نہیں، بغیر، کمی change the meaning.

## Shortening Urdu: sentence → note

| Technique | Text | Note |
|---|---|---|
| Drop the helper verb | یہاں پانی کم ہوتا جا رہا ہے | پانی کی کمی |
| Use a noun | عمارت کو ٹھیک کیا جائے گا | عمارت کی مرمت |
| Use an infinitive | بچوں کو روزانہ کتاب پڑھنی چاہیے | روزانہ کتاب پڑھنا |
| Keep the key detail | ایک اچھا کاریگر بننے میں کم از کم دس سال لگتے ہیں | کم از کم دس سال کی تربیت |
| Keep the negative | یہاں موبائل فون لانے کی اجازت نہیں | موبائل فون ممنوع |

## Headings that come in pairs

Headings often split one topic in two. Know which side each point belongs to.

| Pair | Common confusion |
|---|---|
| فائدے / نقصانات | a disadvantage phrased positively ("کم وقت بچتا ہے") |
| مسائل / حل | advice inside a problem paragraph |
| وجوہات / نتائج | "because" (cause) versus "so" (result) |
| ماضی / حال | پہلے… اب… sentences that contain both |
| طریقہ / مقصد | how something is done versus why |

## Where hidden points sit

- **Quotations** from people in the text.
- **The last paragraph**, which often adds a new development.
- Sentences starting **تاہم، لیکن، مگر، اس کے علاوہ، نیز**.
- **Examples** in a list: "پودینہ، دھنیا اور ٹماٹر" can be one note ("جلدی اگنے والی سبزیاں").

## Mini worked example

**Text:** "میلے میں اس سال پہلی بار بچوں کے لیے الگ حصہ بنایا گیا، جہاں کہانیاں سنائی گئیں۔ تاہم گاڑی
کھڑی کرنے کی جگہ بہت کم تھی اور کئی لوگوں کو آدھا گھنٹہ انتظار کرنا پڑا۔"

**Headings:** (a) نئی سہولت (1 note) (b) مسئلہ (2 notes)

| Heading | Weak note | Good note |
|---|---|---|
| (a) | بچے | بچوں کے لیے الگ حصہ (کہانیاں) |
| (b) | گاڑی | گاڑی کھڑی کرنے کی کم جگہ |
| (b) | انتظار | آدھا گھنٹہ انتظار |

The weak notes name topics. The good notes carry the point, keep the detail (آدھا گھنٹہ) and follow
the signal word تاہم from the facility to the problem.

## Key terms

| Term | Meaning |
|---|---|
| Heading | the category under which notes must fit |
| Note | a brief phrase carrying one complete point |
| Relevance | whether a point answers the heading |
| Scattered point | a relevant point outside the paragraph that seems to match the heading |
| Background | scene-setting that answers no heading |

## Self-test

1. How many marks is Exercise 3 worth, and which text does Exercise 4 use?
2. Under "سفر کے فائدے", why is "ٹرین" a weak note for "ٹرین سے سفر کرنے سے وقت بچتا ہے"? Give a better
   note.
3. Shorten to a note: "اس گاؤں کے زیادہ تر لوگ کھیتی باڑی کر کے روزی کماتے ہیں۔"
4. The heading is "مسائل". Is "حکومت سے مدد مانگنا" a creditable note? Why?
5. Why should you not repeat the same point in two bullets?
6. Name two places in a text where scattered points are often found.

**Answers:** 1. 9 marks; Exercise 4 summarises an aspect or aspects of the Exercise 3 text. 2. "ٹرین"
names the topic, not the benefit; a better note is "وقت کی بچت". 3. Any equivalent of "زیادہ تر لوگ
کھیتی باڑی کرتے ہیں" or "روزگار: کھیتی باڑی". 4. No: it is a solution or action, not a problem, so it
belongs under a heading such as "حل". 5. Because a repeated point is normally credited once, so the
second bullet is wasted. 6. Any two of: quotations, the final paragraph, sentences beginning with
تاہم، لیکن or اس کے علاوہ.
