## 6.2.1 and 6.2.2 Core recall

- **Gene:** a sequence of nucleotides, part of a DNA molecule, coding for a polypeptide.
- **Triplet code:** three bases → one amino acid. A triplet on mRNA is a **codon**.
- **Start codon:** AUG (also methionine). **Stop codons:** UAA, UAG, UGA (no amino acid).
- **Universal:** same triplets, same amino acids in almost all organisms.
- **Degenerate:** most amino acids have more than one codon.
- **Non-overlapping:** each base is read once, in a fixed reading frame.

## 6.2.3 and 6.2.4 Transcription (nucleus)

| Step | Detail |
|---|---|
| 1 | Gene unwinds; hydrogen bonds between strands break |
| 2 | RNA polymerase moves along the **template (transcribed) strand** |
| 3 | Free RNA nucleotides pair: DNA A–U RNA, T–A, C–G, G–C |
| 4 | RNA polymerase forms phosphodiester bonds |
| 5 | RNA released; DNA rejoins |

- Other strand = **non-transcribed strand**.
- mRNA sequence = non-transcribed strand with U for T.

## 6.2.5 Splicing

- Primary transcript contains **introns** (non-coding) and **exons** (coding).
- Introns removed; exons joined → mRNA.
- mRNA leaves the nucleus through a nuclear pore.

```
Primary transcript 1 950 nt; introns 420 + 330 = 750
mRNA = 1 200 nt -> 400 codons -> 399 amino acids (if exons are only start-to-stop coding sequence)
```

## 6.2.3 Translation (cytoplasm, ribosomes)

| Step | Detail |
|---|---|
| 1 | mRNA binds to a ribosome |
| 2 | tRNA with anticodon UAC brings methionine to the start codon AUG |
| 3 | Next tRNA's anticodon pairs with the next codon |
| 4 | Peptide bond forms between amino acids |
| 5 | Ribosome moves one codon; empty tRNA leaves |
| 6 | Repeat until a stop codon; polypeptide released |

### Converting between strands

| From | To | Rule |
|---|---|---|
| Template strand | mRNA | Complementary, U for A |
| Non-transcribed strand | mRNA | Same sequence, U for T |
| mRNA codon | tRNA anticodon | Complementary |
| Anticodon | Template triplet | Same letters, T for U |

**Example:** template 3′-TAC GGT CTT-5′ → mRNA 5′-AUG CCA GAA-3′ → anticodons UAC, GGU, CUU → Met–Pro–Glu.

## 6.2.6 and 6.2.7 Mutations

**Definition:** a change in the sequence of base pairs in a DNA molecule that may result in an altered polypeptide.

| Type | Effect on reading frame | Possible effects |
|---|---|---|
| Substitution | None | No change (same amino acid); one amino acid changed; early stop codon |
| Deletion (1 base pair) | Frame shift | Many amino acids changed; early stop or lost stop |
| Insertion (1 base pair) | Frame shift | Many amino acids changed; early stop or lost stop |
| Deletion or insertion of 3 base pairs | Frame restored | One amino acid lost or gained |

**Why it matters:** changed amino acid → different R group → altered bonds in tertiary structure → protein (e.g. enzyme active site) may not function.

## Key terms

| Term | Meaning |
|---|---|
| Codon | Three bases on mRNA coding for an amino acid or stop |
| Anticodon | Three bases on tRNA complementary to a codon |
| Template strand | DNA strand used in transcription |
| Non-transcribed strand | The other DNA strand |
| RNA polymerase | Enzyme that builds RNA on the template strand |
| Primary transcript | RNA before introns are removed |
| Intron | Non-coding sequence removed from the primary transcript |
| Exon | Coding sequence joined to form mRNA |
| Frame shift | Change in how all later bases are grouped into triplets |

## Exam traps

- No T in mRNA; no U in DNA.
- Codons on mRNA, anticodons on tRNA.
- mRNA is complementary to the **template** strand.
- Stop codons code for no amino acid.
- Transcription in the nucleus; translation in the cytoplasm.
- A substitution does not always change the polypeptide.

## Quick self-test

1. Define a gene.
2. What does "degenerate" mean for the genetic code?
3. Name the enzyme that makes mRNA.
4. Which DNA strand has the same sequence as mRNA (apart from U and T)?
5. Template triplet CAT: give the codon and anticodon.
6. What is removed from a primary transcript?
7. Where does translation take place?
8. What bond forms between amino acids on the ribosome?
9. An mRNA coding sequence (start to stop) has 1 503 nucleotides. How many amino acids are in the polypeptide?
10. Why does a single-base deletion usually have a large effect?
11. Give one reason a substitution may have no effect on the polypeptide.
12. Why does the universal code allow a human gene to be expressed in bacteria?

### Answers

1. A sequence of nucleotides, forming part of a DNA molecule, that codes for a polypeptide.
2. Most amino acids are coded for by more than one triplet.
3. RNA polymerase.
4. The non-transcribed strand.
5. Codon GUA; anticodon CAU.
6. Introns.
7. On ribosomes in the cytoplasm.
8. Peptide bond.
9. 1 503 ÷ 3 = 501 codons; 500 amino acids.
10. It causes a frame shift, changing every codon after it.
11. The new triplet codes for the same amino acid (or the change is in a part of the protein that does not affect its function).
12. The same triplets code for the same amino acids in bacteria, so bacterial ribosomes produce the same polypeptide (provided the inserted sequence has no introns).
