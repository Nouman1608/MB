These questions cover content statement **B10** of AQA A-level Mathematics (7357), Section B: Algebra and functions: "Decompose rational functions into partial fractions (denominators not more complicated than squared linear terms and with no more than 3 terms, numerators constant or linear)." Write the form with unknown constants before you start each one. Revise from the [B10 study guide](/resources/aqa-a-level-mathematics-7357-b10-partial-fractions/) and the [B10 revision notes](/resources/aqa-a-level-mathematics-7357-b10-partial-fractions-revision-notes/).

## Section A

**1.** Express (5x + 4)/((x + 2)(x − 1)) in partial fractions. **[3]**

**2.** Express 6/(x² + x − 2) in partial fractions. **[4]**

**3.** Express (3x + 5)/(x + 1)² in the form A/(x + 1) + B/(x + 1)². **[3]**

**4.** Express (x − 7)/((2x + 1)(x − 2)) in partial fractions. **[3]**

**5.** Write down the form of the partial fraction decomposition, using constants A, B and C, of:

**(a)** (2x − 5)/((x + 3)(x − 4)²) **[1]**

**(b)** 7/(x³ − 9x) **[2]**

**6.** Given that (ax + b)/((x − 1)(x + 3)) ≡ 4/(x − 1) − 1/(x + 3), find the values of a and b. **[2]**

## Section B

**7.** Express (10x − 4)/(x³ − 4x) in partial fractions. **[5]**

**8.**

**(a)** Factorise x³ − 2x² + x fully. **[1]**

**(b)** Hence express (4x − 3)/(x³ − 2x² + x) in partial fractions. **[4]**

**9.** Express (3x + 5)/(3 + 5x − 2x²) in partial fractions. **[5]**

**10.** It is given that (kx + 1)/((x + 1)(x − 2)) ≡ 3/(x − 2) + B/(x + 1), where k and B are constants. Find k and B. **[4]**

**11.** Express (x + 1)/((2x − 1)(x + 2)) in partial fractions, giving the constants as exact fractions. **[4]**

**12.** In an invented model, the concentration of a chemical, in mg per litre, t minutes after a reaction starts is C = 12/((t + 1)(t + 4)), for t ≥ 0.

**(a)** Express C in partial fractions. **[3]**

**(b)** Verify your answer to part (a) when t = 2. **[1]**

**(c)** Use your answer to part (a) to explain what happens to C as t becomes large. **[1]**

## Answers

**1.** 5x + 4 ≡ A(x − 1) + B(x + 2) [1]. x = −2: −6 = −3A, so A = 2 [1]. x = 1: 9 = 3B, so B = 3 [1]. **2/(x + 2) + 3/(x − 1)**

**2.** x² + x − 2 = (x + 2)(x − 1) [1]. 6 ≡ A(x − 1) + B(x + 2) [1]. x = −2: 6 = −3A, so A = −2 [1]. x = 1: 6 = 3B, so B = 2 [1]. **−2/(x + 2) + 2/(x − 1)**

**3.** 3x + 5 ≡ A(x + 1) + B [1]. x coefficients: A = 3 [1]. x = −1 (or constants): B = 2 [1]. **3/(x + 1) + 2/(x + 1)²**

**4.** x − 7 ≡ A(x − 2) + B(2x + 1) [1]. x = 2: −5 = 5B, so B = −1. x = −1/2: −15/2 = −(5/2)A, so A = 3 [1]. **3/(2x + 1) − 1/(x − 2)** [1]

*Examiner insight:* the value that makes 2x + 1 zero is x = −1/2. Substituting x = −1 is a common slip that gives a wrong A and loses the last two marks.

**5. (a)** **A/(x + 3) + B/(x − 4) + C/(x − 4)²** [1]

**(b)** x³ − 9x = x(x − 3)(x + 3) [1], so the form is **A/x + B/(x − 3) + C/(x + 3)** [1]

**6.** Combine: 4(x + 3) − (x − 1) [1] = 3x + 13, so **a = 3 and b = 13** [1]

**7.** x³ − 4x = x(x − 2)(x + 2) [1]. 10x − 4 ≡ A(x − 2)(x + 2) + Bx(x + 2) + Cx(x − 2) [1]. x = 0: −4 = −4A, so A = 1 [1]. x = 2: 16 = 8B, so B = 2 [1]. x = −2: −24 = 8C, so C = −3 [1]. **1/x + 2/(x − 2) − 3/(x + 2)**

*Examiner insight:* check with x = 1: the left side is 6/(−3) = −2 and the right side is 1 − 2 − 1 = −2.

**8. (a)** x(x² − 2x + 1) = **x(x − 1)²** [1]

**(b)** 4x − 3 ≡ A(x − 1)² + Bx(x − 1) + Cx [1]. x = 0: A = −3 [1]. x = 1: C = 1 [1]. x² coefficients: 0 = A + B, so B = 3 [1]. **−3/x + 3/(x − 1) + 1/(x − 1)²**

*Examiner insight:* the third constant needs a comparison of coefficients or a third value of x. Check with x = 2: 5/2 on the left and −3/2 + 3 + 1 = 5/2 on the right.

**9.** 3 + 5x − 2x² = (3 − x)(1 + 2x) [1]. 3x + 5 ≡ A(1 + 2x) + B(3 − x) [1]. x = 3: 14 = 7A, so A = 2 [1]. x = −1/2: 7/2 = (7/2)B, so B = 1 [1]. **2/(3 − x) + 1/(1 + 2x)** [1]

*Examiner insight:* factorising a quadratic with a negative x² term is where most errors happen. Expand (3 − x)(1 + 2x) to check: 3 + 6x − x − 2x².

**10.** kx + 1 ≡ 3(x + 1) + B(x − 2) [1]. x = 2: 2k + 1 = 9 [1], so k = 4 [1]. x = −1: −k + 1 = −3B, so −3 = −3B and B = 1 [1]. **k = 4, B = 1**

**11.** x + 1 ≡ A(x + 2) + B(2x − 1) [1]. x = 1/2: 3/2 = (5/2)A, so A = 3/5 [1]. x = −2: −1 = −5B, so B = 1/5 [1]. **3/(5(2x − 1)) + 1/(5(x + 2))** [1]

*Examiner insight:* fractional constants are fine. Check with x = 0: the left side is 1/(−2) = −1/2, and the right side is −3/5 + 1/10 = −1/2.

**12. (a)** 12 ≡ A(t + 4) + B(t + 1) [1]. t = −1: 12 = 3A, so A = 4 [1]. t = −4: 12 = −3B, so B = −4. **C = 4/(t + 1) − 4/(t + 4)** [1]

**(b)** Original: 12/(3 × 6) = 2/3. Partial fractions: 4/3 − 4/6 = 2/3. They agree [1].

**(c)** Both 4/(t + 1) and 4/(t + 4) tend to 0 as t becomes large, so C tends to 0: the chemical is eventually used up [1].

## Where marks are usually lost

- Not factorising the denominator fully before writing the form.
- Missing the B/(x − a) term when (x − a)² is present.
- Using the wrong value of x for factors like (2x + 1) or (3 − x).
- Sign errors with factors such as (3 − x).
- Stopping after two constants in a three-term decomposition.
- Not checking, so an arithmetic slip goes unnoticed.
