These questions cover section **3.2.1.1 Classification** of the AQA AS and A-level Chemistry specification (7404/7405), for teaching from September 2015. It is AS content, examined on Paper 1. Learn the ideas first in the [Classification study guide](/resources/aqa-a-level-chemistry-7405-classification/) and the [Classification revision notes](/resources/aqa-a-level-chemistry-7405-classification-revision-notes/). Use the proton numbers given where needed: Mg 12, Cl 17, Ca 20, Fe 26, As 33, Ge 32, Ba 56.

## Questions

**1.** State what is meant by an element being in the p-block of the Periodic Table. **[1]**

**2.** State the block (s, p, d or f) of each element.

**(a)** magnesium **[1]**

**(b)** chlorine **[1]**

**(c)** iron **[1]**

**(d)** barium **[1]**

**3.** Write the full electron configuration of arsenic (proton number 33) and state its block. **[3]**

**4.** An element has the electron configuration 1s² 2s² 2p⁶ 3s² 3p⁶ 3d¹⁰ 4s² 4p².

**(a)** State its block. **[1]**

**(b)** State the period and group number of the element. **[2]**

**(c)** Name the element. **[1]**

**5.** Explain why the elements in the Periodic Table are arranged in order of proton number and not in order of relative atomic mass. **[2]**

**6.** The first d-block elements appear in period 4, not period 3. Explain why. **[2]**

**7.** Chromium has proton number 24.

**(a)** Write its electron configuration in the form [Ar] ... **[1]**

**(b)** State its block. **[1]**

**8.** Write the electron configuration, in the form [Ar] ..., of each ion.

**(a)** Fe²⁺ **[1]**

**(b)** Fe³⁺ **[1]**

**9.** An element has proton number 82 and is in period 6. By counting the sub-levels filled, deduce its block. Period 6 begins with 6s, followed by 4f, 5d and 6p. **[3]**

**10.** State why helium, with the configuration 1s², is an s-block element but is placed with the noble gases. **[2]**

**11.** The d-block in period 4 contains ten elements. Explain, in terms of sub-levels, why there are ten. **[2]**

**12.** Elements W, X, Y and Z have these outer configurations.

W: 3s² X: 3s² 3p⁴ Y: [Ar] 3d⁷ 4s² Z: 5s¹

For each element, state the block and the group (where it can be given). **[4]**

## Answers

**1.** The highest-energy electron (the last one added when the configuration is built up) is in a p sub-level [1]. **[1]**

**2. (a)** s-block [1]

**(b)** p-block [1]

**(c)** d-block [1]

**(d)** s-block [1]. **[4]**

**3.** 1s² 2s² 2p⁶ 3s² 3p⁶ 3d¹⁰ 4s² 4p³ (or [Ar] 3d¹⁰ 4s² 4p³) [2]; the last electron enters 4p, so it is **p-block** [1]. **[3]**

**4. (a)** p-block [1]

**(b)** Period 4 (the highest shell is 4) [1]; Group 4 (14), because there are four electrons in the outer shell (4s² 4p²) [1]

**(c)** Germanium [1]. **[4]**

*Examiner insight:* The 3d¹⁰ electrons do not count as outer-shell electrons for the group number. The outer shell is the fourth shell.

**5.** The proton number is the number of protons in the nucleus and determines the number of electrons and the electron configuration [1]; ordering by proton number puts elements with similar configurations and properties in the same group, whereas ordering by relative atomic mass would put some elements in the wrong group (for example argon and potassium) [1]. **[2]**

**6.** In period 3 the 3s and 3p sub-levels fill [1]; the 4s sub-level is lower in energy than 3d, so 4s fills first and the 3d sub-level only begins to fill after calcium, in period 4 [1]. **[2]**

**7. (a)** [Ar] 3d⁵ 4s¹ [1]

**(b)** d-block [1]. **[2]**

**8. (a)** [Ar] 3d⁶ [1]

**(b)** [Ar] 3d⁵ [1]. **[2]**

*Examiner insight:* For d-block ions the 4s electrons are lost before the 3d electrons.

**9.** Elements up to xenon: 2 + 8 + 8 + 18 + 18 = 54 [1]; period 6 fills 6s (2), 4f (14), 5d (10) and then 6p, so mercury is element 80 and the 6p sub-level begins at element 81 [1]; element 82 has two 6p electrons (6p²), so it is **p-block** [1]. **[3]**

**10.** Helium has its last electron in the 1s sub-level, so by configuration it is s-block [1]; it has a full outer shell and the unreactive properties of a noble gas, so it is placed with Group 0 (18) [1]. **[2]**

**11.** The 3d sub-level has five orbitals [1]; each orbital holds up to two electrons, so the 3d sub-level can hold ten electrons, giving ten elements [1]. **[2]**

**12.** W: s-block, Group 2 [1]; X: p-block, Group 6 (16) [1]; Y: d-block, no main group number needed [1]; Z: s-block, Group 1 [1]. **[4]**

## Where marks are usually lost

- Deciding the block from the outer shell rather than the sub-level of the last electron.
- Counting 3d electrons in the outer shell when finding the group.
- Removing 3d electrons before 4s in ions.
- Stating that the table is ordered by relative atomic mass.
- Forgetting that helium is s-block.
