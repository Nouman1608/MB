These notes condense section 1.04, Inverse operations, of OCR GCSE (9-1) Mathematics J560, Version 2.1 (August 2026). Statement 1.04a asks you to know that addition and subtraction, multiplication and division, and powers and roots are inverse operations, and to "use this to simplify and check calculations", including "I'm thinking of a number" and "missing digit" problems. It is content for **both tiers**.

The [1.04 study guide](/resources/ocr-gcse-mathematics-j560-inverse-operations-ocr-gcse-maths/) has the full explanations and worked examples; the [1.04 practice questions](/resources/ocr-gcse-mathematics-j560-inverse-operations-ocr-gcse-maths-practice/) have exam-style questions with mark schemes. For 1.04 alongside the rest of Topic 1, see the [integer arithmetic and number theory revision notes](/resources/ocr-gcse-mathematics-integer-arithmetic-number-theory-priority-of-revision-notes/).

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Inverse operation | An operation that undoes another | ÷ 8 undoes × 8 |
| Compensation | Change a number to a friendly one, then undo the change | 538 + 297 = 538 + 300 − 3 |
| Balancing | Change two numbers in opposite ways so the result is unchanged | 45 × 16 = 90 × 8 |
| Equivalent calculation | A different calculation with the same answer | 2 100 ÷ 15 = 4 200 ÷ 30 |
| Check | Use the inverse to get back to a starting number | 108 × 16 = 1 728 confirms 1 728 ÷ 16 = 108 |
| Flowchart | The steps of a puzzle written in order | n → +5 → ×4 → 72 |
| Missing digit | A digit replaced by a letter or box in a written calculation | 5a7 + 36b = 923 |

## The inverse pairs

```
+ a   ↔   − a
× a   ↔   ÷ a
x²    ↔   √x     (for positive numbers)
x³    ↔   ∛x
```

## Simplifying: which move?

| Calculation | Move | Example |
|---|---|---|
| Adding a number close to a round number | Round it, then undo the extra | 538 + 297 = 538 + 300 − 3 = 835 |
| Subtracting a number close to a round number | Round it, then give back the extra | 642 − 396 = 642 − 400 + 4 = 246 |
| Subtraction, other route | Add the same to both numbers | 642 − 396 = 646 − 400 = 246 |
| Product with an even factor | Double one, halve the other | 45 × 16 = 90 × 8 = 180 × 4 = 720 |
| Division | Multiply both numbers by the same amount | 2 100 ÷ 15 = 4 200 ÷ 30 = 140 |

## Checking

| Original | Inverse check |
|---|---|
| Addition | Subtract one number from the answer |
| Subtraction | Add the answer to the number taken away |
| Multiplication | Divide the answer by one factor |
| Division | Multiply the answer by the divisor |
| Square root | Square the answer |
| Cube root | Cube the answer |

Use a different calculation for the check, not the same one again.

## "I'm thinking of a number"

```
1. Write the forward flowchart.
2. Reverse the ORDER.
3. Replace each step with its INVERSE.
4. Run the original steps forward to check.
```

Special cases, where the step is its own inverse:

| Step | Undo with |
|---|---|
| Subtract the number **from** 40 | Subtract the result **from** 40 |
| Divide 96 **by** the number | Divide 96 **by** the result |

## Missing numbers

```
□ + a = b    →  □ = b − a
□ − a = b    →  □ = b + a
a − □ = b    →  □ = a − b
□ × a = b    →  □ = b ÷ a
□ ÷ a = b    →  □ = b × a
a ÷ □ = b    →  □ = a ÷ b
```

## Missing digits

```
1. Start at the units column.
2. Write any carry (addition, multiplication) or exchange (subtraction).
3. Move left one column at a time.
4. Check the finished calculation with the inverse.
```

For multiplication by a single digit, list that digit's times-table units: for 7 they are 0, 7, 4, 1, 8, 5, 2, 9, 6, 3, so each possible units digit appears exactly once.

## Exam traps

- **Same order:** undoing "+5 then ×4" as "−5 then ÷4" gives the wrong number. Undo ÷4 first.
- **"From" and "by":** the inverse of "subtract the number from 40" is not "add 40".
- **Compensating the wrong way:** 538 + 297 is 538 + 300 **− 3**.
- **One-sided division:** 2 100 ÷ 15 = 4 200 ÷ 15 is false; both numbers must change.
- **Forgotten carry** in a missing-digit column.
- **No check written** when the question says "show how you could check".
- **Negative root ignored or included wrongly:** if the puzzle says the number is positive, give only the positive root.

## Quick self-test

1. Work out 538 + 297 using compensation.
2. Work out 642 − 396 using compensation.
3. Work out 45 × 16 by doubling and halving.
4. Work out 2 100 ÷ 15 by first multiplying both numbers by 2.
5. Show how to use an inverse operation to check that 1 728 ÷ 16 = 108.
6. I think of a number, add 5, then multiply by 4. The answer is 72. What is my number?
7. I think of a positive number, square it, subtract 11, then divide by 5. The answer is 14. What is my number?
8. I think of a number and subtract it from 40. I multiply the result by 3 and get 51. What is my number?
9. I divide 96 by my number, then add 4. The answer is 16. What is my number?
10. Find the missing number: □ × 18 = 1 134.
11. Find the missing number: 900 − □ = 467.
12. Find the missing digits: 5a7 + 36b = 923.

### Answers

1. 538 + 300 − 3 = **835**.
2. 642 − 400 + 4 = **246**.
3. 90 × 8 = 180 × 4 = **720**.
4. 4 200 ÷ 30 = **140**.
5. 108 × 16 = 1 080 + 648 = **1 728**, the original number, so the division is correct.
6. 72 ÷ 4 = 18, 18 − 5 = **13**.
7. 14 × 5 = 70, 70 + 11 = 81, √81 = **9**.
8. 51 ÷ 3 = 17, so 40 − n = 17 and n = **23**.
9. 16 − 4 = 12, so 96 ÷ n = 12 and n = **8**.
10. 1 134 ÷ 18 = **63**.
11. 900 − 467 = **433**.
12. Units: 7 + b ends in 3, so b = 6, carry 1. Tens: a + 6 + 1 ends in 2, so a = 5, carry 1. Hundreds: 5 + 3 + 1 = 9. **a = 5, b = 6**, giving 557 + 366 = 923.
