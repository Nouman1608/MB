## Section A: short answers

**1.** State what is meant by a *bookmark* in a word-processed document. **[1]**

**2.** Which **one** of the following would be accepted as a bookmark name in Microsoft Word?

A: Opening times

B: 1st_Section

C: Opening_times

D: Opening-times!

**[1]**

**3.** Name **two** types of target, other than a bookmark, that a hyperlink in a document can go to. **[2]**

**4.** State the effect of clicking a hyperlink whose target begins with *mailto:*. **[1]**

**5.** Give **two** reasons why bookmarks and hyperlinks are useful in a long electronic document. **[2]**

## Section B: structured questions

**6.** A student is told: "Make the words *see the map* a hyperlink to the bookmark *Map*."

**(a)** Describe how the student should create the hyperlink. **[3]**

**(b)** State how the student should check that the hyperlink works. **[1]**

**7.** A document has a hyperlink on the word *timetable*. The instruction is: "Remove the hyperlink from the word *timetable*."

**(a)** Describe how this should be done. **[1]**

**(b)** A student selects the word and presses Delete. Explain why this does not meet the instruction. **[2]**

**8.** A user deletes the bookmark *Results* from a report. Three hyperlinks in the report used this bookmark as their target.

**(a)** Explain what happens to the three hyperlinks. **[2]**

**(b)** Describe what the user should do about them. **[2]**

**9.** A school produces a 40-page electronic handbook. The head of year wants students to be able to move around it quickly.

Describe **three** ways bookmarks and hyperlinks could be used in the handbook. **[3]**

**10.** A student's printed evidence shows the words *Back to top* underlined and blue, but the examiner cannot tell whether the link is correct.

**(a)** Explain why the printout is not enough evidence. **[1]**

**(b)** State what further evidence the student should provide. **[1]**

**11.** A student creates a bookmark called *Fees* but places the cursor on the blank line below the heading *Course fees*, instead of selecting the heading.

Explain the effect of this on a hyperlink to *Fees*, and how it should be corrected. **[2]**

**12.** A task asks for the text *Email the office* to be a hyperlink that opens a new message to the school office.

**(a)** State the type of hyperlink target to choose. **[1]**

**(b)** Explain why choosing a web page target with the email address typed in would not work. **[1]**

**13.** Explain the difference between deleting a bookmark and deleting the text that the bookmark marks. **[2]**

## Answers

**1.** A named location (a point or selected text) in a document that can be jumped to or used as the target of a hyperlink. **[1]**

**2.** C: Opening_times. **[1]**

**3.** Any two: a web page (1); an existing file (1); an email address (1); a heading or place in the document without a bookmark (1). **[2]**

**4.** It opens a new email message with the address already entered. **[1]**

**5.** Any two: the reader can jump directly to a section without scrolling (1); a contents list can link to each section (1); "back to top" links help the reader return to the start (1); cross-references take the reader straight to related content (1); links can open related web pages, files or email messages (1). **[2]**

**6. (a)** Select only the words *see the map* (1); choose the insert hyperlink option and choose a place in this document (1); select the bookmark *Map* and confirm (1). **[3]**

**(b)** Ctrl+click (or click) the link and check that it jumps to the place marked by the *Map* bookmark. **[1]**

**7. (a)** Right-click the word and choose remove hyperlink (or the equivalent option), so the word remains as plain text. **[1]**

**(b)** Pressing Delete removes the word itself as well as the link (1); the instruction was to remove only the hyperlink, so the word *timetable* should still be in the document (1). **[2]**

**8. (a)** The hyperlinks still exist and still show their display text (1), but their target no longer exists, so they are broken and will not jump to the results section (1). **[2]**

**(b)** Either recreate the bookmark *Results* at the correct place (1), or edit each of the three hyperlinks to point to a valid target, or remove them if they are no longer needed (1). **[2]**

**9.** Any three, 1 mark each: a contents list with each entry hyperlinked to a bookmark at the start of each section (1); "back to top" links at the end of each section (1); cross-references, such as "see the uniform rules", linked to the relevant section (1); links to the school website or other documents, such as the term dates (1); a link that opens an email to the head of year (1). **[3]**

**10. (a)** A printout shows only the formatting of the display text, not the target the link goes to. **[1]**

**(b)** A screenshot of the hyperlink settings (dialogue) showing the target bookmark *Top*. **[1]**

**11.** The hyperlink would take the reader to the blank line below the heading, not to the heading itself (1); the student should delete the bookmark and create it again with the heading *Course fees* selected (1). **[2]**

**12. (a)** An email address (mailto) target. **[1]**

**(b)** A web page target would try to open the address in a web browser as a website, which does not exist, rather than opening a new email message. **[1]**

**13.** Deleting a bookmark removes only the named location; the text remains in the document (1). Deleting the marked text removes the text and, with it, the bookmark, so links to that bookmark are broken (1). **[2]**

## Frequently asked questions

**Can an image be a hyperlink?**
Yes. Select the image instead of text and insert a hyperlink in the same way. The image then acts as the clickable link.

**Do I need to know how hyperlinks work in presentations?**
Hyperlinks in presentations are covered in Topic 19. This page covers bookmarks and hyperlinks in document production.
