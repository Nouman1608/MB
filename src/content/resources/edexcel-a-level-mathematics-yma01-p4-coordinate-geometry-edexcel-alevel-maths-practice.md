These questions cover section 3 of Unit P4: Pure Mathematics 4 in Pearson Edexcel International A Level Mathematics (YMA01): parametric equations of curves and conversion between cartesian and parametric forms. Several questions also ask for the domain and range of the cartesian function, which depend on the values the parameter can take.

## Section A

**1.** A curve has parametric equations x = 2t + 3, y = t² − 1. Find a cartesian equation of the curve in the form y = f(x). **[2]**

**2.** A curve has parametric equations x = −2 + 4 cos t, y = 1 + 4 sin t, 0 ≤ t < 2π. Find a cartesian equation of the curve and state its centre and radius. **[3]**

**3.** A curve has parametric equations x = 3 cot t, y = 2 cosec t, 0 < t < π. Show that a cartesian equation of the curve is 9y² − 4x² = 36. **[3]**

**4.** A curve C has parametric equations x = t³ − t, y = t² + 1.

**(a)** Find the coordinates of the point on C where t = 2. **[1]**

**(b)** Show that C passes through the point (0, 2) for two different values of t. **[2]**

**5.** Show that x = t + 2, y = t² − 4 is a parametric form of the curve y = x² − 4x. **[2]**

**6.** A curve has parametric equations x = 2t + 1, y = t² + 4t − 3. Determine whether each of the points A(5, 9) and B(7, 10) lies on the curve. **[3]**

## Section B

**7.** A curve has parametric equations x = sin t + cos t, y = sin 2t, 0 ≤ t ≤ π/2.

**(a)** Show that a cartesian equation of the curve is y = x² − 1. **[3]**

**(b)** By writing x in the form R sin(t + α), or otherwise, find the domain and the range of the cartesian function. **[3]**

**8.** A curve has parametric equations x = 2t/(1 + t), y = 1/(1 + t), t ≥ 0.

**(a)** Show that every point of the curve lies on the line x + 2y = 2. **[2]**

**(b)** The curve is part of this line. Find the coordinates of the end point that belongs to the curve, and explain why the point (2, 0) does not lie on the curve. **[3]**

**9.** A curve has parametric equations x = eᵗ + 1, y = e²ᵗ − 3, for all real t.

**(a)** Show that a cartesian equation of the curve is y = x² − 2x − 2. **[2]**

**(b)** State the domain and find the range of this function. **[2]**

**10.** An ellipse E has parametric equations x = 4 cos t, y = 2 sin t, 0 ≤ t < 2π.

**(a)** Find a cartesian equation of E. **[2]**

**(b)** Show that E meets the line x + 2y = 4 where sin t + cos t = 1, and hence find the coordinates of the points of intersection. **[4]**

**11.** A curve has parametric equations x = 3 − 2 sin t, y = cos 2t, −π/2 ≤ t ≤ π/2.

**(a)** Find a cartesian equation of the curve in the form y = f(x). **[3]**

**(b)** State the domain of f and find its range. **[3]**

**12.** A curve C has parametric equations x = t² − 4, y = t³ − 4t, for all real t.

**(a)** Find the coordinates of the points where C meets the x-axis. **[3]**

**(b)** Show that a cartesian equation of C is y² = x²(x + 4). **[3]**

**(c)** Explain how your answer to part (a) shows that C crosses itself. **[1]**

## Answers

**1.** t = (x − 3)/2 [1], so **y = (x − 3)²/4 − 1** [1].

**2.** cos t = (x + 2)/4 and sin t = (y − 1)/4, and cos²t + sin²t = 1 [1].

**(x + 2)² + (y − 1)² = 16** [1]. Centre **(−2, 1)**, radius **4** [1].

**3.** cot t = x/3 and cosec t = y/2 [1].

cosec²t = 1 + cot²t gives y²/4 = 1 + x²/9 [1].

Multiplying by 36: 9y² = 36 + 4x², so **9y² − 4x² = 36** [1].

**4. (a)** x = 8 − 2 = 6, y = 4 + 1 = 5, so **(6, 5)** [1].

**(b)** y = 2 gives t² = 1, so t = 1 or t = −1 [1]. For both, x = t³ − t = 0, so both values give **(0, 2)** [1].

**5.** Substitute: x² − 4x = (t + 2)² − 4(t + 2) [1] = t² + 4t + 4 − 4t − 8 = t² − 4 = y, so the form fits [1].

**6.** For A: x = 5 gives t = 2 [1]; then y = 4 + 8 − 3 = 9, so **A lies on the curve** [1].

For B: x = 7 gives t = 3; then y = 9 + 12 − 3 = 18 ≠ 10, so **B does not lie on the curve** [1].

**7. (a)** x² = sin²t + 2 sin t cos t + cos²t [1] = 1 + sin 2t [1].

So sin 2t = x² − 1, giving **y = x² − 1** [1].

**(b)** x = √2 sin(t + π/4). For 0 ≤ t ≤ π/2, t + π/4 runs from π/4 to 3π/4, so sin(t + π/4) runs from 1/√2 up to 1 and back [1].

Domain: **1 ≤ x ≤ √2** [1].

Range: y = sin 2t with 0 ≤ 2t ≤ π, so **0 ≤ y ≤ 1** [1].

**8. (a)** x + 2y = 2t/(1 + t) + 2/(1 + t) [1] = 2(t + 1)/(1 + t) = 2, for every t ≥ 0 [1].

**(b)** At t = 0 the point is **(0, 1)** [1].

As t increases, y = 1/(1 + t) decreases towards 0 but is never 0 [1], so y = 0 is never reached and **(2, 0) is not on the curve** [1].

**9. (a)** eᵗ = x − 1, so y = (eᵗ)² − 3 = (x − 1)² − 3 [1] = **x² − 2x − 2** [1].

**(b)** eᵗ > 0, so the domain is **x > 1** [1]. Then (x − 1)² > 0, so the range is **y > −3** [1].

**10. (a)** cos t = x/4 and sin t = y/2 [1], so **x²/16 + y²/4 = 1** [1].

**(b)** Substitute into the line: 4 cos t + 2(2 sin t) = 4, so **sin t + cos t = 1** [1].

√2 sin(t + π/4) = 1, so sin(t + π/4) = 1/√2 and t + π/4 = π/4 or 3π/4 [1].

So t = 0 or t = π/2 [1], giving the points **(4, 0)** and **(0, 2)** [1].

**11. (a)** sin t = (3 − x)/2 [1]. cos 2t = 1 − 2sin²t [1].

y = 1 − 2(3 − x)²/4, so **f(x) = 1 − (3 − x)²/2** [1].

**(b)** For −π/2 ≤ t ≤ π/2, −1 ≤ sin t ≤ 1, so x runs from 5 down to 1 [1]. Domain **1 ≤ x ≤ 5** [1].

(3 − x)² takes every value from 0 to 4, so the range is **−1 ≤ f(x) ≤ 1** [1].

**12. (a)** y = t(t² − 4) = 0 gives t = 0, t = 2 or t = −2 [1].

t = 0 gives **(−4, 0)** [1]. t = ±2 both give **(0, 0)** [1].

**(b)** y = t(t² − 4) = tx [1].

So y² = t²x² [1], and t² = x + 4, giving **y² = x²(x + 4)** [1].

**(c)** Two different parameter values, t = 2 and t = −2, give the same point (0, 0), so the curve passes through the origin twice and crosses itself there [1].

## Where marks are usually lost

- Leaving t in a cartesian equation, or stopping one step short of the requested form.
- Giving no domain, or copying the interval for t as if it were the interval for x.
- Using cos 2t = 2cos²t − 1 when the other equation gives sin t.
- Finding a value of t and not substituting it back to give the coordinates.
- Testing a point with only one of the two equations.
- Missing that an end point is excluded when the parameter only tends to a value.
