These notes condense subtopic **2.6 Inequalities** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027). Core (C2.6) is representing and interpreting inequalities, including on a number line. Everything marked *(Extended)* is E2.6 only: solving linear inequalities, regions in two variables, and listing the inequalities for a region. For full worked examples, read the [inequalities study guide](/resources/cambridge-igcse-mathematics-0580-inequalities-cambridge-igcse-maths/); for exam-style questions, use the [inequalities practice questions](/resources/cambridge-igcse-mathematics-0580-inequalities-cambridge-igcse-maths-practice/).

## The conventions (fixed by the syllabus)

| Where | Strict: < or > | Inclusive: ≤ or ≥ |
|---|---|---|
| Number line | open circle ○ | closed circle ● |
| Graph boundary *(Extended)* | broken line | solid line |
| Graph region *(Extended)* | shade the **unwanted** region unless told otherwise | same |

Linear programming (optimising a quantity over a region) is **not** in the syllabus.

## Key terms

| Term | Meaning |
|---|---|
| Strict inequality | The end value is not included: x < 3 |
| Inclusive inequality | The end value is included: x ≤ 3 |
| Double inequality | Two conditions at once: −2 < x ≤ 5 |
| Integer solutions | The whole numbers that satisfy an inequality |
| Boundary line *(Extended)* | The line where the two sides of the inequality are equal |
| Test point *(Extended)* | A point substituted to decide which side of a boundary is wanted |
| Region *(Extended)* | The set of points satisfying all the given inequalities at once |

## Condensed recall

### Words to symbols

| Words | Symbol |
|---|---|
| at least, no fewer than, minimum | ≥ |
| at most, no more than, maximum, up to and including | ≤ |
| more than, over, exceeds | > |
| less than, under, below | < |

### Number lines

- Read each end separately: circle type gives < or ≤; direction of the arrow or line gives which side.
- An arrow to the right means "greater than"; to the left, "less than".
- For integer lists, include a closed end, exclude an open end.

### Solving *(Extended)*

```
Same as an equation, EXCEPT:
multiply or divide by a NEGATIVE  ->  reverse the sign

-2x ≥ 8   ->   x ≤ -4
```

- Double inequality: do the same operation to **all three** parts.
- Fractions: multiply through by the (positive) common denominator; no reversal.
- To avoid dividing by a negative, move the x term to the side where it is positive.

### Two variables *(Extended)*

```
1. Draw the boundary (solid for ≤ ≥, broken for < >).
2. Test a point not on the line, e.g. (0, 0).
3. True -> that side is wanted; false -> that side is unwanted.
4. Shade the unwanted side.
```

Vertical boundaries are x = k; horizontal ones are y = k. x > k is to the right; y > k is above.

### Inequalities from a region *(Extended)*

1. Equation of each boundary (y = mx + c for sloping lines).
2. Line style gives strict or inclusive.
3. A point inside the region gives the direction.

## Exam traps

- **Open end in an integer list.** −3 < n ≤ 2 gives −2, −1, 0, 1, 2; not −3.
- **Forgetting to reverse.** 2 − 5x ≥ 17 gives −5x ≥ 15, so x ≤ −3 (not x ≥ −3).
- **Reversing when you should not.** Dividing by +3 never reverses the sign, even if the right-hand side is negative: 3x < −12 gives x < −4.
- **Only two parts changed.** In −1 < 3x + 5 ≤ 14, subtract 5 from all three parts: −6 < 3x ≤ 9.
- **A point on a broken line.** It is not in the region. (2, 5) does not satisfy y > 2x + 1, because 5 > 5 is false.
- **Shading the wanted side.** The convention is the opposite, unless the question says to shade the region required.
- **"Smallest integer"** for n > 4.6 is 5, not 4.6 and not 4.

## Self-test

1. A number line shows a closed circle at −1 and an open circle at 4, joined by a line. Write the inequality.
2. List the integers n such that −3 < n ≤ 2.
3. A ride is for children at least 120 cm tall. Write an inequality for a rider's height h cm.
4. *(Extended)* Solve 4x + 7 < 19.
5. *(Extended)* Solve 2 − 5x ≥ 17.
6. *(Extended)* Solve 6x − 1 > 4x + 8.
7. *(Extended)* Solve −1 < 3x + 5 ≤ 14 and list the integer solutions.
8. *(Extended)* Solve x/2 − 1 ≥ (x + 3)/4.
9. *(Extended)* Find the smallest integer n for which 5n − 2 > 21.
10. *(Extended)* Does the point (2, 5) lie in the region y > 2x + 1? Explain.
11. *(Extended)* For x + 2y ≤ 6, which side of the line x + 2y = 6 should be shaded?
12. *(Extended)* A region lies to the right of the solid line x = 1, below the broken line y = 4 and above the solid line y = x. Write its three inequalities.

### Answers

1. **−1 ≤ x < 4**.
2. **−2, −1, 0, 1, 2**.
3. **h ≥ 120**.
4. 4x < 12, **x < 3**.
5. −5x ≥ 15, **x ≤ −3** (sign reversed).
6. 2x > 9, **x > 4.5**.
7. −6 < 3x ≤ 9, **−2 < x ≤ 3**; integers **−1, 0, 1, 2, 3**.
8. Multiply by 4: 2x − 4 ≥ x + 3, **x ≥ 7**.
9. 5n > 23, n > 4.6, so **n = 5**.
10. **No**: 2(2) + 1 = 5 and 5 > 5 is false; the point is on the broken boundary, which is not included.
11. Test (0, 0): 0 ≤ 6 is true, so (0, 0) is wanted. **Shade the side not containing the origin.**
12. **x ≥ 1, y < 4, y ≥ x**.
