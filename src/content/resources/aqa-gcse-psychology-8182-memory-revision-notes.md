Condensed recall for **section 3.1.1 Memory** of Paper 1. For full explanations and worked examples, read the [Memory study guide](/resources/aqa-gcse-psychology-8182-memory/) first; then test yourself with the [Memory practice questions](/resources/aqa-gcse-psychology-8182-memory-practice/).

## Key terms

| Term | Meaning |
|---|---|
| Encoding | Changing information into a form that can be stored (acoustic, visual or semantic) |
| Storage | Holding information in memory over time |
| Retrieval | Getting stored information back out when it is needed |
| Episodic memory | Memory of personal events, with a time and place |
| Semantic memory | Memory of facts and meanings |
| Procedural memory | Memory of skills; hard to put into words |
| Capacity | How much a store can hold |
| Duration | How long a store holds information |
| Primacy effect | Better recall of items at the start of a list |
| Recency effect | Better recall of items at the end of a list |
| Schema | A mental framework of knowledge built from experience |
| Effort after meaning | Changing unfamiliar information so it makes sense in terms of existing schemas |
| Proactive interference | Old learning disrupts recall of new learning |
| Retroactive interference | New learning disrupts recall of old learning |
| False memory | Recalling something that did not happen, or not in that way |

## Multi-store model at a glance

| Store | Coding | Capacity | Duration | Moves on by |
|---|---|---|---|---|
| Sensory | Same form as the sense | Very large | A moment | Attention |
| Short-term | Mainly acoustic | About 5-9 items | About 18-30 seconds | Rehearsal |
| Long-term | Mainly semantic | Potentially unlimited | Potentially a lifetime | Retrieval back to STM |

**For:** clear and testable; the serial position curve fits it; HM's case suggests STM and LTM are separate.
**Against:** stores treated as single units (Clive Wearing kept procedural but lost episodic memory); rehearsal is not the only route to LTM; evidence mostly from artificial word lists.

## Key studies

**Murdock (serial position curve)**
- *Method:* lists of words read aloud one at a time; free recall in any order.
- *Results:* U-shaped curve; start and end recalled best, middle worst.
- *Conclusion:* primacy = rehearsed into LTM; recency = still in STM. Supports separate stores.
- *Evaluation:* controlled and replicable, but word lists lack ecological validity.

**Bartlett (War of the Ghosts)**
- *Method:* English participants read an unfamiliar Native American folk tale and reproduced it several times.
- *Results:* the story got shorter; unfamiliar details were left out or changed into familiar ones.
- *Conclusion:* memory is reconstructive and shaped by schemas and effort after meaning.
- *Evaluation:* explains everyday distortions and eyewitness errors; but no standardised instructions or tight control, and qualitative data were scored subjectively.

## Accuracy of memory: three factors

1. **Interference** -- competition between similar memories (proactive or retroactive).
2. **Context** -- matching the setting at recall to the setting at learning gives cues that help retrieval (divers in Godden and Baddeley's study recalled better in the same environment).
3. **False memories** -- suggestion and reconstruction can create memories of events that never happened.

**Memory hook:** *pro* = forwards, so old interferes forwards with new; *retro* = backwards, so new interferes backwards with old.

## Exam traps

- STM is acoustic and LTM is semantic, not the other way round.
- The recency effect is explained by **short-term** memory.
- "Memory is like a recording" contradicts Bartlett: recall is rebuilt.
- Name the type of interference **and** apply it to the scenario.

## Self-test

1. State the coding, capacity and duration of short-term memory.
2. Which type of long-term memory is used when you ride a bicycle?
3. Why are words in the middle of a list recalled worst?
4. What is meant by effort after meaning?
5. Give **one** weakness of Bartlett's War of the Ghosts study.
6. A student revises French then Spanish, and in the French test keeps writing Spanish words. Which type of interference is this?
7. Why might a student remember more if tested in the room where they learned?

**Answers:**
1. Mainly acoustic; about 5-9 items; about 18-30 seconds without rehearsal.
2. Procedural memory.
3. They have been pushed out of STM by later words but were not rehearsed enough to reach LTM.
4. Changing unfamiliar information so it fits existing schemas and makes sense to us.
5. Participants were not given standardised instructions or asked to be accurate, so some changes may have been guesses (or: qualitative data were judged subjectively).
6. Retroactive interference: the newer learning (Spanish) disrupts the older (French).
7. The room provides context cues present at encoding, which help retrieval.

## Frequently asked questions

**What are the coding, capacity and duration of long-term memory?**
Long-term memory codes mainly semantically, has a potentially unlimited capacity and can last a lifetime.

**What is the difference between primacy and recency effects?**
The primacy effect is better recall of the first items in a list, explained by rehearsal into long-term memory; the recency effect is better recall of the last items, still in short-term memory.
