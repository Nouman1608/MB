## Section A: short answers

**1.** State the difference between *Replace* and *Replace all*. **[1]**

**2.** State what the *match case* option does. **[1]**

**3.** A search for *pen* is made with *whole words only* switched on. Which **one** of the following would be found?

A: open

B: Pen

C: penguin

D: spent

**[1]**

**4.** Give **two** situations in which find and replace would be used to edit a document. **[2]**

**5.** Explain why a search for a short word such as *in* should use whole words only. **[2]**

## Section B: structured questions

**6.** A document contains this original sentence:

"The cat sat by the Cat Cafe sign. Catherine wrote cat on the category list, then CAT in capitals. Locate the cat."

A search is made for *cat*. State how many occurrences would be found with:

**(a)** no options selected; **[1]**

**(b)** whole words only; **[1]**

**(c)** match case only; **[1]**

**(d)** both match case and whole words only. **[1]**

**7.** A letter contains the surname *Shah* several times. It also contains the place name *Shahpur*. The surname must be replaced with *Shaw*.

**(a)** Describe what would happen if Replace all were used with no options selected. **[2]**

**(b)** State the option that should be selected and explain why. **[2]**

**8.** A report uses the abbreviation *IT* many times and must be changed to use *ICT* instead. The report also contains the word *it* many times.

**(a)** State which option prevents the word *it* from being changed. **[1]**

**(b)** Explain why selecting whole words only, without that option, would not be enough. **[2]**

**9.** A student is told to swap every *morning* with *afternoon*, and every *afternoon* with *morning*, in a timetable.

**(a)** The student replaces *morning* with *afternoon*, then replaces *afternoon* with *morning*. Explain what goes wrong. **[2]**

**(b)** Describe a method that would work. **[3]**

**10.** Describe **three** checks a student should carry out after using Replace all, and why each is useful. **[3]**

**11.** A school's handbook mentions the *Main Hall* many times. The hall has been renamed the *Assembly Hall*, but one paragraph about the school's history must still say *Main Hall*.

Explain why the student should use Find next and Replace, one occurrence at a time, rather than Replace all. **[2]**

**12.** A teacher wants to correct the misspelling *recieve* everywhere in a long document. Explain why find and replace is better than correcting each one by reading through the document. **[2]**

## Answers

**1.** Replace changes only the currently highlighted occurrence, whereas Replace all changes every occurrence in one step. **[1]**

**2.** It makes the search distinguish between capital and lower-case letters, so only text with exactly the same capitals is found. **[1]**

**3.** B: Pen. **[1]**

**4.** Any two: correcting a name or word spelt wrongly throughout (1); updating details such as a date, a venue or a product name (1); making terms consistent with a house style (1); replacing double spaces with single spaces (1). **[2]**

**5.** The letters *in* appear inside many other words, such as *find*, *line* or *print* (1); without whole words, these would be found and could be wrongly changed by Replace all (1). **[2]**

**6. (a)** 8: cat, Cat, Cat(herine), cat, cat(egory), CAT, (Lo)cat(e), cat. **[1]**

**(b)** 5: cat, Cat, cat, CAT, cat. **[1]**

**(c)** 5: cat, cat, category, Locate, cat. **[1]**

**(d)** 3: the three separate, lower-case words *cat*. **[1]**

**7. (a)** Every occurrence of *Shah* would be replaced, including the letters inside *Shahpur* (1), which would become *Shawpur*, introducing an error in the place name (1). **[2]**

**(b)** Whole words only (1), so that *Shah* is replaced only where it is a complete word, and *Shahpur* is left unchanged (1). **[2]**

**8. (a)** Match case. **[1]**

**(b)** *it* is a complete word, just like *IT* (1), so with whole words only both would be found and *it* would wrongly become *ICT*; match case is needed to separate them (1). **[2]**

**9. (a)** After the first step, every *morning* has become *afternoon* (1), so the second step changes all of them, the original afternoons and the new ones, to *morning*; nothing ends up as *afternoon* (1). **[2]**

**(b)** Replace *morning* with a placeholder that does not appear anywhere in the document, such as *zzzz* (1); replace *afternoon* with *morning* (1); replace *zzzz* with *afternoon*, then search for *zzzz* to check none remains (1). **[3]**

**10.** Any three, 1 mark each: read the number of replacements reported, to check it matches the number expected (1); search for the old text, to make sure none that should have changed remains (1); search for the new text or read the changed areas, to check no word inside another word has been altered (1); check capital letters at the start of sentences, which may not match after replacement (1). **[3]**

**11.** Replace all would change every occurrence, including the one in the history paragraph that must stay as *Main Hall* (1); Find next lets the student see each occurrence in context, replace the ones that should change and skip the history paragraph (1). **[2]**

**12.** Find and replace locates every occurrence, so none is missed, which can easily happen when reading a long document (1); Replace all corrects them all at once, saving time (1). **[2]**

## Frequently asked questions

**Do whole words and match case have to be used together?**
No. They do different jobs. Use whole words to stop matches inside longer words and match case to separate capitals from lower case. Use both when you need both.

**Does find and replace work in other software?**
Yes. Spreadsheets, presentations and web authoring tools have similar tools, but the syllabus places this skill in document production.
