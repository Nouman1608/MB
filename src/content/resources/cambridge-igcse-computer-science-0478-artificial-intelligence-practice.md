## Section A

**1.** Define the term **artificial intelligence**. **[2]**

**2.** State **two** characteristics of AI. **[2]**

**3.** Name the component of an expert system that applies the rules to the facts to reach a conclusion. **[1]**

**4.** State what is stored in the knowledge base of an expert system. **[1]**

**5.** Give **one** example of the use of an expert system. **[1]**

**6.** State what is meant by machine learning. **[1]**

## Section B

**7.** Describe the purpose of each of the four components of an expert system. **[4]**

**8.** A car-repair expert system has these rules.

Rule A: IF engine does not turn over AND lights are dim THEN battery is flat.

Rule B: IF engine does not turn over AND lights are bright THEN starter motor is faulty.

Rule C: IF engine turns over AND engine does not start THEN fuel system is faulty.

**(a)** A user enters: engine turns over, engine does not start. State the conclusion. **[1]**

**(b)** A user enters: engine does not turn over, lights are bright. State the conclusion and the rule used. **[2]**

**(c)** State which component of the expert system holds the three rules. **[1]**

**9.** Explain how an expert system reaches a conclusion after a user answers a series of questions. **[4]**

**10.** A music app suggests songs based on what the user has listened to. The suggestions improve over time. Explain how machine learning could be used to do this. **[3]**

**11.** Explain **one** way in which machine learning differs from an expert system. **[2]**

**12.** A hospital uses an expert system to suggest possible illnesses. Discuss the advantages and disadvantages of this for patients and doctors. **[4]**

**13.** Explain why the ability to reason is a characteristic of AI. **[2]**

**14.** A company wants to use an AI system to decide which job applicants are invited to interview. Explain **two** concerns about this. **[4]**

## Answers

**1.** A branch of computer science [1] dealing with the simulation of intelligent behaviours by computers [1].

**2.** Any two from: collection of data and rules for using that data; the ability to reason; the ability to learn and adapt [1 each].

**3.** The inference engine [1].

**4.** Facts and knowledge about a subject, collected from experts [1].

**5.** Any one from: medical diagnosis, fault finding in machines, identifying minerals, giving financial or tax advice [1].

**6.** When a program has the ability to automatically adapt its own processes and/or data [1].

**7.** The knowledge base stores facts about the subject [1]. The rule base holds the rules that link facts to conclusions [1]. The inference engine reasons by applying the rules to the facts and the user's answers [1]. The interface lets the user enter answers and see the result [1].

**8.** **(a)** The fuel system is faulty [1].

**(b)** The starter motor is faulty [1], using Rule B [1].

**(c)** The rule base [1].

**9.** The interface asks the questions and takes the answers [1]. The inference engine searches the knowledge base for matching facts [1] and applies the rules in the rule base to the answers [1]. It reaches a conclusion that the interface displays [1].

**10.** The app collects data on the songs the user plays, skips and repeats [1]. It looks for patterns, such as the style of music the user prefers [1]. It adjusts its own data or processes to suggest similar songs, and checks whether the user plays them, so the suggestions improve [1].

**11.** An expert system uses rules written in advance from human experts [1], whereas machine learning finds its own rules or patterns from data and adapts them [1]. Accept: an expert system only changes when someone updates it, but a machine learning program changes itself.

**12.** Any four from: advantages: available at any time [1]; gives consistent suggestions and holds more knowledge than one doctor [1]; may help doctors consider less common illnesses [1]; disadvantages: it is only as good as its rules and knowledge, so it can be wrong [1]; it cannot use common sense or consider the patient as a whole [1]; the doctor must still make the decision [1]. Maximum 4.

**13.** Reasoning means using data and rules to reach a conclusion or make a decision [1]. This is what makes the system appear intelligent, because it does more than store or display information [1].

**14.** The system is only as good as its data and rules, so if the data is unfair or incomplete [1] it could reject suitable applicants unfairly [1]. Applicants' personal data must be collected and stored [1], so it must be kept secure and used properly [1]. Also accept: the system cannot judge personal qualities as a person can; an applicant has no way to challenge a wrong decision. Maximum 4.

## Where marks are usually lost

- Question 1: leaving out the word simulation or saying the computer "thinks".
- Question 7: giving the names of the components without a purpose for each.
- Question 8: choosing a rule whose conditions only partly match.
- Question 9: skipping the knowledge base or the interface.
- Question 10: describing a fixed list of songs instead of adapting data from the user's behaviour.
- Question 11: describing one of the two systems only.

## Quick reference for checking your answers

| Item | Key point |
|---|---|
| AI | Simulation of intelligent behaviours |
| Expert system | Knowledge base, rule base, inference engine, interface |
| Machine learning | Program adapts its own processes and/or data |
