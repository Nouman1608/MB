These questions cover **section 5.10 of IB DP Mathematics: Analysis and Approaches: indefinite integration, including composites with ax + b and integration by inspection or substitution**. It is SL content, so the set suits SL and HL students. All questions are calculator-free, as this section is mainly tested on Paper 1. Assume every logarithm is of a positive quantity unless a domain is given.

Learn the methods first in the [section 5.10 study guide](/resources/ib-dp-mathematics-analysis-and-approaches-5-10/) and the [section 5.10 revision notes](/resources/ib-dp-mathematics-analysis-and-approaches-5-10-revision-notes/).

## Section A

**1.** Find ∫ (4x^(1/3) − 2/√x) dx. **[3]**

**2.** Find ∫ 5 cos(3x − 2) dx. **[2]**

**3.** Find ∫ 8/(4x + 1) dx, for x > −1/4. **[2]**

**4.** Find ∫ e^(3 − 2x) dx. **[2]**

**5.** Find ∫ 6/(2x − 5)³ dx. **[3]**

**6.** Find ∫ x³(x⁴ − 2)⁵ dx. **[3]**

## Section B

**7.** Find

**(a)** ∫ sin x cos³x dx **[3]**
**(b)** ∫ (3x² + 2)/(x³ + 2x + 5) dx, for x > 0 **[2]**

**8.** **(a)** Find ∫ x e^(−x²) dx. **[3]**
**(b)** The curve y = f(x) has gradient x e^(−x²) and passes through (0, 1). Find f(x). **[2]**

**9.** Use the substitution u = 4 − x² to find ∫ 2x√(4 − x²) dx. **[4]**

**10.** **(a)** Find ∫ (ln x)³/x dx, for x > 0. **[3]**
**(b)** Find ∫ 1/(x ln x) dx, for x > 1. **[3]**

**11.** Let f′(x) = cos x e^(sin x).

**(a)** Find f(x), given that f(π) = 3. **[4]**
**(b)** Find the exact value of f(π/2). **[1]**

**12.** **(a)** Find ∫ x(x² + 1)⁴ dx. **[2]**
**(b)** Explain why the method you used in part (a) cannot be used to find ∫ x²(x² + 1)⁴ dx. **[1]**

**13.** **(a)** Show that d/dx[(x² + 9)^(3/2)] = 3x√(x² + 9). **[2]**
**(b)** Hence find ∫ 5x√(x² + 9) dx. **[2]**

**14.** The gradient of a curve is given by dy/dx = 2/(3 − 4x)², for x < 3/4. The curve passes through the point (1/2, 1).

**(a)** Find the equation of the curve. **[4]**
**(b)** Find the y-intercept of the curve. **[1]**

## Answers

**1.** 4x^(1/3) → 4x^(4/3)/(4/3) = 3x^(4/3) [1]; −2x^(−1/2) → −2x^(1/2)/(1/2) = −4√x [1]; **3x^(4/3) − 4√x + C** [1] **[3]**

**2.** 5 × (1/3) sin(3x − 2) [1]; **(5/3) sin(3x − 2) + C** [1] **[2]**

**3.** 8 × (1/4) ln(4x + 1) [1]; **2 ln(4x + 1) + C** [1] **[2]**

**4.** e^(3 − 2x)/(−2) [1]; **−(1/2)e^(3 − 2x) + C** [1] **[2]**

**5.** Rewrite as 6(2x − 5)^(−3) [1]; 6(2x − 5)^(−2)/((−2) × 2) [1]; **−3/(2(2x − 5)²) + C** [1] **[3]**
*Examiner insight:* Treating 1/(2x − 5)³ as a logarithm is a frequent error; only the power −1 gives ln.

**6.** g = x⁴ − 2, g′ = 4x³, so x³ = (1/4)g′ [1]; trial (x⁴ − 2)⁶ has derivative 24x³(x⁴ − 2)⁵ [1]; **(1/24)(x⁴ − 2)⁶ + C** [1] **[3]**

**7. (a)** g = cos x, g′ = −sin x [1]; integrand = −g′g³ [1]; **−(1/4)cos⁴x + C** [1]
**(b)** The numerator is the derivative of the denominator [1]; **ln(x³ + 2x + 5) + C** [1] **[5]**

**8. (a)** g = −x², g′ = −2x, so x = −(1/2)g′ [1]; trial e^(−x²) has derivative −2x e^(−x²) [1]; **−(1/2)e^(−x²) + C** [1]
**(b)** f(0) = −1/2 + C = 1, so C = 3/2 [1]; **f(x) = 3/2 − (1/2)e^(−x²)** [1] **[5]**

**9.** du/dx = −2x, so 2x dx = −du [1]; ∫ −u^(1/2) du [1] = −(2/3)u^(3/2) + C [1] = **−(2/3)(4 − x²)^(3/2) + C** [1] **[4]**
*Examiner insight:* The sign comes from du = −2x dx; losing it is the commonest error, and differentiating the answer would catch it.

**10. (a)** g = ln x, g′ = 1/x [1]; pattern g′g³ [1]; **(1/4)(ln x)⁴ + C** [1]
**(b)** Write as (1/x)/(ln x) [1]; pattern g′/g with g = ln x, which is positive for x > 1 [1]; **ln(ln x) + C** [1] **[6]**

**11. (a)** g = sin x, g′ = cos x: pattern g′e^g [1]; f(x) = e^(sin x) + C [1]; f(π) = e⁰ + C = 1 + C = 3 [1]; **f(x) = e^(sin x) + 2** [1]
**(b)** f(π/2) = e¹ + 2 = **e + 2** [1] **[5]**

**12. (a)** x = (1/2)(2x), the derivative of x² + 1 [1]; **(1/10)(x² + 1)⁵ + C** [1]
**(b)** x² is not a constant multiple of 2x (the derivative of x² + 1), so the integrand is not of the form k g′(x) f(g(x)) [1] **[3]**

**13. (a)** Chain rule: (3/2)(x² + 9)^(1/2) × 2x [1] = 3x√(x² + 9) [1]
**(b)** 5x√(x² + 9) = (5/3) × 3x√(x² + 9) [1]; **(5/3)(x² + 9)^(3/2) + C** [1] **[4]**
*Examiner insight:* "Hence" expects you to use part (a); a fresh substitution can reach the right answer but may not earn the "hence" marks.

**14. (a)** Rewrite as 2(3 − 4x)^(−2) [1]; y = 2(3 − 4x)^(−1)/((−1)(−4)) + C = 1/(2(3 − 4x)) + C [1]; at x = 1/2, 3 − 4x = 1, so 1 = 1/2 + C and C = 1/2 [1]; **y = 1/(2(3 − 4x)) + 1/2** [1]
**(b)** At x = 0, y = 1/6 + 1/2 = **2/3** [1] **[5]**
*Examiner insight:* Two negatives meet here: the power −1 from integrating and the coefficient −4 inside the bracket. Their product is positive, so the anti-derivative has a positive coefficient; differentiating it is the quickest check.

## How this set builds

Questions 1 to 5 test the standard results and the ax + b rule one at a time, so a mistake there points to a single rule to relearn. Questions 6 to 11 each hide a reverse chain rule pattern: g′gⁿ in questions 6, 7(a) and 10(a), g′/g in 7(b) and 10(b), and g′e^g in 8 and 11. Question 9 asks for a formal substitution, where the sign of du is the trap. Questions 12 to 14 test judgement: when the method applies, how to use a "hence", and how to combine an integral with a boundary condition.
