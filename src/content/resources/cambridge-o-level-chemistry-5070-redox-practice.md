## Section A

**1.** Define oxidation in terms of oxygen, in terms of electrons and in terms of oxidation number. **[3]**

**2.** Deduce the oxidation number of: nitrogen in N₂; aluminium in Al³⁺; phosphorus in PO₄³⁻. **[3]**

**3.** Write the formula of iron(III) oxide, and name the compound MnO₂ using a Roman numeral. **[2]**

**4.** Define a reducing agent. **[2]**

**5.** State the colour change seen when an oxidising agent is added to aqueous potassium iodide, and when a reducing agent is added to acidified aqueous potassium manganate(VII). **[2]**

**6.** Which reaction is **not** a redox reaction?

A: Zn + 2HCl → ZnCl₂ + H₂

B: CuCO₃ → CuO + CO₂

C: 2Mg + O₂ → 2MgO

D: Cl₂ + 2KI → 2KCl + I₂ **[1]**

## Section B

**7.** Aluminium reacts with iron(III) oxide in a very exothermic reaction.

2Al + Fe₂O₃ → Al₂O₃ + 2Fe

**(a)** Identify the substance oxidised and the substance reduced, in terms of oxygen.

**(b)** State the oxidation numbers of iron and of aluminium before and after the reaction.

**(c)** Name the reducing agent. **[5]**

**8.** Zinc is added to aqueous silver nitrate.

Zn(s) + 2Ag⁺(aq) → Zn²⁺(aq) + 2Ag(s)

**(a)** Construct the two half-equations for this reaction.

**(b)** Explain, in terms of electrons, why this is a redox reaction.

**(c)** Identify the oxidising agent. **[5]**

**9.** Bromine water is added to aqueous potassium iodide.

Br₂ + 2I⁻ → 2Br⁻ + I₂

**(a)** State the change in oxidation number of bromine and of iodine.

**(b)** Describe what would be seen.

**(c)** Identify the oxidising agent. **[4]**

**10.** A few drops of acidified aqueous potassium manganate(VII) are added to aqueous iron(II) sulfate.

**(a)** State the colour change of the potassium manganate(VII).

**(b)** State what this shows about iron(II) ions.

**(c)** State the change in oxidation number of iron. **[3]**

**11.** Deduce the oxidation number of: sulfur in H₂SO₄; nitrogen in NH₄Cl; chlorine in ClO⁻. **[3]**

**12.** A student says that NaOH + HNO₃ → NaNO₃ + H₂O is a redox reaction. Use oxidation numbers to show that the student is wrong. **[2]**

**13.** During the electrolysis of molten sodium chloride, sodium forms at the cathode and chlorine at the anode. Use half-equations to explain which electrode reaction is oxidation and which is reduction. **[4]**

**14.** Burning magnesium continues to burn in carbon dioxide, forming magnesium oxide and black specks of carbon.

2Mg + CO₂ → 2MgO + C

**(a)** Use oxidation numbers to show which element is oxidised and which is reduced.

**(b)** Identify the oxidising agent. **[3]**

## Answers

**1.** Gain of oxygen [1]; loss of electrons [1]; increase in oxidation number [1].

**2.** N in N₂: 0 [1]. Al in Al³⁺: +3 [1]. P in PO₄³⁻: P + 4(−2) = −3, so **+5** [1].

**3.** Fe₂O₃ [1]; manganese(IV) oxide [1].

**4.** A substance that reduces another substance [1] and is itself oxidised [1].

**5.** Potassium iodide: colourless to (yellow-)brown [1]. Potassium manganate(VII): purple to colourless [1].

**6.** **B** [1].

**7. (a)** Aluminium gains oxygen, so it is oxidised [1]; iron(III) oxide loses oxygen, so it is reduced [1].

**(b)** Iron: +3 → 0 [1]. Aluminium: 0 → +3 [1].

**(c)** Aluminium [1].

**8. (a)** Zn → Zn²⁺ + 2e⁻ [1]. Ag⁺ + e⁻ → Ag (or 2Ag⁺ + 2e⁻ → 2Ag) [1].

**(b)** Zinc loses electrons, so it is oxidised [1]; silver ions gain electrons, so they are reduced; both happen at the same time [1].

**(c)** Silver ions, Ag⁺ (silver nitrate) [1].

**9. (a)** Bromine: 0 → −1 [1]. Iodine: −1 → 0 [1].

**(b)** The solution turns (yellow-)brown / darker brown as iodine forms [1].

**(c)** Bromine [1].

**10. (a)** Purple to colourless [1].

**(b)** Iron(II) ions act as a reducing agent [1].

**(c)** +2 → +3 [1].

**11.** S in H₂SO₄: 2(+1) + S + 4(−2) = 0, so **+6** [1]. N in NH₄Cl: NH₄⁺ has charge +1, so N + 4(+1) = +1 and N = **−3** [1]. Cl in ClO⁻: Cl + (−2) = −1, so **+1** [1].

**12.** Na stays +1, O stays −2, H stays +1, and N stays +5 (in HNO₃ and in NaNO₃) [1]. No element changes oxidation number, so the reaction is not redox [1].

**13.** Cathode: Na⁺ + e⁻ → Na [1]; sodium ions gain electrons, which is reduction [1]. Anode: 2Cl⁻ → Cl₂ + 2e⁻ [1]; chloride ions lose electrons, which is oxidation [1].

**14. (a)** Magnesium: 0 → +2, an increase, so magnesium is oxidised [1]. Carbon: +4 in CO₂ → 0 in C, a decrease, so carbon is reduced [1].

**(b)** Carbon dioxide [1].

## Where marks are usually lost

- Question 2: giving P as −3 by copying the charge on the ion. The whole ion has −3; phosphorus alone is +5.
- Question 3: writing FeO for iron(III) oxide. The numeral III means each iron is +3, so two Fe balance three O.
- Question 4: writing "is reduced" in a reducing agent definition. The agent is itself oxidised.
- Question 7(b): giving iron as +6 in Fe₂O₃ by not dividing by two.
- Question 7(c): naming iron(III) oxide as the reducing agent because "it is reduced". The substance reduced is the oxidising agent.
- Question 8(a): putting electrons on the wrong side. Loss of electrons appears on the right.
- Question 9(b): writing "the solution turns purple". Iodine in water gives a brown solution.
- Question 11: treating NH₄Cl as if N were combined with Cl directly. Split it into NH₄⁺ and Cl⁻ first.
- Question 14: saying oxygen is reduced. Oxygen stays at −2 throughout; it is the carbon whose oxidation number falls.
