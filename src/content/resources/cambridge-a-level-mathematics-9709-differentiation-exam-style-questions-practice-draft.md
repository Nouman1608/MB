## Questions

**1.** Find dy/dx for y = 5x⁴ − 8√x + 3/x². **[3]**

**2.** Find the gradient of the curve y = (3x − 2)⁴ at the point where x = 1. **[3]**

**3.** A curve has equation y = 2x³ − 9x² + 12x + 1.

**(a)** Find the coordinates of the stationary points of the curve. **[5]**

**(b)** Determine the nature of each stationary point. **[3]**

**4.** The curve y = x² + 6/x passes through the point P where x = 2.

**(a)** Find the equation of the tangent to the curve at P. **[4]**

**(b)** Find the equation of the normal to the curve at P. **[2]**

**(c)** Find the x-coordinate of the point where this normal crosses the x-axis. **[1]**

**5.** The function f is defined by f(x) = 2x³ − 3x² − 36x. Find the set of values of x for which f is a decreasing function. **[4]**

**6.** A circular patch of oil is spreading on water. Its radius r cm is increasing at a constant rate of 0.05 cm per second. Calculate the rate at which the area of the patch is increasing at the instant when r = 8. **[3]**

**7.** An open box has a square base of side x cm and a height of h cm. Its volume is 500 cm³.

**(a)** Show that the total external surface area, S cm², of the box is given by S = x² + 2000/x. **[3]**

**(b)** Find dS/dx and hence the value of x for which S is stationary. **[4]**

**(c)** Determine whether this stationary value of S is a maximum or a minimum. **[2]**

**(d)** State the stationary value of S. **[1]**

**8.** Find the coordinates of the points on the curve y = x³ − 3x² + 2x at which the tangent is parallel to the line y = 2x − 7. **[4]**

**9.** A student differentiates y = (2x + 1)³ and writes dy/dx = 3(2x + 1)².

**(a)** Explain the error in the student's working. **[1]**

**(b)** State the correct derivative. **[1]**

**(c)** State the gradient of the curve at the point where x = 1. **[1]**

**10.** The curve C has equation y = x³ − 12x.

**(a)** Verify that the point (2, −16) is a stationary point of C. **[2]**

**(b)** Determine the nature of this stationary point. **[2]**

## Answers

Marking key: **M** = method mark, **A** = accuracy mark (depends on the preceding M mark unless stated), **B** = independent mark. "ft" = follow through: a later mark can still be awarded for correct use of an earlier wrong value. Unsupported answers from a calculator score no marks except where a question says otherwise.

**1.** 20x³ [B1]; −4x^(−1/2) [B1]; −6x⁻³ [B1]. So dy/dx = **20x³ − 4x^(−1/2) − 6x⁻³**. (Accept −4/√x and −6/x³.)

**2.** dy/dx = 4(3x − 2)³ × 3 [M1]; = 12(3x − 2)³ [A1]; at x = 1: 12 × 1³ = **12** [A1].

**3.**

**(a)** dy/dx = 6x² − 18x + 12 [M1 A1]; set to zero: 6(x − 1)(x − 2) = 0 [M1]; x = 1 and x = 2 [A1]; y = 6 and y = 5, so the stationary points are **(1, 6)** and **(2, 5)** [A1].

**(b)** d²y/dx² = 12x − 18 [M1]; at x = 1 it is −6 and at x = 2 it is +6 [A1]; so **(1, 6) is a maximum and (2, 5) is a minimum** [A1]. (A correct gradient sign-change argument is also accepted.)

**4.**

**(a)** At x = 2, y = 4 + 3 = 7 [B1]; dy/dx = 2x − 6x⁻² [M1]; gradient at P = 4 − 1.5 = 2.5 [A1]; tangent: y − 7 = 2.5(x − 2), so **y = 2.5x + 2** [A1] (accept 5x − 2y + 4 = 0).

**(b)** Normal gradient = −1 ÷ 2.5 = −0.4 [M1]; y − 7 = −0.4(x − 2), so **y = −0.4x + 7.8** [A1] (accept 2x + 5y = 39).

**(c)** 0 = −0.4x + 7.8, so **x = 19.5** [1] (ft from (b) if the normal gradient is used correctly).

**5.** f′(x) = 6x² − 6x − 36 [M1 A1]; f is decreasing where f′(x) < 0: 6(x − 3)(x + 2) < 0 [M1]; **−2 < x < 3** [A1]. (Accept −2 < x < 3 written as x > −2 and x < 3; not "or".)

**6.** A = πr², so dA/dr = 2πr [M1]; dA/dt = dA/dr × dr/dt = 2π × 8 × 0.05 [M1]; = 0.8π = **2.51 cm² per second** [A1] (accept 0.8π).

**7.**

**(a)** h = 500 ÷ x² [B1]; S = x² + 4xh [M1]; S = x² + 4x × 500/x² = **x² + 2000/x** [A1] (the final step must be shown).

**(b)** dS/dx = 2x − 2000x⁻² [M1 A1]; set to zero: 2x³ = 2000, so x³ = 1000 [M1]; **x = 10** [A1].

**(c)** d²S/dx² = 2 + 4000x⁻³ [M1]; at x = 10 this is 6, which is positive, so the stationary value is a **minimum** [A1].

**(d)** S = 100 + 200 = **300 cm²** [1].

**8.** The line has gradient 2 [B1]; dy/dx = 3x² − 6x + 2 = 2 [M1]; 3x(x − 2) = 0, so x = 0 or x = 2 [A1]; the points are **(0, 0)** and **(2, 0)** [A1].

**9.**

**(a)** The chain rule has not been applied: the derivative of the inner function 2x + 1, which is 2, is missing [1].

**(b)** **6(2x + 1)²** [1].

**(c)** 6 × 3² = **54** [1].

**10.**

**(a)** At x = 2, y = 8 − 24 = −16, so the point is on C [B1]; dy/dx = 3x² − 12 = 12 − 12 = 0 [B1]. Both must be shown.

**(b)** d²y/dx² = 6x [M1]; at x = 2 it is 12, which is positive, so the point is a **minimum** [A1].

## Where marks are usually lost

- Differentiating a bracket to a power without multiplying by the derivative of the inside (question 2, question 9).
- Writing 6/x² or 1/√x in a form that cannot be differentiated; rewrite as a power of x first.
- Using the sign of the second derivative without stating the conclusion (maximum or minimum) in words.
- Forgetting the normal gradient is −1 divided by the tangent gradient.
- In "show that" questions, jumping to the printed result without the substitution step.
- Stating a range for a decreasing function with "or" instead of a single inequality.
