## The router in more detail

- **Connects networks to the internet**: links a home or school LAN to the internet service provider, so every device can share one connection.
- **Stores computer addresses**: keeps a table of the addresses of devices on the network (and of routes to other networks), so incoming data reaches the right device.
- **Routes data packets**: data is split into **packets**; each packet carries the destination address. The router reads the address and forwards the packet along the best available route. Packets may travel by different routes and are put back in order at the destination.

## Network devices

| Device | What it does | Key point |
|---|---|---|
| NIC | Lets a device connect to a network; has a unique hardware address | Wired or wireless versions |
| Hub | Sends incoming data to **every** connected device | Simple; extra traffic; less secure |
| Switch | Learns which device is on each port; sends data **only** to the intended device | Less traffic, faster, more secure than a hub |
| Bridge | Joins two network segments so they act as one network | Connects networks of the same type; does not connect to the internet |
| Router | Joins different networks, such as a LAN to the internet | Uses addresses to route packets |

## Wi-fi and Bluetooth

**Connecting with wi-fi**: turn on wi-fi → choose the network name from the list → enter the network password (key) → device receives an address and joins the network.

**Connecting with Bluetooth**: turn on Bluetooth on both devices → make one discoverable → select it on the other device → confirm a pairing code if asked → devices are paired and connect automatically next time.

| | Wi-fi | Bluetooth |
|---|---|---|
| Main purpose | Connecting devices to a network and the internet | Connecting two or a few devices directly |
| Range | Longer (whole building with access points) | Short (a room) |
| Data rate | Faster | Slower |
| Devices connected | Many | Few at once |
| Security | Password and encryption; larger range is easier to intercept | Pairing; shorter range is harder to intercept |
| Typical uses | Laptops, phones and smart TVs online; streaming | Headphones, keyboards, smartwatches, car hands-free, file sharing between phones |

**Similarities**: both are wireless, use radio waves, need devices in range and can be secured.

## Cloud computing

- **Characteristics**: data and software are stored on remote **servers** owned by a provider and reached over the internet; storage space can be increased as needed; often paid by subscription.
- **Storing**: files are uploaded to the provider's servers and usually copied to more than one data centre.
- **Managing**: the provider maintains hardware, security and backups; users organise files in a browser or app.
- **Sharing**: users send links or set permissions, so others can view or edit the same file; several people can work on a document at once.
- **Uses**: syncing photos and files, online office software, shared projects, backup.

| Advantages of cloud storage | Disadvantages of cloud storage |
|---|---|
| Access from any device with internet, anywhere | No internet connection means no access |
| No need to buy local storage hardware | Ongoing subscription cost |
| Provider handles maintenance and backups | Security depends on the provider; data could be hacked |
| Easy sharing and collaboration | Data may be stored in another country with different laws |
| Survives local fire, theft or device failure | Provider could lose data or stop the service |

## Internet, intranet, extranet

| | Internet | Intranet | Extranet |
|---|---|---|---|
| Who can use it | Anyone | Organisation's members | Authorised outsiders |
| Access | Public | Login inside the organisation | Login from outside |
| Content | Huge, unchecked | Internal, relevant, more reliable | Selected parts of the intranet |
| Purpose | Worldwide information and communication | Internal news, policies, documents | Working with partners, for example orders |

**Similarities**: all use internet technology (web pages, browsers, the same protocols); all can be accessed through a web browser.

## LAN, WLAN, WAN

- **LAN**: devices connected by cables within one building or site; fast; owned by the organisation.
- **WLAN**: a LAN using wireless access points instead of cables; flexible and mobile, but slower, shorter range and easier to intercept.
- **WAN**: networks connected over a large geographical area, often using third-party communication links; the internet is the largest WAN.

## Key terms

| Term | Meaning |
|---|---|
| Data packet | A small unit of data carrying a destination address |
| Wireless access point | Device that lets wireless devices join a wired network |
| Pairing | Setting up a trusted Bluetooth connection between two devices |
| Cloud computing | Using remote servers over the internet to store data and run software |
| Intranet | Private network for an organisation's members |
| Extranet | Part of an intranet opened to authorised outside users |

## Exam traps

- A hub sends data to **all** devices; a switch sends it to the **intended** device only.
- A bridge joins network segments; a router joins different networks, such as a LAN to the internet.
- Bluetooth links a few devices directly over a short range; for joining a network and the internet, wi-fi is the usual answer.
- "Cloud storage is safer" needs balancing: it depends on the provider's security.
- An extranet is not the internet: access is limited to authorised outsiders.

## Self-test

1. State the **three** functions of a router named in the syllabus.
2. What does a data packet contain that lets the router forward it?
3. Give **one** reason a switch is better than a hub.
4. State the purpose of a bridge.
5. List the steps to connect a laptop to a wi-fi network.
6. Give **two** differences between wi-fi and Bluetooth.
7. Give **two** uses of Bluetooth.
8. Describe how a file is shared using cloud computing.
9. Give **two** disadvantages of cloud storage compared with a portable hard drive.
10. State the difference between an intranet and an extranet.

## Self-test answers

1. Connecting networks and devices to the internet; storing computer addresses; routing data packets.
2. The destination address.
3. It sends data only to the intended device, reducing traffic and improving security.
4. To connect two network segments so they act as a single network.
5. Turn on wi-fi; select the network name; enter the password; the laptop joins the network.
6. Any two: wi-fi has a longer range; wi-fi is faster; wi-fi connects many devices to a network and the internet whereas Bluetooth connects a few devices directly.
7. Any two: wireless headphones, keyboards and mice, smartwatches, car hands-free, sending files between phones.
8. The file is uploaded to the provider's servers and a link or permission is given to others, who can open or edit it over the internet.
9. Any two: needs internet access; subscription cost; security depends on the provider; slow transfer on poor connections.
10. An intranet is for the organisation's own members; an extranet also lets authorised outside users log in.
