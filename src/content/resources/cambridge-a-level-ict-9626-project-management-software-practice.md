## Section A

**1.** State what is meant by collaborative project management software. **[2]**

**2.** Give **two** advantages of web-based project management software. **[2]**

**3.** Give **two** disadvantages of mobile project management software. **[2]**

**4.** Describe how project management software helps with scheduling of tasks. **[2]**

**5.** State **two** ways in which project management software supports communication. **[2]**

## Section B

**6.** A project has four tasks. Task A takes 3 days. Tasks B (6 days) and C (4 days) can only start when A has finished and can run side by side. Task D (2 days) can start only when both B and C have finished.

**(a)** Calculate the shortest time for the project. **[2]**

**(b)** Task A takes 5 days instead of 3. Calculate the new shortest time, and describe what the software does when this change is entered. **[3]**

**7.** A developer works 36 hours a week. The software shows she has been assigned tasks of 24, 20 and 16 hours in the same week.

**(a)** Calculate her total workload and her utilisation as a percentage of her available time, to the nearest whole number. **[3]**

**(b)** Describe **two** actions the manager could take. **[2]**

**8.** A company has 25 staff who will use project management software. A web-based collaborative tool costs £7 per user per month. A desktop package costs £280 per licence, paid once.

**(a)** Calculate the cost of the web-based tool for one year and for three years. **[3]**

**(b)** Calculate the cost of the desktop package. **[1]**

**(c)** State **two** factors, other than cost, that the company should consider. **[2]**

**9.** Distinguish between personal software and single-user software for project management, and give a situation where each is suitable. **[4]**

**10.** Explain how project management software helps a manager to control the costs of a project. **[4]**

**11.** A construction company has a site manager who walks around building sites and a head office team who plan the work. Recommend the types of project management software the company should use and justify your choice. **[6]**

**12.** Discuss the advantages and disadvantages of using project management software to support a project. **[6]**

**13.** A project manager says: "Now that we have the software, we do not need to monitor the project." Evaluate this statement. **[4]**

---

## Answers

**1.** Software that allows several users to work on the same project plan [1] at the same time, updating their own tasks, sharing files and seeing each other's changes [1]. **[2]**

**2.** Any two from: nothing to install [1]; accessible from any device with a browser [1]; updates are automatic [1]; everyone sees the same live plan [1]. **[2]**

**3.** Any two from: small screen makes charts hard to see or edit [1]; fewer features than desktop software [1]; limited by battery and signal [1]; project data is at risk if the device is lost [1]. **[2]**

**4.** The user enters the duration of each task and the dependencies between them [1], and the software works out the start and finish dates, draws a Gantt chart and recalculates them when a task changes [1]. **[2]**

**5.** Any two from: messaging and comments on tasks [1]; notifications of deadlines and changes [1]; shared calendars [1]; automatic progress reports [1]. **[2]**

**6. (a)** Longest path: A, B, D = 3 + 6 + 2 [1] = 11 days [1].

**(b)** 5 + 6 + 2 = 13 days [1]. The software recalculates the start and finish dates of tasks that depend on A [1] and shows the new project end date [1].

**7. (a)** 24 + 20 + 16 = 60 hours [1]; 60 ÷ 36 = 1.67 [1]; 167% [1].

**(b)** Any two from: give one task to another person [1]; extend the schedule [1]; add staff [1]; reduce the scope [1].

**8. (a)** 25 × 7 × 12 = £2,100 for one year [1]; 2,100 × 3 [1] = £6,300 for three years [1].

**(b)** 25 × 280 = £7,000 [1].

**(c)** Any two from: whether staff need to work offline [1]; features and ease of use [1]; security of data held by a provider [1]; training and support [1]; need for staff in different places to share one plan [1].

**9.** Personal software manages one person's own tasks and goals, with simple lists and calendars [1]; suitable for a student planning revision [1]. Single-user software is a full package used by one person, with Gantt charts, dependencies and budgets [1]; suitable for a project manager building a plan on one computer for a client [1]. **[4]**

**10.** The software stores a cost for each resource, such as a daily rate [1]. It adds up the costs of the tasks to give the total budget [1] and compares planned costs with actual costs [1], warning the manager when spending goes over budget, so action can be taken early [1]. **[4]**

**11.** Mobile software for the site manager [1], because updates, photographs and alerts can be made on site, wherever there is a signal [1]. Collaborative web-based software for the head office team and the site manager together [1], so that everyone works on the same live plan and sees changes at once [1]. Desktop software could be used by planners for detailed schedules and charts, because it has the most features and can work offline [1]. The data from all should be linked or exported to avoid several versions [1]. Maximum 6 marks. **[6]**

**12.** Advantages: schedules and costs are calculated and updated automatically, saving time [1]; all information is in one place [1]; early warnings of delays, clashes and overspending [1]; reports and charts are produced automatically [1]; supports teams in different places [1]. Disadvantages: cost of licences and training [1]; time to set up and enter data [1]; the plan is only as accurate as the data entered [1]; staff may not use it properly [1]; data held online may be at risk [1]. Maximum 6 marks. **[6]**

**13.** The statement is wrong [1]. The software only shows what has been entered, so someone has to update progress, costs and problems regularly [1]. The manager still has to review the information, decide what to do and report to stakeholders [1]. The software makes monitoring faster and more accurate, but cannot replace it [1]. **[4]**

## Where marks are usually lost

- Confusing the groupings by where the software runs and by who uses it.
- Giving general advantages such as "it saves time" without a feature.
- Forgetting the internet connection needed for web-based tools.
- Stating a type of software for a scenario without a reason linked to it.
- Treating the software as a replacement for the manager's judgement.
