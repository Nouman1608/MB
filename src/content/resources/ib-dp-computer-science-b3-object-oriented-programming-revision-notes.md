B.3 Object oriented programming (OOP) is a Theme B sub-topic of IB DP Computer Science (first assessment 2027), studied for 7 hours at SL and 23 hours at HL and examined on Paper 2, with extra HL questions on OOP. These notes summarise what the IB's public subject brief says. The brief does not list B.3's learning outcomes; those are in the full DP guide, so build your revision checklist from your school's copy.

Full explanation: [B.3 Object oriented programming study guide](/resources/ib-dp-computer-science-b3-object-oriented-programming/).

## Key facts from the subject brief

| Item | What the brief says |
|---|---|
| Theme | B, "Computational thinking and problem-solving" |
| Teaching hours | 7 SL / 23 HL |
| SL assessment | Paper 2 covers the three Theme B topics for SL and HL (B.1, B.2, B.3) |
| HL assessment | Paper 2 also has additional HL questions on OOP and abstract data types |
| Paper 2 timing | SL 1 h 15 min (35%); HL 2 h (40%) |
| Language | Java or Python; programming questions have equivalent versions in each |

## What the numbers mean for revision

- **SL**: 7 hours is a modest allocation, so expect B.3 to be a smaller part of Paper 2 than B.2 Programming (40 hours).
- **HL**: 23 hours, more than three times the SL time, plus dedicated HL questions. Treat B.3 as a major HL topic alongside B.4 (23 hours).
- **Both levels**: Paper 2 can require you to write code, so practise OOP in the language your course uses.

## General background (not the IB outcome list)

In object oriented programming a **class** describes the attributes (data) and methods (behaviour) of a kind of thing, and an **object** is one instance of that class. Java and Python both support classes and objects. Check the full guide for the exact OOP features and vocabulary B.3 requires at SL and at HL.

## Revision checklist to build with your teacher

1. Copy the B.3 learning outcomes from the full guide, marking which are HL only.
2. For each outcome, write one short program in your course language that demonstrates it.
3. Practise reading and predicting the output of object oriented code.
4. Apply the B.1 process when designing classes: specify, decompose, abstract, test and evaluate.
5. HL: work through longer, multi-part OOP problems under timed conditions.

## Common mistakes and exam traps

- Assuming OOP is HL only. The brief lists B.3 with 7 SL hours, and SL Paper 2 covers all three SL Theme B topics.
- Revising OOP from a different syllabus's list and assuming it matches the IB's. Use the full guide.
- Learning definitions without writing code; Paper 2 includes programming questions.

## Frequently asked questions

**How many hours is B.3 at HL?**
23 hours, compared with 7 at SL.

**Which paper tests OOP?**
Paper 2, at both levels, with additional HL questions focused on OOP and abstract data types.

**Can I answer in Python?**
Yes. The brief says programming questions have equivalent Java and Python versions.
