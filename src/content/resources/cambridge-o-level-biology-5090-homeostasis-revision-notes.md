These notes condense subtopic **14.4 Homeostasis** of Cambridge O Level Biology 5090, 2026-2028 series: the definition of homeostasis, the idea of a set point, and how negative feedback keeps a condition steady. The full explanations and worked examples are in the [14.4 study guide](/resources/cambridge-o-level-biology-5090-homeostasis/). Then try the [14.4 practice questions](/resources/cambridge-o-level-biology-5090-homeostasis-practice/).

## Key facts

| Item | Fact |
|---|---|
| Homeostasis | The maintenance of a constant internal environment |
| Internal environment | The blood and tissue fluid surrounding the cells |
| Set point | The normal level or target value of a condition |
| Negative feedback | A change triggers a response that reverses the change and returns the condition to the set point |

## What is kept constant

| Condition | Approximate set point or note |
|---|---|
| Core body temperature | About 37 degrees Celsius |
| Blood glucose concentration | Kept within narrow limits (see blood glucose control) |
| Water content of the blood | Kept balanced by the kidneys |
| Carbon dioxide in the blood | Linked to breathing rate |

The value is not perfectly fixed. It varies slightly above and below the set point.

## Why it matters

- Enzymes work best at an optimum temperature and pH.
- Cells need a steady glucose supply for respiration.
- Cells need the right water content to avoid swelling or shrinking by osmosis.
- The body can work normally when the outside environment changes.

## The parts of a feedback loop

| Part | Role |
|---|---|
| Receptor | Detects the change from the set point |
| Control centre | Compares the value with the set point (for temperature, the hypothalamus) |
| Effector | Carries out the corrective response |
| Response | Reverses the change |

## Negative feedback in steps

**If the condition rises above the set point:**

1. Receptors detect the rise.
2. The control centre signals the effectors.
3. The effectors produce a response that lowers the condition.
4. The condition returns to the set point and the response reduces.

**If the condition falls below the set point:**

1. Receptors detect the fall.
2. The control centre signals the effectors.
3. The effectors produce a response that raises the condition.
4. The condition returns to the set point and the response reduces.

## Examples to learn

| Condition | Change | Corrective response |
|---|---|---|
| Body temperature | Rises | Sweating, vasodilation |
| Body temperature | Falls | Shivering, vasoconstriction, hair erection |
| Blood glucose | Rises | Insulin released; glucose taken up by the liver |
| Blood glucose | Falls | Glucagon released; glucose released by the liver |

The details of these responses are covered in the next two subtopics.

## Thermostat analogy

- Set temperature: the set point.
- Thermometer in the thermostat: the receptor.
- Control switch: the control centre.
- Heater: the effector.
- Room warms to the set temperature, so the heater switches off.

Use the analogy for understanding. In an answer about the body, use the biological terms.

## Worked calculation

*Blood glucose concentration is 85 mg per 100 cm3 before a meal and rises to 125 mg per 100 cm3 afterwards. Find the percentage increase.*

1. Increase = 125 - 85 = 40 mg per 100 cm3.
2. Percentage = 40 divided by 85 x 100 = 47.1 per cent (to one decimal place).

Divide by the value before the change (the starting value).

## Reading a graph of a controlled variable

| Feature of the graph | Meaning |
|---|---|
| Line wiggles around a horizontal level | Negative feedback working; the level is the set point |
| A rise followed by a fall back | The response has reversed the change |
| A line that keeps rising | The control has failed or been overwhelmed |
| A flat, perfectly straight line | Not realistic for a living system |

## Short model answers

**Define homeostasis.** The maintenance of a constant internal environment.

**Explain what is meant by negative feedback.** A change in a condition triggers a response that reverses the change and returns the condition to its set point.

**Explain why a set point is needed.** The control system needs a target value to compare the actual value against, so it can tell when a correction is needed and when to stop.

**Explain why constant body temperature is important.** Enzymes work best at an optimum temperature, so a steady temperature keeps the reactions of the cells working.

**Describe the response when the core temperature rises.** Receptors detect the rise and the brain signals effectors, such as sweat glands, which cool the body until the temperature returns to the set point.

## Exam traps

- Homeostasis is the **maintenance of a constant internal environment**, not "keeping the body the same as the outside".
- The correction must **reverse** the change, then **stop** at the set point.
- "Negative" does not mean harmful.
- Include the **receptor** and the **effector** in a description.
- The internal environment is the blood and tissue fluid.
- Do not write that the value is absolutely fixed; it stays within narrow limits.
- Use the starting value as the divisor in a percentage change.
- Do not mix up the two directions of response (rise and fall).
