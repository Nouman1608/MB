## Key terms

| Term | Meaning |
|---|---|
| Gradient m | Change in y ÷ change in x; the steepness and direction of a line |
| y-intercept c | Where the line crosses the y-axis, at (0, c) |
| x-intercept | Where the line crosses the x-axis; put y = 0 |
| Parallel | Same gradient, never meet |
| Perpendicular | Meet at 90°; gradients multiply to −1 |
| Negative reciprocal | −1/m; the perpendicular gradient |
| Tangent | A line touching a circle at one point; perpendicular to the radius there |
| Rate of change | What a gradient means in context, in units of y per unit of x |

## Core formulae

```
y = mx + c
m = (y₂ − y₁)/(x₂ − x₁)
perpendicular gradient = −1/m      (m₁ × m₂ = −1)
midpoint of (x₁, y₁) and (x₂, y₂) = ((x₁ + x₂)/2, (y₁ + y₂)/2)
```

## Gradient

| Line shape | Gradient |
|---|---|
| Rises left to right | Positive |
| Falls left to right | Negative |
| Horizontal (y = k) | 0 |
| Vertical (x = k) | Undefined; not of the form y = mx + c |

From a graph: two grid-exact points far apart, rise ÷ run using the axis scales.

## Finding an equation

```
Two points:      1. m from the formula   2. substitute one point for c   3. write y = mx + c
Point + gradient: substitute the point into y = mx + c to find c
Check:           the other point must satisfy the equation
```

Reminder: through (1, 5) and (3, 11): m = 6/2 = 3; 5 = 3 + c, so c = 2; y = 3x + 2. Check (3, 11): 9 + 2 = 11.

Reminder: rearranging 3x + 4y = 12 gives 4y = −3x + 12, y = −0.75x + 3.

## Interpreting in context

- Gradient = rate, with units: "£12 per day", "−3 litres per minute".
- Intercept = starting or fixed value when x = 0: "fixed charge of £40", "the tank starts with 60 litres".
- A negative gradient in context means the quantity is decreasing.

## Parallel lines

Same m. Line parallel to y = 4x − 1 through (2, 3): 3 = 8 + c, c = −5, so y = 4x − 5.

## Perpendicular lines (Higher tier only)

Flip the fraction and change the sign.

| m | 5 | −2 | 3/4 | −1/3 |
|---|---|---|---|---|
| −1/m | −1/5 | 1/2 | −4/3 | 3 |

Reminder: perpendicular to y = 2x + 1 through (4, 1): m = −1/2, 1 = −2 + c, c = 3, so y = −x/2 + 3.

Perpendicular bisector of AB: midpoint of AB, then the negative reciprocal of the gradient of AB.

## Tangent to x² + y² = r² (Higher tier only)

```
1. Check the point is on the circle.
2. Gradient of radius = y/x of the point (centre at origin).
3. Tangent gradient = negative reciprocal.
4. Substitute the point to find c.
```

Reminder: x² + y² = 10 at (3, 1): radius gradient 1/3, tangent gradient −3, 1 = −9 + c, c = 10, so y = −3x + 10.

## Regions (Higher tier only)

y > mx + c: above the line, dashed. y ≤ mx + c: below the line, solid. Otherwise test (0, 0).

## Exam traps

- Counting squares when the two axes have different scales.
- Upside-down gradient (run over rise).
- Sign slips with negative coordinates: subtract in brackets.
- Comparing gradients before every equation is in y = mx + c form.
- Perpendicular gradient with only the sign changed or only the fraction flipped.
- Radius gradient used as the tangent gradient.
- Interpreting a gradient as a plain number with no units.
- Leaving an answer as m = 3, c = 2 rather than y = 3x + 2.

## Quick self-test

1. Find the gradient of the line through (2, −1) and (6, 7).
2. Write down the gradient and y-intercept of y = 5 − 2x.
3. Find the gradient and y-intercept of 3x + 4y = 12.
4. Find the equation of the line through (1, 5) and (3, 11).
5. Does (−3, −7) lie on y = 3x + 2?
6. Find where 2x − 5y = 10 crosses each axis.
7. Find the equation of the line parallel to y = 4x − 1 through (2, 3).
8. A taxi fare F (£) for d miles is F = 1.8d + 3.5. Interpret 1.8 and 3.5. (Prices invented.)
9. (Higher tier only) Write down the gradient of a line perpendicular to y = (3/4)x − 2.
10. (Higher tier only) Find the equation of the line perpendicular to y = 2x + 1 through (4, 1).
11. (Higher tier only) Are y = 3x + 1 and x + 3y = 6 perpendicular?
12. (Higher tier only) Find the tangent to x² + y² = 10 at (3, 1).

### Answers

1. 8/4 = 2
2. Gradient −2, intercept 5
3. y = −0.75x + 3: gradient −3/4, intercept 3
4. y = 3x + 2
5. 3(−3) + 2 = −7, so yes
6. x-axis at (5, 0); y-axis at (0, −2)
7. y = 4x − 5
8. 1.8 is the cost per mile, £1.80; 3.5 is a fixed charge of £3.50
9. −4/3
10. y = −x/2 + 3
11. x + 3y = 6 gives y = −x/3 + 2; 3 × (−1/3) = −1, so yes
12. y = −3x + 10
