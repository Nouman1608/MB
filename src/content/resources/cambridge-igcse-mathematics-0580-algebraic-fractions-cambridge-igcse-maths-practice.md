These questions cover subtopic **2.3 Algebraic fractions** in the Cambridge IGCSE Mathematics 0580 syllabus for examination in 2025, 2026 and 2027. The subtopic is **Extended only** (E2.3), so every question here is Extended content for Papers 2 and 4. None of them needs a calculator. Give every answer in its simplest form.

For explanations, read the [algebraic fractions study guide](/resources/cambridge-igcse-mathematics-0580-algebraic-fractions-cambridge-igcse-maths/); for a one-page summary, use the [algebraic fractions revision notes](/resources/cambridge-igcse-mathematics-0580-algebraic-fractions-cambridge-igcse-maths-revision-notes/).

## Questions

### Section A: short questions

**1.** Simplify 12a³b²/(18ab⁴). **[2]**

**2.** Simplify (5x − 15)/(x² − 3x). **[2]**

**3.** Simplify (x² − 49)/(x² + 4x − 21). **[3]**

**4.** Write (x + 3)/2 + (x − 4)/5 as a single fraction. **[2]**

**5.** Write (2x − 1)/3 − (x + 4)/4 as a single fraction. **[3]**

**6.** Simplify (4x/9) ÷ (2x²/3). **[2]**

### Section B: structured questions

**7.** Simplify (3x² + 5x − 2)/(9x² − 1). **[3]**

**8.** Write 4/(x − 1) − 3/(x + 2) as a single fraction in its simplest form. **[3]**

**9.** Write 2/(x + 3) + (x − 1)/(x² + 3x) as a single fraction in its simplest form. **[3]**

**10.**

**(a)** Factorise completely 2x² − 8. **[2]**

**(b)** Hence simplify (2x² − 8)/(x² + x − 6) × (x + 3)/(4x + 8). **[3]**

**11.**

**(a)** Show that x/(x − 4) − 16/(x² − 4x) simplifies to (x + 4)/x. **[4]**

**(b)** Hence solve the equation x/(x − 4) − 16/(x² − 4x) = 3. **[2]**

**12.** Simplify ((x² − 5x)/(x² − 25)) ÷ (2x/(x² + 10x + 25)). **[4]**

**13.** A cyclist rides 60 km to a town at x km/h and returns along the same road at (x − 10) km/h.

**(a)** Write an expression for the total time taken, in hours, as a single fraction in its simplest form. **[3]**

**(b)** Use your expression to find the total time when x = 40. **[1]**

## Answers

**1.** Numbers: 12/18 = 2/3 [1]. Letters: a³/a = a², b²/b⁴ = 1/b². Answer **2a²/(3b²)** [1].

**2.** 5(x − 3)/(x(x − 3)) [1] = **5/x** [1].

**3.** Numerator (x − 7)(x + 7) [1]. Denominator (x + 7)(x − 3) [1]. Answer **(x − 7)/(x − 3)** [1].

**4.** (5(x + 3) + 2(x − 4))/10 = (5x + 15 + 2x − 8)/10 [1] = **(7x + 7)/10**, or 7(x + 1)/10 [1].

**5.** Common denominator 12 [1]. 4(2x − 1) − 3(x + 4) = 8x − 4 − 3x − 12 [1]. Answer **(5x − 16)/12** [1].
*Examiner insight:* −3(x + 4) is −3x − 12. Candidates who write −3x + 4 have not multiplied the second term of the bracket.

**6.** (4x/9) × (3/(2x²)) [1] = 12x/(18x²) = **2/(3x)** [1].

**7.** Numerator: ac = −6, numbers 6 and −1, giving (3x − 1)(x + 2) [1]. Denominator: (3x − 1)(3x + 1) [1]. Answer **(x + 2)/(3x + 1)** [1].

**8.** Common denominator (x − 1)(x + 2) [1]. 4(x + 2) − 3(x − 1) = 4x + 8 − 3x + 3 = x + 11 [1]. Answer **(x + 11)/((x − 1)(x + 2))** [1].

**9.** x² + 3x = x(x + 3), so the lowest common denominator is x(x + 3) [1]. 2x + x − 1 = 3x − 1 [1]. Answer **(3x − 1)/(x(x + 3))** [1].
*Examiner insight:* using (x + 3) × x(x + 3) as the denominator leads to a correct but unsimplified answer; the final mark needs the simplest form.

**10. (a)** 2(x² − 4) [1] = **2(x − 2)(x + 2)** [1].

**(b)** x² + x − 6 = (x + 3)(x − 2) and 4x + 8 = 4(x + 2) [1]. 2(x − 2)(x + 2)/((x + 3)(x − 2)) × (x + 3)/(4(x + 2)) [1]. Every bracket cancels, leaving 2/4 = **1/2** [1].

**11. (a)** x² − 4x = x(x − 4) [1]. Over x(x − 4): x × x − 16 = x² − 16 [1]. x² − 16 = (x − 4)(x + 4) [1]. (x − 4)(x + 4)/(x(x − 4)) = **(x + 4)/x** [1].

**(b)** (x + 4)/x = 3, so x + 4 = 3x [1], giving **x = 2** [1] (allowed, since x is not 0 or 4).

**12.** x² − 5x = x(x − 5) and x² − 25 = (x − 5)(x + 5) [1]. x² + 10x + 25 = (x + 5)² [1]. x(x − 5)/((x − 5)(x + 5)) × (x + 5)²/(2x) [1] = **(x + 5)/2** [1].
*Examiner insight:* invert the second fraction only, and do it after factorising so the matching brackets are easy to see.

**13. (a)** Time = distance ÷ speed: 60/x + 60/(x − 10) [1]. (60(x − 10) + 60x)/(x(x − 10)) = (120x − 600)/(x(x − 10)) [1] = **120(x − 5)/(x(x − 10))** [1].

**(b)** 120 × 35/(40 × 30) = 4200/1200 = **3.5 hours** [1] (check: 60/40 + 60/30 = 1.5 + 2).

## Where marks are usually lost

- Cancelling terms instead of factors, such as the x² in (x² − 49)/(x² + 4x − 21).
- Losing a sign when a numerator is subtracted.
- Inverting the wrong fraction when dividing.
- Leaving an answer that still has a common factor, as in Question 11.
- Not factorising the quadratic denominators before choosing a common denominator.
