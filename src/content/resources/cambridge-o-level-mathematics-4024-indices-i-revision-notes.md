Condensed notes for subtopic **1.7 Indices I** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025 to 2027. The [Indices I study guide](/resources/cambridge-o-level-mathematics-4024-indices-i/) explains each rule with worked examples; the [Indices I practice questions](/resources/cambridge-o-level-mathematics-4024-indices-i-practice/) give exam-style questions with mark schemes.

## Syllabus outcomes

1. Understand and use indices (positive, zero, negative and fractional).
2. Understand and use the rules of indices.

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Base | number being multiplied | 5 in 5³ |
| Index (power) | number of times the base is used | 3 in 5³ |
| Zero index | any non-zero base to power 0 is 1 | 9⁰ = 1 |
| Negative index | reciprocal of the positive power | 3⁻² = 1/9 |
| Fractional index | a root and a power | 8^(2/3) = 4 |
| Reciprocal | 1 divided by the number | reciprocal of 4 is 1/4 |

## Rules

| Rule | Example |
|---|---|
| a^m × a^n = a^(m+n) | 2⁻³ × 2⁴ = 2¹ = 2 |
| a^m ÷ a^n = a^(m-n) | 2³ ÷ 2⁴ = 2⁻¹ = 1/2 |
| (a^m)^n = a^(mn) | (2³)² = 2⁶ = 64 |
| a⁰ = 1 | 17⁰ = 1 |
| a^(-n) = 1/a^n | 7⁻² = 1/49 |
| a^(1/n) = n-th root of a | 16^(1/4) = 2 |
| a^(m/n) = (n-th root of a)^m | 8^(2/3) = 4 |
| (a/b)^(-n) = (b/a)^n | (2/3)⁻² = 9/4 |

The bases must be the same to add or subtract indices.

## Order of steps for fractional and negative indices

1. Negative: take the reciprocal (flip a fraction).
2. Denominator: take that root.
3. Numerator: raise to that power.

| Value | Steps | Result |
|---|---|---|
| 27^(-2/3) | reciprocal; ∛27 = 3; 3² = 9 | 1/9 |
| (1/4)^(-3/2) | flip → 4^(3/2); √4 = 2; 2³ | 8 |
| 125^(-1/3) | reciprocal; ∛125 = 5 | 1/5 |
| 16^(3/4) | ⁴√16 = 2; 2³ | 8 |
| 9^(-1/2) | reciprocal; √9 = 3 | 1/3 |
| 32^(2/5) | ⁵√32 = 2; 2² | 4 |
| (9/16)^(1/2) | root of top and bottom | 3/4 |
| 64^(-2/3) | reciprocal; ∛64 = 4; 4² = 16 | 1/16 |

## Combining rules: method

1. Write every number as a power of the same base (prime if possible).
2. Add indices for ×, subtract for ÷, multiply for a power of a power.
3. Evaluate. Give a fraction answer where the index is negative.

```
3^5 x 3^-2 ÷ 3^4 = 3^(5 - 2 - 4) = 3^-1 = 1/3
(2^-3 x 16) ÷ 4  = 2^(-3 + 4 - 2) = 2^-1 = 1/2
16^(3/4) - 9^(-1/2) = 8 - 1/3 = 7 2/3
25^(-1/2) x 10^2 = 1/5 x 100 = 20
```

## Index equations: simple cases

Find n when the base can be matched.

| Equation | Working | n |
|---|---|---|
| 2ⁿ = 1/32 | 1/32 = 2⁻⁵ | -5 |
| 3ⁿ = 81 | 81 = 3⁴ | 4 |
| 4ⁿ = 8 | 2²ⁿ = 2³ | 3/2 |
| 5ⁿ = 1 | 5⁰ = 1 | 0 |
| 10ⁿ = 0.001 | 10⁻³ | -3 |

## Calculator (Paper 2)

Put a fractional index in brackets: 12^(3/2) = 41.569... = 41.6 (3 s.f.). Use exact values (not decimals) when the question says "show".

## Why the rules work

| Rule | Reason | Check |
|---|---|---|
| Add when multiplying | counting factors | 2⁴ × 2⁵ = 2⁹ |
| Subtract when dividing | cancelling factors | 2⁶ ÷ 2² = 2⁴ |
| Multiply for power of power | groups of factors | (2³)² = 2⁶ |
| a⁰ = 1 | a³ ÷ a³ = 1 | 5⁰ = 1 |
| a⁻ⁿ = 1/aⁿ | a² ÷ a⁵ = 1/a³ | 5⁻² = 1/25 |
| a^(1/2) = √a | a^(1/2) × a^(1/2) = a | 9^(1/2) = 3 |

## Exam traps

- 2⁻³ = 1/8, not -8 and not -6.
- 2³ = 8, not 6.
- 3 × 5⁰ = 3, but (3 × 5)⁰ = 1.
- 2³ × 3² cannot be written with one base. Work it out: 8 × 9 = 72.
- (2/3)⁻² = 9/4: flip the fraction as well as squaring.
- 8^(2/3): cube root first (2), then square (4).
- Subtracting a negative index: 2³ ÷ 2⁻² = 2⁵.
- Check the final form: fraction, whole number or power as requested.

## Self-test

1. Find the value of 3⁻⁴.
2. Find the value of 10⁻⁵ as a decimal.
3. Find the value of (3/5)⁻¹.
4. Find the value of 36^(1/2).
5. Find the value of 125^(2/3).
6. Find the value of 16^(-3/4).
7. Simplify 5⁴ × 5⁻⁶ as a fraction.
8. Work out 2⁵ ÷ 2⁻².
9. Find n if 3ⁿ = 1/9.
10. Work out (4^(1/2))³ ÷ 2².

**Answers**

1. **1/81**.
2. **0.00001**.
3. **5/3**.
4. **6**.
5. (∛125)² = 5² = **25**.
6. 1/(⁴√16)³ = 1/8 = **1/8**.
7. 5⁻² = **1/25**.
8. 2⁷ = **128**.
9. 3⁻² = 1/9, so **n = -2**.
10. 2³ ÷ 4 = 8 ÷ 4 = **2**.
