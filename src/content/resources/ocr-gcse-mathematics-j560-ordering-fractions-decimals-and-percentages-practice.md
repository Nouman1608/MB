## Section A: short questions

**1.** Write these numbers in order, smallest first: 0.29, 3/10, 28%, 0.2 **[2]**

**2.** Write these numbers in order, smallest first: −2, 1/4, −0.3, 0 **[1]**

**3.** Insert <, > or = between each pair.

**(a)** 4/5 ... 0.8 **[1]**

**(b)** 0.09 ... 0.9% **[1]**

**(c)** 5/6 ... 0.83 **[1]**

**4.** Which is larger, 7/9 or 11/14? Show how you decide. **[2]**

**5.** Write down a decimal that lies between 0.35 and 0.36. **[1]**

**6.** Write down a fraction that lies between 1/4 and 1/3. **[1]**

## Section B: structured questions

**7.** Write these numbers in order, largest first: 5/12, 0.42, 41.5%, 0.4166 **[3]**

**8.** Write these numbers in order, smallest first: −1/3, −0.35, −30%, −0.333 **[3]**

**9.** Write these numbers in order, smallest first: 7/5, 135%, 1 3/8, 1.42 **[2]**

**10.** Four students took the same test. Their results were:

Ana 31/40, Ben 0.78 of the marks, Cara 76%, Dev 47/60.

**(a)** List the students in order of their results, highest first. **[3]**

**(b)** The pass mark is "at least 77%". Write this as an inequality using s for a student's percentage. **[1]**

**(c)** Which students passed? **[1]**

**11.** Mo says, "0.6 is less than 0.58, because 58 is bigger than 6."

**(a)** Explain why Mo is wrong. **[1]**

**(b)** Write 0.6, 0.58 and 0.605 in order, smallest first. **[1]**

**12.** List all the integers n such that −4 ≤ n < 1. **[2]**

**13.** Jen says, "2/3 = 0.67."

**(a)** Write a correct statement comparing 2/3 and 0.67 using the symbol ≠. **[1]**

**(b)** Write 2/3, 0.67, 0.6 and 0.66 in order, smallest first. **[2]**

**14.** Find the fraction with denominator 20 that lies between 0.6 and 2/3. **[2]**

## Answers

**1.** Converted to one form, for example 0.29, 0.30, 0.28, 0.20 [1]; **0.2, 28%, 0.29, 3/10** [1] **[2]**

*Examiner insight:* Write 0.2 as 0.20 so that it is compared with 0.28 and 0.29 correctly.

**2.** **−2, −0.3, 0, 1/4** [1] **[1]**

*Examiner insight:* −2 is further from zero than −0.3, so it is smaller.

**3. (a)** **=** [1]

**(b)** 0.9% = 0.009, so **>** [1]

**(c)** 5/6 = 0.8333..., so **>** [1] **[3]**

*Examiner insight:* In part (b), divide the percentage by 100 before comparing: 0.9% is far smaller than 0.09.

**4.** 7 × 14 = 98 and 9 × 11 = 99 (or 98/126 and 99/126) [1]; **11/14** is larger [1] **[2]**

*Examiner insight:* Cross-multiplying avoids two long divisions. As decimals the values are 0.7777... and 0.7857..., which confirms the result.

**5.** Any decimal strictly between, such as **0.355** [1] **[1]**

*Examiner insight:* Adding a third decimal place creates room: 0.350 to 0.360.

**6.** Any correct fraction, such as **7/24** (1/4 = 6/24 and 1/3 = 8/24) [1] **[1]**

*Examiner insight:* Over twelfths, 3/12 and 4/12 leave no gap, so double the denominator to 24.

**7.** 5/12 = 0.41666... [1]; values 0.4167, 0.4200, 0.4150, 0.4166 compared to four places [1]; **0.42, 5/12, 0.4166, 41.5%** [1] **[3]**

*Examiner insight:* 5/12 is just larger than 0.4166, because its 6s continue for ever.

**8.** Values −0.3333..., −0.35, −0.30, −0.333 [1]; recognising that the larger size is the smaller number [1]; **−0.35, −1/3, −0.333, −30%** [1] **[3]**

*Examiner insight:* −1/3 is smaller than −0.333, because 1/3 is slightly larger than 0.333.

**9.** Values 1.4, 1.35, 1.375, 1.42 [1]; **135%, 1 3/8, 7/5, 1.42** [1] **[2]**

*Examiner insight:* Percentages over 100% and improper fractions convert in the usual way: 135% = 1.35 and 7/5 = 1.4.

**10. (a)** Ana 0.775 and Dev 0.7833... [1]; all four compared, with Ben 0.78 and Cara 0.76 [1]; **Dev, Ben, Ana, Cara** [1]

**(b)** **s ≥ 77** (s in per cent) [1]

**(c)** **Dev, Ben and Ana** [1] **[5]**

*Examiner insight:* "At least" includes the boundary, so ≥ is needed rather than >. Ana's 77.5% passes.

**11. (a)** 0.6 = 0.60, and 60 hundredths is more than 58 hundredths, so 0.6 > 0.58 [1]

**(b)** **0.58, 0.6, 0.605** [1] **[2]**

*Examiner insight:* Compare digits in the same place: the tenths digit 6 beats the tenths digit 5.

**12.** −4 included and 1 excluded [1]; **−4, −3, −2, −1, 0** [1] **[2]**

*Examiner insight:* The ≤ includes −4. The < stops before 1.

**13. (a)** **2/3 ≠ 0.67** [1]

**(b)** 2/3 = 0.6666... [1]; **0.6, 0.66, 2/3, 0.67** [1] **[3]**

*Examiner insight:* 0.67 is a rounded value of 2/3, not an equal one.

**14.** 0.6 = 12/20 and 2/3 = 13.33.../20 [1]; **13/20** [1] **[2]**

*Examiner insight:* Check: 13/20 = 0.65, which is between 0.6 and 0.666...

## Where marks are usually lost

- Comparing decimals with different numbers of places without padding them.
- Ordering negative numbers by the size of their digits.
- Writing the final answer in converted decimals instead of the original forms.
- Stopping at two decimal places when values agree there.
- Treating a rounded decimal such as 0.67 as equal to 2/3.
- Using > for "at least", or < for "at most".
- Including an end value that a strict symbol excludes.
