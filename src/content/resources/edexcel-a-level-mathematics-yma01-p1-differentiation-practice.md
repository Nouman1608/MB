## Section A

**1.** Given y = 2x⁵ − 6x + 9, find dy/dx. **[2]**

**2.** Given f(x) = 4/√x + 3x^(2/3), x > 0, find f′(x). **[3]**

**3.** Given y = (3 − 2x)², find dy/dx. **[2]**

**4.** Given y = (x⁴ − 5x)/(2x²), x ≠ 0, find dy/dx. **[3]**

**5.** Given f(x) = 2x³ − 6√x, x > 0, find f″(x). **[3]**

## Section B

**6.** Prove, from first principles, that the derivative of 2x² − 5x is 4x − 5. **[4]**

**7.** The curve C has equation y = x³ − 5x² + 4x + 3.

**(a)** Find the gradient of C at the point where x = 3. **[2]**

**(b)** Find the x-coordinates of the points on C where the gradient is −4. **[3]**

**8.** The curve C has equation y = x² + 16/x, x ≠ 0. The point P on C has x-coordinate 4.

**(a)** Find an equation of the tangent to C at P, in the form y = mx + c. **[4]**

**(b)** The normal to C at P meets the x-axis at Q. Find the x-coordinate of Q. **[3]**

**9.** The curve y = 3√x − x, x > 0, meets the x-axis at the point A where x = 9. The tangent to the curve at A meets the y-axis at B, and O is the origin. Find the area of triangle OAB. **[5]**

**10.** The curve y = px³ + qx², where p and q are constants, has gradient 0 at the point where x = 2 and gradient 12 at the point where x = −2. Find p and q. **[4]**

**11.** The tangent to y = 2x² − 3x + 1 at the point R is perpendicular to the line x + 5y = 2. Find the coordinates of R and an equation of the tangent at R. **[4]**

**12.** The volume V cm³ of a spherical balloon of radius r cm is V = (4/3)πr³. Find dV/dr and its value when r = 3, and state what this value represents. **[3]**

**13.** The curve C has equation y = x² − 2x − 3. The normal to C at the point where x = 2 meets C again at the point S. Find the coordinates of S. **[6]**

## Answers

**1.** 10x⁴ [1] − 6, so **dy/dx = 10x⁴ − 6** [1]. **[2]**

**2.** f(x) = 4x^(−1/2) + 3x^(2/3) [1]. f′(x) = −2x^(−3/2) [1] + 2x^(−1/3), so **f′(x) = −2x^(−3/2) + 2x^(−1/3)** [1]. **[3]**

*Examiner insight:* The rewrite earns the first mark; with fractional powers, subtract 1 carefully: −½ − 1 = −3/2 and 2/3 − 1 = −1/3.

**3.** y = 9 − 12x + 4x² [1], so **dy/dx = 8x − 12** [1]. **[2]**

**4.** y = ½x² − (5/2)x^(−1) [1]. dy/dx = x [1] + (5/2)x^(−2), so **dy/dx = x + 5/(2x²)** [1]. **[3]**

*Examiner insight:* Split the fraction term by term over 2x²; differentiating numerator and denominator separately earns nothing.

**5.** f(x) = 2x³ − 6x^(1/2). f′(x) = 6x² − 3x^(−1/2) [1]. f″(x) = 12x [1] + (3/2)x^(−3/2), so **f″(x) = 12x + (3/2)x^(−3/2)** [1]. **[3]**

**6.** f(x + h) = 2(x + h)² − 5(x + h) = 2x² + 4xh + 2h² − 5x − 5h [1]. f(x + h) − f(x) = 4xh + 2h² − 5h [1]. Dividing by h: 4x + 2h − 5 [1]. As h → 0, f′(x) = lim(h→0) (4x + 2h − 5) = **4x − 5** [1]. **[4]**

*Examiner insight:* State the limit as h → 0 before the final answer. Putting h = 0 before dividing by h is not valid, because it would mean dividing by zero.

**7. (a)** dy/dx = 3x² − 10x + 4 [1]. At x = 3: 27 − 30 + 4 = **1** [1].

**(b)** 3x² − 10x + 4 = −4, so 3x² − 10x + 8 = 0 [1]. (3x − 4)(x − 2) = 0 [1], so **x = 4/3 or x = 2** [1]. **[5]**

**8. (a)** At x = 4, y = 16 + 4 = 20 [1]. dy/dx = 2x − 16x^(−2) [1]. At x = 4, the gradient is 8 − 1 = 7 [1]. y − 20 = 7(x − 4), so **y = 7x − 8** [1].

**(b)** Normal gradient −1/7 [1]. y − 20 = −(1/7)(x − 4); at Q, y = 0 so −140 = −(x − 4) [1], giving **x = 144** [1]. **[7]**

**9.** At x = 9, y = 9 − 9 = 0, confirming A(9, 0) [1]. dy/dx = (3/2)x^(−1/2) − 1 [1], which is ½ − 1 = −½ at x = 9 [1]. Tangent: y = −½(x − 9), so B is (0, 4.5) [1]. Area = ½ × 9 × 4.5 = **81/4 (20.25)** [1]. **[5]**

**10.** dy/dx = 3px² + 2qx [1]. At x = 2: 12p + 4q = 0. At x = −2: 12p − 4q = 12 [1]. Adding: 24p = 12, so **p = ½** [1], and then 6 + 4q = 0 gives **q = −3/2** [1]. **[4]**

**11.** The line x + 5y = 2 has gradient −1/5, so the tangent has gradient 5 [1]. dy/dx = 4x − 3 = 5, so x = 2 [1]. y = 8 − 6 + 1 = 3, so **R = (2, 3)** [1]. Tangent: y − 3 = 5(x − 2), so **y = 5x − 7** [1]. **[4]**

*Examiner insight:* "Perpendicular to the line" fixes the tangent's gradient as the negative reciprocal of the line's gradient; it is not the normal to the curve.

**12.** dV/dr = 4πr² [1]. At r = 3, dV/dr = **36π** (about 113) [1]. It is the rate at which the volume increases with radius, in cm³ per cm, when r = 3 [1]. **[3]**

**13.** At x = 2, y = 4 − 4 − 3 = −3 [1]. dy/dx = 2x − 2 = 2, so the normal gradient is −½ [1]. Normal: y + 3 = −½(x − 2), so y = −½x − 2 [1]. Solve x² − 2x − 3 = −½x − 2, giving 2x² − 3x − 2 = 0 [1]. (2x + 1)(x − 2) = 0, and x = 2 is P, so x = −½ [1]. y = ¼ − 2, so **S = (−½, −7/4)** [1]. **[6]**

*Examiner insight:* One root of the intersection equation is always the original point, which is a check on the algebra before you find the other.

## Where marks are usually lost

- Rewriting roots and reciprocals with the wrong power, especially 1/√x as x^(1/2).
- Differentiating brackets or fractions without expanding or splitting first.
- Substituting into dy/dx to find a y-coordinate.
- Using −m or 1/m for a normal gradient.
- First-principles answers with no limit statement.
- Forgetting that a tangent perpendicular to a given line uses that line's negative reciprocal gradient.

## Frequently asked questions

**How much working is needed in a first-principles proof?**
Every step: f(x + h) expanded, the subtraction, the division by h and the limit as h → 0. Each step carries a mark, so a proof that jumps to the answer scores little.

**Why are there no stationary-point questions here?**
In Edexcel IAL Mathematics, stationary points and increasing and decreasing functions are part of Pure Mathematics 2. P1 differentiation covers gradients, tangents, normals and second derivatives.

**Can a question ask for d²y/dx² without a reason?**
Yes. Reference 4.1 includes second order derivatives, so finding f″(x) can be asked on its own in P1.
