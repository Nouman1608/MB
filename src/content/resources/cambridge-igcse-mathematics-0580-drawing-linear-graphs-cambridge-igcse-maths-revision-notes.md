These notes condense subtopic **3.2 Drawing linear graphs** from Topic 3 of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. Both tiers must "Draw straight-line graphs for linear equations." Core equations are given as y = mx + c unless a table of values is provided; **Extended** adds forms such as y = 7 – 4x and 3x + 2y = 5, marked *(Extended)* below. For worked examples, read the [drawing linear graphs study guide](/resources/cambridge-igcse-mathematics-0580-drawing-linear-graphs-cambridge-igcse-maths/); for exam-style questions, use the [drawing linear graphs practice questions](/resources/cambridge-igcse-mathematics-0580-drawing-linear-graphs-cambridge-igcse-maths-practice/).

## The method

```
1. Read the x-range, e.g. -3 <= x <= 3.
2. Choose 3 x-values: both ends + one in the middle (x = 0 if possible).
3. Substitute each x into the equation. Use brackets for negatives.
4. Check the y-values change by a steady amount.
5. Plot small crosses. Rule ONE line across the whole range.
6. Label the line if there is more than one on the grid.
```

## Key terms

| Term | Meaning |
|---|---|
| Linear equation | x and y appear only to the power 1, with no xy term; the graph is a straight line |
| Table of values | x-values with the y-values worked out from the equation |
| Range | The x-values the line must cover, e.g. –2 ≤ x ≤ 4 |
| y-intercept | Where the line crosses the y-axis; the value of y when x = 0 |
| x-intercept | Where the line crosses the x-axis; the value of x when y = 0 |
| Horizontal line | y = k, every point has y-coordinate k |
| Vertical line | x = k, every point has x-coordinate k |

## Choosing x-values

| Coefficient of x | Pick x-values that are |
|---|---|
| a whole number | any; include the range ends |
| ½ or a multiple of ½ | even |
| 1/3, 2/3 | multiples of 3 |
| 0.2, 0.4, 0.6 | multiples of 5 |
| 0.25, 0.75 | multiples of 4 |

*(Extended)* For ax + by = c with b not 1, choose x so that c – ax divides exactly by b.

## Quick table check

Equally spaced x-values give equally spaced y-values.

```
y = 3x - 4
x: -2   -1    0    1    2
y: -10  -7   -4   -1    2     (steps of +3: consistent)
```

A step that differs from the rest marks the wrong value. Recalculate that one only.

## Lines with one letter

```
y = 4    horizontal, through (0, 4)
y = -1   horizontal, through (0, -1)
x = 2    vertical,   through (2, 0)
x = -3   vertical,   through (-3, 0)
x-axis:  y = 0       y-axis:  x = 0
```

Memory check: write two points. y = 4 gives (1, 4) and (5, 4): same height, so it goes across.

## *(Extended)* Other forms

```
y = 7 - 4x        substitute directly; multiply first, then subtract from 7
3x + 2y = 5       y = (5 - 3x) / 2    use odd x: (-1, 4), (1, 1), (3, -2)
x - 2y = 4        y = (x - 4) / 2     (-2, -3), (0, -2), (4, 0), (6, 1)
2x + 5y = 10      axis crossings: (0, 2) and (5, 0); check x = -5 gives y = 4
```

When both axis crossings are whole numbers, setting x = 0 then y = 0 is the fastest method. When one is a fraction, use the rearranged form instead.

## When the line leaves the grid

If a y-value is beyond the printed axis:

1. Recheck the arithmetic.
2. If it is correct, find where the line meets the edge: set y equal to the edge value and solve for x.
3. Draw the line only as far as the edge.

## Exam traps

- Drawing y = k as a vertical line, or x = k as a horizontal one.
- Plotting only two points, so one error goes unnoticed.
- Stopping the line at the last plotted point instead of the end of the range.
- –3 × –2 worked out as –6. Brackets round negative x-values prevent this.
- Leaving a gap in a printed table because the line "is already drawn".
- *(Extended)* Dividing only one term by the coefficient of y: 2y = 5 – 3x becomes y = 5 – 1.5x, which is wrong.
- *(Extended)* Reading 7 – 4x as 3x.

## Self-test

1. Which x-values would you choose to draw y = 2x – 3 for –2 ≤ x ≤ 3?
2. Complete: for y = –x + 2, when x = –3, y = …
3. Find the y-values of y = ½x – 2 at x = –4, 0 and 4.
4. A table for y = 4x + 1 reads x: 0, 1, 2, 3 and y: 1, 5, 8, 13. Which value is wrong, and what should it be?
5. Describe the line x = –4.
6. Write down the equation of the horizontal line through (6, –5).
7. Write down three points on the line y = 0.2x + 3 with whole-number coordinates.
8. Where does y = 5x – 10 cross the x-axis?
9. A grid goes from y = –4 to y = 10. Where does y = –3x + 1 leave the top of the grid?
10. *(Extended)* Find the points where 2x + 3y = 12 crosses the axes.
11. *(Extended)* Find y when x = 3 on the line 5x – 2y = 9.
12. *(Extended)* Rearrange 4x + 2y = 6 into the form y = mx + c.

### Answers

1. **–2, 0 and 3** (both ends and one in the middle)
2. y = –(–3) + 2 = **5**
3. **–4, –2 and 0**
4. At x = 2, y = 4(2) + 1 = 9, so **8 is wrong; it should be 9** (steps of 4)
5. A **vertical** line through (–4, 0)
6. **y = –5**
7. For example **(–5, 2), (0, 3) and (5, 4)**
8. 5x – 10 = 0 gives x = 2: **(2, 0)**
9. –3x + 1 = 10 gives x = –3: **(–3, 10)**
10. x = 0 gives y = 4; y = 0 gives x = 6: **(0, 4) and (6, 0)**
11. 15 – 2y = 9, so 2y = 6: **y = 3**
12. 2y = 6 – 4x, so **y = –2x + 3**
