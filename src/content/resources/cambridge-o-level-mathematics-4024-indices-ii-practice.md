## Section A

**1.** Find the value of:

**(a)** 64^(1/3) **[1]**

**(b)** (1/5)^(−2) **[1]**

**(c)** 32^(4/5) **[1]**

**2.** Find the value of 100^(−3/2). **[2]**

**3.** Find the value of (8/27)^(−4/3). **[2]**

**4.** Work out 9^(1/2) + 8^(2/3) − 4⁰. **[2]**

**5.** Simplify:

**(a)** 6x^(3/4) × x^(1/4) **[1]**

**(b)** (16x⁸)^(3/4) **[2]**

**6.** Solve 5^x = 1/125. **[2]**

## Section B

**7.** Simplify 15x^(−2) ÷ 5x^(−1/2), giving your answer in the form kx^n. **[2]**

**8.** Simplify (2x^(1/2) y^(−1))⁴. **[2]**

**9.** Expand and simplify 2x^(1/2)(x^(3/2) + 3x^(−1/2)). **[3]**

**10.** Solve 4^x = 1/8. **[3]**

**11.** Solve 8^(x + 1) = 4^(2x − 1). **[3]**

**12.** Solve (1/9)^x = 3^(x + 6). **[3]**

**13.** **(a)** Write 2^x × 4^(x + 1) as a single power of 2. **[2]**

**(b)** Hence solve 2^x × 4^(x + 1) = 32. **[2]**

**14.** **(a)** Write 12/(3√x) in the form kxⁿ. **[2]**

**(b)** Solve x^(3/2) = 64, where x > 0. **[2]**

**(c)** Explain why the equation 2^x = −4 has no solution. **[1]**

## Answers

**1. (a)** ∛64 = **4** [1]

**(b)** 5² = **25** [1]

**(c)** (⁵√32)⁴ = 2⁴ = **16** [1] **[3]**

**2.** √100 = 10, 10³ = 1000 [1]; reciprocal: **1/1000** [1] **[2]**

*Examiner insight:* The denominator 2 of the index means square root. Some candidates multiply 100 by 3/2 to get 150; an index is never a multiplier.

**3.** (27/8)^(4/3) [1] = (3/2)⁴ = **81/16** [1] **[2]**

*Examiner insight:* Take the cube root of top and bottom separately: ∛27 = 3 and ∛8 = 2.

**4.** 3 + 4 − 1 [1] = **6** [1] **[2]**

*Examiner insight:* 4⁰ = 1, not 0 and not 4.

**5. (a)** **6x** [1]

**(b)** 16^(3/4) = 2³ = 8 [1]; (x⁸)^(3/4) = x⁶; answer **8x⁶** [1] **[3]**

**6.** 1/125 = 5^(−3) [1], so **x = −3** [1] **[2]**

*Examiner insight:* Recognise 125 = 5³ first; the reciprocal then gives the negative index.

**7.** 15 ÷ 5 = 3; x^(−2 − (−1/2)) = x^(−3/2) [1]; **3x^(−3/2)** [1] **[2]**

**8.** 2⁴ x² y^(−4) [1] = **16x²/y⁴** (or 16x²y^(−4)) [1] **[2]**

*Examiner insight:* The power 4 applies to every factor in the bracket: 2⁴ = 16, (x^(1/2))⁴ = x², (y^(−1))⁴ = y^(−4).

**9.** 2x^(1/2) × x^(3/2) = 2x² [1]; 2x^(1/2) × 3x^(−1/2) = 6x⁰ = 6 [1]; answer **2x² + 6** [1] **[3]**

*Examiner insight:* Multiply the outside term by each term in the bracket, adding indices each time: 1/2 + 3/2 = 2 and 1/2 + (−1/2) = 0.

**10.** 2^(2x) = 2^(−3) [1]; 2x = −3 [1]; **x = −3/2** [1] **[3]**

*Examiner insight:* 4 and 8 are not powers of each other with whole-number indices, but both are powers of 2. Choosing base 2 is the first mark.

**11.** 2^(3x + 3) = 2^(4x − 2) [1]; 3x + 3 = 4x − 2 [1]; **x = 5** [1] **[3]**

*Check:* 8⁶ = 2¹⁸ and 4⁹ = 2¹⁸. ✓

**12.** 3^(−2x) = 3^(x + 6) [1]; −2x = x + 6 [1]; **x = −2** [1] **[3]**

*Check:* (1/9)^(−2) = 81 and 3⁴ = 81. ✓ Writing 1/9 as 3^(−2) and then (3^(−2))^x = 3^(−2x) is the key step.

**13. (a)** 4^(x + 1) = 2^(2x + 2) [1]; 2^x × 2^(2x + 2) = **2^(3x + 2)** [1]

**(b)** 2^(3x + 2) = 2⁵ [1]; 3x + 2 = 5, **x = 1** [1] **[4]**

*Examiner insight:* "Hence" means use part (a). Starting again from the original equation may still reach x = 1, but uses more time and risks a slip.

**14. (a)** 12/3 = 4 and √x = x^(1/2) [1], so **4x^(−1/2)** [1]

**(b)** Raise both sides to the power 2/3: x = 64^(2/3) [1] = (∛64)² = **16** [1]

**(c)** A positive base raised to any power gives a positive value, so 2^x can never equal −4 [1] **[5]**

*Examiner insight:* In (a), the 3 in the denominator divides the 12; it does not become 3^(−1) attached to x.

## Where marks are usually lost

- Treating a negative index as a negative number (Questions 1(b) and 2).
- Forgetting to turn the fraction over in Question 3, giving 16/81.
- Raising only x to the power in Question 5(b), giving 16x⁶.
- Subtracting a negative index wrongly in Question 7.
- Writing x⁰ as x or 0 in Question 9.
- Using base 4 and base 8 without converting to base 2 in Questions 10 and 11.
- Writing 12/(3√x) as 12x^(−1/2)/3 and leaving it unsimplified, or as 4x^(1/2), in Question 14(a).
- Squaring 64 before taking the cube root in Question 14(b), which makes the arithmetic far harder.

## Frequently asked questions

**Do I need logarithms for 4024 index equations?**
No. The syllabus says knowledge of logarithms is not required. Every equation can be solved by writing both sides as powers of the same base.

**Should I take the root or the power first?**
Root first. 32^(4/5) is (⁵√32)⁴ = 2⁴ = 16, which avoids working with 32⁴.

**How do I solve an equation where x is the base, such as x^(3/2) = 64?**
Raise both sides to the reciprocal power, here 2/3. Then evaluate as usual: root first, then power.

**Is a negative index acceptable in a final answer?**
Usually yes, unless the question asks for a particular form such as kx^n with n positive or an answer without negative indices.
