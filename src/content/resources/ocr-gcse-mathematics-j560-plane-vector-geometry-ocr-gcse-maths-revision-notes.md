Notation: (a over b) is a column vector; bold **a** is a vector (underline it by hand); **AB** is the vector from A to B.

## Key terms

| Term | Meaning |
|---|---|
| Vector | A quantity with size and direction |
| Scalar | An ordinary number that multiplies a vector |
| Column vector | (x-step over y-step) |
| Equal vectors | Same size and same direction, wherever they are drawn |
| Negative vector | Same size, opposite direction: −**a** |
| Parallel vectors | One is a scalar multiple of the other |
| Resultant | The single vector equal to a route of two or more vectors |
| Collinear | Lying on one straight line |
| Position vector | The vector from the origin O to a point |

## Column vectors

```
AB = (x_B − x_A  over  y_B − y_A)        end minus start
BA = −AB
B = A + AB                               coordinates from a vector
```

Reminder: A(4, −1), B(−2, 3): **AB** = (−6 over 4); **BA** = (6 over −4).

Drawing (−2 over 5): 2 left, 5 up, arrowhead at the finish.

## Arithmetic

```
(a over b) + (c over d) = (a + c over b + d)
(a over b) − (c over d) = (a − c over b − d)
k(a over b) = (ka over kb)
```

Reminder: **p** = (5 over −1), **q** = (−2 over 3). 3**p** + 2**q** = (15 − 4 over −3 + 6) = (11 over 3). **p** − **q** = (7 over −4).

## Parallel test

- k**a** is parallel to **a**; same direction if k > 0, opposite if k < 0; k times as long (|k| times if negative).
- Two column vectors are parallel if the same multiplier links both components.
- (3 over −6) and (−1 over 2): (3 over −6) = −3 × (−1 over 2), so parallel.
- (n over 10) parallel to (3 over 5): multiplier 2, so n = 6.

## Routes

```
AB = AO + OB = −a + b = b − a              (OA = a, OB = b)
Going against an arrow: change the sign.
Any route from A to B gives the same vector.
```

| Point | Position vector (OA = **a**, OB = **b**) |
|---|---|
| Midpoint of AB | ½(**a** + **b**) |
| P on AB with AP : PB = 1 : 2 | **a** + ⅓(**b** − **a**) = ⅔**a** + ⅓**b** |
| P on AB with AP : PB = 3 : 1 | **a** + ¾(**b** − **a**) = ¼**a** + ¾**b** |
| P on AB with AP : PB = m : n | **a** + m/(m + n) (**b** − **a**) |

## Proof patterns (Higher tier only)

```
Parallel:     show XY = k × ZW
Collinear:    show PQ = k × PR (or QR) AND they share a point
Ratio:        k gives the ratio of lengths, e.g. PR = 3PQ means PQ : QR = 1 : 2
Midpoint theorem: joining the midpoints of two sides of a triangle
              gives a line parallel to the third side and half its length
```

Finish every proof with a sentence: "so ... is parallel to ...", or "so P, Q and R are collinear".

## Exam traps

- **AB** = **a** − **b** (wrong) instead of **b** − **a**.
- Start minus end instead of end minus start.
- Scalar applied to one component only.
- Ratio 1 : 3 treated as 1/3 instead of 1/4.
- Collinear claimed without the shared point.
- Answers left unsimplified: collect the **a** and **b** terms.
- Vectors written as coordinates, or coordinates as column vectors.

## Quick self-test

1. A is (2, 5) and B is (7, 1). Write down **AB**.
2. Write down **BA** for question 1.
3. **a** = (4 over −3). Write down −2**a**.
4. **a** = (4 over −3) and **b** = (−1 over 2). Find **a** + 3**b**.
5. Find 2**a** − **b** for the vectors in question 4.
6. Is (−8 over 6) parallel to (4 over −3)? Explain.
7. Find m so that (m over −12) is parallel to (2 over 3).
8. C is (−1, 4) and **CD** = (5 over −6). Find D.
9. **OA** = **a** and **OB** = **b**. Write **AB** in terms of **a** and **b**.
10. M is the midpoint of AB in question 9. Find **OM**.
11. P is on AB with AP : PB = 2 : 3. Find **OP**.
12. (Higher tier only) **PQ** = 2**a** + **b** and **QR** = 6**a** + 3**b**. What can you say about P, Q and R?

### Answers

1. (5 over −4)
2. (−5 over 4)
3. (−8 over 6)
4. (4 − 3 over −3 + 6) = (1 over 3)
5. (8 + 1 over −6 − 2) = (9 over −8)
6. Yes: (−8 over 6) = −2 × (4 over −3); opposite direction, twice as long
7. Multiplier −4, so m = −8
8. (−1 + 5, 4 − 6) = (4, −2)
9. **b** − **a**
10. ½(**a** + **b**)
11. **a** + ⅖(**b** − **a**) = ⅗**a** + ⅖**b**
12. **QR** = 3**PQ**, so they are parallel; they share Q, so P, Q and R are collinear, with PQ : QR = 1 : 3
