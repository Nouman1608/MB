Condensed notes for subtopic **2.5 Equations** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025–2027. Worked examples are in the [equations study guide](/resources/cambridge-o-level-mathematics-4024-equations/); exam-style questions with mark schemes are in the [equations practice questions](/resources/cambridge-o-level-mathematics-4024-equations-practice/).

## Syllabus outcomes

1. Construct expressions, equations and formulas, including simultaneous equations.
2. Solve linear equations in one unknown.
3. Solve fractional equations with numerical and linear algebraic denominators.
4. Solve simultaneous linear equations in two unknowns.
5. Solve quadratics by factorisation, completing the square and the formula (surd answers possible; formula given in the List of formulas).
6. Change the subject of formulas, including where the subject appears twice or as a power or root.

## Key terms

| Term | Meaning |
|---|---|
| Solve | Find every value of the unknown that makes the equation true |
| Root / solution | A value that satisfies the equation |
| Linear equation | Highest power of the unknown is 1 |
| Quadratic equation | Can be written ax² + bx + c = 0 with a ≠ 0 |
| Simultaneous equations | Two equations true at the same time for the same values |
| Elimination | Adding or subtracting equations to remove one unknown |
| Substitution | Replacing one unknown with an expression from the other equation |
| Surd form | An exact answer containing a root, such as 4 + √13 |
| Discriminant | b² − 4ac, the part under the root in the formula |
| Subject | The letter on its own on one side of a formula |

## Linear and fractional equations

```
7 − 3x = 2(x + 6)          →  7 − 3x = 2x + 12  →  −5 = 5x  →  x = −1
(2x − 1)/5 + (x + 3)/2 = 4 →  ×10: 2(2x − 1) + 5(x + 3) = 40  →  9x + 13 = 40  →  x = 3
x/(2x + 1) = 2/5           →  5x = 2(2x + 1)  →  x = 2
4/(x − 2) = 3/(x + 1)      →  4(x + 1) = 3(x − 2)  →  x = −10
```

Fractions summed with algebraic denominators often give a quadratic:

```
3/(x − 1) − 2/(x + 2) = 1
3(x + 2) − 2(x − 1) = (x − 1)(x + 2)
x + 8 = x² + x − 2
x² = 10,  x = ±√10
```

Reject any value that makes a denominator zero.

## Simultaneous linear equations

| Method | Best when | Example |
|---|---|---|
| Elimination | Both in the form ax + by = c | 2x + 3y = 12 and 4x − y = 10 → x = 3, y = 2 |
| Substitution | One already gives y = … or x = … | y = 4x − 10 into 2x + 3y = 12 |

Same signs → subtract. Different signs → add. Check in the other equation.

```
5x + 2y = 1     (×2)  10x + 4y = 2
3x + 4y = −5          3x + 4y = −5
subtract:             7x = 7,  x = 1,  y = −2
```

## Quadratic equations

| Method | Use when | Example |
|---|---|---|
| Factorise | It factorises neatly | 3x² + 10x − 8 = 0 → (3x − 2)(x + 4) = 0 → x = 2/3 or −4 |
| Complete the square | Asked to, or surds needed | x² − 8x + 3 = 0 → (x − 4)² = 13 → x = 4 ± √13 |
| Formula | No neat factors; decimals needed | 2x² + 3x − 7 = 0 → x = (−3 ± √65)/4 → 1.27 or −2.77 |

```
x = [−b ± √(b² − 4ac)] / 2a
```

Special cases: x² − 7x = 0 → x(x − 7) = 0 → x = 0 or 7. 4x² − 25 = 0 → x = ±5/2.

## Changing the subject

| Formula | Subject | Result |
|---|---|---|
| T = 2π√(l/g) | l | l = gT²/(4π²) |
| y = (3x + a)/(x − 2) | x | x = (a + 2y)/(y − 3) |
| kx − 3 = 2x + m | x | x = (m + 3)/(k − 2) |
| 1/f = 1/u + 1/v | v | v = fu/(u − f) |

Subject twice: expand → collect subject terms → factorise → divide.

## Exam traps

- Multiply **every** term by the common denominator, including whole numbers.
- −2(x − 1) = −2x + 2.
- Do not divide an equation by x; factorise instead.
- Square root both sides → ±.
- With b negative, −b is positive.
- Reject a negative length or count, and say why.
- Give surd answers when asked; decimals when asked; otherwise 3 significant figures on Paper 2.
- In context questions, define letters and finish with a sentence answer.

## Self-test

1. Solve 7 − 3x = 2(x + 6).
2. Solve (x + 4)/3 − (2x − 1)/4 = 1.
3. Solve 4/(x − 2) = 3/(x + 1).
4. Solve 2x + 3y = 12 and 4x − y = 10.
5. Solve 3x² + 10x − 8 = 0.
6. Solve x² − 8x + 3 = 0, giving answers in surd form.
7. Solve 2x² + 3x − 7 = 0, giving answers to 2 decimal places.
8. Solve 2x² = 3x + 5.
9. A rectangle has width x cm and length (x + 5) cm. Its area is 84 cm². Find x.
10. 40 coins are worth $1.56, made of 3-cent and 5-cent coins. How many of each?
11. Make l the subject of T = 2π√(l/g).
12. Make x the subject of y = (3x + a)/(x − 2).

**Answers**

1. **x = −1**.
2. 4(x + 4) − 3(2x − 1) = 12 → −2x + 19 = 12 → **x = 7/2**.
3. **x = −10**.
4. **x = 3, y = 2**.
5. (3x − 2)(x + 4) = 0 → **x = 2/3 or x = −4**.
6. **x = 4 ± √13**.
7. x = (−3 ± √65)/4 → **1.27 or −2.77**.
8. 2x² − 3x − 5 = 0 → (2x − 5)(x + 1) = 0 → **x = 5/2 or x = −1**.
9. x² + 5x − 84 = 0 → (x + 12)(x − 7) = 0 → **x = 7** (x = −12 rejected: a width cannot be negative).
10. x + y = 40 and 3x + 5y = 156 → **22 three-cent and 18 five-cent coins**.
11. T/(2π) = √(l/g) → T²/(4π²) = l/g → **l = gT²/(4π²)**.
12. y(x − 2) = 3x + a → xy − 3x = a + 2y → **x = (a + 2y)/(y − 3)**.
