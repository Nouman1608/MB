## The core idea in one line

The software reads the text file as an **outline**: **top-level lines become slide titles**, **indented lines become bullet points** on the slide above them.

## Key terms

| Term | Meaning |
|---|---|
| Text file (.txt) | A file of plain characters with no formatting; levels are shown by tab characters |
| Rich text file (.rtf) | A text file that can hold formatting such as fonts and heading styles |
| Outline | The structure of a presentation as titles and bullet levels, without design |
| Level | The position of a line in the outline hierarchy: title, bullet, sub-bullet |
| Placeholder | A box on a slide layout reserved for a title or body content |
| Promote | Move a line up a level (for example a bullet to a title) |
| Demote | Move a line down a level (for example a bullet to a sub-bullet) |
| Reset slide | Return a slide's placeholders and formatting to the master's settings |

## How levels map to slides

| In a .txt file | In a .rtf or word-processed file | On the slide |
|---|---|---|
| No tab at start of line | Heading 1 (or outline level 1) | New slide; line is the title |
| One tab | Heading 2 (or outline level 2) | First-level bullet |
| Two tabs | Heading 3 (or outline level 3) | Second-level bullet |

Number of slides = number of top-level lines.

## Two ways to create the presentation

| Method | What happens | Watch out for |
|---|---|---|
| Open the file as an outline (change the file-type filter in the Open dialogue) | A new presentation is built from the file | Check the first slide is a real title from the file |
| New blank presentation, then insert slides from the outline | Slides are added after the current slide | The blank first slide is still there; delete it unless a title slide is wanted |

## Why import instead of typing?

- **Speed**: no time spent keying the text.
- **Accuracy**: no new typing or spelling errors.
- **Structure kept**: titles and bullets come out at the right levels.
- **Division of work**: content written in a word processor by one person, designed later by another.

## Post-import checklist

- Slide count matches the top-level lines.
- Every title is in the title placeholder.
- Bullets are under the right slide, at the right level.
- No blank slides or empty bullet lines.
- Text matches the file word for word.
- Slides reset so the master controls formatting.
- Saved in the presentation format, with the given file name.

## Fixing problems

| Problem seen | Likely cause | Fix |
|---|---|---|
| One extra, empty slide at the start | Slides inserted into a new presentation that already had a blank slide | Delete the empty slide |
| A bullet shows as a separate slide | The line had no tab (or spaces instead of a tab) | Demote it to a bullet on the slide above |
| A sub-point appears as a main bullet | Only one tab, not two | Demote it one more level |
| Text in an odd font or colour | Formatting carried over from a rich text file | Reset the slide so it follows the master |
| An empty bullet point | A blank line in the file | Delete the empty line |

## Exam traps

- Saying the presentation was "copied" from the file: the correct term is **import** or **create from a text file**.
- Forgetting the leftover blank slide: the slide count is wrong and later instructions such as "slide 3" point to the wrong slide.
- Editing the wording of imported text when the task did not ask you to.
- Starting master slide formatting before checking the import: mistakes then have to be fixed twice.
- In theory answers, writing only "it is quicker". Add a second, different benefit such as accuracy.

## Self-test

1. What does a top-level line in a text file become when the file is imported into presentation software?
2. What does a line with one tab at the start become?
3. A .txt file has five lines with no tab and eight lines with one tab. How many slides are created?
4. How are levels usually shown in a rich text file?
5. Give **two** benefits of creating a presentation from a text file.
6. After inserting slides from an outline into a new presentation, there is an empty slide at the start. Why?
7. A line indented with spaces became a slide title. Explain why.
8. What does "demote" mean?
9. Why should slides be reset before formatting the master slide?
10. A student retypes a heading to correct its capital letters, though the task did not ask for this. Why could this lose marks?
11. Name the placeholder that should hold each top-level line.

### Answers

1. The title of a new slide.
2. A first-level bullet point on the slide whose title is above it.
3. Five slides (the eight indented lines become bullets).
4. By heading styles or outline levels, for example Heading 1 for titles and Heading 2 for bullets.
5. Any two: faster than retyping; no new typing errors; the structure of titles and bullets is kept; content can be written separately from design.
6. A new blank presentation already contains an empty title slide, and the imported slides are added after it.
7. The software uses tab characters to decide levels; spaces are not tabs, so the line was read as top level.
8. To move a line down one level, for example from a bullet to a sub-bullet.
9. Formatting carried from the file can override the master; resetting makes every slide take its formatting from the master, so master changes reach all slides.
10. The text should match the supplied file exactly; changing it introduces a difference from the expected content.
11. The title placeholder.
