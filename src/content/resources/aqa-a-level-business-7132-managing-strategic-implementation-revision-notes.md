Condensed notes on section **3.10.3 Managing strategic implementation** of AQA A-level Business (7132, for first teaching from September 2023). Section 3.10 is A-level only. The nine-activity store opening network is in the [study guide](/resources/aqa-a-level-business-7132-managing-strategic-implementation/); questions are in the [practice set](/resources/aqa-a-level-business-7132-managing-strategic-implementation-practice/).

## Specification content

- How to implement strategy effectively: the value of leadership and of communications.
- The importance of organisational structure in strategic implementation.
- The value of network analysis: understanding and interpreting network diagrams, amending them, identifying the critical path and total float.

## Key terms

| Term | Meaning |
|---|---|
| Implementation | Turning a strategic decision into action |
| Leadership | Ability to influence and direct others towards a goal |
| Two-way communication | Messages and feedback flowing in both directions |
| Network analysis | Planning a project by showing activities, durations and order |
| Critical path | The longest path; it sets the project duration |
| Earliest start time (EST) | Earliest an activity can begin |
| Latest finish time (LFT) | Latest an activity can end without delaying the project |
| Total float | Delay possible without delaying the project |

## Leadership

Sets direction; motivates; decides; allocates resources; models behaviour; builds support.

| Style | Suits |
|---|---|
| Autocratic | Crisis; inexperienced staff; speed |
| Democratic | Skilled staff; need for commitment and ideas |
| Laissez-faire | Expert, self-motivated staff |
| Paternalistic | Staff needing reassurance |

Limits: over-dependence on one leader; leadership alone is not enough.

## Communications

Explain the strategy; reduce resistance; co-ordinate departments; give feedback; build commitment.
Problems: distortion through layers; overload; inconsistent messages; poor listening; missing remote or shift workers.
Good practice: one clear message, repeated through several channels, with a way to respond.

## Structure

| Feature | Effect |
|---|---|
| Tall against flat | Tall slows communication; flat speeds decisions but loads managers |
| Centralised against decentralised | Control against speed and local response |
| Functional against product or region | Expertise against fit with diversification or expansion |
| Project teams or matrix | Cross-department change; reporting lines may blur |
| Clear accountability | Someone owns each action |

## Network analysis: method

1. **Forward pass:** EST = largest earliest finish of preceding activities; EFT = EST + duration.
2. **Backward pass:** LFT of last activity = project duration; LFT of earlier activity = smallest latest start of the activities that follow; latest start = LFT − duration.
3. **Total float = LFT − duration − EST.**
4. **Critical path:** zero-float activities; the longest path.

## Worked mini-example

| Activity | Duration | Follows |
|---|---|---|
| A | 3 | none |
| B | 2 | none |
| C | 4 | A |
| D | 5 | A, B |
| E | 2 | C, D |

EST: A 0, B 0, C 3, D 3, E 8 (D finishes at 8; C at 7). Project duration = 10.
LFT: E 10, D 8, C 8, B 3, A 3.
Float: A 0; B 3 − 2 − 0 = **1**; C 8 − 4 − 3 = **1**; D 0; E 0.
Critical path: A, D, E (3 + 5 + 2 = 10).

## Amending a network

- Change the duration, then repeat the passes.
- Shortening a **critical** activity shortens the project (until another path becomes critical).
- Shortening a **non-critical** activity saves nothing overall.
- A delay longer than an activity's float delays the project.

## Value and limits of network analysis

| Value | Limits |
|---|---|
| Shortest time; focus on critical tasks | Depends on accurate time estimates |
| Highlights float for resource use | Costs ignored unless added |
| Clear dependencies; easy to re-plan | Large networks complex |
| Basis for monitoring | Ignores motivation and people issues |

## Model analysis paragraph

"The critical path is B, D, F, I, so a delay to shopfitting delays the opening of the store. Recruiting the manager has two weeks of float, so it can slip without affecting the opening. The manager should therefore focus resources on the critical activities and keep a close eye on any that use up their float. The network is only as reliable as the estimates, so the plan should be reviewed regularly."

## Command words

- **Calculate:** show the forward and backward pass, state the float and the critical path.
- **Evaluate:** judge the usefulness of leadership, communication, structure and network analysis for the case.

## Exam traps

- The critical path is the **longest** path.
- Float = LFT − duration − EST (do not forget the duration).
- Use the project duration as the LFT for the final activity.
- Shortening non-critical activities does not speed up the project.
- Link leadership style to the situation, not to a fixed "best" style.

## Self-test

1. Define "critical path".
2. State the formula for total float.
3. An activity has EST 6, duration 4 and LFT 12. Calculate the total float.
4. What does zero float mean?
5. In the mini-example, what is the effect of C taking 6 weeks instead of 4?
6. Give two reasons communication matters in implementation.
7. Give one problem of tall hierarchies for communication.
8. When is an autocratic style appropriate?
9. Give one limit of network analysis.
10. Why does shortening a non-critical activity not shorten the project?
11. Give one structural change that could suit expansion into overseas markets.
12. Why is two-way communication better than one-way during change?

### Answers

1. The longest path through the network; it determines the project duration.
2. Total float = LFT − duration − EST.
3. 12 − 4 − 6 = **2** weeks.
4. The activity is critical: any delay to it delays the whole project.
5. C would finish at 9 (3 + 6) instead of 7, so E starts at 9 and the project takes 11 weeks; C is now critical (float was only 1).
6. Any two: explain the strategy; reduce resistance; co-ordinate; give feedback; build commitment.
7. Messages become slow or distorted as they pass through many layers.
8. In a crisis, when speed is vital or staff are inexperienced.
9. Any one: depends on accurate estimates; ignores cost unless added; complex for large projects; ignores people issues.
10. Because the critical path still sets the end date; the longest path is unchanged.
11. For example, a regional structure with local decision-making.
12. It lets staff ask questions and raise problems, which reduces misunderstanding and gives managers feedback to adjust the plan.
