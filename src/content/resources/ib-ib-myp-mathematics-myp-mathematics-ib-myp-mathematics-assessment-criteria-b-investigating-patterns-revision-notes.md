## Key terms

| Term | Meaning |
|---|---|
| Conjecture | A rule you think is true but have not yet proved |
| General rule | A rule for any case n, stated in symbols and words |
| Consistent with findings | Fits every result you have recorded |
| Verify | Test the rule on a new case found independently |
| Justify | Give the reason the situation produces the rule |
| Prove | An argument that holds for every n |
| Counter-example | One case where a rule fails; it disproves the rule |
| Domain | The values of n for which the rule applies |

## Which test finds which rule

| What you see | Type of rule | Leading term |
|---|---|---|
| Constant first differences d | Linear | dn |
| Constant second differences D | Quadratic | (D/2)n² |
| Constant third differences T | Cubic | (T/6)n³ |
| Constant ratio r | Exponential | a × rⁿ (or a × rⁿ⁻¹ from n = 1) |
| Differences copy the original sequence | Exponential with ratio 2 | 2ⁿ |
| Fractions whose numerator and denominator each follow a rule | Rational | Find each rule separately |

Worked reminder: 2, 9, 28, 65, 126. First differences 7, 19, 37, 61; second 12, 18, 24; third 6, 6. Cubic with leading term n³. Subtract n³ (1, 8, 27, 64, 125): leftovers all 1, so the rule is **n³ + 1**.

Worked reminder: 5, 15, 45, 135. Ratio 3 each time, first term 5, so the rule is **5 × 3ⁿ⁻¹**.

Worked reminder: 1/3, 2/5, 3/7, 4/9. Numerators n, denominators 2n + 1, so the rule is **n/(2n + 1)**.

## The investigation routine

1. Simplify: start with the smallest cases.
2. Work systematically so no case is missed.
3. Tabulate case number against result.
4. Test differences, then ratios, then known numbers.
5. State the conjecture in words and symbols, defining the variable.
6. Verify on a new, larger case, found without the rule.
7. Justify from the structure, or prove with algebra.
8. State the domain and any limits.

## Proof patterns worth knowing

- **Even and odd**: write an even number as 2k and an odd number as 2k + 1.
- **Consecutive integers**: n, n + 1, n + 2.
- **Multiple of m**: show the expression equals m × (a whole number).
- **Cancelling sums**: split each term so neighbours cancel, as in 1/k − 1/(k + 1).
- **Difference of terms**: subtract the nth term from the (n + 1)th to show what is added each time.

Worked reminder: prove that the sum of two consecutive odd numbers is a multiple of 4. (2k + 1) + (2k + 3) = 4k + 4 = 4(k + 1), and k + 1 is a whole number.

## Exam traps

- Verifying with a case already used to build the rule.
- Fitting a rule to two data points: many rules pass through any two points.
- Calling a rule proved after checking more examples.
- Writing n² + 1 when the table starts at n = 0 but the rule was found from n = 1.
- Missing cases because counting was not systematic (squares of size 2 on a grid are often under-counted).
- Assuming a pattern is linear because the first two differences look close.
- Ignoring the limits of a physical situation, such as a sheet of paper that cannot be folded indefinitely.

## Must-know distinctions

- **Pattern vs rule**: a pattern is what you notice; a rule is the general statement in symbols.
- **Verify vs justify**: verifying tests; justifying explains why.
- **Justify vs prove**: a justification can be a structural explanation; a proof is a complete argument for every n.
- **One counter-example vs many examples**: one failure disproves a rule; no number of successes proves it.

## Quick self-test

1. State the three Year 5 strands of Criterion B.
2. Find the rule for 3, 8, 13, 18.
3. Find the rule for 4, 7, 12, 19, 28.
4. A sequence has constant third differences of 12. What is the leading term of its rule?
5. Find the rule for 3, 6, 12, 24.
6. Find the rule for the fractions 2/3, 3/4, 4/5, 5/6.
7. A rule for some data is 3n + 1. The table has n = 1 to 4. Which case would you use to verify it, and why?
8. Show that n² + n is always even.
9. Give a counter-example to "n² + n + 41 is always prime".
10. Which band is the first in which strand iii is credited?
11. Name two patterns the guide's Year 5 examples treat as simple.
12. Prove that the sum of three consecutive integers is a multiple of 3.

### Answers

1. Select and apply techniques to discover complex patterns; describe patterns as general rules consistent with findings; prove, or verify and justify, general rules.
2. Difference 5, so **5n − 2**.
3. Second differences 2, so n² is the leading term; leftovers 3, 3, 3, 3, 3, so **n² + 3**.
4. 12 ÷ 6 = 2, so **2n³**.
5. Ratio 2, first term 3, so **3 × 2ⁿ⁻¹**.
6. **(n + 1)/(n + 2)**.
7. A new case such as n = 10, counted independently, because n = 1 to 4 were used to build the rule.
8. n² + n = n(n + 1), a product of consecutive integers, one of which is even, so the product is even.
9. n = 40 gives 1600 + 40 + 41 = 1681 = 41², which is not prime.
10. The **5-6** band.
11. Linear rules and quadratics of the form ax² (or ax² + c).
12. n + (n + 1) + (n + 2) = 3n + 3 = 3(n + 1), a multiple of 3.

## Frequently asked questions

**How do I know whether to look at differences or ratios?**
If the results grow by roughly the same amount, try differences. If they grow by roughly the same factor, try ratios. If neither settles, look for known numbers such as squares or powers.

**Is a justification enough for the top band in Year 5?**
The Year 5 descriptor accepts proof, or verification and justification, so a correct rule that is verified on a new case and justified from the structure can meet it.
