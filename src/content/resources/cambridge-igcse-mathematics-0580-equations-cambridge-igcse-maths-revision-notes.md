These notes condense subtopic **2.5 Equations** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027). Lines marked *(Extended)* are E2.5 only; the rest is in both C2.5 and E2.5. For worked examples and exam technique, read the [equations study guide](/resources/cambridge-igcse-mathematics-0580-equations-cambridge-igcse-maths/); for marked questions, use the [equations practice questions](/resources/cambridge-igcse-mathematics-0580-equations-cambridge-igcse-maths-practice/).

## What you must be able to do

| Skill | Core | Extended |
|---|---|---|
| Construct expressions, equations, formulas (including simultaneous) | yes | yes |
| Linear equations in one unknown | yes | yes |
| Simultaneous linear equations | yes | yes |
| Change the subject (appears once, no power or root) | yes | yes |
| Change the subject (appears twice, or with a power or root) | no | yes |
| Fractional equations (numerical and linear algebraic denominators) | no | yes |
| Quadratic equations: factorising, completing the square, formula | no | yes |
| One linear and one non-linear simultaneous equation | no | yes |

## Key terms

| Term | Meaning |
|---|---|
| Equation | A statement that two expressions are equal for particular values of the unknown |
| Solution (root) | A value that makes the equation true |
| Formula | A rule linking two or more variables, e.g. v = u + at |
| Subject | The variable on its own on one side of a formula |
| Simultaneous equations | Two equations that must both be true at once |
| Surd form *(Extended)* | An exact answer containing a root, e.g. 3 ± √5 |
| Quadratic formula *(Extended)* | x = (−b ± √(b² − 4ac))/2a for ax² + bx + c = 0; it is printed in the List of formulas |

## Condensed recall

### Linear equations

```
1. Expand brackets.
2. Multiply through by any numerical denominator.
3. Collect the unknown on one side, numbers on the other.
4. Divide by the coefficient.
```

### Simultaneous linear equations

- **Elimination:** make one coefficient match, then add (signs differ) or subtract (signs the same).
- **Substitution:** best when one equation already reads y = … or x = ….
- Substitute back to find the second unknown, and check in the **other** equation.

### Changing the subject

| Situation | Move |
|---|---|
| Subject inside a bracket | expand or divide by the multiplier |
| Subject in a fraction | multiply both sides by the denominator |
| Subject squared *(Extended)* | square root both sides (± if a negative value is possible) |
| Subject under a root *(Extended)* | isolate the root, then square both whole sides |
| Subject appears twice *(Extended)* | collect both terms on one side, factorise, divide |

### Fractional equations *(Extended)*

Multiply **every term** (both sides) by the lowest common denominator. With algebraic denominators the result is often a quadratic. Reject any answer that makes a denominator zero.

### Quadratic equations *(Extended)*

```
Rearrange to ax^2 + bx + c = 0 first.

Factorise:            (x - p)(x - q) = 0  ->  x = p or x = q
Complete the square:  (x + h)^2 = k       ->  x = -h ± √k
Formula:              x = (-b ± √(b^2 - 4ac)) / 2a
```

Choose the formula whenever the question asks for answers to a number of decimal places or significant figures.

### Linear and non-linear together *(Extended)*

Make x or y the subject of the linear equation, substitute into the other, solve the quadratic, then find each partner value from the **linear** equation. Answers come in pairs.

## Exam traps

- **The lone number.** In (x + 1)/3 − (x − 2)/4 = 2, the 2 must be multiplied by 12 too.
- **Minus before a bracket.** −(x − 7) = −x + 7.
- **Elimination signs.** Subtracting −2y from 3y gives 5y, not y.
- **Dividing by x.** From x² = 5x, dividing by x loses x = 0. Rearrange to x² − 5x = 0 and factorise.
- **The formula with negative c.** For 3x² + 5x − 1 = 0, b² − 4ac = 25 + 12 = 37, not 25 − 12.
- **Forgetting ±** when square-rooting in completing the square.
- **Half a pair.** For simultaneous equations with a quadratic, two x-values need two y-values.
- **Context.** Reject a negative length or time and say so.

## Self-test

1. Solve 5x − 7 = 2x + 11.
2. Solve 3(2x − 1) = 4 − (x − 7).
3. Solve x/4 + 3 = 7.
4. Solve the simultaneous equations 2x + y = 11 and x − y = 1.
5. Make r the subject of C = 2πr.
6. Make b the subject of A = ½(a + b)h.
7. *(Extended)* Solve x² − 2x − 15 = 0.
8. *(Extended)* Solve 3x² + 5x − 1 = 0, giving answers correct to 2 decimal places.
9. *(Extended)* Solve x² + 4x − 1 = 0, giving answers in the form p ± √q.
10. *(Extended)* Solve 3/(x − 1) = 2/(x + 2).
11. *(Extended)* Solve the simultaneous equations y = x + 1 and y = x² − 5.
12. *(Extended)* Make x the subject of y = (x + 2)/(x − 3).

### Answers

1. 3x = 18, **x = 6**.
2. 6x − 3 = 11 − x, 7x = 14, **x = 2**.
3. x/4 = 4, **x = 16**.
4. Adding: 3x = 12, **x = 4**, then **y = 3** (check: 4 − 3 = 1).
5. **r = C/(2π)**.
6. 2A = (a + b)h, so 2A/h = a + b and **b = 2A/h − a**.
7. (x − 5)(x + 3) = 0, **x = 5 or x = −3**.
8. x = (−5 ± √37)/6, **x = 0.18 or x = −1.85**.
9. (x + 2)² = 5, **x = −2 ± √5**.
10. 3(x + 2) = 2(x − 1), 3x + 6 = 2x − 2, **x = −8**.
11. x² − 5 = x + 1, x² − x − 6 = 0, (x − 3)(x + 2) = 0: **x = 3, y = 4** and **x = −2, y = −1**.
12. xy − 3y = x + 2, xy − x = 3y + 2, x(y − 1) = 3y + 2, **x = (3y + 2)/(y − 1)**.
