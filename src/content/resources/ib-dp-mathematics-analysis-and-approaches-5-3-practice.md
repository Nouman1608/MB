## Section A

**1.** Find dy/dx for y = 6x⁵ − 4x³ + x − 9. **[2]**

**2.** Find dy/dx for y = 8/x² − 3/x. **[2]**

**3.** Find dy/dx for y = (x − 3)(2x + 5). **[3]**

**4.** f(x) = (2x³ − 5x)/x².

**(a)** Find f′(x). **[2]**

**(b)** Find f′(1). **[1]**

**5.** Find the gradient of the curve y = x⁴ − 2/x at the point where x = −1. **[3]**

**6.** Find f′(x) for f(x) = 1/(5x⁵). **[2]**

## Section B

**7.** A curve has equation y = 2x³ − 9x² + 12x.

**(a)** Find the coordinates of the points where the gradient is 0. **[4]**

**(b)** Find the coordinates of the points where the gradient is 12. **[3]**

**8.** The curve y = ax³ + bx² has gradient 0 at x = 2 and gradient 9 at x = −1. Find a and b. **[5]**

**9.** f(x) = x² + 16/x, x ≠ 0.

**(a)** Find f′(x). **[2]**

**(b)** Find the coordinates of the point where f′(x) = 0. **[3]**

**(c)** Find the gradient of the curve at x = −2. **[1]**

**10.** The height of a model rocket, h metres, t seconds after launch is h = 40t − 5t² for
0 ≤ t ≤ 8.

**(a)** Find dh/dt. **[1]**

**(b)** Find dh/dt at t = 1 and at t = 6. **[2]**

**(c)** Interpret both answers to (b). **[2]**

**(d)** Find the time at which dh/dt = 0 and the height at that time. **[2]**

**11.** Show that the curve y = x³ + 3x − 1/x has a positive gradient at every point. **[3]**

**12.** The curve y = x³ + px + q passes through (1, 3), and its gradient at that point is 5. Find p
and q. **[4]**

**13.** f(x) = (x² + 1)(x − 2).

**(a)** Expand f(x) and hence find f′(x). **[3]**

**(b)** Find the values of x at which the gradient of the curve is 1. **[3]**

## Answers

**1.** dy/dx = 30x⁴ − 12x² + 1 [2: 1 for the first two terms, 1 for the rest including no constant].
**[2]**

**2.** y = 8x⁻² − 3x⁻¹ [1]; dy/dx = −16x⁻³ + 3x⁻² = −16/x³ + 3/x² [1]. **[2]**

**3.** y = 2x² − x − 15 [2]; dy/dx = 4x − 1 [1]. **[3]**

**4. (a)** f(x) = 2x − 5x⁻¹ [1]; f′(x) = 2 + 5x⁻² [1]

**(b)** f′(1) = 2 + 5 = 7 [1]. **[3]**

**5.** y = x⁴ − 2x⁻¹, dy/dx = 4x³ + 2x⁻² [2]. At x = −1: −4 + 2 = −2 [1]. **[3]**

**6.** f(x) = (1/5)x⁻⁵ [1]; f′(x) = −x⁻⁶ = −1/x⁶ [1]. **[2]**

**7. (a)** dy/dx = 6x² − 18x + 12 [1] = 6(x − 1)(x − 2) = 0, so x = 1 or 2 [1]. y(1) = 5 and y(2) = 4
[1]. Points (1, 5) and (2, 4) [1].

**(b)** 6x² − 18x + 12 = 12, so 6x(x − 3) = 0 and x = 0 or 3 [1]. y(0) = 0, y(3) = 54 − 81 + 36 = 9 [1].
Points (0, 0) and (3, 9) [1]. **[7]**

**8.** dy/dx = 3ax² + 2bx [1]. x = 2: 12a + 4b = 0 [1]. x = −1: 3a − 2b = 9 [1]. From the first,
b = −3a; then 3a + 6a = 9 [1], so a = 1 and b = −3 [1]. **[5]**

**9. (a)** f(x) = x² + 16x⁻¹ [1]; f′(x) = 2x − 16x⁻² [1]

**(b)** 2x = 16/x² [1], so x³ = 8 and x = 2 [1]; f(2) = 4 + 8 = 12, giving (2, 12) [1].

**(c)** f′(−2) = −4 − 16/4 = −8 [1]. **[6]**

**10. (a)** dh/dt = 40 − 10t [1]

**(b)** t = 1: 30 m s⁻¹ [1]; t = 6: −20 m s⁻¹ [1]

**(c)** At 1 second the rocket is rising at 30 m s⁻¹ [1]; at 6 seconds it is falling at 20 m s⁻¹ [1].

**(d)** 40 − 10t = 0 at t = 4 s [1]; h = 160 − 80 = 80 m [1]. **[7]**

**11.** y = x³ + 3x − x⁻¹, dy/dx = 3x² + 3 + x⁻² [1] = 3x² + 3 + 1/x² [1]. Each term is non-negative and
3 > 0, so dy/dx > 0 for every x ≠ 0 [1]. **[3]**

**12.** dy/dx = 3x² + p; at x = 1: 3 + p = 5 [1], so p = 2 [1]. Through (1, 3): 1 + 2 + q = 3 [1], so
q = 0 [1]. **[4]**

**13. (a)** f(x) = x³ − 2x² + x − 2 [1]; f′(x) = 3x² − 4x + 1 [2].

**(b)** 3x² − 4x + 1 = 1, so 3x² − 4x = x(3x − 4) = 0 [1]. x = 0 or x = 4/3 [1]. Both are needed; a
common error is dividing by x and losing x = 0 [1]. **[6]**

## How this set builds

Questions 1 to 6 practise rewriting and the power rule on polynomials, reciprocals, products and
quotients. Questions 7 to 9 and 12 use the derivative to find points and unknown constants, the
forms Paper 1 most often takes. Question 10 interprets the derivative as a rate of change, and
question 11 is a short "show that" about the sign of a gradient. Question 13 practises
expanding a product before differentiating, then solving a gradient equation without losing a root.
