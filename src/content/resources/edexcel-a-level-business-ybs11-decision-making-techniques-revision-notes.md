## Formula sheet

```
Three-period moving average = (a + b + c) / 3
Four-quarter average        = (a + b + c + d) / 4, then centre by averaging adjacent pairs
Seasonal variation          = actual - trend
Payback                     = full years + (cost still to recover / cash flow of that year)
ARR                         = (total net return / years) / initial cost x 100
Present value               = cash flow x discount factor
NPV                         = total present values - initial cost
Expected value              = sum of (probability x outcome), less the cost of the option
Total float                 = latest finish time - earliest start time - duration
Contribution per unit       = selling price - variable cost per unit
Break-even output           = fixed costs / contribution per unit
```

## Sales forecasting

- **Moving averages** smooth short-term variation to show the trend. Four-quarter averages fall between quarters, so they must be **centred**.
- **Forecast** = extended trend + average seasonal variation for that quarter.
- **Line of best fit:** draw through the middle of the scatter; read off or use its equation to predict. **Extrapolating** beyond the data is less reliable.
- **Limitations:** assumes the past pattern continues; ignores sudden changes, competitors and fashion; moving averages lag; correlation is not causation.

## Investment appraisal

| Method | Rule | Strength | Weakness |
|---|---|---|---|
| Payback | Shorter is better; compare with a target | Simple; focuses on risk and cash | Ignores flows after payback and the time value of money |
| ARR | Higher is better; compare with target or cost of borrowing | Uses all cash flows | Ignores timing; averages hide the pattern |
| NPV | Positive means accept; higher is better | Allows for the time value of money | Discount rate and cash flows are estimates |

- Payback in months: multiply the decimal fraction of a year by 12.
- In ARR the average annual return is **net** of the initial cost.
- A higher discount rate lowers present values and NPV.
- Non-financial factors also matter: risk, brand, environment, staff.

## Decision trees

- Squares are decisions; circles are chance events; branches carry probabilities that add to 1 at each circle.
- Work from right to left, calculating expected values, then subtract costs on the branches.
- Choose the option with the highest net expected value, but note the risk of the worst outcome.
- **Limitations:** probabilities are guessed; values are forecasts; no time value of money; non-financial factors ignored.

## Critical path analysis

| Term | Meaning |
|---|---|
| Earliest start time | Earliest an activity can begin, after all its predecessors finish |
| Latest finish time | Latest an activity can end without delaying the project |
| Total float | Spare time: latest finish - earliest start - duration |
| Critical path | Chain of activities with zero float; sets the project duration |

- Forward pass: take the **largest** earliest finish among predecessors.
- Backward pass: take the **smallest** latest start among successors.
- Benefits: shows the critical path, helps schedule resources and allows resources to move from activities with float.
- **Limitations:** estimates may be wrong; complex networks; must be updated; no cost information.

## Contribution

| Use | Rule |
|---|---|
| Break-even | Fixed costs / contribution per unit |
| Special order | Accept if contribution is positive, there is spare capacity and normal sales are not harmed |
| Drop a product | Consider whether it makes a positive contribution to fixed costs, even if it shows a loss after allocated overheads |
| Make or buy | Compare the variable cost of making with the price of buying |

Contribution ignores fixed costs and capacity limits, and can tempt a firm to accept low prices. Total contribution minus fixed costs is profit.

## Key terms

| Term | Meaning |
|---|---|
| Time series | Data over equal time intervals |
| Trend | Long-run direction of a series |
| Discounting | Converting future cash into present values |
| Expected value | Probability-weighted average outcome |
| Float | Spare time on a non-critical activity |
| Contribution | Selling price minus variable cost, per unit or in total |

## Exam traps

- Four-quarter averages need centring.
- Subtract the initial cost to get NPV.
- Net return for ARR is total inflows minus the cost.
- Decision tree values need the option cost taken off.
- Float is zero on the critical path, not on other activities.
- Contribution is not profit. A product can have positive contribution and still lose money after fixed costs.
- A technique gives a number, not a decision: always add a limitation or a risk point.

## Self-test

1. Calculate the three-period moving averages for sales of 40, 46, 43 and 51.
2. A project costs $60,000 and returns $20,000, $25,000, $30,000 and $20,000 in years 1 to 4. Calculate payback.
3. Calculate the ARR for the same project.
4. At 10%, the discount factors are 0.909, 0.826, 0.751 and 0.683. Calculate the NPV.
5. A launch costs $40,000 and has a 0.7 chance of $200,000 and a 0.3 chance of -$50,000. Calculate its net expected value.
6. An activity has an earliest start time of 5, a duration of 3 and a latest finish time of 12. Calculate its total float.
7. Price is $12, variable cost $7 and fixed costs $15,000. Calculate the break-even output.
8. Calculate the profit at 4,000 units.
9. State one limitation of payback.
10. What does a positive NPV indicate?

### Answers

1. (40 + 46 + 43) / 3 = **43.0**; (46 + 43 + 51) / 3 = **46.7**.
2. Cumulative: 20,000; 45,000; 75,000. Payback = 2 + 15,000 / 30,000 = **2.5 years**.
3. Total return = 95,000 - 60,000 = 35,000; annual = 8,750; ARR = 8,750 / 60,000 x 100 = **14.6%**.
4. 18,180 + 20,650 + 22,530 + 13,660 = 75,020; NPV = 75,020 - 60,000 = **+$15,020**.
5. 0.7 x 200,000 + 0.3 x (-50,000) = 140,000 - 15,000 = 125,000; less 40,000 = **$85,000**.
6. 12 - 5 - 3 = **4**.
7. Contribution = 12 - 7 = $5; 15,000 / 5 = **3,000 units**.
8. 4,000 x 5 = 20,000; 20,000 - 15,000 = **$5,000 profit**.
9. Any one: ignores cash flows after payback; ignores time value of money; no measure of profitability.
10. Present value of the inflows exceeds the cost, so the project earns more than the discount rate; accept on financial grounds.
