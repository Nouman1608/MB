## Section A: 1.1 Hardware and software

**1.** Define *hardware* and *software*. **[2]**

**2.** Name **three** internal hardware components of a computer. **[3]**

**3.** State the difference between applications software and system software, and give **two**
examples of each. **[6]**

**4.** Describe **two** differences between analogue and digital data. **[2]**

**5.** A greenhouse uses a temperature sensor and a computer to control a heater. Explain why the
data must be converted from analogue to digital, and from digital to analogue. **[4]**

## Section B: 1.3 Operating systems

**6.** Describe **two** characteristics of a command line interface. **[2]**

**7.** Give **two** advantages and **one** disadvantage of a graphical user interface. **[3]**

**8.** A driver wants to make phone calls while driving. Identify the most suitable type of
interface and explain why. **[3]**

## Section C: 1.4 Types of computer

**9.** Give **two** advantages of a desktop computer compared with a laptop. **[2]**

**10.** A sales representative travels to meet customers. Compare the use of a smartphone and a
laptop for this job. **[4]**

**11.** Explain what is meant by *expandability* and why it is usually lower for mobile computers. **[2]**

**12.** Describe how a smartphone can be used to remotely control a device in the home. **[2]**

## Section D: 1.5 Emerging technologies

**13.** Explain the difference between virtual reality and augmented reality. **[2]**

**14.** Discuss the impact of artificial intelligence on everyday life. **[6]**

## Answers

**1.** Hardware: the physical components of a computer system [1]. Software: programs that control
the operation of the computer or the processing of data [1].

**2.** Any three: CPU/processor [1]; motherboard [1]; RAM [1]; ROM [1]; graphics card [1]; sound card [1];
network interface card [1]; internal hard disk or SSD [1].

**3.** Applications software provides the services the user needs to carry out a task [1]; examples,
any two: word processor, spreadsheet, database management system, video or graphics editor, CAD,
apps [2]. System software provides the services the computer needs to operate [1]; examples, any two:
operating system, compiler, linker, device driver, utilities [2].

**4.** Any two: analogue data varies continuously, while digital data takes discrete values [1];
analogue data is the form found in the real world, such as temperature, while digital data is stored
as binary (0s and 1s) [1]; computers can only process digital data [1].

**5.** The temperature sensor produces an analogue signal, but the computer can only process digital
data, so an analogue-to-digital converter changes it [1–2]. The computer's digital output must be
converted to an analogue signal by a digital-to-analogue converter to control the heater or a
motor [1–2].

**6.** Any two: user types commands at a prompt [1]; commands must be learned and typed exactly [1];
little or no use of graphics [1]; gives direct control over the operating system [1].

**7.** Advantages, any two: easy to learn [1]; no commands to remember [1]; icons and menus are
intuitive [1]; several programs visible in windows [1]. Disadvantage, any one: needs more memory and
processing power [1]; can be slower than typing commands for expert users [1].

**8.** A dialogue-based interface [1], because the driver can speak commands such as "call home" and
keep both hands on the wheel and eyes on the road [1], which is safer than using a touch screen [1].

**9.** Any two: easier to upgrade and expand [1]; usually cheaper for the same performance [1];
larger screen and full-size keyboard [1]; less likely to be stolen or damaged [1].

**10.** Smartphone: very portable and always with the representative [1]; can make calls, email and
use maps on the mobile network [1]. Laptop: larger screen and keyboard, better for writing reports and
giving presentations [1]; more processing power but heavier and needs Wi-Fi or tethering to go online
[1].

**11.** Expandability is how easily a computer can be upgraded or have components added, such as
more RAM or storage [1]. Mobile computers are compact with components fixed or soldered in to save
space, so they are hard to upgrade [1].

**12.** An app on the smartphone sends commands over Wi-Fi or the internet to a smart device, such as
a heating system or lights [1], letting the user switch it on or off or change settings when away
from home [1].

**13.** Virtual reality creates a fully computer-generated environment that replaces the user's view
of the real world, usually through a headset [1]; augmented reality overlays digital images or
information on the real world, for example through a phone camera [1].

**14.** Positive, up to 4: voice assistants make tasks easier [1]; recommendations personalise
shopping and streaming [1]; medical AI helps doctors detect disease early [1]; banks use AI to spot
fraud [1]; translation tools help communication [1]. Negative, up to 4: some jobs replaced [1]; biased
decisions if trained on biased data [1]; large amounts of personal data collected, raising privacy
concerns [1]; fake images or text can spread misinformation [1]. A balanced answer with both sides is
needed for full marks. Maximum 6.
