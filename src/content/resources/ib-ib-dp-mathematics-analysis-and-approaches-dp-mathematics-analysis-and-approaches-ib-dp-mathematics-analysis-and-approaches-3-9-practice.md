These questions cover syllabus section 3.9 of IB DP Mathematics: Analysis and Approaches (first assessment 2021), which is HL only: the reciprocal ratios, the identities 1 + tan²θ = sec²θ and 1 + cot²θ = cosec²θ, and the inverse functions arcsin, arccos and arctan. Questions are labelled "(calculator-free)" or "(calculator allowed)". The methods are in the [3.9 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-9/) and the [3.9 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-9-revision-notes/).

## Section A

**1.** (calculator-free) Find the exact value of:

**(a)** sec(π/3) **[1]**

**(b)** cosec(−π/6) **[1]**

**(c)** cot(3π/4) **[1]**

**2.** (calculator-free) Find the exact value of:

**(a)** arcsin(−1/2) **[1]**

**(b)** arccos(−√3/2) **[1]**

**(c)** arctan(√3/3) **[1]**

**3.** (calculator-free) Given that cot θ = 3 and π < θ < 3π/2, find the exact value of cosec θ. **[3]**

**4.** (calculator-free)

**(a)** Write down the domain and range of f(x) = arccos(x − 2). **[2]**

**(b)** Write down the range of g(x) = 4 arctan x. **[1]**

**5.** (calculator-free) Find the exact value of cos(arcsin(−5/13)). **[2]**

**6.** (calculator-free) Show that sec²θ − cosec²θ = tan²θ − cot²θ. **[2]**

## Section B

**7.** (calculator allowed)

**(a)** Show that the equation 2tan²x + sec x = 1 can be written as 2sec²x + sec x − 3 = 0. **[2]**

**(b)** Hence solve 2tan²x + sec x = 1 for 0 ≤ x ≤ 2π. **[5]**

**8.** (calculator-free) Let θ = arctan(3/4).

**(a)** Find the exact value of sin θ. **[2]**

**(b)** Find the exact value of sin(2 arctan(3/4)). **[2]**

**(c)** Find the exact value of cos(2 arctan(3/4)). **[1]**

**9.** (calculator-free) Find the exact value of:

**(a)** arcsin(sin(4π/5)) **[2]**

**(b)** arccos(cos(−2π/7)) **[2]**

**10.** (calculator-free) Let f(x) = 2 arccos x − π/2.

**(a)** Write down the domain of f and find its range. **[3]**

**(b)** Solve f(x) = π/6. **[3]**

**(c)** Find an expression for f⁻¹(x), stating its domain. **[2]**

**11.** (calculator-free) Prove that (cosec θ − sin θ)(sec θ − cos θ) = sin θ cos θ, for all θ where the left-hand side is defined. **[4]**

**12.** (calculator-free) Given that sec x + tan x = 3:

**(a)** Use the identity sec²x − tan²x = 1 to find the value of sec x − tan x. **[2]**

**(b)** Hence find the values of cos x and sin x. **[3]**

## Answers

**1. (a)** 1/cos(π/3) = **2** [1]

**(b)** 1/sin(−π/6) = 1/(−1/2) = **−2** [1]

**(c)** 1/tan(3π/4) = 1/(−1) = **−1** [1]

**2. (a)** **−π/6** [1]

**(b)** **5π/6** [1]

**(c)** **π/6** [1]

*Examiner insight:* −π/6 for arccos(−√3/2) in (b) is outside the range of arccos and scores nothing.

**3.** cosec²θ = 1 + cot²θ = 10 [1]. In the third quadrant sin θ < 0, so cosec θ < 0 [1]: **cosec θ = −√10** [1]

**4. (a)** −1 ≤ x − 2 ≤ 1, so the domain is **1 ≤ x ≤ 3** [1]; the range is **0 ≤ f(x) ≤ π** [1]

**(b)** **−2π < g(x) < 2π** [1]

**5.** Let θ = arcsin(−5/13), so −π/2 ≤ θ ≤ 0 and cos θ ≥ 0 [1]. cos θ = √(1 − 25/169) = **12/13** [1]

**6.** sec²θ − cosec²θ = (1 + tan²θ) − (1 + cot²θ) [1] = **tan²θ − cot²θ** [1]

**7. (a)** tan²x = sec²x − 1, so 2(sec²x − 1) + sec x = 1 [1], giving **2sec²x + sec x − 3 = 0** [1]

**(b)** (2 sec x + 3)(sec x − 1) = 0 [1]. sec x = 1 gives cos x = 1, so **x = 0, 2π** [1]. sec x = −3/2 gives cos x = −2/3 [1], so **x = 2.30** [1] or **x = 2π − 2.30 = 3.98** [1]

*Examiner insight:* Converting sec x to cos x before solving is essential; most calculators have no sec key, and arccos(−2/3) gives only the first of the two solutions.

**8. (a)** tan θ = 3/4 with θ in ]−π/2, π/2[, so θ is acute and the triangle is 3, 4, 5 [1]: **sin θ = 3/5** [1]

**(b)** cos θ = 4/5, so sin 2θ = 2(3/5)(4/5) [1] = **24/25** [1]

**(c)** cos 2θ = 16/25 − 9/25 = **7/25** [1]

**9. (a)** sin(4π/5) = sin(π − 4π/5) = sin(π/5) [1], and π/5 is in [−π/2, π/2], so the value is **π/5** [1]

**(b)** cos(−2π/7) = cos(2π/7) [1], and 2π/7 is in [0, π], so the value is **2π/7** [1]

*Examiner insight:* An answer of 4π/5 or −2π/7 shows the range of the inverse function has been ignored; both score zero.

**10. (a)** Domain **−1 ≤ x ≤ 1** [1]. 0 ≤ arccos x ≤ π gives 0 ≤ 2 arccos x ≤ 2π [1], so **−π/2 ≤ f(x) ≤ 3π/2** [1]

**(b)** 2 arccos x − π/2 = π/6 gives 2 arccos x = 2π/3 [1], so arccos x = π/3 [1] and **x = 1/2** [1]

**(c)** x = 2 arccos y − π/2 gives arccos y = (x + π/2)/2, so **f⁻¹(x) = cos(x/2 + π/4)** [1], with domain **−π/2 ≤ x ≤ 3π/2** [1]

*Examiner insight:* The domain of the inverse is the range found in (a); stating "all real x" loses the mark even with a correct expression.

**11.** Left side = (1/sin θ − sin θ)(1/cos θ − cos θ) [1] = ((1 − sin²θ)/sin θ)((1 − cos²θ)/cos θ) [1] = (cos²θ/sin θ)(sin²θ/cos θ) [1] = **sin θ cos θ** [1]

**12. (a)** (sec x + tan x)(sec x − tan x) = sec²x − tan²x = 1 [1], so sec x − tan x = **1/3** [1]

**(b)** Adding the two equations: 2 sec x = 10/3, so sec x = 5/3 and **cos x = 3/5** [1]. Subtracting: 2 tan x = 8/3, so tan x = 4/3 [1]. sin x = tan x cos x = **4/5** [1]

*Examiner insight:* A check is that sin²x + cos²x = 16/25 + 9/25 = 1.

## Where marks are usually lost

- Answers to inverse functions outside the function's range, as in questions 2 and 9.
- The wrong sign for a reciprocal ratio because the quadrant was ignored.
- Solving with sec x directly instead of rewriting as cos x.
- Domain of an inverse function taken as all real numbers instead of the original range.
- Proofs that work on both sides at once instead of one clear chain.
