These questions cover syllabus section 3.7 of IB DP Mathematics: Analysis and Approaches (first assessment 2021): the circular functions sin x, cos x and tan x, amplitude and period, f(x) = a sin(b(x + c)) + d, transformations and real-life contexts. They are SL and HL. Questions are labelled "(calculator-free)" or "(calculator allowed)". Give calculator answers to 3 significant figures and use radians throughout. Methods are in the [3.7 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-7/) and the [3.7 revision notes](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-3-7-revision-notes/).

## Section A

**1.** (calculator-free) For y = 3 − 4 sin(πx/6), write down the amplitude, the period and the range. **[3]**

**2.** (calculator-free) For y = 5 tan 3x, write down the period and the equations of the asymptotes for 0 ≤ x ≤ π. **[3]**

**3.** (calculator-free) The graph of y = sin x is stretched vertically with scale factor 3, then stretched horizontally with scale factor 1/2, then translated 1 unit down. The result is y = g(x).

**(a)** Write down g(x). **[2]**

**(b)** Write down the range of g. **[1]**

**4.** (calculator-free) The graph of f(x) = a cos(bx) + d, where a, b > 0, has a maximum point at (0, 8) and the next minimum point at (π/2, 2). Find a, b and d. **[3]**

**5.** (calculator-free) Describe fully a sequence of transformations that maps the graph of y = cos x onto the graph of y = 2 cos(x/3 + π/6). **[3]**

**6.** (calculator-free) Let f(x) = 2 sin(x + π/3) − 1, for 0 ≤ x ≤ 2π.

**(a)** Find the y-intercept of the graph of f. **[1]**

**(b)** Find the coordinates of the maximum point. **[2]**

## Section B

**7.** (calculator allowed) A Ferris wheel has diameter 50 m and its lowest point is 2 m above the ground. It turns at a constant rate, making one revolution every 20 minutes. A rider boards at the lowest point at t = 0. The rider's height after t minutes is h(t) = p cos(qt) + r.

**(a)** Find p, q and r. **[3]**

**(b)** Find the rider's height after 4 minutes. **[2]**

**(c)** Find the length of time in one revolution for which the rider is more than 40 m above the ground. **[4]**

**8.** (calculator-free) Let f(x) = 3 sin(2(x + π/8)) − 1, for 0 ≤ x ≤ π.

**(a)** Write down the amplitude and the period of f. **[2]**

**(b)** Write down the maximum and minimum values of f. **[2]**

**(c)** Find the value of x at which the maximum occurs. **[2]**

**(d)** Find the range of f when the domain is restricted to 0 ≤ x ≤ π/4. **[2]**

**9.** (calculator-free) *Invented data.* In a town the mean daily temperature is greatest, 24 °C, in month 7 and least, 4 °C, in month 1. It is modelled by T(m) = a sin(b(m − c)) + d, where m is the month number, a > 0 and 0 < c < 12.

**(a)** Find a, b, c and d. **[4]**

**(b)** Find the temperature the model predicts for month 10. **[1]**

**(c)** Find the months for which the model predicts a temperature above 19 °C. **[3]**

**10.** (calculator-free) Let y = 2 tan(x + π/6), for −π ≤ x ≤ π.

**(a)** Find the equations of the asymptotes. **[2]**

**(b)** Find the x-intercepts. **[2]**

**(c)** Find the y-intercept. **[1]**

**11.** (calculator-free) The graph of y = p sin(qx) + r, where q > 0, has a minimum point at (π/4, −1), and the next maximum point is at (3π/4, 5). Find p, q and r. **[4]**

## Answers

**1.** Amplitude **4** [1]; period 2π ÷ (π/6) = **12** [1]; range **−1 ≤ y ≤ 7** [1]

**2.** Period **π/3** [1]. Asymptotes where 3x = π/2 + kπ [1], so **x = π/6, π/2, 5π/6** [1]

*Examiner insight:* Using 2π/3 as the period of a tangent graph loses the first mark and usually the asymptotes as well.

**3. (a)** **g(x) = 3 sin 2x − 1**: 3 sin 2x [1]; − 1 [1]

**(b)** **−4 ≤ g(x) ≤ 2** [1]

**4.** d = (8 + 2)/2 = **5** and a = (8 − 2)/2 = **3** [1]. Half a period is π/2, so the period is π [1] and **b = 2** [1]

**5.** Write 2 cos((1/3)(x + π/2)) [1]. Horizontal stretch with scale factor 3, then translation π/2 to the left [1]; vertical stretch with scale factor 2 [1]

*Examiner insight:* A translation of π/6 to the left is correct only if it comes before the stretch. After the stretch, the translation is π/2, read from the factorised bracket. Always state the order you use.

**6. (a)** f(0) = 2 sin(π/3) − 1 = **√3 − 1** [1]

**(b)** Maximum where x + π/3 = π/2, so x = π/6 [1]; maximum point **(π/6, 1)** [1]

**7. (a)** Centre at 27 m and radius 25 m, starting at the bottom: **p = −25** [1] and **r = 27** [1]. Period 20, so **q = 2π/20 = π/10** [1]

**(b)** h(4) = 27 − 25 cos(0.4π) [1] = **19.3 m** [1]

**(c)** 27 − 25 cos(πt/10) > 40 gives cos(πt/10) < −0.52 [1]. πt/10 = 2.1176 or 2π − 2.1176 = 4.1656 [1], so t = 6.741 or 13.259 [1]. Time above 40 m = **6.52 minutes** [1]

*Examiner insight:* Rounding t to 6.7 and 13.3 before subtracting gives 6.6, which loses the accuracy mark. Keep full values until the last step.

**8. (a)** Amplitude **3** [1]; period **π** [1]

**(b)** Maximum **2** [1]; minimum **−4** [1]

**(c)** 2(x + π/8) = π/2 [1], so **x = π/8** [1]

**(d)** For 0 ≤ x ≤ π/4, the argument 2(x + π/8) runs from π/4 to 3π/4, so sin runs from √2/2 up to 1 and back to √2/2 [1]. Range: **3√2/2 − 1 ≤ f(x) ≤ 2** [1]

*Examiner insight:* Evaluating only the two endpoints gives 3√2/2 − 1 for both and misses the maximum inside the interval.

**9. (a)** a = (24 − 4)/2 = **10** and d = (24 + 4)/2 = **14** [1]. Period 12 months, so **b = π/6** [1]. sin is greatest when b(m − c) = π/2, so (π/6)(7 − c) = π/2 [1], giving **c = 4** [1]

**(b)** T(10) = 10 sin(π) + 14 = **14 °C** [1]

**(c)** 10 sin((π/6)(m − 4)) + 14 > 19 gives sin((π/6)(m − 4)) > 1/2 [1]. So π/6 < (π/6)(m − 4) < 5π/6 [1], giving 1 < m − 4 < 5: **months 6, 7 and 8** (5 < m < 9) [1]

*Examiner insight:* Check the model with the given minimum: T(1) = 10 sin(−π/2) + 14 = 4, as required.

**10. (a)** x + π/6 = ±π/2 [1], so **x = π/3 and x = −2π/3** [1]

**(b)** x + π/6 = 0 or ±π [1]; inside the domain, **x = −π/6 and x = 5π/6** [1]

**(c)** y = 2 tan(π/6) = **2√3/3** [1]

**11.** Amplitude |p| = (5 − (−1))/2 = 3 and **r = 2** [1]. Half a period is 3π/4 − π/4 = π/2, so the period is π and **q = 2** [1]. With p = 3, x = π/4 would give 3 sin(π/2) + 2 = 5, a maximum, not a minimum [1], so **p = −3** [1]

*Examiner insight:* The sign of p is the point of the question. Checking the given minimum in the final equation catches the error.

## Where marks are usually lost

- Period of a tangent graph taken as 2π/b instead of π/b.
- Translation read from an unfactorised bracket, as in question 5.
- A cosine model started at a maximum when the context starts at the lowest point.
- Rounding intermediate values in a model, as in question 7.
- Checking only the endpoints of a restricted domain when finding a range.
- Assuming a > 0 when the given point is a minimum.
