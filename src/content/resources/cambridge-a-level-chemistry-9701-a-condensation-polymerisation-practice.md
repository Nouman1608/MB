## Section A

**1.** State the small molecule lost when a diol reacts with a dioyl chloride to form a polyester.
**[1]**

**2.** Give the structure of the link present in every polyamide. **[1]**

## Section B

**5.** Propane-1,3-diol, HO(CH₂)₃OH, reacts with benzene-1,4-dioyl chloride, ClOCC₆H₄COCl.

**(a)** Draw the repeat unit of the polymer formed. **[2]**

**(b)** Write a balanced equation for the polymerisation, using n. **[2]**

**(c)** Calculate the Mᵣ of the repeat unit. **[1]**

**6.** A section of a polymer is shown.

–NHCH(CH₃)CO–NHCH₂CO–NHCH(CH₃)CO–NHCH₂CO–

**(a)** State the type of condensation polymer and the name given to its links. **[1]**

**(b)** Identify the two monomers. **[2]**

**(c)** State the number of complete links between units shown in the section. **[1]**

**7.** A section of a polyester is shown.

–OCH₂CH₂CH₂OOCCH₂CH₂CO–OCH₂CH₂CH₂OOCCH₂CH₂CO–

**(a)** Identify the two monomers, giving the acid-derived monomer as a dioyl chloride. **[2]**

**(b)** Draw the repeat unit. **[1]**

**8.** A sample of poly(lactic acid), –[OCH(CH₃)CO]ₙ–, has Mᵣ = 50 400.

**(a)** Calculate the Mᵣ of the repeat unit. **[1]**

**(b)** Calculate the number of repeat units in each chain. **[1]**

**9.** Benzene-1,4-diamine, H₂NC₆H₄NH₂, reacts with hexanedioic acid, HOOC(CH₂)₄COOH.

**(a)** Draw the repeat unit of the polyamide formed. **[2]**

**(b)** A single chain contains 200 repeat units. State the number of water molecules released in
forming this chain, explaining your answer. **[1]**

**10.** 4-aminobenzoic acid, H₂NC₆H₄COOH, can polymerise on its own.

**(a)** State the type of polymer formed. **[1]**

**(b)** Draw the repeat unit. **[1]**

**(c)** Write the equation for the polymerisation, using n. **[1]**

**11.** A student is asked for the repeat unit of the polymer formed from ethane-1,2-diol and
hexanedioic acid, and writes:

HO–CH₂CH₂–OOC(CH₂)₄CO–OH

**(a)** Identify two errors in the student's answer. **[2]**

**(b)** Give the correct repeat unit. **[1]**

**12.** A polyester is made from benzene-1,4-dicarboxylic acid and a diol, HO(CH₂)ₓOH. Its repeat unit
has Mᵣ = 220.0. Deduce the value of x and name the diol, showing your working. **[3]**

**13.** Nylon-6,6 can be made from hexane-1,6-diamine and either hexanedioic acid or hexanedioyl
chloride.

**(a)** Explain why a section of the finished polymer cannot show which of the two acid-derived
monomers was used. **[1]**

**(b)** Suggest one advantage of using hexanedioyl chloride and one disadvantage. **[2]**

## Answers

**1.** Hydrogen chloride, HCl [1].

**2.** The amide link, –CONH– (C=O bonded to N–H) [1].

**3.** 5-hydroxypentanoic acid, HO(CH₂)₄COOH [1].

**4.** An amine group (–NH₂) and a carboxylic acid group (–COOH) (or acyl chloride, –COCl) [1].

**5. (a)** –O(CH₂)₃OOCC₆H₄CO–: correct ester links joining one diol residue and one diacid residue
[1]; open bonds at both ends with no end groups, in brackets with n [1].

**(b)** n HO(CH₂)₃OH + n ClOCC₆H₄COCl → –[O(CH₂)₃OOCC₆H₄CO]ₙ– + 2n HCl: correct polymer with n [1];
2n HCl (accept (2n − 1) HCl) [1].

**(c)** C₁₁H₁₀O₄ = 11(12.0) + 10(1.0) + 4(16.0) = 206.0 [1].

**6. (a)** A polyamide (polypeptide), with peptide (amide) links [1].

**(b)** Alanine, H₂NCH(CH₃)COOH [1]; glycine, H₂NCH₂COOH [1].

**(c)** Three [1].

**7. (a)** Propane-1,3-diol, HOCH₂CH₂CH₂OH [1]; butanedioyl chloride, ClOCCH₂CH₂COCl [1].

**(b)** –OCH₂CH₂CH₂OOCCH₂CH₂CO– [1].

**8. (a)** C₃H₄O₂ = 3(12.0) + 4(1.0) + 2(16.0) = 72.0 [1].

**(b)** 50 400 / 72.0 = 700 [1].

**9. (a)** –NHC₆H₄NHCO(CH₂)₄CO–: amide links joining one diamine residue and one diacid residue [1];
open bonds at both ends, no end groups [1].

**(b)** 399, because 200 of each monomer form 2 × 200 − 1 = 399 links, each releasing one water
molecule (accept 400 if the 2n approximation is explained) [1].

**10. (a)** A polyamide [1].

**(b)** –NHC₆H₄CO– [1].

**(c)** n H₂NC₆H₄COOH → –[NHC₆H₄CO]ₙ– + n H₂O (accept (n − 1) H₂O) [1].

**11. (a)** The H of the diol's –OH and the –OH of the acid group should have been removed, so the
unit must not start with HO– or end with –OH [1]; the ends should be open bonds drawn through
brackets with n, showing that the unit links to the next one [1].

**(b)** –OCH₂CH₂OOC(CH₂)₄CO– [1].

**12.** The repeat unit is –O(CH₂)ₓOOCC₆H₄CO–; the part without the CH₂ groups is C₈H₄O₄, Mᵣ = 164.0
[1]; 220.0 − 164.0 = 56.0, and 56.0 / 14.0 = 4, so x = 4 [1]; the diol is butane-1,4-diol [1].

**13. (a)** Both give exactly the same amide links and the same repeat unit; only the small molecule
lost (H₂O or HCl) differs, and it is not part of the polymer [1].

**(b)** Advantage: the dioyl chloride is more reactive, so polymerisation is faster and needs no
strong heating [1]. Disadvantage: corrosive HCl is produced (and dioyl chlorides react with moisture,
so they are harder to store and handle) [1].

## Where marks are usually lost

- Writing H₂O as the by-product when a dioyl chloride is used.
- Leaving H, OH or Cl on the ends of a repeat unit.
- Including two diol residues, or two acid residues, in a two-monomer repeat unit.
- Breaking a chain at the C=O bond rather than the C–O or C–N single bond.
- Missing the second amino acid in a polypeptide section because the links all face the same way;
  compare the side chains, not just the links.
- In mass deductions, forgetting the two oxygen atoms that the diol contributes to the ester links.
- Writing a different n for each monomer in a polymerisation equation, or forgetting to multiply the
  small molecule by 2n when there are two monomers.
