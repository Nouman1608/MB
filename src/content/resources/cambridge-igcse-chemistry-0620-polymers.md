## Core: polymers, monomers and poly(ethene)

A **polymer** is a **large molecule built up from many smaller molecules called monomers**. That is the syllabus definition, and "large" and "many" both matter: a dimer of two units is not a polymer.

**Addition polymerisation** joins monomers that contain a **C=C double bond**. The double bond in each monomer opens, and the monomers link into a long chain. Nothing else is produced.

**Poly(ethene)** is made from **ethene** monomers:

```
many CH₂=CH₂  →  —CH₂—CH₂—CH₂—CH₂—CH₂—CH₂—
   ethene              part of poly(ethene)
```

Written with *n* to stand for a large number:

```
     H   H              H   H
     |   |              |   |
 n   C = C     →    —[ C — C ]—
     |   |              |   |   n
     H   H              H   H
```

The double bond becomes a single bond, and each carbon gains a new bond to the next unit, shown by the bonds that extend through the brackets.

### Plastics and their disposal

**Plastics are made from polymers.** The properties that make plastics useful are the same ones that make them hard to dispose of:

| Useful property | Disposal problem |
|---|---|
| unreactive / durable: do not corrode or rot | **non-biodegradable**: not broken down by microorganisms, so they persist for a very long time |
| low density, strong | light pieces are carried by wind and water and spread widely |
| made from carbon-containing polymers | release toxic gases when burned |

The syllabus names three **environmental challenges**:

1. **Disposal in landfill sites** – plastics do not decompose, so they take up landfill space for a very long time.
2. **Accumulation in oceans** – plastic waste builds up in the sea, where animals can swallow it or become trapped in it, and it breaks into smaller pieces rather than decomposing.
3. **Formation of toxic gases from burning** – burning plastics, especially with limited oxygen, can release toxic gases such as carbon monoxide.

A "describe" answer should give the problem **and** its cause: "plastics are non-biodegradable, so they remain in landfill sites for many years" is worth more than "plastics fill up landfill".

## Repeat units of addition polymers *(Extended)*

The **repeat unit** is the smallest section of the chain that repeats. For an addition polymer it contains the same atoms as the monomer, with the C=C turned into C–C and a bond extending out of each side.

### Worked example 1: from monomer to repeat unit, and back

**Monomer to polymer.** Draw the repeat unit of the polymer made from propene, CH₂=CH–CH₃.

1. Draw the two carbons of the C=C in a line, with their attached groups above and below.
2. Replace C=C with C–C.
3. Add a bond extending out from each of those two carbons, and brackets with *n*.

```
     H   H
     |   |
 —[ C — C ]—
     |   |   n
     H   CH₃
```

The CH₃ group is a **side branch**; it is not part of the main chain.

**Polymer to monomer.** A polymer has the repeat unit —[CH₂—CH(C₂H₅)]—. Find the monomer.

1. Take the two main-chain carbons of the repeat unit.
2. Remove the extending bonds and put a double bond between those two carbons.
3. Monomer: CH₂=CH–C₂H₅, which is **but-1-ene**.

## Condensation polymerisation *(Extended)*

In **condensation polymerisation**, monomers each have **two** functional groups, one at each end. When two monomers join, a **small molecule (water)** is eliminated, and a new linkage forms. The syllabus limits this to two types, both using a **dicarboxylic acid** (–COOH at both ends):

| Polymer type | Other monomer | Linkage formed | Example |
|---|---|---|---|
| **polyamide** | **diamine**, H₂N–□–NH₂ | **amide**, –CO–NH– | **nylon** |
| **polyester** | **diol**, HO–□–OH | **ester**, –CO–O– | **PET** |

Here □ stands for the carbon chain between the functional groups; the syllabus uses blocks in the same way and does not require the exact chain.

Nylon (a polyamide):

```
 —[ CO —□— CO — NH —□— NH ]—
```

PET (a polyester):

```
 —[ CO —□— CO — O —□— O ]—
```

The full name of PET is not required. PET **can be converted back into its monomers and re-polymerised**, which allows it to be recycled into new PET.

### Worked example 2: deducing a condensation repeat unit

*Monomers: HOOC–□–COOH and HO–■–OH. Draw the repeat unit and name the linkage.*

1. Identify the groups: –COOH and –OH, so a **polyester** forms.
2. At each join, the –OH of the acid and the H of the alcohol's –OH leave as **H₂O**.
3. The acid keeps –CO– at each end; the diol keeps –O– at each end.
4. Repeat unit: —[CO–□–CO–O–■–O]—. Linkage: **ester**.

Reversing the process: given a polyamide chain, cut through each –CO–NH– linkage, add –OH back to each C=O end and H back to each N–H end. You recover HOOC–□–COOH and H₂N–■–NH₂.

## Addition vs condensation *(Extended)*

| | Addition | Condensation |
|---|---|---|
| Monomers | contain C=C | have two functional groups each |
| Number of monomer types | usually one | usually two (or one with two different groups, as in amino acids) |
| Products | polymer only | polymer + small molecule (water) |
| Repeat unit vs monomer | same atoms | fewer atoms than the monomers combined |
| Examples | poly(ethene), poly(propene) | nylon, PET, proteins |

## Proteins *(Extended)*

**Proteins are natural polyamides**, formed from **amino acid** monomers. Each amino acid has an amine group (–NH₂) and a carboxylic acid group (–COOH) on the same carbon, which also carries H and a side-chain **R**:

```
        H
        |
H₂N  —  C  — COOH
        |
        R
```

R represents different side-chains, so there are many different amino acids. When amino acids join, water is eliminated and **amide linkages** (–CO–NH–) form, exactly as in nylon:

```
 — NH — CH(R) — CO — NH — CH(R′) — CO — NH — CH(R″) — CO —
```

A protein chain differs from nylon in that its repeating sections carry **different R groups**, and each unit comes from a single monomer with both groups.

## Common mistakes

- **Leaving the double bond in a repeat unit**, or forgetting the extending bonds.
- **Putting a side group into the main chain**: in poly(propene), CH₃ hangs off the chain.
- **Forgetting water** as the second product of condensation polymerisation.
- **Mixing up linkages**: amide is –CO–NH–; ester is –CO–O–.
- **Saying plastics "dissolve" or "rot" in landfill.** They are non-biodegradable.
- **Giving "pollution" alone** as an environmental challenge without naming landfill, oceans or toxic gases.

## Exam technique

- **Define:** "large molecules built up from many smaller molecules called monomers".
- **Describe** (poly(ethene)): monomer, addition polymerisation, C=C breaks, long chain, no other product.
- **Describe** (environmental challenges): name the challenge and link it to a property.
- **Deduce** *(Extended)*: work methodically – identify functional groups, decide the polymer type, remove water, draw the linkage, add brackets and *n*.
- **Describe the differences** *(Extended)*: compare like with like (products, monomers), one difference per mark.
