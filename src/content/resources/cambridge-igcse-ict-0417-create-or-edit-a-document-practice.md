## Section A: short answers

**1.** State what is meant by *drag and drop*. **[1]**

**2.** Which **one** of these leaves the original text in place?

A: cut

B: copy

C: delete

D: move **[1]**

**3.** Give **two** types of object, other than an image, that can be placed into a document. **[2]**

**4.** State what is meant by a *database extract*. **[1]**

**5.** Name the text-wrapping option in which text follows the outline of an irregularly shaped object. **[1]**

**6.** Give **two** types of error that a spell checker would not find. **[2]**

## Section B: structured questions

**7.** This sentence was copied from a source: "Order 2 360 units by 14 March from Ellacott Ltd." The typed version reads: "Order 2 630 units by 14 march from Elacott Ltd"

**(a)** Identify **four** errors in the typed version. **[4]**

**(b)** Describe **two** methods of checking that data has been entered with total accuracy. **[2]**

**8.** A student is editing a five-page report.

**(a)** Describe how to move the final paragraph on page 5 so that it becomes the first paragraph on page 1. **[3]**

**(b)** After the move, the paragraph appears in a different font from the rest of the report. Explain why this may have happened and how to avoid it. **[2]**

**9.** A sales report needs a table of the top five products copied from a spreadsheet of 400 products.

**(a)** Explain why only an extract of the spreadsheet should be placed in the report. **[2]**

**(b)** Describe how to place the extract in the report. **[2]**

**10.** A newsletter contains a circular logo, a rectangular photograph and a bar chart.

**(a)** State the most suitable wrapping for the logo so that text follows its edge, and explain your choice. **[2]**

**(b)** Explain why square and tight wrapping would look the same for the photograph. **[1]**

**(c)** The bar chart must have text above and below it but none beside it. Name this arrangement. **[1]**

**11.** A teacher wants to show students the settings she used in a database query. Describe how she could place this evidence in a worksheet so that it is clear. **[3]**

**12.** Compare using drag and drop with using cut and paste to move text. **[4]**

## Answers

**1.** Moving (or copying) a selected item by dragging it with the mouse and releasing it in a new position (1). **[1]**

**2.** B: copy. **[1]**

**3.** Any two: text from another file (1); screenshot (1); shapes (1); table (1); graph or chart (1); spreadsheet extract (1); database extract (1). **[2]**

**4.** Selected records or fields from a database, such as the results of a query, placed into a document (1). **[1]**

**5.** Tight (1). **[1]**

**6.** Any two: a mistyped number (1); a correctly spelled word used wrongly, such as "form" for "from" (1); a wrong capital letter in some cases (1); a missing or extra space (1); a proper noun typed differently from the source (1). **[2]**

**7. (a)** Any four: 2 360 typed as 2 630, digits transposed (1); "March" typed with a lower-case m (1); "Ellacott" missing an l (1); full stop missing at the end (1).

**(b)** Any two: compare the typed text with the source line by line (1); check numbers digit by digit (1); turn on show formatting marks to find extra spaces or paragraph marks (1); ask someone else to proofread against the source (1). **[6]**

**8. (a)** Select the whole paragraph, including the paragraph mark (1); cut it (1); place the cursor at the start of the first paragraph on page 1 and paste (1).

**(b)** The text was pasted with a formatting option that kept different formatting, or the paragraph had different direct formatting (1). Paste using the option that matches the destination formatting, or as text only, then apply the report's style (1). **[5]**

**9. (a)** The report only needs the top five products (1); placing all 400 would add unwanted data, make the report long and hard to read, and lose the focus the task asks for (1).

**(b)** In the spreadsheet, sort or filter to show the top five, then select only those rows and the required columns and copy them (1); in the report, place the cursor where the table should go and paste, checking it fits within the margins (1). **[4]**

**10. (a)** Tight (1), because the logo is circular, so tight wrapping lets the text follow the curve instead of leaving a square gap at the corners (1).

**(b)** The photograph's outline is already a rectangle, so following its outline is the same as wrapping round a rectangular box (1).

**(c)** Above and below (top and bottom) wrapping (1). **[4]**

**11.** Any three: take a screenshot of the query design screen (1); crop it so only the relevant settings are shown (1); place the screenshot in the worksheet at the correct point (1); resize it, keeping the aspect ratio, so the text is readable (1); add a caption explaining what it shows (1). Maximum 3. **[3]**

**12.** Up to 4 marks, with at least one point about each:
- Drag and drop is quicker because the selection is moved in one action (1), and it is useful for short moves visible on the same screen (1).
- Drag and drop is hard to control over long distances, and text can be dropped in the wrong place (1).
- Cut and paste works over any distance, including between pages or documents (1), and the clipboard allows the same text to be pasted more than once (1).
- Cut and paste needs more steps (1).

**[4]**

## Frequently asked questions

**Does 13.1 only apply to word processing?**
No. The syllabus says that in this section "document" relates to any of the applications in the practical sections, so the same skills apply to presentations, spreadsheets, databases and web pages.

**Is "highlight" the same as highlighting text in yellow?**
In the 13.1 list it is an editing technique: selecting text or numbers so that they can be deleted, moved, cut, copied or formatted.
