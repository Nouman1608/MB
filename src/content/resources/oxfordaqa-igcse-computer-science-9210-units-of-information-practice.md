## Section A

**1.** State what is meant by a bit and by a byte. **[2]**

**2.** State the symbol that is used for a bit and the symbol that is used for a byte. **[2]**

**3.** Complete the table with the symbol and the value in bytes of each unit.

| Unit | Symbol | Value in bytes |
|---|---|---|
| kilobyte | | |
| megabyte | | |
| gigabyte | | |
| terabyte | | |

**[4]**

**4.** Convert each quantity.

**(a)** 5 kB to bytes **[1]**

**(b)** 0.25 GB to MB **[1]**

**(c)** 45,000,000 bytes to MB **[1]**

**(d)** 3 TB to GB **[1]**

## Section B

**5.** Convert each quantity to bits.

**(a)** 2.5 kB **[2]**

**(b)** 3 MB **[2]**

**6.** A sensor sends a message of 40,000 bits. Convert this to kilobytes, showing your working. **[2]**

**7.** A music player has a 32 GB memory. Each song needs 8 MB of storage. Calculate how many songs can be stored.
**[3]**

**8.** A drive holds 500 GB. Each video file is 1.6 GB. Calculate the greatest number of whole video files that can be
stored on the drive. **[3]**

**9.** Put these file sizes in order, starting with the smallest: 1.6 MB, 1,500 kB, 0.0018 GB, 1,200,000 B. **[3]**

**10.** A student says, "A kilobyte is 1,024 bytes." Explain what value is used in this course and why the
statement would lose a mark in an assessment. **[2]**

**11.** A phone stores 250 photographs and each photograph is 6 MB. State the total size in gigabytes and state
whether they fit on an 8 GB memory card. **[3]**

**12.** A text file is 12 kB. A student states the size as "12 kb". Explain what mistake the student has made and
state the size of the file in bits. **[3]**

**13.** A school server has a capacity of 2 TB. Each student's folder is limited to 500 MB. Calculate the greatest
number of folders that can be stored. **[3]**

**14.** A file is 0.5 MB in size. Calculate its size in bits. **[3]**

**15.** A text message is 280 bytes long. State its size in bits and in kilobytes. **[3]**

**16.** A student says that a 4 MB file is smaller than a 3,900 kB file because 4 is smaller than 3,900. Explain why the
student is wrong, and state which file is larger. **[3]**

## Answers

**1.** A bit is a single binary digit, a 0 or a 1 [1]; a byte is a group of 8 bits [1].

**2.** Bit: b (lower case) [1]. Byte: B (upper case) [1].

**3.**

| Unit | Symbol | Value in bytes |
|---|---|---|
| kilobyte | kB | 1,000 |
| megabyte | MB | 1,000,000 |
| gigabyte | GB | 1,000,000,000 |
| terabyte | TB | 1,000,000,000,000 |

One mark for each correct row (both the symbol and the value) [4].

**4.** **(a)** 5,000 bytes [1]. **(b)** 250 MB [1]. **(c)** 45 MB [1]. **(d)** 3,000 GB [1].

**5.** **(a)** 2.5 × 1,000 = 2,500 bytes [1]; 2,500 × 8 = 20,000 bits [1].
**(b)** 3 × 1,000,000 = 3,000,000 bytes [1]; 3,000,000 × 8 = 24,000,000 bits [1].

**6.** 40,000 ÷ 8 = 5,000 bytes [1]; 5,000 ÷ 1,000 = 5 kB [1].

**7.** 32 GB = 32,000 MB [1]; 32,000 ÷ 8 [1] = 4,000 songs [1].

**8.** 500 ÷ 1.6 [1] = 312.5 [1]; only whole files can be stored, so round down to 312 [1].

**9.** In bytes the sizes are 1,600,000 B, 1,500,000 B, 1,800,000 B and 1,200,000 B [1]. The order from smallest is
1,200,000 B, then 1,500 kB [1], then 1.6 MB, then 0.0018 GB [1].

**10.** The course uses decimal prefixes, so 1 kB = 1,000 bytes [1]; assessments use powers of 10, and the value 1,024 is
a power of 2 that is not used [1].

**11.** 250 × 6 = 1,500 MB [1]; 1,500 ÷ 1,000 = 1.5 GB [1]; the photographs fit, because 1.5 GB is less than 8 GB [1].

**12.** The student has used a lower-case b, which stands for bit, instead of B for byte [1]. The file is 12 kB, which is
12,000 bytes [1]; 12,000 × 8 = 96,000 bits [1].

**13.** 2 TB = 2,000 GB = 2,000,000 MB [1]; 2,000,000 ÷ 500 [1] = 4,000 folders [1].

**14.** 0.5 MB = 0.5 × 1,000,000 = 500,000 bytes [1]; 500,000 × 8 [1] = 4,000,000 bits [1].

**15.** 280 × 8 = 2,240 bits [1]; 280 ÷ 1,000 = 0.28 kB [1]; units given with both answers [1].

**16.** The units are different, so the numbers cannot be compared directly [1]; 4 MB = 4 × 1,000 = 4,000 kB [1]; so the 4 MB file
is larger than the 3,900 kB file [1].

---

## Where marks are usually lost

- Writing 1,024 instead of 1,000.
- Dividing instead of multiplying, or the other way round, when changing units.
- Using one factor of 1,000 where two are needed (MB to bytes in Question 5).
- Not rounding down to a whole number of files in Question 8.
- Writing a final answer with no unit, or with b and B confused.
