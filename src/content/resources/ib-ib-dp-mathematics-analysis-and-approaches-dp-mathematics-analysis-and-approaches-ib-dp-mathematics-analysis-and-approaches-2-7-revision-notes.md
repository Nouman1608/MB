These notes condense section 2.7 of the IB *Mathematics: analysis and approaches guide* (first assessment 2021): solving quadratic equations and inequalities, the quadratic formula, and the discriminant Δ = b² − 4ac with the nature of the roots. It is common to SL and HL. For full explanations and worked examples, see the [2.7 study guide](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-7/); for exam-style questions, see the [2.7 practice set](/resources/ib-ib-dp-mathematics-analysis-and-approaches-dp-mathematics-analysis-and-approaches-ib-dp-mathematics-analysis-and-approaches-2-7-practice/).

## Core recall

- Quadratic formula: **x = (−b ± √(b² − 4ac))/(2a)**.
- **Discriminant Δ = b² − 4ac.**
- Δ > 0: two distinct real roots. Δ = 0: two equal real roots. Δ < 0: no real roots.
- "Real roots" means Δ ≥ 0.
- For a > 0: ax² + bx + c < 0 between the roots; > 0 outside them.
- Always positive: a > 0 and Δ < 0. Always negative: a < 0 and Δ < 0.
- Line meets curve: equate, rearrange to a quadratic = 0, use Δ (tangent: Δ = 0).
- Roots of an equation = zeros of the function.

## Key terms

| Term | Meaning |
|---|---|
| Root | Solution of an equation |
| Zero | Input where a function equals 0 |
| Discriminant | Δ = b² − 4ac, the expression under the square root |
| Distinct roots | Two different roots |
| Equal (repeated) roots | One root counted twice; the graph touches the axis |
| Critical values | Roots used as boundaries when solving an inequality |
| Tangent | A line meeting the curve at exactly one point without crossing it |
| Disguised quadratic | An equation that becomes quadratic after a substitution such as u = x² |

## Methods at a glance

**Equation:** factorise → complete the square → formula → GDC (Paper 2).

**Inequality:**
1. Rearrange to one side 0.
2. Find the critical values.
3. Sketch the parabola.
4. Read the region; use "or" for two separate regions.

**Quick example.** 5 − 4x − x² > 0 becomes x² + 4x − 5 < 0, so (x + 5)(x − 1) < 0 and −5 < x < 1.

**Disguised quadratic:** substitute u, solve, return to x, reject impossible values (u = x² < 0 or u = eˣ ≤ 0).

## Standard discriminant problems

| Question | Condition |
|---|---|
| Two distinct real roots | Δ > 0 |
| Equal roots / tangent | Δ = 0 |
| No real roots / line misses curve | Δ < 0 |
| Real roots | Δ ≥ 0 |
| Show real roots for all k | Rewrite Δ as (…)² ≥ 0 |
| Show two distinct roots for all k | Rewrite Δ as (…)² + positive |
| Always positive | a > 0 and Δ < 0 |

**Quick example.** For x² + kx + (k − 5) = 0, Δ = k² − 4(k − 5) = k² − 4k + 20 = (k − 2)² + 16 > 0, so there are two distinct real roots for every k.

## Roots and the graph

| Algebra | Graph of y = ax² + bx + c |
|---|---|
| Roots x = p and x = q | Crosses the x-axis at p and q |
| Repeated root x = p | Vertex on the x-axis at (p, 0) |
| No real roots | Whole graph above (a > 0) or below (a < 0) the axis |
| Roots p and q | Axis of symmetry x = (p + q)/2 |

**Quick example.** The roots of 2x² − 6x + 1 = 0 are (3 ± √7)/2, so the axis of symmetry is x = 3/2, the average of the two roots, which matches −b/(2a) = 6/4.

## Exam traps

- "x < −3 and x > 5" instead of "or".
- Reading the wrong region of the inequality.
- −b written as −6 when b = −6.
- Δ ≥ 0 versus Δ > 0 confused.
- "Always positive" answered with Δ < 0 alone.
- A parameter that makes a = 0 not checked.
- Dividing both sides of an inequality by x, which may be negative.

## Self-test

1. Solve x² + x − 12 = 0.
2. Solve x² − 4x + 2 = 0 exactly.
3. Find the discriminant of 3x² − 2x + 5 and state the nature of the roots.
4. Solve x² ≤ 9.
5. Solve x² > 4x.
6. Find k if 4x² + kx + 1 = 0 has equal roots.
7. State the conditions for ax² + bx + c > 0 for all x.
8. State the nature of the roots of x² − 6x + 9 = 0.
9. Find m if y = mx is a tangent to y = x² + 1.
10. Solve (x − 1)(x + 5) < 0.
11. Solve x⁴ − 10x² + 9 = 0.
12. How many x-intercepts does y = 2x² + 3x − 7 have?

### Answers

1. (x + 4)(x − 3) = 0: x = 3 or x = −4
2. x = (4 ± √8)/2 = 2 ± √2
3. Δ = 4 − 60 = −56 < 0: no real roots
4. −3 ≤ x ≤ 3
5. x(x − 4) > 0: x < 0 or x > 4
6. k² − 16 = 0: k = ±4
7. a > 0 and b² − 4ac < 0
8. Δ = 0: two equal real roots (x = 3)
9. x² − mx + 1 = 0 with m² − 4 = 0: m = ±2
10. −5 < x < 1
11. (x² − 1)(x² − 9) = 0: x = ±1, ±3
12. Δ = 9 + 56 = 65 > 0: two
