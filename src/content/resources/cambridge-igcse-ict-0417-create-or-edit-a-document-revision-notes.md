These notes condense section 13.1 of Cambridge IGCSE ICT 0417, "Create or edit a document". Remember that "document" here means work in any of the practical applications, not only a word processor. For explanations and a worked editing task, read the [create or edit a document study guide](/resources/cambridge-igcse-ict-0417-create-or-edit-a-document/), then try the [create or edit a document practice questions](/resources/cambridge-igcse-ict-0417-create-or-edit-a-document-practice/).

## Syllabus coverage

| Syllabus wording | Revise |
|---|---|
| Enter and modify text and numbers with total accuracy | Types of error; line-by-line checking |
| Editing techniques | Highlight, delete, move, cut, copy, paste, drag and drop |
| Place objects from a variety of sources | Text, image, screenshot, shapes, table, graph or chart, spreadsheet extract, database extract |
| Wrap text around a table, chart or image | Above, below, square, tight |

## Total accuracy

**Error types:** spelling (including names), case, transposed characters or digits, missing or extra characters, spaces and punctuation, wrong symbols (letter O for zero), omitted words or lines.

**Checking method:**

- compare with the source line by line;
- show formatting marks to spot double spaces and blank paragraphs;
- check numbers digit by digit;
- do not trust spell check for names, numbers or real-but-wrong words.

## Editing techniques

| Technique | How | When |
|---|---|---|
| Highlight (select) | Double-click word; triple-click or margin-click paragraph; Shift + arrows; Select All | Before any edit |
| Delete | Delete key (right of cursor) or Backspace (left) | Removing text; check for leftover spaces |
| Cut | Removes selection to clipboard | First half of a move |
| Copy | Copies selection to clipboard; original stays | Duplicating text |
| Paste | Inserts clipboard at cursor; can repeat | Second half of a move or copy |
| Move | Cut, then paste | Relocating text |
| Drag and drop | Drag selection to new place (modifier key to copy) | Short moves on screen |

**Paste options:** keep source formatting; match destination formatting; text only. Match the destination when the pasted text must look like the rest of the document.

## Objects and their sources

| Object | Check after placing |
|---|---|
| Text from a file | Matches document styles; no stray blank lines |
| Image | Position, size, aspect ratio |
| Screenshot | Cropped and readable |
| Shapes | Size, line, fill; grouped if several parts |
| Table | Rows and columns as asked; within margins |
| Graph or chart | Correct data; readable titles and labels |
| Spreadsheet extract | Only the required cells; number formats kept |
| Database extract | Only the required fields and records, in order |

**Extract** = part of a file. Select only what the task names.

## Text wrapping

| Option | Result |
|---|---|
| Above and below (top and bottom) | Text above and below the object, none beside it |
| Square | Text flows around a rectangle enclosing the object |
| Tight | Text follows the object's actual outline |

Square and tight are identical for a rectangular image; tight differs for irregular shapes.

## Key terms

| Term | Meaning |
|---|---|
| Total accuracy | Data entered exactly as in the source |
| Transposition | Two adjacent characters typed in the wrong order |
| Clipboard | Temporary store for cut or copied items |
| Drag and drop | Moving a selection by dragging it with the mouse |
| Extract | A selected part of a spreadsheet or database |
| Screenshot | An image of what is shown on the screen |
| Text wrapping | How text flows around an object |
| Formatting marks | Hidden symbols for spaces, tabs and paragraph ends |

## Exam traps

- **Move** means cut and paste; copy leaves the original behind.
- Spell check **misses** wrong numbers and real words used wrongly.
- Paste with **matching formatting** to avoid a different font.
- An **extract** is not the whole worksheet or table.
- Tight and square only differ for **irregular** outlines.
- After deleting, check for **double spaces** and **empty paragraphs**.
- "Document" in 13.1 includes **presentations, spreadsheets, databases and web pages**.

## Self-test

1. Give three types of data-entry error.
2. Why is checking by reading for sense unreliable?
3. Give one feature that helps find double spaces.
4. State the difference between cut and copy.
5. Which two actions together move text?
6. Give one advantage of drag and drop over cut and paste.
7. Give one situation where cut and paste is better than drag and drop.
8. Name four sources of objects listed in the syllabus.
9. What is a spreadsheet extract?
10. Which wrapping makes text follow the outline of a star-shaped logo?
11. Which wrapping leaves no text beside a chart?
12. Pasted text appears in a different font. What should have been done?

## Self-test answers

1. Any three: spelling, case, transposition, missing characters, extra spaces, wrong punctuation, wrong symbols, omitted words.
2. The brain sees what it expects, so errors such as transposed digits are missed.
3. Show formatting marks.
4. Cut removes the original; copy leaves it in place.
5. Cut, then paste.
6. Quicker for short distances on the same screen.
7. Moving text a long way, such as to another page.
8. Any four: text, image, screenshot, shapes, table, graph or chart, spreadsheet extract, database extract.
9. A selected part of a spreadsheet, such as some rows and columns, placed in a document.
10. Tight.
11. Above and below (top and bottom).
12. Paste using the option that matches the destination formatting, or paste as text only.
