These questions cover the "File size reduction" statement in Topic 12 of Cambridge IGCSE ICT 0417: reducing the file size of an image by reducing its resolution or its colour depth. Sizes are uncompressed. Take 1 MB = 1 000 000 bytes and 1 byte = 8 bits.

## Section A: short answers

**1.** State what is meant by the *colour depth* of an image. **[1]**

**2.** Which **one** of these changes reduces the number of pixels in an image?

A: reducing the colour depth

B: reducing the resolution

C: increasing the contrast

D: flipping the image **[1]**

**3.** State how many colours can be shown with a colour depth of 8 bits. **[1]**

**4.** Give **one** effect on quality of reducing the resolution of a photograph. **[1]**

**5.** Give **one** effect on quality of reducing the colour depth of a photograph. **[1]**

**6.** An image uses 200 different colours. State the smallest colour depth that can store all of them, and explain why. **[2]**

## Section B: structured questions

**7.** A camera produces images of 3 000 x 2 000 pixels with a colour depth of 24 bits.

**(a)** Calculate the size of one image in MB. Show your working. **[2]**

**(b)** The resolution is reduced to 1 500 x 1 000 pixels. Calculate the new size in MB. **[1]**

**(c)** Calculate the percentage reduction in file size. **[1]**

**8.** A cartoon image is 1 000 x 800 pixels with a colour depth of 24 bits. It uses only 12 colours.

**(a)** Calculate its size in MB. **[1]**

**(b)** The colour depth is reduced to 4 bits. State how many colours are now available and explain why the cartoon will look the same. **[2]**

**(c)** Calculate the new size in MB. **[1]**

**9.** A web designer has 10 photographs for a page. Each is 2 000 x 1 500 pixels at 24 bits. On the page, each photograph is shown no more than 1 000 pixels wide.

**(a)** Calculate the total size of the 10 photographs in MB. **[2]**

**(b)** Each photograph is reduced to 1 000 x 750 pixels. Calculate the new total size in MB. **[1]**

**(c)** Explain why reducing the resolution, rather than the colour depth, is the better choice for these photographs. **[2]**

**10.** A black and white scanned signature is 2 000 x 1 000 pixels and was saved with a colour depth of 24 bits.

**(a)** State the most suitable colour depth for the signature. **[1]**

**(b)** Calculate the size of the signature at that colour depth, in bytes. **[1]**

**(c)** Calculate how many times smaller this is than the 24-bit version. **[1]**

**11.** A student reduces the resolution of a photograph for an email. Later she needs to print it as a large poster and enlarges the reduced copy. Explain what will happen to the printed poster and what she should have done. **[3]**

**12.** Explain why reducing either the resolution or the colour depth reduces the file size of an image. **[4]**

## Answers

**1.** The number of bits used to store the colour of each pixel (1). **[1]**

**2.** B: reducing the resolution. **[1]**

**3.** 256 (1). **[1]**

**4.** Any one: fine detail is lost (1); the image may look blocky or pixelated when enlarged (1). **[1]**

**5.** Any one: fewer colours can be shown, so colours may look unrealistic (1); smooth gradients show banding or patches of flat colour (1). **[1]**

**6.** 8 bits (1), because 7 bits give only 128 colours, which is fewer than 200, while 8 bits give 256 (1). **[2]**

**7. (a)** 3 000 x 2 000 x 24 / 8 = 18 000 000 bytes (1) = 18 MB (1).

**(b)** 1 500 x 1 000 x 24 / 8 = 4 500 000 bytes = 4.5 MB (1).

**(c)** (18 - 4.5) / 18 x 100 = 75% (1). **[4]**

**8. (a)** 1 000 x 800 x 24 / 8 = 2 400 000 bytes = 2.4 MB (1).

**(b)** 16 colours (1); the cartoon only uses 12 colours, so all of them can still be stored and none needs to change (1).

**(c)** 1 000 x 800 x 4 / 8 = 400 000 bytes = 0.4 MB (1). **[4]**

**9. (a)** One photograph: 2 000 x 1 500 x 24 / 8 = 9 000 000 bytes = 9 MB (1); total = 10 x 9 = 90 MB (1).

**(b)** 1 000 x 750 x 24 / 8 = 2 250 000 bytes = 2.25 MB each; total 22.5 MB (1).

**(c)** The photographs are only displayed at about 1 000 pixels wide, so the extra pixels are not seen and removing them causes no visible loss (1); reducing the colour depth of photographs would cause banding and unrealistic colours that would be noticed (1). **[5]**

**10. (a)** 1 bit (1).

**(b)** 2 000 x 1 000 x 1 / 8 = 250 000 bytes (1).

**(c)** 24 times smaller (6 000 000 / 250 000 = 24) (1). **[3]**

**11.** The reduced copy has fewer pixels (1), so when it is enlarged for the poster the pixels become visible and the print looks blocky, pixelated or blurred (1). She should have saved the reduced copy under a new name and used the original high-resolution image for the poster (1). **[3]**

**12.** Any four: an image is stored as a grid of pixels, with a colour value stored for each pixel (1); file size depends on the number of pixels multiplied by the bits per pixel (1); reducing the resolution reduces the number of pixels, so fewer colour values are stored (1); reducing the colour depth reduces the number of bits stored for each pixel (1); so in both cases less data in total is stored (1). Maximum 4. **[4]**

## Frequently asked questions

**Does reducing colour depth change the image's dimensions?**
No. The number of pixels stays the same; only the number of bits stored for each pixel, and therefore the number of possible colours, is reduced.

**Why do these answers ignore compression?**
The syllabus statement is about resolution and colour depth, so the questions use uncompressed sizes to show their effect clearly.
