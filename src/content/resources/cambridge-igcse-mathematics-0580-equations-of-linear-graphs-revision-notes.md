These notes condense subtopic **3.5 Equations of linear graphs** from Topic 3 of the Cambridge IGCSE Mathematics 0580 syllabus for 2025, 2026 and 2027. Core (C3.5) works with lines in the forms y = mx + c and x = k, including finding the equation from a graph. **Extended** (E3.5) adds other forms such as ax + by = c; those items are marked *(Extended)*. Both tiers must give equations in a fully simplified form. For worked examples, read the [equations of linear graphs study guide](/resources/cambridge-igcse-mathematics-0580-equations-of-linear-graphs/); for exam-style questions, use the [equations of linear graphs practice questions](/resources/cambridge-igcse-mathematics-0580-equations-of-linear-graphs-practice/).

## The core fact

```
y = mx + c
m = gradient          (coefficient of x when y is the subject)
c = y-intercept       (line crosses the y-axis at (0, c))
```

## Key terms

| Term | Meaning |
|---|---|
| Gradient, m | Change in y ÷ change in x |
| y-intercept, c | y-value where the line meets the y-axis |
| x-intercept | x-value where the line meets the x-axis (set y = 0) |
| Subject | The letter on its own on one side, e.g. y in y = 2x + 1 |
| Fully simplified | Fractions cancelled, like terms collected, no unnecessary brackets |
| Horizontal line | y = k, gradient 0 |
| Vertical line | x = k, gradient not defined |

## Reading m and c

```
y = 4x - 9          m = 4,    c = -9
y = 8 - 3x          m = -3,   c = 8
y = x/5 + 2         m = 1/5,  c = 2
y = -x              m = -1,   c = 0
y = 6               m = 0,    c = 6
x = -1              vertical, no y-intercept
```

## Equation from a graph (Core and Extended)

```
1. c = where the line crosses the y-axis
2. m = rise / run from a triangle, in axis units, with the correct sign
3. y = mx + c, simplified
4. Check with another point on the line
```

Example: through (0, 5) and (2, –1). c = 5, m = –6/2 = –3, so **y = –3x + 5**.

## *(Extended)* Equation from two points

```
Through (-1, -4) and (3, 8):
m = (8 - (-4)) / (3 - (-1)) = 12/4 = 3
-4 = 3(-1) + c   ->   c = -1
y = 3x - 1        check (3, 8): 9 - 1 = 8
```

## *(Extended)* Converting between forms

| From | To | How |
|---|---|---|
| ax + by = c | y = mx + c | subtract the x-term, divide every term by b |
| y = mx + c with fractions | ax + by = c with integers | multiply every term by the common denominator, then rearrange |

```
5x + 2y = 10   ->   2y = -5x + 10   ->   y = -2.5x + 5
y = (3/4)x - 2  ->  4y = 3x - 8     ->   3x - 4y = 8
```

## Interpreting in context

| Equation | m means | c means |
|---|---|---|
| Cost = 3n + 15 (n items) | $3 per item | fixed $15 charge |
| Depth = 120 – 4t (t minutes) | depth falls 4 cm each minute | starting depth 120 cm |
| Temperature = 2h + 18 (h hours) | rises 2 °C per hour | 18 °C at the start |

Always give units and the real meaning.

## Exam traps

- Reading c where the line crosses the x-axis.
- Losing the minus sign of m for a falling line.
- Reading m from 3y = 6x + 9 as 6 instead of 2.
- Leaving 2/4 unsimplified.
- Writing only "m = 3, c = –1" when the question asks for the equation.
- Writing y = k for a vertical line, or x = k for a horizontal one.
- *(Extended)* Multiplying only some terms when clearing fractions.

## Self-test

1. Write down the gradient and y-intercept of y = 7x – 2.
2. Write down the gradient and y-intercept of y = 3 – x.
3. Write down the equation of the line with gradient –4 and y-intercept 6.
4. A line crosses the y-axis at (0, –1) and passes through (3, 5). Find its equation.
5. Write down the equation of the vertical line through (–5, 2).
6. Find where y = 2x – 8 crosses the x-axis.
7. Does (4, 9) lie on y = 3x – 2?
8. *(Extended)* Find the gradient and y-intercept of 4x + 2y = 9.
9. *(Extended)* Find the equation of the line through (2, 3) and (6, 1).
10. *(Extended)* Write y = (2/5)x + 1 in the form ax + by = c with integers.
11. Hire of a boat costs C = 12h + 20 dollars for h hours. What does 20 represent?
12. Line A is y = –5x + 1 and line B is y = 2x + 9. Which is steeper?

### Answers

1. **m = 7, c = –2**
2. **m = –1, c = 3**
3. **y = –4x + 6**
4. m = 6/3 = 2, c = –1: **y = 2x – 1**
5. **x = –5**
6. 2x – 8 = 0: **(4, 0)**
7. 3(4) – 2 = 10, not 9: **no**
8. y = –2x + 4.5: **m = –2, c = 4.5**
9. m = –2/4 = –½; 3 = –1 + c, c = 4: **y = –½x + 4**
10. 5y = 2x + 5, so **2x – 5y = –5** (or equivalent)
11. A **fixed charge of $20** paid whatever the number of hours
12. **Line A** (size 5 is bigger than 2)
