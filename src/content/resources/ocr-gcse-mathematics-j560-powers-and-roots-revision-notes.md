These notes condense section 3.01, Powers and roots, of OCR GCSE (9-1) Mathematics J560, Version 2.1 (August 2026): 3.01a index notation, 3.01b calculation and estimation of powers and roots, and 3.01c laws of indices. Positive and negative integer indices, exact roots and the three laws are for **both tiers**. Fractional indices, fractional powers and estimating powers and roots are **Higher tier only**.

The [3.01 study guide](/resources/ocr-gcse-mathematics-j560-powers-and-roots/) explains each idea with worked examples; the [3.01 practice questions](/resources/ocr-gcse-mathematics-j560-powers-and-roots-practice/) give exam-style questions with mark schemes. For powers with standard form, see the [powers, roots and standard form revision notes](/resources/ocr-gcse-mathematics-powers-roots-laws-of-indices-and-standard-form-revision-notes/).

## Key terms

| Term | Meaning | Example |
|---|---|---|
| Base | The number being multiplied repeatedly | 3 in 3⁴ |
| Index (power, exponent) | How many times the base is a factor | 4 in 3⁴ |
| Square, cube | Index 2, index 3 | 11² = 121, 5³ = 125 |
| Square root | A number that squares to the given number; √ means the positive one | √121 = 11 |
| Cube root | A number that cubes to the given number | ∛(−125) = −5 |
| Reciprocal | 1 divided by the number | Reciprocal of 9 is 1/9 = 3⁻² |
| Negative index | Reciprocal of the positive power | 3⁻² = 1/9 |
| Zero index | Any non-zero base to the power 0 is 1 | 6⁰ = 1 |
| Fractional index (Higher tier only) | Denominator is a root, numerator a power | 27^(2/3) = 9 |

## Powers to recognise

```
2:  2, 4, 8, 16, 32, 64, 128, 256, 512, 1024
3:  3, 9, 27, 81, 243
4:  4, 16, 64, 256
5:  5, 25, 125, 625
squares to 15² = 225; cubes 1, 8, 27, 64, 125, 1 000
```

## Rules in one place

| Rule | Example |
|---|---|
| aᵐ × aⁿ = aᵐ⁺ⁿ | 7⁵ × 7⁻³ = 7² = 49 |
| aᵐ ÷ aⁿ = aᵐ⁻ⁿ | 5⁷ ÷ 5⁹ = 5⁻² |
| (aᵐ)ⁿ = aᵐⁿ | (5²)⁻¹ = 5⁻² = 1/25 |
| a⁰ = 1 | 6⁰ = 1 |
| a⁻ⁿ = 1/aⁿ | 3⁻² = 1/9 |
| (a/b)⁻ⁿ = (b/a)ⁿ | (3/4)⁻² = 16/9 |
| a^(1/n) = ⁿ√a (Higher tier only) | 25^(1/2) = 5 |
| a^(m/n) = (ⁿ√a)ᵐ (Higher tier only) | 27^(2/3) = 3² = 9 |

The three laws only work when the **bases are the same**. Change the base first if you can: 27² ÷ 9 = (3³)² ÷ 3² = 3⁶ ÷ 3² = 3⁴.

## Roots

- x² = 121 has two solutions: x = ±11. The symbol √121 means +11 only.
- Cube roots keep the sign: ∛(−125) = −5.
- Roots of fractions: root the top and the bottom. √(25/36) = 5/6.
- Roots of decimals: halve the decimal places for a square root (√0.49 = 0.7), divide them by three for a cube root (∛0.008 = 0.2).

## Solving for an index

```
1. Write both sides as powers of the same base.
2. Set the indices equal.
3. Solve.
4ˣ = 2¹⁰  →  2²ˣ = 2¹⁰  →  2x = 10  →  x = 5
```

## Estimating (Higher tier only)

```
1. Find the perfect powers either side.
2. Decide which is closer (test the midpoint if unsure).
√90: 9² = 81, 10² = 100; 9.5² = 90.25 > 90, so √90 ≈ 9
```

## Worked reminders

```
Change the base:      8² × 4³ = 2⁶ × 2⁶ = 2¹²
Negative and zero:    2⁻¹ + 2⁰ = 1/2 + 1 = 3/2
Root of a decimal:    √0.0016 = 0.04   (0.04² = 0.0016)
Unknown index:        3ˣ⁺¹ = 81 = 3⁴, so x + 1 = 4 and x = 3
```

**Higher tier only.**

```
Fractional power:     16^(3/4) = (⁴√16)³ = 2³ = 8
Negative fraction:    8^(−2/3) = 1/(∛8)² = 1/4
Root as a power:      √8 = 2^(3/2), so √8 × √2 = 2^(3/2 + 1/2) = 2² = 4
```

**Which form is the answer?** "Write as a power of 2" wants 2¹²; "work out" or "evaluate" wants 4 096. Read the command before you stop.

## Exam traps

- **2⁴ ≠ 2 × 4.**
- **Negative index read as negative value:** 3⁻² = 1/9, not −9.
- **Missing ± when solving x² = k.**
- **Different bases combined:** 2³ × 3² ≠ 6⁵.
- **Wrong law:** multiply powers by adding indices; raise a power to a power by multiplying them.
- **(Higher tier only) Power before root** in a fractional index, giving unmanageable numbers.
- **(Higher tier only) Negative fractional index:** take the reciprocal as well as the root and power.
- **Zero index:** 6⁰ is 1, not 0 or 6.

## Quick self-test

1. Write 3 × 3 × 3 × 3 × 11 × 11 in index form.
2. Work out 2⁵ − 3³.
3. Write 64 as a power of 4 and as a power of 2.
4. Solve x² = 121.
5. Work out √(25/36) and ∛(−125).
6. Work out 3⁻² and (3/4)⁻².
7. Work out 6⁰ + 6⁻¹.
8. Work out 7⁵ × 7⁻³.
9. Write (5²)⁻¹ as a fraction.
10. Write 27² ÷ 9 as a single power of 3.
11. Find x if 4ˣ = 2¹⁰.
12. (Higher tier only) Evaluate 27^(2/3) and 25^(−1/2).
13. (Higher tier only) Estimate √90 to the nearest whole number.

### Answers

1. **3⁴ × 11²**.
2. 32 − 27 = **5**.
3. **4³** and **2⁶**.
4. **x = ±11**.
5. **5/6** and **−5**.
6. **1/9** and **16/9**.
7. 1 + 1/6 = **7/6**.
8. 7² = **49**.
9. 5⁻² = **1/25**.
10. 3⁶ ÷ 3² = **3⁴**.
11. 2²ˣ = 2¹⁰, so **x = 5**.
12. (∛27)² = **9**; 1/√25 = **1/5**.
13. 9.5² = 90.25, which is above 90, so **9**.
