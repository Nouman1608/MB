Condensed notes on section **3.4.3 Vectors** of the AQA GCSE Mathematics (8300) specification (G24 and G25). Learn the methods in the [study guide](/resources/aqa-gcse-maths-8300-vectors/) and test yourself with the [practice questions](/resources/aqa-gcse-maths-8300-vectors-practice/). Content marked **Higher tier only** is not assessed on the Foundation tier.

## Spec at a glance

| Ref | Topic | Tier |
|---|---|---|
| G24 | Translations as 2D vectors | Both |
| G25 | Addition, subtraction, scalar multiplication; diagrams and column vectors | Both |
| G25 | Vectors in geometric arguments and proofs | Higher tier only |

## Key ideas

| Idea | Rule |
|---|---|
| Column vector (x, y) | x units right (negative: left), y units up (negative: down) |
| Vector from A to B | B − A (coordinates), or AB |
| Opposite vector | BA = −AB |
| Addition | Add top to top, bottom to bottom |
| Subtraction | Subtract entry by entry; take care with negatives |
| Scalar multiple | Multiply every entry by the number |
| Triangle law | AB + BC = AC |
| Parallel vectors | One is a scalar multiple of the other |
| Inverse translation | Opposite vector |
| Two translations in a row | Add the vectors |

## Notation

Bold letters **a**, **b** (underline when handwriting), or AB for the journey from A to B. Always show column vectors in brackets.

## Method for vectors in diagrams

1. Choose a route from the start to the finish along known vectors.
2. Going along an arrow: add. Going against: subtract.
3. Simplify by collecting terms.
4. Check with a second route.

## Standard results (parallelogram ABCD with AB = **p**, AD = **q**)

| Vector | In terms of p and q |
|---|---|
| AC | **p** + **q** |
| BD | **q** − **p** |
| DC | **p** |
| BC | **q** |
| CA | −**p** − **q** |

## Higher tier only: proof checklist

| To show | Method |
|---|---|
| Lines are parallel | One vector is a scalar multiple of the other |
| Points are collinear | Two vectors between them are parallel and share a common point |
| Midpoint | The position vector is ½ of the journey |
| A ratio on a line | Use the fraction of the line vector, for example AP : PB = 2 : 3 gives AP = 2/5 AB |
| Lines bisect | Show the same point is halfway along each line |

Always end with a conclusion in words.

## Worked mini-examples

- a = (4, −1), b = (2, 5). 2a + b = (8 + 2, −2 + 5) = **(10, 3)**.
- Translation (−3, 2) applied to (5, 1) gives **(2, 3)**.
- (Higher tier only) OA = **a**, OB = **b**, P is the midpoint of AB. OP = **a** + ½(**b** − **a**) = ½(**a** + **b**).
- (Higher tier only) If AB = 2**a** + 4**b** and BC = **a** + 2**b**, then AB = 2BC, so A, B and C are collinear.

## Worked examples to copy

**Column vectors.** a = (3, 2), b = (−1, 4). Find 3a − b. 3a = (9, 6). 3a − b = (9 − (−1), 6 − 4) = **(10, 2)**.

**Finding a translation.** P(2, 5) moves to P'(−1, 9). Vector = (−1 − 2, 9 − 5) = **(−3, 4)**.

**Journey method.** In triangle ABC, AB = **m** and AC = **n**. Find BC. BC = BA + AC = −**m** + **n** = **n** − **m**.

**Midpoint (Higher tier only).** In the same triangle, M is the midpoint of BC. AM = AB + BM = **m** + ½(**n** − **m**) = ½(**m** + **n**).

**Ratio point (Higher tier only).** X is on BC with BX : XC = 1 : 3. BX = 1/4 BC = 1/4(**n** − **m**). AX = **m** + 1/4(**n** − **m**) = 3/4**m** + 1/4**n**.

## Typical wording and what to do

| Wording | Action |
|---|---|
| "Write down the vector that maps..." | Image minus original |
| "Find the translation that undoes..." | Use the opposite vector |
| "Express in terms of a and b" | Find a route using only a and b |
| "Show that ... are parallel" | Find a scalar multiple |
| "Prove that P, Q and R are collinear" (Higher tier only) | Show parallel and a common point |

## Common errors

- Adding top to bottom entries.
- Treating BA as equal to AB.
- Sign errors when subtracting negative entries.
- Confusing a point (x, y) with a vector (x, y).
- (Higher tier only) Claiming collinear with no common point; omitting the final sentence.

## Quick self-test

1. Write down the vector from A (2, 5) to B (7, 1).
2. Work out (3, −2) + (−5, 4).
3. Work out 4 × (2, −3).
4. a = (1, 3), b = (−2, 5). Work out 2a − b.
5. Write down the vector BA when AB = (6, −2).
6. A shape is translated by (4, −3). Write down the vector that maps it back.
7. Are (6, −9) and (4, −6) parallel? Explain.
8. ABCD is a parallelogram with AB = **p** and AD = **q**. Write BD in terms of **p** and **q**.
9. (Higher tier only) OA = **a** and OB = **b**. M is the midpoint of AB. Write OM in terms of **a** and **b**.
10. (Higher tier only) PQ = 2**a** + 6**b** and QR = **a** + 3**b**. What can you say about P, Q and R?

### Answers

1. (7 − 2, 1 − 5) = **(5, −4)**.
2. (3 − 5, −2 + 4) = **(−2, 2)**.
3. **(8, −12)**.
4. (2, 6) − (−2, 5) = (4, 1).
5. BA = −AB = **(−6, 2)**.
6. **(−4, 3)**.
7. Yes: (6, −9) = 1.5 × (4, −6), so one is a scalar multiple of the other.
8. BD = BA + AD = −**p** + **q** = **q** − **p**.
9. OM = **a** + ½(**b** − **a**) = **½(a + b)**.
10. PQ = 2QR, so PQ and QR are parallel; they share the point Q, so P, Q and R are **collinear**, with PQ twice QR.
