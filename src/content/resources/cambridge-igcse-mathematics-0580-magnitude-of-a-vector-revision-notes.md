These notes condense subtopic **E7.3 Magnitude of a vector** of the Cambridge IGCSE Mathematics 0580 syllabus (examination in 2025, 2026 and 2027). It is **Extended only**; C7.3 reads "Extended content only". For full explanations and worked examples, read the [magnitude of a vector study guide](/resources/cambridge-igcse-mathematics-0580-magnitude-of-a-vector/); for exam-style questions, use the [magnitude of a vector practice questions](/resources/cambridge-igcse-mathematics-0580-magnitude-of-a-vector-practice/).

## What the syllabus says

Calculate the magnitude of a vector (x, y) as √(x² + y²). Magnitudes are written with modulus signs: |**a**| for the vector **a**, and |AB| (arrow over AB) for the vector AB.

## Key terms

| Term | Meaning |
|---|---|
| Magnitude | The length of a vector; never negative |
| Modulus signs | The vertical bars in |**a**| |
| Displacement | A change of position, given by a vector; its magnitude is the straight-line distance |
| Exact value | A simplified surd such as 2√13, not a rounded decimal |
| Pythagorean triple | Three whole numbers with a² + b² = c², such as 5, 12, 13 |

## The formula and its consequences

```
|(x, y)| = √(x² + y²)

|−a| = |a|                 reversing does not change length
|AB| = |BA|
|k a| = |k| × |a|          e.g. |−2 × (3, 4)| = 2 × 5 = 10
|a + b| ≤ |a| + |b|        equal only when a and b point the same way
```

## Steps for each question type

| Question | Steps |
|---|---|
| Magnitude of a column vector | square each entry, add, square root |
| Magnitude of AB from points | AB = end − start, then the formula |
| Magnitude of 2**a** − **b** (etc.) | combine first, then the formula |
| Unknown entry, magnitude given | square both sides, solve, keep both signs |
| Is a triangle isosceles or right-angled? | find all three magnitudes; compare; test a² + b² = c² |

## Pythagorean triples to spot

| Entries (either sign) | Magnitude |
|---|---|
| 3, 4 | 5 |
| 5, 12 | 13 |
| 8, 15 | 17 |
| 7, 24 | 25 |
| 20, 21 | 29 |
| 9, 40 | 41 |
| 6, 8 (and other multiples) | 10 |

## Exact surds

```
√45 = √(9 × 5) = 3√5
√72 = √(36 × 2) = 6√2
√40 = √(4 × 10) = 2√10
```

Take out the largest square factor.

## Worked reminders

**Unknown entry.** |(k, 3)| = 5 → k² + 9 = 25 → k² = 16 → **k = 4 or −4**.

**Calculator.** |(4.5, −2.8)| = √(20.25 + 7.84) = √28.09 = **5.3** (exact, so no rounding needed).

**Combination.** **a** = (2, 7), **b** = (−1, 3): **a** − **b** = (3, 4), so |**a** − **b**| = **5**. Compare |**a**| − |**b**| = √53 − √10, which is a different number.

**Triangle from three points.** A(0, 0), B(4, 2), C(1, 6):

```
AB = (4, 2)    |AB| = √20
BC = (−3, 4)   |BC| = 5
AC = (1, 6)    |AC| = √37
```

No two magnitudes are equal, so the triangle is not isosceles. For a right angle, the largest squared magnitude must equal the sum of the other two: 37 is the largest, and 20 + 25 = 45 ≠ 37, so there is no right angle. Putting the wrong side on the right of a² + b² = c² is a common slip.

**Parallel vector with a given length.** A vector parallel to (8, 15) with magnitude 34: |(8, 15)| = 17 and 34 ÷ 17 = 2, so the vector is **(16, 30)** or **(−16, −30)**. Both directions count as parallel.

**Missing coordinate.** A(1, −2), B(4, y), |AB| = 5: AB = (3, y + 2), so 9 + (y + 2)² = 25, (y + 2)² = 16, y + 2 = ±4, giving **y = 2 or y = −6**.

## Exam traps

- Leaving out the square root.
- Writing −5² as −25; it must be (−5)² = 25.
- Giving a decimal when an exact answer is asked for.
- Finding |**a**| + |**b**| when the question asks for |**a** + **b**|.
- Losing the negative solution when an entry is squared.
- Expanding (2k)² as 2k².
- Finding the vector as start − end; the magnitude is unaffected, but if the vector itself is also asked for, it will be wrong.

## Self-test

1. Find |(9, 40)|.
2. Find |(−20, 21)|.
3. Find the exact value of |(2, −6)|.
4. P is (3, −2) and Q is (−3, 6). Find |PQ|.
5. Find the possible values of k if |(k, 3)| = 5.
6. Find the exact magnitude of 2(1, −2).
7. (calculator) Find |(1.2, −3.5)|.
8. **a** = (2, 7) and **b** = (−1, 3). Find |**a** − **b**|.
9. Explain why no vector can have magnitude −4.
10. Find |−5**u**| if |**u**| = 3.
11. (calculator) Find |(3, −11)| to 3 significant figures.
12. **v** = (a, a). Find a if |**v**| = 4√2 and a > 0.

### Answers

1. √(81 + 1600) = √1681 = **41**
2. √(400 + 441) = √841 = **29**
3. √40 = **2√10**
4. PQ = (−6, 8), |PQ| = **10**
5. **k = 4 or k = −4**
6. (2, −4) has magnitude √20 = **2√5**
7. √(1.44 + 12.25) = √13.69 = **3.7**
8. (3, 4), so **5**
9. A magnitude is a square root of a sum of squares, so it is never negative.
10. 5 × 3 = **15**
11. √130 = **11.4**
12. 2a² = 32, a² = 16, **a = 4**
