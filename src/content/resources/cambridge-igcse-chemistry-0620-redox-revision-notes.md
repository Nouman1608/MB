Condensed notes for subtopic **6.4 Redox**, Cambridge IGCSE Chemistry 0620, 2026–2028. Items marked *(Extended)* are Supplement content. Worked examples are in the [redox study guide](/resources/cambridge-igcse-chemistry-0620-redox/); exam-style questions are in the [redox practice questions](/resources/cambridge-igcse-chemistry-0620-redox-practice/).

## Key terms

| Term | Definition |
|---|---|
| Redox | A reaction involving simultaneous oxidation and reduction |
| Oxidation (Core) | Gain of oxygen |
| Reduction (Core) | Loss of oxygen |
| Oxidation *(Extended)* | Loss of electrons; increase in oxidation number |
| Reduction *(Extended)* | Gain of electrons; decrease in oxidation number |
| Oxidising agent *(Extended)* | Oxidises another substance and is itself reduced |
| Reducing agent *(Extended)* | Reduces another substance and is itself oxidised |
| Oxidation number | Shown by a Roman numeral in a name, e.g. iron(III) |

**OIL RIG:** Oxidation Is Loss, Reduction Is Gain (of electrons).

## Roman numerals (Core)

| Name | Ion | Formula |
|---|---|---|
| Iron(II) sulfate | Fe²⁺ | FeSO₄ |
| Iron(III) oxide | Fe³⁺ | Fe₂O₃ |
| Copper(I) oxide | Cu⁺ | Cu₂O |
| Copper(II) nitrate | Cu²⁺ | Cu(NO₃)₂ |

The numeral = the oxidation number of the metal = the charge on its ion.

## Oxygen-transfer examples (Core)

| Reaction | Oxidised | Reduced |
|---|---|---|
| Fe₂O₃ + 3CO → 2Fe + 3CO₂ | CO (gains O) | Fe₂O₃ (loses O) |
| 2CuO + C → 2Cu + CO₂ | C | CuO |
| Fe₂O₃ + 2Al → Al₂O₃ + 2Fe | Al | Fe₂O₃ |
| 2Mg + O₂ → 2MgO | Mg | O₂ (shown by electron or oxidation-number definition) |

## Oxidation number rules *(Extended)*

1. Uncombined element = 0.
2. Monatomic ion = its charge.
3. Sum in a compound = 0.
4. Sum in an ion = the ion's charge.

Useful values in compounds: O = −2, H = +1, Group I = +1, Group II = +2.

| Species | Element | Oxidation number |
|---|---|---|
| SO₂ | S | +4 |
| SO₃ / SO₄²⁻ / H₂SO₄ | S | +6 |
| NH₃ / NH₄⁺ | N | −3 |
| NO₃⁻ | N | +5 |
| MnO₄⁻ | Mn | +7 |
| Fe₂O₃ | Fe | +3 |

## Electron transfer *(Extended)*

```
Zn + Fe2+ → Zn2+ + Fe
Zn → Zn2+ + 2e-       oxidation
Fe2+ + 2e- → Fe       reduction
```

Electrons lost = electrons gained.

## Is it redox? *(Extended)*

Assign oxidation numbers to every element on both sides; a change means redox.

- **Redox:** metal displacement, halogen displacement, combustion, metal + acid, extraction of metals by reduction.
- **Not redox:** neutralisation, precipitation, thermal decomposition of carbonates.

## Agents *(Extended)*

1. Find what is oxidised and what is reduced.
2. The substance **reduced** is the **oxidising agent**.
3. The substance **oxidised** is the **reducing agent**.

Example: Cl₂ + 2I⁻ → 2Cl⁻ + I₂. Cl₂ is reduced (0 → −1): oxidising agent. I⁻ is oxidised (−1 → 0): reducing agent.

## Colour tests *(Extended)*

| Reagent | Colour change | Detects |
|---|---|---|
| Acidified aqueous KMnO₄ | Purple → colourless | Reducing agents (e.g. Fe²⁺, SO₂) |
| Aqueous KI | Colourless → brown | Oxidising agents (e.g. Cl₂, Br₂) |

## Where redox turns up elsewhere in 0620

| Context | What is oxidised | What is reduced |
|---|---|---|
| Electrolysis | Anions (or water) at the anode, losing electrons | Cations at the cathode, gaining electrons |
| Extraction of iron | Carbon monoxide | Iron(III) oxide |
| Rusting | Iron | Oxygen |
| Metal + dilute acid | Metal (e.g. Mg → Mg²⁺) | H⁺ ions (→ H₂) |
| Metal displacement | More reactive metal | Ions of less reactive metal |
| Halogen displacement | Halide ions of less reactive halogen | More reactive halogen |

Recognising these lets you answer "explain why this is redox" in any topic, not just this one.

## Exam traps

- Oxidising agent is **reduced**, not oxidised.
- Manganate(VII) goes **colourless**, not "clear".
- Oxidation numbers need a **sign**: +3, −2.
- Divide the total by the number of atoms: Fe in Fe₂O₃ is +3, not +6.
- Oxidation and reduction always happen **together**.
- Core answers can use oxygen gain/loss; Extended questions about ions need electrons or oxidation numbers.
- Precipitation and neutralisation are **not** redox even though ions are involved.
- In half-equations, electrons appear on the **right** for oxidation and on the **left** for reduction; check that charges balance on both sides.
- When asked to identify an agent, name the exact species from the equation (Fe²⁺, Cl₂, I⁻), not just the element.

## Self-test

1. Define a redox reaction.
2. In 2CuO + C → 2Cu + CO₂, which substance is reduced? Explain using oxygen.
3. Give the formula of iron(III) chloride.
4. *(Extended)* Define oxidation in terms of electrons and in terms of oxidation number.
5. *(Extended)* Deduce the oxidation number of nitrogen in NO₃⁻.
6. *(Extended)* Deduce the oxidation number of chromium in Cr₂O₃.
7. *(Extended)* Is BaCl₂ + Na₂SO₄ → BaSO₄ + 2NaCl a redox reaction? Explain.
8. *(Extended)* In Mg + Zn²⁺ → Mg²⁺ + Zn, name the reducing agent.
9. *(Extended)* Define an oxidising agent.
10. *(Extended)* What colour change shows that a substance is a reducing agent when added to acidified potassium manganate(VII)?
11. *(Extended)* Aqueous potassium iodide turns brown when a solution X is added. What does this show about X?
12. *(Extended)* Write the half-equation for the oxidation of an iron(II) ion to an iron(III) ion.

**Answers**

1. A reaction in which oxidation and reduction happen simultaneously.
2. Copper(II) oxide; it loses oxygen.
3. FeCl₃.
4. Loss of electrons; an increase in oxidation number.
5. N + 3(−2) = −1, so N = +5.
6. 2Cr + 3(−2) = 0, so Cr = +3.
7. No; no element changes oxidation number (Ba +2, Cl −1, Na +1, S +6, O −2 throughout).
8. Magnesium (Mg); it is oxidised.
9. A substance that oxidises another substance and is itself reduced.
10. Purple to colourless.
11. X is an oxidising agent (it oxidises iodide ions to iodine).
12. Fe²⁺ → Fe³⁺ + e⁻.
