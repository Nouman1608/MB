Condensed notes for subtopic **2.3 Algebraic fractions** of Cambridge O Level Mathematics (Syllabus D) 4024, 2025–2027. Full worked examples are in the [algebraic fractions study guide](/resources/cambridge-o-level-mathematics-4024-algebraic-fractions/); exam-style questions are in the [algebraic fractions practice questions](/resources/cambridge-o-level-mathematics-4024-algebraic-fractions-practice/).

## Syllabus outcomes

1. Manipulate algebraic fractions: add, subtract, multiply and divide, with numerical or linear denominators.
2. Factorise and simplify rational expressions.

Usually tested on Paper 1 (non-calculator).

## Key terms

| Term | Meaning |
|---|---|
| Algebraic fraction | A fraction with a letter in the numerator, denominator or both |
| Rational expression | One polynomial divided by another, such as (x² − 1)/(x² + 3x + 2) |
| Numerator | The top of a fraction |
| Denominator | The bottom of a fraction |
| Lowest common denominator | The simplest expression that every denominator divides into |
| Factor | An expression multiplying the whole numerator or whole denominator |
| Reciprocal | The fraction turned upside down: the reciprocal of a/b is b/a |
| Single fraction | One numerator over one denominator |

## The four operations

```
add / subtract:   a/b ± c/d = (ad ± bc) / bd
multiply:         a/b × c/d = ac / bd
divide:           a/b ÷ c/d = a/b × d/c = ad / bc
```

Always factorise first and cancel before multiplying out.

## Adding and subtracting: method

1. Factorise each denominator.
2. Find the lowest common denominator.
3. Rewrite each numerator in brackets over it.
4. Expand, taking care with a minus sign in front of a bracket.
5. Simplify the numerator; check whether it shares a factor with the denominator.

**Numerical denominators**

```
x/2 + (x + 1)/5          = [5x + 2(x + 1)]/10 = (7x + 2)/10
(3x − 1)/4 − (x − 2)/3   = [3(3x − 1) − 4(x − 2)]/12
                         = (9x − 3 − 4x + 8)/12 = (5x + 5)/12 = 5(x + 1)/12
2/x + 3/(4x)             = 8/(4x) + 3/(4x) = 11/(4x)
```

**Linear denominators**

```
4/(x − 3) + 1/(x + 2)    = [4(x + 2) + (x − 3)] / [(x − 3)(x + 2)]
                         = (5x + 5) / [(x − 3)(x + 2)] = 5(x + 1) / [(x − 3)(x + 2)]
```

**Shared factor**

```
1/(x − 4) − 2/(x² − 16)  = [(x + 4) − 2] / [(x − 4)(x + 4)]
                         = (x + 2) / [(x − 4)(x + 4)]
```

## Multiplying and dividing: examples

```
6a/7 × 14/(9a²)          = 84a / 63a² = 4/(3a)
10x²/3 ÷ 5x/9            = 10x²/3 × 9/(5x) = 90x²/15x = 6x
```

## Simplifying: factorise, then cancel

| Expression | Factorised | Simplified |
|---|---|---|
| (x² + 4x)/(x² − 16) | x(x + 4) / (x − 4)(x + 4) | x/(x − 4) |
| (x² − 25)/(x² + 2x − 15) | (x − 5)(x + 5) / (x + 5)(x − 3) | (x − 5)/(x − 3) |
| (2x² − x − 1)/(x² − 1) | (2x + 1)(x − 1) / (x + 1)(x − 1) | (2x + 1)/(x + 1) |
| (x² − 4x + 4)/(3x − 6) | (x − 2)² / 3(x − 2) | (x − 2)/3 |
| (9 − x²)/(x² − x − 6) | (3 − x)(3 + x) / (x − 3)(x + 2) | −(x + 3)/(x + 2) |

**Sign switch:** (a − b) = −(b − a). Use it when factors look reversed.

## Checking an answer

Substitute a convenient value into the original and your answer; avoid values that make a denominator zero. For 4/(x − 3) + 1/(x + 2) at x = 0: −4/3 + 1/2 = −5/6, and 5(1)/[(−3)(2)] = −5/6. ✓

## Exam traps

- Never cancel terms: (x + 3)/x is not 3, and (x² + 4)/(x + 2) does not simplify.
- Bracket the second numerator before subtracting.
- a/b + c/d is not (a + c)/(b + d).
- Turn the **second** fraction upside down when dividing.
- Factorise every part fully; 2x² − 8 needs two steps.
- Watch for (3 − x) and (x − 3): they cancel to −1.
- If every factor on top cancels, the numerator is 1.
- Leave denominators factorised unless asked otherwise.

## Self-test

1. Write x/3 + x/4 as a single fraction.
2. Write (x + 2)/3 − (x − 1)/2 as a single fraction.
3. Write 3/a − 2/(5a) as a single fraction.
4. Write 5/(x + 1) − 3/(x − 2) as a single fraction.
5. Simplify 8x/9 × 3/(4x²).
6. Simplify 2y/5 ÷ 6y²/15.
7. Simplify (3x + 6)/(x² − 4).
8. Simplify (x² − 9)/(2x² − 5x − 3).
9. Simplify (4 − x)/(x² − 16).
10. Write 3/(2x − 1) + 2/(x + 3) as a single fraction.
11. Simplify (x² − x − 12)/(x² − 16) × (x + 4)/(x + 3).
12. Explain why (x + 5)/(x + 10) cannot be simplified to 1/2.

**Answers**

1. (4x + 3x)/12 = **7x/12**.
2. [2(x + 2) − 3(x − 1)]/6 = (2x + 4 − 3x + 3)/6 = **(7 − x)/6**.
3. 15/(5a) − 2/(5a) = **13/(5a)**.
4. [5(x − 2) − 3(x + 1)]/[(x + 1)(x − 2)] = **(2x − 13)/[(x + 1)(x − 2)]**.
5. 24x/(36x²) = **2/(3x)**.
6. 2y/5 × 15/(6y²) = 30y/(30y²) = **1/y**.
7. 3(x + 2)/[(x − 2)(x + 2)] = **3/(x − 2)**.
8. (x − 3)(x + 3)/[(2x + 1)(x − 3)] = **(x + 3)/(2x + 1)**.
9. −(x − 4)/[(x − 4)(x + 4)] = **−1/(x + 4)**.
10. [3(x + 3) + 2(2x − 1)]/[(2x − 1)(x + 3)] = (7x + 7)/[(2x − 1)(x + 3)] = **7(x + 1)/[(2x − 1)(x + 3)]**.
11. (x − 4)(x + 3)/[(x − 4)(x + 4)] × (x + 4)/(x + 3) = **1**.
12. x, 5 and 10 are terms, not factors; nothing multiplies the whole top and bottom, so nothing cancels. Testing x = 1 gives 6/11, not 1/2.
