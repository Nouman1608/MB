## Understanding

- I can state the junction rule in words and as ΣI_in = ΣI_out. *(Guide: "The junction rule"; Practice Q1)*
- I can explain why the rule follows from conservation of charge, and why charge cannot build up at a junction in a steady circuit. *(Guide: "Charge has nowhere to go"; Practice Q2)*
- I can say which Kirchhoff rule comes from charge conservation and which from energy conservation. *(Practice Q2)*
- I can explain why every element in one branch carries the same current, so current is not used up. *(Guide: "Branches, junctions and regions"; Practice Q6c, Q7a)*

## Calculation and skills

- I can find an unknown current at a junction and state its direction. *(Practice Q1, Q5)*
- I can use assumed directions and interpret a negative answer as a current flowing the other way. *(Guide: Worked example 1; Practice Q5b)*
- I can apply the junction rule to a boundary drawn around part of a circuit. *(Guide: Worked example 1 check; Practice Q5d)*
- I can find how a current splits between parallel branches using the same ΔV and the junction rule. *(Practice Q3)*
- I can write junction and loop equations for a one-battery circuit and solve them for every branch current. *(Guide: Worked example 2; Practice Q6)*

## Reasoning

- I can predict how the current from an ideal battery changes when a parallel branch is removed. *(Practice Q4, Q7d)*
- I can use measured currents and meter resolution to decide whether data support the junction rule. *(Guide: Worked example 3; Practice Q7b)*
- I can rank resistances of parallel elements from their measured currents. *(Practice Q7c)*
