Guide = [study guide](/advanced-course-resources/chemistry/7-4-calculating-equilibrium-constant-study-guide/); Practice = [practice questions](/advanced-course-resources/chemistry/7-4-calculating-equilibrium-constant-practice/).

## Understanding

- I can explain how experimental data show that a system has reached equilibrium. *(Guide: Figure 1; Practice Q5(e))*
- I can explain why only equilibrium values, not starting values, go into K. *(Guide: "Common misconceptions"; Practice Q3)*
- I can explain why experiments at the same temperature give the same K even when their concentrations differ. *(Practice Q7(b))*

## Calculation

- I can calculate Kc from a set of equilibrium concentrations. *(Guide: Worked example 1(a); Practice Q1)*
- I can calculate Kp from equilibrium partial pressures, leaving out any solid. *(Guide: Worked example 1(b); Practice Q2)*
- I can convert moles to mol L⁻¹ before using Kc. *(Guide: Worked example 2)*
- I can build an ICE table from starting amounts and one measured equilibrium value, using the coefficients for the change row. *(Guide: Worked example 2; Practice Q3, Q5)*
- I can allow for dilution when two solutions are mixed. *(Practice Q5(b))*
- I can turn a total pressure into partial pressures using the mole ratio of the gases. *(Guide: Worked example 3; Practice Q6)*
- I can use a known K to find one missing equilibrium concentration. *(Practice Q7(c))*

## Reasoning

- I can explain, using the powers in the expression, how one equilibrium concentration must change when another changes at constant K. *(Guide: "Reading K as a relationship"; Practice Q4)*
- I can spot a calculation error when two experiments at the same temperature give very different K values. *(Guide: "Reading K as a relationship"; Practice Q7)*
