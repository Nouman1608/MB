## Understanding

- I can explain that setting includes time, place and the social, cultural and historical situation. *(Guide: "Setting is a world, not only a place")*
- I can explain how details of setting convey the values of a society or household. *(Guide: Worked example 2; Practice question 5)*
- I can explain how setting can shape characters' options and create conflict. *(Guide: "Reading setting in a longer work"; Practice question 6)*
- I can explain how stage directions and props create setting in a play. *(Guide: "Setting in drama"; Practice question 7)*

## Skills

- I can read the arrangement of people and spaces as evidence of rank. *(Guide: Worked example 2, Steps 2 and 3; Practice questions 3 and 5)*
- I can identify a contrast between places and say what it conveys. *(Guide: Worked example 2, Step 4)*
- I can use only the text's details to describe a social or historical situation. *(Guide: "Checking your inference"; Practice question 2)*
- I can write a short explanation of social division using two details. *(Practice question 8)*

## Reasoning

- I can explain how a setting is arranged to make an absence visible. *(Practice questions 7 and 9)*
- I can explain how a Prologue or opening description sets up the conflict before characters speak. *(Guide: Worked example 1)*
- I can say what a setting detail adds to the conflict, not only to the scenery. *(Guide: "Strong and weak statements about setting in longer works")*
