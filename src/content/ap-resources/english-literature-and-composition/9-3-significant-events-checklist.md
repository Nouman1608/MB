Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/english-literature-and-composition/9-3-significant-events-study-guide/); Practice = [practice questions](/advanced-course-resources/english-literature-and-composition/9-3-significant-events-practice/).

## Understanding

- I can explain the difference between the content and the function of an event. *(Guide: "When an event matters more than the others"; Practice Question 6)*
- I can explain what makes an event significant. *(Guide: "When an event matters more than the others"; Practice Question 1)*
- I can explain how significant events illustrate competing value systems. *(Guide: Worked examples 1 and 2; Practice Question 3)*
- I can explain how events collide and accumulate to create anticipation and suspense. *(Guide: "When an event matters more than the others"; Practice Question 5)*

## Skills

- I can state what changes before and after an event. *(Guide: "A method for significant events"; Practice Question 2)*
- I can name the values in collision in a scene. *(Guide: Worked example 1; Practice Questions 3 and 4)*
- I can trace earlier events that build up to a later one. *(Guide: Worked example 2; Practice Question 5)*
- I can quote accurately from a pivotal scene. *(Practice Question 7)*

## Reasoning

- I can explain the function of an event for the whole work, not only the scene. *(Guide: Worked examples 1 and 2; Practice Question 7)*
- I can treat a set of related scenes as one significant event and explain why. *(Guide: Worked example 2)*
- I can compare a weak and a strong sentence about an event and say why the strong one scores. *(Guide: "Weak and strong versions side by side")*
- I can write a paragraph on a significant event with a claim, evidence and commentary. *(Practice Questions 7 and 8)*

When every box is ticked, move on to the [9.4 study guide](/advanced-course-resources/english-literature-and-composition/9-4-conflict-and-its-function-study-guide/).
