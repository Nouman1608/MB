## Understanding

- I can name episodes, encounters and scenes as kinds of event. *(Guide: "Events are the working parts of a plot")*
- I can explain that the significance of an event depends on the narrative, the conflict and the development of characters. *(Guide: "What makes an event significant")*
- I can state the removal test for a significant event. *(Guide: "What makes an event significant"; Practice question 4)*
- I can list functions an event can have: introduce, develop, reveal, turn, resolve, mirror. *(Guide: "Types of function")*

## Skills

- I can trace cause and effect between two events. *(Guide: Worked example 2; Practice question 1)*
- I can identify the turning point in a plot outline. *(Guide: Worked example 2, Step 3; Practice question 3)*
- I can describe an event briefly and then explain its function. *(Guide: "Writing about an event"; Practice question 8)*
- I can name the conflict an event relates to. *(Practice questions 2 and 7)*

## Reasoning

- I can explain why a quiet event can be more significant than a loud one. *(Guide: "Common misconceptions")*
- I can explain how one event changes a character. *(Guide: Worked example 1, Step 4; Practice question 6)*
- I can explain how an event resolves one conflict while leaving another open. *(Practice question 5)*
