Guide = [study guide](/advanced-course-resources/english-literature-and-composition/7-2-setting-relationship-character-study-guide/); Practice = [practice questions](/advanced-course-resources/english-literature-and-composition/7-2-setting-relationship-character-practice/).

## Understanding

- I can explain that a setting depicts a time and place and also conveys values. *(Guide: "More than a backdrop"; Practice Question 1)*
- I can explain how a change of setting may suggest a shift in the narrative. *(Guide: Worked example 2; Practice Question 2)*
- I can explain how contrasted settings can set up a conflict of values or ideas. *(Guide: "Contrasted settings"; Practice Questions 3 and 8)*
- I can explain how a character's interaction with surroundings gives insight into the character and the setting. *(Guide: "How characters behave in a setting"; Practice Question 4)*

## Skills

- I can use the four-column grid to analyse a setting. *(Guide: "Reading a setting"; Practice Question 7)*
- I can tell describing a setting from analysing it. *(Guide: "Common misconceptions"; Practice Question 6)*
- I can use a character's behaviour in a place as evidence of an attitude. *(Guide: Worked example 1; Practice Questions 4 and 7)*
- I can write a paragraph that links setting details to character and to what they suggest. *(Guide: both model sentences; Practice Question 7)*

## Reasoning

- I can explain what position a character occupies when caught between two settings. *(Guide: "Contrasted settings"; Practice Questions 8 and 9)*
- I can decide whether a setting is only a backdrop or is doing interpretive work. *(Guide: "Common misconceptions"; Practice Question 6)*
- I can use a public-domain example, such as the opening of The Open Boat, to show how a setting conveys values. *(Guide: "Public-domain examples to learn from"; Practice Question 5)*
