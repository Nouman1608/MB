Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/english-language-and-composition/4-5-definition-description-study-guide/); Practice = [practice questions](/advanced-course-resources/english-language-and-composition/4-5-definition-description-practice/).

## Understanding

- I can explain how definition and description develop an idea. *(Guide: "Two methods that make an idea visible"; Practice question 5)*
- I can tell a formal definition from an extended definition. *(Guide: "Definition"; Practice question 1)*
- I can explain how description differs from definition. *(Guide: "Two methods that make an idea visible"; Practice question 2)*
- I can explain why examples and illustrations strengthen both methods. *(Guide: "Using examples and illustrations"; Practice question 2)*

## Skills

- I can identify the method (definition or description) and the features used in a passage. *(Guide: Worked example 2; Practice questions 1 and 4)*
- I can write an extended definition that uses examples, contrast or features. *(Guide: Worked example 1; Practice question 6)*
- I can turn vague description into concrete, sensory detail. *(Guide: "Description"; Practice question 7)*
- I can describe what a definition or description does in a published text. *(Guide: "Definition as strategy", Worked example 2; Practice questions 3 and 4)*

## Reasoning

- I can judge whether a definition is fair or decides the argument in advance. *(Guide: "Definition as strategy"; Practice questions 3 and 6)*
- I can explain how a choice of details serves a writer's purpose. *(Guide: Worked example 2, Step 4; Practice questions 4 and 8)*
- I can link a definition or description to a claim in my own paragraph. *(Guide: Worked example 1, Step 4; Practice question 6)*
- I can write a one-sentence analysis of the method and its effect. *(Guide: Worked example 2, Step 5; Practice question 8)*
