Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/english-language-and-composition/9-5-introducing-counterarguments-study-guide/); Practice = [practice questions](/advanced-course-resources/english-language-and-composition/9-5-introducing-counterarguments-practice/).

## Understanding

- I can explain how transitions can introduce counterarguments and signal what comes next. *(Guide: "Transitions that introduce a counterargument"; Practice question 1)*
- I can explain how the position of a counterargument affects its impact. *(Guide: "Where to put a counterargument"; Practice question 2)*
- I can explain that not all arguments explicitly address a counterargument. *(Guide: "Does every argument need a counterargument?"; Practice question 3)*

## Skills

- I can choose transitions for introducing, conceding, pivoting and returning. *(Guide: "Transitions that introduce a counterargument"; Practice question 4)*
- I can recognise whether a transition introduces a true counterargument or only a contrast. *(Guide: "Common misconceptions"; Practice question 5)*
- I can write a concise counterargument paragraph and place it for an audience. *(Guide: Worked example 1; Practice question 6)*

## Reasoning

- I can decide which counterargument deserves an explicit answer in a timed essay and where it should go. *(Guide: Worked example 2; Practice question 7)*
- I can analyse how an argument manages opposition implicitly without inventing an explicit counterargument. *(Guide: "Does every argument need a counterargument?"; Practice question 8)*
- I can analyse a public-domain use of a transition to introduce a counter-consolation, such as Paine's "yet". *(Guide: "Public-domain examples"; Practice question 8)*
