Guide = [study guide](/advanced-course-resources/english-language-and-composition/6-1-synthesising-sources-study-guide/); Practice = [practice questions](/advanced-course-resources/english-language-and-composition/6-1-synthesising-sources-practice/).

## Understanding

- I can explain what synthesising sources means. *(Guide: "From using a source to synthesising sources"; Practice question 5)*
- I can explain the difference between summary and synthesis. *(Guide: "Summary versus synthesis"; Practice question 1)*
- I can explain why a writer selects strategically rather than using everything. *(Guide: "From using a source to synthesising sources"; Practice question 3)*
- I can explain that sources differ in reliability and credibility. *(Guide: "From using a source to synthesising sources"; Practice question 4)*

## Skills

- I can integrate a quotation or paraphrase with a signal phrase and commentary. *(Guide: "Ways of bringing source material in"; Practice question 2)*
- I can name how two sources relate (agreement, extension, qualification, conflict). *(Guide: "Combining sources: four moves"; Practice question 1)*
- I can write a synthesis paragraph from several sources. *(Guide: Worked example 1; Practice question 6)*
- I can rewrite a source-by-source summary as a synthesis. *(Guide: Worked example 2; Practice question 7)*

## Reasoning

- I can choose which source material is most relevant to a claim and justify the choice. *(Guide: Worked example 1, Step 2; Practice questions 3 and 6)*
- I can organise a paragraph by idea rather than by source. *(Guide: Worked example 2, Step 3; Practice question 3)*
- I can comment on a source's reliability when it affects my claim. *(Guide: Worked example 1, Step 2; Practice question 8)*
- I can describe how a writer has combined sources in an argument. *(Guide: Worked example 1, Step 5; Practice questions 1 and 6)*
