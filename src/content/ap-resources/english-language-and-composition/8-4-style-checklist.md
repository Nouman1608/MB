Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/english-language-and-composition/8-4-style-study-guide/); Practice = [practice questions](/advanced-course-resources/english-language-and-composition/8-4-style-practice/).

## Understanding

- I can define style as the mix of word choice, syntax and conventions. *(Guide: "What style is"; Practice question 1)*
- I can explain the difference between style and tone. *(Guide: "Style, tone and purpose"; Practice question 2)*
- I can explain why the same content can be written in different styles for different purposes. *(Guide: Worked example 2; Practice question 3)*

## Skills

- I can describe a passage's style using label, evidence and effect. *(Guide: "Describing style precisely"; Practice question 4)*
- I can pick out features of word choice, syntax and conventions that make up a style. *(Guide: "What style is"; Practice question 5)*
- I can rewrite a passage in a different style for a stated audience and purpose. *(Guide: Worked example 2; Practice question 7)*

## Reasoning

- I can explain how a passage's style contributes to its tone and to the writer's purpose. *(Guide: Worked example 1; Practice question 6)*
- I can analyse the style of a short public-domain sentence, such as Bacon's on reading, conference and writing. *(Guide: "Public-domain examples"; Practice question 8)*
- I can avoid vague adjectives and support every label with evidence. *(Guide: "Describing style precisely"; Practice question 6)*
