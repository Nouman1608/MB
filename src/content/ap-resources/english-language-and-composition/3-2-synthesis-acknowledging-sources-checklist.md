Guide = [study guide](/advanced-course-resources/english-language-and-composition/3-2-synthesis-acknowledging-sources-study-guide/); Practice = [practice questions](/advanced-course-resources/english-language-and-composition/3-2-synthesis-acknowledging-sources-practice/); also see the [revision notes](/advanced-course-resources/english-language-and-composition/3-2-synthesis-acknowledging-sources-revision-notes/).

## Understanding

- ☐ I can explain the difference between summary and synthesis. *(Guide: "Synthesis is not summary"; practice question 1)*
- ☐ I can list six moves a writer can make with a source. *(Guide: "Ways to put sources in conversation"; practice question 4)*
- ☐ I can explain what needs to be acknowledged and what does not. *(Guide: "Acknowledging sources"; practice questions 2 and 5)*

## Skills

- ☐ I can attribute a quotation, paraphrase or idea using a signal phrase, embedded or parenthetical form. *(Guide: "Attribution within a sentence")*
- ☐ I can group sources by idea instead of by order. *(Guide: Worked example 1; practice question 6)*
- ☐ I can write a thesis that takes a position and acknowledges complexity. *(Guide: Worked example 1; practice question 6)*
- ☐ I can integrate a source with commentary in my own sentence. *(Practice question 3)*

## Reasoning

- ☐ I can repair a paragraph that only summarises sources. *(Guide: Worked example 2; practice question 7)*
- ☐ I can qualify or extend a public-domain author's idea in my own words. *(Guide: Thoreau example; practice question 8)*
- ☐ I can explain how a source that disagrees can strengthen my credibility. *(Guide: "Common misconceptions")*
