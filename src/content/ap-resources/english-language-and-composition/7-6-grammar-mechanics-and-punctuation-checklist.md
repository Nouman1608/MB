## Understanding

- I can explain why conventional grammar and mechanics enable clear communication, and when errors matter on the exam. *(Guide: "Conventions exist so that readers can follow you"; Practice question 1)*
- I can name what each mark of punctuation can do: clarify, organise, emphasise, indicate purpose, supplement or set tone. *(Guide: "What punctuation can do"; Practice question 2)*
- I can explain the difference between a colon, a semicolon and a dash. *(Guide: "What punctuation can do"; Practice question 3)*

## Skills

- I can identify and fix a comma splice, a run-on and a fragment. *(Guide: "Errors that interfere with meaning"; Practice questions 4 and 5)*
- I can edit a short paragraph so that errors that block meaning are removed, and explain each change. *(Guide: Worked example 2; Practice question 6)*
- I can use a colon, semicolon or dash for a purpose in my own sentences. *(Guide: Worked example 1; Practice question 7)*

## Reasoning

- I can explain how a punctuation choice contributes to a sentence's effect and the writer's purpose. *(Guide: Worked example 1; Practice question 8)*
- I can analyse the dashes in a public-domain passage, such as Lincoln's at Gettysburg. *(Guide: "Public-domain examples"; Practice question 8)*
- I can avoid analysis that only names a mark without saying what it does. *(Guide: "Common misconceptions")*
