Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-5-boolean-expressions-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-5-boolean-expressions-practice/).

## Understanding

- I can state that a Boolean value is true or false and that comparisons produce Booleans *(Guide: Boolean values and relational operators; Practice: Question 1)*
- I can explain that OR is inclusive and AND needs both operands true *(Guide: Logical operators; Practice: Question 5)*
- I can tell = (comparison) apart from ← (assignment) *(Guide: Boolean values and relational operators)*

## Skills

- I can evaluate expressions with =, ≠, >, <, ≥ and ≤ *(Guide: Boolean values and relational operators; Practice: Questions 1 and 6)*
- I can complete a truth table for NOT, AND and OR *(Guide: Logical operators; Practice: Question 9)*
- I can evaluate a compound expression by writing the value of each part *(Guide: Worked example 1; Practice: Question 2)*
- I can write a range test using AND and the correct boundary operators *(Guide: Worked example 2, Task A; Practice: Question 3)*
- I can write a condition from a sentence with brackets and AND/OR *(Guide: Worked example 2; Practice: Question 8)*

## Reasoning

- I can apply De Morgan's laws to find an equivalent expression *(Guide: Worked example 2, Task C; Practice: Question 4)*
- I can decide whether two expressions are equivalent using a truth table or test values *(Guide: Worked example 2, Task C; Practice: Question 7)*
- I can spot errors such as OR instead of AND, or > instead of ≥ *(Guide: Common misconceptions; Practice: Question 3)*
- I can test boundary values to check a condition *(Guide: Worked example 2, Task A; Practice: Question 3)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-5-boolean-expressions-revision-notes/).
