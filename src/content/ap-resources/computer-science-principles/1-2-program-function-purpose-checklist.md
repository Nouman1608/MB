Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/computer-science-principles/1-2-program-function-purpose-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-principles/1-2-program-function-purpose-practice/).

## Understanding

- I can explain the difference between purpose, function and behavior of a program. *(Guide: "What is a program for, and what does it do?"; Practice Q2, Q5)*
- I can explain what a program and a code segment are and how they differ. *(Guide: same section)*
- I can define input, output and event, and give examples of each kind of input. *(Guide: "Inputs, outputs and events"; Practice Q1, Q3)*
- I can explain what event-driven programming means. *(Guide: "Inputs, outputs and events"; Practice Q3)*

## Skills

- I can identify the inputs, outputs and events in a described program. *(Guide: Worked example 1; Practice Q8)*
- I can describe a code segment broadly and in more detail. *(Guide: Worked example 2; Practice Q9)*
- I can trace a short code segment and give its output for given inputs. *(Guide: Worked example 2; Practice Q4, Q6)*

## Reasoning

- I can explain why a program must work for a variety of inputs. *(Guide: "A program must work for a variety of inputs"; Practice Q7 and question 10)*
- I can choose a boundary input that tests a condition. *(Guide: Worked example 2; Practice Q6, Q7)*
- I can tell apart statements about purpose, function and behavior in an exam-style scenario. *(Guide: "Common misconceptions"; Practice Q5)*
