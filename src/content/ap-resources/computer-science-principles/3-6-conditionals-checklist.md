Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-6-conditionals-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-6-conditionals-practice/).

## Understanding

- I can explain selection and the flow of control *(Guide: Selection and flow of control)*
- I can state that every algorithm can be built from sequencing, selection and iteration *(Guide: Selection and flow of control)*
- I can describe what IF and IF/ELSE do when the condition is true and when it is false *(Guide: IF and IF ... ELSE; Practice: Question 7)*

## Skills

- I can trace an IF/ELSE and say which block runs *(Guide: Worked example 1; Practice: Question 1)*
- I can trace IF without ELSE using a default value *(Guide: IF without ELSE; Practice: Question 4)*
- I can write a condition from a description, choosing ≥ or > correctly *(Guide: Worked example 2; Practice: Questions 3 and 6)*
- I can use a Boolean variable as a condition *(Guide: IF and IF ... ELSE; Practice: Question 5)*
- I can express a selection in words or a flowchart before coding it *(Guide: Selection and flow of control; Worked example 2)*

## Reasoning

- I can explain why two separate IF statements are not the same as IF/ELSE *(Guide: Worked example 1; Practice: Question 2)*
- I can choose test values that cover every branch and each boundary *(Guide: Worked example 2; Practice: Question 8)*
- I can explain why the ELSE does not run when the condition is true *(Guide: Common misconceptions; Practice: Question 9)*
- I can identify the correct segment among options that differ at the boundary *(Guide: Worked example 2; Practice: Question 6)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-6-conditionals-revision-notes/).
