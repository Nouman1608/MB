Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-10-lists-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-10-lists-practice/).

## Understanding

- I can state the valid index range of a list and what happens outside it *(Guide: The list operations; Practice: Question 5)*
- I can describe what INSERT, APPEND, REMOVE and LENGTH do to a list *(Guide: The list operations; Practice: Questions 1 and 8)*
- I can explain complete and partial traversal *(Guide: Traversing a list)*
- I can explain that FOR EACH gives item a copy of each element *(Guide: Traversing a list; Practice: Question 7)*

## Skills

- I can trace a sequence of list operations, redrawing the list after each *(Guide: Worked example 1; Practice: Question 1)*
- I can swap two list elements using a temporary variable *(Revision notes: Key relationships; Practice: Questions 3 and 4)*
- I can write FOR EACH and index loops over a list *(Guide: Traversing a list; Practice: Question 9)*
- I can compute a sum and an average of a list *(Guide: Algorithms with lists; Practice: Question 9)*
- I can find the maximum or minimum of a list and its position *(Guide: Algorithms with lists; Practice: Question 10)*
- I can count the elements that meet a condition *(Guide: Worked example 2; Practice: Question 2)*
- I can trace a linear search and say how many elements it examines *(Guide: Algorithms with lists; Practice: Question 6)*

## Reasoning

- I can predict how INSERT and REMOVE change the indices of later elements *(Guide: The list operations (Figure 1); Practice: Questions 1 and 8)*
- I can choose > or ≥ from the wording of a counting task *(Guide: Worked example 2; Practice: Question 2)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-10-lists-revision-notes/).
