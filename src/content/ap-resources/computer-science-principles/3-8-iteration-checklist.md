Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-8-iteration-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-8-iteration-practice/).

## Understanding

- I can explain iteration as repeating a block zero or more times until a stopping condition *(Guide: Three building blocks, third part)*
- I can state that REPEAT UNTIL checks its condition before each pass and stops when it is true *(Guide: REPEAT UNTIL(condition); Practice: Question 7)*
- I can recognise that a REPEAT UNTIL loop can run zero times *(Guide: Worked example 2; Practice: Question 2)*
- I can explain what makes a loop infinite *(Guide: Worked example 2; Practice: Questions 3 and 9)*

## Skills

- I can trace REPEAT n TIMES with a table *(Guide: Worked example 1; Practice: Question 1)*
- I can trace REPEAT UNTIL and count passes *(Guide: Worked example 2; Practice: Question 4)*
- I can write a counter and an accumulator inside a loop *(Guide: Worked example 1; Practice: Question 8)*
- I can combine a loop and an IF to count items *(Guide: Worked example 1; Practice: Question 5)*
- I can choose a loop that moves a robot to a wall for any corridor length *(Guide: Iteration with a robot; Practice: Question 6)*

## Reasoning

- I can repair a loop whose condition never becomes true *(Guide: Worked example 2; Practice: Question 9)*
- I can choose between = and ≤ (or ≥) as a safe stopping test *(Guide: Worked example 2; Practice: Question 3)*
- I can check a loop result against a known pattern (sum of the first k odd numbers) *(Guide: Worked example 1; Practice: Question 8)*
