Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-14-libraries-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-14-libraries-practice/).

## Understanding

- I can define a software library and say how it simplifies programming *(Guide: Libraries, APIs and documentation; Practice: Question 1)*
- I can define an API *(Guide: Libraries, APIs and documentation; Practice: Question 2)*
- I can explain why documentation is necessary *(Guide: Libraries, APIs and documentation; Practice: Question 3)*
- I can give internal and external sources of existing code *(Guide: Libraries, APIs and documentation)*

## Skills

- I can predict what a documented library procedure returns *(Guide: Worked example 1; Practice: Question 4)*
- I can evaluate nested library calls from the inside out *(Guide: Worked example 1; Practice: Question 8)*
- I can use the returned value of a library procedure in a statement *(Guide: Worked example 1; Practice: Question 9)*
- I can guard a call so the documented conditions are met *(Guide: Worked example 2; Practice: Question 5)*

## Reasoning

- I can decide whether to use a library or write my own code *(Guide: Worked example 2, Step 3)*
- I can choose an appropriate library for a stated need *(Guide: Choosing an appropriate library; Practice: Question 6)*
- I can state the benefits of using a library *(Guide: Libraries, APIs and documentation; Practice: Question 7)*
- I can explain why my use of a library still needs testing *(Guide: Choosing an appropriate library)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-14-libraries-revision-notes/).
