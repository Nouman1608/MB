Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/computer-science-principles/2-1-binary-numbers-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-principles/2-1-binary-numbers-practice/).

## Understanding

- I can define bit and byte and explain why computers use binary. *(Guide: "Why does a computer use only 0 and 1?"; Practice Q5)*
- I can explain that n bits give 2 to the power n values and why each extra bit doubles the count. *(Guide: "Comparing binary numbers and counting values"; Practice Q3)*
- I can explain that the same bits can mean different data in different contexts. *(Guide: "Same bits, different meanings"; Practice Q7)*
- I can explain analog data, sampling and why digital data approximate analog data. *(Guide: "Analog data, sampling and approximation"; Practice Q9)*

## Skills

- I can convert a positive whole number from binary to decimal. *(Guide: Worked example 1 part B; Practice Q1)*
- I can convert a positive whole number from decimal to binary and check it a second way. *(Guide: Worked example 1 part A; Practice Q2, Q8)*
- I can compare and order binary numbers. *(Guide: "Comparing binary numbers and counting values"; Practice Q4)*
- I can work out the number of bits needed to represent a given number of values. *(Guide: Worked example 2 part (a); Practice question 10)*

## Reasoning

- I can identify an overflow error and explain it using the range of n bits. *(Guide: Worked example 2 part (b); Practice Q6)*
- I can tell overflow from round-off and describe what causes each. *(Guide: "Limits: overflow and round-off")*
- I can explain how a higher sampling rate or more bits per sample changes the approximation and the cost. *(Guide: "Analog data, sampling and approximation"; Practice Q9)*
