Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-4-strings-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-4-strings-practice/).

## Understanding

- I can define a string as an ordered sequence of characters *(Guide: What a string is)*
- I can explain that a space and a digit in quotes are characters *(Guide: What a string is; Practice: Question 4)*
- I can explain that concatenation makes a new string and order matters *(Guide: Concatenation; Practice: Question 1)*
- I can explain that a substring is part of a string and leaves the original unchanged *(Guide: Substrings; Practice: Question 5)*

## Skills

- I can evaluate substring calls by marking the characters from the start position *(Guide: Substrings; Practice: Question 2)*
- I can evaluate nested concat calls from the inside out *(Guide: Concatenation; Practice: Question 8)*
- I can trace code that cuts a string and rejoins the parts *(Guide: Worked example 1; Practice: Question 3)*
- I can build a username or code from parts of several strings *(Guide: Worked example 2; Practice: Question 9)*
- I can trace a string built up inside a loop *(Guide: Worked example 2; Practice: Question 6)*

## Reasoning

- I can check an answer by counting characters *(Guide: Worked examples 1 and 2; Practice: Question 8)*
- I can decide between a string and a number for a piece of data *(Guide: Choosing between a string and something else; Practice: Question 4)*
- I can find which of several expressions produces a target string *(Guide: Worked example 1; Practice: Question 7)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-4-strings-revision-notes/).
