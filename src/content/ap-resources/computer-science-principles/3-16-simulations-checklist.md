Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-16-simulations-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-16-simulations-practice/).

## Understanding

- I can define a simulation as an abstraction of a more complex phenomenon for a specific purpose *(Guide: What a simulation is; Practice: Question 1)*
- I can state when a simulation is most useful (too big, small, fast, slow, expensive or dangerous) *(Guide: What a simulation is; Practice: Questions 2 and 7)*
- I can explain that building a simulation removes details or simplifies functionality *(Guide: Abstraction: what to leave out; Practice: Question 3)*
- I can explain how random numbers represent real-world variability *(Guide: Random numbers and variability; Practice: Question 4)*

## Skills

- I can trace a small simulation that uses RANDOM when the values are given *(Guide: Worked example 1; Practice: Question 6)*
- I can write a simulation of a chance event with a given probability *(Guide: Worked example 1; Practice: Question 10)*
- I can list what a model includes and excludes *(Guide: Worked example 2; Practice: Question 9)*

## Reasoning

- I can explain how an excluded detail biases a simulation and in which direction *(Guide: Abstraction: what to leave out; Practice: Question 5)*
- I can explain why one run of a random simulation is one possible outcome *(Guide: Worked example 1; Practice: Question 10)*
- I can compare a simulation with a real-world experiment *(Guide: Simulation or real-world experiment?; Practice: Question 8)*
- I can suggest how to check a simulation against real data *(Guide: Worked example 2, Step 3; Practice: Question 9)*
- I can explain that a simulation supports decisions but does not replace real evidence *(Guide: Worked example 2, Step 4)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-16-simulations-revision-notes/).
