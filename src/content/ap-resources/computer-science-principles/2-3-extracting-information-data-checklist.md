Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/computer-science-principles/2-3-extracting-information-data-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-principles/2-3-extracting-information-data-practice/).

## Understanding

- I can explain the difference between data and information. *(Guide: "From data to information")*
- I can explain what metadata are and that changing them does not change the primary data. *(Guide: "Metadata: data about data"; Practice Q1, Q2)*
- I can explain why correlation does not show causation. *(Guide: "Correlation is not causation"; Practice Q4, Q9)*
- I can explain why more data does not remove bias from the source. *(Guide: "Challenges when processing data"; Practice Q7)*

## Skills

- I can clean a set of free-text entries without changing their meaning and recount. *(Guide: Worked example 1; Practice Q3, Q8)*
- I can name and apply transforming, filtering, combining and visualising. *(Guide: "Processes that extract information"; Practice Q6)*
- I can handle incomplete or invalid records and account for them. *(Guide: Worked example 1; Practice Q5, Q8)*

## Reasoning

- I can describe a pattern in data without claiming a cause. *(Guide: Worked example 2; Practice Q9)*
- I can suggest a further data source to investigate a possible cause. *(Guide: Worked example 2; Practice Q9)*
- I can explain how data size creates challenges and why scalability matters. *(Guide: "Challenges when processing data"; Practice question 10)*

All ticked? Move on to the [Topic 2.4 study guide](/advanced-course-resources/computer-science-principles/2-4-using-programs-data-study-guide/), Using Programs with Data.
