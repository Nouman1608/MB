Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/computer-science-principles/1-3-program-design-development-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-principles/1-3-program-design-development-practice/).

## Understanding

- I can name the common phases of development and say what happens in each. *(Guide: "How is a program really developed?"; Practice Q1, Q5)*
- I can explain the difference between iterative and incremental development, and between ordered and exploratory processes. *(Guide: "Iterative and incremental"; Practice Q2, Q6)*
- I can explain what requirements and a specification are, and how design differs. *(Guide: "Investigation, requirements and specification"; Practice Q4)*
- I can explain what documentation and comments do and do not do. *(Guide: "Documentation and acknowledgement"; Practice Q3)*

## Skills

- I can sort the activities in a project into the correct phases. *(Guide: Worked example 1; Practice Q1, Q5)*
- I can name ways to investigate users' needs, and activities that belong in design. *(Guide: "What the design phase may include"; Practice Q8)*
- I can write or improve a comment so that it explains purpose. *(Guide: Worked example 2; Practice Q9)*

## Reasoning

- I can decide whether a described project is iterative, incremental or both, with a reason. *(Guide: Worked example 1; Practice Q6 and question 10)*
- I can say how a requirement is used to choose tests. *(Guide: "Investigation, requirements and specification"; Practice Q8)*
- I can explain how to acknowledge code from another source and why it matters. *(Guide: Worked example 2; Practice Q7)*

All ticked? Move on to the [Topic 1.4 study guide](/advanced-course-resources/computer-science-principles/1-4-identifying-correcting-errors-study-guide/), Identifying and Correcting Errors.
