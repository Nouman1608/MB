Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-12-calling-procedures-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-12-calling-procedures-practice/).

## Understanding

- I can define a procedure and say that method and function are other names *(Guide: What a procedure is)*
- I can distinguish parameters from arguments *(Guide: What a procedure is; Practice: Question 1)*
- I can describe how a call interrupts the sequence and where control returns *(Guide: Calling a procedure and the flow of control; Practice: Question 7)*
- I can distinguish DISPLAY from RETURN *(Guide: Tools the reference sheet provides; Practice: Question 4)*

## Skills

- I can match arguments to parameters by position *(Guide: Worked example 1; Practice: Question 3)*
- I can trace nested procedure calls *(Guide: Worked example 1; Practice: Question 2)*
- I can trace a procedure with an early RETURN and a DISPLAY *(Guide: Worked example 2; Practice: Question 5)*
- I can use INPUT() and a call inside an expression *(Guide: Worked example 2; Practice: Question 6)*
- I can write a call that assigns a returned value to a variable *(Guide: Calling a procedure and the flow of control; Practice: Question 8)*

## Reasoning

- I can predict the order of DISPLAY outputs when procedures also display *(Guide: Worked example 2; Practice: Question 4)*
- I can explain what happens when a procedure uses an invalid list index *(Guide: Common misconceptions; Practice: Question 9)*
- I can use the five-step checklist to read any call *(Guide: Reading a call correctly; Practice: Questions 8 and 9)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-12-calling-procedures-revision-notes/).
