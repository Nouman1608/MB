Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-1-variables-assignments-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-1-variables-assignments-practice/).

## Understanding

- I can explain what a variable is and why a program needs one *(Guide: Why programs need variables)*
- I can state that a variable holds one value at a time, and that the value can be a list *(Guide: Why programs need variables; Practice: Question 6)*
- I can explain why meaningful variable names help readability and maintenance *(Guide: Why programs need variables; Practice: Question 4)*
- I can choose between number, Boolean, string and list for a piece of information *(Guide: Data types and choosing a representation; Practice: Question 5)*

## Skills

- I can describe the two steps of assignment (evaluate, then store a copy) *(Guide: The assignment operator; Practice: Question 1)*
- I can tell ← (assignment) apart from = (equality test) *(Guide: The assignment operator; Practice: Question 6)*
- I can build a trace table and find a variable after several assignments *(Guide: Worked example 1; Practice: Question 8)*
- I can write a running-total update such as total ← total + price *(Guide: Worked example 2; Practice: Questions 3 and 9)*
- I can swap two variables using a temporary variable *(Guide: Worked example 2; Practice: Question 2)*

## Reasoning

- I can explain why b ← a does not keep b equal to a afterwards *(Guide: The assignment operator (Figure 1); Practice: Question 1)*
- I can predict the result when a list is assigned to another list variable *(Guide: Lists and copies; Practice: Question 7)*
- I can explain why count ← count + 1 is an update and not an equation *(Guide: Common misconceptions; Practice: Question 9)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-1-variables-assignments-revision-notes/).
