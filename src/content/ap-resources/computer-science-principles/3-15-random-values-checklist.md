Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-15-random-values-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-15-random-values-practice/).

## Understanding

- I can state what RANDOM(a, b) returns, including that both ends are included *(Guide: What RANDOM(a, b) does; Practice: Question 1)*
- I can state that each execution may give a different result *(Guide: What RANDOM(a, b) does; Practice: Question 7)*
- I can count the possible values of RANDOM(a, b) *(Guide: What RANDOM(a, b) does; Practice: Question 2)*

## Skills

- I can list the possible results of an expression that uses RANDOM *(Guide: Possible results of an expression; Practice: Question 3)*
- I can write an expression for a required range or pattern of values *(Guide: Possible results of an expression; Practice: Question 9)*
- I can write a condition with a given probability *(Guide: Worked example 2; Practice: Question 10)*
- I can choose a random element of a list safely *(Guide: Worked example 2; Practice: Question 6)*

## Reasoning

- I can explain why the sum of two RANDOM calls is not uniform *(Guide: Worked example 1; Practice: Question 4)*
- I can compute a probability as favourable values over possible values *(Guide: Worked example 2; Practice: Questions 5 and 10)*
- I can spot off-by-one errors in a range or index *(Guide: Worked example 2, Step 2; Practice: Question 6)*
- I can decide which expression could produce a given value *(Guide: Possible results of an expression; Practice: Question 8)*
- I can explain why random code needs repeated testing *(Guide: What RANDOM(a, b) does; Practice: Question 10)*
