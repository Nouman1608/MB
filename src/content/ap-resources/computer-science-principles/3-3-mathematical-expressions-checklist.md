Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-3-mathematical-expressions-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-3-mathematical-expressions-practice/).

## Understanding

- I can state that an expression is evaluated to a single value *(Guide: Expressions and how they are evaluated)*
- I can explain what a MOD b means in terms of whole copies and a remainder *(Guide: MOD from first principles; Practice: Question 1)*
- I can state that MOD shares precedence with * and / and that equal precedence goes left to right *(Guide: Expressions and how they are evaluated; Practice: Questions 2 and 6)*
- I can explain why a MOD b is always between 0 and b - 1 *(Guide: MOD from first principles; Practice: Question 4)*

## Skills

- I can evaluate an expression that mixes + - * / and MOD *(Guide: Worked example 1; Practice: Questions 2 and 9)*
- I can write an expression that tests for even, odd or divisible by d *(Guide: MOD from first principles; Practice: Question 3)*
- I can extract the last digit of a number and remove it *(Guide: Worked example 2, Part C; Practice: Question 5)*
- I can convert a number of minutes or seconds into whole units plus a remainder *(Guide: Worked example 2, Part A; Practice: Question 8)*
- I can wrap a value onto a clock with MOD *(Guide: Worked example 2, Part B; Practice: Question 4)*

## Reasoning

- I can identify the precedence error that produced a wrong answer *(Guide: Common misconceptions; Practice: Question 9)*
- I can check a MOD result by multiplying back and adding the remainder *(Guide: Worked example 2; Practice: Question 8)*
- I can decide which of several expressions gives a required value *(Guide: Worked example 1; Practice: Question 7)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-3-mathematical-expressions-revision-notes/).
