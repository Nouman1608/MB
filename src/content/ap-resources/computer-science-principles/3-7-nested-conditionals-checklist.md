Work through the list without notes. If you cannot do a statement, follow the pointer, then come back. Guide = the [study guide](/advanced-course-resources/computer-science-principles/3-7-nested-conditionals-study-guide/); Practice = the [practice questions](/advanced-course-resources/computer-science-principles/3-7-nested-conditionals-practice/).

## Understanding

- I can explain what a nested conditional is *(Guide: What nesting means)*
- I can state when the inner condition is evaluated *(Guide: What nesting means; Practice: Questions 2 and 7)*
- I can pair each ELSE with the correct IF by reading the braces *(Guide: What nesting means; Practice: Question 5)*

## Skills

- I can trace a nested conditional for given inputs *(Guide: Worked example 1; Practice: Question 1)*
- I can write a nested conditional that produces three different outcomes *(Guide: What nesting means; Practice: Question 8)*
- I can trace the leap-year conditional for a year *(Guide: Worked example 2; Practice: Question 6)*
- I can choose test values that reach every path and boundary *(Guide: Worked examples 1 and 2; Practice: Question 8)*

## Reasoning

- I can explain why the order of tests in a chain matters *(Guide: Nesting as a chain of ranges; Practice: Question 3)*
- I can rewrite a nested conditional with no ELSE as a single condition with AND *(Guide: When can nesting be flattened?; Practice: Questions 4 and 9)*
- I can explain why nesting with several outcomes cannot be flattened to one AND *(Guide: When can nesting be flattened?; Practice: Question 9)*
- I can write the leap-year rule as one Boolean expression and check it *(Guide: Worked example 2, Step 3)*
- I can state when the inner ELSE runs (outer true and inner false) *(Guide: Common misconceptions; Practice: Question 1)*

When every line is secure, move on. The revision notes are here: [revision notes](/advanced-course-resources/computer-science-principles/3-7-nested-conditionals-revision-notes/).
