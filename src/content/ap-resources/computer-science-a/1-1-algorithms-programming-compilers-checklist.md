Guide = [study guide](/advanced-course-resources/computer-science-a/1-1-algorithms-programming-compilers-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-a/1-1-algorithms-programming-compilers-practice/).

## Understanding

- I can define an algorithm and give an everyday example. *(Guide: "An algorithm is a plan you can follow one step at a time"; Practice Question 1)*
- I can explain what sequencing means and why changing the order of steps can change the result. *(Guide: Worked example 1; Practice Questions 1 and 6)*
- I can say what an IDE provides and what a compiler does, and why compile errors must be fixed before a program runs. *(Guide: "From idea to running program"; Practice Question 2)*
- I can state the order write, compile, run, and say which kinds of error appear at which stage. *(Guide: Figure 1; Practice Question 3)*
- I can define syntax error, logic error, run-time error and exception, and say how each is detected. *(Guide: "Three families of error"; Practice Question 7)*

## Skills

- I can describe a simple process as an ordered list of steps and spot a step that is in the wrong place. *(Practice Question 6)*
- I can trace a short sequence of statements with a table, one row per statement. *(Guide: Worked example 1; Practice Question 5)*
- I can classify a given fault or symptom as a syntax, logic or run-time error. *(Guide: Worked example 2; Practice Questions 3, 4 and 7)*
- I can recognise that integer division by zero compiles but throws an exception when run. *(Guide: "Three families of error"; Practice Question 9)*

## Reasoning

- I can explain why a program that compiles is not necessarily correct. *(Guide: "Common misconceptions"; Practice Question 4)*
- I can explain why output printed before an exception still appears. *(Practice Question 7, part (d))*
- I can choose test data that would expose a logic error and explain why some data hides it. *(Practice Question 8)*
