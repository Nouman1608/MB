## Understanding

- ☐ I can explain that a 2D array is an array of arrays (study guide: From a list to a table; Figure 2).
- ☐ I can say which index is the row and which is the column (study guide: Picturing it; practice: Question 2).
- ☐ I can state the default value for each element type and why a new String array holds null (study guide: Creating a 2D array; practice: Question 6).
- ☐ I can explain why a row taken with arr[r] is an alias, not a copy (study guide: Rows are references; practice: Question 5).

## Skills

- ☐ I can create a 2D array with new and with an initializer list (study guide: Creating a 2D array; practice: Question 7).
- ☐ I can read and change an element with [row][col] (study guide: Worked example 1; practice: Question 2).
- ☐ I can find the number of rows and columns from length (study guide: Reading, writing and measuring; practice: Question 3).
- ☐ I can write a method that copies a column or checks an index (study guide: Worked example 2; practice: Questions 9 and 10).

## Reasoning

- ☐ I can trace assignments to a grid and write the final table (study guide: Worked example 1).
- ☐ I can predict an ArrayIndexOutOfBoundsException on either index (practice: Question 4).
- ☐ I can predict a NullPointerException on a null element (study guide: Worked example 2; practice: Question 6).
- ☐ I can predict the result of swapping two rows by swapping references (practice: Question 8).
