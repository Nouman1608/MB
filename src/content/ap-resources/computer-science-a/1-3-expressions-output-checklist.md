Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/computer-science-a/1-3-expressions-output-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-a/1-3-expressions-output-practice/).

## Understanding

- I can explain the difference between `print` and `println` in terms of the cursor. *(Guide: "Showing results"; Practice Question 1)*
- I can define a literal and a string literal, and say what an escape sequence is. *(Guide: "String literals and escape sequences")*
- I can state the result type of an operation on two `int` values and on a `double` and an `int`. *(Guide: "Arithmetic expressions"; Practice Question 5)*
- I can explain what integer division and the remainder operator compute. *(Guide: "Integer division" and "The remainder operator"; Practice Question 3)*
- I can say when an `ArithmeticException` occurs and that it is a run-time error. *(Guide: "Dividing by zero"; Practice Question 6)*

## Skills

- I can write a string literal that includes a double quote, a backslash or a new line, and say what it displays. *(Guide: the escape-sequence table; Practice Questions 2 and 8)*
- I can evaluate an expression by hand using precedence, left-to-right order and parentheses, writing one step per line. *(Guide: Worked example 1; Practice Questions 3, 4 and 5)*
- I can tell the output of a short mixed `print`/`println` program. *(Practice Questions 1 and 8)*
- I can use `/` and `%` to split a quantity into whole groups and a remainder. *(Guide: Worked example 2; Practice Question 7)*
- I can extract digits of a whole number using `/` and `%`. *(Practice Question 9)*

## Reasoning

- I can explain why `double x = 7 / 2;` stores 3.0, not 3.5. *(Guide: "Common misconceptions"; Practice Question 10)*
- I can explain why `7 / 2 * 2.0` and `7 / 2.0 * 2` differ. *(Guide: the arithmetic output listing)*
- I can find and correct a precedence bug in an average calculation. *(Practice Question 10)*
