Guide = [study guide](/advanced-course-resources/computer-science-a/1-10-calling-class-methods-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-a/1-10-calling-class-methods-practice/).

## Understanding

- I can explain what a class method is and how it differs from an instance method. *(Guide: "Methods that belong to the class"; Practice Question 1)*
- I can say what `static` means in a method header. *(Guide: "Methods that belong to the class"; Practice Question 1)*
- I can explain why the `Math` class never needs an object. *(Guide: "Methods that belong to the class")*
- I can say when the class name is optional in a call and when it is required. *(Guide: "Calling a class method"; Practice Questions 2 and 5)*
- I can name the parts of a class method call: class name, dot operator, method name, arguments. *(Guide: Figure 1)*

## Skills

- I can write a call to a class method that matches its signature. *(Guide: "Calling a class method"; Practice Questions 2 and 7)*
- I can evaluate nested calls from the inside out, in left-to-right order. *(Guide: Worked example 1; Practice Questions 3, 6 and 9)*
- I can write a class method and call it from another class. *(Practice Question 7)*
- I can store, print or pass on the value of a non-void call, and call a void method as a statement. *(Guide: "The value of a call")*
- I can find the cause of a compile-time error in a call and correct it. *(Guide: Worked example 2; Practice Questions 4 and 8)*

## Reasoning

- I can explain why a missing class name causes "cannot find symbol" when the call is in another class. *(Guide: "Why a call does not compile"; Practice Question 8)*
- I can explain why a `double` argument cannot be passed to an `int` parameter. *(Guide: "Why a call does not compile"; Practice Question 4)*
- I can explain why the result of a void method cannot be stored. *(Guide: "Why a call does not compile"; Practice Question 8)*
