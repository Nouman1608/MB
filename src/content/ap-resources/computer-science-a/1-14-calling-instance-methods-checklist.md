Guide = [study guide](/advanced-course-resources/computer-science-a/1-14-calling-instance-methods-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-a/1-14-calling-instance-methods-practice/).

## Understanding

- I can explain that instance methods are called on objects with the object name and the dot operator. *(Guide: "Asking an object to do something"; Practice Question 1)*
- I can explain the difference between calling a class method and an instance method. *(Guide: "A call needs an object"; Practice Question 1)*
- I can explain why the same method gives different results for different objects. *(Guide: the `Instances` program; Practice Question 2)*
- I can explain the difference between a void and a non-void instance method. *(Guide: "Void and non-void instance methods"; Practice Question 4)*
- I can say when a `NullPointerException` occurs. *(Guide: "Calling a method on null"; Practice Question 6)*

## Skills

- I can write calls that match a method's parameters and use or store its return value. *(Guide: Worked example 1; Practice Questions 2 and 9)*
- I can trace a sequence of calls on several objects with a table. *(Guide: Worked example 1; Practice Questions 3 and 8)*
- I can trace code in which two variables refer to one object. *(Guide: Worked example 2; Practice Question 5)*
- I can say why a call does not compile. *(Guide: the table of faults; Practice Question 4)*
- I can call `String` instance methods on variables and on literals. *(Guide: "String objects use instance methods too"; Practice Question 7)*

## Reasoning

- I can explain why the compiler does not report a call on a `null` variable. *(Guide: Worked example 2; Practice Question 10)*
- I can fix code so that it creates an object before calling a method on it. *(Practice Question 10)*
- I can explain why a change through one name is seen through another name for the same object. *(Guide: Worked example 2; Practice Question 5)*
