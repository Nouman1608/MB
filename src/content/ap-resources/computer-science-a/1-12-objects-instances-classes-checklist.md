Guide = [study guide](/advanced-course-resources/computer-science-a/1-12-objects-instances-classes-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-a/1-12-objects-instances-classes-practice/).

## Understanding

- I can explain a class as a blueprint and an object as a specific instance of it. *(Guide: "Blueprints and the things built from them"; Practice Question 1)*
- I can explain that different objects of one class have their own attribute values but share the same behaviors. *(Guide: Worked example 1; Practice Question 7)*
- I can explain that a reference variable holds an object reference, like a memory address. *(Guide: "Variables that hold references"; Practice Question 2)*
- I can explain that declaring a reference variable does not create an object. *(Guide: "Variables that hold references"; Practice Question 3)*
- I can say what a superclass, a subclass and an inheritance relationship are, and that all classes are subclasses of `Object`. *(Guide: "Class hierarchies and the Object class"; Practice Question 5)*

## Skills

- I can declare a variable of a reference type. *(Guide: "Variables that hold references"; Practice Question 3)*
- I can classify things as class, object, attribute or behavior. *(Guide: Worked example 1; Practice Question 7)*
- I can draw and use a reference diagram with variables on one side, objects on the other and arrows for references. *(Guide: Figure 2; Practice Questions 4 and 8)*
- I can trace code in which two variables refer to one object and state the output. *(Guide: Worked example 2; Practice Questions 4, 6 and 8)*

## Reasoning

- I can explain why `Counter b = a;` does not create a second object. *(Guide: "Two names for one object"; Practice Questions 4 and 8)*
- I can contrast copying a primitive with copying a reference. *(Guide: "Two names for one object"; Practice Questions 6 and 9)*
- I can say what is, and is not, expected about inheritance in this course. *(Guide: "Class hierarchies and the Object class")*
