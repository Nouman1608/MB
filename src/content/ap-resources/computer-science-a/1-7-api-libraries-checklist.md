Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/computer-science-a/1-7-api-libraries-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-a/1-7-api-libraries-practice/).

## Understanding

- I can define library, package and class, and say how they fit together. *(Guide: "Why use code that someone else wrote?"; Practice Question 9)*
- I can explain what an API specification is and why documentation is essential. *(Guide: "Reading API documentation"; Practice Question 1)*
- I can explain that a class defines a reference type from which objects are created. *(Guide: "Why use code that someone else wrote?")*
- I can define attributes and behaviors and say how each appears in code. *(Guide: "Attributes and behaviors"; Practice Questions 3 and 7)*
- I can say which packages are available by default and which classes need an import. *(Guide: "Using classes from a library"; Practice Questions 2 and 9)*

## Skills

- I can identify the return type, name, parameter list and description in a method entry. *(Guide: the entry table; Practice Questions 4 and 8)*
- I can write a call to a library method that matches the number, types and order of its parameters. *(Guide: Worked example 1; Practice Questions 4 and 8)*
- I can predict the result of `length`, `substring` and `indexOf` calls by writing the indices under the string. *(Guide: Worked example 2; Practice Questions 5, 6 and 10)*
- I can classify features of a class as attributes or behaviors. *(Practice Question 7)*

## Reasoning

- I can explain why a `double` result from `Math.pow` cannot be stored in an `int` without a cast. *(Guide: Worked example 1; Practice Question 8)*
- I can explain why a missing import gives a "cannot find symbol" error. *(Guide: "Using classes from a library"; Practice Question 9)*
- I can explain how procedural abstraction lets me use a method without seeing its code. *(Guide: "Why use code that someone else wrote?")*
