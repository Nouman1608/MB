Guide = [study guide](/advanced-course-resources/computer-science-a/1-9-method-signatures-study-guide/); Practice = [practice questions](/advanced-course-resources/computer-science-a/1-9-method-signatures-practice/).

## Understanding

- I can define a method and a block, and describe procedural abstraction. *(Guide: "A method is a named block of code")*
- I can define parameter and argument and tell them apart. *(Guide: "The anatomy of a method header")*
- I can state the signature of a method and say what is not part of it. *(Guide: Figure 1; Practice Questions 1 and 2)*
- I can explain the difference between void and non-void methods and how a returned value is used. *(Guide: "Void and non-void methods"; Practice Questions 4 and 6)*
- I can explain call by value. *(Guide: "Call by value"; Practice Question 3)*

## Skills

- I can match a call to a signature by the number, order and types of the arguments. *(Guide: Worked example 2; Practice Question 4)*
- I can identify legal overloads and choose the method an overloaded call uses. *(Guide: "Overloading"; Practice Questions 2 and 9)*
- I can trace the order of output through nested method calls. *(Guide: "The flow of control"; Practice Question 5)*
- I can trace a program with parameters and return values using a table. *(Guide: Worked example 1; Practice Question 8)*
- I can write a method header and body and call it, storing the result. *(Practice Question 7)*

## Reasoning

- I can explain why two methods cannot differ only in their return type. *(Guide: "Overloading"; Practice Question 2)*
- I can explain why changing a primitive parameter does not change the caller's variable. *(Guide: "Call by value"; Practice Questions 3 and 8)*
- I can say where control goes when a method ends. *(Guide: "The flow of control"; Practice Question 5)*
