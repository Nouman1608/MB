## Understanding

- I can name the standard array algorithms and the extra state each needs. *(Guide: "Standard plans, now in Java"; Practice Questions 1 to 6)*
- I can explain why a maximum starts from the first element, not from 0. *(Guide: "Minimum and maximum"; Practice Questions 1 and 9)*
- I can explain why an "at least one" loop returns true inside and false after, and an "all" loop does the opposite. *(Guide: "At least one, and all"; Practice Question 2)*
- I can explain why the duplicates inner loop starts at i + 1 and the pairs loop stops at length - 1. *(Guide: "Consecutive pairs" and "Duplicates"; Practice Questions 4 and 7)*

## Skills

- I can write code to find a minimum, maximum, sum, average and count. *(Guide: Worked example 1; Practice Questions 1, 3 and 9)*
- I can write code for any, all, consecutive pairs and duplicates. *(Guide: Worked example 2; Practice Questions 2, 4 and 7)*
- I can rotate or shift elements one place left or right using a saved element. *(Guide: Worked example 2; Practice Questions 5 and 8)*
- I can reverse an array by swapping from the ends to the middle. *(Guide: Worked example 2; Practice Question 6)*

## Reasoning

- I can trace an array algorithm on a small array and state the array afterwards. *(Guide: Worked example 2; Practice Questions 5, 6 and 8)*
- I can find and correct a fault such as a wrong starting value, early return or integer division. *(Guide: "Common faults the exam likes to test"; Practice Questions 2 and 9)*
- I can say whether an algorithm changes the caller's array and why. *(Guide: "Standard plans, now in Java"; Practice Question 8)*
