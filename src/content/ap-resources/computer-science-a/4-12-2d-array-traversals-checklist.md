## Understanding

- ☐ I can explain why a 2D array needs nested loops and what row-major and column-major mean (study guide: Why traversal needs two loops; Figures 1 and 2).
- ☐ I can state the correct bounds for the row and column loops (study guide: Row-major and column-major with index loops; practice: Question 3).
- ☐ I can state the type of each variable in a nested enhanced for loop (study guide: Nested enhanced for loops; practice: Question 4).
- ☐ I can explain what assigning to an enhanced for variable does and does not change (study guide: Nested enhanced for loops; practice: Questions 5 and 6).

## Skills

- ☐ I can write a row-major traversal and a column-major traversal (study guide: Row-major and column-major with index loops; practice: Questions 1 and 2).
- ☐ I can compute row sums and column sums into arrays of the right length (study guide: Worked example 1; practice: Question 9).
- ☐ I can fill a 2D array from a formula (study guide: Worked example 2; practice: Question 8).
- ☐ I can build a transposed copy of a table (study guide: Building a new 2D array; practice: Question 10).

## Reasoning

- ☐ I can trace a traversal and write its output in order (practice: Questions 1, 2 and 7).
- ☐ I can predict an out-of-range error caused by swapped bounds (practice: Question 3).
- ☐ I can trace a snake or diagonal traversal (study guide: Worked example 2; practice: Question 7).
- ☐ I can check row and column totals against the grand total (study guide: Worked example 1).
