## Understanding

- I can say what a data set is and give an everyday example. *(Guide: "What is a data set?"; Practice Question 1)*
- I can explain that a program accesses and processes the values of a data set one at a time. *(Guide: "Values are used one at a time"; Practice Question 2)*
- I can explain why a chart, table or flowchart helps to plan an algorithm. *(Guide: "Representing a data set and a plan"; Practice Question 3)*
- I can describe the three parts of a typical plan: set up, repeat for each value, report. *(Guide: "Values are used one at a time"; Practice Question 7)*

## Skills

- I can write a plan in numbered steps for counting, totalling and averaging a data set. *(Guide: Worked example 1; Practice Question 7)*
- I can trace a plan with a table and read off the result. *(Guide: Worked example 1; Practice Questions 4 and 7)*
- I can plan how to find the largest value and where it occurred. *(Guide: Worked example 2; Practice Questions 6 and 9)*
- I can draw a flowchart that shows the loop, the choice and the report. *(Guide: Figure 1; Practice Question 3)*

## Reasoning

- I can find the flaw in a plan that resets a count inside the loop and predict its output. *(Guide: Worked example 2; Practice Question 5)*
- I can explain why a maximum should start from the first value. *(Guide: Worked example 2; Practice Question 6)*
- I can adapt a standard plan to a new question about the same data. *(Practice Questions 8 and 9)*
