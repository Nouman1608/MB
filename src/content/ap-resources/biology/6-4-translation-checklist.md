Work through the list without notes (a genetic code table is allowed). If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/biology/6-4-translation-study-guide/); Practice = [practice questions](/advanced-course-resources/biology/6-4-translation-practice/).

## Understanding

- I can state where translation happens in prokaryotic and eukaryotic cells, including the rough ER. *(Guide: "Where translation happens")*
- I can explain why prokaryotes can translate an mRNA while it is still being transcribed. *(Guide: "Where translation happens"; Practice Q1)*
- I can describe initiation, elongation and termination, including the role of rRNA at the start codon and what happens at a stop codon. *(Guide: "Three stages of translation"; Figure 1)*
- I can explain how a tRNA's anticodon makes sure the correct amino acid is added. *(Guide: "The players"; Practice Q3)*
- I can describe the steps by which a retrovirus copies its RNA into DNA and gets its genes expressed. *(Guide: "A special case: retroviruses"; Practice Q4)*

## Skills

- I can translate an mRNA with a code table, starting at AUG and stopping at a stop codon. *(Guide: Worked example 1; Practice Q2)*
- I can write the anticodon for a codon, and the codon for an anticodon, with correct 5′ and 3′ labels. *(Guide: Worked example 1; Practice Q3)*
- I can count codons and amino acids from nucleotide positions or lengths, remembering the stop codon. *(Guide: Worked example 2; Practice Q6, Q7)*
- I can analyse protein synthesis data, calculate percentage changes and interpolate between points. *(Practice Q5)*

## Reasoning

- I can explain why a nearly universal genetic code is evidence for common ancestry. *(Guide: "Why a shared code points to common ancestry"; Practice Q7)*
- I can use the redundancy of the code to predict whether a codon change alters a polypeptide. *(Guide: Worked example 2; Practice Q6)*
- I can predict the effect of blocking a step in information flow, such as reverse transcriptase or the ribosome. *(Practice Q4, Q5)*
