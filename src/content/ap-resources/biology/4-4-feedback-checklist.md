Work through the list without notes. If you cannot do a statement, follow its link, then come back. Guide = [study guide](/advanced-course-resources/biology/4-4-feedback-study-guide/); Practice = [practice questions](/advanced-course-resources/biology/4-4-feedback-practice/).

## Understanding

- I can name the parts of a feedback loop and explain what a set point is. *(Guide: "Parts of a feedback loop")*
- I can explain the difference between negative and positive feedback in terms of what the response does to the stimulus. *(Guide: comparison table; Practice Q1)*
- I can describe how insulin and glucagon keep blood glucose near its set point. *(Guide: Figure 1; Practice Q4)*
- I can explain end-product inhibition as negative feedback at the molecular level. *(Guide: "Negative feedback inside cells"; Practice Q2)*
- I can describe childbirth, lactation and fruit ripening as positive feedback, and say what ends each loop. *(Guide: "Positive feedback"; Practice Q5, Q6)*

## Calculation and skills

- I can describe glucose or hormone data with peaks, timings and percentage changes. *(Guide: Worked example 1; Practice Q4)*
- I can use a simple model to show how a negative feedback correction shrinks and a positive feedback change grows. *(Guide: Worked example 2; Practice Q7)*
- I can describe a slow-start, steep-rise, levelling-off pattern using numbers from a table. *(Practice Q6)*

## Reasoning

- I can find the broken link in a loop and predict what the variable and the signal will do. *(Guide: "When feedback fails"; Practice Q3, Q4)*
- I can explain the difference between type 1 and type 2 diabetes as two different broken links in the same loop. *(Guide: "When feedback fails"; Worked example 1)*
- I can use evidence from several treatment groups to justify a claim that a process involves positive feedback. *(Practice Q6)*
