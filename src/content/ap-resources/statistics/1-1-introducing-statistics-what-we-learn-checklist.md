Guide = [study guide](/advanced-course-resources/statistics/1-1-introducing-statistics-what-we-learn-study-guide/); Practice = [practice questions](/advanced-course-resources/statistics/1-1-introducing-statistics-what-we-learn-practice/).

## Understanding

- I can explain why statistics is needed when the answer to a question varies from one individual to another. *(Guide: "What can we learn from data?")*
- I can describe what a statistical study is: data from a sample used to answer a question about a larger population. *(Guide: "The parts of a statistical study")*
- I can give reasons a study uses a sample, such as size, cost, difficulty or measurements that destroy the item. *(Guide: "Why use a sample?"; Practice Q7)*
- I can explain why a sample result is not exactly the value for the whole population. *(Guide: "Writing in context"; Practice Q7)*

## Skills

- I can identify the population and the sample in a described study, including when the individuals are not people. *(Guide: Worked example 1; Practice Q1, Q5)*
- I can state N and n correctly and never swap them. *(Practice Q3, Q5, Q7)*
- I can give an example of a datum and describe the data set for a study. *(Guide: Worked example 1; Practice Q5)*
- I can decide whether a question needs a statistical investigation to answer it. *(Guide: "What makes a good investigative question?"; Practice Q2)*

## Reasoning

- I can judge whether an investigative question has a clear purpose and asks for data that can be collected and analysed, and rewrite it if not. *(Guide: Worked example 2; Practice Q6)*
- I can explain why the investigative question must not be changed after the data are analysed. *(Guide: Worked example 2; Practice Q4)*
- I can state a result in context, naming the individuals, what was recorded and the units. *(Guide: "Writing in context"; Practice Q5, Q7)*
