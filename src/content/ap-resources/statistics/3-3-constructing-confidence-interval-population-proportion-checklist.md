Guide = [study guide](/advanced-course-resources/statistics/3-3-constructing-confidence-interval-population-proportion-study-guide/); Practice = [practice questions](/advanced-course-resources/statistics/3-3-constructing-confidence-interval-population-proportion-practice/).

## Understanding

- I can explain the difference between a point estimate and an interval estimate. *(Guide: "From one number to a range of values")*
- I can explain what the standard error of p̂ measures and why it uses p̂ instead of p. *(Guide: "Step 4")*
- I can explain why the margin of error is half the width of the interval. *(Guide: Figure 2; Practice Q3)*
- I can explain why p̂ = 0.5 gives the largest sample size needed. *(Guide: Worked example 3; Practice Q6)*

## Skills

- I can name the one-sample z-interval for a population proportion and define p with the proportion, the response and the population. *(Guide: "Step 1"; Practice Q5)*
- I can check the random, 10% and large-counts conditions in context, with numbers. *(Guide: "Step 2"; Practice Q2, Q5)*
- I can find z* for any confidence level using the area (1 + C)/2. *(Guide: "Step 3"; Practice Q1)*
- I can calculate the standard error, the margin of error and the interval, keeping p̂ unrounded. *(Guide: Worked examples 1 and 2; Practice Q4)*
- I can find p̂ and the margin of error from a reported interval. *(Guide: "Working backwards"; Practice Q3)*
- I can find the smallest sample size for a chosen margin of error and round it up. *(Guide: Worked example 3; Practice Q6)*

## Reasoning

- I can decide when a z-interval should not be used because a condition fails, and say which one. *(Guide: Worked example 2; Practice Q2)*
- I can find and correct errors in someone else's interval, including the parameter, the conditions and z*. *(Practice Q7)*
